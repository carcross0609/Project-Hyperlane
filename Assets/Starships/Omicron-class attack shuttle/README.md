# Omicron-class attack shuttle

**Continuity:** Canon  
**Source:** [Omicron-class attack shuttle](https://starwars.fandom.com/wiki/Omicron-class_attack_shuttle)

The Omicron-class attack shuttle, also known as an Omicron-class shuttle,, Omicron-class gunship or simply, the Omicron was a class of attack shuttle that was active during the Clone Wars. The Marauder, the starship of the Galactic Republic's Clone Force 99, was a modified Omicron-class attack shuttle. Halland Goth and TC-99 would later pilot one to visit the Diso system.

- **Name:** Omicron-class attack shuttle

- **Affiliation:**
