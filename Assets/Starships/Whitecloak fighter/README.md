# Whitecloak fighter

**Continuity:** Legends  
**Source:** [Whitecloak fighter](https://starwars.fandom.com/wiki/Whitecloak_fighter)

Whitecloak fighters were modified CloakShape fighters employed by the Jedi Order prior to the Clone Wars.

## Specifications

- **Name:** Whitecloak fighter
- **Model:** Modified CloakShape fighter
- **Type:** Starfighter
- **Cost:**
  - New: 150,000 credits
  - Used: 100,000 credits
- **Length:** 15 meters
- **Max Speed:** 1,000 km/h
- **Hyperdrive:** Class 1.5
- **Armament:**
  - Light laser cannons (2)
  - Concussion missile launchers (2)
  -   8 missiles each
- **Crew:** Pilot (1)
- **Passengers:** 1 or 2
- **Capacity:** 40 kg
- **Consumables:** 2 weeks
- **Role:** Interceptor
- **Affiliation:** Jedi Order
