# System Defense Ship

**Continuity:** Legends  
**Source:** [System Defense Ship](https://starwars.fandom.com/wiki/System_Defense_Ship)

A System Defense Ship was a class of starship used by the Kalindan Deep Space Fleet and Kalindan System Defense Force. Four ships of that class were deployed during the Battle of Kalinda.
