# Molator; (Savrip)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Molator (Vindicator-class)](https://starwars.fandom.com/wiki/Molator_%28Vindicator-class%29)

Molator, originally known as Savrip, was the first Vindicator-class vessel that was not converted into an Interdictor cruiser. It served in the Imperial Starfleet, and patrolled the Mid Rim during the height of the Empire. Savrip was later captured by the Rebel Alliance and renamed Molator. The Rebels used this cruiser as an armed diplomatic vessel, sending it throughout the Outer Rim in search of more support for the Alliance.
