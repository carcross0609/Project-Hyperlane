# Exactor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Exactor/Legends](https://starwars.fandom.com/wiki/Exactor/Legends)

The Exactor was the second Imperator-class Star Destroyer to be produced. It was one of the first ships of a design that would later become infamous under the name Imperial-class Star Destroyer.

## Specifications

- **Name:** Exactor
- **Model:** Imperator-class Star Destroyer
- **Crew:** R4-K5
- **Affiliation:** Galactic Empire
- **Owners:** Darth Vader
