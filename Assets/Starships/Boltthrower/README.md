# Boltthrower

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Boltthrower](https://starwars.fandom.com/wiki/Boltthrower)

The Boltthrower was an Imperial EF76 Nebulon-B escort frigate. It was responding to an attack on a Cargo Transfer Area which the BFF-1 bulk freighter Libom, which carried new surveillance probes for the Relentless, was disabled. Despite assistance from the CR90 corvette Scorpion and the frigate's own TIE/IN interceptors and TIE/sa bombers, the freighter was captured and the Scorpion was destroyed.
