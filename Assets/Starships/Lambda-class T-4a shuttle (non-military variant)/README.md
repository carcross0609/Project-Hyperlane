# Lambda-class T-4a shuttle

**Continuity:** Canon  
**Source:** [Lambda-class T-4a shuttle (non-military variant)](https://starwars.fandom.com/wiki/Lambda-class_T-4a_shuttle_%28non-military_variant%29)

After producing a miltary varient of the Lambda-class T-4a shuttle, as subcontracted by Raith Sienar of Sienar Fleet Systems, Cygnus Spaceworks created a non-military variant of the Lambda-class T-4a, which appears identical to the standard version aside from a few minor subtle details. With this version of the shuttle, Cygnus Spaceworks attempted to compete directly with Sienar Fleet Systems.

## Specifications

- **Name:** Lambda-class T-4a shuttle
- **Manufacturer:** Cygnus Spaceworks
- **Line:** Abecederian line
- **Model:** Lambda-class T-4a shuttle
- **Hull:** Heavy armor
