# Crescent-class Transport Mark II

**Continuity:** Legends  
**Source:** [Crescent-class Transport Mark II](https://starwars.fandom.com/wiki/Crescent-class_Transport_Mark_II)

The Crescent-class Mark II Transport or Crescent-class Mark II freighter was a fast luxury courier manufactured by Hyrotii Corporation.

- **Name:** Crescent-class Transport Mark II
- **Manufacturer:** Hyrotii Corporation
- **Model:** Light freighter
- **Cost:**

  - 125,000 (used)
- **Length:** 30 meters
- **Max Speed:** 950 KMH
- **Hyperdrive:** None
- **Sensor:** Equipped
- **Navigation:** Equipped
- **Armament:** 1 Light Laser cannon
- **Crew:** 1-2
- **Passengers:** (Varied) Up to 8
- **Capacity:** 80 metric tons
- **Consumables:** 2 months
- **Role:** Freighter
