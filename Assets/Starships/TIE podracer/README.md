# TIE podracer

**Continuity:** Legends  
**Source:** [TIE podracer](https://starwars.fandom.com/wiki/TIE_podracer)

The TIE podracer was a racing pod that resembled a TIE Series starfighter. It had faster acceleration, higher top speed, greater durability, better maneuverability, more efficient cooling, and was easier to repair than any other known podracer except the Sith Infiltrator podracer.
