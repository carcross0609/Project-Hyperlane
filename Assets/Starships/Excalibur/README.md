# Excalibur

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Excalibur](https://starwars.fandom.com/wiki/Excalibur)

The Excalibur was Emperor Palpatine's personal C-3 passenger liner, which he used during the Galactic Civil War.

## Specifications

- **Name:** Excalibur
- **Manufacturer:** Leonore Luxury Liners Incorporated
- **Line:** C-3 passenger liner
- **Length:** 409 meters
- **Width:** 132 meters
- **Height:** 94 meters
- **Affiliation:** Galactic Empire
- **Owners:** Emperor Palpatine
