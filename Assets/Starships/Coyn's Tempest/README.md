# Coyn's Tempest

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Coyn's Tempest](https://starwars.fandom.com/wiki/Coyn%27s_Tempest)

The Coyn's Tempest was a Ye-4 gunship that was used as a flagship by a band of Coynite mercenaries active in the Dathomir system during the Galactic Civil War.

## Specifications

- **Name:** Coyn's Tempest
- **Model:** Ye-4 gunship
- **Destroyed:** 1 ABY, Dathomir system
- **Affiliation:** Coynite mercenaries
