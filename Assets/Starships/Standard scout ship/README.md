# Standard scout ship

**Continuity:** Legends  
**Source:** [Standard scout ship](https://starwars.fandom.com/wiki/Standard_scout_ship)

Standard scout ships were small, lightly armed craft commonly used by explorers. They also made up the fleet of the Merson slavers. Though not meant for heavy combat, they could easily outgun the transports Merson slavers preyed upon.

## Specifications

- **Name:** Standard scout ship
- **Type:** Standard scout ship
- **Engine:** 2 engine units
- **Armament:** Laser cannon (1)
- **Role:** Scout ship
- **Affiliation:** Merson pirates
