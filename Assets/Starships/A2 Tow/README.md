# A2 Tow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [A2 Tow](https://starwars.fandom.com/wiki/A2_Tow)

A2 Tow was an Rebel Alliance Heavy Lifter that was picking up and delivering supplies Admiral Harkov's Flagship the Victory-class Star Destroyer Protector during his attempt to defect to the Alliance.
