# VA-13 Sweeper

**Continuity:** Legends  
**Source:** [VA-13 Sweeper](https://starwars.fandom.com/wiki/VA-13_Sweeper)

The VA-13 Sweeper was a ship constructed by the Daedalus Gas Mines Corporation for use in radiocarbon harvesting, which involved dredging an ion-rich atmosphere for radioactive carbon isotopes.
