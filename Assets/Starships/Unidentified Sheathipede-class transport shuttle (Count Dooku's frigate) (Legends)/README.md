# Unidentified Sheathipede-class transport shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Sheathipede-class transport shuttle (Count Dooku's frigate)/Legends](https://starwars.fandom.com/wiki/Unidentified_Sheathipede-class_transport_shuttle_%28Count_Dooku%27s_frigate%29/Legends)

A Sheathipede-class transport shuttle was stolen from Count Dooku's frigate by Jedi Generals Anakin Skywalker and Obi-Wan Kenobi during a skirmish of the Clone Wars. Skywalker and Kenobi used it to pursue Count Dooku to Vanqor, where both parties crash-landed.
