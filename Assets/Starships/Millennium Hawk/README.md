# Millennium Hawk

**Continuity:** Legends  
**Source:** [Millennium Hawk](https://starwars.fandom.com/wiki/Millennium_Hawk)

The Millennium Hawk was a model of starship manufactured by Millennium Astro-Engineering. They were popular among criminals in the galaxy's Outer Rim Territories.

## Specifications

- **Name:** Millennium Hawk
- **Manufacturer:** Millennium Astro-Engineering
- **Type:** Starship
- **Engine:** Sublight drives (2)
- **Power:** Central power core
