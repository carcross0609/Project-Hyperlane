# Channel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Channel](https://starwars.fandom.com/wiki/Channel)

Channel was a Lambda-class T-4a shuttle used by the Rebel Alliance. The shuttle was present at the Rebel Summit at the Delfii system, carrying "Com Staff".
