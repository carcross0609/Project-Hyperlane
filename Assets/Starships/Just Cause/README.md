# Just Cause

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Just Cause](https://starwars.fandom.com/wiki/Just_Cause)

The Just Cause was a starfreighter that crashed in Rathalay's western ocean. The legend says that precious metals were found in the hull some 900 meters deep being guarded by schools of narkaa.
