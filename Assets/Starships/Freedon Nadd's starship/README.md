# Freedon Nadd's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Freedon Nadd's starship](https://starwars.fandom.com/wiki/Freedon_Nadd%27s_starship)

Freedon Nadd's starship was the vessel he used to travel to Onderon. Its remains were used as a Jedi base c. 4,000 BBY.
