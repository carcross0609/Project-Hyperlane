# Valiant (armored transport ship)

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Valiant (armored transport ship)](https://starwars.fandom.com/wiki/Valiant_%28armored_transport_ship%29)

Valiant was an Imperial armored transport ship. Stormtroopers were asking if anyone had heard of this ship in the Mos Eisley Cantina when Sithless Leethe was selling the Limping Lady to a group of wannabe Rebels.
