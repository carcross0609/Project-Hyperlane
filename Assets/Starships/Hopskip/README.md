# Hopskip

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hopskip](https://starwars.fandom.com/wiki/Hopskip)

The Hopskip was a modified YT-1300 light freighter operated by smugglers Haber Trell and Maranne Darmic, who mainly smuggled weapons for the Rebel Alliance on Derra IV. It was destroyed by the 181st Imperial Fighter Group above Derra IV.
