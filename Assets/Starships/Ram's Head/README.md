# Ram's Head

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ram's Head](https://starwars.fandom.com/wiki/Ram%27s_Head)

The Ram's Head was a Rebel Alliance CR90 corvette, the first and only ship to be outfitted with the experimental Shield X deflector shield.

## Specifications

- **Name:** Ram's Head
- **Type:** CR90 corvette
- **Shield Gen:** Shield X deflector shield
- **Role:** Corvette
- **Affiliation:** Alliance to Restore the Republic
