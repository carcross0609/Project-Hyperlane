# Pickaxe

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pickaxe](https://starwars.fandom.com/wiki/Pickaxe)

Pickaxe was a Naboo Moon Mining Union kassoti spice transport that ran between Naboo and Rori, captained by Calquad Dominé. In 22 BBY, it prevented the Sluissi Wanderlust from landing in Kwilaan Starport.
