# Folna

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Folna](https://starwars.fandom.com/wiki/Folna)

The Folna was a Agave-class picket ship in the New Republic Navy, commanded by Colonel Foag, and captained by Captain Madis.
