# TIE/se Bomber

**Continuity:** Canon  
**Source:** [TIE/se Bomber](https://starwars.fandom.com/wiki/TIE/se_Bomber)

The TIE/se Bomber, also known as the First Order TIE bomber, was a class of TIE fighter series bomber using by the First Order during its war with the Resistance.

## Specifications

- **Name:** TIE/se Bomber
- **Line:** TIE series
- **Type:** Bomber
- **Engine:** Twin ion engine
- **Armament:**

  - Laser cannons (4)
- **Role:** Bombardment
- **Affiliation:**
  - First Order
  -   First Order starfighter corps
