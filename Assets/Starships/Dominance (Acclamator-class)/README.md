# Dominance (Acclamator-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dominance (Acclamator-class)](https://starwars.fandom.com/wiki/Dominance_%28Acclamator-class%29)

The Dominance was an Acclamator-class assault ship serving the Grand Army of the Republic during the Clone Wars. The Dominance was dispatched to the planet Jabiim, in an effort to prevent a secessionist war.
