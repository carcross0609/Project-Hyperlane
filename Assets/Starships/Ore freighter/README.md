# Ore freighter

**Continuity:** Canon  
**Source:** [Ore freighter](https://starwars.fandom.com/wiki/Ore_freighter)

An ore freighter was a ship that hauled ores across the galaxy. Filia Rossi was First officer on an escort ship of such a freighter until becoming captain of the Blood Crow.
