# TL-1800 light freighter

**Continuity:** Legends  
**Source:** [TL-1800 light freighter/Legends](https://starwars.fandom.com/wiki/TL-1800_light_freighter/Legends)

The TL-1800 transport, also known as the TL-1800 freighter or TL-1800 light freighter, was a light freighter manufactured by Suwantek Systems as part of their TL-series line.

## Specifications

- **Name:** TL-1800 light freighter
- **Manufacturer:** Suwantek Systems
- **Line:** TL-series
- **Model:** TL-1800 transport
- **Type:** Light freighter
- **Cost:**
  - 41,500 credits (new)
  - 28,000 credits
- **Length:** 30 meters
- **Max Speed:** 800 km/h
- **Engine:** 5 Y-v-6 model sublight drive
- **Hyperdrive:**
  - Class 2.0
  - Class 10 backup
- **Hdsystem:** StarBurn 4 hyperdrive
- **Armament:** SFS Laser cannons (2)
- **Crew:** 2
- **Skeleton:** 1
- **Passengers:** 7
- **Capacity:**

  - 400 metric tons (with external cargo pods)
- **Consumables:** 3 months
- **Affiliation:**
  - Hand of Judgment
  - Imperial Security Bureau
