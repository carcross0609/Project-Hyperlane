# Sargantuan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sargantuan/Legends](https://starwars.fandom.com/wiki/Sargantuan/Legends)

The Sargantuan was a Raider-class corvette that served alongside the Warhawk and the Blood Ambition.

- **Name:** Sargantuan
- **Manufacturer:** Kuat Drive Yards
- **Model:** Raider-class corvette
- **Type:** Corvette
- **Length:** 150 meters
- **Engine:**

  - 1 large engine
- **Armament:**
  - Dual heavy laser cannons (6)
  - Single turbolasers
  - Ion cannons
  - Concussion missile launcher
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:**
  - 14th Sector Fleet
  -   Ralchio Nervi's task force
