# Casement's ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Casement's ship](https://starwars.fandom.com/wiki/Casement%27s_ship)

Casement's ship was a starship which belonged to a Rebel operative codenamed Casement. It was produced by Surronians and had an armored inner hull.
