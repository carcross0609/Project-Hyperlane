# Starcrusher

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Starcrusher](https://starwars.fandom.com/wiki/Starcrusher)

The Starcrusher was a battleship active during the Clone Wars. The Galactic Republic sent a squadron of Venator-class Star Destroyers to attack the Separatist fuel tanker Aurora in an attempt to draw out the Starcrusher, though the Aurora was able to escape.
