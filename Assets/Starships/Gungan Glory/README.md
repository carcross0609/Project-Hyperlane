# Gungan Glory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gungan Glory](https://starwars.fandom.com/wiki/Gungan_Glory)

The Gungan Glory was a starfighter owned by Piknab Carsels. It was paid for by financing from Riboga the Hutt and the Smugglers' Confederation.
