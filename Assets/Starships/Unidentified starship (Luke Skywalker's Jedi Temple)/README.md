# Unidentified starship

**Continuity:** Canon  
**Source:** [Unidentified starship (Luke Skywalker's Jedi Temple)](https://starwars.fandom.com/wiki/Unidentified_starship_%28Luke_Skywalker%27s_Jedi_Temple%29)
