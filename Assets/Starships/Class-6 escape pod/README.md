# Class-6 escape pod

**Continuity:** Canon  
**Source:** [Class-6 escape pod](https://starwars.fandom.com/wiki/Class-6_escape_pod)

The Class-6 escape pod was a model of escape pod. The Tantive IV was equipped with eight Class-6 escape pods, one of which was used by R2-D2 and C-3PO during the secret mission to Tatooine.

## Specifications

- **Name:** Class-6 escape pod
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Escape pod
- **Engine:**
  - Four escape thrusters
  - Six maneuvering thrusters
- **Passengers:** Six
- **Role:** Escape craft
- **Affiliation:** Alliance to Restore the Republic
