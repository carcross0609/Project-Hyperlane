# Starhawk shuttle

**Continuity:** Legends  
**Source:** [Starhawk shuttle](https://starwars.fandom.com/wiki/Starhawk_shuttle)

The Starhawk shuttle was a class of shuttle. At least one Starhawk shuttle was used around the time of the Second Galactic Civil War.
