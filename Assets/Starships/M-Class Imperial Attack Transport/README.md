# M-Class Imperial Attack Transport

**Continuity:** Legends  
**Source:** [M-Class Imperial Attack Transport](https://starwars.fandom.com/wiki/M-Class_Imperial_Attack_Transport)

The M-Class Imperial Attack Transport was a type of starship which saw service in the Imperial Military during the Galactic Civil War. The Regina Cayli was a known M-Class Imperial Attack Transport.

## Specifications

- **Name:** M-Class Imperial Attack Transport
- **Type:** Transport
- **Armament:** Torpedoes
- **Escapepods:** Equipped
- **Affiliation:** Galactic Empire
