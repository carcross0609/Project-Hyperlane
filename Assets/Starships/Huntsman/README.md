# Huntsman

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Huntsman](https://starwars.fandom.com/wiki/Huntsman)

The Huntsman was an Imperial Strike-class medium cruiser during the Galactic Civil War. It was to arrive as reinforcements along with Assault Gunboats should the Tortali Platform be unable to handle the Rebel strike force.

## Specifications

- **Name:** Huntsman
- **Type:** Strike-class medium cruiser
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
