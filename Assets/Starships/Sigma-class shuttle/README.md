# Sigma-class shuttle

**Continuity:** Legends  
**Source:** [Sigma-class shuttle](https://starwars.fandom.com/wiki/Sigma-class_shuttle)

The Sigma-class shuttle was a Koensayr Manufacturing shuttlecraft that was considered obsolete by 2 ABY, but continued to see use by traders and criminals such as the Granse Confederacy.
