# Warhog

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Warhog](https://starwars.fandom.com/wiki/Warhog)

The Warhog was a VGK-3 Shooting Star class starfighter prototype that was stolen by Alliance Infiltrator Bryce Agoris and freelance operative Myrgaanti Shi-Iki.

- **Name:** Warhog

- **Type:** VGK-3 Shooting Star class starfighter
- **Length:** 19 meters
- **Max Speed:** 1,000 kmh
- **Hyperdrive:** Class 1

- **Armament:**

- **Crew:** 1; 1 gunner

- **Consumables:** 1 week
- **Owners:**
