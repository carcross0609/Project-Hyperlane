# Stoneskipper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Stoneskipper](https://starwars.fandom.com/wiki/Stoneskipper)

The Stoneskipper was a small skiff that was docked on Lando Calrissian's Colossus I Beta Series asteroid tug, the Rockhound.
