# Spiral-class Viz-Core Eviscerator

**Continuity:** Canon  
**Source:** [Spiral-class Viz-Core Eviscerator](https://starwars.fandom.com/wiki/Spiral-class_Viz-Core_Eviscerator)

The Spiral-class Viz-Core Eviscerator was a ship model used during the High Republic Era. It was in service before the Eiram and E'ronoh War. The ship had no viewport so the pilot had to rely on primitive sensor systems and The Force to operate it. The weapons of the ship were described as ancient and brutal. The ships main way of attacking was by using a drill to puncture the hulls of enemy ships and burrowing to their reactor core. After the Battle of Jedha, the Republic petitioned to ban them.

## Specifications

- **Name:** Spiral-class Viz-Core Eviscerator
- **Designer:** Frander
- **Model:** Spiral-class Viz-Core Eviscerator
- **Type:** Drill ship
- **Hull:** VIX-force metallic blast-proof shielding
- **Navigation:** Modulated navicomputer
- **Armament:** Twin canister omega cannons
