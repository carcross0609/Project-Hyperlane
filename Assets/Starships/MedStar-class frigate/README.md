# MedStar-class frigate

**Continuity:** Canon  
**Source:** [MedStar-class frigate](https://starwars.fandom.com/wiki/MedStar-class_frigate)

The MedStar-class frigate was a class of medical frigate used by the Republic Navy during the Clone Wars, which lasted from 22 BBY to 19 BBY, between the Galactic Republic and the Confederacy of Independent Systems. Injured clone troopers requiring long-term care were transferred from Republic Mobile Surgical Units to larger medical facilities, which included MedStar-class frigates.

## Specifications

- **Name:** MedStar-class frigate
- **Type:** Frigate
- **Role:** Hospital ship
- **Affiliation:**
  - Galactic Republic
  -   Galactic Republic Navy
