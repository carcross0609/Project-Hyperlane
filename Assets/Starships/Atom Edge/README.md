# Atom Edge

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Atom Edge](https://starwars.fandom.com/wiki/Atom_Edge)

Atom Edge was a freighter affiliated with the Rebel Alliance in use after the Battle of Yavin. It was carrying supplies to the Rebels on Tatooine when it was shot down. The Galactic Empire arrived at the crashsite first, and set up a trap for the Rebels. When Saponza's partner's forces arrived to salvage, the Imperials attacked, although they were defeated. The Rebels then recovered supplies.

## Specifications

- **Name:** Atom Edge
- **Type:** Freighter
- **Role:** Transport
- **Destroyed:** After the Battle of Yavin
- **Affiliation:** Alliance to Restore the Republic
