# Oppressor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Oppressor (Harrower-class)](https://starwars.fandom.com/wiki/Oppressor_%28Harrower-class%29)

The Oppressor was a Harrower-class dreadnought that served as the flagship of Darth Angral during the Cold War.
