# Pushti

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pushti](https://starwars.fandom.com/wiki/Pushti)

Pushti was a CR90 corvette in the Alliance Fleet. It was present during the Battle of Endor. It also was a part of the Liberty task force at Sullust prior to the battle.
