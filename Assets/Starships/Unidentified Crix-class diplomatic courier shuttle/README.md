# Unidentified Crix-class diplomatic courier shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Crix-class diplomatic courier shuttle](https://starwars.fandom.com/wiki/Unidentified_Crix-class_diplomatic_courier_shuttle)

Galactic Alliance Remnant Admiral Gar Stazi traveled to The Wheel in 137 ABY aboard a Crix-class diplomatic courier shuttle. The shuttle was later fired upon by a Nune-class Imperial shuttle of the Empire-in-exile, whose controls had been overridden by four Command Override Limpet Droids planted by agents of the One Sith and Darth Krayt's Galactic Empire.
