# CR20 troop carrier

**Continuity:** Legends  
**Source:** [CR20 troop carrier/Legends](https://starwars.fandom.com/wiki/CR20_troop_carrier/Legends)

The CR20 troop carrier or CR-20 trooper carrier was a type of transport ship used to deploy small units of clone troopers.

## Specifications

- **Name:** CR20 troop carrier
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** CR20 troop carrier
- **Type:** Troop carrier
- **Cost:** 680,000 credits (265,000 used)
- **Length:** 60 meters
- **Max Speed:** 850 km/h
- **Hyperdrive:** Class 3 (backup class 12)
- **Shield Gen:** Equipped
- **Armament:** Double turbolaser cannons (2)
- **Complement:** 74-Z speeder bikes (12)
- **Escapepods:** 4
- **Crew:**
  - Pilots (2)
  - Communications officer (1)
  - Engineers (3)
- **Passengers:** 40 clone troopers
- **Capacity:** 15 tons
- **Consumables:** 2 weeks
- **Availability:** Restricted
- **Role:** Troop carrier
- **Affiliation:**
  - Corellian Defense Force
  - Galactic Republic
  - Confederacy of Independent Systems
