# Lightning (shuttle group)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lightning (shuttle group)](https://starwars.fandom.com/wiki/Lightning_%28shuttle_group%29)

Lightning was a pair of Rebel Lambda-class T-4a shuttles that, along with shuttle groups Typhoon and Thunder, took part in the first phrase of Operation Grain Snatch. Their role was to capture the Y-wing escorts of Overlord Ghorin's CR90 corvette Halifax, which contained grain for the Empire. Keyan Farlander disabled all the Y-wings and the shuttles captured the Y-wings so that they could be used to discredit Ghorin.
