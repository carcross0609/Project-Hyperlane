# Isilia

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Isilia](https://starwars.fandom.com/wiki/Isilia)

The Isilia was a Ghtroc Industries 440 freighter owned and operated by Captain Adriav Kavos. It was crewed by the Arconan Gezzov-tak, the Ortolan Nabkess, and the Quarren Segken Tels.
