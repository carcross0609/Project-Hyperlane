# Unidentified freighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified freighter (Torban Buck)](https://starwars.fandom.com/wiki/Unidentified_freighter_%28Torban_Buck%29)

A freighter was active following the Great Hyperspace Disaster during the High Republic Era. In order to assist with injured individuals following the disaster, the freighter was refitted to serve as mobile hospital for the injured.
