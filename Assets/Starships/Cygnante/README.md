# Cygnante

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cygnante](https://starwars.fandom.com/wiki/Cygnante)

The Cygnante was a highly modified Mark I Bulk Transport, and was used by members of the Shield organization. The ship had been reinforced to be battle worthy, and to serve as a home base for extended periods without resupply. The Cygnante also had five false transponders, which could be used to give false ship identification codes to Imperial patrol cruisers.
