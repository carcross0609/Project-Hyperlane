# Experimental V-wing

**Continuity:** Legends  
**Source:** [Experimental V-wing](https://starwars.fandom.com/wiki/Experimental_V-wing)

The Experimental V-wing was an experimental model of the Alpha-3 Nimbus-class V-wing starfighter, which served the Republic Starfighter Corps during the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems. This model was equipped with a compact hyperdrive of limited capacity. A number of these fighters were rumored to belong to an elite crimson-clad pilot brigade that reported directly to Supreme Chancellor Palpatine.
