# Red 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red 1](https://starwars.fandom.com/wiki/Red_1)

Red 1 was a T-65 X-wing starfighter in service to the Alliance to Restore the Republic during the Galactic Civil War. The fighter was flown by Red Leader Garven Dreis, and had previously been stationed at Dantooine base prior to being transferred to Yavin 4. R5-K6 served as Red 1's astromech droid.
