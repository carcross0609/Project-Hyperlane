# Fury

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fury (Imperial-class)](https://starwars.fandom.com/wiki/Fury_%28Imperial-class%29)

The Fury was an Imperial-class Star Destroyer that was a part of Lumiya's fleet shortly after the Battle of Endor. It could carry 72 TIE Fighters.

## Specifications

- **Name:** Fury
- **Model:** Imperial-class Star Destroyer
- **Complement:** TIE/LN starfighters
- **Affiliation:** Galactic Empire
- **Navy:** Lumiya's fleet
- **Owners:** Lumiya
