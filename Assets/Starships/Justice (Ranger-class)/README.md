# Justice

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Justice (Ranger-class)](https://starwars.fandom.com/wiki/Justice_%28Ranger-class%29)

The Justice was a Ranger-class gunship used by the New Republic. During Operation Trinity, the Justice was part of a task force assigned to the Mon Mothma.
