# 903 Transport

**Continuity:** Legends  
**Source:** [903 Transport](https://starwars.fandom.com/wiki/903_Transport)

The 903 Transport or Harkners-Balix 903 was a transport ship, similar to the Harkners-Balix 917 and 922 models. Wedge Antilles referred to the Etherway as a Harkners-Balix 903 when he met Mara Jade on Abregado-rae, as part of an elaborate identification scheme set up by Fynn Torve.
