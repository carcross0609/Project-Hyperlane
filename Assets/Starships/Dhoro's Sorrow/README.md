# Dhoro's Sorrow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dhoro's Sorrow](https://starwars.fandom.com/wiki/Dhoro%27s_Sorrow)

Dhoro's Sorrow was the personal starship of the criminal named Grintlok. In 2 ABY he and his accomplices used it to travel from the Nelvana Gas Cluster to Cataalda.

## Specifications

- **Name:** Dhoro's Sorrow
- **Owners:** Grintlok
