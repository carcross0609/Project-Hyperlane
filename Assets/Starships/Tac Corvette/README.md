# Tac Corvette

**Continuity:** Canon  
**Source:** [Tac Corvette](https://starwars.fandom.com/wiki/Tac_Corvette)

A Tac Corvette was a type of corvette used during the Imperial Era. In 5 BBY, a Tac Corvette was expected by Bix Caleen to arrive at Ferrix within the week looking for scrap.
