# Class VI bulk freighter

**Continuity:** Legends  
**Source:** [Class VI bulk freighter](https://starwars.fandom.com/wiki/Class_VI_bulk_freighter)

The Class VI bulk freighter was a type of cargo hauler built by Corellian Engineering Corporation, considered antiquated by the time of the Galactic Civil War. It was developed from the earlier Praetorian-class frigate.
