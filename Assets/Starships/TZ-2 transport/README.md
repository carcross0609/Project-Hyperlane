# TZ-2 transport

**Continuity:** Legends  
**Source:** [TZ-2 transport](https://starwars.fandom.com/wiki/TZ-2_transport)

The TZ-2 transport was a transport class that was the basis for the smaller TZ-24 Enforcer, a model of starfighter that was designed before the start of the Great Galactic War between the Galactic Republic and the Sith Empire.
