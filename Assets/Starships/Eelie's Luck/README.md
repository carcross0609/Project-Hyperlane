# Eelie's Luck

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eelie's Luck](https://starwars.fandom.com/wiki/Eelie%27s_Luck)

Eelie's Luck was a starship that was used by a Quarren smuggler captain. The Quarren named the craft after Eelie, a female Twi'lek who got herself into a number of dangerous situations, without ever coming to harm.
