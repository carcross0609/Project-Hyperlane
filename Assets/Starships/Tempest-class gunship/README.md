# Tempest-class gunship

**Continuity:** Legends  
**Source:** [Tempest-class gunship](https://starwars.fandom.com/wiki/Tempest-class_gunship)

The Tempest-class gunship was a type of small attack craft the size of a light freighter. It was in use around the time of the Battle of Naboo, and was used by criminal elements. The Hawk-Bat was perhaps the most famous Tempest.
