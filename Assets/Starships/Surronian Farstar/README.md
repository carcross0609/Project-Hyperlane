# Surronian Farstar

**Continuity:** Legends  
**Source:** [Surronian Farstar](https://starwars.fandom.com/wiki/Surronian_Farstar)

Surronian Farstars were starships that predated the Galactic Empire. By 1 ABY, they were considered first class collector's items. Lando Calrissian had three in his used starship lot on Nar Shaddaa, which he decisively wagered against the Cloud City in his Sabacc game with the corrupt Baron Administrator Dominic Raynor.
