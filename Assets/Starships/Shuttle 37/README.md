# Shuttle 37

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shuttle 37](https://starwars.fandom.com/wiki/Shuttle_37)

Shuttle 37 was an Imperial shuttle originally designed to supply the Imperial II-class Star Destroyer Chimaera in the Wistril system.

- **Role:** Supply Shuttle
