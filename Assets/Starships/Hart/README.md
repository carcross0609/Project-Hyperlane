# Hart

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hart](https://starwars.fandom.com/wiki/Hart)

Hart was a CR90 corvette that served with the Rebel Alliance Fleet during the Galactic Civil War. The warship's most notable mission came when it was tasked with helping to evacuate the Alliance EF76 Nebulon-B escort frigate Anvil. Thanks to its Rebel escorts, it escaped with the Anvil survivors.

## Specifications

- **Name:** Hart
- **Model:** CR90 corvette
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
