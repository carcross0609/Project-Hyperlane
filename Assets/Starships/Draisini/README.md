# Draisini

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Draisini](https://starwars.fandom.com/wiki/Draisini)

The Draisini was a Mining Guild Xiytiar-class heavy transport under the command of Captain Forma. It was hit by pirates under Sol Mon in 11 ABY.
