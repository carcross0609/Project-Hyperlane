# Perspicacity

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Perspicacity (New Sith Wars)](https://starwars.fandom.com/wiki/Perspicacity_%28New_Sith_Wars%29)

The Perspicacity was a starship that was used by the mercenary Beld Yulan during the Republic Dark Age. The Human Jarrow Rusher served aboard the ship for a time.

- **Name:** Perspicacity
