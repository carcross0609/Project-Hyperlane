# Satellite Liberator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Satellite Liberator](https://starwars.fandom.com/wiki/Satellite_Liberator)

The Satellite Liberator was a Bendine XR12 starship in operation at some point prior to the Invasion of Naboo. It was slightly smaller than an average escape pod.

- **Name:** Satellite Liberator
- **Manufacturer:** Bendine
