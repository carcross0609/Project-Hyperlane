# Asteroid crusher

**Continuity:** Legends  
**Source:** [Asteroid crusher](https://starwars.fandom.com/wiki/Asteroid_crusher)

Asteroid crushers were massive ships that could be used to mine the mineral contents of asteroids within an asteroid field. They needed a large crew to function and could be used as a mobile base of operations for mining companies. In 45 ABY, the Columi brothers, Craitheus and Marvid Qreph used an asteroid crusher, the Ormni as their mobile base within the Chiloon Rift.
