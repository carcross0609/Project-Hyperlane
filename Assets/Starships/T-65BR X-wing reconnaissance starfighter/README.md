# T-65BR X-wing reconnaissance starfighter

**Continuity:** Legends  
**Source:** [T-65BR X-wing reconnaissance starfighter](https://starwars.fandom.com/wiki/T-65BR_X-wing_reconnaissance_starfighter)

The T-65BR X-wing reconnaissance starfighter, commonly called the Recon-X or Snoopscoot, was a variant of the Incom T-65 X-wing starfighter modified for reconnaissance missions.

## Specifications

- **Name:** T-65BR X-wing reconnaissance starfighter
- **Manufacturer:** Incom Corporation
- **Line:** X-wing
- **Model:** T-65BR
- **Type:** Reconnaissance starfighter
- **Cost:**

  - 95,000 credits (used)
- **Max Speed:** 1,150 km/h
- **Engine:** 4L4 fusial thrust engine (4)
- **Hyperdrive:** Class 1
- **Armament:** Laser cannons (4)
- **Crew:**
  - Pilot (1)
  - R2-R-series astromech droid (1)
- **Passengers:** None
- **Capacity:** 110 kg
- **Consumables:** 1 week
- **Othersystems:** Deadman baradium charge (destroys the vessel and its recorded data if pilot is killed)
- **Availability:** Military
- **Role:** Scout
- **Affiliation:** New Republic
