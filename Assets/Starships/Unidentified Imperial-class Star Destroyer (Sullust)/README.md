# Unidentified Imperial-class Star Destroyer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Imperial-class Star Destroyer (Sullust)](https://starwars.fandom.com/wiki/Unidentified_Imperial-class_Star_Destroyer_%28Sullust%29)

This Imperial-class Star Destroyer was commanded by Captain Wankle during the Galactic Civil War. It patrolled near the planet Sullust, and conducted cargo inspections of ships entering and exiting the system.
