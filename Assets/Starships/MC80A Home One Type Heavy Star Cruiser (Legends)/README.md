# MC80A Home One Type Heavy Star Cruiser

**Continuity:** Legends  
**Source:** [MC80A Home One Type Heavy Star Cruiser/Legends](https://starwars.fandom.com/wiki/MC80A_Home_One_Type_Heavy_Star_Cruiser/Legends)

The MC80A Home One Type Heavy Star Cruiser, also known as the MC80 Home One type Star Cruiser or MC80 Command Cruiser, was one of the several MC80 Star Cruiser designs built by the Mon Calamari. Originally fielded before the Galactic Civil War as civilian vessels, they were modified by the Rebel Alliance, and served in command ship and battleship roles in the Alliance Fleet.
