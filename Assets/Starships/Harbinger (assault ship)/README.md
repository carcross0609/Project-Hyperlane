# Harbinger

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Harbinger (assault ship)](https://starwars.fandom.com/wiki/Harbinger_%28assault_ship%29)

The Harbinger was an assault ship owned and piloted by Bel Att while he worked for the Nalroni crimelord Sprax. Limna Yith stole the ship and used it as a ship for her mercenary work.

## Specifications

- **Name:** Harbinger
- **Type:** Assault ship
- **Owners:**
  - Bel Att
  - Limna Yith
