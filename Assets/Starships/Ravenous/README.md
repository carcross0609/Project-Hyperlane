# Ravenous

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Ravenous](https://starwars.fandom.com/wiki/Ravenous)

The Ravenous was a Maxima-A-class heavy cruiser of the First Order Navy around 30 years after the Battle of Endor. During the Cold War, Agent Terex commanded the ship during the Mission to Ovanis.

## Specifications

- **Name:** Ravenous
- **Model:** Maxima-A-class heavy cruiser
- **Complement:** TIE/fo space superiority fighters
- **Passengers:** Agent Terex
- **Commission:** Sometime before the mission to Ovanis
- **Affiliation:**
  - First Order
  -   First Order Navy
