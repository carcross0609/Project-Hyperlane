# Waq

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Waq](https://starwars.fandom.com/wiki/Waq)

Waq was the name given to a number of Heavy Lifters that were used by Admiral Harkov's fleet when they defected to the Rebellion.
