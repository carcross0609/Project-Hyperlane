# Tramp freighter

**Continuity:** Legends  
**Source:** [Tramp freighter/Legends](https://starwars.fandom.com/wiki/Tramp_freighter/Legends)

A tramp freighter was a type of independent freighter with no established scheduled ports of call, as opposed to a freight liner. Notable tramp freighters were the Dorion Discus, the Millennium Falcon, the Pulsar Skate and Beggar's Solace.
