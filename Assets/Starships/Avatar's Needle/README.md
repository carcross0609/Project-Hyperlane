# Avatar's Needle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Avatar's Needle](https://starwars.fandom.com/wiki/Avatar%27s_Needle)

Avatar's Needle was a Guardian-class light cruiser owned and operated by the bacta pirate Shanto Dhil. A former Imperial Customs ship, Dhil refused to divulge how he obtained the ship. Dhil personally modified the vessel at Port Bianco, expanding the cargo capacity by removing the existing hold and brige and replacing it with half-spherical cradle designed to connect with the storage tanks used by bacta transports.
