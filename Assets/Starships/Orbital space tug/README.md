# Orbital space tug

**Continuity:** Legends  
**Source:** [Orbital space tug](https://starwars.fandom.com/wiki/Orbital_space_tug)

The Orbital Space Tug was a type of space tug. It took the form was an orbiting satellite used for dragging objects into position in space, and was presumably equipped with a tractor beam or gravity well projector of some kind.
