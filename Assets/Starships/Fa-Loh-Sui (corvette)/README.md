# Fa-Loh-Sui

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fa-Loh-Sui (corvette)](https://starwars.fandom.com/wiki/Fa-Loh-Sui_%28corvette%29)

The Fa-Loh-Sui was the flagship of the Abin-Ral-Xufush. It was a CR90 corvette that originally belonged to an Outer Rim-based Rebel Alliance command before the Shadow Wing seized it. Abin named the ship after his former love interest, Fa-Loh-Sui.
