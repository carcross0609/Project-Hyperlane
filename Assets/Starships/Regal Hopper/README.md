# Regal Hopper

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Regal Hopper](https://starwars.fandom.com/wiki/Regal_Hopper)

The Regal Hopper was a cargo ship operated by Regal Star Freight. On one occasion, the starship transported grains from Yitabo to Keldooine.
