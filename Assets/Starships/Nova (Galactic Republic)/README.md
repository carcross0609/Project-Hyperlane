# Nova

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nova (Galactic Republic)](https://starwars.fandom.com/wiki/Nova_%28Galactic_Republic%29)

Nova was a cruiser in the Republic Navy that participated in the Battle of the Maelstrom, the mission of which was to free Revan from the Maelstrom Prison.
