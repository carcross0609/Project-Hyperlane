# Shieldship

**Continuity:** Legends  
**Source:** [Shieldship](https://starwars.fandom.com/wiki/Shieldship)

The Shieldship was a starship designed to protect ships while traveling to the planet Nkllon in the Athega system from Athega's superhot star. It was so hot that the dark side of Nkllon was the only habitable half of the planet though it was rich in mineral resources.
