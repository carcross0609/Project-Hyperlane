# Lightning

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lightning (Nebulon-B2 frigate)](https://starwars.fandom.com/wiki/Lightning_%28Nebulon-B2_frigate%29)

The Lightning was a Nebulon-B2 frigate that was part of Task Force Vengeance. It was involved in the failed attempt to destroy a rebel convoy intending to deliver B-wing starfighters to the Liberty.

## Specifications

- **Name:** Lightning
- **Manufacturer:** Kuat Drive Yards
- **Model:** Nebulon-B2 frigate
- **Type:** Frigate
- **Length:** 253.2 meters
- **Width:** 147.7 meters
- **Height:** 94.3 meters
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:** Task Force Vengeance
