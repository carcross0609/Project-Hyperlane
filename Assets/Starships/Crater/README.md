# Crater

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Crater](https://starwars.fandom.com/wiki/Crater)

Crater was an Assassin-class corvette belonging to the Rebel Alliance. It attempted to rescue the MC80 Star Cruiser Link when it was disabled but was instead destroyed by Tan Maarek Stele.
