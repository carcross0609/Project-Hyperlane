# Crane's YT-2400 light freighter

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Crane's YT-2400 light freighter](https://starwars.fandom.com/wiki/Crane%27s_YT-2400_light_freighter)

A YT-2400 light freighter was used by the Rebel Princess Crane following the evacuation of a rebel base on the planet Joetz. Crane sat in the YT-2400 light freighter's cockpit with the rescued Gigoran child Woopas and spoke with Admiral Basil Kiucee via hologram.
