# A-6 Interceptor

**Continuity:** Legends  
**Source:** [A-6 Interceptor](https://starwars.fandom.com/wiki/A-6_Interceptor)

The A-6 Interceptor was a nimble short-range starfighter, manufactured by Kuat Drive Yards during the waning days of the Galactic Republic. It was equipped with triple laser cannons.
