# War Pig

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [War Pig](https://starwars.fandom.com/wiki/War_Pig)

The War Pig was a MC40a light cruiser used by the Rebel Alliance. The cruiser was going to rendezvous with the Alliance Fleet at Sullust. But was destroyed by Tan Maarek Stele in a Missile Boat.
