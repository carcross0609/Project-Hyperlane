# Drop-sled

**Continuity:** Legends  
**Source:** [Drop-sled](https://starwars.fandom.com/wiki/Drop-sled)

A drop-sled was an Imperial assault vehicle that was able to drop from orbit and deploy a battalion of stormtroopers. It had an ablative coating for fast re-entry, and braking engines to slow its descent.
