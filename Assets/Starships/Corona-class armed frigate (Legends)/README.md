# Corona-class armed frigate

**Continuity:** Legends  
**Source:** [Corona-class armed frigate/Legends](https://starwars.fandom.com/wiki/Corona-class_armed_frigate/Legends)

The Corona-class armed frigate was a saucer-shaped craft manufactured by Haor Chall Engineering before the Clone Wars. It was based on an ancient Surronian cruiser design.
