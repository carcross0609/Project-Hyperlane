# Padawan Academic Cruiser

**Continuity:** Canon  
**Source:** [Padawan Academic Cruiser](https://starwars.fandom.com/wiki/Padawan_Academic_Cruiser)

The Padawan Academic Cruiser was a model of cruiser that was used by the Jedi Order during the High Republic Era to train Jedi Padawans. The cruiser had a large bridge that was the focus of the ship's activity.
