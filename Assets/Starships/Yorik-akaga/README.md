# Yorik-akaga

**Continuity:** Legends  
**Source:** [Yorik-akaga](https://starwars.fandom.com/wiki/Yorik-akaga)

The yorik-akaga was a pearlescent picket used by the Yuuzhan Vong. Warmaster Nas Choka fielded york-akaga during the final stages of the Yuuzhan Vong War.
