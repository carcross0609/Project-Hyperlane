# Echo-97

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Echo-97](https://starwars.fandom.com/wiki/Echo-97)

Echo-97 was a V-19 Torrent starfighter. During the Clone Wars, the Jedi Knight Anakin Skywalker flew it from Coruscant to the planet JanFathal to rendezvous with the warship Leveler.
