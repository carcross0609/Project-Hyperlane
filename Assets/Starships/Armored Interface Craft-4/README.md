# Armored Interface Craft-4

**Continuity:** Legends  
**Source:** [Armored Interface Craft-4](https://starwars.fandom.com/wiki/Armored_Interface_Craft-4)

The Armored Interface Craft-4 was a medium-sized dropship used by the Galactic Empire and produced by Sonda Armament.

## Specifications

- **Name:** Armored Interface Craft-4
- **Manufacturer:** Sonda Armament
- **Type:** Dropship
- **Length:** 40 meters
- **Max Speed:**
  - 1,150 KMH (during drop)
  - 750 KMH (return flight)
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Armament:**
  - 2 laser cannons
  - 2 heavy repeating blasters
- **Crew:** 6
- **Passengers:** 44
- **Capacity:** 10 metric tons
- **Consumables:** 3 days
- **Role:** Troop dropship
