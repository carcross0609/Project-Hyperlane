# Huntbird

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Huntbird](https://starwars.fandom.com/wiki/Huntbird)

The Huntbird was an explorer-cruiser lent to Luke Skywalker on behalf of the New Jedi Order by Umwaw Moolis in 12 ABY. Skywalker flew the ship from Ithor to the Moonflower Nebula to search for the Eye of Palpatine.

## Specifications

- **Name:** Huntbird
- **Type:** Explorer-cruiser
- **Hyperdrive:** Equipped
- **Role:** Private transport
- **Destroyed:** 12 ABY
- **Affiliation:** New Jedi Order
- **Owners:** Umwaw Moolis
