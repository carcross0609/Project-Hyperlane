# Obi-Wan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Obi-Wan (Nebula-class)](https://starwars.fandom.com/wiki/Obi-Wan_%28Nebula-class%29)

The Obi-Wan was the first Nebula-class Star Destroyer commissioned by the New Republic. It was named in honor of Jedi Master and General Obi-Wan Kenobi.

## Specifications

- **Name:** Obi-Wan
- **Type:** Nebula-class Star Destroyer
- **Role:** Destroyer
- **Affiliation:**

  - Galactic Federation of Free Alliances
- **Navy:** New Republic Defense Fleet
- **Captains:** Captain Whyrrryk
