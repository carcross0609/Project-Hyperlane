# Epsilon Four

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Epsilon Four](https://starwars.fandom.com/wiki/Epsilon_Four)

The Epsilon Four was a Lambda-class shuttle used for resupplying the Star Dreadnought Terror. In 3 ABY, it was hijacked by Rebel operatives Rookie One and Ru Murleen while receiving cargo on Imdaar to gain access to the Terror. It was supposedly still aboard the Star Dreadnought when it was destroyed shortly thereafter.
