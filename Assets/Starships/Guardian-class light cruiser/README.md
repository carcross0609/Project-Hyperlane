# Guardian-class light cruiser

**Continuity:** Legends  
**Source:** [Guardian-class light cruiser](https://starwars.fandom.com/wiki/Guardian-class_light_cruiser)

The Guardian-class light cruiser, also known as Guardian-class Customs corvette, was an Inter-System Customs Vessel used primarily by the Galactic Empire.

## Specifications

- **Name:** Guardian-class light cruiser
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Guardian-class light cruiser
- **Type:** Light cruiser
- **Length:** 42 meters
- **Max Speed:** 1,150 km/h
- **Hyperdrive:** Class 1.0
- **Hdsystem:** Equipped
- **Shield Gen:** Equipped
- **Navigation:** Equipped with Nav computer
- **Armament:**
  - Laser cannon turrets (2)
  - Forward laser cannons (2)
  - Or
  - Double Turbolaser cannons (6)
  - (some variations of above configurations replace lasers with turbolasers)
- **Complement:** TIE/LN starfighters (6; external rack, optional)
- **Crew:** 16 (3 command crew, 4 gunners, 9 crewmen)
- **Passengers:** 6 (prisoners/brig)
- **Capacity:** 200 tons
- **Consumables:** 3 months
- **Availability:** Military
- **Role:**
  - Picket
  - Patrol
  - Customs corvette
- **Affiliation:**
  - Galactic Empire
  - Pirates
  - The Wheel
  - House Pelagia
