# Overt

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Overt (starship)](https://starwars.fandom.com/wiki/Overt_%28starship%29)

The Overt was a Republic Navy training vessel in service between 40 BBY to 35 BBY. Lieutenant Kan Pojo was the range officer and small-arms instructor onboard.
