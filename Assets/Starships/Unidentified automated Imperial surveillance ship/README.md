# Unidentified automated Imperial surveillance ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified automated Imperial surveillance ship](https://starwars.fandom.com/wiki/Unidentified_automated_Imperial_surveillance_ship)

An automated Imperial surveillance ship had crashed on the planet Kajim during the Cold War between the Galactic Republic and the Sith Empire. Imperial operatives were able to drive off the Republic retrieval team and reclaim it for the Empire.
