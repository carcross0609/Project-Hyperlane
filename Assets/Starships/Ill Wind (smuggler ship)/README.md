# Ill Wind (smuggler ship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ill Wind (smuggler ship)](https://starwars.fandom.com/wiki/Ill_Wind_%28smuggler_ship%29)

Ill Wind was a starship that was used to smuggle spice during the Galactic Civil War. The Ill Wind navigator, Monnda Tebbo prevented the ship from crashing when it was attacked by Imperial forces over Uogo'cor. This incident prompted the ship's entire crew to join the Rebel Alliance.
