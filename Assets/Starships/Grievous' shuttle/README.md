# Grievous' shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Grievous' shuttle](https://starwars.fandom.com/wiki/Grievous%27_shuttle)

A shuttle was used by the Kaleesh warlord Grievous, and it functioned as a troop carrier. One day, it was sabotaged, and when the shuttle crashed, Grievous flung himself from the wreckage.

## Specifications

- **Name:** Grievous' shuttle
- **Type:** Shuttle
- **Role:** Troop carrier
- **Owners:** Grievous
