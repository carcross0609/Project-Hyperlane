# Swift Return

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Swift Return](https://starwars.fandom.com/wiki/Swift_Return)

The Swift Return was a Consular-class cruiser that served in the Republic Navy's Open Circle Fleet. It was destroyed by Admiral Trench prior to the Battle of Christophsis. At one point prior to its destruction, the Swift Return fired its weapons while in an asteroid field. When Galactic Republic Admiral Wullf Yularen researched Trench, believing the presumed-dead commander to be leading Separatist forces above Christophsis, he saw information on the Swift Return.
