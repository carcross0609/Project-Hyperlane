# Fantail-class destroyer

**Continuity:** Canon  
**Source:** [Fantail-class destroyer](https://starwars.fandom.com/wiki/Fantail-class_destroyer)

Fantail-class destroyers were a class of destroyer that saw use by the Corporate Alliance and later the naval forces of the Confederacy of Independent Systems during the Clone Wars against the Galactic Republic. During the war, in which the Corporate Alliance sided with the Confederacy, Fantail-class destroyers were used to defend the corporation's headquarters on the planet Murkhana and were supported by Sikurdian privateers.
