# Onteba

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Onteba](https://starwars.fandom.com/wiki/Onteba)

Onteba was a BFF-1 bulk freighter responsible for delivering a replacement hyperdrive to the Imperial EF76 Nebulon-B escort frigate Red Wind. The delivery was a failure as Keyan Farlander and a set of CR90 corvettes destroyed the frigate.

## Specifications

- **Name:** Onteba

- **Type:** Medium-sized freighter
- **Length:** 120.9 meters
- **Width:** 75.56 meters
- **Height:** 34 meters
- **Role:** Transport
- **Affiliation:** Galactic Empire
