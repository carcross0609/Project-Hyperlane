# Vessel three-niner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vessel three-niner](https://starwars.fandom.com/wiki/Vessel_three-niner)

Vessel three-niner was a starship that served the Imperial Navy. It was assigned to Kline Security operating in the Monor system. The crew of the vessel intercepted a Rebel tug and captured Daye Azur-Jamin, Toalar Yalom Yalom, and Woyiq.
