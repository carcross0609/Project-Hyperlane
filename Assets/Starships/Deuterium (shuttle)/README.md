# Deuterium

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Deuterium (shuttle)](https://starwars.fandom.com/wiki/Deuterium_%28shuttle%29)

Deuterium was a Lambda-class T-4a shuttle of the same group as Tydirium. It was found departing Outpost 327 by the Sabra when the latter docked the station in the Mission to Zhar.
