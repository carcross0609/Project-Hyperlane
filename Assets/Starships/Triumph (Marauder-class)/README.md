# Triumph

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Triumph (Marauder-class)](https://starwars.fandom.com/wiki/Triumph_%28Marauder-class%29)

The Triumph was a Republic Sienar Systems Marauder-class corvette in the Kathol Republic Navy. The ship was commanded by Hendric Faile, and carried a complement of marines onboard.
