# Indomitable

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Indomitable (Carrack-class)/Legends](https://starwars.fandom.com/wiki/Indomitable_%28Carrack-class%29/Legends)

Indomitable was a Carrack-class cruiser. It served in the Old Republic's Home Fleet Strike Group Five during the Clone Wars, and took great damage that reduced it to a mere shell by the Invisible Hand during the Battle of Coruscant. It is unknown if the ship was repaired and returned to active duty following the battle.

## Specifications

- **Name:** Indomitable
- **Model:** Carrack-class light cruiser
- **Type:** Frigate
- **Length:** 350 meters
- **Width:** 72 meters
- **Height:** 75 meters
- **Affiliation:**

  -   Republic Navy
- **Navy:** Coruscant Defense Fleet
- **Fleet:** Home Fleet Strike Group Five
