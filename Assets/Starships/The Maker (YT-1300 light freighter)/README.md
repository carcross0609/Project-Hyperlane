# The Maker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [The Maker (YT-1300 light freighter)](https://starwars.fandom.com/wiki/The_Maker_%28YT-1300_light_freighter%29)

The Maker was a YT-1300 light freighter that was stolen from Sythluss Leethe by T'Charek Haathi and her crew on Zelos II. It was used by Haathi on missions for the Rebel Alliance.
