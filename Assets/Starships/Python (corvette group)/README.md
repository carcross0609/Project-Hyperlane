# Python

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Python (corvette group)](https://starwars.fandom.com/wiki/Python_%28corvette_group%29)

Python was a pair of CR90 corvettes that were part of a Rebel convoy that contained B-wing starfighters. The corvettes were attacked, but thanks to the X-wings the entire convoy managed to escape into hyperspace.

## Specifications

- **Name:** Python
- **Model:** CR90 corvette
- **Type:** Corvette
