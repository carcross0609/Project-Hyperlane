# Repair barge

**Continuity:** Canon  
**Source:** [Repair barge](https://starwars.fandom.com/wiki/Repair_barge)

Repair barges were huge, bulky starships that were used to mend other vessels while in space. The Imperial Navy notably made use of such ships.
