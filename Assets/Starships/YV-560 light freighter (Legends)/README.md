# YV-560 light freighter

**Continuity:** Legends  
**Source:** [YV-560 light freighter/Legends](https://starwars.fandom.com/wiki/YV-560_light_freighter/Legends)

The YV-560 light freighter was an exploration class freighter made by the Corellian Engineering Corporation. Similar in design to CEC's YT-1300 light freighter, the YV-560 was slightly smaller, with a 30.1 meter length and a 22.4 meter saucer diameter.
