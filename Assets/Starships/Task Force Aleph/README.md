# Task Force Aleph

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Task Force Aleph](https://starwars.fandom.com/wiki/Task_Force_Aleph)

Task Force Aleph was an element of the New Republic Fifth Fleet that attempted to jump from Bothawui to Fondor to reinforce the First Fleet during the Battle of Fondor. Half the force was yanked from hyperspace by dovin basal mines, and six ships were pulled into mass shadows. The fleet was forced to retreat before ever reaching Fondor. The planet would eventually fall.
