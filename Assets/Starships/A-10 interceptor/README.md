# A-10 interceptor

**Continuity:** Legends  
**Source:** [A-10 interceptor](https://starwars.fandom.com/wiki/A-10_interceptor)

The A-10 interceptor was a starfighter produced by Kuat Drive Yards in operation as of 40 ABY. It was the successor to the A-9 Vigilance interceptor.
