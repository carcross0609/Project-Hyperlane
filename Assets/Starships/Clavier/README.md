# Clavier

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Clavier](https://starwars.fandom.com/wiki/Clavier)

The Clavier was a CR90 corvette belonging to the Pakuuni Pirates. She was defending a pirate outpost along with Leach and Grapler. Clavier was destroyed by Imperial ace Maarek Stele along with the other corvettes and the entire outpost.
