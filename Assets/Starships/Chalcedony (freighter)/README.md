# Chalcedony

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chalcedony (freighter)](https://starwars.fandom.com/wiki/Chalcedony_%28freighter%29)

The Chalcedony was a YT-1300 light freighter modified for passenger transport. It was outbound from Pallaxides when it was forced to crash-land on Celanon.

## Specifications

- **Name:** Chalcedony
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** Modified YT-1300 light freighter
- **Type:** Passenger freighter
- **Length:** 34.75 meters
- **Role:** Passenger liner
