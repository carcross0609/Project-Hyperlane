# Reviler

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Reviler](https://starwars.fandom.com/wiki/Reviler)

The Reviler was the flagship of Admiral Gallia Kryder of the Imperial Navy. By 3 ABY, it was stationed at the edge of Wild Space. Basic information about Kryder commanding the Reviler was supplied to the BX-series ND-5 by a contact in 3 ABY before he and Kay Vess began smuggling a class-one hyperdrive from Achra Station in the Akiva system to Hauler's Keep in the Khepi system. Vess was able to use Kryder's name as well as that of the Reviler at an Imperial checkpoint to stall log enough for ND-5 to find clearance codes which would allow the group to pass the check without being searched.
