# Thannik's Thunder

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thannik's Thunder](https://starwars.fandom.com/wiki/Thannik%27s_Thunder)

Thannik's Thunder was a Ghtroc Industries 720 light freighter operated by a female Human pilot named Rhen. She flew the freighter in combat against pirates flying Z-95 Headhunters, and against Imperial TIE fighters.

## Specifications

- **Name:** Thannik's Thunder
- **Manufacturer:** Ghtroc Industries
- **Model:** 720 light freighter
- **Owners:** Rhen
