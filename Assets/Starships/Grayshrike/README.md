# Grayshrike

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Grayshrike](https://starwars.fandom.com/wiki/Grayshrike)

The Grayshrike was a Chiss heavy cruiser in service to the Chiss Ascendancy's Expansionary Defense Fleet. It served as part of Picket Force Six under Admiral Ar'alani and was commanded by Senior Captain Lakinda.
