# Leena

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Leena](https://starwars.fandom.com/wiki/Leena)

Leena was an Action VI bulk transport that carried Twi'lek dancers of the Dunari's Rest when the latter was attacked by Imperial forces. It made it to hyperspace intact thanks to assistance from the Rebel Alliance.
