# Neeka-Ranga

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Neeka-Ranga](https://starwars.fandom.com/wiki/Neeka-Ranga)

The Neeka-Ranga was a dreadcruiser that was owned by the Hutt Myarga Anjiliac Atirue and later owned by Skarabda. The ship was attacked by the Twi'lek Lourna Dee in the Ataraxia.
