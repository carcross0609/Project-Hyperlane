# Core Conveyor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Core Conveyor](https://starwars.fandom.com/wiki/Core_Conveyor)

The Core Conveyor was a Galactic Republic auxiliary ship in service during the Clone Wars and in use of the 2nd Airborne Company (212th Attack Battalion). It carried Omega Squad during their stealth insertion to Gaftikar. Presumably, it next went to Mirial along with the rest of the 2nd Airborne.
