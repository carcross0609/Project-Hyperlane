# Eliminator (Clone Wars)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eliminator (Clone Wars)](https://starwars.fandom.com/wiki/Eliminator_%28Clone_Wars%29)

The Eliminator was a Star Destroyer in service to the Galactic Republic during the Clone Wars. One notable battle in participated in was the Battle of Daalang where it carried out an orbital bombardment of a CIS base.
