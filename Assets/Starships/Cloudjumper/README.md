# Cloudjumper

**Continuity:** Legends  
**Source:** [Cloudjumper](https://starwars.fandom.com/wiki/Cloudjumper)

A cloudjumper was a small starship. Jedi Padawan Nason Laric used one to travel between the planet Yabosta and its moon Skalokor. It was able to carry at least two passengers.
