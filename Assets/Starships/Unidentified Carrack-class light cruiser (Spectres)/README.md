# Unidentified Carrack-class light cruiser

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Carrack-class light cruiser (Spectres)](https://starwars.fandom.com/wiki/Unidentified_Carrack-class_light_cruiser_%28Spectres%29)

A Carrack-class light cruiser was owned by the Galactic Empire during the Imperial Era. Sometime between 5 BBY and 4 BBY, the ship was abandoned in the Kryton system due to a technical mishap. The Spectres traveled to tag the Carrack-class light cruiser with a Rebel Alliance starbird in order to make the Empire think the Spectres did it.
