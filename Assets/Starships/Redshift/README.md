# Redshift

**Continuity:** Legends  
**Source:** [Redshift](https://starwars.fandom.com/wiki/Redshift)

The Redshift was a class of starfighter manufactured by Kuat Drive Yards that was used by the Jedi Starfighter Corps during the New Sith Wars. Following the end of the conflict, the Redshift was considered to be outdated, so the Jedi replaced them with the Savage Star fighter.
