# Gold 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gold 3](https://starwars.fandom.com/wiki/Gold_3)

Gold 3 was the designation of a BTL-A4 Y-wing in service to the Alliance to Restore the Republic. Flown by Ryle Torsyn, the fighter was originally stationed at Dantooine base where it was part of the squadron under Davish Krail's command.

## Specifications

- **Name:** Gold 3
- **Line:** BTL Y-wing starfighter
- **Model:** BTL-A4 Y-wing starfighter
- **Destroyed:** 0 BBY, Yavin system
- **Affiliation:**

  -   Gold Squadron
- **Captains:** Ryle Torsyn
