# Salamander (frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Salamander (frigate)](https://starwars.fandom.com/wiki/Salamander_%28frigate%29)

The Salamander was an EF76 Nebulon-B escort frigate that served with the New Republic Defense Fleet during the Galactic Civil War. The vessel was dispatched to the world of Krann in order to investigate a threat on the nova crystal mines located there.
