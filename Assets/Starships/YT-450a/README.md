# YT-450a

**Continuity:** Legends  
**Source:** [YT-450a](https://starwars.fandom.com/wiki/YT-450a)

The YT-450a was a clunky-looking starship from Corellian Engineering Corporation's YT-series light freighters. It was slow and not very maneuverable in its stock configuration, but it could be modified to improve its power and weaponry.

## Specifications

- **Name:** YT-450a
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** Light freighter
