# Transport eight

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Transport eight](https://starwars.fandom.com/wiki/Transport_eight)

Transport eight was a TR-286 automated transport that was based at a cargo port on Daiyu. It was used to secretly ferry Jedi Master Obi-Wan Kenobi and Princess Leia Organa from Daiyu to Mapuzo.

## Specifications

- **Name:** Transport eight
- **Manufacturer:** SoroSuub Corporation
- **Model:** TR-286 transport
- **Type:** Automated transport
- **Engine:** Sublight engines (3)
- **Hdsystem:** Equipped
- **Crew:** None
- **Role:** Cargo transportation
