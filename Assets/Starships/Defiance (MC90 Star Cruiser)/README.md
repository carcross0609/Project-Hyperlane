# Defiance

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Defiance (MC90 Star Cruiser)](https://starwars.fandom.com/wiki/Defiance_%28MC90_Star_Cruiser%29)

Defiance was a Mon Calamari Star Cruiser that served with the New Republic Defense Fleet during Operation Shadow Hand. It was the first warship of the new MC90 Star Cruiser class of vessel.

- **Name:** Defiance

- **Type:** MC90 Star Cruiser

- **Role:**

- **Commission:** 9 ABY
