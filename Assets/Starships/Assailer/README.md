# Assailer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Assailer](https://starwars.fandom.com/wiki/Assailer)

The Assailer was a Raider-class corvette that, during the Imperial Era, formed part of the Imperial Navy. The corvette boasted sublight engines and measured 150 meters in length.

## Specifications

- **Name:** Assailer
- **Line:** Raider-class corvette
- **Type:** Corvette
- **Length:** 150 meters
- **Engine:** Sublight engines
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
