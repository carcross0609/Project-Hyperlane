# Invincible

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Invincible (Star Destroyer)](https://starwars.fandom.com/wiki/Invincible_%28Star_Destroyer%29)

Invincible was a Star Destroyer serving in the Imperial Navy. It was one of four ships that formed the core forces of Moff anti-piracy task force.
