# Drop pod

**Continuity:** Canon  
**Source:** [Drop pod](https://starwars.fandom.com/wiki/Drop_pod)

Drop pods were simple crafts that resembled escape pods and were used to bring vehicles to the battlefield. During the Galactic Civil War, the Alliance to Restore the Republic modified such craft to deploy troops and supplies directly into battle.
