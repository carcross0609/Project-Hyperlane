# Jendirian Valley III

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jendirian Valley III](https://starwars.fandom.com/wiki/Jendirian_Valley_III)

The Jendirian Valley III was a freighter leaving Nar Shaddaa in 19 BBY when it collided with the Stellar Envoy. While the Jenridian Valley III took minimal damage, the Envoy was wrecked and its co-pilot Reeze Duurmun died in the impact.
