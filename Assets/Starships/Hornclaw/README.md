# Hornclaw

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hornclaw](https://starwars.fandom.com/wiki/Hornclaw)

The Hornclaw was a modified Corellian Engineering Corporation YT-1300 light freighter which was stolen from Abek's Station by the Kerestian Limna Yith.

- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
