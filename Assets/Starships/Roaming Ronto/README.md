# Roaming Ronto

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Roaming Ronto](https://starwars.fandom.com/wiki/Roaming_Ronto)

The Roaming Ronto was a Gallofree Yards, Inc., GR-75 medium transport owned by Bornaryn Trading which was used to transport at least a dozen turbolaser batteries to the Killiks.
