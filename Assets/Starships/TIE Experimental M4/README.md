# TIE Experimental M4

**Continuity:** Legends  
**Source:** [TIE Experimental M4](https://starwars.fandom.com/wiki/TIE_Experimental_M4)

The TIE Experimental M4, also known as the TIE Bomb, was a guided missile based on TIE Series technology and a part of the TIE Experimental Project.

## Specifications

- **Name:** TIE Experimental M4
- **Manufacturer:** Sienar Fleet Systems
- **Line:** TIE Series Experimental
- **Model:** Twin Ion Engine Experimental M4 (T/e4)
- **Type:** Starfighter
- **Length:** 8.7 meters
- **Mglt:** 144 MGLT
- **Engine:**
  - Twin Ion Engines
  - 1 booster engine
- **Hdsystem:** Equipped
- **Hull:** Titanium alloy hull (38 RU)
- **Navigation:** None (slaved to control ship)
- **Armament:** Suicide explosive payload
- **Crew:** Remote control system
- **Passengers:** None
- **Role:** Long-range anti-capital ship missile
- **Affiliation:** Galactic Empire
