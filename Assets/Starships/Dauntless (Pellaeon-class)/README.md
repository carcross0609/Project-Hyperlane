# Dauntless

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dauntless (Pellaeon-class)](https://starwars.fandom.com/wiki/Dauntless_%28Pellaeon-class%29)

The Dauntless was a Pellaeon-class Star Destroyer in the Imperial Navy of the Fel Empire; though following the coup orchestrated by the One Sith it became part of the Sith Empire's fleet.

## Specifications

- **Name:** Dauntless
- **Manufacturer:** Kuat Drive Yards
- **Model:** Pellaeon-class Star Destroyer
- **Destroyed:** 137 ABY, Agamar
- **Affiliation:**
  - Fel Empire
  - Darth Krayt's Galactic Empire
  - Empire-in-exile
- **Captains:**
  - Captain Dorn
  - Admiral Tohri Challon
  - Captain Basile
