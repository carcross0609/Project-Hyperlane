# Cargo vessel TR-141

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Cargo vessel TR-141](https://starwars.fandom.com/wiki/Cargo_vessel_TR-141)

Cargo vessel TR-141 was the designation of an Intersystem Transport Ship used by the Resistance during their war against the First Order. It participated in the mission to Batuu, where it was helmed by Nien Nunb and under the command of Lieutenant Bek. It was tasked with bringing recruits from Batuu to the Resistance base on Pacara. Above Batuu however, it was captured by a First Order Resurgent-class Star Destroyer, the Finalizer.
