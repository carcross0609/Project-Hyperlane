# Reclamation cruiser

**Continuity:** Legends  
**Source:** [Reclamation cruiser](https://starwars.fandom.com/wiki/Reclamation_cruiser)

A reclamation cruiser was a starship used by Squibs. The Two-for-One was a reclamation cruiser which visited Mos Eisley on Tatooine before 0 BBY, and left without her bartender, Macemillian-winduarté.
