# Ubote 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ubote 3](https://starwars.fandom.com/wiki/Ubote_3)

Ubote 3 was a CR90 corvette in the service of the Alliance to Restore the Republic. It fought at the First Battle of Javin as part of the Ubote group, along with Ubote 1 and Ubote 2.
