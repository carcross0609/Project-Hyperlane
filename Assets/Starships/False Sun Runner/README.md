# False Sun Runner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [False Sun Runner](https://starwars.fandom.com/wiki/False_Sun_Runner)

In 23 BBY, one year before the start of the Clone Wars, Groodo the Hutt created a copy of the ancient starship the Sun Runner in a scheme to destroy the Fondor Shipyards. The counterfeit derelict was powered by a hypermatter reactor, fitted with a contemporary sensor jammer, and armed with 20 Arakyd Industries sensor-guided missiles and state-of-the-art Trang Robotics Duelist Elite combat droids with flexisteel sabers and vocabulators. Additionally, controlling the ship was a dome-headed, black R1 astromech (Industrial Automaton) guarded by three SoroSuub 501-Z security droids heavily armed with new Merr-Sonn B-20 blaster rifles with pressure-wiped stocks.
