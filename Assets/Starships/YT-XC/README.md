# YT-XC

**Continuity:** Legends  
**Source:** [YT-XC](https://starwars.fandom.com/wiki/YT-XC)

The YT-XC, later known as the "mini-fighter," was a small explorer craft that could be carried aboard the YT-1300 light freighter.

## Specifications

- **Name:** YT-XC
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Starfighter
- **Engine:** Sublight thrusters (2)
- **Armament:**
  - Blaster cannons (2) (modified variant)
  - Concussion missile launcher (modified variant)
- **Crew:** Pilot (1)
- **Role:**
  - Exploration craft
  - Miniature starfighter (modified variant)
