# Perfect

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Perfect](https://starwars.fandom.com/wiki/Perfect)

Perfect was a CR90 corvette that served with the Imperial Navy during the Galactic Civil War. It sent a single TIE/LN starfighter to destroy a Rebel Alliance supply depot which held a number of tugs T-XL, containers Vic and Limi, RZ-1 A-wing interceptors and T-65 X-wing starfighters.
