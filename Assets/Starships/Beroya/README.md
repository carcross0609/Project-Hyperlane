# Beroya

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Beroya](https://starwars.fandom.com/wiki/Beroya)

Beroya (meaning "bounty hunter" in Mando'a) was a Mandalorian-designed and built Gladiator-class assault fighter that was flown by Goran Beviin.
