# Tri-wing shuttle

**Continuity:** Legends  
**Source:** [Tri-wing shuttle](https://starwars.fandom.com/wiki/Tri-wing_shuttle)

A tri-wing shuttle was used by General Grievous to flee Coruscant with his captive, Supreme Chancellor Palpatine.
