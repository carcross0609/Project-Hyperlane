# YV-865 Aurore-class freighter

**Continuity:** Legends  
**Source:** [YV-865 Aurore-class freighter/Legends](https://starwars.fandom.com/wiki/YV-865_Aurore-class_freighter/Legends)

The YV-865 Aurore-class freighter was a bulky freighter transport used during the Clone Wars. It became known as the Zygerrian slave ship due to its widespread use by slavers such as Zygerrians and Thalassians.
