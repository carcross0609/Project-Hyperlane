# Beta Cruiser

**Continuity:** Legends  
**Source:** [Beta Cruiser](https://starwars.fandom.com/wiki/Beta_Cruiser)

A Beta Cruiser was a type of battleship used by the Hapan Royal Navy. It was much smaller than the Nova-class battle cruiser, but also more maneuverable. The Hapan fleet that fought in the Battle of Fondor contained many ships of this class, but few survived that engagement. One such cruiser as these was the Starsprite.
