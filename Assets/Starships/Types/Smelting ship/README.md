# Smelting ship

**Continuity:** Legends  
**Source:** [Smelting ship](https://starwars.fandom.com/wiki/Smelting_ship)

A smelting ship was an immense starship used to pulverize asteroids, collect the debris, then extract useful and valuable minerals from the remains. Minos-Mestra Corporation operated a number of these vessels throughout the Mestra system.
