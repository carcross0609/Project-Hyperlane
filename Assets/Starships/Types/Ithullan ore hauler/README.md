# Ithullan ore hauler

**Continuity:** Legends  
**Source:** [Ithullan ore hauler](https://starwars.fandom.com/wiki/Ithullan_ore_hauler)

The Ithullan ore haulers were large starships in use circa 4000 BBY. Unlike standard starships, it was not manufactured, but built out of Ithullian colossus wasp corpses, giant insectoids over a kilometer in length. This unique design easily distinguished them from any other type of ship. These ships were used by the humanoid Nessies of the Stenness Node systems, a valuable mining region in what was then the galaxy's frontier.

## Specifications

- **Name:** Ithullan ore hauler
- **Manufacturer:** Nessies
- **Model:** Ithullan ore hauler
- **Length:** 1 kilometer
- **Engine:** Ion drive engines (2)
- **Hyperdrive:** Class 15
- **Armament:**

  - Point-defense blasters
- **Role:** Ore hauler
