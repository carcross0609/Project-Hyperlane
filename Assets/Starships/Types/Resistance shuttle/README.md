# Resistance shuttle

**Continuity:** Canon  
**Source:** [Resistance shuttle](https://starwars.fandom.com/wiki/Resistance_shuttle)

Simply known as the Resistance shuttle, the craft was used by the Resistance in the First Order-Resistance War. Three of these shuttles were used by Jade and Ace Squadrons when rescuing Resistance recruits from Dantooine. While evacuating Dantooine, however, one shuttle was destroyed by the First Order.
