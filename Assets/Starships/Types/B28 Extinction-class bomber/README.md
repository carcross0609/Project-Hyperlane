# B28 Extinction-class bomber

**Continuity:** Legends  
**Source:** [B28 Extinction-class bomber](https://starwars.fandom.com/wiki/B28_Extinction-class_bomber)

The B28 Extinction-class bomber, also referred to as the B-28, was a Bomber class used by the reconstituted Sith Empire in the Great Galactic War and during the Cold War.
