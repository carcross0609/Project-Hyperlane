# Phraetiss system patrol cruiser

**Continuity:** Unknown  
**Source:** [Phraetiss system patrol cruiser](https://starwars.fandom.com/wiki/Phraetiss_system_patrol_cruiser)

The Phraetiss system patrol cruisers were only used in the Phraetiss system, and were designed to patrol the system for smugglers and outlaws. One such ship managed to seize the Tyaonon Ranger.
