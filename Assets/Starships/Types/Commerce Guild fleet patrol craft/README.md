# Commerce Guild fleet patrol craft

**Continuity:** Legends  
**Source:** [Commerce Guild fleet patrol craft](https://starwars.fandom.com/wiki/Commerce_Guild_fleet_patrol_craft)

The Commerce Guild fleet patrol craft was a type of patrol craft modeled on the Nantex-class territorial defense starfighter that was used by the Commerce Guild. Alongside Commerce Guild corvettes, these patrol craft were employed by the Escarte Guard to defend the Commerce Guild's Escarte asteroid mining facility during the Clone Wars.

## Specifications

- **Name:** Commerce Guild fleet patrol craft
- **Type:** Patrol craft
- **Affiliation:**
  - Commerce Guild
  -   Escarte Guard
