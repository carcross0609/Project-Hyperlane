# Imperial Leviathan

**Continuity:** Unknown  
**Source:** [Imperial Leviathan](https://starwars.fandom.com/wiki/Imperial_Leviathan)

The Imperial Leviathans were 5,000 meter-long starship-factories, precursors of the better-known World Devastators, which were able to produce several different kinds of vehicles and vessels.

## Specifications

- **Name:** Imperial Leviathan
- **Length:** 5,000 meters
- **Armament:**
  - Turbolasers (30)
  - Ion cannons (20)
- **Crew:** 12,500 droids
- **Role:** Automated Factory
- **Affiliation:** Galactic Empire
