# CR70 corvette

**Continuity:** Legends  
**Source:** [CR70 corvette/Legends](https://starwars.fandom.com/wiki/CR70_corvette/Legends)

The CR70 corvette was a predecessor of the CR90 corvette, produced by the Corellian Engineering Corporation. The Sundered Heart was a CR70 corvette before later being retrofitted with the Vanguard c20 retrofit suite to become a CR90 corvette.
