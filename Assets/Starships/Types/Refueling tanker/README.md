# Refueling tanker

**Continuity:** Legends  
**Source:** [Refueling tanker](https://starwars.fandom.com/wiki/Refueling_tanker)

Refueling tankers were tanker starships used by various navies to refuel other vessels in space. One notable refueling tanker was the Bastion, used by Warlord Zsinj's Imperial forces. Another example was the Golan Ribbon tanker used by the Alliance to Restore the Republic. The GR-75 medium transport also functions as a refueling tanker at times.
