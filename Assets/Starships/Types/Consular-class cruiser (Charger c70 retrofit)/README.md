# Consular-class cruiser; (Charger c70 retrofit)

**Continuity:** Canon  
**Source:** [Consular-class cruiser (Charger c70 retrofit)](https://starwars.fandom.com/wiki/Consular-class_cruiser_%28Charger_c70_retrofit%29)

The Consular-class cruiser (Charger c70 retrofit), also known as the Consular-class frigate, Consular-class Armed Cruiser, Charger C70 Combat Refit or the Republic frigate, was a modified variant of Consular-class light cruiser that saw service with the Galactic Republic during the Clone Wars. Converted from Judicial Forces starships as part of Project Supercharger, the combat-oriented Charger c70 featured new battle-armored hull and laser turrets and proved a mainstay of the Republic Navy during the conflict.
