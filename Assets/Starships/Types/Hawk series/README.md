# Hawk series

**Continuity:** Legends  
**Source:** [Hawk series](https://starwars.fandom.com/wiki/Hawk_series)

The Hawk series was a freighter line produced by the Corellian Engineering Corporation prior to the Clone Wars. During the Clone Wars the series was discontinued to make way for the production of military vessels. The line was continued some time before Darth Krayt became Emperor.
