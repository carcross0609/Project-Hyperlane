# Bardictol

**Continuity:** Legends  
**Source:** [Bardictol](https://starwars.fandom.com/wiki/Bardictol)

Bardictol was a Habassan Delta-class DX-9 stormtrooper transport that carried the Habassan envoy to the Independence in order to attain a diplomatic meeting with the Rebel Alliance

## Specifications

- **Name:** Bardictol
- **Manufacturer:** Telgorn Corporation
- **Model:** Delta-class DX-9 stormtrooper transport
- **Type:** Transport
- **Length:** 20 meters
- **Width:** 7.8 meters
- **Height:** 5.8 meters
- **Affiliation:** Habassa
