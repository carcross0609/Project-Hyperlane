# Chiss merchant ship

**Continuity:** Canon  
**Source:** [Chiss merchant ship](https://starwars.fandom.com/wiki/Chiss_merchant_ship)

The Chiss merchant ship was a class of merchant starship used by the Unknown Regions Chiss Ascendancy nation. By 36 BBY, the Pathfinder navigator Qilori had served as the navigator for a number of Chiss merchant ships. In that year, he served as the navigator for a Chiss diplomatic cruiser, and privately remarked that the bridge was identical to every Chiss merchant ship he had navigated.

## Specifications

- **Name:** Chiss merchant ship
- **Type:** Merchant starship
- **Affiliation:** Chiss Ascendancy
