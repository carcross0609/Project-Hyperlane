# Wolden-class shuttle

**Continuity:** Legends  
**Source:** [Wolden-class shuttle](https://starwars.fandom.com/wiki/Wolden-class_shuttle)

The Wolden-class shuttle was a model of shuttle. The Alliance to Restore the Republic used a Wolden-class shuttle during Operation Cobolt.

## Specifications

- **Name:** Wolden-class shuttle
- **Type:** Shuttle
- **Passengers:** At least 75 soldiers
- **Capacity:** At least 1,000 kilograms
- **Role:** Troop transport
