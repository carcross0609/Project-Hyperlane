# Orb-wing

**Continuity:** Canon  
**Source:** [Orb-wing](https://starwars.fandom.com/wiki/Orb-wing)

The orb-wing was a model of one-person starfighter whose cockpit was ball-shaped and translucent. At some point prior to the Invasion of Naboo, a faction of pirates that harassed the Trade Federation used such ships.

## Specifications

- **Name:** Orb-wing
- **Type:** Starfighter
- **Affiliation:** A pirate faction
