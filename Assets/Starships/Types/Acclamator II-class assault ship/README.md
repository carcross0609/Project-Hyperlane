# Acclamator II-class assault ship

**Continuity:** Canon  
**Source:** [Acclamator II-class assault ship](https://starwars.fandom.com/wiki/Acclamator_II-class_assault_ship)

The Acclamator II-class assault ship was a variant of the Acclamator-class Assault Ship that was utilized by the Republic Navy. At least one such vessel participated in the Clone Wars between the Galactic Republic and the Separatist Alliance as part of the Open Circle Armada's Fifth Fleet. The Acclamator II-class, alongside the Acclamator I-class, were the main deployment starships of clone troopers during the war.
