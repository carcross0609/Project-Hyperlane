# Class-C frigate

**Continuity:** Canon  
**Source:** [Class-C frigate](https://starwars.fandom.com/wiki/Class-C_frigate)

The Class-C frigate was a class of frigate that saw use around the time of the Clone Wars. The EF76 Nebulon-B escort frigate, which was introduced after the war, was the replacement of the Class-C frigate.
