# L-class troopship

**Continuity:** Legends  
**Source:** [L-class troopship](https://starwars.fandom.com/wiki/L-class_troopship)

The L-class troopship was a model of troop transports. The Rebel Barga believed that the triple bunks used for quarters in Oracle Base were salvaged from an L-class troopship.
