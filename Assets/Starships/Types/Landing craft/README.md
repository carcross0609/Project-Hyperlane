# Landing craft

**Continuity:** Canon  
**Source:** [Landing craft](https://starwars.fandom.com/wiki/Landing_craft)

A landing craft was a type of starship that served as a transport for armed forces between a capital ship and a planetary surface. Examples included the Trade Federation's C-9979 landing craft and the Galactic Empire's Sentinel-class landing craft.
