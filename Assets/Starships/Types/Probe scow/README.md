# Probe scow

**Continuity:** Legends  
**Source:** [Probe scow](https://starwars.fandom.com/wiki/Probe_scow)

Probe scow was a generic term given to a dilapitated ship, piloted by a lazy Ranat Imperial spy, around the time of the Mechis III Uprising.
