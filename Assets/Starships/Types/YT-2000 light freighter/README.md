# YT-2000 light freighter

**Continuity:** Canon  
**Source:** [YT-2000 light freighter](https://starwars.fandom.com/wiki/YT-2000_light_freighter)

The YT-2000 light freighter, also called the YT-2000 transport, was a model of freighter produced by Corellian Engineering Corporation. One such vessel, the Stellar Sun, was owned by the human Rikarda.

## Specifications

- **Name:** YT-2000 light freighter
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-2000
- **Type:** Freighter
- **Cost:**

- **Hyperdrive:**
