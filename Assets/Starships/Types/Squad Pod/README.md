# Squad Pod

**Continuity:** Legends  
**Source:** [Squad Pod](https://starwars.fandom.com/wiki/Squad_Pod)

The Squad Pod was a Rebel Alliance modified escape pod used to transport SpecForce operatives.

## Specifications

- **Name:** Squad Pod
- **Type:** Modified escape pod
- **Length:** 6 meters
- **Passengers:** 10
- **Capacity:** 100 kilograms
- **Role:** Landing craft
- **Affiliation:** Alliance to Restore the Republic
