# Pursuer-class enforcer

**Continuity:** Canon  
**Source:** [Pursuer-class enforcer](https://starwars.fandom.com/wiki/Pursuer-class_enforcer)

The Pursuer-class enforcer was type of patrol ship. In 35 ABY, one such craft joined the fleet assembled in response to General Lando Calrissian's call to action against the Sith Eternal forces.

## Specifications

- **Name:** Pursuer-class enforcer
- **Type:** Patrol ship
