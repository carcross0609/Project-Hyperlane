# Snub-fighter

**Continuity:** Canon  
**Source:** [Snub-fighter](https://starwars.fandom.com/wiki/Snub-fighter)

Snub-fighter was a term used to describe small starfighters such as the Z-95 Headhunter, its successor, the T-65B X-wing starfighter, the BTL-A4 Y-wing assault starfighter/bomber, the B-wing, the TIE/fo space superiority fighter, and the TIE/sf space superiority fighter.
