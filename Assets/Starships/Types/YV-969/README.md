# YV-969

**Continuity:** Canon  
**Source:** [YV-969](https://starwars.fandom.com/wiki/YV-969)

The YV-969 was a model of starship produced by Corellian Engineering Corporation. It redeemed the reputation of the YV-series, previously tarnished by the YV-865 Aurore-class freighter's association with the Zygerrian Slave Empire.

## Specifications

- **Name:** YV-969
