# Tadjyyyk

**Continuity:** Legends  
**Source:** [Tadjyyyk](https://starwars.fandom.com/wiki/Tadjyyyk)

Tadjyyyk was a group of two Rebel Delta-class DX-9 stormtrooper transports that carried personnel from the damaged Mon Calamari Star Cruiser Maximus before it was destroyed. The transports were able to make it to Nebulon-B frigate Anvil.
