# Z-95ML Headhunter

**Continuity:** Legends  
**Source:** [Z-95ML Headhunter](https://starwars.fandom.com/wiki/Z-95ML_Headhunter)

The Z-95ML Headhunter was a common Z-95 Headhunter variant built as a missile launch platform. It was outfitted with additional missile-racks and long range ordnance hard-points.

## Specifications

- **Name:** Z-95ML Headhunter
- **Manufacturer:** Incom Corporation/Subpro Corporation
- **Line:** Z-95 Headhunter
- **Type:** Starfighter
- **Armament:**
  - Missile-racks
  - Long range ordnance hard-points
- **Role:** Missile launch platform
