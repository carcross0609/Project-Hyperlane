# Class type B

**Continuity:** Legends  
**Source:** [Class type B/Legends](https://starwars.fandom.com/wiki/Class_type_B/Legends)

Class Type B escort shuttles were transports used by the Confederacy of Independent Systems during the Clone Wars. At least one Type B shuttle was captured by the Galactic Republic.

## Specifications

- **Name:** Class type B
- **Manufacturer:** Haor Chall Engineering
- **Type:** Sheathipede-class shuttle
- **Length:** 20 meters
- **Hyperdrive:** Class 2.0
- **Hdsystem:** Equipped
- **Armament:** Laser cannons (3)
- **Role:** Transport
- **Firstuse:** 21 BBY
- **Affiliation:**
  - Confederacy of Independent Systems
  - Galactic Republic
