# Imperial Customs Corvette

**Continuity:** Legends  
**Source:** [Imperial Customs Corvette](https://starwars.fandom.com/wiki/Imperial_Customs_Corvette)

The Rendili StarDrive light corvette, commonly known as the Imperial Customs Corvette, was a light starship commonly used for patrol and inspection actions.

## Specifications

- **Name:** Imperial Customs Corvette
- **Manufacturer:** Rendili StarDrive
- **Model:** Light Corvette
- **Type:** Corvette
- **Cost:**
  - Not legally available for sale.
  - Black market cost varies based on market conditions.
- **Length:** 180 meters
- **Max Speed:** 1,050 kph
- **Hyperdrive:**
  - Class 2.0
  - Class 8.0 (backup)
- **Shield Gen:** Shield generator equipped
- **Navigation:** Navigation computer equipped
- **Armament:** Double turbolaser turrets (6)
- **Bays:** No onboard craft capacity; multiple external docking systems
- **Crew:**
  - Crew (52)
  - Gunners (6)
- **Skeleton:** 18
- **Passengers:** 20 (stormtroopers)
- **Capacity:** 500 metric tons
- **Consumables:** 2 months (can be extended mid-mission through capture operations)
- **Availability:**
  - Legal: military only
  - Black market: available from pirates and shadowports
- **Role:**
  - Picket
  - Patrol
- **Affiliation:**
  - Galactic Empire
  - Rodian Home Fleet
  - Pirates
