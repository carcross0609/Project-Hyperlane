# Drone ore shuttle

**Continuity:** Legends  
**Source:** [Drone ore shuttle](https://starwars.fandom.com/wiki/Drone_ore_shuttle)

Drone ore shuttles were used in the Koros system around 5000 BBY. They had no firepower, but had strong armor. Also they were equipped with repulsor-chute.

## Specifications

- **Name:** Drone ore shuttle
- **Type:** Shuttle
- **Affiliation:** Galactic Republic
