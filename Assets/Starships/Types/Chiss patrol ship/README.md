# Chiss patrol ship

**Continuity:** Canon  
**Source:** [Chiss patrol ship](https://starwars.fandom.com/wiki/Chiss_patrol_ship)

The Chiss patrol ship was utilized by the Chiss Ascendancy. Several of these ships participated in a exercise at the Taharim Academy. The Ascendancy's Ruling and Great Families also used Chiss patrol ships, all with the same basic hull. Each family then added their crest and family design ornamentation. The Xodlak family used the ships as part of their planetary defense fleet.

- **Name:** Chiss patrol ship
- **Type:** Patrol ship
