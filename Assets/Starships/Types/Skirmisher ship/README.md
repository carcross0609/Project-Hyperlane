# Skirmisher ship

**Continuity:** Legends  
**Source:** [Skirmisher ship](https://starwars.fandom.com/wiki/Skirmisher_ship)

Skirmisher ships were starships of the Confederate Navy, used to send battle droids to board hostile capital ships. They were deployed prior to the Battle of Praesitlyn, in near-orbit of that planet, activating their cloaking devices and ambushing the Republic battle fleet as it approached. One such skirmisher was used to successfully board the Republic command ship Ranger, albeit only temporarily.
