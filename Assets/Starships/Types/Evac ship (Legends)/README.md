# Evac ship

**Continuity:** Legends  
**Source:** [Evac ship/Legends](https://starwars.fandom.com/wiki/Evac_ship/Legends)

Evac ship was a starship used to evacuate individuals from a hostile situation. Asajj Ventress and Durge used an evac ship to escape Queyta in the Clone Wars. Evac ships were also used decades later during the Battle of Gyndine, where an entire planetary population was evacuated.
