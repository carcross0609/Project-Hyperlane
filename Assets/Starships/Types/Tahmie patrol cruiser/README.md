# Tahmie patrol cruiser

**Continuity:** Canon  
**Source:** [Tahmie patrol cruiser](https://starwars.fandom.com/wiki/Tahmie_patrol_cruiser)

The Tahmie patrol cruiser was a type of patrol cruiser utilized by the Chiss Ascendancy's Tahmie family. Equipped with engines and a hyperdrive, the cruisers were armed with spectrum lasers.
