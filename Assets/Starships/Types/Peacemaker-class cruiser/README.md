# Peacemaker-class cruiser

**Continuity:** Legends  
**Source:** [Peacemaker-class cruiser](https://starwars.fandom.com/wiki/Peacemaker-class_cruiser)

The Peacemaker-class cruiser was an ancient type of warship used by Je'daii explorers to travel between the worlds of the Tython system, during the pre-Republic era.

## Specifications

- **Name:** Peacemaker-class cruiser
- **Type:** Cruiser
- **Shield Gen:** None
- **Armament:** 4 laser cannons
- **Crew:** 3
- **Skeleton:** 1
- **Othersystems:** HoloNet entertainment system
- **Availability:** Used by Je'daii Rangers
- **Affiliation:** Je'daii Order
