# Trandoshan dropship

**Continuity:** Legends  
**Source:** [Trandoshan dropship](https://starwars.fandom.com/wiki/Trandoshan_dropship)

The Trandoshan dropship was a large transport vessel used to deploy Trandoshan mercenaries and slavers on target ships.

## Specifications

- **Name:** Trandoshan dropship
- **Model:** Trandoshan troop transport
- **Type:** Transport
- **Crew:** Pilot (2)
- **Passengers:** 30 (approximately)
- **Role:** Carrier
- **Affiliation:**
  - Trandoshans
  -   Trandoshan fleet
  - Confederacy of Independent Systems
