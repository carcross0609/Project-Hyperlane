# Felpajh 10A

**Continuity:** Legends  
**Source:** [Felpajh 10A](https://starwars.fandom.com/wiki/Felpajh_10A)

The Felpajh 10A was a luxury suborbital shuttle manufactured by Larjh StarCorporation. These shuttles were commonly used to transport passengers from the ground to a waiting liner.

## Specifications

- **Name:** Felpajh 10A
- **Manufacturer:** Larjh StarCorporation
- **Type:** Sublight passenger shuttle
- **Cost:**
  - 225,000 credits (new)
  - 100,000 credits (used)
- **Length:** 31 meters
- **Max Speed:** 750 kmh
- **Crew:** 1
- **Passengers:** 8
- **Capacity:** 5 metric tons
- **Consumables:** 10 days
- **Role:** Personal shuttle
