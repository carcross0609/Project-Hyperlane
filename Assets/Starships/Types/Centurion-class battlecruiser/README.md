# Centurion-class battlecruiser

**Continuity:** Canon  
**Source:** [Centurion-class battlecruiser](https://starwars.fandom.com/wiki/Centurion-class_battlecruiser)

The Centurion-class battlecruiser was a class of battlecruiser; at least one ship of this class was active during the New Republic Era. Zeva Bliss, head of the Spice Runners of Kijimi in 18 ABY, used one such vessel as her flagship. The crime leader used it to transport her daughter Zorii Bliss and pilot Poe Dameron back to Kijimi.
