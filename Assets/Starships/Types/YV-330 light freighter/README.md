# YV-330 light freighter

**Continuity:** Legends  
**Source:** [YV-330 light freighter](https://starwars.fandom.com/wiki/YV-330_light_freighter)

The YV-330 light freighter was a YV series light freighter produced by the Corellian Engineering Corporation. It was 26 meters long, and its stock configuration included a twin weapons mounting beneath the cockpit. Although YV-series ships were not as easily customized as the earlier YT series, a number of standard upgrades were available, including an enhanced sensor package.
