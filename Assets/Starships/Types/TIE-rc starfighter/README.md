# TIE/rc starfighter

**Continuity:** Legends  
**Source:** [TIE/rc starfighter](https://starwars.fandom.com/wiki/TIE/rc_starfighter)

The TIE/rc starfighter was a variant of the standard TIE/LN starfighter that was used by the Galactic Empire which was specialized for reconnaissance, used for scouting in both fleet and starfighter wing operations.
