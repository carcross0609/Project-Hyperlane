# Cargolift vessel

**Continuity:** Legends  
**Source:** [Cargolift vessel](https://starwars.fandom.com/wiki/Cargolift_vessel)

A cargolift Vessel was a ship that carried exports from one system to another. Offworld Mining Corporation made use of these vessels. One such class was the Conductor-class short-haul landing craft.
