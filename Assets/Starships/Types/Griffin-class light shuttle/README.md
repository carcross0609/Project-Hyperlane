# Griffin-class light shuttle

**Continuity:** Canon  
**Source:** [Griffin-class light shuttle](https://starwars.fandom.com/wiki/Griffin-class_light_shuttle)

The Griffin-class light shuttle was a type of shuttle used by the First Order. One such shuttle was stolen by J-Squadron, a group of Resistance cadets, during the Battle of Starkiller Base.

- **Name:** Griffin-class light shuttle
- **Type:** Shuttle
- **Hdsystem:** Equipped
- **Affiliation:**
