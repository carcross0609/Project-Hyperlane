# SRX-T Manta

**Continuity:** Canon  
**Source:** [SRX-T Manta](https://starwars.fandom.com/wiki/SRX-T_Manta)

The SRX-T Manta was a class of cruiser used by Crimson Dawn and pirates during the Imperial Era. The Manta was armed with eight laser cannon turrets and missile launchers. It was outfitted with a targeting computer, a deflector shield generator, and had six sublight engines along with a hyperdrive system.
