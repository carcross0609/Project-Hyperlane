# Refinery ship

**Continuity:** Canon  
**Source:** [Refinery ship](https://starwars.fandom.com/wiki/Refinery_ship)

A refinery ship was a class of starship that served as a mobile processing facility. OteroaCorp owned three refinery ships, one of which, The Oteroan Sky, eventually crashed into the planet Dathomir. The ships were designed to orbit a planet and process shiploads of material from the surface.
