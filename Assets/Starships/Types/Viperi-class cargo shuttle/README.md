# Viperi-class cargo shuttle

**Continuity:** Canon  
**Source:** [Viperi-class cargo shuttle](https://starwars.fandom.com/wiki/Viperi-class_cargo_shuttle)

The Viperi-class cargo shuttle was a type of shuttle. Dahara, a Hutt of the Devirsivik Clan, utilized a refitted Viperi-class cargo shuttle that she named the Sarlacc's Scorn. Churo the Hutt compared the shape of the shuttle to the head of a Hutta snake with landing struts that gave it a spiderlike appearance.
