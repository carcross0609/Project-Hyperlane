# Deep space satellite tender

**Continuity:** Legends  
**Source:** [Deep space satellite tender](https://starwars.fandom.com/wiki/Deep_space_satellite_tender)

Deep space satellite tenders were a type of starship. One of the most common conversions of a bulk freighter, the craft was intended for the specialized use of looking after satellites.
