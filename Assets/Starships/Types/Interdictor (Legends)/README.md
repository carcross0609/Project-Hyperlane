# Interdictor

**Continuity:** Legends  
**Source:** [Interdictor/Legends](https://starwars.fandom.com/wiki/Interdictor/Legends)

An interdictor, also called an Interdictor ship, was the term used to refer to starships that had the capability of generating Interdiction fields using gravity well projectors.
