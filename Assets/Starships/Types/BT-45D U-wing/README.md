# BT-45D U-wing

**Continuity:** Canon  
**Source:** [BT-45D U-wing](https://starwars.fandom.com/wiki/BT-45D_U-wing)

The BT-45D U-wing was a transport model manufactured by Incom Corporation, and was the civilian version of the military UT-60D U-wing starfighter/support craft. Stripped of all its military applications as well as its hyperdrive, the BT-45D found favor with private security forces on a few scattered worlds in the Mid Rim during the reign of the Galactic Empire, while the UT-60D only had a limited production run prior to 1 BBY. Incom Corp recycled pre-planned options for the BT-45 version.
