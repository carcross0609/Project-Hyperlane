# RGC-6b escape pod

**Continuity:** Canon  
**Source:** [RGC-6b escape pod](https://starwars.fandom.com/wiki/RGC-6b_escape_pod)

The RGC-6b escape pod was a model of escape pod used by the Alliance to Restore the Republic as well as the gangster Azmorigan. They were crewed by one pilot and could accommodate a number of passengers. Phoenix Home, Merchant One, and Vanguard were equipped with RGC-6b escape pods.

## Specifications

- **Name:** RGC-6b escape pod
- **Type:** Escape pod
- **Crew:** 1
- **Passengers:** Several
- **Affiliation:**
  - Alliance to Restore the Republic
  -   Massassi Group
  -   Phoenix Cell
  - Azmorigan
