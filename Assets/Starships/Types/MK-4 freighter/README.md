# MK-4 freighter

**Continuity:** Canon  
**Source:** [MK-4 freighter](https://starwars.fandom.com/wiki/MK-4_freighter)

The MK-4 freighter was a starship model manufactured on the planet Corellia. A type of freighter, MK-4s were often used by smugglers. Owerto Naiucho owned one such ship, dubbed the Moth.

## Specifications

- **Name:** MK-4 freighter
- **Model:** MK-4
- **Type:** Freighter
- **Armament:** Equipped
- **Crew:**

  - 1 gunner
