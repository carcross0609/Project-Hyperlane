# Aramand System Cruiser III

**Continuity:** Legends  
**Source:** [Aramand System Cruiser III](https://starwars.fandom.com/wiki/Aramand_System_Cruiser_III)

The Aramand System Cruiser III was an Aramandi capital ship used in the Taler navy.

## Specifications

- **Name:** Aramand System Cruiser III
- **Length:** 140 meters
- **Max Speed:** 950 kmh
- **Hyperdrive:**
  - Class 1
  - Class 15 (backup)
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Navigation:** Equipped, limited to Aramand Cluster star systems
- **Armament:** 4 laser cannons
- **Crew:** 15; 4 gunners
- **Skeleton:** 7
- **Passengers:** 10 (troops)
- **Capacity:** 250 metric tons
- **Consumables:** 1 month
- **Role:** Aramand Cluster patrol and defense
- **Affiliation:** Taler
