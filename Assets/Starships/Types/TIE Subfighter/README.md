# TIE Subfighter

**Continuity:** Legends  
**Source:** [TIE Subfighter](https://starwars.fandom.com/wiki/TIE_Subfighter)

The TIE Subfighter was a submersible attack craft. It was armed with a concussion missile launcher and a single blaster cannon.

## Specifications

- **Name:** TIE Subfighter
- **Line:** TIE Series
- **Speed:** 90 kmh
- **Armament:**
  - concussion missile launcher
  - blaster cannon
- **Affiliation:** Galactic Empire
