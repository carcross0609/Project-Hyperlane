# Trident-class surveyor ship

**Continuity:** Legends  
**Source:** [Trident-class surveyor ship](https://starwars.fandom.com/wiki/Trident-class_surveyor_ship)

The Trident-class surveyor ship was a scout ship produced by Arakyd Industries during the Galactic Civil War for long-term, deep-space exploration and planetary surveying.

## Specifications

- **Name:** Trident-class surveyor ship
- **Manufacturer:** Arakyd Industries
- **Model:** Trident-class surveyor ship
- **Type:** Exploration ship
- **Cost:**
  - 1,475,000 credits (new)
  - 950,000 credits (used)
- **Length:** 82.5 meters
- **Max Speed:**
  - 800 km/h (atmosphere)
  - 200 km/h (aquatic)
- **Engine:** Capable of underwater operation
- **Hyperdrive:**
  - Class 0.75
  - Backup: Class 10
- **Shield Gen:** Equipped
- **Hull:** Reinforced for high pressure
- **Sensor:** Scientific-grade sensors capable of underwater operation
- **Armament:**

  - Concussion mine layer   (1, aft)
  -   12 seismic charges
- **Escapepods:** 1 escape pod, plus detachable command pod "life boat"
- **Crew:** 7&ndash;10
- **Skeleton:** 1 in conjunction with AI
- **Passengers:** 3
- **Capacity:** 80 tons
- **Consumables:** 9 months
- **Othersystems:**
  - Droid intelligence system
  - Hidden electronics suite
  - Bacta tanks (4)
  - Stasis pods (2)
- **Role:** Scout ship
