# Cargo Empress super freighter

**Continuity:** Canon  
**Source:** [Cargo Empress super freighter](https://starwars.fandom.com/wiki/Cargo_Empress_super_freighter)

The Cargo Empress super freighter was a model of transport produced by Ghtroc Industries. The super freighter class was a commercial failure and led to the respected starship company going defunct by the Imperial Era.

## Specifications

- **Name:** Cargo Empress super freighter
- **Manufacturer:** Ghtroc Industries
- **Model:** Cargo Empress
- **Type:** Super freighter
- **Role:** Transport
