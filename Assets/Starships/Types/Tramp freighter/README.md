# Tramp freighter

**Continuity:** Canon  
**Source:** [Tramp freighter](https://starwars.fandom.com/wiki/Tramp_freighter)

A tramp freighter was a type of freighter classification. Because of its many dents and scratches, the Millennium Falcon was said to resemble a tramp freighter.
