# Praetor II-class ship

**Continuity:** Canon  
**Source:** [Praetor II-class ship](https://starwars.fandom.com/wiki/Praetor_II-class_ship)

The Praetor II-class ship was a class of enormous starship used by the naval forces of the Galactic Empire. The Empire's Mk IX Orbital Maintenance Depots were large enough to service Praetor II-class ships as well as Executor-class Star Dreadnoughts. The starship also shared a similar name to the Praetor-class Star Battlecruiser.
