# Fuel container

**Continuity:** Legends  
**Source:** [Fuel container](https://starwars.fandom.com/wiki/Fuel_container)

A fuel container was a type of starship used by the Galactic Empire. The Transtom was a fuel container, and was destroyed en route to the main fleet during the Galactic Civil War.
