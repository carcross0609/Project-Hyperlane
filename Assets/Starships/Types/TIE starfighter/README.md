# TIE starfighter

**Continuity:** Legends  
**Source:** [TIE starfighter](https://starwars.fandom.com/wiki/TIE_starfighter)

The TIE starfighter was the first upgraded model of the T.I.E. starfighter produced by the Galactic Empire.

## Specifications

- **Name:** TIE starfighter
- **Manufacturer:** Sienar Fleet Systems
- **Line:** TIE Series
- **Model:** Twin Ion Engine starfighter
- **Type:** Starfighter
- **Cost:**
  - 75,000 credits (new)
  - 45,000 credits (used)
- **Length:** 6.3 meters
- **Max Accel:** 4,100 G
- **Mglt:** 100 MGLT
- **Max Speed:** 1,200 km/h
- **Engine:**
  - SFS P-s4 twin ion engines (rated 150 KTU)
  - SFS P-w401 ion maneuvering jets (2)
- **Hdsystem:** 2-jump memory navicomputer
- **Power:** SFS I-a2b solar ionization reactor
- **Shield Gen:** None (upgrade only)
- **Hull:** Titanium alloy hull (15 RU)
- **Avionics:** SFS F-3.2 flight avionics system
- **Armament:**
  - SFS L-s1 laser cannons (2)
  - Concussion missile launchers (2)
- **Crew:** Pilot (1)
- **Passengers:** None
- **Capacity:** 65 kilograms
- **Consumables:** 2 days
- **Othersystems:**
  - AE-35 subspace transceiver
  - Ejection seat
- **Role:** Multi-purpose space superiority fighter
- **Affiliation:** Galactic Empire
