# D-wing fighter

**Continuity:** Canon  
**Source:** [D-wing fighter](https://starwars.fandom.com/wiki/D-wing_fighter)

The D-wing fighter was a type of starfighter active during the First Order-Resistance War. A modified D-wing was used by the bounty hunter Seleno Chandro.
