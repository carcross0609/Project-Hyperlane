# ILH-KK Citadel-class civilian cruiser

**Continuity:** Legends  
**Source:** [ILH-KK Citadel-class civilian cruiser](https://starwars.fandom.com/wiki/ILH-KK_Citadel-class_civilian_cruiser)

The ILH-KK Citadel-class civilian cruiser, also known as simply the Citadel-class cruiser or Citadel cruiser, was a heavily armed and armored transport built by Koensayr during the final years of the Galactic Republic.
