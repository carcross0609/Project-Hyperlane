# Unar-Con tug

**Continuity:** Canon  
**Source:** [Unar-Con tug](https://starwars.fandom.com/wiki/Unar-Con_tug)

The Unar-Con tug was a model of spacetug. Woan Barso owned one, which he used to move cargo up to the freighters orbiting Jedha, as well smuggle refugees out of Jedha City.

- **Name:** Unar-Con tug
- **Type:** Spacetug
