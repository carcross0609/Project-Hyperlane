# Gunship fighter

**Continuity:** Legends  
**Source:** [Gunship fighter](https://starwars.fandom.com/wiki/Gunship_fighter)

The gunship fighter was the direct predecessor of the LAAT/i and advanced gunship fighter. It was used in the Clone Wars by the Clone Army.
