# CEC Class-1 escape pod

**Continuity:** Legends  
**Source:** [CEC Class-1 escape pod/Legends](https://starwars.fandom.com/wiki/CEC_Class-1_escape_pod/Legends)

The CEC Class-1 escape pod was a model of escape pod with capacity for a single passenger that was manufactured by the Corellian Engineering Corporation. At the time that the smuggler Han Solo acquired the YT-1300 light freighter Millennium Falcon, the starship carried five Class-1 escape pods.

## Specifications

- **Name:** CEC Class-1 escape pod
- **Manufacturer:** Corellian Engineering Corporation
- **Passengers:** 1 passenger
- **Role:** Escape pod
