# Drovan Freighter

**Continuity:** Canon  
**Source:** [Drovan Freighter](https://starwars.fandom.com/wiki/Drovan_Freighter)

The Drovan Freighter was a type of freighter. At least one Drovan freighter flew with the Citizens' Fleet during the Battle of Exegol against the Sith Eternal forces.

## Specifications

- **Name:** Drovan Freighter
- **Type:** Freighter
