# XA-8 starfighter

**Continuity:** Legends  
**Source:** [XA-8 starfighter](https://starwars.fandom.com/wiki/XA-8_starfighter)

The XA-8 starfighter was a starfighter class in use by the Galactic Republic during the Cold War. In 3643 BBY they were used in the Independent Operation Sebaddon.
