# Action VI bulk transport

**Continuity:** Canon  
**Source:** [Action VI bulk transport](https://starwars.fandom.com/wiki/Action_VI_bulk_transport)

The Action VI bulk transport or Action VI bulk freighter, was a model of unarmed bulk freighter manufactured by the Corellian Engineering Corporation. It was in use by the time of the Separatist Crisis. One such ship landed at Theed Spaceport shortly before the outbreak of the Clone Wars.

## Specifications

- **Name:** Action VI bulk transport
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** Action series
- **Type:** Bulk freighter
- **Cost:** 200,000 credits
- **Length:** 100 meters
- **Hyperdrive:**
  - Class 3 (primary)
  - Class 20 (backup)
- **Shield Gen:** Equipped (rudimentary)
- **Sensor:** Medium range
- **Armament:**
  - None
  - Quad laser cannons
  - Concussion missile launchers (modified)
- **Crew:** 20
- **Passengers:** 5
- **Consumables:** 3 months
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
