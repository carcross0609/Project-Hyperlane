# Dark Trooper hyperspace capsule

**Continuity:** Legends  
**Source:** [Dark Trooper hyperspace capsule](https://starwars.fandom.com/wiki/Dark_Trooper_hyperspace_capsule)

.]] Dark troopers used hyperspace capsule vehicles when serving the Galactic Empire, which were were launched from the Arc Hammer. One devastating feature of the launch pods was the ability to explode on contact with a Rebel planet, which softened the Rebel forces just prior to the attack on Tak Base.
