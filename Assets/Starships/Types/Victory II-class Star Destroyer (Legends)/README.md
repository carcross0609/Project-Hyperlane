# Victory II-class Star Destroyer

**Continuity:** Legends  
**Source:** [Victory II-class Star Destroyer/Legends](https://starwars.fandom.com/wiki/Victory_II-class_Star_Destroyer/Legends)

The Victory II-class Star Destroyer, also known as the Victory II-class Destroyer, or Victory Cruiser, was an improved version of the Victory I-class Star Destroyer. The Victory II-class was a more direct predecessor to the Imperial-class Star Destroyer.
