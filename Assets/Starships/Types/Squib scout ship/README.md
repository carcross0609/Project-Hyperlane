# Squib scout ship

**Continuity:** Legends  
**Source:** [Squib scout ship](https://starwars.fandom.com/wiki/Squib_scout_ship)

Squib scout ships were small scouting vessels used by Squibs to find garbage and salvage. The typical Squib scout ship was armed with only a tractor beam.
