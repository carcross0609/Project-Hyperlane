# Drop-fighter

**Continuity:** Legends  
**Source:** [Drop-fighter](https://starwars.fandom.com/wiki/Drop-fighter)

A Drop-fighter was a type of Separatist starship capable of orbital bombardment. During the Battle of Duro Drop-fighters bombarded Duro's planetside industrial factories. The bombardment caused the environment to be exposed to toxic chemicals, which allowed General Grievous's droid forces to easily claim victory.
