# V-wing Speeder Transport, Model A

**Continuity:** Legends  
**Source:** [V-wing Speeder Transport, Model A](https://starwars.fandom.com/wiki/V-wing_Speeder_Transport%2C_Model_A)

The V-wing Speeder Transport, Model A was a transport used by the New Republic to deploy V-wing airspeeders from capital starships. Like the V-wing itself, the transport was manufactured by Slayn & Korpil.

## Specifications

- **Name:** V-wing Speeder Transport, Model A
- **Manufacturer:** Slayn & Korpil
- **Type:** Orbital interface transport
- **Cost:** 175,000 credits
- **Length:** 20 meters
- **Max Speed:** 1,000 kmh
- **Shield Gen:** Equipped
- **Crew:** 2
- **Skeleton:** 1
- **Passengers:** 4 (pilots)
- **Capacity:**
  - 2 metric tons
  - Docking sleeves for 4 V-wing airspeeders
- **Consumables:** 3 days
- **Role:** Airspeeder transport and deployment
