# Corona-class armed frigate

**Continuity:** Canon  
**Source:** [Corona-class armed frigate](https://starwars.fandom.com/wiki/Corona-class_armed_frigate)

The Corona-class armed frigate, also known as the pirate saucer mothership, was a large saucer-shaped combat frigate model used by the Ohnaka Gang of Florrum, led by pirate leader Hondo Ohnaka.

## Specifications

- **Name:** Corona-class armed frigate
- **Manufacturer:** Haor Chall Engineering Corporation
- **Type:** Combat frigate
- **Length:** 376.29-meter diameter
- **Max Speed:** 700 kph
- **Hyperdrive:** Class 1
- **Hdsystem:** Equipped
- **Armament:**
  - Ion cannons
  - Laser cannons
  - Missiles
  - Point-defense laser cannons
  - Tractor beams
- **Complement:**
  - Flarestar-class attack shuttles (6)
  - WLO-5 battle tanks (12)
- **Crew:** 64
- **Othersystems:** Planetary surface landing capability
- **Role:** Space combat
- **Affiliation:**
  - Confederacy of Independent Systems (proposed)
  - Ohnaka Gang
