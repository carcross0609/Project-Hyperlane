# TIE/fc

**Continuity:** Canon  
**Source:** [TIE/fc](https://starwars.fandom.com/wiki/TIE/fc)

The TIE/fc, or Fire Control, was a model of reconnaissance TIE fighter series starfighter that was used by the Galactic Empire. It was a variant from the base TIE/ln space superiority starfighter by fitting the standard model's fuselage with specialized equipment.

## Specifications

- **Name:** TIE/fc
- **Line:** TIE series
- **Role:** Reconnaissance
- **Affiliation:** Galactic Empire
