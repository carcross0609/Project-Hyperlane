# Geonosian corvette

**Continuity:** Legends  
**Source:** [Geonosian corvette](https://starwars.fandom.com/wiki/Geonosian_corvette)

A type of corvette was built by the Geonosian species that was bronze-skinned with a pointed prow which split into a pair of mandibles. Two of the corvettes were used in an ambush upon the forces of the Galactic Republic on Pengalan IV, during the battle there between the Republic and the Confederacy of Independent Systems in the Clone Wars.
