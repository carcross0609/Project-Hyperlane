# Battlecarrier

**Continuity:** Canon  
**Source:** [Battlecarrier](https://starwars.fandom.com/wiki/Battlecarrier)

A battlecarrier was a type of capital ship that served as a battlecruiser and a carrier. The Secutor-class Star Destroyer was a type of battlecarrier.
