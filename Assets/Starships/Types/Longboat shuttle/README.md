# Longboat shuttle

**Continuity:** Legends  
**Source:** [Longboat shuttle](https://starwars.fandom.com/wiki/Longboat_shuttle)

Longboat shuttles were a type of shuttlecraft built by the Tof Kingdom. They were used as troop transports during planetary invasions.

## Specifications

- **Name:** Longboat shuttle
- **Type:** Shuttle
- **Crew:** 40
- **Role:** Troop transport
- **Affiliation:** Tof Kingdom
