# VCX-series auxiliary starfighter

**Continuity:** Canon  
**Source:** [VCX-series auxiliary starfighter](https://starwars.fandom.com/wiki/VCX-series_auxiliary_starfighter)

The VCX-series auxiliary starfighter, also known as an Auxiliary Shuttle or an Attack Shuttle, was a short-range starfighter that was attachable to the VCX-100 light freighter manufactured by Corellian Engineering Corporation. The rebels of Lothal used a modified type of this fighter during various situations when fighting against the Empire.
