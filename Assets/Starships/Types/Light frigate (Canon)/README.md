# Light frigate

**Continuity:** Canon  
**Source:** [Light frigate](https://starwars.fandom.com/wiki/Light_frigate)

A light frigate was a classification of frigate used by the Paataatus Hiveborn in the Unknown Regions of the galaxy. The Paataatus utilized light frigates, which seldom traveled alone.
