# Field Secured Container Vessel ; (FSCV)

**Continuity:** Canon  
**Source:** [Field Secured Container Vessel](https://starwars.fandom.com/wiki/Field_Secured_Container_Vessel)

The Field Secured Container Vessel (FSCV) was a class of fuel tanker spacetug that was used to transport starship fuel cells by the Galactic Empire. Two FSCVs could generate one or more force field bubbles or spheres using force-field generators. Additional force fields could be linked, forming a train. An FSCV contained a command capsule, a force field generator, fuel cells, an auxiliary command capsule, hexagonal-shaped engines. One train of FSCVs was Black Ice, which consisted of nine fuel bubbles and was assigned to the Imperial Replenishment Fleet DK-209 before it was captured by the Alliance to Restore the Republic and destroyed in a collision.
