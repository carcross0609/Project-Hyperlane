# Republic space tug

**Continuity:** Canon  
**Source:** [Republic space tug](https://starwars.fandom.com/wiki/Republic_space_tug)

The Republic space tug, or Republic tugboat, was a model of spacetug deployed by the Republic Navy during the Clone Wars. Several tugs were launched following the Carida incident to rescue the astromech droid of Jedi General Anakin Skywalker, R2-D2, from the wreckage of the Venator-class Star Destroyer Renown, which was turned by Separatist Alliance forces into a large bomb.

## Specifications

- **Name:** Republic space tug
- **Type:** Spacetug
- **Engine:** Sublight engines (8)
- **Role:**
  - Rescue
  - Salvage
- **Affiliation:**
  - Galactic Republic
  -   Republic Navy
