# Nestt-class light freighter

**Continuity:** Legends  
**Source:** [Nestt-class light freighter](https://starwars.fandom.com/wiki/Nestt-class_light_freighter)

The Nestt-class light freighter was one of SoroSuub Corporation's later attempts to seize a portion of the small starship market, while simultaneously appeasing the Empire. The Nestt had a fairly short cruising range, but was a little higher than average on cargo tonnage. Its major weakness was that it was not designed to carry weapons, nor did it have surplus power for adding them later (an addition intended to keep the Empire from squashing the project). To add weapons systems required an upgrade of the power core, generally considered to be more trouble than it was worth.
