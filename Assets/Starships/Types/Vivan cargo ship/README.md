# Vivan cargo ship

**Continuity:** Canon  
**Source:** [Vivan cargo ship](https://starwars.fandom.com/wiki/Vivan_cargo_ship)

The Vivan cargo ship was a class of freighter that was used by the Chiss Ascendancy in the time prior to the Vagaari pirate operations. They carried life-support supplies, such as foodstuffs and oxygen reserves enough to last three weeks.

## Specifications

- **Name:** Vivan cargo ship
- **Type:** Freighter
- **Affiliation:** Chiss Ascendancy
