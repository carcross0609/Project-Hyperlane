# MK-II shuttle

**Continuity:** Legends  
**Source:** [MK-II shuttle](https://starwars.fandom.com/wiki/MK-II_shuttle)

The MK-II shuttle was a ship used by the Eternal Empire. In 3631 BBY Koth Vortena stole two of these shuttles when he and Lana Beniko came to Zakuul to rescue the Outlander.

## Specifications

- **Name:** MK-II shuttle
- **Type:** Shuttle
- **Role:** Transport personnel
- **Affiliation:**
  - Eternal Empire
  - Eternal Alliance
