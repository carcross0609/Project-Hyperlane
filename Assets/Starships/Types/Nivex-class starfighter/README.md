# Nivex-class starfighter

**Continuity:** Canon  
**Source:** [Nivex-class starfighter](https://starwars.fandom.com/wiki/Nivex-class_starfighter)

The Nivex-class starfighter was a type of single-pilot starfighter. The thieves Pax Maripher and Rahara Wick owned a Nivex-class starfighter, the Facet.

## Specifications

- **Name:** Nivex-class starfighter
- **Type:** Starfighter
- **Engine:** At least 1
- **Target:** Autopursuit
- **Crew:** 1 pilot
