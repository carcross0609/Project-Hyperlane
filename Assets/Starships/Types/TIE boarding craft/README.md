# TIE boarding craft

**Continuity:** Canon  
**Source:** [TIE boarding craft](https://starwars.fandom.com/wiki/TIE_boarding_craft)

The TIE boarding craft was a variant of Sienar Fleet Systems's TIE series. An armored shuttle, it was used by the Galactic Empire for troop transportation and boarding.
