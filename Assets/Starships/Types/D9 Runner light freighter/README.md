# D9 Runner light freighter

**Continuity:** Legends  
**Source:** [D9 Runner light freighter](https://starwars.fandom.com/wiki/D9_Runner_light_freighter)

The D9 Runner light freighter was one of the first freighter designs created by Kuat Drive Yards after the rise of the New Order.

## Specifications

- **Name:** D9 Runner light freighter
- **Manufacturer:** Kuat Drive Yards
- **Model:** D9 Runner
- **Type:** Light freighter
- **Length:** 23 meters
- **Navigation:** Nav computer equipped
- **Crew:** 3 (2 gunners)
- **Skeleton:** 1
- **Passengers:** 4
- **Capacity:** 75 metric tons
- **Consumables:** 2 months
- **Lifesupport:** Equipped
- **Role:** Transport
