# Hunter-class starfighter

**Continuity:** Legends  
**Source:** [Hunter-class starfighter](https://starwars.fandom.com/wiki/Hunter-class_starfighter)

The Hunter-class starfighter was a starfighter designed for interplanetary flight. They were heavily armed and the fastest, most maneuverable ships used by the Je'daii Order in the Tython system. Je'daii Rangers often customized these ships.
