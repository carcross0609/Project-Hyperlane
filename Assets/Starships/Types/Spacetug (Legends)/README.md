# Spacetug

**Continuity:** Legends  
**Source:** [Spacetug/Legends](https://starwars.fandom.com/wiki/Spacetug/Legends)

.]] A spacetug, also called a tug, space tug or tugship, was a type of starship used to move other ships or structures. This usually happened by docking with the structure or with the use of tractor beams. Capital ships used tugs to load and unload cargo containers. Tugs could be equipped with hyperdrives, like the Heavy Lifter, but were more frequently without. Likewise, tugs were usually unarmed, but variants with weapon-equipped models existed as well.
