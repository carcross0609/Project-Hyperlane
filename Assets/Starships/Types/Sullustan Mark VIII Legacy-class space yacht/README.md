# Sullustan Mark VIII Legacy-class space yacht

**Continuity:** Canon  
**Source:** [Sullustan Mark VIII Legacy-class space yacht](https://starwars.fandom.com/wiki/Sullustan_Mark_VIII_Legacy-class_space_yacht)

The Sullustan Mark VIII Legacy-class space yacht was a yacht that was manufactured in the Sullust shipyards. It was considered old in 377 BBY but it was still desirable. Piralli had spent many years restoring the one he owned but still needed a central processor to make it flyable.
