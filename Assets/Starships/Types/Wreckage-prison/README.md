# Wreckage-prison

**Continuity:** Canon  
**Source:** [Wreckage-prison](https://starwars.fandom.com/wiki/Wreckage-prison)

A wreckage-prison was a type of prison comprised of various wrecked starships that was hauled by a prison-tug. During the Galactic Civil War, Accresker Jail was a wreckage-prison connected to a prison-tug that was used by the Galactic Empire.
