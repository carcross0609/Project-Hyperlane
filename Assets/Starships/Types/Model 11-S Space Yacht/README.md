# Model 11-S Space Yacht

**Continuity:** Legends  
**Source:** [Model 11-S Space Yacht](https://starwars.fandom.com/wiki/Model_11-S_Space_Yacht)

The Aavman Extravagance Model 11-S Space Yacht was a large and luxurious space yacht, favored by wealthy senior citizens. Leger DeMain's starship, Siren III, was a heavily modified Model 11-S Space Yacht.
