# Rocket ship

**Continuity:** Legends  
**Source:** [Rocket ship](https://starwars.fandom.com/wiki/Rocket_ship)

A rocket ship was one of the earliest forms of space transport, usually armed with primitive laser weaponry and powered by nuclear propulsion. C-3PO and R2-D2 traveled to Sooma on a rocket ship.
