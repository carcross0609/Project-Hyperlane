# Unidentified Raxus ship

**Continuity:** Canon  
**Source:** [Unidentified Raxus ship](https://starwars.fandom.com/wiki/Unidentified_Raxus_ship)

A ship was a ship designed to be used by the Raxus guards. Used for transportation, it was also armed with laser cannons on the bow of the ship.

## Specifications

- **Name:** Unidentified Raxus ship
- **Engine:** 2
- **Armament:** Two laser cannon
- **Role:** Transport
