# Ship of the line

**Continuity:** Legends  
**Source:** [Ship of the line/Legends](https://starwars.fandom.com/wiki/Ship_of_the_line/Legends)

A ship of the line was a term for a heavy capital ship in the Galactic Republic Navy, and Imperial Navy, and the Rebel Alliance Fleet.
