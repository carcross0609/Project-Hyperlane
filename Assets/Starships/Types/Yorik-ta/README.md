# Yorik-ta

**Continuity:** Legends  
**Source:** [Yorik-ta](https://starwars.fandom.com/wiki/Yorik-ta)

The yorik-ta was the Yuuzhan Vong version of an escape pod. They were made from black yorik coral and included a dovin basal for travel and defense. Supreme Overlord Shimrra Jamaane maintained a yorik-ta as his personal escape vessel aboard his Citadel worldship.
