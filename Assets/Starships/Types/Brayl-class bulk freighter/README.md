# Brayl-class bulk freighter

**Continuity:** Legends  
**Source:** [Brayl-class bulk freighter](https://starwars.fandom.com/wiki/Brayl-class_bulk_freighter)

The Brayl-class bulk freighter was a cargo hauler. A modified Brayl-class bulk freighter, the Voxen Tass, measured 100 meters in length, required one pilot and seven other crewmembers, and carried 75,000 metric tons of cargo.
