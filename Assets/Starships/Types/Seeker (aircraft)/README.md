# Seeker (aircraft)

**Continuity:** Legends  
**Source:** [Seeker (aircraft)](https://starwars.fandom.com/wiki/Seeker_%28aircraft%29)

A seeker was a type of aircraft, a starfighter or atmospheric-combat flyer, used by the Jedi forces of the Army of Light during the Ruusan campaign in the New Sith Wars.
