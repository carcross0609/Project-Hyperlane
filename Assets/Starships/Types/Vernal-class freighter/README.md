# Vernal-class freighter

**Continuity:** Legends  
**Source:** [Vernal-class freighter](https://starwars.fandom.com/wiki/Vernal-class_freighter)

The Vernal-class freighter was a class of freighter during the time of the Clone Wars. The Altisian Jedi sect operated out of one such starship named Wookiee Gunner.
