# Cal-class battleship

**Continuity:** Legends  
**Source:** [Cal-class battleship](https://starwars.fandom.com/wiki/Cal-class_battleship)

The Cal-class battleship was the final version of a warship type designed by the Kumauri Empire.

- **Name:** Cal-class battleship
- **Manufacturer:**

- **Type:** Battleship
- **Length:** 3,000 meters
- **Armament:**

- **Role:** Battleship
- **Affiliation:**
