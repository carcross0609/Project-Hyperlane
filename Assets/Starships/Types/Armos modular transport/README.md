# Armos modular transport

**Continuity:** Legends  
**Source:** [Armos modular transport](https://starwars.fandom.com/wiki/Armos_modular_transport)

The Armos Modular Transport was a popular model of transport in the Outer Rim Territories and produced by SoroSuub Corporation during the Galactic Civil War.

## Specifications

- **Name:** Armos modular transport
- **Manufacturer:** SoroSuub Corporation
- **Model:** Armos
- **Type:** Transport
- **Cost:** 780,000 credits
- **Hyperdrive:**
  - Class 2
  - Class 15 (backup)
- **Navigation:** Equipped
- **Crew:** 150
- **Passengers:** 1,000
