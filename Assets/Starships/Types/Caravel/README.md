# Caravel

**Continuity:** Legends  
**Source:** [Caravel](https://starwars.fandom.com/wiki/Caravel)

A caravel was a type of starship used by the Baobab Merchant Fleet. Caravels, such as the Seltiss-2 caravel, were in common usage by the Hutts.
