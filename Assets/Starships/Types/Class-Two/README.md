# Class-Two

**Continuity:** Canon  
**Source:** [Class-Two](https://starwars.fandom.com/wiki/Class-Two)

Class-Two was a class of starship that was deployed as part of the Dawn Fleet during Lady Qi'ra's attempts to destroy the Sith Lords Darth Sidious and Darth Vader. During the Battle at Amaxine Station, the Class-Two and Three vessels were ordered by Margo to destroy the long-range cannons of the Executor.
