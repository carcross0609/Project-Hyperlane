# FT-3C Imperium

**Continuity:** Legends  
**Source:** [FT-3C Imperium](https://starwars.fandom.com/wiki/FT-3C_Imperium)

The FT-3C Imperium was a starfighter in the reconstituted Sith Empire which performed in Strikefighter roles. Created in the shipyards of Dromund Kalakar, the Imperium was derived from the similar F-T2 Quell, though it was designed as a sensor-oriented coordinator starfighter.

## Specifications

- **Name:** FT-3C Imperium
- **Manufacturer:** Dromund Kalakar shipyards
- **Type:** Starfighter
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Armament:**
  - 2 twin laser cannons
  - equipable missiles or torpedoes
- **Role:** Reconnaissance
- **Affiliation:** Sith Empire
