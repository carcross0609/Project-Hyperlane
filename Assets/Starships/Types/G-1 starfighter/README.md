# G-1 starfighter

**Continuity:** Legends  
**Source:** [G-1 starfighter](https://starwars.fandom.com/wiki/G-1_starfighter)

The G-1 starfighter was a vessel created through a joint venture between Gungan BullbaBong and the Theed Palace Space Vessel Engineering Corps.
