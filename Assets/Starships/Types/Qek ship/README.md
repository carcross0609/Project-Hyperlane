# Qek ship

**Continuity:** Canon  
**Source:** [Qek ship](https://starwars.fandom.com/wiki/Qek_ship)

The term "Qek ship" referred to any starship featuring heavy armament concealed to look like normal cargo. Action VI bulk freighters were frequently modified for that purpose.
