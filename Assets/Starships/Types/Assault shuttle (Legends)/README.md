# Assault shuttle

**Continuity:** Legends  
**Source:** [Assault shuttle/Legends](https://starwars.fandom.com/wiki/Assault_shuttle/Legends)

Assault shuttles were a type of armed shuttles used by the Galactic Empire and New Republic for landing infantry units. An assault shuttle would typically contain one platoon consisting of forty stormtroopers.
