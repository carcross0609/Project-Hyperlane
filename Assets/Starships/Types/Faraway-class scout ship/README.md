# Faraway-class scout ship

**Continuity:** Legends  
**Source:** [Faraway-class scout ship](https://starwars.fandom.com/wiki/Faraway-class_scout_ship)

The Faraway-class scout ship was a spotter ship used by the Republic during the Clone Wars. As a scout ship, it was used primarily for reconnaissance and was loaded with sensory equipment. It also contained a slot for an astromech droid behind the cockpit.
