# CE-2 Transport

**Continuity:** Legends  
**Source:** [CE-2 Transport](https://starwars.fandom.com/wiki/CE-2_Transport)

The CE-2 Transport was a class of light freighter produced by Corellian Engineering Corporation.

## Specifications

- **Name:** CE-2 Transport
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Light Freighter
- **Cost:**
  - 200,000 credits (new)
  - 95,000 credits (used)
- **Length:** 100 meters
- **Max Speed:** 950 kmh
- **Hyperdrive:** Class 2, Class 12 backup
- **Crew:** 2
- **Passengers:** 2
- **Capacity:** 50,000 metric tons
- **Consumables:** 2 months
