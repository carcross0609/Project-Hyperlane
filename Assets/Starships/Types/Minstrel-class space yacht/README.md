# Minstrel-class space yacht

**Continuity:** Canon  
**Source:** [Minstrel-class space yacht](https://starwars.fandom.com/wiki/Minstrel-class_space_yacht)

The Minstrel-class space yacht was a model of large luxury space yacht manufactured by Ubrikkian Industries. Every Minstrel-class vessel was built to the specifications of its buyer.

## Specifications

- **Name:** Minstrel-class space yacht
- **Manufacturer:** Ubrikkian Industries
- **Type:** Yacht
- **Cost:** 1,750,000 credits
- **Hyperdrive:**
  - Class 2 (primary)
  - Class 12 (backup)
- **Sensor:** Medium range
- **Armament:**
  - Concealed turret-mounted light turbolaser batteries (6)
  - Medium ion cannons (6)
  - Heavy tractor beam projector (1)
- **Complement:**
  - Starfighters (6)
  - Shuttles (2)
- **Crew:** 37
- **Passengers:** 75
- **Consumables:** One year
- **Affiliation:**
  - Hutt Clan
  -   Jabba Desilijic Tiure's criminal empire
