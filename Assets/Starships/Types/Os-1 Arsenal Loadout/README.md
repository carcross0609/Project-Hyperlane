# Os-1 Arsenal Loadout

**Continuity:** Canon  
**Source:** [Os-1 Arsenal Loadout](https://starwars.fandom.com/wiki/Os-1_Arsenal_Loadout)

The Os-1 Arsenal Loadout was an alternate loadout for the Alpha-class Xg-1 Star Wing. One starship of this model once fired many explosives within an asteroid field.
