# TIE/rpt starfighter

**Continuity:** Legends  
**Source:** [TIE/rpt starfighter](https://starwars.fandom.com/wiki/TIE/rpt_starfighter)

The TIE/rpt starfighter, or TIE Raptor, was an unofficial, smaller variant of the standard TIE Fighter.

## Specifications

- **Name:** TIE/rpt starfighter
- **Manufacturer:**
  - Sienar Fleet Systems (original TIE design and components)
  - Rancor Base (Raptor design and manufacture)
- **Line:** TIE Series (derivative)
- **Model:** Twin Ion Engine/rpt starfighter
- **Type:** Starfighter
- **Length:** 6.8 meters
- **Max Speed:** 1,050 kmh
- **Hyperdrive:** Class 1.0
- **Shield Gen:** Equipped on some ships
- **Armament:**
  - Laser cannons (4)
  - Concussion missile launchers (2)
- **Crew:** Pilot (1)
- **Passengers:** None
- **Capacity:** 50 kilograms
- **Role:**
  - Space superiority fighter
  - Assault fighter
- **Affiliation:** Zsinj's Empire
