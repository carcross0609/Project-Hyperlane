# Consular escape pod

**Continuity:** Legends  
**Source:** [Consular escape pod](https://starwars.fandom.com/wiki/Consular_escape_pod)

The two escape pod carried aboard Consular-class cruisers carried 8 passengers each. They could only be activated from the inside.

## Specifications

- **Name:** Consular escape pod
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Escape pod
- **Passengers:** 8
