# Black Sun frigate

**Continuity:** Canon  
**Source:** [Black Sun frigate](https://starwars.fandom.com/wiki/Black_Sun_frigate)

The Black Sun frigate was a modified Gozanti-class cruiser that was repurposed to be used as a frigate by the Black Sun criminal syndicate during the Clone Wars.

## Specifications

- **Name:** Black Sun frigate
- **Model:** Modified Gozanti-class cruiser
- **Type:** Frigate
- **Engine:** Sublight engines (3)
- **Hdsystem:** Equipped
- **Armament:** Ventral twin laser cannon turret
- **Communications:** Rectennas (3)
- **Othersystems:** Landing gear
- **Role:** Smuggling vessel
- **Affiliation:**
  - Black Sun
  - Xomit Transport Systems
