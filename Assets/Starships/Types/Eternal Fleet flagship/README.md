# Eternal Fleet flagship

**Continuity:** Legends  
**Source:** [Eternal Fleet flagship](https://starwars.fandom.com/wiki/Eternal_Fleet_flagship)

- **Manufacturer:** Eternal Empire

- **Engine:** 9
- **Armament:** Laser cannons
- **Complement:**

  - Zakuul fighters
- **Role:** Flagship
