# Scout ship

**Continuity:** Legends  
**Source:** [Scout ship (TIE model)](https://starwars.fandom.com/wiki/Scout_ship_%28TIE_model%29)

The scout ship was a TIE Series model very similar to the TIE/LN starfighter, but it was equipped with a hyperdrive. The ship was used as a recon vessel by Thrawn's confederation, and was in service by 9 ABY. Grand Admiral Thrawn notably sent some of his operatives in a number of scout ships to conduct an information raid on Obroa-skai's library.
