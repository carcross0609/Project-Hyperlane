# Ore barge

**Continuity:** Legends  
**Source:** [Ore barge](https://starwars.fandom.com/wiki/Ore_barge)

Ore barges were a type of transport starship. The Eyttyrmin Batiiv pirates used a few dozen ore barges and cargo haulers, mounted with weapons, as part of their fleet. Sub-orbital ore barges were employed on worlds like Lan Barell to transport ore from the domestic mines to Shulell City airport.
