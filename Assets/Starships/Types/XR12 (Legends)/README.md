# XR12

**Continuity:** Legends  
**Source:** [XR12/Legends](https://starwars.fandom.com/wiki/XR12/Legends)

The XR12 was a type of personal-use spacecraft that was produced by Bendine during the time of the Galactic Republic. It was capsule-shaped and smaller than an average escape pod.

## Specifications

- **Name:** XR12
- **Manufacturer:** Bendine
- **Type:** Shuttle
