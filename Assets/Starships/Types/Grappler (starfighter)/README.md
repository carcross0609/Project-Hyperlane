# Grappler (starfighter)

**Continuity:** Legends  
**Source:** [Grappler (starfighter)](https://starwars.fandom.com/wiki/Grappler_%28starfighter%29)

The Grappler was an organic ship created by the living planet Zonama Sekot during the Battle of Yuuzhan'tar as part of the "Fight Without Fighting" plan against the Yuuzhan Vong.
