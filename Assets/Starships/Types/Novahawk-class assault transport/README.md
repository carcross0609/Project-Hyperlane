# Novahawk-class assault transport

**Continuity:** Canon  
**Source:** [Novahawk-class assault transport](https://starwars.fandom.com/wiki/Novahawk-class_assault_transport)

The Novahawk-class assault transport was a model of starship produced by Sabaoth Industries. The bounty hunter Ax Tagrin owned one called the Dalkor Dagger.
