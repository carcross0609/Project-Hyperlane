# Mere cruiser

**Continuity:** Legends  
**Source:** [Mere cruiser](https://starwars.fandom.com/wiki/Mere_cruiser)

The Mere Cruiser was a heavy cruiser created by the Mere of Maramere some time prior to the Clone Wars.

## Specifications

- **Name:** Mere cruiser
- **Manufacturer:** Mere
- **Type:** Cruiser
- **Length:** 195 meters
- **Engine:** Twin sublight drive engines
- **Armament:**
  - Heavy fore composite-beam laser cannon
  - 12 light turbolaser cannons
- **Affiliation:** Mere Resistance
