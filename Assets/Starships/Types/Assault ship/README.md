# Assault ship

**Continuity:** Canon  
**Source:** [Assault ship](https://starwars.fandom.com/wiki/Assault_ship)

Assault ships were a type of starship used for combat. The Galactic Republic used Acclamator-class transgalactic military assault ships during the Clone Wars, while the Mandalorian Death Watch used Mandalorian gunships, another model of assault ship. The Sentinel-class landing craft was the Imperial Navy's primary assault ship.
