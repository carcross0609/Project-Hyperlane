# SGS-45 Quarrel

**Continuity:** Legends  
**Source:** [SGS-45 Quarrel](https://starwars.fandom.com/wiki/SGS-45_Quarrel)

The SGS-45 Quarrel was a gunship model developed by Republic Sienar Systems for the Republic Navy that saw use during the Galactic War with the Sith Empire. Sporting long-range rail guns capable of being switched between ion, plasma or the standard slug models, the ship would fire at its targets from long range. It was well armed but had unimpressive speed.
