# Cranan star-hopper

**Continuity:** Canon  
**Source:** [Cranan star-hopper](https://starwars.fandom.com/wiki/Cranan_star-hopper)

The Cranan star-hopper was a type of starship. The Barbadelan pilot Karamu owned one such ship with his L-1g general purpose droid SV-3, but it was damaged when it crashed onto Rendel.
