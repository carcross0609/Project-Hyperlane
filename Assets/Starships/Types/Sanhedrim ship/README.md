# Sanhedrim ship

**Continuity:** Legends  
**Source:** [Sanhedrim ship](https://starwars.fandom.com/wiki/Sanhedrim_ship)

The Sanhedrim Ship was the mode of transportation used by the warrior class of the Aing-Tii monks.

## Specifications

- **Name:** Sanhedrim ship
- **Manufacturer:** Aing-Tii
- **Length:** ~300 meters
- **Hdsystem:** None, equipped with instant transportation system
- **Armament:**
  - Energy web generators (30)
  - Null-burst projectors (6)
- **Crew:**
  - Crewmembers (150)
  -   Gunners (66)
- **Role:** Transport
- **Affiliation:** Aing-Tii
