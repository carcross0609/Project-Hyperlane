# Carreras starfighter

**Continuity:** Legends  
**Source:** [Carreras starfighter](https://starwars.fandom.com/wiki/Carreras_starfighter)

A class of starfighter was used by the Shifalan government of the Carreras system in the year 138 ABY. Ania Solo ran afoul of them several times during the Carreras Incident.

## Specifications

- **Name:** Carreras starfighter
- **Type:** Starfighter
- **Armament:** Lasers
- **Affiliation:** Shifalan government
