# Varda-class starship

**Continuity:** Legends  
**Source:** [Varda-class starship](https://starwars.fandom.com/wiki/Varda-class_starship)

The Varda-class starship was a small model of spacecraft. Considered antiquated and abandoned by the time of the Great Sith War, the Jedi Kith Kark flew one before he joined the Jedi Order.
