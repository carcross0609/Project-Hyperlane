# NK-Witell-class freighter

**Continuity:** Canon  
**Source:** [NK-Witell-class freighter](https://starwars.fandom.com/wiki/NK-Witell-class_freighter)

The NK-Witell-class freighter was a freighter class built by Sanhar-Witell which entered common service roughly 13 years after the Battle of Endor. Seventeen years later, an estimated 137,417 NK-Witell-class freighters were still in use throughout the galaxy's trade lanes. One such freighter, the Yissira Zyde, was hijacked by the First Order in the Mirrin sector.

## Specifications

- **Name:** NK-Witell-class freighter
- **Manufacturer:** Sanhar-Witell
- **Type:** Freighter
- **Engine:** Hoersch-Kessel model alpha
- **Hyperdrive:** Class 3
- **Hdsystem:** Sanhar model 67 hyperdrive
