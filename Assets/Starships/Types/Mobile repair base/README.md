# Mobile repair base

**Continuity:** Legends  
**Source:** [Mobile repair base](https://starwars.fandom.com/wiki/Mobile_repair_base)

During the height of the Galactic Empire, some Super Star Destroyers served as dedicated mobile repair bases rather than as sector command ships.

## Specifications

- **Name:** Mobile repair base
- **Line:** Super Star Destroyers
- **Type:** Mobile repair base
- **Length:** Somewhere between 3,800 meters and 19,000 meters.
- **Role:** Repair vessel
- **Affiliation:** Galactic Empire
