# C-73 Tracker starfighter

**Continuity:** Legends  
**Source:** [C-73 Tracker starfighter](https://starwars.fandom.com/wiki/C-73_Tracker_starfighter)

The C-73 Tracker starfighter was a starfighter produced by Sublight Products Corporation that predated the Z-95 Headhunter.

## Specifications

- **Name:** C-73 Tracker starfighter
- **Manufacturer:** Sublight Products Corporation
- **Type:** Starfighter
- **Cost:** 20,000 credits (used)
- **Length:** 11.5 meters
- **Max Speed:** 950 kmh
- **Armament:** Laser cannons (2)
- **Capacity:** 60 kilograms
- **Consumables:** 1 day
- **Role:** Starfighter
- **Affiliation:**
  - Confederacy of Independent Systems
  - Virgillian Free Alignment
  - m'Yalfor'ac Order
