# Robotic cargo ship

**Continuity:** Legends  
**Source:** [Robotic cargo ship](https://starwars.fandom.com/wiki/Robotic_cargo_ship)

Robotic cargo ships were automated starships used to bring cargo into planets such as Coruscant. Small ships could attach themselves to these vessels to slip past Imperial patrols.
