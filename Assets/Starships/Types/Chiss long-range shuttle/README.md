# Chiss long-range shuttle

**Continuity:** Legends  
**Source:** [Chiss long-range shuttle](https://starwars.fandom.com/wiki/Chiss_long-range_shuttle)

Chiss long-range shuttles were transport vehicles, each equipped with a hyperdrive, used by the Chiss Expansionary Defense Force around 27 BBY. These shuttles were considered to be small, but could easily carry a pilot, two droidekas and four battle droids.
