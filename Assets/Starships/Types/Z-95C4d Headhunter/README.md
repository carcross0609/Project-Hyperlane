# Z-95C4d Headhunter

**Continuity:** Legends  
**Source:** [Z-95C4d Headhunter](https://starwars.fandom.com/wiki/Z-95C4d_Headhunter)

The Z-95C4d Headhunter was a common Z-95 Headhunter variant built as a bomber for ground support. It was outfitted with additional bomb-racks and ordnance hard-points.

## Specifications

- **Name:** Z-95C4d Headhunter
- **Manufacturer:** Incom Corporation/Subpro Corporation
- **Line:** Z-95 Headhunter
- **Type:** Starfighter
- **Armament:**
  - Bomb-racks
  - Ordnance hard-points
- **Role:** Ground support bomber
