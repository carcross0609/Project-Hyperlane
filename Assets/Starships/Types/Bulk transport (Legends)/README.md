# Bulk transport

**Continuity:** Legends  
**Source:** [Bulk transport/Legends](https://starwars.fandom.com/wiki/Bulk_transport/Legends)

Bulk transports were large starships designed to carry far greater quantities of cargo than light freighters. Notable bulk freighters included the Action series transports. Bulk transports saw heavy use with the Alliance Fleet during the Galactic Civil War as supply ships and troop ships.
