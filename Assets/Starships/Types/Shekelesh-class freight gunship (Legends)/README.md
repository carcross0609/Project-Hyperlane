# Shekelesh-class freight gunship

**Continuity:** Legends  
**Source:** [Shekelesh-class freight gunship/Legends](https://starwars.fandom.com/wiki/Shekelesh-class_freight_gunship/Legends)

The Shekelesh-class freight gunship was a model of freighter gunship manufactured by the Techno Union and frequently used by Moogans, earning it the names Moogan cargo ship and Moogan smuggler ship.

## Specifications

- **Name:** Shekelesh-class freight gunship
- **Manufacturer:** Techno Union
- **Model:** Shekelesh-class freight gunship
- **Type:** Freighter
- **Height:** 21.15 meters
- **Hdsystem:** Equipped
- **Armament:** Laser cannons (4)
- **Crew:** 8
- **Affiliation:**

  - Moogan smugglers
