# SS-54 assault ship

**Continuity:** Legends  
**Source:** [SS-54 assault ship/Legends](https://starwars.fandom.com/wiki/SS-54_assault_ship/Legends)

The SS-54 assault ship was a gunship model developed by Botajef Shipyards during the Clone Wars. Originally designed for Planetary Security Forces, it was misclassified as a light freighter&mdash;earning the name SS-54 light freighter&mdash;due to a clerical error. Subsequently, many assault ships were sold without clearance from Galactic Republic authorities.

## Specifications

- **Name:** SS-54 assault ship
- **Manufacturer:** Botajef Shipyards
- **Model:** SS-54 assault ship
- **Type:** Gunship
- **Length:** 24.19 meters
- **Armament:**
  - 4 laser cannons (front)
  - 1 double laser turret (rear arc)
- **Crew:** 3
