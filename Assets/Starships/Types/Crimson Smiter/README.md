# Crimson Smiter

**Continuity:** Canon  
**Source:** [Crimson Smiter](https://starwars.fandom.com/wiki/Crimson_Smiter)

The Crimson Smiter was an MG-100 StarFortress SF-17 in the Resistance's Crimson Squadron. When a First Order TIE fighter crashed into its bomb bay, it set off a chain reaction which resulted in the Cobalt Hammer being the final bomber left.
