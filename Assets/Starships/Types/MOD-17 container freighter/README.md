# MOD-17 container freighter

**Continuity:** Legends  
**Source:** [MOD-17 container freighter](https://starwars.fandom.com/wiki/MOD-17_container_freighter)

The MOD-17 was a container freighter produced by Loronar Corporation. It measured five hundred and fifty meters in length.

## Specifications

- **Name:** MOD-17 container freighter
- **Manufacturer:** Loronar Corporation
- **Type:** freighter
- **Length:** 550 meters
- **Hyperdrive:** Equipped
- **Crew:** 50
- **Passengers:** 30
- **Capacity:** 200,000 metric tons
