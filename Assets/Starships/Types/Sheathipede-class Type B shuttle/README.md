# Sheathipede-class Type B shuttle

**Continuity:** Canon  
**Source:** [Sheathipede-class Type B shuttle](https://starwars.fandom.com/wiki/Sheathipede-class_Type_B_shuttle)

The Sheathipede-class Type B shuttle, also known simply as the Class Type B shuttle, was a model of cargo shuttle manufactured by Haor Chall Engineering Corporation and used by the Confederacy of Independent Systems during the Clone Wars. At least one was captured by the Galactic Republic.

## Specifications

- **Name:** Sheathipede-class Type B shuttle
- **Manufacturer:** Haor Chall Engineering Corporation
- **Model:** Sheathipede-class Type B shuttle
- **Type:** Shuttle

- **Hyperdrive:** Class 2

- **Role:** Cargo shuttle
- **Affiliation:**
