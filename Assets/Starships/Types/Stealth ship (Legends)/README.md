# Stealth ship

**Continuity:** Legends  
**Source:** [Stealth ship/Legends](https://starwars.fandom.com/wiki/Stealth_ship/Legends)

Stealth ships were a type of starship outfitted with cloaking devices or other stealth technology. During the Clone Wars, the Galactic Republic fielded one such ship during the Battle of Christophsis.
