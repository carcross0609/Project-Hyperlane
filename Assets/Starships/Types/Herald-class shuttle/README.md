# Herald-class shuttle

**Continuity:** Legends  
**Source:** [Herald-class shuttle](https://starwars.fandom.com/wiki/Herald-class_shuttle)

The Herald-class shuttle was a light freighter created by the Star Forge for use in the Jedi Civil War.

- **Model:** Herald-class shuttle

- **Role:** Freighter
