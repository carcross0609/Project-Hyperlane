# Starcutter

**Continuity:** Canon  
**Source:** [Starcutter](https://starwars.fandom.com/wiki/Starcutter)

A starcutter, or cutter, was a type of civilian starship used during the reign of the Galactic Empire. In 3 BBY, Kier Domadi piloted a starcutter to the Paucris system in an attempt to gather information about a group of insurgents so that he could report them to the Empire.
