# Forward ReCon fighter

**Continuity:** Canon  
**Source:** [Forward ReCon fighter](https://starwars.fandom.com/wiki/Forward_ReCon_fighter)

The Forward ReCon fighter, also known as FRC, was a model of starfighter. The FRC-40 was an older and smaller version of the FRC that was being used in 382 BBY.
