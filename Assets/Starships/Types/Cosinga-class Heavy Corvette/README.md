# Cosinga-class Heavy Corvette

**Continuity:** Canon  
**Source:** [Cosinga-class Heavy Corvette](https://starwars.fandom.com/wiki/Cosinga-class_Heavy_Corvette)

The Cosinga-class Heavy Corvette was a class of corvette that was used as a Luxury Star Yacht for Galactic Emperor Palpatine. The Imperialis and its replica at the Jakku Observatory were ships of this class.
