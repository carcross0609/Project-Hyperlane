# Twin-pod paracapsule

**Continuity:** Legends  
**Source:** [Twin-pod paracapsule](https://starwars.fandom.com/wiki/Twin-pod_paracapsule)

Twin-pod paracapsules were orbit-to-surface entry vehicles used by the Galactic Empire. The Strike-class medium cruiser Ion Storm deployed seatroopers and single-person waveskimmers via twin-pod paracapsules during an orbital insertion on the planet Sedri.
