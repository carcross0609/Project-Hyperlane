# Luxury Cruiser 200

**Continuity:** Legends  
**Source:** [Luxury Cruiser 200](https://starwars.fandom.com/wiki/Luxury_Cruiser_200)

The Luxury Cruiser 200 was a yacht manufactured by SoroSuub Corporation. This model was popular among the young rich of the Mid Rim. Small enough to be intimate and cozy, the 200 was built for amusement, not combat.

## Specifications

- **Name:** Luxury Cruiser 200
- **Manufacturer:** SoroSuub Corporation

- **Type:** Yacht
