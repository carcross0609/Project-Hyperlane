# FRC-40

**Continuity:** Canon  
**Source:** [FRC-40](https://starwars.fandom.com/wiki/FRC-40)

The FRC-40 was a model of Forward ReCon fighter. The FRC-40 was an older and smaller version of the current FRC that was being produced in 382 BBY.

## Specifications

- **Name:** FRC-40
- **Line:** Forward ReCon fighter
- **Model:** FRC-40
- **Type:** Starfighter
