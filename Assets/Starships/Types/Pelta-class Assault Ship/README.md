# Pelta-class Assault Ship

**Continuity:** Canon  
**Source:** [Pelta-class Assault Ship](https://starwars.fandom.com/wiki/Pelta-class_Assault_Ship)

The Pelta-class Assault Ship was a variant of the Pelta-class frigate. The Alliance to Restore the Republic used modified Pelta-class Assault Ships during the Galactic Civil War. At one point, a Pelta-class Assault Ship engaged and destroyed an Imperial Navy Raider-class corvette over a terrestrial body, while T-65B X-wing starfighters and TIE/ln space superiority starfighters engaged with each other near them. It was equipped with turbolasers.

## Specifications

- **Name:** Pelta-class Assault Ship
- **Model:** Pelta-class frigate
- **Type:** Assault ship
- **Armament:** Turbolasers
- **Affiliation:**
  - Alliance to Restore the Republic
  -   Rebel Alliance Navy
