# Delta-6 system defense starfighter

**Continuity:** Canon  
**Source:** [Delta-6 system defense starfighter](https://starwars.fandom.com/wiki/Delta-6_system_defense_starfighter)

The Delta-6 system defense starfighter, also known more simply as the Delta-6 starfighter was a model of venerable starfighter with aerospace superiority capabilities. It had a long, narrow, arrowhead-shaped fuselage with two light laser cannons mounted forward and a small, cramped, bubble-canopied cockpit mounted far aft over the engine.

## Specifications

- **Name:** Delta-6 system defense starfighter
- **Line:** Delta-series
- **Type:** Starfighter
- **Hdsystem:** None
- **Navigation:** None
- **Armament:** 2 laser cannons
- **Lifesupport:** Equipped
- **Othersystems:** Combat avionics suite
