# Gamma-class assault shuttle

**Continuity:** Legends  
**Source:** [Gamma-class assault shuttle/Legends](https://starwars.fandom.com/wiki/Gamma-class_assault_shuttle/Legends)

The Gamma-class assault shuttle was an Imperial shuttle used to ferry spacetroopers into battle.
