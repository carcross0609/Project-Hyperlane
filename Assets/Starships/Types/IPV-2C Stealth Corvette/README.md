# IPV-2C Stealth Corvette

**Continuity:** Canon  
**Source:** [IPV-2C Stealth Corvette](https://starwars.fandom.com/wiki/IPV-2C_Stealth_Corvette)

The IPV-2C Stealth Corvette was an experimental starship developed by the Galactic Republic and manufactured by Sienar Design Systems during the Clone Wars. Equipped with a cloaking device that rendered it invisible, the prototype stealth ship was used during the Battle of Christophsis by Jedi General Anakin Skywalker. An advanced ship of the same class, the Carrion Spike, was later developed as the personal ship of Grand Moff Wilhuff Tarkin.
