# TIE/ca Punisher

**Continuity:** Legends  
**Source:** [TIE/ca Punisher/Legends](https://starwars.fandom.com/wiki/TIE/ca_Punisher/Legends)

The TIE/ca Punisher, also known as the TIE Punisher, TIE Interdictor, TIE/it Interdictor starfighter, or Advanced TIE Bomber, was a heavy bomber in service to the Galactic Empire.

- **Line:** TIE Series
- **Model:** Twin Ion Engine/IT Interdictor
- **Type:** Starfighter

- **Hyperdrive:** None

- **Armament:**

- **Crew:** Pilot (1)
- **Passengers:** None
- **Consumables:** 2 days
- **Role:** Heavy space/planetary bomber
- **Affiliation:** Galactic Empire
