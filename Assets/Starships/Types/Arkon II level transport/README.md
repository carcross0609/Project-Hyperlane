# Arkon II level transport

**Continuity:** Canon  
**Source:** [Arkon II level transport](https://starwars.fandom.com/wiki/Arkon_II_level_transport)

The Arkon II level transport was a class of transport starship used during the Republic Era. The salvage yard of Renzoh Silliac on Hallitron-7 utilized Arkon II level transports as garbage scows.

## Specifications

- **Name:** Arkon II level transport
- **Type:** Transport
- **Engine:** Equipped
- **Hyperdrive:** Equipped
- **Affiliation:** Renzoh Silliac's salvage yard
