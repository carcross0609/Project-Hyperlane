# Beta-class assault shuttle

**Continuity:** Legends  
**Source:** [Beta-class assault shuttle](https://starwars.fandom.com/wiki/Beta-class_assault_shuttle)

The Beta-class assault shuttle was an Imperial shuttle and a direct predecessor to the Gamma-class assault shuttle.

## Specifications

- **Name:** Beta-class assault shuttle
- **Manufacturer:** Telgorn Corporation
- **Model:** Beta-class assault shuttle
- **Type:** Assault shuttle
- **Length:** 30 meters
- **Max Speed:** 1,050 km/h
- **Hyperdrive:** Class 3.0
- **Hdsystem:** Equipped
- **Shield Gen:** Equipped
- **Hull:** Modular
- **Navigation:** Equipped, three jump limit
- **Avionics:** Telgorn twin-tandem flight computers
- **Armament:**
  - Laser cannons (4)
  - Concussion missile launcher (1)
  - Tractor beam/Legends projector (1)
- **Crew:** 5
- **Skeleton:** 3
- **Passengers:**
  - Depending on cargo module:
  - 40 spacetroopers
  - 68 standard troops
  - None (cargo or weapons)
- **Capacity:** 500 kg
- **Consumables:** 5 days
- **Role:**
  - Transport
  - Boarding craft
  - Gunship
  - Convoy escort
- **Affiliation:** Galactic Empire
