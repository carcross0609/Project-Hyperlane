# R93 refractor

**Continuity:** Canon  
**Source:** [R93 refractor](https://starwars.fandom.com/wiki/R93_refractor)

The R93 Refractor was a type of starfighter that served as the main vessel model used by the Rokana Raiders by 3 ABY.

## Specifications

- **Name:** R93 refractor
- **Type:** Starfighter
- **Engine:** T-57B Light Engine
- **Hdsystem:** Equipped
- **Shield Gen:**
  - FE-3 energy shield
  - Ion shield
- **Hull:** Rokana hull
- **Armament:**
  - modified L-13 cannons (2)
  - modified M-19 cannons (2)
  - Ion torpedoes
- **Complement:** RK-250 repair system
- **Affiliation:** Rokana Raiders
