# Sabaoth Frigate

**Continuity:** Legends  
**Source:** [Sabaoth Frigate](https://starwars.fandom.com/wiki/Sabaoth_Frigate)

The Sabaoth Frigate was a capital ship in the mercenary fleet commanded by Captain Cavik Toth prior to the Clone Wars. Sabaoth Frigates operated alongside the larger Sabaoth Destroyers.

## Specifications

- **Name:** Sabaoth Frigate
- **Model:** Sabaoth Frigate
- **Type:** Frigate
- **Length:** 275 Meters
- **Armament:**
  - Heavy laser cannon turrets (4)
  - Tractor beam projectors
- **Affiliation:**
  - Sabaoth Squadron
  - Confederacy of Independent Systems
