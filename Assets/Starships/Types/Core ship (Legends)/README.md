# Core ship

**Continuity:** Legends  
**Source:** [Core ship/Legends](https://starwars.fandom.com/wiki/Core_ship/Legends)

Core ships, also called Lucrehulk-class modular control core or LH-1740, were modified Lucrehulk-class modular control cores that were used as an autonomous transport by the Trade Federation and later the Confederacy of Independent Systems during the Clone Wars, as well as the Separatist holdouts during the Imperial Era.

## Specifications

- **Name:** Core ship
- **Manufacturer:**
  - Hoersch-Kessel Drive, Inc. (basic core ship)
  - Baktoid Combat Automata (Separatist Droid Army control core)
- **Model:** Modified Lucrehulk-class modular control core
- **Cost:** Not for sale (Black market value 25,000,000 credits)
- **Width:** 696 meters
- **Height:** 914 meters (when landed, minus transmission mass)
- **Max Accel:** 300 G
- **Hyperdrive:** None
- **Poweroutput:**
  - Peak (reactor): 3 × 1024 W
  - Peak (shields): 6 × 1023 W
- **Shield Gen:** Equipped
- **Navigation:** Navicomputer
- **Armament:**
  - Pre-Clone Wars refitting:
  - Point-defense light laser cannons (280)
  - Clone Wars refitting:
  - Point-defense quad laser batteries (21)
  - Assault laser cannons (48)
  - Turbolasers (3)
- **Crew:**
  - 60 Trade Federation supervisors
  - 3,000 droid crew
  - 200,000 maintenance droids
- **Passengers:** 60,000 (stateroom capacity for delegates)
- **Capacity:** c. 66,000,000 m³
- **Consumables:** Supplies for 3 years
- **Role:**
  - Freighter
  - Command ship
  - Destroyer (modified version)
- **Firstuse:** During or prior to 122 BBY (design)
- **Affiliation:**
  - Trade Federation
  - Confederacy of Independent Systems
  - Corporate Sector Authority
  - Separatist holdouts
  - Baktoid Armor Workshop
