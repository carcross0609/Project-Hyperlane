# Unidentified consumer model corvette

**Continuity:** Legends  
**Source:** [Unidentified consumer model corvette](https://starwars.fandom.com/wiki/Unidentified_consumer_model_corvette)

A model of corvette was available for civilians to purchase during the Great Galactic War. Rendili Vehicle Corporation based the Defender-class light corvette on the consumer model while designing the Jedi vessel.
