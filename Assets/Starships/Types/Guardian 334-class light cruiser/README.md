# Guardian 334-class light cruiser

**Continuity:** Legends  
**Source:** [Guardian 334-class light cruiser](https://starwars.fandom.com/wiki/Guardian_334-class_light_cruiser)

The Guardian 344-class light cruiser was made by Sienar Fleet Systems to succeed the Guardian-class. It addressed the previous cruiser's lack of space for a boarding party. It is known that some 344s fell into pirate hands, an example would be The Last Thing owned by Dorok Zalaster.

## Specifications

- **Name:** Guardian 334-class light cruiser
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Guardian 344-class light cruiser
- **Type:** Light cruiser
- **Crew:** 5
- **Passengers:** 16 (10 troopers and 6 prisoners)
- **Affiliation:**
  - Pirates
  - Galactic Empire
