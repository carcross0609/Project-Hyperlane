# BB-wing

**Continuity:** Unknown  
**Source:** [BB-wing](https://starwars.fandom.com/wiki/BB-wing)

The BB-wing was a model of droid starfighter created by Sig Greebling. Three BB-wings were BB-2, BB-5, and BB-8.

- **Type:** Droid starfighter

- **Armament:** Three laser cannons
