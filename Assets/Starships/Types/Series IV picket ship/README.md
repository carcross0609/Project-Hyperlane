# Series IV picket ship

**Continuity:** Legends  
**Source:** [Series IV picket ship](https://starwars.fandom.com/wiki/Series_IV_picket_ship)

The Series IV picket ship was a type of small warship which was developed and manufactured by Cindev. The Buzzzer, a known pirate vessel operating in the Corellian system, was one such ship of this class.
