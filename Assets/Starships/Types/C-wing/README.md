# C-wing

**Continuity:** Legends  
**Source:** [C-wing](https://starwars.fandom.com/wiki/C-wing)

The C-wing was a starfighter designed to be piloted by a single person with an optional gunner and room for two passengers.

## Specifications

- **Name:** C-wing
- **Model:** C-wing
- **Hyperdrive:** Class 1.5
- **Armament:**
  - Fire-linked heavy blaster cannons (4)
  - Proton torpedo launcher (1)
- **Crew:**
  - 1 Pilot
  - 1 Gunner
- **Skeleton:** 1 Person
- **Passengers:** 1 Person
- **Capacity:** 220 kg
- **Consumables:** 2 weeks
- **Role:** Starfighter
