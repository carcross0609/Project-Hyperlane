# B-class X-wing

**Continuity:** Canon  
**Source:** [B-class X-wing](https://starwars.fandom.com/wiki/B-class_X-wing)

A B-class X-wing was a model of X-wing starfighter that existed in the galaxy during the New Republic Era. The fourteen-year-old Force-sensitive Karr Nuq Sin owned a replica of the B-class X-wing.
