# Rainhawk-class transport

**Continuity:** Legends  
**Source:** [Rainhawk-class transport/Legends](https://starwars.fandom.com/wiki/Rainhawk-class_transport/Legends)

The Rainhawk-class transport, also known as the Pantoran cruiser, was a shuttle model used during the Clone Wars. Baron Notluwiski Papanoida owned one such vessel, dubbed the Falfa.

## Specifications

- **Name:** Rainhawk-class transport
- **Manufacturer:** Kuat Systems Engineering
- **Model:** Rainhawk-class transport
- **Type:** Transport
- **Length:** 20.46 meters
- **Armament:** Laser cannons
- **Crew:** 2
- **Role:** Shuttle
- **Firstuse:** c. 21 BBY
- **Affiliation:** Pantoran Assembly
