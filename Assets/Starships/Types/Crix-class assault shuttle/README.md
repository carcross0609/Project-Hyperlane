# Crix-class assault shuttle

**Continuity:** Legends  
**Source:** [Crix-class assault shuttle](https://starwars.fandom.com/wiki/Crix-class_assault_shuttle)

The Crix-class assault shuttle, also designated A-2s, was an assault vessel used by the Galactic Alliance and later by the Galactic Alliance Core Fleet.

## Specifications

- **Name:** Crix-class assault shuttle
- **Manufacturer:**
  - Corellian Engineering Corporation
  - Mon Calamari Shipyards
- **Model:** Crix-class
- **Type:** Assault shuttle
- **Cost:** 600,000 credits (260,000 used)
- **Max Speed:** 850 km/h
- **Hyperdrive:** Class 1 (backup class 10)
- **Shield Gen:** Equipped
- **Sensor:** Long-range communication sensors
- **Navigation:** Navicomputer
- **Armament:**
  - Twin laser cannons
  - Blaster cannon battery (2)
- **Crew:** 5
- **Passengers:** 50
- **Capacity:** 50 tons
- **Consumables:** 1 month
- **Availability:** Military
- **Role:** Assault shuttle
- **Affiliation:**
  - Galactic Federation of Free Alliances
  - Galactic Alliance Remnant
