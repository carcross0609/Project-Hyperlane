# Scarab-class starfighter

**Continuity:** Canon  
**Source:** [Scarab-class starfighter](https://starwars.fandom.com/wiki/Scarab-class_starfighter)

The Scarab-class starfighter was a model of starfighter used by the naval forces of the Confederacy of Independent Systems around the time of the Clone Wars against the Galactic Republic. Near the time of the war, Scarab-class starfighters, alongside Vulture-class droid starfighters, were transported aboard the Lucrehulk-class battleships of the Trade Federation, whose cargo holds were utilized as hangars and staging areas for Separatist forces following the corporation's alignment with the confederate government.
