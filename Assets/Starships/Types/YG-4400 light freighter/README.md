# YG-4400 light freighter

**Continuity:** Legends  
**Source:** [YG-4400 light freighter](https://starwars.fandom.com/wiki/YG-4400_light_freighter)

The YG-4400 light freighter was a transport ship created by the Corellian Engineering Corporation around 44 BBY. The main distinguishing feature of the YG-4400 was their armament, which included a getaway concussion missile launcher.
