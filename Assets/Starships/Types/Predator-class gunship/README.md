# Predator-class gunship

**Continuity:** Legends  
**Source:** [Predator-class gunship](https://starwars.fandom.com/wiki/Predator-class_gunship)

The Predator-class gunship was an armored space vessel. It was larger than a Lantillian cruiser. The Kintan Gunrunners operated one.

- **Type:** Gunship
