# S-46I Medium Scout Ship

**Continuity:** Canon  
**Source:** [S-46I Medium Scout Ship](https://starwars.fandom.com/wiki/S-46I_Medium_Scout_Ship)

The S-46I Medium Scout Ship was a class of espionage scout ship used by the Imperial Security Bureau of the Galactic Empire. One such ship was the Darkflare, captained by ISB Commander Trey Trellen. The Darkflare was involved in Operation Night Fire, an operation by the Rebel Alliance Intelligence Service to steal the Darkflare.
