# Warden-class light cruiser

**Continuity:** Legends  
**Source:** [Warden-class light cruiser](https://starwars.fandom.com/wiki/Warden-class_light_cruiser)

A small starship with a wide mission profile, the Warden-class light cruiser was produced by Sienar Fleet Systems as a follow-up to the Guardian-class light cruiser.

## Specifications

- **Name:** Warden-class light cruiser
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Warden-class light cruiser
- **Type:** Light cruiser
- **Length:** 42 meters
- **Max Speed:** 1,200 kmh
- **Hyperdrive:**
  - x1 (Primary)
  - x10 (Backup)
- **Sensor:** Improved over the Guardian-class
- **Armament:** Turreted laser cannons (2)
- **Crew:** 16
- **Passengers:** 14
- **Capacity:** 100 tons
- **Consumables:** 2 months
- **Role:**
  - Picket
  - Patrol
  - Customs corvette
- **Affiliation:** Galactic Empire
