# Iskallon Light Frigate

**Continuity:** Legends  
**Source:** [Iskallon Light Frigate](https://starwars.fandom.com/wiki/Iskallon_Light_Frigate)

The Iskallon Light Frigate was a class of frigate employed by the Iskalloni species. The Stelaciter was of this class.

## Specifications

- **Name:** Iskallon Light Frigate
- **Type:** Frigate
- **Length:** 83 meters
- **Hyperdrive:** Class 2
- **Shield Gen:** Equipped
- **Navigation:** Equipped
- **Armament:**
  - 2 double laser cannons
  - 1 heavy laser cannon
- **Crew:** 39
- **Passengers:** 15
- **Capacity:** 400 metric tons
- **Consumables:** 4 months
- **Affiliation:** Iskalloni
