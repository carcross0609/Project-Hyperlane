# Model Eleven Corellian transport shuttle

**Continuity:** Canon  
**Source:** [Model Eleven Corellian transport shuttle](https://starwars.fandom.com/wiki/Model_Eleven_Corellian_transport_shuttle)

The Model Eleven Corellian transport shuttle was a type of shuttle dating back to the Old Republic. When searching for a pilot, the smugglers Lando Calrissian and Han Solo traveled aboard one of these shuttles to get from Hanna City to Frander's Bay.

## Specifications

- **Name:** Model Eleven Corellian transport shuttle
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Shuttle
