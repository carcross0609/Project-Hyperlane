# Luxury yacht

**Continuity:** Legends  
**Source:** [Luxury yacht/Legends](https://starwars.fandom.com/wiki/Luxury_yacht/Legends)

Luxury yachts were starships that catered to the galaxy's rich and prestigious citizens. The Chancellor Fillorean was one such yacht, which carried thirty passengers, and housed full luxury accommodations for each guest. The Lady Luck was another well known luxury yacht, owned by Lando Calrissian. The Baudo-class was another model of luxury yacht.
