# N-1T Advanced Starfighter

**Continuity:** Legends  
**Source:** [N-1T Advanced Starfighter](https://starwars.fandom.com/wiki/N-1T_Advanced_Starfighter)

The Naboo N-1T Advanced Starfighter was the successor of the N-1 starfighter.

## Specifications

- **Name:** N-1T Advanced Starfighter
- **Model:** N-1T Advanced Starfighter
- **Type:** Starfighter
- **Engine:** 2 engines
- **Armament:** Laser cannons, more powerful than the N-1 starfighter
- **Crew:**
  - 1 pilot
  - 1 astromech droid
- **Role:** Starfighter
- **Affiliation:** Naboo Royal Space Fighter Corps
