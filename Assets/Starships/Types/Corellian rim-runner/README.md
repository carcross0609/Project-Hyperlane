# Corellian rim-runner

**Continuity:** Legends  
**Source:** [Corellian rim-runner](https://starwars.fandom.com/wiki/Corellian_rim-runner)

The Corellian rim-runner was a type of starship. Together with Katya M'Buele, Han Solo crewed a Corellian rim-runner smuggling ship after leaving Imperial Military service in the year 5 BBY.
