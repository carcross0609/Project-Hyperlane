# Class-6 escape pod

**Continuity:** Legends  
**Source:** [Class-6 escape pod/Legends](https://starwars.fandom.com/wiki/Class-6_escape_pod/Legends)

The Class-6 escape pod was a standard emergency craft created by Corellian Engineering Corporation and used on many of their designs, such as the CR90 corvette.

## Specifications

- **Name:** Class-6 escape pod
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Escape pod
- **Engine:**
  - Escape thrusters (4)
  - Several maneuvering thrusters
- **Passengers:** 6
