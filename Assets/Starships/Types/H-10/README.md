# H-10

**Continuity:** Legends  
**Source:** [H-10](https://starwars.fandom.com/wiki/H-10)

The H-10 was a type of small shuttle manufactured by Sienar Fleet Systems, designed primarily for short intra-system trips, and sometimes referred to as a brig.

- **Type:** Troop transport
