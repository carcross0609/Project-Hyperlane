# ExplorCorps scout ship

**Continuity:** Legends  
**Source:** [ExplorCorps scout ship](https://starwars.fandom.com/wiki/ExplorCorps_scout_ship)

An ExplorCorps scout ship was a large model of starship that was used by the Jedi Exploration Corps in the years following the New Sith Wars. They were used to meet with species wishing to join the Galactic Republic.
