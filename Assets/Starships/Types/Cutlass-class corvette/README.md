# Cutlass-class corvette

**Continuity:** Legends  
**Source:** [Cutlass-class corvette](https://starwars.fandom.com/wiki/Cutlass-class_corvette)

The Cutlass-class corvette was a corvette type used by the time of the Second Galactic Civil War. The Imperial Remnant used it as a capital ship during the years following the Swarm War. In 40 ABY, at least one ship of this class appeared among the Bonadan forces supporting the Corellians during the Blockade of Corellia.
