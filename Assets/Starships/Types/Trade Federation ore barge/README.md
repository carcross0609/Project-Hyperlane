# Trade Federation ore barge

**Continuity:** Legends  
**Source:** [Trade Federation ore barge](https://starwars.fandom.com/wiki/Trade_Federation_ore_barge)

The Trade Federation ore barge was a narrow ship that had been used by the Trade Federation for centuries prior to 33 BBY. Trade Federation Viceroy Nute Gunray believed it to be the basis for the C-9979 landing craft designed by Haor Chall Engineering, with the fuselage instead set on a pedestal and capped with two enormous wings.
