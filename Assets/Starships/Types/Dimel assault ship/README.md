# Dimel assault ship

**Continuity:** Legends  
**Source:** [Dimel assault ship](https://starwars.fandom.com/wiki/Dimel_assault_ship)

The Ulig Abaha Ltd. Dimel assault ship was a class of warship that was utilized by the Corporate Sector Authority. One of these vessels, the Eye of Shiblizar, was utilized by slavers Magg and Zlarb for their operations.

## Specifications

- **Name:** Dimel assault ship
- **Manufacturer:** Ulig Abaha Ltd.
- **Cost:** 450,000 credits
- **Length:** 95 meters
- **Max Speed:** 750 km/h
- **Hyperdrive:**
  - Class 2.0
  - Backup Class 16
- **Shield Gen:** Equipped
- **Armament:**
  - Double laser cannons (10)
  - ion cannon (1)
  - Tractor beam projector (1)
- **Skeleton:** 16
- **Cargohandling:** 600 tons
- **Role:** Warship
- **Affiliation:** Corporate Sector Authority
