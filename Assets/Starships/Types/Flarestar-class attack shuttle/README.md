# Flarestar-class attack shuttle

**Continuity:** Canon  
**Source:** [Flarestar-class attack shuttle](https://starwars.fandom.com/wiki/Flarestar-class_attack_shuttle)

The Flarestar-class attack shuttle, also known simply as the rapier ship, was a model of saucer-shaped shuttle used by the criminal Ohnaka Gang during the Clone Wars. They were often deployed from the Gang's larger Corona-class armed frigate.

## Specifications

- **Name:** Flarestar-class attack shuttle
- **Manufacturer:** Surronian Engineering
- **Model:** Flarestar-class
- **Type:** Shuttle
- **Length:** 22.6 meters
- **Max Speed:** 1,175 kph
- **Hyperdrive:** Class 2
- **Armament:**
  - Laser cannons (2)
  - Torpedo launchers (2)
- **Affiliation:**
  - Ohnaka Gang
  - Cad Bane's group (briefly; appropriated)
