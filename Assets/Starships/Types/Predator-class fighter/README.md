# Predator-class fighter

**Continuity:** Legends  
**Source:** [Predator-class fighter](https://starwars.fandom.com/wiki/Predator-class_fighter)

The Predator-class fighter, also called the TIE Predator and nicknamed Eyeballs by the Galactic Alliance, was a TIE Series starfighter produced by Sienar Fleet Systems and used by the Fel Empire as of 130 ABY.
