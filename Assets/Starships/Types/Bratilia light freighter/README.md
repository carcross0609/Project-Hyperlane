# Bratilia light freighter

**Continuity:** Legends  
**Source:** [Bratilia light freighter](https://starwars.fandom.com/wiki/Bratilia_light_freighter)

The Bratilia light freighter was manufactured by Ganrite Yards of Elrood, Inc. It was a knock-off version of the SoroSuub Corporation Starmite.
