# FT-5A Honor Guard

**Continuity:** Legends  
**Source:** [FT-5A Honor Guard](https://starwars.fandom.com/wiki/FT-5A_Honor_Guard)

The FT-5A Honor Guard was a model of starfighter in the FT-series produced by Rendili StarDrive for the Galactic Republic. The FT-5A later received a redesign that resulted in the FT-8 Star Guard model.
