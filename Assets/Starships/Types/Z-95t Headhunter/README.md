# Z-95t Headhunter

**Continuity:** Legends  
**Source:** [Z-95t Headhunter](https://starwars.fandom.com/wiki/Z-95t_Headhunter)

The Z-95t Headhunter was a variant of the Z-95 Headhunter designed by Adar Tallon. Unlike the standard headhunter, it was equipped with a class 3 hyperdrive and lacked concussion missile launchers.

## Specifications

- **Name:** Z-95t Headhunter
- **Line:** Z-95 Headhunter
- **Model:** Z-95t
- **Type:** Starfighter
- **Modifier:** Adar Tallon
- **Hyperdrive:** Class 3
- **Hdsystem:** Equipped
- **Armament:**
  - Linked triple blasters (2)
- **Affiliation:** Alliance to Restore the Republic
