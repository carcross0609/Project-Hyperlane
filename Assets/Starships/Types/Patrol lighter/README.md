# Patrol lighter

**Continuity:** Legends  
**Source:** [Patrol lighter](https://starwars.fandom.com/wiki/Patrol_lighter)

Patrol lighters were a type of starship used by the military forces of the planet Freda. Several patrol lighters destroyed a Jante mining camp in the Rettna system.
