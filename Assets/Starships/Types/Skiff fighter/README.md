# Skiff fighter

**Continuity:** Canon  
**Source:** [Skiff fighter](https://starwars.fandom.com/wiki/Skiff_fighter)

Skiff fighters, sometimes stylized as skiff-fighters, were a type of starfighter used by the mercenaries of Skarabda the Hutt. Terec flew one after their Jedi Vector was destroyed in battle.

## Specifications

- **Name:** Skiff fighter
- **Type:** Starfighter
- **Affiliation:** Hutt Clan
