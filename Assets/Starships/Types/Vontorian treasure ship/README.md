# Vontorian treasure ship

**Continuity:** Canon  
**Source:** [Vontorian treasure ship](https://starwars.fandom.com/wiki/Vontorian_treasure_ship)

A Vontorian treasure ship was a type of starship. It shared visual similarities with the Munificent-class star frigate. The Graceful Promising was a Vontorian treasure ship.
