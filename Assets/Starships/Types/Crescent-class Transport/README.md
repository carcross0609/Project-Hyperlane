# Crescent-class Transport

**Continuity:** Legends  
**Source:** [Crescent-class Transport](https://starwars.fandom.com/wiki/Crescent-class_Transport)

The Crescent-class Transport or Crescent-class freighter was a fast luxury courier manufactured by Hyrotii Corporation.

- **Cost:** 25,000 credits (used)
- **Length:** 30 meters
- **Max Speed:** 950 KMH
- **Hyperdrive:**

- **Armament:** 1 Light Laser cannon
- **Crew:** 1-2
- **Passengers:** (Varies) Up to 8
- **Capacity:** 80 metric tons
- **Consumables:** 2 months
