# Starhawk-class Battleship Mark II

**Continuity:** Canon  
**Source:** [Starhawk-class Battleship Mark II](https://starwars.fandom.com/wiki/Starhawk-class_Battleship_Mark_II)

The Starhawk-class Battleship Mark II was a class of battleship used by the naval arm of the burgeoning New Republic. The Mark II was part of the Starhawk-class line of ships, which included the initial prototype and the Mark I. The Starhawks were built from disassembled Imperial Star Destroyers and had a hatchet shaped frontal hull.
