# Cabur-class starfighter

**Continuity:** Legends  
**Source:** [Cabur-class starfighter](https://starwars.fandom.com/wiki/Cabur-class_starfighter)

The Cabur-class starfighter was a starfighter produced by MandalMotors, a renowned vehicle manufacturer based on the planet Mandalore. It was a wedge-shaped, twin-engine starship flown by a pair of pilots.
