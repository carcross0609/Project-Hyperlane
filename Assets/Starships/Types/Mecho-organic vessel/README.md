# Mecho-organic vessel

**Continuity:** Legends  
**Source:** [Mecho-organic vessel](https://starwars.fandom.com/wiki/Mecho-organic_vessel)

Mecho-organic vessels were part machine and part living spacecraft made by a race from another galaxy. The vessels existed in a state of symbiosis with their computer and pilot.
