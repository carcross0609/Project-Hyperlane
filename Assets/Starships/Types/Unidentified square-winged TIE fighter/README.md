# Unidentified square-winged TIE fighter

**Continuity:** Canon  
**Source:** [Unidentified square-winged TIE fighter](https://starwars.fandom.com/wiki/Unidentified_square-winged_TIE_fighter)

A TIE series variant was in service of the Zantarrk Gang on the planet Kaltrais. The starfighter had square solar panels rather than the traditional hexagonal wings found on TIEs.
