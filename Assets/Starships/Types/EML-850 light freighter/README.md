# EML-850 light freighter

**Continuity:** Canon  
**Source:** [EML-850 light freighter](https://starwars.fandom.com/wiki/EML-850_light_freighter)

The EML-850 light freighter was a type of light freighter. The high material cost of the freighter thwarted any chance of mass production. The Trailblazer was an EML-850 light freighter designed in the Republic Era.
