# YT-2600

**Continuity:** Canon  
**Source:** [YT-2600](https://starwars.fandom.com/wiki/YT-2600)

The YT-2600 was a freighter built by Corellian Engineering Corporation. It was considered more advanced than the YT-1300 light freighter but shared many of the same parts. A reactor from a YT-2600 was used at Echo Base to provide power for levels 4 through 8.

## Specifications

- **Name:** YT-2600
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Type:** Freighter
