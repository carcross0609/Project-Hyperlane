# YT-720

**Continuity:** Canon  
**Source:** [YT-720](https://starwars.fandom.com/wiki/YT-720)

The YT-720 was a model of starship used during during the Galactic Civil War. In 3 ABY,, the clearance for one YT-720 to depart Achra Station in the Akiva system was revoked. Afterwards at least one announcement indicating the status change and asking passengers to report to customs was broadcast over the station's speaker system in Huttese.
