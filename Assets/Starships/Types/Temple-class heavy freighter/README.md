# Temple-class heavy freighter

**Continuity:** Legends  
**Source:** [Temple-class heavy freighter](https://starwars.fandom.com/wiki/Temple-class_heavy_freighter)

The Temple-class heavy freighter was a type of freighter produced by the Kuat Drive Yards. Twelve Temple-class heavy freighters, along with their escort starships, made up the secret Imperial convoy known as the Perlemian Haul.
