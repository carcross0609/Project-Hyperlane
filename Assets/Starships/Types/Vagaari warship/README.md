# Vagaari warship

**Continuity:** Legends  
**Source:** [Vagaari warship](https://starwars.fandom.com/wiki/Vagaari_warship)

Vagaari warships were used by the race of nomadic warriors called the Vagaari around 27 BBY. The outer hull of these starships were covered with Geroon slaves encased within zero-g plastic bubbles which created a living shield. These warships unsuccessfully faced the Chiss Expansionary Defense Force in the Skirmish in the Crustai system and the battle of the Geroon homeworld, which simply flew in close enough to fire between the bubbles.
