# Z-95ER Headhunter

**Continuity:** Legends  
**Source:** [Z-95ER Headhunter](https://starwars.fandom.com/wiki/Z-95ER_Headhunter)

The Z-95ER Headhunter was a common Z-95 Headhunter variant built for extended missions. It was equipped with additional fuel tanks for extra range.

## Specifications

- **Name:** Z-95ER Headhunter
- **Manufacturer:** Incom Corporation/Subpro Corporation
- **Line:** Z-95 Headhunter
- **Type:** Starfighter
- **Othersystems:** Extra consumable fuel tanks
- **Role:** Long range missions
