# Alderaanian War Frigate

**Continuity:** Legends  
**Source:** [Alderaanian War Frigate](https://starwars.fandom.com/wiki/Alderaanian_War_Frigate)

The Alderaanian War Frigate was a warship that served the Royal Alderaan Civil Fleet during the Clone Wars. Later models of this type appeared in service of the Alderaanian Resistance, the Rebel Alliance, the Alliance of Free Planets, and the New Republic.
