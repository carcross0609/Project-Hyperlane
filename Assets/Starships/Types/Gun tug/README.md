# Gun tug

**Continuity:** Canon  
**Source:** [Gun tug](https://starwars.fandom.com/wiki/Gun_tug)

Gun tugs were a class of starship that saw use around the time of the Clone Wars between the Galactic Republic and Confederacy of Independent Systems. The Nebula Raiders, a constant source of problems for the Republic, utilized gun tugs alongside Z-95 Headhunters in their raids on the Republic's supply convoys.

## Specifications

- **Name:** Gun tug
- **Affiliation:** Nebula Raiders
