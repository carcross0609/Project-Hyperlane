# GAT-12p

**Continuity:** Legends  
**Source:** [GAT-12p](https://starwars.fandom.com/wiki/GAT-12p)

The GAT-12p "Skipray" was part of the GAT Blastboat series produced by Sienar Fleet Systems.

## Specifications

- **Name:** GAT-12p
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Defense and patrol blastboat
- **Length:** 25 meters
- **Hyperdrive:** Class 2
- **Shield Gen:** Equipped
- **Navigation:** Equipped (4 jump limit)
- **Armament:**
  - 3 medium ion cannons
  - 1 proton torpedo launcher
  - 2 laser cannons
  - 1 concussion missile launcher
- **Crew:** 2 and 2 gunners
- **Affiliation:** Galactic Empire
