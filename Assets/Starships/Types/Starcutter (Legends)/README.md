# Starcutter

**Continuity:** Legends  
**Source:** [Starcutter/Legends](https://starwars.fandom.com/wiki/Starcutter/Legends)

A starcutter, or cutter, was a type of small starship model. Starcutters used by the Galactic Empire were usually employed as customs vessels and carried a starfighter complement. Starcutters were also used as personal spacecraft used as of 41 ABY. The Beam Racer was a starcutter.
