# Droch-class boarding ship

**Continuity:** Canon  
**Source:** [Droch-class boarding ship](https://starwars.fandom.com/wiki/Droch-class_boarding_ship)

The Droch-class boarding ship, also referred to as the Droch dropship, the Separatist boarding ship, droid landing pod, or pod-hunter, was a model of boarding craft manufactured by Colicoid Creation Nest and used by the Confederacy of Independent Systems during the Clone Wars against the Galactic Republic.

- **Model:** Droch-class boarding ship

- **Max Speed:** 850 kph
