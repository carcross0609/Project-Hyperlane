# Thranta-class corvette

**Continuity:** Legends  
**Source:** [Thranta-class corvette](https://starwars.fandom.com/wiki/Thranta-class_corvette)

The Thranta-class corvette, also known as the CR-12 corvette, was a cruiser in service with the Republic Navy during the Great Galactic War.
