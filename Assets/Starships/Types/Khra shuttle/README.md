# Khra shuttle

**Continuity:** Legends  
**Source:** [Khra shuttle](https://starwars.fandom.com/wiki/Khra_shuttle)

The Khra shuttle was a type of shuttle used by Noghri bodyguards. A fast unit capable of carrying at least two Noghri, one was used by Sakhisakh and Barkhimkh in their mission to Pakrik Minor.
