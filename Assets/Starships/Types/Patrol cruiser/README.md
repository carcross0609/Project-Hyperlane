# Patrol cruiser

**Continuity:** Canon  
**Source:** [Patrol cruiser](https://starwars.fandom.com/wiki/Patrol_cruiser)

A patrol cruiser was a type of cruiser that was used for patrol duties. The Republic Defense Coalition used Pacifier-class sector patrol cruisers during the High Republic Era, with five such cruisers participating in the Battle of Kur. The Parala was a patrol cruiser belonging to the Chiss Ascendancy.
