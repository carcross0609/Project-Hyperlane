# Starfly

**Continuity:** Legends  
**Source:** [Starfly](https://starwars.fandom.com/wiki/Starfly)

The Starfly was a small, maneuverable single-person vessel. It was equipped with a tractor beam but carried no life support equipment, hence, Starfly pilots were forced to wear self-contained suits while flying the ships. Starflies were piloted by miners in the asteroid belts near Ithor.
