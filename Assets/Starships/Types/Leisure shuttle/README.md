# Leisure shuttle

**Continuity:** Canon  
**Source:** [Leisure shuttle](https://starwars.fandom.com/wiki/Leisure_shuttle)

A leisure shuttle was a shuttle used for tourism and vacationing. The pilot Norra Wexley used one to get off the planet of Akiva and join the Resistance on Ryloth.
