# Stalwart-class light freighter

**Continuity:** Legends  
**Source:** [Stalwart-class light freighter](https://starwars.fandom.com/wiki/Stalwart-class_light_freighter)

The Stalwart-class light freighter was a starship class in the era of the Galactic Civil War, more often seen in the core, and was competitive against the standard setting YT-1300.

- **Name:** Stalwart-class light freighter
- **Type:** Stock Light freighter
- **Cost:**

- **Length:** 19.7 meters
- **Max Speed:** 850 kmh (atmosphere)
- **Hyperdrive:**

  - Backup class 15
- **Shield Gen:** Equipped
- **Hull:** Armor plating
- **Sensor:** Equipped
- **Navigation:** Navigation computer equipped
- **Armament:**
  - Turreted Laser cannon (1)
- **Crew:** 2
- **Passengers:** 5
- **Capacity:** 120 metric tons
- **Consumables:** 3 months
