# JumpMaster 5000

**Continuity:** Legends  
**Source:** [JumpMaster 5000/Legends](https://starwars.fandom.com/wiki/JumpMaster_5000/Legends)

The JumpMaster 5000, also known as the JM-5000 Jumpmaster Long Range Scout, or colloquially as simply the JM-5K, was a scout ship designed by Corellian Engineering Corporation.

- **Manufacturer:** Corellian Engineering Corporation
- **Model:** JumpMaster 5000

- **Length:** 20 meters
- **Max Speed:** 1200 km/h
- **Hyperdrive:**

- **Sensor:** Military-grade long-range sensor suite
- **Navigation:** Equipped
- **Armament:** Twin Laser cannon (1)
- **Crew:** 1 (pilot)
- **Passengers:** 1
- **Capacity:** 50 metric tons
- **Consumables:** 4 months
- **Availability:** Restricted
- **Role:** Scout vessel
