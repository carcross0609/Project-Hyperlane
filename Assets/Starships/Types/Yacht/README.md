# Yacht

**Continuity:** Canon  
**Source:** [Yacht](https://starwars.fandom.com/wiki/Yacht)

design]] A Yacht, or Star Yacht, was a generalized term for any type of vessel whose primary purpose was that of recreation and leisure, as well for the personal vessels of certain individuals. The Luxury 3000 space yacht and the Petite Opu-Yacht were examples of this type of vessel, as was the Mellcrawler and the Stinger Mantis.
