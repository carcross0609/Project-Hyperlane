# Concealer-class Prison Ship

**Continuity:** Legends  
**Source:** [Concealer-class Prison Ship](https://starwars.fandom.com/wiki/Concealer-class_Prison_Ship)

The Concealer-class Prison Ship was a 50-meter transport built by Sienar Fleet Systems. It was used by the Galactic Empire to move prisoners from one location to another. Two vessels operated by the Empire were the Caged Animal and the Constrictor.

## Specifications

- **Name:** Concealer-class Prison Ship
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Transport
- **Length:** 50 meters
- **Armament:** Laser cannons (4)
- **Crew:**
  - Pilots (3)
  - Gunners (4)
  - Guards (10)
- **Capacity:** Up to 60 prisoners and 25 metric tons of cargo
- **Role:** Prison ship
- **Affiliation:** Galactic Empire
