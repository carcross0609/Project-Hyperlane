# Alpha-class heavy transport

**Continuity:** Legends  
**Source:** [Alpha-class heavy transport](https://starwars.fandom.com/wiki/Alpha-class_heavy_transport)

The Alpha-class heavy transport was a 400-meter-long starship, used for both cargo and passenger transport, that was manufactured before 4000 BBY by Corellia StarDrive.

## Specifications

- **Name:** Alpha-class heavy transport
- **Manufacturer:** Corellia StarDrive
- **Type:** Transport
- **Length:** 400 meters
- **Role:** Passenger freighter and cargo transport
- **Affiliation:** Galactic Republic
