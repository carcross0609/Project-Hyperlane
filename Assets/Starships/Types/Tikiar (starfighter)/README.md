# Tikiar

**Continuity:** Canon  
**Source:** [Tikiar (starfighter)](https://starwars.fandom.com/wiki/Tikiar_%28starfighter%29)

Tikiars were starfighters manufactured in the Senex sector, but it was not uncommon to see them in some sections of the Outer Rim. A number of these fighters, together with Z-95 Headhunters, attacked Sentinel Base fourteen years before the Battle of Yavin. The Tikiars and Headhunters present in this engagement were modified with basic hyperdrives and upgraded weaponry.

## Specifications

- **Name:** Tikiar
- **Type:** Starfighter
- **Affiliation:** Berch Teller's rebel cell
