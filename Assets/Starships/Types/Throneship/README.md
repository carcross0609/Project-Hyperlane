# Throneship

**Continuity:** Canon  
**Source:** [Throneship](https://starwars.fandom.com/wiki/Throneship)

A Throneship was the personal vessel of a member of the Anoat sector's Noble Court. Such ships had gilded hallways. Captain Regmus commanded the Throneship Honorbound until it was lost to the Galactic Empire.
