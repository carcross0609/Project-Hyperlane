# Delta-class carrier

**Continuity:** Legends  
**Source:** [Delta-class carrier](https://starwars.fandom.com/wiki/Delta-class_carrier)

A Delta-class carrier was a type of starfighter carrier that served in the Imperial Navy during the Great Galactic War. An example of this class was the carrier Extempus, which was commanded by Moff Nezzor during the Battle of Duro.

## Specifications

- **Name:** Delta-class carrier
- **Model:** Delta-class carrier
- **Type:** Carrier
- **Complement:**

- **Role:** Starfighter carrier
- **Affiliation:**
