# TIE/ag "Aggressor" Starfighter

**Continuity:** Legends  
**Source:** [TIE/ag "Aggressor" Starfighter/Legends](https://starwars.fandom.com/wiki/TIE/ag_%22Aggressor%22_Starfighter/Legends)

The TIE/ag "Aggressor" Starfighter, or simply the TIE Aggressor, was a multi-role superiority starfighter-strike fighter. Its specific role was a hybrid fighter/bomber.

- **Name:** TIE/ag "Aggressor" Starfighter
- **Manufacturer:** Santhe/Sienar Technologies
- **Line:** TIE Series
- **Model:** Twin Ion Engine/AG Aggressor starfighter
- **Type:** Hybrid starfighter/bomber
- **Cost:** 75,000 credits, not available for sale
- **Max Speed:** 1,100 km/h
- **Hyperdrive:** None
- **Shield Gen:** None
- **Sensor:** Close
- **Armament:**
  - Laser cannons
  -   Turret mounted twin light laser cannons
  -   Forward-mounted medium laser cannons
  - Missile launcher
  -   6 concussion missiles
- **Crew:**
  - Pilot (1)
  - Gunner/Weapon Systems Operator (1)
- **Passengers:** None
- **Capacity:** 75 kilograms
- **Consumables:** 2 days&ndash;1 week
- **Availability:** Military
- **Role:** Multi-purpose starfighter
- **Affiliation:** Galactic Empire
