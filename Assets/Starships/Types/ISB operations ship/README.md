# ISB operations ship

**Continuity:** Legends  
**Source:** [ISB operations ship](https://starwars.fandom.com/wiki/ISB_operations_ship)

The ISB operations ship was a cruiser outfitted by the Galactic Empire for use by the Imperial Security Bureau. It was capable of landing on a planet's surface to carry out its operations.

## Specifications

- **Name:** ISB operations ship
- **Max Speed:** 1,200 kmh
- **Shield Gen:** Equipped
- **Armament:** 4 Laser cannons
- **Crew:** 3 (4 gunners)
- **Role:** Imperial Security Bureau operations
- **Affiliation:** Galactic Empire
