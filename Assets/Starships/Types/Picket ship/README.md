# Picket ship

**Continuity:** Canon  
**Source:** [Picket ship](https://starwars.fandom.com/wiki/Picket_ship)

A picket ship, or simply picket, was a type of starship. Pelta-class frigates were used as picket ships by the Galactic Republic. The Galactic Empire utilized several pickets during the Berch Teller campaign. The Kilji Illumine theocracy used Kilji picket cruisers, one of which, the Hammer, was part of Illumine General Crofyp's task force.
