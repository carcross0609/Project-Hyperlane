# CCR-class pinnace

**Continuity:** Canon  
**Source:** [CCR-class pinnace](https://starwars.fandom.com/wiki/CCR-class_pinnace)

The CCR-class pinnace was a civilian starship. During the reign of the Galactic Empire, the vessel was used as a scout ship. One particular vessel was used as a scout in the Western Reaches. Saw Gerrera's Partisans discovered the vessel. Using clearance codes created by Jyn Erso, the crew boarded the vessel and overpowered the Imperial passengers, stealing valuable data about what the surveyors had discovered.

## Specifications

- **Name:** CCR-class pinnace
- **Model:** CCR-class

- **Role:** Scout ship
