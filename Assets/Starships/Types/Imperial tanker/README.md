# Imperial tanker

**Continuity:** Legends  
**Source:** [Imperial tanker](https://starwars.fandom.com/wiki/Imperial_tanker)

Imperial tankers were long, tube-shaped transports in use by the Galactic Empire during the Galactic Civil War. One of their uses was transporting tibanna gas.

## Specifications

- **Name:** Imperial tanker
- **Type:** Tanker
- **Hdsystem:** Equipped
- **Capacity:** Fuel cylinder
- **Role:** Transport
- **Affiliation:** Galactic Empire
