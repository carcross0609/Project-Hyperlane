# Remote scout module

**Continuity:** Legends  
**Source:** [Remote scout module](https://starwars.fandom.com/wiki/Remote_scout_module)

Remote scout modules were used by Xizor's flagship the Vendetta to discreetly investigate the area surrounding the starship. These modules were used around 0 ABY to locate Boba Fett's ship Slave I coming out of hyperspace.
