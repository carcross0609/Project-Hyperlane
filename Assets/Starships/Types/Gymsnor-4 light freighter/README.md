# Gymsnor-4 light freighter

**Continuity:** Legends  
**Source:** [Gymsnor-4 light freighter](https://starwars.fandom.com/wiki/Gymsnor-4_light_freighter)

The Gymsnor-4 light freighter was the fourth ship in the Gymsnor series produced by CorelliSpace. It resembled a flying wing, though some spacers insultingly compared it to a mynock. The Rimrunner, Salla Zend's smuggling vessel, was a Gymsnor-4.
