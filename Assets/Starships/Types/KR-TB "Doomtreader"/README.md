# KR-TB "Doomtreader"

**Continuity:** Legends  
**Source:** [KR-TB "Doomtreader"](https://starwars.fandom.com/wiki/KR-TB_%22Doomtreader%22)

The KR-TB "Doomtreader" was a freighter produced by Corellian Engineering Corporation. It had expansive cargo holds, heavy deflector shields and dual laser cannons, but came at a relatively high price.
