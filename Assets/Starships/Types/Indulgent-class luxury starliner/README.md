# Indulgent-class luxury starliner

**Continuity:** Legends  
**Source:** [Indulgent-class luxury starliner](https://starwars.fandom.com/wiki/Indulgent-class_luxury_starliner)

The Indulgent-class luxury starliner was one of the most luxurious models of passenger liner during the Galactic Civil War. It was manufactured by Leonore Luxury Liners Incorporated.

## Specifications

- **Name:** Indulgent-class luxury starliner
- **Manufacturer:** Leonore Luxury Liners Incorporated
- **Model:** Indulgent
- **Type:** Passenger liner
- **Cost:** 25,500,000 credits
- **Hyperdrive:**
  - Class 3
  - Class 12 (backup)
- **Navigation:** Equipped
- **Armament:** Heavy ion cannons (4)
- **Crew:** 850
- **Passengers:** 1,500
