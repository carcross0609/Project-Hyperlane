# Starhunter

**Continuity:** Legends  
**Source:** [Starhunter](https://starwars.fandom.com/wiki/Starhunter)

The Starhunter was a further evolution of the TIE/IN interceptor starfighter that saw use with the navy of the Imperial Remnant during the latter stages of the Second Galactic Civil War. Boasting more firepower, with heavy weapons in addition to laser cannons, the Starhunter also carried a deflector shield generator. It was operated by a single pilot.
