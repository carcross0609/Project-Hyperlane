# Spearpoint

**Continuity:** Legends  
**Source:** [Spearpoint](https://starwars.fandom.com/wiki/Spearpoint)

The Spearpoint was a starfighter in the Galactic Republic which performed in scouting roles. Produced by Corellia StarDrive, it used dozens of components manufactured by scientific sensor manufacturers, giving it the best sensor and communication suite on the market. However, the Spearpoint sacrificed some of its internal storage space, maneuverability, and speed in exchange for its upgrades.
