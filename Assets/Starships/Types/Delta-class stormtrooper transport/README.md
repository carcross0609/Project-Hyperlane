# Delta-class stormtrooper transport

**Continuity:** Canon  
**Source:** [Delta-class stormtrooper transport](https://starwars.fandom.com/wiki/Delta-class_stormtrooper_transport)

The Delta-class stormtrooper transport was a class of transport that was used for the transportation of stormtroopers. An Imperial-class Star Destroyer could have fifteen such transports within its complement.

## Specifications

- **Name:** Delta-class stormtrooper transport
- **Model:** Delta-class
- **Type:** Transport
- **Affiliation:**
