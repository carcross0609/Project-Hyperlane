# XJ6 X-wing starfighter

**Continuity:** Legends  
**Source:** [XJ6 X-wing starfighter](https://starwars.fandom.com/wiki/XJ6_X-wing_starfighter)

The XJ6 X-wing starfighter was a variant of the classic X-wing starfighter produced by Incom Corporation. In service with the Galactic Alliance Navy as of 40 ABY, it saw action in the Second Galactic Civil War. Luke Skywalker's Hardpoint Squadron of Jedi pilots used these models exclusively.
