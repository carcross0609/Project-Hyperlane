# JumpMaster 5000

**Continuity:** Canon  
**Source:** [JumpMaster 5000](https://starwars.fandom.com/wiki/JumpMaster_5000)

The JumpMaster 5000 was a model of lightly-armed starship designed for long-distance reconnaissance missions and scouting new hyperlane routes. One such vessel was the Punishing One owned by the bounty hunter Dengar.

## Specifications

- **Name:** JumpMaster 5000
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Scout ship
- **Cost:** 55,000 credits
- **Hyperdrive:**
  - Class 3 (Primary)
  - Class 15 (Backup)
- **Sensor:** Extreme
- **Armament:** Light laser cannon
- **Crew:** 1 pilot
- **Passengers:** 1
- **Consumables:** 2 months
