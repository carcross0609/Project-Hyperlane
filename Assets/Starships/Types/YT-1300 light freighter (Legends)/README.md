# YT-1300 light freighter

**Continuity:** Legends  
**Source:** [YT-1300 light freighter/Legends](https://starwars.fandom.com/wiki/YT-1300_light_freighter/Legends)

The YT-1300 light freighter was one of the Corellian Engineering Corporation's freighter designs. The most notable example of this model was the Millennium Falcon, a heavily modified YT-1300.
