# StarMite light freighter

**Continuity:** Legends  
**Source:** [StarMite light freighter](https://starwars.fandom.com/wiki/StarMite_light_freighter)

The SoroSuub Corporation StarMite light freighter, often called simply the Starmite, was a light freighter in use during the Clone Wars and Galactic Civil War. About 2/3rds the size of a YT-1300 light freighter, it had a blunt, rounded bow. It had thick stubby wings and rounded thick body that narrowed back to a flattened tail section. It did not work well with modifications, particularly those made with non-SoroSuub parts. Han Solo's Bria was a heavily-modified Starmite-class freighter.
