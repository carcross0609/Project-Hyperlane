# Evac pod

**Continuity:** Legends  
**Source:** [Evac pod](https://starwars.fandom.com/wiki/Evac_pod)

Evac pods were large, armed variants of escape pods that served as troop landers during the Stark Hyperspace War. Numerous evac pods were carried aboard the Invincible and other ships of Ranulph Tarkin's fleet.

## Specifications

- **Name:** Evac pod
- **Type:** Escape pod
- **Affiliation:** Galactic Republic
