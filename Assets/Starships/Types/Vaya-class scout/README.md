# Vaya-class scout

**Continuity:** Legends  
**Source:** [Vaya-class scout](https://starwars.fandom.com/wiki/Vaya-class_scout)

The Vaya-class scout was a type of scout ship manufactured by Hoersch-Kessel Drive, Inc. c. 3999 BBY.

## Specifications

- **Name:** Vaya-class scout
- **Manufacturer:** Hoersch-Kessel Drive, Inc.
- **Model:** Scout
- **Cost:** 45,000 credits (new) or 15,000 credits (used)
- **Length:** 30 meters
- **Engine:** Six ion engines
- **Hyperdrive:**
  - Class 8 or Class 4
  - Class 15 (backup)
- **Armament:**
  - Laser cannon
  - Concussion projectile launcher
- **Crew:** (1), Gunners (2)
- **Passengers:** 4
- **Capacity:** 60 metric tons
- **Consumables:** 1 month
- **Affiliation:**
  - Republic Astrogation Survey Team
  - independent scouts
