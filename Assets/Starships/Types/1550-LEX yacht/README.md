# 1550-LEX yacht

**Continuity:** Canon  
**Source:** [1550-LEX yacht](https://starwars.fandom.com/wiki/1550-LEX_yacht)

The 1550-LEX yacht was a model of yacht used during and after the Galactic Civil War. One such ship, the Serendipity, belonged to Delia Leighton and featured a cantina inside.
