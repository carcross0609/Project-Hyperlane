# Huttian star yacht

**Continuity:** Legends  
**Source:** [Huttian star yacht](https://starwars.fandom.com/wiki/Huttian_star_yacht)

A certain type of bell-shaped space yacht was used by the Hutts at some point before the start of the Clone Wars in 22 BBY. Those yachts had big entrance hatches, large enough for a masive Hutt to get in or out. The Huttese criminal Zorba Desilijic Tiure owned one, which he had christened the Zorba Express.

## Specifications

- **Name:** Huttian star yacht
- **Model:** Yacht
- **Role:** Personal transport
- **Affiliation:** Hutts
