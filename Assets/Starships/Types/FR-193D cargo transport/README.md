# FR-193D cargo transport

**Continuity:** Canon  
**Source:** [FR-193D cargo transport](https://starwars.fandom.com/wiki/FR-193D_cargo_transport)

The FR-193D cargo transport was a model of hauler starship manufactured by Ferrix Field Yards. Clem and Maarva Andor, natives of the planet Ferrix, used one such hauler to search the galaxy for salvage.

## Specifications

- **Name:** FR-193D cargo transport
- **Manufacturer:** Ferrix Field Yards
- **Model:** FR-193D
- **Type:** Hauler
- **Length:** 14.3 meters (46 ft, 11 in)
- **Mglt:** 70 mglt
- **Hdsystem:** Equipped
- **Crew:** 2
