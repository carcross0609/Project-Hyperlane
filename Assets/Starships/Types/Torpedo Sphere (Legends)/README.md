# Torpedo Sphere

**Continuity:** Legends  
**Source:** [Torpedo Sphere/Legends](https://starwars.fandom.com/wiki/Torpedo_Sphere/Legends)

The Torpedo Sphere was a massive mobile battle station manufactured by Loronar Defense Industries, a subsidiary of Loronar Corporation.

## Specifications

- **Name:** Torpedo Sphere
- **Manufacturer:** Loronar Defense Industries
- **Type:** Dedicated siege platform
- **Cost:** Not available for sale; 327,830,000 credits (construction cost)
- **Length:** 1,900 meters
- **Max Speed:** 930 kmh
- **Engine:** Equipped
- **Hyperdrive:**
  - Class 3
  - Class 18 (back-up)
- **Shield Gen:** Loronar Corporation DS-13 projectors
- **Sensor:** Dedicated energy receptors
- **Navigation:** Sienar Fleet Systems navigation computer
- **Armament:**
  - 10 turbolaser batteries
  - 500 proton torpedo tubes
  - Two-wave gravshock (custom ordnance)
- **Complement:**
  - Lambda-class T-4a shuttles
  - MT/191 drop-ships
- **Crew:** 61,245; 2,030 gunners
- **Skeleton:** 20,415
- **Passengers:** 8,540 (troops)
- **Capacity:** 3.8 million metric tons
- **Consumables:** 4 years
- **Role:** Planetary bombardment
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
  - Thrawn's Confederation
  -   Thrawn's Fleet
  - Dark Empire
