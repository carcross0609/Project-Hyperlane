# TT4449

**Continuity:** Legends  
**Source:** [TT4449](https://starwars.fandom.com/wiki/TT4449)

TT4449 was a Delta-class DX-9 stormtrooper transport employed by the Rebel Alliance to extract officers from the frigate Anvil which had been severely damaged and needed to be abandoned. Three X-wings, one of which piloted by Keyan Farlander, provided support and cover for the convoy of ships to escape to Hyperspace.
