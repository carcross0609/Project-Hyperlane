# Yorik-trema

**Continuity:** Legends  
**Source:** [Yorik-trema](https://starwars.fandom.com/wiki/Yorik-trema)

The yorik-trema or airskiff was a bio-engineered transport vessel used by the extragalactic Yuuzhan Vong invaders.

## Specifications

- **Name:** Yorik-trema
- **Manufacturer:** Yuuzhan Vong
- **Model:** Yorik-trema transport carrier
- **Type:** Transport
- **Length:** 48 meters (on average)
- **Max Accel:** 1,500 G
- **Max Speed:** 3,000 km/h (descent)/1,000 km/h (ascent)
- **Engine:** Dovin basals
- **Hdsystem:** None
- **Shield Gen:** Dovin basals
- **Hull:** Yorik coral hull with ablative coating
- **Armament:**
  - Yaret-Kors (2)
  - Dovin basals
- **Crew:**
  - 4
  - Pilot (1)
  - Commander (1)
- **Passengers:**

  - 30 support troops
- **Capacity:** 35 metric tons
- **Consumables:** 3 days
- **Othersystems:** Molleung worms (boarding/disembarking tubes)
- **Role:** Landing craft
- **Affiliation:** Yuuzhan Vong
