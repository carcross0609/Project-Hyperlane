# Utility crane ship

**Continuity:** Canon  
**Source:** [Utility crane ship](https://starwars.fandom.com/wiki/Utility_crane_ship)

A utility crane ship was a type of small starship featuring a utility crane. The Wookiee Chalmun, proprietor of Chalmun's Spaceport Cantina in Mos Eisley, owned one such craft. He used it to pick up liquor imports from heavy freighters orbiting around Tatooine, but also as an escape craft.
