# Blockade frigate

**Continuity:** Canon  
**Source:** [Blockade frigate](https://starwars.fandom.com/wiki/Blockade_frigate)

A blockade frigate was a classification of frigate that was used by the Nikardun Destiny of the Unknown Regions of the galaxy. The Nikardun used one class of blockade frigate. One such warship was captured by the Paccian Governance and renamed the Aelos.
