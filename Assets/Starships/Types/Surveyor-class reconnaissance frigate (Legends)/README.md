# Surveyor-class reconnaissance frigate

**Continuity:** Legends  
**Source:** [Surveyor-class reconnaissance frigate/Legends](https://starwars.fandom.com/wiki/Surveyor-class_reconnaissance_frigate/Legends)

The Surveyor-class reconnaissance frigate was an Imperial scout craft manufactured by Kuat Drive Yards for the Imperial Navy. It was based on the Active-class fast attack frigate, with a hull that resembled that of the Vindicator-class heavy cruisers, while the bridge and primary sensor arrays were in a structure resembling the bridge of a Bellator-class dreadnought.
