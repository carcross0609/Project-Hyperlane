# Scorpion-class Intercept Shuttle

**Continuity:** Legends  
**Source:** [Scorpion-class Intercept Shuttle](https://starwars.fandom.com/wiki/Scorpion-class_Intercept_Shuttle)

The Scorpion-class Intercept Shuttle was a model of shuttle used by the Mandalorians of the Hidden Chain during the Third Galactic War. A spacecrafts of this class possessed with light armaments and features variable wing configurations for swift, maneuverable flight in-atmosphere. It carries a 12-person armored squad, their gear, a pilot, and a navigator. Mandalorians can deploy via a ladder in vertical mode, exiting rapidly with jetpacks.

## Specifications

- **Name:** Scorpion-class Intercept Shuttle
- **Manufacturer:** Cindev shipyards
- **Type:** Shuttle
- **Crew:**
  - Pilot (1)
  - Navigator flight crew (1)
- **Passengers:** 12
- **Affiliation:**

  - InterStellar Regulators
  - Hidden Chain
