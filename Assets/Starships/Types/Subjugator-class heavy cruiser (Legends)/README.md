# Subjugator-class heavy cruiser

**Continuity:** Legends  
**Source:** [Subjugator-class heavy cruiser/Legends](https://starwars.fandom.com/wiki/Subjugator-class_heavy_cruiser/Legends)

The Subjugator-class heavy cruiser was a Confederacy of Independent Systems warship class that consisted of at least five ships.
