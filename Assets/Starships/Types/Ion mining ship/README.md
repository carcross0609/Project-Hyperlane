# Ion mining ship

**Continuity:** Legends  
**Source:** [Ion mining ship](https://starwars.fandom.com/wiki/Ion_mining_ship)

Dakar and his fellow ion miners piloted a number of ion mining ships, which they kept docked at Exis Station. Using the ships, they harvested plasma from Teedio.

## Specifications

- **Name:** Ion mining ship
- **Type:** Starship
- **Role:** Harvesting plasma
- **Affiliation:** Dakar
