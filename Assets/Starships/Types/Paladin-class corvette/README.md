# Paladin-class corvette

**Continuity:** Canon  
**Source:** [Paladin-class corvette](https://starwars.fandom.com/wiki/Paladin-class_corvette)

The Paladin-class corvette, also known simply as the Jedi training cruiser, the Jedi training vessel or the Jedi cruiser, was a corvette manufactured by Rendili Vehicle Corporation. The Crucible was a ship of this class that was custom built for the Jedi Order during the Galactic Republic.
