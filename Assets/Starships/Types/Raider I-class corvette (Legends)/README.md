# Raider I-class corvette

**Continuity:** Legends  
**Source:** [Raider I-class corvette/Legends](https://starwars.fandom.com/wiki/Raider_I-class_corvette/Legends)

The Raider I-class corvette was the first sub-class of the Raider-class line of corvettes used by the Galactic Empire during the Galactic Civil War. It was succeeded by the Raider II-class corvette.

## Specifications

- **Name:** Raider I-class corvette

- **Model:** Raider I-class corvette
- **Armament:**

  - Single turbolasers
  - Ion cannons
- **Affiliation:**
  - Galactic Empire
