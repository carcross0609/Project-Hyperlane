# F-99 radon gunship

**Continuity:** Canon  
**Source:** [F-99 radon gunship](https://starwars.fandom.com/wiki/F-99_radon_gunship)

The F-99 radon gunship was a class of gunship. In 18 BBY, Cli Pastayra of the Wandering Star syndicate deployed a pair of F-99s in a confrontation with Fyzen Gor and his organic-augmented droids on Utapau. By 7 ABY, those models were still in use in order to protect the Phylanx Redux Transmitter while in the Mesulan Remnants Belt.

## Specifications

- **Name:** F-99 radon gunship
- **Type:** Gunship
- **Othersystems:** Autopilot
- **Affiliation:** Wandering Star
