# Ambassador-class shuttle

**Continuity:** Legends  
**Source:** [Ambassador-class shuttle](https://starwars.fandom.com/wiki/Ambassador-class_shuttle)

The Ambassador-class shuttle, also known as the Ambassador-class luxury shuttle and Luxury Shuttle 001, was a SoroSuub shuttle model.

## Specifications

- **Name:** Ambassador-class shuttle
- **Manufacturer:** SoroSuub Corporation
- **Length:** 50 meters
- **Max Speed:** 1,000 kmh
- **Hyperdrive:**
  - Class 2
  - Class 14
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Navigation:** Equipped
- **Armament:** Twin double laser cannons
- **Crew:** 2; 1 gunner
- **Passengers:** 10
- **Capacity:** 100 metric tons
- **Consumables:** 1 month
