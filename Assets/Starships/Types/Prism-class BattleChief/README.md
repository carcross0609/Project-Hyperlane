# Prism-class BattleChief

**Continuity:** Canon  
**Source:** [Prism-class BattleChief](https://starwars.fandom.com/wiki/Prism-class_BattleChief)

The Prism-class BattleChief was a class of warship used by the Grysk Hegemony of the Unknown Regions. Eleven BattleChiefs were part of an armada of Grysk ships that included three StoneCrusher-class WarMasters and one Shatter-class WarMaster.
