# 580 freighter

**Continuity:** Legends  
**Source:** [580 freighter](https://starwars.fandom.com/wiki/580_freighter)

The 580 freighter was an older model light freighter produced by Ghtroc Industries. It was not as impressive as some of the newer models, but it did have the advantage of a larger cargo capacity and longer operational times between replenishment. It was operated by a crew of one.

## Specifications

- **Name:** 580 freighter
- **Manufacturer:** Ghtroc Industries
- **Model:** Class 580 freighter
- **Type:** Light freighter
- **Cost:** 20,000 credits
- **Length:** 37 meters
- **Max Speed:** 800 kmh
- **Hyperdrive:**

  - Class 15 backup
- **Shield Gen:** Equipped
- **Armament:** Laser cannon (1)
- **Crew:** 1
- **Passengers:** 6
- **Capacity:** 200 metric tons
- **Consumables:** 6 months
- **Affiliation:**
