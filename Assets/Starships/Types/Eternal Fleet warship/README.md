# Eternal Fleet warship

**Continuity:** Legends  
**Source:** [Eternal Fleet warship](https://starwars.fandom.com/wiki/Eternal_Fleet_warship)

The Eternal Fleet warship was the main ship of the Eternal Fleet, a fleet of ships controlled by the sentient GEMINI droid units.

## Specifications

- **Name:** Eternal Fleet warship
- **Type:** Battle cruiser
- **Power:** Sun Generator
- **Armament:** Many Heavy Turbolasers
- **Crew:** GEMINI units
- **Passengers:**
  - Skytroopers
  - Knights of Zakuul
- **Role:** Warship
- **Affiliation:**
  - Eternal Fleet
  - Eternal Empire
  - Eternal Alliance
  -   Eternal Alliance fleet
