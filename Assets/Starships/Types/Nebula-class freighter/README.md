# Nebula-class freighter

**Continuity:** Canon  
**Source:** [Nebula-class freighter](https://starwars.fandom.com/wiki/Nebula-class_freighter)

The Nebula-class freighter was a type of freighter that was in use during the Clone Wars. By 19 BBY, the pilot Trace Martez owned a heavily-modified Nebula-class freighter that she hoped to turn into a faster vessel which she named the Silver Angel.
