# Rainhawk-class shuttle

**Continuity:** Canon  
**Source:** [Rainhawk-class shuttle](https://starwars.fandom.com/wiki/Rainhawk-class_shuttle)

The Rainhawk-class shuttle was a type of shuttle. When traveling back to Coruscant from Teth, Qui-Gon Jinn and his Padawan Obi-Wan Kenobi piloted a Rainhawk-class shuttle.

## Specifications

- **Name:** Rainhawk-class shuttle
- **Type:** Shuttle
- **Crew:** At least 1 pilot
