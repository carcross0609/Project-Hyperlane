# Giga-class transport

**Continuity:** Canon  
**Source:** [Giga-class transport](https://starwars.fandom.com/wiki/Giga-class_transport)

The Giga-class transport was an enormous model of transport ship that could accommodate thousands of passengers. One such craft was the leisure cruise ship Ultimo Vista, which by the time of the Separatist Crisis had become a contained, almost entirely self-sufficient world.

## Specifications

- **Name:** Giga-class transport
- **Type:** Transport
- **Passengers:** Thousands
- **Role:**
  - Transport
  - Leisure cruise ship
