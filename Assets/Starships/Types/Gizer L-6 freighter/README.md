# Gizer L-6 freighter

**Continuity:** Legends  
**Source:** [Gizer L-6 freighter](https://starwars.fandom.com/wiki/Gizer_L-6_freighter)

The Gizer L-6 freighter was a class of freighter developed on Gizer that was used predominantly during the Clone Wars as a civilian transport craft. Omega Squad was tasked to interdict a Separatist Gizer L-6 freighter in 21 BBY. The mission was a near disaster.
