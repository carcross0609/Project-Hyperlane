# Warbird starfighter

**Continuity:** Canon  
**Source:** [Warbird starfighter](https://starwars.fandom.com/wiki/Warbird_starfighter)

The Warbird starfighter was a custom starfighter model utilized by the Warbird gang during the First Order-Resistance War. The starfighter was heavily modified, taking parts from A-wings, Eta-2 Actis-class interceptors, and Imperial TIE/IN interceptors.

## Specifications

- **Name:** Warbird starfighter
- **Type:** Starfighter
- **Armament:** Laser cannon
- **Role:** Starfighter combat
- **Affiliation:** Warbird gang
