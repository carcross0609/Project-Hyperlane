# Evakmar-KDY transport

**Continuity:** Legends  
**Source:** [Evakmar-KDY transport](https://starwars.fandom.com/wiki/Evakmar-KDY_transport)

Evakmar-KDY transports were examples of one of the few cases of true cooperation between the Imperial Army and the Imperial Navy. These vessels were designed to carry a full standard Army Corps, regardless of the specific type of corps. Additionally, the ships were built with the possibility of expansion in mind, in order to allow for some expansion in the size of a standard corps.

## Specifications

- **Name:** Evakmar-KDY transport
- **Manufacturer:** Evakmar-Kuat Drive Yards
- **Hyperdrive:** Equipped
- **Passengers:** 74,794+
- **Role:** Transport
- **Affiliation:**

  -   Imperial Army
