# YV-545 light freighter

**Continuity:** Legends  
**Source:** [YV-545 light freighter](https://starwars.fandom.com/wiki/YV-545_light_freighter)

The YV-545 light freighter was a light freighter produced by the Corellian Engineering Corporation in an attempt to replace the aging YT-series freighters.

- **Name:** YV-545 light freighter
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YV series
- **Model:** YV-545 light freighter
- **Type:** Freighter
- **Cost:** 120,000 credits (35,000 used)
- **Max Accel:** 800 km/h
- **Hyperdrive:** Class 2 (Backup class 15)
- **Navigation:** Navicomputer
- **Crew:** 2
- **Passengers:** 5
- **Capacity:** 80 tons
- **Consumables:** 3 months
