# Cargo ferry

**Continuity:** Legends  
**Source:** [Cargo ferry](https://starwars.fandom.com/wiki/Cargo_ferry)

The cargo ferry was a transport manufactured by Kiara Cargo Corporation. It was a freighter with six engines. The ferry could carry cargo both internally and externally in attached containers, or externally carry captured spacecraft. The Galactic Empire and the Alliance to Restore the Republic employed such ferries, as did various space pirates and civilians.
