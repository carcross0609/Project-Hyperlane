# Corsair-class cruiser

**Continuity:** Legends  
**Source:** [Corsair-class cruiser](https://starwars.fandom.com/wiki/Corsair-class_cruiser)

The Corsair-class cruiser was an 18-meter heavy assault starfighter built by SoroSuub. It was armed with two turbolaser batteries and a pair of ion cannons. It was used by the Cavrilhu Pirates, Dharus’ Buccaneers, as well as by the pirate Rei'Kas.
