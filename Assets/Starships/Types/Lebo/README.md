# Lebo

**Continuity:** Legends  
**Source:** [Lebo](https://starwars.fandom.com/wiki/Lebo)

Lebo was the name of a group of two Rebel Delta-class DX-9 stormtrooper transports that carried Rebel equipment away from Yavin 4. Red Squadron oversaw their exit from the Imperial blockade.
