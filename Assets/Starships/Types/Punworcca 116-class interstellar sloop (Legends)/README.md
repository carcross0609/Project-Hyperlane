# Punworcca 116-class interstellar sloop

**Continuity:** Legends  
**Source:** [Punworcca 116-class interstellar sloop/Legends](https://starwars.fandom.com/wiki/Punworcca_116-class_interstellar_sloop/Legends)

The Punworcca 116-class interstellar sloop was a personal yacht designed by the Huppla Pasa Tisc Shipwrights Collective of Geonosis. Count Dooku possessed such a vessel that was gifted to him by Archduke Poggle the Lesser. His particular vessel was heavily modified, propelled by a unique solar sail using ancient Gree technology. He used the vessel to enter and leave Coruscant undetected.
