# Chiss Defense Force Transport

**Continuity:** Canon  
**Source:** [Chiss Defense Force Transport](https://starwars.fandom.com/wiki/Chiss_Defense_Force_Transport)

The Chiss Defense Force Transport was a class of transport that served the Defense Force of the Chiss Ascendancy. One such vessel was the Tomra, commanded by Junior Captain Vorlip.
