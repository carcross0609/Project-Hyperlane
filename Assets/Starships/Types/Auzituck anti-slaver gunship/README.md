# Auzituck anti-slaver gunship

**Continuity:** Canon  
**Source:** [Auzituck anti-slaver gunship](https://starwars.fandom.com/wiki/Auzituck_anti-slaver_gunship)

The Auzituck anti-slaver gunship, also called the Auzituck-class gunship, or the Wookiee gunship, was a gunship manufactured by Appazanna Engineering Works and used by Wookiees to battle slavers.

## Specifications

- **Name:** Auzituck anti-slaver gunship
- **Manufacturer:** Appazanna Engineering Works
- **Cost:** 95,000 credits
- **Length:** 14.7 meters
- **Width:** 7.6 meters
- **Height:** 6 meters
- **Max Speed:** 950 km/h
- **Hyperdrive:**
  - Class 2 (primary)
  - Class 12 (backup)
- **Hdsystem:** Equipped
- **Shield Gen:** Equipped
- **Armament:** Sureggi twin laser cannons (3)
- **Crew:**
  - One pilot
  - One co-pilot/gunner
- **Passengers:** 8
- **Consumables:** One month
- **Affiliation:**
  - Kashyyyk resistance
  - Citizens' Fleet
