# YG-5000 light freighter

**Continuity:** Legends  
**Source:** [YG-5000 light freighter](https://starwars.fandom.com/wiki/YG-5000_light_freighter)

The YG-5000 light freighter was a design in the successful YG-series transport line developed by the Corellian Engineering Corporation, many centuries before the Galactic Civil War. Three main sublight engines were mounted to the YG-5000, similar in arrangement to the engines of the Consular-class space cruiser.

## Specifications

- **Name:** YG-5000 light freighter
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YG-series
- **Model:** YG-5000
- **Type:** Light freighter
- **Engine:** 3 sublight engines
