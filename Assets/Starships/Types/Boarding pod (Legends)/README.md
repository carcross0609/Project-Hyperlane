# Boarding pod

**Continuity:** Legends  
**Source:** [Boarding pod/Legends](https://starwars.fandom.com/wiki/Boarding_pod/Legends)

Boarding pods were a type of a boarding craft used by various militaries, such as the Eternal Empire of Zakuul. Vessels of the Eternal Fleet carried boarding pods, which were able to dig into the hulls of enemy ships and deploy a contingent of Skytroopers.

## Specifications

- **Name:** Boarding pod
- **Type:** Boarding craft
- **Role:** Boarding vessel
