# Star Duster

**Continuity:** Legends  
**Source:** [Star Duster](https://starwars.fandom.com/wiki/Star_Duster)

A Star Duster was a type of starship. By 3 ABY, it was considered old enough that replacement parts for use in it were in low supply. Yakar's Parts offered such replacement parts for the Star Duster among its multitude of equipment.
