# Escort gunboat

**Continuity:** Canon  
**Source:** [Escort gunboat](https://starwars.fandom.com/wiki/Escort_gunboat)

An escort gunboat was a type of gunboat that was used by the Imperial Navy. In 14 BBY, two escort gunboats were commanded by Moff Wilhuff Tarkin while springing a trap for Berch Teller's rebel cell.
