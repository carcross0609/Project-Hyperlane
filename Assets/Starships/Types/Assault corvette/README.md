# Assault corvette

**Continuity:** Legends  
**Source:** [Assault corvette](https://starwars.fandom.com/wiki/Assault_corvette)

Assault corvettes were a class of starship utilized by the Galactic Empire. One Imperial assault corvette destroyed the Alliance to Restore the Republic ship Pride of Stars.
