# Corellian heavy lifter

**Continuity:** Legends  
**Source:** [Corellian heavy lifter](https://starwars.fandom.com/wiki/Corellian_heavy_lifter)

The Corellian heavy lifter was a transport vessel designed by the Rebel Alliance to haul cargo.

## Specifications

- **Name:** Corellian heavy lifter
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Heavy lifter
- **Length:** 150m
- **Engine:** 3
- **Cargohandling:** Heavy-duty clamps (2)
- **Role:** Transport
- **Affiliation:** Alliance to Restore the Republic
