# First Order Light Cruiser

**Continuity:** Canon  
**Source:** [First Order Light Cruiser](https://starwars.fandom.com/wiki/First_Order_Light_Cruiser)

The First Order Light Cruiser was a model of light cruiser used by the First Order. It could be docked on the nose of a Resurgent-class Star Destroyer, and was also used as a crew transfer shuttle. The Enshado was one such ship. Following the discovery of Lor San Tekka, the First Order dispatched another cruiser to recover him, but it was destroyed by Black Squadron.
