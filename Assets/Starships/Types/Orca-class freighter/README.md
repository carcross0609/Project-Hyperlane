# Orca-class freighter

**Continuity:** Canon  
**Source:** [Orca-class freighter](https://starwars.fandom.com/wiki/Orca-class_freighter)

The Orca-class freighter was a class of civilian freighter that saw use during the Galactic Civil War. One Orca-class, Freighter 2716, was used by the Galactic Empire as part of Project Stardust and delivered a large kyber crystal to the Tonnis sector.

- **Name:** Orca-class freighter
