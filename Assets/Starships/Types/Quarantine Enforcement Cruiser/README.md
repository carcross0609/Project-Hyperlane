# Quarantine Enforcement Cruiser

**Continuity:** Legends  
**Source:** [Quarantine Enforcement Cruiser](https://starwars.fandom.com/wiki/Quarantine_Enforcement_Cruiser)

A Quarantine Enforcement Cruiser was a starship tasked with maintaining a quarantine in times of disease outbreak. In 13 ABY, the starship Lycoming served as a Quarantine Enforcement Cruiser.
