# ARC-200 Wing Cutter Fighter

**Continuity:** Canon  
**Source:** [ARC-200 Wing Cutter Fighter](https://starwars.fandom.com/wiki/ARC-200_Wing_Cutter_Fighter)

The ARC-200 Wing Cutter Fighter was a starfighter used by the Ashiga Clan and the Hutt Clan during the Imperial Era. The ARC-200 used the same heavy blaster cannons used by the ARC-170 starfighter, as well as a similar prow and cockpit design. Like the ARC-170, the ARC-200 Wing Cutter also had two rear blaster turrets, missile launchers, and a dorsal astromech socket.
