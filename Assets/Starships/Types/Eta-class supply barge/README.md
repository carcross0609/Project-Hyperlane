# Eta-class supply barge

**Continuity:** Canon  
**Source:** [Eta-class supply barge](https://starwars.fandom.com/wiki/Eta-class_supply_barge)

The Eta-class supply barge was a type of supply barge used by the Galactic Empire. Larger than the Zeta-class Heavy Cargo Shuttle, the Eta-class could hold multiple pods aloft on a dorsal cargo bed.

- **Name:** Eta-class supply barge

- **Model:** Eta-class supply barge
- **Type:** Supply ship

- **Crew:**

- **Cargohandling:** Dorsal cargo bed
