# XL-5 Guardian force reconnaissance ship

**Continuity:** Canon  
**Source:** [XL-5 Guardian force reconnaissance ship](https://starwars.fandom.com/wiki/XL-5_Guardian_force_reconnaissance_ship)

The XL-5 Guardian force reconnaissance ship was a class of starship manufactured by Tion Mil/Sci Industries. During the Galactic Civil War, it was used by the Galactic Empire's Imperial Army and Imperial Security Bureau. The XL-3c Guardsman Patrol Airspeeder was the civilian law enforcement version of the XL-5.

## Specifications

- **Name:** XL-5 Guardian force reconnaissance ship
- **Manufacturer:** Tion Mil/Sci Industries
- **Type:** Reconnaissance starship
- **Affiliation:**

  -   Imperial Army
  -   Imperial Security Bureau
