# Ithorian herd ship

**Continuity:** Canon  
**Source:** [Ithorian herd ship](https://starwars.fandom.com/wiki/Ithorian_herd_ship)

Ithorian herd ships were a class of massive city-ship used by the Ithorians as a home away from home. They were based on the repulsorlift herd-cities of their planet, but were enclosed for space travel. The ships travel the galaxy on a predetermined course set by the herd, but return to Ithor once every three years in an event known as the Herd Meet.
