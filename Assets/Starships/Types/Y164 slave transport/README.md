# Y164 slave transport

**Continuity:** Legends  
**Source:** [Y164 slave transport](https://starwars.fandom.com/wiki/Y164_slave_transport)

The Y164 Slave Transport was used by the Thalassian slavers to transport their slaves to the new owners. It was bulky but durable. It had decent firepower, but usually was protected by Kaloth-style battlecruisers.
