# Class Three

**Continuity:** Canon  
**Source:** [Class Three](https://starwars.fandom.com/wiki/Class_Three)

The third class of starship used by the Crimson Dawn criminal syndicate was deployed during their battle against the Galactic Empire at the Amaxine Station. The class, along with Class-Two, were ordered by Margo to target and destroy the long-range cannons of the Executor, and to therefore prevent it from destroying the station.
