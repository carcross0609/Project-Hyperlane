# StealthX

**Continuity:** Legends  
**Source:** [StealthX](https://starwars.fandom.com/wiki/StealthX)

The StealthX was a model of X-wing starfighter used by Luke Skywalker's New Jedi Order that entered service sometime between the end of the Yuuzhan Vong War and the Killik-Chiss conflict.

## Specifications

- **Name:** StealthX
- **Manufacturer:** Incom Corporation
- **Line:** X-wing
- **Model:** StealthX starfighter
- **Type:** Starfighter
- **Engine:** Fusial engines (4; retooled to burn TibannaX)
- **Shield Gen:** Equipped (downgraded)
- **Countermeasures:**
  - Sensor negators
  - Gravitic modulator (1)
  - Photon absorber
  - Thermal dissipator
- **Armament:**
  - Laser cannons (4)
  - Proton torpedo launchers (2)
  - Alternatively:
  - Jedi shadow bombs
  - Glop bombs
  - Bunker-buster bombs
- **Crew:**
  - Pilot (1)
  - Astromech droid (1)
- **Role:**
  - Reconnaissance
  - Escort
- **Affiliation:**
  - New Jedi Order
  - Galactic Federation of Free Alliances
  - Jedi Coalition
