# Freight-Loading External Rover

**Continuity:** Legends  
**Source:** [Freight-Loading External Rover/Legends](https://starwars.fandom.com/wiki/Freight-Loading_External_Rover/Legends)

The Freight-Loading External Rover, also known as the F-LER, was a small, extremely rare single-pilot starship that was manufactured by the Corellian Engineering Corporation for use in conjunction with the YT-1300 light freighter.

## Specifications

- **Name:** Freight-Loading External Rover
- **Designer:** Tem Riffle
- **Manufacturer:** Corellian Engineering Corporation
- **Armament:**
  - 2 laser cannons (optional)
  - Harpoon and tow cable
  - Ap/11 double laser cannon (modified variant)
- **Crew:** 1 pilot
- **Role:**
  - Cargo handler
  - Tug
- **Affiliation:** Corellian Engineering Corporation
