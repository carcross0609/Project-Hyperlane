# Sandonian 4XA Prensile Cruiser

**Continuity:** Legends  
**Source:** [Sandonian 4XA Prensile Cruiser](https://starwars.fandom.com/wiki/Sandonian_4XA_Prensile_Cruiser)

The Sadonian 4XA Prensile Cruiser was a class of starship that was used during the waning years of the Galactic Republic. The merchant Pwi'lin owned a Sadonian Cruiser called the Rindoon Dart.
