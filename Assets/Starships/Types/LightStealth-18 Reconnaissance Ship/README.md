# LightStealth-18 Reconnaissance Ship

**Continuity:** Legends  
**Source:** [LightStealth-18 Reconnaissance Ship](https://starwars.fandom.com/wiki/LightStealth-18_Reconnaissance_Ship)

A carbon-black, six-passenger craft with a needle-like body and, disproportionate, down sloping stabilizers, the LightStealth-18 Reconnaissance Ship (LSR for short) was the closest anyone had come to producing a starship capable of hiding itself even while it was scanning.

## Specifications

- **Name:** LightStealth-18 Reconnaissance Ship
- **Manufacturer:** Kuat Drive Yards
- **Model:** LightStealth-18 Reconnaissance
- **Type:** Starfighter
- **Length:** 18.2 meters
- **Hyperdrive:** Class 1
- **Armament:** 1 forward-mounted laser cannon
- **Passengers:** 6
- **Role:** Reconnaissance
- **Affiliation:**
  - Galactic Empire
  - Imperial Remnant
  - New Republic
