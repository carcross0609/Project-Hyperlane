# PDT-8 personnel transport

**Continuity:** Canon  
**Source:** [PDT-8 personnel transport](https://starwars.fandom.com/wiki/PDT-8_personnel_transport)

The PDT-8 personnel transport was a transport manufactured by Gallofree Yards, Inc.. It was used, along side the GR-75 medium transport, to found the Rebel Alliance's Echo Base on Hoth.

## Specifications

- **Name:** PDT-8 personnel transport
- **Manufacturer:** Gallofree Yards, Inc.
- **Type:** Transport
- **Affiliation:** Alliance to Restore the Republic
