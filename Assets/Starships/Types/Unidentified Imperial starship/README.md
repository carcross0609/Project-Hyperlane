# Unidentified Imperial starship

**Continuity:** Canon  
**Source:** [Unidentified Imperial starship](https://starwars.fandom.com/wiki/Unidentified_Imperial_starship)

This starship model was used by the Galactic Empire. A number of these were stationed on Yavin 4. They resembled the Atmospheric Assault Landers later used by the First Order.
