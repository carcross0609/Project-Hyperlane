# Heavy frigate

**Continuity:** Canon  
**Source:** [Heavy frigate](https://starwars.fandom.com/wiki/Heavy_frigate)

Heavy frigates were a type of starship used by the Paataatus military during the Nikardun campaigns. The Munificent-class star frigate was also identified as the Munificent-class heavy frigate.
