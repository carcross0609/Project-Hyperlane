# D-class Starfarer

**Continuity:** Legends  
**Source:** [D-class Starfarer](https://starwars.fandom.com/wiki/D-class_Starfarer)

The D-class Starfarer was a popular small civilian starship manufactured by Corellian Engineering Corporation. Bail Prestor Organa owned one, in which he and Obi-Wan Kenobi flew to Zigoola.

## Specifications

- **Name:** D-class Starfarer
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** D-class Starfarer
- **Type:** Transport
