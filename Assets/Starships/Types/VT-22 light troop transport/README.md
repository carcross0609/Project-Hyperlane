# VT-22 light troop transport

**Continuity:** Legends  
**Source:** [VT-22 light troop transport](https://starwars.fandom.com/wiki/VT-22_light_troop_transport)

The VT-22 light troop transport was a type of starship manufactured by Vokoff-Strood that was used during the Cold War. The ship possessed a cockpit, four troop deployment bays with four bay doors, and an engine room. It could carry hundreds of people, and ships of this class were used during Independent Operation Sebaddon.

## Specifications

- **Name:** VT-22 light troop transport
- **Manufacturer:** Vokoff-Strood
- **Type:** Transport
- **Engine:** Ion Engines
- **Bays:** 4 Troop Deployment Bays
- **Crew:** 1 Pilot
- **Firstuse:** 3643 BBY
- **Affiliation:** Sith Empire
