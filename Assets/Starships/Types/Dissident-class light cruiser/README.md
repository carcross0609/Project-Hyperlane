# Dissident-class light cruiser

**Continuity:** Canon  
**Source:** [Dissident-class light cruiser](https://starwars.fandom.com/wiki/Dissident-class_light_cruiser)

The Dissident-class light cruiser was a type of warship that served in the First Order Navy by around 31 ABY. In that year, New Republic Commander Poe Dameron encountered a number of First Order starships at a staging point in the OR-Kappa-2722 system, which included a Dissident-class cruiser. Dameron then briefly engaged several First Order TIE fighters before fleeing the system.
