# Alpha-class starfighter

**Continuity:** Canon  
**Source:** [Alpha-class starfighter](https://starwars.fandom.com/wiki/Alpha-class_starfighter)

Alpha-class starfighters, also known as Alpha-3 Jedi starfighters were starfighters used by the Jedi Order during the High Republic Era. During a skirmish during the Eiram and E'ronoh War, Jedi Knight Gella Nattai used one such fighter.
