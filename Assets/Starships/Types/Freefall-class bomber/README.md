# Freefall-class bomber

**Continuity:** Legends  
**Source:** [Freefall-class bomber](https://starwars.fandom.com/wiki/Freefall-class_bomber)

The Freefall-class bomber was designed to serve as a bomber. Jinkins' personal starfighter, the Freefall, was a modified version of this craft.

- **Manufacturer:** Nubian Design Collective
- **Model:** Freefall-class bomber

- **Length:** 30 meters
- **Max Speed:** 1,000 km/h
- **Hyperdrive:** Class 2 (backup class 10)
- **Armament:**

  - 1 bomb chute

- **Crew:**

  - Gunner (1)
  - Navigator (1)
  - Bombardier (1)
- **Passengers:** 10
- **Capacity:** 20 metric tons
- **Consumables:** 4 weeks
- **Availability:** Restricted
- **Role:**
  - Bomber
  - Starfighter
- **Affiliation:** Lok Revenants
