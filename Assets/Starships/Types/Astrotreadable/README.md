# Astrotreadable

**Continuity:** Canon  
**Source:** [Astrotreadable](https://starwars.fandom.com/wiki/Astrotreadable)

An astrotreadable was a type of starship. During the High Republic Era, Jedi Master Kelnacca made a shelter in the wreckage of an ancient astrotreadable on the planet Khofar.
