# Zephyr Light Combat Fighter

**Continuity:** Legends  
**Source:** [Zephyr Light Combat Fighter](https://starwars.fandom.com/wiki/Zephyr_Light_Combat_Fighter)

The Zephyr Light Combat Fighter was a model of starfighter produced by Mestapol. Vohrkrewel Yahrkar owned a Zephyr Light Combat Fighter named the Blood Hawk.

- **Name:** Zephyr Light Combat Fighter
- **Manufacturer:** Mestapol
- **Model:** Zephyr

- **Length:** 50 meters
- **Hyperdrive:** x1

  - Photon torpedo
- **Crew:** 1 pilot
- **Passengers:** 2
- **Capacity:** 300 kilograms
