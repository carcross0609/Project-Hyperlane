# AD-1S Modular Multi-Role Starfighter

**Continuity:** Legends  
**Source:** [AD-1S Modular Multi-Role Starfighter/Legends](https://starwars.fandom.com/wiki/AD-1S_Modular_Multi-Role_Starfighter/Legends)

Koensayr's AD-1S Modular Multi-Role Starfighter was a highly modifiable design which uses a central chassis for the starfighter and equipped with a modular rail system.

- **Name:** AD-1S Modular Multi-Role Starfighter
- **Manufacturer:** Koensayr Manufacturing
- **Model:** AD-1S
- **Type:** Modular Multi-Role Starfighter
- **Cost:** 25,000 credits
- **Hyperdrive:** None
- **Armament:** None
- **Crew:** 1 Pilot
- **Passengers:** 2
- **Consumables:** 1 week
- **Othersystems:** Magnetic modular rail system
- **Role:** Multi-role
