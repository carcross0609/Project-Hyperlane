# Strikeship

**Continuity:** Canon  
**Source:** [Strikeship](https://starwars.fandom.com/wiki/Strikeship)

Strikeships were a class of starfighter-like starship utilized by the marauder group known as the Nihil. They were smaller than the Nihil Cloudships and Stormships.

- **Name:** Strikeship
- **Hdsystem:** Equipped
