# GAT-12g

**Continuity:** Legends  
**Source:** [GAT-12g](https://starwars.fandom.com/wiki/GAT-12g)

The GAT-12g "Skipray" was part of the GAT Blastboat series produced by Sienar Fleet Systems.

## Specifications

- **Name:** GAT-12g
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Defense and patrol blastboat
- **Length:** 25 meters
- **Hyperdrive:** Class 2
- **Shield Gen:** Equipped
- **Navigation:** Equipped (4 jump limit)
- **Armament:**
  - 3 medium ion cannons
  - 1 proton torpedo launcher
  - 2 laser cannons
  - 1 tractor beam
- **Crew:** 2 and 2 gunners
- **Affiliation:** Galactic Empire
