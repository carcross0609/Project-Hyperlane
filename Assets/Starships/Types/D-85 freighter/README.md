# D-85 freighter

**Continuity:** Canon  
**Source:** [D-85 freighter](https://starwars.fandom.com/wiki/D-85_freighter)

The D-85 freighter was a class of freighter that was manufactured by Hyrotii Corporation. One freighter was parked at Zorby's Western Shiplot when Cassian Jeron Andor returned from Morlana One.

## Specifications

- **Name:** D-85 freighter
- **Manufacturer:** Hyrotii Corporation
