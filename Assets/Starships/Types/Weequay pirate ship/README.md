# Weequay pirate ship

**Continuity:** Canon  
**Source:** [Weequay pirate ship](https://starwars.fandom.com/wiki/Weequay_pirate_ship)

The Weequay pirate ship was a type of starship used by Weequay pirates during the Clone Wars. The Marauder was a Weequay pirate ship used as a gladiatorial fighting arena for droids.

## Specifications

- **Name:** Weequay pirate ship
- **Engine:** Six thrusters
- **Armament:** Laser cannons (2)
- **Role:** Transport
- **Affiliation:** Weequay
