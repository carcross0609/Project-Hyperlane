# Star Galleon-class frigate

**Continuity:** Legends  
**Source:** [Star Galleon-class frigate](https://starwars.fandom.com/wiki/Star_Galleon-class_frigate)

The Star Galleon-class frigate was an armed cargo freighter and escort frigate used by the Imperial Navy. The Star Galleon-class was manufactured by Kuat Drive Yards.

## Specifications

- **Name:** Star Galleon-class frigate
- **Manufacturer:** Kuat Drive Yards
- **Model:** Star Galleon-class frigate
- **Type:** Frigate
- **Cost:** 17,503,500 credits
- **Length:** 300 meters
- **Hyperdrive:**
  - Class 2.0
  - Class 15 (backup)
- **Shield Gen:** Rated 320 SBD
- **Hull:** Rated 228 RU
- **Armament:**

  - 1 forward concussion missile launcher
  -   16 heavy concussion missiles
- **Crew:**
  - 130
  - 20 gunners
- **Skeleton:** 50
- **Passengers:** 300 troops
- **Capacity:** 100,000 metric tons
- **Consumables:** 6 months
- **Othersystems:** Hyperdrive-equipped cargo bay
- **Role:** Cargo/escort frigate
- **Affiliation:**
  - Galactic Empire
  - Viraxo Industries
  - Zann Consortium
