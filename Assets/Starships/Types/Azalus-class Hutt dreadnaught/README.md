# Azalus-class Hutt dreadnaught

**Continuity:** Legends  
**Source:** [Azalus-class Hutt dreadnaught](https://starwars.fandom.com/wiki/Azalus-class_Hutt_dreadnaught)

The Azalus-class Hutt dreadnaught was a warship used by the Hutts. One of these vessels was turned into the mobile space station Port Nowhere and served as a gathering point for various criminal activity.
