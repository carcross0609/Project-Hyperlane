# Warlord Dropship

**Continuity:** Legends  
**Source:** [Warlord Dropship](https://starwars.fandom.com/wiki/Warlord_Dropship)

The Warlord Dropship was an Imperial transport used for large ground operations.

## Specifications

- **Name:** Warlord Dropship
- **Manufacturer:** Telgorn Corporation
- **Type:** Dropship
- **Length:** 110 meters
- **Max Speed:**
  - 1,200 KMH (during drop)
  - 800 KMH (return flight)
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Armament:** 6 double turbolaser cannons
- **Crew:** 200
- **Passengers:** 360 (troops)
- **Capacity:** 180 metric tons
- **Consumables:** 3 days
- **Othersystems:** Ablative heatshield
- **Role:** Troop or armor dropship
