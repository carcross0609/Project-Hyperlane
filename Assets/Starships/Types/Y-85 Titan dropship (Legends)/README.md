# Y-85 Titan dropship

**Continuity:** Legends  
**Source:** [Y-85 Titan dropship/Legends](https://starwars.fandom.com/wiki/Y-85_Titan_dropship/Legends)

The Y-85 Titan dropship, colloquially known as the walker dropship, was an important dropship used to deploy AT-ATs, prefabricated garrison bases and AT-STs onto planetary surfaces.

## Specifications

- **Name:** Y-85 Titan dropship
- **Manufacturer:** Incom Corporation
- **Model:** Y-85 Titan dropship
- **Type:** Dropship
- **Armament:** Twin laser cannons (2)
- **Capacity:**
  - All Terrain Armored Transports (4)
  - All Terrain Scout Transports (4)
  - Or
  - Parts for prefabricated garrison
- **Affiliation:**
  - Galactic Empire
  - United Warlord Fleets
