# Katarn-class boarding shuttle

**Continuity:** Legends  
**Source:** [Katarn-class boarding shuttle](https://starwars.fandom.com/wiki/Katarn-class_boarding_shuttle)

The 28 meter-long Katarn-class boarding shuttle was a Rendili StarDrive design made with a nose-end airlock. It could carry up to 50 troops and 500 kilograms of equipment, with a crew requirement of 3 people.

- **Crew:**
