# D-type Stealth Freighter

**Continuity:** Legends  
**Source:** [D-type Stealth Freighter](https://starwars.fandom.com/wiki/D-type_Stealth_Freighter)

The D-Type Stealth Freighter was designed by Nubia Star Drives, Incorporated following the Nubian tradition of designing unusual vessels. Most craft intended for smuggling depended on speed or firepower to avoid capture. The D-type instead relied almost entirely on stealth, carrying no weapons and only managing a low sublight speed due to the baffle shielding drive it was equipped with. Unlike most light freighters, the D-Type was not designed to allow modification of any kind. Instead, if an owner wishes a modified version of the ship, they must commission a customized one from the manufacturer.
