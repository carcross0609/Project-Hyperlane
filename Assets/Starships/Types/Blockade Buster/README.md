# Blockade Buster

**Continuity:** Legends  
**Source:** [Blockade Buster](https://starwars.fandom.com/wiki/Blockade_Buster)

A Blockade Buster was a patrol craft developed by Santhe/Sienar Technologies. They were employed by the native Liann military forces.
