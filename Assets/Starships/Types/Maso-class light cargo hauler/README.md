# Maso-class light cargo hauler

**Continuity:** Legends  
**Source:** [Maso-class light cargo hauler](https://starwars.fandom.com/wiki/Maso-class_light_cargo_hauler)

The Maso-class light cargo hauler was a class of freighter. The Last Legs, a freighter captured by the pirate vessel Harmzuay, was a Maso-class.
