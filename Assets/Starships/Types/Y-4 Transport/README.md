# Y-4 Transport

**Continuity:** Legends  
**Source:** [Y-4 Transport](https://starwars.fandom.com/wiki/Y-4_Transport)

The Y-4 Transport was a military transport manufactured by Incom Corporation. Quite common during the Zsinj campaign, they came to be so synonymous with Zsinj's Raptors that the vessels were called Y-4 Raptors in common conversation.
