# CX Dagger vessel

**Continuity:** Canon  
**Source:** [CX Dagger vessel](https://starwars.fandom.com/wiki/CX_Dagger_vessel)

The CX Dagger vessel was a type of transport used by Clone X troopers part of a deep undercover program within the Galactic Empire's Advanced Science Division during or after 18 BBY. It was dagger-shaped and featured twin red-colored engines in the back. It could be remotely-controlled by a small remote built on the arms of the clone X troopers' armor, with features including providing a long-range communications boost to the assassins. An entry ramp was located on the back underneath the engines for the assassin to disembark the ship. It also possessed a special stealth function that jams the ship from sensors.
