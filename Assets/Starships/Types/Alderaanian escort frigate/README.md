# Alderaanian escort frigate

**Continuity:** Canon  
**Source:** [Alderaanian escort frigate](https://starwars.fandom.com/wiki/Alderaanian_escort_frigate)

The Alderaanian escort frigate was a warship that served in the New Republic Defense Fleet. One known starship was the Sunspire, which was gifted by Princess Leia Organa. Another ship named the Sunspire saw action during the rebellion on Akiva and a skirmish near Wild Space.

## Specifications

- **Name:** Alderaanian escort frigate
- **Type:** Frigate
- **Affiliation:**
  - New Republic
  - Alderaan Flotilla
