# Cord-class starfighter

**Continuity:** Canon  
**Source:** [Cord-class starfighter](https://starwars.fandom.com/wiki/Cord-class_starfighter)

The Cord-class starfighter was a model of fighter craft used by the clone trooper pilots of the Galactic Republic during the pan-galactic Clone Wars against the Confederacy of Independent Systems. They were available to the Republic Starfighter Corps early in the conflict, which started in 22 BBY, alongside other craft like V-19 Torrent starfighters.
