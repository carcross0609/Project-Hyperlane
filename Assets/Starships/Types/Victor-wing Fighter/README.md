# Victor-wing Fighter

**Continuity:** Canon  
**Source:** [Victor-wing Fighter](https://starwars.fandom.com/wiki/Victor-wing_Fighter)

The Victor-wing Fighter was a model of starfighter that was active during the Imperial Era and used by criminal factions. In 1 BBY, several Victor-wing fighters ambushed the smuggling ship Windfall after the freighter stole a shipment of spice from the Hutt Clan. By 3 ABY, Victor-wing Fighters were used by Crimson Dawn in the space around both the moon Toshara and the planet Kijimi. These Victor-wings used the red livery associated with the Dawn.
