# Quasar Fire II-class Cruiser-Carrier

**Continuity:** Canon  
**Source:** [Quasar Fire II-class Cruiser-Carrier](https://starwars.fandom.com/wiki/Quasar_Fire_II-class_Cruiser-Carrier)

The Quasar Fire II-class Cruiser-Carrier was a model of Quasar Fire-class cruiser-carrier used by the Imperial Navy during the Imperial Era. At one point, one such cruiser-carrier flew over a cloudy celestial body, accompanied by TIE/IN interceptors and TIE/d "Defender" Multi-Role Starfighters, while carrying various TIE series starships.
