# Hex Bomber

**Continuity:** Legends  
**Source:** [Hex Bomber](https://starwars.fandom.com/wiki/Hex_Bomber)

The Hex Bomber, also known as a Sabaoth Hex Bomber or a Sabaoth Bomber, was a bomber starfighter used by Sabaoth Squadron of the Confederacy of Independent Systems.

## Specifications

- **Name:** Hex Bomber
- **Type:** Bomber
- **Armament:**
  - Missile launcher (2)
  - Hex bombs
- **Role:** Assault bomber
- **Affiliation:**
  - Confederacy of Independent Systems
  -   Sabaoth Squadron
