# Kazellis-class light freighter

**Continuity:** Legends  
**Source:** [Kazellis-class light freighter](https://starwars.fandom.com/wiki/Kazellis-class_light_freighter)

The Kazellis-class light freighter was a freighter manufactured and produced by the Kazellis Corporation.

- **Name:** Kazellis-class light freighter

- **Type:** Light freighter
- **Cost:** 50,000 credits (23,000 used)
- **Length:** 28 meters
- **Max Speed:** 1000 km/h
- **Hyperdrive:** Class 2 (Backup class 12)
- **Shield Gen:** Equipped

- **Armament:** Quad laser cannons
- **Crew:** Pilot (1)
- **Passengers:** 3
- **Capacity:** 100 tons
- **Consumables:** 2 months
