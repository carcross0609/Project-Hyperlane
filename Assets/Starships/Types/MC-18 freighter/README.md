# MC-18 freighter

**Continuity:** Canon  
**Source:** [MC-18 freighter](https://starwars.fandom.com/wiki/MC-18_freighter)

The MC-18 freighter was a model of freighter used during during the Galactic Civil War. In 3 ABY,, one MC-18 freighter was in-route from Mon Cala to Achra Station. Prior to its arrival a broadcast of the station's speaker system in Huttese announcing the freighter's arrival.
