# RHTT-6 transport

**Continuity:** Legends  
**Source:** [RHTT-6 transport](https://starwars.fandom.com/wiki/RHTT-6_transport)

The RHTT-6 transport was a space troopship designed by Baktoid Armor Workshop. It was the basis of the Zann Consortium's F9-TZ cloaking transport.
