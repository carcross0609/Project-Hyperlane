# TIE fighter boat

**Continuity:** Legends  
**Source:** [TIE fighter boat](https://starwars.fandom.com/wiki/TIE_fighter_boat)

The TIE fighter boat was an aquatic superiority variant of the original TIE/LN starfighter. This specialized TIE fighter had been designed to operate underwater but was able to participate in surface assaults.

## Specifications

- **Name:** TIE fighter boat
- **Model:** Twin Ion Engine fighter boat
- **Type:** Aquatic vessel
- **Speed:** 90 km/h
- **Armament:** 2 laser cannons (fire-linked)
- **Crew:**
  - Pilot (1)
  - Gunner (1)
- **Passengers:** None
- **Affiliation:** Galactic Empire
