# Avandor-class fighter/transport

**Continuity:** Canon  
**Source:** [Avandor-class fighter/transport](https://starwars.fandom.com/wiki/Avandor-class_fighter/transport)

The Avandor-class fighter/transport, also known as the Guavian Ship, was a model of starship that was used by the Guavian Death Gang during the war between the First Order and the Resistance.

## Specifications

- **Name:** Avandor-class fighter/transport
- **Manufacturer:** Incom-FreiTek
- **Model:** Avandor-class
- **Type:** Fighter/transport
- **Engine:** Sublight engines (4)
- **Armament:** At least 3 laser cannons
- **Crew:** Pilot (1)
- **Passengers:**
  - Several Guavian security soldiers
  - Several Kanjiklub members
- **Role:**
  - Scout ship
  - Starfighter
  - Transport
- **Affiliation:**
  - Guavian Death Gang
  - First Order
  - Citizens' Fleet
