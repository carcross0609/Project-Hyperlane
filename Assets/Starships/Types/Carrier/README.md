# Carrier

**Continuity:** Canon  
**Source:** [Carrier](https://starwars.fandom.com/wiki/Carrier)

A carrier was a type of military starship specifically designed to focus on transporting smaller starships. The Quasar Fire-class cruiser-carrier was one type of carrier used by both the Galactic Empire and Phoenix Cell, as was the Imperial escort carrier. This carrier featured two light turbolaser batteries at the forward part of the ship.
