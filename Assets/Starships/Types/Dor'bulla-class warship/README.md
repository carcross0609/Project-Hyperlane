# Dor'bulla-class warship

**Continuity:** Legends  
**Source:** [Dor'bulla-class warship](https://starwars.fandom.com/wiki/Dor%27bulla-class_warship)

The Dor'bulla-class warship was a starship class manufactured by the Hutts during the Galactic Civil War. It was one the rarest warships used by the Hutt Cartel. This ship was produced on Nal Hutta, in the sprawling facilities of the Guarja Shipyards to the south of Bilbousa.
