# Seinar T4D

**Continuity:** Legends  
**Source:** [Seinar T4D](https://starwars.fandom.com/wiki/Seinar_T4D)

Seinar T4D was a civilian Delta-class DX-9 stormtrooper transport that passed an Imperial customs checkpoint. A TIE Interceptor was then launched and the transport was the third to be inspected by the fighter to find workers in the cargo.
