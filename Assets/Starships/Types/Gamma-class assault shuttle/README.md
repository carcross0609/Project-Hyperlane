# Gamma-class assault shuttle

**Continuity:** Canon  
**Source:** [Gamma-class assault shuttle](https://starwars.fandom.com/wiki/Gamma-class_assault_shuttle)

The Gamma-class assault shuttle was a class of shuttle that was used by the Galactic Empire. An Imperial-class Star Destroyer could have at least one such shuttle within its complement.

## Specifications

- **Name:** Gamma-class assault shuttle
- **Model:** Gamma-class
- **Type:** Assault shuttle
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
