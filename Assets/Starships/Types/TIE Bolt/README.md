# TIE Bolt

**Continuity:** Canon  
**Source:** [TIE Bolt](https://starwars.fandom.com/wiki/TIE_Bolt)

The TIE Bolt, also known as the TIE podracer, was a custom-made demo podracer created as a gift for Imperial Admiral Rellen, from Grakkus Jahibakti Tingi. The podracer was stolen by Sebulba following a failed heist at the Hutt colosseum on Nar Shaddaa. Volo Bolus prevented Sebulba from escaping, causing the TIE podracer to crash and be destroyed.

## Specifications

- **Name:** TIE Bolt
- **Designer:** Grakkus's criminal empire
- **Type:** Podracer
- **Crew:** 1 pilot
- **Role:** Podracing
- **Affiliation:**
  - Grakkus's criminal empire
  - Sebulba's crew (stolen)
