# LT-9000 Rendilii Interceptor

**Continuity:** Legends  
**Source:** [LT-9000 Rendilii Interceptor](https://starwars.fandom.com/wiki/LT-9000_Rendilii_Interceptor)

The LT-9000 Rendilii Interceptor was a hyperdrive-equipped starfighter designed and manufactured by Rendili StarDrive. The Chikarri Plako owned one such vessel, named Tasty Acorn.
