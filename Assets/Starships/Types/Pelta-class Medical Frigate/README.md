# Pelta-class Medical Frigate

**Continuity:** Canon  
**Source:** [Pelta-class Medical Frigate](https://starwars.fandom.com/wiki/Pelta-class_Medical_Frigate)

The Pelta-class Medical Frigate was a variant derived from the Pelta-class frigate used by the Republic Navy that was active during the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems. It later served under the Galactic Empire during the Imperial Era.
