# Unidentified frigate class

**Continuity:** Legends  
**Source:** [Unidentified frigate class](https://starwars.fandom.com/wiki/Unidentified_frigate_class)

A bulbous-nosed class of frigates was still in service during the Corellian Crisis, when the Sacorrian Triad modified four frigates into robot ramships and used them to attack the Bakuran fleet.
