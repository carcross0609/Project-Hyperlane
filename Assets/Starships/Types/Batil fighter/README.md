# Batil fighter

**Continuity:** Legends  
**Source:** [Batil fighter](https://starwars.fandom.com/wiki/Batil_fighter)

The Batil fighter was a type of starfighter that was used by the Hutt Empire during the time of the Xim Wars. A number of them were deployed during the First Battle of Vontor.

## Specifications

- **Name:** Batil fighter
- **Type:** Starfighter
- **Role:** Space warfare
- **Affiliation:**
  - Hutt Empire
  - Kossak Inijic Ar'durv
