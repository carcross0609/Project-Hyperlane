# Preybird-class starfighter

**Continuity:** Legends  
**Source:** [Preybird-class starfighter](https://starwars.fandom.com/wiki/Preybird-class_starfighter)

The Preybird-class starfighter was a model of heavy starfighter used by the Imperial Remnant and was designed by SoroSuub and would replace the TIE/LN starfighter due to a loss of production lines.

## Specifications

- **Name:** Preybird-class starfighter
- **Manufacturer:** SoroSuub Corporation
- **Model:** Preybird-class starfighter
- **Type:** Heavy assault starfighter
- **Cost:** 84,000 credits
- **Length:** 21 meters
- **Max Accel:** 13 MGLT/s
- **Mglt:** 100 MGLT
- **Max Speed:** 1,150 km/h
- **Maneuverability:** 86 DPF
- **Hyperdrive:** Class 3.0
- **Shield Gen:** Rated 46 SBD
