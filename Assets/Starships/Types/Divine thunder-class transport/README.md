# Divine thunder-class transport

**Continuity:** Canon  
**Source:** [Divine thunder-class transport](https://starwars.fandom.com/wiki/Divine_thunder-class_transport)

The Divine thunder-class transport was a Transport Starship from the Aakaash system. It was a notably fast ship which could even outmaneuver the governmental forces of the Land & Sky Corporation. Zhang Jincheng kept a ship of this class as an escape vessel in his Hangar on Fire.

## Specifications

- **Name:** Divine thunder-class transport
- **Model:** Divine Thunder
- **Type:** Transport
- **Hyperdrive:** Advanced Hyperdrive
- **Shield Gen:** Powerful Deflector shield
- **Lifesupport:** Equipped
- **Role:** Transport
- **Affiliation:**
  - Zhang Jincheng
  - Land & Sky Corporation
