# Corellian rescue frigate

**Continuity:** Canon  
**Source:** [Corellian rescue frigate](https://starwars.fandom.com/wiki/Corellian_rescue_frigate)

Corellian rescue frigates were a class of disc-hulled frigate that saw use by the Space Rescue Corps of the Galactic Republic around the time of the Clone Wars against the Confederacy of Independent Systems. Along with the nimble Sprint-class rescue craft, the Corellian rescue frigate was a starship model commonly deployed by the rescue corps in order to fulfill larger assignments, while also seeing utilization in locating missing starships and space battle survivors as well as responding to distress calls.

## Specifications

- **Name:** Corellian rescue frigate
- **Type:** Frigate
- **Role:** Rescue craft
- **Affiliation:**
