# Megafreighter

**Continuity:** Legends  
**Source:** [Megafreighter](https://starwars.fandom.com/wiki/Megafreighter)

A Megafreighter was a type of transport vessel designed in the shape of a ring, similar to the Lucrehulk-class battleship. By the Swarm War, this model was considered ancient.

## Specifications

- **Name:** Megafreighter
- **Type:** Freighter
- **Complement:** Dartships
- **Role:** Carrier
- **Affiliation:** The Colony
