# T-65B X-wing starfighter Exterior Variant /2

**Continuity:** Canon  
**Source:** [T-65B X-wing starfighter Exterior Variant /2](https://starwars.fandom.com/wiki/T-65B_X-wing_starfighter_Exterior_Variant_/2)

A T-65B X-wing starfighter design, dubbed Exterior Variant /2, was proposed for Operation Buckler undertook by the Rebel Alliance. The rebels' objective was to steal Y-wing starfighters from the Ord Biniir orbital scrapyard, while posing the Red Squadron X-wings as pirate starfighters in order to avoid the attention of the Galactic Empire. The operation eventually resulted in success. The details of the mission, along with an image of the design, were later included in The Rebel Files.
