# Passenger liner

**Continuity:** Canon  
**Source:** [Passenger liner](https://starwars.fandom.com/wiki/Passenger_liner)

Passenger liners or starliners were starships designed for carrying passengers. Some were present in the Hetzal system during the Great Hyperspace Disaster. Star Liner Travel operated starliner flights including Flight 1020 during the New Republic Era.
