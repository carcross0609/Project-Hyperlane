# YT-2400 light freighter

**Continuity:** Canon  
**Source:** [YT-2400 light freighter](https://starwars.fandom.com/wiki/YT-2400_light_freighter)

The YT-2400 light freighter, also known as the YT-2400 transport, was a class of YT-series light freighter. During the Imperial Era, this model of freighter was widely used by many factions, primarily by cargo haulers and pirates.
