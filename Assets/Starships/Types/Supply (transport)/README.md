# Supply

**Continuity:** Legends  
**Source:** [Supply (transport)](https://starwars.fandom.com/wiki/Supply_%28transport%29)

Supply was an Imperial Delta-class DX-9 stormtrooper transport retrofitted to be a supply ship that would provide starfighters with more warheads should they run out. The ship was present on the Imperial-class Star Destroyer Garrett.

## Specifications

- **Name:** Supply
- **Manufacturer:** Telgorn Corporation
- **Model:** Delta-class DX-9 stormtrooper transport
- **Type:** Transport
- **Length:** 20 meters
- **Width:** 7.8 meters
- **Height:** 5.8 meters
- **Complement:** Warheads
- **Role:** Supply ship
- **Affiliation:** Galactic Empire
