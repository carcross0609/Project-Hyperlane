# Tapani-class assault frigate

**Continuity:** Legends  
**Source:** [Tapani-class assault frigate](https://starwars.fandom.com/wiki/Tapani-class_assault_frigate)

The Tapani-class Assault Frigate was the primary capital ship used in the Tapani sector by both the noble houses and the Freeworlds.

## Specifications

- **Name:** Tapani-class assault frigate
- **Manufacturer:** Tapani Starship Cooperative
- **Type:** Heavy Assault Frigate
- **Cost:** 1.6 billion credits
- **Length:** 750 meters
- **Hyperdrive:**
  - Class 2.0
  - Class 14 (backup)
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Navigation:** Equipped
- **Armament:**
  - 20 laser cannons
  - 15 turbolaser batteries
  - 6 quad turbolaser batteries
- **Crew:** 3,550; 114 gunners
- **Skeleton:** 988
- **Passengers:** 800 troops
- **Capacity:** 12,500 metric tons
- **Consumables:** 1 year
