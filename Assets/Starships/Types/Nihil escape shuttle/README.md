# Nihil escape shuttle

**Continuity:** Canon  
**Source:** [Nihil escape shuttle](https://starwars.fandom.com/wiki/Nihil_escape_shuttle)

The Nihil escape shuttle was a type of shuttle used by the Nihil pirates during the High Republic Era. By 229 BBY, one such shuttle had crashed onto the Outer Rim planet Valo. That year, the aspiring pirate Zyle Keem used one of the shuttles to escape from a Nihil ship. After they arrived on Valo, the shuttle, along with the one which had crashed before, were stripped for parts for an Spiral-class Viz-Core Eviscerator used by the Jedi Padawan Ram Jomaram.
