# Diplomatic barge

**Continuity:** Legends  
**Source:** [Diplomatic barge](https://starwars.fandom.com/wiki/Diplomatic_barge)

A diplomatic barge was a ship used to transport diplomats. Examples include the J-type diplomatic barge used by Padmé Amidala and the Consular-class cruiser used by the Republic to transport Jedi and other ambassadors on various diplomatic missions.
