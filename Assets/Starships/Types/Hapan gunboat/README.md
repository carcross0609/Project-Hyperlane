# Hapan gunboat

**Continuity:** Legends  
**Source:** [Hapan gunboat](https://starwars.fandom.com/wiki/Hapan_gunboat)

The Hapan gunboat was a class of support ship used by the Hapes Consortium. Four gunboats were assigned as part of the complement aboard a Hapan Battle Dragon.

## Specifications

- **Name:** Hapan gunboat
- **Type:** Gunboat
- **Affiliation:** Hapes Consortium
