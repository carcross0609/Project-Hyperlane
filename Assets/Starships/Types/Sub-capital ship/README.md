# Sub-capital ship

**Continuity:** Canon  
**Source:** [Sub-capital ship](https://starwars.fandom.com/wiki/Sub-capital_ship)

Sub-capital ships were a type of small capital ships. The Galactic Empire's Imperial Navy High Command had vessels ranging from sub-capital to capital ships under its control. The Pelta-class frigate was one such ship of this class, as was the Munificent-class Comms Frigate, the Surveyor-class reconnaissance frigate, and cruisers.
