# Geonosian transport

**Continuity:** Legends  
**Source:** [Geonosian transport](https://starwars.fandom.com/wiki/Geonosian_transport)

The Geonosian transport was a model of landing craft donated by the Geonosians to the Confederate Navy during the Clone Wars.

## Specifications

- **Name:** Geonosian transport
- **Manufacturer:** Huppla Pasa Tisc Shipwrights Collective
- **Type:** Landing craft
- **Role:** Troop Transport
- **Affiliation:**
  - Geonosians
  - Confederacy of Independent Systems
