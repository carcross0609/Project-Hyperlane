# Branch-class vehicle

**Continuity:** Canon  
**Source:** [Branch-class vehicle](https://starwars.fandom.com/wiki/Branch-class_vehicle)

The Branch-class vehicle, also known as the Czerka Corporation cruiser, was a class of cruiser used by the Czerka Corporation. The class was long and bulky with a sizable cargo bay, and had a crew of up to 10,000. One such ship was the Leverage, commanded by Meritt Col, which was deployed to Pijal a few years before the Invasion of Naboo.

## Specifications

- **Name:** Branch-class vehicle
- **Type:** Cruiser
- **Bays:** At least 1
- **Affiliation:** Czerka Corporation
