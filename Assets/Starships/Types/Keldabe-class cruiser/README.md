# Keldabe-class cruiser

**Continuity:** Legends  
**Source:** [Keldabe-class cruiser](https://starwars.fandom.com/wiki/Keldabe-class_cruiser)

The Keldabe-class cruiser, also known as the Keldabe-class battleship, was one of several different warship classes utilized by Tyber Zann's faction and others in the Galactic Civil War. At least one vessel of this class was employed by the Mandalorians during the Galactic Civil War.
