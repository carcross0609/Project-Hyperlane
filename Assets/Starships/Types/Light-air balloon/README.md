# Light-air balloon

**Continuity:** Legends  
**Source:** [Light-air balloon](https://starwars.fandom.com/wiki/Light-air_balloon)

The Light-air balloon was a balloon used to transport goods between the moons of Bogden. Some were used during the beginning of the Clone Wars to transport counterfeit credits produced on Bogg 2 to Bogg 9.

## Specifications

- **Name:** Light-air balloon
- **Engine:** None
- **Hyperdrive:** None
