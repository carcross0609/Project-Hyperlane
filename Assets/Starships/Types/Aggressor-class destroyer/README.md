# Aggressor-class destroyer

**Continuity:** Legends  
**Source:** [Aggressor-class destroyer](https://starwars.fandom.com/wiki/Aggressor-class_destroyer)

The Aggressor-class destroyer was one of several different warship classes utilized by Tyber Zann's faction in the Galactic Civil War.

## Specifications

- **Name:** Aggressor-class destroyer
- **Designer:** Galactic Empire
- **Manufacturer:** Zann Consortium
- **Type:** Destroyer
- **Engine:**
  - Main engines (4, centrally mounted)
  - Secondary engines (2 port, 2 starboard)
- **Hdsystem:** Equipped
- **Shield Gen:** Equipped
- **Navigation:** Navigation computer equipped
- **Armament:**
  - Linked ion/plasma cannon
  - Turbolasers
- **Othersystems:** Enhanced self-destruct system
- **Role:**
  - Destroyer
  - Command ship
- **Affiliation:** Zann Consortium
