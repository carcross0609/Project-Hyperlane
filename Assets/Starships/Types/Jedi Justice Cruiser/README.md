# Jedi Justice Cruiser

**Continuity:** Legends  
**Source:** [Jedi Justice Cruiser](https://starwars.fandom.com/wiki/Jedi_Justice_Cruiser)

A Jedi Justice Cruiser was a heavily armed gunboat model used by the Jedi Order.

## Specifications

- **Name:** Jedi Justice Cruiser
- **Manufacturer:** Republic Shipyards
- **Type:** Starfighter
- **Cost:**
  - New: 775,000 credits
  - Used: 525,000
- **Length:** 68 meters
- **Max Speed:** 1,050 km/h
- **Hyperdrive:** Class 1 (backup Class 6)
- **Armament:**
  - Turreted double turbolaser cannon (1)
  - Front-facing ion cannon (1)
  - Front-facing concussion missile launchers (2: 16 missiles each)
- **Crew:** 5
- **Passengers:** 7
- **Capacity:** 100 metric tons
- **Consumables:** 3 months
- **Affiliation:**
  - Jedi Order
  - Galactic Republic
