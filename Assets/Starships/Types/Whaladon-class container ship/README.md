# Whaladon-class container ship

**Continuity:** Legends  
**Source:** [Whaladon-class container ship](https://starwars.fandom.com/wiki/Whaladon-class_container_ship)

The Whaladon-class container ship was a class of large freighter that saw use during the years prior to the Galactic Civil War. Slow and costly, they were used for transporting cargo between systems. They could not land, therefore smaller transports took deliveries to collect and transfer their stock. One such ship was Shandy's Pleasure Palace, which was utilized as a type of portable cantina.
