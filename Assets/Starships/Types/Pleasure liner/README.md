# Pleasure liner

**Continuity:** Canon  
**Source:** [Pleasure liner](https://starwars.fandom.com/wiki/Pleasure_liner)

Pleasure liners were starships during the Imperial Era. RX-48 complained about not getting paid enough by Visler Aqorian Korda III and that he would rather pilot pleasure liners for the Galactic Tourist Bureau.

- **Name:** Pleasure liner
- **Type:** Liner
