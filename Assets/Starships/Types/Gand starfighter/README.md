# Gand starfighter

**Continuity:** Legends  
**Source:** [Gand starfighter](https://starwars.fandom.com/wiki/Gand_starfighter)

The Gand starfighter was a heavily-modified TIE Bomber that was used by the Gand species.

- **Name:** Gand starfighter
- **Manufacturer:** Sienar Fleet Systems
- **Modifier:** Gand
- **Hdsystem:** Equipped
- **Hull:** Titanium alloy hull with quadanium solar panels
- **Armament:**

  - Concussion missile launcher (1)

- **Crew:** Pilot (1)
