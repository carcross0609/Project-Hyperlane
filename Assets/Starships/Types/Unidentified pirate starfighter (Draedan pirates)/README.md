# Unidentified pirate starfighter

**Continuity:** Canon  
**Source:** [Unidentified pirate starfighter (Draedan pirates)](https://starwars.fandom.com/wiki/Unidentified_pirate_starfighter_%28Draedan_pirates%29)

The Draedan pirates used a class of starfighter in the time between 1 ABY and 3 ABY They once fought the Rebel Alliance in the Cilpar system. The arrival of Rogue Squadron saved the CR90 corvette, and they shot down multiple pirate ships.
