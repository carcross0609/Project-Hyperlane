# Belbullab-22 heavy starfighter

**Continuity:** Canon  
**Source:** [Belbullab-22 heavy starfighter](https://starwars.fandom.com/wiki/Belbullab-22_heavy_starfighter)

The Belbullab-22 heavy starfighter was a single-pilot heavy starfighter model manufactured by Feethan Ottraw Scalable Assemblies. It was the heaviest fighter in the Confederacy of Independent Systems naval forces during the Clone Wars against the Galactic Republic and the only fighter crewed by a pilot. General Grievous flew a customized Belbullab-22 named the Soulless One.
