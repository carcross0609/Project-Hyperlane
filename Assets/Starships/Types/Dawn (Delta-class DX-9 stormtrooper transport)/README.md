# Dawn

**Continuity:** Legends  
**Source:** [Dawn (Delta-class DX-9 stormtrooper transport)](https://starwars.fandom.com/wiki/Dawn_%28Delta-class_DX-9_stormtrooper_transport%29)

Dawn was a Delta-class DX-9 stormtrooper transport used by the Rebel Alliance. It was part of an arms deal between the Alliance and the pirates in a cargo loading area located in the Tungra sector. The Imperials learned of this deal and attacked. Maarek Stele inspected the ship to find it containing Rebel advisers. Maarek then destroyed the transport.

## Specifications

- **Name:** Dawn
