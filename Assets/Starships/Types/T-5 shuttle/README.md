# T-5 shuttle

**Continuity:** Canon  
**Source:** [T-5 shuttle](https://starwars.fandom.com/wiki/T-5_shuttle)

The T-5 shuttle was a type of shuttle used by the Jedi Order. It had large semicircle wings which would rotate around the body. They remained horizontal while docked, but in flight, they were vertical to make the cockpit and engines more aerodynamic. It had several seats for passengers in addition to the pilot and copilot's chairs. It was considered not as spacious as a T-6 shuttle.

## Specifications

- **Name:** T-5 shuttle
