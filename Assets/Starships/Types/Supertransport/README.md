# Supertransport

**Continuity:** Legends  
**Source:** [Supertransport](https://starwars.fandom.com/wiki/Supertransport)

Supertransports were a type of transport. During the Galactic Civil War, Hoersch-Kessel Drive, Inc. specialized in building supertransports and container ships.
