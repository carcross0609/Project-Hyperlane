# Capital-class starship

**Continuity:** Legends  
**Source:** [Capital-class starship](https://starwars.fandom.com/wiki/Capital-class_starship)

The Capital-class starship was a starship manufactured by Hoersch-Kessel and Gwori Revolutionary Industries. The ship was shaped with a flat underbelly and elongated pod. Powerful hyperwave transceiver arrays were housed on the lateral wing, which transected the hull of the ship.
