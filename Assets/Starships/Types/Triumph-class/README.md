# Triumph-class

**Continuity:** Legends  
**Source:** [Triumph-class](https://starwars.fandom.com/wiki/Triumph-class)

The Triumph-class was a model of transport used by the Special Forces Division of the Galactic Republic during the Cold War with the reconstituted Sith Empire.

- **Name:** Triumph-class
- **Type:** Transport
- **Hdsystem:** Equipped
- **Armament:** Twin laser cannons (2)
- **Passengers:** 2+
- **Availability:** Military
- **Role:** Troop transport
- **Affiliation:**
