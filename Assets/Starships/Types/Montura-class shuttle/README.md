# Montura-class shuttle

**Continuity:** Canon  
**Source:** [Montura-class shuttle](https://starwars.fandom.com/wiki/Montura-class_shuttle)

The Montura-class shuttle was a model of shuttle used during the era of the Galactic Republic. Its engine pods were known to be sturdy and reliable, and were later fitted to Resistance transports as one of the vessel's numerous aftermarket modifications.

## Specifications

- **Name:** Montura-class shuttle
- **Model:** Montura-class shuttle
- **Type:** Shuttle
- **Engine:** Engine pods
