# Bulk cruiser

**Continuity:** Canon  
**Source:** [Bulk cruiser](https://starwars.fandom.com/wiki/Bulk_cruiser)

A bulk cruiser was a type of cruiser used by the Galactic Empire near the planet Tatooine. The Neutron Star-class bulk cruiser was one starship type under this class, as was the Deep Space Recovery Vessel L-2783.
