# Venture-class cruiser

**Continuity:** Canon  
**Source:** [Venture-class cruiser](https://starwars.fandom.com/wiki/Venture-class_cruiser)

The Venture-class cruiser was a type of cylindrical cruiser and light freighter. The former Jedi Master Cohmac Vitus owned one such starship known as the Excavator during the High Republic Era.
