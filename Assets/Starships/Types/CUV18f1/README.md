# CUV18f1

**Continuity:** Legends  
**Source:** [CUV18f1](https://starwars.fandom.com/wiki/CUV18f1)

Imperial forces used Delta-class DX-9 stormtrooper transport CUV18f1 during the Galactic Civil War. Transport CUV18f1 reloaded warheads for essential TIE starfighters attacking the MC40a light cruiser Warhawk and the Victory-class Star Destroyer Protector at the Treachery at Ottega.
