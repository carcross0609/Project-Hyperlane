# TIE stealth

**Continuity:** Legends  
**Source:** [TIE stealth](https://starwars.fandom.com/wiki/TIE_stealth)

The TIE stealth was a modified TIE/ln starfighter, optimized as an infiltrator and Imperial commando transport, in use by the Second Imperium around 23 ABY.

## Specifications

- **Name:** TIE stealth
- **Manufacturer:** Sienar Fleet Systems
- **Line:** TIE series
- **Model:** Twin Ion Engine stealth starfighter
- **Type:** Starfighter
- **Engine:** Secondary low-emissions twin ion engines
- **Hull:** Sensor-dampening hull coating
- **Crew:**
  - Pilot (1; Typically an Imperial commando)
- **Passengers:** None
- **Othersystems:**
  - Landing gear
- **Role:**
  - Starfighter
  - Infiltrator
- **Affiliation:**
  - Second Imperium
  - Shadow Academy
