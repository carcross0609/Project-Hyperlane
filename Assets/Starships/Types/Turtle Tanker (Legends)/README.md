# Turtle Tanker

**Continuity:** Legends  
**Source:** [Turtle Tanker/Legends](https://starwars.fandom.com/wiki/Turtle_Tanker/Legends)

The Turtle Tanker was a starship used during the Clone Wars. Its enlarged, box-like hull was mostly utilized for storage and transport of medical equipment, rations or other cargo.

## Specifications

- **Name:** Turtle Tanker
- **Type:** Transport/Walker hybrid
- **Length:** 38.2 meters
- **Height:** 26.1 meters
- **Hdsystem:** Equipped
- **Escapepods:** 1
- **Role:** Cargo freighter
