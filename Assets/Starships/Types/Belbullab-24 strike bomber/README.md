# Belbullab-24 strike bomber

**Continuity:** Legends  
**Source:** [Belbullab-24 strike bomber](https://starwars.fandom.com/wiki/Belbullab-24_strike_bomber)

The Belbullab-24 strike bomber, also known as the CIS Strike Bomber, was a bomber variant of the Belbullab-22 starfighter that saw action during the Clone Wars and later. The fighter was equipped with proton bombs and laser cannons.
