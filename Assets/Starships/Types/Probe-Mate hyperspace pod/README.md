# Probe-Mate hyperspace pod

**Continuity:** Legends  
**Source:** [Probe-Mate hyperspace pod](https://starwars.fandom.com/wiki/Probe-Mate_hyperspace_pod)

The Arakyd Industries Probe-Mate hyperspace pod was a streamlined hyperdrive- and sublight drive-equipped pod used to transport Viper probe droids through hyperspace.

## Specifications

- **Name:** Probe-Mate hyperspace pod
- **Manufacturer:** Arakyd Industries
- **Type:** Hyperdrive pod
- **Cost:** 22,500 credits
- **Length:** 3.4&ndash;3.5 meters
- **Max Speed:** 1,200 kmh
- **Hyperdrive:** Class 1
- **Navigation:** Equipped, limited to 1 jump
- **Avionics:** Droid brain
- **Consumables:** 1 month
- **Affiliation:** Galactic Empire
