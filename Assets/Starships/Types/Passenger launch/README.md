# Passenger launch

**Continuity:** Legends  
**Source:** [Passenger launch](https://starwars.fandom.com/wiki/Passenger_launch)

Passenger launches were starships. They were used by the Gree to shuttle passengers between the Rokak'k Baran and the planets of the Gree Enclave.
