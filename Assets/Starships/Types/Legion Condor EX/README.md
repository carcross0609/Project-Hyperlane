# Legion Condor EX

**Continuity:** Legends  
**Source:** [Legion Condor EX](https://starwars.fandom.com/wiki/Legion_Condor_EX)

The Legion Condor EX was a starship model that was in use around the Galactic Civil War. It was capable of hyperspace travel and was popular with starship renters.
