# Roc-class starfighter

**Continuity:** Canon  
**Source:** [Roc-class starfighter](https://starwars.fandom.com/wiki/Roc-class_starfighter)

Roc-class starfighter was a two-winged starfighter used by the First Order. The craft had multiple laser cannons mounted on its wings and a single missile launcher attached beneath it.

- **Name:** Roc-class starfighter
- **Type:** Starfighter
