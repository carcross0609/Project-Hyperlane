# Kihraxz Light Starfighter

**Continuity:** Canon  
**Source:** [Kihraxz Light Starfighter](https://starwars.fandom.com/wiki/Kihraxz_Light_Starfighter)

The Kihraxz Light Starfighter was a model of starfighter that was commissioned by the Black Sun criminal organization and shared its name with the Kihraxz Heavy Fighter. Some of the light fighters were used by the Rebel Alliance Intelligence Service. In order to increase performance, the manufacturer offered a modification package after some time.
