# Imperial Dreadnought

**Continuity:** Unknown  
**Source:** [Imperial Dreadnought](https://starwars.fandom.com/wiki/Imperial_Dreadnought)

An Imperial Dreadnought, also called a Jedi Dreadnought, was a class of capital ship used by lords of the Empire. The flagship of the Jedi lord Hanrai was an Imperial Dreadnought named the Reverent.

## Specifications

- **Name:** Imperial Dreadnought
- **Affiliation:**
  - The Empire
  - Jedi clans
