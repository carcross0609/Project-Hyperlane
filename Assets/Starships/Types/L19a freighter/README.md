# L19a freighter

**Continuity:** Legends  
**Source:** [L19a freighter](https://starwars.fandom.com/wiki/L19a_freighter)

The L19a was a freighter produced by Surron StarTech. It was the initial production run of the Surronian L19 heavy freighter and was much more luxurious than the standard L19. It had a limited production run as was highly desirable. This meant prices for a genuine L19a could be four times the amount of a L19.

## Specifications

- **Name:** L19a freighter
- **Manufacturer:** Surron StarTech
- **Model:** L19a
- **Type:** Freighter
