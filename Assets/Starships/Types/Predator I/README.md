# Predator I

**Continuity:** Legends  
**Source:** [Predator I](https://starwars.fandom.com/wiki/Predator_I)

The Arakyd Industries Predator I was a streamlined hyperdrive and sublight drive-equipped pod used to transport Viper probe droids through hyperspace.

## Specifications

- **Name:** Predator I
- **Manufacturer:** Arakyd Industries
- **Type:** Hyperdrive pod
- **Length:** 4 meters
- **Max Speed:** 750 kmh
- **Hyperdrive:** Class 2
- **Shield Gen:** Equipped
- **Crew:** 1 Viper probe droid
- **Affiliation:** Galactic Empire
