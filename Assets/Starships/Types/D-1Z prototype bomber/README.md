# D-1Z prototype bomber

**Continuity:** Legends  
**Source:** [D-1Z prototype bomber](https://starwars.fandom.com/wiki/D-1Z_prototype_bomber)

The D-1Z prototype bomber was a prototype variant of the B28 Extinction-class bomber developed by the Sith Empire which was taken for a test flight during the Battle above Lorta.

## Specifications

- **Name:** D-1Z prototype bomber
- **Manufacturer:** Sith Empire
- **Model:** Modified B28 Extinction-class bomber
- **Type:** Bomber
- **Affiliation:** Sith Empire
