# System Patroller

**Continuity:** Legends  
**Source:** [System Patroller](https://starwars.fandom.com/wiki/System_Patroller)

The System Patroller was the standard patrol craft used by the Lant Mining Corporation's Security Patrol. The design of the vessel was a modified IPV-1 System Patrol Craft manufactured by Sienar Fleet Systems.

## Specifications

- **Name:** System Patroller
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Modified IPV-1 System Patrol Craft
- **Length:** 120 meters
- **Max Speed:** 1,000 kmh
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Armament:** 4 turbolaser cannons
- **Crew:** 12; 8 gunners
- **Skeleton:** 5
- **Passengers:** 10 (troops)
- **Capacity:** 200 metric tons
- **Consumables:** 3 months
- **Role:** System patrol
- **Affiliation:** Lant Mining Corporation
