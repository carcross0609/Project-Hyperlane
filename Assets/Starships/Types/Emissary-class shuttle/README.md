# Emissary-class shuttle

**Continuity:** Legends  
**Source:** [Emissary-class shuttle](https://starwars.fandom.com/wiki/Emissary-class_shuttle)

The Emissary-class shuttle was a diplomatic shuttle type used after the Seventh Battle of Ruusan. Emissary-class shuttles were hyperdrive-equipped shuttles used by the Galactic Republic. They were referred to as serviceable, but far from luxurious, like the Theta-class shuttle. The New Dawn, a shuttle owned by Chancellor Tarsus Valorum, was an Emissary-class shuttle.

## Specifications

- **Name:** Emissary-class shuttle
- **Hyperdrive:** Class 6.0
- **Crew:** 2
- **Passengers:** 6
- **Role:** Transport
- **Affiliation:** Galactic Republic
