# Thranta-class War Cruiser

**Continuity:** Legends  
**Source:** [Thranta-class War Cruiser](https://starwars.fandom.com/wiki/Thranta-class_War_Cruiser)

The Thranta-class War Cruiser was one of the last starship classes manufactured by Alderaan.

## Specifications

- **Name:** Thranta-class War Cruiser
- **Type:** Light cruiser
- **Length:** Around 350 meters
- **Hyperdrive:** Equipped
- **Shield Gen:** Equipped
- **Armament:**
  - Five heavy turbolasers
  - Ten laser cannons
- **Role:**
  - Warship
  - Escort
