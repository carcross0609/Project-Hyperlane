# Starcat-class Freighter

**Continuity:** Legends  
**Source:** [Starcat-class Freighter](https://starwars.fandom.com/wiki/Starcat-class_Freighter)

The Starcat-class Freighter was a custom designed starship model built by Salem Victory and Dapp Solus. The Starcat was the only known vessel of the class.
