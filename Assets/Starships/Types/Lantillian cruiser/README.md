# Lantillian cruiser

**Continuity:** Legends  
**Source:** [Lantillian cruiser](https://starwars.fandom.com/wiki/Lantillian_cruiser)

The Lantillian cruiser was an armored space vessel smaller than a Predator-class gunship. The Kintan Gunrunners operated one.
