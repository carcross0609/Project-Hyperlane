# E-wing: Type B

**Continuity:** Legends  
**Source:** [E-wing: Type B](https://starwars.fandom.com/wiki/E-wing%3A_Type_B)

The E-Wing: Type B was a modified version of the base E-wing escort starfighter manufactured by FreiTek Incorporated. Due to the initial designs of the E-wing relying on synthetically spin-sealed Tibanna gas to power the laser cannons, the starfighters' weapon system were found to be underpowered. The gas broke down too quickly, reducing the effective range of the E-wing's weapons.

## Specifications
