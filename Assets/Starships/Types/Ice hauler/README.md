# Ice hauler

**Continuity:** Canon  
**Source:** [Ice hauler](https://starwars.fandom.com/wiki/Ice_hauler)

An ice hauler was a type of starship active during the High Republic Era. In 382 BBY, members of the Thylefire Squadron were selected for a mission to escort an ice hauler to the planet E'ronoh's capital, The Rook, so it could distribute ice.
