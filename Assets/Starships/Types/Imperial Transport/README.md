# Imperial Transport

**Continuity:** Unknown  
**Source:** [Imperial Transport](https://starwars.fandom.com/wiki/Imperial_Transport)

The Imperial Transport was a class of transport vessel used by the Galactic Empire on Tao. It was larger than an Imperial Gozanti-class cruiser and a BFF-1 bulk freighter.

## Specifications

- **Name:** Imperial Transport
- **Type:** Transport
- **Role:** Cargo transportation
- **Affiliation:** Galactic Empire
