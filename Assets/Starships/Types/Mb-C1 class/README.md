# Mb-C1 class

**Continuity:** Canon  
**Source:** [Mb-C1 class](https://starwars.fandom.com/wiki/Mb-C1_class)

The MB-C1 class, also known as the MB-C1 Medium Cargo Hauler, was a cargo heavy transport made by Mobquet Swoops and Speeders during the time of the Galactic Civil War. It was of similar size to the Xiytiar transport.

## Specifications

- **Name:** Mb-C1 class
- **Manufacturer:** Mobquet Swoops and Speeders
- **Model:** Mb-C1
- **Type:** Heavy transport
- **Role:** Cargo hauler
