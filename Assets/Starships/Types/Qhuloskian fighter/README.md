# Qhuloskian fighter

**Continuity:** Canon  
**Source:** [Qhuloskian fighter](https://starwars.fandom.com/wiki/Qhuloskian_fighter)

The Qhuloskian fighter was a type of attack craft used in the mission on Qhulosk by the native Qhuloskians. It had six wings and was a pale green color. Several of them attacked Beilert Valance and shot down his TIE/ln space superiority starfighter.

## Specifications

- **Name:** Qhuloskian fighter
- **Role:** Anti-starfighter attack
