# IL-5 Ocula

**Continuity:** Legends  
**Source:** [IL-5 Ocula](https://starwars.fandom.com/wiki/IL-5_Ocula)

The IL-5 Ocula, also known to the Galactic Republic as the IL-5 Skybolt, was a starfighter produced by Czerka Corporation. Czerka's first entry into the scout starfighter field, the craft was well-known for its proprietary miniaturization techniques that allowed for almost all popular internal components to be installed.
