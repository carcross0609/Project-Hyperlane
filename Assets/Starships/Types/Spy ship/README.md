# Spy ship

**Continuity:** Canon  
**Source:** [Spy ship](https://starwars.fandom.com/wiki/Spy_ship)

A Spy ship was a type of ship used for spying. The ship 090192 was a spy ship used by the Separatist Alliance T-series tactical droid TX-532.
