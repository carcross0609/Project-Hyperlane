# Goat (Delta-class DX-9 stormtrooper transport)

**Continuity:** Legends  
**Source:** [Goat (Delta-class DX-9 stormtrooper transport)](https://starwars.fandom.com/wiki/Goat_%28Delta-class_DX-9_stormtrooper_transport%29)

Goat was the name of a group of two Rebel Delta-class DX-9 stormtrooper transports that carried Rebel engineers and workers away from Yavin 4. The Red Squadron oversaw their exit from the Imperial blockade.
