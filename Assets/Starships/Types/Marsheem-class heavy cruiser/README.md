# Marsheem-class heavy cruiser

**Continuity:** Canon  
**Source:** [Marsheem-class heavy cruiser](https://starwars.fandom.com/wiki/Marsheem-class_heavy_cruiser)

The Marsheem-class heavy cruiser was a class of warship that was used by the Ishi Tib of Tibrin during the Galactic Civil War. At least three cruisers participated in a skirmish above Tibrin after the Ishi Tib allied themselves with the Rebel Alliance.
