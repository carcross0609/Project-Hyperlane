# Alpha-class Xg-1 Star Wing

**Continuity:** Legends  
**Source:** [Alpha-class Xg-1 Star Wing/Legends](https://starwars.fandom.com/wiki/Alpha-class_Xg-1_Star_Wing/Legends)

The Cygnus Spaceworks Alpha-class Xg-1 Star Wing, also known as the Xg-1 Starwing or Assault Gunboat, was one of the Galactic Empire's first general-deployment starfighters to be equipped with deflector shields and a hyperdrive.
