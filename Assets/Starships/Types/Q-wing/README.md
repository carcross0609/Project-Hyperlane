# Q-wing

**Continuity:** Unknown  
**Source:** [Q-wing](https://starwars.fandom.com/wiki/Q-wing)

The Q-wing was a predecessor of the Rebel Alliance's BTL-A4 Y-wing assault starfighter/bomber. The latter starfighter bomber craft was significantly more aerodynamic than the Q-wing model, which was swiftly abandoned.
