# Victrix

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Victrix](https://starwars.fandom.com/wiki/Victrix)

The Victrix was a Star Destroyer serving the Galactic Empire during the Galactic Civil War. It was deployed to the planet Demophon to assist in the evacuation of the planet prior to the Demophon supernova.
