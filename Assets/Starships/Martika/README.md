# Martika

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Martika](https://starwars.fandom.com/wiki/Martika)

Martika was a cargo starship which ran shipping jobs from the planet Alderaan. When Brock Lar came to the planet, he managed to become the first mate of this ship.
