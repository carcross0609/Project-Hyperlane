# Finalizer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Finalizer](https://starwars.fandom.com/wiki/Finalizer)

The Finalizer was a Resurgent-class Star Destroyer of the naval forces of the First Order. It served as the flagship of General Armitage Hux and Kylo Ren.
