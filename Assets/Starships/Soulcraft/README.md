# Soulcraft

**Continuity:** Canon  
**Source:** [Soulcraft](https://starwars.fandom.com/wiki/Soulcraft)

Soulcraft were spherical starships used by the early settlers of the planet Pijal. At some point in Pijal's history, the local form of Force worship urged pilgrims to travel into space using the soulcraft.
