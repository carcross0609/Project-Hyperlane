# Doombringer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Doombringer](https://starwars.fandom.com/wiki/Doombringer)

The Doombringer was a Harrower-class dreadnought equipped with the Silencer, a superlaser capable of destroying an entire fleet. During the Cold War it was Moff Valion Pyron's flagship and became part of Darth Nox's fleet.

## Specifications

- **Name:** Doombringer
- **Model:** Harrower-class dreadnought
- **Type:**

  - Dreadnaught
- **Hdsystem:** Equipped
- **Armament:** ca. 39-43 Turbolaser cannon turrets, 1 Silencer Superlaser
- **Complement:** Mark VI Supremacy-class starfighters
- **Affiliation:** Sith Empire
