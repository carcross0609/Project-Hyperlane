# Barker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Barker](https://starwars.fandom.com/wiki/Barker)

Barker was a Nebulon-B2 frigate belonging to the Rebel Alliance. It was supposed to rendezvous with the Rebel Fleet at Sullust, but was destroyed by Maarek Stele.

- **Model:** Nebulon-B2 frigate
- **Type:** Frigate
