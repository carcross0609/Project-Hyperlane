# Plain Lady

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Plain Lady](https://starwars.fandom.com/wiki/Plain_Lady)

The Plain Lady was a starliner in use in 44 ABY. In that year, the Jedi Valin Horn and Jysella Horn went undercover aboard the EconoClass starliner to the Galactic Center Spaceport to infiltrate the planet Coruscant in order to liberate the world from the Lost Tribe of Sith.
