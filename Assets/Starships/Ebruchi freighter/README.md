# Ebruchi freighter

**Continuity:** Legends  
**Source:** [Ebruchi freighter](https://starwars.fandom.com/wiki/Ebruchi_freighter)

The Ebruchi freighter was a type of attack craft used by the Ebruchi Pirates. The light freighter was often heavily modified with nonstandard weapons welded to the ship's hull. The vessel typically traveled in flotillas consisting of up to a dozen of these ships being led by an Ebruchi command ship.

## Specifications

- **Name:** Ebruchi freighter
- **Type:** Light freighter
- **Engine:** Gas-drive landing jets
- **Shield Gen:** Equipped
- **Armament:**
  - Torpedo launchers (add-on)
  - Net traps (add-on)
  - Solid-projectile cannons (add-on)
  - Magnetic grapples
- **Role:**
  - Attack craft
  - Planetary base
- **Affiliation:** Unidentified Ebruchi clan
