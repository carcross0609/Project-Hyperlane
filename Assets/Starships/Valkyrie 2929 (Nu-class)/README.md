# Valkyrie 2929

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Valkyrie 2929 (Nu-class)](https://starwars.fandom.com/wiki/Valkyrie_2929_%28Nu-class%29)

Valkyrie 2929 was the callsign of a Nu-class attack/transport shuttle used to bring Obi-Wan Kenobi, Anakin Skywalker, Ahsoka Tano and Rex to meet the rebels on Onderon during the Clone Wars.

- **Model:** Nu-class attack/transport shuttle

- **Role:** Transport
