# YT-1930 transport

**Continuity:** Legends  
**Source:** [YT-1930 transport/Legends](https://starwars.fandom.com/wiki/YT-1930_transport/Legends)

The YT-1930 was a moderately successful YT-series light freighter that was released by the Corellian Engineering Corporation shortly before the Battle of Yavin.
