# Aerie

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Aerie](https://starwars.fandom.com/wiki/Aerie)

The Aerie was a Quasar Fire-class cruiser-carrier used by the Galactic Empire's 204th Imperial Fighter Wing. It pursued and destroyed the New Republic frigate Hellion's Dare.
