# Guillotine

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Guillotine (starship)](https://starwars.fandom.com/wiki/Guillotine_%28starship%29)

The Guillotine was the personal starship used by the Kyuzo bounty hunter Embo during the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems.

## Specifications

- **Name:** Guillotine
- **Armament:**
  - Laser cannons
  - Laser turret
- **Affiliation:** Krayt's Claw
