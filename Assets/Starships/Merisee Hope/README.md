# Merisee Hope

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Merisee Hope](https://starwars.fandom.com/wiki/Merisee_Hope)

The starship Merisee Hope was a known slave-runner for one of the brothels on the edge of Invisec on the planet Coruscant. The Pulsar Skate later used that ship's name as an alias during the insertion of several Rogue Squadron members into Coruscant.
