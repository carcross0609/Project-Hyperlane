# Pulsar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pulsar (Lancer-class)](https://starwars.fandom.com/wiki/Pulsar_%28Lancer-class%29)

The Pulsar was a Lancer-class frigate in Moff Kentor Sarne's forces around 8 ABY. Along with three Skipray Blastboats, it engaged the FarStar shortly after the New Republic corvette had left the planet Binaros.

## Specifications

- **Name:** Pulsar
- **Manufacturer:** Kuat Drive Yards
- **Model:** Lancer-class frigate
- **Type:** Frigate
- **Length:** 250 meters
- **Width:** 57 meters
- **Height:** 60 meters
- **Affiliation:**

  -   Kentor Sarne
