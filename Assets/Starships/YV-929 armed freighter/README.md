# YV-929 armed freighter

**Continuity:** Legends  
**Source:** [YV-929 armed freighter](https://starwars.fandom.com/wiki/YV-929_armed_freighter)

The YV-929 armed freighter was a 22-meter-long light freighter produced by Corellian Engineering Corporation. It used the same forward cockpit structure as the much larger YV-100 light freighter.
