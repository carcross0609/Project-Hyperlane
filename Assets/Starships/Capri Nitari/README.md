# Capri Nitari

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Capri Nitari](https://starwars.fandom.com/wiki/Capri_Nitari)

The Capri Nitari was a smuggling ship owned by Captain Scarlet Bloodhawk. It was known to have made the Kessel Run at least once, and made many stops at the planet Mandrine.
