# Himner

**Continuity:** Legends  
**Source:** [Himner](https://starwars.fandom.com/wiki/Himner)

The Himner was a pair of Delta-class DX-9 stormtrooper transports that were part of Admiral Harkov Admiral Harkov's fleet that defected to the Rebel Alliance the transports attempted to attack the Interdictor Harpax. Both were destroyed in the battle.
