# Atlas

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Atlas](https://starwars.fandom.com/wiki/Atlas)

Atlas group was a group of Heavy Lifter transports dedicated solely to the Rebel Alliance. They were primarily used to pick up captured Imperial cargo. At one point it was responsible for stealing new fighters from the new TIE Experimental Project.
