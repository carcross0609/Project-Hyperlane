# Barderia

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Barderia](https://starwars.fandom.com/wiki/Barderia)

The Barderia was a Corellian freighter owned by Captain Rhanken. It was roughly 100 meters long and boxy. The captain worked a route of several systems in the Quelii sector, which included the Halmad system.

## Specifications

- **Name:** Barderia
- **Type:** Freighter
- **Length:** c. 100 meters
- **Owners:** Captain Rhanken
- **Captains:** Rhanken
