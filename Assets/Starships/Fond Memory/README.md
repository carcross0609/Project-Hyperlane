# Fond Memory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fond Memory](https://starwars.fandom.com/wiki/Fond_Memory)

The Fond Memory was a Lambda-class T-4a shuttle in the service of the New Republic around 25 ABY. Several months after the Battle of Helska IV it ferried Leia Organa Solo and Elegos A'Kla from Coruscant to Agamar and Dubrillion.
