# MC30a light cruiser

**Continuity:** Legends  
**Source:** [MC30a light cruiser](https://starwars.fandom.com/wiki/MC30a_light_cruiser)

The MC30a light cruiser was a class of light cruiser produced at the Krinemonen III shipyards. It was based off of stolen designs for the Strike-class medium cruiser, produced by Loronar Corporation.

## Specifications

- **Name:** MC30a light cruiser
- **Manufacturer:** Krinemonen III shipyards
- **Model:** MC30a light cruiser; based on the Strike-class medium cruiser
- **Type:** Light cruiser
