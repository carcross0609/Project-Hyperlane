# Garth Ezzar's Sith Infiltrator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Garth Ezzar's Sith Infiltrator](https://starwars.fandom.com/wiki/Garth_Ezzar%27s_Sith_Infiltrator)

Garth Ezzar's Sith Infiltrator was a custom-made Star Courier that was built by Republic Sienar Systems for the Dark Jedi Garth Ezzar. It resembled a similar craft, the Scimitar, that was built by RSS for Darth Maul and was possibly of the same design. However, unlike that craft, it had no cloaking technology. Ezzar used it in the Destruction of the Almas Academy, when he attacked the Almas Academy. He then flew it to Coruscant afterwards.
