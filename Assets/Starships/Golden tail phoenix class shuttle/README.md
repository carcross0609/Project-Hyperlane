# Golden tail phoenix class shuttle

**Continuity:** Canon  
**Source:** [Golden tail phoenix class shuttle](https://starwars.fandom.com/wiki/Golden_tail_phoenix_class_shuttle)

The Golden tail phoenix class shuttle was an expensive, winged luxury Shuttle used by the elite of the Aakaash system. The burn of the shuttle's engines was said to resemble a golden tail. The Nan family used a beautiful white shuttle of this type.

## Specifications

- **Name:** Golden tail phoenix class shuttle
- **Model:** Golden Tail Phoenix
- **Type:** Shuttle
- **Lifesupport:** Equipped
- **Role:** Transport
- **Affiliation:**
