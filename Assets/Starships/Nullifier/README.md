# Nullifier

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nullifier](https://starwars.fandom.com/wiki/Nullifier)

The Nullifier was an Imperial I-class Star Destroyer of the Imperial Navy. In 0 ABY, the Nullifier was present above Corulag soon before the events of the skirmish on Corulag.

## Specifications

- **Name:** Nullifier
- **Model:** Imperial I-class Star Destroyer
- **Type:** Star Destroyer
