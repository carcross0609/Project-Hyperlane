# Crix-class diplomatic courier shuttle

**Continuity:** Legends  
**Source:** [Crix-class diplomatic courier shuttle](https://starwars.fandom.com/wiki/Crix-class_diplomatic_courier_shuttle)

The Crix-class diplomatic courier shuttle, also designated as DC-4a, was a diplomatic shuttle used by the Galactic Alliance and later by the Galactic Alliance Core Fleet.

- **Name:** Crix-class diplomatic courier shuttle
- **Manufacturer:**
  - Corellian Engineering Corporation
  - Mon Calamari Shipyards
- **Model:** Crix-class diplomatic courier shuttle
- **Type:** Shuttle
- **Cost:** 500,000 credits (200,000 used)
- **Max Speed:** 850 km/h
- **Hyperdrive:** Class 1 (backup class 10)
- **Shield Gen:** Equipped
- **Sensor:** Long-range communication sensors
- **Navigation:** Navicomputer
- **Armament:**
  - Twin laser cannons
  - Blaster cannon battery
- **Crew:** 5
- **Passengers:** 30
- **Capacity:** 50 tons
- **Consumables:** 2 months
- **Availability:** Military
- **Role:** Diplomatic courier
- **Affiliation:**
  - Galactic Federation of Free Alliances
  - Galactic Alliance Remnant
