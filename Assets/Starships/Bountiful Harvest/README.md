# Bountiful Harvest

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Bountiful Harvest](https://starwars.fandom.com/wiki/Bountiful_Harvest)

The Bountiful Harvest was a Great camel-head class cargo ship in the Aakaash system. Its Captain and crew were regularly employed by the Land & Sky Corporation, making runs between the planets Wind and Land. It crash-landed on the space station Fire.
