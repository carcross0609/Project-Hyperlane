# Lsumu

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lsumu](https://starwars.fandom.com/wiki/Lsumu)

The Lsumu was a Rebel Alliance Carrack-class light cruiser that was originally going to rendezvous with the Rebel Fleet at Sullust but was destroyed by Tan Maarek Stele in a Missile Boat.
