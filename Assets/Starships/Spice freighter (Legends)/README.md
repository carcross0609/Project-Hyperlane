# Spice freighter

**Continuity:** Legends  
**Source:** [Spice freighter/Legends](https://starwars.fandom.com/wiki/Spice_freighter/Legends)

A spice freighter was any transport used to transport spice. Owen Lars lied to young Luke Skywalker, claiming Anakin Skywalker had been a spice freighter navigator. This did hold a kernel of truth, as Anakin had navigated the Twilight, a spice freighter, a number of times during the Clone Wars. During the Clone Wars, the Wayfarer, a vessel operated by Zygerrian deserters led by Colonel M'rch, claimed to be a spice freighter to raid the Galactic Republic Pelta-class frigate Medica. Before joining the Rebel Alliance, Mishowan Shigormallan served as a cargo handler aboard a spice freighter.
