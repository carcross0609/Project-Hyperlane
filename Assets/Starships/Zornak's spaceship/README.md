# Zornak's spaceship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Zornak's spaceship](https://starwars.fandom.com/wiki/Zornak%27s_spaceship)

Zornak's spaceship was the vessel in which Zornak and his crew traveled to the forest moon of Endor. It had many advanced technological features, including a transport chamber.
