# Senate-class transport

**Continuity:** Legends  
**Source:** [Senate-class transport](https://starwars.fandom.com/wiki/Senate-class_transport)

Senate-class transports was a multi-purpose transport used by senators of the Galactic Republic shortly before the Clone Wars. One such transport was also used to carry Jedi Obi-Wan Kenobi and Anakin Skywalker to a transfer dock in the orbit of Coruscant, where they boarded the starship Star Sea Flower.
