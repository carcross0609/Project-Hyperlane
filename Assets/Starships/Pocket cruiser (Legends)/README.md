# Pocket cruiser

**Continuity:** Legends  
**Source:** [Pocket cruiser/Legends](https://starwars.fandom.com/wiki/Pocket_cruiser/Legends)

A pocket cruiser was a type of starship. It entered service near the end of the Clone Wars, and was considered obsolete by the time of the Galactic Civil War.
