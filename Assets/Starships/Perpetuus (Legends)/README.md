# Perpetuus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Perpetuus/Legends](https://starwars.fandom.com/wiki/Perpetuus/Legends)

Perpetuus was an 80 meter-long CSS-1 Corellian Star Shuttle which brought the newly-elected Supreme Chancellor Palpatine to Naboo following the end of the Trade Federation invasion in 32 BBY.

## Specifications

- **Name:** Perpetuus
- **Model:** CSS-1 Corellian Star Shuttle
- **Type:** Transport
- **Length:** 80 meters
- **Affiliation:** Galactic Republic
