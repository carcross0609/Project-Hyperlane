# Bandit 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bandit 1](https://starwars.fandom.com/wiki/Bandit_1)

Bandit 1 was a Z-95 Headhunter in the Alliance to Restore the Republic's Bandit Squadron. During the Galactic Civil War it served as Ace Azzameen's personal Z-95.
