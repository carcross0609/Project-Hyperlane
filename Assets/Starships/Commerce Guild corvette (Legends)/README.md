# Commerce Guild corvette

**Continuity:** Legends  
**Source:** [Commerce Guild corvette/Legends](https://starwars.fandom.com/wiki/Commerce_Guild_corvette/Legends)

The Commerce Guild corvette was a type of corvette used by the Commerce Guild. Alongside Commerce Guild fleet patrol craft, these corvettes were employed by the Escarte Guard to defend the Commerce Guild's Escarte asteroid mining facility during the Clone Wars.

## Specifications

- **Name:** Commerce Guild corvette
- **Type:** Corvette
- **Armament:** Turbolaser batteries
- **Affiliation:**
  - Commerce Guild
  -   Escarte Guard
