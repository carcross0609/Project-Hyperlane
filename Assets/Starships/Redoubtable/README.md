# Redoubtable

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Redoubtable](https://starwars.fandom.com/wiki/Redoubtable)

Redoubtable was an early-model Imperial I-class Star Destroyer. It was later renamed the Destiny of Yevetha.

## Specifications

- **Name:** Redoubtable
- **Manufacturer:** Kuat Drive Yards
- **Type:** Imperial I-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/LN starfighters
- **Affiliation:**
  - Galactic Empire
  - Duskhan League
- **Navy:** Imperial Navy
- **Aliases:** Destiny of Yevetha
