# Krakana

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Krakana (Viscount-class)](https://starwars.fandom.com/wiki/Krakana_%28Viscount-class%29)

The Krakana was a Viscount-class Star Defender that was used by the New Republic Defense Fleet during the Yuuzhan Vong War. In 27 ABY, the Krakana was ordered to travel to the planet Kuat, where the New Republic intended to use it as an orbital artillery battery. However, the vessel was destroyed by the Yuuzhan Vong while en-route to Kuat.
