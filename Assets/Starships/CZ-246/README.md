# CZ-246

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [CZ-246](https://starwars.fandom.com/wiki/CZ-246)

CZ-246 was a Lambda-class T-4a shuttle that belonged to the Galactic Empire. It was destroyed shortly after the Battle of Yavin, when it was attacked by pirates.
