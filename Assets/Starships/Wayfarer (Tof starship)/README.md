# Wayfarer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wayfarer (Tof starship)](https://starwars.fandom.com/wiki/Wayfarer_%28Tof_starship%29)

The Wayfarer was a large boat-shaped star cruiser, commanded by Tof forces led by a Supreme in the Battle of Zeltros in 4 ABY.

## Specifications

- **Name:** Wayfarer
- **Type:** Bulk cruiser
- **Length:** 1,800 meters
- **Complement:** Tof fighters
- **Destroyed:** 4 ABY
- **Affiliation:** Tof
- **Navy:** Tof invasion fleet
- **Captains:** A Tof Supreme
