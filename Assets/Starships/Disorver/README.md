# Disorver

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Disorver](https://starwars.fandom.com/wiki/Disorver)

Disorver was an Imperial Dreadnaught-class heavy cruiser during the Galactic Civil War. It was part of the fleet that patrolled the Killaniri system.

## Specifications

- **Name:** Disorver
- **Type:** Dreadnaught-class heavy cruiser
- **Length:** 600 meters
- **Role:** Cruiser
- **Affiliation:** Galactic Empire
