# Shador

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shador (Strike-class)](https://starwars.fandom.com/wiki/Shador_%28Strike-class%29)

Shador was a Strike-class medium cruiser during the Galactic Civil War. Alongside a fleet including the Valiant under the command of Moff Vensell, Shador was part of an operation against the Alliance to Restore the Republic that was launched from Jerijador.

## Specifications

- **Name:** Shador
- **Type:** Strike-class medium cruiser
- **Affiliation:** Galactic Empire
