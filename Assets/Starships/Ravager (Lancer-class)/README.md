# Ravager

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ravager (Lancer-class)](https://starwars.fandom.com/wiki/Ravager_%28Lancer-class%29)

The Ravager was a Lancer-class frigate serving the Imperial Navy after the Battle of Endor. It was part of the Rachuk sector fleet under Admiral Devlia and was sometimes paired with the Carrack Cruiser Expeditious.

## Specifications

- **Name:** Ravager
- **Model:** Lancer-class
- **Type:** Frigate
- **Navigation:** Navigation computer equipped
- **Complement:** Shuttles (2)
- **Destroyed:** 6.5 ABY
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Captains:** Admiral Devlia
