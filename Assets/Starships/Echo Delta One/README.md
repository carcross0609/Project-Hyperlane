# Echo Delta One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Echo Delta One](https://starwars.fandom.com/wiki/Echo_Delta_One)

Echo Delta One was a transport that served in the Rebel Alliance. At some point Ryland informed the ship that it had cleared atmosphere and was ready to go hyperspace.
