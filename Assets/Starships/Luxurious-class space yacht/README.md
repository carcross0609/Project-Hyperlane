# Luxurious-class space yacht

**Continuity:** Legends  
**Source:** [Luxurious-class space yacht](https://starwars.fandom.com/wiki/Luxurious-class_space_yacht)

Luxurious-class space yachts were 31-meter long starships manufactured by Ghtroc Industries.
