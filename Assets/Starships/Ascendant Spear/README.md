# Ascendant Spear

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ascendant Spear](https://starwars.fandom.com/wiki/Ascendant_Spear)

The Ascendant Spear was a Terminus-class destroyer that had been modified into a long-range battle cruiser with a Class 0.5 hyperdrive. This made it incredibly fast in hyperspace compared to the other capital ships of its time. Because of its speed and its ability to interface a Force-user's mind with the ship's computer systems through bionic implants, it was considered a superweapon by the reconstituted Sith Empire.
