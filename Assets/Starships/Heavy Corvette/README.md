# Heavy Corvette

**Continuity:** Canon  
**Source:** [Heavy Corvette](https://starwars.fandom.com/wiki/Heavy_Corvette)

A Heavy Corvette was a classification of corvette that was used by the Galactic Empire. One example of a Heavy Corvette was the Cosinga-class, a 120 meter long armed luxury yacht that belonged to Galactic Emperor Sheev Palpatine.
