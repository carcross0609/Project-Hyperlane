# RK-720 Light Freighter

**Continuity:** Legends  
**Source:** [RK-720 Light Freighter](https://starwars.fandom.com/wiki/RK-720_Light_Freighter)

The RK-720 Light Freighter was a prototype starship class designed by SoroSuub Corporation on Edic Bar, Genarius. Only one ship of the design was created, named the Sivulliq. The line was never put into full production as the prototype was stolen from the manufacturing plant. When it was eventually recovered, the SoroSuub decided to give the prototype to a hero from the Cularin system that had aided them during an ion storm.
