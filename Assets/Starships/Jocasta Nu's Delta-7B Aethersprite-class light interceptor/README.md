# Jocasta Nu's Delta-7B Aethersprite-class light interceptor

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Jocasta Nu's Delta-7B Aethersprite-class light interceptor](https://starwars.fandom.com/wiki/Jocasta_Nu%27s_Delta-7B_Aethersprite-class_light_interceptor)
