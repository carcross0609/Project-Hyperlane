# Unidentified Flarestar-class attack shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Flarestar-class attack shuttle (Ohnaka Gang)](https://starwars.fandom.com/wiki/Unidentified_Flarestar-class_attack_shuttle_%28Ohnaka_Gang%29)

This Flarestar-class attack shuttle was used by Hondo Ohnaka and his pirate gang to transport separatist leader Count Dooku from Vanqor to the surface of Florrum. The pirate Barb Mentir later used it to shoot down a Republic Nu-class attack/transport shuttle carrying a ransom of spice for Dooku.
