# T-DP

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [T-DP](https://starwars.fandom.com/wiki/T-DP)

T-DP was a Rebel Utility Tug that tried to ferry pilots to parked A-wings to defend a foothold against an Imperial attack from the Nebulon-B frigate Compton. The tug was destroyed before it could deliver pilots to the A-wings.
