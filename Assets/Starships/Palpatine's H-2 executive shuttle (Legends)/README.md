# Palpatine's H-2 executive shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Palpatine's H-2 executive shuttle/Legends](https://starwars.fandom.com/wiki/Palpatine%27s_H-2_executive_shuttle/Legends)
