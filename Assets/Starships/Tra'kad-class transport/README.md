# Tra'kad-class transport

**Continuity:** Legends  
**Source:** [Tra'kad-class transport](https://starwars.fandom.com/wiki/Tra%27kad-class_transport)

The Tra'kad was a Mandalorian Protector starship introduced in 40 ABY, meant to complement the Bes'uliik. It was a slow, heavily-armored ship described as a "flying tank," the main uses of which were in assault, troop insertion and extraction, and fire support.

## Specifications

- **Name:** Tra'kad-class transport
- **Manufacturer:** MandalMotors
- **Model:** Tra'kad
- **Type:** Assault vessel
- **Length:** 20 meters
- **Hull:** Mandalorian iron armor
- **Armament:**
  - Cannon turrets (6)
  - Rotating modular weapon platforms
- **Crew:**
  - Pilot (1)
  - Five additional crew members
- **Passengers:** More than a dozen
- **Role:** Troop transport and insertion, assault, fire support
- **Firstuse:** 40 ABY
- **Affiliation:** Mandalorian Protectors
