# Borleias

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Borleias (transport)](https://starwars.fandom.com/wiki/Borleias_%28transport%29)

The Borleias was a New Republic troop transport based on Folor. When Admiral Apwar Trigit attacked the base, the transport was delayed in evacuating by an engine malfunction. Luckily for the crew, the newly-formed Wraith Squadron was able to buy time for them to escape. It later delivered supplies to the captured Night Caller.

## Specifications

- **Role:** Troop transport
