# Trips

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Trips](https://starwars.fandom.com/wiki/Trips)

Trips was a Rebel BFF-1 bulk freighter that reclaimed D3RM3, the cargo of the stranded freighter Op Mus containing grain vital to the Alliance due to the food shortage following the evacuation of Yavin.
