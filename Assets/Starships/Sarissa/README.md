# Sarissa

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sarissa](https://starwars.fandom.com/wiki/Sarissa)

The Sarissa was a dreadnought that served the Galactic Empire by guarding the Candoras sector's Poln system as part of the sector's fleet. Imperial Senior Captain Thrawn sent the dreadnought's Caldorf VII interceptor missiles to Poln's planet of Poln Minor, where Storm-hair Warlord Nuso Esva's stole them and loaded them aboard Esva's fifty Whisperlike fighters in 0 ABY. The dreadnought later fought Esva's Eastern Fleet along with other Imperial forces.
