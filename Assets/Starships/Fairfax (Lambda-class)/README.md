# Fairfax

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fairfax (Lambda-class)](https://starwars.fandom.com/wiki/Fairfax_%28Lambda-class%29)

Fairfax was a Lambda-class T-4a shuttle that Habeen researchers used at the Mylok IV Conflict during the Galactic Civil War. Shuttle Nexus docked with Fairfax to finalize arrangements for completed hyperdrives and citizenship of the Habeen.

- **Name:** Fairfax
