# Dreadnaught-One

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dreadnaught-One](https://starwars.fandom.com/wiki/Dreadnaught-One)

Dreadnaught-One, called D-One for short, was the first of six Dreadnaught-class heavy cruisers used on Outbound Flight.
