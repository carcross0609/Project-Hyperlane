# Polis Massa flitter shuttle

**Continuity:** Legends  
**Source:** [Polis Massa flitter shuttle](https://starwars.fandom.com/wiki/Polis_Massa_flitter_shuttle)

Polis Massa flitter shuttles, or flitters, were short-range spacecraft used by the residents of the Polis Massa Research Base.
