# Class four container transport

**Continuity:** Canon  
**Source:** [Class four container transport](https://starwars.fandom.com/wiki/Class_four_container_transport)

Class four container transports, also called a class four freighter, Imperial Class 4 Cargo Ship or more simply as an Imperial cargo ship, were tetrahedral, hyperspace-capable, bulk freighters built by Kuat Drive Yards and used by the Galactic Empire to haul large numbers of crates and containers across the galaxy.

## Specifications

- **Name:** Class four container transport
- **Manufacturer:** Kuat Drive Yards
- **Type:** Bulk freighter
- **Length:** 233 meters
- **Max Speed:** 700 kph
- **Engine:** Sublight engines (3)
- **Hyperdrive:** Class 1
- **Hdsystem:** Equipped
- **Armament:**
  - Top-mounted double-barreled turbolaser battery (1)
  - Side-mounted laser turrets (2)
- **Escapepods:** 6
- **Crew:**
  - 2 pilots
  - 4 gunners
  - 1 captain
  - 1 cargo master
  - 1 navigator
- **Capacity:** 230 large containers
- **Othersystems:** Container-mounted sublight engines
- **Role:** Hauling cargo crates and containers
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
  - Phoenix Cell (stolen)
