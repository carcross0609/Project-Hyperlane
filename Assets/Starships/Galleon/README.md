# Galleon

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Galleon](https://starwars.fandom.com/wiki/Galleon)

The Galleon was a sail barge composed of various old Imperial vehicles that served as the headquarters of Kragan Gorr's Warbird gang on Castilon.

## Specifications

- **Name:** Galleon
- **Type:** Sail barge
- **Armament:** Several laser cannons
- **Complement:**
  - Warbird Skiffs
  - 8 Warbird starfighters
  - Swoops
  - Kragan Gorr's shuttle
  - Sheathipede-class transport shuttle
- **Affiliation:** Warbird gang
- **Captains:** Kragan Gorr
