# Marauder

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Marauder (Arquitens-class command cruiser)](https://starwars.fandom.com/wiki/Marauder_%28Arquitens-class_command_cruiser%29)

The Marauder was an Arquitens-class command cruiser in the Imperial Navy under the command of Brom Titus in 1 BBY. It was destroyed when the Jalindi relay was blown up by rebel extremist Saw Gerrera.
