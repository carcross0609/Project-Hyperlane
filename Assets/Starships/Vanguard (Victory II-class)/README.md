# Vanguard

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vanguard (Victory II-class)](https://starwars.fandom.com/wiki/Vanguard_%28Victory_II-class%29)

Vanguard was an Imperial Victory II-class Star Destroyer. The ship protected a convoy passing the Eidoloni system, which carried material for the Second Death Star.

## Specifications

- **Name:** Vanguard
- **Type:** Victory II-class Star Destroyer
- **Length:** 900 meters
- **Hyperdrive:** Equipped
- **Role:** Cruiser
- **Affiliation:**
