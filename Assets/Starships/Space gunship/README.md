# Space gunship

**Continuity:** Canon  
**Source:** [Space gunship](https://starwars.fandom.com/wiki/Space_gunship)

Space gunships were pressurized Low Altitude Assault Transports modified to function within the vacuum of space with features such as artificial gravity. It was a later design of the LAAT created because the original models' inability to fly in space was a tactical shortcoming.

## Specifications

- **Name:** Space gunship
- **Line:** Low Altitude Assault Transport
- **Affiliation:**
  - Galactic Republic
  -   Galactic Republic Navy
