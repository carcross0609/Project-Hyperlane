# Kraken

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kraken (Assassin-class)](https://starwars.fandom.com/wiki/Kraken_%28Assassin-class%29)

The Kraken was an Assassin-class corvette that formed part of the Corrupter Task Force under Imperial Admiral Garreth Holtz. The ship was commanded by Captain Ollender.

- **Name:** Kraken
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** Assassin-class corvette
- **Type:** Corvette

- **Width:** 58.95 meters
- **Height:** 16.97 meters

- **Affiliation:** Galactic Empire
- **Fleet:** Corrupter Task Force
- **Captains:** Captain Ollender
