# Bria

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bria](https://starwars.fandom.com/wiki/Bria)

The Bria was a heavily modified SoroSuub StarMite light freighter.

- **Name:** Bria

- **Model:** Modified StarMite light freighter
- **Type:** Freighter
- **Armament:** 2 turret-mounted Laser cannons on wings, 1 forward-mounted twin-Laser cannons on the bow
- **Destroyed:** 3 BBY
- **Owners:**
