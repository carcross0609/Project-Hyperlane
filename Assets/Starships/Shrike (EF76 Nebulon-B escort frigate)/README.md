# Shrike (EF76 Nebulon-B escort frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shrike (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Shrike_%28EF76_Nebulon-B_escort_frigate%29)

Shrike was an EF76 Nebulon-B escort frigate which served in the Imperial Navy during the Galactic Civil War. The frigate was attacked and destroyed by three B-wing starfighters, one of them piloted by Keyan Farlander, and four RZ-1 A-wing interceptors. After the Shrike destruction, a pair of CR90 corvettes, designated Banshee, and a number of Alpha-class Xg-1 Star Wings arrived at the same location, only to be destroyed by the same strike force.
