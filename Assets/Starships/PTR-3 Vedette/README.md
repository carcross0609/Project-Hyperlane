# PTR-3 Vedette

**Continuity:** Legends  
**Source:** [PTR-3 Vedette](https://starwars.fandom.com/wiki/PTR-3_Vedette)

The PTR-3 Vedette was a single-seater snubfighter developed by Core Galaxy Systems in times of the Galactic Republic.

## Specifications

- **Name:** PTR-3 Vedette
- **Manufacturer:** Core Galaxy Systems
- **Model:** PTR-3 Vedette Starfighter
- **Cost:** 75,000 credits; 30,000 credits (used)
- **Length:** 10.5 meters
- **Max Speed:** 1,080 km/h (atmospheric)
- **Hyperdrive:** None
- **Armament:** 1 laser cannon
- **Crew:** 1 pilot
- **Passengers:** None
- **Capacity:** 50 kg.
- **Consumables:** 1 day
