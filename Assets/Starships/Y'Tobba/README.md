# Y'Tobba

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Y'Tobba](https://starwars.fandom.com/wiki/Y%27Tobba)

The Y'Tobba was a ship owned by the Hutt fringer Tobba. At one point, Tobba used the ship to store his krayt dragons, which he had captured on Tatooine in order to impress Jabba Desilijic Tiure.

## Specifications

- **Name:** Y'Tobba
- **Length:** Described as "massive"
- **Affiliation:** Desilijic kajidic
- **Owners:** Tobba
