# Unidentified Nu-class attack shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Nu-class attack shuttle (Coruscant)/Legends](https://starwars.fandom.com/wiki/Unidentified_Nu-class_attack_shuttle_%28Coruscant%29/Legends)
