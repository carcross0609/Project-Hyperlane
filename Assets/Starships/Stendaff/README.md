# Stendaff

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Stendaff](https://starwars.fandom.com/wiki/Stendaff)

Stendaff was a Sacheen-class light escort vessel that served in the New Republic Defense Fleet during the Black Fleet Crisis. The warship was a part of New Republic Intelligence Colonel Ejagga Pakkpekatt's task force stationed at Gmar Askilon, following the departure of the Teljkon Vagabond into hyperspace.

## Specifications

- **Name:** Stendaff
- **Model:** Sacheen-class light escort
- **Type:** Frigate
- **Length:** 375 meters
- **Affiliation:** New Republic
- **Navy:** New Republic Defense Fleet
