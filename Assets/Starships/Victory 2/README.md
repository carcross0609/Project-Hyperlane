# Victory 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Victory 2](https://starwars.fandom.com/wiki/Victory_2)

Victory 2 was an Imperial Victory II-class Star Destroyer. It destroyed the Rebel Bulk cruiser Fairfax in the Battle of the Bajic Shipyards.
