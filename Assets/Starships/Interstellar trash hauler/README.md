# Interstellar trash hauler

**Continuity:** Canon  
**Source:** [Interstellar trash hauler](https://starwars.fandom.com/wiki/Interstellar_trash_hauler)

Interstellar trash haulers were a type of starships. A particular model of trash hauler was designed by Tiaan Jerjerrod for the Corellian Engineering Corporation.
