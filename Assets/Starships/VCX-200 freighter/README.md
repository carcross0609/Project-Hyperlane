# VCX-200 freighter

**Continuity:** Canon  
**Source:** [VCX-200 freighter](https://starwars.fandom.com/wiki/VCX-200_freighter)

The VCX-200 freighter was a class of freighter. One VCX-200 freighter was present at the Galactic Empire transfer point in the Kurost sector, where a gralloc landed on it.
