# Protector StarSpeeder

**Continuity:** Legends  
**Source:** [Protector StarSpeeder](https://starwars.fandom.com/wiki/Protector_StarSpeeder)

The Protector StarSpeeder was a class of starfighter. The fighters had a top speed of 560 KMH and were armed with two laser cannons.

## Specifications

- **Name:** Protector StarSpeeder
- **Type:** Starfighter
- **Max Speed:** 560 KMH
- **Armament:** 2 laser cannons
- **Role:** Planetary defense
