# Trawler

**Continuity:** Canon  
**Source:** [Trawler](https://starwars.fandom.com/wiki/Trawler)

A trawler was a type of ship. One trawler was operated by the Hutt Clan during the High Republic Era, and towed the Ro family's ship to Nar Shaddaa.
