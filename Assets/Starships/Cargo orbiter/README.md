# Cargo orbiter

**Continuity:** Legends  
**Source:** [Cargo orbiter](https://starwars.fandom.com/wiki/Cargo_orbiter)

Cargo orbiters were small cargo craft which were not designed with hyperspace abilities. The design required a single pilot to be operated.

## Specifications

- **Name:** Cargo orbiter
- **Hdsystem:** None
- **Role:** Transport
- **Firstuse:** Prior to 0 ABY
- **Affiliation:** Alliance to Restore the Republic
