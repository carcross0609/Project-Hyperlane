# TIE Advanced x1

**Continuity:** Canon  
**Source:** [TIE Advanced x1](https://starwars.fandom.com/wiki/TIE_Advanced_x1)

The TIE Advanced x1, also referred to as the TIE Advanced Fighter X1 or simply TIE/ad, was an advanced prototype starfighter that was part of the TIE fighter series manufactured by Sienar Fleet Systems. Darth Vader notably flew a TIE Advanced x1.
