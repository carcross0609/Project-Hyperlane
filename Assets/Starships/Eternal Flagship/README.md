# Eternal Flagship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eternal Flagship](https://starwars.fandom.com/wiki/Eternal_Flagship)

The Eternal Flagship was a capital ship that served as the flagship of the Eternal Fleet under the command of Arcann, Prince and later Emperor of the Eternal Empire.

## Specifications

- **Name:** Eternal Flagship
- **Model:** Eternal Fleet flagship
- **Type:** Capital ship
- **Complement:** Many Shuttles
- **Role:** Flagship
- **Destroyed:** 3630 BBY
- **Affiliation:** Eternal Empire
- **Owners:** Arcann
- **Captains:**
  - Knight Commander Dara Nadal
  - Security Commander Shernisa Varless
