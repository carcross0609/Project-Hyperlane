# Providence

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Providence](https://starwars.fandom.com/wiki/Providence)

The Providence was a starship owned by the pirate and treasure hunter Phee Genoa. Genoa's droid, MEL-221, was frequently destroyed during their adventures, so Genoa kept her memory backed up on the ship's databank, allowing for Mel to be rebuilt.

## Specifications

- **Name:** Providence
- **Hyperdrive:** Equipped
- **Owners:** Phee Genoa
