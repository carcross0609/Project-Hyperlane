# Turbulent-class Star Destroyer

**Continuity:** Legends  
**Source:** [Turbulent-class Star Destroyer](https://starwars.fandom.com/wiki/Turbulent-class_Star_Destroyer)

The Turbulent-class Star Destroyer, also known as the Turbulent-class destroyer, was a type of Star Destroyer built by the Imperial Remnant following the Swarm War. Because of its smaller size, it was sometimes referred to as a "pocket Star Destroyer."
