# Empyrean

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Empyrean](https://starwars.fandom.com/wiki/Empyrean)

The Empyrean was a New Republic cruiser stationed at Cybloc XII along with the Ithor Lady. The warship was destroyed by Loronar Corporation Needle fighters in the Drovian system.
