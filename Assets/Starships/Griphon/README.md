# Griphon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Griphon](https://starwars.fandom.com/wiki/Griphon)

Griphon was an Imperial Delta-class JV-7 escort shuttle in operation during the Galactic Civil War. Along with its sister ship, Manticore, the Griphon was assigned to escort the POW-carrying Dreadnaught VTR-LX to penal station Bundil II. However, both shuttles were destroyed in a Rebel rescue operation that also destroyed VTR-LX.
