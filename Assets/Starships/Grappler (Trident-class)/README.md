# Grappler

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Grappler (Trident-class)](https://starwars.fandom.com/wiki/Grappler_%28Trident-class%29)

The Grappler was a Trident-class assault ship that served in the naval forces of the Confederacy of Independent Systems. During the Clone Wars, the Grappler fought in the Battle of Kamino alongside several other Trident-class assault ships.
