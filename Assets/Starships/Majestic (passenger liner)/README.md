# Majestic

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Majestic (passenger liner)](https://starwars.fandom.com/wiki/Majestic_%28passenger_liner%29)

The Majestic was a small passenger liner used by Galaxy Tours. Celia Durasha once served aboard the ship, and helped to return it to port after it was damaged by pirates.

## Specifications

- **Name:** Majestic
- **Role:** Passenger liner
- **Affiliation:** Galaxy Tours
