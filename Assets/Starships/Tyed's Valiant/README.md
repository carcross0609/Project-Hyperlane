# Tyed's Valiant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tyed's Valiant](https://starwars.fandom.com/wiki/Tyed%27s_Valiant)

The Tyed's Valiant was a CR90 corvette owned by Gryseium Incorporated during the Galactic Civil War. After Alliance to Restore the Republic agents infected Sprawl 18 with the Mynock II virus, Sabel Axis Corazon personally pursued them in the Tyed's Valiant.
