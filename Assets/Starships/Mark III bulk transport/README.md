# Mark III bulk transport

**Continuity:** Legends  
**Source:** [Mark III bulk transport](https://starwars.fandom.com/wiki/Mark_III_bulk_transport)

The Mark III bulk transport was a product of Sienar Ships, basically an oversized version of the Mark I bulk transport.

## Specifications

- **Name:** Mark III bulk transport
- **Manufacturer:** Sienar Ships
- **Model:** Mark III
- **Type:** Bulk transport
- **Cost:** 400,000 credits (used)
- **Length:** 300 meters
- **Max Speed:** 750 km/h
- **Hyperdrive:**
  - Class 3.0
  - Class 20 (backup)
- **Shield Gen:** None
- **Armament:** Laser cannon
- **Crew:** 10
- **Capacity:** 160,000 metric tons
- **Consumables:** 5 months
- **Role:** Bulk freighter
