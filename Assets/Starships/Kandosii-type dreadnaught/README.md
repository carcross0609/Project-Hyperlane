# Kandosii-type dreadnaught

**Continuity:** Legends  
**Source:** [Kandosii-type dreadnaught](https://starwars.fandom.com/wiki/Kandosii-type_dreadnaught)

The Kandosii-type dreadnaught, named after the Mando'a word for "indomitable", was the largest capital ship used by the Mandalorians during the Mandalorian Wars.

## Specifications

- **Name:** Kandosii-type dreadnaught
- **Manufacturer:**
  - Original parts stolen from the Fenelar
  - Various Mandalorian manufacturers
- **Model:** Kandosii-type dreadnaught
- **Type:** Dreadnaught
- **Cost:** 200 million credits (120 million used)
- **Length:** 1,360 meters
- **Engine:** Corellia StarDrive engine system
- **Hyperdrive:**
  - Class 2.0
  - Class 9.0 (backup)
- **Hdsystem:** Equipped
- **Shield Gen:** Double layered deflector shields
- **Hull:** Deck plating by Byblos Drive Yards
- **Navigation:** Navicomputer equipped
- **Armament:**
  - Heavy double turbolaser batteries (5)
  - Point-defense medium ion cannon batteries (4)
  - Point-defense triple laser cannon batteries (2)
  - Super-heavy concussion missile batteries (2)
  -   120 missiles
  - Tractor beam batteries (2)
- **Complement:**
  - Davaab-type fighters (128)
  - Shaadlar-type troopships (8)
  - various support craft
- **Crew:** 10,000
- **Passengers:** 30,000 troops
- **Capacity:** 45,000 tons
- **Consumables:** 5 years
- **Availability:** Restricted
- **Role:** Battleship
- **Affiliation:** Mandalorian Neo-Crusaders
