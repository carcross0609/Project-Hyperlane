# 440 freighter

**Continuity:** Legends  
**Source:** [440 freighter](https://starwars.fandom.com/wiki/440_freighter)

The 440 freighter was an older model light freighter produced by Ghtroc Industries. It was operated by a crew of two plus two gunners.

- **Name:** 440 freighter
- **Manufacturer:** Ghtroc Industries
- **Model:** Class 440 freighter
- **Type:** Light freighter
- **Length:** 28 meters
- **Max Speed:** 800 km/h
- **Hyperdrive:**

  - Class 15 backup
- **Shield Gen:** Equipped
- **Armament:** Laser cannons (2)
- **Crew:** 4, 2 gunners
- **Passengers:** 4
- **Capacity:** 100 metric tons
- **Consumables:** 2 months
- **Affiliation:**
