# Shurik

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shurik](https://starwars.fandom.com/wiki/Shurik)

Shurik was the designation given to a group of Imperial CR90 corvettes. The vessels of this group were destroyed while escorting the BFF-1 bulk freighters Dotermin and Sornsen, which had attempted to resupply the Relentless.
