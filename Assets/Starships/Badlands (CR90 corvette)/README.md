# Badlands

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Badlands (CR90 corvette)](https://starwars.fandom.com/wiki/Badlands_%28CR90_corvette%29)

Badlands was an Imperial CR90 corvette during the Galactic Civil War. Commanded by Commander Kraven, Badlands served under Garreth Holtz's Corrupter Task Force.
