# Bay Point

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bay Point](https://starwars.fandom.com/wiki/Bay_Point)

Bay Point was a Nebulon-B2 frigate belonging to the Rebel Alliance. It was part of a second attempt to rescue Rebel and Bothan prisoners, the attempt was foiled by Tan Maarek Stele.

## Specifications

- **Name:** Bay Point
- **Manufacturer:** Kuat Drive Yards
- **Model:** Nebulon-B2 frigate
- **Type:** Frigate
- **Length:** 253.2 meters
- **Width:** 147.7 meters
- **Height:** 94.3 meters
- **Affiliation:** Alliance to Restore the Republic
