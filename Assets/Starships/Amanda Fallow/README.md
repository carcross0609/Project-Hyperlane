# Amanda Fallow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Amanda Fallow](https://starwars.fandom.com/wiki/Amanda_Fallow)

The Amanda Fallow was one of the many starships that worked for and participated in Talon Karrde's vast and varied smuggling operations. The ship was a modified Corellian Engineering Corporation YZ-775 medium transport.
