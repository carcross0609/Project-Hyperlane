# Teroch-type gunship

**Continuity:** Legends  
**Source:** [Teroch-type gunship](https://starwars.fandom.com/wiki/Teroch-type_gunship)

The Teroch-type gunship, named for a Mando'a word "pitiless", was a fast-attack gunship used by Mandalorian Neo-Crusaders during the Mandalorian Wars. If they broke through an enemy line they could surround enemy capital ships in moments.

## Specifications

- **Name:** Teroch-type gunship
- **Type:** Gunship
- **Cost:** 400,000 credits (200,000 used)
- **Length:** 18 meters
- **Max Speed:** 1,000 km/h
- **Hyperdrive:** Class 2
- **Hdsystem:** Equipped
- **Armament:** Laser cannons (double)
- **Crew:** 8
- **Passengers:** 6
- **Consumables:** 3 weeks
- **Availability:** Restricted
- **Role:** Gunship
- **Affiliation:** Mandalorian Neo-Crusaders
