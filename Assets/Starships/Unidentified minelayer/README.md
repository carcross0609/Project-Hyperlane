# Unidentified minelayer

**Continuity:** Legends  
**Source:** [Unidentified minelayer](https://starwars.fandom.com/wiki/Unidentified_minelayer)

A starfighter model used by the Trade Federation Droid Army featured a blocky underside with a square front and triangular rear. The unshielded craft was capable of deploying floating proximity mines from a rear compartment.

## Specifications

- **Name:** Unidentified minelayer
- **Type:** Starfighter
- **Armament:** Proximity mines
- **Role:** Minelayer
- **Affiliation:** Trade Federation Droid Army
