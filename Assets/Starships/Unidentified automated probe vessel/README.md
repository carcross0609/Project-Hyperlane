# Unidentified automated probe vessel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified automated probe vessel](https://starwars.fandom.com/wiki/Unidentified_automated_probe_vessel)

An automated probe vessel was dispatched to catalog the flora of several uninhabited planets in the Outer Rim Territories during the Cold War between the Galactic Republic and the Sith Empire, but it later turned up derelict in the Shadola sector.
