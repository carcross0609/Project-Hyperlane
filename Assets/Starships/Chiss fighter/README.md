# Chiss fighter

**Continuity:** Legends  
**Source:** [Chiss fighter](https://starwars.fandom.com/wiki/Chiss_fighter)

Chiss fighters were starfighters used by the Chiss Ascendancy's Picket Force Two. It is grey and built in a curved, flowing design. It is about the size of a shuttle or heavy fighter.
