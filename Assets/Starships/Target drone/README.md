# Target drone

**Continuity:** Canon  
**Source:** [Target drone](https://starwars.fandom.com/wiki/Target_drone)

Target drones were a type of drone starship used in training exercises for pilots. After the Battle of D’Qar in 34 ABY, the First Order used Microraptor-class target drones to train their TIE/fo Fighter pilot recruits aboard the Resurgent-class Star Destroyer Thunderer.

## Specifications

- **Name:** Target drone
- **Type:** Drone
- **Models:** Microraptor-class target drone
- **Role:** Live fire training drone
- **Affiliation:** First Order
