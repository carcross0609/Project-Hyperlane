# Gaze landing shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Gaze's landing shuttle](https://starwars.fandom.com/wiki/Gaze%27s_landing_shuttle)

The Gaze landing shuttle was a shuttle on the Gaze Electric starship used by the Path of the Open Hand cult. It was destroyed during the Battle of Jedha.

## Specifications

- **Name:** Gaze landing shuttle
- **Type:** Shuttle
- **Destroyed:** 382 BBY, Jedha
- **Affiliation:** Path of the Open Hand
- **Owners:** Elecia Zeveron
