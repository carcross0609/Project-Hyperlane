# Starcat

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starcat (light freighter)](https://starwars.fandom.com/wiki/Starcat_%28light_freighter%29)

Starcat was a customized light freighter used by the Happy Blasters. It was custom designed and built by Salem Victory and Dapp Solus.
