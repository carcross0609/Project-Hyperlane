# Spinward-class tender

**Continuity:** Legends  
**Source:** [Spinward-class tender](https://starwars.fandom.com/wiki/Spinward-class_tender)

The Spinward-class tender was a mobile repair ship used by the Galactic Federation of Free Alliances nearly 100 years after the Yuuzhan Vong War. As large as bulk freighters, these tenders performed major repairs on damaged Alliance warships.
