# Superiority fighter

**Continuity:** Legends  
**Source:** [Superiority fighter](https://starwars.fandom.com/wiki/Superiority_fighter)

A superiority fighter was a type of starfighter that was designed to be effective against both larger starships and starfighters. The Alpha-class XG-1 "Star Wing" and the X-wing starfighter were superiority fighters.
