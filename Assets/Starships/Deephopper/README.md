# Deephopper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Deephopper](https://starwars.fandom.com/wiki/Deephopper)

Deephopper was the name of Marka Durn's battered Ghtroc Industries freighter. He was always upgrading it with his droid, R2-C9.

## Specifications

- **Name:** Deephopper
- **Manufacturer:** Ghtroc Industries
