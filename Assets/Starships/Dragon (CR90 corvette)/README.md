# Dragon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dragon (CR90 corvette)](https://starwars.fandom.com/wiki/Dragon_%28CR90_corvette%29)

Dragon was a CR90 corvette in the service of the Rebel Alliance. It was presumably trying to destroy the Imperial heavy tugs under the command of Vice Admiral Thrawn in order to stop a salvage attempt. It was destroyed by attacking TIE/sa bombers.

- **Name:** Dragon

- **Destroyed:** 3 ABY
