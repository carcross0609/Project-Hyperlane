# Space Control Ship

**Continuity:** Legends  
**Source:** [Space Control Ship](https://starwars.fandom.com/wiki/Space_Control_Ship)

A Space Control Ship was a class of starship. One was deployed by the Kalindan Deep Space Fleet and Kalindan System Defense Force during the Battle of Kalinda.
