# Blazing Torch

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blazing Torch](https://starwars.fandom.com/wiki/Blazing_Torch)

The Blazing Torch was a starship of the Galactic Republic's navy some time before a new conflict with the Sith Empire. Dol Narlock served aboard before rising to the command of the Valor-class cruiser Krakana.
