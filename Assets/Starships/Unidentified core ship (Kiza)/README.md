# Unidentified core ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified core ship (Kiza)](https://starwars.fandom.com/wiki/Unidentified_core_ship_%28Kiza%29)

A core ship located on an asteroid outside the Red Honeycomb Zone was used as a home by the former Acolyte of the Beyond Kiza around 21 ABY. During a duel in the ship, the ship's forge caught fire, which caused much of the ship's interior to burn down.

## Specifications

- **Name:** Unidentified core ship
- **Model:** Core ship
- **Length:** 696 meters
