# Star Herald

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Star Herald](https://starwars.fandom.com/wiki/Star_Herald)

The Star Herald was a top-of-the-line prototype scout ship that was developed by the Galactic Empire around 18 BBY. It had a long, arrow-like hull supporting a tractor beam projector, and it housed at least one probe that could go underwater.
