# Kyramud-type battleship

**Continuity:** Legends  
**Source:** [Kyramud-type battleship](https://starwars.fandom.com/wiki/Kyramud-type_battleship)

The Kyramud-type battleship, named after the Mando'a word for killer or assassin, comprised a series of capital ships used by the Mandalorian Crusaders and Neo-Crusaders.
