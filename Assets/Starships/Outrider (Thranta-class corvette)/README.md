# Outrider

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Outrider (Thranta-class corvette)](https://starwars.fandom.com/wiki/Outrider_%28Thranta-class_corvette%29)

The Outrider was a Thranta-class corvette in the Republic Navy of the Galactic Republic that served in the renewed war with the reconstituted Sith Empire. The Outrider was captained by the Human Hardin, and had a Zabrak navigator named Tarev and a Human communications officer named Sola. The ship was assigned by Supreme Chancellor Leontyne Saresh to investigate Hutt Cartel military activity in the Vyron system, and it then ferried Saresh's strike team to Nal Hutta.
