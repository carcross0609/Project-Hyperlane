# Talon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Talon (Immobilizer 418 cruiser)](https://starwars.fandom.com/wiki/Talon_%28Immobilizer_418_cruiser%29)

The Talon was a Sienar Fleet Systems Immobilizer 418 cruiser. During the Galactic Civil War it patrolled the Demophon system prior to the destruction of that system in a supernova.
