# Vangaard Pathfinder

**Continuity:** Canon  
**Source:** [Vangaard Pathfinder](https://starwars.fandom.com/wiki/Vangaard_Pathfinder)

The Vangaard Pathfinder was a scout ship used by the Commerce Guild before the Clone Wars to find valuable planets. Tibbs Ospe flew one when he discovered the planet Vandor.

## Specifications

- **Name:** Vangaard Pathfinder
- **Role:** Scout ship
- **Affiliation:** Commerce Guild
