# Epoch Swift

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Epoch Swift](https://starwars.fandom.com/wiki/Epoch_Swift)

The Epoch Swift was the personal starship of Maz Kanata. It was kept in a private hangar in her castle on the planet Takodana.
