# Sigma 1

**Continuity:** Legends  
**Source:** [Sigma 1](https://starwars.fandom.com/wiki/Sigma_1)

Sigma 1 was a Delta-class DX-9 stormtrooper transport serving the Imperial Navy. It participated in the Skirmish at Outpost D-34, and carried troops.
