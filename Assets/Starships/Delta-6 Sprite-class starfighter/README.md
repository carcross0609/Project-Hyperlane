# Delta-6 Sprite-class starfighter

**Continuity:** Legends  
**Source:** [Delta-6 Sprite-class starfighter](https://starwars.fandom.com/wiki/Delta-6_Sprite-class_starfighter)

The Delta-6 Sprite-class starfighter was a short-range light starfighter used by the Jedi Order during the time of the Invasion of Naboo. It was the predecessor of the Delta-7 Aethersprite-class interceptor.
