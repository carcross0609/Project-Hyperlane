# Midnight Star

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Midnight Star](https://starwars.fandom.com/wiki/Midnight_Star)

The Midnight Star was a modified YV-545 light freighter, captained by Cala Worner, and co-piloted by Thul Kariss. It was registered to the Outer Rim Trade Consortium, and was affiliated with the Rebel Alliance.
