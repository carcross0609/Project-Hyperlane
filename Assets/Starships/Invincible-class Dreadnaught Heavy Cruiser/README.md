# Invincible-class Dreadnaught Heavy Cruiser

**Continuity:** Legends  
**Source:** [Invincible-class Dreadnaught Heavy Cruiser](https://starwars.fandom.com/wiki/Invincible-class_Dreadnaught_Heavy_Cruiser)
