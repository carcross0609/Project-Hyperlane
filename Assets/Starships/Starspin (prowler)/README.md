# Starspin (prowler)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starspin (prowler)](https://starwars.fandom.com/wiki/Starspin_%28prowler%29)

The Starspin was a Galactic Republic prowler ship. It responded to a distress call sent by Oss Wilum, who had stumbled on a crippled Republic courier. When the Starspin arrived, it assisted the courier and ordered Willum to depart the area.
