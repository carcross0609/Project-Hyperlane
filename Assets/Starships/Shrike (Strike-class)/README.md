# Shrike

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shrike (Strike-class)](https://starwars.fandom.com/wiki/Shrike_%28Strike-class%29)

The Shrike was a Strike-class medium cruiser manufactured by Loronar Corporation. It was in the service of the Galactic Empire, and was commanded by Captain Dren Jamer following the Battle of Endor.

## Specifications

- **Name:** Shrike
- **Manufacturer:** Loronar Corporation
- **Type:** Strike-class medium cruiser
- **Affiliation:** Galactic Empire
- **Captains:** Captain Dren Jamer
