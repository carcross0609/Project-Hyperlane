# Lady Ucce's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lady Ucce's starship](https://starwars.fandom.com/wiki/Lady_Ucce%27s_starship)

Lady Ucce has a starship. The starship had a smooth, golden hull, peppered with gilded portholes. Lady Ucce traveled to Crseih Station aboard the starship, along with an individual of a furred species.
