# Gamma-class Light Personnel Carrier

**Continuity:** Legends  
**Source:** [Gamma-class Light Personnel Carrier](https://starwars.fandom.com/wiki/Gamma-class_Light_Personnel_Carrier)

The Gamma-class Light Personnel Carrier was an Imperial shuttle used to supply planetary forces. It was also known as the Telgorn II lpc Gamma-class personnel shuttle, while Rebel ground forces referred to them as Gift boxes.
