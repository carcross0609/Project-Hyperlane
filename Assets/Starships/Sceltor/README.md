# Sceltor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sceltor](https://starwars.fandom.com/wiki/Sceltor)

The Sceltor was a Victory I-class Star Destroyer commanded by Admiral Thrawn. Sceltor participated in the capture of space station RS-32. It also fell into an ambush at the space station's location, but Tan Maarek Stele helped it escape.
