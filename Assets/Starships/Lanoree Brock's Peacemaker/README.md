# Lanoree Brock's Peacemaker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lanoree Brock's Peacemaker](https://starwars.fandom.com/wiki/Lanoree_Brock%27s_Peacemaker)

Lanoree Brock's Peacemaker was the personal Peacemaker-class cruiser of Je'daii Ranger Lanoree Brock during the Stargazer Uprising. Ironholgs, an upgraded Holgorian IM-220 maintenance droid, was assigned to security and maintenance of the ship, and was capable of remotely piloting it.

## Specifications

- **Name:** Lanoree Brock's Peacemaker
- **Model:** Peacemaker-class cruiser
- **Type:** Cruiser
- **Affiliation:** Je'daii Order
- **Owners:** Lanoree Brock
