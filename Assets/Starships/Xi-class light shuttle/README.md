# Xi-class light shuttle

**Continuity:** Canon  
**Source:** [Xi-class light shuttle](https://starwars.fandom.com/wiki/Xi-class_light_shuttle)

The Xi-class light shuttle was a transport craft used by the First Order in 34 ABY.

## Specifications

- **Name:** Xi-class light shuttle
- **Manufacturer:** Sienar-Jaemus Fleet Systems
- **Type:** Transport
- **Length:** 11.84 meters (38.84 ft)
- **Width:** 22.87 meters (75.04 ft)
- **Height:** 18.31 meters (60.08 ft)
- **Armament:** 2 light laser cannons
- **Crew:** 1-2
- **Passengers:** 6 passengers
- **Affiliation:**
  - First Order
  - Resistance (stolen)
