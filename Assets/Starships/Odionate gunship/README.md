# Odionate gunship

**Continuity:** Legends  
**Source:** [Odionate gunship](https://starwars.fandom.com/wiki/Odionate_gunship)

Odionate gunships were medium-sized starships used by the Sith Lord Odion's independent princedom the Odionate during the Second Charge Matrica. These gunships saw action during the defense of the mobile space station The Spike, destroying many Daimanate starfighters.

## Specifications

- **Name:** Odionate gunship
- **Manufacturer:** Odionate
- **Type:** Gunship
- **Role:** Anti-starfighter platform
- **Affiliation:** Odionate
