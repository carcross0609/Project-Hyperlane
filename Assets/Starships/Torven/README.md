# Torven

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Torven](https://starwars.fandom.com/wiki/Torven)

Torven was a Container transport located at an Imperial scrap yard in Tolig IV. Its cargo was Motivators. It was present there when Ace and Emon Azzameen went there to investigate the various containers to search for the Data Core, and when the raid took place.

- **Name:** Torven
- **Manufacturer:** Xizor Transport Systems
- **Model:** Container transport
- **Type:** Medium freighter
