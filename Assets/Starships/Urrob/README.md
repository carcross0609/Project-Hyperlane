# Urrob

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Urrob](https://starwars.fandom.com/wiki/Urrob)

The Urrob was a Ton-Falk-class escort carrier that served with the Galactic Empire during the Galactic Civil War. It was used to deliver replacement starfighters to the Imperial-class Star Destroyer Rage near Essebra, in the Essebra system.

## Specifications

- **Name:** Urrob
- **Model:** Ton-Falk-class escort carrier
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
