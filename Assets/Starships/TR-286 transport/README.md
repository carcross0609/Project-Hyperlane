# TR-286 transport

**Continuity:** Canon  
**Source:** [TR-286 transport](https://starwars.fandom.com/wiki/TR-286_transport)

The TR-286 transport was a type of automated transport used in the galaxy during the Imperial Era. One TR-286, transport eight, was present on Daiyu and was used to ferry Jedi Master Obi-Wan Kenobi and Princess Leia Organa to the mining planet Mapuzo. Many TR-286 transports were used on Epikonia to transport data-discs containing droid code updates to the surrounding sector.
