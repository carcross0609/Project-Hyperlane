# Gatekeeper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gatekeeper (Imperial Customs corvette)](https://starwars.fandom.com/wiki/Gatekeeper_%28Imperial_Customs_corvette%29)
