# Lish Runner VII

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lish Runner VII](https://starwars.fandom.com/wiki/Lish_Runner_VII)

Lish Runner VII was a passenger liner owned and operated by Lant Mining Corporation. The vessel was used to transport LMC workers between Lish's moons.

## Specifications

- **Name:** Lish Runner VII
- **Type:** Passenger liner
- **Role:** Company passenger transport
