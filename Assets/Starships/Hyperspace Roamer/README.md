# Hyperspace Roamer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hyperspace Roamer](https://starwars.fandom.com/wiki/Hyperspace_Roamer)

Hyperspace Roamer was a freighter bringing X-1 Viper war droids in to Byss in 10 ABY. It landed at Bay 327 of Port Tower Tarkin-12.
