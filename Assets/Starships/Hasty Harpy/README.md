# Hasty Harpy

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hasty Harpy](https://starwars.fandom.com/wiki/Hasty_Harpy)

The Hasty Harpy was a YT-1760 starship owned by Lalo Gunn during the Clone Wars. It was grounded on Kynachi in 22 BBY by the Trade Federation along with all other ships on the planet, causing Gunn to be stranded there.
