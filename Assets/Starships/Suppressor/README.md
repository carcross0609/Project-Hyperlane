# Suppressor

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Suppressor](https://starwars.fandom.com/wiki/Suppressor)

The Suppressor was an Imperial Gozanti-class cruiser that was in service to the Imperial Navy during the Imperial Era. At one point, it flew over a rocky, tan terrestrial body alongside a TIE fighter.

- **Model:** Imperial Gozanti-class cruiser
