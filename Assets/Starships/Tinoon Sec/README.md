# Tinoon Sec

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tinoon Sec](https://starwars.fandom.com/wiki/Tinoon_Sec)

The Tinoon Sec was a DP20 gunship that was part of Tinoon Station's security forces. It was destroyed during a pirate raid, that was successfully driven off by Ace Azzameen.
