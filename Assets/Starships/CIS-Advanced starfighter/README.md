# CIS-Advanced starfighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [CIS-Advanced starfighter](https://starwars.fandom.com/wiki/CIS-Advanced_starfighter)

The CIS-Advanced starfighter was designed by the Confederacy of Independent Systems, during the Clone Wars. The prototype never saw any action except for a few trials.
