# Mega-class Star Dreadnought

**Continuity:** Canon  
**Source:** [Mega-class Star Dreadnought](https://starwars.fandom.com/wiki/Mega-class_Star_Dreadnought)

The Mega-class Star Dreadnought, also known as the Mega-class Star Destroyer, the Mega Star Destroyer, or the First Order Mega-Destroyer, was a class of Star Dreadnought utilized by the First Order during their conflict with the Resistance. It was believed to be the largest ship ever constructed in galactic history.
