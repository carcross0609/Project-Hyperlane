# Class One

**Continuity:** Canon  
**Source:** [Class One](https://starwars.fandom.com/wiki/Class_One)

Class One was a class of starship utilized by the criminal syndicate Crimson Dawn during Lady Qi'ra's attempts to destroy the Sith Lords Darth Sidious and Darth Vader. Between 3 ABY and 4 ABY, the Class One ships were deployed by Crimson Dawn during a Battle at Amaxine Station to keep the Class-Two and Class Three ships from being attacked by the fighters deployed by the Executor.
