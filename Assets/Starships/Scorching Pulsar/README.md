# Scorching Pulsar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Scorching Pulsar](https://starwars.fandom.com/wiki/Scorching_Pulsar)

The Scorching Pulsar was a pirate starship that was a rival of the Dreaded Shyrack. The two destroyed each other in a shootout during the Cold War, prompting scavengers to raid the vessels for their treasure.
