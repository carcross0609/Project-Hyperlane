# First Order Tanker Vessel

**Continuity:** Canon  
**Source:** [First Order Tanker Vessel](https://starwars.fandom.com/wiki/First_Order_Tanker_Vessel)

The First Order Tanker Vessel was a class of fuel tanker. It featured three large external fuel tanks. In 34 ABY, one vessel intercepted a Phelarion-class fuel tanker carrying fuel for the Resistance. It lacked a hyperdrive, requiring a Hyperspace transport ring to travel far distances.

## Specifications

- **Name:** First Order Tanker Vessel
- **Type:** Fuel tanker
- **Hyperdrive:** Equipped
- **Shield Gen:** Deflector shield
- **Bays:** Hangar bay
- **Capacity:** Three fuel cylinders
- **Affiliation:**
  - First Order
  -   First Order Navy
