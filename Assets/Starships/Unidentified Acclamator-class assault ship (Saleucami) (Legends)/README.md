# Unidentified Acclamator-class assault ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Acclamator-class assault ship (Saleucami)/Legends](https://starwars.fandom.com/wiki/Unidentified_Acclamator-class_assault_ship_%28Saleucami%29/Legends)

Around 22 BBY during the Clone Wars, an Acclamator-class assault ship was used to transport Jedi General Obi-Wan Kenobi, Marshal Commander Cody, and Clone Captain Rex's 501st Legion troops to the surface of Saleucami. Shortly after landing, it returned to orbit.
