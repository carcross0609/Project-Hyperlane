# Commuter ship

**Continuity:** Canon  
**Source:** [Commuter ship](https://starwars.fandom.com/wiki/Commuter_ship)

A commuter ship was a type of starship used for commercial travel between planets. The Star Tours Speeder was a ship of this type. They were often operated by droids. The most recognizable commuter ship pilots were RX-Series pilot droids. Before them, AC-series pilot droids were often used to operate commuter vehicles.
