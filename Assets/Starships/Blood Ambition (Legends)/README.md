# Blood Ambition

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blood Ambition/Legends](https://starwars.fandom.com/wiki/Blood_Ambition/Legends)

The Blood Ambition was a Gladiator II-class Star Destroyer in the naval forces of the Galactic Empire. It was commanded by Captain Ralchio Nervi and was part of a task force along with Sargantuan and Warhawk.
