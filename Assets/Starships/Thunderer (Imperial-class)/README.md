# Thunderer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thunderer (Imperial-class)](https://starwars.fandom.com/wiki/Thunderer_%28Imperial-class%29)

The Thunderer was an Imperial-class Star Destroyer which served under rogue Grand Admiral Demetrius Zaarin. She helped destroy the Star Destroyer Courageous. Her fate following Zaarin's defeat is unknown.

## Specifications

- **Name:** Thunderer
- **Manufacturer:** Kuat Drive Yards
- **Model:** Imperial-class Star Destroyer
- **Type:** Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/ln starfighters
- **Affiliation:** Zaarin coup forces
