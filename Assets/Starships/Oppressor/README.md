# Oppressor

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Oppressor](https://starwars.fandom.com/wiki/Oppressor)

The Oppressor was an Executor-class Star Dreadnought serving in the Imperial Navy during the Imperial Era. At a time when it was the newest Executor-class vessel, the Oppressor prepared to test its hyperdrive prior to final deployment. At this point, the Star Dreadnought was only manned by a skeleton crew.
