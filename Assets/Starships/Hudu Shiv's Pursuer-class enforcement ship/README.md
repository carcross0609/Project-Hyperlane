# Hudu Shiv's Pursuer-class enforcement ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hudu Shiv's Pursuer-class enforcement ship](https://starwars.fandom.com/wiki/Hudu_Shiv%27s_Pursuer-class_enforcement_ship)

A Pursuer-class enforcement ship belonged to the Mandalorian Death Watch member Hudu Shiv. He used the vessel during an assassination in 22 BBY. Shiv used the vessel as a decoy and it was destroyed by the transport Hasty Harpy; this successfully fooled the Jedi Padawan Nuru Kungurama into thinking Shiv was dead.
