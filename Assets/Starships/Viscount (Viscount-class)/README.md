# Viscount

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Viscount (Viscount-class)](https://starwars.fandom.com/wiki/Viscount_%28Viscount-class%29)

The Viscount was the lead ship of the Viscount-class Star Defender line produced for the New Republic and later the Galactic Alliance.

## Specifications

- **Name:** Viscount
- **Line:** Mon Calamari Star Cruisers
- **Model:** Viscount-class Star Defender
- **Type:** Star Defender
- **Length:** 3,000 meters
- **Role:**
  - Battlecruiser
  - Technology demonstrator
- **Commission:** 25 ABY
- **Navy:**
  - New Republic First Battle Group
  - Galactic Alliance First Fleet
