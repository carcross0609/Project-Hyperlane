# M3-A Scyk interceptor

**Continuity:** Canon  
**Source:** [M3-A Scyk interceptor](https://starwars.fandom.com/wiki/M3-A_Scyk_interceptor)

The M3-A Scyk interceptor was a class of interceptor that was used during the Imperial Era. The Galactic Empire used four such vessels. The Hutt Cartel also utilized these interceptors.

## Specifications

- **Name:** M3-A Scyk interceptor
- **Manufacturer:** MandalMotors
- **Type:** Interceptor
- **Cost:** 55,000 credits
- **Engine:** 1 R303 Ion Jet Engine
- **Hyperdrive:** Class 2
- **Sensor:** Short
- **Navigation:** Equipped
- **Crew:** One pilot
- **Passengers:** Zero
- **Consumables:** Two days
- **Affiliation:**
  - Car'das
  - Hutt Clan
  - Galactic Empire
  -   Imperial Navy
