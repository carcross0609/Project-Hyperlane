# Omicron

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Omicron (shuttle)](https://starwars.fandom.com/wiki/Omicron_%28shuttle%29)

Omicron was an Imperial Gamma-class assault shuttle that was stationed near Comm Center. It attempted to stop the Azzameen family from hacking into one of the station's satellites by deploying spacetroopers. It was either driven off or destroyed.

## Specifications

- **Name:** Omicron
- **Manufacturer:** Telgorn Corporation
- **Model:** Gamma-class assault shuttle
- **Type:** Shuttle
- **Length:** 30 meters
- **Width:** 13 meters
- **Height:** 9 meters
- **Engine:** Telgorn IA/4 fusial thrust engines
- **Hyperdrive:**
  - Class 2.0
  - Backup class 18
- **Power:** Fabritech UL.2 power modulator
- **Armament:** Turbolaser cannons (4)
- **Affiliation:** Galactic Empire
