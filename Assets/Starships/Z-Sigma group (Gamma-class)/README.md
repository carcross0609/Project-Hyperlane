# Z-Sigma group (Gamma-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Z-Sigma group (Gamma-class)](https://starwars.fandom.com/wiki/Z-Sigma_group_%28Gamma-class%29)

Z-Sigma group was a group of Gamma-class ATR-6 assault transports that served the Zaarin coup forces during the Zaarin insurrection. It was present at the Evacuation of Vorknkx Project Base.
