# 327-C

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [327-C](https://starwars.fandom.com/wiki/327-C)

327-C was a CR90 corvette dispatched along with 327-A and 327-B to attack the Rebel-allied X7 factory in the Mobetta sector. The corvette was produced by Corellian Engineering Corporation. It was part of Admiral Wooyou Senn's Task Force Vengeance.

## Specifications

- **Name:** 327-C
- **Model:** CR90 corvette
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
