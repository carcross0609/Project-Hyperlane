# Prowler-class reconnaissance vessel

**Continuity:** Legends  
**Source:** [Prowler-class reconnaissance vessel](https://starwars.fandom.com/wiki/Prowler-class_reconnaissance_vessel)

The Prowler-class reconnaissance vessel was a spy vessel for the New Republic built by the Republic Engineering Corporation as part of the New Class Modernization Program.

- **Manufacturer:** Republic Engineering Corporation
- **Line:** New Class Modernization Program
- **Type:** Scout vessel
- **Length:** 48 meters
- **Engine:** Baffled sublight drive
- **Hyperdrive:**

- **Navigation:** Navigation computer
- **Countermeasures:** Sensor decoys (4 sets)
- **Armament:**

  - 10 Concussion missiles
- **Crew:** 6
- **Passengers:** 0
- **Capacity:** 3 tons
- **Consumables:** 5 months
- **Role:** Reconnaissance
- **Affiliation:** New Republic
