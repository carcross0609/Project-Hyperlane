# Vindi's shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vindi's shuttle/Legends](https://starwars.fandom.com/wiki/Vindi%27s_shuttle/Legends)

Vindi's shuttle was a Sheathipede-class transport shuttle was owned by Doctor Nuvo Vindi during the Clone Wars. It was later captured during a Galactic Republic raid on Nuvo Vindi's laboratory, in which Jedi Generals Anakin Skywalker and Obi-Wan Kenobi used the shuttle to transport Vindi to Naboo's capital, Theed, for trial.

## Specifications

- **Name:** Vindi's shuttle
- **Manufacturer:** Haor Chall Engineering
- **Model:** Sheathipede-class transport shuttle
- **Type:** Transport shuttle
- **Crew:** Pilot (1)
- **Role:** Transport
- **Affiliation:**

  - Galactic Republic (Captured)
- **Owners:** Nuvo Vindi
