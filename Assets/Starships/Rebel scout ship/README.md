# Rebel scout ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rebel scout ship](https://starwars.fandom.com/wiki/Rebel_scout_ship)

A Rebel Alliance scout ship was a ship used by Princess Leia Organa and Luke Skywalker while scouting out locations for a new Rebel Alliance base shortly after the Battle of Yavin. Imperial stormtroopers found the vessel on Jarnollen and destroyed it, though the Rebels were not inside.
