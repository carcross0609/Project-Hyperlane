# Eliall-class Cargo Barge

**Continuity:** Legends  
**Source:** [Eliall-class Cargo Barge](https://starwars.fandom.com/wiki/Eliall-class_Cargo_Barge)

The Eliall-class Cargo Barge was a cargo hauler used by many shipping companies in the Outer Rim.

## Specifications

- **Name:** Eliall-class Cargo Barge
- **Type:** Freighter
- **Length:** 100 meters
- **Crew:**
  - 1 pilot
  - 4 other crew
- **Capacity:** 300 metric tons
- **Role:** Transport
- **Affiliation:** Outer Rim shipping companies
