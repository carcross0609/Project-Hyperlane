# HH-87 Starhopper

**Continuity:** Legends  
**Source:** [HH-87 Starhopper/Legends](https://starwars.fandom.com/wiki/HH-87_Starhopper/Legends)

The HH-87 Starhopper was a starfighter used commonly by various factions of the criminal underworld. Notably, the craft saw widespread use by the Hutt crime families and Zygerrian slavers of the Zygerrian Slave Empire.

## Specifications

- **Name:** HH-87 Starhopper
- **Manufacturer:** MandalMotors
- **Type:** Starfighter
- **Cost:** 50,000 credits
- **Length:** 6.8 meters
- **Width:** 13.59 meter wingspan
- **Hyperdrive:** Class 1.0
- **Navigation:** Yes
- **Armament:** Twin light laser cannons (2)
- **Crew:** 1
- **Consumables:** 2 days
- **Affiliation:**
  - Hutts
  - Zygerrian Slave Empire
  - Various others
