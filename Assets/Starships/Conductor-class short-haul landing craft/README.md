# Conductor-class short-haul landing craft

**Continuity:** Legends  
**Source:** [Conductor-class short-haul landing craft](https://starwars.fandom.com/wiki/Conductor-class_short-haul_landing_craft)

The Conductor-class short-haul landing craft was a special-purpose shuttle, used by the Galactic Republic as a military cargo transport during the Mandalorian Wars.

- **Max Speed:** 500 km/h
- **Hyperdrive:** Class 3
- **Armament:** Light laser cannons
- **Crew:** 1

- **Role:** Shuttle
- **Affiliation:** Galactic Republic
