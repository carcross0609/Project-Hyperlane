# "Explorer" Scout Ship

**Continuity:** Legends  
**Source:** ["Explorer" Scout Ship](https://starwars.fandom.com/wiki/%22Explorer%22_Scout_Ship)

"Explorer" Scout Ships were a starship model from Incom Corporation that measured 15 meters long. Widow Maker and Hell's Axe belonged to this class.

## Specifications

- **Name:** "Explorer" Scout Ship
- **Manufacturer:** Incom Corporation
- **Length:** 15 meters
