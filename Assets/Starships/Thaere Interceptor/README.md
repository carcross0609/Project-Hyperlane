# Thaere Interceptor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thaere Interceptor](https://starwars.fandom.com/wiki/Thaere_Interceptor)

The Thaere Interceptor was a DP20 gunship that saw service with the Navy of Thaere during the Clone Wars. Lieutenant Toric Bisilt was assigned to serve on it for a time and it participated in the Blockade of the Cularin system.

- **Name:** Thaere Interceptor
- **Model:** DP20 gunship
