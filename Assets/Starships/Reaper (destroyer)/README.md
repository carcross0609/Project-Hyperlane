# Reaper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Reaper (destroyer)](https://starwars.fandom.com/wiki/Reaper_%28destroyer%29)

The Reaper was a destroyer, that served in the Confederate Navy, during the Clone Wars. It was armed with forty turbolasers.

## Specifications

- **Name:** Reaper
- **Type:** Destroyer
- **Armament:** Turbolasers (40)
- **Affiliation:** Confederacy of Independent Systems
