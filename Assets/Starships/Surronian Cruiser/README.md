# Surronian Cruiser

**Continuity:** Canon  
**Source:** [Surronian Cruiser](https://starwars.fandom.com/wiki/Surronian_Cruiser)

The Surronian Cruiser, as it was known by historians, was a class cruiser that was considered an ancient and rare design by the time of the Clone Wars. The Haor Chall Engineering Corporation Corona-class armed frigate was considered a knock-off design of the cruiser.
