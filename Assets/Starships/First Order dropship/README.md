# First Order dropship

**Continuity:** Canon  
**Source:** [First Order dropship](https://starwars.fandom.com/wiki/First_Order_dropship)

The First Order used dropships to carry vehicles into battle. Found aboard the mobile capital Supremacy, at least three delivered First Order All Terrain Armored Transports and the superlaser siege cannon to the Battle of Crait in 34 ABY. These vessels could carry six walkers each.

## Specifications

- **Name:** First Order dropship
- **Type:** Dropship
- **Role:** Vehicle transport
- **Affiliation:** First Order
