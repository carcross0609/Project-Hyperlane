# Attack Recon Fighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Attack Recon Fighter](https://starwars.fandom.com/wiki/Attack_Recon_Fighter)

A compact starfighter that saw use during the Clone Wars, where it saw use by Jedi pilots such as Anakin Skywalker. The vehicle boasts a foldable wing to allow it to be transported by the Republic gunships. Offensively, the vehicle boasts a pair of wingtip cannons mounted on rotating turrets to maximize attack potential.

- **Type:** Starfighter
- **Complement:** Wing-mounted cannon (2)

- **Role:** Reconnaissance
