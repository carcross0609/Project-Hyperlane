# Anuti

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Anuti](https://starwars.fandom.com/wiki/Anuti)

The Anuti was a GR-75 medium transport that was part of the Rebel Alliance. It saw service in the Airam sector.

- **Model:** GR-75 medium transport
