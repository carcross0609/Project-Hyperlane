# Galactic Breeze

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Galactic Breeze](https://starwars.fandom.com/wiki/Galactic_Breeze)

The Galactic Breeze was a cruise ship. A number of XLT-014 labor droids were used aboard the ship and when one of the droids programmed the ship's computer with an incorrect destination, the ship was brought off-course and captured by pirates near the planet of Bestine IV.

## Specifications

- **Name:** Galactic Breeze
- **Navigation:** Equipped
- **Crew:** Numerous XLT-014 labor droids
- **Role:** Luxury liner
