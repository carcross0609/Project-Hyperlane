# Lutdze

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lutdze](https://starwars.fandom.com/wiki/Lutdze)

The Lutdze was an MC80 Star Cruiser belonging to the Rebel Alliance. The Lutdze was part of a Rebel fleet mobilizing at the Delfii system prior to the Battle of Endor.
