# Heavy duty lifter

**Continuity:** Canon  
**Source:** [Heavy duty lifter](https://starwars.fandom.com/wiki/Heavy_duty_lifter)

Heavy duty lifters were a type of starship design that existed in the galaxy. The Bellicose-class heavy lifter was a model of starship that served as one type of heavy duty lifter.
