# Starhound

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starhound](https://starwars.fandom.com/wiki/Starhound)

The Starhound was a Simiyiar-class light freighter that was used by the undercover Imperial Security Bureau agent Eren Garai.

## Specifications

- **Name:** Starhound
- **Manufacturer:** Mon Calamari Shipyards
- **Type:** Simiyiar-class light freighter
- **Crew:**

  - 1 Pilot
  - 1 Co-pilot
- **Passengers:** 5
- **Consumables:** 2 months
- **Affiliation:** Imperial Security Bureau
- **Captains:** Eren Garai
