# Dreadnaught

**Continuity:** Legends  
**Source:** [Dreadnaught/Legends](https://starwars.fandom.com/wiki/Dreadnaught/Legends)

]] A dreadnaught or dreadnought was normally a powerful battleship. In the Anaxes War College System it referred to any ship over 5,000 meters long. In some cases, if they were large enough, they could even be listed as superdreadnaughts.
