# Resolve

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Resolve (Epoch-class)](https://starwars.fandom.com/wiki/Resolve_%28Epoch-class%29)

Resolve was an Epoch-class freighter manufactured by Shobquix Yards. The Resolve was owned and operated by the Svivreni Mihalik. The vessel was a gift to Mihalik from Caleb Hctaqsas for an undefined favor. The Resolve was fitted with thrust packages from Koensayr Manufacturing and KapriCorp, giving it a better lift to mass ratio.
