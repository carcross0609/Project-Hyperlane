# Mini Scavenger

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Mini Scavenger](https://starwars.fandom.com/wiki/Mini_Scavenger)

The Mini Scavenger was a small scavenging starship owned by the Freemakers that also doubled as a small shuttle when they were not using the StarScavenger.
