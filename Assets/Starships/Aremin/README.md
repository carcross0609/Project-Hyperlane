# Aremin

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Aremin](https://starwars.fandom.com/wiki/Aremin)

The Aremin was a Star Galleon-class frigate in the Imperial Navy. It was attacked by the smuggler Toob Ancher while suffering from the last stages of Bitter Winter.

- **Name:** Aremin
- **Manufacturer:** Kuat Drive Yards
- **Model:** Star Galleon-class frigate
- **Type:** Frigate
