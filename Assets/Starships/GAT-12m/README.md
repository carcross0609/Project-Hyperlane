# GAT-12m

**Continuity:** Legends  
**Source:** [GAT-12m](https://starwars.fandom.com/wiki/GAT-12m)

The GAT-12m "Skipray" was part of the GAT Blastboat series produced by Sienar Fleet Systems.

## Specifications

- **Name:** GAT-12m
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Interception blastboat
- **Length:** 25 meters
- **Hyperdrive:** Faster than class 2.0
- **Shield Gen:** Equipped
- **Navigation:** Equipped
- **Armament:**
  - 3 medium ion cannons
  - 1 proton torpedo launcher
  - 2 laser cannons
  - 1 concussion missile launcher
- **Crew:** 2 and 2 gunners
- **Affiliation:** Galactic Empire
