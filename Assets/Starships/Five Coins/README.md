# Five Coins

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Five Coins](https://starwars.fandom.com/wiki/Five_Coins)

The Five Coins was the personal starship of Oorn Noth. Noth eventually gave up the ship for a more advanced craft, known as the Last Laugh.
