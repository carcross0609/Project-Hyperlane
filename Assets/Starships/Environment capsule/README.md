# Environment capsule

**Continuity:** Legends  
**Source:** [Environment capsule](https://starwars.fandom.com/wiki/Environment_capsule)

An environment capsule was a type of drop pod used for high orbit precision entry. The four members of the High Orbit Precision Entry Squad used environment capsules during their mission to Yorn Skot.

## Specifications

- **Name:** Environment capsule
- **Crew:** Clone commando (1)
- **Lifesupport:** Equipped
- **Othersystems:** Holographic viewscreen
- **Role:** High orbit precision entry
- **Affiliation:**
  - Galactic Republic
  -   High Orbit Precision Entry Squad
