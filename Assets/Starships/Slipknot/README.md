# Slipknot

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Slipknot](https://starwars.fandom.com/wiki/Slipknot)

The Slipknot was a YT-2400 freighter that Admiral Thrawn and ensign Eli Vanto used during the Batonn insurgency. Thrawn destroyed the freighter during an escape attempt from Nevil Cygni's Nomad starship.

## Specifications

- **Name:** Slipknot
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-2400 light freighter
- **Type:** Light freighter
- **Length:** 21 meters
- **Max Speed:** 800 kph
- **Hyperdrive:** Class 2
- **Armament:**

  - concussion missile launchers
  - Variable
- **Affiliation:**

- **Fleet:** Ninety-Sixth Task Force
