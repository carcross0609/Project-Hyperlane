# Iron Sun

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Iron Sun](https://starwars.fandom.com/wiki/Iron_Sun)

The Iron Sun was a Pellaeon-class Star Destroyer that served with the Imperial Navy prior to the Sith–Imperial War.

- **Manufacturer:** Kuat Drive Yards
- **Model:** Pellaeon-class Star Destroyer
