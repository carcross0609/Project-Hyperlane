# Slader's Raider I

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Slader's Raider I](https://starwars.fandom.com/wiki/Slader%27s_Raider_I)

Slader's Raider I was a Vee-Kir 4 Bulk Transport owned and operated by Roark Slader. It was modified to allow the DP20 frigate Slader's Raider II to be concealed in the bow.

## Specifications

- **Name:** Slader's Raider I
- **Model:** Vee-Kir 4 Bulk Transport
- **Role:** Pirate vessel
- **Owners:** Roark Slader
