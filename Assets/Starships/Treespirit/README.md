# Treespirit

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Treespirit](https://starwars.fandom.com/wiki/Treespirit)

The Treespirit was a Ghtroc Class 720 freighter owned by the Wookiee pirate Grakkata. Painted a forest green in remembrance of the Wookiee homeworld, the craft appeared battered, but was extensively modified and heavily-armed with four retractable laser cannons.
