# Leia Organa's Rebel scout craft

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Leia Organa's Rebel scout craft](https://starwars.fandom.com/wiki/Leia_Organa%27s_Rebel_scout_craft)

An unidentified starship was used as a scout ship by Luke Skywalker and Princess Leia Organa in 0 ABY to make contact with the Akuria Rebel Base. It was destroyed in the Akuria system by robotic TIE/LN starfighters and forced to crash-land on Akuria II.

- **Name:** Leia Organa's Rebel scout craft
- **Armament:** Double laser turret
- **Role:** Scout craft
