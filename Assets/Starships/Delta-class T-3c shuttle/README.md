# Delta-class T-3c shuttle

**Continuity:** Canon  
**Source:** [Delta-class T-3c shuttle](https://starwars.fandom.com/wiki/Delta-class_T-3c_shuttle)

The Delta-class T-3c shuttle, or simply the Delta-class shuttle, was a type of shuttle used by the Galactic Empire around the time of the Battle of Yavin. Director Orson Krennic owned one such vessel. It had a starkly geometric hull shape and folding bat-like wings.
