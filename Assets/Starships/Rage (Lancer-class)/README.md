# Rage

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rage (Lancer-class)](https://starwars.fandom.com/wiki/Rage_%28Lancer-class%29)

The Rage was an Imperial Navy Lancer-class frigate that was stationed in 0 ABY alongside two IPV-1 System Patrol Craft, Green/Aura and Green/Besh, at the Galactic Empire's Bavos-II military space platform Station 1B6/Green, on the edge of the Core Worlds' Ringali Nebula. The Rage had 20 Quad laser cannons, and, as a Lancer-class frigate, was manufactured by Kuat Drive Yards. It measured 250 meters long.
