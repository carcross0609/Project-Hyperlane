# Whipsaw

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Whipsaw](https://starwars.fandom.com/wiki/Whipsaw)

The Whipsaw was a Republic Light Cruiser that served in the Republic Navy during the Clone Wars. It was commanded by General Fyefee Tiis and participated in the Battle of Cartao, where it disabled a Separatist Lucrehulk-class Droid Control Ship.

## Specifications

- **Name:** Whipsaw
- **Type:** Light Cruiser
- **Destroyed:** 22 BBY
- **Captains:** General Fyefee Tiis
