# Unidentified Providence-class Dreadnought

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Providence-class Dreadnought (Attack on a Republic fleet)](https://starwars.fandom.com/wiki/Unidentified_Providence-class_Dreadnought_%28Attack_on_a_Republic_fleet%29)

A Providence-class Dreadnought took part in an attack on a Republic fleet during the Clone Wars between 21 BBY and 19 BBY. The Providence had the same hull markings as the Invincible, the flagship of Admiral Trench that was lost in the Battle of Christophsis of 22 BBY.
