# Farlight

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Farlight](https://starwars.fandom.com/wiki/Farlight)

The Farlight was a New Republic ship sent to Wehttam with the Jantol to protect it from the Yevetha. It was once part of the New Republic Third Fleet.
