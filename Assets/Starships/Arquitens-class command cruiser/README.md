# Arquitens-class command cruiser

**Continuity:** Canon  
**Source:** [Arquitens-class command cruiser](https://starwars.fandom.com/wiki/Arquitens-class_command_cruiser)

The Arquitens-class command cruiser, also known as the Imperial light cruiser, was a multipurpose light cruiser used by the Imperial Navy, in which it filled roles from detached patrol vessel to communications ship to capital ship support. It was a reworking of Kuat Drive Yards' Arquitens-class light cruiser, though they shared only structural similarities.
