# Thackery

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thackery](https://starwars.fandom.com/wiki/Thackery)

The Thackery was a warship that saw service with the New Republic Defense Fleet during the Black Fleet Crisis. It was sent to Galantos, along with the Gol Storn in order to protect it from the Yevetha.
