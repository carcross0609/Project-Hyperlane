# Virella Systems cargo freighter

**Continuity:** Legends  
**Source:** [Virella Systems cargo freighter](https://starwars.fandom.com/wiki/Virella_Systems_cargo_freighter)

The Virella Systems cargo freighter was a long-distance freight haulage solution designed by Virella Systems for use in conjunction with several classes of Xizor cargo containers. In this respect it was similar to Virella Systems' other widespread cargo vessel, the cargo tanker.

## Specifications

- **Name:** Virella Systems cargo freighter
- **Manufacturer:** Virella Systems
- **Max Accel:** 9 MGLT/second
- **Mglt:** 33 MGLT
- **Hdsystem:** Equipped
- **Shield Gen:** Rated 320 SBD
- **Hull:** Rated 36 RU
- **Armament:** None
- **Crew:** 3-6
- **Role:** Cargo hauler
- **Affiliation:**
  - Galactic Empire
  - Rebel Alliance
  - Various private, commercial, and pirate interests
