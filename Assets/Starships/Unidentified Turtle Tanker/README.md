# Unidentified Turtle Tanker

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Turtle Tanker](https://starwars.fandom.com/wiki/Unidentified_Turtle_Tanker)

A Terrapin-class Bulk Tanker was owned by a Sakiyan cargo hauler during the Clone Wars. In 20 BBY, it was used by Savage Opress in order to escape from the planet Stobar and retrieve his brother Darth Maul from Lotho Minor to take him back to Dathomir.
