# Ramship

**Continuity:** Legends  
**Source:** [Ramship](https://starwars.fandom.com/wiki/Ramship)

A ramship was a term used to refer to starships used for the sole purpose of ramming other vessels during space battles. Most ramships were built from the frame of standard starships though their interiors would be packed with explosives. Due to the highly dangerous profile of the mission, few sentients would pilot these craft and many were entirely automated like robot ramships.
