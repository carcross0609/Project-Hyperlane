# Spotrunner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Spotrunner](https://starwars.fandom.com/wiki/Spotrunner)

The Spotrunner was a Galactic Republic scout ship. During an expedition into the depths of the Unknown Regions, a Mnggal-Mnggal outbreak occurred on Spotrunner which lead to the death of the entire crew.

- **Name:** Spotrunner
- **Type:** Scout ship
