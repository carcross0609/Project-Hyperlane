# CR25 troop carrier

**Continuity:** Legends  
**Source:** [CR25 troop carrier/Legends](https://starwars.fandom.com/wiki/CR25_troop_carrier/Legends)

The CR25 troop carrier, more commonly known as the Republic dropship, was a multipurpose dropship used to deploy units of clone troopers and gunships in battlefronts where the use of an Acclamator-class assault ship was deemed too impractical.

## Specifications

- **Name:** CR25 troop carrier
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** CR25 troop carrier
- **Type:** Dropship
- **Length:** 60 meters
- **Hdsystem:** Equipped
- **Shield Gen:** Equipped
- **Armament:** Twin turbolaser cannons (2)
- **Complement:**
  - 8 LAAT/i gunships
- **Passengers:** 40 clone troopers
- **Capacity:** Appropriate supplies for complement and troops
- **Role:** Troop/supply transport
- **Affiliation:**
  - Galactic Republic
  - Galactic Empire
