# Unidentified Republic command ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Republic command ship](https://starwars.fandom.com/wiki/Unidentified_Republic_command_ship)

A Venator-class Star Destroyer served as a Galactic Republic command ship during the Clone Wars. High Jedi General Obi-Wan Kenobi and Clone Marshal Commander CC-2224 were present on the vessel after the destruction of his flagship, the Negotiator.
