# YT-450

**Continuity:** Canon  
**Source:** [YT-450](https://starwars.fandom.com/wiki/YT-450)

The YT-450 was a type of freighter used by the Alliance to Restore the Republic. Lando Calrissian included the YT-450 in a report on vessels that might suit the Alliance's needs that he sent to Admiral Gial Ackbar prior to the Battle of Endor.

## Specifications

- **Name:** YT-450
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Type:** Freighter
