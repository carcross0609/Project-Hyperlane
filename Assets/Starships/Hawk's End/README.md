# Hawk's End

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Hawk's End](https://starwars.fandom.com/wiki/Hawk%27s_End)

The Hawk's End was a starship used by the Rebel Alliance under the command of Captain Magna Tolvan during the Imperial Era. Between 3 ABY and 4 ABY, Tolvan used the ship to depart from Mareti Base on the Outer Rim astronimical object Hiorin. Tolvan later used the ship to travel with her crew to a Rebel Base where General Leia Organa was based.

## Specifications

- **Affiliation:**

- **Navy:** Rebel Alliance Navy
