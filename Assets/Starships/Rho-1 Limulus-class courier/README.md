# Rho-1 Limulus-class courier

**Continuity:** Canon  
**Source:** [Rho-1 Limulus-class courier](https://starwars.fandom.com/wiki/Rho-1_Limulus-class_courier)

A Rho-1 Limulus-class courier was used by Obi-Wan Kenobi and Qui-Gon Jinn during a mission to help miners on the Codia's second moon. It was commonly used in the Clone Wars.
