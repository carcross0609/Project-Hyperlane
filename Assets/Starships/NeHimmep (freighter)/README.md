# NeHimmep

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [NeHimmep (freighter)](https://starwars.fandom.com/wiki/NeHimmep_%28freighter%29)

NeHimmep was a Starfeld Industries ZH-25 Questor-class freighter, named for a famous Duros explorer. Her owner, Captain Mirchidi NeMall, used it for non-smuggling trading purposes.
