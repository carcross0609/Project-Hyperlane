# Sigma 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sigma 2 (escort shuttle)](https://starwars.fandom.com/wiki/Sigma_2_%28escort_shuttle%29)

Sigma 2 was an Imperial Delta-class JV-7 escort shuttle. Along with Sigma 1, Sigma 3, and Omega 1, Sigma 2 attack on the factory ZA-13, which at the time was held by traitorous Grand Admiral Demetrius Zaarin.
