# Diamond-class cruiser

**Continuity:** Canon  
**Source:** [Diamond-class cruiser](https://starwars.fandom.com/wiki/Diamond-class_cruiser)

The Diamond-class cruiser, also known simply as the Commerce Guild cruiser and Commerce Guild Starship, was a class of cruiser used by the Commerce Guild. Forty-one such ships were involved in the First Battle of Geonosis, which was the first battle of the Clone Wars.

## Specifications

- **Name:** Diamond-class cruiser
- **Manufacturer:** Commerce Guild
- **Model:** Diamond-class cruiser
- **Type:**
  - Cruiser
  - Transport
- **Length:** 200 meters
- **Hyperdrive:** Class 0.75
- **Hdsystem:** Equipped
- **Armament:** Laser cannons (2)
- **Complement:** OG-9 homing spider droids or DSD1 dwarf spider droids
- **Crew:** 148
- **Role:** Defense
- **Affiliation:**
  - Commerce Guild
  - Confederacy of Independent Systems
  -   Confederacy of Independent Systems Navy
