# Reaver

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Reaver (Sabaoth destroyer)](https://starwars.fandom.com/wiki/Reaver_%28Sabaoth_destroyer%29)

The Reaver was a Sabaoth destroyer under the command of Lieutenant Bella, ensign to Captain Cavik Toth. The Reaver saw combat just prior to the Clone Wars.
