# Pertenax

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pertenax](https://starwars.fandom.com/wiki/Pertenax)

The Pertenax was a MC40a light cruiser that served with the Rebel Alliance during the Galactic Civil War. It was present at the shipyard Calenz in the Nocto system not long before the Battle of Nocto.

## Specifications

- **Name:** Pertenax
- **Model:** MC40a light cruiser
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
