# Davaab-type starfighter

**Continuity:** Legends  
**Source:** [Davaab-type starfighter](https://starwars.fandom.com/wiki/Davaab-type_starfighter)

The Davaab-type starfighter was a type of starfighter used by the Mandalorians from before and during the Mandalorian Wars.
