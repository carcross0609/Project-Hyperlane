# Recalcitrant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Recalcitrant](https://starwars.fandom.com/wiki/Recalcitrant)

Recalcitrant was an Imperial warship that took part in the Battle of ThonBoka. It opened fire on The Rest when they arrived to break up the battle, and was subsequently destroyed.
