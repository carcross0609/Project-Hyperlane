# Ore hauler

**Continuity:** Legends  
**Source:** [Ore hauler](https://starwars.fandom.com/wiki/Ore_hauler)

An ore hauler was a starship smaller than a Tsukkian water freighter. The Rebel SpecForce elite unit Reekeene's Roughnecks had two of these.
