# BT-7 Thunderclap

**Continuity:** Legends  
**Source:** [BT-7 Thunderclap](https://starwars.fandom.com/wiki/BT-7_Thunderclap)

The BT-7 Thunderclap was an assault ship model in the Republic Military, commonly used by Republic troopers. It was based on smaller rapid-assault ships used during the Great Galactic War.

## Specifications

- **Name:** BT-7 Thunderclap
- **Designer:** Ryden Pollad
- **Manufacturer:** Rendili Hyperworks
- **Type:** Rapid assault/deployment craft
- **Length:** 96 meters
- **Width:** 61 meters
- **Height:** 80 meters
- **Shield Gen:** Modular shields
- **Armament:**
  - Heavy laser cannons (3)
  - Missiles
- **Communications:** Long-range encrypted holotransmitter
- **Availability:** Military
- **Role:** Rapid assault ship
- **Firstuse:** Before 3653 BBY
- **Affiliation:**
  - Galactic Republic
  -   Republic Military
  -   Republic Navy
  -   Republic Special Forces Division
