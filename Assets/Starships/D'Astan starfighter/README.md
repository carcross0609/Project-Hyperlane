# D'Astan starfighter

**Continuity:** Legends  
**Source:** [D'Astan starfighter](https://starwars.fandom.com/wiki/D%27Astan_starfighter)

The D'Astan starfighter was a starfighter design used by Imperial Baron Ragez D'Asta's private fleet. This force composed the largest privately owned starfighter fleet in the galaxy.
