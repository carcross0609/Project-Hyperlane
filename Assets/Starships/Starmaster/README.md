# Starmaster

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starmaster](https://starwars.fandom.com/wiki/Starmaster)

The Starmaster was a freighter the size of a Victory-class Star Destroyer. It was used by Rol'Waran and Crev Bombaasa to smuggle spice for the Hutts.
