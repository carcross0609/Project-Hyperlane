# Darkness

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Darkness (battlecruiser)](https://starwars.fandom.com/wiki/Darkness_%28battlecruiser%29)

The Darkness was a battlecruiser that served as the flagship of the Sith Lord Darth Angral. It saw action in the Sacking of Coruscant. It would later be replaced by the Oppressor as Angral's flagship.
