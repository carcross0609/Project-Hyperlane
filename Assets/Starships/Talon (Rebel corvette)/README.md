# Talon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Talon (Rebel corvette)](https://starwars.fandom.com/wiki/Talon_%28Rebel_corvette%29)

Talon was an CR90 corvette used by the Rebel Alliance. It accompanied the cruiser Liberty on a number of occasions, at times when Liberty was not operating alone.

## Specifications

- **Name:** Talon
- **Line:** Corellian Engineering Corporation
- **Model:** CR series
- **Type:** CR90 corvette
- **Cost:** Corvette
- **Length:** 150 meters
- **Width:** 48.6 meters
- **Height:** 32.6 meters
- **Affiliation:** Alliance to Restore the Republic
