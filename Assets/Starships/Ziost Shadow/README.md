# Ziost Shadow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ziost Shadow](https://starwars.fandom.com/wiki/Ziost_Shadow)

The Ziost Shadow was a Harrower-class dreadnought that served the reconstituted Sith Empire during the Cold War and was named after the planet Ziost.

## Specifications

- **Name:** Ziost Shadow
- **Model:** Harrower-class dreadnought
- **Type:** Dreadnaught
- **Armament:** Turbolasers
- **Complement:**
  - Mark VI Supremacy-class starfighters
  - Shuttles
- **Role:**
  - Armed transport
  - Logistical support
- **Affiliation:**
  - Sith Empire
  -   Imperial Navy
