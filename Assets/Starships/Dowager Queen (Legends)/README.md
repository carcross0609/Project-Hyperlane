# Dowager Queen

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dowager Queen/Legends](https://starwars.fandom.com/wiki/Dowager_Queen/Legends)

The Dowager Queen, or "Jah Dowahga Kwee-Kunee" in Huttese, was a colony ship from Bestine IV that crash-landed on the planet of Tatooine in 100 BBY.

- **Name:** Dowager Queen
- **Type:** Colony ship
