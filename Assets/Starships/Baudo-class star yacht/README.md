# Baudo-class star yacht

**Continuity:** Legends  
**Source:** [Baudo-class star yacht](https://starwars.fandom.com/wiki/Baudo-class_star_yacht)

The Baudo-class star yacht was a yacht manufactured by Mendel Baudo Shipyards. A favorite ship of rich youngsters, it also had the ability to be easily modified, so the ship was sometimes used by smugglers.

## Specifications

- **Name:** Baudo-class star yacht
- **Manufacturer:** Mendel Baudo Shipyards
- **Model:** Baudo-class star yacht
- **Type:** Light freighter
- **Cost:** 400,000 credits (250,000 used)
- **Length:** 32 meters
- **Max Speed:** 1,200 km/h
- **Hyperdrive:**
  - Class 2.0
  - Backup Class 7.0 or 12.0
- **Sensor:** Equipped
- **Armament:** Laser cannon turret (1)
- **Crew:**
  - 1 pilot
  - 1 co-pilot/engineer
- **Passengers:** 8
- **Capacity:** 35 tons
- **Consumables:** 1 month
- **Role:**
  - Yacht
  - Light freighter
