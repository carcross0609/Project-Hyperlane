# Great camel-head class cargo ship

**Continuity:** Canon  
**Source:** [Great camel-head class cargo ship](https://starwars.fandom.com/wiki/Great_camel-head_class_cargo_ship)

The Great Camel-head class cargo ship was a popular and cheap civilian Freighter in the Aakaash system. It was designed with saving space and having an attractive exterior in mind. This led to a flaw where many critical energy pipelines were all concentrated under the cargo hold in a maintenance tunnel. Damage in this part of the Starship would cause the loss of about 50% of the ship's power. This was accounted for by the designers by surrounding the tunnel with a thick metal wall. Other than damage to this flawed area, the ship was said to be easy to repair and maintain. The ship had a top-heavy structure with the bridge at the front.
