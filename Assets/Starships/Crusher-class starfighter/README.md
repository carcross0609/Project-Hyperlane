# Crusher-class starfighter

**Continuity:** Legends  
**Source:** [Crusher-class starfighter](https://starwars.fandom.com/wiki/Crusher-class_starfighter)

The Crusher-class starfighter was a two-man starfighter equipped with formidable cannons used by two Bounty hunters working for the Kaminoans during the Clone Wars.
