# Neimoidian Grasp

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Neimoidian Grasp](https://starwars.fandom.com/wiki/Neimoidian_Grasp)

The Neimoidian Grasp was a Trident-class assault ship that served in the naval forces of the Confederacy of Independent Systems. During the Clone Wars, the Neimoidian Grasp fought underwater on the planet Mon Cala.

## Specifications

- **Name:** Neimoidian Grasp
- **Model:** Trident-class assault ship
- **Type:** Assault ship
