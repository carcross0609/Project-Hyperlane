# Bureaucrat's Triumph

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bureaucrat's Triumph](https://starwars.fandom.com/wiki/Bureaucrat%27s_Triumph)

A military CR90 corvette, Bureaucrat's Triumph was the central component of Algara II's planetary defense force, aided only by a squadron of Z-95 Headhunters.
