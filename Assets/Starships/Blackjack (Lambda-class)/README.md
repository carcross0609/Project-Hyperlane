# Blackjack

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blackjack (Lambda-class)](https://starwars.fandom.com/wiki/Blackjack_%28Lambda-class%29)

Blackjack was a Lambda-class shuttle used by the Imperials. The shuttle was on its way to the Star Destroyer Relentless carrying a spy when it was shot down by Keyan Farlander in a B-wing.

## Specifications

- **Name:** Blackjack
- **Model:** Lambda-class T-4a shuttle
- **Type:** Shuttle
- **Destroyed:** During the Galactic Civil War
- **Affiliation:** Galactic Empire
