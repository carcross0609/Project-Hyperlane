# Sun jammer

**Continuity:** Legends  
**Source:** [Sun jammer](https://starwars.fandom.com/wiki/Sun_jammer)

Sun jammers were a type of solar wind-driven recreational vehicle/racing ship. Piloting a sun jammer was known as "sun jamming." Popular sun jammer racing events included the Chandrilan Cometary Games.
