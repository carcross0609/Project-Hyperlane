# Freighter-class vessel

**Continuity:** Legends  
**Source:** [Freighter-class vessel](https://starwars.fandom.com/wiki/Freighter-class_vessel)

The Zygerrian Freighter-class vessel was a class of freighters used by the Zygerrians. The Fate's Hand was a member of this starship class.

## Specifications

- **Name:** Freighter-class vessel
- **Role:** Freighter
- **Firstuse:** c. 22 BBY
- **Affiliation:** Zygerria
