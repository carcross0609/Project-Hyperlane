# Fell Defender

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fell Defender](https://starwars.fandom.com/wiki/Fell_Defender)

Fell Defender was the Chiss Star Destroyer that Commander Jagged Fel was in command of during the Dark Nest Crisis and later, the Swarm War. It captured the Millennium Falcon above Tenupe.
