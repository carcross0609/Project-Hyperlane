# Trainer (starship)

**Continuity:** Canon  
**Source:** [Trainer (starship)](https://starwars.fandom.com/wiki/Trainer_%28starship%29)

A trainer was a type of starship used for the training of pilots. The RZ-1T trainer was a model of A-wing trainer developed during the early rebellion against the Galactic Empire which, unlike the base RZ-1, featured an instructor's seat at the back of the cockpit.
