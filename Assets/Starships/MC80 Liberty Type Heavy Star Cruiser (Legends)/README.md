# MC80 Liberty Type Heavy Star Cruiser

**Continuity:** Legends  
**Source:** [MC80 Liberty Type Heavy Star Cruiser/Legends](https://starwars.fandom.com/wiki/MC80_Liberty_Type_Heavy_Star_Cruiser/Legends)

The MC80 Liberty Type Heavy Star Cruiser or MC80 Liberty type Star Cruiser was an early type of Mon Calamari Star Cruiser put into service for the Rebel Alliance during the Galactic Civil War.
