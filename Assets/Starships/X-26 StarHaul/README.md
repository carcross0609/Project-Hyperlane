# X-26 StarHaul

**Continuity:** Legends  
**Source:** [X-26 StarHaul](https://starwars.fandom.com/wiki/X-26_StarHaul)

The X-26 StarHaul was a freighter developed by Incom Corporation and utilized most by the Galactic Empire.

## Specifications

- **Name:** X-26 StarHaul
- **Manufacturer:** Incom Corporation
- **Type:** Space barge
- **Cost:**
  - 400,000 Galactic Credit Standard (new)
  - 175,000 credits (used)
- **Length:** 55 meters
- **Max Speed:** 200 kmh
- **Hyperdrive:** Class 4
- **Navigation:** Equipped
- **Armament:** Double laser cannon
- **Crew:** 2; 1 droid
- **Capacity:** 5,000 metric tons, 2,000 cubic meters
- **Consumables:** 1 week
- **Role:** Cargo barge
