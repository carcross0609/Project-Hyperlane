# Liberty

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Liberty (Majestic-class)](https://starwars.fandom.com/wiki/Liberty_%28Majestic-class%29)

The Liberty was a Majestic-class heavy cruiser in the New Republic's Fifth Battle Group. It was named in honor of the MC80 Star Cruiser lost at the Battle of Endor
