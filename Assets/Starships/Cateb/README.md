# Cateb

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cateb](https://starwars.fandom.com/wiki/Cateb)

Delta-class JV-7 escort shuttle Cateb was an Airam starship. It was present at Goff Platform, where it was destroyed during the Imperial attack there along with the rest of the defense force.
