# Daunted Gypsy

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Daunted Gypsy](https://starwars.fandom.com/wiki/Daunted_Gypsy)

The Daunted Gypsy was a Jermaguim-class Light Freighter operated by the New Republic. It was used by Republic operatives during the Freedom Strike Seltos operation.
