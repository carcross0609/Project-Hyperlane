# B-4RB Haunter

**Continuity:** Canon  
**Source:** [B-4RB Haunter](https://starwars.fandom.com/wiki/B-4RB_Haunter)

The B-4RB Haunter was a starfighter used by the Ashiga Clan during the Imperial Era. The B-4RB was armed with two laser cannons and had two large sublight engines.
