# Burst Fire-class Deep-Space Patrol Vessel

**Continuity:** Legends  
**Source:** [Burst Fire-class Deep-Space Patrol Vessel](https://starwars.fandom.com/wiki/Burst_Fire-class_Deep-Space_Patrol_Vessel)

The Burst Fire-class Deep-Space Patrol Vessel, also called pocket corvette, was a deep space patrol vessel with usually 30 crewmembers used by the Imperial Remnant. It had a length of 60 Imperial standard meters and a complement of two TIE Interceptors and one shuttle.
