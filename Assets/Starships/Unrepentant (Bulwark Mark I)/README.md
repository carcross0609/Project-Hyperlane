# Unrepentant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unrepentant (Bulwark Mark I)](https://starwars.fandom.com/wiki/Unrepentant_%28Bulwark_Mark_I%29)

The Unrepentant was a Bulwark Mark I battlecruiser that served the Confederacy of Independent Systems as Admiral Dua Ningo's flagship in the Bulwark Fleet. The ship was destroyed during the Battle of Anaxes in 20 BBY.
