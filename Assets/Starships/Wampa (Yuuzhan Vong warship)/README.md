# Wampa (Yuuzhan Vong warship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wampa (Yuuzhan Vong warship)](https://starwars.fandom.com/wiki/Wampa_%28Yuuzhan_Vong_warship%29)

Wampa was a New Republic designation given to a Yuuzhan Vong warship that fought at the Second Battle of Sernpidal during the Yuuzhan Vong War. It was destroyed by Rogue Squadron pilots.
