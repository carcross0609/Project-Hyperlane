# Zonama Sekotan fighter

**Continuity:** Legends  
**Source:** [Zonama Sekotan fighter](https://starwars.fandom.com/wiki/Zonama_Sekotan_fighter)

The Zonama Sekotan fighter was a three-lobed bioship armed with lava cannons and propelled by a dovin basal that Zonama Sekot grew for defense against the Yuuzhan Vong.
