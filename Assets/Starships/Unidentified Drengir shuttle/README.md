# Unidentified Drengir shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Drengir shuttle](https://starwars.fandom.com/wiki/Unidentified_Drengir_shuttle)

A shuttle was used by the Drengir to leave the planet Banchii. The Drengir, who had a truce with the Jedi on Banchii, were given the ship by Jedi Knight Lily Tora-Asi in exchange for agreeing to help protect the planet.
