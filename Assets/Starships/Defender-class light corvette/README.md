# Defender-class light corvette

**Continuity:** Canon  
**Source:** [Defender-class light corvette](https://starwars.fandom.com/wiki/Defender-class_light_corvette)

The Defender-class light corvette was a class of light corvette manufactured by the Rendili Vehicle Corporation that was used by the Jedi Order. Although there was not official evidence presented, the Paladin-class corvette was likely influenced by the Defender-class, which was an ancient design. It was introduced long before the Clone Wars, and the visual similarities between both the Defender-class and the Paladin-class were not likely to be a coincidence. Similar to the Defender-class, the Crucible, a Paladin-class corvette, featured a front section that was shaped as an anvil.

## Specifications

- **Name:** Defender-class light corvette
- **Manufacturer:** Rendili Vehicle Corporation
- **Model:** Defender-class
- **Type:** Light corvette
- **Affiliation:** Jedi Order
