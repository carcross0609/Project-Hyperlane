# Counter-Puncher

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Counter-Puncher](https://starwars.fandom.com/wiki/Counter-Puncher)

Counter-Puncher was a modified Imperial Customs Frigate commanded by Tor Skylow. Skylow persuaded the crew to rebel from the Empire, taking the ship with them. She was used as a pirate craft, raiding Imperial craft.
