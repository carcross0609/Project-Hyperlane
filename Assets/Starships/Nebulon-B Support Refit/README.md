# Nebulon-B Support Refit

**Continuity:** Legends  
**Source:** [Nebulon-B Support Refit](https://starwars.fandom.com/wiki/Nebulon-B_Support_Refit)

The Nebulon-B Support Refit was a refit of the EF76 Nebulon-B escort frigate used by the Alliance to Restore the Republic during the Galactic Civil War. At some point, a frigate of this class was attacked by several TIE/LN starfighters.

## Specifications

- **Name:** Nebulon-B Support Refit
- **Model:** EF76 Nebulon-B escort frigate
- **Type:** Frigate
- **Affiliation:**
  - Alliance to Restore the Republic
  -   Alliance Fleet
