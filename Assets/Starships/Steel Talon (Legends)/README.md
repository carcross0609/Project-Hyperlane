# Steel Talon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Steel Talon/Legends](https://starwars.fandom.com/wiki/Steel_Talon/Legends)

The Steel Talon was an Imperial-class Star Destroyer commanded by Admiral Conan Antonio Motti. It was part of the Sector Fleet tasked with guarding the construction of the Death Star at Despayre.

## Specifications

- **Name:** Steel Talon
- **Manufacturer:** Kuat Drive Yards
- **Line:** Star Destroyer
- **Type:** Imperial-class Star Destroyer
- **Navy:** Admiral Motti's Sector Fleet
- **Captains:** Admiral Motti
