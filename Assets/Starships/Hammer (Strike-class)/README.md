# Hammer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hammer (Strike-class)](https://starwars.fandom.com/wiki/Hammer_%28Strike-class%29)

Hammer was an Imperial Strike-class medium cruiser created by Loronar Corporation. It was assigned to a small fleet under the command of Captain Vocis Kenit during his search for the vessel Far Orbit, which had committed mutiny against him.

## Specifications

- **Name:** Hammer
- **Manufacturer:** Loronar Corporation
- **Model:** Strike-class cruiser
- **Type:** Cruiser
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
