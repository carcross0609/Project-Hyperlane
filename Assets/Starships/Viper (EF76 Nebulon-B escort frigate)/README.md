# Viper (EF76 Nebulon-B escort frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Viper (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Viper_%28EF76_Nebulon-B_escort_frigate%29)

Viper was a EF76 Nebulon-B escort frigate belonging to the Rebel Alliance. The frigate had, along with several other rebel starships were part of a military summit located at the Delfii system. The ship was for some reason needing new engines which were delivered by the CR90 corvette Deep. Her cargo was warheads.
