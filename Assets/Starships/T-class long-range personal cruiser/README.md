# T-class long-range personal cruiser

**Continuity:** Canon  
**Source:** [T-class long-range personal cruiser](https://starwars.fandom.com/wiki/T-class_long-range_personal_cruiser)

The T-class long-range personal cruiser was a type of starship that possessed a pair of folding wings. The Valcyn was one such cruiser, which was used by multiple Sith Lords, including Darth Bane.

## Specifications

- **Name:** T-class long-range personal cruiser
- **Model:** T-class
- **Type:** Personal cruiser
- **Affiliation:** Sith
