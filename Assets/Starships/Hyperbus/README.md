# Hyperbus

**Continuity:** Canon  
**Source:** [Hyperbus](https://starwars.fandom.com/wiki/Hyperbus)

A hyperbus was a variant of transport ship used for public transportation. Obi-Wan Kenobi and Anakin Skywalker caught a hyperbus from a planetoid to the Wheel in the Besh Gorgon system.

## Specifications

- **Name:** Hyperbus
- **Type:** Transport
- **Role:** Public transportation
