# Timely

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Timely](https://starwars.fandom.com/wiki/Timely)

Timely was an Imperial Armored Transport of the same class as Elusive. Both vessels saw service with the Imperial Navy, participating in a series of intelligence and salvage operations at the former Rebel Alliance base on Dankayo.

## Specifications

- **Name:** Timely
- **Model:** Imperial Armored Transport
- **Type:** Transport
- **Length:** 50 meters
- **Hyperdrive:** Class 2
- **Capacity:** 30,000 metric tons
- **Consumables:** 3 months
- **Affiliation:** Galactic Empire
