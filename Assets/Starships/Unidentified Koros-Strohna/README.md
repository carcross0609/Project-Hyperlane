# Unidentified Koros-Strohna

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Koros-Strohna](https://starwars.fandom.com/wiki/Unidentified_Koros-Strohna)

A cramped Koros-Strohna was the home of Uunu, one of the Shamed Ones. It was one of the poorest of the worldships.
