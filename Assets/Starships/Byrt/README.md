# Byrt

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Byrt](https://starwars.fandom.com/wiki/Byrt)

Byrt was a 200-meter public starferry on Coruscant. It was used to evacuate people from Eastport during the Battle of Coruscant. It was built to handle 5,000 passengers but took on 12,000. During the evacuation it was invaded by Yuuzhan Vong looking for Ben Skywalker, but were driven off by YVH 1 droids under Lando Calrissian and Ba'tra.
