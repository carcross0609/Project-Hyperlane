# IDT-28

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [IDT-28](https://starwars.fandom.com/wiki/IDT-28)

IDT-28 was the designation of a starship used to transport new recruits into the Galactic Empire. While it was located at Coronet Spaceport on Corellia, the Imperial Recruitment Officer Drawd Munbrin sent a recruit to IDT-28.

## Specifications

- **Name:** IDT-28
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
