# Field Secured Container Vessel

**Continuity:** Legends  
**Source:** [Field Secured Container Vessel/Legends](https://starwars.fandom.com/wiki/Field_Secured_Container_Vessel/Legends)

A Field Secured Container Vessel (FSCV) was a type of bulk transport vessel used by the Imperial Navy.

## Specifications

- **Name:** Field Secured Container Vessel
- **Manufacturer:**
  - Loronar Corporation
  - Rendili StarDrive
- **Model:** Field Secured Container Vessel
- **Length:**
  - Loronar design:
  -   ~19,200 meters (with maximum number of field bubbles)
  - Rendili design:
  -   ~10,400 meters (with maximum number of field bubbles)
- **Crew:** Rendili design: 100 (per tug)
- **Capacity:**
  - Loronar design:
  -   Up to 5 billion cubic meters
  - Rendili design:
  -   Up to 990 million tons
- **Role:** Massive transport vessel
- **Affiliation:** Galactic Empire
