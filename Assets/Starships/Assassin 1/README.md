# Assassin 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Assassin 1](https://starwars.fandom.com/wiki/Assassin_1)

Assassin 1 was an Imperial CR90 corvette. It was sent to destroy a container full of grain that was earlier dropped in haste to escape an ambush and then sent to be picked up again. The Assassin 1, however was destroyed by Rebel ace Keyan Farlander.
