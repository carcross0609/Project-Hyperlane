# Fighter Gold

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fighter Gold](https://starwars.fandom.com/wiki/Fighter_Gold)

Fighter Gold was a squadron of E-wing escort starfighters assigned to the Endurance-class fleet carrier Intrepid of the New Republic Defense Fleet Fifth Battle Group.
