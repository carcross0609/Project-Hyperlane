# Starswan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starswan](https://starwars.fandom.com/wiki/Starswan)

The Starswan was a passenger liner active in 0 BBY. It was stationed in the Tatooine spaceport Mos Eisley that year, and the Gotal tax collector Feltipern Trevagg booked passage on it for the H'nemthe M'iiyoom Onith to her homeworld of H'nemthe.
