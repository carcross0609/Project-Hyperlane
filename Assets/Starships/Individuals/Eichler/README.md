# Eichler

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eichler](https://starwars.fandom.com/wiki/Eichler)

Eichler was a BFF-1 bulk freighter that supported the task force, led by the Imperial-class Star Destroyer Invincible, during Operation Strike Fear. While mustering in the Dellalt system it was identified as carrying military equipment by a Rebel reconnaissance mission flown by Keyan Farlander in a lone R-22 Spearhead.
