# Light Racer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Light Racer](https://starwars.fandom.com/wiki/Light_Racer)

The Light Racer was a starship that operated around the time of the Yuuzhan Vong War. In 27 ABY, it arrived at Nova Station, where the arrival was indicated in the Big Boom Cantina.
