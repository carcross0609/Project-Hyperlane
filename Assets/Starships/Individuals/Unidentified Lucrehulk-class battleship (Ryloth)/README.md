# Unidentified Lucrehulk-class battleship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Lucrehulk-class battleship (Ryloth)](https://starwars.fandom.com/wiki/Unidentified_Lucrehulk-class_battleship_%28Ryloth%29)

During the Clone Wars, a Lucrehulk-class battleship served in the naval forces of the Confederacy of Independent Systems, where it was used as the flagship of Neimoidian Captain Mar Tuuk. In 21 BBY, the Lucrehulk was placed in command of the Confederacy's blockade of the planet Ryloth, and was contested by a Galactic Republic fleet led by Jedi General Anakin Skywalker.
