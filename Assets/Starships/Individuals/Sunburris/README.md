# Sunburris

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sunburris](https://starwars.fandom.com/wiki/Sunburris)

The Sunburris was a proposed praxeum ship envisioned by the Jedi ace Crix Sunburris. It was eventually realized as the starship Chu'unthor.
