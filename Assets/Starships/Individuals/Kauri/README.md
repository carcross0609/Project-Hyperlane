# Kauri

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kauri](https://starwars.fandom.com/wiki/Kauri)

Kauri was an Agave-class picket ship assigned by the New Republic to assist in the capture of the Teljkon Vagabond. It was attacked and badly damaged.
