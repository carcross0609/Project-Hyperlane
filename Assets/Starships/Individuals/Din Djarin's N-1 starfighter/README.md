# Din Djarin's N-1 starfighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Din Djarin's N-1 starfighter](https://starwars.fandom.com/wiki/Din_Djarin%27s_N-1_starfighter)

Din Djarin's N-1 starfighter, also known as The Mandalorian's N-1 starfighter, was a modified N-1 starfighter owned by Din Djarin following the destruction of the Razor Crest. Djarin and the mechanic Peli Motto worked together to build the N-1 starfighter as a replacement.
