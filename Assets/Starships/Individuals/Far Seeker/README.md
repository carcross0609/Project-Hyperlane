# Far Seeker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Far Seeker](https://starwars.fandom.com/wiki/Far_Seeker)

The Far Seeker was a decrepit luxury liner that ran the hyperlane to the Travnin system in the Minos Cluster every month.
