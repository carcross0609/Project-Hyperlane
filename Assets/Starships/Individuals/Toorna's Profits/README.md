# Toorna's Profits

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Toorna's Profits](https://starwars.fandom.com/wiki/Toorna%27s_Profits)

The Toorna's Profits was a freighter that landed on Vogga the Hutt's dock on Nar Shaddaa. The landing was delayed however, due to a mix-up of the ID signatures of the Toorna's Profits, the Silver Zephyr, and the Alakandor.
