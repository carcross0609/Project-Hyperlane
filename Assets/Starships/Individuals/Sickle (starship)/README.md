# Sickle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sickle (starship)](https://starwars.fandom.com/wiki/Sickle_%28starship%29)

The Sickle was a starship that was owned by the Lannik Nihil Skrood. In 228 BBY, Skrood, alongside other Nihil marauders, boarded the Longbeam-class corvette Aurora III from the Sickle while above the planet Eriadu.
