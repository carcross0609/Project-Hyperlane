# Nitsa

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nitsa](https://starwars.fandom.com/wiki/Nitsa)

The Nitsa was an Imperial-class Star Destroyer assigned to the Tapani sector. It was assigned to the sector capital planet Procopia.
