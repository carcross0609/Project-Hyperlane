# Cutlass

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Cutlass (R93 refractor)](https://starwars.fandom.com/wiki/Cutlass_%28R93_refractor%29)

The Cutlass was a R93 refractor of the Rokana Raiders. In 3 ABY, the ship was present in the Khepi system, where it was boarded and hijacked by Hondo Ohnaka after the Weequay sneaked aboard through a cargo crate. Kay Vess' crew would later travel to Tatooine and the Khepi Tomb within the Sayma Nebula with the ship. Before Kay Vess' crew could return onto the Cutlass, a fraction of Rokana Raiders escaped with the ship after the tomb began to collapse.
