# Hardly Worth Stealing

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hardly Worth Stealing](https://starwars.fandom.com/wiki/Hardly_Worth_Stealing)

The Hardly Worth Stealing was a ship owned by the prospecter Jag Murrock. He brought it with him to the Cularin asteroid belt during the Clone Wars.
