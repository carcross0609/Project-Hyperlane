# Chedaki's blockade runner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chedaki's blockade runner](https://starwars.fandom.com/wiki/Chedaki%27s_blockade_runner)

Chedaki's blockade runner was one of many vessels in the Alliance Fleet. A small, fast craft, it was disabled in orbit of Shiva IV. Princess Leia managed to evacuate the craft in a shuttle.

## Specifications

- **Name:** Chedaki's blockade runner
- **Affiliation:** Alliance to Restore the Republic
- **Fleet:** Alliance Fleet
- **Captains:** Chedaki
