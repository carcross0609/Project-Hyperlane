# Heart's Dagger

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Heart's Dagger](https://starwars.fandom.com/wiki/Heart%27s_Dagger)

The Heart's Dagger was an X4 Gunship that was used by the Velocity Mercenaries during the Galactic Civil War. It was destroyed by Black Epsilon in the Dantooine system in 1 ABY.

## Specifications

- **Name:** Heart's Dagger
- **Model:** X4 Gunship
- **Destroyed:** 1 ABY, Dantooine system
- **Affiliation:** Velocity Mercenaries
