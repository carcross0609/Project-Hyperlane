# Unidentified Ghtroc 630 freighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Ghtroc 630 freighter](https://starwars.fandom.com/wiki/Unidentified_Ghtroc_630_freighter)

This Ghtroc Industries 630 freighter was a ship operated by the newly formed squad under the command of General Rahm Kota. It transported the squad from Malastare to the Alliance Fleet near the Itani Nebula.
