# Echo of Hope

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Echo of Hope](https://starwars.fandom.com/wiki/Echo_of_Hope)

The Echo of Hope was a refitted Mon Calamari MC80A Home One Type Heavy Star Cruiser in service to the Resistance during their conflict with the First Order. After leaving the New Republic to join the Resistance, Rapier Squadron was redeployed aboard the Echo of Hope. Poe Dameron later attended a briefing onboard where he learned about a First Order code breaking device on Nar Kaaga.

## Specifications

- **Name:** Echo of Hope
- **Model:** MC80A Home One Type Heavy Star Cruiser (refitted)
- **Type:** Star Cruiser
- **Complement:** T-70 X-wing starfighters
- **Role:** Resistance command ship
- **Affiliation:** Resistance
- **Navy:** Resistance navy
