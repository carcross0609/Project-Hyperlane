# Spitfire (shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Spitfire (shuttle)](https://starwars.fandom.com/wiki/Spitfire_%28shuttle%29)

.]] Rebel Alliance Delta-class JV-7 escort shuttle Spitfire served in the Rebel fleet during the Galactic Civil War. Spitfire escorted CR90 corvettes Triumph during the Treachery at Ottega. Shuttle Spitfire futilely attacked Imperial starfighters in attempt to save MC40a light cruiser Warhawk and defecting Victory-class Star Destroyer Protector, only to be destroyed.
