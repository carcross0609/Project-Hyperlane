# Corellian Way

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Corellian Way](https://starwars.fandom.com/wiki/Corellian_Way)

The Corellian Way was a frigate operated by the Galactic Alliance during the Yuuzhan Vong War. The frigate was dispatched to the key communication facility located on Esfandia. The ship and all hands were lost when it was destroyed by a Yuuzhan Vong fleet.

## Specifications

- **Name:** Corellian Way
