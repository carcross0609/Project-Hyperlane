# Valiant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valiant (Thranta-class War Cruiser)](https://starwars.fandom.com/wiki/Valiant_%28Thranta-class_War_Cruiser%29)

The Thranta-class War Cruiser Valiant was the sister ship of Courage and Fidelity. When Alderaan disarmed after the Clone Wars, Valiant and its sister ships were assigned to escort the Alderaanian War Frigate Another Chance, which had been turned into an armory ship, carrying the military's surrendered weapons away from the planet.
