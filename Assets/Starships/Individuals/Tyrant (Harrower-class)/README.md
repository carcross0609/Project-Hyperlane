# Tyrant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tyrant (Harrower-class)](https://starwars.fandom.com/wiki/Tyrant_%28Harrower-class%29)

The Tyrant was the flagship of Darth Tormen in the beginning of the Galactic War. It was captained by a Human named Evlen.

- **Name:** Tyrant
- **Type:** Harrower-class dreadnought
