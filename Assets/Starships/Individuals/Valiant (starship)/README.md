# Valiant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valiant (starship)](https://starwars.fandom.com/wiki/Valiant_%28starship%29)

The Valiant was an Imperial starship under the command of Captain Oweg. Pit Lieutenant Hast also served aboard the vessel. During the Galactic Civil War, the Valiant led an Imperial force, including the Strike-class medium cruiser Shador, on an operation against the Alliance to Restore the Republic. Moff Vensell commanded the force, which departed from Jerijador.
