# Command Performance

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Command Performance](https://starwars.fandom.com/wiki/Command_Performance)

The Command Performance was a Rendili-Surron Starlight-class light freighter owned and operated by Ahric Korownosek and his acting troupe the NovaCluster Players.

## Specifications

- **Name:** Command Performance
- **Manufacturer:** Rendili StarDrive and Surron StarTech
- **Model:** Starlight-class light freighter
- **Type:** Freighter

- **Length:** 34 meters
- **Max Speed:** 800 km/h
- **Armament:** Turret-mounted blaster cannon
- **Crew:** 2
- **Passengers:** 6
- **Capacity:** 50 tons
- **Consumables:** 3 weeks
- **Owners:**
