# Sungrazer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sungrazer](https://starwars.fandom.com/wiki/Sungrazer)

Sungrazer was a mining vessel that served as the headquarters for Sungrazer cooperative, an organization that used slaves for deadly risky comet mining. As of 3963 BBY, the ship hosted about 80 slaves of various species that were forced to mine thorilide crystals on the comet in the Koornacht Cluster.
