# SV-45

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [SV-45](https://starwars.fandom.com/wiki/SV-45)

The SV-45 was a StarSpeeder 3000 used by Corellian Translines as a transport during the early New Republic era. It was captained by Duran Har at this time.
