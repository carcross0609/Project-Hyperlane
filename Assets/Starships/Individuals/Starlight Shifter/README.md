# Starlight Shifter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starlight Shifter](https://starwars.fandom.com/wiki/Starlight_Shifter)

The Starlight Shifter was a light freighter. Operated by the smuggler Mil Stanner, the Starlight Shifter had hidden cargo compartments.
