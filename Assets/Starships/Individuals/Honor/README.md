# Honor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Honor](https://starwars.fandom.com/wiki/Honor)

The Honor was one of the capital ships used by the Yevetha of the Duskhan League during the genocidal Great Purge in 16-17 ABY.
