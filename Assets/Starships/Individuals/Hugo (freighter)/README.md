# Hugo

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hugo (freighter)](https://starwars.fandom.com/wiki/Hugo_%28freighter%29)

The Hugo was a BFF-1 bulk freighter used by Overlord Ghorin to be part of a convoy to deliver grain to the Imperials. Unfortunately the freighter, along with the Grotius, were disabled along with the rest of the convoy by Rebel Y-wings. They were then boarded by Rebel freighters intending to swap grain cargos in order to discredit Ghorin as a traitor.
