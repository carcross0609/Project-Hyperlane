# Jak Sazz's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jak Sazz's starship](https://starwars.fandom.com/wiki/Jak_Sazz%27s_starship)

An antiquated starship was the personal vessel of the Ab'Ugartte Jak Sazz. Sazz would often repair the vessel with his hydrospanner, nicknamed "Grivooga."
