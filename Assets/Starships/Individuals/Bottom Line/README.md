# Bottom Line

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bottom Line](https://starwars.fandom.com/wiki/Bottom_Line)

The Bottom Line was a starship that was owned by an unidentified crime lord. When the vessel landed on the homeworld of the Tinnells, Purr stowed away on board.
