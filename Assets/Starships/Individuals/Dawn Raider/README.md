# Dawn Raider

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dawn Raider](https://starwars.fandom.com/wiki/Dawn_Raider)

The Dawn Raider was a modified CloakShape fighter that was flown by the Jedi ace Jaizen Suel during the latter years of the Galactic Republic.
