# Freedom

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Freedom](https://starwars.fandom.com/wiki/Freedom)

Freedom was an Imperial II-class Star Destroyer that served in the New Republic's starfleet. Prior to its New Republic service, the ship served in the Imperial Navy under the name Avarice.

## Specifications

- **Name:** Freedom
- **Type:** Imperial II-class Star Destroyer
- **Length:** 1,600 meters
- **Affiliation:**
  - Galactic Empire
  - New Republic Defense Fleet
- **Captains:** Sair Yonka
