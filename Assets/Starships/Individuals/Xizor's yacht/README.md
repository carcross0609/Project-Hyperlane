# Xizor's yacht

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Xizor's yacht](https://starwars.fandom.com/wiki/Xizor%27s_yacht)

The yacht of the Black Sun leader Prince Xizor was a large, stealth black starship. Xizor used the vessel to attack the holostar and Rebel agent Javul Charn while she was aboard the YT-1300 light freighter Millennium Falcon near Circarpous V.

## Specifications

- **Name:** Xizor's yacht
- **Type:** Yacht
- **Role:** Private yacht
- **Affiliation:** Black Sun
- **Owners:** Xizor
