# Dutyfree

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dutyfree/Legends](https://starwars.fandom.com/wiki/Dutyfree/Legends)

The Dutyfree was a GR-75 medium transport that operated as part of the Rebel fleet, serving in several fleet engagements, including the Battle of Hoth. It was commanded by Captain Areta Bell from 2 ABY to 3 ABY.

## Specifications

- **Name:** Dutyfree
- **Model:** GR-75 medium transport
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
- **Captains:** Areta Bell
