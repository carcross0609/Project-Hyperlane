# Unidentified Squib vessel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Squib vessel](https://starwars.fandom.com/wiki/Unidentified_Squib_vessel)

A Squib vessel crashed on the planet Holador c. 220 BBY. The Squibs who survived the crash awaited rescue, but none came.
