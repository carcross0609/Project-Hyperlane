# Wait a Minute

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wait a Minute](https://starwars.fandom.com/wiki/Wait_a_Minute)

The Wait a Minute was a Corellian CC-7700/E interdiction cruiser in the New Republic's Rapid Response Task Force and the Mandalorian Protectors. The Wait a Minute was captained by Jav Patrell.
