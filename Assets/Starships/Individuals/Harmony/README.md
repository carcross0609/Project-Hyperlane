# Harmony

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Harmony](https://starwars.fandom.com/wiki/Harmony)

The Harmony was a shuttle used by the Path of the Open Hand cult during the High Republic Era. The Children, a team set up by the Mother, the Path's leader, travlled in the starship on missions to "liberate" Force artifacts.

## Specifications

- **Name:** Harmony
- **Type:** Shuttle
- **Hdsystem:** Equipped
- **Affiliation:** Path of the Open Hand
