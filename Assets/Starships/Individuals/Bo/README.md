# Bo

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bo](https://starwars.fandom.com/wiki/Bo)

Bo was the name of a group of two Rebel BFF-1 bulk freighters that carried food away from Yavin 4. Red Squadron oversaw their exit from the Imperial blockade.
