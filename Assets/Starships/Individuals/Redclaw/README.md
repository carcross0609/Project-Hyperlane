# Redclaw

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Redclaw](https://starwars.fandom.com/wiki/Redclaw)

The Redclaw was a Sabertooth-class assault/rescue vessel that served the Galactic Alliance Remnant. It carried several Venom assault squads, including Redclaw Venom One.

## Specifications

- **Name:** Redclaw
- **Model:** Sabertooth-class assault/rescue vessel
- **Passengers:**
  - Venom assault squads
  -   Redclaw Venom One
- **Affiliation:** Galactic Alliance Remnant
