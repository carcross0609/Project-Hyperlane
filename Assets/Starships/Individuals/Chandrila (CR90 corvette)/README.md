# Chandrila (CR90 corvette)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chandrila (CR90 corvette)](https://starwars.fandom.com/wiki/Chandrila_%28CR90_corvette%29)

The Chandrila was a Corellian Corvette in service to the New Republic during the Galactic Civil War. It was part of a task force commanded by Admiral Ackbar during the Battle of Ciutric. It shared its name with the planet Chandrila.
