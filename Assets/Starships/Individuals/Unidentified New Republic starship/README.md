# Unidentified New Republic starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified New Republic starship](https://starwars.fandom.com/wiki/Unidentified_New_Republic_starship)

A New Republic starship was lured by the outlaw Wertram Farege into the Iskallon system in order to be captured by the Iskalloni. However, the starship's crew managed to escape.
