# Wholesale

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wholesale](https://starwars.fandom.com/wiki/Wholesale)

The Wholesale was a needle ship and the flagship of the Squib Reclamation Fleet at some point before the Galactic Civil War. The Squib Smileredon-Verdont claimed to have been born on the Wholesale.
