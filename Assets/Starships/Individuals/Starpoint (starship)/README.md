# Starpoint (starship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starpoint (starship)](https://starwars.fandom.com/wiki/Starpoint_%28starship%29)

The Starpoint was an Endurance-class fleet carrier of the New Republic Fifth Battle Group, and was Commodore Poqua's flagship.
