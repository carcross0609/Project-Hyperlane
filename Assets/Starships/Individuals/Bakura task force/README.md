# Bakura task force

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bakura task force](https://starwars.fandom.com/wiki/Bakura_task_force)

The Bakura task force was a small fleet of Rebel Alliance starships dispatched from the Endor fleet to assist the Imperial world of Bakura in repelling the Ssi-ruuvi invasion force of 4 ABY.

## Specifications

- **Name:** Bakura task force
- **Leader:** Commander Luke Skywalker
- **Locations:** Bakura
- **Founded:** 4 ABY
- **Dissolved:** 4 ABY
- **Affiliation:**
