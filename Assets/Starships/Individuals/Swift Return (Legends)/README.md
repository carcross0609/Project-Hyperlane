# Swift Return

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Swift Return/Legends](https://starwars.fandom.com/wiki/Swift_Return/Legends)

Swift Return was a retrofitted Consular-class cruiser that served as a frigate in the Galactic Republic's Navy. Swift Return was destroyed in battle with the acclaimed Admiral Trench prior to the Battle of Christophsis of 22 BBY.

## Specifications

- **Name:** Swift Return
- **Type:** Retrofitted Consular-class cruiser
- **Role:** Frigate
- **Destroyed:** Prior to the Battle of Christophsis, in 22 BBY
- **Affiliation:** Galactic Republic
- **Navy:** Republic Navy
