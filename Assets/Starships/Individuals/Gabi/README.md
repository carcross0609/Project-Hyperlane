# Gabi

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gabi](https://starwars.fandom.com/wiki/Gabi)

Gabi was a Container Transport located at an Imperial scrap yard in Tolig IV. Its cargo was electronics. It was present there when Ace and Emon Azzameen went there to investigate the various containers to search for their family's Comm Datacore.
