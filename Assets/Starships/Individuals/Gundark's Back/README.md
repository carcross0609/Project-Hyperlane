# Gundark's Back

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Gundark's Back](https://starwars.fandom.com/wiki/Gundark%27s_Back)

The Gundark's Back was a GR-75 medium transport once owned by Malia Shariv. The transport was stolen by Dai Danu, and its transponder code was cloned onto another, almost identical GR-75. Malia Shariv attempted to get her transport back from Danu, but she attacked the transport with the cloned transponder code instead.

## Specifications

- **Name:** Gundark's Back
- **Manufacturer:** Gallofree Yards, Inc.
- **Line:** GR-series
- **Model:** GR-75 medium transport
- **Type:** Medium transport
- **Length:** 90 meters
- **Owners:**

  - Dai Danu
- **Captains:** Malia Shariv
