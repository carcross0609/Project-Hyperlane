# Metternich

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Metternich](https://starwars.fandom.com/wiki/Metternich)

The Metternich was an Imperial EF76 Nebulon-B escort frigate. Along with the frigate Juvaini, it attacked the MC80 Star Cruiser Maria while the latter was receiving B-wing starfighters prototypes during the Galactic Civil War.
