# The Bug Stomper

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [The Bug Stomper](https://starwars.fandom.com/wiki/The_Bug_Stomper)

The Bug Stomper was a Low Altitude Assault Transport/infantry that took part in the Second Battle of Geonosis. The nose of the gunship was painted with a clone trooper's foot squashing a Geonosian, and the ship's name written in Aurebesh.

## Specifications

- **Name:** The Bug Stomper

- **Model:** Low Altitude Assault Transport/infantry
- **Type:** Gunship

- **Max Speed:** 620 kph
- **Armament:**

- **Crew:**

- **Affiliation:** Galactic Republic
