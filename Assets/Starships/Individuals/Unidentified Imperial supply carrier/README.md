# Unidentified Imperial supply carrier

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Imperial supply carrier](https://starwars.fandom.com/wiki/Unidentified_Imperial_supply_carrier)

In 3 ABY, an Imperial supply carrier was transporting material near to the planet Karatha. Alliance to Restore the Republic forces from Eyrie Base attempted to hijack the carrier, but were unsuccessful.
