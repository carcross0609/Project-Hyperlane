# Render

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Render](https://starwars.fandom.com/wiki/Render)

Render was an Imperial-class Star Destroyer of the Imperial Starfleet. The Render arrived at the factory ZA-13 to relieve Maarek Stele.
