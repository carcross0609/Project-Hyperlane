# Banshee (corvette group)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Banshee (corvette group)](https://starwars.fandom.com/wiki/Banshee_%28corvette_group%29)

Banshee was a pair of CR90 corvettes belonging to the Galactic Empire. They, along with the EF76 Nebulon-B escort frigate Shrike, were destroyed by B-wings, one of them piloted by Keyan Farlander.
