# Overlord (Terminus-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Overlord (Terminus-class)](https://starwars.fandom.com/wiki/Overlord_%28Terminus-class%29)

The Overlord was a Terminus-class destroyer operating at the beginning of the third Galactic War. At one point, it was ambushed by a Republic fighter wing, shortly before the Sith Empire's attack on the Meridian Complex.
