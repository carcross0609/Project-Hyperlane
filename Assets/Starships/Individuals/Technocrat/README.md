# Technocrat

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Technocrat](https://starwars.fandom.com/wiki/Technocrat)

The Technocrat was a dreadnought that was the flagship of Zeetar's Tempest of the Nihil marauder group. The Technocrat was lost to Jedi forces, and left Zeetar's forces with only nine starships.

## Specifications

- **Name:** Technocrat
- **Type:** Dreadnought
- **Affiliation:**
