# Baylan's shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Baylan's shuttle](https://starwars.fandom.com/wiki/Baylan%27s_shuttle)

Baylan's shuttle was an Eta-class shuttle used by Baylan Skoll and Shin Hati during the search for Grand Admiral Thrawn in 9 ABY. Ezra Bridger later stole it and used it to return to the New Republic, landing it in the hanger of Home One
