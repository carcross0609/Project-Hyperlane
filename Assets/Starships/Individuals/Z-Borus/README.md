# Z-Borus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Z-Borus](https://starwars.fandom.com/wiki/Z-Borus)

Borus was a modified Imperial Nebulon-B2 frigate that was in the service of the rogue Grand Admiral Demetrius Zaarin.
