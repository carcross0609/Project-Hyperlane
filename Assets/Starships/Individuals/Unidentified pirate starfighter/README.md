# Unidentified pirate starfighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified pirate starfighter](https://starwars.fandom.com/wiki/Unidentified_pirate_starfighter)

The pirate starfighter were starfighters utilized by a pirate group during a battle with the New Republic's Rapier Squadron. Rapier Leader Poe Dameron had his X-wing starfighter disabled by an ion pulse shot by one of the starfighters.

## Specifications

- **Name:** Unidentified pirate starfighter
- **Type:** Starfighter
- **Armament:**
  - 3 laser cannons
  - Ion pulse
- **Role:** Starfighter combat
