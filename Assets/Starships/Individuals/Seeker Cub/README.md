# Seeker Cub

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Seeker Cub](https://starwars.fandom.com/wiki/Seeker_Cub)

The Seeker Cub was a customized T-65B X-wing starfighter that belonged to the Rebel pilot Starter. During the time of the New Republic, Starter often flew missions for the Black Curs.
