# Vessel 4240-C

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Vessel 4240-C](https://starwars.fandom.com/wiki/Vessel_4240-C)

Vessel 4240-C was a Lambda-class T-4a shuttle attached to the Imperial Star Destroyer Implacable. Lieutenant Commander Del Meeko, then chief engineer aboard the Implacable, used it to reach Imperial City upon being summoned by Admiral Garrick Versio of the Imperial Security Bureau.

## Specifications

- **Name:** Vessel 4240-C
- **Manufacturer:** Sienar Fleet Systems
- **Line:** Abecederian line
- **Model:** Lambda-class T-4a shuttle
- **Type:** Multi-purpose transport
- **Length:** 20 meters
- **Hyperdrive:** Equipped
- **Armament:**
  - 2 forward double laser cannons
  - 2 wing-mounted double cannons
  - 1 rear double laser cannon
- **Capacity:** 80 metric tons
- **Role:** Transport
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
