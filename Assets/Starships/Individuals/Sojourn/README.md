# Sojourn

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sojourn](https://starwars.fandom.com/wiki/Sojourn)

The Sojourn was an MPO-1400 Purrgil-class star cruiser active during the First Order-Resistance War. Alongside the Halcyon, the Idyll, the Wanderlight, and the Sterling, it was one of five starships of the class in active service.

## Specifications

- **Name:** Sojourn
- **Model:** MPO-1400 Purrgil-class star cruiser
- **Type:** Starcruiser
