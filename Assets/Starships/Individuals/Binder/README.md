# Binder

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Binder](https://starwars.fandom.com/wiki/Binder)

Binder was an Imperial Interdictor-class Star Destroyer given to the command of Admiral Delak Krennel by Ysanne Isard for use in the evacuation of Ciutric. Its captain was Phulik.

## Specifications

- **Name:** Binder
- **Manufacturer:** Kuat Drive Yards
- **Model:** Interdictor-class Star Destroyer
- **Length:** 1,600 meters
- **Armament:** Gravity well projectors (4)
- **Affiliation:**
  - Galactic Empire
  - Ciutric Hegemony
  - New Republic
- **Owners:** Admiral Delak Krennel
- **Captains:** Captain Phulik
