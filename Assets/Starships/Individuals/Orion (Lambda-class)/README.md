# Orion (Lambda-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Orion (Lambda-class)](https://starwars.fandom.com/wiki/Orion_%28Lambda-class%29)

Orion was a Lambda-class T-4a shuttle that carried Sabacc players from the Dunari's Rest when the latter was attacked by Imperial forces. It made it to the hyperspace intact thanks to assistance from the Rebel Alliance.
