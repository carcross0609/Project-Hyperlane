# TAC 171

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [TAC 171](https://starwars.fandom.com/wiki/TAC_171)

TAC 171 was the designation given to a ISB TAC shuttle used by forces from ISB Tactical during the raid on the Axis safehouse at Tomkip Towers on Coruscant.

## Specifications

- **Name:** TAC 171
- **Model:** ISB TAC shuttle
- **Type:** Tactical troop transport
- **Armament:** 2 forward-mounted cannons
- **Crew:**
  - 1 ISB pilot
  -   Unidentified TAC 171 pilot
  - 8 ISB tactical agents
  -   TAC 2C
  -   Sergeant Gharial
  -   Sergeant Benzi
  - 1 ISB Supervisor
  -   Avril Heert
- **Role:** Tactical troop transport
- **Affiliation:** Galactic Empire
