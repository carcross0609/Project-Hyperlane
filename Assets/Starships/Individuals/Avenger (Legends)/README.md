# Avenger

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Avenger/Legends](https://starwars.fandom.com/wiki/Avenger/Legends)

The Avenger, full name CVS 1401 Avenger, was a prestigious Imperial II-class Star Destroyer of the Imperial Navy during the Galactic Civil War.
