# Juro's ship

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Juro's ship (Anda)](https://starwars.fandom.com/wiki/Juro%27s_ship_%28Anda%29)

Juro's ship was a starship used by the Jedi Juro, Ethan, Lah Kara, and Homen. While being pursued by Jedi Hunters, Kara was blasted into space and left behind when the starship jumped to hyperspace to escape. The Jedi later returned to rescue Kara.
