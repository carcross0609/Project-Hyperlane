# Nahosos

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nahosos](https://starwars.fandom.com/wiki/Nahosos)

Nahosos was a YT-1300 transport used by the Alliance to restore the Republic. The transport was present for the Rebel Summit in the Delfii system carrying Wookiees.
