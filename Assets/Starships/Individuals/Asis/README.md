# Asis

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Asis](https://starwars.fandom.com/wiki/Asis)

The Asis was a Corellian YT-1300 transport used by the Rebel Alliance. The transport was to rendezvous with the Rebel Fleet at Sullust but was destroyed at Sul-34 by Maarek Stele in a Missile Boat.
