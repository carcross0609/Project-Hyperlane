# Worthless Fool

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Worthless Fool](https://starwars.fandom.com/wiki/Worthless_Fool)

The Worthless Fool was a VR-10 Cuirilla-Rayl Xylines-class spacetug belonging to the Alliance to Restore the Republic. It was captained by Maytoc Kollene.
