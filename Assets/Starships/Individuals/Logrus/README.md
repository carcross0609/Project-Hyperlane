# Logrus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Logrus](https://starwars.fandom.com/wiki/Logrus)

The Logrus was an ExcelStar Lone Scout-A used by Dhar Bullwin in an attempt to recover a power that he hoped to use to rule the galaxy. The Logrus was destroyed by a group of New Republic scouts over Koda's World. Dhar Bullwin was able to escape in an escape pod and land on the planet to continue harassing the scouts.
