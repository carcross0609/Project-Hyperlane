# Baanu Ghezh

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Baanu Ghezh](https://starwars.fandom.com/wiki/Baanu_Ghezh)

Baanu Ghezh was a Yuuzhan Vong worldship. During the Yuuzhan Vong War, the Vong male Zhul Yim was stationed aboard the Baanu Ghezh as a shaper adept.
