# Klivering

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Klivering](https://starwars.fandom.com/wiki/Klivering)

The Klivering was a smuggling vessel used by Ellor. It was part of the Smugglers' Alliance fleet in the Battle of Bilbringi, running flanking position to the Kai Mir when they entered the shipyards.
