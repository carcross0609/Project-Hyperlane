# Last Chance

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Last Chance (YT-1300 light freighter)](https://starwars.fandom.com/wiki/Last_Chance_%28YT-1300_light_freighter%29)

The Last Chance was a heavily modified YT-1300 light freighter owned by the smuggler Platt Okeefe. It had severeal features that distinguished it from the stock YT-1300. Notably, the rear engine section was flattened at the stern, while the gap between the mandibles was plated over. The cockpit was mounted on the port quarter, as opposed to the more common starboard side.

## Specifications

- **Name:** Last Chance
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
