# Ironhand

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ironhand (Trenchant-class)](https://starwars.fandom.com/wiki/Ironhand_%28Trenchant-class%29)

The Ironhand was High Inquisitor Mox Slosin's personal ship. A modified Merkuni Drives Trenchant-class cruiser, it was used by Slosin personally to patrol the Lesser Plooriod Cluster looking for Rebel activity. The ship frequently traveled through the Entana Run and the Burna Trade Route.
