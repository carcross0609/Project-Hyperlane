# Virulence (frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Virulence (frigate)](https://starwars.fandom.com/wiki/Virulence_%28frigate%29)

Virulence was an EF76 Nebulon-B escort frigate in the Imperial Navy during the Galactic Civil War. The Virulence responded to a Rebel attack on an unguarded Imperial repair dock as part of the Alliance's testing of the R-22 Spearhead but arrived too late to prevent the destruction of the facility.
