# Yogi

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yogi](https://starwars.fandom.com/wiki/Yogi)

Yogi was the designation given to a group of Rebel CR90 corvettes. The warships, along with fellow corvette Chip, participated in a battle that saw the destruction of the Imperial freighter group Sornsen and the corvette group Shurik.
