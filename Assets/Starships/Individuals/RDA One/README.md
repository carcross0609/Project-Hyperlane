# RDA One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [RDA One](https://starwars.fandom.com/wiki/RDA_One)

RDA One was a Rycrit-class starship piloted by Hahnee Brethen for the Ryloth Defense Authority. When the Millennium Falcon arrived above Ryloth, Brethen flew RDA One to the freighter, using her authority as a member of the Ryloth Defense Authority to force government Can-Cell class ships to disengage.

## Specifications

- **Name:** RDA One
- **Model:** Rycrit-class
- **Affiliation:** Ryloth Defense Authority
