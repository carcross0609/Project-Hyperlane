# Phoenix

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Phoenix (GX1 short hauler)](https://starwars.fandom.com/wiki/Phoenix_%28GX1_short_hauler%29)

The Phoenix was a GX1 short hauler used by the Galactic Republic during an attempt to negotiate with the Separatists during the Clone Wars. It was a diplomatic vessel that was designed for long and extended missions.

## Specifications

- **Name:** Phoenix
- **Model:** GX1 short hauler
- **Type:** Diplomatic vessel
- **Length:** 37.28 meters
- **Hdsystem:** Equipped
- **Armament:** Turret-mounted double laser cannons
- **Escapepods:** 1, Hyperdrive-equipped escape pod
- **Role:** Senatorial transport
- **Affiliation:** Galactic Republic
