# Chaf Exalted

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chaf Exalted](https://starwars.fandom.com/wiki/Chaf_Exalted)

The Chaf Exalted was a large Chiss ship in service as a flaghip of the Chiss Ascendancy's Chaf family, serving as part of a fleet led by Aristocra Chaf'orm'bintrano, core name "Formbi."

## Specifications

- **Name:** Chaf Exalted
- **Crew:** Chaf family officers
- **Role:** Flagship
- **Affiliation:**
  - Chiss Ascendancy
  -   Chaf family
- **Fleet:** Chaf'orm'bintrano's fleet
- **Captains:** Aristocra Chaf'orm'bintrano
