# Unidentified Lucrehulk-class battleship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Lucrehulk-class battleship (Ukio)](https://starwars.fandom.com/wiki/Unidentified_Lucrehulk-class_battleship_%28Ukio%29)

A Lucrehulk-class battleship was used during the Clone Wars by Magistrate Passel Argente of the Corporate Alliance to carry out the operation known as Project Instinction on behalf of the Confederacy of Independent Systems. It transported seismic tanks loaded up with badlands soil on the planet Moorja, alongside three neural broadcast transmitters, to the agriworld Ukio.
