# Kirana Ti's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kirana Ti's starship](https://starwars.fandom.com/wiki/Kirana_Ti%27s_starship)

This starship was owned by the New Jedi Order in 12 ABY. It was used by Streen and Kirana Ti to travel to the planet Corbos in response to Dorsk 82's signal for help.
