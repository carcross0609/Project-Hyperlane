# Melisse

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Melisse](https://starwars.fandom.com/wiki/Melisse)

Melisse was an EF76 Nebulon-B escort frigate which had a few squadrons of Y-wings under her command. The Melisse arrived at the System Patrol Squadron above Farfeld II and attacked the Imperial frigate Dark Eye and, with the help of Keyan Farlander in a B-wing, managed to destroy it.
