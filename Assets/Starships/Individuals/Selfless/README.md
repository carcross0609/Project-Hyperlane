# Selfless

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Selfless](https://starwars.fandom.com/wiki/Selfless)

Selfless was a Venator-class Star Destroyer in the Republic Navy during the Clone Wars. It transported Jedi Master Keelyvine Reus, her Padawan Tyzen Xebec, Clone Commander Ganch, and the Agricultural Corps member Sanya to Coruscant following the battle of Ukio.
