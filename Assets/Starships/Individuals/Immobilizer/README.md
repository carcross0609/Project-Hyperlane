# Immobilizer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Immobilizer](https://starwars.fandom.com/wiki/Immobilizer)

The Immobilizer was an Immobilizer 418 cruiser that served in the Imperial Navy during the Galactic Civil War. It was used to prevent enemy ships from entering to hyperspace.

## Specifications

- **Name:** Immobilizer
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Immobilizer 418 cruiser
- **Length:** 600 meters
- **Width:** 300 meters
- **Height:** 100 meters
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
