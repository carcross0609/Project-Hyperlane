# Birkby

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Birkby](https://starwars.fandom.com/wiki/Birkby)

Birkby was the group designation for a force of Rebel CR90 corvettes. They assisted the Independence that hosted the diplomatic meeting with the Habassa, during which they were attacked by the Imperial EF76 Nebulon-B escort frigates Havok and Riptide.
