# Unidentified Jedi shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Jedi shuttle](https://starwars.fandom.com/wiki/Unidentified_Jedi_shuttle)

A shuttle was used by the Jedi Porter Engle and Creighton Sun. Engle later visited its wreckage on the planet Daedus.
