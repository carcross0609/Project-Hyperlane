# Yavin's Glory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yavin's Glory](https://starwars.fandom.com/wiki/Yavin%27s_Glory)

Yavin's Glory was a New Republic patrol cruiser. Its crew once happened upon an abandoned Imperial vessel which had been attacked by the Red Moons group. The Red Moons had used the chemical DX-343 to force the Imperials to abandon ship.
