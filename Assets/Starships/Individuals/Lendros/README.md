# Lendros

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lendros](https://starwars.fandom.com/wiki/Lendros)

Lendros was a Lambda-class T-4a shuttle on which Golov Nakhym attempted to escape the Hurrim Base during the combined assault by Rebel Alliance forces and Dunari's Longshot. The shuttle was disabled and Nakhym was captured by a Storm Unit.
