# Predator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Predator (Kell Douro's ship)](https://starwars.fandom.com/wiki/Predator_%28Kell_Douro%27s_ship%29)

Predator was the Anzati assassin Kell Douro's personal ship. He used it to pursue Jaden Korr to the frozen moon in the Unknown Regions.
