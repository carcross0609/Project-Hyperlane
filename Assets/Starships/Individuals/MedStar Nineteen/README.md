# MedStar Nineteen

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [MedStar Nineteen](https://starwars.fandom.com/wiki/MedStar_Nineteen)

The MedStar Nineteen was a MedStar-class frigate under the command of Admiral Tarnese Bleyd during the Clone Wars. The Galactic Republic dispatched this medical frigate to aid the Rimsoo facilities on Drongar.

## Specifications

- **Name:** MedStar Nineteen
- **Model:** MedStar-class frigate
- **Type:** Medical frigate
- **Role:** Mobile hospital
- **Affiliation:** Galactic Republic
- **Captains:** Admiral Tarnese Bleyd
