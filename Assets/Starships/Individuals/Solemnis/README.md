# Solemnis

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Solemnis](https://starwars.fandom.com/wiki/Solemnis)

The Solemnis was a Rebel Alliance starship. After the Battle of Abelard, the Solemnis was tasked with conveying the stabilized Ytterbium cargo that the Rebels had stolen from the Imperial forces to the Rebel base on Hoth but it disappeared before reaching Ristal.

## Specifications

- **Name:** Solemnis
- **Affiliation:** Alliance to Restore the Republic
