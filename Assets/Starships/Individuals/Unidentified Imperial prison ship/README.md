# Unidentified Imperial prison ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Imperial prison ship](https://starwars.fandom.com/wiki/Unidentified_Imperial_prison_ship)

A prison ship belonging to the reconstituted Sith Empire was carrying the captive Jedi Master Wyellett when it was shot down during the Battle of Hoth in 3665 BBY.
