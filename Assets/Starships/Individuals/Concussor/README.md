# Concussor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Concussor](https://starwars.fandom.com/wiki/Concussor)

Concussor was a Burst Fire-class Deep-Space Patrol Vessel. Originally in service of the Imperial Remnant, it was seized by Wraith Squadron in 44 ABY. Concussor was self-destructed by the Wraiths after a confrontation with the Galactic Alliance vessel Starhook.
