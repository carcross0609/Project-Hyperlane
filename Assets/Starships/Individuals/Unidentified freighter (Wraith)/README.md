# Unidentified freighter (Wraith)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified freighter (Wraith)](https://starwars.fandom.com/wiki/Unidentified_freighter_%28Wraith%29)

A freighter belonging to the Imperial agent known as the Wraith was stashed on the planet Sebiris. He used it in 8 ABY to escape the planet when he ran afoul of the local villagers and the crew of the New Republic CR90 corvette FarStar.
