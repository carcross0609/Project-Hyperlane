# Champion's Glory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Champion's Glory](https://starwars.fandom.com/wiki/Champion%27s_Glory)

The Champion's Glory was a warship of the Mandalorian Clan Varad. In 3626 BBY, the starship participated in the assault on the Spirit of Vengeance II.
