# Unidentified Flarestar-class attack shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Flarestar-class attack shuttle (Barb Mentir)/Legends](https://starwars.fandom.com/wiki/Unidentified_Flarestar-class_attack_shuttle_%28Barb_Mentir%29/Legends)
