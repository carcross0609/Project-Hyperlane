# Naboo Spacelines StarSpeeder 1000

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Naboo Spacelines StarSpeeder 1000](https://starwars.fandom.com/wiki/Naboo_Spacelines_StarSpeeder_1000)

The Naboo Spacelines StarSpeeder 1000 was a modified StarSpeeder 1000 spacecraft used by interstellar travel agency Star Tours to operate flights bound for the Mid Rim planet Naboo prior to 0 BBY. This starship was painted yellow and light grey with a red circle containing a white Aurebesh letter Nern. It was named after both the planet as well as Naboo Spacelines, a separate spaceliner company from Star Tours, which was a fellow member with Star Tours in the Galactic Tourist Bureau.
