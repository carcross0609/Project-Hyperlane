# Red Jammer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Red Jammer](https://starwars.fandom.com/wiki/Red_Jammer)

Red Jammer was a BTL-A4 Y-wing assault starfighter/bomber that flew with the Adelphi Rangers of the New Republic Defense Fleet. During a New Republic raid on Nal Hutta, Red Jammer launched bombs at the palace of the Hutt Twins, destroying the structure.
