# Star Seeker

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Star Seeker](https://starwars.fandom.com/wiki/Star_Seeker)

The Star Seeker was a Renning-class shuttle piloted by the droid 0G-LC. With this ship 0G-LC explored the Bri'ahl sectorand discovered the planet Fobaris.
