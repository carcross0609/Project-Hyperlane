# Ashanti

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ashanti](https://starwars.fandom.com/wiki/Ashanti)

The Ashanti was a BFF-1 bulk freighter used by the Rebel Alliance. It was part of the operation to steal TIE Avengers from a secret Imperial base. Despite the Imperials sending reinforcements consisting of the CR90 corvette group Eagle, Assault Gunboats, and Delta-class DX-9 stormtrooper transports, the freighter managed to steal TIE Avengers so that the Rebels could study them.
