# Negotiator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Negotiator/Legends](https://starwars.fandom.com/wiki/Negotiator/Legends)

The Negotiator was a Venator-class Star Destroyer that served as a flagship of Jedi Master Obi-Wan Kenobi and Clone Commander CC-2224 "Cody" during the Clone Wars. It was also commanded by Admiral Block of the Republic Navy.
