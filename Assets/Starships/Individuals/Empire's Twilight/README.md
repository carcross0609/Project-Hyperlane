# Empire's Twilight

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Empire's Twilight](https://starwars.fandom.com/wiki/Empire%27s_Twilight)

The Empire's Twilight was a CR90 corvette that was attacked by pirates in the Atrig system, near the planet Abatrarg. The crew of forty-five escaped the ship, and landed on the planet with enough supplies to survive for a week.
