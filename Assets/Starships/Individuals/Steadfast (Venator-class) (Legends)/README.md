# Steadfast

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Steadfast (Venator-class)/Legends](https://starwars.fandom.com/wiki/Steadfast_%28Venator-class%29/Legends)

The Steadfast was a Venator-class Star Destroyer and the flagship of Jedi General Eeth Koth during the Clone Wars.

## Specifications

- **Name:** Steadfast
- **Type:** Venator-class Star Destroyer
- **Armament:** DBY-827 heavy dual turbolaser turrets
- **Bays:** 1 ventral docking bay
- **Crew:** Clone troopers
- **Role:**
  - Destroyer
  - Carrier
  - Command ship
- **Destroyed:** 21 BBY, near the Arda system
- **Affiliation:** Galactic Republic
- **Navy:** Republic Navy
- **Fleet:** Open Circle Fleet
- **Captains:** General Eeth Koth
