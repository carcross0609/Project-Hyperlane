# Sontor Skipper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sontor Skipper](https://starwars.fandom.com/wiki/Sontor_Skipper)

The Sontor Skipper was an independent freighter that was owned and operated by Captain Ross. Ross and the Sontor Skipper were contracted by Aqualis Base, an Alliance to Restore the Republic food processing plant on Baralou, to pick up a shipment of bestrum algae every twenty-three local days.
