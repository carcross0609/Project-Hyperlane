# Star Jewel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Star Jewel/Legends](https://starwars.fandom.com/wiki/Star_Jewel/Legends)

The Star Jewel was the personal space yacht of Jabba Desilijic Tiure.

- **Name:** Star Jewel

- **Model:** Customized Minstrel-class space yacht
- **Type:** Yacht

- **Max Speed:** 800 km/h
- **Engine:**

- **Hyperdrive:** Class 2.0
- **Hdsystem:** Koensayr CL-14 hyperdrive motivator
- **Shield Gen:** Equipped
- **Armament:** Hidden CEC turbolasers (6)
- **Complement:**

- **Crew:**

  - Several droids
  - Enforcers including Grans, Trandoshans (possibly Sissks) and Gamorreans
  - Star Jewel Guard pilots (6)
  - Unspecified additional crew
- **Othersystems:** tractor beam
- **Role:** Armed transport
- **Owners:** Jabba Desilijic Tiure
