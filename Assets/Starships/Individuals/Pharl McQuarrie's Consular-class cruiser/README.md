# Pharl McQuarrie's Consular-class cruiser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pharl McQuarrie's Consular-class cruiser](https://starwars.fandom.com/wiki/Pharl_McQuarrie%27s_Consular-class_cruiser)

During the Clone Wars, Republic Navy Captain Pharl McQuarrie commanded a refitted Consular-class cruiser. McQuarrie and the cruiser served in the Republic defense of the planet Ukio in the early years of the war.
