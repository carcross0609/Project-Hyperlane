# Airship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Airship (Dantooine)](https://starwars.fandom.com/wiki/Airship_%28Dantooine%29)

The airship was a starship used by the Jedi. This ship belonged to the Agricultural Corps based on Dantooine. After the separatist attack on Dantooine, it was used by the Jedi to escape the planet and head for Coruscant.

## Specifications

- **Name:** Airship
- **Affiliation:** Jedi Order
