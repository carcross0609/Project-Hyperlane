# Dravilla

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dravilla](https://starwars.fandom.com/wiki/Dravilla)

The Dravilla was a destroyer used by the reconstituted Sith Empire during the Galactic War. It was destroyed at the Battle of Duro.

## Specifications

- **Name:** Dravilla
- **Type:** Destroyer
- **Destroyed:** 3640 BBY, Duro system
- **Affiliation:** Sith Empire
