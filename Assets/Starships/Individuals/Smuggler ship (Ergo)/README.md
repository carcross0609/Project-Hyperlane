# Smuggler ship (Ergo)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Smuggler ship (Ergo)](https://starwars.fandom.com/wiki/Smuggler_ship_%28Ergo%29)

This smuggler ship operated under the interests of the Galactic Empire during the Dark Trooper Project of the Galactic Civil War. Eventually it was raided by agent Kyle Katarn in order to reach the Super Star Destroyer Executor.
