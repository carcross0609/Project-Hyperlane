# Karthakk Queen

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Karthakk Queen](https://starwars.fandom.com/wiki/Karthakk_Queen)

The Karthakk Queen was a X4 Gunship that was used by the Lok Revenants during the Galactic Civil War. It was destroyed by Black Epsilon in the Karthakk system in 1 ABY.

## Specifications

- **Name:** Karthakk Queen
- **Model:** X4 Gunship
- **Destroyed:** 1 ABY, Karthakk system
- **Affiliation:** Lok Revenants
