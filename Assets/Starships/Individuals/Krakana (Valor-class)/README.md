# Krakana

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Krakana (Valor-class)](https://starwars.fandom.com/wiki/Krakana_%28Valor-class%29)

The Krakana was a Galactic Republic Valor-class starship, and the flagship of the Twenty-Ninth Fleet. It was under the command of Vice Admiral Dol Narlock.

- **Name:** Krakana
- **Model:** Valor-class cruiser
