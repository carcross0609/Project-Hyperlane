# Escro 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Escro 3](https://starwars.fandom.com/wiki/Escro_3)

Escro 3 was a Lambda-class T-4a shuttle serving the Alliance Fleet. The ship was part of Escro group which participated in the Skirmish at Outpost D-34. Escro 3, along with Escro 1 and 2 following Roe group, attempted to stop Imperial forces from capturing Onece 3 of Onece group which carried their fellow rebels. Both shuttle groups were unsuccessful and were all destroyed in the process.
