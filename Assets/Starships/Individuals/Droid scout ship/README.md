# Droid scout ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Droid scout ship](https://starwars.fandom.com/wiki/Droid_scout_ship)

This droid scout ship was used to scout the planet Jakku, and was scheduled to leave on the afternoon following the attack on Tuanul. The loading droid F3-ZK was scheduled to be picked up at the Starship Graveyard by the droid ship, but fell into a trap set by Teedo. Fez was saved by BB-8, and after a series of misadventures reached his ship. BB-8 distracted Teedo while Fez boarded, and the vessel departed Jakku safely.
