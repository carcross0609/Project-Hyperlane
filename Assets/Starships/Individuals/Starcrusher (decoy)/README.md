# "Starcrusher"

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starcrusher (decoy)](https://starwars.fandom.com/wiki/Starcrusher_%28decoy%29)

The "Starcrusher" was a large Separatist starship made to look like the battleship Starcrusher during the Clone Wars. It served as a trap for a team of Jedi Knights.

## Specifications

- **Name:** "Starcrusher"
- **Type:** Transport
- **Hdsystem:** Equipped
- **Armament:** None
- **Complement:** Escape pods
- **Role:** Decoy
- **Affiliation:** Confederacy of Independent Systems
- **Captains:** Kirst
