# Adamantine

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Adamantine](https://starwars.fandom.com/wiki/Adamantine)

Adamantine was a New Republic escort cruiser used at Nam Chorios. All hands were lost and the ship destroyed when the Death Seed plague was released. Its crew included Koth Barak and Gallie Wover.

## Specifications

- **Name:** Adamantine
- **Type:** Cruiser
- **Destroyed:** 13 ABY
- **Affiliation:** New Republic
