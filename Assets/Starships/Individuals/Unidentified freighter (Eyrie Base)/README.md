# Unidentified freighter (Eyrie Base)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified freighter (Eyrie Base)](https://starwars.fandom.com/wiki/Unidentified_freighter_%28Eyrie_Base%29)

In 3 ABY, Alliance to Restore the Republic members Stevan Makintay and Merinda Niemeh used a freighter to infiltrate the planet Hargeeva. The two-person freighter had originally been stolen by Eyrie Base's Red Team on Ongella.
