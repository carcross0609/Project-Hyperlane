# Vellus

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Vellus](https://starwars.fandom.com/wiki/Vellus)

The Vellus was a GR-75 medium transport belonging to the Rebel Alliance and was destroyed by Darth Vader between 2 BBY and 4 ABY.
