# Bantha Can

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bantha Can](https://starwars.fandom.com/wiki/Bantha_Can)

The Bantha Can was a freighter decommissioned prior to the Galactic Civil War. Its wreck was abandoned in Scrapheap Point, a ship junkyard located on Raxus Prime.
