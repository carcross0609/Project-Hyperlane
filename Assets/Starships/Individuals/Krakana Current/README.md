# Krakana Current

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Krakana Current](https://starwars.fandom.com/wiki/Krakana_Current)

The Krakana Current was the personal starship of Quarren Senator Tikkes, presumably a Mon Calamari model, during the Clone Wars. It was named after the fearsome krakana, a large, dangerous, carnivorous fish from Tikkes' homeworld of Mon Calamari.
