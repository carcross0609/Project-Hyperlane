# Tallinn

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tallinn](https://starwars.fandom.com/wiki/Tallinn)

Tallinn was a BFF-1 bulk freighter that contained spares and carried a container of spares. It dropped the container and attempted to enter hyperspace but was destroyed by Tan Maarek Stele.
