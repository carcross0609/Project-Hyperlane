# Murtceps

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Murtceps](https://starwars.fandom.com/wiki/Murtceps)

Murtceps was a BFF-1 bulk freighter that transferred TIE ships to the Dellalt system, preparing the Operation Strike Fear. It was destroyed by Keyan Farlander and Hamo Blastwell during the defection of Bixby.
