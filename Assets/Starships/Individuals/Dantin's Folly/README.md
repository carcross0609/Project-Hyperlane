# Dantin's Folly

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dantin's Folly](https://starwars.fandom.com/wiki/Dantin%27s_Folly)

Dantin's Folly was a starship that belonged to the Rebel privateer Chaeloe Dantin. It saw service throughout her work with the Alliance to Restore the Republic.
