# Arreis

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Arreis](https://starwars.fandom.com/wiki/Arreis)

Arreis was a BFF-1 bulk freighter that transferred robo haulers to the Dellalt system, preparing for Operation Strike Fear. It was destroyed by Keyan Farlander and Hamo Blastwell during the defection of Bixby.
