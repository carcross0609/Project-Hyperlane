# Star Dreadnought Assault Prototype

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Star Dreadnought Assault Prototype](https://starwars.fandom.com/wiki/Star_Dreadnought_Assault_Prototype)

The Star Dreadnought Assault Prototype was a prototype Executor-class Star Dreadnought used by the Imperial Navy during the Imperial Era. It was constructed surrounded by a large dock, running more than half the Star Dreadnought's length, in orbit above a cloudy celestial body.
