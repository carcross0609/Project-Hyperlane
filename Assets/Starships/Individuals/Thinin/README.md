# Thinin

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thinin](https://starwars.fandom.com/wiki/Thinin)

Thinin was an EF76 Nebulon-B escort frigate operating in the Imperial Navy under Grand Admiral Demetrius Zaarin. When the Grand Admiral turned rogue, in 3 ABY, and led a coup d'etat against the Empire, the Thinin remained under Zaarin's command.

## Specifications

- **Name:** Thinin
- **Type:** EF76 Nebulon-B escort frigate
- **Role:** Support
- **Destroyed:** 3 ABY
