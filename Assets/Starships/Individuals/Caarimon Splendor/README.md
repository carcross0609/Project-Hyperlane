# Caarimon Splendor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Caarimon Splendor](https://starwars.fandom.com/wiki/Caarimon_Splendor)

Caarimon Splendor was a ship owned by the Metatheran Cartel. It was captured by the Red Fury Brotherhood, a pirate group, and refitted for use by them. It later traveled to the Cularin asteroid belt, where Len Markus had it gutted for spare parts.
