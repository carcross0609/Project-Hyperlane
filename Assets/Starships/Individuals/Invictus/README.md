# Invictus

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Invictus](https://starwars.fandom.com/wiki/Invictus)

The Invictus was an Imperial Lambda-class T-4a shuttle that was stolen by the Alliance to Restore the Republic. It was used by Leia Organa and Han Solo to search for a new Rebel base.

## Specifications

- **Name:** Invictus
- **Manufacturer:** Sienar Fleet Systems
- **Line:** Abecederian line
- **Model:** Lambda-class T-4a shuttle
- **Type:** Multi-purpose transport

- **Hyperdrive:** Equipped
- **Armament:**

  - 2 wing-mounted double cannons
  - 1 rear double laser cannon
- **Capacity:** 80 metric tons
- **Role:** Transport
- **Destroyed:** 0 ABY, unidentified planet
- **Affiliation:**
  - Galactic Empire
  - Alliance to Restore the Republic (After being stolen)
- **Navy:** Imperial Navy
