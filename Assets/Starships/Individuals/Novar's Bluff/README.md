# Novar's Bluff

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Novar's Bluff](https://starwars.fandom.com/wiki/Novar%27s_Bluff)

Novar's Bluff was a Lianna-class corvette in service to the Imperial Navy during the Galactic Civil War. It was outfitted with an experimental cloaking device constructed by Santhe/Sienar Technologies.
