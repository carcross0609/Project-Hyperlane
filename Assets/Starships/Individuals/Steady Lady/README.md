# Steady Lady

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Steady Lady](https://starwars.fandom.com/wiki/Steady_Lady)

The Steady Lady was a sleek, 500-meter-long fast-haul bulk cruiser that could carry 1000 passengers. It was above Coruscant in 27 ABY and helped the Coruscant Planetary Defense Force evacuate refugees from the Sweet Surprise.
