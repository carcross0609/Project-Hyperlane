# Unidentified Acclamator-class assault ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Acclamator-class assault ship (Kamino)](https://starwars.fandom.com/wiki/Unidentified_Acclamator-class_assault_ship_%28Kamino%29)
