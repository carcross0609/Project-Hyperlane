# Marut

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Marut](https://starwars.fandom.com/wiki/Marut)

The Marut was a Victory II-class Star Destroyer in the Imperial fleet. It was used to raid Rebel training facilities before the Battle of Endor.
