# Wayward Girl

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wayward Girl](https://starwars.fandom.com/wiki/Wayward_Girl)

The Wayward Girl was owned by Jadonna Veloz. Han Solo piloted it from Alderaan to Bespin so that he could attend the Cloud City Sabacc Tournament. It carried nerf tenderloins in stasis for the Yarith Bespin kitchens.

## Specifications

- **Name:** Wayward Girl
- **Role:** Freighter
- **Owners:** Jadonna Veloz
