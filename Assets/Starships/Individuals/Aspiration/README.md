# Aspiration

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Aspiration](https://starwars.fandom.com/wiki/Aspiration)

The Aspiration was an MC75 Star Cruiser in the Rebel Alliance Navy. During its Alliance service, the Aspiration participated in a battle against a Victory-class Star Destroyer.
