# Iphige

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Iphige](https://starwars.fandom.com/wiki/Iphige)

IPV-1 System Patrol Craft Iphige was an Airam starship. Present as defense at Goff space platform during Task Force Vengeance's attack there, it sought to engage Avenger Squadron but was soon destroyed.
