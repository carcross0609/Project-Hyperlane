# Executrix

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Executrix/Legends](https://starwars.fandom.com/wiki/Executrix/Legends)

Executrix was the first Imperator-class Star Destroyer, launched late during the Clone Wars.

## Specifications

- **Name:** Executrix
- **Type:** Imperial I-class Star Destroyer
- **Length:** 1,600 meters
- **Affiliation:**
  - Galactic Republic
  - Galactic Empire
- **Captains:**
