# Mercurium

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mercurium](https://starwars.fandom.com/wiki/Mercurium)

Mercurium was a Lambda-class T-4a shuttle of the same group as Tydirium. It was found in Outpost 327 when the latter was captured in the Mission to Zhar.
