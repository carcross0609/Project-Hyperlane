# Paramount

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Paramount](https://starwars.fandom.com/wiki/Paramount)

The Paramount was a Keizar-Volvec manufactured bulk cruiser that was part of the Sith fleet in 3643 BBY. The ship was described as a "behemoth" with a hollow nose which housed its primary hangar bay. The Paramount was equipped with a complement of B28 Extinction-class bombers, ISF Starfighters, VT-22 transports, shuttles, and carried one Mk. VII advanced interceptor.
