# Boco

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Boco](https://starwars.fandom.com/wiki/Boco)

The Boco was a patrol ship in service to the Chiss Ascendancy's Expansionary Defense Fleet. It served under the command of Senior Commander Mitth'raw'nuru during a rescue of a luxury passenger liner that was descending into a gas giant planet, during which time it was Thrawn's first command.

## Specifications

- **Name:** Boco
- **Type:** Patrol ship
- **Armament:**
  - Tractor beam projectors
  - Laser weaponry
- **Affiliation:** Chiss Ascendancy
- **Navy:** Chiss Expansionary Defense Fleet
- **Captains:** Senior Commander Mitth'raw'nuru
