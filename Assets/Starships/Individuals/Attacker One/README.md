# Attacker One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Attacker One](https://starwars.fandom.com/wiki/Attacker_One)

Attacker One was the designation provided to a heavy cruiser by the Chiss Ascendancy. Accompanied by three other heavy cruisers, Attacker One was sent by the Lioaoin Regime to attack the Chiss warship Vigilant on behalf of the Nikardun Destiny when the Vigilant visited the planet Primea to collect Senior Captain Mitth'raw'nuruodo. Attackers One and Two provided flanking fire upon the Vigilant starboard hull. However, with Thrawn damaging Attacker Four in a commandeered Vak patrol boat, the Vigilant was able to use Four as cover to escape the Primea system.
