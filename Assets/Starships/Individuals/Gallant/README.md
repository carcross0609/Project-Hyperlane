# Gallant

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Gallant](https://starwars.fandom.com/wiki/Gallant)

The Gallant was a Corellian corvette belonging to the Galactic Empire's Vensenor Flight Academy, located in orbit above the planet Arkanis. The commandant of the flight academy, Bythen Forral, commonly used the corvette for his personal business.
