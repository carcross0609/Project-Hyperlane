# Potala Um Var

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Potala Um Var](https://starwars.fandom.com/wiki/Potala_Um_Var)

The Potala Um Var was a warship commanded by the Hutt Ulal and used to patrol the Ardos system. Its name meant "eternal vigilance."
