# Vindicator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vindicator (New Republic)](https://starwars.fandom.com/wiki/Vindicator_%28New_Republic%29)

- **Complement:**

- **Role:** Carrier
