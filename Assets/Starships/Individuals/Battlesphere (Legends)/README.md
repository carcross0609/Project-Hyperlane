# Battlesphere

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Battlesphere/Legends](https://starwars.fandom.com/wiki/Battlesphere/Legends)

The battlesphere was a variant of the Trade Federation Lucrehulk-class Core Ship, used by the Confederacy of Independent Systems during the Clone Wars.

- **Name:** Battlesphere
- **Manufacturer:**

  - Hyper-Communications Cartel
- **Line:** Lucrehulk-class Core Ship
- **Type:** Core ship
- **Power:** Multiple reactors
- **Shield Gen:** Equipped
- **Complement:**

  - Rogue-class starfighter (at least 3)
  - Other fighter craft
- **Role:**
  - Listening post
  - Battlestation
- **Affiliation:** Confederacy of Independent Systems
