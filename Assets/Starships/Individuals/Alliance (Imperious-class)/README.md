# Alliance

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Alliance (Imperious-class)](https://starwars.fandom.com/wiki/Alliance_%28Imperious-class%29)

The Alliance, originally known as the Imperious, was a large, powerful warship built by the Galactic Empire ruled by Darth Krayt. It was the prototype of the Imperious-class Star Destroyer, a Star Destroyer design larger and more powerful than the Pellaeon-class. It was a personal flagship of Galactic Alliance Admiral Gar Stazi.
