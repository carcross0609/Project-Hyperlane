# Annihilator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Annihilator (starship)](https://starwars.fandom.com/wiki/Annihilator_%28starship%29)

Annihilator was the mobile command base of Atha Prime. It resembled two Star Destroyers joined together and was used to launch his Clone Warriors. Prime's personal starfighter, Apex Invader, was able to attach atop the Annihilator which presumably gave him the ultimate command vantage point for battles.

## Specifications

- **Name:** Annihilator
- **Type:** Star Destroyer
- **Role:** Mobile command base
- **Captains:** Atha Prime
