# TC-159

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [TC-159](https://starwars.fandom.com/wiki/TC-159)

TC-159 was the signal of one Sheathipede-class Type B shuttle of the Confederacy of Independent Systems during the Clone Wars. During the Battle of Anaxes, the Galactic Republic forces used the code to infiltrate enemy lines disguised as the Sheathipede-class Type B shuttle.
