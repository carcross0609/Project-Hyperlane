# Nova

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Nova (Vector)](https://starwars.fandom.com/wiki/Nova_%28Vector%29)

The "Nova" was the nickname Jedi Padawan Bell Zettifar gave to the Jedi Vector typically flown by him and his Master, Loden Greatstorm. It was distinguishable from other Vectors by carbon scoring acquired when Greatstorm and Zettifar had flown it through an ion storm.

## Specifications

- **Name:** Nova
- **Model:** Jedi Vector
- **Crew:** 2
- **Destroyed:** 232 BBY, Elphrona system
- **Affiliation:** Jedi Order
- **Captains:** Loden Greatstorm
