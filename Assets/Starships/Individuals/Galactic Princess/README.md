# Galactic Princess

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Galactic Princess](https://starwars.fandom.com/wiki/Galactic_Princess)

The Galactic Princess was a freighter captained by the Gran Oobolo in 44 ABY. Oobolo ran a gambling operation on board the ship as a cover for his criminal activity.

## Specifications

- **Name:** Galactic Princess
- **Type:** Freighter
- **Captains:** Oobolo
