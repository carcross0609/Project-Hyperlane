# Vanquisher

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vanquisher (Kiltirin-class)](https://starwars.fandom.com/wiki/Vanquisher_%28Kiltirin-class%29)

The Vanquisher was a modified Kiltirin-class dungeon ship used as a mobile headquarters for the Mytaranor Slaving Council.

- **Role:** slavery, HQ
