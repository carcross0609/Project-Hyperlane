# Unidentified escort frigate

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified escort frigate](https://starwars.fandom.com/wiki/Unidentified_escort_frigate)

This unidentified escort frigate was a frigate that served in the Imperial Navy during the Galactic Civil War. In 3 ABY, this frigate was used as an escort for a convoy of Imperial drone freighters en route to the Kuat Drive Yards.
