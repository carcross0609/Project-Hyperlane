# Gilded Claw

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gilded Claw](https://starwars.fandom.com/wiki/Gilded_Claw)

The Gilded Claw was an Imperial-class Star Destroyer of the Imperial Navy. By 8 ABY, it was assigned to defend Kuat Drive Yards.
