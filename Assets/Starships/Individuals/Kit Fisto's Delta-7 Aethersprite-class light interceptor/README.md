# Kit Fisto's Delta-7 Aethersprite-class light interceptor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kit Fisto's Delta-7 Aethersprite-class light interceptor](https://starwars.fandom.com/wiki/Kit_Fisto%27s_Delta-7_Aethersprite-class_light_interceptor)

Kit Fisto flew a Delta-7 Aethersprite-class light interceptor during the Clone Wars. It could be used in combination with a hyperdrive docking ring, a device used to achieve faster-than-light travel by starships with no onboard hyperdrive.
