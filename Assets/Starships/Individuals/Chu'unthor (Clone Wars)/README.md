# Chu'unthor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chu'unthor (Clone Wars)](https://starwars.fandom.com/wiki/Chu%27unthor_%28Clone_Wars%29)

The Chu'unthor, the second ship to bear that name, was the wandering praxeum starship of the Jedi Djinn Altis during the Clone Wars.

## Specifications

- **Name:** Chu'unthor
- **Passengers:** Altisian Jedi students
- **Role:** Jedi Praxeum ship
- **Affiliation:** Jedi Master Djinn Altis
