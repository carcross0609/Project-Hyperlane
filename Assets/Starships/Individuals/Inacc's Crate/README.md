# Inacc's Crate

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Inacc's Crate](https://starwars.fandom.com/wiki/Inacc%27s_Crate)

Inacc's Crate was a Corellian Engineering Corporation YT-1300 light freighter. Owned by Gol Inacc, it was the only ship operated by Inacc's Shipping based out of Estaria Central Starport.
