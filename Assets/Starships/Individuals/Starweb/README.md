# Starweb

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starweb](https://starwars.fandom.com/wiki/Starweb)

The Starweb was a disk-shaped freighter owned and operated by Asyr Sei'lar after she resigned from duty with the New Republic. It had been loaned to her by Booster Terrik.
