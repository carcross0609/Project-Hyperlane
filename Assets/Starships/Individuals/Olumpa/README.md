# Olumpa

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Olumpa](https://starwars.fandom.com/wiki/Olumpa)

Olumpa was a civilian Container transport that was carrying Foodstuffs. The transport was passing through Navigation buoys B-52 and B-53 for an unknown destination. A single TIE Defender was present at the route and scanned the container transport despite Rebel fighters running interference.
