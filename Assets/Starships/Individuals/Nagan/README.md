# Nagan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nagan](https://starwars.fandom.com/wiki/Nagan)

Nagan was a Strike-class medium cruiser in the Imperial Navy. Nagan, along with Shotel, were sent to reinforce the Immobilizer 418 cruiser Red Claw position and assist Maarek Stele in destroying the Kopsh.
