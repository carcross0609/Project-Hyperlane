# Protector

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Protector (Damarind Corporation)](https://starwars.fandom.com/wiki/Protector_%28Damarind_Corporation%29)

The Protector was an armed frigate in service to the Damarind Corporation. It ferried the Corusca Stones acquired by the Damarind Fishing Station in the Yavin system back to the corporation.

- **Name:** Protector
- **Model:** Frigate
