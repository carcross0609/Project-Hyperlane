# Mathayus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mathayus](https://starwars.fandom.com/wiki/Mathayus)

The Mathayus was an Imperial-class Star Destroyer commanded by Admiral Coy, and later Admiral Dezsetes. Its First Officer was Atali.

## Specifications

- **Name:** Mathayus
- **Manufacturer:** Kuat Drive Yards
- **Model:** Imperial-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/LN starfighters
- **Passengers:** Darth Vader
- **Affiliation:** Galactic Empire
- **Captains:**

  - Admiral Dezsetes
