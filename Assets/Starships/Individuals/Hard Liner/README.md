# Hard Liner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hard Liner](https://starwars.fandom.com/wiki/Hard_Liner)

The Hard Liner was an Imperial shuttle that was piloted by Erlick Frodar during the Galactic Civil War. It ferried stormtroopers to their destinations.

## Specifications

- **Name:** Hard Liner
- **Type:** Shuttle
- **Affiliation:** Galactic Empire
- **Captains:** Erlick Frodar
