# Moonglow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Moonglow (light freighter)](https://starwars.fandom.com/wiki/Moonglow_%28light_freighter%29)

The Moonglow was a light freighter owned and operated by Lorcu Malshae and his Twi'lek co-pilot Par'tha. The ship was destroyed over Ord Mantell.

## Specifications

- **Name:** Moonglow
- **Type:** Light freighter
- **Role:** Smuggling ship
- **Captains:** Lorcu Malshae
