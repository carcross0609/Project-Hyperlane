# Vor'Teth

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vor'Teth](https://starwars.fandom.com/wiki/Vor%27Teth)

The Vor'Teth was a ship owned by smugglers Rezzo and Drossh. On one of their heists, a disagreement erupted between them, and they accidentally set off one of the explosives on board, killing both of them. The Vor'Teth was eventually salvaged and later sold as scrap.
