# Regalle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Regalle](https://starwars.fandom.com/wiki/Regalle)

Regalle was a light cruiser in service to the Galactic Alliance sometime in 44 ABY. Regalle was part of a task force along with three frigates commanded by Admiral Polow with orders to patrol the planet Coruscant.
