# Corellian Consort

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Corellian Consort](https://starwars.fandom.com/wiki/Corellian_Consort)

The Corellian Consort was an Imperial Space Rescue ship and was captained by Everik Dondarvan. The ship held the record for the highest number of successful operations (56), and the largest total persons rescued (543) record of any Rescue Corps craft.
