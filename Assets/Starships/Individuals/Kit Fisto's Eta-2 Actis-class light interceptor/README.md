# Kit Fisto's Eta-2 Actis-class; light interceptor

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Kit Fisto's Eta-2 Actis-class light interceptor](https://starwars.fandom.com/wiki/Kit_Fisto%27s_Eta-2_Actis-class_light_interceptor)

Nautolan Jedi Master Kit Fisto owned an Eta-2 Actis-class light interceptor. It was painted in a light green and red color scheme similar to his older Delta-7B interceptor. At one point, he flew the interceptor in an engagement against Vulture droid starfighters.
