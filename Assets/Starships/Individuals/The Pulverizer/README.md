# The Pulverizer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [The Pulverizer](https://starwars.fandom.com/wiki/The_Pulverizer)

The Pulverizer was an Asteroid Prospector AP-300 owned and operated by Lant Mining Corporation. The vessel was commanded by Captain Niree. Hema and Rikap were part of the vessel's crew.

## Specifications

- **Name:** The Pulverizer
- **Manufacturer:** Kuat Drive Yards
- **Type:** Asteroid Prospector AP-300
- **Role:** Asteroid mining
- **Affiliation:** Lant Mining Corporation
- **Captains:** Niree
