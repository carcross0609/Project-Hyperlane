# Pegasus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pegasus](https://starwars.fandom.com/wiki/Pegasus)

The Pegasus was a cruiser that served in the Alliance to Restore the Republic's Pegasus Strike Force, under the command of Captain Longmar, during the Galactic Civil War.
