# Eclipse II

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eclipse II](https://starwars.fandom.com/wiki/Eclipse_II)

Eclipse II was the second Eclipse-class dreadnought. It was also the second flagship of Palpatine.

## Specifications

- **Name:** Eclipse II
- **Model:** Eclipse-class dreadnought
- **Sysmods:**
  - Extensively redesigned engines
  - Tower-structure added to axial superlaser
- **Length:** 17,500 meters
- **Engine:** 8 engine arrays
- **Hdsystem:** equipped
- **Hull:** Jet-black durasteel and quadranium alloyed hull
- **Navigation:** Equipped
- **Armament:**
  - 1 axial superlaser
  - 500 Heavy Turbolaser Batteries
  - 500 Point Defense Laser Cannon Batteries
- **Role:**
  - Battleship (Dreadnaught)
  - Battlestation (while under construction)
  - Command ship
  - Carrier
  - Battlecruiser
- **Commission:** circa 0 BBY-0 ABY
- **Destroyed:** 11 ABY, Byss
- **Affiliation:**
  - Galactic Empire
  - Dark Empire
  - Order of the Sith Lords
- **Owners:** Emperor Palpatine
