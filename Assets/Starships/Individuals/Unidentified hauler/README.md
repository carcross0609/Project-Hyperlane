# Unidentified hauler

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified hauler](https://starwars.fandom.com/wiki/Unidentified_hauler)

A hauler was used by the Galactic Society of Creature Enthusiasts to transport creatures. SF-R3 and CAM were locked in the cargo bay together with many Gorgs.
