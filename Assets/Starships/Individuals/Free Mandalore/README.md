# Free Mandalore

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Free Mandalore](https://starwars.fandom.com/wiki/Free_Mandalore)

The Free Mandalore was a modified Kubrai-class S4 transport produced by Kubrai Transportation. In addition it served as Fenn Shysa's personal starship, which he used during the race for the Tessent.
