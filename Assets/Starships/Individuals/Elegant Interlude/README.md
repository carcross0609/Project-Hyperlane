# Elegant Interlude

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Elegant Interlude](https://starwars.fandom.com/wiki/Elegant_Interlude)

The Elegant Interlude was a light freighter owned and operated by the smuggler Danith Jalay. It accompanied Roa's Lwyll in the Battle of Nar Shaddaa.
