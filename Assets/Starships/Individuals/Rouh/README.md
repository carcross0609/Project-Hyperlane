# Rouh

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rouh](https://starwars.fandom.com/wiki/Rouh)

The Rouh was an Imperial freighter destroyed by Rebel pilot Dev when he accidentally found himself in an Imperial training area. The incident was ported into a simulated exercise for Rebel pilots.
