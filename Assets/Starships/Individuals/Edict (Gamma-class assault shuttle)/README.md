# Edict (Gamma-class assault shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Edict (Gamma-class assault shuttle)](https://starwars.fandom.com/wiki/Edict_%28Gamma-class_assault_shuttle%29)

The Edict was one of the two Gamma-class assault shuttles carried aboard the Imperial I-class Star Destroyer Gorgon. It was used by Admiral Daala in 11 ABY.
