# Wayfarer (Agave-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wayfarer (Agave-class)](https://starwars.fandom.com/wiki/Wayfarer_%28Agave-class%29)

Wayfarer was an Agave-class picket ship in the New Republic's Fifth Battle Group in 16 ABY. During the hyperdrive transit to the Koornacht Cluster, Wayfarer's hyperdrive failed and had to be towed to the Alland Yards.
