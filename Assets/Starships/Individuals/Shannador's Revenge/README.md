# Shannador's Revenge

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shannador's Revenge](https://starwars.fandom.com/wiki/Shannador%27s_Revenge)

Shannador's Revenge was an Invincible-class Dreadnaught Heavy Cruiser in the CSA Picket Fleet used by the Corporate Sector Authority to defend Orron III.
