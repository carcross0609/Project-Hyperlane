# Super TIE/LN starfighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Super TIE/LN starfighter](https://starwars.fandom.com/wiki/Super_TIE/LN_starfighter)

The Super TIE/LN starfighter, commonly called the Super TIE, was a customized Sienar Fleet Systems TIE/ln starfighter created at the Maw Installation to overcome some of the shortcomings of the traditional TIE/ln starfighter.

## Specifications

- **Name:** Super TIE/LN starfighter
- **Manufacturer:** Maw Installation
- **Type:** Starfighter
- **Length:** 6.3 meters
- **Max Speed:** 1,250 km/h
- **Armament:** 2 laser cannons
- **Crew:** 1 (pilot)
- **Capacity:** 55 kilograms
- **Consumables:** 2 days
- **Affiliation:** Maw Irregular Fleet
