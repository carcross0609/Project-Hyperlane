# Memory

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Memory](https://starwars.fandom.com/wiki/Memory)

The Memory was a Nau'ur-class yacht manufactured by Kalevala Spaceworks. Following the destruction of Alderaan in 1 BBY, the surviving elements of the planet's crown jewels were kept inaccessibly locked away on board the yacht. At some point during the Imperial Era, the yacht moored on the moon Pantora for one night in order to host an exclusive charity ball for the Alderaanian diaspora, presenting a chance for the jewels to be stolen.

## Specifications

- **Model:** Nau'ur-class yacht
