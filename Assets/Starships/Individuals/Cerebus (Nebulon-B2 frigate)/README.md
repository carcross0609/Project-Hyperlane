# Cerebus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cerebus (Nebulon-B2 frigate)](https://starwars.fandom.com/wiki/Cerebus_%28Nebulon-B2_frigate%29)

Cerebus was a Nebulon-B2 frigate belonging to the Galactic Empire. It was under the command of Captain Monfre and had TIE Avengers from Avenger squadron carried aboard.
