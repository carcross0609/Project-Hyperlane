# Unidentified Jedi Master's Defender-class light corvette

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Jedi Master's Defender-class light corvette](https://starwars.fandom.com/wiki/Unidentified_Jedi_Master%27s_Defender-class_light_corvette)

A Jedi Master piloted a Defender-class light corvette while leading a Galactic Republic border patrol during the Cold War, but the ship was destroyed when the patrol was lured to the Mugaar system and ambushed by Imperial forces.
