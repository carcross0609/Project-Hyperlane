# Listing Dewback

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Listing Dewback](https://starwars.fandom.com/wiki/Listing_Dewback)

The Listing Dewback was a light freighter owned by Shella Rinou. The ship was equipped with sensor jamming systems and several stealth programs, which facilitated her illegal trips to defended planets such as Rodia.
