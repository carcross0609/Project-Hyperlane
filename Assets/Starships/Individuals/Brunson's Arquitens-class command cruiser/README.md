# Brunson's Arquitens-class command cruiser

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Brunson's Arquitens-class command cruiser](https://starwars.fandom.com/wiki/Brunson%27s_Arquitens-class_command_cruiser)

Around 2 BBY, an Arquitens-class command cruiser was captained by the Imperial captain Brunson. It was patrolling Geonosis when it encountered Phoenix Cell, who were in search of Saw Gerrera and his unit. In the following skirmish, the cruiser was destroyed by the Ghost.
