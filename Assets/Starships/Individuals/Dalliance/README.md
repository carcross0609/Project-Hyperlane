# Dalliance

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dalliance](https://starwars.fandom.com/wiki/Dalliance)

The Dalliance was a modified Corellian YT-1210 light freighter owned by the New Jedi Order. It was housed at the Jedi Praxeum on Yavin 4.

## Specifications

- **Name:** Dalliance
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** Modified YT-1210 light freighter
- **Type:** Light freighter
- **Affiliation:** New Jedi Order
