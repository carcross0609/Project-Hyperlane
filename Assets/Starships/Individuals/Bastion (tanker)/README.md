# Bastion

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bastion (tanker)](https://starwars.fandom.com/wiki/Bastion_%28tanker%29)

Bastion was an ancient refueling tanker Wraith Squadron captured on Halmad during a mission disguised as the Hawk-bat Independent Space Force. Wraith pilot Kell Tainer rigged the tanker to blow upon a signal from him, which the Wraiths planned to use in demolishing a newly constructed starfighter base near the city of Hullis on Halmad.

## Specifications

- **Name:** Bastion
- **Type:** Tanker
- **Destroyed:** 7 ABY
- **Affiliation:** New Republic
