# Gorgon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gorgon (INT-66)](https://starwars.fandom.com/wiki/Gorgon_%28INT-66%29)

The Gorgon was Daxtorn Lethos's personal ship. It was a heavily-armed INT-66, modified to have faster engines, which Daxtorn used for smuggling and bounty hunting.

## Specifications

- **Name:** Gorgon
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** INT-66
- **Length:** 50 m
- **Armament:**
  - 2 turbolasers
  - 4 multi-repeat blasters
  - 1 double pulse laser
- **Crew:** 1
- **Passengers:** 3
- **Capacity:** 35 metric tons
- **Consumables:** 4 months
- **Role:**
  - Bounty hunting
  - Smuggling
- **Affiliation:** Daxtorn Lethos
