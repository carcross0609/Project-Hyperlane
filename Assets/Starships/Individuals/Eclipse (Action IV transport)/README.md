# Eclipse

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eclipse (Action IV transport)](https://starwars.fandom.com/wiki/Eclipse_%28Action_IV_transport%29)

The Eclipse was a Action IV bulk freighter operated by the Galactic Empire. It was used to support the Empire's Ando Project, ferrying Andoan mineral-fish from the planet Ando to the moon Uridia.

## Specifications

- **Name:** Eclipse
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Action IV transport
- **Max Speed:** 650 kmh
- **Armament:** Two laser cannon
- **Affiliation:** Galactic Empire
