# Haven Jace

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Haven Jace](https://starwars.fandom.com/wiki/Haven_Jace)

Haven Jace was a New Republic frigate that served as the hospital ship for Wedge Antilles' fleet during the second Battle of Borleias during the Yuuzhan Vong War.
