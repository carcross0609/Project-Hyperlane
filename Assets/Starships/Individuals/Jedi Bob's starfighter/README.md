# Jedi Bob's starfighter

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Jedi Bob's starfighter](https://starwars.fandom.com/wiki/Jedi_Bob%27s_starfighter)

Jedi Bob's starfighter was a starfighter built by Bobarian Afol. At some point, he and Servo encountered an Ackbar trooper.

- **Type:** Starfighter
- **Armament:** 2 blaster cannons

- **Owners:** Bobarian Afol
