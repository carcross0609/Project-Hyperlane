# Frontier Hawk

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Frontier Hawk](https://starwars.fandom.com/wiki/Frontier_Hawk)

The Frontier Hawk was a heavily-armed, modified YT-1300 light freighter owned and operated by smuggler Roget Jiriss as of 10 ABY.
