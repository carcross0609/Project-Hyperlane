# Derriphan

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Derriphan](https://starwars.fandom.com/wiki/Derriphan)

The Derriphan was a Xyston-class Star Destroyer of the Final Order that was the first of the new ships to launch from Exegol. It destroyed the planet Kijimi. The name came from the Sith word for "devourer."
