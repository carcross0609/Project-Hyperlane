# Contispex Crusader

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Contispex Crusader](https://starwars.fandom.com/wiki/Contispex_Crusader)

The Contispex Crusader was a gunship captained by Shyndi Oglerk during the Galactic Civil War. It served as a privateer ship for the Rebel Alliance.
