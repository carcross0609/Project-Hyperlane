# Leveler

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Leveler](https://starwars.fandom.com/wiki/Leveler)

The Leveler was a modified Acclamator-class assault ship that served in the Republic Navy during the Clone Wars, captained by Gilad Pellaeon.

## Specifications

- **Name:** Leveler
- **Manufacturer:** Rothana Heavy Engineering
- **Model:** Modified Acclamator-class assault ship
- **Type:** Assault ship
- **Length:** 752 meters
- **Width:** 460 meters
- **Armament:** Concussion Missiles
- **Othersystems:** Modified to carry a ventral hangar bay.
- **Role:**
  - Assault ship
  - Command ship
- **Affiliation:** Galactic Republic
- **Captains:** Gilad Pellaeon
