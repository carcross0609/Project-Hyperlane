# Gruna's ore hauler

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gruna's ore hauler](https://starwars.fandom.com/wiki/Gruna%27s_ore_hauler)

This ship was an Ithullan ore hauler active in the Stenness Node in the years leading up to the Great Sith War. It was under the control of Captain Gruna. In 3999 BBY, the ore hauler was attacked by Finhead Stonebone's pirate gang, but the ship was saved by local crime lord Bogga the Hutt's dreadnaught, Enforcer One.
