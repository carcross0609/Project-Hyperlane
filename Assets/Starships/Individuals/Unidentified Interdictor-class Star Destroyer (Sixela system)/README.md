# Unidentified Interdictor-class Star Destroyer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Interdictor-class Star Destroyer (Sixela system)](https://starwars.fandom.com/wiki/Unidentified_Interdictor-class_Star_Destroyer_%28Sixela_system%29)

An Interdictor Star Destroyer took part in the Battle of the Sixela system in 0 ABY. Following the launch of resonance torpedoes toward the system's star, the Interdictor and the rest of the Imperial fleet fled into hyperspace.
