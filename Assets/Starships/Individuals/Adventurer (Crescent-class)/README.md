# Adventurer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Adventurer (Crescent-class)](https://starwars.fandom.com/wiki/Adventurer_%28Crescent-class%29)

The Adventurer was a Hyrotii Corporation Crescent-class transport, Mark II. It had only limited use and almost no customizations even twenty years after being bought.

## Specifications

- **Name:** Adventurer
- **Manufacturer:** Hyrotii Corporation
- **Model:** Crescent-class Transport Mark II
- **Type:** Light freighter
- **Length:** 21 meters
- **Max Speed:** 900 km/h
- **Hyperdrive:**
  - Class 2.0
  - Backup Class 10
- **Armament:** Light blaster cannon (1)
- **Crew:** 1
- **Passengers:** 8
- **Capacity:** 80 metric tons
- **Consumables:** 2 months
- **Owners:**
  - Aelon Reglis
  - Lynx Reglis
- **Captains:** Aelon Reglis
