# Shredder (CR90 corvette)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shredder (CR90 corvette)](https://starwars.fandom.com/wiki/Shredder_%28CR90_corvette%29)

Shredder was an Imperial CR90 corvette. It was destroyed while attempting to stop the Rebel transport Raider stealing food from a grain supply depot located in an asteroid field.
