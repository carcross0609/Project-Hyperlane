# Harpy

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Harpy](https://starwars.fandom.com/wiki/Harpy)

Harpy was a Nebulon-B2 frigate serving the Galactic Empire. The frigate was present at the attack on the Gelgelar system where it attempted to attack the Liberty. Harpy was destroyed by Rebel B-wing starfighters.

- **Name:** Harpy

- **Type:** Frigate
