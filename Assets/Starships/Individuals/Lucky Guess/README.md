# Lucky Guess

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lucky Guess](https://starwars.fandom.com/wiki/Lucky_Guess)

The Lucky Guess was a modified YKL-37R Nova Courier cargo ship in use during the Galactic Civil War. It was owned by the Corellian smuggler siblings Orpa and Wex Vio.

## Specifications

- **Name:** Lucky Guess
- **Model:** YKL-37R Nova Courier
- **Armament:**
  - Dorsal turret
  -   Medium laser cannon
  - Ventral turret
  -   Medium laser cannon
- **Role:** Freighter
- **Owners:**
  - Orpa Vio
  - Wex Vio
