# Mandible

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Mandible](https://starwars.fandom.com/wiki/Mandible)

The Mandible was an Imperial starship that was involved in an accident by 3 ABY, when the vessel's captain ferried vaporous cargo aboard the ship while drunk. As a result, an emissary to the Imperial Ruling Council, Everi Chalis, punished the crew of the Mandible during the Belnar Insurrections and cited these punishments later on when pressuring the crew of a heavy freighter into changing course.

## Specifications

- **Name:** Mandible
