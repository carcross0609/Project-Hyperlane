# Thunderer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thunderer (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Thunderer_%28EF76_Nebulon-B_escort_frigate%29)

Thunderer was an EF76 Nebulon-B escort frigate used by the Galactic Empire. It was part of back-up at Zaarin's XQ6 Platform Research platform should the need for reinforcements be required.
