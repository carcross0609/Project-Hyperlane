# Bravo Fighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bravo Fighter](https://starwars.fandom.com/wiki/Bravo_Fighter)

Bravo Fighter was the an N-1 starfighter attached to Bravo Flight during the Invasion of Naboo in 32 BBY. Anakin Skywalker used the fighter during the Battle of Naboo.

- **Name:** Bravo Fighter
- **Model:** Starfighter
- **Type:** N-1 starfighter
