# Ghorman's Honor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ghorman's Honor](https://starwars.fandom.com/wiki/Ghorman%27s_Honor)

The Ghorman's Honor was a DP20 gunship in the service of the Alliance Fleet. It was named after the victims of the Ghorman Massacre.

## Specifications

- **Name:** Ghorman's Honor
- **Model:** DP20 gunship
- **Type:** Gunship
- **Affiliation:** Alliance to Restore the Republic
- **Fleet:** Bakura task force
