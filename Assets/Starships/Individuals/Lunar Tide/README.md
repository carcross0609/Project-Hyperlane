# Lunar Tide

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lunar Tide](https://starwars.fandom.com/wiki/Lunar_Tide)

The Lunar Tide was a New Republic frigate operating as part of the task force defending Borleias during the Second Battle of Borleias in the Yuuzhan Vong War.
