# Tumnor

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Tumnor](https://starwars.fandom.com/wiki/Tumnor)

The Tumnor was an Arquitens-class light cruiser that served in the Imperial Navy and participated in the Batonn insurgency. It was commanded by Captain Yelfis under Admiral Mitth'raw'nuruodo's 96th Task Force.

## Specifications

- **Name:** Tumnor
- **Manufacturer:** Kuat Drive Yards
- **Model:** Arquitens-class light cruiser
- **Type:** Light cruiser

- **Fleet:** 96th Task Force
- **Captains:** Yelfis
