# Indefatigable

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Indefatigable (Inexpugnable-class)](https://starwars.fandom.com/wiki/Indefatigable_%28Inexpugnable-class%29)

The Indefatigable was one of six Inexpugnable-class tactical command ships to serve the Galactic Republic during the Mandalorian Wars.

## Specifications

- **Name:** Indefatigable
- **Model:** Inexpugnable-class tactical command ship
- **Type:** Command ship
- **Length:** 3,100 meters
- **Width:** 3,100 meters
- **Armament:**
  - Double turbolaser batteries (5)
  - Light turbolaser batteries (5)
  - Point-defense light laser cannon batteries (2)
  - Tractor beam batteries (2)
- **Affiliation:** Galactic Republic
