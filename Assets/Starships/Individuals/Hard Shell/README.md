# Hard Shell

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hard Shell](https://starwars.fandom.com/wiki/Hard_Shell)

The Hard Shell was an Imperial Class-7 Repair Vessel produced by Kuat Drive Yards. Deployed to the planet Jatee, the Hard Shell was hijacked by agents of the Rebel Alliance in an attempt to take Dr. Soron Hegerty offworld.

## Specifications

- **Name:** Hard Shell
- **Manufacturer:** Kuat Drive Yards
- **Model:** Class-7 Repair Vessel
- **Type:** Repair vessel
- **Cost:** 4.5 million credits
- **Length:** 560 meters
- **Crew:** 3, 15 droids, 1 gunner
- **Passengers:** 10
- **Capacity:** 400,000 metric tons
- **Consumables:** 3 months
- **Role:** Mine repair and supply vessel
- **Affiliation:** Galactic Empire
