# Victorum

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Victorum](https://starwars.fandom.com/wiki/Victorum)

The Victorum was an Imperial-class Star Destroyer that served the Galactic Empire during the Galactic Civil War. At one point, it participated in combat against New Republic forces in the atmosphere of Yavin Prime after it was intercepted by Talus Group when it chased a New Republic medical convoy. The Victorum was then captured with the aid of Vanguard Squadron, and was set to be scrapped for Project Starhawk.
