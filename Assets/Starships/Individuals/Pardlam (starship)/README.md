# Pardlam

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pardlam (starship)](https://starwars.fandom.com/wiki/Pardlam_%28starship%29)

The Pardlam was a cargo ship. It was one of the ships that answered the call to aid the Heart of Artorias when Commander Bylsma sent out a request for support to defend Shramar. It shared its name with the pardlam, a large herbivorous creature.
