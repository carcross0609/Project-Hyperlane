# Bathysphere (starship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bathysphere (starship)](https://starwars.fandom.com/wiki/Bathysphere_%28starship%29)

Bathysphere was an Action VI bulk transport owned by the Mon Calamari bounty hunter Bringe. Due to Bringe's condition of not being able to handle normal atmospheric pressure, the cabin of Bathysphere was pressurized.
