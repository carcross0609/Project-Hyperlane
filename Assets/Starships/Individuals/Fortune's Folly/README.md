# Fortune's Folly

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fortune's Folly](https://starwars.fandom.com/wiki/Fortune%27s_Folly)

The Fortune's Folly was a pleasure barge owned by the Mandalorian Bask Sunn, a Dar'manda lieutenant and recruitment officer. In 3626 BBY, the starship participated in the assault on the Spirit of Vengeance II.

## Specifications

- **Name:** Fortune's Folly
- **Model:** A freighter class
- **Type:** Luxury liner
- **Affiliation:**
  - Mandalorians
  -   Dar'manda
  -   Hidden Chain
- **Owners:** Bask Sunn
