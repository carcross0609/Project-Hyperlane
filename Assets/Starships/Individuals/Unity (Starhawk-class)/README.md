# Unity

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unity (Starhawk-class)](https://starwars.fandom.com/wiki/Unity_%28Starhawk-class%29)

The Unity was a Starhawk-class Battleship Mark I that served in the New Republic Defense Fleet during the Galactic Civil War in 5 ABY. The Unity took part in the Battle of Jakku.
