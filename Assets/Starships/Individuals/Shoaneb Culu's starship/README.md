# Shoaneb Culu's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shoaneb Culu's starship](https://starwars.fandom.com/wiki/Shoaneb_Culu%27s_starship)

Shoaneb Culu's starship was the starship given to Shoaneb Culu at Ossus which she used to pursue Aleema Keto and Crado into the Cron Cluster. When Aleema detonated the Cluster, Shoaneb's vessel was destroyed in a following supernova in The Cron Drift, Shoaneb got killed with it.

## Specifications

- **Name:** Shoaneb Culu's starship
- **Owners:** Shoaneb Culu
