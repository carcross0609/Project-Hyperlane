# G'mi Moa

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [G'mi Moa](https://starwars.fandom.com/wiki/G%27mi_Moa)

The G'mi Moa was a Liannan bulk freighter, which traveled a regular shipping route along the Perlemian Trade Route. At one point along its usual routine, the ship was boarded and hijacked by the pirate Gunda Mabin.

## Specifications

- **Name:** G'mi Moa
- **Type:** Bulk freighter
- **Owners:** Gunda Mabin
