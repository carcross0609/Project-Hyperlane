# Unidentified Munificent-class star frigate

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Munificent-class star frigate (Gwori)](https://starwars.fandom.com/wiki/Unidentified_Munificent-class_star_frigate_%28Gwori%29)

A Munificent-class star frigate was created at the Gwori shipyards during the Clone Wars. In 22 BBY, Obi-Wan Kenobi, Anakin Skywalker, and Ahsoka Tano stole the frigate to help them transport the slave workers in the shipyards off-world during a battle on Gwori.
