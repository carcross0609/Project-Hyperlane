# Malak's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Malak's starship](https://starwars.fandom.com/wiki/Malak%27s_starship)

This starship was owned and operated by Malak, a female Rodian slaver, circa 1 BBY. Flying this ship, Malak visited the planet Byss to capture native Abyssins. After a successful hunt, she flew the ship to Kinun Depot, where she refueled it. An Abyssin prisoner, Myo, escaped Malak's ship there.
