# Yellow Rover

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yellow Rover](https://starwars.fandom.com/wiki/Yellow_Rover)

Yellow Rover was a New Republic shuttle, whose arrival in the Lucaya system signaled to Wraith Squadron, a commando unit, that the attack force was a mere half an hour away.
