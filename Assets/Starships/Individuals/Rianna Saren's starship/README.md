# Rianna Saren's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rianna Saren's starship](https://starwars.fandom.com/wiki/Rianna_Saren%27s_starship)

A starship was used by the rebel Rianna Saren during the Galactic Civil War. It was destroyed on Tatooine in 0 BBY when bounty hunter Boba Fett shot it down and it crashed in the Dune Sea.

## Specifications

- **Name:** Rianna Saren's starship
- **Armament:** Laser cannon turret
- **Role:** Mercenary vessel
- **Destroyed:** 0 BBY
- **Affiliation:** Alliance to Restore the Republic
- **Owners:** Rianna Saren
