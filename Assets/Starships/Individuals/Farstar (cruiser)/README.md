# Farstar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Farstar (cruiser)](https://starwars.fandom.com/wiki/Farstar_%28cruiser%29)

Farstar was a cruiser in the Republic Navy that participated in the Battle of the Maelstrom, the mission of which was to free Revan from the Maelstrom Prison.

## Specifications

- **Name:** Farstar
- **Type:** Cruiser
- **Affiliation:** Galactic Republic
- **Navy:** Republic Navy
- **Fleet:** First Expeditionary Fleet
