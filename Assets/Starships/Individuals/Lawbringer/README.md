# Lawbringer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Lawbringer](https://starwars.fandom.com/wiki/Lawbringer)

The Lawbringer was an Imperial I-class Star Destroyer commanded by Captain Hiram Zataire. In 5 BBY, it was requisitioned by Agent Kallus of the Imperial Security Bureau, who would use it in his mission to snuff out the rebel uprising on the planet Lothal.
