# Martinette

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Martinette](https://starwars.fandom.com/wiki/Martinette)

The Martinette was a Corellian Engineering Corporation YT-1300 light freighter, with customized modifications. It was used by pirate Captain Jayhawk and his crew.
