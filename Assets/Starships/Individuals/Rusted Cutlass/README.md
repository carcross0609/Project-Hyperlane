# Rusted Cutlass

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rusted Cutlass](https://starwars.fandom.com/wiki/Rusted_Cutlass)

The Rusted Cutlass was a an old battered corvette owned by the Dread Pirate Mendel Cutter. When Cutter decided to retire from piracy, he attached his ship to Zirtran's Anchor.
