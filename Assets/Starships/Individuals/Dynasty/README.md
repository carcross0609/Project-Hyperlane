# Dynasty

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dynasty](https://starwars.fandom.com/wiki/Dynasty)

The Dynasty was a modified YT-1210 light freighter that was owned and operated by Axtor Bridgeman. It boasted a faster hyperdrive, both main and backup, as well as two concussion missile launchers. The Dynasty was also 7 meters longer than a stock YT-1210. Around 0 ABY, Axtor and his ship was operating in the Minos Cluster.
