# Blacken

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blacken](https://starwars.fandom.com/wiki/Blacken)

The Blacken was an Imperial-class Star Destroyer which arrived minutes after the Nebulon-B Frigate Enforcer as Keyan Farlander and Rebel Alliance Stormtrooper Transport Raider were escaping after stealing Imperial food supplies.
