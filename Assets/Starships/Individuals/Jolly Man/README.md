# Jolly Man

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jolly Man](https://starwars.fandom.com/wiki/Jolly_Man)

Jolly Man was a freighter used by the New Jedi Order as part of the Wild Knights. It was used to transport their non-hyperdrive equipped ships (2 I-7 Howlrunners and 3 A-9 Vigilances).

## Specifications

- **Name:** Jolly Man
- **Type:** Freighter
- **Hdsystem:** Equipped
- **Role:** Flagship
- **Affiliation:** New Jedi Order
- **Captains:** Corran Horn
