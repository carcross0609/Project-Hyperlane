# Rampaging Ranat

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rampaging Ranat](https://starwars.fandom.com/wiki/Rampaging_Ranat)

The Rampaging Ranat was a modified Corellian Engineering Corporation YT-2400 light freighter owned by the smuggler Az-Iban, and later the Disac pirate Morturr Heth.
