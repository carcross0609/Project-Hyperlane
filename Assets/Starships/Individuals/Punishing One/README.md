# Punishing One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Punishing One](https://starwars.fandom.com/wiki/Punishing_One)

The Punishing One was a JumpMaster 5000 owned by the bounty hunter Dengar. The ship had no holding cell due to the fact that Dengar usually only took in dead bounties.

## Specifications

- **Name:** Punishing One
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** JumpMaster 5000
- **Cost:** 380,000 credits
- **Hyperdrive:**
  - Class 1 (Primary)
  - Class 10 (Backup)
- **Sensor:** Extreme
- **Armament:**
  - Quad laser cannon
  - Ion cannon
- **Crew:** 1 pilot
- **Passengers:** 1
- **Consumables:** 2 months
- **Owners:** Dengar
