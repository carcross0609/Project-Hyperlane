# LMC Hauler One-Six

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [LMC Hauler One-Six](https://starwars.fandom.com/wiki/LMC_Hauler_One-Six)

LMC Hauler One-Six was a freighter owned by the Lant Mining Corporation. It was the flagship of Convoy LMC-55c when it was captured by a squadron of Rebel Alliance BTL Y-wing starfighters.
