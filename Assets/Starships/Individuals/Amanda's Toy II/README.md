# Amanda's Toy II

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Amanda's Toy II](https://starwars.fandom.com/wiki/Amanda%27s_Toy_II)

Amanda's Toy II was a ship owned by Unlimited Horizons Inc.. It was registered on Kalla VII with registration number RN18-950319. In 16 ABY, Luke Skywalker tracked this ship as it passed the inner flight control buoys of the planet Teyr.

- **Name:** Amanda's Toy II
