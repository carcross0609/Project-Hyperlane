# Recovery

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Recovery](https://starwars.fandom.com/wiki/Recovery)

Recovery was a Heavy Lifter used by the Galactic Empire during the Galactic Civil War. The Lifter was used to pick up a Rebel B-wing Scarlet 4 that a TIE Defender was ordered to disable.
