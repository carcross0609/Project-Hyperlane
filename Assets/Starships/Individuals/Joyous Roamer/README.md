# Joyous Roamer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Joyous Roamer](https://starwars.fandom.com/wiki/Joyous_Roamer)

The Joyous Roamer was an asteroid tug under the command of Omad Kaeg that had been built sometime before 45 ABY. It was used in the Chiloon Rift.

## Specifications

- **Name:** Joyous Roamer
- **Captains:** Omad Kaeg
