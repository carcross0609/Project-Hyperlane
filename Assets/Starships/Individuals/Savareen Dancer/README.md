# Savareen Dancer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Savareen Dancer](https://starwars.fandom.com/wiki/Savareen_Dancer)

The Savareen Dancer was a relatively well-known luxury liner that shared its name with the Savareen system of the Outer Rim Territories' Savareen sector and was active in the Outer Rim during the Galactic Civil War between the Galactic Empire and the Rebel Alliance.

## Specifications

- **Name:** Savareen Dancer
- **Type:** Luxury liner
