# Riley

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Riley (transport)](https://starwars.fandom.com/wiki/Riley_%28transport%29)

Riley was an Action VI transport. The Riley was present in the Nezni system, going into the hangar of the Corvalis, where the incident between the Rebel Alliance and the Hurrim took place.

## Specifications

- **Name:** Riley
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** Action series
- **Model:** Action VI bulk transport
- **Length:** 125 meters
- **Armament:** None
