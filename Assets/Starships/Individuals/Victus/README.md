# Victus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Victus](https://starwars.fandom.com/wiki/Victus)

The Victus was a Mandalorian battle cruiser under the command of Vipsanis. The warship was the flagship of a fleet led by Vipsanis to conquer the planet Endelaan.

## Specifications

- **Name:** Victus
- **Type:** Battle cruiser
- **Affiliation:** Mandalorians
- **Owners:** Vipsanis
