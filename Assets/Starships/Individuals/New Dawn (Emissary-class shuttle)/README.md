# New Dawn

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [New Dawn (Emissary-class shuttle)](https://starwars.fandom.com/wiki/New_Dawn_%28Emissary-class_shuttle%29)

The New Dawn was an Emissary-class shuttle owned by the former Supreme Chancellor Tarsus Valorum. He preferred the ship over others as he believed he did not need a luxurious ship nor much protection. Valorum's security detail, headed by Jedi Knight Johun Othone, rode with him in the New Dawn.

## Specifications

- **Name:** New Dawn
- **Model:** Emissary-class shuttle
- **Hyperdrive:** Class 6
- **Crew:** 2
- **Passengers:** 6
- **Role:** Personal transport
- **Affiliation:** Galactic Senate
- **Owners:** Tarsus Valorum
