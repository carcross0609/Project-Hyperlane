# Unidentified Turtle Tanker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Turtle Tanker/Legends](https://starwars.fandom.com/wiki/Unidentified_Turtle_Tanker/Legends)

An unidentified Turtle Tanker was owned by a Sakiyan cargo hauler around 21 BBY, during the Clone Wars. Savage Opress used the ship to escape from planet Stobar and get to the planet Lotho Minor in order to rescue his brother Darth Maul and return him to Dathomir. Following this the ship was taken to Raydonia, during which time Obi-Wan Kenobi found a surprising ally in Asajj Ventress when they fought Savage Opress and Darth Maul in a lightsaber duel known as the Skirmish above Raydonia aboard the Turtle Tanker. Obi-Wan and Ventress escaped via the Tanker's escape pod cockpit, after which the ship was piloted by the brothers to Orto Norwe and abandoned.
