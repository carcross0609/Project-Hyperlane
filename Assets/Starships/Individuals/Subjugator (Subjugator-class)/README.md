# Subjugator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Subjugator (Subjugator-class)](https://starwars.fandom.com/wiki/Subjugator_%28Subjugator-class%29)

The Subjugator was the first Subjugator-class heavy cruiser produced. Uniquely this vessel was armed with a Trihexalon launcher. During the Trihexalon attack on Coruscant, Mavra Zane and Chewbacca infiltrated the warship and sabotaged the main reactor, destroying the vessel.

## Specifications

- **Name:** Subjugator
- **Model:** Subjugator-class heavy cruiser
- **Type:** Heavy Cruiser
- **Length:** 4,845 meters
- **Armament:** Trihexalon launcher
- **Destroyed:** Sometime during the Clone Wars
- **Affiliation:** Confederacy of Independent Systems
