# Kylo Ren's TIE silencer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Kylo Ren's TIE silencer](https://starwars.fandom.com/wiki/Kylo_Ren%27s_TIE_silencer)

Kylo Ren's TIE silencer was a prototype TIE/vn space superiority fighter used by Kylo Ren during the First Order's war with the Resistance. Ren's use of the TIE silencer allowed Sienar-Jaemus Fleet Systems to refine its onboard system from his detailed post-flight reports.
