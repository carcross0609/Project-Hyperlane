# Mother Sea

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mother Sea](https://starwars.fandom.com/wiki/Mother_Sea)

The Mother Sea was a New Republic Frigate. The imperial intelligence officer Gara Petothel served some time on this ship under the false identity of the communications officer Chyan Mezzine, spying for the Empire and, later, for Admiral Apwar Trigit.
