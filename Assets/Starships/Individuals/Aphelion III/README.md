# Aphelion III

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Aphelion III](https://starwars.fandom.com/wiki/Aphelion_III)

The Aphelion III was a Galactic Republic ship in operation during the third Galactic War. The ship was the most heavily-secured ship under the command of Vice Admiral Dol Narlock.
