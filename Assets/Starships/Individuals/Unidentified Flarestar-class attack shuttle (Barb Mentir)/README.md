# Unidentified Flarestar-class attack shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Flarestar-class attack shuttle (Barb Mentir)](https://starwars.fandom.com/wiki/Unidentified_Flarestar-class_attack_shuttle_%28Barb_Mentir%29)

This Flarestar-class attack shuttle was used by the Weequay pirate Barb Mentir to shoot down the Nu-class shuttle carrying Senator Kharrus. It was stolen by Confederacy of Independent Systems leader Count Dooku during his escape from Florrum in 22 BBY.
