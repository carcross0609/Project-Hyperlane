# Zorneth's Herdship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Zorneth's Herdship](https://starwars.fandom.com/wiki/Zorneth%27s_Herdship)

Zorneth's Herdship belonged to the Ithorian scientist Zorneth. It was crewed by Ithorians and assorted other species, along with numerous droids, including C-3PO, PDA6, and R2-D2. A passenger aboard the Ithorian Herdship was the Human botanist Klorr Vilia.

## Specifications

- **Name:** Zorneth's Herdship
- **Model:** Ithorian Herdship
- **Owners:** Zorneth
