# Annihilator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Annihilator (Imperial I-class)](https://starwars.fandom.com/wiki/Annihilator_%28Imperial_I-class%29)

The Imperial I-class Star Destroyer Annihilator, was stationed on the borders of Hutt Space, near the Periphery, with the Ruthless around 4 ABY. Governor Newen Streeg of the Periphery had the option of calling on the Annihilator when necessary.
