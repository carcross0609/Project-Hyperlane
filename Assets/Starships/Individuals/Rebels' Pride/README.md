# Rebels' Pride

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rebels' Pride](https://starwars.fandom.com/wiki/Rebels%27_Pride)

Rebels' Pride was a New Republic freighter. It was part of the bacta convoy which was destroyed by Warlord Zsinj in the ambush at Alderaan.
