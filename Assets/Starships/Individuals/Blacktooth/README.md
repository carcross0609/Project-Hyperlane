# Blacktooth

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blacktooth](https://starwars.fandom.com/wiki/Blacktooth)

The Blacktooth was a CEC YT-2400 light freighter owned by Faskus Olvidan. It was destroyed by the pirates of the Boneyard Rendezvous.
