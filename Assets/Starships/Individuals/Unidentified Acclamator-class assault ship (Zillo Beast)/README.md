# Unidentified Acclamator-class assault ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Acclamator-class assault ship (Zillo Beast)](https://starwars.fandom.com/wiki/Unidentified_Acclamator-class_assault_ship_%28Zillo_Beast%29)

This Acclamator-class transgalactic military assault ship was used by the Galactic Republic during the Clone Wars. When a Zillo Beast was captured after the Battle of Malastare, this ship was used to transport the creature to Coruscant.

- **Name:** Unidentified Acclamator-class assault ship

- **Line:** Acclamator-class transgalactic military assault ship

- **Affiliation:**
