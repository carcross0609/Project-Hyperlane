# Bellicose

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Bellicose (Imperial-class)](https://starwars.fandom.com/wiki/Bellicose_%28Imperial-class%29)

The Bellicose was an Imperial-class Star Destroyer in the Galactic Empire that was captained by Commander Tylux. It was destroyed while chasing a spy of the Alliance to Restore the Republic. The Bellicose was part of a fleet that consisted of at least five Imperial-class Star Destroyers.
