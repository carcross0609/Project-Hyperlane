# Tellstar

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Tellstar](https://starwars.fandom.com/wiki/Tellstar)

The Tellstar was an Arquitens-class command cruiser in service to the Galactic Empire's navy. After the destruction of Lothal's Imperial Communications Center, the Tellstar was used to capture and relay information from surface courier droids brought aboard.
