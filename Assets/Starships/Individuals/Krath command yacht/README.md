# Krath command yacht

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Krath command yacht](https://starwars.fandom.com/wiki/Krath_command_yacht)

For local skirmishes in the Empress Teta system, Ulic Qel-Droma and Aleema Keto directed military operations from a Krath command yacht. Captain Rooks commanded this yacht in 3996 BBY when it was attacked by Mandalorians.
