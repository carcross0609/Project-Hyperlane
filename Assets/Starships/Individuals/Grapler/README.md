# Grapler

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Grapler](https://starwars.fandom.com/wiki/Grapler)

Grapler was a CR90 corvette belonging to the Pakuuni Pirates. It was defending a pirate outpost along with Clavier and Leach. Grapler was destroyed by Imperial ace Maarek Stele along with the other corvettes and the entire outpost.
