# Hydian Marauder

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Hydian Marauder](https://starwars.fandom.com/wiki/Hydian_Marauder)

The Hydian Marauder was a pirate starship that crashed in the Jundland Wastes of Tatooine, between Arnthout and Mos Eisley, during or prior to the Galactic Civil War.
