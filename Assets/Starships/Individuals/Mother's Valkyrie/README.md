# Mother's Valkyrie

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mother's Valkyrie](https://starwars.fandom.com/wiki/Mother%27s_Valkyrie)

The Mother's Valkyrie was a Paqwe diplomatic ship sent to Coruscant and was allowed to be damaged by the Yevetha by Belezaboth Ourn.
