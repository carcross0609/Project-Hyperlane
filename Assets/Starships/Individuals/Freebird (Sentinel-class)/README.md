# Freebird

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Freebird (Sentinel-class)](https://starwars.fandom.com/wiki/Freebird_%28Sentinel-class%29)

The Freebird was a Sentinel-class landing craft under the command of Imperial Commander Gorrister. The shuttle was stationed on the Vector, which was the base of operations for the secret Imperial weapons project codenamed "Blackwing virus."

## Specifications

- **Name:** Freebird
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Sentinel-class landing craft
- **Passengers:** Stormtroopers and Imperial workers, Purge survivors
- **Role:** Transport shuttle
- **Affiliation:**
  - Galactic Empire
  - Black Hammer pirates
