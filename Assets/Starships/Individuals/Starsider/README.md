# Starsider

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starsider](https://starwars.fandom.com/wiki/Starsider)

The Starsider was a Dreadnaught-class heavy cruiser in service to the New Republic and later the Galactic Federation of Free Alliances.
