# Thor (container transport)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thor (container transport)](https://starwars.fandom.com/wiki/Thor_%28container_transport%29)

Thor was a container transport used by pirates. The transport was present deploying escort shuttles Thoret to ferry pilots to stationary TIE Defenders.
