# Trench's flagship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Trench's flagship](https://starwars.fandom.com/wiki/Trench%27s_flagship)

Admiral Trench commanded a flagship when he led a corporate fleet which blockaded the planet Malastare. The flagship was destroyed during the Battle of Malastare Narrows by a Jedi-led task force.
