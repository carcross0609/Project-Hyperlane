# Segue

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Segue](https://starwars.fandom.com/wiki/Segue)

Segue was a shuttle used to transport Belindi Kalenda, Joi Eicroth, and Yintal to Wayland in 25 ABY to meet with Elan and Vergere.
