# Unidentified Nune-class Imperial shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Nune-class Imperial shuttle](https://starwars.fandom.com/wiki/Unidentified_Nune-class_Imperial_shuttle)

Captain Mingo Bovark of the Empire-in-exile traveled to The Wheel in 137 ABY aboard a Nune-class Imperial shuttle. The shuttle's controls were later overridden by four Command Override Limpet Droids planted by agents of the One Sith and Darth Krayt's Galactic Empire, and the shuttle fired upon a Crix-class diplomatic courier shuttle of the Galactic Alliance Remnant.
