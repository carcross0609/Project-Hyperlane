# Trawler (Modular conveyors)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Trawler (Modular conveyors)](https://starwars.fandom.com/wiki/Trawler_%28Modular_conveyors%29)

Trawler was a pair of civilian Modular conveyors that were carrying Foodstuffs to an unknown destination. The ships were inspected by a TIE Defender to find nothing of concern and the conveyors were allowed to enter Hyperspace without incident.
