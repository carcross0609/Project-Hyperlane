# SPF 14897

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [SPF 14897](https://starwars.fandom.com/wiki/SPF_14897)

SPF 14897 was a Mark III bulk transport ship that was owned and operated by Santhe Passenger and Freight. It was under the command of Mils Lolinc when the Empire used the transport as bait in a trap set for the Far Orbit. The ship was supposed to be carrying military-grade control modules to Raithal, but when the Far Orbit captured her, the hold was full of stormtroopers and SpecNav forces.
