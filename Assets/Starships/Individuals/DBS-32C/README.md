# DBS-32C

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [DBS-32C](https://starwars.fandom.com/wiki/DBS-32C)

DBS-32C was a Hyena-class Droid Bomber that served in the Separatist Alliance during the Clone Wars. At one point, DBS-32C flew near a Dual Hemisphere-Omni Support Vessel in space.
