# Y'Dar Princess

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Y'Dar Princess](https://starwars.fandom.com/wiki/Y%27Dar_Princess)

The Y'Dar Princess was a relatively well-known luxury liner that shared its name with the Y'Dar system of the Outer Rim Territories' Astal sector and was active in the Outer Rim during the Galactic Civil War between the Galactic Empire and the Rebel Alliance.

## Specifications

- **Name:** Y'Dar Princess
- **Type:** Luxury liner
