# New Gilliland

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [New Gilliland](https://starwars.fandom.com/wiki/New_Gilliland)

The New Gilliland was a cruiser that the Delphidian pirate Sidon Ithano and the Weequay pirate Scorza served aboard until it was destroyed by the Hutt Clan.

## Specifications

- **Name:** New Gilliland
- **Type:** Cruiser
- **Destroyed:** Prior to the hunt for Dooku's Treasure
