# Flan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Flan](https://starwars.fandom.com/wiki/Flan)

Flan was an Airam Lambda-class T-4a shuttle that was present at Goff Platform during the Imperial attack there. it was destroyed along with the rest of the defense force.
