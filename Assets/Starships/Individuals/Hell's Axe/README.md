# Hell's Axe

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hell's Axe](https://starwars.fandom.com/wiki/Hell%27s_Axe)

The Hell's Axe was a modified Incom Corporation "Explorer" Scout Ship owned by Kin Laron. The Hell's Axe was extensively modified by Kin to have drastically superior sublight speed, maneuverability, hyperdrive, shields, and weapon systems from the ships stock model. Additionally, the ship featured an enlarged airlock which could accommodate Kin's space trooper armor, as well as an section of converted cargo space turned into an arsenal compartment.
