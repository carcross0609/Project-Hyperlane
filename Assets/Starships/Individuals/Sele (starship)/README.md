# Sele (starship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sele (starship)](https://starwars.fandom.com/wiki/Sele_%28starship%29)

IPV-1 System Patrol Craft Sele was an Airam starship. Present as defense at Goff space platform during Task Force Vengeance's attack there, it sought to engage Avenger Squadron but was soon destroyed.
