# Compton

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Compton](https://starwars.fandom.com/wiki/Compton)

Compton was a Nebulon-B escort frigate used by the Galactic Empire. It appeared in a number of Imperial Navy training simulation missions involving an attack by TIE Bombers on an Alliance to Restore the Republic storage yard.

## Specifications

- **Name:** Compton
- **Manufacturer:** Kuat Drive Yards
- **Type:** EF76 Nebulon-B Escort Frigate
- **Affiliation:** Galactic Empire
