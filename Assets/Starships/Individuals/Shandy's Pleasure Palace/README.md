# Shandy's Pleasure Palace

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shandy's Pleasure Palace](https://starwars.fandom.com/wiki/Shandy%27s_Pleasure_Palace)

Shandy's Pleasure Palace was a Whaladon-class container ship captained by Shandy Fanaso. It operated (briefly) as a portable cantina, and was later seized by the Domains of Triton.

## Specifications

- **Name:** Shandy's Pleasure Palace
- **Model:** Whaladon-class container ship
- **Owners:** Shandy Fanaso
