# Dark Revenge

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dark Revenge](https://starwars.fandom.com/wiki/Dark_Revenge)

The Dark Revenge was a DP20 gunship that served as the command vessel for the privateer Dharus during the time of the Galactic Civil War. Dharus' Buccaneers utilized the warship in their dealings along the Leisure Corridor, attacking vessels and coming into conflict with the Imperial Navy.

## Specifications

- **Name:** Dark Revenge
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** DP20 gunship
- **Type:** Modified anti-starfighter warship
- **Length:** 120 meters
- **Max Speed:** 1000 km/h
- **Hdrange:**

  - Backup Class 8
- **Armament:**
  - 8 double turbolaser batteries
  - 6 quad laser cannons
  - 4 concussion missile tubes
- **Crew:** 46
- **Capacity:** 300 metric tons
- **Consumables:** 5 months
- **Role:** Command vessel
- **Affiliation:** Dharus' Buccaneers
- **Captains:** Dharus
