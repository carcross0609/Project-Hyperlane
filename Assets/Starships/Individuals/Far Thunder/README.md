# Far Thunder

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Far Thunder](https://starwars.fandom.com/wiki/Far_Thunder)

The Far Thunder was one of the Republic-class cruisers that were introduced during the Yuuzhan Vong War. Republic-class vessels were cheap to produce, allowing large numbers to be brought into service.

## Specifications

- **Name:** Far Thunder
- **Model:** Republic-class cruiser
- **Type:** Cruiser
- **Destroyed:** 28 ABY
- **Affiliation:** New Republic
- **Captains:** Captain Hannser
