# Kintan ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kintan ship](https://starwars.fandom.com/wiki/Kintan_ship)

A ship was used to escape Kintan by Jedi Master Tholme, Padawan Aayla Secura, Jedi Knight Quinlan Vos, and Clan Secura heir Nat Secura after a mission there.
