# Meniscus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Meniscus](https://starwars.fandom.com/wiki/Meniscus)

Meniscus was the personal Imperial-class Star Destroyer of Grand Admiral Martio Batch. The executive officer of the Meniscus betrayed and executed Batch following the Battle of Endor, and joined Admiral Blitzer Harrsk in the Deep Core.

## Specifications

- **Name:** Meniscus
- **Manufacturer:** Kuat Drive Yards
- **Type:** Imperial-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/LN starfighters
- **Affiliation:**
  - Galactic Empire
  - Zero Command
- **Owners:**
  - Grand Admiral Martio Batch
  - Admiral Blitzer Harrsk
