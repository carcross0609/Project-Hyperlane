# Floran

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Floran](https://starwars.fandom.com/wiki/Floran)

Floran was an Assassin-class corvettes belonging to the Rebel Alliance. They was supposed to rendezvous with the Rebel Fleet at Sullust but were destroyed by Maarek Stele.
