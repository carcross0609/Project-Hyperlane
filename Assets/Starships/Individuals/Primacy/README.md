# Primacy

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Primacy](https://starwars.fandom.com/wiki/Primacy)

The Primacy, also known as the Sunken Lucrehulk, was a Lucrehulk-class LH-3210 cargo freighter that served as the base of operations for the Bedlam Raiders, a group of marauders on the Outer Rim planet Koboh.
