# Sea Legacy

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sea Legacy](https://starwars.fandom.com/wiki/Sea_Legacy)

The Sea Legacy was an Acclamator-class assault ship that deployed the clone forces in the Battle of Pengalan IV. When the battle turned out to be an ambush, the Sea Legacy recovered her troops, and retreated immediately.
