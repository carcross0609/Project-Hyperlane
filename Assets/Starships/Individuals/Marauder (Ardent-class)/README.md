# Marauder

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Marauder (Ardent-class)](https://starwars.fandom.com/wiki/Marauder_%28Ardent-class%29)

The Marauder was an Ardent-class fast frigate serving as the flagship of the First Coruscant Task Force, a detachment of the Imperial Navy loyal to the Sith Empire. It was commanded by the Human Admiral Krion Grail and his second-in-command, Captain Shantillen.
