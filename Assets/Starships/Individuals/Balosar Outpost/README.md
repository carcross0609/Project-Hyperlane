# Balosar Outpost

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Balosar Outpost](https://starwars.fandom.com/wiki/Balosar_Outpost)

Balosar Outpost was an illegally constructed space station in the Balosar system acting as a staging point for assaults on Galactic Republic territories. It was the site of a massive battle involving all available Republic ships in an effort to disable the station.

## Specifications

- **Name:** Balosar Outpost
- **Manufacturer:** Sith Empire
- **Shield Gen:** 4 Shield Generators
- **Armament:** 26 Laser turrets
- **Complement:** Over 60 Mark VI Supremacy-class starfighters
- **Bays:** 4 Hangars
- **Communications:** Five antennae

  - Southern Core
- **System:** Balosar system
- **Coordinates:** L-12
- **Orbited:** Balosar
- **Affiliation:** Sith Empire
- **Battles:** Battle of the Balosar system
- **Services:** Sith Empire
