# Silvo's pirate frigate

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Silvo's pirate frigate](https://starwars.fandom.com/wiki/Silvo%27s_pirate_frigate)

The pirate frigate was operated by Silvo's pirates in the New Republic Era. It was equipped with multiple Turbolaser batteries and a large central hanger that could launch out pirate Snub fighters. The ship was adorned in a black and white color scheme, the livery of the Pirate Nation.
