# Scythe

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Scythe (Strike-class)](https://starwars.fandom.com/wiki/Scythe_%28Strike-class%29)

A Loronar Strike-class medium cruiser serving in the Galactic Empire's Imperial Starfleet, the Scythe had been assigned as a convoy escort ship during the Battle of Hoth. The convoy it was assigned to protect en route to the Hoth system was destroyed by then-rookie pilot Ace Azzameen. It is unclear if the Scythe itself survived the battle or not.
