# T-ST

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [T-ST](https://starwars.fandom.com/wiki/T-ST)

T-ST was a Utility Tug in use by a Rebel Alliance outpost during the Galactic Civil War, within an Imperial simulation. During an Imperial torpedo attack by Alpha Squadron TIE Bombers, T-ST attempted to board one of the Class-A cargo containers along with fellow Utility Tug T-SP. However, the ships were destroyed in the attack, along with the entire outpost.

- **Name:** T-ST
