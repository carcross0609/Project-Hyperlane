# Permondiri Explorer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Permondiri Explorer/Legends](https://starwars.fandom.com/wiki/Permondiri_Explorer/Legends)

The Permondiri Explorer was an infamous lost survey vessel. After it had departed to examine a newly discovered star system, all contact with the Permondiri Explorer was lost and several large expeditions were mounted to find it and its crew of 112 beings. With the failure of these searches, the Permondiri Explorer eventually became a legend among spacers.
