# G'nabgib

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [G'nabgib](https://starwars.fandom.com/wiki/G%27nabgib)

The G'nabgib was an Imperial Lambda-class T-4a shuttle used to evacuate the leading TIE/D Defender scientist and other remaining personnel from a research facility. Part of a convoy that included the Mharsup and escorted by Maarek Stele, it was intended to rendezvous with the Hashim group.
