# Cielo

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cielo](https://starwars.fandom.com/wiki/Cielo)

Cielo was a BFF-1 bulk freighter escorted by the CR90 corvette Wasp. It was part of an Alliance to Restore the Republic convoy after Operation Grain Snatch still looking for a site for a new base, but was endangered by Red Wind.

## Specifications

- **Name:** Cielo
- **Model:** BFF-1 bulk freighter
- **Type:** Freighter
- **Length:** 120.9 meters
- **Width:** 75.56 meters
- **Height:** 34 meters
- **Affiliation:** Alliance to Restore the Republic
