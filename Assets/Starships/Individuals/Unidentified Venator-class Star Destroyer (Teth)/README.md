# Unidentified Venator-class Star Destroyer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Venator-class Star Destroyer (Teth)](https://starwars.fandom.com/wiki/Unidentified_Venator-class_Star_Destroyer_%28Teth%29)
