# Heartbound

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Heartbound](https://starwars.fandom.com/wiki/Heartbound)

The Heartbound was a warship in the Alliance Fleet in 1 BBY. The ship fought in the Battle of Scarif, where Admiral Raddus ordered it and the Deviant to box in the Imperial Star Destroyers.
