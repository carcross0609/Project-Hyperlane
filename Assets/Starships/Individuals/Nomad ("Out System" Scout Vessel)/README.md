# Nomad

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nomad ("Out System" Scout Vessel)](https://starwars.fandom.com/wiki/Nomad_%28%22Out_System%22_Scout_Vessel%29)

The Nomad was a Loronar Corporation "Out System" Scout Vessel piloted by Imperial scouts during the Galactic Civil War. Prior to the Demophon supernova the Nomad sought new locations for the Empire's Demophon operations.
