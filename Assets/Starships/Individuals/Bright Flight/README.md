# Bright Flight

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bright Flight](https://starwars.fandom.com/wiki/Bright_Flight)

Bright Flight was a Sprint-class rescue craft used by the Grand Army of the Republic during the Clone Wars. Several bacta tanks were installed aboard.

## Specifications

- **Name:** Bright Flight
- **Manufacturer:** SoroSuub Corporation
- **Type:** Sprint-class rescue craft
- **Length:** 30 meters
- **Max Speed:** 1,150 km/h
- **Hyperdrive:**
  - Class 1
  - Class 12 (backup)
- **Armament:** None
- **Crew:**
  - Pilots (2)
  - Other crew (1)
  - Medics (5)
- **Passengers:**
  - 40 patients
- **Capacity:** 2 metric tons
- **Consumables:** 1 month
- **Role:** Medical frigate
- **Affiliation:** Galactic Republic
