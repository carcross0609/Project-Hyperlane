# Imperator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Imperator (Victory-class)](https://starwars.fandom.com/wiki/Imperator_%28Victory-class%29)

The Imperator was a Victory-class Star Destroyer in the Imperial Navy. During the New Republic push to take Coruscant in 6 ABY, intelligence indicated that a Star Destroyer named Imperator was part of the defensive fleet guarding the Galactic capital. It was apparently a well-regarded ship, but it is implied that that the squadron defending Coruscant was composed entirely of Victory-class Star Destroyers, which would suggest that this Imperator belonged to this class of smaller, older Star Destroyers.
