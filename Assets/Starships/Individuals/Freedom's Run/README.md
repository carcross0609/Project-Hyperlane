# Freedom's Run

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Freedom's Run](https://starwars.fandom.com/wiki/Freedom%27s_Run)

The Freedom's Run was an MC80 Star Cruiser of the Alliance to Restore the Republic that served in the Galactic Civil War. Although other Star Cruisers such as Home One, Nautilian, Liberty, and Amalthea were confirmed for the assault on Endor in 4 ABY, the Freedom's Run status was tentative, as was the cruiser Restoration. Admiral Gial Ackbar listed the Alliance Navy starships and their condition in a report to Commander-in-Chief Mon Mothma, and was included in The Rebel Files.

## Specifications

- **Name:** Freedom's Run
- **Manufacturer:** Mon Calamari Shipyards
- **Line:** MC80 Star Cruiser
- **Type:** Star Cruiser
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Rebel Alliance Navy
