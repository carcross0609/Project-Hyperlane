# Hoopaju

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hoopaju](https://starwars.fandom.com/wiki/Hoopaju)

Hoopaju was a Rebel Alliance GR-75 medium transport. In 3 ABY, while carrying weapons, it was caught by the Rage in the Airam sector.

## Specifications

- **Name:** Hoopaju
- **Manufacturer:** Gallofree Yards, Inc.
- **Model:** GR-75 medium transport
- **Type:** Medium transport
- **Length:** 90 meters
- **Affiliation:** Alliance to Restore the Republic
