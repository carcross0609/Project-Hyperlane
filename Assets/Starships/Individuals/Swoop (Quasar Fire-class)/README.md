# Swoop

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Swoop (Quasar Fire-class)](https://starwars.fandom.com/wiki/Swoop_%28Quasar_Fire-class%29)

The Swoop was a Quasar Fire-class cruiser-carrier that served the Galactic Empire during government's reign. Lieutenant Canonhaus served aboard the carrier as liaison to the stormtroopers, who called him Footoo. The troopers liked the lieutenant but did not trust him. One day, the Swoop responded to an insurrection in the highland jungles of Haruun Kal.
