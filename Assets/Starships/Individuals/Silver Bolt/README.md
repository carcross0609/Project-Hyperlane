# Silver Bolt

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Silver Bolt](https://starwars.fandom.com/wiki/Silver_Bolt)

The Silver Bolt was a starship operated by Alliance to Restore the Republic member Erisson Flask. Polke acted as the co-pilot. At some point, it was engaged in battle by TIE/LN starfighters.
