# Arc Hammer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Arc Hammer](https://starwars.fandom.com/wiki/Arc_Hammer)

The Arc Hammer was an Imperial spacefaring production facility used to supplement the Imperial Stormtrooper Corps with dark troopers, a new generation of battle droid stormtroopers to be used in the Galactic Civil War against the Rebel Alliance.
