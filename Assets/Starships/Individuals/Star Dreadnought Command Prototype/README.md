# Star Dreadnought Command Prototype

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Star Dreadnought Command Prototype](https://starwars.fandom.com/wiki/Star_Dreadnought_Command_Prototype)

The Star Dreadnought Command Prototype was a prototype Executor-class Star Dreadnought used by the Imperial Navy during the Imperial Era. At some point, the Star Dreadnought was escorted through space by several Imperial II-class Star Destroyers. It was equipped with sublight engines.

## Specifications

- **Name:** Star Dreadnought Command Prototype
- **Line:** Prototype Executor-class Star Dreadnought
- **Type:** Star Dreadnought
- **Engine:** Sublight engines
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
