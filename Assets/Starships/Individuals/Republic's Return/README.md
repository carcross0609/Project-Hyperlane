# Republic's Return

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Republic's Return](https://starwars.fandom.com/wiki/Republic%27s_Return)

The Republic's Return was a star cruiser used by the Alliance to Restore the Republic in the evacuation of its base on Yavin 4 following the Battle of Yavin.
