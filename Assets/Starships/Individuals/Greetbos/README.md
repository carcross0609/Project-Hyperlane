# Greetbos

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Greetbos](https://starwars.fandom.com/wiki/Greetbos)

The Greetbos was a GAT-12j Skipray blastboat used by the Imperials to patrol the Elrood sector after the invasion of Derilyn.

- **Name:** Greetbos
- **Manufacturer:** Sienar Fleet Systems
- **Model:** GAT-12j Skipray Blastboat
- **Length:** 25 meters
- **Max Speed:** 1,200 km/h
- **Hyperdrive:** Class 2
- **Shield Gen:** Equipped
- **Navigation:** Navigation computer (4 jump capability)
- **Armament:**

  - Twin laser cannon turret
  - Proton torpedo launcher
  - Concussion missile launcher
- **Crew:** 2; 2 gunners
- **Skeleton:** 1
- **Capacity:** 20 metric tons
- **Consumables:** 1 month
- **Role:** Patrol ship
- **Affiliation:** Galactic Empire
- **Captains:** Lieutenant Kader Tentrata
