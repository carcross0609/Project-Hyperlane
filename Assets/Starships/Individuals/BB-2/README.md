# BB-2

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [BB-2](https://starwars.fandom.com/wiki/BB-2)

BB-2 was a BB-wing droid starfighter created by Sig Greebling. It was piloted by Cassian Andor during a battle against Solitus, alongside BB-5 and BB-8.
