# Red 8

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red 8](https://starwars.fandom.com/wiki/Red_8)

Red 8 was a T-65 X-wing starfighter in service to the Alliance to Restore the Republic during the Galactic Civil War. It was assigned to Red Squadron and stationed at the Rebel base on Yavin 4.
