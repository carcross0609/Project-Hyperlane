# Impasse

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Impasse](https://starwars.fandom.com/wiki/Impasse)

Impasse was a Kuat Drive Yards Super Transport VII container ship. It was commanded by Chalmer Trillili, leader of the Scourge Pirates, who outfitted the 280 meter long ship with a single gravity well projector salvaged from an Interdictor cruiser.
