# Lathir

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lathir](https://starwars.fandom.com/wiki/Lathir)

Lathir was a Rebel Alliance cruiser that acted as a command vessel. It was one of the closest to Onderon, and was used to transfer prisoners captured from Whisper Base.

## Specifications

- **Name:** Lathir
- **Type:** Cruiser
- **Role:**

- **Affiliation:** Rebel Alliance
