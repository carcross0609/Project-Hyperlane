# Meteor Racer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Meteor Racer](https://starwars.fandom.com/wiki/Meteor_Racer)

The Meteor Racer was one of the 600 refugee starships that were trapped on Coruscant when the Yuuzhan Vong invaded. The Yuuzhan Vong used these ships and their passengers as Human shields in the Battle of Coruscant.

## Specifications

- **Name:** Meteor Racer
- **Type:** Starship
- **Role:** Refugee ship
