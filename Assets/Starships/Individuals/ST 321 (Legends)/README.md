# ST 321

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [ST 321/Legends](https://starwars.fandom.com/wiki/ST_321/Legends)

ST 321 was the comm unit designation of a Imperial Lambda-class T-4a shuttle belonging to Supreme Commander Darth Vader. The transport most notably ferried the Dark Lord of the Sith in 4 ABY to the second Death Star, which was undergoing construction above Endor.

## Specifications

- **Name:** ST 321
- **Model:** Lambda-class T-4a shuttle
- **Length:** 20 meters
- **Sensor:** Specialized tactical displays
- **Countermeasures:** Sensor jammers
- **Crew:**
  - Captain Yorr
  - Colonel Jendon
- **Role:** Shuttle
- **Affiliation:** Galactic Empire
- **Owners:** Darth Vader
