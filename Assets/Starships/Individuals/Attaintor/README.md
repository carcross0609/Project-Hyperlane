# Attaintor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Attaintor](https://starwars.fandom.com/wiki/Attaintor)

The Attaintor was a starship that saw service among the forces of the Galactic Empire during the Galactic Civil War. The Imperial pilot Flight Captain Myrette Davani served aboard the Attaintor for a time, working in fighter operations.

- **Name:** Attaintor
