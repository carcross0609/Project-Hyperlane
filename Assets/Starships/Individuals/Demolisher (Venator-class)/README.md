# Demolisher (Venator-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Demolisher (Venator-class)](https://starwars.fandom.com/wiki/Demolisher_%28Venator-class%29)

The Demolisher was a Venator-class Star Destroyer in the service of the Galactic Republic around 22 BBY. This ship was present when the clone troopers of Breakout Squad liberated the inhabitants of the planet Kynachi from the Trade Federation.
