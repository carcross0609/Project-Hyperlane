# Goliath

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Goliath (Imperial II-class)](https://starwars.fandom.com/wiki/Goliath_%28Imperial_II-class%29)

Goliath was an Imperial II-class Star Destroyer used by the Galactic Empire to protect a Golan platform Golan I. Goliath oversaw a convoy of fifteen Sentinel-class landing craft, the KDT Group.

## Specifications

- **Name:** Goliath
- **Type:** Imperial II-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/LN starfighters
- **Affiliation:** Galactic Empire
