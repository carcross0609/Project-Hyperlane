# Kooba's Pride

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kooba's Pride](https://starwars.fandom.com/wiki/Kooba%27s_Pride)

The Kooba's Pride was a starliner that operated along Keller's Void. The ship was seized by pirates who used an asteroid as a natural interdictor.
