# Hauler VI

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hauler VI](https://starwars.fandom.com/wiki/Hauler_VI)

Hauler VI was a Censian-class transport for the Alliance to Restore the Republic. The Alliance used it to transport SpecForce Marines of its army.
