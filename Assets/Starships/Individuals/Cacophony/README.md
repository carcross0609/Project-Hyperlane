# Cacophony

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Cacophony](https://starwars.fandom.com/wiki/Cacophony)

The Cacophony was a Nihil Stormship under the command of Melis Shryke. The ship was equipped with a Path engine, which allowed it to traverse hyperspace through the Stormwall. In 228 BBY, the vessel was stolen by Jedi Master Avar Kriss, who used it to traverse past the Stormwall to return to Galactic Republic-controlled space.

## Specifications

- **Name:** Cacophony
- **Hdsystem:** Path engine
- **Affiliation:** Nihil
- **Captains:** Melis Shryke
