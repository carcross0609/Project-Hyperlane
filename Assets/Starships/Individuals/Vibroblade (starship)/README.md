# Vibroblade

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vibroblade (starship)](https://starwars.fandom.com/wiki/Vibroblade_%28starship%29)

Vibroblade was a Skipray Blastboat that operated as part of the Khuiumin Survivors' pirate forces. It was used to board luxury liners and other larger vessels that had been targeted for plunder.

## Specifications

- **Name:** Vibroblade
- **Model:** GAT-12 Skipray Blastboat
- **Length:** 25 meters
- **Affiliation:** Khuiumin Survivors
