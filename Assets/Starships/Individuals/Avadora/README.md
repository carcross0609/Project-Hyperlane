# Avadora

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Avadora](https://starwars.fandom.com/wiki/Avadora)

The Avadora was a small First Order yacht owned by Vroc Raynshi, the father of Maize Raynshi. When Vroc was reassigned, Maize, along with the Force-sensitive Karr Nuq Sin, and the droid RZ-7, stole the ship for their journey to travel around the galaxy and uncover Jedi artifacts. Eventually, Sin and RZ-7 returned the ship when they traveled back to Merokia.
