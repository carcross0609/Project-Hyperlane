# Jade's Fire

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jade's Fire](https://starwars.fandom.com/wiki/Jade%27s_Fire)

The Jade's Fire was a highly modified Personal Luxury Yacht 3000. Originally owned by the industrialist Ja Bardrin and named The Winning Gamble, the ship later belonged to Mara Jade, who named it Jade's Fire.
