# Alamintari

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Alamintari](https://starwars.fandom.com/wiki/Alamintari)

The Alamintari was a luxury liner bound for the Outer Rim Territories when ten kilograms of Garcornian spice was discovered in a T-P-C4 Live Organism Comfort Conveyor and a pre-recorded sound chip of a Breshig trill beast to scare away Customs Inspectors.
