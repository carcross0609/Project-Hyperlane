# Razor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Razor (Imperial-class)](https://starwars.fandom.com/wiki/Razor_%28Imperial-class%29)

The Razor was an Imperial-class Star Destroyer in service to the Galactic Empire. During the Galactic Civil War, the Razor was stationed in the Tallaan system, guarding the Tallaani Shipyards.
