# Corellian shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Corellian shuttle](https://starwars.fandom.com/wiki/Corellian_shuttle)

A Corellian shuttle was a type of starship that was manufactured on Corellia. Mercurial Swift used one of these around the time of the Battle of Jakku.
