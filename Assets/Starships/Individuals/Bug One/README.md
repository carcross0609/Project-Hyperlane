# "Bug One"

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bug One](https://starwars.fandom.com/wiki/Bug_One)

"Bug One" was the designation Alliance Admiral Nek Bwua'tu gave to the nest ship which belonged to the Dark Nest during the Battle of the Murgo Choke in 36 ABY.
