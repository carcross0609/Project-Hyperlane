# Jonram Dremel's ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Jonram Dremel's ship](https://starwars.fandom.com/wiki/Jonram_Dremel%27s_ship)

A ship owned by the Thradian Jonram Dremel was used between the years 14 BBY and 9 BBY. The Mohsenian Kricad would later steal the ship following the death of Dremel onboard the DS-1 Death Star Mobile Battle Station.

## Specifications

- **Name:** Jonram Dremel's ship
- **Affiliation:** Galactic Empire
- **Owners:**
