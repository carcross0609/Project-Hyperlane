# Shark

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shark (starfighter)](https://starwars.fandom.com/wiki/Shark_%28starfighter%29)

The Shark was Commander Merai's personal heavy starfighter during the Clone Wars. It was of Mon Calamari design.

- **Manufacturer:** Mon Calamari Shipyards

- **Crew:** Pilot (1)
