# Empire Maker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Empire Maker](https://starwars.fandom.com/wiki/Empire_Maker)

The Empire Maker was a Imperial II-class Star Destroyer built by the Imperial Remnant that served as Moff Drikl Lecersen's flagship at the Battle over Exodo II.
