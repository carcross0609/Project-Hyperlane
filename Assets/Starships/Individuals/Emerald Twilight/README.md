# Emerald Twilight

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Emerald Twilight](https://starwars.fandom.com/wiki/Emerald_Twilight)

The Emerald Twilight was the starship of Sheel Odala. She used it on her trip to Void Station where she fell in with an old acquaintance.
