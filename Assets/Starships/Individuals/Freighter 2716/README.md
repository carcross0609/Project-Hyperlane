# Freighter 2716

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Freighter 2716](https://starwars.fandom.com/wiki/Freighter_2716)

Freighter 2716 was an Orca-class freighter used by the Galactic Empire to transport a giant kyber crystal to the Tonnis sector. It was disguised as a civilian freighter to avoid notice. In 1 BBY, it was infiltrated by rebels Saw Gerrera, Ezra Bridger, Sabine Wren, and Chopper during a brief stop at Faos Station. When Gerrera discovered the freighter's cargo, he wired the crystal up to the ship's hyperdrive to create a bomb, which destroyed both the freighter and the Imperial I-class Star Destroyer it was rendezvousing with when it went off.
