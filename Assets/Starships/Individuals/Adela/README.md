# Adela

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Adela](https://starwars.fandom.com/wiki/Adela)

Adela was a starship owned by Refka Trell. It was registered on Elom with registration number RN32-000439. In 16 ABY, this was one of many ships Luke Skywalker tracked as it passed the inner flight control buoys of the planet Teyr.
