# Lament

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lament](https://starwars.fandom.com/wiki/Lament)

Lament was a Strike-class medium cruiser belonging the Galactic Empire. The Lament along with Corrupter was part of the attack on Dunari's Casino and was destroyed by Rebel B-wing starfighters.
