# Lifeline (cargo ship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lifeline (cargo ship)](https://starwars.fandom.com/wiki/Lifeline_%28cargo_ship%29)

The Lifeline was an Imperial cargo ship. During the Rebellion era it was used as a decoy to draw in Rebel ships, so it could use its secret weapon, a battery of gravity well projectors.
