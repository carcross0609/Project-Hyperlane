# Redma

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Redma](https://starwars.fandom.com/wiki/Redma)

The Redma was a Galactic Alliance cruiser assigned to the Fifth Fleet. It was destroyed during the Battle of Kashyyyk following a sustained barrage from the Bothan navy.
