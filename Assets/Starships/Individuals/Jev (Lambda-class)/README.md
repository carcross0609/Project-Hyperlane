# Jev

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jev (Lambda-class)](https://starwars.fandom.com/wiki/Jev_%28Lambda-class%29)

Jev was a Imperial Lambda-class T-4a shuttle that was at the Sensor Control station. When the station was under attack and the shields began to fail. The shuttle carrying several Imperial officers left the station in an attempt to escape but it was destroyed before it could jump into hyperspace.
