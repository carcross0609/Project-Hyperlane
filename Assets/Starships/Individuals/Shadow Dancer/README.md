# Shadow Dancer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shadow Dancer](https://starwars.fandom.com/wiki/Shadow_Dancer)

The Shadow Dancer was a Imperial Customs Corvette used as privateer vessel. The captain sought to make his ship stealthy, using sensor baffling, a sensor mask, and a baffled drive.

## Specifications

- **Name:** Shadow Dancer
- **Type:** Imperial Customs Corvette
- **Role:** Privateering vessel
