# Wurger

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wurger](https://starwars.fandom.com/wiki/Wurger)

Wurger was group of Assassin-class corvettes used by the Rebel Alliance, that contained troops for Admiral Harkov's fleet. They were eventually destroyed by Imperial pilot Maarek Stele.
