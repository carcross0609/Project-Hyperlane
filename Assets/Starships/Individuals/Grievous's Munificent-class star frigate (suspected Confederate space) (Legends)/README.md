# Grievous's Munificent-class star frigate

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Grievous's Munificent-class star frigate (suspected Confederate space)/Legends](https://starwars.fandom.com/wiki/Grievous%27s_Munificent-class_star_frigate_%28suspected_Confederate_space%29/Legends)

In 22 BBY, a Munificent-class star frigate was used by the Confederate General Grievous. Grievous used the frigate when he was attempting to track Jedi Knight Anakin Skywalker's position in Confederate space.
