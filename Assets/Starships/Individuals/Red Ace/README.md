# Red Ace

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Red Ace](https://starwars.fandom.com/wiki/Red_Ace)

The Red Ace was a starship piloted by Freya Fenris. Freya Fenris took inspiration from Kuat Systems Engineering's A-wing starfighter line, and incorporated wings with laser cannons for better stability and firepower.

## Specifications

- **Name:** Red Ace
- **Manufacturer:**
  - Kuat Systems Engineering
  - Freya Fenris
- **Type:** Racer
- **Engine:** K-99 Event Horizon sublight engines
- **Armament:**
  - Asgar-4 lasers (2)
  - Valkyr-2 laser cannons (2)
- **Crew:**
  - Pilot (1)
  - Astromech droid (1)
- **Affiliation:**
  - Ace Squadron
  - Citizens' Fleet
- **Owners:** Freya Fenris
