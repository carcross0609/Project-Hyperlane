# Kedriss One

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kedriss One](https://starwars.fandom.com/wiki/Kedriss_One)

Kedriss One was an evacuation ship used by several Jedi in an attempt to flee Ossus before its destruction. The ship was destroyed by Mandalorian Crusaders on Basilisk war droids before it could leave the system.

## Specifications

- **Name:** Kedriss One
- **Role:** Evacuation ship
- **Destroyed:** 3996 BBY
- **Affiliation:**
  - Galactic Republic
  - Jedi Order
