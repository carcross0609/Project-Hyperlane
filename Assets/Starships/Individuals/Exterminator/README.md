# Exterminator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Exterminator](https://starwars.fandom.com/wiki/Exterminator)

The Exterminator was a Star Destroyer being manufactured in 3 ABY for the Imperial Navy by Kuat Drive Yards. As the Exterminator construction neared its finish, the amateur slicer Shannon Voorson managed to slice into an Imperial computer file listing a number of Star Destroyers being built at Kuat, including Exterminator. Shannon later showed the Star Destroyer list to her cousin and Rebel Alliance member, Deen Voorson.

## Specifications

- **Name:** Exterminator
- **Manufacturer:** Kuat Drive Yards
- **Model:** Star Destroyer
- **Role:** Destroyer
- **Commission:** 3 ABY, Kuat
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
