# Destiny

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Destiny (Imperial starship)](https://starwars.fandom.com/wiki/Destiny_%28Imperial_starship%29)

The Destiny was an Imperial craft under the command of General Wessel and Imperial Sovereign Protector Carnor Jax. It was used in the hunt for Kir Kanos. Most of the crew were killed on Zaddja by a trap set by Kanos.

- **Name:** Destiny
