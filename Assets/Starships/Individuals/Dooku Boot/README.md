# Dooku Boot

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Dooku Boot](https://starwars.fandom.com/wiki/Dooku_Boot)

Dooku Boot was a Low Altitude Assault Transport/infantry used by the Galactic Republic that took part in the Second Battle of Geonosis during the Clone Wars. The nose of the gunship was customized with a painting of Count Dooku getting booted in the backside by a clone trooper's armored leg.
