# Virago

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Virago](https://starwars.fandom.com/wiki/Virago)

Virago was a prototype StarViper-class attack platform and the personal starship of Prince Xizor.

- **Capacity:** 1 metric ton

- **Othersystems:** S-foil actuator
- **Role:**

  - Space superiority fighter
- **Destroyed:** 3 ABY
- **Affiliation:** Black Sun
- **Owners:** Xizor
