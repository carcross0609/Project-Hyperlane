# Storm Killer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Storm Killer](https://starwars.fandom.com/wiki/Storm_Killer)

Storm Killer was a heavily modified CEC YT-1300 light freighter which was optimized for combat and put on sale by the Bith used space transport salesman Fiz Cor'gril.
