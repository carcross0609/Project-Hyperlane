# Gilad Halsek's Lambda-class shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gilad Halsek's Lambda-class shuttle](https://starwars.fandom.com/wiki/Gilad_Halsek%27s_Lambda-class_shuttle)

Gilad Halsek maintained a personal Lambda-class shuttle in his post as the Imperial consul-general of the Bothan colony world of Kothlis. Docking Berth 120 at the Kothlis Starport was specially reserved for Halsek's shuttle.
