# Chilastra

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chilastra](https://starwars.fandom.com/wiki/Chilastra)

Chilastra was a MOD-17 container freighter converted to transport refugees from Druckenwell while it was under Yuuzhan Vong occupation.

## Specifications

- **Name:** Chilastra
- **Manufacturer:** Loronar Corporation
- **Model:** MOD-17 container freighter
- **Type:** Freighter
- **Length:** 550 meters
