# Intruder

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Intruder (Marauder-class)](https://starwars.fandom.com/wiki/Intruder_%28Marauder-class%29)

Shortly before the Battle of Endor, this ship led a mercenary force to disrupt a meeting between the Rebel cruiser Liberty and members of the Bothan Spynet.

## Specifications

- **Name:** Intruder
- **Model:** Marauder-class corvette
- **Type:** Corvette
- **Destroyed:** 3 ABY
- **Affiliation:** Falcon's Nest mercenaries
