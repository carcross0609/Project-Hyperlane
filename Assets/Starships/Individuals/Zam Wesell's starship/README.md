# Zam Wesell's starship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Zam Wesell's starship](https://starwars.fandom.com/wiki/Zam_Wesell%27s_starship)

A starship was used by Clawdite assassin Zam Wesell to hunt the criminal mastermind Phaedra to Nar Shaddaa sometime between 40 BBY and 34 BBY.

## Specifications

- **Name:** Zam Wesell's starship
- **Armament:** Cannons (at least 2)
- **Owners:** Zam Wesell
