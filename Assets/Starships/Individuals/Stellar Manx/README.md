# Stellar Manx

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Stellar Manx](https://starwars.fandom.com/wiki/Stellar_Manx)

Stellar Manx was an Action VI bulk transport captained by Kar Lamoran. In 0 ABY, it was commandeered by the Galactic Empire for a top-secret experiment.
