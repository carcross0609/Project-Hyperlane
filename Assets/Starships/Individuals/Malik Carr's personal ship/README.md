# Malik Carr's personal ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Malik Carr's personal ship](https://starwars.fandom.com/wiki/Malik_Carr%27s_personal_ship)

A frigate was owned by the Yuuzhan Vong Malik Carr during the Yuuzhan Vong War. It saw action in the Bilbringi system, where it engaged the carrier-cruiser Thurse before its commanders allowed it to appear to be driven off by the New Republic vessel.
