# Leach

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Leach](https://starwars.fandom.com/wiki/Leach)

Leach was a CR90 corvette belonging to the Pakuuni Pirates. It was defending a pirate outpost along with Clavier and Grapler. Leach was destroyed by Imperial ace Maarek Stele along with the other corvettes and the entire outpost.
