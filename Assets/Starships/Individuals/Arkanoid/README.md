# Arkanoid

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Arkanoid](https://starwars.fandom.com/wiki/Arkanoid)

The Arkanoid was a Zeta-class long-range shuttle in service to the Galactic Empire.

- **Name:** Arkanoid
- **Manufacturer:** Telgorn Corporation
- **Model:** Zeta-class long-range shuttle
- **Type:** Shuttle
- **Length:** 35 meters
- **Hyperdrive:**

  - Class 8.0 (backup)
- **Armament:**

  - 2 double blaster cannons
  - 1 retractable rear-mounted double blaster cannon
- **Role:** Transport
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Owners:** P'laang Ri
