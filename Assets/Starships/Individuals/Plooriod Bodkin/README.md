# Plooriod Bodkin

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Plooriod Bodkin](https://starwars.fandom.com/wiki/Plooriod_Bodkin)

The Plooriod Bodkin was a cruiser in the Judicial Starfleet of the Galactic Republic during the Separatist Crisis. Shortly before the start of the Clone Wars, it was dispatched to recapture the Judicial corvette Scarlet Thranta, commanded by Captain Zozridor Slayke, which had gone renegade in hopes of provoking war with the Confederacy of Independent Systems.
