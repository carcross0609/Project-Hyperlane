# Danni Quee's corvette

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Danni Quee's corvette](https://starwars.fandom.com/wiki/Danni_Quee%27s_corvette)

The scientist Danni Quee used a battered corvette to transport a yammosk jammer to the planet Coruscant in order to test the device against the Yuuzhan Vong in the fighting at Coruscant in 27 ABY.
