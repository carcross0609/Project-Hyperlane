# Relentless

**Kind:** Individual ship

**Source:** [Relentless (Sith Imperial ship)](https://starwars.fandom.com/wiki/Relentless_%28Sith_Imperial_ship%29)

- **Role:** Royal transport
- **Affiliation:**
