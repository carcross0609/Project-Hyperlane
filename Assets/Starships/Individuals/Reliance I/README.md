# Reliance I

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Reliance I](https://starwars.fandom.com/wiki/Reliance_I)

The Reliance I was a Republic command ship used by the Galactic Republic around 4000 BBY. It served as the flagship of Ulic Qel-Droma during the opening stages of the Great Sith War.
