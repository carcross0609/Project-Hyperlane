# Anakin's shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Anakin's shuttle](https://starwars.fandom.com/wiki/Anakin%27s_shuttle)

Anakin's shuttle was an refitted Eta-class shuttle that used by the Galactic Republic during the Clone Wars. Jedi Generals Anakin Skywalker and Adi Gallia used it to board General Grievous's Recusant-class light destroyer and rescue Jedi Master Eeth Koth.
