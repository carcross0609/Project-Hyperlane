# Vigilant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vigilant (CR90 corvette)/Legends](https://starwars.fandom.com/wiki/Vigilant_%28CR90_corvette%29/Legends)

The TNV Vigilant was a CR90 corvette that was used by the Thaereian military during the Clone Wars. It participated in the Battle of Cularin. It was commanded by Captain Baltor Yfridian.
