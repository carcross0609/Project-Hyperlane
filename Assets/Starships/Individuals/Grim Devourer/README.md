# Grim Devourer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Grim Devourer](https://starwars.fandom.com/wiki/Grim_Devourer)

The Grim Devourer was a ship owned by the Dank Graks during the High Republic Era. Only Force-sensitive individuals could fly or use the weapons of the ship.
