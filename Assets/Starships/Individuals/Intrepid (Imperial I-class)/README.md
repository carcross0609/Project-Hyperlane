# Intrepid

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Intrepid (Imperial I-class)](https://starwars.fandom.com/wiki/Intrepid_%28Imperial_I-class%29)

Intrepid was an Imperial I-class Star Destroyer that served with the Imperial Starfleet during the early years of the Galactic Civil War. It was the first Star Destroyer to be destroyed in a direct assault by forces of the Alliance to Restore the Republic.
