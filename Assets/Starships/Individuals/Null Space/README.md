# Null Space

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Null Space](https://starwars.fandom.com/wiki/Null_Space)

The Null Space was a Corellian DP20 gunship. It was commanded by the pirate, Captain Obigon, and his crew including H'Krav and Meekeef. The Null Space was surrendered to Imperial Zero-G assault stormtroopers to avoid a fight.
