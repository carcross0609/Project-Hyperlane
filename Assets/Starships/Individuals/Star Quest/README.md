# Star Quest

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Star Quest](https://starwars.fandom.com/wiki/Star_Quest)

The Star Quest was a Suwantek Systems TL-1800 transport that was owned and operated by the Riileb Tere Metallo.

## Specifications

- **Name:** Star Quest
- **Manufacturer:** Suwantek Systems
- **Model:** TL-1800 transport
- **Type:** Light freighter
- **Max Speed:** 800 kmh
- **Hyperdrive:**
  - x2 (primary)
  - x10 (backup)
- **Armament:** Laser cannon (2)
- **Crew:** 2
- **Passengers:** 7
- **Capacity:** 110 metric tons
- **Consumables:** 2 months
- **Owners:** Tere Metallo
