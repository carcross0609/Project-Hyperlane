# Onager-class Testbed

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Onager-class Testbed](https://starwars.fandom.com/wiki/Onager-class_Testbed)

The Onager-class Testbed was an experimental testbed for the Onager-class Star Destroyer. The starship possessed a bow with two prongs, protruding away from a central cavity. Each prong accommodated a rear-facing hangar. One Orbital Bombardment Particle Cannon could be installed on each of the starboard and port sides of the cavity, whose projectiles could strike astronomical objects from outer space. The ship's ventral surface also had various terraced sections as well as a central dome to the rear of the particle cannons.
