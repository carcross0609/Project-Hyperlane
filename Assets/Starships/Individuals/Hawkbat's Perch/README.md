# Hawkbat's Perch

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hawkbat's Perch](https://starwars.fandom.com/wiki/Hawkbat%27s_Perch)

Hawkbat's Perch was a Lambda-class shuttle assigned to the Hawkbat, a supply ship in service to Admiral Apwar Trigit and Warlord Zsinj.
