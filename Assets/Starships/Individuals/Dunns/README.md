# Dunns

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dunns](https://starwars.fandom.com/wiki/Dunns)

Dunns was a Lambda-class T-4a shuttle serving the Mugaari pirates. It participated in the Battle of the Tungra sector. Where it was destroyed along with all the other Mugaari ships at a cargo loading area doing an arms deal between the pirates and the Rebel Alliance located in the Tungra sector.

## Specifications

- **Name:** Dunns
- **Type:** Lambda-class T-4a shuttle
- **Shield Gen:** Equipped
- **Destroyed:** 3 ABY, Tungra sector
- **Affiliation:** Mugaari pirates
