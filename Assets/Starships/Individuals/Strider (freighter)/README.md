# Strider (freighter)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Strider (freighter)](https://starwars.fandom.com/wiki/Strider_%28freighter%29)

Strider was a BFF-1 bulk freighter in the service of the Empire. The freighter was scheduled to arrive with the Nebulon-B escort frigate Mayhem with base equipment along with the freighters Treader and Walker. However the Rebels attacked and destroyed the freighter along with Treader and after, liberating the Habassa slaves, the Walker as well.
