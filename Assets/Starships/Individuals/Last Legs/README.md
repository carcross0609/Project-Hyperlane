# Last Legs

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Last Legs](https://starwars.fandom.com/wiki/Last_Legs)

The Last Legs was a Maso-class light cargo hauler. Navigator Selbo was part of the crew when it was captured by the pirate vessel Harmzuay.
