# Emza

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Emza](https://starwars.fandom.com/wiki/Emza)

The Emza was a civilian C-3 passenger liner that was present at Calast, a Golan Space Colony 2 space station during the Rescue at Bundil II. The ship contained debutantes.

## Specifications

- **Name:** Emza
- **Manufacturer:** Leonore Luxury Liners Incorporated
- **Model:** C-3 passenger liner
- **Length:** 409 meters
- **Width:** 132 meters
- **Height:** 94 meters
- **Armament:** None
- **Role:** Passenger liner
