# Vector

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vector (Star Destroyer)](https://starwars.fandom.com/wiki/Vector_%28Star_Destroyer%29)

The Vector was an Imperial-class Star Destroyer of the Imperial Navy in service prior to the Battle of Yavin.

## Specifications

- **Name:** Vector
- **Manufacturer:** Kuat Drive Yards
- **Model:** Imperial-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/LN starfighters (72)
- **Passengers:**
  - Stormtroopers (Approx. 9,700)
  - Imperial workers (Approx. 37,000)
- **Role:** Flagship
- **Affiliation:** Galactic Empire
- **Aliases:** (Star) Destroyer 316
