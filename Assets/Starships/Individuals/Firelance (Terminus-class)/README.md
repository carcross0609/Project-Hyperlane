# Firelance (Terminus-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Firelance (Terminus-class)](https://starwars.fandom.com/wiki/Firelance_%28Terminus-class%29)

The Firelance was a Terminus-class destroyer that was part of the Sith Imperial Navy during the Galactic War. In 3642 BBY it participated in the Battle of the Foundry, during which it suffered critical damage.
