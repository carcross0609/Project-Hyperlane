# Sunulok

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sunulok](https://starwars.fandom.com/wiki/Sunulok)

The Sunulok was the flagship of Warmaster Tsavong Lah during the early stage of the Yuuzhan Vong War. It command area was the Glory Room and its mess was the High Chew.
