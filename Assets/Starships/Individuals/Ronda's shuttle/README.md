# Ronda's shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ronda's shuttle](https://starwars.fandom.com/wiki/Ronda%27s_shuttle)

A shuttle carrying the bioanalyst Doctor Ronda crashed on the planet Corsin during the Cold War between the Galactic Republic and the Sith Empire, killing the scientist.
