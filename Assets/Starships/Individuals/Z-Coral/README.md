# Z-Coral

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Z-Coral](https://starwars.fandom.com/wiki/Z-Coral)

Z-Coral was a YT-1300 light freighter used Grand Admiral Zaarin, it was part of an attempt to loot ZA-13. It was carrying TIE Avenger parts. However it was disabled by Tan Maarek Stele, then boarded by Imperial boarding parties to recover the cargo, before being destroyed.

## Specifications

- **Name:** Z-Coral
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** YT-1300 light freighter
- **Type:** Light freighter
- **Length:** 34.75 meters
- **Destroyed:** 3 ABY
- **Captains:** Grand Admiral Demetrius Zaarin
