# D-Squad's shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [D-Squad's shuttle/Legends](https://starwars.fandom.com/wiki/D-Squad%27s_shuttle/Legends)

A Nu-class attack Transport was captured by the Confederacy of Independent Systems during the Clone Wars, being used to help load Rhydonium explosives from Abafar to the captured cruiser Renown as part of a terrorist plot. It was eventually stolen by the Galactic Republic's D-Squad during their escape from Abafar.
