# Garel Shuttle 63725

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Garel Shuttle 63725](https://starwars.fandom.com/wiki/Garel_Shuttle_63725)

Garel Shuttle 63725 was a GX1 short hauler on Garel. In 4 BBY, the Spectres Sabine Wren and Chopper hijacked the shuttle after picking up the GNK-series power droid EG-86. The shuttle was damaged in a skirmish with the bounty hunter Ketsu Onyo's ship Shadow Caster. Sabine and Ketsu later blew up the shuttle in order to escape an Arquitens-class command cruiser.

## Specifications

- **Name:** Garel Shuttle 63725
- **Model:** GX1 short hauler
- **Length:** 37.28 meters
- **Armament:** Turret-mounted double laser cannons (diplomatic version only)
- **Escapepods:** 1, Hyperdrive-equipped escape pod
- **Destroyed:** 4 BBY, above Garel
