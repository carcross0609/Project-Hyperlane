# Padmé Amidala's H-type Nubian yacht

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Padmé Amidala's H-type Nubian yacht (Malevolence)/Legends](https://starwars.fandom.com/wiki/Padm%C3%A9_Amidala%27s_H-type_Nubian_yacht_%28Malevolence%29/Legends)

Senator Padmé Amidala piloted an H-type Nubian yacht to alleged negotiations with the InterGalactic Banking Clan in 22 BBY during the Clone Wars. The yacht was destroyed when it was intercepted by General Grievous's Malevolence.
