# Prism

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Prism](https://starwars.fandom.com/wiki/Prism)

Prism was a Carrack-class light cruiser belonging to the Rebel Alliance. It was part of an operation to receive stolen TIE Defenders from Strike-class medium cruiser Nuance. While the Nuance was captured, the Prism was destroyed by Maarek Stele in a Missile Boat.

## Specifications

- **Name:** Prism
- **Manufacturer:** Damorian Manufacturing Corporation
- **Model:** Carrack-class light cruiser
- **Type:** Frigate
- **Length:** 350 meters
- **Width:** 72 meters
- **Height:** 75 meters
- **Affiliation:** Alliance to Restore the Republic
