# Quicksilver

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Quicksilver](https://starwars.fandom.com/wiki/Quicksilver)

Quicksilver was a Corellian courier ship used by Han Solo and Chewbacca to deliver gifts to Moff Sarn Shild from Jiliac Desilijic Tiron. Solo was paid 10,000 credits for the job, though it did little to help the Hutts from an attack by the Galactic Empire.
