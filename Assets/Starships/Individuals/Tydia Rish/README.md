# Tydia Rish

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tydia Rish](https://starwars.fandom.com/wiki/Tydia_Rish)

The Tydia Rish was a small personal transport ship used by Fiolla in 0 ABY. It was hyperspace capable and boasted a sensor system capable of detecting life forms from orbit. The Rish was used by Fiolla on a mission to ferry a prisoner, Naven Crel, to trial before she became embroiled in uncovering corruption within the Prex's office.
