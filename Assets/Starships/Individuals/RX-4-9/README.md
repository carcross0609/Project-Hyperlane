# RX-4-9

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [RX-4-9](https://starwars.fandom.com/wiki/RX-4-9)

RX-4-9 was the call sign of an Imperial Navy TIE/ln starfighter which was manufactured by Sienar Fleet Systems. Some time after 3 ABY's Battle of Hoth, RX-4-9 pursued the YT-1300 light freighter Millennium Falcon.

## Specifications

- **Line:** TIE series
