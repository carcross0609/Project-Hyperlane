# Sarsuma

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sarsuma](https://starwars.fandom.com/wiki/Sarsuma)

Sarsuma was a Rebel BFF-1 bulk freighter which attempted to steal Imperial supplies from a depot, during the food shortage following the evacuation from Yavin 4.

## Specifications

- **Name:** Sarsuma
- **Model:** BFF-1 bulk freighter
- **Type:** Medium-sized freighter
- **Length:** 120.9 meters
- **Width:** 75.56 meters
- **Height:** 34 meters
- **Destroyed:** 0.5 ABY
- **Affiliation:** Alliance to Restore the Republic
