# Hawkeye (DP20 gunship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hawkeye (DP20 gunship)](https://starwars.fandom.com/wiki/Hawkeye_%28DP20_gunship%29)

Hawkeye was a Corellian Gunship used by the Rebel Alliance. It accompanied the cruiser Liberty on a number of occasions, at times when Liberty was not operating alone.
