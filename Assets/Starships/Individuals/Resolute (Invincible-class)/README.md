# Resolute

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Resolute (Invincible-class)](https://starwars.fandom.com/wiki/Resolute_%28Invincible-class%29)

Resolute was an Invincible-class Dreadnaught used by the Corporate Sector Authority early on in the reign of the Galactic Empire. Its commander was Angela Krin.
