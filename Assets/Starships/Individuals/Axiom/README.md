# Axiom

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Axiom](https://starwars.fandom.com/wiki/Axiom)

The Axiom was a Republic Defense Coalition cruiser in the service of the Galactic Republic by 228 BBY, commanded by Captain Ba'luun. It took part in the assault on Naboo.
