# Talon 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Talon 2](https://starwars.fandom.com/wiki/Talon_2)

The Talon 2 was an Imperial Gamma-class ATR-6 assault transport attached to the Super Star Destroyer Executor that participated in the Battle of Kothlis in 3 ABY.
