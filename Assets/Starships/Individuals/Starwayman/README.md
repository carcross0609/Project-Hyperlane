# Starwayman

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starwayman](https://starwars.fandom.com/wiki/Starwayman)

The Starwayman was a freighter stolen by Booster Terrik. Terrik used the starship in his smuggling operations around the time of the Clone Wars.

- **Max Speed:** 800 km/h
- **Armament:** Triple laser cannon (1)
