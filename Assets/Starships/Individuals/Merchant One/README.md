# Merchant One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Merchant One](https://starwars.fandom.com/wiki/Merchant_One)

Merchant One was a C-ROC Gozanti-class light cruiser owned by the crime lord Azmorigan. The ship carried a number of armaments, including laser turrets and laser cannons used in criminal operations. The vessel also held a number of escape pods.

## Specifications

- **Name:** Merchant One
- **Model:** C-ROC Gozanti-class light cruiser
- **Type:** Light cruiser
- **Armament:**

  - Forward laser canons (2)
  - Rear laser cannons (2)
- **Escapepods:** Escape pods
- **Owners:** Azmorigan
