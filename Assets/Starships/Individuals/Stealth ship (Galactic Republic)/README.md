# Stealth ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Stealth ship (Galactic Republic)](https://starwars.fandom.com/wiki/Stealth_ship_%28Galactic_Republic%29)

The stealth ship was a prototype IPV-2C Stealth Corvette developed for the Republic Navy during the Clone Wars that was used by the Jedi Knight Anakin Skywalker to break Admiral Trench's blockade of the planet Christophsis.

## Specifications

- **Name:** Stealth ship
- **Manufacturer:** Sienar Design Systems
- **Model:** Modified IPV-2C Stealth Corvette
- **Type:** Corvette
- **Length:** 99.7 m (327 ft)
- **Max Speed:** 950 kph (590 mph)
- **Hyperdrive:** None
- **Countermeasures:**
  - Cloaking devices (28)
  - Flares
- **Armament:**
  - 2 anti-aircraft dual laser cannon turrets
  - 4 proton torpedo launchers
- **Affiliation:** Galactic Republic
- **Navy:** Galactic Republic Navy
