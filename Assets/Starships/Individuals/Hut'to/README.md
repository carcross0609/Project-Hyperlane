# Hut'to

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hut'to](https://starwars.fandom.com/wiki/Hut%27to)

Hut'to was an Assassin-class corvette belonging to the Rebel Alliance. It was fitted with explosives and was attempting to destroy the Dreadnaught Dargon through crashing into the ship. The attempt was foiled by Maarek Stele in a TIE Avenger.
