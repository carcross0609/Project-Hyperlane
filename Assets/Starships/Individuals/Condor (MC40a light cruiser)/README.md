# Condor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Condor (MC40a light cruiser)](https://starwars.fandom.com/wiki/Condor_%28MC40a_light_cruiser%29)

Condor was an MC40a light cruiser used by the Rebel Alliance. It accompanied the cruiser Liberty on a number of occasions, at times when Liberty was not operating alone.

## Specifications

- **Name:** Condor
- **Manufacturer:** Mon Calamari Shipyards
- **Line:** Mon Calamari Star Cruisers
- **Model:** MC40a light cruiser
- **Type:** Light Cruiser
- **Role:**
  - Destroyer
  - Carrier
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
