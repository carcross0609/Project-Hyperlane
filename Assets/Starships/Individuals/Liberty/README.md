# Liberty

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Liberty](https://starwars.fandom.com/wiki/Liberty)

The Liberty was a MC80 Liberty Type Heavy Star Cruiser of the MC80 Star Cruiser line that served in the Alliance Fleet during the Galactic Civil War. The ship served as Corona Squadron's headquarters, and notably participated in the decisive battle fought at Endor, where it was the first victim of the second Death Star.
