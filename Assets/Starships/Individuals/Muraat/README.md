# Muraat

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Muraat](https://starwars.fandom.com/wiki/Muraat)

Muraat was a pair of Imperial Assassin-class corvettes. The duo was part of reinforcements against the raid of XQ2 Platform RS-32, ordered to arrive on Tan Maarek Stele's request.
