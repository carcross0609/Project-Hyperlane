# Lambda 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lambda 1](https://starwars.fandom.com/wiki/Lambda_1)

Lambda 1 was a Lambda-class T-4a shuttle used by the Galactic Empire. It was present at the Battle of To-phalion Base.
