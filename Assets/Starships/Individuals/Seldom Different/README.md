# Seldom Different

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Seldom Different](https://starwars.fandom.com/wiki/Seldom_Different)

The Seldom Different was a modified YT-1300 light freighter that belonged to Abdi-Badawzi. It was boarded by the Inquisitor around 3 BBY. Elias Halbert was in command of the ship at that time.
