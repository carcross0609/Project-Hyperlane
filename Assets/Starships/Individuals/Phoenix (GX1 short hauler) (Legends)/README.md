# Phoenix

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Phoenix (GX1 short hauler)/Legends](https://starwars.fandom.com/wiki/Phoenix_%28GX1_short_hauler%29/Legends)

The Phoenix was a GX1 short hauler used by the Galactic Republic during an attempt to negotiate with the Separatists during the Clone Wars.

- **Model:** GX1 short hauler

- **Hdsystem:** Equipped

- **Escapepods:** 1, hyperdrive-equipped
- **Role:** Diplomatic vessel
