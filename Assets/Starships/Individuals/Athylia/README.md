# Athylia

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Athylia](https://starwars.fandom.com/wiki/Athylia)

The Athylia was a Pelta-class frigate in the service of the Jedi Order. Jedi Master Kelleran Beq often served aboard the vessel, alongside the protocol droid AD-3 and the astromech droid LX-R5.
