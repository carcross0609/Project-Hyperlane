# Adiss's ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Adiss's ship](https://starwars.fandom.com/wiki/Adiss%27s_ship)

Adiss's ship was a starship used by the Yuvernian smuggler Cane Adiss. Adiss's vessel was spacious enough to accommodate the Yuvernian's large body and was present in the Yuvern system during the Rebel Alliance attack on the Imperial Oplovis Sector Fleet.
