# Falcon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Falcon (Lambda-class)](https://starwars.fandom.com/wiki/Falcon_%28Lambda-class%29)

Falcon was a Lambda-class shuttle used by the Rebel Alliance. When Shantipole Project was compromised by an Imperial spy the project staff, Admiral Ackbar, and the two prototype B-wings had to evacuate. The first prototype was unarmed but the second was and provided support. The Falcon was able to board the research station, pick up Ackbar, and escape into hyperspace while the B-wing prototype, with help from some X-wings, held off corvette group Javelin and multiple stormtrooper transports to allow the Shantipole to escape.

## Specifications

- **Name:** Falcon
