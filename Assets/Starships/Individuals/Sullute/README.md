# Sullute

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sullute](https://starwars.fandom.com/wiki/Sullute)

Sullute was a MC40a Mon Calamari Star Cruiser in service to the Alliance Fleet during the Galactic Civil War. The cruiser was one of several Rebel warships that met in the Delfii system prior to the Battle of Endor. The cruiser's cargo was warheads.
