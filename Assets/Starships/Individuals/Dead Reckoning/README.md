# Dead Reckoning

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dead Reckoning](https://starwars.fandom.com/wiki/Dead_Reckoning)

Dead Reckoning was a modified Consular-class space cruiser. The smuggler Rif Taranu aided the Rebel Alliance by using it to transport goods for them.

## Specifications

- **Name:** Dead Reckoning
- **Model:** Modified Consular-class cruiser
- **Role:** Smuggler vessel
- **Affiliation:** Alliance to Restore the Republic
- **Owners:** Rif Taranu
