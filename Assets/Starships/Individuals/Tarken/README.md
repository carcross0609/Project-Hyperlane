# Tarken

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tarken](https://starwars.fandom.com/wiki/Tarken)

Tarken was a Nebulon-B2 frigate belonging to the Rebel Alliance. The Tarken attempted rescue the Rebel MC80 Star Cruiser Knights which was captured during a meeting with Bothans in a Dreadnaught-class heavy cruiser called Doomer. The Tarken was disabled and captured as well, by Gamma-class ATR-6 assault transports with the assistance of Tan Maarek Stele.
