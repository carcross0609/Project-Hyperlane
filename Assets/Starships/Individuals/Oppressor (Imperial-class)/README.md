# Oppressor

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Oppressor (Imperial-class)](https://starwars.fandom.com/wiki/Oppressor_%28Imperial-class%29)

Oppressor was an Imperial-class Star Destroyer that pursued the Jedi F. The Star Destroyer was captained by an admiral of the Imperial Navy and served as the flagship of Zero, formerly the Jedi Master known as Shad-Rah.
