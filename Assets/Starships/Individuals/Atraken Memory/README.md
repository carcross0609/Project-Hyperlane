# Atraken Memory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Atraken Memory](https://starwars.fandom.com/wiki/Atraken_Memory)

The Atraken Memory was one of the light freighters used by Atrakenite refugees during the evacuation of Atraken to Trilos. By 6 ABY, it was kept operational by virtue of using another freighter, the Atraken Hope, as a source of spare parts.
