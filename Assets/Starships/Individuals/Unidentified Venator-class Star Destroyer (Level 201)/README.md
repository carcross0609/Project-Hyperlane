# Unidentified Venator-class Star Destroyer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Venator-class Star Destroyer (Level 201)](https://starwars.fandom.com/wiki/Unidentified_Venator-class_Star_Destroyer_%28Level_201%29)

A nearly-entirely intact Venator-class Star Destroyer was left abandoned on Level 201 of Coruscant. During the aerial assault on Coruscant between 3 ABY and 4 ABY, the Rebel Alliance YT-1300 light freighter Millennium Falcon raced by it as it flew through the level in order to lose TIE/ln space superiority starfighters that were chasing it.
