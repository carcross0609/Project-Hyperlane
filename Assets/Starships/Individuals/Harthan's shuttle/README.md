# Harthan's shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Harthan's shuttle](https://starwars.fandom.com/wiki/Harthan%27s_shuttle)

Harthan's shuttle was used by the Harthan family during diplomatic discussions with the Hobors and the Troobs on Tahlboor.
