# Imperial Protector

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Imperial Protector](https://starwars.fandom.com/wiki/Imperial_Protector)

Imperial Protector was an Imperial Ton-Falk-class escort carrier. It was destroyed in the ambush on Ral's Run in 0 ABY by Blue Squadron.

## Specifications

- **Name:** Imperial Protector
- **Type:** Ton-Falk-class escort carrier
- **Complement:** TIE/LN starfighters
- **Role:** Carrier
