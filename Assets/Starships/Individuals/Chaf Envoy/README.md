# Chaf Envoy

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chaf Envoy](https://starwars.fandom.com/wiki/Chaf_Envoy)

The Chaf Envoy was a diplomatic vessel used by Aristocra Chaf'orm'bintrano of the Fifth Ruling Family in 22 ABY during the rediscovery of Outbound Flight.

- **Name:** Chaf Envoy
- **Type:** Diplomatic vessel
- **Crew:**

- **Role:**

  -   Chiss Expansionary Defense Force
- **Owners:** Chaf'orm'bintrano
- **Captains:** Captain Brast'alshi'barku
