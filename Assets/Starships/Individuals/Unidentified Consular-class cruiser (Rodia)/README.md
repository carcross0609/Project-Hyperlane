# Unidentified Consular-class cruiser

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Consular-class cruiser (Rodia)](https://starwars.fandom.com/wiki/Unidentified_Consular-class_cruiser_%28Rodia%29)

This Consular-class cruiser was used by the Galactic Republic during the Clone Wars. Jedi Master Luminara Unduli and Jedi Padawan Ahsoka Tano used it to transfer arrested Viceroy Nute Gunray to the Tranquility. It was later stolen by Faro Argyus during his escape with Gunray.

## Specifications

- **Name:** Unidentified Consular-class cruiser
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** Retrofitted Consular-class cruiser
- **Type:** Frigate
- **Hdsystem:** Equipped
- **Role:** Transport
- **Affiliation:**
  - Galactic Republic
  - Confederacy of Independent Systems (stolen)
- **Navy:** Galactic Republic Navy
- **Owners:**
  - Captain Faro Argyus (after hijacking)
  - Sith acolyte Asajj Ventress (after hijacking)
