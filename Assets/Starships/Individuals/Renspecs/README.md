# Renspecs

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Renspecs](https://starwars.fandom.com/wiki/Renspecs)

Renspecs was a BFF-1 bulk freighter present at a salvage yard near Venzeiia 2 Prime. The freighter was to be repaired by a shuttle Poltroon as it was carrying cargo that was likely illegal. The freighter was destroyed by Imperial fighters, including a TIE Defender before it could escape.
