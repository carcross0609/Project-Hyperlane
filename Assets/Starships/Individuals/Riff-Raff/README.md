# Riff-Raff

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Riff-Raff](https://starwars.fandom.com/wiki/Riff-Raff)

The Riff-Raff was a modified Gymsnor-3 light freighter owned and operated by Korkeal Hai. The Riff-Raff could often be found hauling freight in the Minos Cluster.
