# Unidentified Bulwark-class battlecruiser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Bulwark-class battlecruiser](https://starwars.fandom.com/wiki/Unidentified_Bulwark-class_battlecruiser)

During the Battle of Mindor in 5 ABY, an aged, modified Bulwark-class battleship served with the New Republic's Rapid Response Task Force. This Bulwark Mark I dated from before the Clone Wars and was manufactured originally by the Techno Union.

## Specifications

- **Name:** Unidentified Bulwark-class battlecruiser
- **Manufacturer:** Techno Union
- **Model:** Bulwark Mark I
- **Modifier:** New Republic
- **Hyperdrive:** Class 0.6 (retrofitted)
- **Shield Gen:** Multiple-redundancy deflector and particle shields
- **Complement:** Up to 3 starfighter squadrons
- **Affiliation:** New Republic
- **Navy:** New Republic Defense Fleet
- **Fleet:** Rapid Response Task Force
