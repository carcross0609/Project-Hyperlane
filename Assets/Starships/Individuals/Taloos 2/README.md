# Taloos 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Taloos 2](https://starwars.fandom.com/wiki/Taloos_2)

Taloos 2 was a Container Transport aligned with the Galactic Empire. It was present at the Skirmish at Outpost D-34, and was carrying machinery.
