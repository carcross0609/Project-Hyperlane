# Bail Jumper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bail Jumper](https://starwars.fandom.com/wiki/Bail_Jumper)

The Bail Jumper was a modified Incom T-65B X-wing starfighter, painted black and bronze. The cybernetic pilot, whose implants negated the need for an astromech droid, replaced the standard astromech socket with a fifth fire-linked laser cannon.
