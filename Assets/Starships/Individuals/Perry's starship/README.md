# Perry's starship

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Perry's starship](https://starwars.fandom.com/wiki/Perry%27s_starship)

The Alliance to Restore the Republic Platypus agent Perry owned a starship that he used to escape the Death Star space station shortly before it was destroyed with Galactic Empire Scientist Heinz Darthenshmirtz onboard. However, Darthenshmirtz escaped in one of the ship's Platypus-sized escape pods.
