# Elegencia

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Elegencia](https://starwars.fandom.com/wiki/Elegencia)

The Elegencia was a corvette-sized starship owned by Pan Eyta, a Tempest Runner of the Nihil marauder organization. It had a beautiful interior, with surfaces covered in soft leather and lighting that accented Eyta's design choices.

- **Name:** Elegencia

- **Destroyed:** 231 BBY, Cyclor
- **Affiliation:**

- **Owners:** Pan Eyta
