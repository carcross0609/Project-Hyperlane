# Audacity

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Audacity](https://starwars.fandom.com/wiki/Audacity)

The Audacity was a Venator-class Star Destroyer that saw action during the Clone Wars. As of 0 ABY, it was still active (albeit badly damaged) by Tag Rogaren, who encountered Leia Organa in the ruined remains of Alderaan and gave her permission to board.
