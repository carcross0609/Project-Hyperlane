# Prominence

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Prominence (Dreadnaught-class)](https://starwars.fandom.com/wiki/Prominence_%28Dreadnaught-class%29)

Prominence was a Dreadnaught-class heavy cruiser that served in the Republic Navy during the Clone Wars. It was destroyed by Separatist forces during the Battle of Duro.

## Specifications

- **Name:** Prominence
- **Manufacturer:** Rendili StarDrive
- **Model:** Dreadnaught-class heavy cruiser
- **Type:** Heavy cruiser
- **Engine:** 6 ion engines
- **Destroyed:** 21 - 20 BBY
- **Affiliation:** Galactic Republic
