# Alakandor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Alakandor](https://starwars.fandom.com/wiki/Alakandor)

The Alakandor was a freighter that landed on Vogga the Hutt's dock on Nar Shaddaa. The landing was delayed however, due to a mix-up of the ID signatures of the Alakandor, the Silver Zephyr, and Toorna's Profits.
