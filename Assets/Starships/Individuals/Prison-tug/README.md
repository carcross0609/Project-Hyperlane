# Prison-tug

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Prison-tug](https://starwars.fandom.com/wiki/Prison-tug)

A prison-tug, also referred to as a tug cruiser was a type of modified Arquitens-class command cruiser utilized by the Galactic Empire as a tug for wreckage-prisons. One such prison-tug hauled Accresker Jail, which was in operation during the Galactic Civil War until a Gundravian hookspore infestation forced the evacuation of the jail.

## Specifications

- **Name:** Prison-tug
- **Model:** Modified Arquitens-class command cruiser
- **Type:** Cruiser/tug
- **Hdsystem:** Equipped
- **Escapepods:** Equipped
- **Affiliation:** Galactic Empire
