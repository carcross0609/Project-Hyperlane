# Dreadnaught-Four

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dreadnaught-Four](https://starwars.fandom.com/wiki/Dreadnaught-Four)

Dreadnaught-Four, D-Four for short, was the fourth of six Dreadnaught-class heavy cruisers used on Outbound Flight.

- **Name:** Dreadnaught-Four
- **Model:** Dreadnaught-class heavy cruiser
- **Passengers:** A contingent of Jedi led by Master Justyn Ma'Ning
- **Role:** Colony ship
- **Affiliation:** Galactic Republic
- **Navy:**
