# Unidentified transport shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified transport shuttle (Ringo Vinda)/Legends](https://starwars.fandom.com/wiki/Unidentified_transport_shuttle_%28Ringo_Vinda%29/Legends)

A modified Nu-class attack shuttle was used to transport clone trooper Tup from Ringo Vinda to Kamino during the Clone Wars. However, it was rendered inoperable before it could even leave Ringo Vinda due to a Separatist assault. The shuttles dorsal wing was adorned with the symbol of the clone medic corps.
