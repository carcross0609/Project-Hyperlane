# Dellaltian warship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dellaltian warship](https://starwars.fandom.com/wiki/Dellaltian_warship)

Sometime before the Galactic Republic's founding in 25,053 BBY, a warship from the planet Dellalt crashed on the planet Rhinnal near the southern pole, and it became buried in the ice over the following millennia.
