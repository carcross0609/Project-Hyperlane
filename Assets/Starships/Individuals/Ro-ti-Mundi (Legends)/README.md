# Ro-ti-Mundi

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ro-ti-Mundi/Legends](https://starwars.fandom.com/wiki/Ro-ti-Mundi/Legends)

The Ro-ti-Mundi was a Venator-class Star Destroyer that was in service with the Grand Army of the Republic during the later part of the Clone Wars. This vessel was part of the Open Circle Fleet that participated in the Battle of Coruscant.

## Specifications

- **Name:** Ro-ti-Mundi
- **Type:** Venator-class Star Destroyer
- **Complement:** Clone Fight Squad Seven
- **Role:**

- **Affiliation:** Galactic Republic
- **Navy:** Republic Navy
- **Fleet:** Open Circle Fleet
