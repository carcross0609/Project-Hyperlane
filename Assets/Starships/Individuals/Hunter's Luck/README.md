# Hunter's Luck

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hunter's Luck](https://starwars.fandom.com/wiki/Hunter%27s_Luck)

Hunter's Luck was one of the myriad of ships owned and operated by Mara Jade when she was a smuggler. It had originally been a rich kid's private yacht, but was then captured by pirates.
