# Jakku Transport

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Jakku Transport](https://starwars.fandom.com/wiki/Jakku_Transport)

The Jakku Transport was a model of transport ships. In 34 ABY, a ship of this model departed from Niima Outpost on Jakku, before the settlement was attacked by the First Order.
