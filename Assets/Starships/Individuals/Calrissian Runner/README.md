# Calrissian Runner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Calrissian Runner](https://starwars.fandom.com/wiki/Calrissian_Runner)

In 25 ABY, Anakin Solo flew the Calrissian Runner&mdash;a modified racing TIE Advanced x1&mdash;at the Lando's Folly asteroid belt obstacle course. Like other "Belt-Runner" TIE Advanced x1s, the Calrissian Runner was customized for speed and the rigors of the course.
