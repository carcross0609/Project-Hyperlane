# Rebellion Blaze

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rebellion Blaze](https://starwars.fandom.com/wiki/Rebellion_Blaze)

The Rebellion Blaze was an infamous gunboat of the Alliance to Restore the Republic. The Rebellion Blaze Quadrant in the Karthakk system was named after this ship.
