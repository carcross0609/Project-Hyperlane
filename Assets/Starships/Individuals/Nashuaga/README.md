# Nashuaga

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nashuaga](https://starwars.fandom.com/wiki/Nashuaga)

The Nashuaga was a Dynamic-class freighter that had crash-landed on the planet Volik around the time of the First Jedi Purge. It was located in the hidden base of the smuggler group Wavelength Gale, and the freighter was rumored to be the final resting place of the Sith Lord Darth Nihilus's mask.
