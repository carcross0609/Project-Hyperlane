# White Wing

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [White Wing](https://starwars.fandom.com/wiki/White_Wing)

The White Wing was a customized YZ-900 freighter. The ship sacrificed weaponry and added extensive droid automation; this lowered the amount of crewmen necessary to run the ship, so much that a single individual could pilot the ship.
