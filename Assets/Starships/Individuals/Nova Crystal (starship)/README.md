# Nova Crystal (starship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nova Crystal (starship)](https://starwars.fandom.com/wiki/Nova_Crystal_%28starship%29)

The Nova Crystal was a Republic civilian freighter in service during the Clone Wars. It fired upon and destroyed the Traffic Interdiction Vessel TIV Z590/1, which it had mistakenly identified as a pirate vessel.
