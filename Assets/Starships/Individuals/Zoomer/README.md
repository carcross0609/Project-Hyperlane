# Zoomer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Zoomer](https://starwars.fandom.com/wiki/Zoomer)

The Zoomer was an overhauled light freighter belonging to the salvage pilot and mercenary Reti.

## Specifications

- **Name:** Zoomer
- **Type:** Light freighter
- **Modifier:** Reti
- **Countermeasures:** Automatic jump hyperdrive
- **Armament:** 4 front-mounted laser cannons, chaingun, cruise and cluster missile launchers, proximity mines
- **Crew:** 1 pilot
- **Passengers:** 2
- **Othersystems:** Tractor beam projector, tow cable
- **Role:**
  - Transport
  - Salvage vessel
- **Affiliation:** Lok Revenants
- **Owners:** Reti
- **Captains:** Reti
