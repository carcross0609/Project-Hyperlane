# Cutlass

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cutlass (CR90 corvette)](https://starwars.fandom.com/wiki/Cutlass_%28CR90_corvette%29)

Cutlass was an Imperial CR90 corvette. It was destroyed while stationed in the System Patrol Squadron above Farfeld II by a Rebel attack force consisting of three B-wing starfighters, one of them piloted by Keyan Farlander.
