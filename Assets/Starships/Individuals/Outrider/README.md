# Outrider

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Outrider](https://starwars.fandom.com/wiki/Outrider)

The Outrider was a YT-2400 light freighter owned by Dash Rendar that left the planet Tatooine in 1 BBY. Like other YT-2400 light freighters, it was manufactured by Corellian Engineering Corporation; could reach speeds of 800 kilometers per hour; was equipped with two double laser turrets, concussion missile launchers, and a class 2 hyperdrive; and measured 18.65 meters.
