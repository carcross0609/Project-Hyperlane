# Requital

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Requital](https://starwars.fandom.com/wiki/Requital)

The Requital was an Immobilizer 418 cruiser in the Imperial Navy during the Galactic Civil War. Commander Voldt served aboard the Requital in 10 ABY when it interdicted the Messenger.

## Specifications

- **Name:** Requital
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Immobilizer 418 cruiser
- **Type:** Cruiser
- **Affiliation:** Galactic Empire
- **Captains:** Voldt
