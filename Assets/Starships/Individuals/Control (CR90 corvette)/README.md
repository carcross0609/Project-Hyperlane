# Control

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Control (CR90 corvette)](https://starwars.fandom.com/wiki/Control_%28CR90_corvette%29)

Control was a CR90 corvette used by the Galactic Empire during the Galactic Civil War within an Imperial simulation. In the simulation, it served as a command ship for the TIE bomber squadron Alpha Squadron during an attack on a Rebel outpost, which would ultimately become a victory for the Imperial forces.

## Specifications

- **Name:** Control
- **Model:** CR90 corvette
- **Type:** Corvette
- **Length:** 150 meters
- **Mglt:** 20 MGLT
- **Shield Gen:** Equipped
- **Hull:** 50 RU
- **Armament:** Turret-mounted dual H9 turbolasers (2)
- **Role:** Command ship
- **Affiliation:** Galactic Empire
