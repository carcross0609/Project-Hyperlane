# Talon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Talon (Strike-class)](https://starwars.fandom.com/wiki/Talon_%28Strike-class%29)

The Talon was an Strike-class medium cruiser that was part of Task Force Vengeance. It was part of the group of reinforcements that were pulled out of hyperspace by the Rebel Alliance Modified Strike Cruiser Peregrine and was destroyed along with the rest of the group by the Rebels.
