# Cr'ee'ei

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cr'ee'ei](https://starwars.fandom.com/wiki/Cr%27ee%27ei)

Cr'ee'ei was the Lwhekk-class manufacturing ship assigned to the first Ssi-ruuvi fleet that attacked Bakura. Its name roughly translates into "Maker Ship".
