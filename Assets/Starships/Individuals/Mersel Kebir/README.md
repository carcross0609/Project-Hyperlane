# Mersel Kebir

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mersel Kebir](https://starwars.fandom.com/wiki/Mersel_Kebir)

The Mersel Kebir was a Dreadnaught-class heavy cruiser that served as the flagship of the Rendili Home Defense Fleet. At the time of the Clone Wars, it was under the command of Captain Jace Dallin. Other officers included Lieutenant Mellor Yago, and Gallan.

## Specifications

- **Name:** Mersel Kebir
- **Manufacturer:** Rendili StarDrive
- **Model:** Dreadnaught-class heavy cruiser
- **Type:** Heavy cruiser
- **Role:** Flagship
- **Affiliation:** Galactic Republic
- **Navy:** Rendili Home Defense Fleet
- **Captains:** Captain Jace Dallin
