# Relentless

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Relentless (Star Destroyer)](https://starwars.fandom.com/wiki/Relentless_%28Star_Destroyer%29)

The Relentless was a Star Destroyer serving in the Imperial Navy. It was one of four ships that formed the core forces of Moff Vanko's personal fleet.

- **Name:** Relentless
- **Type:** Star Destroyer
