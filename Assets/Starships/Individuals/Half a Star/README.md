# Half a Star

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Half a Star](https://starwars.fandom.com/wiki/Half_a_Star)

Half a Star was a transport owned by the Sullustan Nien Nunb. It was one of the ships used in the attempt to save the planet of Kessel from destruction in 43.5 ABY.
