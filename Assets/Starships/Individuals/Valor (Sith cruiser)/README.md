# Valor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valor (Sith cruiser)](https://starwars.fandom.com/wiki/Valor_%28Sith_cruiser%29)

The Valor was a Sith cruiser that served as the personal starship of the Sith Lord Darth Malgus. It was commanded by captain Jard and saw action in the Sacking of Coruscant and after.

## Specifications

- **Name:** Valor
- **Type:** Cruiser
- **Affiliation:** Sith Empire
- **Owners:** Darth Malgus
- **Captains:** Captain Jard
