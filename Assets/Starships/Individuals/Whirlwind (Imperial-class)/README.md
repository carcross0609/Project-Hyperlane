# Whirlwind

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Whirlwind (Imperial-class)](https://starwars.fandom.com/wiki/Whirlwind_%28Imperial-class%29)

Whirlwind was an Imperial-class Star Destroyer from which Imperial Admiral Blitzer Harrsk led Arrowhead Command until the Battle of Endor. In the years following the death of Palpatine's clones, it was one of twelve Imperial Star Destroyers under Harrsk's control as Supreme Warlord.
