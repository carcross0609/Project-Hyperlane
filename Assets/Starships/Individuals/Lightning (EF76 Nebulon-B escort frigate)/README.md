# Lightning (EF76 Nebulon-B escort frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lightning (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Lightning_%28EF76_Nebulon-B_escort_frigate%29)
