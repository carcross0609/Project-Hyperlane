# Mace Windu's Jedi fighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Mace Windu's Jedi fighter](https://starwars.fandom.com/wiki/Mace_Windu%27s_Jedi_fighter)

Mace Windu's Jedi fighter was a Delta-7B Aethersprite-class light interceptor flown by Jedi Master Mace Windu. R8-B7 was Windu's astromech droid copilot, but after R8's destruction, R2-D2 commandeered the starfighter.
