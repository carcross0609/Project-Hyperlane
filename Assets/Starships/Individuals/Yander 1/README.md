# Yander 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yander 1](https://starwars.fandom.com/wiki/Yander_1)

Yander 1 was a YT-1300 light freighter aligned with the Galactic Empire. It was present at the Skirmish at Outpost D-34, and was carrying foodstuff.
