# Kharrus's Nu-class attack shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Kharrus's Nu-class attack shuttle](https://starwars.fandom.com/wiki/Kharrus%27s_Nu-class_attack_shuttle)

A Nu-class attack/transport shuttle was used by a Galactic Republic delegation under Senator Kharrus assigned to deliver a ransom of spice to Hondo Ohnaka's gang of pirates in exchange for Count Dooku. When arriving on Florrum, it was shot down by the pirate Barb Mentir using a Flarestar-class attack shuttle.

- **Name:** Kharrus's Nu-class attack shuttle
