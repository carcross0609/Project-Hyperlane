# Cygnus Spaceworks luxury personnel shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cygnus Spaceworks luxury personnel shuttle](https://starwars.fandom.com/wiki/Cygnus_Spaceworks_luxury_personnel_shuttle)

The Cygnus Spaceworks luxury personnel shuttle was a prototype of a new shuttle model by Cygnus Spaceworks that crashed on Dagobah during its test run.
