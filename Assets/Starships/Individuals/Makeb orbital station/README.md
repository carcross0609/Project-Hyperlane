# Makeb orbital station

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Makeb orbital station](https://starwars.fandom.com/wiki/Makeb_orbital_station)

The Imperial Orbital Station was a space station, belonging to the Sith Empire, in orbit of the planet Makeb during the Galactic War. In the weeks following the invasion of the planet by the Hutt Cartel, the space station was used as a staging point for Imperial operations.
