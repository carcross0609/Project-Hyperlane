# D-89

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [D-89](https://starwars.fandom.com/wiki/D-89)

D-89 was a New Republic Intelligence Ferret-class reconnaissance vessel. Assigned to Colonel Pakkpekkat's Teljkon Vagabond task force, D-89 was used to trail the Vagabond while an interdiction line was established. Once in place, D-89 was pushed within the twelve-kilometer safe-zone. After Lady Luck was allowed to land on the Vagabond by providing C-3PO's code, D-89 was sent in to use the same code. Although the code was repeated accurately, the vessel was expecting a new code, and destroyed the Ferret.
