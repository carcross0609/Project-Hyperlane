# Webley

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Webley](https://starwars.fandom.com/wiki/Webley)

The Webley was a New Republic starship which fought at the Battle of Yaga Minor near the end of the Galactic Civil War. It was under the command of Captain Alex Winger.
