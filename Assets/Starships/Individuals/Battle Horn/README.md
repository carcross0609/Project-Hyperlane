# Battle Horn

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Battle Horn](https://starwars.fandom.com/wiki/Battle_Horn)

The Battle Horn was a Rendili StarDrive produced starship which famously served the New Republic. The Battle Horn-class bulk cruiser was named after it.
