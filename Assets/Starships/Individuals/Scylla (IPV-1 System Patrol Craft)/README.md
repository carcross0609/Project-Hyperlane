# Scylla

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Scylla (IPV-1 System Patrol Craft)](https://starwars.fandom.com/wiki/Scylla_%28IPV-1_System_Patrol_Craft%29)

The Scylla was an IPV-1 System Patrol Craft in the service of Viraxo Industries. It was guarding Industrial Complex VXO-33274, and was destroyed by Rebel pilot Ace Azzameen in the YT-2000 Otana.
