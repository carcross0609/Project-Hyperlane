# Ephant Mon's freighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ephant Mon's freighter](https://starwars.fandom.com/wiki/Ephant_Mon%27s_freighter)

A freighter was used by Ephant Mon during a smuggling job on Cerea prior to the Invasion of Naboo. The ship was infested with deadly divviks, and Mon, along with the Techrats and Sylvn were trapped in an escape pod. Jedi Knight Ki-Adi-Mundi came to their rescue, hitting the manual release lever for the pod.

- **Name:** Ephant Mon's freighter
- **Type:** Freighter
