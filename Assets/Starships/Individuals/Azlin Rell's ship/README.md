# Azlin Rell's ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Azlin Rell's ship](https://starwars.fandom.com/wiki/Azlin_Rell%27s_ship)

A ship that belonged to the Jedi Barnabas Vim was later found on the planet Sophros by the former Jedi Azlin Rell, who used it to leave the planet. Aboard the ship, Rell found Vim's lightsaber and bled its kyber crystal.

## Specifications

- **Name:** Azlin Rell's ship
- **Affiliation:** Jedi Order
- **Owners:**
  - Barnabas Vim
  - Azlin Rell
