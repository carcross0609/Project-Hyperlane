# Bnef Nlle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bnef Nlle](https://starwars.fandom.com/wiki/Bnef_Nlle)

Bnef Nlle was the small modified light freighter owned by Niev Jaub. It was part of the First Strike Element in the Battle of Nar Shaddaa and lay hidden in the debris field as the Carrack-class light cruiser Vigilance approached the moon. It was destroyed when Niev Jaub sent his ship hurtling into the Vigilance port side, weakening the shields. "Bnef Nlle" meant "Good Luck" in the Sullustan language.
