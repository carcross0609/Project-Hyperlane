# Horizon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Horizon (Strike-class)](https://starwars.fandom.com/wiki/Horizon_%28Strike-class%29)

The Horizon was a Strike-class medium cruiser. It was a part of the Alliance to Restore the Republic's fleet during the Galactic Civil War.
