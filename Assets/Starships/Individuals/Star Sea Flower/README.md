# Star Sea Flower

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Star Sea Flower](https://starwars.fandom.com/wiki/Star_Sea_Flower)

The Star Sea Flower was the personal YT-1150 cargo transport of the aquatic Priapulin, Charza Kwinn. Using it, Kwinn was able to transport Obi-Wan Kenobi and Anakin Skywalker to Zonama Sekot.

## Specifications

- **Name:** Star Sea Flower
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-1150 cargo transport
- **Skeleton:** 1 pilot, large amounts of fodder
- **Owners:** Charza Kwinn
