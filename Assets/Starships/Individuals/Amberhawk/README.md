# Amberhawk

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Amberhawk](https://starwars.fandom.com/wiki/Amberhawk)

Amberhawk was Personal Luxury Yacht 3000 which contained artwork. The Amberhawk was present in the Nezni system, where the incident between the Rebel Alliance and the Hurrim took place.

## Specifications

- **Name:** Amberhawk
- **Manufacturer:** SoroSuub Corporation
- **Model:** Personal Luxury Yacht 3000
- **Type:** Yacht
