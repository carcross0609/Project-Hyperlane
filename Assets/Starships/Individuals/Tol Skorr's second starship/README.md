# Tol Skorr's second starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tol Skorr's second starship](https://starwars.fandom.com/wiki/Tol_Skorr%27s_second_starship)

Tol Skorr's second starship was a heavily-armed KR-TB "Doomtreader". Tol Skorr and Asajj Ventress used it to chase Quinlan Vos to the Titavian IV.
