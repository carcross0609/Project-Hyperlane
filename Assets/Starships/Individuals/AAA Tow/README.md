# AAA Tow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [AAA Tow](https://starwars.fandom.com/wiki/AAA_Tow)

AAA Tow was an Rebel Alliance Heavy Lifter that was picking up and delivering supplies to Admiral Harkov during his attempt to defect to the Alliance.
