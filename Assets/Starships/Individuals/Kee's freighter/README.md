# Kee's freighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Kee's freighter](https://starwars.fandom.com/wiki/Kee%27s_freighter)

Kee's freighter was operated by the First Order operative Teroj Kee to leave the supertanker fuel depot Colossus in 34 ABY, but was destroyed due to sabotage done by mechanic Kazuda Xiono.

## Specifications

- **Name:** Kee's freighter
- **Type:** Darius G-class freighter
- **Destroyed:** 34 ABY, Castilon
