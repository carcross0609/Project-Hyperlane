# 36DD

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [36DD](https://starwars.fandom.com/wiki/36DD)

36DD (nicknamed the Deedee) was an Imperial barge. In 3 ABY, 36DD was to pick up a Colony Class 23669 power generator at Kuat Drive Yards, but a Rebel Alliance team led by Deen Voorson and Boo Rawl disguised the Rebel ship Long Run as 36DD, took the barge carrying the generator, and escaped as the real ship entered the system.
