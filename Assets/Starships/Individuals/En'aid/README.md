# En'aid

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [En'aid](https://starwars.fandom.com/wiki/En%27aid)

En'aid was a Ferryboat liner that carried smugglers from the Dunari's Rest when the latter was attacked by Imperial forces. It made it to the hyperspace intact thanks to assistance from the Rebel Alliance.
