# Neverquit

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Neverquit](https://starwars.fandom.com/wiki/Neverquit)

The Neverquit was a small, custom built starship owed by the bounty hunter Grea the Orfite. Built on the planet Coyn, it was the only one of its kind, though the schematics existed to build more. The vessel looked like a dagger, with the engines set into the "handle". It had a belly-mounted laser cannon turret. The entire ship was black.
