# Silencer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Silencer](https://starwars.fandom.com/wiki/Silencer)

The Silencer was a Resurgent-class Star Destroyer in service to the navy of the First Order that was sent along with Captain Phasma to patrol a hyperspace transit point between the Unknown Regions and the Core Worlds.
