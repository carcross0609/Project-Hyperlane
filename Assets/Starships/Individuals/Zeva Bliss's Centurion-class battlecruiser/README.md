# Zeva Bliss's Centurion-class battlecruiser

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Zeva Bliss's Centurion-class battlecruiser](https://starwars.fandom.com/wiki/Zeva_Bliss%27s_Centurion-class_battlecruiser)
