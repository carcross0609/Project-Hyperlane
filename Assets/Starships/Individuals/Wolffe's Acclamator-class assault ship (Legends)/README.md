# Wolffe's Acclamator-class assault ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wolffe's Acclamator-class assault ship/Legends](https://starwars.fandom.com/wiki/Wolffe%27s_Acclamator-class_assault_ship/Legends)

Clone Commander Wolffe commanded an Acclamator-class assault ship during the Clone Wars, sent to reinforce Jedi General Plo Koon in the Qiilura system. En route, Wolffe's assault ship was temporarily redirected to deliver relief supplies to the groundquake-stricken Aleen.
