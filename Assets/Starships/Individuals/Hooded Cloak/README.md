# Hooded Cloak

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hooded Cloak](https://starwars.fandom.com/wiki/Hooded_Cloak)

The Hooded Cloak was a YT-1300 light freighter belonging to a Cloak pirate officer during the Galactic Civil War. The ship was captured by the Corellian Security Force in the Corellian system in 1 ABY.

## Specifications

- **Name:** Hooded Cloak
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-1300 light freighter
- **Type:** Transport
- **Armament:** Laser turrets (2)
- **Affiliation:** Cloak
