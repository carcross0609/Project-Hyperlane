# Count Dooku's frigate

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Count Dooku's frigate](https://starwars.fandom.com/wiki/Count_Dooku%27s_frigate)

Count Dooku's frigate was a Munificent-class star frigate that served in the naval forces of the Confederacy of Independent Systems as the flagship of Separatist leader Count Dooku during the Clone Wars, until it was crippled during a skirmish at Vanqor.
