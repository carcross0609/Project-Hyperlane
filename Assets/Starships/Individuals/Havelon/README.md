# Havelon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Havelon](https://starwars.fandom.com/wiki/Havelon)

The LQ Flagship Havelon was a capital ship that served as Wilhuff Tarkin's flagship above the planet Despayre, while the first Death Star was undergoing completion. It was aboard Havelon that Tarkin received Darth Vader for his inspection of the station's progress.

## Specifications

- **Name:** Havelon
- **Affiliation:** Galactic Empire
- **Owners:** Grand Moff Wilhuff Tarkin
