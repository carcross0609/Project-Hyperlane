# Luthen Rael's Fondor Haulcraft

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Luthen Rael's Fondor Haulcraft](https://starwars.fandom.com/wiki/Luthen_Rael%27s_Fondor_Haulcraft)

Luthen Rael's Fondor Haulcraft was a heavily modified V-21.1 Chevlex in use by Luthen Rael in 5 BBY. The ship, which Rael referred to as "the Fondor," had an added droid Mod serving as a co-pilot as well as multiple hidden countermeasures such as laser beams and a projectile launcher.
