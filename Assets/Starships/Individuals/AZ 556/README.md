# AZ 556

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [AZ 556](https://starwars.fandom.com/wiki/AZ_556)

AZ 556 was a Modular conveyor docked with the space station Azzameen Home Base during the Azzameen family raid on the Viraxo Industries base Viraxo 54.

## Specifications

- **Name:** AZ 556
- **Manufacturer:** Allegra Enterprise Systems
- **Model:** Modular conveyor
- **Length:** 126.8 meters
- **Width:** 70.35 meters
- **Height:** 42.27 meters
- **Armament:** Dual laser cannon turrets (3)
