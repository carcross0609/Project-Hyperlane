# Wavesong

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wavesong](https://starwars.fandom.com/wiki/Wavesong)

Wavesong was a Mon Calamari Star Cruiser in the Rebel Fleet during the Galactic Civil War. It was commanded by a Mon Calamari named Elpfel.
