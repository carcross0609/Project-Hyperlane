# Implacable

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Implacable (Acclamator-class)/Legends](https://starwars.fandom.com/wiki/Implacable_%28Acclamator-class%29/Legends)

Implacable was an Acclamator-class assault ship that served the Republic Navy during the Clone Wars and was present at the First Battle of Geonosis. It survived the Clone Wars to serve the Imperial Navy in the Galactic Civil War.

## Specifications

- **Name:** Implacable
- **Manufacturer:** Rothana Heavy Engineering
- **Model:** Acclamator-class assault ship
- **Type:** Assault ship
- **Length:** 752 meters
- **Width:** 460 meters
- **Height:**
  - 200 meters (with landing gear)
  - 183 meters (in flight)
- **Hull:** Ablative armor modifications
- **Armament:**
  - Quad turbolaser cannons (12)
  - Point-defense laser cannons (24)
  - Proton torpedo tubes (4)
- **Role:**
  - Transport
  - Medium frigate
- **Affiliation:**
  - Galactic Republic
  - Galactic Empire
