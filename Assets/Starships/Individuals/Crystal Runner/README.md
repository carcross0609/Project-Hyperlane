# Crystal Runner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Crystal Runner](https://starwars.fandom.com/wiki/Crystal_Runner)

The Crystal Runner was a CEC YT-1300 light freighter. It operated in the Dathomir system in the year 1 ABY, transporting lightly glowing crystals.

## Specifications

- **Name:** Crystal Runner
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
