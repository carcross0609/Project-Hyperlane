# Sterling

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sterling (starcruiser)](https://starwars.fandom.com/wiki/Sterling_%28starcruiser%29)

The Sterling was an MPO-1400 Purrgil-class star cruiser. By 34 ABY, during the First Order-Resistance War, it was one of five starships of its class still in active service, alongside the Halcyon, the Idyll, the Wanderlight, and the Sojourn.

## Specifications

- **Name:** Sterling
- **Model:** MPO-1400 Purrgil-class star cruiser
- **Type:** Starcruiser
