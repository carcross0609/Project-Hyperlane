# Vendetta (Imperial-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vendetta (Imperial-class)/Legends](https://starwars.fandom.com/wiki/Vendetta_%28Imperial-class%29/Legends)

The Vendetta was an Imperial-class Star Destroyer that served the Galactic Empire in the Inner Rim Territories during the Galactic Civil War. Lieutenant Ander Rendrake, who was secretly a spy for the Alliance to Restore the Republic, served aboard the Vendetta. During his time aboard the Vendetta, Rendrake managed to acquire a number of code cylinders and access codes, allowing him access to every part of the Star Destroyer.
