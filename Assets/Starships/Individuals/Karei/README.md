# Karei

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Karei](https://starwars.fandom.com/wiki/Karei)

Karei was a Dreadnaught-class heavy cruiser that served with the Rebel Alliance during the Galactic Civil War. It was attacked by Strike-class medium cruiser Ull, which had TIE Avengers from Avenger Squadron as well as Assault Gunboats as backup. The Dreadnaught had X-wings and A-wings to cover its attempted retreat as well as B-wings as backup.

## Specifications

- **Name:** Karei
- **Type:** Dreadnaught-class heavy cruiser
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
