# Telgordo's Pride

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Telgordo's Pride](https://starwars.fandom.com/wiki/Telgordo%27s_Pride)

The Telgordo's Pride was a luxury liner operated by Telgordo Travel during the Galactic Civil War. It was hijacked by a rebel group led by the Mon Calamari Rutralli Optor.

- **Name:** Telgordo's Pride
- **Role:** Luxury liner
