# Cavalry

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cavalry](https://starwars.fandom.com/wiki/Cavalry)

Cavalry was an Imperial-class star destroyer used by the Galactic Empire within an Imperial simulation. In the simulation, it served as a secondary flagship and command post for the TIE bomber squadron Alpha Squadron during an attack on a Rebel outpost, which would ultimately become a victory for the Imperial forces.
