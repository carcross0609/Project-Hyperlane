# Maledoth

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Maledoth](https://starwars.fandom.com/wiki/Maledoth)

The Maledoth was a former Yuuzhan Vong slaveship used in the Ramoan relocation project by the Jedi. According to Corran Horn, the Jedi in control of the project was the Wookiee Lowbacca; when he left for the Unknown Regions the project came to a standstill because no others possessed his understanding of Yuuzhan Vong biotechnology.
