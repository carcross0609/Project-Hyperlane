# First Light

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [First Light](https://starwars.fandom.com/wiki/First_Light)

First Light was a Nau'ur-class yacht owned by the near-human crime lord Dryden Vos of Crimson Dawn who used it as a personal residence and mobile base of operations for the crime syndicate. It fell into the possession of Qi'ra after Vos's death.
