# Iron Tether

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Iron Tether](https://starwars.fandom.com/wiki/Iron_Tether)

The Iron Tether was a Galactic Republic Space Rescue Corps patrol cutter. In 22 BBY near the end of the Separatist Crisis, it was attacked by Separatist C-73 Tracker starfighters while patrolling the Cowl Crucible near the edge of the Lahara sector.
