# Errinung'ka

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Errinung'ka](https://starwars.fandom.com/wiki/Errinung%27ka)

The Errinung'ka was one of the two Sh'ner-class planetary assault carriers that was a part of the Keeramak Entourage that arrived on Bakura prior to the battle of Bakura in 28 ABY The vessel would see action in that engagement.
