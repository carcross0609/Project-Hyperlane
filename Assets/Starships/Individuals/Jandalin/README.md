# Jandalin

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Jandalin](https://starwars.fandom.com/wiki/Jandalin)

The Jandalin was a patrol ship of the Chiss Ascendancy's Stybla family. The starship carried Senior Aide Stybla'ppin'cykok "Lappincyk," alongside Mid Commander Mitth'raw'nuru "Thrawn" and Syndic Mitth'ras'safis "Thrass," in their investigations into a hijacked freighter.
