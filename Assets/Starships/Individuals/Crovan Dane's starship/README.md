# Crovan Dane's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Crovan Dane's starship](https://starwars.fandom.com/wiki/Crovan_Dane%27s_starship)

This starship belonged to the bounty hunter Crovan Dane in 21 BBY and was used to transport creatures to the Trandoshan moon Akoshissss for use in Muun cyberneticist Bitt Panith's experiments.
