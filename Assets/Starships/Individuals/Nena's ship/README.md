# Nena's ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Nena's ship](https://starwars.fandom.com/wiki/Nena%27s_ship)

Nena's ship was a ship owned by the Nikto engineer Nenavakasa Nalor. In 34 ABY, Nalor feigned damage to her ship in order to board the supertanker fuel depot Colossus in order to sabotage it for the First Order.

## Specifications

- **Name:** Nena's ship
- **Affiliation:** First Order
- **Owners:** Nenavakasa Nalor
