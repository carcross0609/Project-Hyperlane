# Uranium (shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Uranium (shuttle)](https://starwars.fandom.com/wiki/Uranium_%28shuttle%29)

Uranium was a Lambda-class T-4a shuttle of the same group as Tydirium. It was found in Outpost 327 when the latter was captured in the Mission to Zhar.
