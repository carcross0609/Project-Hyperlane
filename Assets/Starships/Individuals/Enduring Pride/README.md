# Enduring Pride

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Enduring Pride](https://starwars.fandom.com/wiki/Enduring_Pride)

The Enduring Pride was a modified IGV-55 surveillance vessel used by the Coalition for Progress during the Galactic Civil War. It was an Imperial propaganda flagship that served under Captain Okma.

## Specifications

- **Name:** Enduring Pride
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** Modified IGV-55 surveillance vessel
- **Type:** Listener ship
- **Length:** 64 meters
- **Max Speed:** 900 kph
- **Hyperdrive:** Class 1

  - Railguns
- **Communications:** Equipped
- **Affiliation:**

  -   Coalition for Progress
- **Navy:** Imperial Navy
- **Captains:** Okma
