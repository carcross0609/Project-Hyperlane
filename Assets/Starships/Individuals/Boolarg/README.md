# Boolarg

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Boolarg](https://starwars.fandom.com/wiki/Boolarg)

The Boolarg was a YT-1210 light freighter owned by Gaber Rollobad. The Sullustan smuggler used it to run goods across the Core Worlds until it was shot down by Imperial forces over Corellia.

## Specifications

- **Name:** Boolarg
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-1210 light freighter
- **Type:** Light freighter
- **Length:** 28 meters
- **Owners:** Gaber Rollobad
