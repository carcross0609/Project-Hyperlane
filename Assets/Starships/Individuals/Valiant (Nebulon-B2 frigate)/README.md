# Valiant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valiant (Nebulon-B2 frigate)](https://starwars.fandom.com/wiki/Valiant_%28Nebulon-B2_frigate%29)

The Valiant was a Nebulon-B2 frigate that served with the Rebel Alliance during the Galactic Civil War. It was present at the shipyard Calenz in the Nocto system not long before the Battle of Nocto.

## Specifications

- **Name:** Valiant
- **Model:** Nebulon-B2 frigate
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
