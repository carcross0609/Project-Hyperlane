# Mud Sloth

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mud Sloth](https://starwars.fandom.com/wiki/Mud_Sloth)

The Mud Sloth was a Verpine Adventurer starship of the Model 201, Production Group E subtype, with the individual registation number NR80-109399, owned by Akanah Norand Goss Pell. It was used during the Black Fleet Crisis to locate the Fallanassi Circle and Luke Skywalker's mother.
