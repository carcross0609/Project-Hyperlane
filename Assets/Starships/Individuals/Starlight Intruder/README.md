# Starlight Intruder

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starlight Intruder](https://starwars.fandom.com/wiki/Starlight_Intruder)

The Starlight Intruder was a large ship built by Salla Zend and Shug Ninx, two smugglers in Ninx's Spacebarn on Nar Shaddaa. They began work on it in 4 ABY.
