# Lanupan security vessel

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Lanupan security vessel](https://starwars.fandom.com/wiki/Lanupan_security_vessel)

Lanupan security vessels were compact starfighters designed to escort arriving starships to Skull Ridge Mountain Hotel & Spa. These vessels operated in pairs, each piloted by a single individual.

## Specifications

- **Name:** Lanupan security vessel
- **Model:** Starship
- **Type:** Starfighter
- **Hull:** Gray and light blue
- **Crew:** 1
- **Role:** Atmospheric starship escort
