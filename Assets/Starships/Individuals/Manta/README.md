# Manta

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Manta](https://starwars.fandom.com/wiki/Manta)

Manta was a C-3 passenger liner located at an Imperial scrap yard at Tolig IV. It had Dejarik boards as its cargo. It was present there when Ace and Emon Azzameen went there to investigate the various containers to search for the data core, and when the raid took place.

## Specifications

- **Name:** Manta
- **Manufacturer:** Leonore Luxury Liners Incorporated
- **Model:** C-3 passenger liner
- **Length:** 409 meters
- **Width:** 132 meters
- **Height:** 94 meters
- **Armament:** None
