# Silver Howl

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Silver Howl](https://starwars.fandom.com/wiki/Silver_Howl)

The Silver Howl was a modified YT-2400 light freighter piloted by the smuggler Astrid Fenris.

## Specifications

- **Name:** Silver Howl
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-2400 light freighter
- **Type:** Light freighter
- **Length:** 21 meters
- **Max Speed:** 800 kph
- **Hyperdrive:** Class 2
- **Armament:**
  - 2 double laser turrets
  - concussion missile launchers
