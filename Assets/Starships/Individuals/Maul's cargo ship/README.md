# Maul's cargo ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Maul's cargo ship](https://starwars.fandom.com/wiki/Maul%27s_cargo_ship)

Maul's cargo ship was a YV-865 Aurore-class freighter that owned by the Snivvian Morlimur Snugg, superintendent of the InterGalactic Banking Clan's Cybloc Transfer Station. In 19 BBY, the renegade Sith Lord Maul and his brother, Savage Opress, raided the station and stole the freighter, which they flew to Florrum, where it was soon destroyed.
