# Sentinel

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sentinel (Acclamator-class)](https://starwars.fandom.com/wiki/Sentinel_%28Acclamator-class%29)

The Sentinel was an Acclamator-class assault ship that was part of the Republic Navy during the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems. The Sentinel was destroyed and crashed near Foundry Four on the surface of Xorrn while participating in one of the battles there.
