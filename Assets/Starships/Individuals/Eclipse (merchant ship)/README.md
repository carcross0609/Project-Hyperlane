# Eclipse (merchant ship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eclipse (merchant ship)](https://starwars.fandom.com/wiki/Eclipse_%28merchant_ship%29)

The Eclipse was a merchant ship that was attacked by Karn Granzor and his pirates. Drek Drednar served aboard this ship, but joined the pirate crew.
