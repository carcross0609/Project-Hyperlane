# Triumphant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Triumphant (Star Destroyer)](https://starwars.fandom.com/wiki/Triumphant_%28Star_Destroyer%29)

Triumphant was a Star Destroyer serving in the Imperial Navy. It was one of four Star Destroyers that composed Moff Vanko's Vanko's anti-piracy task force.

## Specifications

- **Name:** Triumphant
- **Type:** Star Destroyer
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:** Vanko's anti-piracy task force
