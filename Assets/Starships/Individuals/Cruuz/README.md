# Cruuz

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cruuz](https://starwars.fandom.com/wiki/Cruuz)

Cruuz was an EF76 Nebulon-B escort frigate that saw service with the the Rebel Alliance Fleet during the height of the Galactic Civil War. The warship was destroyed by Imperial forces at the Battle of the Bajic Shipyards.
