# Unidentified Darius G-class freighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Darius G-class freighter (Widowmaker)](https://starwars.fandom.com/wiki/Unidentified_Darius_G-class_freighter_%28Widowmaker%29)

A Darius G-class freighter was operating off of the supertanker fuel depot Colossus in 34 ABY. The Resistance operatives Poe Dameron and Kazuda Xiono performed a Widowmaker maneuver with the latter's racer, the Fireball, by hiding on the freighter.
