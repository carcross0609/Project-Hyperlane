# New Crucible

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [New Crucible](https://starwars.fandom.com/wiki/New_Crucible)

The New Crucible was a capital ship that served the Arkadianate, a Sith state that operated in the Grumani sector during the Republic Dark Age. In 1032 BBY, the New Crucible served as the flagship of an Arkadianate fleet that attacked forces of the Dyarchy Sith state over the planet Byllura.

## Specifications

- **Name:** New Crucible
- **Role:** Flagship
- **Affiliation:** Arkadianate
