# Tholme's commandeered fighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tholme's commandeered fighter](https://starwars.fandom.com/wiki/Tholme%27s_commandeered_fighter)

Tholme's commandeered fighter was a starfighter stationed aboard the Raptor. Jedi Master Tholme and his Padawan Quinlan Vos stole it to escape the doomed starship as it was exploding.
