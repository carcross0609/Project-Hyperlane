# Unidentified Consular-class cruiser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Consular-class cruiser (Obredaan)](https://starwars.fandom.com/wiki/Unidentified_Consular-class_cruiser_%28Obredaan%29)

A Consular-class cruiser was used by the Jedi Order in 32 BBY. The starship crashed into the swamps of Obredaan while two Jedi Masters were on an investigative mission.
