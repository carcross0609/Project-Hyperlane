# Veldt

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Veldt (Ithorian Herdship)](https://starwars.fandom.com/wiki/Veldt_%28Ithorian_Herdship%29)

Veldt was an Ithorian Herdship that travelled throughout the galaxy, from the Outer Rim Territories to the Core Worlds. Tredo Dopra was chief trader aboard the Veldt.
