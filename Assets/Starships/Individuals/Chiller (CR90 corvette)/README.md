# Chiller

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chiller (CR90 corvette)](https://starwars.fandom.com/wiki/Chiller_%28CR90_corvette%29)

Chiller was a CR90 corvette employed by the Rebels. The corvette, along with the Glaser, was part of a Rebel strike force attacking Imperial frigate Laantis while it was receiving a new hyperdrive engine from the freighter Rasvin. The corvette, along with the rest of the Rebels, was destroyed in the battle.

## Specifications

- **Name:** Chiller
- **Model:** CR90 corvette
- **Type:** Corvette
- **Affiliation:** Alliance to Restore the Republic
