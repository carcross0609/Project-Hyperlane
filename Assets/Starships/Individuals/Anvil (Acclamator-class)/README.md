# Anvil

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Anvil (Acclamator-class)](https://starwars.fandom.com/wiki/Anvil_%28Acclamator-class%29)

The Anvil was an Acclamator-class assault ship of the Republic Navy during the Clone Wars. It was destroyed by Separatist forces during the Battle of Duro.
