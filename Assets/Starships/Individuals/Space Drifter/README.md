# Space Drifter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Space Drifter](https://starwars.fandom.com/wiki/Space_Drifter)

Space Drifter was a medium freighter owned and operated by Core to Rim Shipping. The vessel was commanded by the Sullustan, Captain Prem Nistt.

## Specifications

- **Name:** Space Drifter
- **Type:** Medium freighter
- **Role:** Cargo transport
- **Owners:** Core to Rim Shipping
- **Captains:** Captain Prem Nistt
