# Reaver Station

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Reaver Station](https://starwars.fandom.com/wiki/Reaver_Station)

Reaver Station was a space station in the Marranis system held by the reconstituted Sith Empire during the Cold War. It was a port for entertainment to be used for leave.
