# Ast'ria

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ast'ria](https://starwars.fandom.com/wiki/Ast%27ria)

The Ast'ria was a New Republic CR90 corvette during the Galactic Civil War. It served in the Bothan Combat Response Element and fought in the Battle of Kathol System, in which it assisted in the defeat of Moff Kentor Sarne.

## Specifications

- **Name:** Ast'ria
- **Type:** CR90 corvette
- **Max Speed:** 950 kmh
- **Hyperdrive:** Equipped
- **Shield Gen:** Equipped
- **Armament:**
  - 6 double turbolaser cannons
- **Role:** Combat vessel
- **Affiliation:** New Republic
- **Navy:** New Republic Defense Fleet
- **Fleet:** Bothan Combat Response Element
