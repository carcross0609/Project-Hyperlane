# Mercatan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mercatan](https://starwars.fandom.com/wiki/Mercatan)

Mercatan was a Naboo freighter in use before and during the time of the Invasion of Naboo. Before the invasion, it was in the same fleet as Charm's Way during a pirate attack.

## Specifications

- **Name:** Mercatan
- **Type:** Freighter
- **Affiliation:** Naboo Resistance
