# Furious

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Furious (Lambda-class)](https://starwars.fandom.com/wiki/Furious_%28Lambda-class%29)

Furious was the Lambda-class T-4a shuttle serving the droid information broker 8t88. Its crew included a pilot and at least one Stormtrooper.
