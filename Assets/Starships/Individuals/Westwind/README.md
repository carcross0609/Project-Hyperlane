# Westwind

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Westwind](https://starwars.fandom.com/wiki/Westwind)

The Westwind was a T-6 shuttle piloted by Rissa Mano to transport a squad of Jedi to the Outer Rim planet Hissrich during the early stages of the Clone Wars.
