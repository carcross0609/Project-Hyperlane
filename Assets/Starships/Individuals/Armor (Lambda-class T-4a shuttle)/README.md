# Armor (Lambda-class T-4a shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Armor (Lambda-class T-4a shuttle)](https://starwars.fandom.com/wiki/Armor_%28Lambda-class_T-4a_shuttle%29)

Armor was a Lambda-class T-4a shuttle used by the Rebel Alliance. The shuttle was present at the Rebel Summit taking place in the Delfii system. The shuttle was carrying commanders.
