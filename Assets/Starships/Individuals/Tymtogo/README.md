# Tymtogo

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tymtogo](https://starwars.fandom.com/wiki/Tymtogo)

Tymtogo was a Lambda-class T-4a shuttle belonging to the Imperial Navy. It was part of Deep Space Manufacturing Facility Drekker's procedure that, should the station's hull integrity go to at least 25%, the shuttle would launch, carrying officers. The shuttle in this case would make a run for the Victory-class Star Destroyer Inexorable.
