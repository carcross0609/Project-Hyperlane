# Reptavian

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Reptavian (starship)](https://starwars.fandom.com/wiki/Reptavian_%28starship%29)

The Reptavian was a Republic-class Star Destroyer in the New Republic Defense Fleet. It was one of the ships that answered the call to aid the Heart of Artorias when Commander Bylsma sent out a request for support to defend Shramar.

## Specifications

- **Name:** Reptavian
- **Manufacturer:** Rendili StarDrive
- **Model:** Republic-class Star Destroyer
- **Length:** 1,250 meters
- **Affiliation:** New Republic
- **Navy:** New Republic Defense Fleet
