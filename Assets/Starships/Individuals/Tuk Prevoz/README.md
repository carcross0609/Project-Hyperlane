# Tuk Prevoz

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tuk Prevoz](https://starwars.fandom.com/wiki/Tuk_Prevoz)

The Tuk Prevoz was a modified tug owned by the Independent Ship Owners registered on Coruscant, but under contract to Xizor Transport Systems. In 3.5 ABY, it towed several linked cargo cylinders (each as big as a YT-1300 and containing braking rockets), with total cargo around 800/900 megatons, in to Coruscant.
