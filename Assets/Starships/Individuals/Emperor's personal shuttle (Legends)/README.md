# Emperor's personal shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Emperor's personal shuttle/Legends](https://starwars.fandom.com/wiki/Emperor%27s_personal_shuttle/Legends)

The Emperor's personal shuttle, also known as Palpatine's personal shuttle, was a Lambda-class shuttle used by Galactic Emperor Palpatine.

## Specifications

- **Name:** Emperor's personal shuttle
- **Model:** Lambda-class T-4a shuttle
- **Countermeasures:** Cloaking device
- **Role:** Shuttle
- **Destroyed:** 4 ABY, aboard the Death Star II
- **Affiliation:** Galactic Empire
- **Owners:** Palpatine
