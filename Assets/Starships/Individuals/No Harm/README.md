# No Harm

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [No Harm](https://starwars.fandom.com/wiki/No_Harm)

The No Harm was a medical frigate in the navy of the New Republic. Yrica Quell was treated aboard the frigate after the battle on Pandem Nai.

- **Type:** Frigate
