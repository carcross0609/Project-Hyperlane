# Mist Laden

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mist Laden](https://starwars.fandom.com/wiki/Mist_Laden)

Mist Laden was bounty hunter Lu'daal-ud's personal ship, in use by his associates of the Granse Confederacy. Lu'daal-ud captured the original owner, an independent trader, in the Imberlin system.
