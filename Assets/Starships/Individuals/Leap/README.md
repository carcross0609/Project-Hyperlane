# Leap

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Leap](https://starwars.fandom.com/wiki/Leap)

Leap is a Lambda-class T-4a shuttle that was used by the Rebel Alliance. The shuttle was onboard the frigate Dodger and was used by Rebel officers.
