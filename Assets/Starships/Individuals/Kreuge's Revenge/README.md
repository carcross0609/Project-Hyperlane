# Kreuge's Revenge

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Kreuge's Revenge](https://starwars.fandom.com/wiki/Kreuge%27s_Revenge)

Kreuge's Revenge was a Razor-class frigate in service with the navy of the Galactic Empire around 0 ABY. At the time, it was commanded by Lieutenant Pyparr.

## Specifications

- **Name:** Kreuge's Revenge
- **Model:** Razor-class frigate
- **Type:** Frigate
- **Armament:** Three dual turbolaser cannons
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Captains:** Pyparr
