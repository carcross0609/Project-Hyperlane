# Dominator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dominator (Harrower-class)](https://starwars.fandom.com/wiki/Dominator_%28Harrower-class%29)

The Dominator was an BSX-5 Harrower-class dreadnought used by the reconstituted Sith Empire. It functioned as Darth Jadus' flagship until its disappearance and Jadus' supposed death.

## Specifications

- **Name:** Dominator
- **Model:** BSX-5
- **Type:** Harrower-class dreadnought
- **Length:** 600 meters
- **Armament:**
  - 28 turbolasers
  - 12 ion cannons
  - 2 tractor beam projectors
- **Complement:**
  - 8 fighters
  - 2 shuttles
- **Crew:** 2,000 crew
- **Passengers:** 1,500
- **Othersystems:** Passenger quarters can be converted to prison cells.
- **Role:** Flagship
- **Destroyed:** 3643 BBY
- **Affiliation:** Sith Empire
- **Fleet:** 500 soldiers
- **Captains:** Darth Jadus
