# Blood Gutter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blood Gutter](https://starwars.fandom.com/wiki/Blood_Gutter)

The Blood Gutter was a Carrack-class cruiser of the Imperial Navy. By 7.5 ABY, the Blood Gutter was a part of Warlord Zsinj's fleet.

## Specifications

- **Name:** Blood Gutter
- **Manufacturer:** Damorian Manufacturing Corporation
- **Model:** Carrack-class light cruiser
- **Type:** Frigate
- **Length:** 350 meters
- **Width:** 72 meters
- **Height:** 75 meters
- **Affiliation:** Zsinj's Empire
