# Harrar's priestship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Harrar's priestship](https://starwars.fandom.com/wiki/Harrar%27s_priestship)

The Yuuzhan Vong priest Harrar possessed a priestship. It was present at Obroa-skai after it was conquered, and the priestship served as a base of operations of sorts for Harrar and Nom Anor's plot to use bo'tous to infect Jedi.
