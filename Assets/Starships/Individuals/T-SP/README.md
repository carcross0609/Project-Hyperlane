# T-SP

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [T-SP](https://starwars.fandom.com/wiki/T-SP)

T-SP was a Utility Tug in use by a Rebel Alliance outpost during the Galactic Civil War within an Imperial simulation. During an Imperial torpedo attack by Alpha Squadron TIE Bombers, T-SP attempted to board one of the Class-A cargo containers along with fellow Utility Tug T-ST. However, while trying to board the containers, the two utility tugs were destroyed along with the rest of the outpost's complement.
