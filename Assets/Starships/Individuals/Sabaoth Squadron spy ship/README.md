# Sabaoth Squadron spy ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sabaoth Squadron spy ship](https://starwars.fandom.com/wiki/Sabaoth_Squadron_spy_ship)

This spy ship was a scout vessel employed by Captain Cavik Toth's Sabaoth Squadron around the time of the Occupation of Karthakk. Its design resembled the U-shape of a Sabaoth Frigate, but was the size of a starfighter and unarmed.
