# Dakkrakk

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dakkrakk](https://starwars.fandom.com/wiki/Dakkrakk)

The Dakkrakk was a Container transport under the employ of the Rebel Alliance. The transport was supposed to arrive at the Alliance Fleet massing near Sullust, but was destroyed at Sul-34 by Maarek Stele in a Missile Boat.
