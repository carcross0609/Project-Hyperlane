# Black One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Black One](https://starwars.fandom.com/wiki/Black_One)

Black One was a T-70 X-wing starfighter that was used by Resistance pilot Commander Poe Dameron. Dameron was usually accompanied by his trusty co-pilot, the spherical astromech droid BB-8.
