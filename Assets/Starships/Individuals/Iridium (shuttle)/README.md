# Iridium (shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Iridium (shuttle)](https://starwars.fandom.com/wiki/Iridium_%28shuttle%29)

Iridium was a Lambda-class T-4a shuttle of the same group as Tydirium. It was found in Outpost 327 when the latter was captured in the Mission to Zhar.
