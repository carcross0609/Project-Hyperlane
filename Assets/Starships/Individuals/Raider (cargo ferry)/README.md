# Raider

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Raider (cargo ferry)](https://starwars.fandom.com/wiki/Raider_%28cargo_ferry%29)

Raider was a mercenary cargo ferry. It attempted to steal from the Azzameens in 3 ABY, but it was destroyed by Ace Azzameen.

## Specifications

- **Name:** Raider
- **Model:** Cargo ferry
- **Length:** 90 meters
- **Destroyed:** 3 ABY
