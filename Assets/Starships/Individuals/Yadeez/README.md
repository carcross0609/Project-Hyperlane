# Yadeez

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Yadeez](https://starwars.fandom.com/wiki/Yadeez)

The Yadeez was a bulk freighter utilized as a carrier by the Galactic Empire's 204th Imperial Fighter Wing and commanded by Colonel Soran Keize. It was named for Fara Yadeez, Acting Governor of the planet Troithe, who had previously assisted the 204th before being taken into New Republic custody.
