# Hornet (corvette group)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hornet (corvette group)](https://starwars.fandom.com/wiki/Hornet_%28corvette_group%29)

Hornet was a group of Imperial corvettes deployed to protect the freighters near Petrakis when they were attacked by Rebel Alliance starfighters.
