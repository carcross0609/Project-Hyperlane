# Bogey One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Bogey One (Nikardun base)](https://starwars.fandom.com/wiki/Bogey_One_%28Nikardun_base%29)

Bogey One was a patrol cruiser that was used by the Grysk Hegemony. It participated in a battle at listening post KR21. During the battle it was destroyed.

## Specifications

- **Name:** Bogey One
- **Type:** Patrol cruiser
- **Destroyed:** c. 18 BBY
- **Affiliation:** Grysk Hegemony
