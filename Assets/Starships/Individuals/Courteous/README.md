# Courteous

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Courteous](https://starwars.fandom.com/wiki/Courteous)

Courteous was an Imperial cruiser of unknown class dispatched from the Centrality to blockade the Starcave. It was destroyed just before the Battle of ThonBoka when a negotiating party of Oswaft shouted at it.
