# Terrup

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Terrup](https://starwars.fandom.com/wiki/Terrup)

Terrup was an Imperial Ton-Falk-class escort carrier during the Galactic Civil War. It was part of the fleet that patrolled the Killaniri system.

## Specifications

- **Name:** Terrup
- **Type:** Ton-Falk-class escort carrier
- **Length:** 500 meters
- **Role:** Carrier
- **Affiliation:** Galactic Empire
