# Toron Voq

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Toron Voq](https://starwars.fandom.com/wiki/Toron_Voq)

The Toron Voq was a Galactic Republic patrol frigate that was sent to investigate a distress signal from the Jedi enclave on Rhinnal. The Toron Voq discovered the Red Reaper, but the Sith warship destroyed the frigate before it could escape.

## Specifications

- **Name:** Toron Voq
- **Type:** Frigate
- **Role:** Patrol vessel
- **Destroyed:** c. 3641—3640 BBY, Rhinnal system
- **Affiliation:** Galactic Republic
- **Navy:** Republic Navy
