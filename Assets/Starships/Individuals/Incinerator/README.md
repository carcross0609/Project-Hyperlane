# Incinerator

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Incinerator](https://starwars.fandom.com/wiki/Incinerator)

The Incinerator was a Resurgent-class Star Destroyer that was a part of the navy of the First Order at some point by 35 ABY. It was manufactured by Kuat-Entralla Engineering and measured 2,915.84 meters (9,566.29 feet) in length.
