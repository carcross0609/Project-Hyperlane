# Yanov

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yanov](https://starwars.fandom.com/wiki/Yanov)

The Yanov was an Imperial Customs Frigate stolen by agents of the Black Sun Vigo Sprax. It was later used in an operation by the Rebel Alliance Sandwind Team.
