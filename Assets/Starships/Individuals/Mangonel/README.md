# Mangonel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mangonel](https://starwars.fandom.com/wiki/Mangonel)

Dimok forces used Cargo ferry Mangonel during the Sepan Civil War. Mangonel aided other Dimok starships in raiding a Ripoblus supply convoy in the beginning of the Imperial Sepan campaign. With intent to drive off the Dimok raiders, Imperial TIE Bombers destroyed Cargo ferry Mangonel.

## Specifications

- **Name:** Mangonel
- **Model:** Cargo ferry
- **Length:** 90 meters
- **Destroyed:** 3 ABY
- **Affiliation:** Dimok government
