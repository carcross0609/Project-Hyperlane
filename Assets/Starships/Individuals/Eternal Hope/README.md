# Eternal Hope

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Eternal Hope](https://starwars.fandom.com/wiki/Eternal_Hope)

The Eternal Hope was a light freighter. It was owned and operated by Trel Modetto, an outlaw tech and smuggler. Modetto stole the Eternal Hope, using it as a base of operations which working as a smuggler, tech, scout, and gunman.
