# Blind Luck

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blind Luck](https://starwars.fandom.com/wiki/Blind_Luck)

The Blind Luck was a freighter that was owned by Desric Fol during the Galactic Civil War. The aging freighter's computer systems rarely calculated accurate hyperspace routes.

## Specifications

- **Name:** Blind Luck
- **Type:** Freighter
- **Crew:** At least 2
- **Owners:** Desric Fol
