# Minder

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Minder](https://starwars.fandom.com/wiki/Minder)

The Minder was a surveillance vessel of the Galactic Empire. The starship served as an escort of the bulk freighter Yadeez, the flagship of the Empire's 204th Imperial Fighter Wing. In 5 ABY, the Minder assisted in the 204th's genocidal crusade over worlds which had gone rogue from the Empire's loyalist forces.
