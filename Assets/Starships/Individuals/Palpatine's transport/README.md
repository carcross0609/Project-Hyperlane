# Palpatine's transport

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Palpatine's transport](https://starwars.fandom.com/wiki/Palpatine%27s_transport)

Palpatine's transport was the starship in which Supreme Chancellor Palpatine came to Nar Shaddaa to transport Obi-Wan Kenobi and Anakin Skywalker home to Coruscant after Anakin killed Krayn.
