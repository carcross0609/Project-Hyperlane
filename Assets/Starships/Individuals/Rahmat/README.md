# Rahmat

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rahmat](https://starwars.fandom.com/wiki/Rahmat)

The Rahmat was a Dreadnaught-class heavy cruiser. It was the first escort of the BFF-1 bulk freighter group Furlo that was destroyed by Imperial forces under the command of the Courageous.
