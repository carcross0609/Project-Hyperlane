# Sian Holt's ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sian Holt's ship](https://starwars.fandom.com/wiki/Sian_Holt%27s_ship)

A ship was owned by private investigator Sian Holt. The ship was used by Holt and Jedi Master Emerick Caphtor during their investigation into the death of Jedi Master Loden Greatstorm.
