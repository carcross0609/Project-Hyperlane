# Romold

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Romold](https://starwars.fandom.com/wiki/Romold)

Romold was a cargo ferry used by Mugaari pirates. The Cargo ferry was part of an illicit weapons deal between the pirates and the Rebel Alliance. However, the Imperials attacked the the cargo loading area and the cargo ferry, along with all the other Mugaari and rebel ships were destroyed in the Battle of the Tungra sector.

## Specifications

- **Name:** Romold
- **Model:** Cargo ferry
- **Length:** 90 meters
- **Destroyed:** 3 ABY, Tungra sector
- **Affiliation:** Mugaari pirates
