# Reliant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Reliant (cruiser)](https://starwars.fandom.com/wiki/Reliant_%28cruiser%29)

The Reliant was a battle cruiser in the Republic Navy during the Clone Wars. Along with the Devout, it was sent to the Cularin system to enforce the Emergency Powers Act after the Almas Academy engaged the Right of Denial.

## Specifications

- **Name:** Reliant
- **Type:** Cruiser
- **Affiliation:** Galactic Republic
- **Navy:** Republic Navy
