# Sarpazian Rose

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sarpazian Rose](https://starwars.fandom.com/wiki/Sarpazian_Rose)

The Sarpazian Rose was a ship used by the female Human smuggler Bera Kazan during the Clone Wars. It was somewhat dented and scarred, a trait owing to the extreme conditions in which Kazan operated.

## Specifications

- **Name:** Sarpazian Rose
- **Owners:** Bera Kazan
