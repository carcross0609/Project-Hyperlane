# Sargantuan

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sargantuan](https://starwars.fandom.com/wiki/Sargantuan)

The Sargantuan was a Raider I-class corvette that served the Imperial Navy during the Galactic Civil War. It was part of a task force led by Captain Ralchio Nervi that participated in the Battle of Xorrn.

## Specifications

- **Name:** Sargantuan
- **Manufacturer:** Kuat Drive Yards
- **Line:** Raider-class corvette
- **Model:** Raider I-class corvette
- **Type:** Corvette
- **Length:** 150 meters
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:** Ralchio Nervi's task force
