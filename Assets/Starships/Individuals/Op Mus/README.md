# Op Mus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Op Mus](https://starwars.fandom.com/wiki/Op_Mus)

Op Mus was a BFF-1 bulk freighter that had been assigned to carried food during and after the evacuation of Yavin 4.
