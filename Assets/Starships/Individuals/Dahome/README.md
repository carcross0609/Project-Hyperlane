# Dahome

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dahome](https://starwars.fandom.com/wiki/Dahome)

The Dahome was an EF76 Nebulon-B escort frigate used by the Alliance to Restore the Republic. It was present at the Battle of Organarms.
