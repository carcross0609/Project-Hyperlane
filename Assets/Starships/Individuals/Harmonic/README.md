# Harmonic

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Harmonic](https://starwars.fandom.com/wiki/Harmonic)

The Harmonic was a Republic Defense Coalition cruiser in the service of the Galactic Republic by 228 BBY, commanded by Captain Mitker. It took part in the assault on Naboo.
