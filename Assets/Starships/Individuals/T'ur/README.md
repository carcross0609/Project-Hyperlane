# T'ur

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [T'ur](https://starwars.fandom.com/wiki/T%27ur)

T'ur was the designation for a group of Lambda-class T-4a shuttles that saw service with the Rebel Alliance. These shuttles participated in the evacuation of personnel from the crippled and foundering Mon Calamari Star Cruiser Maximus, taking them to the Nebulon-B frigate Anvil.
