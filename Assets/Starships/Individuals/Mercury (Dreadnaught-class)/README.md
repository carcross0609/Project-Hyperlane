# Mercury

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mercury (Dreadnaught-class)](https://starwars.fandom.com/wiki/Mercury_%28Dreadnaught-class%29)

A Dreadnaught-class heavy cruiser owned and operated by an unknown independent party, Mercury at one point aided the Alliance by exiting hyperspace near to where the CR90 corvette Razor was captured by Avenger. She picked up escape pod V33-1XP carrying a lone Rebel crewman, who had with him the plans for the second Death Star.

## Specifications

- **Name:** Mercury
- **Manufacturer:** Rendili StarDrive
- **Model:** Dreadnaught-class heavy cruiser
- **Length:** 600 meters
- **Width:** 116.5 meters
- **Height:** 129.7/123.3 meters
- **Affiliation:** Unknown
