# Hasti

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hasti](https://starwars.fandom.com/wiki/Hasti)

The Hasti was a Lambda-class T-4a shuttle serving the Alliance to Restore the Republic during the Galactic Civil War. It was primarily used to insert Alliance commandos into the battlefields. It deployed starfighters during a battle with the Vehemence.
