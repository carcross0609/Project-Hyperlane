# Sapphire Rogue

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sapphire Rogue](https://starwars.fandom.com/wiki/Sapphire_Rogue)

The Sapphire Rogue was a starship that responded to the hyper-transceiver beacon that Leia Organa and her team placed on Sesid during Operation Yellow Moon. It was the size of a a small freighter but accelerated like an attack ship.

## Specifications

- **Name:** Sapphire Rogue
- **Type:** Freighter
- **Hyperdrive:** Equipped
