# L'ulo L'ampar's A-wing

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [L'ulo L'ampar's A-wing](https://starwars.fandom.com/wiki/L%27ulo_L%27ampar%27s_A-wing)
