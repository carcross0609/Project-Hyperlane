# Gasbag

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gasbag](https://starwars.fandom.com/wiki/Gasbag)

The Gasbag was a tibanna tanker manufactured by the BramDorc Corporation. By 44 ABY it was one of the last BramDorc products known to still exist, and had been turned into the orbital fortress of a two-bit Hutt crime lord.
