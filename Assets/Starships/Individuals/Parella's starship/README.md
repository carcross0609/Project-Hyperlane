# Parella's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Parella's starship](https://starwars.fandom.com/wiki/Parella%27s_starship)

Parella's starship was a starship owned by Hutt crime lord Parella Jiramma Baco. At some point, the Hutt used the ship to travel to the planet Lowick to hunt down a surviving member of the legendary Gorach species.

- **Name:** Parella's starship
- **Owners:** Parella Jiramma Baco
