# Vemmer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vemmer](https://starwars.fandom.com/wiki/Vemmer)

Vemmer was the designation for a group of six Mobquet medium transports in the service of the Alliance to Restore the Republic in 3 ABY.
