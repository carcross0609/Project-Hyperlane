# Blackstar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blackstar (pirate ship)](https://starwars.fandom.com/wiki/Blackstar_%28pirate_ship%29)

The Blackstar was a pirate ship and her crew were part of the Invids. It was stationed on Courkrus, and was one of the last ships to leave when Corran Horn's "avenging Jedi" appeared.

## Specifications

- **Name:** Blackstar
- **Affiliation:** Invids
