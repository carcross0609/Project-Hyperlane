# Last Laugh

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Last Laugh](https://starwars.fandom.com/wiki/Last_Laugh)

The Last Laugh was the personal starship of Oorn Noth. Noth used the ship for racing purposes as well as occasional smuggling jobs.
