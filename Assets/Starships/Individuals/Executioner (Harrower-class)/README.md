# Executioner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Executioner (Harrower-class)](https://starwars.fandom.com/wiki/Executioner_%28Harrower-class%29)

The Executioner was a Harrower-class dreadnought that served the reconstituted Sith Empire during the renewed conflict with the Galactic Republic. The ship was sent to assist the Imperial operation on Manaan.

## Specifications

- **Name:** Executioner
- **Model:** Harrower-class dreadnought
- **Type:** Dreadnaught
- **Armament:** Turbolasers
- **Complement:**
  - Mark VI Supremacy-class starfighters
  - Shuttles
- **Affiliation:**
  - Sith Empire
  -   Imperial Navy
