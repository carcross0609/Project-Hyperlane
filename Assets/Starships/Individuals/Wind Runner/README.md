# Wind Runner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wind Runner](https://starwars.fandom.com/wiki/Wind_Runner)

Wind Runner was a Ferryboat liner seen near Dunari's Rest. It was also seen near Camen Spaceport when shuttle Merte escaped the station.

## Specifications

- **Name:** Wind Runner
- **Manufacturer:** SoroSuub Corporation
- **Model:** Ferryboat liner
- **Length:** 363 meters
- **Role:** Passenger liner
