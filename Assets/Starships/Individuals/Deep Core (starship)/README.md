# Deep Core (starship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Deep Core (starship)](https://starwars.fandom.com/wiki/Deep_Core_%28starship%29)

The Deep Core was a freighter used to carry equipment for the holostar Javul Charn during her 2 BBY tour. The cargo was split between the Deep Core and the SoroSuub PLY-3500 Nova's Heart, with each ship carrying enough equipment for her to continue to perform if something were to happen to the other vessel.
