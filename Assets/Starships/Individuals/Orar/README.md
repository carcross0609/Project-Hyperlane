# Orar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Orar](https://starwars.fandom.com/wiki/Orar)

Orar was a Mandalorian Protector assault ship that served as the Mandalorian flagship at the Second Battle of Fondor. Its name was the Mando'a word for "thunder".
