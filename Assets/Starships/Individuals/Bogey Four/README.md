# Bogey Four

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Bogey Four](https://starwars.fandom.com/wiki/Bogey_Four)

Bogey Four was the name given to a light cruiser-sized warship of the Grysk Hegemony by the crew of the Imperial Star Destroyer Chimaera. Along with Bogey Three, Bogey Four joined a battle against the Chimaera.

## Specifications

- **Name:** Bogey Four
- **Affiliation:** Grysk Hegemony
