# Unidentified replenishment shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified replenishment shuttle](https://starwars.fandom.com/wiki/Unidentified_replenishment_shuttle)

A replenishment shuttle was aboard the Leveler, used by a small strike force to rescue Republic Intelligence agent Hallena Devis from JanFathal during the Clone Wars.
