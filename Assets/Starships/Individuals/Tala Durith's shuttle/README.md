# Tala Durith's shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Tala Durith's shuttle](https://starwars.fandom.com/wiki/Tala_Durith%27s_shuttle)

The Imperial officer and Hidden Path mole Tala Durith owned a shuttle that served as her transport. An Iota-class TS-485 light shuttle produced by Sienar Fleet Systems and Cygnus Space Workshops, it was taken away by the Galactic Empire while it had docked in Fortress Inquisitorius on the water moon Nur.

- **Model:** Iota-class TS-485 light shuttle
- **Type:** Transport
- **Engine:** 2
- **Affiliation:** Hidden Path
- **Captains:** Tala Durith
