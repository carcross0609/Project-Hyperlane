# Taanab Sunrise

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Taanab Sunrise](https://starwars.fandom.com/wiki/Taanab_Sunrise)

The Taanab Sunrise was a Victory-class Star Destroyer that was part of the New Republic's Defense Fleet as of 25 ABY. That year, as part of the Yuuzhan Vong War, it fought Yuuzhan Vong forces over the Outer Rim planet Garqi. There, it was severely damaged as it provided the New Republic forces with the time to extract intelligence operatives off Garqi, and was only saved thanks to the intervention of the Imperial Remnant Star Destroyer Red Harvest.
