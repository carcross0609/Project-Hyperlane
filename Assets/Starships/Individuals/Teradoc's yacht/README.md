# Teradoc's yacht

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Teradoc's yacht](https://starwars.fandom.com/wiki/Teradoc%27s_yacht)

A yacht was owned by the Imperial Admiral Kosh Teradoc. It was elegantly long and painted in Imperial-style white. Inside it had a grill, a bar, and weather-resistant furnishings.
