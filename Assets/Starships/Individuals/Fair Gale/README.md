# Fair Gale

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fair Gale](https://starwars.fandom.com/wiki/Fair_Gale)

The Fair Gale was a Short Range Transit Shuttle SST-67 owned and piloted by Worlohp. It was used to ferry passengers around the Naboo system.
