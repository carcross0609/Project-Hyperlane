# Starsprite

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starsprite](https://starwars.fandom.com/wiki/Starsprite)

The Starsprite was a Beta Cruiser, formerly used by the Hapan Royal Navy. It picked up Tenel Ka's Yuuzhan Vong escape pod.
