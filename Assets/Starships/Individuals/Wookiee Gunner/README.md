# Wookiee Gunner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wookiee Gunner](https://starwars.fandom.com/wiki/Wookiee_Gunner)

Wookiee Gunner was a Vernal-class freighter owned and operated by the Altisian Jedi faction during the Clone Wars. It was used for humanitarian missions to war-torn planets.

## Specifications

- **Name:** Wookiee Gunner
- **Type:** Vernal-class freighter
- **Role:** Freighter
- **Affiliation:** Altisian Jedi
- **Owners:** Djinn Altis
