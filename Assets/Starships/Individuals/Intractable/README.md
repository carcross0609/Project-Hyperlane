# Intractable

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Intractable](https://starwars.fandom.com/wiki/Intractable)

Intractable was an Imperial warship of unknown class that was present at the Battle of ThonBoka. Its captain questioned Rokur Gepta's tactics before the main battle. The Sorcerer of Tund subsequently ordered both the captain and his second in command thrown out an airlock for being individualist.
