# Luster

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Luster (cruiser)](https://starwars.fandom.com/wiki/Luster_%28cruiser%29)

The Luster was a cruiser owned by the Solodoe ambassador Ketas. While Ketas was negotiating with the Plinovians on Station Zeta, the Jedi diplomat Arath Tarrex stole Ketas's seal of office, made of solid mythra, from the Luster, using the Force to circumvent the security systems.

## Specifications

- **Name:** Luster
- **Type:** Cruiser
- **Owners:** Ketas
