# 3R3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [3R3](https://starwars.fandom.com/wiki/3R3)

3R3.]] 3R3 was the designation of a Kuat Systems Engineering Delta-7 Aethersprite-class light interceptor in service with the Jedi Order prior to and during the Clone Wars. Its pilot flew with a green-domed R4-series agromech droid.
