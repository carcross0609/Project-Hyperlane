# Blackguard

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blackguard (Star Destroyer)](https://starwars.fandom.com/wiki/Blackguard_%28Star_Destroyer%29)

The Blackguard was an Imperial-class Star Destroyer, that was captured by the rogue Imperial Captain&mdash;and self-proclaimed Grand Admiral&mdash;Andal Sait, with intention of selling it to the criminal organization Black Sun.
