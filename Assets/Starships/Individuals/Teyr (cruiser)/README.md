# Teyr (cruiser)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Teyr (cruiser)](https://starwars.fandom.com/wiki/Teyr_%28cruiser%29)

The Teyr was a battlecruiser in the Republic Navy during the Clone Wars. In 20 BBY, it shipped 50 clone commandos to the Battle of Praesitlyn.
