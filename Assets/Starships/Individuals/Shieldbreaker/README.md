# Shieldbreaker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shieldbreaker](https://starwars.fandom.com/wiki/Shieldbreaker)

Shieldbreaker was a Galactic Alliance ship. In 44 ABY, it was under the command of Captain Voyce Evlen during a brief skirmish with the Imperial Remnant vessel Concussor, which was secretly commandeered by Galactic Alliance commando unit Wraith Squadron.
