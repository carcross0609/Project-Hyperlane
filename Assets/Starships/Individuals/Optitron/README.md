# Optitron

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Optitron](https://starwars.fandom.com/wiki/Optitron)

Optitron was a Nikto ship in the service of the Imperial Department of Redesign. In 0 ABY, Kassihm hijacked the ship, and used it for his own purposes.
