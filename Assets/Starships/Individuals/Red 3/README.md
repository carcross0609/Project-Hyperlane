# Red 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red 3](https://starwars.fandom.com/wiki/Red_3)

Red 3 was a T-65 X-wing starfighter in service to the Alliance to Restore the Republic during the Galactic Civil War. The fighter was flown by Biggs Darklighter, and had previously been stationed near Sullust as part of the Ecliptic Evaders squadron. The X-wing was eventually transferred to Yavin 4. R2-F2 served as the astromech droid aboard Red 3.
