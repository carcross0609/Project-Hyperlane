# Ormni

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ormni](https://starwars.fandom.com/wiki/Ormni)

The Ormni was an asteroid crusher owned by the criminal Marvid and Craitheus Qreph. They used it as their mobile base in the Chiloon Rift.
