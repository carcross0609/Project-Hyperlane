# Conquest

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Conquest (Secutor-class)](https://starwars.fandom.com/wiki/Conquest_%28Secutor-class%29)

The Conquest was a Secutor-class Star Destroyer in service of the Galactic Empire in 14 BBY. It was in use by Vice Admiral Dodd Rancit as a command ship while partaking in the blockade of the Carrion Spike above Carida. The Conquest was 2,200 meters in length.
