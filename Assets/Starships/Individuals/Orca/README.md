# Orca

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Orca](https://starwars.fandom.com/wiki/Orca)

Orca was a pair of CR90 corvettes belonging to the Rebel Alliance. The ships were part of a convoy containing supplies for a new base that was attacked by Assault Gunboats and the EF76 Nebulon-B escort frigate Red Wind. Despite this pressure they made it into hyperspace by Keyan Farlander in an A-wing.
