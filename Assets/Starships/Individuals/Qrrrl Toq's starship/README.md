# Qrrrl Toq's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Qrrrl Toq's starship](https://starwars.fandom.com/wiki/Qrrrl_Toq%27s_starship)

Qrrrl Toq's starship was the Jedi ship given to Qrrrl Toq at Ossus which he used to pursue Aleema Keto and Crado into the Cron Cluster. When Aleema detonated the Cluster, Qrrrl was killed in his vessel.
