# Bespin Bandit

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Bespin Bandit](https://starwars.fandom.com/wiki/Bespin_Bandit)

The Bespin Bandit was a delta-shaped smuggling freighter with an off-set cockpit. It belonged to Uz Bonearm and it fought for the New Republic in the battle of New Alderaan alongside Starhook Ten and Hyperspace Marauder. It was equipped with ion cannons.

## Specifications

- **Name:** Bespin Bandit
- **Type:** Freighter
- **Armament:** Ion cannons
- **Affiliation:** New Republic
- **Owners:** Uz Bonearm
