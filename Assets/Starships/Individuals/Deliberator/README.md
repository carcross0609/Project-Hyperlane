# Deliberator

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Deliberator](https://starwars.fandom.com/wiki/Deliberator)

The Deliberator was an Imperial-class Star Destroyer used by the Imperial Navy. The Star Destroyer contained databanks, which included a file titled "Pyke Syndicate" from the "Kessel" section of the Imperial Archives. This file detailed the Galactic Empire's deal with the criminal Pyke Syndicate, whereby the Empire excavated the addictive substance spice from the mines on the planet Kessel before the Pykes sold the drug on the black market. The file also noted that although the Empire received a substantial share of the profits, it ultimately assumed full control of the spice output.
