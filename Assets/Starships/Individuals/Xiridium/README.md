# Xiridium

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Xiridium](https://starwars.fandom.com/wiki/Xiridium)

Xiridium was a Lambda-class T-4a shuttle of the same group as Tydirium. It was found in Outpost 327 when the latter was captured in the Mission to Zhar.
