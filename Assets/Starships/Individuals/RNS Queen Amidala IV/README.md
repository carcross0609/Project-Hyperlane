# RNS Queen Amidala IV

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [RNS Queen Amidala IV](https://starwars.fandom.com/wiki/RNS_Queen_Amidala_IV)

The RNS Queen Amidala IV was a Mon Calamari Star Cruiser serving in the Royal Naboo Security Forces. The ship was a starliner converted in Star Cruiser. It was named after former Queen and Senator of Naboo Padmé Amidala.

## Specifications

- **Name:** RNS Queen Amidala IV
- **Manufacturer:** Mon Calamari Shipyards
- **Model:** Mon Calamari Star Cruiser
- **Type:** Star Cruiser
- **Sysmods:** Hyperdrive class 1.0
- **Affiliation:** Royal Naboo Security Forces
