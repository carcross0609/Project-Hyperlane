# Imperialis

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Imperialis (Jakku)](https://starwars.fandom.com/wiki/Imperialis_%28Jakku%29)

The Imperialis was a replica of Emperor Palpatine's original luxury yacht of the same name. The replica was stored at the Jakku Observatory.
