# Nautilian

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Nautilian](https://starwars.fandom.com/wiki/Nautilian)

The Nautilian was an MC80A Home One Type Heavy Star Cruiser that served in the Alliance Fleet during the Galactic Civil War. It participated in the decisive battle fought at Endor, where it was entirely obliterated by the second Death Star. In 34 ABY, Admiral Gial Ackbar and Admiral Ushos O. Statura exchanged annotations about the Nautilian in The Rebel Files.
