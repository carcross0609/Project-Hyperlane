# Coronet

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Coronet (Acclamator-class)](https://starwars.fandom.com/wiki/Coronet_%28Acclamator-class%29)

The Coronet was an Acclamator-class assault ship that served in the Republic Navy during the Clone Wars. It was destroyed by Separatist forces during the Battle of Duro.

- **Name:** Coronet
- **Manufacturer:** Rothana Heavy Engineering
