# Solar Dynamica

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Solar Dynamica](https://starwars.fandom.com/wiki/Solar_Dynamica)

Solar Dynamica was a Corellian Buccaneer owned by Elta Besk. It was armed with ten double turbolasers.
