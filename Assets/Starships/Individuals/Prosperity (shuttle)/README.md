# Prosperity

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Prosperity (shuttle)](https://starwars.fandom.com/wiki/Prosperity_%28shuttle%29)

The Prosperity was a luxurious TZ-6 executive shuttle used by SIS agent Theron Shan and Jedi Master Gnost-Dural on their mission to Ziost. It was also used as a part of a temporary deal that Teff'ith set up to get an Imperial shuttle to fly to Reaver Station in order to take out The Ascendant Spear.

## Specifications

- **Name:** Prosperity
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** TZ-6 executive shuttle
- **Role:** Transport
- **Affiliation:** Jedi Order
- **Captains:** Gnost-Dural
