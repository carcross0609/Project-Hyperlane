# Arbiter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Arbiter (Star Destroyer)](https://starwars.fandom.com/wiki/Arbiter_%28Star_Destroyer%29)

The Arbiter was an Imperial-class Star Destroyer that served as part of the Imperial Navy. Zeck Tambell served aboard the Arbiter for two years as a naval security officer.
