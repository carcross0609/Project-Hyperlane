# Lagos

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Lagos (Sentinel-class)](https://starwars.fandom.com/wiki/Lagos_%28Sentinel-class%29)

Lagos was a Sentinel-class landing craft used by the Galactic Empire. After the destruction of the Imperial Communications Center on Lothal, Lagos was used to ferry R4 courier droids to and from the Tellstar in order to maintain Imperial communications.
