# Ahsoka's Delta-7B Jedi Starfighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ahsoka's Delta-7B Jedi Starfighter/Legends](https://starwars.fandom.com/wiki/Ahsoka%27s_Delta-7B_Jedi_Starfighter/Legends)

Ahsoka Tano, a Jedi Padawan under the tutelage of Jedi Knight Anakin Skywalker, piloted a red Delta-7B Aethersprite-class light interceptor with white markings for the Galactic Republic during the Clone Wars.

- **Affiliation:**
