# Blood Crow

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Blood Crow](https://starwars.fandom.com/wiki/Blood_Crow)

The Blood Crow was an Imperial Gozanti-class cruiser originally commanded by Captain Rik Virgilio, and later by Captain Filia Rossi. It was the first assignment of Lieutenant Thrawn and Ensign Eli Vanto.
