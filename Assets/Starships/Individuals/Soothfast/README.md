# Soothfast

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Soothfast](https://starwars.fandom.com/wiki/Soothfast)

Soothfast was a retrofitted Proficient-class light cruiser of the New Republic Defense Fleet that served during the Yuuzhan Vong War under the command of Captain Skent Graff.
