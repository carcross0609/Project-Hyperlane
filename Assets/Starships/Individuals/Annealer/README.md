# Annealer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Annealer](https://starwars.fandom.com/wiki/Annealer)

Annealer was an Acclamator-class assault ship of the Republic Navy. During the Clone Wars, Annealer was dispatched to defend Duro. There it was destroyed by General Grievous during Operation Durge's Lance.
