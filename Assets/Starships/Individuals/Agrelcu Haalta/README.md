# Agrelcu Haalta

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Agrelcu Haalta](https://starwars.fandom.com/wiki/Agrelcu_Haalta)

The Agrelcu Haalta, which could be translated as the Aggressive Defender in Basic, was a Dreadnaught-class heavy cruiser that served as the flagship of Troonol. It was the command ship of a Qunaalac fleet that patrolled the Bootana Hutta region of Hutt Space.

- **Name:** Agrelcu Haalta
- **Model:** Dreadnaught-class heavy cruiser
