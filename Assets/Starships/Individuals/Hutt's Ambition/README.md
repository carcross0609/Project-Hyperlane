# Hutt's Ambition

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hutt's Ambition](https://starwars.fandom.com/wiki/Hutt%27s_Ambition)

Hutt's Ambition was a New Republic bulk cruiser during the Galactic Civil War. It served in the Bothan Combat Response Element and fought in the Battle of Kathol System, in which it assisted in the defeat of Moff Kentor Sarne.

## Specifications

- **Name:** Hutt's Ambition
- **Type:** Bulk cruiser
- **Hyperdrive:** Equipped
- **Shield Gen:** Equipped
- **Armament:**
  - 30 quad laser cannons
  - 2 tractor beam projectors
- **Complement:** Starfighters (24)
- **Role:** Combat vessel
- **Affiliation:** New Republic
- **Navy:** New Republic Defense Fleet
- **Fleet:** Bothan Combat Response Element
