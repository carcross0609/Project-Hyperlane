# Valla's Glorious Gesture

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valla's Glorious Gesture](https://starwars.fandom.com/wiki/Valla%27s_Glorious_Gesture)

The Valla's Glorious Gesture was the flagship of the Vallaido Clan. The Vallaido children, including Siro Simito, would begin their pirate careers by operating the ship's turbolasers.
