# Black Krrsantan's Auzituck anti-slaver gunship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Black Krrsantan's Auzituck anti-slaver gunship](https://starwars.fandom.com/wiki/Black_Krrsantan%27s_Auzituck_anti-slaver_gunship)

During the Galactic Civil War, the Wookiee Krrsantan owned an Auzituck anti-slaver gunship which he flew on his missions with the rogue archeologist Doctor Aphra. The two used it to pull off the Son-tuul Pride robbery.
