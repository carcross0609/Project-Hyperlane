# Taylander-XCE shuttle

**Continuity:** Canon  
**Source:** [Taylander-XCE shuttle](https://starwars.fandom.com/wiki/Taylander-XCE_shuttle)

The Taylander-XCE shuttle was a miniaturized variant of the Taylander shuttle. One, the Heartfelt Apogee, was present on Nevarro in 9 ABY.
