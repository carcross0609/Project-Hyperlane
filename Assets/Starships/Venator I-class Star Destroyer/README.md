# Venator I-class Star Destroyer

**Continuity:** Canon  
**Source:** [Venator I-class Star Destroyer](https://starwars.fandom.com/wiki/Venator_I-class_Star_Destroyer)

The Venator I-class Star Destroyer was operated by the Galactic Republic Navy. The wedge-shaped starship was armed with eight DBY-827 heavy turbolaser turrets and two medium dual turbolaser cannons. The Venator I-class was succeeded by the Venator II-class.
