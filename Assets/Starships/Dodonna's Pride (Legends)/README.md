# Dodonna's Pride

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dodonna's Pride/Legends](https://starwars.fandom.com/wiki/Dodonna%27s_Pride/Legends)

The Dodonna's Pride was a CR90 corvette named for the Rebel Alliance hero General Jan Dodonna. The Alliance Fleet used the vessel in a series of hit-and-run raids on Imperial supply convoys during the Galactic Civil War.

## Specifications

- **Name:** Dodonna's Pride
- **Model:** CR90 corvette
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
