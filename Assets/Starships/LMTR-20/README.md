# LMTR-20

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [LMTR-20](https://starwars.fandom.com/wiki/LMTR-20)

LMTR-20 was a UT-60D U-wing starfighter/support craft that was owned by the Rebel Alliance during the early rebellion against the Galactic Empire. It was used by Captain Cassian Andor, Jyn Erso, and K-2SO during Operation Fracture.
