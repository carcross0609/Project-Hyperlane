# Diamond-class cruiser

**Continuity:** Legends  
**Source:** [Diamond-class cruiser/Legends](https://starwars.fandom.com/wiki/Diamond-class_cruiser/Legends)

The Diamond-class cruiser, also known as Diamond-class courier ship and the Commerce Guild cruiser, was a cruiser used by the Commerce Guild prior to and during the Clone Wars.

## Specifications

- **Name:** Diamond-class cruiser
- **Manufacturer:** Commerce Guild
- **Model:** Diamond-class cruiser
- **Type:** Cruiser
- **Cost:** 5,000,000 credits (2,125,000 used)
- **Length:** 200 meters
- **Mglt:** 80 MGLT
- **Max Speed:** 1,050 km/h
- **Hyperdrive:** Class 0.75 (backup class 4)
- **Navigation:** Navicomputer
- **Armament:** Laser cannon batteries (2)
- **Complement:**
  - OG-9 homing spider droids (600)
  - DSD1 dwarf spider droids (2,400)
- **Crew:** 148
- **Passengers:** 45
- **Capacity:** 1,380 tons
- **Consumables:** 3 months
- **Availability:** Military
- **Role:**
  - Transport
  - Cruiser
- **Affiliation:**
  - Commerce Guild
  - Confederacy of Independent Systems
