# Lucre

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lucre](https://starwars.fandom.com/wiki/Lucre)

Lucre was a small transport that was used by Corran Horn during the Yuuzhan Vong War. It was destroyed when Corran, Anakin Solo and Tahiri Veila set it on a preprogrammed evasion course in a Yuuzhan Vong fleet and escaped to a nearby asteroid in vacsuits.

## Specifications

- **Name:** Lucre
- **Type:** Transport
- **Destroyed:** 26.5 ABY
- **Affiliation:** New Jedi Order
- **Captains:** Corran Horn
