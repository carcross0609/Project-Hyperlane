# Idyll

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Idyll](https://starwars.fandom.com/wiki/Idyll)

The Idyll was an MPO-1400 Purrgil-class star cruiser active during the First Order-Resistance War. It was one of five starships of the class in active service at that time, along with the Halcyon, the Wanderlight, the Sojourn, and the Sterling.

## Specifications

- **Name:** Idyll
- **Model:** MPO-1400 Purrgil-class star cruiser
- **Type:** Starcruiser
