# Unidentified pirate ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified pirate ship](https://starwars.fandom.com/wiki/Unidentified_pirate_ship)

An unidentified pirate ship was a starship belonging to the Filthy Zephyrs, a gang of pirate Quarren based on the ocean planet of Manaan.

## Specifications

- **Name:** Unidentified pirate ship
- **Escapepods:** At least one escape pod
- **Owners:**
  - The Filthy Zephyrs
  - Wan'yek Whett's fishing crew
- **Captains:** Wan'yek Whett
