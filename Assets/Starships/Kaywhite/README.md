# Kaywhite

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Kaywhite](https://starwars.fandom.com/wiki/Kaywhite)

The Kaywhite was a Corporate Sector Authority capital ship that was the sister ship of the Emchen. The two served as the command ships of the CSA's fleet in 21 ABY.
