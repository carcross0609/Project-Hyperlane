# Valorous

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valorous/Legends](https://starwars.fandom.com/wiki/Valorous/Legends)

The Valorous was a GX1 short hauler in service to the Galactic Republic during the Clone Wars. Around 20 BBY, it delivered Padmé Amidala, Teckla Minnau, Nix Card, and two Senate Commandos to Scipio.
