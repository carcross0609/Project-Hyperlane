# Nest ship

**Continuity:** Legends  
**Source:** [Nest ship](https://starwars.fandom.com/wiki/Nest_ship)

A nest ship was a capital vessel class built by the Killik Colony during the Dark Nest Crisis to ferry their nests outside of the Utegetu Nebula.

## Specifications

- **Name:** Nest ship
- **Manufacturer:** Killiks
- **Length:** 8,000 meters on average
- **Armament:**
  - Turbolasers
  - Proton torpedo launchers
- **Role:**
  - Command ship
  - Battleship
  - Carrier
- **Affiliation:** The Colony
