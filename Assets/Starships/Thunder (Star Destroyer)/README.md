# Thunder (Star Destroyer)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thunder (Star Destroyer)](https://starwars.fandom.com/wiki/Thunder_%28Star_Destroyer%29)

The Thunder was a Star Destroyer of the Galactic Empire under Commander Tobal Siy. N-3PO, a Shard agent posing as a protocol droid, was planted aboard the Thunder as a spy for the Alliance to Restore the Republic.
