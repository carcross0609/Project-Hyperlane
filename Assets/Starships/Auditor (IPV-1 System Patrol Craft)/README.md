# Auditor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Auditor (IPV-1 System Patrol Craft)](https://starwars.fandom.com/wiki/Auditor_%28IPV-1_System_Patrol_Craft%29)

The Auditor was a Sienar Fleet Systems IPV-1 System Patrol Craft assigned to the planet Demophon during the Galactic Civil War. It attempted to stop the Black Obsession as it smuggled political prisoners off world.
