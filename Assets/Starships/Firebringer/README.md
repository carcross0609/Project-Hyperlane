# Firebringer

**Continuity:** Canon  
**Source:** [Firebringer](https://starwars.fandom.com/wiki/Firebringer)

The Firebringer was a heavily modified Spider Squall cruiser owned by the Nihil scientist Doctor Zadina Mkampa during the High Republic Era.

## Specifications

- **Name:** Firebringer
- **Model:** Modified Spider Squall
- **Type:** Cruiser
- **Destroyed:** 228 BBY, Kashyyyk
- **Affiliation:** Nihil
- **Owners:** Zadina Mkampa
