# Knife's Edge

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Knife's Edge](https://starwars.fandom.com/wiki/Knife%27s_Edge)

Knife's Edge was a Mansk-class escort frigate used by House Melantha during the Galactic Civil War. The vessel posed as a privateer in service to both the Rebel Alliance and House Mecetti to hide its true affiliations.
