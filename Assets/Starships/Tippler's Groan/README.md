# Tippler's Groan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tippler's Groan](https://starwars.fandom.com/wiki/Tippler%27s_Groan)

The Tippler's Groan was a commercial passenger starship. In 4 ABY, after escaping from Imperial Center, Mara Jade flew on the Tippler's Groan from Darsie to Phorliss.
