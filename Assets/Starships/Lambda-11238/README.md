# Lambda-11238

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lambda-11238](https://starwars.fandom.com/wiki/Lambda-11238)

Lambda-11238 was an Imperial Lambda-class T-4a shuttle which landed at Landing Bay Besh, in Mos Shuuta spaceport on Tatooine, while a band of fugitives infiltrated the control center in an attempt to release the docking clamps on the YT-1300 light freighter Krayt Fang.
