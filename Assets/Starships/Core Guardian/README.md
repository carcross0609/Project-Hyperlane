# Core Guardian

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Core Guardian](https://starwars.fandom.com/wiki/Core_Guardian)

The Core Guardian was a Galactic Republic auxiliary ship that was destroyed during the Clone Wars. Gurlanin spies claimed responsibility for the destruction of the vessel by leaking troop readiness information to Confederate commanders. Core Guardian defensive cannon was offline during an unscheduled maintenance and no survivors were reported.
