# Vellian drop ship

**Continuity:** Unknown  
**Source:** [Vellian drop ship](https://starwars.fandom.com/wiki/Vellian_drop_ship)

The Vellian drop ship was a model of starship. One such ship was meant to be in Squarn's Junkyard when a group of Rebels were looking for spare parts to repair their hyperdrive, but in its place was a hummock denoting a partially collapsed cargo container.
