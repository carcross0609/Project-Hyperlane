# Siol

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Siol](https://starwars.fandom.com/wiki/Siol)

Siol was a Ferryboat liner that carried smugglers from Dunari's Rest when the station was attacked by Imperial forces. It made it to hyperspace intact thanks to assistance from the Rebel Alliance.
