# Ugly

**Continuity:** Canon  
**Source:** [Ugly](https://starwars.fandom.com/wiki/Ugly)

Ugly was a term used to describe starships which were crafted from various origins. The crime lord and First Order agent Terex's Ranc Gang had an armada of Uglies, which he used to hunt down the Resistance agent Poe Dameron during the Cold War.
