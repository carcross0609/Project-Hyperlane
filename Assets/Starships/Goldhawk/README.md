# Goldhawk

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Goldhawk](https://starwars.fandom.com/wiki/Goldhawk)

The Goldhawk was a YT-1300 light freighter in service of the Rebel Alliance. It served in the Airam sector during the Rebellion's operations there.

## Specifications

- **Name:** Goldhawk
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** YT-series
- **Model:** YT-1300 light freighter
- **Type:** Light freighter
- **Destroyed:** 3 ABY
- **Affiliation:** Alliance to Restore the Republic
