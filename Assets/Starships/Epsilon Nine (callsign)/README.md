# Epsilon Nine

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Epsilon Nine (callsign)](https://starwars.fandom.com/wiki/Epsilon_Nine_%28callsign%29)

Epsilon Nine was a callsign for a First Order TIE/sf space superiority fighter. During the Cold War, an Epsilon Nine pilot encountered Han Solo, who was piloting the Eravana.

## Specifications

- **Name:** Epsilon Nine
- **Government:** First Order
- **Organization:** Epsilon Squadron
- **Duties:** Member of Epsilon Squadron
