# Lancer-class frigate

**Continuity:** Canon  
**Source:** [Lancer-class frigate](https://starwars.fandom.com/wiki/Lancer-class_frigate)

Lancer-class frigates were warships employed by the First Order around 30 years after the Battle of Endor. Commander Poe Dameron discovered two of the venerable frigates at a staging point as the Cold War heated up.

## Specifications

- **Name:** Lancer-class frigate
- **Type:** Frigate
- **Cost:** High
- **Length:** 250 meters
- **Hdsystem:** Dynamic hyperdrive systems
- **Armament:** Point-defense laser cannons (20)
- **Crew:** 800
- **Passengers:** 40 soldiers
- **Capacity:** 300 metric tons
- **Role:** Hunting down starfighters
- **Affiliation:**
  - Galactic Empire
  - First Order
  -   First Order Navy
