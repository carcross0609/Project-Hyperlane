# Overseer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Overseer (Acclamator-class)](https://starwars.fandom.com/wiki/Overseer_%28Acclamator-class%29)

The Overseer was an Acclamator-class assault vessel in the service of the Galactic Empire. It was destroyed by buzz droids jettisoned from the Second Chance.
