# Missile cruiser

**Continuity:** Legends  
**Source:** [Missile cruiser](https://starwars.fandom.com/wiki/Missile_cruiser)

Missile cruiser was a term used to describe ships belonging to one of the myriad cruiser classes whose primary armament consisted of missile launchers rather than energy weapons or along side them.
