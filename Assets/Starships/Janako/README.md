# Janako

**Continuity:** Legends  
**Source:** [Janako](https://starwars.fandom.com/wiki/Janako)

The Janako was a model of the MaKing-class transport that was manufactured by General Spacetronics and made under local license. It shared its name with the Janako system of the Inner Rim. The Janako featured distinguishing rear flanges and featured gunports.

## Specifications

- **Name:** Janako
- **Manufacturer:** General Spacetronics
- **Type:** MaKing-class transport
- **Armament:** Equipped
