# Deliverance (Rebel Alliance)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Deliverance (Rebel Alliance)](https://starwars.fandom.com/wiki/Deliverance_%28Rebel_Alliance%29)
