# Chellatine-class shuttle

**Continuity:** Canon  
**Source:** [Chellatine-class shuttle](https://starwars.fandom.com/wiki/Chellatine-class_shuttle)

The Chellatine-class shuttle was a transport ship manufactured by Mejson Spaceworks in the High Republic Era. The pilot Nash Durango owned a customized Chellatine, the Crimson Firehawk.

## Specifications

- **Name:** Chellatine-class shuttle
- **Manufacturer:** Mejson Spaceworks
- **Type:** Shuttle
- **Role:** Freight/passenger transport
