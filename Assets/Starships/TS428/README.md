# TS428

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [TS428](https://starwars.fandom.com/wiki/TS428)

TS428 was a transport shuttle that traveled from Belderone to Kijimi in 3 ABY. An announcement was broadcast over the Kijimi Spaceport speaker system informing its personnel to prepare for landing procedure.
