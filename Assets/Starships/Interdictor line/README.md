# Interdictor line

**Continuity:** Canon  
**Source:** [Interdictor line](https://starwars.fandom.com/wiki/Interdictor_line)

The Interdictor line was a line of Interdictor vessels of the Galactic Empire. The Interdictor-class heavy cruiser was a model of the line, which was an evolution of the Immobilizer 418 cruiser.

- **Name:** Interdictor line
- **Line:** Interdictor line
- **Type:** Interdictor vessel
- **Models:** Interdictor-class heavy cruiser
