# Unidentified starship class

**Continuity:** Canon  
**Source:** [Unidentified starship class](https://starwars.fandom.com/wiki/Unidentified_starship_class)

A time-honored type of starship manufactured by Rendili Hyperworks was used centuries prior to the Imperial Era. Decades prior to the formation of the Galactic Empire, the model had already fallen out of use, and vessels of a similar design and name, the Sphyrna-class Hammerhead corvette, became ubiquitous.

## Specifications

- **Name:** Unidentified starship class
- **Manufacturer:** Rendili Hyperworks
