# A-24 Sleuth-class scout ship

**Continuity:** Legends  
**Source:** [A-24 Sleuth-class scout ship](https://starwars.fandom.com/wiki/A-24_Sleuth-class_scout_ship)

The A-24 Sleuth-class scout ship, often called simply the A-24 Sleuth, was a model of high-performance scout vessel built by the venerable Incom Corporation.

## Specifications

- **Name:** A-24 Sleuth-class scout ship
- **Manufacturer:** Incom Corporation
- **Model:** A-24 Sleuth
- **Type:** Scout vessel
- **Length:** 14-20 meters
- **Max Speed:** 1,000 kmh
- **Engine:** High-output 804.d Starslinger ion drives (3)
- **Hyperdrive:**
  - Class 1.0 (primary)
  - Class 10 (backup)
- **Armament:** Fire-linked IX4 laser cannons (2)
- **Crew:**
  - 1 Pilot
  - 1 Astromech droid (optional)
- **Passengers:** 1
- **Capacity:** 2 metric tons
- **Consumables:** 3 months
- **Role:**
  - Scout vessel
  - Bockade runner
