# Nebula Chaser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nebula Chaser](https://starwars.fandom.com/wiki/Nebula_Chaser)

Nebula Chaser was a modified thousand-meter long Corellian Engineering Corporation cruiser under the command of Captain Pollux, customized with Hoersch-Kessel Drive, Inc. sublight drives. It had a hammerhead-shaped front.

## Specifications

- **Name:** Nebula Chaser
- **Type:** Cruiser
- **Length:** 1,000 meters
- **Destroyed:** 27 ABY
- **Captains:** Pollux
