# Unidentified soulcraft

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified soulcraft](https://starwars.fandom.com/wiki/Unidentified_soulcraft)

A soulcraft was in operation on the Inner Rim planet Pijal by 40 BBY. During that year, the vessel was attacked by blackguards and was engulfed in plasma fire. The Jedi Qui-Gon Jinn and Obi-Wan Kenobi attempted to rescue it using field lasers to dispel the flames.
