# GNK Power Cruiser

**Continuity:** Unknown  
**Source:** [GNK Power Cruiser](https://starwars.fandom.com/wiki/GNK_Power_Cruiser)

The GNK Power Cruiser was a class of cruiser that shared a name and resemblance with the GNK-series power droid. Gonkobo was seen flying this model of cruiser in Mustafarian space.

- **Name:** GNK Power Cruiser
