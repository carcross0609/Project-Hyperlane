# Crimson Sword

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Crimson Sword](https://starwars.fandom.com/wiki/Crimson_Sword)

The Crimson Sword was a CEC YT-2400 light freighter in operation during the Galactic Civil War. Like many such freighters, it was more than a simple transport craft.

- **Name:** Crimson Sword
- **Manufacturer:** Corellian Engineering Corporation
