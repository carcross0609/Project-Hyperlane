# Unidentified transport class

**Continuity:** Legends  
**Source:** [Unidentified transport class](https://starwars.fandom.com/wiki/Unidentified_transport_class)

Transport ships of this unidentified class were used at the time of the Galactic Civil War. This class had an elongated body with a bridge section in the bow and outriggers extending from the stern section on both sides.
