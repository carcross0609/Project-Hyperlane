# Averis Starburst

**Continuity:** Canon  
**Source:** [Averis Starburst](https://starwars.fandom.com/wiki/Averis_Starburst)

Averis Starburst was a model of luxury yacht. Cair San Tekka owned one of the vessels, which featured engines, a hyperdrive, and landing year. In 228 BBY, General Abediah Viess stole the yacht to escape Jedi pursuers on the planet Naboo.
