# Electro

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Electro](https://starwars.fandom.com/wiki/Electro)

Electro was a Lambda-class T-4a shuttle that was used by the Airam. When Tamaron was offered to use the X7 Factory Gallofree to swap the recently captured Interdictor Compellor's Gravity well technology onto a Strike-class medium cruiser Peregrine. While another Imperial patrol was dispatched to investigate the disappearance of the first patrol. While Rogue Squadron and Green Squadron held the Imperial forces long enough for the Electro to board the shuttle to provide finishing touches to the Peregrine so that it can be made ready for duty and the cruiser escaped to Hyperspace while the Rebel fighters destroyed all Imperial forces to prevent any witnesses.
