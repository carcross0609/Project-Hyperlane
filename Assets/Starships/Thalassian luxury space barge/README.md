# Thalassian luxury space barge

**Continuity:** Legends  
**Source:** [Thalassian luxury space barge](https://starwars.fandom.com/wiki/Thalassian_luxury_space_barge)

A Thalassian luxury space barge was a model of starship. Moff Abran Balfour's personal ship, the Lady Telura, was a Thalassian luxury space barge. By the time of the Galactic Civil War it was considered a rare model, requiring specific parts in order to be properly maintained.
