# Neebray Manta

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Neebray Manta](https://starwars.fandom.com/wiki/Neebray_Manta)

The Neebray Manta was a starship that was used by the Pacithhip smuggler Kozzel Qwok and his gang, during the time of the Clone Wars.

## Specifications

- **Name:** Neebray Manta
- **Type:** Corellian Freighter
- **Armament:** Rockets
- **Role:** Smuggling ship
- **Destroyed:** c. 22 BBY, Coruscant
- **Owners:** Kozzel Qwok
