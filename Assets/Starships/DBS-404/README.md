# DBS-404

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [DBS-404](https://starwars.fandom.com/wiki/DBS-404)

DBS-404 was a Hyena-class Droid Bomber that served in the Separatist Alliance during the Clone Wars. At one point, DBS-404 was damaged while in a battle on Geonosis and conducted a suicidal run on a Galactic Republic All Terrain Tactical Enforcer after its preservation protocols were not found. DBS-404 was painted in yellow markings.
