# Truthseeker

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Truthseeker](https://starwars.fandom.com/wiki/Truthseeker)

The Truthseeker was a shuttle that belonged to Jedi Master Lene Kostana. The shuttle was eventually have to be broken apart while Dooku, Lene Kostana, and Sifo-Dyas are battling Abyssin from the Invasion of Serenno. They had to jettison the cockpit, because the escape pods were jammed.
