# TDF104

**Continuity:** Unknown  
**Source:** [TDF104](https://starwars.fandom.com/wiki/TDF104)

TDF104 was the class name of the pirate ship owned by Captain Oxus. Oxus's ship was stolen by Han Solo, Chewbacca and Montross Holdaack, members of its crew, to take Luke Starkiller and his droids to Ogana Major.
