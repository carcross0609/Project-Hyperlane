# Glowworm

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Glowworm (ship)](https://starwars.fandom.com/wiki/Glowworm_%28ship%29)

The Glowworm was a ship owned by the Hutt Churo that shared its name with the glowworm, a type of worm that infested soil samples he had kept in his greenhouse on the Hutt Space planet Nal Hutta.

- **Name:** Glowworm
