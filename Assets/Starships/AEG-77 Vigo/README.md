# AEG-77 Vigo

**Continuity:** Legends  
**Source:** [AEG-77 Vigo](https://starwars.fandom.com/wiki/AEG-77_Vigo)

The AEG-77 Vigo was a transport vessel of the criminal Black Sun organization that was also used by Xizor Transport Systems and other organizations and individuals at the time of the Galactic Civil War. Some ships were heavily modified for use as convoy escorts.

## Specifications

- **Name:** AEG-77 Vigo
- **Model:** AEG-77 Vigo
- **Type:** Transport
- **Cost:** 200,000 credits (75,000 used)
- **Hyperdrive:** Class 3 (backup class 15)
- **Navigation:** Navicomputer
- **Armament:**
  - Laser cannon (2)
  - Laser cannon turrets (6)
- **Crew:** 8
- **Passengers:** 6
- **Capacity:** 25 tons (100 tons in unarmed transport version)
- **Consumables:** 1 month
- **Availability:** Licensed
- **Role:**
  - Cargo transport
  - Convoy escort
- **Affiliation:**
  - Black Sun
  - Ay'Nat pirates
