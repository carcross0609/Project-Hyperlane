# Hand of Justice

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hand of Justice/Legends](https://starwars.fandom.com/wiki/Hand_of_Justice/Legends)

The Hand of Justice was an Arquitens-class light cruiser, commanded by Admiral Coburn during an operation to rescue Togruta slaves from a Zygerrian slave processing facility on Kadavo.
