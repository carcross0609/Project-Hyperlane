# Selonian cone ship

**Continuity:** Legends  
**Source:** [Selonian cone ship](https://starwars.fandom.com/wiki/Selonian_cone_ship)

Selonian cone ships were short-range craft of primitive design, incapable of interstellar travel (and some would say barely capable of interplanetary travel), used by the Selonians.

## Specifications

- **Name:** Selonian cone ship
- **Manufacturer:** Selonians
- **Length:** 20 meters
- **Width:** 20 meters
- **Height:** 20 meters
- **Hyperdrive:** None
- **Shield Gen:** None
- **Armament:** None
- **Crew:** Pilot (1)
- **Passengers:** 4
- **Capacity:** 50 tons
- **Consumables:** 1 month
- **Role:** Freighter
- **Affiliation:** Selonian
