# Blockade Bandit

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blockade Bandit](https://starwars.fandom.com/wiki/Blockade_Bandit)

The Bright Blast was a CR90 corvette of the Corellian Security Force. It was later captured by pirates and renamed Blockade Bandit. The ship was eventually shot down above Raxus Prime by Republic cruisers prior to the Clone Wars. Its wreck was abandoned in Scrapheap Point, a ship junkyard located on Raxus Prime.
