# Snoop 2

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Snoop 2](https://starwars.fandom.com/wiki/Snoop_2)

Snoop 2 was a Patrol X-wing used by the Alliance to Restore the Republic that was assigned to perimeter and reconnaissance sweeps around Base One on Yavin 4.

- **Name:** Snoop 2
- **Manufacturer:** Incom Corporation
- **Line:** X-wing
- **Type:** Starfighter

- **Role:** Reconnaissance craft
