# Renegade

**Continuity:** Legends  
**Source:** [Renegade (Delta-class DX-9 stormtrooper transport)](https://starwars.fandom.com/wiki/Renegade_%28Delta-class_DX-9_stormtrooper_transport%29)

Renegade was a Delta-class DX-9 stormtrooper transport used by Imperial forces during the Galactic Civil War. The Renegade took part on the first skirmish on Deep Space Manufacturing Facility ZA-13. It was used to reload the TIE Defenders with warheads when they run out and needed to reload.

## Specifications

- **Name:** Renegade
- **Manufacturer:** Telgorn Corporation
- **Model:** Delta-class DX-9 stormtrooper transport
- **Type:** Transport
- **Length:** 20 meters
- **Width:** 7.8 meters
- **Height:** 5.8 meters
- **Complement:** Warheads
- **Role:** Supply ship
- **Affiliation:** Galactic Empire
