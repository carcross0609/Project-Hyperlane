# Durosian fighter

**Continuity:** Canon  
**Source:** [Durosian fighter](https://starwars.fandom.com/wiki/Durosian_fighter)

The Durosian fighter was a type of starfighter active during the First Order-Resistance War. One visible Durosian fighter, along with a few others, were part of the Citizens' Fleet led by General Lando Calrissian during the Battle of Exegol between the Resistance and the Sith Eternal.

## Specifications

- **Name:** Durosian fighter
- **Type:** Starfighter
- **Affiliation:** Citizens' Fleet
