# Aggressive ReConnaissance-170 starfighter

**Continuity:** Legends  
**Source:** [Aggressive ReConnaissance-170 starfighter/Legends](https://starwars.fandom.com/wiki/Aggressive_ReConnaissance-170_starfighter/Legends)
