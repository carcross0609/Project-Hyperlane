# Fury-class starfighter

**Continuity:** Legends  
**Source:** [Fury-class starfighter](https://starwars.fandom.com/wiki/Fury-class_starfighter)

The Fury-class starfighter, also known as Sith Fury, was a starfighter first used by the One Sith around 130 ABY. Its design was based on the Old Republic Cutlass-9 patrol fighter.
