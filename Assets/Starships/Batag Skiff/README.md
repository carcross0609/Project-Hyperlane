# Batag Skiff

**Continuity:** Legends  
**Source:** [Batag Skiff](https://starwars.fandom.com/wiki/Batag_Skiff)

A Batag Skiff was a type of Hapan skiff. Lalu Morwan owned one. The hatch code for her skiff was "Alophon", and the pilot's code was "Remela". Morwan let Aurra Sing take the skiff in order to attempt to assassinate the Chume'da Allana, while Morwan rode in the Millennium Falcon. Its sensors included automatic filters.
