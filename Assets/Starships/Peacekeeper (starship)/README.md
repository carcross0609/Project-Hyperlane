# Peacekeeper (starship)

**Continuity:** Legends  
**Source:** [Peacekeeper (starship)](https://starwars.fandom.com/wiki/Peacekeeper_%28starship%29)

The Peacekeeper was a class of Imperial low-orbit patrol craft. A dozen were stationed at the Lola Curich Starport on the planet Lianna.
