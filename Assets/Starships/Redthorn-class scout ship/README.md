# Redthorn-class scout ship

**Continuity:** Legends  
**Source:** [Redthorn-class scout ship](https://starwars.fandom.com/wiki/Redthorn-class_scout_ship)

The Tykannin Drive Redthorn-class scout was a 24-meter long design with a forward light triple blaster. It carried one pilot, one co-pilot, one gunner, and 10 metric tons of cargo. The Lwyll was an example of this class.
