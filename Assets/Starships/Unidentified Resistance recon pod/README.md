# Unidentified Resistance recon pod

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Resistance recon pod](https://starwars.fandom.com/wiki/Unidentified_Resistance_recon_pod)

This recon pod was built by Jessika Pava in 34 ABY for a reconnaissance mission on Starkiller Base following the Hosnian Cataclysm. To keep it small and undetectable, it did not contain engines or weapons, only a scanner, life support, communications, and a mag-field generator to help mask its signature even more.
