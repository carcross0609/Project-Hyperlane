# Anuto

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Anuto](https://starwars.fandom.com/wiki/Anuto)

The Anuto was a GR-75 medium transport used by the Rebel Alliance. It saw service in the Airam sector.

- **Model:** GR-75 medium transport
- **Type:** Medium transport

- **Destroyed:** 3 ABY
