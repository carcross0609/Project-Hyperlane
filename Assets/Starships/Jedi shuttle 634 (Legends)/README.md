# Jedi shuttle 634

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jedi shuttle 634/Legends](https://starwars.fandom.com/wiki/Jedi_shuttle_634/Legends)

Jedi shuttle 634 was an Eta-class shuttle and served as a Jedi ambassadorial shuttle during the Clone Wars. It was flown by Anakin Skywalker and Obi-Wan Kenobi, as well as Ahsoka Tano to the planet Mortis.
