# Alpha-52 starfighter

**Continuity:** Legends  
**Source:** [Alpha-52 starfighter](https://starwars.fandom.com/wiki/Alpha-52_starfighter)

The Alpha-52 starfighter was a starfighter model that was manufactured by Incom Corporation. Only a prototype that never reached the open market, the only known example, the Shrike, was kept by Talon Karrde, who loaned it to Mara Jade.
