# Class 546 Cruiser

**Continuity:** Canon  
**Source:** [Class 546 Cruiser](https://starwars.fandom.com/wiki/Class_546_Cruiser)

The Arquitens-class 546, also known as the Class 546 Cruiser, was a modified model of Arquitens-class command cruiser primarily designed for greater speed under the Class 546 program. A Class 546 Cruiser was used by an Imperial remnant led by Moff Gideon. Although similar to the command cruiser model, the Class 546 housed a large internal hangar bay that could be accessed by port and starboard hangar doors and a launch tube at the center of the vessel, along the spine of the vessel Designated as a Lightspeed Cruiser, its bridge was also different from the standard Arquitens-class models, and was equipped with three primary and four secondary sublight engines.
