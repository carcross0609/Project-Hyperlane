# Vengeance

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vengeance (Executor-class)](https://starwars.fandom.com/wiki/Vengeance_%28Executor-class%29)

The Vengeance was an Executor-class Star Dreadnought that served with the Imperial Navy, under the command of Admiral Wooyou Senn. It was thought to have perished as a result of the Battle of Nocto.

## Specifications

- **Name:** Vengeance
- **Manufacturer:** Kuat Drive Yards
- **Type:** Executor-class Star Dreadnought
- **Length:** 19,000 meters
- **Complement:** TIE/LN starfighters
- **Role:**
  - Command ship
  - Carrier
  - Battleship (dreadnought)
- **Destroyed:** 3.5 ABY, Nocto system (probably)
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:** Task Force Vengeance
- **Captains:** Admiral Wooyou Senn
