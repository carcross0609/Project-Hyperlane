# Unidentified Spiral-class Viz-Core Eviscerator

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Spiral-class Viz-Core Eviscerator](https://starwars.fandom.com/wiki/Unidentified_Spiral-class_Viz-Core_Eviscerator)

A Spiral-class Viz-Core Eviscerator was used by Shug Drabor as inspiration for his ship designs. It was constructed around 430 BBY. It was all black, and had no viewports. It participated in the Battle of Jedha, shortly before the model was banned. It was later used by Ram Jomaram during the Battle of Corellia to disable the engines of several Republic Longbeams and MPO cruisers that were stolen by the Nihil. He later used it to travel to Valo.

## Specifications

- **Name:** Unidentified Spiral-class Viz-Core Eviscerator
- **Model:** Spiral-class Viz-Core Eviscerator

- **Hull:** VIX-force metallic blast-proof shielding
- **Navigation:** Modulated navicomputer

- **Owners:** Shug Drabor
- **Captains:** Ram Jomaram
