# Grek-class troop shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Grek-class troop shuttle](https://starwars.fandom.com/wiki/Grek-class_troop_shuttle)

The Grek-class troop shuttle was a class of troop transport shuttle named after the seventh letter of the Aurebesh script, Grek. The namesake was due to the shuttle physically resembling the character, rather than being the seventh starship in a series. EF76 Nebulon-B escort frigates, used by both the Galactic Empire and the Alliance to Restore the Republic, commonly carried the Grek-class.

## Specifications

- **Name:** Grek-class troop shuttle
- **Model:** Grek-class
- **Type:** Troop shuttle
- **Role:** Troop transport
