# Chandi

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chandi](https://starwars.fandom.com/wiki/Chandi)

The Chandi was a DP20 gunship in the Rebel Alliance Fleet. It was present during the Battle of Endor. It was a part of the Defiance task force at Sullust before the battle.

## Specifications

- **Name:** Chandi
- **Model:** DP20 gunship
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
- **Fleet:** Independence task force
