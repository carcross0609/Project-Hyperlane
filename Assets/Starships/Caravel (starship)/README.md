# Caravel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Caravel (starship)](https://starwars.fandom.com/wiki/Caravel_%28starship%29)

The Caravel was the personal starship of Mungo Baobab. Following Mungo's capture in The Cloak of the Sith, Caravel was briefly captured by Roon's Governor Koong before eventually being returned to its owner.
