# SpaceBantha-class freighter

**Continuity:** Legends  
**Source:** [SpaceBantha-class freighter](https://starwars.fandom.com/wiki/SpaceBantha-class_freighter)

The SpaceBantha-class freighter was a boxy cargo ship built by Damorian Manufacturing Corporation. It was used in the years after the Yuuzhan Vong War.

- **Name:** SpaceBantha-class freighter
- **Manufacturer:** Damorian Manufacturing Corporation
