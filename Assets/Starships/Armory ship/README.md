# Armory ship

**Continuity:** Legends  
**Source:** [Armory ship](https://starwars.fandom.com/wiki/Armory_ship)

An armory ship, also known as an arsenal ship, was a starship designation. Ships of this type were used to store armaments, rather than serving as full warships. The Alderaanian War Frigate Another Chance was an armory ship, as was a Trade Federation vessel carrying battle droids and other armaments bound for a Galactic Republic decommissioning station following the Battle of Naboo.
