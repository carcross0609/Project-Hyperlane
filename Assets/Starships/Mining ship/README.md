# Mining ship

**Continuity:** Legends  
**Source:** [Mining ship](https://starwars.fandom.com/wiki/Mining_ship)

Mining ships were specialized starships designed with the sole purpose of conducting deep-space mining operations. Mining ships were used to mine asteroids, or mine gas from gas giants. The Asteroid Prospector AP-300 was a model of asteroid miner, while the Garman-class Gas Miner was a model of gas mining starship.
