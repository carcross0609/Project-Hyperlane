# CORT-327

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [CORT-327](https://starwars.fandom.com/wiki/CORT-327)

CORT-327 was a freighter used by the Alliance to Restore the Republic. The ship was piloted by Burin Kassal and copiloted by Calle Tharandon during a mission to Ord Mantell to extract rebel operatives who's location had been compromised.

## Specifications

- **Name:** CORT-327
- **Type:** Freighter
