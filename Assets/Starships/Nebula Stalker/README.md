# Nebula Stalker

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nebula Stalker](https://starwars.fandom.com/wiki/Nebula_Stalker)

The Nebula Stalker was a famous ghost ship. According to a spacer tale, the Nebula Stalker crash-landed on the planet Durace, in the Unknown Regions.
