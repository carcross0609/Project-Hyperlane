# Torr Snapit's starship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Torr Snapit's starship](https://starwars.fandom.com/wiki/Torr_Snapit%27s_starship)

Torr Snapit's starship was the transport in which Torr Snapit took Sladak, Slatka, Rain, Bug, and Tomcat to the Hoth's Brand system. It was shot down by Sith minions.
