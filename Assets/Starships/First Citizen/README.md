# First Citizen

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [First Citizen](https://starwars.fandom.com/wiki/First_Citizen)

The First Citizen was Chief of State Borsk Fey'lya's Kothlis Systems Luxuflier. It was used to evacuate people during the Battle of Coruscant, as Fey'lya refused to leave Coruscant. Its captain was Durm.
