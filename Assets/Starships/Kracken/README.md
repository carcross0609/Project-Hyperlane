# Kracken

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kracken](https://starwars.fandom.com/wiki/Kracken)

Kracken was a Nebulon-B2 frigate belonging to the Rebel Alliance. The frigate, along with several other ships, was mobilizing at the Delfii system prior to the Battle of Endor. The frigate's cargo was troops.

## Specifications

- **Name:** Kracken

- **Model:** Nebulon-B2 frigate
- **Type:** Frigate
- **Length:** 253.2 meters
- **Width:** 147.7 meters
- **Height:** 94.3 meters
- **Affiliation:** Alliance to Restore the Republic
