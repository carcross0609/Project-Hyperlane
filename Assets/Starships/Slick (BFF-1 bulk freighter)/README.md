# Slick (BFF-1 bulk freighter)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Slick (BFF-1 bulk freighter)](https://starwars.fandom.com/wiki/Slick_%28BFF-1_bulk_freighter%29)

Slick was an Imperial BFF-1 bulk freighter which carried stormtroopers and attempted to board the Habassa freighter group Jess in the Pii system. It was destroyed by Red Squadron B-wing starfighters.
