# Marl-class heavy freighter

**Continuity:** Legends  
**Source:** [Marl-class heavy freighter](https://starwars.fandom.com/wiki/Marl-class_heavy_freighter)

The Marl-class heavy freighter was created by Kuat Drive Yards. The design was a blocky drive connected to a long series of detachable storage pods. The ship was headed up by a narrow habitation compartment.

## Specifications

- **Name:** Marl-class heavy freighter
- **Designer:** Kuat Drive Yards
