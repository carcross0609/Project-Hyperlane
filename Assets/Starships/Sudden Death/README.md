# Sudden Death

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sudden Death](https://starwars.fandom.com/wiki/Sudden_Death)

The Sudden Death was a modified MRX-BR Pacifier owned by the bounty hunter Iceman. He added an additional proton torpedo launcher and additional prisoner space by converting the passenger quarters into a brig.
