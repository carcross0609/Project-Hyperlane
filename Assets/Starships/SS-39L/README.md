# SS-39L

**Continuity:** Legends  
**Source:** [SS-39L](https://starwars.fandom.com/wiki/SS-39L)

The SS-39L was a variant of the SS-39 Space Skiff manufactured by Telex-Delcor. The SS-39L differed from the standard model by mounting a Kuat Vonak 21-Dx light laser cannon.
