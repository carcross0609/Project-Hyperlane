# Geist

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Geist (cruiser)](https://starwars.fandom.com/wiki/Geist_%28cruiser%29)

The Geist was a Mon Calamari cruiser captained by General Hera Syndulla. It was present at the Mako-Ta Space Docks when it was attacked by the Galactic Empire. It was one of the few cruisers to escape the attack.
