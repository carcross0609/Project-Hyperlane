# Nemzet

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nemzet](https://starwars.fandom.com/wiki/Nemzet)

Nemzet was a IPV-1 System Patrol Craft used by a salvage yard that was hiding criminals, including a Rebel spy. When the Imperials arrived to disable the criminals' Corellian YT-1300 transports. The Patrol Craft was in need of repair so the platform sent a shuttle called Poltroon to repair the craft along with freighter Renspecs. Whether the shuttle did repair the patrol craft was unclear but either way the patrol craft was destroyed by the Imperials.
