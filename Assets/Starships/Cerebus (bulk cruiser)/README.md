# Cerebus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cerebus (bulk cruiser)](https://starwars.fandom.com/wiki/Cerebus_%28bulk_cruiser%29)

The Cerebus was a bulk cruiser that formed part of the Imperial Corrupter Task Force. It was commanded by Captain Tains.
