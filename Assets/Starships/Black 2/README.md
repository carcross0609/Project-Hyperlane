# Black 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Black 2](https://starwars.fandom.com/wiki/Black_2)

Black 2 was a TIE fighter assigned to Black Squadron. The starfighter was flown by TIE pilot "Mauler" Mithel, and the craft was stationed aboard the first Death Star.
