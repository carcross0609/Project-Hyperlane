# Compassion

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Compassion](https://starwars.fandom.com/wiki/Compassion)

The Compassion was a Lambda-class shuttle that saw service with the Rebel Alliance Fleet around 3 ABY. During a mission to treat the wounded of Gelgelar, the vessel was used to ferry medical supplies to the Medical Frigate Redemption.

## Specifications

- **Name:** Compassion
- **Type:** Lambda-class T-4a shuttle
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
- **Fleet:** Liberty Task Force
