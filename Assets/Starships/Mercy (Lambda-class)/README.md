# Mercy (Lambda-class)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mercy (Lambda-class)](https://starwars.fandom.com/wiki/Mercy_%28Lambda-class%29)

Mercy was a Lambda-class T-4a shuttle in service to the Rebel Alliance. The shuttle was used in a rescue operation near Stars' End to board the BFF-1 bulk freighter Hampton and rescue two Rebel pilots, while two Alliance-flown Y-wings held off the escort frigate Furious attacks long enough for the Mercy to rescue the two pilots and escape into hyperspace.
