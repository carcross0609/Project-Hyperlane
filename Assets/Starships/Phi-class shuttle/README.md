# Phi-class shuttle

**Continuity:** Canon  
**Source:** [Phi-class shuttle](https://starwars.fandom.com/wiki/Phi-class_shuttle)

The Phi-class shuttle was a class of shuttle used by the Galactic Empire, including the Scythe, which was used by members of the Inquisitorius and named for the Sith whom they served.

## Specifications

- **Name:** Phi-class shuttle
- **Manufacturer:** Sienar Fleet Systems
- **Model:** Phi-class
- **Type:** Shuttle
- **Affiliation:**
  - Galactic Empire
  -   Inquisitorius
