# Marcadian luxury cruiser

**Continuity:** Legends  
**Source:** [Marcadian luxury cruiser](https://starwars.fandom.com/wiki/Marcadian_luxury_cruiser)

Marcadian luxury cruisers were a type of starship that acted as pleasure cruisers. One particular vessel was the Aurel Moon, owned by the Columi brothers, Craitheus and Marvid Qreph.

## Specifications

- **Name:** Marcadian luxury cruiser
- **Type:** Cruiser
- **Role:** Luxury vessel
