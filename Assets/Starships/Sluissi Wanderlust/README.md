# Sluissi Wanderlust

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sluissi Wanderlust](https://starwars.fandom.com/wiki/Sluissi_Wanderlust)

The Sluissi Wanderlust was a starliner carrying 323 refugees to Kwilaan Starport, Naboo, in 22 BBY. After being detained in a holding pattern for four hours by the Pickaxe, it was redirected to Theed.
