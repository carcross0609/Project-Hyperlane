# Martial-class shuttle

**Continuity:** Legends  
**Source:** [Martial-class shuttle](https://starwars.fandom.com/wiki/Martial-class_shuttle)

The Martial-class shuttle was a starship used in boarding operations. Produced by Sienar Fleet Systems, the ship was small enough that three could fit into a retrofitted landing bay in a CR90 corvette. They were in use since at least 5 ABY.
