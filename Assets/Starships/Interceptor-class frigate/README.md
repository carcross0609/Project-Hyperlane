# Interceptor-class frigate

**Continuity:** Canon  
**Source:** [Interceptor-class frigate](https://starwars.fandom.com/wiki/Interceptor-class_frigate)

The so-called Interceptor-class frigates were modified Action VI bulk transports used by pirates and other criminal organizations. With the addition of heavy weaponry, the bulk freighters became ersatz capital ship capable of facing some corvettes. Although incapable of defeating proper warships, Interceptor-class frigates still provided enough firepower to intimidate civilian targets into surrendering.Toward the end of the Clone Wars, the Black Sun crime syndicate used such converted ships.

## Specifications

- **Name:** Interceptor-class frigate
- **Model:** Modified Action VI bulk transport
- **Type:** Frigate
- **Affiliation:** Black Sun
