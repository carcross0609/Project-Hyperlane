# Halifax

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Halifax](https://starwars.fandom.com/wiki/Halifax)

Halifax was an Imperial CR90 corvette owned by Overlord Ghorin, that supplied Emperor Palpatine with food. It was usually escorted by 6 BTL Y-wing starfighters.
