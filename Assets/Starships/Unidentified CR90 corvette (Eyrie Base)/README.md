# Unidentified CR90 corvette (Eyrie Base)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified CR90 corvette (Eyrie Base)](https://starwars.fandom.com/wiki/Unidentified_CR90_corvette_%28Eyrie_Base%29)

In 3 ABY, a CR90 corvette was assigned to the Alliance to Restore the Republic forces attached to Eyrie Base. The corvette participated in an attack on an Imperial supply carrier, as well as the rescue of Stevan Makintay from Imperial captivity.
