# Cerberus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Cerberus](https://starwars.fandom.com/wiki/Cerberus)

The Cerberus was an Imperial Sentinel-class landing craft used to deploy sandtroopers to the surface of Tatooine in search of the stolen data that contained information about the first Death Star.

- **Name:** Cerberus

- **Model:** Sentinel-class landing craft
