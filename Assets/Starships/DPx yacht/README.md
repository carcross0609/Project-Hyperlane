# DPx yacht

**Continuity:** Legends  
**Source:** [DPx yacht](https://starwars.fandom.com/wiki/DPx_yacht)

The DPx yacht was a 12-meter, "top of the line" yacht from Uulshos Manufacturing. A popular variant of the ship was the long-range scout ship called the Deep-X Explorer.

## Specifications

- **Name:** DPx yacht
- **Manufacturer:** Uulshos Manufacturing
- **Type:** Luxury yacht
- **Length:** 12 meters
- **Role:** Luxury vessel
