# Ganoidian tri-deck cruiser

**Continuity:** Canon  
**Source:** [Ganoidian tri-deck cruiser](https://starwars.fandom.com/wiki/Ganoidian_tri-deck_cruiser)

A Ganoidian tri-deck cruiser, also referred to as a Ganoidian cruiser, was a type of yacht. It was described as being spare in design, unlike a luxury craft, made up of hard angles and flat surfaces. New Republic Senator Tolwar Wartol owned a Ganoidian tri-deck cruiser which he used to travel from Chandrila to Nakadia when the Galactic Senate moved there.
