# Stormhawk

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Stormhawk (Victory-class)](https://starwars.fandom.com/wiki/Stormhawk_%28Victory-class%29)

The Stormhawk was a Victory-class Star Destroyer that served as part of Task Force Vengeance. It took part in the Evacuation of Gelgelar and stayed there to guard the station. Later the Rebel Alliance destroyed it in the attack on the Gelgelar system.

## Specifications

- **Name:** Stormhawk
- **Line:** Star Destroyers
- **Model:** Victory-class Star Destroyer
- **Type:** Star Destroyer
- **Length:** 900 meters
- **Engine:** Alderaan Royal Engineers LF9 ion engines
- **Destroyed:** 3 ABY
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:** Task Force Vengeance
