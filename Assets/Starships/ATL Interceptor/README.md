# ATL Interceptor

**Continuity:** Legends  
**Source:** [ATL Interceptor](https://starwars.fandom.com/wiki/ATL_Interceptor)

The ATL (Air-to-Land) Interceptor was a starfighter developed by the Incom Corporation prior to the Galactic Civil War. It was the predecessor of the New Republic Defender starfighter.

## Specifications

- **Name:** ATL Interceptor
- **Manufacturer:** Incom Corporation
- **Model:** ATL (Air-to-Land) Interceptor
- **Type:** Starfighter
- **Armament:** Laser cannons
- **Affiliation:** Fromm Gang
