# Celador Sash

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Celador Sash](https://starwars.fandom.com/wiki/Celador_Sash)

The Celador Sash was a twin-hulled freighter donated to the New Jedi Order. The parents of its original owner were once saved by Obi-Wan Kenobi and in gratitude the ship was gifted to the Academy some time before 12 ABY. Although it was outdated by that time, it was kept in a good state of repairs. It was equipped with a modified navicomputer that included a 3D holomap.

## Specifications

- **Name:** Celador Sash
- **Width:** Double-hulled
- **Crew:** 2
- **Role:** Transport
- **Affiliation:** New Jedi Order
- **Captains:** Kyp Durron
