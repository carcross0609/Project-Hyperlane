# Betar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Betar](https://starwars.fandom.com/wiki/Betar)

Betar was a BFF-1 bulk freighter in service to the Galactic Empire. It was scheduled to rendezvous with the Imperial-class Star Destroyer Warrior, carrying a cargo of war matériel. Two Y-wings, however, disabled it. Then Rebel pilot Halley Kadorto destroyed the freighter afterward to prevent the weapons being used for any future battles.
