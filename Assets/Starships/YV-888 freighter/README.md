# YV-888 freighter

**Continuity:** Legends  
**Source:** [YV-888 freighter](https://starwars.fandom.com/wiki/YV-888_freighter)

The YV-888 freighter was a Corellian Engineering Corporation light freighter similar to the earlier YV-666 light freighter. It had a blocky hull and port and starboard maneuvering fins.
