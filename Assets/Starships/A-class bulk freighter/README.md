# A-class bulk freighter

**Continuity:** Legends  
**Source:** [A-class bulk freighter](https://starwars.fandom.com/wiki/A-class_bulk_freighter)

The A-class bulk freighter was a type of container ship that gained popularity among terraforming expeditions shortly before the Galactic Civil War. It could also be referred to as an A-class bulk freighter.

## Specifications

- **Name:** A-class bulk freighter
- **Type:** Freighter
- **Capacity:** 160,000 metric tons
- **Consumables:** Capable of carrying enough for six months
- **Role:** Transport ship
