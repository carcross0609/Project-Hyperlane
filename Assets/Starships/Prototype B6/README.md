# Prototype B6

**Continuity:** Canon  
**Source:** [Prototype B6](https://starwars.fandom.com/wiki/Prototype_B6)

Prototype B6, also known as the Blade Wing, the Bevel Wing and Hera Syndulla's B-wing, was a prototype B-wing heavy assault starfighter designed and built by the Mon Calamari engineer Quarrie on the planet Shantipole as a part of Project Shantipole.
