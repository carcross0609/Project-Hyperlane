# Pursuer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Pursuer](https://starwars.fandom.com/wiki/Pursuer)

The Pursuer was an Imperial I-class Star Destroyer that was in service to the Imperial Navy of the Galactic Empire. The Pursuer became the headquarters of the Empire's 204th Imperial Fighter Wing, and assisted the fighter wing in a number of operations. The Star Destroyer earned its name as a result of a chase through the Redspace Reefs.
