# Seinar T5D

**Continuity:** Legends  
**Source:** [Seinar T5D](https://starwars.fandom.com/wiki/Seinar_T5D)

Seinar T5D was a civilian Delta-class DX-9 stormtrooper transport that passed an Imperial customs checkpoint. A TIE Interceptor was then launched and inspected to find workers in the cargo.
