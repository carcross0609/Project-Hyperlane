# Black 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Black 3](https://starwars.fandom.com/wiki/Black_3)

Black 3 was a TIE fighter assigned to Black Squadron. The starfighter was flown by TIE pilot DS-61-3, nicknamed "Backstabber," and the craft was stationed aboard the first Death Star.
