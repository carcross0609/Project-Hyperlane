# Malachite Scent

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Malachite Scent](https://starwars.fandom.com/wiki/Malachite_Scent)

The Malachite Scent was a royal Shistavanen star cruiser that was lost along the Anoat trade corridor shortly before the fall of the Galactic Republic in 19 BBY. The notorious space pirate Clabburn the Elder made off with the vast treasures found on board the ship, which was his final raid before disappearing for good.
