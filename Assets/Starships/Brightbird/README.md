# Brightbird

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Brightbird](https://starwars.fandom.com/wiki/Brightbird)

The Brightbird was a minicruiser that was the starship of pilot Sky Graf. In 384 BBY, it was built offworld but finished on Thelj. The Brightbird eventually became a personal cruiser for some time and then became a warship of the Nihil marauders. The vessel later came to be owned by San Tekka family member Cair San Tekka, who refurbished the Brightbird. San Tekka additionally registered the vessel with the Nihil as the Blood Vulture, acting as a smuggler.
