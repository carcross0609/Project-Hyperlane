# Vrexlir

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vrexlir](https://starwars.fandom.com/wiki/Vrexlir)

Vrexlir was a Xiytiar-class heavy transport delivering sensors to Bretie Facility as part of the TIE Experimental Project during the Galactic Civil War, shortly before Imperial Grand Admiral Demetrius Zaarin's attempted coup. It was accompanied by its sister ship, the Dandi.
