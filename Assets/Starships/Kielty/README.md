# Kielty

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kielty](https://starwars.fandom.com/wiki/Kielty)

The Kielty was a pair of Rebel BFF-1 bulk freighters that received cargo from the new Alliance members, the Habassa, who delievered it with freighters called Starmover.
