# Swift Liberty

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Swift Liberty](https://starwars.fandom.com/wiki/Swift_Liberty)

Swift Liberty was a New Republic Victory II-class Star Destroyer commanded by Admiral Areta Bell and was often paired with the Imperial II-class Star Destroyer Moonshadow. Lieutenant Cyslo was the helmsman for the Swift Liberty, while Commander Tal'kina served as the sensor officer.

## Specifications

- **Name:** Swift Liberty
- **Model:** Victory II-class Star Destroyer
- **Affiliation:** New Republic
- **Captains:** Admiral Areta Bell
