# Spartzen

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Spartzen](https://starwars.fandom.com/wiki/Spartzen)

Spartzen was a CR90 Corvette employed by the Rebels as part of an assault force attacking an Imperial Frigate Laantis while it was receiving a new Hyperdrive engine from the freighter Rasvin. The corvette, along with the rest of the Rebels was destroyed in the battle.
