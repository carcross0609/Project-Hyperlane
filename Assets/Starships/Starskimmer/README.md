# Starskimmer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Starskimmer](https://starwars.fandom.com/wiki/Starskimmer)

The Starskimmer was the starship of the bounty hunter Nakano Lash, who led a crew of other hunters. The ship included a large room with a holoprojector at its center, which Lash would use for briefing before missions.

## Specifications

- **Name:** Starskimmer
- **Affiliation:** Nakano Lash's crew
- **Owners:** Nakano Lash
