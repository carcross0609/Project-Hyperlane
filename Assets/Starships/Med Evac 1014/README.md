# Med Evac 1014

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Med Evac 1014](https://starwars.fandom.com/wiki/Med_Evac_1014)

The Med Evac 1014 was a Galactic Alliance med sprinter in use during the Second Battle of Fondor. Jacen Solo appropriated this ship in order to rescue Tahiri Veila from the Bloodfin.
