# SkyWind III

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [SkyWind III](https://starwars.fandom.com/wiki/SkyWind_III)

The SkyWind III was an Alderaanian diplomatic vessel that operated during the Clone Wars. It was attacked by the Separatist destroyer Starshot, in an attempt to capture the SkyWind III passenger, Ambassador Lerron.
