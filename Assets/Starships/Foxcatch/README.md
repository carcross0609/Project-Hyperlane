# Foxcatch

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Foxcatch](https://starwars.fandom.com/wiki/Foxcatch)

The Foxcatch was a heavily modified Lambda-class T-4a shuttle owned by Jodo Kast. Its tail was emblazoned with Kast's personal emblem.

- **Name:** Foxcatch
- **Type:** Lambda-class T-4a shuttle

  - Incom 4L4 fusial thrust engine (6)
