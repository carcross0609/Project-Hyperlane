# KDY security cruiser

**Continuity:** Legends  
**Source:** [KDY security cruiser](https://starwars.fandom.com/wiki/KDY_security_cruiser)

The KDY security cruiser was the main enforcement vessel of the Kuat Drive Yards corporate-security starfleet during the era of the Galactic Civil War. In 4 ABY, around the time of the Battle of Endor, the KDY security cruiser, under the command of Kuat Drive Yards chief of security Kodir of Kuhlvult, pursued the bounty hunter vessel Hound's Tooth into the Oranessan system.
