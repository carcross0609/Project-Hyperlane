# Tallanx-class stealth fighter

**Continuity:** Legends  
**Source:** [Tallanx-class stealth fighter](https://starwars.fandom.com/wiki/Tallanx-class_stealth_fighter)

The Tallanx-class stealth fighter was a type of starfighter that saw regular service during the Galactic Civil War. It was involved in fighting on Ord Gimmel. The Tallanx-class was fast and agile but very lightly armed and designed strictly for swift sneak attacks using its stealth systems to ambush its prey.
