# Marauder

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Marauder (Firespray-31-class)](https://starwars.fandom.com/wiki/Marauder_%28Firespray-31-class%29)

Marauder was a Firespray-31-class patrol and attack craft with a red and white color scheme. At one point it was accompanied by a Z-95-AF4 Headhunter painted in similar livery.

## Specifications

- **Name:** Marauder
- **Manufacturer:** Kuat Systems Engineering
- **Model:** Firespray-31-class patrol and attack craft
- **Type:** Pursuit vessel
