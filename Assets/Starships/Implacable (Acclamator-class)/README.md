# Implacable

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Implacable (Acclamator-class)](https://starwars.fandom.com/wiki/Implacable_%28Acclamator-class%29)

The Implacable was an Acclamator-class transgalactic military assault ship that was part of the Republic Navy during the Clone Wars, which lasted from 22 BBY to 19 BBY and was fought by the Galactic Republic and Separatist Alliance. The Implacable was equipped with sublight engines and a deflector shield generator.
