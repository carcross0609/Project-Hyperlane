# CSS-1 Corellian Star Shuttle

**Continuity:** Legends  
**Source:** [CSS-1 Corellian Star Shuttle/Legends](https://starwars.fandom.com/wiki/CSS-1_Corellian_Star_Shuttle/Legends)

The CSS-1 Corellian Star Shuttle, also known as the Republic shuttle, was a starship designed to carry a large number of ambassadors on missions throughout the galaxy.

## Specifications

- **Name:** CSS-1 Corellian Star Shuttle
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Shuttle
- **Length:** 80 meters
- **Hyperdrive:** Class 1.5 (backup: Class 12)
- **Armament:** None standard, can be refitted with various configurations
- **Complement:** Varies, based on modular configuration
- **Crew:** 8
- **Passengers:** 200
- **Capacity:** 900 metric tons
- **Consumables:** 3 years
- **Role:**
  - Shuttle
  - Diplomatic ship
  - Transport
  - Corvette (refit)
  - Cruiser
  - Armored freighter (Rebellion era)
- **Affiliation:**
  - Galactic Republic
  - Private individuals
