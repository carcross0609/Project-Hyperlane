# Jaesa Willsaam's corvette

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jaesa Willsaam's corvette](https://starwars.fandom.com/wiki/Jaesa_Willsaam%27s_corvette)

Jedi Padawan Jaesa Willsaam flew a corvette that was similar to the Defender-class light corvette before joining Darth Baras's apprentice. While visually identical to the Defender-class, her ship was twice as large and featured a radically different layout.

## Specifications

- **Name:** Jaesa Willsaam's corvette
- **Model:** Similar to the Defender-class light corvette
- **Type:** Light corvette
- **Engine:** 2
- **Hyperdrive:** Equipped
- **Armament:** Dual turbolaser cannons
- **Role:** Corvette starfighter
- **Affiliation:** Jedi Order
- **Captains:** Jaesa Willsaam
