# Command shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Command shuttle](https://starwars.fandom.com/wiki/Command_shuttle)

A command shuttle was part of the complement of Lambda-class T-4a shuttles assigned to the Victory-class Star Destroyer Subjugator. It was readied on the order of Captain Kolaff to transport him to safety, but was commandeered by Walex Blissex and a team of Alliance to Restore the Republic agents to escape the starship.
