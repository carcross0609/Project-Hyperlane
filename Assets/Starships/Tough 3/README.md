# Tough 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tough 3](https://starwars.fandom.com/wiki/Tough_3)

Tough 3 was a Delta-class JV-7 escort shuttle serving the Alliance Fleet. The ship was part of Tough group which participated in the Skirmish at Outpost D-34. Tough 3, along with Tough 1 and 2 following Ravtin group, attempted to stop Imperial forces from capturing Onece 3 of Onece group which carried their fellow rebels. Both shuttle groups were unsuccessful and were all destroyed in the process.
