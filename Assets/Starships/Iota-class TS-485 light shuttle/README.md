# Iota-class TS-485 light shuttle

**Continuity:** Canon  
**Source:** [Iota-class TS-485 light shuttle](https://starwars.fandom.com/wiki/Iota-class_TS-485_light_shuttle)

The Iota-class TS-485 light shuttle, also simply known as the Imperial light shuttle, was an unarmed light shuttle used by the Imperial Navy during the reign of the Galactic Empire. It was considered a compact version of the Lambda shuttle. It was intended for short trips, although it did have a hyperdrive for when the need arose. Tala Durith, an Imperial officer-turned-Hidden Path member, used a shuttle of the type.
