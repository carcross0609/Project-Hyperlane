# Exemplar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Exemplar (Harrower-class)](https://starwars.fandom.com/wiki/Exemplar_%28Harrower-class%29)

The Exemplar was a Harrower-class dreadnought and the flagship of the Sith Lord Darth Gravus at the Second battle of Leritor. It was destroyed by the Ascendant Spear.

- **Name:** Exemplar

- **Model:** Harrower-class dreadnought
