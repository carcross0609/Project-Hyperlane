# Scupper

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Scupper](https://starwars.fandom.com/wiki/Scupper)

The Scupper was a pleasure yacht owned by the smuggler and prospector Radicaz Dobbs during the High Republic Era. Deliberately kept in a state of apparent disrepair, the Scupper was outfitted with powerful sublight engines and safes for Dobbs to store the Force artifacts he fenced.
