# Venturer-class freighter

**Continuity:** Legends  
**Source:** [Venturer-class freighter](https://starwars.fandom.com/wiki/Venturer-class_freighter)

The Venturer-class freighter was a starship design manufactured by Ckratar Crafts. Barosa Warren's unique craft, the Cannibal, used a Venturer hull combined with a Firespray hull as its own covering.

## Specifications

- **Name:** Venturer-class freighter
- **Manufacturer:** Ckratar Crafts
