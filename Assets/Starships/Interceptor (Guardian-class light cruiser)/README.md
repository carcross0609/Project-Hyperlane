# Interceptor (Guardian-class light cruiser)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Interceptor (Guardian-class light cruiser)](https://starwars.fandom.com/wiki/Interceptor_%28Guardian-class_light_cruiser%29)

The Interceptor was an Imperial Customs Guardian-class light cruiser that had been assigned to patrol the Elin Roe system at some point during the Galactic Civil War. It was commanded by Captain Hallyn Phlynne.
