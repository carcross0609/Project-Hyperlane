# Lusankya

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Lusankya/Legends](https://starwars.fandom.com/wiki/Lusankya/Legends)

The Lusankya (), originally known as Executor II, was an Executor-class Star Dreadnought built by Kuat Drive Yards, as the sister ship to the Executor, which was built at Fondor.

## Specifications

- **Name:** Lusankya
- **Manufacturer:** Kuat Drive Yards
- **Model:** Executor-class Star Dreadnought
- **Length:** 19,000 meters
- **Armament:** Some heavy turbolaser batteries exchanged for more point-defense guns.

- **Role:**
