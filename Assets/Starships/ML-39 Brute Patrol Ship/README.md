# ML-39 Brute Patrol Ship

**Continuity:** Legends  
**Source:** [ML-39 Brute Patrol Ship](https://starwars.fandom.com/wiki/ML-39_Brute_Patrol_Ship)

The ML-39 Brute Patrol Ship was a class of minelayer used during the era of the Great Galactic War onwards. The vessel was seen in hands of many through the wars.

- **Role:** Minelayer
