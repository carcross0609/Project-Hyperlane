# Z-Jumimi

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Z-Jumimi](https://starwars.fandom.com/wiki/Z-Jumimi)

The Jumimi was a Carrack-class light cruiser used by Grand Admiral Demetrius Zaarin. The Jumimi was part of an attempt to destroy the Deep Space Manufacturing Facility ZA-13. However, the cruiser was destroyed by Tan Maarek Stele.

## Specifications

- **Name:** Z-Jumimi
- **Manufacturer:** Damorian Manufacturing Corporation
- **Model:** Carrack-class light cruiser
- **Type:** Frigate
- **Length:** 350 meters
- **Width:** 72 meters
- **Height:** 75 meters
- **Affiliation:** Zaarin coup forces
