# Deep

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Deep](https://starwars.fandom.com/wiki/Deep)

Deep was a CR90 corvette belonging to the Rebel Alliance. The corvette brought engines to the stranded EF76 Nebulon-B escort frigate Viper in the Delfii system.
