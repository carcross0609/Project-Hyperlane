# Solar sailer

**Continuity:** Canon  
**Source:** [Solar sailer](https://starwars.fandom.com/wiki/Solar_sailer)

A solar sailer was a class of starship yacht that used sails to absorb stray space energies as a source of almost limitless fuel. During the High Republic Era, Hutt Clan Dreadcruisers were solar sailers. Count Dooku owned a Punworcca 116-class interstellar sloop during the Clone Wars that he had modified to include a solar sail.
