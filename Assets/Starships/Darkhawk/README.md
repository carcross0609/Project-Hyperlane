# Darkhawk

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Darkhawk](https://starwars.fandom.com/wiki/Darkhawk)

The Darkhawk was a Separatist freighter that had been refitted to be used by the 1st Legion, an elite Imperial stormtrooper unit that served as the personal forces of the Sith Lord Darth Vader.

## Specifications

- **Name:** Darkhawk
- **Type:** Freighter
- **Role:** Transport
- **Affiliation:**
  - Confederacy of Independent Systems
  - Galactic Empire
  -   First Legion
- **Captains:** Darth Vader
