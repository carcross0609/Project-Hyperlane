# Silver-class light starship

**Continuity:** Legends  
**Source:** [Silver-class light starship](https://starwars.fandom.com/wiki/Silver-class_light_starship)

The Silver-class light starship was produced by Haor Chall Engineering. Zonama Sekot originally used the type-seven engines from this ship to power its seed-ships, before it left known space and had to improvise.

- **Name:** Silver-class light starship
