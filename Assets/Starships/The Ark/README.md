# The Ark

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [The Ark](https://starwars.fandom.com/wiki/The_Ark)

The Ark was a massive starship created by the Hutt Cartel. Commissioned by Toborro the Hutt as a way to escape the volatile atmosphere of the planet Makeb while carrying a huge supply of the recently discovered power source called Isotope-5.

## Specifications

- **Name:** The Ark
- **Manufacturer:** Hutt Cartel
- **Passengers:** Millions
- **Commission:** c. 3638 BBY
- **Affiliation:**
  - Hutt Cartel
  - Galactic Republic
- **Owners:** Toborro
