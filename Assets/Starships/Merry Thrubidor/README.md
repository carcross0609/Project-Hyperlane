# Merry Thrubidor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Merry Thrubidor](https://starwars.fandom.com/wiki/Merry_Thrubidor)

The Merry Thrubidor was a 720 light freighter manufactured by Ghtroc Industries. It was used by Alliance to Restore the Republic operatives to retrieve stolen cargo from pirates on the planet Prexiar.
