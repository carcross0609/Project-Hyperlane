# Rampaea Horizon

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Rampaea Horizon](https://starwars.fandom.com/wiki/Rampaea_Horizon)

The Rampaea Horizon was a bulk freighter that Tivoche Bilure worked on to get passage off of Corellia. It visited Venustria, Ulness Prime, Great Aglamerti, Kessel, and Vandor.

## Specifications

- **Name:** Rampaea Horizon
- **Type:** Bulk freighter
