# Warlover

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Warlover](https://starwars.fandom.com/wiki/Warlover)

The Warlover was an Imperial Dreadnaught-class heavy cruiser that attempted to destroy a cargo supply cache in the Esyram system that the Mon Calamari Star Cruiser Valorous was attempting to retrieve.
