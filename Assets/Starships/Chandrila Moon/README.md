# Chandrila Moon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Chandrila Moon](https://starwars.fandom.com/wiki/Chandrila_Moon)

The Chandrila Moon was a Marketta-class shuttle carried aboard the Protector in 25 ABY. Leia Organa Solo rode it from the Protector to the Bastion customs station to meet Gilad Pellaeon.
