# Tantive III

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tantive III (Rebel Alliance)](https://starwars.fandom.com/wiki/Tantive_III_%28Rebel_Alliance%29)

Tantive III was a CR90 corvette used by the Rebel Alliance during the Galactic Civil War. When Biggs Darklighter's X-wing broke down while carrying the recently intercepted schematics for the Death Star, the Tantive III, along with the Tantive I and the Tantive II, was sent to escort Lambda-class T-4a shuttles which would restore the X-wing's power generator.

## Specifications

- **Name:** Tantive III
- **Model:** CR90 corvette
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Alliance Fleet
