# Aris Brace

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Aris Brace](https://starwars.fandom.com/wiki/Aris_Brace)

Aris Brace was an independently owned bulk freighter. The ship held the Corellian Merchants' Guild record for continuous cargo runs over five parsecs.
