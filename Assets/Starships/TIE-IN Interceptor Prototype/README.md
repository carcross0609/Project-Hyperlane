# TIE/IN Interceptor Prototype

**Continuity:** Canon  
**Source:** [TIE/IN Interceptor Prototype](https://starwars.fandom.com/wiki/TIE/IN_Interceptor_Prototype)

The TIE/IN Interceptor Prototype was a prototype TIE/IN interceptor utilized by the Second Sister, an Inquisitor and Jedi hunter of the Galactic Empire's Inquisitorius during the Great Jedi Purge.
