# Warrior

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Warrior (gunship)](https://starwars.fandom.com/wiki/Warrior_%28gunship%29)

The Warrior was the first Warrior-class gunship to be produced under the New Republic's New Class Modernization Program for starships. It was then assigned to the inaugural New Republic Fifth Fleet.
