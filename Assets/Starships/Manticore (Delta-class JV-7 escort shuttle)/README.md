# Manticore

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Manticore (Delta-class JV-7 escort shuttle)](https://starwars.fandom.com/wiki/Manticore_%28Delta-class_JV-7_escort_shuttle%29)

Manticore was an Imperial Delta-class JV-7 escort shuttle in operation during the Galactic Civil War. Along with its sister ship, Griphon, the Manticore was assigned to escort the POW-carrying Dreadnaught VTR-LX to penal station Bundil II. However, both shuttles were destroyed in a Rebel rescue operation that also destroyed VTR-LX.
