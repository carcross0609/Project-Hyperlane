# Squall (shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Squall (shuttle)](https://starwars.fandom.com/wiki/Squall_%28shuttle%29)

The Squall was a combat shuttle that was assigned to the Republic cruiser Maelstrom during the Clone Wars. In 19 BBY, the ARC trooper Mar'ek received a transmission from Supreme Chancellor Palpatine while on the bridge of the Squall, ordering the trooper to execute the contingency directive Order 66.
