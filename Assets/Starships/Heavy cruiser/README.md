# Heavy cruiser

**Continuity:** Canon  
**Source:** [Heavy cruiser](https://starwars.fandom.com/wiki/Heavy_cruiser)

, a Subjugator-class heavy cruiser]] Heavy cruiser was a classification of capital starships that were usually 600 - 1200 meters in length which included vessels such as Subjugator-class heavy cruisers, Marsheem-class heavy cruisers, MC85 Star Cruisers, and Maxima-A-class heavy cruisers The Lioaoin Regime utilized heavy cruisers.
