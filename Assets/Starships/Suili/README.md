# Suili

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Suili](https://starwars.fandom.com/wiki/Suili)

Suili was a C-3 passenger liner which was used for tourism. It was present in the Nezni system where an incident between the Rebel Alliance and the Hurrim took place.

## Specifications

- **Name:** Suili
- **Manufacturer:** Leonore Luxury Liners Incorporated
- **Model:** C-3 passenger liner
- **Type:** Transport
- **Length:** 409 meters
- **Width:** 132 meters
- **Height:** 94 meters
- **Engine:** 6 sublight engine units
- **Hyperdrive:** Equipped
- **Role:** Passenger liner
