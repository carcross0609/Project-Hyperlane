# Needle fighter

**Continuity:** Legends  
**Source:** [Needle fighter](https://starwars.fandom.com/wiki/Needle_fighter)

Needle fighters was a remote controlled starfighter which were fitted with hyperspace rendezvous capabilities produced and used by the Loronar Corporation.

## Specifications

- **Name:** Needle fighter
- **Manufacturer:** Loronar Corporation
- **Type:** Remote controlled Starfighter
- **Length:** ~2.5 meters
- **Width:** ~1 meter
- **Height:** ~1 meter
- **Hdsystem:** equipped
- **Armament:** Laser cannon
- **Affiliation:** Loronar Corporation
