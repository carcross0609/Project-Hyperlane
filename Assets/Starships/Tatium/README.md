# Tatium

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tatium](https://starwars.fandom.com/wiki/Tatium)

Tatium was a Lambda-class T-4a shuttle assigned to the Victory-class Star Destroyer Subjugator. Lira Wessex used it to flee the Star Destroyer before its self-destruction.
