# Kizbon's Box

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kizbon's Box](https://starwars.fandom.com/wiki/Kizbon%27s_Box)

Kizbon's Box was a Helix-class light interceptor operating during the Galactic Civil War. It was the target of an ambush near Darknon Station by a pirate band led by Larken. However, the three vessels under his command were destroyed by the Crotok pilot.

## Specifications

- **Name:** Kizbon's Box
- **Manufacturer:** Arakyd Industries
- **Model:** Helix-class light interceptor
- **Owners:** Pilot
