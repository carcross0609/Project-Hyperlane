# YV-865 Aurore-class freighter

**Continuity:** Canon  
**Source:** [YV-865 Aurore-class freighter](https://starwars.fandom.com/wiki/YV-865_Aurore-class_freighter)

The YV-865 Aurore-class freighter was a highly durable model of freighter built by the Corellian Engineering Corporation. Due to their excessive use by the Zygerrian Slave Empire, they were often nicknamed Zygerrian slave ships.
