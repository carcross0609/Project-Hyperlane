# Geedon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Geedon](https://starwars.fandom.com/wiki/Geedon)

Geedon was a convoy of seven CR90 corvettes containing food for the Galactic Empire. The entire convoy was destroyed by X-wings and Y-wings stolen from Overlord Ghorin's arsenal before the Remoh could arrive to assist it.
