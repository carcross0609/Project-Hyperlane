# Z-Rok

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Z-Rok](https://starwars.fandom.com/wiki/Z-Rok)

flies a TIE/ad starfighter against an Assassin-class corvette from Rok group.]] Z-Rok was a group of four Assassin-class corvettes belonging to Grand Admiral Zaarin. They were part of the second attack on To-phalion Base which had the CR90 corvette Vorknkx inside. The corvettes managed to destroy the asteroid defenses which were disabled by Assault Gunboats but all four corvettes were destroyed by Tan Maarek Stele.
