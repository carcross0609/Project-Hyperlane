# Quasar Fire-class cruiser-carrier

**Continuity:** Legends  
**Source:** [Quasar Fire-class cruiser-carrier/Legends](https://starwars.fandom.com/wiki/Quasar_Fire-class_cruiser-carrier/Legends)

The Quasar Fire-class cruiser-carrier, also referred to as the Quasar Fire-class bulk cruiser or Alliance escort carrier, was a modular starship typically used for freight.

## Specifications

- **Name:** Quasar Fire-class cruiser-carrier
- **Manufacturer:** SoroSuub Corporation
- **Model:** Quasar Fire-class bulk cruiser
- **Type:** Bulk cruiser
- **Length:** 350 meters
- **Hyperdrive:**
  - Class 2 (primary)
  - Class 12 (backup)
- **Armament:**
  - 2 light turbolaser batteries
  - 2 medium tractor beam projectors
- **Complement:**
  - 48 starfighters
  - Shuttles
  - Utility/landing craft
- **Crew:** 250
- **Skeleton:** 100
- **Consumables:** One year
- **Role:**
  - Freighter
  - Starfighter carrier (Rebel use)
- **Affiliation:**
  - Virgillian Free Alignment
  - Sullustan Home Guard
  - Alliance to Restore the Republic
  - New Republic
  - Zsinj's Empire
  - Fringe groups
