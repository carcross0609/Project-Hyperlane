# Garfin

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Garfin](https://starwars.fandom.com/wiki/Garfin)

The Garfin was a New Republic warship sent to aid General Garm Bel Iblis, Booster Terrik, and the Errant Venture at Yaga Minor in an attempt to steal a copy of the Caamas Document.
