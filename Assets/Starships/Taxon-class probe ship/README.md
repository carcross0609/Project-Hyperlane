# Taxon-class probe ship

**Continuity:** Legends  
**Source:** [Taxon-class probe ship](https://starwars.fandom.com/wiki/Taxon-class_probe_ship)

The Taxon-class probe ship was a utility capital ship used by the Galactic Republic Judicial Forces around 29 BBY. The ship was one of four that made up Raith Sienar's expeditionary naval squadron which went to Zonama Sekot to aqcuire Zekotan ship-technology.

## Specifications

- **Name:** Taxon-class probe ship
- **Type:** Capital ship
- **Affiliation:**
  - Galactic Republic
  -   Judicial Forces
  -   Republic Outland Regions Security Force
