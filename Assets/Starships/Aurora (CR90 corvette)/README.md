# Aurora

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Aurora (CR90 corvette)](https://starwars.fandom.com/wiki/Aurora_%28CR90_corvette%29)

Aurora was a CR90 corvette that was used by the Cularin Militia during the Clone Wars. It participated in the Battle of Cularin.

- **Name:** Aurora
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** CR series
- **Model:** CR90 corvette
- **Type:** Corvette
- **Length:** 150 meters
- **Width:** 48.6 meters
- **Affiliation:** Cularin Militia
