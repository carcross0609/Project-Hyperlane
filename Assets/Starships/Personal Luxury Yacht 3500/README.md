# Personal Luxury Yacht 3500

**Continuity:** Legends  
**Source:** [Personal Luxury Yacht 3500](https://starwars.fandom.com/wiki/Personal_Luxury_Yacht_3500)

The Personal Luxury Yacht 3500 or PLY-3500 was a type of luxury yacht manufactured by SoroSuub Corporation. Holostar Javul Charn's Nova's Heart was one such vessel.
