# Arleen

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Arleen](https://starwars.fandom.com/wiki/Arleen)

The Arleen was a pleasure yacht that was in service by 3 BBY. It shared its name with the Arleen system and the Arleen Loop hyperlane. The Arleen made year-long tours from the Oseon system to the Antipose system celestial body Antipose IX as well as the planet Antipose XII.

## Specifications

- **Name:** Arleen
- **Type:** Yacht
- **Role:** Pleasure vessel
- **Commission:** By 3 BBY
