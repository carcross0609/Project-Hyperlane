# Nihil attack ship

**Continuity:** Canon  
**Source:** [Nihil attack ship](https://starwars.fandom.com/wiki/Nihil_attack_ship)

A Nihil attack ship was a type of ship that was employed by the Nihil marauder organization. In 228 BBY, one such ship attempted to board the Grim Devourer II, but was unsuccessful when the ship jumped to hyperspace.

- **Type:** Starship
