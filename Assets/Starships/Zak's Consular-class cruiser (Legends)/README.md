# Zak's Consular-class cruiser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Zak's Consular-class cruiser/Legends](https://starwars.fandom.com/wiki/Zak%27s_Consular-class_cruiser/Legends)
