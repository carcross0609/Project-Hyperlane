# Load Spider THK 421

**Continuity:** Legends  
**Source:** [Load Spider THK 421](https://starwars.fandom.com/wiki/Load_Spider_THK_421)

The Load Spider THK 421 was a type of cargo shuttle produced by Bespin Motors. It was used extensively during the construction of Cloud City over the planet Bespin.
