# Unidentified Western Reaches Exchange banking ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Western Reaches Exchange banking ship](https://starwars.fandom.com/wiki/Unidentified_Western_Reaches_Exchange_banking_ship)

This banking ship was captained by the Kubaz Banker, Rikard Lovas. It would land at Niima Outpost on Jakku for a few days each cycle to allow the inhabitants to conduct business. It could carry a modestly sized cargo but many transactions were done electronically using credits.

## Specifications

- **Name:** Unidentified Western Reaches Exchange banking ship
- **Type:** Transport
- **Affiliation:** Western Reaches Exchange
- **Captains:** Rikard Lovas
