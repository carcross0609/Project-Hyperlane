# Z-'ceptor

**Continuity:** Legends  
**Source:** [Z-'ceptor](https://starwars.fandom.com/wiki/Z-%27ceptor)

The Z-'ceptor was a type of "Ugly" starfighter that was cobbled together from the salvaged parts of Z-95 Headhunters and TIE Interceptors.
