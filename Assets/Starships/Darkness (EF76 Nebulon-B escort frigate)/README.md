# Darkness (EF76 Nebulon-B escort frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Darkness (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Darkness_%28EF76_Nebulon-B_escort_frigate%29)

The Darkness was an Imperial Nebulon-B frigate that launched an attack on the CR90 corvette Ram's Head and Libra while the Shield X Deflector Shield was being delivered. The attack was thwarted by Keyan Farlander in an X-wing starfighter and a few other Rebel pilots who turned to this starship destroying it.
