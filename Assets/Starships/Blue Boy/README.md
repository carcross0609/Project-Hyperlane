# Blue Boy

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blue Boy](https://starwars.fandom.com/wiki/Blue_Boy)

The Blue Boy was a Ghtroc Industries 720 light freighter. Owned and operated by Mair Koda, the Blue Boy was used to transport goods throughout the Zuni cluster.
