# Wayward Current

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Wayward Current](https://starwars.fandom.com/wiki/Wayward_Current)

The Wayward Current was a transport barge that at some point undertook a week journey from the Mooshie Cluster to Canto Bight captained by Tuuma the Hutt.
