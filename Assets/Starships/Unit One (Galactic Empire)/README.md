# Unit One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unit One (Galactic Empire)](https://starwars.fandom.com/wiki/Unit_One_%28Galactic_Empire%29)

Unit One was an armored vehicle using by a contingent in the Galactic Empire's Imperial Army led by Lieutenant Krole.

## Specifications

- **Name:** Unit One
- **Model:** Imperial armored vehicle
- **Type:** Repulsorcraft
- **Armament:** 1 mounted blaster cannon
- **Crew:** 1 driver, 1 gunner
- **Passengers:** At least 3
- **Role:** Transport
- **Affiliation:**
  - Galactic Empire
  -   Krole's contingent
