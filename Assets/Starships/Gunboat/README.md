# Gunboat

**Continuity:** Canon  
**Source:** [Gunboat](https://starwars.fandom.com/wiki/Gunboat)

A gunboat was a type of starship used by the Galactic Empire. The assault gunboat and the escort gunboat were classes of gunboat, An Imperial battle group located in the Ilum system utilized multiple gunboats.
