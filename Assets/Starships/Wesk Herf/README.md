# Wesk Herf

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wesk Herf](https://starwars.fandom.com/wiki/Wesk_Herf)

The two glyphs Wesk Herf (the letters W. H. in the Aurebesh) represented the name of a spaceship, apparently a capital ship in the Imperial Navy of the Fel Empire.
