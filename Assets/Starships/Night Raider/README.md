# Night Raider

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Night Raider](https://starwars.fandom.com/wiki/Night_Raider)

The Night Raider was a Ghtroc Industries 720 light freighter captained and presumably owned by a Barabel smuggler named Yarrku. It was destroyed in space battle by Kinnin Vo-Shay.

## Specifications

- **Name:** Night Raider
- **Manufacturer:** Ghtroc Industries
- **Model:** 720 light freighter
- **Type:** Freighter
- **Role:** Smuggling
- **Owners:** Yarrku
- **Captains:** Yarrku
