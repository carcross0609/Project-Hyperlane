# Watcher (starship)

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Watcher (starship)](https://starwars.fandom.com/wiki/Watcher_%28starship%29)

The Watcher was an Imperial Customs Frigate under the command of the Imperial Star Destroyer Revenge. It once took the Rebel ship Arion Star on board for inspection, but allowed it depart when no contraband was found on board.
