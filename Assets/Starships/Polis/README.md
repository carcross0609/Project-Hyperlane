# Polis

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Polis](https://starwars.fandom.com/wiki/Polis)

Polis was a BFF-1 bulk freighter the served in the Imperial Navy. It was part of the Imperial II-class Star Destroyer Corrupters resupply convoy which was lead by the Nebulon-B Frigate Monitor to the Corrupter in the Mev system. The ship was then attacked by Rebel raiders and was destroyed.

- **Type:** Medium-sized freighter
