# Resolve

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Resolve (New Republic Star Destroyer)](https://starwars.fandom.com/wiki/Resolve_%28New_Republic_Star_Destroyer%29)

## Specifications

- **Name:** Resolve
- **Type:** Star Destroyer or star cruiser
- **Armament:** None
- **Othersystems:** Multiple deflector shield systems.
- **Navy:** New Republic Fifth Fleet
- **Captains:** Commander Syub Snunb
