# Jes' courier ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jes' courier ship](https://starwars.fandom.com/wiki/Jes%27_courier_ship)

Jes' courier ship served as Jes' personal courier whle she served with the Alliance to Restore the Republic during the Galactic Civil War. As most courier ships it was built for speed, not for comfortable voyage.
