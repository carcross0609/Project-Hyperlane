# Starheart

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Starheart](https://starwars.fandom.com/wiki/Starheart)

The Starheart was a gunship that served as the command ship of the New Republic's Halo Squadron. The Starheart intercepted a freighter carrying Dathan, Miramir, and Rey as it was chased by forces of the Sith Eternal.

## Specifications

- **Name:** Starheart
- **Type:** Gunship
- **Armament:** Tractor beam projector
- **Role:** Command ship
- **Affiliation:**

  -   New Republic Defense Force
- **Navy:** New Republic Defense Fleet
- **Fleet:** Halo Squadron
