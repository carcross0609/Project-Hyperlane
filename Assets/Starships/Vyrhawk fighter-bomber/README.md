# Vyrhawk fighter-bomber

**Continuity:** Legends  
**Source:** [Vyrhawk fighter-bomber](https://starwars.fandom.com/wiki/Vyrhawk_fighter-bomber)

Vyrhawk fighter-bombers were a class of starfighter used by the Mandalorian Protectors around 44 ABY. The Mandalorians deployed the fighter-bomber class vessels during their siege of the New Jedi Temple.
