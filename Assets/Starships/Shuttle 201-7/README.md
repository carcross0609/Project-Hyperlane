# Shuttle 201-7

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shuttle 201-7](https://starwars.fandom.com/wiki/Shuttle_201-7)

Shuttle 201-7 was the designation of a Lambda-class T-4a shuttle. At some point, it was stolen by the Rebel Alliance and used on a mission to Martle Station.
