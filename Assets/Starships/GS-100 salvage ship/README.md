# GS-100 salvage ship

**Continuity:** Canon  
**Source:** [GS-100 salvage ship](https://starwars.fandom.com/wiki/GS-100_salvage_ship)

The GS-100 salvage ship was a salvage freighter, the ship design included multiple arms that could pick up debris from space battles. The scavenger Gha Nachkt owned one such ship, the Vulture's Claw, during the Clone Wars. In 3 ABY, a GS-100 was approved to depart from Hauler's Keep in the Khepi system.

- **Name:** GS-100 salvage ship
- **Manufacturer:** Gallofree Yards, Inc.
- **Model:** GS-100 salvage ship

- **Max Speed:** 400 kph (248 mph)

- **Armament:**

  - Dual laser cannon
- **Crew:** Pilot
- **Capacity:** 140 metric tons
- **Cargohandling:** Multiple arms for handling salvaged material
