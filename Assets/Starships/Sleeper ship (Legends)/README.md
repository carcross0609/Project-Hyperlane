# Sleeper ship

**Continuity:** Legends  
**Source:** [Sleeper ship/Legends](https://starwars.fandom.com/wiki/Sleeper_ship/Legends)

A sleeper ship was an interstellar vessel capable of achieving faster than light travel, via rudimentary dimensional drive technology, while its inhabitants were kept in a state of suspended animation. Typical speeds made travel between distant stars last decades or centuries, well beyond a normal Human lifespan.
