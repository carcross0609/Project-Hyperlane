# Immobilizer 418 Interdictor-class Heavy Cruiser

**Continuity:** Legends  
**Source:** [Immobilizer 418 Interdictor-class Heavy Cruiser](https://starwars.fandom.com/wiki/Immobilizer_418_Interdictor-class_Heavy_Cruiser)

The Immobilizer 418 Interdictor-class Heavy Cruiser, also known simply as the Interdictor-class heavy cruiser, Interdictor-class medium frigate, Interdictor Dreadnaught, or simply the Interdictor, and sometimes colloqually as the Drag Ship, was a 600-meter-long cruiser built on the standard Vindicator-class heavy cruiser hull (later used for the Enforcer-class picket cruiser).
