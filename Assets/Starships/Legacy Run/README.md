# Legacy Run

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Legacy Run](https://starwars.fandom.com/wiki/Legacy_Run)

The Legacy Run was a Class A modular freight transport that was destroyed in an event known as the Great Hyperspace Disaster. Fragments of its debris were shot through hyperspace and traveled to points across the galaxy.

## Specifications

- **Name:** Legacy Run
- **Manufacturer:** Kaniff Yards
- **Model:** Class A modular freight transport
- **Type:** Freighter
- **Hdsystem:** Equipped
- **Passengers:** 9,000
- **Destroyed:** 232 BBY
- **Affiliation:** Byne Guild
- **Captains:** Hedda Casset
