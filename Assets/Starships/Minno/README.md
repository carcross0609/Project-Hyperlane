# Minno

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Minno](https://starwars.fandom.com/wiki/Minno)

Minno was a Lambda Shuttle belonging to the Rebel Alliance. The shuttle left the MC80 Star Cruiser Cathleen, that was on its way to the remote world of Hoth. The shuttle carrying pilots, jumped into hyperspace for parts unknown.
