# Zaxxovian Special

**Continuity:** Canon  
**Source:** [Zaxxovian Special](https://starwars.fandom.com/wiki/Zaxxovian_Special)

A Zaxxovian Special was a type of starfighter that originated from the Zaxxovia system. The pilot Jarek Yeager had a racer that was a modified Zaxxovian Special.

- **Name:** Zaxxovian Special
