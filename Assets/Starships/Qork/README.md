# Qork

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Qork](https://starwars.fandom.com/wiki/Qork)

Qork was a Nebulon-B2 frigate belonging to the Galactic Empire. Along with the Mist, it delivered supplies to the Imperial-class Star Destroyer Garrett.

## Specifications

- **Name:** Qork
- **Manufacturer:** Kuat Drive Yards
- **Model:** Nebulon-B2 frigate
- **Length:** 253.2 meters
- **Width:** 147.7 meters
- **Height:** 94.3 meters
- **Affiliation:** Galactic Empire
