# HT-2200

**Continuity:** Canon  
**Source:** [HT-2200](https://starwars.fandom.com/wiki/HT-2200)

A HT-2200 was a model of starship that was capable of transporting cargo. In 3 ABY, a HT-2200 carrying volatile cargo traveled to the space station Hauler's Keep located in the Khepi system of Wild Space. A message instructing the station's repair droids to standby to assess the ship was broadcast over the station's speaker system.

## Specifications

- **Name:** HT-2200
- **Role:** Transport cargo
