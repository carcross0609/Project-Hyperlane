# Unidentified freighter class

**Continuity:** Legends  
**Source:** [Unidentified freighter class](https://starwars.fandom.com/wiki/Unidentified_freighter_class)

A class of freighter was widely used in the centuries following the Jedi Civil War that featured three engines, an elongated body, and a brownish hull. It was not uncommon during the time of the Cold War, and later the Galactic War, to see this class of freighter used in combat by third-parties around the galaxy.
