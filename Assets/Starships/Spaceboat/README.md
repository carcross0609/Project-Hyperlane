# Spaceboat

**Continuity:** Legends  
**Source:** [Spaceboat](https://starwars.fandom.com/wiki/Spaceboat)

A spaceboat was an extremely light spacecraft, smaller than even a lighter and generally not hyperspace-capable. Han Solo was able to shoot one down using only a Kell Mark II heavy assault rifle. At least some models were armed.
