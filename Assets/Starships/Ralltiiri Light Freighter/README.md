# Ralltiiri Light Freighter

**Continuity:** Canon  
**Source:** [Ralltiiri Light Freighter](https://starwars.fandom.com/wiki/Ralltiiri_Light_Freighter)

The Ralltiiri Light Freighter was a class of light freighter active during the First Order-Resistance War. At least one Ralltiiri Light Freighter participated in the Battle of Exegol against the Sith Eternal forces as part of the Citizens' Fleet.

## Specifications

- **Name:** Ralltiiri Light Freighter
- **Type:** Light freighter
- **Affiliation:** Citizens' Fleet
