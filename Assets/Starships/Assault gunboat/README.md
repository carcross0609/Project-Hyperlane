# Assault gunboat

**Continuity:** Canon  
**Source:** [Assault gunboat](https://starwars.fandom.com/wiki/Assault_gunboat)

An assault gunboat was a type of gunboat that was used by the naval forces of the Galactic Empire and other parties. Imperial I-class Star Destroyers carried five of this type of gunboat and Death Star's fleet was composed of hundreds of starships, that ranged from dreadnoughts to assault gunboats. The SS-54 assault ship was a class of assault gunboat that was mistakenly registered as a light freighter.
