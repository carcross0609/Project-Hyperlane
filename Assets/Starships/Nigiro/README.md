# Nigiro

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nigiro](https://starwars.fandom.com/wiki/Nigiro)

Nigiro was a BFF-1 bulk freighter that transferred munitions to the Dellalt system, preparing the Operation Strike Fear. It was destroyed by Keyan Farlander and Hamo Blastwell during the defection of Bixby.
