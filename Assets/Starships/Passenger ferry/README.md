# Passenger ferry

**Continuity:** Legends  
**Source:** [Passenger ferry](https://starwars.fandom.com/wiki/Passenger_ferry)

A passenger ferry was a small starship used for passenger transport. During the initial construction of the secret base on Tel III that would become Oracle Base, the quarter compartments were modules taken from passenger ferries and freighters.
