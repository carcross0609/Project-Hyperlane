# Unidentified HCT-2001 Dragonboat-class freighter

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified HCT-2001 Dragonboat-class freighter/Legends](https://starwars.fandom.com/wiki/Unidentified_HCT-2001_Dragonboat-class_freighter/Legends)

An HCT-2001 Dragonboat-class Reugeot 905 freighter was owned by a Quarren male during the Clone Wars. The freighter was stolen by Cad Bane, Moralo Eval, and Obi-Wan Kenobi&mdash;disguised as Rako Hardeen&mdash;during their escape from Coruscant's Republic Judiciary Central Detention Center.
