# Geroon shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Geroon shuttle](https://starwars.fandom.com/wiki/Geroon_shuttle)

A Vagaari shuttle was disguised as a Geroon shuttle during the Aristocra Chaf'orm'bintrano's plot to begin a war against the Vagaari Empire.
