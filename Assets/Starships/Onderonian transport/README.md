# Onderonian transport

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Onderonian transport](https://starwars.fandom.com/wiki/Onderonian_transport)

An Onderonian sarcophagus transport was used to transport the sarcophagi of Amanoa, Freedon Nadd, and Ommin from Onderon to Dxun.

## Specifications

- **Name:** Onderonian transport
- **Type:** Starship
- **Role:** Transporting sarcophagi
