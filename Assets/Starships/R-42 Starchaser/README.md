# R-42 Starchaser

**Continuity:** Legends  
**Source:** [R-42 Starchaser](https://starwars.fandom.com/wiki/R-42_Starchaser)

The R-42 Starchaser was a modified variant of R-41 Starchaser with a second seat for a gunner. Apart from being a two-seated version, it was completely identical to the earlier model. It was also much less common&mdash;only a few hundred were ever produced.
