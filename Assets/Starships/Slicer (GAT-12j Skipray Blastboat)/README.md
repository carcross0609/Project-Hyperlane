# Slicer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Slicer (GAT-12j Skipray Blastboat)](https://starwars.fandom.com/wiki/Slicer_%28GAT-12j_Skipray_Blastboat%29)

The Slicer was a Sienar Fleet Systems GAT-12j Skipray Blastboat. It was one of two Blastboats used by Bazak's Gang.
