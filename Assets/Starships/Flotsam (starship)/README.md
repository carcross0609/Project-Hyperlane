# Flotsam

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Flotsam (starship)](https://starwars.fandom.com/wiki/Flotsam_%28starship%29)

Flotsam was a Starhawk shuttle owned by Khedryn Faal and Marr Idi-Shael. The primary ship owned by Faal, Junker, was modified so that Flotsam was attached on the side, rather than the standard escape pod. Faal and Jedi Knight Jaden Korr flew Flotsam during a mission to a frozen moon in a remote star system containing a secret Imperial cloning center.

## Specifications

- **Name:** Flotsam
- **Model:** Starhawk shuttle
- **Type:** Shuttle
- **Role:** Salvage vessel
