# Gazle's Tours

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gazle's Tours](https://starwars.fandom.com/wiki/Gazle%27s_Tours)

Gazle's Tours was a civilian Ferryboat liner that was present at Calast, a Golan Space Colony 2 space station, during the Rescue at Bundil II. The ship contained tourists.

## Specifications

- **Name:** Gazle's Tours
- **Manufacturer:** SoroSuub Corporation
- **Model:** Ferryboat liner
- **Length:** 363 meters
- **Role:** Passenger liner
