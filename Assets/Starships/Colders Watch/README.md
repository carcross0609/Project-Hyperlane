# Colders Watch

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Colders Watch](https://starwars.fandom.com/wiki/Colders_Watch)

The Colders Watch was a bulk freighter operating during the Galactic Civil War. It was commanded by Captain Beezrul Granf, and the crew included First Mate Chessa Dohhenty and Chief Engineer Dirk Harkness.

## Specifications

- **Name:** Colders Watch
- **Type:** Bulk freighter
- **Captains:** Captain Beezrul Granf
