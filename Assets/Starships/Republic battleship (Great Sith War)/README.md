# Republic battleship

**Continuity:** Legends  
**Source:** [Republic battleship (Great Sith War)](https://starwars.fandom.com/wiki/Republic_battleship_%28Great_Sith_War%29)

During the Great Sith War, the Galactic Republic fielded this heavy class of battleship and divided command of the ships between the Republic Navy and the Jedi Order.

## Specifications

- **Name:** Republic battleship
- **Type:** Battleship
- **Hdsystem:** Equipped
- **Armament:** Turbolasers (at least 5)
- **Role:** Battleship
- **Affiliation:** Galactic Republic
