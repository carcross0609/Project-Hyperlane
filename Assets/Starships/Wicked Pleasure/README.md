# Wicked Pleasure

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Wicked Pleasure](https://starwars.fandom.com/wiki/Wicked_Pleasure)

The Wicked Pleasure was Senator Viqi Shesh's KDY yacht. It had a roof-mounted turret and was based at Eastport's Docking Bay 3732.
