# Last Chance

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Last Chance](https://starwars.fandom.com/wiki/Last_Chance)

The Last Chance was a Sentinel-class shuttle that belonged to the Weequay pirate Hondo Ohnaka, after he stole it from Reklam Station, a secret Imperial reclamation plant located on the planet Yarma.
