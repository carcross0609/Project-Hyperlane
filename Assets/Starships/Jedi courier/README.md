# Jedi courier

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jedi courier](https://starwars.fandom.com/wiki/Jedi_courier)

at Deneba|thumb|200px|right]] Jedi courier was the generic term used for the personal transport of a Jedi. In ancient times, each Jedi chose their own courier, choosing from any number of available classes; following the Exar Kun War, Vanya-class Jedi Couriers were released specifically for the purpose.
