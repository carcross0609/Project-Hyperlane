# Mourning Glory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mourning Glory](https://starwars.fandom.com/wiki/Mourning_Glory)

Mourning Glory was a pirate ship captained by Grov Bricker. It was captured by the Hapans during a trip through the Transitory Mists. The captain and crew were eventually released along with Mourning Glory when the ship's First Mate, who turned out to be Prince Isolder hiding in disguise, was shot with the Gun of Command by Ta'a Chume and ordered him to return home.

## Specifications

- **Name:** Mourning Glory
- **Role:** Pirate ship
- **Captains:** Captain Grov Bricker.
