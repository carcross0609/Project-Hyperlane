# Commerce Guild bomber

**Continuity:** Canon  
**Source:** [Commerce Guild bomber](https://starwars.fandom.com/wiki/Commerce_Guild_bomber)

The Commerce Guild bomber was a type of bomber that saw use by the Commerce Guild and later the naval forces of the Confederacy of Independent Systems during the Clone Wars against the Galactic Republic. During the war, which saw the corporation side with the Confederacy, Guild bombers were used alongside Guild corvettes, Recusant-class light destroyers, and Diamond-class cruisers to defend planets off the end of the Perlemian Trade Route such as Castell, Escarte, Felucia, Mooga, and Minntooine.

## Specifications

- **Type:** Bomber
