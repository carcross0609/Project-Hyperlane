# Dinko (corvette group)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dinko (corvette group)](https://starwars.fandom.com/wiki/Dinko_%28corvette_group%29)

Dinko was a group of CR90 corvettes protecting the Imperial I-class Star Destroyer Relentless. They were destroyed by Keyan Farlander in a B-wing starfighter. The Relentless itself soon shared the same fate.
