# Oramac

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Oramac](https://starwars.fandom.com/wiki/Oramac)

Oramac was a CR90 corvette in service to the Galactic Empire. It attempted to reinforce the System Patrol Squadron above the planet Farfeld II, but was destroyed by a B-wing piloted by Keyan Farlander.
