# Derriphan-class battleship

**Continuity:** Legends  
**Source:** [Derriphan-class battleship](https://starwars.fandom.com/wiki/Derriphan-class_battleship)

The Derriphan-class battleship was the primary capital ship used by the old Sith Empire. Most Sith Lords of the time carried these vessels in their fleets.
