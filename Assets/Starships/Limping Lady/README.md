# Limping Lady

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Limping Lady](https://starwars.fandom.com/wiki/Limping_Lady)

The Limping Lady was a modified YT-1300 light freighter which had been owned several times by Sithless Leethe.

- **Model:** Modified YT-1300 light freighter
- **Type:** Light freighter
- **Hyperdrive:** Class 2
- **Armament:**

  - 1 mass-driver cannon (ventrally mounted)
- **Crew:** 2
- **Passengers:** 6
- **Capacity:** 100 metric tons
- **Consumables:** 2 months
- **Role:** Transport
