# Agave-class picket ship

**Continuity:** Legends  
**Source:** [Agave-class picket ship](https://starwars.fandom.com/wiki/Agave-class_picket_ship)

The Agave-class picket ship was a tactical/operational reconnaissance ship produced under the New Republic's New Class Modernization Program. Task force commanders sent these ships ahead of the main battlegroup to either scout quietly, or in force. They were assigned to the New Republic Fifth Battle Group.
