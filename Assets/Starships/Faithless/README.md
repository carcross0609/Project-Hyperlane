# Faithless

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Faithless](https://starwars.fandom.com/wiki/Faithless)

The Faithless was a YT-2000 light freighter operated by Luca, a Rebel Alliance sympathizer. The ship was known as a tramp freighter.

- **Line:** YT-series
