# Helotek Loadhauler

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Helotek Loadhauler](https://starwars.fandom.com/wiki/Helotek_Loadhauler)

The Helotek Loadhauler was a class of cargo shuttle. The Loadhauler was a cheaper knock-off of the Galactic Empire's Zeta-class cargo shuttle, though it lacked weaponry and used cheaper parts. Yrica Quell bought one such shuttle after the Galactic Civil War.

- **Name:** Helotek Loadhauler
- **Type:** Cargo shuttle
