# Worldcraft

**Continuity:** Legends  
**Source:** [Worldcraft](https://starwars.fandom.com/wiki/Worldcraft)

A Worldcraft was a large type of habitation sphere. The Worldcraft were artificial planetoids which resembled a terrestrial planet or moon and were capable of traveling through hyperspace and realspace.
