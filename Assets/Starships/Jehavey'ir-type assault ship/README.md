# Jehavey'ir-type assault ship

**Continuity:** Legends  
**Source:** [Jehavey'ir-type assault ship](https://starwars.fandom.com/wiki/Jehavey%27ir-type_assault_ship)

The Jehavey'ir-type assault ship, named after a Mando'a word for "ambush", was utilized by the Mandalorian Neo-Crusaders during the Mandalorian Wars.

- **Navigation:** Navicomputer equipped
- **Armament:**

  - Heavy ion cannon batteries

- **Bays:** None
- **Crew:** 200
- **Passengers:** 500 (Mandalorian troops)
- **Capacity:** 3,500 tons
- **Consumables:** 6 months
- **Availability:** Restricted
- **Role:** Assault ship
- **Affiliation:** Mandalorian Neo-Crusaders
