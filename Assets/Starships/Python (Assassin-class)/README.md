# Python

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Python (Assassin-class)](https://starwars.fandom.com/wiki/Python_%28Assassin-class%29)

The Python was an Assassin-class corvette warship. It was used by the Alliance to Restore the Republic in the defection of the Imperial officer Commander Zaletta.
