# Unidentified bomber class

**Continuity:** Canon  
**Source:** [Unidentified bomber class](https://starwars.fandom.com/wiki/Unidentified_bomber_class)

A class of bomber that ran on zylium 12 fuel was used by the Nihil marauders during the High Republic Era. In 231 BBY, a bomber of the class was deployed during the Nihil attack on the Republic Fair on the planet Valo.

## Specifications

- **Name:** Unidentified bomber class
- **Type:** Bomber
- **Affiliation:** Nihil
