# Executor II-class Star Dreadnought

**Continuity:** Canon  
**Source:** [Executor II-class Star Dreadnought](https://starwars.fandom.com/wiki/Executor_II-class_Star_Dreadnought)

The Executor II-class Star Dreadnought was a type of Executor-class Star Dreadnought used by the Imperial Navy during the Imperial Era. At one point, one such Star Dreadnought flew over a cloudy celestial body with two Imperial-class Star Destroyers. The model was propelled by red-hued engines and it succeeded the Executor I-class Star Dreadnought.
