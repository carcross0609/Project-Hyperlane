# Yander 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yander 3](https://starwars.fandom.com/wiki/Yander_3)

Yander 3 was a YT-1300 light freighter aligned with the Galactic Empire. It was present at the Skirmish at Outpost D-34, and was carrying foodstuff.
