# Reep

**Continuity:** Legends  
**Source:** [Reep](https://starwars.fandom.com/wiki/Reep)

Reep was a Delta-class DX-9 stormtrooper transport used by the Rebel Alliance. The transport was present at a Rebel summit in the Delfii system, carrying advisors.
