# Larkrer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Larkrer](https://starwars.fandom.com/wiki/Larkrer)

The Larkrer was a Separatist freighter. Boroklif served as a captain onboard the vessel and used it to ship supplies between Batuu and Mokivj, where the Separatists had a secret droid factory.

## Specifications

- **Name:** Larkrer
- **Type:** Freighter
- **Affiliation:** Confederacy of Independent Systems
- **Navy:** Confederacy of Independent Systems Navy
- **Captains:** Captain Boroklif
