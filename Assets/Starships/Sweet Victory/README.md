# Sweet Victory

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sweet Victory](https://starwars.fandom.com/wiki/Sweet_Victory)

The Sweet Victory was a Marauder-class corvette that was captured by Zan Dane. He used it as the flagship for his pirate fleet.

## Specifications

- **Name:** Sweet Victory
- **Manufacturer:** Republic Sienar Systems
- **Type:** Corvette
- **Owners:** Zan Dane
- **Captains:** Zan Dane
