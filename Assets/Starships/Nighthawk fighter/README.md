# Nighthawk fighter

**Continuity:** Canon  
**Source:** [Nighthawk fighter](https://starwars.fandom.com/wiki/Nighthawk_fighter)

The Nighthawk fighter was a type of starfighter. By 3 ABY, they were used by pirates in Wild Space which were attacked by Red Squadron.
