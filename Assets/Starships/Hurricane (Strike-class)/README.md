# Hurricane

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Hurricane (Strike-class)](https://starwars.fandom.com/wiki/Hurricane_%28Strike-class%29)

Hurricane was a Strike-class medium cruiser used by the Galactic Empire. It was sent to investigate a communication array that had been attacked twice. The culprits were revealed to be Ace and Aeron Azzameen; the Hurricane attempted to stop the two with TIE/LN starfighters, but Ace, in his YT-1300 light freighter Sabra, managed to fend of the Hurricane's fighters and retreat back to the Liberty.
