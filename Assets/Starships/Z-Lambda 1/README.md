# Z-Lambda 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Z-Lambda 1](https://starwars.fandom.com/wiki/Z-Lambda_1)

Z-Lambda 1 was Beta-class ETR-3 escort transport used by the Zaarin coup forces. It was present at the Destruction of the Glory.
