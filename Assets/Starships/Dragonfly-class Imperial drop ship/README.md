# Dragonfly-class Imperial drop ship

**Continuity:** Legends  
**Source:** [Dragonfly-class Imperial drop ship](https://starwars.fandom.com/wiki/Dragonfly-class_Imperial_drop_ship)

The Dragonfly-class Imperial drop ship was a starship used by the Sith Empire during the Great Galactic War. Bounty hunter Vrath Xizor used one as his personal transport, which he named the Razor.
