# Hernon-class light freighter

**Continuity:** Canon  
**Source:** [Hernon-class light freighter](https://starwars.fandom.com/wiki/Hernon-class_light_freighter)

The Hernon-class light freighter was a starship design commonly seen on the desert planet Jakku. A type of light freighter, they were boxy and considered ugly by many.
