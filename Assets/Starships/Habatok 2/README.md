# Habatok 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Habatok 2](https://starwars.fandom.com/wiki/Habatok_2)

Habatok 2 was a CR90 corvette sent by the Habassa to rescue the station crew of a B-wing assembly area. Red Squadron led by Rebel pilot Keyan Farlander oversaw the evacuation.
