# Starrunner

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starrunner (Scythe-class)](https://starwars.fandom.com/wiki/Starrunner_%28Scythe-class%29)

The Starrunner was an MC140 Scythe-class main battle cruiser in service to the Galactic Alliance Core Fleet during the Second Imperial Civil War. In 138 ABY it participated during the space battle above Taivas when the forces of the Sith Empire attacked the Jedi Temple. The Starrunner was destroyed by a group of Annihilator-class starfighters.
