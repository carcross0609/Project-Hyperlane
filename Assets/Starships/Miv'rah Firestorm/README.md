# Miv'rah Firestorm

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Miv'rah Firestorm](https://starwars.fandom.com/wiki/Miv%27rah_Firestorm)

Miv'rah Firestorm was a highly modified Nestt-class light freighter owned and operated by the Sullustan smuggler Gaor Tembon.

## Specifications

- **Name:** Miv'rah Firestorm
- **Manufacturer:** SoroSuub Corporation
- **Line:** Light freighter
- **Type:** Highly modified Nestt-class light freighter
- **Length:** 29 meters
- **Hyperdrive:**
  - Class 1
  - Class 9 (backup)
- **Power:** SoroSuub Corporation Nepton power core with Koensayr Manufacturing TLB power converters
- **Shield Gen:** Equipped
- **Sensor:** Equipped
- **Navigation:** Equipped
- **Armament:** 2 quad laser cannons
- **Crew:** 1 with optional co-pilot
- **Passengers:** 4
- **Capacity:** 110 metric tons
- **Consumables:** 2 standard weeks
- **Owners:** Gaor Tembon
