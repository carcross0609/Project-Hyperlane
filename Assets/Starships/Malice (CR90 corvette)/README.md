# Malice (CR90 corvette)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Malice (CR90 corvette)](https://starwars.fandom.com/wiki/Malice_%28CR90_corvette%29)

Malice was an Imperial CR90 corvette that formed part of the Corrupter Task Force in its hunt for the Alliance cruiser Defiance. The Malice was commanded by Commander Linder.
