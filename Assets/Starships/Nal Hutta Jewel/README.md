# Nal Hutta Jewel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nal Hutta Jewel](https://starwars.fandom.com/wiki/Nal_Hutta_Jewel)

The Nal Hutta Jewel was a Minstrel-class space yacht manufactured by Ubrikkian Industries. It was the base of operations for Ganis the Hutt.
