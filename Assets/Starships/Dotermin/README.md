# Dotermin

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dotermin](https://starwars.fandom.com/wiki/Dotermin)

Dotermin was an Imperial BFF-1 bulk freighter that was destroyed by Rebel forces while resupplying the Relentless Star Destroyer with TIE fighters. This occurred during the Empire's attempt to destroy Rebel B-wing production in the lead-up to the Battle of Hoth.

## Specifications

- **Type:** Freighter

- **Height:** 34 meters
- **Destroyed:** 2 ABY
