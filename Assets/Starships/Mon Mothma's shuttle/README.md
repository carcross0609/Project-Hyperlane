# Mon Mothma's shuttle

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Mon Mothma's shuttle](https://starwars.fandom.com/wiki/Mon_Mothma%27s_shuttle)

A shuttle was used by the Alliance to Restore the Republic to evacuate Chancellor Mon Mothma in the event that the Death Star destroyed Yavin 4, which housed the Alliance's base of operations.
