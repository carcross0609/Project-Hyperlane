# Emperor's Royal Guard TIE/IN starfighter

**Continuity:** Legends  
**Source:** [Emperor's Royal Guard TIE/IN starfighter](https://starwars.fandom.com/wiki/Emperor%27s_Royal_Guard_TIE/IN_starfighter)

The Emperor's Royal Guard TIE/IN starfighter was a specially modified version of the TIE/IN interceptor. These TIE Interceptors were flown only by Emperor Palpatine's Royal Guard.
