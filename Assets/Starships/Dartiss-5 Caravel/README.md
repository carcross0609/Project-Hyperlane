# Dartiss-5 Caravel

**Continuity:** Legends  
**Source:** [Dartiss-5 Caravel](https://starwars.fandom.com/wiki/Dartiss-5_Caravel)

The Dartiss-5 Caravel was a barge-like Huttian design produced by Ubrikkian Industries.

- **Manufacturer:** Ubrikkian Industries

- **Passengers:** 65

- **Consumables:** 1 week
- **Role:**
