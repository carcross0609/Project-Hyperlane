# Tala 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tala 2](https://starwars.fandom.com/wiki/Tala_2)

Tala 2 was a Z-95t Headhunter which was developed by Alliance to Restore the Republic tactician Adar Tallon. As with all Z-95t Headhunters, Tala 2 had a class 3 hyperdrive, which individually allowed Tala 2 long-range reconnaissance.
