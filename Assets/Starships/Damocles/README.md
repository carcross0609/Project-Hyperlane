# Damocles

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Damocles](https://starwars.fandom.com/wiki/Damocles)

The Damocles was a EF76 Nebulon-B escort frigate that was part of Task Force Vengeance. It was involved in the failed attempt to destroy a Rebel convoy intending to deliver B-wings to the Liberty.

## Specifications

- **Name:** Damocles
- **Model:** EF76 Nebulon-B escort frigate
- **Type:** Frigate
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:** Task Force Vengeance
