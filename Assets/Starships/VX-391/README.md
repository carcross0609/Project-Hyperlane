# VX-391

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [VX-391](https://starwars.fandom.com/wiki/VX-391)

VX-391 was a freighter that carried the bodies of Anakin Skywalker, Obi-Wan Kenobi, Ahsoka Tano and other clone troopers encased in carbonite.

## Specifications

- **Name:** VX-391
- **Type:** Freighter
- **Complement:** 1 droid pilot
- **Affiliation:**

  - Galactic Republic
- **Captains:** R2-D2
