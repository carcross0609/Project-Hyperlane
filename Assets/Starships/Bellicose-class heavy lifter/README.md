# Bellicose-class heavy lifter

**Continuity:** Canon  
**Source:** [Bellicose-class heavy lifter](https://starwars.fandom.com/wiki/Bellicose-class_heavy_lifter)

The Bellicose-class Heavy Lifter was a Clone Wars-era model of heavy duty lifter manufactured by Hoersch-Kessel Drive, Inc. It was originally designed to deploy assault droids from orbit. The rogue archaeologist Chelli Aphra flew a heavily modified Bellicose-class craft dubbed the Ark Angel. Over time, the Angel was repaired and modified so often that it became unrecognizable.

## Specifications

- **Name:** Bellicose-class heavy lifter
- **Manufacturer:** Hoersch-Kessel Drive Inc.
- **Type:** Heavy duty lifter
