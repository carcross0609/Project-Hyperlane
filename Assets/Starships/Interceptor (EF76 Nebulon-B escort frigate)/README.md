# Interceptor (EF76 Nebulon-B escort frigate)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Interceptor (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Interceptor_%28EF76_Nebulon-B_escort_frigate%29)

The Interceptor was an Nebulon-B frigate that served with the Imperial Navy during the Galactic Civil War. The warship engaged and attacked the Rebel Alliance BFF-1 bulk freighter Radley, which had been waiting to rendezvous with the Mon Calamari Star Cruiser Cathleen. When the cruiser arrived, it launched Gold Squadron's BTL Y-wing starfighters, which successfully overwhelmed the defenses of the frigate, resulting in its destruction.
