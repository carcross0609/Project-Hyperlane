# Crusader-class corvette

**Continuity:** Legends  
**Source:** [Crusader-class corvette](https://starwars.fandom.com/wiki/Crusader-class_corvette)

The Crusader-class corvette, also referred to as the Crusader-class gunship, was a warship produced by Mandal Hypernautics that was in use during the Galactic Civil War.
