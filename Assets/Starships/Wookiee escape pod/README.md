# Wookiee escape pod

**Continuity:** Canon  
**Source:** [Wookiee escape pod](https://starwars.fandom.com/wiki/Wookiee_escape_pod)

The Wookiee escape pod, also called a Kashyyyk escape pod, was a custom-built shuttle built by the Wookiees of Kashyyyk. Jedi Grand Master Yoda escaped clone troopers following the Battle of Kashyyyk aboard one of these craft, assisted by Tarfful and Chewbacca.

## Specifications

- **Name:** Wookiee escape pod
- **Manufacturer:** Uurbahhahvoovv Joiners & Artisans
- **Type:** Escape pod
- **Width:** 2.3 meters
- **Height:** 3.4 meters
- **Engine:** 3
- **Armament:** None
- **Passengers:** 1
- **Role:** Escape shuttle
- **Affiliation:**
