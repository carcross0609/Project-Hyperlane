# Fubarium

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fubarium](https://starwars.fandom.com/wiki/Fubarium)

Fubarium was a Lambda-class T-4a shuttle belonging to the Imperials. It was part of Deep Space Manufacturing Facility Drekker's procedure that, should the station's hull be critically damaged, the shuttle would launch, carrying officers. The shuttle in this case would make a run for the Victory-class Star Destroyer Inexorable.
