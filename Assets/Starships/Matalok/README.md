# Matalok

**Continuity:** Legends  
**Source:** [Matalok](https://starwars.fandom.com/wiki/Matalok)

Mataloks were large Yuuzhan Vong bioships commonly found in the Yuuzhan Vong warfleet. As with the Suuv Ban D'Krid and occasionally the Miid ro'ik, the New Republic referred to them as 'cruiser analogs'.

## Specifications

- **Name:** Matalok
- **Manufacturer:** Yuuzhan Vong
- **Type:** Warship
- **Length:** approximately 1,200 meters
- **Engine:** Dovin basals
- **Shield Gen:** Dovin basals
- **Armament:**
  - Yaret-Kors (40)
  - Dovin basals
- **Role:**
  - Cruiser
  - Carrier
- **Affiliation:** Yuuzhan Vong
