# Kappa-class shuttle

**Continuity:** Legends  
**Source:** [Kappa-class shuttle](https://starwars.fandom.com/wiki/Kappa-class_shuttle)

The Kappa-class shuttle was a Galactic Republic-era shuttle that possessed many features which were later incorporated into the Imperial Lambda-class shuttle.

## Specifications

- **Name:** Kappa-class shuttle
- **Manufacturer:** Republic Sienar Systems
- **Model:** Kappa-class troop shuttle
- **Type:** Shuttle
- **Cost:** Usually not for sale, 110,000 credits otherwise
- **Length:** 35 meters
- **Max Speed:** 820 km/h
- **Hyperdrive:** Class 2 (backup Class 18)
- **Sensor:** Equipped
- **Navigation:** Equipped
- **Armament:**
  - Double blaster cannons (2)
  - Forward repeating blaster cannons (2)
- **Complement:**
  - 2 AT-RT or AT-PT walkers
  - or
  - 2 Infantry Support Platforms
- **Crew:**
  - Crew (2)
  -   Pilot (1)
  -   Co-pilot/engineer (1)
  - Gunners (2)
- **Passengers:** 40 (troops)
- **Capacity:** 50 metric tons
- **Consumables:** 1 or 2 months
- **Availability:** Military
- **Role:**
  - Troop shuttle
  - Landing craft
- **Affiliation:**
  - Galactic Republic
  - Galactic Empire
  - Alliance to Restore the Republic
  -   Alliance Navy
