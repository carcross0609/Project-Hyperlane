# Avent100-series light freighter

**Continuity:** Canon  
**Source:** [Avent100-series light freighter](https://starwars.fandom.com/wiki/Avent100-series_light_freighter)

The Avent100-series light freighter was a model of light freighter. The spice trader Trix Sternus owned an Avent100, and sold it to Julen Rakab in Black Spire Outpost on Batuu.
