# Ession Strike

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ession Strike](https://starwars.fandom.com/wiki/Ession_Strike)

The Ession Strike, originally named the Night Caller, was a modified CR90 corvette.
