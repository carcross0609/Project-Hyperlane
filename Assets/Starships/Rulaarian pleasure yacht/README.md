# Rulaarian pleasure yacht

**Continuity:** Legends  
**Source:** [Rulaarian pleasure yacht](https://starwars.fandom.com/wiki/Rulaarian_pleasure_yacht)

The Rulaarian pleasure yacht was a civilian starship that existed during the Galactic Civil War. One such Rulaarian yacht was destroyed by the Galactic Empire as it departed the Wheel, a casino-ridden space station popular amongst gamblers.
