# ZZ-class freighter

**Continuity:** Legends  
**Source:** [ZZ-class freighter](https://starwars.fandom.com/wiki/ZZ-class_freighter)

The ZZ-class freighter was a freighter of an unknown design. It had a long and thin shape. Despite its great size, the class could be operated by a crew of as few as four.
