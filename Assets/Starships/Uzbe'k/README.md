# Uzbe'k

**Continuity:** Legends  
**Source:** [Uzbe'k](https://starwars.fandom.com/wiki/Uzbe%27k)

Uzbe'k was the name given to a group of Rebel Delta-class DX-9 stormtrooper transports that carried Rebel personnel from the exploding Mon Calamari Star Cruiser Maximus.
