# Kraken's Maxillipede shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kraken's Maxillipede shuttle/Legends](https://starwars.fandom.com/wiki/Kraken%27s_Maxillipede_shuttle/Legends)

A Maxillipede shuttle, overseen by the super tactical droid Kraken, was used to transport clone trooper Tup from Ringo Vinda to Kamino before the Clone Wars. However, Galactic Republic forces intercepted the shuttle and rescued Tup before Kraken's shuttle could leave Ringo Vinda.
