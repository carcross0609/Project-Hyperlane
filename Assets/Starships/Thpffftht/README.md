# Thpffftht

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Thpffftht](https://starwars.fandom.com/wiki/Thpffftht)

The Thpffftht was a Bith counselor ship in use of the New Republic. In 8 ABY, it took Luke Skywalker from Toola to the Roche system.
