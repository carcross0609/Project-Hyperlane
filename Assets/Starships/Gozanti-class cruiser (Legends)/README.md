# Gozanti-class cruiser

**Continuity:** Legends  
**Source:** [Gozanti-class cruiser/Legends](https://starwars.fandom.com/wiki/Gozanti-class_cruiser/Legends)

The Gozanti-class cruiser, also known as the Gozanti-class armored cruiser, Gozanti-class armed transport, or simply the Gozanti Cruiser, was a slow but powerful independent transport designed by Corellian Engineering Corporation.
