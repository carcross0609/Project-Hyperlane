# Gorfan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gorfan](https://starwars.fandom.com/wiki/Gorfan)

Gorfan was a pair of Modular conveyors used by the Imperial Navy. The conveyors were used to deliver supplies to help contruct a space station that would be called NL-1 in the Pakuuni system.

## Specifications

- **Name:** Gorfan
- **Model:** Modular conveyor
- **Length:** 126.8 meters
- **Width:** 70.35 meters
- **Height:** 42.27 meters
- **Affiliation:** Galactic Empire
