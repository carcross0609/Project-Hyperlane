# Shmus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shmus](https://starwars.fandom.com/wiki/Shmus)

Shmus was a Nebulon-B2 frigate belonging to the Rebel Alliance. It was supposed to rendezvous with the Rebel Fleet at Sullust, but was destroyed by Maarek Stele.

## Specifications

- **Name:** Shmus
- **Manufacturer:** Kuat Drive Yards
- **Model:** Nebulon-B2 frigate
- **Length:** 253.2 meters
- **Width:** 147.7 meters
- **Height:** 94.3 meters
- **Destroyed:** 3 ABY
- **Affiliation:** Alliance to Restore the Republic
