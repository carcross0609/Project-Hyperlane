# Glaser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Glaser](https://starwars.fandom.com/wiki/Glaser)

Glaser was a CR90 Corvette employed by the Rebels. The corvette was part of a Rebel strike force attacking an Imperial Frigate Laantis while it was receiving a new Hyperdrive engine from the freighter Rasvin. The corvette was destroyed in the battle.
