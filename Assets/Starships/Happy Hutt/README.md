# Happy Hutt

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Happy Hutt](https://starwars.fandom.com/wiki/Happy_Hutt)

The Happy Hutt was one of the 600 refugee ships the Yuuzhan Vong used as Human shields in the Battle of Coruscant. It was carrying 5,000 refugees from Ralltiir.
