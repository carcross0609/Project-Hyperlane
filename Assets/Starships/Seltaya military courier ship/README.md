# Seltaya military courier ship

**Continuity:** Canon  
**Source:** [Seltaya military courier ship](https://starwars.fandom.com/wiki/Seltaya_military_courier_ship)

The Seltaya military courier ship was a type of starship than was used for military purposes. The Nomad Four was a civilian version of the ship, and was used by the Naboo Royal Handmaidens.
