# Venesectrix

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Venesectrix](https://starwars.fandom.com/wiki/Venesectrix)

The Venesectrix was a starship belonging to the late bounty hunter Ree Duptom. The ship was found drifting by Boba Fett in the central sectors of the galaxy with its owner dead inside. According to Fett, the ship's engines experienced a partial core meltdown, which resulted in a high-energy particle burst killing Duptom. Whether this was an engine malfunction or sabotage was undetermined at that time.

## Specifications

- **Owners:** Ree Duptom
