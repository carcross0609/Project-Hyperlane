# Vengeance (Tatooine)

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Vengeance (Tatooine)](https://starwars.fandom.com/wiki/Vengeance_%28Tatooine%29)

Vengeance was an Imperial-class Star Destroyer serving the Imperial Navy during the Galactic Civil War. It was on stationed at Tatooine with Belligerent in 0 ABY when the pair of vessels attempted to stop the freighter Limping Lady from leaving the planet.
