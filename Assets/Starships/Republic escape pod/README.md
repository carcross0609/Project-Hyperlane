# Republic escape pod

**Continuity:** Canon  
**Source:** [Republic escape pod](https://starwars.fandom.com/wiki/Republic_escape_pod)

The Republic escape pod was a type of escape pod used by the Galactic Republic during the Clone Wars. In 22 BBY, Jedi Master Yoda and clone troopers Thire, Jek, and Rys used a Republic escape pod to land on Rugosa where the Jedi Master had a meeting with the Toydarian King Katuunko.

## Specifications

- **Name:** Republic escape pod
- **Type:** Escape pod
- **Affiliation:** Galactic Republic
