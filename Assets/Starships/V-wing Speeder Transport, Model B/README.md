# V-wing Speeder Transport, Model B

**Continuity:** Legends  
**Source:** [V-wing Speeder Transport, Model B](https://starwars.fandom.com/wiki/V-wing_Speeder_Transport%2C_Model_B)

The V-wing Speeder Transport, Model B was an updated model of the Model A produced by Slayn & Korpil and used to transport V-wing airspeeders into battle. It was longer than the Model A, measuring 27 meters, and had an internal cargo capacity of four metric tons. The main difference was that the Model B could transport six V-wing airspeeders and their pilots into battle, rather than the Model A's four.
