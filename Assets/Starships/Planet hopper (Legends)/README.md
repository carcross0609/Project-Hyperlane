# Planet hopper

**Continuity:** Legends  
**Source:** [Planet hopper/Legends](https://starwars.fandom.com/wiki/Planet_hopper/Legends)

A planet hopper, planet skipper, or interplanetary hopper was a starship capable of transit from one planet to another within the same star system. Planet-hoppers had no hyperdrive. The Light of Reason was a planet-hopper.
