# Profusion

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Profusion](https://starwars.fandom.com/wiki/Profusion)

The Profusion was a Lucrehulk-class battleship that served within the naval forces of the Confederacy of Independent Systems during the Clone Wars. Measuring 3,356.9 meters in length, 3,009 meters in width and 1,028.77 meters in height, the battleship was equipped with several droid signal receiver stations.
