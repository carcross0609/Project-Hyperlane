# Blue Flare

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blue Flare](https://starwars.fandom.com/wiki/Blue_Flare)

The Blue Flare was an old light freighter that belonged to Sona Fey'lya, a female Bothan smuggler. At some point, Logron, a crime lord on Tatooine, took away the Blue Flare as payback. She later was able to steal it with the help of the Pero brothers and an adventurer.

## Specifications

- **Name:** Blue Flare
- **Type:** Light freighter
- **Owners:**
  - Sona Fey'lya
  - Logron
