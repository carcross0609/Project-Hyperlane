# D11

**Continuity:** Legends  
**Source:** [D11](https://starwars.fandom.com/wiki/D11)

The D11 was a class of freighter manufactured by Kuat Drive Yards sometime after the rise of the New Order. It was faster and more heavily armed than the earlier D9 Runner light freighter design also produced by Kuat Drive Yards.
