# Safonne's Sword

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Safonne's Sword](https://starwars.fandom.com/wiki/Safonne%27s_Sword)

Safonne's Sword was the flagship of the pirate Safonne Pendon's modest, but effective fleet. It was a CR90 corvette, which was modified to include six turret-mounted double-turbolaser cannons. The ship's drive systems and shields were also upgraded by the Rodian pirate.
