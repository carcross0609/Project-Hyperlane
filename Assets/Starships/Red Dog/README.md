# Red Dog

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red Dog](https://starwars.fandom.com/wiki/Red_Dog)

Red Dog was a Strike-class medium cruiser belonging to the Rebel Alliance. The cruiser was attempting to rendezvous with the Rebel Fleet at Sullust when it was destroyed by Tan Maarek Stele.
