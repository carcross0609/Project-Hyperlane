# Candor

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Candor](https://starwars.fandom.com/wiki/Candor)

The Candor was a Rebel Alliance arms-smuggling CR90 corvette. Minister Amilyn Holdo and her droid Tee-Six stayed aboard the Candor for some time.

## Specifications

- **Name:** Candor
- **Line:** Alderaanian diplomatic cruiser
- **Model:** CR90 corvette
- **Type:** Corvette
- **Role:** Arms smuggling
- **Affiliation:** Alliance to Restore the Republic
- **Navy:** Rebel Alliance Navy
- **Captains:**
  - Jardar
  - Amilyn Holdo
