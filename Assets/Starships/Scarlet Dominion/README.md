# Scarlet Dominion

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Scarlet Dominion](https://starwars.fandom.com/wiki/Scarlet_Dominion)

The Scarlet Dominon was a Nau'ur-class yacht custom made by Kalevala Spaceworks for Aurelia Tagge. It had chromium highlights that were often highlighted by lifestyle paparazzi during the Imperial Era.

## Specifications

- **Name:** Scarlet Dominion
- **Manufacturer:** Kalevala Spaceworks
- **Model:** Nau'ur-class yacht
- **Type:** Yacht
- **Owners:** Aurelia Tagge
