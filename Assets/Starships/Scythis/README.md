# Scythis

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Scythis](https://starwars.fandom.com/wiki/Scythis)

Scythis was a Strike-class medium cruiser belonging to the Galactic Empire. It was stationed at a customs station when Ace Azzameen in the YT-1300 Sabra had to pass through customs to reach Outpost 327.

## Specifications

- **Name:** Scythis
- **Model:** Strike-class medium cruiser
- **Type:** Medium cruiser
- **Length:** 450 meters
- **Height:** 90 meters
- **Affiliation:** Galactic Empire
