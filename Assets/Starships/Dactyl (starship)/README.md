# Dactyl (starship)

**Continuity:** Legends  
**Source:** [Dactyl (starship)](https://starwars.fandom.com/wiki/Dactyl_%28starship%29)

The Dactyl was a model of starship manufactured by Rendili StarDrive. One was once used by Jaina Solo, Zekk and Jagged Fel during their hunt for Alema Rar.
