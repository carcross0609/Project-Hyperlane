# Torment

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Torment (shuttle)](https://starwars.fandom.com/wiki/Torment_%28shuttle%29)

The Torment was the name the Ikkrukkian Jedi Master Porter Engle gave to a shuttle he used during his time in the Nihil pirates Occlusion Zone. The shuttle had originally belonged to a Nihil and was stolen by Engle when he ambushed the Nihil's patrol on the astronomical object Exu Prime.
