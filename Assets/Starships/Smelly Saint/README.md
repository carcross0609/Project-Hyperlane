# Smelly Saint

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Smelly Saint](https://starwars.fandom.com/wiki/Smelly_Saint)

The Smelly Saint was a smuggler ship that smuggled ripoff Agri-Droids out of the Kimm systems and slaves from the Senex sector. It was apparently connected to Fargednim P'taan.
