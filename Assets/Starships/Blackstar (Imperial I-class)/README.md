# Blackstar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blackstar (Imperial I-class)](https://starwars.fandom.com/wiki/Blackstar_%28Imperial_I-class%29)

The Blackstar was an Imperial I-class Star Destroyer held in reserve during the hyperdrive upgrade operation for the Nebulon-B frigate Laantis months after the Battle of Hoth.
