# Ebruchi command ship

**Continuity:** Legends  
**Source:** [Ebruchi command ship](https://starwars.fandom.com/wiki/Ebruchi_command_ship)

The Ebruchi command ship, also known as the Ebruchi command vessel, was a type of frigate used by the Ebruchi Pirates. It served as the backbone of the Ebruchi fleets. The vessels were utilized as command ships for Ebruchi flotillas and scout squadrons. They were also utilized as scout ships for the rest of an Ebruchi clan's fleet.

## Specifications

- **Name:** Ebruchi command ship
- **Type:** Frigate
- **Length:** ~ 200-400 meters
- **Hdsystem:** Equipped
- **Bays:** At least one
- **Role:**
  - Frigate
  - Command ship
  - Scout ship
- **Affiliation:** Ebruchi Pirates
