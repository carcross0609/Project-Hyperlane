# Missile boat

**Continuity:** Legends  
**Source:** [Missile boat/Legends](https://starwars.fandom.com/wiki/Missile_boat/Legends)

A missile boat was a type of combat starship used during the Galactic Civil War. The Eyttyrmin Batiiv converted a number of civilian vessels into missile boats to serve in their pirate armada.
