# Koros Spaceworks interceptor

**Continuity:** Legends  
**Source:** [Koros Spaceworks interceptor](https://starwars.fandom.com/wiki/Koros_Spaceworks_interceptor)

The Koros Spaceworks interceptor was the primary planetary defense starfighter used on Empress Teta and the worlds under Empress Teta's authority.

## Specifications

- **Name:** Koros Spaceworks interceptor
- **Manufacturer:** Koros Spaceworks
- **Type:** Starfighter
- **Length:** 14.2 meters
- **Max Speed:** 800 km/h
- **Hdsystem:** None (can be modified to use TransGalMeg hyperdrive booster rings)
- **Shield Gen:** None
- **Armament:**
  - Laser cannons (4)
  - Ion cannon (1)
- **Crew:** 2
- **Skeleton:** 1
- **Passengers:** None
- **Role:** Planetary defense starfighter
- **Affiliation:**
  - Tetans
  - Republic Navy
