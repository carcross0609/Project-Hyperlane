# Derk Squadron

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Derk Squadron](https://starwars.fandom.com/wiki/Derk_Squadron)

Derk Squadron was the name of a squadron consisting of a sole X-wing, belonging to the Mugaari, that participated in the First Battle of Javin against Outpost D-34.
