# Starfire (Kid DXo'ln)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starfire (Kid DXo'ln)](https://starwars.fandom.com/wiki/Starfire_%28Kid_DXo%27ln%29)
