# A-1 shuttle

**Continuity:** Legends  
**Source:** [A-1 shuttle](https://starwars.fandom.com/wiki/A-1_shuttle)

The A-1 shuttle was a personal shuttle used by many admirals of the Republic during the Clone Wars. It was used as a way of transportation from flagships.
