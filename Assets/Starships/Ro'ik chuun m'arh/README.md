# Ro'ik chuun m'arh

**Continuity:** Legends  
**Source:** [Ro'ik chuun m'arh](https://starwars.fandom.com/wiki/Ro%27ik_chuun_m%27arh)

The ro'ik chuun m'arh was a frigate analog used by the Yuuzhan Vong as a picket and long-range reconnaissance ship.

## Specifications

- **Name:** Ro'ik chuun m'arh
- **Manufacturer:** Yuuzhan Vong
- **Model:** Chuun m'arh frigate
- **Type:** Capital ship
- **Length:** 440 meters as standard but many in fact 150-200 meters
- **Hyperdrive:** Class 3
- **Armament:**
  - Yaret-Kors (30)
  - Dovin basals
- **Complement:** 3 scourges
- **Crew:** 225
- **Passengers:** 370
- **Capacity:** 980 metric tons
- **Consumables:** 3 months
- **Role:**
  - Frigate
  - Picket
  - Long-range reconnaissance
  - Cargo transport
  - Troop transport
- **Affiliation:** Yuuzhan Vong empire
