# Pyre's ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Pyre's ship](https://starwars.fandom.com/wiki/Pyre%27s_ship)

Pyre's ship was an Upsilon-class command shuttle used by Commander Pyre of the First Order during the Cold War to travel to and from Colossus.

- **Manufacturer:** Sienar-Jaemus Fleet Systems
- **Model:** Upsilon-class shuttle

- **Engine:** SJFS-200a sublight ion engines (2)

- **Hull:** Durasteel
- **Sensor:** Equipped (long-range scan-mode sensor array, passive-mode sensors, and a primary sensor node)

- **Role:** Transport
- **Affiliation:** First Order
- **Navy:** First Order Navy
- **Owners:** Pyre
- **Captains:**
  - Tierny
  - Elrik Vonreg
