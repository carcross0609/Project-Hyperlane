# Red Fang

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red Fang](https://starwars.fandom.com/wiki/Red_Fang)

Red Fang was a modified A-24 Sleuth-class scout ship owned by the smuggler Tarquin Zian. Red Fang was armed with two laser cannons. The crew was simply Zian himself, although the ship allowed two more passengers. Zian used this ship to take some Kallistan gems offered by Prefect Dengless Rinn in exchange for transporting weapons for Rinn's coup against Governor Linrec.
