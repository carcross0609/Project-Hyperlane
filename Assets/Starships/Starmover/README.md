# Starmover

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starmover](https://starwars.fandom.com/wiki/Starmover)

Starmover was a pair of BFF-1 bulk freighters used by the Habassa. The freighters placed containers containing foodstuffs near Retep III. Rebel freighters called Kielty were to pick these supplies afterwards. They managed to do so despite being attacked by the EF76 Nebulon-B escort frigate Anjisan.
