# Obi-Wan Kenobi's courier

**Continuity:** Legends  
**Source:** [Obi-Wan Kenobi's courier](https://starwars.fandom.com/wiki/Obi-Wan_Kenobi%27s_courier)

A two-seater Rho-1 Limulus-class courier took Obi-Wan Kenobi and Anakin Skywalker to Ilum, and was a design commonly used by the Jedi.
