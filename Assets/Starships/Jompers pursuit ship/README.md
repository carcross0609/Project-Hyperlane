# Jompers pursuit ship

**Continuity:** Legends  
**Source:** [Jompers pursuit ship](https://starwars.fandom.com/wiki/Jompers_pursuit_ship)

The Jompers pursuit ship was a customs ship described as "modern" in 19 ABY, when the Frezhlix used thirty of them in their attempted blockade of Sif'kric.
