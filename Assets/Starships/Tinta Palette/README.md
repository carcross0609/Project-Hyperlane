# Tinta Palette

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Tinta Palette](https://starwars.fandom.com/wiki/Tinta_Palette)

The Tinta Palette was a liner built by Tinta Lines. It was inspired by the Queen of Empire. Tinta Blue Seven was a shuttle attached to it.
