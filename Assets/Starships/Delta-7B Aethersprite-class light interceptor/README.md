# Delta-7B Aethersprite-class light interceptor

**Continuity:** Canon  
**Source:** [Delta-7B Aethersprite-class light interceptor](https://starwars.fandom.com/wiki/Delta-7B_Aethersprite-class_light_interceptor)

The Delta-7B Aethersprite-class light interceptor, commonly known as the Jedi starfighter due to its widespread use by the Jedi, was a starfighter model employed during the Clone Wars. It was a variant design of the earlier Delta-7 Aethersprite-class light interceptor, with the Delta-7B featuring a relocated astromech droid slot and a slightly enlarged hull. The Delta-7B also had a set of pop-out S-foils that could be extended for certain flight maneuvers.
