# Settie-class drop ship

**Continuity:** Canon  
**Source:** [Settie-class drop ship](https://starwars.fandom.com/wiki/Settie-class_drop_ship)

The Settie-class drop ship was a class of dropship used by the Separatist navy during the Clone Wars. One of these ships, which was visibly lackluster, was present on the planet Vallt in 21 BBY when Galactic Republic Lieutenant Commander Orson Krennic rescued the scientist Galen Erso and his family from the Separatists on Vallt. Shortly after taking off from Tambolor prison, Krennic ordered Commander Prakas to destroy the ship.

- **Type:** Dropship
