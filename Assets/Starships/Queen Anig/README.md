# Queen Anig

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Queen Anig](https://starwars.fandom.com/wiki/Queen_Anig)

The Queen Anig was a civilian C-3 passenger liner that was present at Calast, a Golan Space Colony 2 space station during the Rescue at Bundil II. The ship contained tourists.

## Specifications

- **Name:** Queen Anig
- **Manufacturer:** Leonore Luxury Liners Incorporated
- **Model:** C-3 passenger liner
- **Length:** 409 meters
- **Width:** 132 meters
- **Height:** 94 meters
- **Engine:** 6 sublight engine units
- **Armament:** None
- **Role:** Passenger liner
