# Corona-class transport

**Continuity:** Legends  
**Source:** [Corona-class transport](https://starwars.fandom.com/wiki/Corona-class_transport)

The Corona-class transport was a class of transport that was manufactured by Kuat Drive Yards. Ships of this class were intended to compete with the Corellian Engineering Corporation's YT-series of light freighter, however they did not sell well, being overpriced for their cargo capacity. Some ships were used by the Alliance to Restore the Republic during the Galactic Civil War.
