# Patrol Four

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Patrol Four](https://starwars.fandom.com/wiki/Patrol_Four)

Patrol Four was a Chiss patrol ship stationed at Taharim Academy on Naporar. Mitth'raw'nuruodo proved that he had not cheated on a flight simulator by flying against Patrol Four and three other ships.

- **Name:** Patrol Four
- **Type:** Patrol ship
