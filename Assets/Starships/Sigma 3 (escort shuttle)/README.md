# Sigma 3

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sigma 3 (escort shuttle)](https://starwars.fandom.com/wiki/Sigma_3_%28escort_shuttle%29)

Sigma 3 was an Imperial Delta-class JV-7 escort shuttle. It was one of four such shuttles to participate in an Imperial attack on the factory ZA-13, which at the time was held by traitorous Grand Admiral Demetrius Zaarin.Sigma 3 carried a boarding party that attacked the disabled YT-1300 light freighter Z-Coral.
