# Sweeper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sweeper](https://starwars.fandom.com/wiki/Sweeper)

Sweeper was a BFF-1 bulk freighter that dropped off supplies to the same location where the Imperial Nebulon-B frigate Juvaini was attacked and destroyed.
