# Unidentified Aegis-class combat shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Aegis-class combat shuttle](https://starwars.fandom.com/wiki/Unidentified_Aegis-class_combat_shuttle)

An Aegis-class combat shuttle was assigned to the CR90 corvette FarStar during its mission to track down the rogue Imperial warlord, Moff Kentor Sarne. It was one of two vessels assigned to the ship, alongside the Loronar Corporation B-7 light freighter Muvon.
