# Sharp Spiral

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sharp Spiral](https://starwars.fandom.com/wiki/Sharp_Spiral)

The Sharp Spiral was the cherished personal starfighter of Jedi Master Saesee Tiin during the waning days of the Galactic Republic.

- **Manufacturer:** SoroSuub Corporation
- **Model:** Modified Cutlass-9 patrol fighter

- **Max Speed:** 8,000 km/h

- **Hyperdrive:** Class 1 (Class 0.6 equivalent with Saesee Tiin piloting)
- **Hdsystem:** Custom-built hyperdrive system
- **Shield Gen:** Equipped
- **Armament:**

  - Proton torpedo launcher (1)
- **Crew:** Pilot (1)
- **Passengers:** None
- **Role:** Starfighter
- **Affiliation:** Jedi Order
- **Captains:** Saesee Tiin
