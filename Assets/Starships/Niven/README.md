# Niven

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Niven](https://starwars.fandom.com/wiki/Niven)

Niven was a Rebel BFF-1 bulk freighter that supplied the makeshift B-wing assembly area before its destruction by Imperial forces.
