# Subla Ransom Medium Cargo Hauler

**Continuity:** Legends  
**Source:** [Subla Ransom Medium Cargo Hauler](https://starwars.fandom.com/wiki/Subla_Ransom_Medium_Cargo_Hauler)

The Subla Ransom Medium Cargo Hauler was a starship manufactured by Subla Ransom. The Zicreex, commanded by the Gamorrean sow Ugmush, was one, as was the Efficient, the personal transport of assassin droid Scar.

## Specifications

- **Name:** Subla Ransom Medium Cargo Hauler
- **Manufacturer:** Subla Ransom
- **Type:** Medium freighter
- **Cost:** 110,000 credits
- **Length:** 75.5 meters
- **Max Speed:** 950 kmh
- **Hyperdrive:**
  - Class 2.0 (primary)
  - Class 12.0 (backup)
- **Crew:** 5
- **Passengers:** 5
- **Capacity:** 700 metric tons
- **Consumables:** 3 months
- **Role:** Transport
