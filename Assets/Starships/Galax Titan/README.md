# Galax Titan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Galax Titan](https://starwars.fandom.com/wiki/Galax_Titan)

The Galax Titan was an X46-7-Class Ore Carrier that operated in the Elrood sector, sometime after the Battle of Yavin. It was attacked by pirate freighters.
