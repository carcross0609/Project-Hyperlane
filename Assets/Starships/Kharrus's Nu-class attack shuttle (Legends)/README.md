# Kharrus's Nu-class attack shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Kharrus's Nu-class attack shuttle/Legends](https://starwars.fandom.com/wiki/Kharrus%27s_Nu-class_attack_shuttle/Legends)

A Nu-class attack shuttle was used by a Galactic Republic delegation headed by Senator Kharrus during the Clone Wars. While Kharrus's team was attempting to deliver a ransom to Florrum in exchange for Count Dooku, the pirate Barb Mentir shot down the shuttle over Florrum.

- **Affiliation:**
