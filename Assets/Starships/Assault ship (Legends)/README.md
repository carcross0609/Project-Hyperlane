# Assault ship

**Continuity:** Legends  
**Source:** [Assault ship/Legends](https://starwars.fandom.com/wiki/Assault_ship/Legends)

For example, the Acclamator class was referred to as an assault ship, as was the All Terrain Rapid Deployment Pod, which was small enough to fit hundreds within a ship similar to the Acclamator. They could be used to carry troops or aircraft into combat situations and support their landing operations. Some assault ship designs were small enough to be used similar to boarding craft, attaching to larger space vessels with boarding troops inside.
