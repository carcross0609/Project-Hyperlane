# Clone impound vessel

**Continuity:** Canon  
**Source:** [Clone impound vessel](https://starwars.fandom.com/wiki/Clone_impound_vessel)

The clone impound vessel, also known as the tow truck, was a type of starship utilized by the clone troopers of the newly-formed Galactic Empire. The vessel featured two frontward-facing arms that could be used to seize starships. The clone impound vessel was utilized on the planet Saleucami, where starships&mdash;including civilian vessels&mdash;were seized and taken to an impound dock at the spaceport.

## Specifications

- **Name:** Clone impound vessel
- **Engine:** Equipped
- **Role:** Impounding
- **Affiliation:** Galactic Empire
