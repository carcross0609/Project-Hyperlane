# Sovereign

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sovereign (Sovereign-class)](https://starwars.fandom.com/wiki/Sovereign_%28Sovereign-class%29)

Sovereign was the lead ship of the Sovereign-class Super Star Destroyer line. It was still under construction during the time of the Dark Empire.
