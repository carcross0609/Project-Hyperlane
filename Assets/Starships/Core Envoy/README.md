# Core Envoy

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Core Envoy](https://starwars.fandom.com/wiki/Core_Envoy)

The Core Envoy was an Imperial-class Star Destroyer used by the Imperial Navy during the Imperial Era. The Star Destroyer was equipped with engines and measured 1,600 meters long. In 14 BBY, the Core Envoy was the sole Imperial-class Star Destroyer in the flotilla belonging to Sentinel Base, an Imperial facility commanded by Moff Wilhuff Tarkin which oversaw the construction of the Imperial battle station later known as the Death Star.
