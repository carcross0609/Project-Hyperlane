# Dalgo

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Dalgo (starship)](https://starwars.fandom.com/wiki/Dalgo_%28starship%29)

The Dalgo was a civilian patrol craft used by Saw Gerrera's Partisans. The ship had the capability of multiple propulsion methods, including sustained thruster bursts and also antigravity repulsors.

## Specifications

- **Name:** Dalgo
- **Type:** Civilian patrol craft
- **Engine:** Thrusters
- **Aliases:** Partisans
