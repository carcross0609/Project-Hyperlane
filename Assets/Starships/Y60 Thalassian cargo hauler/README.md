# Y60 Thalassian cargo hauler

**Continuity:** Legends  
**Source:** [Y60 Thalassian cargo hauler](https://starwars.fandom.com/wiki/Y60_Thalassian_cargo_hauler)

The Y60 Thalassian cargo hauler was a type of freighter starship. The smuggler Pinchers owned one until it was "borrowed" by Luke Skywalker in order to infiltrate the Cavrilhu Pirate base in the Kauron asteroid field.
