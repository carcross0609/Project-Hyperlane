# NX-1200

**Continuity:** Legends  
**Source:** [NX-1200](https://starwars.fandom.com/wiki/NX-1200)

The NX-1200 was a starship model in use during the Galactic War. Captain Ari Skyff owned one such ship which he called Corvani. Giana Kayl was another such owner, who called her vessel Meridian Grace.
