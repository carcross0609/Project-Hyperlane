# Sea Killer

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sea Killer](https://starwars.fandom.com/wiki/Sea_Killer)

The Sea Killer was a B'zabuu-class transport owned by Toba. After owning the craft for a month, Toba painted the stylized face of an opee sea killer on the transport's nose. Toba also installed a Getaway concussion missile launcher, removed from a YG-4400 light freighter, which he used for emergency escapes.
