# Opportunity

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Opportunity (Nebulon-B)](https://starwars.fandom.com/wiki/Opportunity_%28Nebulon-B%29)

The Opportunity was a EF76 Nebulon-B escort frigate that served under the banner of Jinata Security during the Cold War. The vessel was eventually disabled above Athulla by Inferno Squad while carrying out Project Resurrection.

## Specifications

- **Name:** Opportunity
- **Manufacturer:** Kuat Drive Yards
- **Model:** Modified EF76 Nebulon-B escort frigate
- **Type:** Frigate
- **Length:** 300 meters
- **Armament:** Laser cannons
- **Complement:** Leema Kai's N-1 starfighter
- **Affiliation:**
  - First Order
  -   Jinata Security
- **Captains:** Leema Kai
