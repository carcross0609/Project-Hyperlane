# Gav Daragon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Gav Daragon (Valor-class)](https://starwars.fandom.com/wiki/Gav_Daragon_%28Valor-class%29)

The Gav Daragon was a Valor-class cruiser serving in the Republic fleet during the Great Galactic War and the subsequent Cold War with the reconstituted Sith Empire. Late in the Cold War, it served in the First Expeditionary Fleet for the Republic forces. It is named for Gav Daragon, a Koros native hyperspace explorer who discovered Korriban.
