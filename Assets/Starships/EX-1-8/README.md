# EX-1-8

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [EX-1-8](https://starwars.fandom.com/wiki/EX-1-8)

EX-1-8 was an Imperial Navy TIE/sa bomber that was manufactured by Sienar Fleet Systems. As a TIE/sa bomber, EX-1-8 carried a destructive payload consisting of proton torpedoes, guided concussion missiles, space mines, and free-falling thermal detonators. Around 3 ABY, EX-1-8 flew through the Hoth asteroid field.
