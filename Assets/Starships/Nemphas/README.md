# Nemphas

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nemphas](https://starwars.fandom.com/wiki/Nemphas)

The Nemphas was a freighter owned by Gorga Desilijic Aarrpo that shot down the Spirit of Jabba near Mos Eisley on Tatooine.

## Specifications

- **Name:** Nemphas
- **Type:** Escort freighter
- **Crew:** 3
- **Affiliation:** Desilijic
