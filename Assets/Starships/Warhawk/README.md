# Warhawk

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Warhawk](https://starwars.fandom.com/wiki/Warhawk)

The Warhawk was a Raider I-class corvette that served alongside the Sargantuan and the Blood Ambition in the navy of the Galactic Empire. It was a part of the task force led by Captain Ralchio Nervi.

## Specifications

- **Name:** Warhawk
- **Manufacturer:** Kuat Drive Yards
- **Line:** Raider-class corvette
- **Model:** Raider I-class corvette
- **Type:** Corvette
- **Length:** 150 meters
- **Armament:**
  - Chin-mounted twin light turbolasers
  - 6 turret-mounted heavy laser cannons
  - 1 chin-mounted ion cannon
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
- **Fleet:**
  - 14th Sector Fleet
  -   Ralchio Nervi's task force
