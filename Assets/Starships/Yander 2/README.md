# Yander 2

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Yander 2](https://starwars.fandom.com/wiki/Yander_2)

Yander 2 was a YT-1300 light freighter aligned with the Galactic Empire. It was present at the Skirmish at Outpost D-34, and was carrying water.
