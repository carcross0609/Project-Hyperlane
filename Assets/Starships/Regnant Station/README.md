# Regnant Station

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Regnant Station](https://starwars.fandom.com/wiki/Regnant_Station)

Regnant Station was a space station that served as a refueling outpost in the Unknown Regions for the Sith Empire during the Galactic War. The Galactic Republic discovered the station's location and attacked it, destroying the station.
