# Idiot's Array

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Idiot's Array (starship)](https://starwars.fandom.com/wiki/Idiot%27s_Array_%28starship%29)

The Idiot's Array was a modified corvette and part of smuggler Talon Karrde's fleet. During the Invasion of Yavin 4 of the Yuuzhan Vong War, it was used to ferry the younglings of the Jedi Praxeum of Yavin 4 to Coruscant where they would be out of danger.

## Specifications

- **Name:** Idiot's Array
- **Type:** Modified Corellian Corvette
- **Length:** 27 meters
- **Navigation:** Navicomputer
- **Destroyed:** 26 ABY
- **Affiliation:** Car'das smugglers
- **Captains:** Shada D'ukal
