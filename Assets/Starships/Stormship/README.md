# Stormship

**Continuity:** Canon  
**Source:** [Stormship](https://starwars.fandom.com/wiki/Stormship)

Stormships were a class of vessel utilized by the marauder group known as the Nihil. Eye of the Nihil Marchion Ro organized for a Stormship to be sent on a Path that intercepted the route taken by the freighter Legacy Run. Ro's actions intentionally caused the Great Hyperspace Disaster, in which the Legacy Run, attempting to avoid the Stormship, came apart in hyperspace.

## Specifications

- **Name:** Stormship
- **Hdsystem:** Equipped
- **Othersystems:** Path engine
