# Unidentified Consular-class cruiser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Consular-class cruiser (Scipio)](https://starwars.fandom.com/wiki/Unidentified_Consular-class_cruiser_%28Scipio%29)

This Consular-class cruiser was part of the Republic garrison that was sent to Scipio to defend Republic interests and Scipio's neutrality. It was accompanied by several LAAT/i gunships and dozens of Clone shock troopers.
