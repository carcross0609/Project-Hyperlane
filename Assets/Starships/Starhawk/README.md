# Starhawk

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Starhawk](https://starwars.fandom.com/wiki/Starhawk)

The Starhawk was the prototype of the Starhawk-class battleship line and the product of the New Republic's Project Starhawk during the Galactic Civil War.
