# Message dinghy

**Continuity:** Legends  
**Source:** [Message dinghy](https://starwars.fandom.com/wiki/Message_dinghy)

A message dinghy was a small transport, akin to a hyperspace courier tube, that was created to transfer coded information from one area to another, generally between starships.
