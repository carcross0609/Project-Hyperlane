# AAL-1971/9.1 Troop Transport

**Continuity:** Canon  
**Source:** [AAL-1971/9.1 Troop Transport](https://starwars.fandom.com/wiki/AAL-1971/9.1_Troop_Transport)

The AAL-1971/9.1 Troop Transport, also known as an Atmospheric Assault Lander (AAL), First Order Transporter, or First Order shuttle was an armored troop carrier operated by the First Order designed to ferry up to twenty stormtroopers from orbital vessels to planetary surfaces.
