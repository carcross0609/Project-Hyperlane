# Imperial Patrol Ship

**Continuity:** Legends  
**Source:** [Imperial Patrol Ship](https://starwars.fandom.com/wiki/Imperial_Patrol_Ship)

The Imperial Patrol Ship was a militarized variant of the Corellian Engineering Corporation Action IV transport. It saw service during the Galactic Civil War as a support ship for remote Imperial outposts, combining the twin roles of resupplying Imperial personnel and performing customs inspections.

## Specifications

- **Name:** Imperial Patrol Ship
- **Manufacturer:** Corellian Engineering Corporation
- **Line:** Action series
- **Type:** Modified bulk freighter
- **Length:** 100 meters
- **Hyperdrive:** Class 3
- **Hull:** 2D
- **Armament:** 2 laser cannons
- **Complement:** 2 TIE starfighters
- **Crew:**
  - 8 crew
  -   2 gunners
- **Passengers:** 4
- **Capacity:** 74,000 TM
- **Consumables:** 3 months
- **Affiliation:**
  - Imperial Navy
  - Imperial Customs
