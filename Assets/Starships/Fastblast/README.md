# Fastblast

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Fastblast](https://starwars.fandom.com/wiki/Fastblast)

Fastblast was a pirate cruiser affiliated with the Invids ran by the renegade Admiral Leonia Tavira. The ship's crew referred to themselves as the Fastblasters.
