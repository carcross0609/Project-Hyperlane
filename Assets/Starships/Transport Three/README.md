# Transport Three

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Transport Three](https://starwars.fandom.com/wiki/Transport_Three)

Transport Three was a class four container transport in service to the Galactic Empire between 19 BBY and 18 BBY.

## Specifications

- **Name:** Transport Three
- **Manufacturer:** Kuat Drive Yards
- **Model:** Class four container transport
- **Type:** Bulk freighter
- **Length:** 233 meters
- **Max Speed:** 700 kph
- **Engine:** Sublight engines (3)
- **Armament:**
  - Top-mounted double-barreled turbolaser battery (1)
  - Side-mounted laser turrets (2)
- **Escapepods:** Six Equipped
- **Crew:** Two pilots
- **Capacity:** Up to 210 large containers
- **Role:** Hauling cargo crates and containers
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
