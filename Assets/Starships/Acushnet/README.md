# Acushnet

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Acushnet](https://starwars.fandom.com/wiki/Acushnet)

The Acushnet was a Corona-class armed frigate that was originally going to be sold to investors and starship collectors following the end of the Separatist-planned production. The pirate captain Hondo Ohnaka managed to steal the Acushnet and classified it as the flagship of the Ohnaka Gang.
