# Trait Luminique

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Trait Luminique](https://starwars.fandom.com/wiki/Trait_Luminique)

The Trait Luminique was a prototype starship built by the corporation Flight Unlimited Group in their base on the planet Lankor VI. It possessed incredible energy boosters and a powerful hyperdrive.
