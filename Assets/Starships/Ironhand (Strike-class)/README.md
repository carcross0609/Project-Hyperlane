# Ironhand

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ironhand (Strike-class)](https://starwars.fandom.com/wiki/Ironhand_%28Strike-class%29)

The Ironhand was an Imperial Strike-class medium cruiser that served as part of Task Force Vengeance during the Galactic Civil War. It was escorting part of the Task Force's convoy. However, the convoy ships containing Warheads would be destroyed by Rebel A-wings to buy time for the Rebels. The Cruiser would then attempt to stop the s from capturing the Interdictor Compellor. However the cruiser was destroyed by X-wings and B-wings.
