# Freejack

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Freejack](https://starwars.fandom.com/wiki/Freejack)

The Freejack was a modified IPV-1 patrol craft that was captured from a planetary defense network by Frei Aycen, during the time leading up to the Clone Wars. Refitting the ship to have additional cargo space, and removing several shield generators in order to make room and power available for a hyperdrive, Aycen made sure the ship had room for 400 metric tons of cargo, and was armed with four light turbolasers and a tractor beam projector.
