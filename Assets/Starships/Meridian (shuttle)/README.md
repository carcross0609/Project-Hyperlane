# Meridian (shuttle)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Meridian (shuttle)](https://starwars.fandom.com/wiki/Meridian_%28shuttle%29)

The Meridian was a sleek, black-hulled shuttle used by New Republic Intelligence to ferry the bodies of Doctors Kroddok Stopa and Josala Krenn, several recovered Qella bodies and artifacts back to Coruscant. She was captained by Wagg.
