# Penumbra

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Penumbra (Star Destroyer)](https://starwars.fandom.com/wiki/Penumbra_%28Star_Destroyer%29)

The Penumbra was a First Order Star Destroyer that traveled to Batuu in order to capture a Resistance spy codenamed Starling and bring her to the Finalizer. First Order Lieutenant Wulfgar Kath was stationed aboard the ship along with his squad, which was second-in-commanded by the stormtrooper CE-6675 and included twenty other troopers, including CD-5502.
