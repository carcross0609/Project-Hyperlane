# Shotel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Shotel](https://starwars.fandom.com/wiki/Shotel)

Shotel was a Strike-class medium cruiser in the Imperial Navy. Shotel, along with Nagan, were sent to reinforce the Immobilizer 418 cruiser Red Claw position and assist Maarek Stele in destroying the Kopsh.
