# Imperial Gozanti-class cruiser

**Continuity:** Canon  
**Source:** [Imperial Gozanti-class cruiser](https://starwars.fandom.com/wiki/Imperial_Gozanti-class_cruiser)

The Imperial Gozanti-class Cruiser, also referred to as the Imperial Gozanti-class TIE carrier and known generally as the Imperial freighter, was a converted and heavily modified model of the standard civilian Gozanti-class cruiser used by the Galactic Empire and later by sympathizers of the First Order.
