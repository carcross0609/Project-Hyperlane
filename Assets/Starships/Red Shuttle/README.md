# Red Shuttle

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red Shuttle](https://starwars.fandom.com/wiki/Red_Shuttle)

Red Shuttle was a blocky shuttle made by Telgorn Corporation and stationed aboard the Eye of Palpatine. In 12 ABY, Nichos Marr operated the shuttle via remote control in order to evacuate the inhabitants of the Eye.
