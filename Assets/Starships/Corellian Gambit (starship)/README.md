# Corellian Gambit (starship)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Corellian Gambit (starship)](https://starwars.fandom.com/wiki/Corellian_Gambit_%28starship%29)

The Corellian Gambit was a light hauler captained by Shandy Fanaso. During the Imperial Period, he converted its hold into a cantina, dubbed "Shandy's Place".
