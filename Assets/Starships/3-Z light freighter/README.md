# 3-Z light freighter

**Continuity:** Legends  
**Source:** [3-Z light freighter](https://starwars.fandom.com/wiki/3-Z_light_freighter)

The 3-Z light freighter was a freighter made by Nova-Drive. It was an upgraded version of the YT-1200 light freighter design to make it competitive with contemporary offerings in the independent spacer market.
