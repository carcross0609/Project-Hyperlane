# Dodonna

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Dodonna (Galactic-class)](https://starwars.fandom.com/wiki/Dodonna_%28Galactic-class%29)

Dodonna was a Galactic-class battle carrier in the Galactic Alliance Defense Fleet.

## Specifications

- **Name:** Dodonna
- **Type:** Galactic-class battle carrier
- **Complement:**
  - One bay:
  - XJ6 X-wing starfighters (1 squadron)
  - Eta-5 interceptors (1 squadron)
  - Shield equipped TIE/LN starfighters (2 squadrons)
  - B-wing starfighters (1/2 squadron)
- **Role:**
  - Carrier
  - Destroyer
  - Command ship
- **Affiliation:** Galactic Federation of Free Alliances
- **Navy:** Galactic Alliance Second Fleet
- **Captains:**
  - Admiral Matric Klauskin
  - Admiral Tarla Limpan
