# Majestic

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Majestic (Imperial-class)](https://starwars.fandom.com/wiki/Majestic_%28Imperial-class%29)

Majestic was an Imperial I-class Star Destroyer that served as Emperor Palpatine's private flagship in the months following the Battle of Hoth.

## Specifications

- **Name:** Majestic
- **Manufacturer:** Kuat Drive Yards
- **Type:** Imperial I-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** TIE/LN starfighters
- **Affiliation:** Galactic Empire
- **Owners:** Palpatine
