# HCT-2001 Dragonboat-class Reugeot 905 freighter

**Continuity:** Canon  
**Source:** [HCT-2001 Dragonboat-class Reugeot 905 freighter](https://starwars.fandom.com/wiki/HCT-2001_Dragonboat-class_Reugeot_905_freighter)

The HCT-2001 Dragon-class Reugeot 905 freighter, also known as the Trandoshan prisoner ship, also known as the Trandoshan transport, or Trandoshan slave ship, was a model of freighter which was well-suited to transporting captive beings. Garnac's hunting guild used one of these ships to ferry prisoners intended to be hunted as prey on the moon Wasskah. The HCT-2001 was also later used by pirate gangs, including that of the Syvik Delegation.
