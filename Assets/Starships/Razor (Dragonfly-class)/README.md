# Razor

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Razor (Dragonfly-class)](https://starwars.fandom.com/wiki/Razor_%28Dragonfly-class%29)

The Razor was a modified Dragonfly-class Imperial drop ship used by the bounty hunter Vrath Xizor during the Great Galactic War. It was later stolen by smuggler Zeerid Korr.

## Specifications

- **Name:** Razor
- **Model:** Dragonfly-class Imperial drop ship
- **Type:** Dropship
- **Owners:**

  - Zeerid Korr
