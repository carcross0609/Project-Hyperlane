# Brentaal

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Brentaal](https://starwars.fandom.com/wiki/Brentaal)

The Brentaal was a starship used by the Imperial Navy during the Imperial Era. It shared its name with the Core world Brentaal IV. In 14 BBY, the vessel was attached to Rampart Station, an Imperial marshaling depot for supply ships bound for the planet Geonosis, where the Imperial battle station later known as the Death Star was being constructed.
