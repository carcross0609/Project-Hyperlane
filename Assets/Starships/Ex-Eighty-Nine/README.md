# Ex-Eighty-Nine

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ex-Eighty-Nine](https://starwars.fandom.com/wiki/Ex-Eighty-Nine)

Ex-Eighty-Nine was a automated shuttle belonging to Calamari Shuttles. Due to an autopilot malfunction, it crashed on Dac with a group of Alliance to Restore the Republic operatives on board.
