# Starscape-class yacht

**Continuity:** Legends  
**Source:** [Starscape-class yacht](https://starwars.fandom.com/wiki/Starscape-class_yacht)

The Starscape-class yacht was an elegant and very rare yacht created by Eleaor Propulsion. The most notable ship of this class was the Visionary, the personal transport of Exchange boss G0-T0.

## Specifications

- **Name:** Starscape-class yacht
- **Manufacturer:** Eleaor Propulsion
- **Model:** Starscape-class Yacht
- **Type:** Yacht

- **Hyperdrive:** Class 1

- **Crew:** 14

- **Capacity:** 50 metric tons

- **Availability:** Unique
- **Role:** Colossal space transport
