# Unidentified Ishi Tib cruise ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Ishi Tib cruise ship](https://starwars.fandom.com/wiki/Unidentified_Ishi_Tib_cruise_ship)

During the Galactic War between the Galactic Republic and the reconstituted Sith Empire, an Ishi Tib cruise ship was repeatedly preyed upon by pirates, regardless of which hyperroutes that the cruise ship tried to travel on.
