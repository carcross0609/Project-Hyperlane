# Agr (starfighter)

**Continuity:** Legends  
**Source:** [Agr (starfighter)](https://starwars.fandom.com/wiki/Agr_%28starfighter%29)

The Agr was a model of Wookiee starfighter named after an animal indigenous to Kashyyyk. It was designed and optimized for atmospheric flight, but could also engage in dogfights in space. It was the predecessor of the Fast Agr.
