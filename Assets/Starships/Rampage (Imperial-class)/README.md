# Rampage

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rampage (Imperial-class)](https://starwars.fandom.com/wiki/Rampage_%28Imperial-class%29)

The Rampage was an Imperial-class Star Destroyer commanded by Lumiya shortly after the Battle of Endor. It was capable of carrying 72 TIE Fighters.

## Specifications

- **Name:** Rampage
- **Manufacturer:** Kuat Drive Yards
- **Model:** Imperial-class Star Destroyer
- **Length:** 1,600 meters
- **Complement:** 72 TIE/LN starfighters
- **Affiliation:** Galactic Empire
- **Navy:** Lumiya's fleet
- **Owners:** Lumiya
