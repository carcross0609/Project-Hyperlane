# Cargo shuttle

**Continuity:** Canon  
**Source:** [Cargo shuttle](https://starwars.fandom.com/wiki/Cargo_shuttle)

Cargo shuttles were a type of shuttle specifically designed to ferry cargo between locations. The Zeta-class Heavy Cargo Shuttle was a model of cargo shuttle manufactured by the Telgorn Corporation and used extensively by the Galactic Empire.
