# Mu 1

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Mu 1](https://starwars.fandom.com/wiki/Mu_1)

Mu 1 was the call sign of an Assault Gunboat of the Galactic Empire that targeted the Rebel Alliance Class-D cargo container Pi alongside the IPV-1 System Patrol Craft Scythis.
