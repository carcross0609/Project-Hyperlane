# Elite

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Elite (EF76 Nebulon-B escort frigate)](https://starwars.fandom.com/wiki/Elite_%28EF76_Nebulon-B_escort_frigate%29)
