# BTL-A4 Y-wing starfighter

**Continuity:** Legends  
**Source:** [BTL-A4 Y-wing starfighter/Legends](https://starwars.fandom.com/wiki/BTL-A4_Y-wing_starfighter/Legends)

The BTL-A4 Y-wing starfighter was the one-man version of the BTL-S3 starfighter model.

## Specifications

- **Name:** BTL-A4 Y-wing starfighter
- **Manufacturer:** Koensayr Manufacturing
- **Line:** BTL Y-wing starfighter
- **Model:** BTL-A4 Y-wing starfighter
- **Type:** Attack starfighter
- **Length:** 16 meters
- **Max Accel:**
  - 2,700 G
  - 11 MGLT/s
- **Mglt:** 80 MGLT
- **Max Speed:** 1000 km/h (higher speeds possible with deflector shields on)
- **Maneuverability:** 59 DPF
- **Engine:** 2 Koensayr R200 ion jet engines (rated 250 KTU)
- **Hyperdrive:** Class 1.0
- **Hdsystem:** Koensayr R300-H hyperdrive motivator
- **Power:** Novaldex power generator; Thiodyne 03-R cryogenic power cells and ionization reactor
- **Shield Gen:** Chempat Shield Generator (rated 75 SBD)
- **Hull:** Titanium-reinforced Alusteel alloy (rated 40 RU)
- **Sensor:** Fabritech ANx-y long-range sensor array with PA-9r long range phased tachyon detection array and PG-7u short range primary threat analysis grid
- **Target:** Fabritech ANc 2.7 tracking computer with either the SI 5g7 "Quickscan" vector imaging system or the IN-344-B "Sightline" holographic imaging system
- **Avionics:** Subpro NH-7 flight control avionics package
- **Armament:**
  - Taim & Bak IX4 or KX5 laser cannons (2)
  - ArMek turreted SW-4 ion cannons (2)
  - Arakyd Flex Tube proton torpedo launchers (2)
  -   10 torpedoes total
  - or
  - 20 proton bombs
- **Crew:**
  - Pilot (1)
  - Astromech droid (1)
- **Passengers:** None
- **Capacity:** 110 kilograms
- **Consumables:** 1 week
- **Othersystems:**
  - Guidenhauser ejection systems
  - Detachable cockpit
- **Role:**
  - Starfighter
  - Bomber
  - Escort
  - Scout
  - Courier
  - Shuttle
- **Affiliation:**
  - Alliance to Restore the Republic
  - Alliance of Free Planets
  - New Republic
  - Galactic Federation of Free Alliances
  - Planetary Security Forces
  - Pirates
  - Mercenaries
