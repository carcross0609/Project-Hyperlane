# Sunspire

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Sunspire](https://starwars.fandom.com/wiki/Sunspire)

The Sunspire was an Alderaanian frigate gifted from the Princess of Alderaan, Leia Organa, to a flotilla composed of seven ships designed to search for anything of note from the crew's former world, Alderaan.

## Specifications

- **Name:** Sunspire
- **Type:** Frigate
- **Affiliation:**
