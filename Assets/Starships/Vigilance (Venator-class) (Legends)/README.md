# Vigilance

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vigilance (Venator-class)/Legends](https://starwars.fandom.com/wiki/Vigilance_%28Venator-class%29/Legends)

The Vigilance was a Venator-class Star Destroyer that was part of the Republic's Open Circle Fleet. It served as a flagship of High Jedi General Obi-Wan Kenobi during the final year of the Clone Wars.
