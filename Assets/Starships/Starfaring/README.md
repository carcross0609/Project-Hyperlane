# Starfaring

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Starfaring](https://starwars.fandom.com/wiki/Starfaring)

The Starfaring was a spaceliner that was crewed by Bothans. It went missing in the Malrev system, and was later found by members of Rogue Squadron.

## Specifications

- **Name:** Starfaring
- **Type:** Spaceliner
- **Affiliation:** New Republic
- **Captains:** Girov Dza'tey
