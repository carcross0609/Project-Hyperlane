# Ars Opus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ars Opus](https://starwars.fandom.com/wiki/Ars_Opus)

Ars Opus was a BFF-1 bulk freighter that was carrying R2-series astromech droids to the Imperial-class Star Destroyer Invincible when it apparently broke down in the Rudrig system.

- **Height:** 34 meters
