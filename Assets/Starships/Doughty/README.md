# Doughty

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Doughty](https://starwars.fandom.com/wiki/Doughty)

The Doughty was an Acclamator-class assault ship of the Republic Navy during the Clone Wars. It was destroyed by Separatist forces during the Battle of Duro.
