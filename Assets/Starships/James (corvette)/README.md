# James (corvette)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [James (corvette)](https://starwars.fandom.com/wiki/James_%28corvette%29)

James was a CR92a Assassin-class corvette used by the Galactic Empire. The corvette was in reserve should the other modified corvette Burke was destroyed during an operation to capture one of two Rebel Escort Carriers Prowler.
