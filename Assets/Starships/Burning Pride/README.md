# Burning Pride

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Burning Pride](https://starwars.fandom.com/wiki/Burning_Pride)

The Burning Pride was a Yuuzhan Vong miid ro'ik cruiser. It served as Deign Lian's flagship at the Battle of Garqi.
