# Patrol One

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Patrol One](https://starwars.fandom.com/wiki/Patrol_One)

Patrol One was a Chiss patrol ship stationed at Taharim Academy on Naporar. Mitth'raw'nuruodo proved that he had not cheated on a flight simulator by flying against Patrol One and three other ships.

- **Name:** Patrol One
- **Type:** Patrol ship
