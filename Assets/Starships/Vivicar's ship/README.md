# Vivicar's ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vivicar's ship](https://starwars.fandom.com/wiki/Vivicar%27s_ship)

During the Dark Plague crisis, Lord Vivicar operated from a ship drifting in deep space. The Sith Lord was tracked there by a Jedi Consular and defeated in a final confrontation.
