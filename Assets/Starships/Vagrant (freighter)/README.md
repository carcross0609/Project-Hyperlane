# Vagrant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Vagrant (freighter)](https://starwars.fandom.com/wiki/Vagrant_%28freighter%29)

The Vagrant was a Corellian Engineering Corporation YV-666 light freighter owned by the Aqualish crime lord and smuggler Bandin Dobah. It served as Dobah's hideout but was badly maintained and its hyperdrive did not work anymore.
