# Peregrine

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Peregrine (Dreadnaught-class)](https://starwars.fandom.com/wiki/Peregrine_%28Dreadnaught-class%29)

The Peregrine was a Dreadnaught-class heavy cruiser that served in the Katana fleet of the Old Republic and later as General Bel Iblis's flagship during the Galactic Civil War.

## Specifications

- **Name:** Peregrine
- **Manufacturer:** Rendili StarDrive
- **Model:** Dreadnaught-class heavy cruiser
- **Sysmods:** Slave circuit
- **Crew:** 2,200
- **Othersystems:** Decryption equipment in an external comm blister
- **Role:** Flagship
- **Affiliation:**
  - Galactic Republic
  - Garm Bel Iblis's movement
  - New Republic
- **Navy:**
  - Judicial Fleet
  -   Katana fleet
  - Bel Iblis' personal fleet
  - New Republic Defense Fleet
- **Owners:** General Garm Bel Iblis
- **Captains:** Captain Tre-na
