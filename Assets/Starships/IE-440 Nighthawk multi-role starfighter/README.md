# IE-440 Nighthawk multi-role starfighter

**Continuity:** Canon  
**Source:** [IE-440 Nighthawk multi-role starfighter](https://starwars.fandom.com/wiki/IE-440_Nighthawk_multi-role_starfighter)

The IE-440 Nighthawk multi-role starfighter was a class of starfighter that was intended to be used by the Galactic Republic during the Clone Wars, but the war ended in the vessel's prototype stage. Later during the Imperial Era, the Rebel Alliance Intelligence Service used the starfighter as part of their operations.
