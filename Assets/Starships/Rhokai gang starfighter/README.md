# Rhokai gang starfighter

**Continuity:** Canon  
**Source:** [Rhokai gang starfighter](https://starwars.fandom.com/wiki/Rhokai_gang_starfighter)

A class of starfighter was used by the Rhokai gang during the Imperial Era. They pursued the renegade Clone Force 99 in a space battle after the clones stole a lizard named Ruby from the Rhokai.

## Specifications

- **Name:** Rhokai gang starfighter
- **Type:** Starfighter
- **Role:** Assault fighter
- **Affiliation:** Rhokai gang
