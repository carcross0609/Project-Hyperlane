# True Justice

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [True Justice](https://starwars.fandom.com/wiki/True_Justice)

The True Justice was an Imperial prison ship, which was used to hold trials for political prisoners in space, rather than on a planet which might potentially support the prisoners.

## Specifications

- **Name:** True Justice
- **Type:** YT-series Corellian transport
- **Crew:**
  - Imperial officers
  - Courtroom officers
- **Passengers:** Prisoners
- **Destroyed:** 18 BBY
- **Affiliation:** Galactic Empire
- **Captains:** Tran
