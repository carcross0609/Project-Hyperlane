# Raider II-class corvette

**Continuity:** Legends  
**Source:** [Raider II-class corvette/Legends](https://starwars.fandom.com/wiki/Raider_II-class_corvette/Legends)

The Raider II-class corvette was the second sub-class of the Raider-class line of corvettes used by the Galactic Empire during the Galactic Civil War. It was preceded by the Raider I-class corvette.
