# Imperial convoy ship

**Continuity:** Legends  
**Source:** [Imperial convoy ship](https://starwars.fandom.com/wiki/Imperial_convoy_ship)

The Imperial convoy ship was a type of Imperial cargo ship used by the Galactic Empire.

## Specifications

- **Name:** Imperial convoy ship
- **Type:** Cargo ship
- **Hdsystem:** Equipped
- **Complement:** At least one TIE/LN starfighter
- **Passengers:** At least 7
- **Role:** Transport
- **Affiliation:**
  - Galactic Empire
  - Alliance to Restore the Republic (briefly)
