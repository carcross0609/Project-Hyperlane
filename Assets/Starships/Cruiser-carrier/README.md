# Cruiser-carrier

**Continuity:** Canon  
**Source:** [Cruiser-carrier](https://starwars.fandom.com/wiki/Cruiser-carrier)

A cruiser-carrier was a type of cruiser that primarily served as a carrier. The Quasar Fire-class bulk cruiser was used by the Galactic Empire as a type of cruiser-carrier, and was considered a light carrier.
