# Watcher

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Watcher (Thaere)](https://starwars.fandom.com/wiki/Watcher_%28Thaere%29)

The Watcher was a customs frigate that served in the Navy of Thaere during the Clone Wars. It was used as a customs ship in the Cularin system.

## Specifications

- **Name:** Watcher
- **Type:** Frigate
- **Role:** Customs ship
