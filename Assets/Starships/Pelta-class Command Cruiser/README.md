# Pelta-class Command Cruiser

**Continuity:** Canon  
**Source:** [Pelta-class Command Cruiser](https://starwars.fandom.com/wiki/Pelta-class_Command_Cruiser)

The Pelta-class Command Cruiser, also known as the Pelta-class Command Ship, was a variant of the Pelta-class frigate, used as a command ship. The Alliance to Restore the Republic used modified Pelta-class Command Ships during the Galactic Civil War. At one point, a Pelta-class Command Cruiser was escorted by two MC30C Frigates over a gas giant. It was equipped with turbolasers.

## Specifications

- **Name:** Pelta-class Command Cruiser
- **Model:** Pelta-class frigate
- **Type:** Cruiser
- **Armament:** Turbolasers
- **Role:** Command ship
- **Affiliation:** Alliance to Restore the Republic
