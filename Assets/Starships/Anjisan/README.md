# Anjisan

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Anjisan](https://starwars.fandom.com/wiki/Anjisan)

Anjisan was an Imperial Nebulon-B escort frigate that tried to disrupt a cargo exchange between the Rebel Alliance and the Habassa above Retep III.
