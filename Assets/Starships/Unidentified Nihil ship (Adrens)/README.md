# Unidentified Nihil ship

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified Nihil ship (Adrens)](https://starwars.fandom.com/wiki/Unidentified_Nihil_ship_%28Adrens%29)

A ship previously owned by the Nihil marauder organization was stranded in space not far from the Stormwall during the High Republic Era. In 229 BBY, a mission was undertaken by the Adrens to retrieve the starship which would greatly help the Galactic Republic.
