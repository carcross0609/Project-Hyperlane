# Corpulentus

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Corpulentus](https://starwars.fandom.com/wiki/Corpulentus)

The Corpulentus was a starship in the Confederate Navy and the flagship of Admiral Pors Tonith. It was destroyed at the Battle of Praesitlyn.
