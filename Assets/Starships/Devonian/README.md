# Devonian

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Devonian](https://starwars.fandom.com/wiki/Devonian)

The Devonian was an assault shuttle used in the First Battle of Borleias. Judder Page was on the ship, which was saved from TIE interceptors by Rogue Squadron X-wings under Corran Horn.
