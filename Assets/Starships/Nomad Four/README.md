# Nomad Four

**Continuity:** Canon  
**Source:** [Nomad Four](https://starwars.fandom.com/wiki/Nomad_Four)

The Nomad Four was a class of starship. It was the civilian version of the Seltaya military courier ship. One Nomad Four, the Possibility, was used by the Naboo Royal Handmaiden Duja to travel to the planet Batuu during the Clone Wars.

## Specifications

- **Name:** Nomad Four
- **Model:** Civilian Seltaya military courier ship
- **Type:** Transport
- **Shield Gen:** Deflector shield
- **Armament:**
  - Twin laser cannons
  - Proton torpedoes
- **Escapepods:** At least 1
