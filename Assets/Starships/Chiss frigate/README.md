# Chiss frigate

**Continuity:** Canon  
**Source:** [Chiss frigate](https://starwars.fandom.com/wiki/Chiss_frigate)

A class of frigate was utilized by the Chiss Ascendancy. It was the fifth largest class of warship used by the Ascendancy, behind the Heavy cruiser, and the Man-of-war classifications. One such frigate, the Midsummer, was part of the fleet used by the Xodlak family, although it was abandoned on Celwis's largest moon.

## Specifications

- **Name:** Chiss frigate
- **Type:** Frigate
