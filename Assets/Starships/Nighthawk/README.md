# Nighthawk

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Nighthawk](https://starwars.fandom.com/wiki/Nighthawk)

Nighthawk was a B-7 light freighter bought by Jedi Grand Master Yoda in a junkyard on Jovan Station following Asajj Ventress's, a Dark Jedi, attack on Phindar Spaceport.

## Specifications

- **Name:** Nighthawk
- **Model:** B-7 light freighter
- **Sensor:** Carbanti active sensor stack
- **Maincomp:** Hanx-Wargel SuperFlow II
- **Communications:** Siep-Irol passive sensor antenna
- **Affiliation:** Jedi Order
- **Owners:** Yoda
