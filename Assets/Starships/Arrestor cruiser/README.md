# Arrestor cruiser

**Continuity:** Canon  
**Source:** [Arrestor cruiser](https://starwars.fandom.com/wiki/Arrestor_cruiser)

An arrestor cruiser, or patrol and detainment cruiser was a type of cruiser that utilized powerful tractor beam projectors. The Cantwell-class 410 cruiser was a model of arrestor cruiser used by the Galactic Empire.
