# Raven's Claw

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Raven's Claw](https://starwars.fandom.com/wiki/Raven%27s_Claw)

The Raven's Claw was a fast light courier that replaced Kyle Katarn's old ship, the Moldy Crow.

- **Name:** Raven's Claw
- **Type:** Light courier
- **Length:** 20 meters
- **Armament:** laser cannons, 2 proton torpedo launchers
- **Crew:**

  - Co-Pilot (1)
- **Skeleton:** 1 (pilot)
- **Passengers:** 2
- **Role:** Shuttle
- **Affiliation:** New Republic
- **Captains:** Kyle Katarn
