# Red (CR90 corvettes)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red (CR90 corvettes)](https://starwars.fandom.com/wiki/Red_%28CR90_corvettes%29)

Red were a pair of Corellian corvettes used by a civilian organization. Both were scanned by a TIE Defender which identified their cargo as "Crew". The ships were allowed to enter Hyperspace without incident.
