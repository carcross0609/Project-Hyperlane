# Oceana

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Oceana](https://starwars.fandom.com/wiki/Oceana)

Oceana was a Lambda-class T-4a shuttle of the Rebel Alliance that carried Commander Kupalo on his transfer from Defiance to the Liberty. The shuttle was escorted by two Delta-class DX-9 stormtrooper transports, Azure.
