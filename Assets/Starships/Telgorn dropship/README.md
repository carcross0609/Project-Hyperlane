# Telgorn dropship

**Continuity:** Legends  
**Source:** [Telgorn dropship](https://starwars.fandom.com/wiki/Telgorn_dropship)

Telgorn dropship was a variant of space transport manufactured by Telgorn Corporation prior to the Clone Wars. The bounty hunter Cad Bane used a modified Telgorn dropship, Sleight of Hand as his personal transport vessel.
