# Unidentified C-9979 landing craft

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified C-9979 landing craft (Rugosa)](https://starwars.fandom.com/wiki/Unidentified_C-9979_landing_craft_%28Rugosa%29)
