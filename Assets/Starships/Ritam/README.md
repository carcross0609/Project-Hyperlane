# Ritam

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Ritam](https://starwars.fandom.com/wiki/Ritam)

Ritam was a Corellian corvette that was passing by an Imperial customs platform. The corvette was inspected by a TIE Interceptor to find that it contained repulsors as it had claimed in the manifest and was allowed to leave.
