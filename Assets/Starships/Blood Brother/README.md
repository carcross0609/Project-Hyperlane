# Blood Brother

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Blood Brother](https://starwars.fandom.com/wiki/Blood_Brother)

The Blood Brother, formerly known as the Dura-Khan III, was a heavily modified Consular III-class cruiser used by Reddjak, and the main command vessel for the Red Fury Brotherhood.

## Specifications

- **Name:** Blood Brother
- **Model:** Modified Consular III-class cruiser
- **Type:** Cruiser
- **Modifier:** Red Fury Brotherhood
- **Shield Gen:** Equipped
