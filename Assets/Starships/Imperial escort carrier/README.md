# Imperial escort carrier

**Continuity:** Canon  
**Source:** [Imperial escort carrier](https://starwars.fandom.com/wiki/Imperial_escort_carrier)

An Imperial escort carrier was a starship used by the Galactic Empire by 14 BBY. In that same year, the Imperial escort carrier Goliath took part in the hunt for Moff Wilhuff Tarkin's stolen corvette Carrion Spike. The Goliath was involved in a skirmish with Berch Teller's rebel cell above Phindar.
