# Volant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Volant](https://starwars.fandom.com/wiki/Volant)

The Volant was a New Republic carrier in the New Republic Fifth Fleet. Colonel Bowman Gavin, starfighter commander of the New Republic Fifth Fleet, visited this carrier in 17 ABY.
