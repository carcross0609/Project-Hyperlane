# Long Run

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Long Run](https://starwars.fandom.com/wiki/Long_Run)

The Long Run was a Rebel Alliance barge piloted by Boo Rawl. In 3 ABY, it was used to steal a Colony Class 23669 power generator from the Galactic Empire on Kuat while disguised as an Imperial barge, 36DD. It was modified by Rawl who upgraded the shields and removed some of the cargo and living space in the bow to create space for a hidden turbolaser mount.
