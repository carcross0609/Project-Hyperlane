# YT-1250 transport

**Continuity:** Canon  
**Source:** [YT-1250 transport](https://starwars.fandom.com/wiki/YT-1250_transport)

The YT-1250 transport was a class of transport of the YT-series that was manufactured by Corellian Engineering Corporation. It was an upgraded version of the YT-1200 and YT-1210 transports.
