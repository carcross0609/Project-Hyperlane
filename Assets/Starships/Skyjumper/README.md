# Skyjumper

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Skyjumper](https://starwars.fandom.com/wiki/Skyjumper)

The Skyjumper was a freighter captained by Drev Jalok and crewed by Sullub Soonin. The ship was attacked by the pirate Drek Drednar while on route to the Altier system.

## Specifications

- **Name:** Skyjumper
- **Type:** Freighter
- **Captains:** Drev Jalok
