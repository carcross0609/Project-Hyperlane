# Aggressor-class Assault Fighter

**Continuity:** Canon  
**Source:** [Aggressor-class Assault Fighter](https://starwars.fandom.com/wiki/Aggressor-class_Assault_Fighter)

The Aggressor-class Assault Fighter was a model of starship. One such vessel was the IG-2000, which was owned by the bounty hunter IG-88B.

## Specifications

- **Name:** Aggressor-class Assault Fighter
- **Manufacturer:** Trilon Incorporated
- **Type:** Starfighter
- **Cost:** 160,000 credits
- **Engine:** Sol-Mk. VI ion engine
- **Hyperdrive:**
  - Class 2 (Primary)
  - Class 8 (Backup)
- **Sensor:** Short range sensor
- **Armament:**
  - Twin medium laser cannons
  - Twin medium ion cannons
  - Light Tractor beam projector
- **Passengers:** 8
- **Consumables:** 3 months
- **Role:** Combat
