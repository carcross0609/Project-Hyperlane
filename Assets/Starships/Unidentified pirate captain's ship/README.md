# Unidentified pirate captain's ship

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified pirate captain's ship](https://starwars.fandom.com/wiki/Unidentified_pirate_captain%27s_ship)

A notorious pirate captain had been carousing on Socorro. While he was distracted, a slicer bypassed security of his ship's navicomputer. Having secured the data that revealed the pirates' home base, the slicer wiped it clean to ensure that the authorities would be able to reach it first.
