# Octofoil

**Continuity:** Legends  
**Source:** [Octofoil](https://starwars.fandom.com/wiki/Octofoil)

An Octofoil was a starship model used by the Torgaigne, a crime syndicate that operated out of Attahox in the Expansion Region. Disk Moosea and Vor Childermoss were known to use them.
