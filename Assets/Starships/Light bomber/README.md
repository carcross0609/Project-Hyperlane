# Light bomber

**Continuity:** Canon  
**Source:** [Light bomber](https://starwars.fandom.com/wiki/Light_bomber)

A light bomber was a relatively small type of bomber starship. The Imperial TIE/sa and a Republic model of the Y-wing that had a second crewmember but no bubble turret fell into that category.
