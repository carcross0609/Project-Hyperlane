# Unidentified Consular-class cruiser

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Unidentified Consular-class cruiser (Rodia)/Legends](https://starwars.fandom.com/wiki/Unidentified_Consular-class_cruiser_%28Rodia%29/Legends)

A Consular-class cruiser was part of the Republic Navy during the Clone Wars, first used by Jedi Master Luminara Unduli and Jedi Padawan Ahsoka Tano to transfer arrested Trade Federation Viceroy Nute Gunray from Rodia to the Tranquility. Captain Faro Argyus later stole the cruiser following his escape with Gunray.
