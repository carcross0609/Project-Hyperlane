# KS-500 Spaceways Transport light freighter

**Continuity:** Unknown  
**Source:** [KS-500 Spaceways Transport light freighter](https://starwars.fandom.com/wiki/KS-500_Spaceways_Transport_light_freighter)

The KS-500 Spaceways Transport light freighter was a standard light freighter produced by the Corellian Engineering Corporation. They were high performance vehicles which could be easily modified, as was evidenced with The Fatal Vision.
