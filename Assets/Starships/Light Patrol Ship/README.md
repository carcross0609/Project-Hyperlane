# Light Patrol Ship

**Continuity:** Legends  
**Source:** [Light Patrol Ship](https://starwars.fandom.com/wiki/Light_Patrol_Ship)

The Sienar Fleet Systems Light Patrol Ship was used by the Sector Rangers, the Ringali Shell Security Forces, as well as bounty hunters.

## Specifications

- **Name:** Light Patrol Ship
- **Manufacturer:** Sienar Fleet Systems
- **Length:** 38 meters
- **Max Speed:** 1,050 kmh
- **Hyperdrive:**
  - Class 1
  - Class 10 (backup)
- **Shield Gen:** Equipped
- **Armament:**
  - (3) Laser cannon turrets
  - (2) Twin laser cannons
- **Crew:** 6 (includes 3 gunners)
- **Passengers:** Prisoners (8)
- **Capacity:** 100 metric tons
- **Consumables:** 1 month
- **Affiliation:**
  - Sector Rangers
  - Ringali Shell Security Forces
  - Bounty hunters
