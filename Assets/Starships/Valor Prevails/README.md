# Valor Prevails

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Valor Prevails](https://starwars.fandom.com/wiki/Valor_Prevails)

The Valor Prevails was a Harrower-class dreadnought used by the resurgent Sith Empire. It was under the command of Captain Eisek and patrolled the Vesla system.

## Specifications

- **Name:** Valor Prevails
- **Model:** Harrower-class dreadnought
- **Type:** Dreadnaught
- **Affiliation:** Sith Empire
- **Captains:** Captain Eisek
