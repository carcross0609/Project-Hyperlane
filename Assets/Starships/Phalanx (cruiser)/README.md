# Phalanx (cruiser)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Phalanx (cruiser)](https://starwars.fandom.com/wiki/Phalanx_%28cruiser%29)

The Phalanx was a New Republic cruiser that was severely damaged at the Battle of Doornik-319. When the Phalanx tried to tractor in a crippled K-wing it was fired on, destroying the K-wing and damaging the Phalanx.
