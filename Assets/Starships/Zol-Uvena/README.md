# Zol-Uvena

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Zol-Uvena](https://starwars.fandom.com/wiki/Zol-Uvena)

Zol-Uvena was one of the ships used by Shistavanen scout Yurdak Fav. It had been modifed to be more maneuverable and had a different weapon system than normally installed on the model.

- **Max Speed:** 950 kmh

- **Armament:** Laser cannon (1)
- **Crew:** 1
- **Passengers:** 2
- **Capacity:** 100 metric tons
- **Consumables:** 6 months
- **Owners:** Yurdak Fav
