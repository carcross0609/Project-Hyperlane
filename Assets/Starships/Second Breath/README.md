# Second Breath

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Second Breath](https://starwars.fandom.com/wiki/Second_Breath)

The Second Breath was a modified YT-1300 light freighter that was used by the Cularin-based company Renna's Transport Service.

## Specifications

- **Name:** Second Breath
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** YT-1300 light freighter
- **Type:** Freighter
- **Length:** 26.7 meters
- **Max Speed:** 800 km/h
- **Hyperdrive:**
  - Class 2
  - Class 16 (backup)
- **Armament:** 2 laser cannons
- **Passengers:** 6
- **Capacity:** 100 metric tons
- **Consumables:** 2 months
- **Othersystems:** Tractor beam
- **Affiliation:** Renna's Transport Service
