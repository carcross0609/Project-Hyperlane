# Corellian Thunder (freighter)

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Corellian Thunder (freighter)](https://starwars.fandom.com/wiki/Corellian_Thunder_%28freighter%29)

Corellian Thunder was a Ghtroc Industries freighter owned and operated by the Corellian pilot Davrin. The freighter was sent to pick up professional thief Sienn Sconn from Rydonni Prime.
