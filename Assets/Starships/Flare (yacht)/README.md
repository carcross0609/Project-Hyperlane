# Flare

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Flare (yacht)](https://starwars.fandom.com/wiki/Flare_%28yacht%29)

The Flare was a modified Kuat Leisure 121-B pleasure craft used by Jedi Knights Aayla Secura and Ylenic It'kla during their mission to rescue Ratri Tane, in the first months of the Clone Wars.

## Specifications

- **Name:** Flare
- **Manufacturer:** Kuat Leisure
- **Model:** Modified 121-B
- **Type:** Yacht
- **Affiliation:** Jedi Order
