# Corusca Rainbow

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Corusca Rainbow](https://starwars.fandom.com/wiki/Corusca_Rainbow)

The Corusca Rainbow was an Immobilizer 418 cruiser under the command of Captain Uwlla Iillor. The ship was originally called the Black Asp and served in the Imperial Navy.
