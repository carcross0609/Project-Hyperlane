# Malevolent

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Malevolent](https://starwars.fandom.com/wiki/Malevolent)

Malevolent was an EF76 Nebulon-B escort frigate that saw service with the Imperial Navy during the Galactic Civil War. During Operation: Clean Sweep, the vessel challenged the Rebel Alliance frigate Endeavor to a ship-to-ship duel which included both warships' contingents of starfighters.
