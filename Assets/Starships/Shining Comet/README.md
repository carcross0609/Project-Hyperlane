# Shining Comet

**Kind:** Individual ship  
**Continuity:** Unknown  
**Source:** [Shining Comet](https://starwars.fandom.com/wiki/Shining_Comet)

The Shining Comet was a lower class personnel transport which once traveled from Lanthrym to Bodrin. The Comet was a dingy, damp, unkempt hole of a freighter, designed to transport as many people as possible without caring for any luxuries. Recreational facilities were at an absolute minimum, although there was a viewing deck which allowed a great view of the surrounding stars.
