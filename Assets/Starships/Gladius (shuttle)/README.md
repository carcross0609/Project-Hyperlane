# Gladius

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Gladius (shuttle)](https://starwars.fandom.com/wiki/Gladius_%28shuttle%29)

The Gladius was a Lambda-class T-4a shuttle of the Galactic Empire that participated in a mission to Hosnian Prime to recover Imperial Security Bureau Agent Thorn from an orbital outpost.

## Specifications

- **Name:** Gladius
- **Line:** Abecederian line
- **Model:** Lambda-class T-4a shuttle
- **Type:** Shuttle
- **Affiliation:** Galactic Empire
- **Navy:** Imperial Navy
