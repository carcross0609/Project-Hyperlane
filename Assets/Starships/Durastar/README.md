# Durastar

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Durastar](https://starwars.fandom.com/wiki/Durastar)

The Durastar was a starship owned by the New Jedi Order, and used by Daeshara'cor in the early months of the Yuuzhan Vong War. It suffered a hyperdrive failure near Corellia, forcing Daeshara'cor to abandon it.

## Specifications

- **Name:** Durastar
- **Hdsystem:** Equipped
- **Affiliation:** New Jedi Order
- **Captains:** Daeshara'cor
