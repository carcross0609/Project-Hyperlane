# Liberator

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Liberator (Imperial I-class)](https://starwars.fandom.com/wiki/Liberator_%28Imperial_I-class%29)

The Liberator, known as the Adjudicator during its Imperial service, was an Imperial I-class Star Destroyer originally used by the Imperial Navy and later by the New Republic.
