# Arcanum

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Arcanum](https://starwars.fandom.com/wiki/Arcanum)

The Arcanum was a space station that was commissioned by the Sith Emperor for the purpose of holding dangerous Sith artifacts possessed by the reconstituted Sith Empire.

- **Name:** Arcanum
- **Type:** Space station

- **System:** Arcanum system
