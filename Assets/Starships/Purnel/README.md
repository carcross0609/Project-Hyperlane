# Purnel

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Purnel](https://starwars.fandom.com/wiki/Purnel)

Purnel was a Rebel BFF-1 bulk freighter that supplied the makeshift B-wing starfighter assembly area before its destruction by the Empire.
