# Stella-class frigate

**Continuity:** Legends  
**Source:** [Stella-class frigate](https://starwars.fandom.com/wiki/Stella-class_frigate)

A Stella-class frigate was a type of frigate used by the Hapan Royal Navy sometime in 44 ABY. The frigate was capable of deploying at least three squadrons of Miy'til starfighters.

## Specifications

- **Name:** Stella-class frigate
- **Manufacturer:** Olanji/Charubah
- **Type:** Frigate
- **Affiliation:**
  - Hapes Consortium
  -   Hapan Royal Navy
