# Chume Sen cruiser

**Continuity:** Legends  
**Source:** [Chume Sen cruiser](https://starwars.fandom.com/wiki/Chume_Sen_cruiser)

A Chume Sen cruiser was a type of starship available in the time of the Sith–Imperial War. It was preferable to the Mynock.
