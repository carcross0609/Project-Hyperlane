# Darkflare

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Darkflare](https://starwars.fandom.com/wiki/Darkflare)

The Darkflare was a state-of-the-art S-46I Medium Scout Ship that was manufactured by Sienar Fleet Systems for the Galactic Empire. During the Galactic Civil War, Rebel Alliance Intelligence forces launched Operation Night Fire to capture the Darkflare while it was under construction at a Seinar Fleet Systems orbital shipyard. It was commanded by Imperial Security Bureau Commander Trey Trellen.
