# T-70 X-wing starfighter

**Continuity:** Canon  
**Source:** [T-70 X-wing starfighter](https://starwars.fandom.com/wiki/T-70_X-wing_starfighter)

The T-70 X-wing starfighter, also known as the T-70 X-wing fighter, was a next-generation model of the X-wing starfighter utilized by the New Republic Defense Fleet as the successor to the T-65B X-wing starfighter, manufactured by Incom-FreiTek Corporation.
