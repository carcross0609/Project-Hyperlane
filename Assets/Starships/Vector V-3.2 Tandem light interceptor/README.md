# Vector V-3.2 Tandem light interceptor

**Continuity:** Canon  
**Source:** [Vector V-3.2 Tandem light interceptor](https://starwars.fandom.com/wiki/Vector_V-3.2_Tandem_light_interceptor)

The Vector V-3.2 Tandem light interceptor, or simply referred to as Vector V-3.2 Tandem, and Jedi Vector V-3, was a model of the Jedi Vector starfighter used by the Jedi Order by 132 BBY.

## Specifications

- **Name:** Vector V-3.2 Tandem light interceptor
- **Manufacturer:** Valkeri-Kuat Consolidated Enterprises
- **Model:** Jedi Vector
- **Type:** Starfighter
- **Length:**
  - 14.62 meters (48 feet) (precise length)
  - 14.6 meters (48 feet)
- **Width:** 19.76 meters (64 ft 10 in)
- **Height:** 3.45 meters (11 ft 4 in)
- **Mglt:** 100 MGLT
- **Max Speed:** 1,100 kph (683 mph)
- **Engine:** Ion engines
- **Hyperdrive:** Class 1
- **Armament:**
  - Heavy laser cannons (2)
  - Proton torpedo launcher
  - Tractor beam
- **Passengers:** 1-2
- **Affiliation:** Jedi Order
