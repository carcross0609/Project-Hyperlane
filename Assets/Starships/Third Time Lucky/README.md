# Third Time Lucky

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Third Time Lucky](https://starwars.fandom.com/wiki/Third_Time_Lucky)

Third Time Lucky was a civilian freighter that was present in the Druckenwell system during the Clone Wars. When the YT-1300 light freighter Dessin's Dagger attempted to flee the system, it collided with the Third Time Lucky and inflicted a lot of damage to it.
