# Defiant

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Defiant (Acclamator-class)](https://starwars.fandom.com/wiki/Defiant_%28Acclamator-class%29)

The Defiant was an Acclamator-class assault ship. The Defiant first saw service in the Republic Navy during the Clone Wars, where it was adorned with lateral red markings port and starboard of the centerline and wore the symbol of the Open Circle Fleet. It later served in the Imperial Navy during the Galactic Civil War, by which time it had its markings removed.
