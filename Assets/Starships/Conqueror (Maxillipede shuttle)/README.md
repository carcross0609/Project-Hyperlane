# Conqueror

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Conqueror (Maxillipede shuttle)](https://starwars.fandom.com/wiki/Conqueror_%28Maxillipede_shuttle%29)

The Conqueror was a Maxillipede shuttle that was present at the battle of Antolus I. It was equipped with a magnetogravitic shield.
