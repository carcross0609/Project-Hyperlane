# Red Dragon

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Red Dragon](https://starwars.fandom.com/wiki/Red_Dragon)

The Red Dragon was an Imperial Star Destroyer that was presumably looking for Rebel Alliance activity near an area where the BFF-1 bulk freighter Op Mus was awaiting repairs from stormtrooper transport Jaamn. It had a complement of TIE Avengers.
