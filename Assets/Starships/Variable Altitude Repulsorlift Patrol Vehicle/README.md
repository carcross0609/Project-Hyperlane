# Variable Altitude Repulsorlift Patrol Vehicle

**Continuity:** Legends  
**Source:** [Variable Altitude Repulsorlift Patrol Vehicle](https://starwars.fandom.com/wiki/Variable_Altitude_Repulsorlift_Patrol_Vehicle)

The Variable Altitude Repulsorlift Patrol Vehicle was a Kuat Drive Yards design used by the Republic Correction Authority for a variety of uses. One such use was guarding the reactor of the Oovo IV's detention facility, where it earned the name of reactor patrol vehicle or RPV for short.
