# Opos

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Opos](https://starwars.fandom.com/wiki/Opos)

The Opos was a YT-1300 transport used by the Rebel Alliance. The freighter attempted to dock with the XQ4 Platform Enin'sd, but it was destroyed in the process by Tan Maarek Stele.
