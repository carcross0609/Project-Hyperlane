# Y-wing scout bomber

**Continuity:** Legends  
**Source:** [Y-wing scout bomber/Legends](https://starwars.fandom.com/wiki/Y-wing_scout_bomber/Legends)

The Y-wing scout bomber was a variant of the BTL-B Y-wing starfighter that was developed during the Clone Wars. Clone trooper pilot Warthog flew a prototype bomber to a Republic outpost during the war.

## Specifications

- **Name:** Y-wing scout bomber
- **Model:** Scout bomber
- **Crew:** Pilot (1)
- **Role:**
  - Reconnaissance
  - Bomber
- **Affiliation:** Galactic Republic
