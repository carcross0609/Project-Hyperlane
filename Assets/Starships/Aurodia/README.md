# Aurodia

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Aurodia](https://starwars.fandom.com/wiki/Aurodia)

The Aurodia was a Galactic Republic warship that fought in the Clone Wars. Lieutenant Commander Ussin Fajinak was its first officer. Its first engagement was the Battle of Kashyyyk.
