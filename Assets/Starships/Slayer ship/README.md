# Slayer ship

**Continuity:** Legends  
**Source:** [Slayer ship](https://starwars.fandom.com/wiki/Slayer_ship)

The slayer ship was a Yuuzhan Vong starfighter created for the use of Supreme Overlord Shimrra Jamaane's Slayers in the final year of the Yuuzhan Vong War.

## Specifications

- **Name:** Slayer ship
- **Manufacturer:** Yuuzhan Vong
- **Type:** Starfighter
- **Length:** >13 meters
- **Hdsystem:** Dovin basals
- **Shield Gen:** Dovin basals
- **Hull:** Yorik coral
- **Armament:**
  - Yaret-Kors (6)
  - Dovin basals
- **Role:** Heavy starfighter
- **Affiliation:** Yuuzhan Vong
