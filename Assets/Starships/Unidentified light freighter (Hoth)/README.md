# Unidentified light freighter

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Unidentified light freighter (Hoth)](https://starwars.fandom.com/wiki/Unidentified_light_freighter_%28Hoth%29)

A light freighter belonged to a Rebel Alliance captain during the Galactic Civil War. In 3 ABY, the captain conducted repairs for the ship while stationed in Echo Base on the planet Hoth.
