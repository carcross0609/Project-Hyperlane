# Stormstrike

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Stormstrike](https://starwars.fandom.com/wiki/Stormstrike)

Stormstrike was a CR90 corvette assigned to the defense of Chandrila prior to the Galactic Civil War. Kylan DuPre served as a quartermaster on the Stormstrike.

## Specifications

- **Name:** Stormstrike
- **Model:** CR90 corvette
- **Affiliation:** Chandrila
- **Navy:** Chandrila Defense Fleet
