# Sundiver

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Sundiver](https://starwars.fandom.com/wiki/Sundiver)

The Sundiver was an Acclamator-class assault ship in use by the Galactic Republic during the Clone Wars. It was captained by Commander Adar Tallon. Wils was a crewman onboard the ship.
