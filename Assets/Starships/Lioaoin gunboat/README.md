# Lioaoin gunboat

**Continuity:** Canon  
**Source:** [Lioaoin gunboat](https://starwars.fandom.com/wiki/Lioaoin_gunboat)

A class of gunboat was used by the Lioaoin Regime. When the Chiss Ascendancy heavy cruiser Springhawk traveled the Lioaoin heartworld, it was met by nine such gunboats.

## Specifications

- **Name:** Lioaoin gunboat
- **Type:** Gunboat
- **Crew:** 1
- **Affiliation:** Lioaoin Regime
