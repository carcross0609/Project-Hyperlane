# Jedi Explorer II

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Jedi Explorer II](https://starwars.fandom.com/wiki/Jedi_Explorer_II)

Jedi Explorer II was a personal starship built by Luke Skywalker to replace his former Jedi Explorer. He used it during the end of Operation Shadow Hand.
