# The Miniad

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [The Miniad](https://starwars.fandom.com/wiki/The_Miniad)

The Miniad was the modified FA-504s transport used by Nir Rinit during his tenure on the planet Naalol.

## Specifications

- **Name:** The Miniad
- **Manufacturer:** Corellian Engineering Corporation
- **Model:** FA-504s transport
- **Type:** Transport
- **Length:** 28 meters
- **Armament:** Single laser cannon
- **Owners:** Nir Rinit
