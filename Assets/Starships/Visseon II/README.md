# Visseon II

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Visseon II](https://starwars.fandom.com/wiki/Visseon_II)

Visseon II was an Alliance to Restore the Republic cruiser operating during the Galactic Civil War. It participated in an ambush of an Imperial convoy in the Laramus system.
