# Count Dooku's solar sailer

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Count Dooku's solar sailer](https://starwars.fandom.com/wiki/Count_Dooku%27s_solar_sailer)

Count Dooku's solar sailer, also known as Count Dooku's Punworcca 116-class interstellar sloop, was a Punworcca 116-class interstellar sloop owned by Count Dooku after receiving it as a gift from the Geonosians. He used it as a private transport throughout the Clone Wars.
