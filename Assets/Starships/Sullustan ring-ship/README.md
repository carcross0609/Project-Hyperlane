# Sullustan ring-ship

**Continuity:** Canon  
**Source:** [Sullustan ring-ship](https://starwars.fandom.com/wiki/Sullustan_ring-ship)

The Sullustan ring-ship was one of several New Republic capital ships present above Chandrila as Grand Admiral Rae Sloane arrived for peace talks with Mon Mothma scheduled to coincide with the Liberation Day celebrations.
