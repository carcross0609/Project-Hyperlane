# Advent

**Kind:** Individual ship  
**Continuity:** Canon  
**Source:** [Advent](https://starwars.fandom.com/wiki/Advent)

The Advent was a cargo freighter. While carrying foodstuff to a system suffering from famine, it was protected by the Jedi Rael Averross and his Padawan Nim Pianna due to pirate activity in the sector. However, the crew mutinied, which led to the death of Nim Pianna.
