# Survival capsule

**Continuity:** Legends  
**Source:** [Survival capsule/Legends](https://starwars.fandom.com/wiki/Survival_capsule/Legends)

Survival capsules were emergency escape devices for ships that either were not equipped with standard escape pods or for last second ejection from a ship.

## Specifications

- **Name:** Survival capsule
- **Capacity:** 1 being
- **Purpose:** Escape pod
