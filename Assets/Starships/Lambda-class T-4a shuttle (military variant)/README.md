# Lambda-class T-4a shuttle

**Continuity:** Canon  
**Source:** [Lambda-class T-4a shuttle (military variant)](https://starwars.fandom.com/wiki/Lambda-class_T-4a_shuttle_%28military_variant%29)

A heavy armored military variant of the Lambda-class T-4a shuttle was created by Cygnus Spaceworks, as subcontracted by Raith Sienar of Sienar Fleet Systems, in order to meet demand for the Lambda-class T-4a.

## Specifications

- **Name:** Lambda-class T-4a shuttle
- **Manufacturer:** Cygnus Spaceworks
- **Line:** Abecederian line
- **Model:** Lambda-class T-4a shuttle
- **Hull:** Heavy armor
