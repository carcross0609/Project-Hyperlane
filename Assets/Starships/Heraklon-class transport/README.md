# Heraklon-class transport

**Continuity:** Legends  
**Source:** [Heraklon-class transport](https://starwars.fandom.com/wiki/Heraklon-class_transport)

The Heraklon-class transport was a frigate-type transport starship that was widely used by the Galactic Republic during the time of the Dark Wars. Typically used as a cargo freighter, its versatility allowed for a broad use as a passenger liner especially in the Core Worlds and Inner Rim.

## Specifications

- **Name:** Heraklon-class transport
- **Manufacturer:** Sadon Shipwrights
- **Type:** Frigate
- **Cost:**
  - 1,250,000 credits (new)
  - 600,000 credits (used)
- **Max Speed:** 725 km/h
- **Hyperdrive:** Class 3
- **Crew:** 20
- **Passengers:**
  - 450 (steerage)
  - 150 (luxury)
- **Capacity:** 75,000 tons
- **Consumables:** 3 months
- **Availability:** Licensed
- **Role:**
  - Freighter
  - Luxury liner
  - Pirate ship
  - Transport
- **Affiliation:**
  - Galactic Republic
  - Zhug brothers
