# Rimrider

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Rimrider](https://starwars.fandom.com/wiki/Rimrider)

The Rimrider was an Imperial scout ship stolen by Halagad Ventor in order to escape Darth Vader. He flew the ship to Trinta, and there it stayed permanently in the swamps.

## Specifications

- **Name:** Rimrider
- **Role:** Scout ship
- **Affiliation:** Galactic Empire
- **Captains:** Halagad Ventor
