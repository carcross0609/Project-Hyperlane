# Pharos

**Kind:** Individual ship  
**Continuity:** Legends  
**Source:** [Pharos](https://starwars.fandom.com/wiki/Pharos)

The Pharos was a hospital ship serving the Alliance to Restore the Republic. Doctor Aurin Leith served in the Pharos triage bay during the Galactic Civil War.
