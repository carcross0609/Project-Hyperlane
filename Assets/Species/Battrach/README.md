# Battrach

**Continuity:** Canon  
**Source:** [Battrach](https://starwars.fandom.com/wiki/Battrach)

The Battrach were a sentient species in the galaxy. During the High Republic Era, Jedi Knight Keeve Trennis claimed to have talked to a male Battrach gunrunner at Port Lennax when infiltrating the Nihil.
