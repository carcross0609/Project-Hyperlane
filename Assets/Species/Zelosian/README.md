# Zelosian

**Continuity:** Legends  
**Source:** [Zelosian](https://starwars.fandom.com/wiki/Zelosian)

Zelosians were sentient plants native to the planet Zelos II.

## Biology & Culture

- **Name:** Zelosian
- **Height:** 1.5–2.0 meters
- **Eyecolor:** Emerald green eyes
- **Distinctions:**
  - Blind in the dark
  - Chlorophyll instead of blood
- **Origin:** Zelos II
- **Language:** Zelosian language, Galactic Basic Standard
