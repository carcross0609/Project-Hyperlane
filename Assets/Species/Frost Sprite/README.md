# Frost Sprite

**Continuity:** Legends  
**Source:** [Frost Sprite](https://starwars.fandom.com/wiki/Frost_Sprite)

A Frost Sprite was a type of sentient humanoid. One Frost Sprite, Odra, the "Duchess of Sleet," lived on the Forest Moon of Endor.

## Biology & Culture

- **Name:** Frost Sprite
- **Designation:** Sentient
- **Skincolor:** Blue
- **Eyecolor:** Yellow
