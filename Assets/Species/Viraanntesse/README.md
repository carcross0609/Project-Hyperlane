# Viraanntesse

**Continuity:** Legends  
**Source:** [Viraanntesse](https://starwars.fandom.com/wiki/Viraanntesse)

Viraanntesses were ten-legged crustacean-like aliens from the Viraanntesse system. Jedi Master Jmmaar was a Viraanntesse.

## Biology & Culture

- **Name:** Viraanntesse
- **Distinctions:** Ten-legged crustaceans
