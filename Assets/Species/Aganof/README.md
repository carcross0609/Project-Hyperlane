# Aganof

**Continuity:** Legends  
**Source:** [Aganof](https://starwars.fandom.com/wiki/Aganof)

Aganof were non-humanoid sentients native to the underground caves of Kuras III in Elrood sector.

## Biology & Culture

- **Name:** Aganof
- **Designation:** Sentient
- **Height:** 1.3–2.5 meters
- **Length:** 1.5–3.5 meters
- **Distinctions:**
  - Blind and deaf
  - Claws
  - Sender organ
  - Vibration detection
- **Origin:** Kuras III
- **Language:** Aganof language
