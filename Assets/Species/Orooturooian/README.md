# Orooturooian

**Continuity:** Canon  
**Source:** [Orooturooian](https://starwars.fandom.com/wiki/Orooturooian)

Orooturooians were a sentient species from the Orooturoo system. The species had purple skin and large bodies with several tendrils. Meerou Woodring was an Orooturooian crime lord who owned an asteroid fortress.

## Biology & Culture

- **Name:** Orooturooian
- **Designation:** Sentient
- **Skincolor:** Purple
- **Origin:** Orooturoo system
