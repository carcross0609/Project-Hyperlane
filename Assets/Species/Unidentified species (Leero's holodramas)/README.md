# Unidentified species

**Continuity:** Legends  
**Source:** [Unidentified species (Leero's holodramas)](https://starwars.fandom.com/wiki/Unidentified_species_%28Leero%27s_holodramas%29)

A sentient species resided in the galaxy around 3643 BBY. Considered by some to be primitive, they treated holodramas created by the Hutt director Leero—which were generally considered tasteless in the wider galaxy—as divine messages.
