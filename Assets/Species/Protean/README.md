# Protean

**Continuity:** Legends  
**Source:** [Protean](https://starwars.fandom.com/wiki/Protean)

The Proteans (also sometimes called Protreans) were sentient beings indigenous to Nathas I which was located within the Questal sector.

## Biology & Culture

- **Name:** Protean
- **Mass:** 80–150 kilograms
- **Distinctions:** Shapeshifters
- **Origin:** Nathas I
