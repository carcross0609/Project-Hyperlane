# Colicoid

**Continuity:** Legends  
**Source:** [Colicoid/Legends](https://starwars.fandom.com/wiki/Colicoid/Legends)

Colicoids were a sentient insectoid species from Colla IV.

- **Name:** Colicoid
- **Designation:** Sentient
- **Height:** 1.3 meters
- **Distinctions:** Carnivorous insectoids, four legs, defensive "ball mode"
