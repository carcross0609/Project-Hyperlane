# Bestoonian

**Continuity:** Canon  
**Source:** [Bestoonian](https://starwars.fandom.com/wiki/Bestoonian)

The Bestoonian were a sentient species. One Bestoonian was the Sith assassin Ochi, who hailed from the planet Bestoon.
