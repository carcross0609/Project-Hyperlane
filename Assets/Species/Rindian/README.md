# Rindian

**Continuity:** Legends  
**Source:** [Rindian](https://starwars.fandom.com/wiki/Rindian)

Rindians were an alien race from the Rindia system. They were small in stature, had pointed ears, and possessed eight digits on each hand. Their speech was melodious to the hearer.

## Biology & Culture

- **Name:** Rindian
- **Distinctions:**
  - 8 fingers on each hand
  - Pointed ears
- **Origin:** Rindia system
