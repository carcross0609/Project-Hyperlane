# Fraii Wys

**Continuity:** Legends  
**Source:** [Fraii Wys](https://starwars.fandom.com/wiki/Fraii_Wys)

The sentient alien race Fraii Wys was thought to be extinct for a very extended period of time. Then after nine thousand years, they reappeared in the galaxy and flourished. It was an extraordinary case brought up when considering the truth behind the disappearance of the Qella.
