# Hekto

**Continuity:** Legends  
**Source:** [Hekto](https://starwars.fandom.com/wiki/Hekto)

Hekto were a sentient species possessing four arms. Members of the species were present in the Red Ronto cantina on Brink Station in 45 ABY.
