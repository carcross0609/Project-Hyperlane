# Juzzian

**Continuity:** Legends  
**Source:** [Juzzian](https://starwars.fandom.com/wiki/Juzzian)

The Juzzians were an alien race from the Juzzia system with cone-shaped bodies and many teeth. There were both sedentary and mountain-hopping Juzzians. They made colony markers and presumably developed the Juzzian armlock.
