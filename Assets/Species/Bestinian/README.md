# Bestinian

**Continuity:** Legends  
**Source:** [Bestinian](https://starwars.fandom.com/wiki/Bestinian)

The Bestinians were the Human natives of the planet Bestine IV and the wider Bestine system. The Bestinians donated ships to the Alliance Fleet for the Battle of Endor.
