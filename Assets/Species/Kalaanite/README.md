# Kalaanite

**Continuity:** Legends  
**Source:** [Kalaanite](https://starwars.fandom.com/wiki/Kalaanite)

The Kalaanites were native to the planet of Kalaan. Red-skinned humanoids with large red eyes and squarish snouts, they spoke the Kalaanite language.

## Biology & Culture

- **Name:** Kalaanite
- **Designation:** Sentient
- **Skincolor:** Red
- **Haircolor:** None
- **Eyecolor:** Red
- **Distinctions:** Red eyes and squarish snouts
- **Origin:** Kalaan
- **Language:** Kalaanite
