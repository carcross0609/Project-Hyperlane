# Tarasin

**Continuity:** Legends  
**Source:** [Tarasin](https://starwars.fandom.com/wiki/Tarasin)

The Tarasins were a bipedal, sapient reptilian species indigenous to Cularin. They were remotely related to the gigantic Kilassin.

## Biology & Culture

- **Name:** Tarasin
- **Designation:** Sentient
- **Height:** 1.6 - 1.7 meters
- **Skincolor:** Variable
- **Distinctions:** Reptilian
- **Origin:** Cularin
- **Language:**
  - Tarasin Skintone Language
  - Tarasinese
