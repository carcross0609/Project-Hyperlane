# Constancian

**Continuity:** Legends  
**Source:** [Constancian](https://starwars.fandom.com/wiki/Constancian)

Constancians were short, telepathic mammalian humanoids indigenous to Constancia.

## Biology & Culture

- **Name:** Constancian
- **Designation:** Sentient
- **Skincolor:** Orange
- **Haircolor:** Flaming orange
- **Eyecolor:** Yellowish-gold
- **Distinctions:** Telepathic, child-like features
- **Origin:** Constancia
