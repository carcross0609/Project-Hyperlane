# Affytechan

**Continuity:** Legends  
**Source:** [Affytechan](https://starwars.fandom.com/wiki/Affytechan)

Affytechans were a species of tall, bipedal sentient plants native to Dom-Bradden, in the Outer Rim of the galaxy.
