# Xexto

**Continuity:** Legends  
**Source:** [Xexto/Legends](https://starwars.fandom.com/wiki/Xexto/Legends)

Xexto were a sentient, four-armed humanoid species native to the planet Troiken, where they lived in arboreal villages. Gasgano the podracer was a Xeto.

- **Name:** Xexto

- **Distinctions:**

- **Origin:** Troiken
- **Language:** Xextese
