# Annoo-dat

**Continuity:** Legends  
**Source:** [Annoo-dat](https://starwars.fandom.com/wiki/Annoo-dat)

Annoo-dat was the name used by two separate species who lived as a single culture on Annoo, an agriworld in the Outer Rim Territories.
