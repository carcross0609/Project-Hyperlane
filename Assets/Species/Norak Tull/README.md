# Norak Tull

**Continuity:** Legends  
**Source:** [Norak Tull](https://starwars.fandom.com/wiki/Norak_Tull)

The Norak Tull were sapient, segmented insectoids and possessed an armor-like exoskeleton. Grekk 9 was a Norak Tull Commodore in the New Republic.
