# Taymar

**Continuity:** Canon  
**Source:** [Taymar](https://starwars.fandom.com/wiki/Taymar)

The Taymar were a sentient species that inhabited the galaxy. Taymar had human-like faces, glittery blue-green skin, flowing tendrils, and the ability to float, as well as multiple arms.

## Biology & Culture

- **Name:** Taymar
- **Designation:** Sentient
- **Skincolor:** Blue-green
- **Distinctions:**
  - Ability to float
  - Flowing tendrils
  - Multiple arms
