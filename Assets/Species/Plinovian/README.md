# Plinovian

**Continuity:** Canon  
**Source:** [Plinovian](https://starwars.fandom.com/wiki/Plinovian)

Plinovians were the native species of the planet Plin Minor. They were gaseous life-forms that were able to self-combust when riled up.

## Biology & Culture

- **Name:** Plinovian
- **Designation:** Sentient
- **Distinctions:** Gaseous life-forms
- **Origin:** Plin Minor
