# Opquis

**Continuity:** Legends  
**Source:** [Opquis](https://starwars.fandom.com/wiki/Opquis)

The Opquis were members of the New Republic. During the Caamas Document crisis, the Opquis senator took an anti-Bothan position, eventually resulting in the Opquis sending six warships to the Both system.
