# Parwan

**Continuity:** Legends  
**Source:** [Parwan/Legends](https://starwars.fandom.com/wiki/Parwan/Legends)

Parwans were a sentient species native to the planet Parwa.

## Biology & Culture

- **Name:** Parwan
- **Designation:** Sentient
- **Height:** 2.2 meters
- **Skincolor:** Light brown, Blue
- **Haircolor:** None
- **Eyecolor:** Gray
- **Distinctions:**
  - 3 eyes
  - Mushroom-like heads
  - Lighter-than-air physiology
  - Long tentacle-like limbs
- **Origin:** Parwa
- **Language:** Parwan language
