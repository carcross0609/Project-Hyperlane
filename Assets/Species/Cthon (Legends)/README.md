# Cthon

**Continuity:** Legends  
**Source:** [Cthon/Legends](https://starwars.fandom.com/wiki/Cthon/Legends)

Cthons, also known as Troglodytes, were a humanoid species native to Coruscant, living in the lowest levels of the Coruscant underworld.
