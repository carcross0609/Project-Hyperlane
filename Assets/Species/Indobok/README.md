# Indobok

**Continuity:** Legends  
**Source:** [Indobok](https://starwars.fandom.com/wiki/Indobok)

Indobok was the living moon of Kalarba, orbiting near Hosk Station. In actuality, it was a giant B'rknaa. The other B'rknaa that lived on Indobok were Indobok's children.
