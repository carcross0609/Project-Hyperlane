# Druckenwellian

**Continuity:** Legends  
**Source:** [Druckenwellian](https://starwars.fandom.com/wiki/Druckenwellian)

Druckenwellians were the Human inhabitants of the planet Druckenwell, an industrial world in the Doldur sector. Jai Maruk was a Druckenwellian.
