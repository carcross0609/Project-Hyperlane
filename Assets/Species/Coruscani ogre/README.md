# Coruscani ogre

**Continuity:** Legends  
**Source:** [Coruscani ogre](https://starwars.fandom.com/wiki/Coruscani_ogre)

The Coruscani ogre was a large semi-sentient humanoid beast that lived in Coruscant sublevels, sewers, and dumps.
