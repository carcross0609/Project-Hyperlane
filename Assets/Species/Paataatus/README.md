# Paataatus

**Continuity:** Canon  
**Source:** [Paataatus](https://starwars.fandom.com/wiki/Paataatus)

The Paataatus were a sentient species with a swarm mentality. The Chiss Ascendancy led an attack on numerous Paataatus fighters above the Paataatus homeworld, Nettehi.

## Biology & Culture

- **Name:** Paataatus
- **Designation:** Sentient
- **Origin:** Nettehi
