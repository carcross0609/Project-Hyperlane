# Stofo Lupinoid

**Continuity:** Legends  
**Source:** [Stofo Lupinoid](https://starwars.fandom.com/wiki/Stofo_Lupinoid)

A Stofo Lupinoid was a name for a wolflike sentient species. On entering for the first time Chalmun's Cantina in Mos Eisley in 0 BBY, Luke Skywalker identified one of the customers as a Stofo Lupinoid.
