# Benathy

**Continuity:** Canon  
**Source:** [Benathy](https://starwars.fandom.com/wiki/Benathy)

The Benathy were a large sentient species that resided on the planet Benath in Wild Space. During the Imperial Era, Darth Vader led a battle against the Benathy, which ultimately failed, though the Benathy were subdued. Kylo Ren of the First Order visited the Benathy for negotiations, accompanied by Captain Ruthford.
