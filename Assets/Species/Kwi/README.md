# Kwi

**Continuity:** Legends  
**Source:** [Kwi](https://starwars.fandom.com/wiki/Kwi)

The Kwi were the degenerated descendants of the saurian Kwa—Dathomir's first sentient inhabitants.

## Biology & Culture

- **Name:** Kwi
- **Designation:** Semi-sentient
- **Height:** 3 meters
- **Length:** 4 meters
- **Skincolor:** Cobalt-blue
- **Eyecolor:** Red
- **Origin:** Dathomir
- **Diet:** Herbivore
