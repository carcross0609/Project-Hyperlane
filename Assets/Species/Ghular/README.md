# Ghular

**Continuity:** Canon  
**Source:** [Ghular](https://starwars.fandom.com/wiki/Ghular)

Ghulars were a sentient species. The Ghulars were enslaved by the Qhuloskians, forced to mine farium on Qhulosk.
