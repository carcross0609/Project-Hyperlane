# Unidentified species

**Continuity:** Legends  
**Source:** [Unidentified species (mecho-organic builders)](https://starwars.fandom.com/wiki/Unidentified_species_%28mecho-organic_builders%29)

A species built massive mecho-organic vessels, including Ship, to fight in an extra-galactic war. At the end of this war one faction released a plague bomb. As far as Ship was aware, this wiped out the entire species.
