# Labbo

**Continuity:** Canon  
**Source:** [Labbo](https://starwars.fandom.com/wiki/Labbo)

The Labbo were a long-eared sentient species that lived in the galaxy. The Labbos' ears had flaps that could touch their shoulders when twitching.
