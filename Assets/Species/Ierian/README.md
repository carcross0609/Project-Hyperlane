# Ierian

**Continuity:** Legends  
**Source:** [Ierian](https://starwars.fandom.com/wiki/Ierian)

Ierians were Humans from Ieria. The wealthier planet Andara was their rival. The Ierians did not enjoy indirect senatorial representation through Andara, and attempted an attack on Andara in 26 BBY.
