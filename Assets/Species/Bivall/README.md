# Bivall

**Continuity:** Canon  
**Source:** [Bivall](https://starwars.fandom.com/wiki/Bivall)

The Bivall were a semi-aquatic sentient species of tall bipeds with lanky bodies, large stalked eyes, crested heads and long fingers that were native to Protobranch in the Core Worlds. Sionver Boll and Okalin were members of this species.
