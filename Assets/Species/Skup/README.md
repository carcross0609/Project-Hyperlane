# Skup

**Continuity:** Canon  
**Source:** [Skup](https://starwars.fandom.com/wiki/Skup)

Skups were a humanoid sentient species with long arms, stooped shoulders, four fingers per hand, a bulbous abdomen, a pair of close-set eyes, and a long nose. Antha Mont was a female Skup affiliated with the Resistance.

## Biology & Culture

- **Name:** Skup
- **Designation:** Sentient
- **Class:** Humanoid
- **Distinctions:** Long arms, four fingers, stooped shoulders, bulbous belly, close-set eyes, long nose
