# Vestaari

**Continuity:** Legends  
**Source:** [Vestaari](https://starwars.fandom.com/wiki/Vestaari)

The Vestaari were native to the planet Vestar. There were known to be Vestaari nomads, one of which Abal Karda attempted to disguise himself as when fleeing Vestar.
