# Riorian

**Continuity:** Canon  
**Source:** [Riorian](https://starwars.fandom.com/wiki/Riorian)

The Riorians were an insect-like species. One named Loje Nella was present during a performance by the Max Rebo Band at Jabba's Palace in 4 ABY.
