# Jin

**Continuity:** Legends  
**Source:** [Jin](https://starwars.fandom.com/wiki/Jin)

The Jin were sapients native to the Zchtek worlds of the Mid Rim. Rebel Alliance officer Dutra Zeneta was a Jin.

## Biology & Culture

- **Name:** Jin
- **Height:** 2.1 meters
- **Skincolor:** Green
- **Haircolor:** Black
- **Eyecolor:** Black
- **Distinctions:** Able to see into the infrared spectrum
- **Origin:** Zchtek worlds
