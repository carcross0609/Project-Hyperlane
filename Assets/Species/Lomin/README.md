# Lomin

**Continuity:** Legends  
**Source:** [Lomin](https://starwars.fandom.com/wiki/Lomin)

A native race to the planet Pantolomin, the Lomins were an amphibious race which shared the administrative duties within the Panto system with their neighbors, the Tolos.
