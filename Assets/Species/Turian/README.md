# Turian

**Continuity:** Unknown  
**Source:** [Turian](https://starwars.fandom.com/wiki/Turian)

The Turians were a species of Near-Humans. Senator Luralon Odaay was one. He came from the Limbala sector, but it is unknown whether or not this was where the species originated.
