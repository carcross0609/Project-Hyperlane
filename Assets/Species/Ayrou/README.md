# Ayrou

**Continuity:** Canon  
**Source:** [Ayrou](https://starwars.fandom.com/wiki/Ayrou)

Ayrou were a sentient species. Kilan T'Dara—who served as chair of the advisory council for Force-related groups known as the Convocation of the Force—was an Ayrou.
