# Unidentified brutish reptilian species

**Continuity:** Legends  
**Source:** [Unidentified brutish reptilian species](https://starwars.fandom.com/wiki/Unidentified_brutish_reptilian_species)

An unidentified reptilian-humanoid species dwelled in the Galaxy. One individual served as the champion of Jabba the Hutt around 32 BBY. The species appeared to be sentient as they were capable of using tools and were seen wearing clothing.
