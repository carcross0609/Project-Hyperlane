# Myke

**Continuity:** Legends  
**Source:** [Myke](https://starwars.fandom.com/wiki/Myke)

Mykes were Near-Humans under the rule of the Galactic Empire. Norym Kim, a member of the Imperial Interim Ruling Council, was a Myke.
