# Aybarian

**Continuity:** Canon  
**Source:** [Aybarian](https://starwars.fandom.com/wiki/Aybarian)

The Aybarian were a sentient species from the Aybaria system in the Outer Rim Territories. At some point before taking back control of Cloud City, Baron Administrator Lando Calrissian played a game of Six-Card Gizka Limit against a spice-drunk Aybarian diplomat, in which he won a Rossmoyne Vitiator Pistol from the diplomat.

## Biology & Culture

- **Name:** Aybarian
- **Designation:** Sentient
- **Origin:** Aybaria system
