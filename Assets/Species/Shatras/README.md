# Shatras

**Continuity:** Legends  
**Source:** [Shatras](https://starwars.fandom.com/wiki/Shatras)

The Shatras were sentient species of reptilian bipeds indigenous to Trascor.

## Biology & Culture

- **Name:** Shatras
- **Races:** 5 Races (Including Y'tras, Hy'tras)
- **Height:** 1.7–1.9 meters
- **Haircolor:** None
- **Distinctions:** Flexible necks, talon-like feet, claws, infrared vision, four eyes
- **Origin:** Trascor
