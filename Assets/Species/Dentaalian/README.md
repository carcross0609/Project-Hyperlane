# Dentaalian

**Continuity:** Legends  
**Source:** [Dentaalian](https://starwars.fandom.com/wiki/Dentaalian)

The Dentaalians were the native Human race that inhabited the planet Dentaal. They were all decimated during a Candorian plague outbreak in 0 ABY.
