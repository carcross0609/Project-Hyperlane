# Atrakenite

**Continuity:** Legends  
**Source:** [Atrakenite](https://starwars.fandom.com/wiki/Atrakenite)

Atrakenites were the Human population native to the planet Atraken, who later moved to the moon Trilos following the Battle of Atraken.
