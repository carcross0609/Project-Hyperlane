# Tintinna

**Continuity:** Canon  
**Source:** [Tintinna](https://starwars.fandom.com/wiki/Tintinna)

The Tintinna were a hairy, rodent-faced sentient species. In 382 BBY, when the Children of E'ronoh attacked E'ronoh's mining village of U'ronoh, a tintinna family lived there.
