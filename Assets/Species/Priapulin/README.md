# Priapulin

**Continuity:** Legends  
**Source:** [Priapulin](https://starwars.fandom.com/wiki/Priapulin)

Priapulins were a sapient species from the planet Pria, one of the Core Worlds.

## Biology & Culture

- **Name:** Priapulin
- **Designation:** Sentient
- **Class:** Gastropod
- **Length:** 4 meters
- **Skincolor:** Yellow
- **Eyecolor:** Deep purple
- **Distinctions:** Five knobby notochords
- **Origin:** Pria
- **Language:** Priap
