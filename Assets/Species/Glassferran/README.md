# Glassferran

**Continuity:** Legends  
**Source:** [Glassferran](https://starwars.fandom.com/wiki/Glassferran)

Glassferrans were a sentient species. They had three expressionless eyes, each of which could focus on a different object. Kartill was a Glassferran.

## Biology & Culture

- **Name:** Glassferran
- **Designation:** Sentient
- **Distinctions:** 3 eyes
- **Origin:** Glassferra system
