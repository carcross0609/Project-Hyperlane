# Unidentified Sarafur species

**Continuity:** Legends  
**Source:** [Unidentified Sarafur species](https://starwars.fandom.com/wiki/Unidentified_Sarafur_species)

A sentient species once lived on the Outer Rim Territories planet Sarafur, which at some point became a tide-locked world. The species built many unusual stone structures in the zone separating the planet's illuminated and dark sides, establishing a bustling city there.
