# Sakavian

**Continuity:** Canon  
**Source:** [Sakavian](https://starwars.fandom.com/wiki/Sakavian)

Sakavians were a sentient species from Sakavi Tar. One Sakavian, Skoova Stev, was a master fisherman on the planet Koboh in 9 BBY.

- **Designation:** Sentient
