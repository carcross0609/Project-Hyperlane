# Lepi

**Continuity:** Canon  
**Source:** [Lepi](https://starwars.fandom.com/wiki/Lepi)

The Lepi was a sentient species characterized by their lanky frame, long ears, and buck teeth. One notable Lepi was the smuggler Jaxxon.
