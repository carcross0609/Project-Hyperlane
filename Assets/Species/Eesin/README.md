# Eesin

**Continuity:** Legends  
**Source:** [Eesin](https://starwars.fandom.com/wiki/Eesin)

The Eesin were a sentient species in the galaxy. Their hives were known to be busy with much activity, to the point that an active landing bay could resemble one.
