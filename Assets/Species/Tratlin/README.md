# Tratlin

**Continuity:** Legends  
**Source:** [Tratlin](https://starwars.fandom.com/wiki/Tratlin)

The Tratlin were a sentient species. The species' members included Rallan, an elderly operative for the Alliance to Restore the Republic who served as First Officer of Sandwind Team.
