# Jenet

**Continuity:** Canon  
**Source:** [Jenet](https://starwars.fandom.com/wiki/Jenet)

Jenet were a rodent sentient species. One Jenet, Cenevax, was a crime lord who operated an unlicensed gambling ring on Coruscant.
