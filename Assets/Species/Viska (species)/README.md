# Viska

**Continuity:** Legends  
**Source:** [Viska (species)](https://starwars.fandom.com/wiki/Viska_%28species%29)

The Viska (singular, Visk) were winged sentients, indigenous to Rordak.

## Biology & Culture

- **Name:** Viska
- **Length:** 2–3 meters
- **Wingspan:** 5 meters
- **Distinctions:**
  - Able to see into the infrared spectrum
  - Wings
- **Origin:** Rordak
