# Unidentified Rigariam-using species

**Continuity:** Canon  
**Source:** [Unidentified Rigariam-using species](https://starwars.fandom.com/wiki/Unidentified_Rigariam-using_species)

A sentient species used the language Rigariam and, according to the Path of the Open Hand cult member Shea Ganandra, had gone extinct sometime before the language was also considered to be dead by her by 382 BBY. That year, Ganandra intercepted a message on a Hutt Clan communications network that was in Rigariam and showed it to the Path's Guide, Marda Ro. After Ro stated that she did not speak Huttese, Ganandra informed her that it was actually Rigariam and told the Guide about the species that had used it before it had died.
