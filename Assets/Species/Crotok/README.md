# Crotok

**Continuity:** Legends  
**Source:** [Crotok](https://starwars.fandom.com/wiki/Crotok)

The Crotok were a sentient alien species. This species' members included the pilot of a Helix-class light interceptor, Kizbon's Box, targeted by a gang of pirates led by Larken. The pirates mistakenly thought the pilot would be unarmed, but much to their surprise, the Crotok managed to outfight them using proton torpedoes.
