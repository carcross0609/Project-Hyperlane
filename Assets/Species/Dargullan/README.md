# Dargullan

**Continuity:** Legends  
**Source:** [Dargullan](https://starwars.fandom.com/wiki/Dargullan)

The Dargullans were the Human natives of the planet Dargul. The Dargullans were ruled by a noble class, headed by a Duchess.
