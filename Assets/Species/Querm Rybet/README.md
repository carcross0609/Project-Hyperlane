# Querm Rybet

**Continuity:** Canon  
**Source:** [Querm Rybet](https://starwars.fandom.com/wiki/Querm_Rybet)

The Querm Rybet, or simply Querm, were one of the many subspecies of Rybet, a sentient amphibian species. Querm Rybet hailed from the planet Quermia.

- **Origin:** Quermia
