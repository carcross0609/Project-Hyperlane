# Geonosian

**Continuity:** Legends  
**Source:** [Geonosian/Legends](https://starwars.fandom.com/wiki/Geonosian/Legends)

Geonosians, often called bugs in clone trooper slang, were an insectoid species native to the planet Geonosis. Geonosians resided in catacomb-like hive colonies beneath the organic-looking spires.

## Biology & Culture

- **Name:** Geonosian
- **Designation:** Sentient

- **Height:** 1.68 - 1.78 meters

- **Distinctions:** Hive-based
- **Origin:**

- **Language:** Geonosian
