# Klytonian

**Continuity:** Legends  
**Source:** [Klytonian](https://starwars.fandom.com/wiki/Klytonian)

The Klytonians were a sentient species originating in the Klytonia system of the Outer Rim Territories' Bheriz sector. Their bodies were covered with leathery scales, which produced electric field vibrations that allowed them to communicate with each other.

## Biology & Culture

- **Name:** Klytonian
- **Designation:** Sentient
- **Distinctions:**
  - Leathery scales
  - Communication via electric field vibrations
- **Origin:** Klytonia system
