# Saurian (species)

**Continuity:** Unknown  
**Source:** [Saurian (species)](https://starwars.fandom.com/wiki/Saurian_%28species%29)

Saurians were a reptilian race with snake-like heads. They spoke with a lisp and generally wore swamp-patterned fatigues. Sithless Leethe and Slopper were both members of this species.
