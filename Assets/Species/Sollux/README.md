# Sollux

**Continuity:** Canon  
**Source:** [Sollux](https://starwars.fandom.com/wiki/Sollux)

The Sollux was a humanoid sentient species with frog-like features which the mysterious being Orphne belonged to.

## Biology & Culture

- **Name:** Sollux
- **Designation:** Sentient
- **Class:**
  - Reptile
  - Amphibian
- **Height:** 1.75 meters
- **Skincolor:** Light green with white patterning
- **Haircolor:** Brown
- **Eyecolor:** Purple
- **Distinctions:**
  - Bulbous fingers
  - Prehensile tongue
  - Purple eyes
