# Yelsainian

**Continuity:** Legends  
**Source:** [Yelsainian](https://starwars.fandom.com/wiki/Yelsainian)

The Yelsainians were the Human natives of the planet Yelsain. Lieutenant Mishowan Shigormallan, a Pathfinder with the Alliance Special Forces, was a Yelsainian.
