# Saadul

**Continuity:** Legends  
**Source:** [Saadul](https://starwars.fandom.com/wiki/Saadul)

The Saadul were a sentient species. In 25 ABY, a number of Saadul were displaced by the Yuuzhan Vong invasion of the galaxy, and ended up with numerous other refugees on the planet Ruan. The Ruan authorities created a central database keeping track of all refugees. While the list was sorted by species, the Saadul did not receive an entry in the main listing; instead, along with the Rybet and Ryn species, they were placed in the "other" category. This was a common occurrence for the species.
