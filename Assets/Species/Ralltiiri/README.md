# Ralltiiri

**Continuity:** Legends  
**Source:** [Ralltiiri](https://starwars.fandom.com/wiki/Ralltiiri)

The Ralltiiri, Ralltireans, or Ralltiirians were natives of the Core World Ralltiir. Ralltiiri natives included Pharl McQuarrie, Yerka Mig, Derek Klivian, Retwin, and Jeroen Webb.
