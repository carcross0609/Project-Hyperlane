# Xi'Dec

**Continuity:** Canon  
**Source:** [Xi'Dec](https://starwars.fandom.com/wiki/Xi%27Dec)

The Xi'Dec were an insectoid sentient species from Stic. Ubbla Mollbro, a female opera singer with engorged egg sacs, was a member of this species.
