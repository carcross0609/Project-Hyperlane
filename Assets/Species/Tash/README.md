# Tash

**Continuity:** Canon  
**Source:** [Tash](https://starwars.fandom.com/wiki/Tash)

The Tash were a sentient species native to Dagobah who grew herbs. These herbs were used in drinks like the Dagobah Slug Slinger on Batuu.

- **Designation:** Sentient
