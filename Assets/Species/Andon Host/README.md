# Andon Host

**Continuity:** Canon  
**Source:** [Andon Host](https://starwars.fandom.com/wiki/Andon_Host)

The Andon Host were a species on the planet Malenko. By the time of the Clone Wars the Andon Host were long extinct. According to legends, they were powerful necromancers.
