# Bergamasque

**Continuity:** Legends  
**Source:** [Bergamasque](https://starwars.fandom.com/wiki/Bergamasque)

The Bergamasque were a sentient race. They had tentacles and stubby fingers. One member of the Bergamasque species was cantina owner and operator Salla C'airam.
