# Unidentified blue humanoid species

**Continuity:** Legends  
**Source:** [Unidentified blue humanoid species](https://starwars.fandom.com/wiki/Unidentified_blue_humanoid_species)

This race of blue-skinned humanoids were native to a planet. Their homeworld was the location of the battle during the Clone Wars. Jedi Master Yoda defeated an entire Separatist army using only a giant chaingun. A cantina patron was a member of this species.
