# Belascan

**Continuity:** Legends  
**Source:** [Belascan](https://starwars.fandom.com/wiki/Belascan)

Belascans were the Human natives of the planet Belasco. One of their trademarks was the Belascan headdress. Senator Uta S'orn was a Belascan.
