# Argazdan

**Continuity:** Canon  
**Source:** [Argazdan](https://starwars.fandom.com/wiki/Argazdan)

Argazdans were a green-skinned sentient species. By 382 BBY, an Argazdan spacer claimed that Evereni could talk to the dead and see ghosts, which prompted Evereni Yana Ro to smash his nose into a bar.

## Biology & Culture

- **Name:** Argazdan
- **Designation:** Sentient
- **Skincolor:** Green
- **Origin:** Argazda system
