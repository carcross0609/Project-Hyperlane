# Duor

**Continuity:** Unknown  
**Source:** [Duor](https://starwars.fandom.com/wiki/Duor)

Duors were highly sentient, Force-sensitive delphinoids indigenous to the planet Arrakan. They believed the Leviathan Kithnarrock to be their creator. They created the Battrach by using bio-engineering techniques.
