# Ho'Din

**Continuity:** Legends  
**Source:** [Ho'Din/Legends](https://starwars.fandom.com/wiki/Ho%27Din/Legends)

Ho'Din were tall aliens, renowned throughout the galaxy for their botanical and healing abilities.
