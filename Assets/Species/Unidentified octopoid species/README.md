# Unidentified octopoid species

**Continuity:** Legends  
**Source:** [Unidentified octopoid species](https://starwars.fandom.com/wiki/Unidentified_octopoid_species)

An octopoid species lived in the galaxy. Two members of this species were serving on the Aurorient Express as musicians in a band.

- **Designation:** Sentient
