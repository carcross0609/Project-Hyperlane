# Gutretee

**Continuity:** Legends  
**Source:** [Gutretee (species)](https://starwars.fandom.com/wiki/Gutretee_%28species%29)

Gutretee were a crystalline sentient species indigenous to Isis. The Gutretee were immune to blaster fire.
