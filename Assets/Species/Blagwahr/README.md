# Blagwahr

**Continuity:** Legends  
**Source:** [Blagwahr](https://starwars.fandom.com/wiki/Blagwahr)

The Blagwahr were a primitive race from Arorua. When Obi-Wan Kenobi and Qui-Gon Jinn trained on the planet, they saved Mosko Bolpa from a Blagwahr snare trap. A sacrificial altar was built for a Silan on a mountain and it is possible that the Blagwahr people built it.
