# Espirion (species)

**Continuity:** Legends  
**Source:** [Espirion (species)/Legends](https://starwars.fandom.com/wiki/Espirion_%28species%29/Legends)

Espirion was a species that included the legendary Jedi Handi. During the rule of the Eternal Empire, researchers claimed to have discovered Handi's lost resting place.
