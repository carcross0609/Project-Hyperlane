# Peripleen

**Continuity:** Legends  
**Source:** [Peripleen](https://starwars.fandom.com/wiki/Peripleen)

Peripleen were long-living, simian sentients with strong jaws and arms. Wim Smoot, an inmate on Oovo IV, was a Peripleen.

## Biology & Culture

- **Name:** Peripleen
- **Designation:** Sentient
- **Skincolor:** Purple
- **Haircolor:** None
- **Distinctions:** Reptilian apes, strong jaws and arms
