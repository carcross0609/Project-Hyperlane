# Karkarodon

**Continuity:** Legends  
**Source:** [Karkarodon/Legends](https://starwars.fandom.com/wiki/Karkarodon/Legends)

Karkarodons were an aggressive, aquatic species that hailed from the planet Karkaris. Some, like Riff Tamson, supported the Confederacy of Independent Systems during the Clone Wars.

## Biology & Culture

- **Name:** Karkarodon
- **Designation:** Sentient
- **Class:** Amphibious humanoid
- **Skincolor:**
  - Gray
  - Blue
  - White
- **Eyecolor:** Black
- **Distinctions:**
  - Multiple rows of sharp teeth
  - Powerful jaws
- **Origin:** Karkaris
- **Habitat:** Aquatic
- **Diet:** Carnivorous
- **Language:** Galactic Basic Standard
