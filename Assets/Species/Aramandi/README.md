# Aramandi

**Continuity:** Legends  
**Source:** [Aramandi](https://starwars.fandom.com/wiki/Aramandi)

The Aramandi were sentient mammalian bipeds indigenous to the planet Aram.

## Biology & Culture

- **Name:** Aramandi
- **Height:** 1.0–1.5 meters
- **Skincolor:**
  - Light red
  - light brown
- **Eyecolor:** Black
- **Distinctions:**
  - Four arms
  - four solid eyes
- **Origin:** Aram
