# Suurjan

**Continuity:** Legends  
**Source:** [Suurjan](https://starwars.fandom.com/wiki/Suurjan)

The Suurjans were a sentient species native to the planet of Suurja, located in the Suurja system of the Ojoster sector of the Outer Rim Territories. Suurjans lacked ears.
