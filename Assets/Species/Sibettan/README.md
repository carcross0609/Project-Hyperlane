# Sibettan

**Continuity:** Canon  
**Source:** [Sibettan](https://starwars.fandom.com/wiki/Sibettan)

Sibettans were a sentient species in the galaxy. Loo Re Anno was a member of the species who, at some point in the distant past, created the Dragon Void Run and disappeared into the seams between space and time.

## Biology & Culture

- **Name:** Sibettan
- **Designation:** Sentient
- **Skincolor:** Blue
- **Eyecolor:** Gold
- **Distinctions:**
  - Two forearms on each arm
  - Three-fingered hands on outer arm
  - Five-fingered hands on inner arm
- **Origin:** Sibetta system
