# Lodi

**Continuity:** Legends  
**Source:** [Lodi](https://starwars.fandom.com/wiki/Lodi)

The Lodi were a species that was native to Solibus IV. They disappeared millennia before the Clone Wars, by which time it was rumored that the secrets of the species were stored in the Shu-Wang Prism.
