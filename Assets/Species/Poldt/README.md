# Poldt

**Continuity:** Legends  
**Source:** [Poldt](https://starwars.fandom.com/wiki/Poldt)

Poldts were lanky sapient bipeds that superficially bore some resemblance to Gungans and the Geonosians.

## Biology & Culture

- **Name:** Poldt
- **Designation:** Sentient
- **Class:** Humanoid
- **Distinctions:** Lanky, with a sour face
