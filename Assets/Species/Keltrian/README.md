# Keltrian

**Continuity:** Canon  
**Source:** [Keltrian](https://starwars.fandom.com/wiki/Keltrian)

The Keltrians were a sentient species from the Keltria system. A book called Ancient Keltrian Poets: Masters of Alliteration contained poetry that ancient Keltrians wrote.

- **Designation:** Sentient
