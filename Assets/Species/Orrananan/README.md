# Orrananan

**Continuity:** Legends  
**Source:** [Orrananan](https://starwars.fandom.com/wiki/Orrananan)

The Orrananans were a sentient species from the Orranana system. According to Evocar by Direus'pei, they were made extinct by Xim.
