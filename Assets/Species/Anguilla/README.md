# Anguilla

**Continuity:** Legends  
**Source:** [Anguilla](https://starwars.fandom.com/wiki/Anguilla)

Anguilla were oceanic sentients indigenous to Alluuvia in Elrood sector.

## Biology & Culture

- **Name:** Anguilla
- **Height:** 3 to 4 meters long
- **Distinctions:** Eel-like bodies, webbed fingers, infrared vision
- **Origin:** Alluuvia
