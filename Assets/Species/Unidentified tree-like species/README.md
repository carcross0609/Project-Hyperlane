# Unidentified tree-like species

**Continuity:** Legends  
**Source:** [Unidentified tree-like species](https://starwars.fandom.com/wiki/Unidentified_tree-like_species)

A tree-like species attempted to colonize the planet Karra at some point in their history. The native Karrans were insulted by the settlement, and proceeded to kill the alien colonists.
