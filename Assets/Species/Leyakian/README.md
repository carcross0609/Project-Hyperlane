# Leyakian

**Continuity:** Canon  
**Source:** [Leyakian](https://starwars.fandom.com/wiki/Leyakian)

Leyakians were a sentient species found in the galaxy. One notable Leyakian, By Bluss, served as a senator in the Separatist Senate.

## Biology & Culture

- **Name:** Leyakian
- **Designation:** Sentient
- **Skincolor:** Brown
- **Eyecolor:** Yellow
- **Origin:** Leyaki system
