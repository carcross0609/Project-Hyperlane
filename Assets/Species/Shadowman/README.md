# Shadowman

**Continuity:** Legends  
**Source:** [Shadowman](https://starwars.fandom.com/wiki/Shadowman)

The Shadowmen were humanoids native to the "night planet" of Nivek.

## Biology & Culture

- **Name:** Shadowman
- **Skincolor:** Purple
- **Distinctions:**
