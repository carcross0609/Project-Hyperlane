# Suerton

**Continuity:** Canon  
**Source:** [Suerton](https://starwars.fandom.com/wiki/Suerton)

The Suerton were a sentient reptilian species that lived in the galaxy. An eerily lucky species, the Suertons allegedly had the ability to subconsciously affect probability. The brothers Dodibin, Thodibin, and Wodibin were all Suertons from Chanceuxi.
