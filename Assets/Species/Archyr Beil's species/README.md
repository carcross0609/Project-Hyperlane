# Archyr Beil's species

**Continuity:** Legends  
**Source:** [Archyr Beil's species](https://starwars.fandom.com/wiki/Archyr_Beil%27s_species)

This humanoid race had six-fingered hands, a lanky build and severe-looking faces. Archyr Beil and Skeck Draggle were members of this species.
