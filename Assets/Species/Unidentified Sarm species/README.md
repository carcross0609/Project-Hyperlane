# Unidentified Sarm species

**Continuity:** Legends  
**Source:** [Unidentified Sarm species](https://starwars.fandom.com/wiki/Unidentified_Sarm_species)

This species were an ancient race from the planet of Sarm, in Wild Space. They were wiped out by the same supernova that created the Utegetu Nebula.
