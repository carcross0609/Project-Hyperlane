# Narvath (species)

**Continuity:** Legends  
**Source:** [Narvath (species)](https://starwars.fandom.com/wiki/Narvath_%28species%29)

The Narvath were long-limbed humanoids hailing from the planet Narvath. Bijo Hammax was a male Narvath.
