# Fneeb

**Continuity:** Legends  
**Source:** [Fneeb](https://starwars.fandom.com/wiki/Fneeb)

Fneebs were a sentient species. In 0 BBY, a number of Fneeb bounty hunters were present on the planet Tatooine within Chalmun's Spaceport Cantina in the Mos Eisley spaceport. The Rodian bounty hunter Greedo noticed the Fneebs among the other patrons while he drank Pica Thundercloud with fellow hunters Dyyz Nataz and Spurch Goa.
