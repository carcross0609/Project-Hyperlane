# Barolian

**Continuity:** Legends  
**Source:** [Barolian/Legends](https://starwars.fandom.com/wiki/Barolian/Legends)

The Barolians were blue-haired Humans from the planet Baroli. Zakarisz Ghent and Ekria were both Barolians.
