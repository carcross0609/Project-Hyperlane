# Purple Ones

**Continuity:** Canon  
**Source:** [Purple Ones](https://starwars.fandom.com/wiki/Purple_Ones)

The "Purple Ones" were an alien species native to a planet. Unable to speak basic or use blasters, many were enslaved by Krastic Tarta, slavemaster of the Arkanian Dawn.

## Biology & Culture

- **Name:** Purple Ones
- **Haircolor:** Purple
- **Distinctions:**
  - Six arms
  - Thick fur
  - Long legs
  - Big eyes
  - Physically strong
- **Origin:** A planet
