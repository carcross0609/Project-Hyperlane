# Britarro

**Continuity:** Canon  
**Source:** [Britarro](https://starwars.fandom.com/wiki/Britarro)

The Britarro were a mysterious sentient humanoid species that were native to Britaxis Minor. Nik Hepho was a Britarro who worked as a bounty hunter.

- **Name:** Britarro
- **Designation:** Sentient
- **Class:** Humanoid

- **Eyecolor:** Green
- **Origin:** Britaxis Minor
