# Gesaril

**Continuity:** Legends  
**Source:** [Gesaril (species)](https://starwars.fandom.com/wiki/Gesaril_%28species%29)

The Gesarils were a furred, six-limbed sentient species indigenous to Gesaril. Gesarils were all born with an affinity for the Force.

## Biology & Culture

- **Name:** Gesaril
- **Height:** 2 meters
- **Distinctions:** Six limbs
- **Origin:** Gesaril
