# Makurth

**Continuity:** Canon  
**Source:** [Makurth](https://starwars.fandom.com/wiki/Makurth)

The Makurth were a sentient species that lived in the galaxy. On Moltok, a Ho'Din settlement came under attack from a local Makurth boss, leading the Ho'Din to request Imperial muscle to avoid it turning into a full-fledged war.
