# Huwawan

**Continuity:** Canon  
**Source:** [Huwawan](https://starwars.fandom.com/wiki/Huwawan)

The Huwawans were a sentient species that existed in the galaxy. Brothers Taibik Kajok and Wiltoo Kajok were members of this species.

## Biology & Culture

- **Name:** Huwawan
- **Designation:** Sentient
- **Skincolor:** Tan
- **Haircolor:** Black
- **Eyecolor:** Dark
- **Origin:** Huwaw system
- **Language:** Huwawi
