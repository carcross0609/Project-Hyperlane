# Kyuzo

**Continuity:** Legends  
**Source:** [Kyuzo/Legends](https://starwars.fandom.com/wiki/Kyuzo/Legends)

The Kyuzo were a sentient species with yellow eyes and green skin. They were fast and high jumpers.
