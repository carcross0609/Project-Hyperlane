# Dawinian

**Continuity:** Canon  
**Source:** [Dawinian](https://starwars.fandom.com/wiki/Dawinian)

Dawinians were a sentient species from the Dawinia system in the Hynestian sector of the Colonies. Lando Calrissian once had an incident involving a Dawinian host and its companion.
