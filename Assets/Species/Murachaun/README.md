# Murachaun

**Continuity:** Legends  
**Source:** [Murachaun](https://starwars.fandom.com/wiki/Murachaun)

The Murachaun were sentient reptilians indigenous to Nahsu Minor in the Ktilac Regions.

## Biology & Culture

- **Name:** Murachaun
- **Designation:** Sentient
- **Class:** Reptilian
- **Height:** 1.8 - 2.3 meters
- **Skincolor:** Blue, Burgundy, and Red
- **Haircolor:** None
- **Origin:** Nahsu Minor
- **Language:** Murachau
