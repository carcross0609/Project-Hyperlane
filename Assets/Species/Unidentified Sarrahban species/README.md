# Unidentified Sarrahban species

**Continuity:** Legends  
**Source:** [Unidentified Sarrahban species](https://starwars.fandom.com/wiki/Unidentified_Sarrahban_species)

A sentient species was native to the planet Sarrahban in the Sarrahban system. Their home system remained neutral throughout the Galactic Civil War, although the Galactic Empire eventually invaded the planet.
