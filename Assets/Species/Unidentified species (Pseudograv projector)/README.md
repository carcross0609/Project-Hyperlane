# Unidentified species

**Continuity:** Legends  
**Source:** [Unidentified species (Pseudograv projector)](https://starwars.fandom.com/wiki/Unidentified_species_%28Pseudograv_projector%29)

An unidentified sentient species possessed gravity well projectors, which were used to pull starships out of hyperspace. The Vagaari Empire stole the projectors from the species and incorporated them into the Vagaari slaver fleet.
