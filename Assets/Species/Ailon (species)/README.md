# Ailon

**Continuity:** Canon  
**Source:** [Ailon (species)](https://starwars.fandom.com/wiki/Ailon_%28species%29)

The Ailon were a sentient humanoid species whose entire population was employed in a mercenary group called the Ailon Nova Guard. They originated from the Ailon system in the Inner Rim Territories.

## Biology & Culture

- **Name:** Ailon
- **Designation:** Sentient
- **Class:** Humanoid
- **Distinctions:** Militaristic traditions
- **Origin:** Ailon system
