# Celegian

**Continuity:** Canon  
**Source:** [Celegian](https://starwars.fandom.com/wiki/Celegian)

Celegians were a tentacled sentient species. One Celegian was present at the annual pre-Dragon Void Run celebration aboard the Dragon Void space station in 0 ABY.

## Biology & Culture

- **Name:** Celegian
- **Designation:** Sentient
- **Skincolor:**
  - Pink
  - Orange
- **Distinctions:**
  - Tentacles
  - Floating
- **Origin:** Celegia system
