# Ma'alkerrite ape-man

**Continuity:** Legends  
**Source:** [Ma'alkerrite ape-man](https://starwars.fandom.com/wiki/Ma%27alkerrite_ape-man)

The Ma'alkerrite ape-men were an ape-like sentient species hailing from the Ma'alkerr system of the Mid Rim. They had contact with the galaxy by the time of the Galactic Civil War.
