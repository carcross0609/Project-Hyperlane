# Revwien

**Continuity:** Canon  
**Source:** [Revwien](https://starwars.fandom.com/wiki/Revwien)

Revwiens were a sentient species. A Revwien merchant sold Owen Lars a Zephyr-G swoop at an auction in Mos Nytram on the planet Tatooine. The Revwien Comedy Academy Playhouse on the planet Coruscant was named for this species.
