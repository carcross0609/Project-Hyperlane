# Purple alien

**Continuity:** Legends  
**Source:** [Purple alien](https://starwars.fandom.com/wiki/Purple_alien)

Purple aliens were a sentient species with long necks and an indestructible outer skin. A number of these aliens could be found in the Mos Eisley Cantina, wielding their signature long range blaster weapons.

## Biology & Culture

- **Name:** Purple alien
- **Designation:** Sentient
- **Skincolor:** Purple
