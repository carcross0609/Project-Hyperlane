# Dowaaka

**Continuity:** Canon  
**Source:** [Dowaaka](https://starwars.fandom.com/wiki/Dowaaka)

The Dowaaka were a sentient reptilian species with lizard-like heads and four breasts. A Dowaaka served as the host of the Clear River News Network around 200 BBY.

## Biology & Culture

- **Name:** Dowaaka
- **Designation:** Sentient
- **Class:** Reptilian
- **Language:** Galactic Basic Standard
