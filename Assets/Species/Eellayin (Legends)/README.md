# Eellayin

**Continuity:** Legends  
**Source:** [Eellayin/Legends](https://starwars.fandom.com/wiki/Eellayin/Legends)

The Eellayin were an ancient species from the planet Polis Massa before it was destroyed in a mysterious cataclysm, leaving an asteroid belt behind and the Ellayin all but extinct.
