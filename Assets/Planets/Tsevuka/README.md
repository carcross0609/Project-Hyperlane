# Tsevuka

**Continuity:** Canon  
**Source:** [Tsevuka](https://starwars.fandom.com/wiki/Tsevuka)
**Galaxy atlas:** system `Tsevuka`, Outer Rim, grid L-10 — map position (240.3, -809.9, -36.7)

Tsevuka was a planet in the Outer Rim of the galaxy, and the homeworld of the Tsevukan species. At some point the planet came under the control of the Galactic Empire, causing an uproar among the planet's natives.
