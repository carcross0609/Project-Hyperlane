# Dorvalla IV

**Continuity:** Legends  
**Source:** [Dorvalla IV](https://starwars.fandom.com/wiki/Dorvalla_IV)
**Galaxy atlas:** system `Dorvalla IV`, Outer Rim — map position (-2378.5, 7499.4, 241.7)

Dorvalla IV was a world controlled by Dorvalla Mining. It was the planet beyond their main base, Dorvalla. It was apparently inhabitable by humanoids; whether it actually was is unknown.

In 34 BBY, the crew of Arwen Cohl wanted to land on Dorvalla IV, but Cohl knew that there were ships under way to Dorvalla. A single shuttle would attract much attention.
