# Korda Six

**Continuity:** Legends  
**Source:** [Korda Six](https://starwars.fandom.com/wiki/Korda_Six)
**Galaxy atlas:** system `Korda Six`, Inner Rim, grid O-8 — map position (4915.6, 2189.7, 34.2)

Korda Six was a planet that ranged from barren rocky plains to small forests in which the natives lived. It was also where Montross betrayed Jaster Mereel to the Death Watch. Jaster was killed by Tor Vizsla, and Jango Fett became the Mandalore.
