# Najiba

**Continuity:** Canon  
**Source:** [Najiba](https://starwars.fandom.com/wiki/Najiba)
**Galaxy atlas:** system `Najiba`, Outer Rim, grid R-17 — map position (9427.7, -10571.6, -371.7)

Najiba was a planet located in the Najiba system of the Arkanis sector in the Outer Rim Territories. It was the homeworld of Corovene Manakor, a Troglof who worked for the InterGalactic Banking Clan. During the Imperial Era, the planet was occupied by the Galactic Empire, and Manakor participated in a heist on Scipio in an attempt to secure funds to help liberate it.
