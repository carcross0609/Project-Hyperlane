# Sardoran

**Continuity:** Legends  
**Source:** [Sardoran](https://starwars.fandom.com/wiki/Sardoran)
**Galaxy atlas:** system `Sardoran`, Core Worlds, grid M-11 — map position (2232.4, -2325.1, 54.8)

Sardoran, at one point known as Ord Sardoran, was a world located in the Sardoran system, a part of the Arrowhead, or the Slice portion of the Core Worlds. It served as an Ordnance/Regional Depot outpost for the Galactic Republic during the Pius Dea Era, a period of time that lasted between approximately 12,000 BBY and 11,000 BBY. The Human Casti Tholon, who was active by 2 ABY, was native to Sardoran, although she grew up in the Core Worlds' Duro system.
