# Sanjin

**Continuity:** Canon  
**Source:** [Sanjin](https://starwars.fandom.com/wiki/Sanjin)
**Galaxy atlas:** system `Sanjin`, Colonies, grid M-13 — map position (1713.7, -4679.8, -190.8)

Sanjin was a planet that had several moons within the Sanjin system, a star system of the Colonies. Before the mission to Vassek's third moon, Jedi Master Neebo traveled to one of these moons to aid refugees.
