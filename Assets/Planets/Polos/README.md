# Polos

**Continuity:** Legends  
**Source:** [Polos](https://starwars.fandom.com/wiki/Polos)

Polos was a terrestrial planet in the Deep Core's Beshqek system. It occupied the third orbital position around the star Beshqek and had one moon. Polos featured a rocky surface and a toxic environment.
