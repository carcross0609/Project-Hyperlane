# Toprawa

**Continuity:** Legends  
**Source:** [Toprawa/Legends](https://starwars.fandom.com/wiki/Toprawa/Legends)
**Galaxy atlas:** system `Toprawa`, Outer Rim, grid P-5 — map position (6138.1, 6648.7, 361.5)

Toprawa was a remote, forested planet in the Toprawa system of the Kalamith sector in the Bright Jewel Oversector, located in the Outer Rim Territories near the Hydian Way.
