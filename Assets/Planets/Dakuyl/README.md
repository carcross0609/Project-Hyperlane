# Dakuyl

**Continuity:** Legends  
**Source:** [Dakuyl](https://starwars.fandom.com/wiki/Dakuyl)
**Galaxy atlas:** system `Dakuyl`, Outer Rim, grid H-17 — map position (-4591.2, -10862.6, 309.6)

Dakuyl was a planet located within the Verkuyl system of the Outer Rim Territories where alazhi was grown. It was in the same system as Verkuyl and a secondary bacta production was begun on the planet, but halted after the Battle of Endor.
