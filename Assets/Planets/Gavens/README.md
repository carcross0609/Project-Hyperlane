# Gavens

**Continuity:** Legends  
**Source:** [Gavens](https://starwars.fandom.com/wiki/Gavens)
**Galaxy atlas:** system `Gavens`, Expansion Region — map position (5418.2, -8154.5, -14.5)

Gavens was a human-inhabited planet located in the Expansion Region's Gavens system. It was the birthplace of Akanah Norand Goss Pell. Its capital city was Torlas.
