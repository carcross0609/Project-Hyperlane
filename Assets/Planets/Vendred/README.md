# Vendred

**Continuity:** Legends  
**Source:** [Vendred](https://starwars.fandom.com/wiki/Vendred)
**Galaxy atlas:** system `Vendred`, Outer Rim, grid Q-10 — map position (8642.4, -355.0, 35.9)

Vendred was the first planet in the Bissillirus system, a barren globe that was orbited by a single unstable moon. The planet had a local year of fifty-six standard days.
