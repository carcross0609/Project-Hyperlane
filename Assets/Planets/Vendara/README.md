# Vendara

**Continuity:** Legends  
**Source:** [Vendara](https://starwars.fandom.com/wiki/Vendara)
**Galaxy atlas:** system `Vendara`, Outer Rim, grid Q-4 — map position (7810.5, 8374.7, 574.0)

Vendara was a planet located within the Vendara system in the Kwymar sector of the Outer Rim region of the galaxy. It was home to the Vendaran species and the predatory mollusks called skeeg.
