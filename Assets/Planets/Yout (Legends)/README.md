# Yout

**Continuity:** Legends  
**Source:** [Yout/Legends](https://starwars.fandom.com/wiki/Yout/Legends)
**Galaxy atlas:** system `Yout`, Mid Rim, grid L-7 — map position (12.2, 4164.0, 166.8)

Yout was a planet located in the Qiilura sector of the Mid Rim. It had at least twelve moons, including one known as Yout 12, where the assassin droid KRONOS-327 was sent to assassinate a Black Sun Vigo, a task which KRONOS-327 failed.
