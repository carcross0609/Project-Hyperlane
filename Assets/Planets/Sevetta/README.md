# Sevetta

**Continuity:** Canon  
**Source:** [Sevetta](https://starwars.fandom.com/wiki/Sevetta)
**Galaxy atlas:** system `Sevetta`, Outer Rim, grid T-16 — map position (13123.9, -10070.9, 387.8)

Sevetta was a mercury-rich planet located in the Sevetta system within the Sevetta sector of the Outer Rim. It had toxic air and was home to a mercury-based species that could shape-shift.
