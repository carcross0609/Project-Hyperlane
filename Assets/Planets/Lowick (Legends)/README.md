# Lowick

**Continuity:** Legends  
**Source:** [Lowick/Legends](https://starwars.fandom.com/wiki/Lowick/Legends)
**Galaxy atlas:** system `Lowick`, Outer Rim, grid U-9 — map position (13612.8, 329.5, -200.5)

Lowick was a neutral planet in the Outer Rim Territories with equatorial rainforests that was the homeworld of the Pa'lowick species who hunted, fished, and farmed in the salt marshes. The planet abounded in fish, reptiles, marlello ducks, and veejy fruit.
