# Kyryll's World

**Continuity:** Legends  
**Source:** [Kyryll's World/Legends](https://starwars.fandom.com/wiki/Kyryll%27s_World/Legends)
**Galaxy atlas:** system `Kyryll's World`, Outer Rim — map position (2095.1, -14938.0, 80.2)

Kyryll's World was a terrestrial planet located in the Kyryll's World system, a part of the Phelleem sector in the Slice portion of the Outer Rim Territories. It was the homeworld of the sentient Pui-ui species, members of which communicated in the Pui-ui language and which was known to the wider galaxy by 671 BBY.
