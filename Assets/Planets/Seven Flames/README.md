# Seven Flames

**Continuity:** Legends  
**Source:** [Seven Flames](https://starwars.fandom.com/wiki/Seven_Flames)

Seven Flames was a planet located in the Rayter sector of the Outer Rim Territories. During the Galactic Civil War, the Alliance to Restore the Republic established a support base on the planet, which the Rebels used to launch a diplomatic operation to the planet Karra in an attempt to gain an alliance with the native Karrans. However, the mission was unsuccessful, though the Rebel diplomatic team was able to return to the base on Seven Flames with Karra's Imperial Governor Darryn Edalm in custody.
