# Buamlon Central

**Continuity:** Legends  
**Source:** [Buamlon Central](https://starwars.fandom.com/wiki/Buamlon_Central)
**Galaxy atlas:** system `Buamlon Central`, Other, grid Q-4 — map position (8515.9, 8487.6, -213.5)

Buamlon Central was a planet located in the system of the same name, situated in the Esstran sector of the Outer Rim Territories. It was a dangerous world, and was staked by Barosa Warren, a scout serving with the Republic Survey Corps.
