# Iktotchon

**Continuity:** Canon  
**Source:** [Iktotchon](https://starwars.fandom.com/wiki/Iktotchon)
**Galaxy atlas:** system `Iktotchon`, Expansion Region, grid O-14 — map position (5190.1, -6096.6, -155.3)

Iktotchon was a planet located in the Iktotch system in the Narvath sector of the Expansion Region. It had a moon, Iktotch, which was the homeworld of Iktotchi Jedi Master Saesee Tiin.
