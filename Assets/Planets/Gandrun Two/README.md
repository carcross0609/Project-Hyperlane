# Gandrun Two

**Continuity:** Legends  
**Source:** [Gandrun Two](https://starwars.fandom.com/wiki/Gandrun_Two)

Gandrun Two was a desert world that occupied the second orbital position in the Colonies' Gandrun system. Its terrain was dominated by endless sand dunes.
