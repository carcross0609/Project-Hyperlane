# Mikak

**Continuity:** Legends  
**Source:** [Mikak](https://starwars.fandom.com/wiki/Mikak)
**Galaxy atlas:** system `Mikak`, Mid Rim — map position (7353.0, -8329.4, 346.8)

Mikak was the first planet orbiting the star Tyrius in the Tyrius system.

Located in the Savareen sector of the Outer Rim Territories, it was a tiny searing rock. Because of its proximity to its sun, it was unusable to the space-faring Rodians.
