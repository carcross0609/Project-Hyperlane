# Unidentified barren planet

**Continuity:** Legends  
**Source:** [Unidentified barren planet](https://starwars.fandom.com/wiki/Unidentified_barren_planet)

This unidentified planet, located beyond the Outer Rim, was the setting for a battle between the Confederacy of Independent Systems and the Galactic Republic in 21 BBY. Its surface features included a quarry.
