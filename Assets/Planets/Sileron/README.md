# Sileron

**Continuity:** Legends  
**Source:** [Sileron](https://starwars.fandom.com/wiki/Sileron)

Sileron was the Derkolo homeworld in the Mektrun Cluster; it was the first planet in the Veron Minor system. It was very hostile and tourists were warned not to visit the planet.
