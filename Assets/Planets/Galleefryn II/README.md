# Galleefryn II

**Continuity:** Legends  
**Source:** [Galleefryn II](https://starwars.fandom.com/wiki/Galleefryn_II)
**Galaxy atlas:** system `Galleefryn II`, Outer Rim — map position (6843.5, -14267.7, -389.1)

Galleefryn II was a jungle planet in Corporate Sector.

It was freed from Imperial control by the Rebel Alliance in a struggle that took place more than ten years before the Battle of Endor.
