# Vergill

**Continuity:** Legends  
**Source:** [Vergill](https://starwars.fandom.com/wiki/Vergill)
**Galaxy atlas:** system `Vergill`, Inner Rim, grid O-9 — map position (5077.3, 872.5, -72.3)

Vergill was a planet located within the Vergill system of the Inner Rim. It was an influential member of the Hapes Consortium. In 25 ABY, the planet's archon was Beed Thane.
