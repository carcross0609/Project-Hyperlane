# Faldos

**Continuity:** Legends  
**Source:** [Faldos](https://starwars.fandom.com/wiki/Faldos)
**Galaxy atlas:** system `Faldos`, Outer Rim, grid K-20 — map position (-1411.6, -15528.3, -194.5)

Faldos was a dirty backwater Outer Rim Territories world used by smugglers to sell stolen weapons, armor, and technology. It sat on the very edge of the galaxy, making it far more removed than most of the Outer Rim Territories.

The planet was attacked by Nagai invaders in 4 ABY.
