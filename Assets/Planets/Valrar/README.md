# Valrar

**Continuity:** Legends  
**Source:** [Valrar](https://starwars.fandom.com/wiki/Valrar)
**Galaxy atlas:** system `Valrar`, Mid Rim, grid J-7 — map position (-1781.8, 4103.2, 61.0)

Valrar was a planet located within the Valrar system of the Mid Rim. Its dense canopy forests blocked most sunlight from reaching the planet's surface. Khabarakh was reassigned here by Thrawn after his failure to capture Leia Organa Solo on Kashyyyk.
