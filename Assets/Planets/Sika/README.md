# Sika

**Continuity:** Legends  
**Source:** [Sika](https://starwars.fandom.com/wiki/Sika)
**Galaxy atlas:** system `Sika`, Expansion Region, grid O-15 — map position (5198.6, -7694.4, -97.2)
