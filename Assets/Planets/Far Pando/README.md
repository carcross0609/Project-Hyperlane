# Far Pando

**Continuity:** Legends  
**Source:** [Far Pando](https://starwars.fandom.com/wiki/Far_Pando)
**Galaxy atlas:** system `Far Pando`, Hutt Space, grid S-13 — map position (11460.6, -5526.0, 52.6)

Far Pando was a peaceful agrarian planet in the Far Pando system of Hutt Space. It was situated along the Pando Spur hyperlane, an offshoot of the larger Hollastin Run. The planet was under the control of the sentient Yahk-Tosh species.
