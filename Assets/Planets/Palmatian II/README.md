# Palmatian II

**Continuity:** Canon  
**Source:** [Palmatian II](https://starwars.fandom.com/wiki/Palmatian_II)

Palmatian II was a world on which gambling could be done safely. It was located in the Palmatian system in the Baronos sector of the Colonies.
