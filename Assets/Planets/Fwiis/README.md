# Fwiis

**Continuity:** Legends  
**Source:** [Fwiis](https://starwars.fandom.com/wiki/Fwiis)
**Galaxy atlas:** system `Fwiis`, Inner Rim, grid M-13 — map position (1866.2, -4662.3, -11.7)

Fwiis was a colony world between Darepp and Motexx visited by the Star Morning after it departed Teyr. It was more than 150 light-years away from Atzerri.
