# Euton

**Continuity:** Legends  
**Source:** [Euton](https://starwars.fandom.com/wiki/Euton)
**Galaxy atlas:** system `Euton`, Outer Rim — map position (3971.3, 6587.8, 276.9)

Euton was a terrestrial planet in the Dathomir system, a part of the Quelii sector in the New Territories portion of the Outer Rim Territories. It occupied the second orbital position around the star Domir, and it featured a searing hot environment and a rocky surface. Euton had no moons.
