# Derenath

**Continuity:** Legends  
**Source:** [Derenath](https://starwars.fandom.com/wiki/Derenath)
**Galaxy atlas:** system `Derenath`, Outer Rim — map position (2484.7, -15487.9, 461.7)

Derenath was a barren, icy planet that occupied the sixth orbit around the star Beheboth in the Beheboth system, a star system located in the Sanbra sector, a part of the Trailing Sectors in the Outer Rim Territories. Derenath had no moons.
