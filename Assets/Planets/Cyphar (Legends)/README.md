# Cyphar

**Continuity:** Legends  
**Source:** [Cyphar/Legends](https://starwars.fandom.com/wiki/Cyphar/Legends)
**Galaxy atlas:** system `Cyphar`, Mid Rim, grid L-17 — map position (135.9, -11170.7, -202.4)
