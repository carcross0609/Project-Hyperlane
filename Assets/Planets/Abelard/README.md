# Abelard

**Continuity:** Unknown  
**Source:** [Abelard](https://starwars.fandom.com/wiki/Abelard)

Abelard was a planet in the Abelard system on which the Galactic Empire had established a base during the Rebellion era. Sometime after the Battle of Yavin, the Alliance to Restore the Republic attacked the base and managed to steal a stabilized ytterbium cargo.

## Planetary data

- **Name:** Abelard
- **System:** Abelard system
- **Affiliation:** Galactic Empire
