# Jomark

**Continuity:** Legends  
**Source:** [Jomark/Legends](https://starwars.fandom.com/wiki/Jomark/Legends)
**Galaxy atlas:** system `Jomark`, Outer Rim, grid R-7 — map position (10223.4, 4001.2, 185.9)

Jomark was the second of six worlds in the Jomark system. Originally known as Bynas, it was absorbed into Xim's Empire as he expanded his borders from the Kingdom of Cron.
