# Rior

**Continuity:** Canon  
**Source:** [Rior](https://starwars.fandom.com/wiki/Rior)
**Galaxy atlas:** system `Rior`, Outer Rim, grid N-18 — map position (3245.4, -12765.4, -289.8)

Rior was an Outer Rim Territories planet located in the Rior system of the Tamarin sector in grid N-18 of the Standard Galactic Grid. It was situated on a hyperspace route that connected it to the Kabal and Sevarcos systems. Rior was the homeworld of Loje Nella, a Riorian member of the court of the Hutt crime lord Jabba Desilijic Tiure.
