# Dorande

**Continuity:** Legends  
**Source:** [Dorande](https://starwars.fandom.com/wiki/Dorande)

Dorande was the homeworld of the Dorande race, who tried to conquer the planet R-Duba. This plan was foiled by C-3PO and R2-D2, however.

It was located in the Outer Rim Territories.
