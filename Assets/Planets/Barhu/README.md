# Barhu

**Continuity:** Legends  
**Source:** [Barhu](https://starwars.fandom.com/wiki/Barhu)
**Galaxy atlas:** system `Barhu`, Mid Rim, grid P-14 — map position (7002.6, -6992.7, -458.6)

Barhu was the first planet from the single star of the Churba system. It was a high-temperature, rocky world that was considered to have no civilized purpose.
