# Ventooine

**Continuity:** Legends  
**Source:** [Ventooine/Legends](https://starwars.fandom.com/wiki/Ventooine/Legends)
**Galaxy atlas:** system `Ventooine`, Outer Rim, grid P-3 — map position (7127.9, 9324.6, -169.4)

Ventooine was a planet located within the Ventooine system of the Outer Rim Territories. It was ruled by the Satabs until their line was ended by Han Solo and the local Tieress, Chrysalla. The planet exported sansanna spice, crystals, and a mineral named Shadeshine.
