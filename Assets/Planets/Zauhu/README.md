# Zauhu

**Continuity:** Legends  
**Source:** [Zauhu](https://starwars.fandom.com/wiki/Zauhu)
**Galaxy atlas:** system `Zauhu`, Core Worlds, grid L-10 — map position (199.1, -172.6, 35.0)

Zauhu was a planet in the Zug system. It was the first planet beyond the asteroid belt and one of the four gas giants in the system, along with Urazuun, Faargau, and Laazrau. Zauhu had the largest number of natural satellites in the star system – forty-seven.
