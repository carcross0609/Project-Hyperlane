# Ravnok

**Continuity:** Unknown  
**Source:** [Ravnok](https://starwars.fandom.com/wiki/Ravnok)

Ravnok was a terrestrial planet where an Imperial base was located. In 9 ABY, Din Djarin and Grogu visited the abandoned base in search of spare parts and were attacked by a Rancor.
