# Tancon

**Continuity:** Legends  
**Source:** [Tancon/Legends](https://starwars.fandom.com/wiki/Tancon/Legends)
**Galaxy atlas:** system `Tancon`, Outer Rim, grid J-18 — map position (-2886.7, -13078.4, 38.4)

Tancon was a terrestrial planet located in the Tancon system of the Outer Rim Territories' Koradin sector. It was situated at a distance of two days' travel with a starship equipped with a Class 1 hyperdrive from the Soarin system of the Wazta sector. At some point between 0 ABY and 3 ABY, the Rebel Alliance maintained on Tancon a base with a briefing room in it.

The base's commander at one point briefed a Rebel team that was due for a rest-and-recuperation period on a mission to deliver supplies from the Soarin system's Greyman's Planet to the Alliance's Karinda Outpost on the Karinda system planet of the same name. The team then departed for Greyman's Planet aboard the base's light freighter Arion Star.
