# Waskiro

**Continuity:** Legends  
**Source:** [Waskiro/Legends](https://starwars.fandom.com/wiki/Waskiro/Legends)
**Galaxy atlas:** system `Waskiro`, Outer Rim, grid R-7 — map position (9479.8, 3425.3, -266.4)

Waskiro was a mountainous world in the Jospro sector of the Outer Rim. The planet was heavily involved in trade, namely mining. At some point in history, the contact with the mining colony was lost.
