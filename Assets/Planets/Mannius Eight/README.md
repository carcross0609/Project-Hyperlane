# Mannius Eight

**Continuity:** Canon  
**Source:** [Mannius Eight](https://starwars.fandom.com/wiki/Mannius_Eight)
**Galaxy atlas:** system `Mannius Eight`, Wild Space — map position (-3750.9, -17802.1, -452.6)

Mannius Eight was a planet located in the Mannius system in Wild Space, in grid square I-14 of the Standard Galactic Grid. At one point it was explored by the Graf family. The planet included lifeforms such as octopoids which communicated by changing their skin patterns.
