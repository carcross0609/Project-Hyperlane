# Quyste

**Continuity:** Legends  
**Source:** [Quyste](https://starwars.fandom.com/wiki/Quyste)
**Galaxy atlas:** system `Quyste`, Outer Rim, grid O-6 — map position (5395.8, 4924.8, 73.3)

Qusyte was a planet in the Quyste system within the Thesme sector of the Outer Rim Territories on which Talon Karrde had a training center. The smuggler sent H'sishi there before 18 ABY to study starship operations.
