# Goroth Prime; Celleballen

**Continuity:** Legends  
**Source:** [Goroth Prime/Legends](https://starwars.fandom.com/wiki/Goroth_Prime/Legends)
**Galaxy atlas:** system `Goroth Prime`, Mid Rim, grid R-16 — map position (9246.0, -9719.0, -49.6)

Goroth Prime, also simply known as Goroth, was the Gorothite homeworld, located on the border with the Mid Rim. The Aqualish knew this world under the name Celleballen, which meant "wasteland."
