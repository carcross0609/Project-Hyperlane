# Lysatra

**Continuity:** Canon  
**Source:** [Lysatra](https://starwars.fandom.com/wiki/Lysatra)
**Galaxy atlas:** system `Lysatra`, Wild Space — map position (-6132.8, -7375.9, -195.8)

Lysatra was an isolated planet in the Lysatra system in grid square I-8 of the Standard Galactic Grid, a portion of the Expansion Region that was considered Wild Space. By 15 BBY, it was still considered a part of Wild Space. Eli Vanto grew up on Lysatra, where he heard stories about the Chiss and worked in a shipping company. Besides Galactic Basic Standard, many trade languages of the Wild Space were spoken, including the language Sy Bisti.
