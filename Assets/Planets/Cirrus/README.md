# Cirrus

**Continuity:** Legends  
**Source:** [Cirrus](https://starwars.fandom.com/wiki/Cirrus)
**Galaxy atlas:** system `Cirrus`, Outer Rim, grid J-6 — map position (-1868.3, 5236.8, -185.9)

Cirrus was a Outer Rim world orbiting two orange suns. It had golden seas and lovely cities, including the capital Ciran near a bay. It was the homeworld of Talesan Fry and his parents.
