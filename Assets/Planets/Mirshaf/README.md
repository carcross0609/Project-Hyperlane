# Mirshaf

**Continuity:** Legends  
**Source:** [Mirshaf](https://starwars.fandom.com/wiki/Mirshaf)

Mirshaf was a planet with an ancient culture that was venerated in the galaxy. Captain Dorja, who served under Grand Admiral Thrawn, used the culture's victory gestures in battle.
