# Gandeal

**Continuity:** Legends  
**Source:** [Gandeal](https://starwars.fandom.com/wiki/Gandeal)
**Galaxy atlas:** system `Gandeal`, Core Worlds, grid M-12 — map position (2190.6, -4249.3, 57.0)

Gandeal was a Planet in the Core Worlds and partner planet to the world of Fondor, a fortress world situated on the Corellian Trade Spine.

It was one of the endpoints of the Gandeal-Fondor Hyperlane, which the Galactic Empire established to export raw materials from Gandeal to the Fondor Shipyards and Gandeal was used as a checkpoint of bulk freighters.
