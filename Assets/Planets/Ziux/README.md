# Ziux

**Continuity:** Legends  
**Source:** [Ziux](https://starwars.fandom.com/wiki/Ziux)

Ziux was the fourth planet orbiting the binary stars Toydar and Little Toydar in the Toydaria system. Located in Hutt Space of the galaxy, it was a gas giant.
