# Alsakan

**Continuity:** Canon  
**Source:** [Alsakan](https://starwars.fandom.com/wiki/Alsakan)
**Galaxy atlas:** system `Alsakan`, Core Worlds, grid L-9 — map position (258.3, 163.8, -2.5)

Alsakan was a Core Worlds planet situated along the Perlemian Trade Route. It was the homeworld of both Doctor Cornelius Evazan and the career military officer Enric Pryde.
