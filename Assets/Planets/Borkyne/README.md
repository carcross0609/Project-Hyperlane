# Borkyne

**Continuity:** Legends  
**Source:** [Borkyne](https://starwars.fandom.com/wiki/Borkyne)
**Galaxy atlas:** system `Borkyne`, Expansion Region, grid L-15 — map position (704.5, -8344.8, -129.1)

Borkyne was location that shared its name with the Borkyne system of the Bes Ber Bikade sector in the Expansion Region. In 2 ABY, Captain Dagon Niriz claimed that Jodo Kast needed an Imperial pardon for a mess made on Borkyne.
