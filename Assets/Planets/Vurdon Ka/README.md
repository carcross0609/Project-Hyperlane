# Vurdon Ka

**Continuity:** Canon  
**Source:** [Vurdon Ka](https://starwars.fandom.com/wiki/Vurdon_Ka)
**Galaxy atlas:** system `Vurdon Ka`, Inner Rim, grid M-9 — map position (2535.3, 1416.2, -84.9)

Vurdon Ka was a planet located in the Vurdon Ka system in the Darlonn sector of the galaxy's Inner Rim that was the homeworld of the Vuvrian species. It was located close to one end of the Perlemian Trade Route, which connected it to the planets Castell and Chazwa.
