# Weytta

**Continuity:** Legends  
**Source:** [Weytta](https://starwars.fandom.com/wiki/Weytta)
**Galaxy atlas:** system `Weytta`, Outer Rim, grid S-6 — map position (11820.4, 4916.1, 60.6)

Weytta was a planet located within the Weytta system of the Outer Rim Territories, near Murkhana. It was the homeworld of the Jedi Master Roan Shryne and his parents, Jula and Jen.
