# Belsmuth II

**Continuity:** Legends  
**Source:** [Belsmuth II](https://starwars.fandom.com/wiki/Belsmuth_II)
**Galaxy atlas:** system `Belsmuth II`, Outer Rim, grid O-6 — map position (4920.7, 5217.8, -95.1)

Belsmuth II was a planet in the Belsmuth system of the Outer Rim. It had an Imperial technical university which warlord Zsinj converted into a pilot training academy. To confuse Zsinj as to the location of Han Solo's task force, Rogue Squadron and Nova Squadron assaulted the academy.
