# Aargonar

**Continuity:** Canon  
**Source:** [Aargonar](https://starwars.fandom.com/wiki/Aargonar)
**Galaxy atlas:** system `Aargonar`, Mid Rim, grid Q-7 — map position (8605.3, 3766.0, 53.8)

Aargonar was a planet located in the galaxy. During the Clone Wars, the husband of Confederacy of Independent Systems Senator Mina Bonteri went there to set up a base for the Separatists, but was killed when Republic clone troopers attacked. The planet was also the homeworld of the human Imperial stormtrooper TK-14057.
