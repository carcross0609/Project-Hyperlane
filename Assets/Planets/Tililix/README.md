# Tililix

**Continuity:** Legends  
**Source:** [Tililix](https://starwars.fandom.com/wiki/Tililix)
**Galaxy atlas:** system `Tililix`, Unknown Regions — map position (-8960.4, 2476.0, -122.7)

Tililix was a planet in the Til system of the Unknown Regions which orbited the star Til. It was the Tarro homeworld before it was destroyed when Til went supernova.
