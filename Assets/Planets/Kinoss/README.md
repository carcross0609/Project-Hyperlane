# Kinoss

**Continuity:** Canon  
**Source:** [Kinoss](https://starwars.fandom.com/wiki/Kinoss)
**Galaxy atlas:** system `Kinoss`, Unknown Regions, grid E-8 — map position (-9762.2, 1836.5, 44.3)

Kinoss was a planet located in the Kinoss system of the Unknown Regions. It was situated within the borders of the Chiss Ascendancy. It was at this system where a Chiss warship, under the command of Mid Captain Irizi'ar'alani (Ziara), destroyed four Lioaoin corsairs, who had followed a Chiss freighter piloted by Pathfinder Qilori of Uandualon and Chiss Junior Commander Mitth'raw'nuru (Thrawn). This skirmish stared the Chiss Lioaoin pirate campaign.
