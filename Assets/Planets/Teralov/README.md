# Teralov

**Continuity:** Canon  
**Source:** [Teralov](https://starwars.fandom.com/wiki/Teralov)
**Galaxy atlas:** system `Teralov`, Other, grid O-8 — map position (5054.4, 2188.1, 34.9)

Teralov was a planet where the rebellion attempted to take supplies in 2 BBY. However en route, the rebel ships were attacked by Imperial forces led by Captain Vult Skerris, a brief battle occurred resulting in the destruction of all the rebel ships and failure to deliver the supplies.
