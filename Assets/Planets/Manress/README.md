# Manress

**Continuity:** Canon  
**Source:** [Manress](https://starwars.fandom.com/wiki/Manress)
**Galaxy atlas:** system `Manress`, Inner Rim, grid N-9 — map position (4376.1, 395.6, -147.8)

Manress was a planet located in the Manress system in the Inner Rim Territories. The world was home to the sentient Stokhli species as well as megafauna that were hunted using spray sticks.
