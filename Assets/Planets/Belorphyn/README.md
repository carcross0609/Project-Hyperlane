# Belorphyn

**Continuity:** Legends  
**Source:** [Belorphyn](https://starwars.fandom.com/wiki/Belorphyn)
**Galaxy atlas:** system `Belorphyn`, Outer Rim, grid M-19 — map position (2024.5, -14312.6, 195.0)

Belorphyn was the ninth planet in the Derilyn system. It was an inhospitable ice ball without moons with an oblong orbit (due to Serrata's influence). For a portion of its "year", it actually was closer to Deril than Serrata.
