# Vvaw

**Continuity:** Legends  
**Source:** [Vvaw/Legends](https://starwars.fandom.com/wiki/Vvaw/Legends)
**Galaxy atlas:** system `Vvaw`, Outer Rim, grid U-9 — map position (14251.8, 597.2, -132.0)

Vvaw was a planet located in the Vvaw system, a part of the Calaron sector in the Slice portion of the Outer Rim Territories. Jedi Master Jmmaar, a member of the Viraanntesse species that originated in the Expansion Region's Viraanntesse system, hailed from Vvaw.
