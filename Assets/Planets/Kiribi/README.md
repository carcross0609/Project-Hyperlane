# Kiribi

**Continuity:** Legends  
**Source:** [Kiribi](https://starwars.fandom.com/wiki/Kiribi)
**Galaxy atlas:** system `Kiribi`, Colonies, grid L-9 — map position (1495.0, 1489.4, 89.3)

Kiribi was a planet located in the Colonies. Its galactic coordinates were 099, 099, 011. Although it was located 5000 light-years away from Coruscant, because Kiribi's coordinates were positive and began with zero, it was part of the Imperial Center Oversector during the Imperial Period.
