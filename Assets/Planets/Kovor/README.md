# Kovor

**Continuity:** Legends  
**Source:** [Kovor](https://starwars.fandom.com/wiki/Kovor)

Kovor was a planet where a battle occurred during the Galactic War between the reconstituted Sith Empire and Galactic Republic, which the latter won thanks to the intervention of the Coruscant Aegis squadron.
