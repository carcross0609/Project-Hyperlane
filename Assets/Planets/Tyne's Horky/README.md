# Tyne's Horky

**Continuity:** Legends  
**Source:** [Tyne's Horky](https://starwars.fandom.com/wiki/Tyne%27s_Horky)
**Galaxy atlas:** system `Tyne's Horky`, Mid Rim, grid Q-11 — map position (8714.7, -1772.4, 63.1)

Tyne's Horky was an ore-rich mining world in the Teraab sector. Its streets were full of mining and service droids, used to mine Keschel and Nergon-14.
