# Amethia Prime

**Continuity:** Canon  
**Source:** [Amethia Prime](https://starwars.fandom.com/wiki/Amethia_Prime)
**Galaxy atlas:** system `Amethia Prime`, Inner Rim — map position (-1690.5, 2714.4, -65.3)

Amethia Prime was a planet located in the galaxy's Inner Rim. It had at least one large ocean which was spotted with volcanoes. During the Age of the Empire, crime lord Big String based his operations on an island fortress there.
