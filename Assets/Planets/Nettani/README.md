# Nettani

**Continuity:** Legends  
**Source:** [Nettani](https://starwars.fandom.com/wiki/Nettani)

Nettani was the fifth planet orbiting the star Rek in the Guter Wade system. Located in the Trilon sector of the Outer Rim, its primary terrain was composed of toxic swamps.
