# Jike

**Continuity:** Legends  
**Source:** [Jike](https://starwars.fandom.com/wiki/Jike)

Jike was a hot rock planet with no moons that occupied the closest orbital position to the star Asar. It was located within the Ilum system, a part of the 7G sector that was situated within the galaxy's Unknown Regions.
