# Ookbat

**Continuity:** Legends  
**Source:** [Ookbat/Legends](https://starwars.fandom.com/wiki/Ookbat/Legends)

Ookbat was the site of a botched mission by bounty hunters Tinian I'att and Chenlambec the Wookiee. A warren-like network of dank caves existed under the planet's surface.
