# Weitun

**Continuity:** Legends  
**Source:** [Weitun](https://starwars.fandom.com/wiki/Weitun)

Weitun was the second planet orbiting the star Sriluur in the Sriluur system. Located in the Tharin sector of the Outer Rim Territories, it was a searing rock.
