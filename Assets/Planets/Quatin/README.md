# Quatin

**Continuity:** Legends  
**Source:** [Quatin](https://starwars.fandom.com/wiki/Quatin)

Quatin was the fifth planet orbiting the star Bright Jewel in the Bright Jewel system. Located in the Bright Jewel sector of the Mid Rim, it was a gas giant.
