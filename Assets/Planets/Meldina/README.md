# Meldina

**Continuity:** Legends  
**Source:** [Meldina](https://starwars.fandom.com/wiki/Meldina)

Meldina was a volcanic rock planet with no moons that occupied the second closest orbital position to the star Abo. It was located within the Lehon system, a part of the Unknown Regions' area known as the Tempered Wastes.
