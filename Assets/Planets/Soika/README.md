# Soika

**Continuity:** Canon  
**Source:** [Soika](https://starwars.fandom.com/wiki/Soika)

Soika was a terrestrial planet which was the homeworld of the Soikan species. It was located in the Soika system in the Inner Rim Territories, in grid square M-8 of the Standard Galactic Grid. By the High Republic Era, Soika had been ravaged by the Soikan conflict, a war between several factions of Soikans.
