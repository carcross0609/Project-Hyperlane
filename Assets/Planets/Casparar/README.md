# Casparar

**Continuity:** Legends  
**Source:** [Casparar](https://starwars.fandom.com/wiki/Casparar)

Casparar was the second planet orbiting the star Stisste in the Saleucami system. Located in the Suolriep sector of the Outer Rim Territories, it was an aquatic world.
