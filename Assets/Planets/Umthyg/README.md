# Umthyg

**Continuity:** Legends  
**Source:** [Umthyg](https://starwars.fandom.com/wiki/Umthyg)
**Galaxy atlas:** system `Umthyg`, Mid Rim, grid K-18 — map position (-21.3, -12208.9, 79.8)

Umthyg was a lackluster industrial world located in the Umthyg system of the Juvex sector, a part of the Senex-Juvex region in the Western Reaches portion of the Mid Rim. A hyperlane known as the Agarix Trade Route linked it to the Dramassia system as well as the Dasoor system of the Agarix sector, while another hyperspace route connected it to the Farstone system. Umthyg was under the control of the aristocratic Ancient Houses of the Senex-Juvex.
