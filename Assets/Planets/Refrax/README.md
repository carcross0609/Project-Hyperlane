# Refrax

**Continuity:** Legends  
**Source:** [Refrax](https://starwars.fandom.com/wiki/Refrax)

Refrax was a planet in the Mortex sector of the Outer Rim Territories. The planet contained an Imperial-controlled spaceport that served as a stop-over point for ships traveling through Mortex sector during the Galactic Civil War.
