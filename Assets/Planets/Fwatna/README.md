# Fwatna

**Continuity:** Legends  
**Source:** [Fwatna](https://starwars.fandom.com/wiki/Fwatna)
**Galaxy atlas:** system `Fwatna`, Outer Rim, grid K-20 — map position (-413.0, -15772.7, -106.4)

Fwatna was a planet in the Subterrel sector near the site where Lando Calrissian found the abandoned freighter Spicy Lady. The ship belonged to his smuggling associate Jarril. This also led to the discovery of Dolph.
