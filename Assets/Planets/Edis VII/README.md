# Edis VII

**Continuity:** Canon  
**Source:** [Edis VII](https://starwars.fandom.com/wiki/Edis_VII)

Edis VII was a frontier planet with similar characteristics to Vandor that was located in the Edis system in the Farana region of Wild Space. The world was exploited by corporate interests to considerable profit.
