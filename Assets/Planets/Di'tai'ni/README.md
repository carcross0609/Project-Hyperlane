# Di'tai'ni

**Continuity:** Legends  
**Source:** [Di'tai'ni](https://starwars.fandom.com/wiki/Di%27tai%27ni)
**Galaxy atlas:** system `Di'tai'ni`, Mid Rim — map position (8125.9, 3478.9, -66.5)

Di'tai'ni was the home of the Tai'ni, as well as many non-Tai'ni resident workers. It was two systems away from the Both system.

It was aligned with the New Republic and maintained a starfighter base for it.
