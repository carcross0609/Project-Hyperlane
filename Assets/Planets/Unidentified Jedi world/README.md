# Unidentified Jedi world

**Continuity:** Legends  
**Source:** [Unidentified Jedi world](https://starwars.fandom.com/wiki/Unidentified_Jedi_world)

A forgotten Jedi world was a planet that was claimed to exist in the Unknown Regions of the galaxy. Jedi Master Gnost-Dural suggested this planet as a possible destination for the evacuation during the Invasion of Ossus in 3628 BBY.

## Planetary data

- **Name:** Unidentified Jedi world
- **Region:** Unknown Regions
- **Affiliation:** Jedi Order
