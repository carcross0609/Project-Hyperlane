# Galtor VI

**Continuity:** Unknown  
**Source:** [Galtor VI](https://starwars.fandom.com/wiki/Galtor_VI)

Galtor VI was a planet mined by the Galactic Empire. Some time during the Galactic Civil War, a prisoner managed to escape from the mines and joined a Rebel outpost in the Silenia system. The mines sometimes produced Socalium crystals.

## Planetary data

- **Name:** Galtor VI
- **Affiliation:** Galactic Empire
