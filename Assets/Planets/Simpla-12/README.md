# Simpla-12

**Continuity:** Legends  
**Source:** [Simpla-12](https://starwars.fandom.com/wiki/Simpla-12)
**Galaxy atlas:** system `Simpla-12`, Outer Rim, grid P-5 — map position (6028.3, 6487.5, -437.2)

Simpla-12 was a neglected, underdeveloped planet, strip-mined and criminal-infested. Jenna Zan Arbor had a lab on the planet surface, and performed her twisted experiments on unfortunate Jedi there. The thieves Cholly, Weez, and Tup lived there, as well as the bounty hunter Ona Nobis.
