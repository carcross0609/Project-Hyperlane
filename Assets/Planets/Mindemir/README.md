# Mindemir

**Continuity:** Legends  
**Source:** [Mindemir](https://starwars.fandom.com/wiki/Mindemir)

Mindemir was the primary planet of the Mindemir system. Jenna Zan Arbor wanted to use the planet's water supplies in her experiments, but was blocked from doing so by the Galactic Senate.
