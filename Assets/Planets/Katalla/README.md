# Katalla

**Continuity:** Legends  
**Source:** [Katalla](https://starwars.fandom.com/wiki/Katalla)

Katalla was a planet in the Kastolar sector of the Mid Rim. It was a casino world considered to be a respite from conflict. During the Clone Wars, the Besadii clan had a money funneling scheme with the Separatists. The clan used the Katalla casino to generate funds for the Separatists. The plot was discovered by the Jedi Order.
