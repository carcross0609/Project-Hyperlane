# Alzar

**Continuity:** Legends  
**Source:** [Alzar](https://starwars.fandom.com/wiki/Alzar)
**Galaxy atlas:** system `Alzar`, Outer Rim, grid R-6 — map position (9942.5, 5775.0, 115.2)

Alzar was a planet located in the Thanium sector of the Outer Rim Territories. The Alzarian homeworld, the world was devastated during the Stenax Massacres of 4 ABY.
