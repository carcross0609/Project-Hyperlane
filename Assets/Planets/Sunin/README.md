# Sunin

**Continuity:** Legends  
**Source:** [Sunin](https://starwars.fandom.com/wiki/Sunin)

Sunin was a world located in the Tharin sector of the Outer Rim Territories. Many gunrunners of the Sendavé Shared Interest Collective were from Elkkasinn and Sunin.
