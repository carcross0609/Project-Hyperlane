# Intran

**Continuity:** Legends  
**Source:** [Intran](https://starwars.fandom.com/wiki/Intran)
**Galaxy atlas:** system `Intran`, Expansion Region, grid O-14 — map position (4793.7, -6748.2, 169.4)

Intran was an uninhabited planet in the Intran system of the Brak sector. An Alliance to Restore the Republic military base was established on the planet shortly before the Battle of Yavin. The base housed a squadron of BTL Y-wing starfighters.
