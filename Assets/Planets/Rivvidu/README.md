# Rivvidu

**Continuity:** Legends  
**Source:** [Rivvidu](https://starwars.fandom.com/wiki/Rivvidu)
**Galaxy atlas:** system `Rivvidu`, Outer Rim, grid O-5 — map position (5656.2, 6503.8, -3.6)

On the planet of Rivvidu, Boba Fett once chased a female Iotran mark. After the capture, Fett acquired his Silver Speeder. Its Imperial governor employed a Kubaz spy.
