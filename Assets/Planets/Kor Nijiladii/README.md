# Kor Nijiladii; (The Bootana Hutta region, with Kor Nijiladii represented by the number 5)

**Continuity:** Legends  
**Source:** [Kor Nijiladii](https://starwars.fandom.com/wiki/Kor_Nijiladii)
**Galaxy atlas:** system `Kor Nijiladii`, Hutt Space, grid S-10 — map position (11329.0, -1110.5, -110.5)

Kor Nijiladii was a world located within the Kor Nijiladii system, a part of the Bootana Hutta region of Hutt Space, and was a part of the Slice section of the galaxy. It was connected by a hyperlane to the Kor Hestilic system.

Kor Nijiladii was the throneworld of the Nijiladii kajidic.
