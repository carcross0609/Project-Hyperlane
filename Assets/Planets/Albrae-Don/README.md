# Albrae-Don

**Continuity:** Canon  
**Source:** [Albrae-Don](https://starwars.fandom.com/wiki/Albrae-Don)
**Galaxy atlas:** system `Albrae-Don`, Colonies, grid L-13 — map position (172.1, -5928.9, 345.2)

Albrae-Don was a world in the Albrae-Don system in the Sern sector of the Colonies, in grid square L-13 of the Standard Galactic Grid. During the Imperial Era, Albrae-Don was a rebellious world along with other worlds in the Sern sector such as Ghorman.
