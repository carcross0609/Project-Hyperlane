# Lesu

**Continuity:** Legends  
**Source:** [Lesu](https://starwars.fandom.com/wiki/Lesu)
**Galaxy atlas:** system `Lesu`, Outer Rim — map position (4278.5, 7450.8, -205.6)

Lesu was a world located in the Lesu system, a part of the Outer Rim Territories' Dail sector. Around 10 ABY, it served as the homeworld of Malakin Enterprises, a criminal organization that constituted a part of the Tenloss Syndicate.
