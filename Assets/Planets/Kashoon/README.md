# Kashoon

**Continuity:** Legends  
**Source:** [Kashoon](https://starwars.fandom.com/wiki/Kashoon)
**Galaxy atlas:** system `Kashoon`, Outer Rim, grid S-5 — map position (11170.2, 6855.5, 295.0)

Kashoon was a planet that was conquered by the Galactic Empire, and later freed with the help of the Rebel Alliance. The Kashoonara were left to their own devices afterwards.
