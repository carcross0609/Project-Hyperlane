# Noonar

**Continuity:** Legends  
**Source:** [Noonar](https://starwars.fandom.com/wiki/Noonar)
**Galaxy atlas:** system `Noonar`, Outer Rim, grid M-6 — map position (1773.1, 5029.8, 22.0)

Noonar was a planet located in the Noonian system of the Outer Rim Territories. During the Cold War between the Galactic Republic and the Sith Empire, Noonar was host to the pacifist Noonar Confederacy, which controlled a key stretch of territory between the two galactic powers. During the Galactic Civil War, Noonar was run by Imperial governor Trophan Thanis.
