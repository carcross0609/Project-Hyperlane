# Suba

**Continuity:** Canon  
**Source:** [Suba](https://starwars.fandom.com/wiki/Suba)

Suba was a planet located in the Atravis sector within the Outer Rim Territories. The Dressellian smuggler Has Obitt found the Malicious Moondog, a cantina on Suba, no more nastier than the cantina on Rajtiri, the Wanton Wellspring.
