# Unidentified planet

**Continuity:** Legends  
**Source:** [Unidentified planet (Kolatill system)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Kolatill_system%29)

A planet was located in the Kolatill system of the Kathol sector in the Outer Rim Territories. In 8 ABY, a starship was attacked and left adrift near this planet. A starfighter patrol from the New Republic CR90 corvette FarStar—in-system responding to a distress call from the neighboring planet of Kolatill, which had been attacked by forces loyal to the Imperial warlord Moff Kentor Sarne—discovered the derelict, prompting the crew of the corvette to search the wreck for any survivors still alive in airtight sections.
