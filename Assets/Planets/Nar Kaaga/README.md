# Nar Kaaga

**Continuity:** Canon  
**Source:** [Nar Kaaga](https://starwars.fandom.com/wiki/Nar_Kaaga)
**Galaxy atlas:** system `Nar Kaaga`, Hutt Space, grid S-13 — map position (10567.6, -4965.6, -381.4)

Nar Kaaga was a planet located in the Hutt Space region of the galaxy. It was connected to fellow Hutt Space world Circumtore and the Bothan Space planet Bothawui by hyperspace routes. Nar Kaaga was located at galactic coordinates S-13.
