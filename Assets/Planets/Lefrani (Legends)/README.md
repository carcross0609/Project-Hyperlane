# Lefrani

**Continuity:** Legends  
**Source:** [Lefrani/Legends](https://starwars.fandom.com/wiki/Lefrani/Legends)
**Galaxy atlas:** system `Lefrani`, Outer Rim — map position (9507.3, -9885.7, 59.5)

Lefrani was a gas giant. It had a strong gravitational pull which prevented Mustafar from becoming a moon of Jestefad.

Lefrani eclipsed the star Priate at the precise moment that Darth Vader began assassinating the leaders of the CIS.
