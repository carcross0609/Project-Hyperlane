# Vulta

**Continuity:** Legends  
**Source:** [Vulta](https://starwars.fandom.com/wiki/Vulta)
**Galaxy atlas:** system `Vulta`, Mid Rim, grid N-7 — map position (3796.7, 3795.9, 180.3)

Vulta was a planet located within the Atreyis system of the Mid Rim. It was the homeworld of the Vultan species, as well as Greff-Timms Industrial and Oss Wilum.
