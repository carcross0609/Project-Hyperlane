# Ulabos

**Continuity:** Legends  
**Source:** [Ulabos](https://starwars.fandom.com/wiki/Ulabos)
**Galaxy atlas:** system `Ulabos`, Core Worlds, grid L-9 — map position (305.4, 381.4, -18.5)

Ulabos was a frozen, rocky planet in the Coruscant system. It was surrounded by immense rings of ice and rock, known as the Ulabos ice bands.
