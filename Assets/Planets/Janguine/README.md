# Janguine

**Continuity:** Legends  
**Source:** [Janguine](https://starwars.fandom.com/wiki/Janguine)
**Galaxy atlas:** system `Janguine`, Outer Rim — map position (-4644.9, -10780.3, -161.0)

Janguine was a jungle planet in the Outer Rim. Its natives spoke Janguine and were overrun by the Mooloolians around 275 BBY.
