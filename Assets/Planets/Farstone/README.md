# Farstone

**Continuity:** Legends  
**Source:** [Farstone](https://starwars.fandom.com/wiki/Farstone)
**Galaxy atlas:** system `Farstone`, Mid Rim, grid K-18 — map position (-13.9, -12240.6, -366.1)

Farstone was a world located in the Farstone system of the Juvex sector, a part of the Senex-Juvex region in the Western Reaches portion of the Mid Rim. A hyperlane connected Farstone to the Umthyg system.

Featuring soaring mountain ranges, Farstone was sparsely populated and was at one point a mining colony, but was eventually abandoned, although nominally remaining under the control of the aristocratic Ancient Houses of the Senex-Juvex. By 43 ABY, the world was mostly inhabited by fugitives, hermits, and sociopaths.
