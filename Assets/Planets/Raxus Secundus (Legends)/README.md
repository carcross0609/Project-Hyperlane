# Raxus Secundus

**Continuity:** Legends  
**Source:** [Raxus Secundus/Legends](https://starwars.fandom.com/wiki/Raxus_Secundus/Legends)
**Galaxy atlas:** system `Raxus Secundus`, Outer Rim, grid S-5 — map position (11574.8, 6633.9, 528.6)

Raxus Secundus, also known simply as Raxus, was at one point during the Clone Wars, the capital of the Confederacy of Independent Systems. It was a temperate world with grassy hills and many trees.
