# Hyomare

**Continuity:** Legends  
**Source:** [Hyomare](https://starwars.fandom.com/wiki/Hyomare)

Hyomare was the seventh planet of the Bestine system located in the Inner Rim Territories. Hyomare was one of the three gas giants in the star system and had ten moons.
