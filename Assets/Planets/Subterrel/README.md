# Subterrel

**Continuity:** Canon  
**Source:** [Subterrel](https://starwars.fandom.com/wiki/Subterrel)
**Galaxy atlas:** system `Subterrel`, Outer Rim, grid L-20 — map position (198.0, -16421.6, 462.3)

Subterrel was a planet located in the Subterrel system in the Subterrel sector of the Outer Rim Territories. At some point before the Clone Wars, Dexter Jettster spent time prospecting on Subterrel. There was an imperial campaign on Subterrel, which was used as an exemplar for high enemy casualties.
