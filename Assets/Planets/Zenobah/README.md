# Zenobah

**Continuity:** Legends  
**Source:** [Zenobah](https://starwars.fandom.com/wiki/Zenobah)
**Galaxy atlas:** system `Zenobah`, Mid Rim, grid M-10 — map position (2308.4, -208.2, 18.5)

Zenobah was the second planet in the Demophon system. It had a hot climate and was covered in plains. It had two moons, and was destroyed when its sun went supernova.
