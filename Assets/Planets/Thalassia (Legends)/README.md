# Thalassia

**Continuity:** Legends  
**Source:** [Thalassia/Legends](https://starwars.fandom.com/wiki/Thalassia/Legends)
**Galaxy atlas:** system `Thalassia`, Outer Rim, grid P-4 — map position (6582.8, 8031.2, 432.8)

Thalassia was a planet located within the Thalassian system of the Outer Rim Territories. It was one of the slavery capitals of the outer rim and the location of the Thalassian slavers' base of operations and the home planet of the Thalassians.
