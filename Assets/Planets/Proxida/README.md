# Proxida

**Continuity:** Legends  
**Source:** [Proxida](https://starwars.fandom.com/wiki/Proxida)

Proxida was the second planet orbiting the star Julevia in the Julevian system. Located in the Dalonbian sector of the Outer Rim Territories, it was a volcanic rock.
