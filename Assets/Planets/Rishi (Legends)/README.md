# Rishi

**Continuity:** Legends  
**Source:** [Rishi/Legends](https://starwars.fandom.com/wiki/Rishi/Legends)
**Galaxy atlas:** system `Rishi`, Outer Rim, grid S-15 — map position (10765.6, -7811.3, -324.4)

Rishi was a tropical planet in the Rishi system which was located in the Outer Rim Territories. The planet was the homeworld of the avian Rishii.
