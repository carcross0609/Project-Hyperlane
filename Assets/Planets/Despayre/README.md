# Despayre

**Continuity:** Legends  
**Source:** [Despayre](https://starwars.fandom.com/wiki/Despayre)
**Galaxy atlas:** system `Despayre`, Outer Rim — map position (9606.3, -9843.3, 28.3)

Despayre, originally known as Horuz, was a planet in the Horuz system in the Outer Rim Territories, that served as a massive penal and slave world for the Galactic Empire and as a location where the first Death Star was constructed and completed, after being relocated many times to avoid Alliance to Restore the Republic.
