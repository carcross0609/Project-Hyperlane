# Paqualis III

**Continuity:** Legends  
**Source:** [Paqualis III/Legends](https://starwars.fandom.com/wiki/Paqualis_III/Legends)
**Galaxy atlas:** system `Paqualis III`, Inner Rim, grid L-8 — map position (1440.5, 2487.0, 2.0)

Paqualis III, also known as Paqualis, was an urbanized planet in the Paqualis system of the Inner Rim. It was the homeworld of Corvastan Benelex of House Benelex. It was the headquarters of the Benelex Bounty Hunters Guild.
