# Allanteen VI

**Continuity:** Legends  
**Source:** [Allanteen VI/Legends](https://starwars.fandom.com/wiki/Allanteen_VI/Legends)
**Galaxy atlas:** system `Allanteen VI`, Expansion Region, grid O-14 — map position (4786.7, -6141.0, -92.0)

Allanteen VI, or Allanteen Six, also referred to simply as Allanteen, was a planet in the Allanteen system in the Tynna sector of the Expansion Region. it was the site of the Allanteen Six shipyards.
