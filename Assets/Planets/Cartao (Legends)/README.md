# Cartao

**Continuity:** Legends  
**Source:** [Cartao/Legends](https://starwars.fandom.com/wiki/Cartao/Legends)
**Galaxy atlas:** system `Cartao`, Expansion Region, grid O-8 — map position (5653.6, 2117.9, 150.8)

Cartao was a planet in the Prackla sector. The siviviv vine was native to Cartao, and it was the homeworld of the Cranscoc.
