# Wxtm

**Continuity:** Legends  
**Source:** [Wxtm](https://starwars.fandom.com/wiki/Wxtm)
**Galaxy atlas:** system `Wxtm`, Outer Rim, grid R-17 — map position (9596.7, -11479.8, 0.6)

Wxtm was a planet located in the Wxtm system of the Outer Rim Territories. One of its native creatures was an avian called a ravenscreecher, which had six legs.
