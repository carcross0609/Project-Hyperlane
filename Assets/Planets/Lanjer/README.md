# Lanjer

**Continuity:** Canon  
**Source:** [Lanjer](https://starwars.fandom.com/wiki/Lanjer)

Lanjer was a tropical jungle planet located in the Lanjer system in the Rseik sector of the Outer Rim Territories. It was situated in grid square N-19 of the Standard Galactic Grid. During the Nihil conflict, Lourna Dee and a number of Jedi visited Lanjer in search of Muglan Tarantyne.
