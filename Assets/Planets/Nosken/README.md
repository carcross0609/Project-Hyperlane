# Nosken

**Continuity:** Legends  
**Source:** [Nosken](https://starwars.fandom.com/wiki/Nosken)
**Galaxy atlas:** system `Nosken`, Outer Rim — map position (-4684.0, -10600.2, -152.5)

Nosken was a gas giant planet. Several years before 400 BBY the TriGas Corporation attempted to set up a dirigible mining operation on this world, which ultimately failed.
