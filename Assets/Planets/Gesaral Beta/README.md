# Gesaral Beta

**Continuity:** Canon  
**Source:** [Gesaral Beta](https://starwars.fandom.com/wiki/Gesaral_Beta)

Gesaral Beta was a planet in the Gesaral Beta system in the Gordian Reach, a sector of the Outer Rim Territories in grid square P-6 of the Standard Galactic Grid. According to Leo Leonis, it had rain so dangerous that it was capable of killing a human.
