# Twing

**Continuity:** Legends  
**Source:** [Twing](https://starwars.fandom.com/wiki/Twing)

Twing was the seventh planet orbiting the star Prael in the Japrael system. Located in the Japrael sector of the Inner Rim, it was a gas giant.
