# Kalist VI

**Continuity:** Canon  
**Source:** [Kalist VI](https://starwars.fandom.com/wiki/Kalist_VI)
**Galaxy atlas:** system `Kalist VI`, Deep Core, grid K-12 — map position (-204.6, -3034.8, 134.1)

Kalist VI, also known simply as Kalist, was a barren rocky planet located in the Kalist system of the Deep Core. It was the homeworld of rebel pilot Dak Ralter, who joined Rogue Squadron of the Rebel Alliance. During the Imperial Era, Kalist VI housed a high-surveillance Galactic Empire penal colony.
