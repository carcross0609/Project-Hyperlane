# Kirtarkin

**Continuity:** Canon  
**Source:** [Kirtarkin](https://starwars.fandom.com/wiki/Kirtarkin)
**Galaxy atlas:** system `Kirtarkin`, Outer Rim, grid K-18 — map position (-1345.8, -12464.7, -121.7)

Kirtarkin was a planet located in the Kirtarkin system of the Anoat sector, in the galaxy's Outer Rim Territories. The Galactic Empire had several depots on Kirtarkin that contained large recycling centers, though they were too late to save the world's polluted environment.
