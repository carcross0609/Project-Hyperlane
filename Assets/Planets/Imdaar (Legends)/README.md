# Imdaar

**Continuity:** Legends  
**Source:** [Imdaar/Legends](https://starwars.fandom.com/wiki/Imdaar/Legends)
**Galaxy atlas:** system `Imdaar`, Outer Rim, grid J-6 — map position (-1986.9, 5394.7, 234.9)

Imdaar was a planet in the Dreighton Nebula with surface features reminiscent of Dagobah. It was the base of the TIE Phantom project, in which the production facility was located on Imdaar Alpha.
