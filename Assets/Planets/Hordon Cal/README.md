# Hordon Cal

**Continuity:** Legends  
**Source:** [Hordon Cal](https://starwars.fandom.com/wiki/Hordon_Cal)
**Galaxy atlas:** system `Hordon Cal`, Core Worlds — map position (-1006.9, -381.5, -57.9)

Hordon Cal was a hot ball of rock located in the Thanta Zilbra system of the Outer Rim Territories, orbited by a small moon. Both were destroyed during the Starbuster Plot by the Sacorrian Triad.
