# Sisk

**Continuity:** Legends  
**Source:** [Sisk/Legends](https://starwars.fandom.com/wiki/Sisk/Legends)
**Galaxy atlas:** system `Sisk`, Outer Rim, grid U-9 — map position (14075.8, 1110.8, 476.0)

Sisk was a planet that orbited a red dwarf star. It was the homeworld of the Sic-Six. It cooled when its star suffered partial atomic collapse.

While Sisk had considerable natural resources, the antisocial nature of the Sic-Six made it impossible to exploit the planetary resources in any organized way.
