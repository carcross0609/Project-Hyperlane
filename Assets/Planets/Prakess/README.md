# Prakess

**Continuity:** Legends  
**Source:** [Prakess](https://starwars.fandom.com/wiki/Prakess)
**Galaxy atlas:** system `Prakess`, Deep Core, grid K-10 — map position (-499.2, -1190.2, -87.7)

Prakess was a tiny terrestrial planet in the Prakith system, located in the Deep Core's Sector 5. It occupied the fifth orbital position around the star Prak and had two moons. Prakess featured a frozen environment and a rocky surface.
