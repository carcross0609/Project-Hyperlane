# Caranthanax B

**Continuity:** Canon  
**Source:** [Caranthanax B](https://starwars.fandom.com/wiki/Caranthanax_B)

Caranthanax B was a world in the Outer Rim. When the former handmaiden Sabé allied with the thief Warba Calip to locate Luke Skywalker—Jedi trainee and the son of Sith Lord Darth Vader—Calip sent Skywalker a datacard summoning him to the Southern Pole on Caranthanax B. Upon Skywalker's arrival, Sabé intended to test if he had a dark side.
