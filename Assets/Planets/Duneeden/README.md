# Duneeden

**Continuity:** Legends  
**Source:** [Duneeden](https://starwars.fandom.com/wiki/Duneeden)
**Galaxy atlas:** system `Duneeden`, Core Worlds — map position (900.4, 1124.0, 22.8)

Duneeden was a planet in the Core Worlds. Despite its proximity to Coruscant, few beings ever came to Duneeden. It was home to the Cascardi Mountains, which was the location of a few private retreats.
