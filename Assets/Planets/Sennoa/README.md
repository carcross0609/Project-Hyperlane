# Sennoa

**Continuity:** Legends  
**Source:** [Sennoa](https://starwars.fandom.com/wiki/Sennoa)

Sennoa was a planet in the galaxy. During the Cold War between the reconstituted Sith Empire and the Galactic Republic, the freelance assassin Tertra Essa was arrested by authorities on Sennoa.
