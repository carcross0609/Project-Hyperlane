# Nar Kaaga

**Continuity:** Legends  
**Source:** [Nar Kaaga/Legends](https://starwars.fandom.com/wiki/Nar_Kaaga/Legends)
**Galaxy atlas:** system `Nar Kaaga`, Hutt Space, grid S-13 — map position (10567.6, -4965.6, -381.4)

Nar Kaaga was a planet located in Hutt Space. It was a cold, swampy world that survived on trade. It was home to the H'uun and Shell Hutt clans.
