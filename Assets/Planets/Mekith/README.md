# Mekith

**Continuity:** Legends  
**Source:** [Mekith](https://starwars.fandom.com/wiki/Mekith)
**Galaxy atlas:** system `Mekith`, Deep Core — map position (-57.1, -1319.9, -69.9)

Mekith was a tiny terrestrial planet in the Prakith system, located in Sector 5 of the Deep Core. It occupied the second orbital position around the star Prak and had a moon. Mekith featured a rocky surface and a toxic environment.
