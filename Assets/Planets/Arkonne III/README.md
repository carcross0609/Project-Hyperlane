# Arkonne III

**Continuity:** Legends  
**Source:** [Arkonne III](https://starwars.fandom.com/wiki/Arkonne_III)
**Galaxy atlas:** system `Arkonne III`, Other, grid M-19 — map position (1728.7, -14447.8, 506.4)

Arkonne III was an Imperial planet in the Arkonne system inhabited by Humans such as business rivals Divina Quri Adner and Phean Tic'Karcta. Phean sabotaged Divina's vehicle, killing her. Wilek Nereus, Divina's beau, put an Imperial bounty on Phean, whom he personally killed.
