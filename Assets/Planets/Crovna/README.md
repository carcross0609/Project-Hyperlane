# Crovna

**Continuity:** Legends  
**Source:** [Crovna](https://starwars.fandom.com/wiki/Crovna)
**Galaxy atlas:** system `Crovna`, Mid Rim, grid L-17 — map position (712.3, -11971.7, 97.4)

Crovna was a planet in Senex sector that was home to the Peven Auction House; and Birtraub Brothers Storage and Reclamation Center, located near the main spaceport on the planet, which was a front for the Birtraub Brothers' criminal activities.
