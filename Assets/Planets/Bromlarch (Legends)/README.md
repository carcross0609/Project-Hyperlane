# Bromlarch

**Continuity:** Legends  
**Source:** [Bromlarch/Legends](https://starwars.fandom.com/wiki/Bromlarch/Legends)
**Galaxy atlas:** system `Bromlarch`, Mid Rim, grid O-16 — map position (5296.1, -9284.2, -129.1)

Bromlarch was a planet in the Mid Rim's Vish sector that was linked to a planetary aqueduct system prior to 20 BBY. Naboo Senator Padmé Amidala and Scipio Senator Rush Clovis jointly prepared a Galactic Senate hearing to rescue Bromlarch's system, which was effective in saving a population from drought and famine.
