# Parwa

**Continuity:** Canon  
**Source:** [Parwa](https://starwars.fandom.com/wiki/Parwa)
**Galaxy atlas:** system `Parwa`, Outer Rim, grid M-18 — map position (1775.1, -12230.4, 98.5)

Parwa was a planet which was the homeworld of the Parwan species. It had seasons which were several centuries long, and some Parwans hibernated along with the changing seasons even if they were not on Parwa. The Parwan bounty hunter Derrown was born on Parwa.
