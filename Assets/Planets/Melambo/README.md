# Melambo

**Continuity:** Legends  
**Source:** [Melambo](https://starwars.fandom.com/wiki/Melambo)

Melambo was the seventh planet orbiting the star Striar in the Malastare system. Located in the Dustig sector of the Mid Rim, it was a gas giant.
