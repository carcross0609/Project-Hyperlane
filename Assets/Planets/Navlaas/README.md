# Navlaas

**Continuity:** Canon  
**Source:** [Navlaas](https://starwars.fandom.com/wiki/Navlaas)
**Galaxy atlas:** system `Navlaas`, Inner Rim — map position (3747.0, 1645.6, -25.7)

Navlaas was a gas giant located in the Manaan system of the Inner Rim. It was orbited by eight moons, including the ice moon Laanen, as well as the Navlaas Triad of space stations. The Navlaas Triad mined and processed clouzon gas from Navlaas.
