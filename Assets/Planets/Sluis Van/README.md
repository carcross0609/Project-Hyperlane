# Sluis Van

**Continuity:** Canon  
**Source:** [Sluis Van](https://starwars.fandom.com/wiki/Sluis_Van)
**Galaxy atlas:** system `Sluis Van`, Outer Rim, grid M-19 — map position (2411.1, -13762.1, -3.7)

Sluis Van was an astronomical object in the southern region of the galaxy's Outer Rim Territories and Western Reaches, along the Rimma Trade Route, in square M-19 of the Standard Galactic Grid. It provided ships to Seswenna's Outland Regions Security Force prior to the Clone Wars.
