# Darepp

**Continuity:** Legends  
**Source:** [Darepp](https://starwars.fandom.com/wiki/Darepp)
**Galaxy atlas:** system `Darepp`, Colonies, grid M-13 — map position (2483.2, -5255.0, 212.8)

Darepp was a planet located in the Southern Core portion of the Colonies. It was located near the Foless Crossroads.

The Star Morning, a Koqus liner owned by the Fallanassi religious order, traveled to Darepp after leaving the planet Teyr. In the weeks that followed, the starliner stopped at the colony worlds 23 Mere, Yisgga, New Polokia, Fwiis and Babbadod, before returning to Motexx.
