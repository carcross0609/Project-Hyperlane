# Korseg IV

**Continuity:** Legends  
**Source:** [Korseg IV](https://starwars.fandom.com/wiki/Korseg_IV)
**Galaxy atlas:** system `Korseg IV`, Outer Rim — map position (-2173.8, 6218.5, -14.0)

Korseg IV was an Outer Rim Territories planet located in the Grohl sector. During the Galactic Civil War, the Rebel Alliance maintained a base there that was discovered and attacked by a ground force of the Galactic Empire. In the ensuing battle, the Alliance emerged victorious.
