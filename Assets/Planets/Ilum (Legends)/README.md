# Ilum

**Continuity:** Legends  
**Source:** [Ilum/Legends](https://starwars.fandom.com/wiki/Ilum/Legends)
**Galaxy atlas:** system `Ilum`, Unknown Regions, grid G-7 — map position (-6195.2, 3684.6, 207.4)

Ilum was an ice planet in the Unknown Regions, one of the main sources of the valuable crystals used in the construction of Jedi lightsabers. The caverns containing these Ilum crystals were long ago turned into a Jedi temple. Unlike the crystals of other planets, those of Ilum were limited to blue, green, and purple in color. The planet was over ninety percent-covered by ice.
