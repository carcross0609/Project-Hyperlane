# Ventrux

**Continuity:** Legends  
**Source:** [Ventrux](https://starwars.fandom.com/wiki/Ventrux)
**Galaxy atlas:** system `Ventrux`, Outer Rim, grid O-6 — map position (4992.9, 5543.7, 205.4)

Ventrux was a planet located within the Ventrux system within the Thesme sector of the Outer Rim Territories. It was the homeworld of Jenna Zan Arbor and original headquarters of Arbor Industries, although the laboratories were closed down when Jenna relocated to Simpla-12.
