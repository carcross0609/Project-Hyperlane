# Lianna

**Continuity:** Legends  
**Source:** [Lianna/Legends](https://starwars.fandom.com/wiki/Lianna/Legends)
**Galaxy atlas:** system `Lianna`, Outer Rim, grid S-6 — map position (10569.4, 5566.1, -302.6)

Lianna was the fourth planet of the Lianna system in the Allied Tion sector of the Outer Rim Territories. The ecumenopolis was the homeworld of House Santhe and the headquarters of Santhe/Sienar Technologies. Located on the junction of the Perlemian Trade Route, the Cadinth Run and the Shaltin Tunnels, Lianna was one of the busiest ports in the Tion Cluster.
