# Nordis Prime

**Continuity:** Canon  
**Source:** [Nordis Prime](https://starwars.fandom.com/wiki/Nordis_Prime)
**Galaxy atlas:** system `Nordis Prime`, Mid Rim — map position (-3124.0, 4758.3, -241.4)

Nordis Prime was a planet located in the galaxy's Mid Rim. It was on this world that security cameras picked up BeeLee Amdas's ID, leading to her death at the hands of Ryn Biggleston.
