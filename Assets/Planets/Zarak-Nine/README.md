# Zarak-Nine

**Continuity:** Legends  
**Source:** [Zarak-Nine](https://starwars.fandom.com/wiki/Zarak-Nine)

Zarak-Nine was a planet that originally had two continents, before a bomb designed by Kapp Zyman sunk into a fault line and detonated, causing an explosion that split off a new continent.
