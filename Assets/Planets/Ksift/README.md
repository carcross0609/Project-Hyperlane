# Ksift

**Continuity:** Unknown  
**Source:** [Ksift](https://starwars.fandom.com/wiki/Ksift)
**Galaxy atlas:** system `Ksift`, Outer Rim — map position (14188.7, 2156.2, 285.5)

Ksift was an Imperial rainforest world in the Outer Rim Territories. Its capital was Rakati. It was also the location of ATC-5/GS and a Rebel security outpost. Nik betrayed the local Rebels, but was brought to justice by Bret Hanson.
