# Routh

**Continuity:** Canon  
**Source:** [Routh](https://starwars.fandom.com/wiki/Routh)

Routh was a planet where the Achinios weed, a plant that was used to create a type of poison, could be found. The ambassador Slokin supposedly acquired a poison derived from the Achinios weed of Routh, which he used to kill his superior, Gorson.

## Planetary data

- **Name:** Routh
- **Region:** Outer Rim Territories
- **Sector:** Velcar sector
- **System:** Routh system
- **Coordinates:** J-5
- **Flora:** Achinios weed
