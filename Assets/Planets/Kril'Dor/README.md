# Kril'Dor

**Continuity:** Canon  
**Source:** [Kril'Dor](https://starwars.fandom.com/wiki/Kril%27Dor)
**Galaxy atlas:** system `Kril'Dor`, Mid Rim, grid I-7 — map position (-3592.9, 3757.4, 227.8)

Kril'Dor was a planet located in the Kril'Dor system in the Outer Jalor sector of the Mid Rim Territories that was a source of tibanna gas. Located close to the Uba system, Kril'Dor was positioned at the coordinates I-7 on the Standard Galactic Grid.

When investigating the theft of tibanna from the freighter Dromedar, Senior Lieutenant Thrawn of the Galactic Empire believed that the smuggler Nevil Cygni would have taken the stolen tibanna to Kril'Dor if he intended to sell it.
