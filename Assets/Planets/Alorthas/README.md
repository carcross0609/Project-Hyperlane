# Alorthas

**Continuity:** Legends  
**Source:** [Alorthas](https://starwars.fandom.com/wiki/Alorthas)
**Galaxy atlas:** system `Alorthas`, Outer Rim, grid M-19 — map position (2371.7, -13929.9, 77.6)

Alorthas was the second planet in the Derilyn system. It was a hot, rocky wasteland that was inundated with signs of technological activity around the time of the Galactic War.
