# Falleen

**Continuity:** Legends  
**Source:** [Falleen (planet)/Legends](https://starwars.fandom.com/wiki/Falleen_%28planet%29/Legends)
**Galaxy atlas:** system `Falleen`, Mid Rim, grid P-15 — map position (7153.7, -8316.5, 299.6)

Falleen was a planet in the Mid Rim region and home to the Falleen species. It had jungles, vast plains, and icy mountains.
