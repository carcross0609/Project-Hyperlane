# Sittana

**Continuity:** Legends  
**Source:** [Sittana](https://starwars.fandom.com/wiki/Sittana)

Sittana was a planet with rivers and falls of fire. Holographic information of Sittana was stored in the Anywhere Room at Hologram Fun World, so that visitors to the attraction could be virtually transported to the locale. Sittana marble was used as a building material.

- **Name:** Sittana
- **Region:** Core Worlds
