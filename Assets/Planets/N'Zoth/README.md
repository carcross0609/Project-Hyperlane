# N'Zoth

**Continuity:** Canon  
**Source:** [N'Zoth](https://starwars.fandom.com/wiki/N%27Zoth)
**Galaxy atlas:** system `N'Zoth`, Core Worlds, grid K-10 — map position (-1435.4, -866.5, 116.3)

N'Zoth was a planet located in the N'zoth system of the Koornacht Cluster in the galaxy's Core Worlds. On the periphery of the Deep Core, it was connected via hyperspace route to Jedha and Coruscant, and situated in square K-10 of the Standard Galactic Grid.
