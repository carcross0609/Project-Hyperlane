# Randa

**Continuity:** Legends  
**Source:** [Randa/Legends](https://starwars.fandom.com/wiki/Randa/Legends)
**Galaxy atlas:** system `Randa`, Outer Rim, grid T-10 — map position (12220.6, -224.1, 197.2)

Randa was a planet in the Outer Rim which hosted a small Rebel base during the Galactic Civil War. That led it to be targeted by Imperial Admiral Gaen Drommel, who decimated the Rebels on Randa during the war.
