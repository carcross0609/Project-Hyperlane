# Dontamo

**Continuity:** Legends  
**Source:** [Dontamo](https://starwars.fandom.com/wiki/Dontamo)

Dontamo was a planet in the Radiant One system, near Alba-16. It was a jungle world in 19 BBY and it was where Ferus Olin and Clive Flax were held in captivity at Dontamo Prison for crimes against the Galactic Empire. The prisoners were compelled to work in a factory building parts of the first Death Star.
