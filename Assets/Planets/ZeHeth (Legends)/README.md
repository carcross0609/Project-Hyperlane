# ZeHeth

**Continuity:** Legends  
**Source:** [ZeHeth/Legends](https://starwars.fandom.com/wiki/ZeHeth/Legends)
**Galaxy atlas:** system `ZeHeth`, Mid Rim, grid N-16 — map position (3184.5, -10022.4, -396.5)

ZeHeth was a Mid Rim planet that was home to the sentient ZeHethbra species. The natives of ZeHeth lived in urban areas as well as in dens amid the roots of the planet's large trees. ZeHeth was a part of the Galactic Republic during the Clone Wars and became a member of the Galactic Empire afterward.
