# Kalee

**Continuity:** Legends  
**Source:** [Kalee/Legends](https://starwars.fandom.com/wiki/Kalee/Legends)
**Galaxy atlas:** system `Kalee`, Wild Space, grid J-4 — map position (-2460.2, 8495.6, 115.4)

Kalee was a planet located in the star system of Wild Space that was the homeworld of the Kaleesh species, including General Grievous. It was located on the border of the Kadok Regions.
