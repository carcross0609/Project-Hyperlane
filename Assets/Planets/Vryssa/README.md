# Vryssa

**Continuity:** Legends  
**Source:** [Vryssa](https://starwars.fandom.com/wiki/Vryssa)
**Galaxy atlas:** system `Vryssa`, Outer Rim, grid K-19 — map position (-1117.7, -13703.5, -558.2)

Vryssa was a planet located within the Vryssa system of the Outer Rim Territories that hosted an Imperial garrison base. Buldobeasts were commonly found on this planet. At some point in 1 ABY, the entire garrison was wiped out by Boba Fett while pursuing the bounty on Rivo Xarran.
