# Noult

**Continuity:** Canon  
**Source:** [Noult](https://starwars.fandom.com/wiki/Noult)

Noult was a planet that played host to a slaughter during the Galactic Civil War. The planet was later found to have housed a secret Rebel base. The incident on Noult was later remarked by Ransolm Casterfo as an example of the Rebel Alliance's so-called terrorist tactics.
