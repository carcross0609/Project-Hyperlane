# Ningoth

**Continuity:** Canon  
**Source:** [Ningoth](https://starwars.fandom.com/wiki/Ningoth)

Ningoth was a water planet located in the Karthakk sector within the Outer Rim Territories. At some point, R0-GR was part of an event on Ningoth which he later recorded in his autobiography, From Trenches to Wrenches: The Roger Story.
