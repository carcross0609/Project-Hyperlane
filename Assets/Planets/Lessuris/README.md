# Lessuris

**Continuity:** Legends  
**Source:** [Lessuris](https://starwars.fandom.com/wiki/Lessuris)

Lessuris was a backwater planet located within the Lessuris system of the Outer Rim Territories. Luskin Exovar was born on Lessuris.
