# Tund

**Continuity:** Canon  
**Source:** [Tund](https://starwars.fandom.com/wiki/Tund)
**Galaxy atlas:** system `Tund`, Outer Rim, grid U-8 — map position (14333.2, 2181.7, 279.3)

Tund was a hidden planet located in the mysterious Tund system, within the Centrality sector of the galaxy's Outer Rim Territories, in grid square U-8 on the Standard Galactic Grid. It was the homeworld of the Toong species and became home to Ben Quadinaros, a Toong Podracer pilot that claimed to be from the Tund system.

The Sorcerers of Tund were a group of Force practitioners from Tund.
