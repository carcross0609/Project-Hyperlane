# Theron

**Continuity:** Canon  
**Source:** [Theron](https://starwars.fandom.com/wiki/Theron)
**Galaxy atlas:** system `Theron`, Other, grid S-4 — map position (11327.9, 7921.3, -23.6)

Theron was a planet in the Theron system in the Vilonis sector of the Mid Rim Territories, in grid square O-16 of the Standard Galactic Grid, whose surface featured famous spiral stone formations. It had a strong racing culture, including podracing and the Five Sabers tournament.
