# Auratera

**Continuity:** Canon  
**Source:** [Auratera](https://starwars.fandom.com/wiki/Auratera)

Auratera was a planet located in the Auratera system of the Vorzyd sector, a sector of the Outer Rim Territories, and was situated along the Salin Corridor hyperspace route. It contained a powerful vergence in the Force, centered at Acablas.
