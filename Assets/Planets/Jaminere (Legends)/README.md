# Jaminere

**Continuity:** Legends  
**Source:** [Jaminere/Legends](https://starwars.fandom.com/wiki/Jaminere/Legends)
**Galaxy atlas:** system `Jaminere`, Outer Rim, grid S-6 — map position (11458.0, 5583.5, 279.9)

Jaminere was a planet located in the Tion Cluster of the Outer Rim Territories, along the Cadinth Run. A powerful manufacturing world known for its efficiency, Jaminere was the capital of the Allied Tion sector.
