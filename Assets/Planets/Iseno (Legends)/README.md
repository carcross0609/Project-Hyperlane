# Iseno

**Continuity:** Legends  
**Source:** [Iseno/Legends](https://starwars.fandom.com/wiki/Iseno/Legends)
**Galaxy atlas:** system `Iseno`, Inner Rim, grid N-13 — map position (3304.8, -4615.2, -191.4)

Iseno was a planet in the Inner Rim, on the Corellian Run. Its people had a strong military tradition and maintained a large army mostly used for ornamental honor guard purposes.
