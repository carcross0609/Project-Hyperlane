# Chal Hudda

**Continuity:** Canon  
**Source:** [Chal Hudda](https://starwars.fandom.com/wiki/Chal_Hudda)
**Galaxy atlas:** system `Chal Hudda`, Outer Rim, grid P-17 — map position (6752.0, -11812.3, -366.2)

Chal Hudda was a marsh-covered planet of the Outer Rim Territories that had a soupy green atmosphere. Because its natural resources held use for almost no life-forms except the native Chalhuddans, that world was of interest to virtually no one else. In 3 BBY, Princess Leia Organa of Alderaan traveled to Chal Hudda on a mercy mission.
