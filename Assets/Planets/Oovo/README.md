# Oovo

**Continuity:** Legends  
**Source:** [Oovo](https://starwars.fandom.com/wiki/Oovo)
**Galaxy atlas:** system `Oovo`, Outer Rim, grid S-8 — map position (11645.0, 2625.0, -10.3)

Oovo was a gas giant located in the Oovo system of the Outer Rim's Tharin sector. It was orbited by an asteroid belt which contained the asteroid Oovo IV, which housed the maximum security prison named Desolation Alley.

Oovo's asteroid counterpart was decimated by the Yuuzhan Vong during the Yuuzhan Vong War.
