# Ebaq

**Continuity:** Legends  
**Source:** [Ebaq/Legends](https://starwars.fandom.com/wiki/Ebaq/Legends)
**Galaxy atlas:** system `Ebaq`, Deep Core, grid M-11 — map position (1592.1, -2148.4, 30.9)

Ebaq was a gas giant in the Treskov system and the fifth planet of that system, orbiting Treskov 115-W. The planet had eleven moons, including Ebaq 9.
