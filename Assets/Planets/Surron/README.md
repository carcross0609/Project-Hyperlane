# Surron

**Continuity:** Legends  
**Source:** [Surron](https://starwars.fandom.com/wiki/Surron)
**Galaxy atlas:** system `Surron`, Expansion Region, grid O-13 — map position (5385.4, -4944.7, -82.2)

Surron was a world located in the Surron sector of the Expansion Region. It was the homeworld of the Surronians, an insectoid species with a guild-based society. The Surronian were long-respected shipbuilders, renowned for their innovative starship designs. The Surron system hosted shipyards and Surron was the headquarters of the shipwright Surron StarTech.
