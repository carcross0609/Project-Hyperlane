# Nar Chunna; (The Bootana Hutta region, with Nar Chunna represented by the number 6)

**Continuity:** Legends  
**Source:** [Nar Chunna](https://starwars.fandom.com/wiki/Nar_Chunna)
**Galaxy atlas:** system `Nar Chunna`, Hutt Space, grid S-10 — map position (11228.2, -1446.2, 166.6)

Nar Chunna was a trade world located in the Nar Chunna system, a part of the Bootana Hutta area in the Hutt Space portion of the Slice. It was connected by a hyperlane to the Kor Hestilic and Kor Utoradii systems. It was rumored that large amounts of priceless artifacts could be obtained on Nar Chunna.
