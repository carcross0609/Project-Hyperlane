# Mastala

**Continuity:** Legends  
**Source:** [Mastala](https://starwars.fandom.com/wiki/Mastala)
**Galaxy atlas:** system `Mastala`, Mid Rim — map position (237.3, -12467.9, 258.8)

Mastala was the third planet in the Outer Rim Territories' Garnib system. It was frigid and rocky. The Alliance to Restore the Republic named a ship after it.
