# Pii IV

**Continuity:** Legends  
**Source:** [Pii IV](https://starwars.fandom.com/wiki/Pii_IV)

Pii IV, also named Pii 4 or Pii4, was a logging world located in the Pii system in the Arkanis sector of the galaxy. It was one of "Teeda's Eyes."
