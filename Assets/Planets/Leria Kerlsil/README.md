# Leria Kerlsil

**Continuity:** Legends  
**Source:** [Leria Kerlsil](https://starwars.fandom.com/wiki/Leria_Kerlsil)
**Galaxy atlas:** system `Leria Kerlsil`, Core Worlds, grid M-10 — map position (1879.7, -1247.0, 47.0)

Leria Kerlsil was a planet in the Core Worlds. It allowed Refugee Relief Movement settlement in 22 BBY, shortly before the Clone Wars, but only by wealthy single men. At the time of the New Republic, the planet had a population of 300,000. Leria Kerlsil was the only planet known to be home to Life-bearers, also known as life-witches.
