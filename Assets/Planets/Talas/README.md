# Talas

**Continuity:** Legends  
**Source:** [Talas](https://starwars.fandom.com/wiki/Talas)
**Galaxy atlas:** system `Talas`, Outer Rim, grid U-7 — map position (14601.6, 4206.8, 9.3)

Talas was a dry, rocky, volcanic Outer Rim world located in the Kamdon system in the Calamari sector. It was the headquarters of Tallet and Lekket.
