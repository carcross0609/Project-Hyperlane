# Selnesh

**Continuity:** Legends  
**Source:** [Selnesh/Legends](https://starwars.fandom.com/wiki/Selnesh/Legends)
**Galaxy atlas:** system `Selnesh`, Mid Rim, grid K-6 — map position (-329.9, 4707.5, 242.2)

Selnesh was a notorious Imperial prison planet orbiting a pale blue star in the Mid Rim. It was a barren, gray, rocky world devoid of vegetation or color. It had a single white, domed building, the Selnesh Imperial Detention Center from which the Rebel Alliance rescued Gebnerret Vibrion.
