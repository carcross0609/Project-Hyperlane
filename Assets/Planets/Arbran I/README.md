# Arbran I

**Continuity:** Legends  
**Source:** [Arbran I](https://starwars.fandom.com/wiki/Arbran_I)

Arbran I was a rocky, moonless planet that orbited the star Arbran. It was the innermost planet in the Arbran system, which was located in the Bon'nyuw-Luq sector, a part of the Trailing Sectors portion of the Outer Rim Territories.
