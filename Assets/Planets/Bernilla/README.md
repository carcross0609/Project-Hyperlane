# Bernilla

**Continuity:** Canon  
**Source:** [Bernilla](https://starwars.fandom.com/wiki/Bernilla)

Bernilla was a planet located in the Bernilla system of the Inner Rim and the Interior regions, in grid square L-14 on the Standard Galactic Grid. It shared its name with Bernillan silk. In 34 ABY, Bernilla was depicted on a map included in the book Traveler's Guide to Batuu, written by historian and author Eloc Throno.
