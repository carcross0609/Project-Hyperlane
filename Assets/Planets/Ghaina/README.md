# Ghaina

**Continuity:** Legends  
**Source:** [Ghaina](https://starwars.fandom.com/wiki/Ghaina)

Ghaina, a Core World, was one of the earliest settled colony worlds in the Galactic Republic. Remotely situated, it was not considered important to galactic society and produced only one Jedi: Taria Damsin.
