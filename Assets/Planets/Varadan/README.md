# Varadan

**Continuity:** Legends  
**Source:** [Varadan](https://starwars.fandom.com/wiki/Varadan)
**Galaxy atlas:** system `Varadan`, Mid Rim, grid L-18 — map position (376.8, -12165.5, -327.7)

Varadan was a Mid Rim world of the Senex sector. It orbited two stars and was very hot. Controlled by the aristocratic Ancient Houses of the Senex-Juvex region, it served as a mining world and employed enslaved labor.
