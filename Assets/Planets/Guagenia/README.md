# Guagenia

**Continuity:** Canon  
**Source:** [Guagenia](https://starwars.fandom.com/wiki/Guagenia)
**Galaxy atlas:** system `Guagenia`, Inner Rim, grid J-14 — map position (-1657.1, -6446.5, -24.5)

Guagenia was a planet located in the Guagenia system, within the Guagenian sector of the Inner Rim and the Interior regions. It was situated in grid square J-14 of the Standard Galactic Grid. In 34 ABY, Guagenia was depicted on a galactic map included in the book Traveler's Guide to Batuu, which was written by historian Eloc Throno and detailed the Outer Rim planet Batuu.
