# Bursant

**Continuity:** Canon  
**Source:** [Bursant](https://starwars.fandom.com/wiki/Bursant)

Bursant was a planet in the galaxy which was the homeworld of the Bursantian species. During the Clone Wars, a group of Jedi and senators, including Jedi Masters Yoda and Mace Windu, and Senator Yarua, visited an archaeological dig site on the planet.
