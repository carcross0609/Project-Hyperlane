# Ques

**Continuity:** Canon  
**Source:** [Ques](https://starwars.fandom.com/wiki/Ques)
**Galaxy atlas:** system `Ques`, Hutt Space, grid S-8 — map position (11637.0, 1545.9, 48.2)

Ques was a swampy planet in the Ques system near the inner border of Hutt Space, and its population primarily consisted of scavengers, such as Dec Hansen. The axton-tarsier, the ferin, the slime crab, and the Snarlap were creatures native to Ques. A school named teacher's cabin was located on Ques.
