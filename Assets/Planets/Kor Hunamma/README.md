# Kor Hunamma; (The Bootana Hutta region, with Kor Hunamma represented by the number 8)

**Continuity:** Legends  
**Source:** [Kor Hunamma](https://starwars.fandom.com/wiki/Kor_Hunamma)
**Galaxy atlas:** system `Kor Hunamma`, Hutt Space, grid S-11 — map position (11176.4, -1884.2, -405.9)

Kor Hunamma was a world located within the Kor Hunamma system, a part of the Bootana Hutta region of Hutt Space. It was part of the Slice section of the galaxy. It was connected by hyperlanes to the Kor Usilic and Kor Utoradii systems.

Kor Hunamma was the throneworld of the Hunamma kajidic.
