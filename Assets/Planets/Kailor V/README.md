# Kailor V

**Continuity:** Legends  
**Source:** [Kailor V](https://starwars.fandom.com/wiki/Kailor_V)
**Galaxy atlas:** system `Kailor V`, Core Worlds, grid L-10 — map position (1036.9, -301.0, 97.6)

Kailor V was a planet in the Kailor system of the Galactic Core. It was the location of the Imperial Zoological Gardens, the aquaria of which were maintained by the Sedrian Shahlik family. The Design Team Beta research facility of Hydrospeare Corporation was also on Kailor V.
