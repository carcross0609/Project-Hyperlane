# Sammun

**Continuity:** Canon  
**Source:** [Sammun](https://starwars.fandom.com/wiki/Sammun)
**Galaxy atlas:** system `Sammun`, Outer Rim, grid O-5 — map position (5562.3, 6811.5, 250.1)

Sammun was a planet in the Outer Rim's Batonn sector that was governed by Governor Estorn. During the reign of the Galactic Empire, Commander Karyn Faro was tasked with taking the Ninety-Sixth Task Force to Sammun and eliminating local insurgents.
