# Baradas II

**Continuity:** Legends  
**Source:** [Baradas II](https://starwars.fandom.com/wiki/Baradas_II)
**Galaxy atlas:** system `Baradas II`, Colonies, grid L-8 — map position (120.9, 1733.5, 13.7)

Baradas II was the second planet in the Baradas system. The planet was ruled by Baron Rovan Tresario who founded the Tresario Bounty Hunters Guild, an organization of bounty hunters whom hunted down pirates.
