# Deltooine

**Continuity:** Legends  
**Source:** [Deltooine](https://starwars.fandom.com/wiki/Deltooine)
**Galaxy atlas:** system `Deltooine`, Outer Rim, grid S-3 — map position (11293.9, 9031.7, -164.2)

Deltooine was a world in the Corporate Sector. It was home to a Corporate Sector Authority military base used to monitor Farana and Wild Space. It was part of the Tertiary Solenbaran hyperlane.
