# Kor Utoradii; (The Bootana Hutta region, with Kor Utoradii represented by the number 7)

**Continuity:** Legends  
**Source:** [Kor Utoradii](https://starwars.fandom.com/wiki/Kor_Utoradii)
**Galaxy atlas:** system `Kor Utoradii`, Hutt Space, grid S-11 — map position (11086.2, -1671.8, 161.3)

Kor Utoradii was a world located within the Kor Utoradii system, a part of the Bootana Hutta region of Hutt Space, and was part of the Slice section of the galaxy. It was connected by hyperlanes to the Kor Hunamma and Nar Chunna systems.

Kor Utoradii was the throneworld of the Utoradii kajidic.
