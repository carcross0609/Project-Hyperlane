# Azameen

**Continuity:** Legends  
**Source:** [Azameen](https://starwars.fandom.com/wiki/Azameen)
**Galaxy atlas:** system `Azameen`, Deep Core, grid N-17 — map position (4315.1, -11254.8, 52.9)

Azameen was the fourth planet from the star Zug in the Zug system. It was an arid terrestrial world that had two natural satellites and was the last planet before the asteroid belt of its star system.
