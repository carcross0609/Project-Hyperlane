# Hol Simo

**Continuity:** Legends  
**Source:** [Hol Simo](https://starwars.fandom.com/wiki/Hol_Simo)

Hol Simo was an extra-galactic gas giant orbiting the star Nagi Prime in the Nagi system, which was located in a dense star cluster. The planet was located in the satellite galaxy Companion Besh, which was officially classified by the Galactic Empire as part of the Unknown Regions. Hol Simo occupied the first orbital position in its star system and had two moons.
