# Eclipse

**Continuity:** Legends  
**Source:** [Eclipse (Deep Core)/Legends](https://starwars.fandom.com/wiki/Eclipse_%28Deep_Core%29/Legends)
**Galaxy atlas:** system `Eclipse`, Deep Core, grid L-11 — map position (1488.7, -2654.1, 42.9)

Eclipse was a planet in the Deep Core of the galaxy that was hidden in an asteroid field. It was discovered by Tionne and Kam Solusar when they were looking for a safeworld for the Jedi. It was where Luke Skywalker created Eclipse Station during the Yuuzhan Vong War.
