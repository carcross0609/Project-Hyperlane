# Damanos

**Continuity:** Canon  
**Source:** [Damanos](https://starwars.fandom.com/wiki/Damanos)

Damanos was an ash-gray planet within the Damanos system, a star system in the Belderone sector of the Outer Rim Territories that contained a Sith castle. The former Sith Lord Maul, now turned crime lord, visited the planet during the Imperial Era, he discovered the secrets inside its Sith castle.
