# Dentaal

**Continuity:** Legends  
**Source:** [Dentaal/Legends](https://starwars.fandom.com/wiki/Dentaal/Legends)
**Galaxy atlas:** system `Dentaal`, Core Worlds, grid K-13 — map position (-64.7, -4887.7, 117.7)

Dentaal was a planet in the Core Worlds. Its population was eradicated by an outbreak of the Candorian plague during the Galactic Civil War.
