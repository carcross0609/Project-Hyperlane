# Sakreen

**Continuity:** Canon  
**Source:** [Sakreen](https://starwars.fandom.com/wiki/Sakreen)

Sakreen was a rocky planet in the Sakreen system in the Ash Worlds of the Outer Rim Territories. It was the hiding place of the pirate Rane Mahal, whose starship had crashed on the planet.
