# New Cylimba

**Continuity:** Legends  
**Source:** [New Cylimba](https://starwars.fandom.com/wiki/New_Cylimba)
**Galaxy atlas:** system `New Cylimba`, Mid Rim, grid L-17 — map position (480.4, -11653.1, 430.5)

New Cylimba was a planet within a star system in the D'Aelgoth sector of the Mid Rim region of the galaxy. It was situated on the Veron Route, which connected it to Veron. It was an industrial world whose badlands were the location of an Alliance base during the Galactic Civil War. The base and its crew would likely have been crushed by Imperial forces, had Rivoche Tarkin not provided the necessary intelligence to avoid the attack.
