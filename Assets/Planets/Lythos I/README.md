# Lythos I

**Continuity:** Legends  
**Source:** [Lythos I](https://starwars.fandom.com/wiki/Lythos_I)

Lythos I was a mining planet located in the Corporate Sector of the Outer Rim Territories. The planet was tidally locked and extremely hot. A number of mining stations were built on the planet's night side.

## Planetary data

- **Name:** Lythos I
- **Region:** Outer Rim Territories; Corporate Sector
- **System:** Lythos system
- **Coordinates:** S-3
- **Climate:** Hot
