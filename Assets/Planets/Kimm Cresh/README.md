# Kimm Cresh

**Continuity:** Legends  
**Source:** [Kimm Cresh](https://starwars.fandom.com/wiki/Kimm_Cresh)
**Galaxy atlas:** system `Kimm Cresh`, Mid Rim, grid L-18 — map position (285.4, -12069.9, 253.9)

Kimm Cresh was a planet located in the Kimm Cresh system of the Juvex sector, in the Mid Rim of the galaxy. It was one of a trio of dingy industrial worlds belonging to House Sreethyn.
