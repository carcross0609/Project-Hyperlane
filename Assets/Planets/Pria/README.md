# Pria

**Continuity:** Canon  
**Source:** [Pria](https://starwars.fandom.com/wiki/Pria)
**Galaxy atlas:** system `Pria`, Core Worlds, grid M-10 — map position (2599.0, -1255.7, -52.8)

Pria was a waterworld in the Pria system of the Core Worlds. Orbited by a single moon, the planet experienced two tidal cycles each day, as well as tectonic activity, causing an ice age every 10,000 years.
