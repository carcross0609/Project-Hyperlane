# Z'fell

**Continuity:** Legends  
**Source:** [Z'fell](https://starwars.fandom.com/wiki/Z%27fell)
**Galaxy atlas:** system `Z'fell`, Deep Core, grid K-10 — map position (-1075.4, -867.3, -18.0)

Z'fell was a planet in the Z'fell system of the Koornacht Cluster. It was one of the original 13 planets of the Duskhan League. The planet was attacked by the New Republic during the Battle of N'zoth.
