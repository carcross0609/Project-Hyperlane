# Kamil

**Continuity:** Canon  
**Source:** [Kamil](https://starwars.fandom.com/wiki/Kamil)

Kamil was a planet located in the Wild Space region of the galaxy. The planet had a desert climate with a breathable atmosphere. Livestock dealing was a popular activity on Kamil with the four main dealers, selling runyips, nunas, moofs, and robas.
