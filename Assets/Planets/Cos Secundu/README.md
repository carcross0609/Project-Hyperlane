# Cos Secundu

**Continuity:** Canon  
**Source:** [Cos Secundu](https://starwars.fandom.com/wiki/Cos_Secundu)
**Galaxy atlas:** system `Cos Secundu`, Deep Core, grid N-5 — map position (3890.8, 6979.4, -61.3)

Cos Secundu was a planet located near Cosia, in the Deep Core region of the galaxy. Cosian bioengineers created an offshoot of their own species, the Nu-Cosians, to colonize that world.
