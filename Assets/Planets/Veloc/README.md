# Veloc

**Continuity:** Legends  
**Source:** [Veloc](https://starwars.fandom.com/wiki/Veloc)
**Galaxy atlas:** system `Veloc`, Mid Rim, grid P-7 — map position (6956.4, 3482.8, 208.2)

Veloc was a planet in the fourth orbit around the star Velm. The first of two gas giants in the Velm system, it was located in the Halori sector in the Trans-Hydian portion of the Mid Rim. Veloc was orbited by thirty-three moons, 281 asteroid moonlets, and a planetary ring.
