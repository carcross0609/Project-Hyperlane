# Rodia

**Continuity:** Legends  
**Source:** [Rodia/Legends](https://starwars.fandom.com/wiki/Rodia/Legends)
**Galaxy atlas:** system `Rodia`, Outer Rim, grid Q-16 — map position (8960.0, -9968.3, 146.9)

Rodia, a rainforested, industrial planet in the Tyrius system in the Outer Rim, was the homeworld of the Rodians.
