# Tarassi

**Continuity:** Legends  
**Source:** [Tarassi](https://starwars.fandom.com/wiki/Tarassi)

Tarassi was the second planet orbiting the binary stars Adega Prime and Adega Besh in the Adega system. Located in the Auril sector of the Outer Rim, it was a barren rock.
