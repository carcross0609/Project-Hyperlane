# Naalol

**Continuity:** Legends  
**Source:** [Naalol/Legends](https://starwars.fandom.com/wiki/Naalol/Legends)
**Galaxy atlas:** system `Naalol`, Mid Rim, grid L-17 — map position (309.8, -10615.6, 67.2)

Naalol was a sparsely-inhabited backwater planet, third in the Naalol system, with a small Imperial garrison. It was the Oquan headquarters. It had high peaks, winding ridges, with small towns in the mountains, and larger cities in the plains below.
