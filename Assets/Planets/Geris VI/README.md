# Geris VI

**Continuity:** Legends  
**Source:** [Geris VI](https://starwars.fandom.com/wiki/Geris_VI)
**Galaxy atlas:** system `Geris VI`, Mid Rim, grid O-7 — map position (4761.6, 3517.1, 139.0)

Geris VI was a planet that occupied the sixth orbital position in the Geris system, a part of the Trans-Vulta sector in the Trans-Hydian portion of the Mid Rim. At some point, it became one of the first worlds to ban mercenaries of the Mandalorian warrior culture—particularly those hired by the planetary government—from drinking in local tapcafs. The Mandalorian drinking song Naasad'guur mhi – Mhi n'ulu dated from that ban.
