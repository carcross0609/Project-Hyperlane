# Heterkus

**Continuity:** Legends  
**Source:** [Heterkus](https://starwars.fandom.com/wiki/Heterkus)

Heterkus was a planet in the Heterkus system, located in the Tharin sector of the Outer Rim Territories. Around 0 BBY, the Galactic Empire's Commander Westen of the Relentless clashed with Adar Tallon and the Rebel Alliance at Heterkus.
