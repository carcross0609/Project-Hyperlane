# Neelanon

**Continuity:** Canon  
**Source:** [Neelanon](https://starwars.fandom.com/wiki/Neelanon)
**Galaxy atlas:** system `Neelanon`, Mid Rim, grid L-17 — map position (670.6, -11946.9, 145.2)

Neelanon was a planet located in the Neelanon system in the Senex sector of the Mid Rim Territories, in grid square L-17 of the Standard Galactic Grid. It was the homeworld of the human senator Terr Taneel, who represented the Senex sector in the Galactic Senate of the Republic during the Clone Wars.
