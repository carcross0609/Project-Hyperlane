# Adarlon

**Continuity:** Legends  
**Source:** [Adarlon/Legends](https://starwars.fandom.com/wiki/Adarlon/Legends)
**Galaxy atlas:** system `Adarlon`, Outer Rim, grid M-20 — map position (2439.6, -15838.5, -234.8)

Adarlon was a planet in the Minos Cluster. Located on the Rimma Trade Route, it attracted many tourists, and was known for its music, schools, theme parks and holographic entertainment.
