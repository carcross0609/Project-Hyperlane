# Rustibar

**Continuity:** Legends  
**Source:** [Rustibar](https://starwars.fandom.com/wiki/Rustibar)
**Galaxy atlas:** system `Rustibar`, Mid Rim, grid J-7 — map position (-2747.1, 4326.8, -92.8)

Rustibar was a Mid Rim planet subjugated by the Galactic Empire.

After the Battle of Endor, Sulamar, a male technician in the Galactic Empire, claimed to be an Imperial General and to be responsible for the Imperial victory on Rustibar.
