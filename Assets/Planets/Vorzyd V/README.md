# Vorzyd V

**Continuity:** Canon  
**Source:** [Vorzyd V](https://starwars.fandom.com/wiki/Vorzyd_V)
**Galaxy atlas:** system `Vorzyd V`, Outer Rim, grid R-6 — map position (9225.6, 5161.0, 288.4)

Vorzyd V, nicknamed the Gambler's Paradise, was a terrestrial planet which contained the urban location Efavan. During the High Republic Era, an undercover agent of the Galactic Republic made contact with the wanted murderer Arathab Fal there during an investigation regarding the Nihil pirates.
