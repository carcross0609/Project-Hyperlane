# Targonn

**Continuity:** Legends  
**Source:** [Targonn/Legends](https://starwars.fandom.com/wiki/Targonn/Legends)
**Galaxy atlas:** system `Targonn`, Wild Space, grid U-7 — map position (14440.4, 3180.2, -680.8)

Targonn was a planet located in the Outer Rim Territories. This mountainous planet was the homeworld of the sentient Targonnian species. It was ruled by Dictator-Forever Craw until it was liberated by the Revoltists with the help of C-3PO and R2-D2.
