# Qasqi

**Continuity:** Legends  
**Source:** [Qasqi](https://starwars.fandom.com/wiki/Qasqi)
**Galaxy atlas:** system `Qasqi`, Mid Rim, grid R-7 — map position (9239.1, 4328.4, -160.6)

Qasqi was the fifth planet in the Centares system. Due to the fact that it was next to Centares, it absorbed most, if not all asteroids that strayed near Centares.
