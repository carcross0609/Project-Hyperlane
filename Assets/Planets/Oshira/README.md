# Oshira

**Continuity:** Canon  
**Source:** [Oshira](https://starwars.fandom.com/wiki/Oshira)

Oshira was a planet located in the Oshira system, within the Vilonis sector of the Mid Rim and the Trailing Sectors regions, in grid square O-16 on the Standard Galactic Grid. It shared its name with Oshiran sapphires, which originated from the same star system. In 34 ABY, historian and author Eloc Throno included a map depicting the location of Oshira in his book Traveler's Guide to Batuu, which detailed the planet Batuu.
