# Dractu

**Continuity:** Legends  
**Source:** [Dractu](https://starwars.fandom.com/wiki/Dractu)
**Galaxy atlas:** system `Dractu`, Mid Rim, grid Q-13 — map position (8838.1, -5085.9, -202.9)

Dractu was a peaceful, undeveloped planet in the Mid Rim, within the borders of Lannik Space, but far from any hyperlanes. It was the homeworld of the Dractuvian people. According to Jedi Knight Obi-Wan Kenobi, the planet had the worst food in the galaxy.
