# Kadavo

**Continuity:** Canon  
**Source:** [Kadavo](https://starwars.fandom.com/wiki/Kadavo)
**Galaxy atlas:** system `Kadavo`, Wild Space, grid S-4 — map position (11840.0, 8354.1, -494.1)

Kadavo was an ugly, barren planet located in the Kadavo system of Wild Space. During the Clone Wars, it was under the control of the Zygerrian Slave Empire, which used it to process slaves. Kadavo had multiple volcanoes, but for the most part, they were dormant. Nonetheless, the planet's atmosphere was affected and remained filled with smog. In 20 BBY, Plo Koon led an operation to free the captured Togruta slaves being held in the facility. The processing facility was completely destroyed, along with it's Keeper and garrison. The slaves were all liberated.
