# Galand

**Continuity:** Legends  
**Source:** [Galand](https://starwars.fandom.com/wiki/Galand)
**Galaxy atlas:** system `Galand`, Core Worlds, grid K-10 — map position (-803.4, -355.8, -74.1)

Galand was a Core world. It was homeworld of the near-Human Galandans, including the religious martyr H'kig. His teachings formed the basis of the H'kig philosophy. To escape persecution, the H'kig fled to distant Rishi.

Galand was girdled with endless equatorial roadways.
