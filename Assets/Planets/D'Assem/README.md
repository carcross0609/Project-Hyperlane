# D'Assem

**Continuity:** Canon  
**Source:** [D'Assem](https://starwars.fandom.com/wiki/D%27Assem)

D'Assem was a planet located in the galaxy. Between 3 ABY and 4 ABY, the bounty hunters T'onga and Khel Tanna met in the Bounty Hunters Guild Social Club within the planet's Black-Market District.
