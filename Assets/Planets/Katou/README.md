# Katou

**Continuity:** Canon  
**Source:** [Katou](https://starwars.fandom.com/wiki/Katou)

Katou was a jungle planet located in Wild Space in the galaxy that became embroiled in the Clone Wars when Count Dooku ordered General Grievous to conquer it. While the planet's population initially proved no threat, Jedi Knight Cardiff Baye arrived with a contingent of clone troopers, prompting Grievous to hunt them amidst the jungles.
