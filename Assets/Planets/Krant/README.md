# Krant

**Continuity:** Legends  
**Source:** [Krant](https://starwars.fandom.com/wiki/Krant)
**Galaxy atlas:** system `Krant`, Mid Rim, grid R-14 — map position (9545.7, -6703.6, 586.7)

Krant was a wilderness planet in the Bothan Space in the Mid Rim. It saw action from the Clone Wars and the Galactic Civil War, and the Jedi Master Echuu Shen-Jon hid on Krant during decades until Princess Leia Organa appeared on the planet, searching for the Bothan agent Utric Sandov.
