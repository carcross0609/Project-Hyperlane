# Algarra II

**Continuity:** Legends  
**Source:** [Algarra II](https://starwars.fandom.com/wiki/Algarra_II)

Algarra II was a planet in Algarra system the Outer Rim Territories on which Tord Gamb engaged in confidence schemes, contributing to a 25,000-credit bounty placed on him by the New Republic.
