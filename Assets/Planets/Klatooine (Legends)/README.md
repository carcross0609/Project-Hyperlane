# Klatooine

**Continuity:** Legends  
**Source:** [Klatooine/Legends](https://starwars.fandom.com/wiki/Klatooine/Legends)
**Galaxy atlas:** system `Klatooine`, Hutt Space, grid S-9 — map position (11616.0, 1443.8, 194.7)

Klatooine was the arid homeworld of the Klatooinian species. It was within the Si'Klaata Cluster, under Hutt control. It was covered with deserts and, to a lesser extent, savannas.
