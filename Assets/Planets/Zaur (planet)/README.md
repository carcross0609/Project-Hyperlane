# Zaur

**Continuity:** Legends  
**Source:** [Zaur (planet)](https://starwars.fandom.com/wiki/Zaur_%28planet%29)
**Galaxy atlas:** system `Zaur`, Core Worlds, grid L-10 — map position (358.5, -364.2, 46.5)

Zaur was the second planet in orbit around the star Zug in the Zug system, which was located in the Arrowhead region, where the Core Worlds intersected the Slice. The planet had no moons and was completely covered in a methane ocean.
