# Uba I

**Continuity:** Legends  
**Source:** [Uba I](https://starwars.fandom.com/wiki/Uba_I)

Uba I was a planet located within the Uba system of the Mid Rim. It was a home to an Ubese colony, which was destroyed by the Jedi in the bombardment of the Uba system during the New Sith Wars.
