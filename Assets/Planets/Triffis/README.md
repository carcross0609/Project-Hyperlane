# Triffis

**Continuity:** Canon  
**Source:** [Triffis](https://starwars.fandom.com/wiki/Triffis)
**Galaxy atlas:** system `Triffis`, Mid Rim, grid O-15 — map position (5752.8, -8352.2, -243.0)

Triffis was a planet that was the homeworld of the Triffian species, including the podracer Ebe E. Endocott. It was located in the Triffis system along a major hyperlane in the Hevvrol sector of the Mid Rim Territories, in grid square O-15 of the Standard Galactic Grid.
