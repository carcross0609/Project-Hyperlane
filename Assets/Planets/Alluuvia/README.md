# Alluuvia

**Continuity:** Legends  
**Source:** [Alluuvia](https://starwars.fandom.com/wiki/Alluuvia)
**Galaxy atlas:** system `Alluuvia`, Outer Rim, grid M-19 — map position (2272.0, -14405.9, -668.3)

Alluuvia was a planet that was located in the Elrood sector. The mining on the planet conducted by Radell Mining Corporation was overseen by an ecologically-mindful Ithorian.
