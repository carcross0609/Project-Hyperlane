# Agora

**Continuity:** Legends  
**Source:** [Agora](https://starwars.fandom.com/wiki/Agora)
**Galaxy atlas:** system `Agora`, Outer Rim, grid M-19 — map position (2266.4, -14126.3, -585.8)

Agora was a planet in the Agora system that was located within Sluis sector of the Outer Rim of the galaxy. Remaining loyal to the Republic for centuries, the Sluis sector quickly allied with the Confederacy of Independent Systems during the Clone Wars. Not wishing to lose the territory, the Freedom's Sons, led by Zozridor Slayke attempted to hold the planet, yet it fell to forces of the Separatists about the same time as the Battle of Cerea.
