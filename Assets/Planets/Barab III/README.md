# Barab III

**Continuity:** Legends  
**Source:** [Barab III](https://starwars.fandom.com/wiki/Barab_III)

Barab III was a planet in the Barab system. A gas giant composed of nitrogen, Barab III was the outermost planet in the system, which also contained the Barabel homeworld of Barab I. It was orbited by 34 moons.
