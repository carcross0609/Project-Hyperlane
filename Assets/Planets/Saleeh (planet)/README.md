# Saleeh

**Continuity:** Legends  
**Source:** [Saleeh (planet)](https://starwars.fandom.com/wiki/Saleeh_%28planet%29)

Saleeh was a gas giant planet in the Ruusan system. The seventh planet orbiting the star Hoth's Brand, it was named for Jedi Lord Saleeh who fought in the Ruusan campaign.
