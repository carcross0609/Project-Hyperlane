# Bory

**Continuity:** Legends  
**Source:** [Bory](https://starwars.fandom.com/wiki/Bory)

Bory was an airless rock planet with no moons that occupied the second closest orbital position to the star Asar. It was located within the Ilum system, a part of the Unknown Regions' 7G sector.
