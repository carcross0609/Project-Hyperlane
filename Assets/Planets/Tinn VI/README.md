# Tinn VI

**Continuity:** Legends  
**Source:** [Tinn VI](https://starwars.fandom.com/wiki/Tinn_VI)
**Galaxy atlas:** system `Tinn VI`, Mid Rim, grid L-17 — map position (934.5, -10789.5, -7.6)

Tinn VI was a gas giant in the Tinn system. It had six moons, including Tinn VI-B and the inhabited Echnos. Located at the limit of the Mid Rim, it was a common stopover point for spacers en route to the Outer Rim Territories.
