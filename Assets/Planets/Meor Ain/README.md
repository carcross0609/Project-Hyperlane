# Meor Ain

**Continuity:** Canon  
**Source:** [Meor Ain](https://starwars.fandom.com/wiki/Meor_Ain)

Meor Ain was a terrestrial planet in the Meor Ain system in the Jubilar sector of the Outer Rim Territories where Dex Acquisitions operated a depot. Tunga Arpagion was rescued from the depot by the Rebel Alliance.
