# Vulvarch

**Continuity:** Legends  
**Source:** [Vulvarch](https://starwars.fandom.com/wiki/Vulvarch)
**Galaxy atlas:** system `Vulvarch`, Colonies, grid L-13 — map position (897.1, -5571.7, -125.2)

Vulvarch was a planet located within the Vulvarch system of the Colonies, not far from Atzerri. Luke Skywalker discovered the Star Morning docked at Vulvarch while en route to retrieve the Fallanassi from Farlax sector.
