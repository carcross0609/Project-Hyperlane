# Philaxia

**Continuity:** Canon  
**Source:** [Philaxia](https://starwars.fandom.com/wiki/Philaxia)

Philaxia was a planet in the Philaxia system in the Har Worlds sector of the Expansion Region. It was discovered by the Galactic Republic. The phase-knife was invented there.

## Planetary data

- **Name:** Philaxia
- **Region:** Expansion Region
- **Sector:** Har Worlds sector
- **System:** Philaxia system
- **Coordinates:** J-16
- **Demonym:** Philaxian
