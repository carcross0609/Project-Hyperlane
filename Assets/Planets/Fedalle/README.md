# Fedalle

**Continuity:** Canon  
**Source:** [Fedalle](https://starwars.fandom.com/wiki/Fedalle)
**Galaxy atlas:** system `Fedalle`, Core Worlds, grid M-10 — map position (2097.2, -817.1, -103.5)

Fedalle was a terrestrial planet within the Fedalle system in the Core Worlds. It was situated along the Hydian Way hyperspace route between Skako and Bellassa, and sat at the head of a second hyperlane that linked it to Kuat.
