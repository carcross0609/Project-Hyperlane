# Pothor

**Continuity:** Canon  
**Source:** [Pothor](https://starwars.fandom.com/wiki/Pothor)
**Galaxy atlas:** system `Pothor`, Mid Rim, grid O-9 — map position (5153.4, 1002.3, -187.4)

Pothor was a planet in the Mid Rim Territories that the Rebel Alliance took over during its unsuccessful Mid Rim Offensive, later being set to evacuate when the Galactic Empire began pushing back in 2 ABY. By 4 ABY, the Imperial II-class Star Destroyer Overseer had won distinction at Pothor.
