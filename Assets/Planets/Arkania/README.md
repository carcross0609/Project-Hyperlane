# Arkania

**Continuity:** Canon  
**Source:** [Arkania](https://starwars.fandom.com/wiki/Arkania)
**Galaxy atlas:** system `Arkania`, Colonies, grid M-8 — map position (1644.5, 1519.0, 160.8)

Arkania was a cold planet located in the Arkania system of the galaxy's Colonies region, positioned at the coordinates M-8 on the Standard Galactic Grid. It was the homeworld of Arkanian species.
