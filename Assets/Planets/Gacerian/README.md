# Gacerian

**Continuity:** Legends  
**Source:** [Gacerian](https://starwars.fandom.com/wiki/Gacerian)
**Galaxy atlas:** system `Gacerian`, Expansion Region, grid N-15 — map position (3489.6, -7692.0, -123.1)

Gacerian was the fourth planet in the Gacerian system. It was home to many Gacerite mines and was the homeworld of the Gacerite species. During Imperial reign, the Imperial governor of the planet, Ulbrek Gostech, was compassionate and kind, allowing the general populace to run the planet. Thus, the Gacerites were happy to abide by Imperial values and obey the laws dictated to them through their governor.
