# Vertseth

**Continuity:** Canon  
**Source:** [Vertseth](https://starwars.fandom.com/wiki/Vertseth)
**Galaxy atlas:** system `Vertseth`, Colonies, grid N-10 — map position (3799.4, -302.6, 89.4)

Vertseth was a planet in the Vertseth system of the Colonies that was the homeworld of Vertseth Automata, a droid manufacturing company that produced techno-service droids. One such droid was named Todo 360 and operated under the bounty hunter Cad Bane during the Clone Wars.
