# Ison

**Continuity:** Canon  
**Source:** [Ison](https://starwars.fandom.com/wiki/Ison)
**Galaxy atlas:** system `Ison`, Outer Rim, grid K-18 — map position (-1367.3, -12918.6, -227.7)

Ison was a planet in the Ison system and found on the Ison Trade Corridor. Ison was near pirate-controlled territory, and at the time of the Iron Blockade, it hosted a debris field which inflicted critical damage to a passenger transport attempting to navigate it. The transport drifted into the pirate territory, so the ship's captain requested help from a young smuggler.
