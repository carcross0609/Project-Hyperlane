# Midani

**Continuity:** Legends  
**Source:** [Midani/Legends](https://starwars.fandom.com/wiki/Midani/Legends)
**Galaxy atlas:** system `Midani`, Outer Rim — map position (11418.1, 8534.6, 188.2)

Midani was an Outer Rim planet near Andasala. It was a favored destination of hunters.

Midani was a notable transshipment point in the spice trade.
