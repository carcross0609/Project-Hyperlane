# Pella

**Continuity:** Legends  
**Source:** [Pella](https://starwars.fandom.com/wiki/Pella)
**Galaxy atlas:** system `Pella`, Colonies, grid L-13 — map position (860.1, -4726.5, 78.9)

Pella was a planet in the Pella system in the Mecetti Province of the Tapani sector. It was probably named after the Pella Compact. The planet produced vast harvests of grain and vegetables each year and was an important agricultural producer of the sector.
