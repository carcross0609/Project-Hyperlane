# Uogo'cor

**Continuity:** Legends  
**Source:** [Uogo'cor/Legends](https://starwars.fandom.com/wiki/Uogo%27cor/Legends)
**Galaxy atlas:** system `Uogo'cor`, Mid Rim, grid Q-10 — map position (8048.7, -1355.1, 304.5)

Uogo'cor was a planet located within Trax sector, just off the Trax Tube. Its port often serviced the pirates that preyed on the Trax Tube. The name translated from the language of the native Uogo meant "home of the suffering ones".
