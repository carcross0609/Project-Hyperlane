# Corvis Minor III

**Continuity:** Legends  
**Source:** [Corvis Minor III](https://starwars.fandom.com/wiki/Corvis_Minor_III)

Corvis Minor III was a semi-arid world in the Corvis Minor system and the Ciutric Hegemony with temperate zones at its poles which produced exotic xenobiological products sold as luxury commodities.
