# Kaller

**Continuity:** Canon  
**Source:** [Kaller](https://starwars.fandom.com/wiki/Kaller)
**Galaxy atlas:** system `Kaller`, Outer Rim, grid S-4 — map position (11313.0, 7919.1, 662.0)

Kaller was a terrestrial planet with a complex climate located in the Kaller system of the galaxy's Outer Rim Territories. It was the homeworld of the Kallerans.
