# Gala

**Continuity:** Legends  
**Source:** [Gala](https://starwars.fandom.com/wiki/Gala)
**Galaxy atlas:** system `Gala`, Outer Rim, grid Q-7 — map position (8143.7, 4498.6, 482.2)

Gala was a beautiful and wealthy world at one point ruled by the Beju-Tallah dynasty. It was fairly close to Phindar.
