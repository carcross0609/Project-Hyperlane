# Daltarri

**Continuity:** Legends  
**Source:** [Daltarri](https://starwars.fandom.com/wiki/Daltarri)

The planet Daltarri was a terrestrial world located in the galaxy. It was covered in plant life which was the home of the plant-based Daltarri species.
