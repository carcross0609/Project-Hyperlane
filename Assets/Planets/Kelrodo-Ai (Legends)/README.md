# Kelrodo-Ai

**Continuity:** Legends  
**Source:** [Kelrodo-Ai/Legends](https://starwars.fandom.com/wiki/Kelrodo-Ai/Legends)
**Galaxy atlas:** system `Kelrodo-Ai`, Outer Rim, grid L-18 — map position (935.2, -13412.5, -380.7)

Kelrodo-Ai was a planet with famous gelatin mines and known for its water-sculptures. In 12 ABY, its Baron Administrator was Drom Guldi.
