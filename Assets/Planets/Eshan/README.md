# Eshan

**Continuity:** Canon  
**Source:** [Eshan](https://starwars.fandom.com/wiki/Eshan)
**Galaxy atlas:** system `Eshan`, Inner Rim, grid N-8 — map position (3565.0, 2637.8, 3.7)

Eshan was a planet in the Eshan system of the Inner Rim Territories where the infamous Droid Gotra caused a gang dispute, resulting in the loss of many innocents. Eshan was also the homeworld of Tayshin Maxa and Moda Maxa.
