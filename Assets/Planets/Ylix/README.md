# Ylix

**Continuity:** Legends  
**Source:** [Ylix](https://starwars.fandom.com/wiki/Ylix)
**Galaxy atlas:** system `Ylix`, Mid Rim, grid M-7 — map position (1529.2, 4022.8, -32.6)

Ylix was a backwater Mid Rim planet located in the Ylix system between Anobis and Ithor. It was a long-time rival of nearby Goelitz, which it finally defeated in battle. It was also the home of the mercenary Gallandro.
