# Rago

**Continuity:** Legends  
**Source:** [Rago/Legends](https://starwars.fandom.com/wiki/Rago/Legends)
**Galaxy atlas:** system `Rago`, Mid Rim, grid I-7 — map position (-3850.2, 3812.2, 4.9)

Rago was a planet located in Wild Space that anchored the Rago Run to the Unknown Regions. It was the closest Galactic Alliance planet to the Colony of the Killiks.
