# Galidraan IV

**Continuity:** Canon  
**Source:** [Galidraan IV](https://starwars.fandom.com/wiki/Galidraan_IV)

Galidraan IV was a planet in the Galidraan system within the galaxy's Outer Rim Territories. It was orbited by at least two moons.

- **Region:** Outer Rim Territories
