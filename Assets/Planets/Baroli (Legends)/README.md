# Baroli

**Continuity:** Legends  
**Source:** [Baroli/Legends](https://starwars.fandom.com/wiki/Baroli/Legends)
**Galaxy atlas:** system `Baroli`, Expansion Region, grid N-14 — map position (3501.5, -7179.8, 357.1)

Baroli was a planet inhabited by blue-haired Humans, and known for its many interesting moons.

The New Republic slicer Zakarisz Ghent hailed from Baroli, as did Jedi Padawan Ekria.
