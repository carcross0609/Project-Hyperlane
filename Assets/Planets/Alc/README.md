# Alc

**Continuity:** Legends  
**Source:** [Alc](https://starwars.fandom.com/wiki/Alc)
**Galaxy atlas:** system `Alc`, Expansion Region, grid N-15 — map position (3860.3, -7614.7, -326.6)

Alc was a jungle planet that was the third world in the Gacerian system. Alc possessed a breathable atmosphere suitable for colonization, but geological surveys reported that the cost of settling the planet would far outweigh any profit to be made from exploiting the planet's resources. It had a single moon.
