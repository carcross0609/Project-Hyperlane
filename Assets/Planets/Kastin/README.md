# Kastin

**Continuity:** Legends  
**Source:** [Kastin](https://starwars.fandom.com/wiki/Kastin)
**Galaxy atlas:** system `Kastin`, Colonies, grid J-9 — map position (-2247.3, 461.3, 26.7)

Kastin, also known as OM811, was a barren rock planet with no moons. It occupied the closest orbital position around the red giant star Thrantin Major in the Thrantin OM81-A system, a part of the Ollonir Boundaries in the Negs portion of the Colonies.
