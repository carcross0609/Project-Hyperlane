# Paucris Major

**Continuity:** Canon  
**Source:** [Paucris Major](https://starwars.fandom.com/wiki/Paucris_Major)
**Galaxy atlas:** system `Paucris Major`, Other, grid L-9 — map position (237.5, 1123.9, -63.1)

Paucris Major was a planet located in the Paucris system. In 3 BBY, Princess Leia Organa traveled to Paucris Major, discovering a fleet of battleships and transports being refurbished in the planet's orbit. Leia later returned to warn the rebel base there that they needed to evacuate because the Galactic Empire intended to "bring peace" to the planet.
