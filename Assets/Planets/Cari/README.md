# Cari

**Continuity:** Legends  
**Source:** [Cari](https://starwars.fandom.com/wiki/Cari)
**Galaxy atlas:** system `Cari`, Colonies, grid M-9 — map position (2401.8, 1243.5, 115.8)

Cari was a gas giant that was located within the Carida system in the Colonies region of the galaxy. Like all planets in the Carida system, it was destroyed by the renegade Jedi student Kyp Durron, who used a superweapon known as the Sun Crusher to cause its primary star to go Supernova.
