# Trauchta

**Continuity:** Legends  
**Source:** [Trauchta](https://starwars.fandom.com/wiki/Trauchta)

Trauchta was a gas giant in the fifth position of the Ansion system, which was located in the Mid Rim's Churnis sector. It had six moons.
