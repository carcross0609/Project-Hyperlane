# Enenpa

**Continuity:** Legends  
**Source:** [Enenpa](https://starwars.fandom.com/wiki/Enenpa)
**Galaxy atlas:** system `Enenpa`, Outer Rim — map position (6319.7, 9737.2, -10.2)

Enenpa was a gas giant located within the Thurra system, a part of the Esstran sector in the Trans-Hydian portion of the Outer Rim Territories. It was orbited by forty moons.
