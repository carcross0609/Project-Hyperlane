# Jandoon

**Continuity:** Legends  
**Source:** [Jandoon](https://starwars.fandom.com/wiki/Jandoon)
**Galaxy atlas:** system `Jandoon`, Outer Rim — map position (6073.2, 8963.5, -55.6)

Jandoon was a planet in the Outer Rim Territories, in the Corva sector. It eventually came to be known as a haunted world. It was home to the ancient ruins of a civilization that disappeared.
