# Sionia

**Continuity:** Legends  
**Source:** [Sionia](https://starwars.fandom.com/wiki/Sionia)
**Galaxy atlas:** system `Sionia`, Hutt Space, grid S-10 — map position (10974.2, -257.8, -54.9)

Sionia was the homeworld of the Skups, located within Hutt Space. Sionian Skups were a near-human species with a vast range of genetic characteristics. Rumor had it that the Skups were genetically altered by another species and sold to the Hutts ages ago.
