# Triffis

**Continuity:** Legends  
**Source:** [Triffis/Legends](https://starwars.fandom.com/wiki/Triffis/Legends)
**Galaxy atlas:** system `Triffis`, Mid Rim, grid O-15 — map position (5752.8, -8352.2, -243.0)

Triffis was a planet located within the Triffis system of the Mid Rim, along the Duros Space Run It was the homeworld of the Triffians, including Podracer pilot Ebe E. Endocott and Senator Eelen Li.
