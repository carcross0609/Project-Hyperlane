# Langsha-Raang

**Continuity:** Canon  
**Source:** [Langsha-Raang](https://starwars.fandom.com/wiki/Langsha-Raang)

Langsha-Raang was a green planet within the galaxy that was the homeworld of the Malangsha species. The planet also housed a greenhouse school.
