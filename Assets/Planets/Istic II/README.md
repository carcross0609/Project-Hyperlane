# Istic II

**Continuity:** Legends  
**Source:** [Istic II](https://starwars.fandom.com/wiki/Istic_II)
**Galaxy atlas:** system `Istic II`, Mid Rim, grid Q-11 — map position (8461.7, -2581.0, -459.9)

Istic II was the irradiated, ore-rich mining planet that was the second world in the Istic system, located within the Teraab sector. With the permission of the local Imperial governor, the native Isticians were hunted by Human settlers as though they were vermin.
