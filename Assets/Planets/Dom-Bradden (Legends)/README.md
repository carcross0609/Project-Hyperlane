# Dom-Bradden

**Continuity:** Legends  
**Source:** [Dom-Bradden/Legends](https://starwars.fandom.com/wiki/Dom-Bradden/Legends)
**Galaxy atlas:** system `Dom-Bradden`, Outer Rim — map position (5755.1, -12948.8, 95.8)

Dom-Bradden, also known as Bradden, was a planet in the Outer Rim. It was the home planet of the Affytechans, a race of sentient botanicals.
