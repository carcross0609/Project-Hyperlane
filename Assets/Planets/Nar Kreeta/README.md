# Nar Kreeta

**Continuity:** Legends  
**Source:** [Nar Kreeta](https://starwars.fandom.com/wiki/Nar_Kreeta)
**Galaxy atlas:** system `Nar Kreeta`, Hutt Space, grid S-10 — map position (10638.9, -533.4, -194.4)
