# Nubisa

**Continuity:** Legends  
**Source:** [Nubisa](https://starwars.fandom.com/wiki/Nubisa)

Nubisa was the second planet orbiting the binary stars Toydar and Little Toydar in the Toydaria system. Located in Hutt Space of the galaxy, it was a hothouse world.
