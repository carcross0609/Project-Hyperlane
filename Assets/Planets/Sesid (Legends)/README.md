# Sesid

**Continuity:** Legends  
**Source:** [Sesid/Legends](https://starwars.fandom.com/wiki/Sesid/Legends)
**Galaxy atlas:** system `Sesid`, Outer Rim, grid P-4 — map position (6479.0, 8350.0, 61.4)

Sesid was a planet in the Sesid system, and home to the Draedan. During the Galactic Civil War, it was run by Governor Arvel Trace.
