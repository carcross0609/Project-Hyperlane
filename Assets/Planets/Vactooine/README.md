# Vactooine

**Continuity:** Legends  
**Source:** [Vactooine](https://starwars.fandom.com/wiki/Vactooine)
**Galaxy atlas:** system `Vactooine`, Outer Rim, grid R-16 — map position (9994.0, -10477.5, 148.9)

Vactooine was a mining colony in the Arkanis sector of the Outer Rim Territories. Its dense jungles made it a suitable habitat for the Elix.
