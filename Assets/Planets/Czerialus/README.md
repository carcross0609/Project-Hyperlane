# Czerialus

**Continuity:** Canon  
**Source:** [Czerialus](https://starwars.fandom.com/wiki/Czerialus)
**Galaxy atlas:** system `Czerialus`, Other, grid O-12 — map position (5505.5, -3435.0, -16.8)

Czerialus was a planet in the Czerialus system in the Kailion sector of the Expansion Region that was the homeworld of the Czerialan species. During the Imperial Era, the planet was under Imperial control and the Xoczuko family sought to return after being disheartened on Corellia, unaware of the Empire's control on the planet.
