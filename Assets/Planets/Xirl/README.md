# Xirl

**Continuity:** Canon  
**Source:** [Xirl](https://starwars.fandom.com/wiki/Xirl)
**Galaxy atlas:** system `Xirl`, Wild Space, grid M-11 — map position (2268.9, -2380.9, -201.2)

Xirl was a jungle planet located in the Xirl system in Wild Space, near the Kalidorn system. The Stinker was a creature that was native to Xirl. The female human Gozetta built a hunting lodge on Xirl. The planet was a source of messages piggy-backing on official channels, calling on people to resist the Galactic Empire.
