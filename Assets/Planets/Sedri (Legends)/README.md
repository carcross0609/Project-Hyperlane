# Sedri

**Continuity:** Legends  
**Source:** [Sedri/Legends](https://starwars.fandom.com/wiki/Sedri/Legends)
**Galaxy atlas:** system `Sedri`, Outer Rim, grid S-8 — map position (11404.3, 2180.2, 343.5)

Sedri was a waterworld, the third planet in the Sedri system. It was the homeworld of the Sedrians and the Golden Sun, a living coral used as a power source.
