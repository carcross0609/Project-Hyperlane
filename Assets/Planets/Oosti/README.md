# Oosti

**Continuity:** Legends  
**Source:** [Oosti](https://starwars.fandom.com/wiki/Oosti)

Oosti was the sixth planet orbiting the star Shadda in the Shadda-Bi-Boran system. Located in the Toblain sector of the Outer Rim Territories, it was an ice world.
