# Kuk'tar

**Continuity:** Legends  
**Source:** [Kuk'tar](https://starwars.fandom.com/wiki/Kuk%27tar)
**Galaxy atlas:** system `Kuk'tar`, Mid Rim — map position (2708.8, -10185.6, 41.3)

Kuk'tar was the second planet in the Kothlis system. It was a chaotic inhospitable world. Kuk'tar was a tiny planetoid with irregular orbit that teared the planet's surface to shreds. The proximity of the planet to its sun caused seering temperatures.
