# Vandelhelm

**Continuity:** Legends  
**Source:** [Vandelhelm/Legends](https://starwars.fandom.com/wiki/Vandelhelm/Legends)
**Galaxy atlas:** system `Vandelhelm`, Expansion Region, grid M-15 — map position (1805.2, -8773.7, -179.7)

Vandelhelm was a planet located in the Vandelhelm system, inside of the Vandelhelm Cloud within the Expansion Region. It was known for its starshipwrights, and manufacturing capabilities.
