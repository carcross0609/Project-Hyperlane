# Majesticas

**Continuity:** Legends  
**Source:** [Majesticas](https://starwars.fandom.com/wiki/Majesticas)
**Galaxy atlas:** system `Majesticas`, Core Worlds — map position (358.1, -183.6, 25.3)

Majesticas was the third planet in the Metellos system, a star system in the Corusca sector of the Core Worlds. It was a toxic rock with no moons.
