# Barkhesh

**Continuity:** Canon  
**Source:** [Barkhesh](https://starwars.fandom.com/wiki/Barkhesh)
**Galaxy atlas:** system `Barkhesh`, Outer Rim, grid K-19 — map position (-818.0, -14616.5, 437.5)

Barkhesh was a planet located in the Barkhesh system of the Seitia sector within the Outer Rim Territories and Western Reaches. It was located in grid square K-19 of the Standard Galactic Grid. Barkhesh was the homeworld of the human Antidar Williams, a Galactic Republic Judicial who perished in the Naboo system in 32 BBY.
