# Inoli

**Continuity:** Unknown  
**Source:** [Inoli](https://starwars.fandom.com/wiki/Inoli)

Inoli was a terrestrial planet. It was the site of a carbonite mine. After earthquakes triggered a gas leak at the mine, a carbon freeze affected Inoli's population.
