# Kaikielius

**Continuity:** Canon  
**Source:** [Kaikielius](https://starwars.fandom.com/wiki/Kaikielius)
**Galaxy atlas:** system `Kaikielius`, Core Worlds, grid L-10 — map position (22.1, -150.3, 59.6)

Kaikielius was a planet in the Kaikielius system of the Core Worlds. Rin Praji, a noble of House Praji, owned an estate on Kaikielius. After winning a holocron that once belonged to Cin Drallig at an auction on Denon, Praji moved it to Kaikielius aboard a luxury yacht.
