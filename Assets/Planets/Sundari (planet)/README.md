# Sundari

**Continuity:** Legends  
**Source:** [Sundari (planet)](https://starwars.fandom.com/wiki/Sundari_%28planet%29)

Sundari was an arid mining world in the Mid Rim colonized around 4000 BBY. It was a longtime rival of Garos IV, although it depended on Garos IV for foodstuffs. It signed a peace treaty with Garos IV 118 BBY, but resumed war 87 BBY.
