# Asimuse

**Continuity:** Legends  
**Source:** [Asimuse](https://starwars.fandom.com/wiki/Asimuse)
**Galaxy atlas:** system `Asimuse`, Core Worlds, grid L-9 — map position (370.4, 1132.4, 35.3)

Asimuse was the fifth planet of the Chandrila system, which was located in the Bormea sector of the Ringali Shell in the Core Worlds. One of three gas giants in the system, the planet orbited the star Chandrila and was itself circled by nine moons. The entirety of the Chandrila system lay on the Perlemian Trade Route, which separated the Northern Dependencies from the Arrowhead portion of the Slice.
