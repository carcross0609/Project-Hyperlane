# Séléann

**Continuity:** Unknown  
**Source:** [Séléann](https://starwars.fandom.com/wiki/S%C3%A9l%C3%A9ann)

Séléann was a desert planet that was the homeworld to the predatory Tian-Ki. There, a farmer named Corran hunted the creatures with his blaster rifle.
