# Vellas Pavo

**Continuity:** Legends  
**Source:** [Vellas Pavo](https://starwars.fandom.com/wiki/Vellas_Pavo)

Vellas Pavo was a planet that was located in the Grumani sector, in the Outer Rim Territories. Before and during the Republic Dark Age the world was a known source of gadolinium.
