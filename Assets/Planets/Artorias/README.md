# Artorias

**Continuity:** Legends  
**Source:** [Artorias](https://starwars.fandom.com/wiki/Artorias)
**Galaxy atlas:** system `Artorias`, Outer Rim, grid K-3 — map position (-194.3, 9171.7, -302.2)

Artorias was a peace-loving Outer Rim planet with few defenses. In 25 ABY, during the onset of the Yuuzhan Vong War, the world was invaded and conquered by the titular race.
