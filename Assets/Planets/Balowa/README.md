# Balowa

**Continuity:** Legends  
**Source:** [Balowa](https://starwars.fandom.com/wiki/Balowa)

Balowa was a planet in the Mid Rim's Balowa system whose primary terrain was rainforest. This planet was the location of a duel in which the Sith Lord Kaox Krul and Jedi Knight Crian Maru, along with her Padawan, Dree Vandap, were killed in 1000 BBY, shortly before the start of the Ruusan campaign.
