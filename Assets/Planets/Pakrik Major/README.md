# Pakrik Major

**Continuity:** Legends  
**Source:** [Pakrik Major](https://starwars.fandom.com/wiki/Pakrik_Major)
**Galaxy atlas:** system `Pakrik Major`, Core Worlds, grid K-9 — map position (-202.0, 891.3, 29.0)

Pakrik Major was the sector capital of Kanchen sector. It was a Planet in the Pakrik system and was located in the Core Worlds region. It was more densely populated than its twin world, Pakrik Minor, and hosted the annual Kanchen Sector Conference. It was ruled by the Grandiose Elector.
