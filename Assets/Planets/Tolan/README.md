# Tolan

**Continuity:** Legends  
**Source:** [Tolan](https://starwars.fandom.com/wiki/Tolan)

Tolan was a planet located within the Tolan system of the Colonies. It was the location of the Tolan Navy Shipyards, near Dankayo and probably within a few sectors of Ralltiir.
