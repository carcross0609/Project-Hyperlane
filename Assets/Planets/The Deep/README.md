# The Deep

**Continuity:** Canon  
**Source:** [The Deep](https://starwars.fandom.com/wiki/The_Deep)
**Galaxy atlas:** system `The Deep`, Unknown Regions, grid R-6 — map position (10241.8, 5711.8, -247.6)

The Deep was a planet located in the Unknown Regions with a barren and lifeless surface. At some point, Luke Skywalker traveled to the Deep to rescue R2-D2 from a mining complex.
