# Miser

**Continuity:** Canon  
**Source:** [Miser](https://starwars.fandom.com/wiki/Miser)
**Galaxy atlas:** system `Miser`, Outer Rim — map position (-963.3, -13387.5, -375.0)

Miser was the innermost planet of the Bespin system. Cloud City, which floated in the habitable atmosphere of the gas giant Bespin, was constructed from materials mined on Miser. During the Iron Blockade, the planet became infested with mynocks, prompting the Ugnaughts to offer a bounty for every dead creature.
