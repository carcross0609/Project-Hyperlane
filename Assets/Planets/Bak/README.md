# Bak

**Continuity:** Legends  
**Source:** [Bak](https://starwars.fandom.com/wiki/Bak)
**Galaxy atlas:** system `Bak`, Wild Space, grid G-16 — map position (-6260.6, -9791.7, -64.1)
