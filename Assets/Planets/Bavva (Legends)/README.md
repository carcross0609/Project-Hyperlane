# Bavva

**Continuity:** Legends  
**Source:** [Bavva/Legends](https://starwars.fandom.com/wiki/Bavva/Legends)
**Galaxy atlas:** system `Bavva`, Outer Rim, grid K-18 — map position (-985.7, -12619.2, -399.8)

Bavva was a colony world of the gold-skinned Nothoiin species. Located on the Nothoiin Corridor in the Outer Rim Territories' Anoat sector, Bavva exported a foul-tasting ale distilled from moss that Lutrillians loved and Humans hated. Sergeant Taray, a Nothoiin member of the Cloud City Wing Guard, grew up in Bavva's lawless Kaniti province.
