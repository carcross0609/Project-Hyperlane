# Ruuria

**Continuity:** Legends  
**Source:** [Ruuria/Legends](https://starwars.fandom.com/wiki/Ruuria/Legends)
**Galaxy atlas:** system `Ruuria`, Outer Rim, grid Q-3 — map position (8698.7, 9115.5, -528.0)

Ruuria, on the Hydian Way, was the homeworld of the insectoid Ruurians. The planet was located near the Corporate Sector. It featured tropical jungles, manufacturing centers, and universities. Ruuria was a member of the Unified Ruurian Colonies.

The Ruurians' society was made up of 143 colonies, and every Ruurian belonged to a single colony for life.
