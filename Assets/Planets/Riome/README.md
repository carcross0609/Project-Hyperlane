# Riome

**Continuity:** Legends  
**Source:** [Riome](https://starwars.fandom.com/wiki/Riome)
**Galaxy atlas:** system `Riome`, Outer Rim, grid M-18 — map position (1922.4, -12830.9, -290.1)

Riome was a little, frigid world located in the Dorvalla system of the Outer Rim Territories. The Toom clan set up a hideout here after sabotaging Lommite Limited and InterGalactic Ore's freighters in 33 BBY, but Darth Maul was able to anonymously lead Patch Bruit and other LL workers to Riome, where they gunned down each and every Toom member on the planet. Eventually, Darth Maul was waiting in the shadows, and himself took down the remaining combatants.
