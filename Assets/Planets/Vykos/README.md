# Vykos

**Continuity:** Legends  
**Source:** [Vykos](https://starwars.fandom.com/wiki/Vykos)
**Galaxy atlas:** system `Vykos`, Outer Rim, grid L-5 — map position (78.8, 7302.4, 240.7)

Vykos was a planet located within the Vykos system of the Outer Rim Territories. It was a stopping point on the Relgim Run of the luxury liner Kuari Princess, a planet of fast-flowing rivers (such as the Tueinami) which attacted white-water rapid rafters and deep canyons (such as the Grand Aderian Range, a kilometer deep).
