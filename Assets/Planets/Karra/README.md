# Karra

**Continuity:** Legends  
**Source:** [Karra](https://starwars.fandom.com/wiki/Karra)
**Galaxy atlas:** system `Karra`, Outer Rim, grid J-19 — map position (-2355.6, -13765.8, 174.8)

Karra was the Karran homeworld. It was briefly colonized by the Mineral Assets Partnership in 500 BBY. Later, the Galactic Empire established varmigio mines on the planet. Both offworld settlements were destroyed by swarms of insects controlled by the Karran hive mind.

Karra had a diverse array of insectoid fauna, including swarmers, karran beetles, karran mantises, and legworms.
