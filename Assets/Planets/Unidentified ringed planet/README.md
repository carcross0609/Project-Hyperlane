# Unidentified ringed planet

**Continuity:** Canon  
**Source:** [Unidentified ringed planet](https://starwars.fandom.com/wiki/Unidentified_ringed_planet)
**Galaxy atlas:** system `Unidentified ringed planet`, Other, grid K-18 — map position (-786.6, -12758.1, 105.4)

A ringed planet was located in the Regani sector, and was orbited by Osisis Station, along with many asteroids. Fool's Run, a private race course owned by the Besalisk Galus Vez, was located in the rings of the planet.
