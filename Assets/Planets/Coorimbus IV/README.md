# Coorimbus IV

**Continuity:** Legends  
**Source:** [Coorimbus IV](https://starwars.fandom.com/wiki/Coorimbus_IV)
**Galaxy atlas:** system `Coorimbus IV`, Colonies, grid L-13 — map position (759.1, -5487.3, -90.4)

Coorimbus IV was a gas giant in the Coorimbus system in Tapani sector where House Calipsa secretly acquired corusca gems.

Losk Tenchi located the secret mining operation and was arrested by House Calipsa to keep their secret safe. He was set free only shortly before the Battle of Endor.
