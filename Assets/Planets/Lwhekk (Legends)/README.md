# Lwhekk

**Continuity:** Legends  
**Source:** [Lwhekk/Legends](https://starwars.fandom.com/wiki/Lwhekk/Legends)
**Galaxy atlas:** system `Lwhekk`, Unknown Regions, grid C-16 — map position (-12229.0, -9521.1, -57.1)

Lwhekk was a planet located in the Ssi-ruuk Star Cluster of the Unknown Regions in the galaxy. It was the homeworld of the sentient Ssi-ruu and P'w'eck species. It was the capital of the Ssi-ruuvi Imperium.
