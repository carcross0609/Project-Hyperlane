# Yurb

**Continuity:** Legends  
**Source:** [Yurb](https://starwars.fandom.com/wiki/Yurb)
**Galaxy atlas:** system `Yurb`, Outer Rim, grid S-10 — map position (11399.9, -572.0, -132.6)

Yurb was an arid planet located within the Yurb system of the Outer Rim Territories. It was the homeworld of the razor-tailed tiger of the Dust Pits.
