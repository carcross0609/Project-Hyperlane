# Sleheyron

**Continuity:** Legends  
**Source:** [Sleheyron/Legends](https://starwars.fandom.com/wiki/Sleheyron/Legends)
**Galaxy atlas:** system `Sleheyron`, Hutt Space, grid S-10 — map position (11546.7, -339.5, -598.5)

Sleheyron was a planet in Hutt Space. Although it was based on slave trade, its powerful economy made Sleheyron one of the most important Hutt worlds.
