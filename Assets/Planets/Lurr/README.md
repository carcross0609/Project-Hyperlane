# Lurr

**Continuity:** Legends  
**Source:** [Lurr](https://starwars.fandom.com/wiki/Lurr)

Lurr was a planet in the Outer Rim's Rayter sector. One of the stormtroopers that accompanied the Sith Lord Darth Vader to Cheelit killed a young woman while on the planet. The Guild of Vindicators assassin Clat the Shamer later used the memories of that event to compel the soldier to commit suicide.
