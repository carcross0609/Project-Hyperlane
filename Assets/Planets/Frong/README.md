# Frong

**Continuity:** Canon  
**Source:** [Frong](https://starwars.fandom.com/wiki/Frong)
**Galaxy atlas:** system `Frong`, Outer Rim — map position (8187.4, 6597.4, 535.7)

Frong was a planet located in the Outer Rim that was the homeworld of the Frong species. It was situated in the Frong system in the Ojoster sector, in grid square N-7 of the Standard Galactic Grid.
