# Little Talhovi

**Continuity:** Legends  
**Source:** [Little Talhovi](https://starwars.fandom.com/wiki/Little_Talhovi)
**Galaxy atlas:** system `Little Talhovi`, Mid Rim, grid K-18 — map position (-11.9, -12029.4, 154.7)

Little Talhovi was a world located in the Little Talhovi system of the Juvex sector, a part of the Senex-Juvex region in the Western Reaches portion of the Mid Rim. A hyperlane connected it to the Talhovi system. Little Talhovi was considered to be a promising agriworld by 43 ABY and, like the rest of the Senex-Juvex worlds, was under the control of the region's aristocratic Ancient Houses.
