# Imvur

**Continuity:** Canon  
**Source:** [Imvur](https://starwars.fandom.com/wiki/Imvur)
**Galaxy atlas:** system `Imvur`, Other, grid L-9 — map position (464.2, 349.9, -66.4)

Imvur was a planet located in the Hasmir system within the Mid Rim Territories. Between 4 BBY and 3 BBY Imvur was controlled by the Galactic Empire, although a rebel cell of the larger rebellion had a base there.
