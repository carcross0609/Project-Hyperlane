# Hollastin

**Continuity:** Legends  
**Source:** [Hollastin/Legends](https://starwars.fandom.com/wiki/Hollastin/Legends)
**Galaxy atlas:** system `Hollastin`, Hutt Space, grid S-12 — map position (11389.9, -4046.5, 125.8)

Hollastin was a busy Hutt Space trade world. At one point, the smuggler Han Solo experienced an instance of good fortune there. Hollastin emerged unscathed from the Yuuzhan Vong invasion of Hutt Space and subsequently rose in importance.
