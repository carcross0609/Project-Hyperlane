# Chirgay

**Continuity:** Legends  
**Source:** [Chirgay](https://starwars.fandom.com/wiki/Chirgay)
**Galaxy atlas:** system `Chirgay`, Outer Rim, grid O-6 — map position (5303.6, 5421.5, 52.0)

Chirgay was an ice planet located in the Dathomir system, a part of the Quelii sector in the New Territories portion of the Outer Rim Territories. A cold planet, it occupied the ninth orbital position around its star, Domir. It was itself circled by one moon.
