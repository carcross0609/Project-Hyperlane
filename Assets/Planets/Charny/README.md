# Charny

**Continuity:** Legends  
**Source:** [Charny](https://starwars.fandom.com/wiki/Charny)
**Galaxy atlas:** system `Charny`, Mid Rim, grid P-11 — map position (6841.0, -2258.5, -70.8)

Charny was the second planet orbiting the star Hoth's Brand in the Ruusan system. Located in the Teraab sector of the Mid Rim, it was a terrestrial world.

It was named after the Jedi Knight Kiel Charny.
