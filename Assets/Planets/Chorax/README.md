# Chorax

**Continuity:** Legends  
**Source:** [Chorax](https://starwars.fandom.com/wiki/Chorax)
**Galaxy atlas:** system `Chorax`, Colonies, grid N-11 — map position (3226.1, -1748.1, -104.7)

Chorax was a planet in the Rachuk sector, which lay between Commenor and Talasea. It was the sole planet of the Chorax system, a haven for pirates and smugglers.
