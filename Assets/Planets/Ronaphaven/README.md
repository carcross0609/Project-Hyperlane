# Ronaphaven

**Continuity:** Canon  
**Source:** [Ronaphaven](https://starwars.fandom.com/wiki/Ronaphaven)

Ronaphaven was an agricultural planet located in a mid-sized system within Galactic Republic space. During the High Republic Era, kelivan root farmers worked on Ronaphaven. The Drengir, a carnivorous plant species, were present on Ronaphaven, but were driven away by the blight. Jedi Knights Burryaga Agaburry and Bell Zettifar investigated a report of Drengir activity on Ronaphaven, where they encountered the blight for the first time.
