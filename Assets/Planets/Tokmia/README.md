# Tokmia

**Continuity:** Canon  
**Source:** [Tokmia](https://starwars.fandom.com/wiki/Tokmia)
**Galaxy atlas:** system `Tokmia`, Outer Rim, grid K-18 — map position (-1175.8, -12929.7, 80.8)

Tokmia was a planet located in the Anoat sector of the galaxy's Outer Rim Territories. Figg Excavations mined the world for crystals, though they eventually abandoned it, leaving behind some crystals guarded by a still-active security system.
