# Korlings

**Continuity:** Legends  
**Source:** [Korlings](https://starwars.fandom.com/wiki/Korlings)

Korlings was a planet in the Korlings system, located in the Outer Rim, and home to a noble family. It was rumored to be the homeworld of the notorious pirate Faarl the Conqueror.
