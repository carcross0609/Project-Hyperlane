# Sessa

**Continuity:** Legends  
**Source:** [Sessa](https://starwars.fandom.com/wiki/Sessa)
**Galaxy atlas:** system `Sessa`, Mid Rim, grid R-14 — map position (10045.9, -6974.1, 364.1)

Sessa was the first planet in the Kothlis system. It was a chaotic inhospitable world. Sessa was a tiny planetoid with irregular orbit that tore the planet's surface to shreds. The proximity of the planet to its sun caused searing temperatures.
