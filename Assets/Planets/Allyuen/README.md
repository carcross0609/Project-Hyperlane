# Allyuen

**Continuity:** Canon  
**Source:** [Allyuen](https://starwars.fandom.com/wiki/Allyuen)
**Galaxy atlas:** system `Allyuen`, Outer Rim, grid K-18 — map position (-1165.9, -12860.9, -153.0)

Allyuen was a planet located in Allyuen system in the Anoat sector of the galaxy's Outer Rim Territories, in grid square K-18 of the Standard Galactic Grid. It was home to the Allyuen spaceport, which was garrisoned by the Galactic Empire. Allyuen and several other locations were identified in a 3 ABY Imperial Security Bureau report that generated targets for Viper probe droid surveys by cross-referencing areas with a high degree of suspicious activity with the unsettled parts of the galaxy favored by the rebels.
