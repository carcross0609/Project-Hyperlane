# Tervissis

**Continuity:** Legends  
**Source:** [Tervissis](https://starwars.fandom.com/wiki/Tervissis)
**Galaxy atlas:** system `Tervissis`, Outer Rim, grid R-5 — map position (9768.8, 6847.9, 165.9)

Tervissis was a planet located within the Tervissis system of the Outer Rim Territories. It was the homeworld of two sentient species, the Tervigs and the Bandies. The two species were at war with one another, with the Tervigs subjugating the Bandies.
