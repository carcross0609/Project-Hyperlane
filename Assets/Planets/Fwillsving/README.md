# Fwillsving

**Continuity:** Legends  
**Source:** [Fwillsving](https://starwars.fandom.com/wiki/Fwillsving)
**Galaxy atlas:** system `Fwillsving`, Outer Rim, grid T-10 — map position (12734.5, -22.7, -510.7)

Fwillsving was a planet near Kessel and Honoghr. It was sometimes used by smugglers as a repair depot and a hideaway from Imperial patrol starships while smuggling spice on the Kessel Run.

In 22 BBY, its capital Svitalos was severely damaged by overzealous celebrants of a limmie victory over neighboring Kubindi.
