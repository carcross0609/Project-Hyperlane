# Zhar

**Continuity:** Legends  
**Source:** [Zhar/Legends](https://starwars.fandom.com/wiki/Zhar/Legends)
**Galaxy atlas:** system `Zhar`, Outer Rim, grid P-17 — map position (7408.3, -10781.9, 1.1)

Zhar was a gas giant located in the Zhar system of the Cadavine sector. Of its dozen moons, two were terrestrial. One of them, Gall, was the site of an Imperial enclave. Rogue Squadron set up a temporary base on the other, Kile, from which they launched an attempt to capture Boba Fett and rescue Han Solo, then trapped in carbonite.
