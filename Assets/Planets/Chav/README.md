# Chav

**Continuity:** Legends  
**Source:** [Chav](https://starwars.fandom.com/wiki/Chav)
**Galaxy atlas:** system `Chav`, Outer Rim, grid O-6 — map position (5081.4, 5848.2, 33.2)

Chav was the tenth and last planet of the Dathomir system, a part of the Quelii sector in the New Territories portion of the Outer Rim Territories. A world made of barren rock, it had two moons and orbited the star Domir.
