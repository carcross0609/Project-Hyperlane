# Nushk

**Continuity:** Legends  
**Source:** [Nushk](https://starwars.fandom.com/wiki/Nushk)
**Galaxy atlas:** system `Nushk`, Outer Rim — map position (2385.2, 4448.0, 220.5)

Nushk was the third planet in the Hoth system, located within the Anoat sector of the Outer Rim Territories. It was mostly covered with methane oceans and had four moons.
