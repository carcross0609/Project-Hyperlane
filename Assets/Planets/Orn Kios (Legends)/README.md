# Orn Kios

**Continuity:** Legends  
**Source:** [Orn Kios/Legends](https://starwars.fandom.com/wiki/Orn_Kios/Legends)
**Galaxy atlas:** system `Orn Kios`, Outer Rim, grid K-18 — map position (-1309.5, -13209.6, 227.2)

Orn Kios was an Outer Rim Territories planet situated in the Yarith sector. It was home to a populace known as the Ornki that practiced fishing and lived in lightweight structures built atop giant lily pads. During the early stages of the settlement of the Greater Javin region which eventually included the Yarith sector, Galactic Republic merchants launched from worlds such as Orn Kios in search of new local trade routes. To the Ornki's resentment, Orn Kios eventually became a tourist attraction.
