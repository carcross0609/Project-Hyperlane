# Teeda's Eyes

**Continuity:** Legends  
**Source:** [Teeda's Eyes](https://starwars.fandom.com/wiki/Teeda%27s_Eyes)

Teeda's Eyes was the collective name given to Pii III and Pii IV. It was a reference to Empress Teeda of the Arkanis Regency; the lush forested planets brought to mind the green eyes of the Empress.
