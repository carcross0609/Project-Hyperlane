# Pakrik Minor

**Continuity:** Legends  
**Source:** [Pakrik Minor](https://starwars.fandom.com/wiki/Pakrik_Minor)
**Galaxy atlas:** system `Pakrik Minor`, Core Worlds, grid K-9 — map position (-996.5, 791.5, -27.1)

Pakrik Minor was a peaceful agriworld in Kanchen sector with fruit and tallgrain farms, resorts, and undeveloped countryside. The cloned Imperial sleeper cell Jenth-44 was located on Pakrik Minor. It was the twin planet of Pakrik Major.
