# Anteevy

**Continuity:** Legends  
**Source:** [Anteevy/Legends](https://starwars.fandom.com/wiki/Anteevy/Legends)
**Galaxy atlas:** system `Anteevy`, Mid Rim, grid P-7 — map position (6895.2, 3958.5, 86.7)

Anteevy was a frigid ice world locked in a perpetual winter. Located in the Mid Rim's Esuain sector, the planet orbited a star in the Anteevy system.
