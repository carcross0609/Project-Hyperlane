# Sapper

**Continuity:** Canon  
**Source:** [Sapper](https://starwars.fandom.com/wiki/Sapper)

Sapper was a desert planet in the galaxy that featured intense sandstorms. During the Clone Wars, Clone Force 99 visited Sapper to investigate a Separatist installation.
