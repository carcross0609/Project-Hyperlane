# Cadomai Prime

**Continuity:** Canon  
**Source:** [Cadomai Prime](https://starwars.fandom.com/wiki/Cadomai_Prime)
**Galaxy atlas:** system `Cadomai Prime`, Outer Rim, grid R-3 — map position (10022.6, 9192.9, 200.1)

Cadomai Prime, also known as simply Cadomai, was a planet located in the galaxy's Outer Rim Territories, situated along the Hydian Way that was the homeworld of the Snivvian species. The winters of Cadomai Prime were very harsh for the Snivvians to survive, during which they spent the time in underground caverns in artistic pursuits. Some did escape the icy tundras to become bounty hunters offworld.
