# Ankhural

**Continuity:** Canon  
**Source:** [Ankhural](https://starwars.fandom.com/wiki/Ankhural)
**Galaxy atlas:** system `Ankhural`, Other, grid O-15 — map position (5225.3, -8334.3, 137.2)

Ankhural was a planet in the system of the same name in Hutt Space. It had one city which was protected by a ray shield to hold off giant clouds of dust from the silicon fields. In 3 ABY, the Rebel Alliance's 61st Mobile Infantry took refuge at abandoned podracing track for repairs on its headquarters, the CR90 corvette Thunderstrike.
