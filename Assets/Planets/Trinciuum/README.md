# Trinciuum

**Continuity:** Legends  
**Source:** [Trinciuum](https://starwars.fandom.com/wiki/Trinciuum)

Trinciuum was the second planet in the Muunilinst system. It was a planet formed of acidic clouds of gas and orbited by a single moon.
