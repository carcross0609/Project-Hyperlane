# Haurgab

**Continuity:** Legends  
**Source:** [Haurgab](https://starwars.fandom.com/wiki/Haurgab)

Haurgab was a planet in the Mid Rim that allied itself with the Separatists during the Clone Wars. The Galactic Republic sent Omega Squad to the planet, who battled the local forces in the Battle of Haurgab.
