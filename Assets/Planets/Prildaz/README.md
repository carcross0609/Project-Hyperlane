# Prildaz

**Continuity:** Legends  
**Source:** [Prildaz](https://starwars.fandom.com/wiki/Prildaz)
**Galaxy atlas:** system `Prildaz`, Core Worlds, grid K-10 — map position (-1053.5, -744.5, -9.7)

Prildaz was the Yevethan name of the third planet in the ILC-905 system in the Farlax sector in the Galactic Core. It was a barren dustball orbited by the Imperial shipyard Black Nine. The New Republic defeated the Yevethan defense of Black Nine.
