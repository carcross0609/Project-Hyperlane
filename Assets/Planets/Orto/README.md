# Orto

**Continuity:** Canon  
**Source:** [Orto](https://starwars.fandom.com/wiki/Orto)
**Galaxy atlas:** system `Orto`, Outer Rim, grid M-19 — map position (2195.1, -13657.0, 42.9)

Orto was a cold planet located in the Outer Rim Territories that was the homeworld of the Ortolan species. Orto was so cold, the natives had to consume large amounts of food in order to develop a warm layer of blubber.

During the Imperial Era, Orto maintained a modest Imperial presence, which escalated following an incident. Orto had some tourist appeal, specifically the city of Cheddatown.
