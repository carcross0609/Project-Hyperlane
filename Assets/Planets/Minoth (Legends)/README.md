# Minoth

**Continuity:** Legends  
**Source:** [Minoth/Legends](https://starwars.fandom.com/wiki/Minoth/Legends)

Minoth was a world located in the Masla sector of the Mid Rim. Prior to the Battle of Hoth, Han Solo planned to run weapons from Minoth to Hendrix for the Rebel Alliance.

## Planetary data

- **Name:** Minoth
- **Region:** Mid Rim
- **Sector:** Masla sector
- **System:** Minoth system
