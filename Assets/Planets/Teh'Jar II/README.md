# Teh'Jar II

**Continuity:** Legends  
**Source:** [Teh'Jar II](https://starwars.fandom.com/wiki/Teh%27Jar_II)
**Galaxy atlas:** system `Teh'Jar II`, Outer Rim, grid M-20 — map position (2226.3, -15186.9, -192.8)

Teh'Jar II was a planet that occupied the second orbital position in the Teh'Jar system, a part of the Outer Rim Territories' Minos Cluster. During the Galactic Civil War, the Galactic Empire began to use armed patrols to enforce a high technology ban there.

Around the same time, the rivals xenoarchaeologist Doctor Angrail Ryhl and the antiquities dealer Nardo Sau were both searching for the Um'Tal, or "Sky Stone," an ancient artifact that originated with a lost civilization and was believed to possess mystical powers. Their search led both men to Teh'Jar II, with Ryhl hiring the best fixer in the Minos Cluster to help him deal with the Imperial technology ban.
