# Tamazall

**Continuity:** Legends  
**Source:** [Tamazall/Legends](https://starwars.fandom.com/wiki/Tamazall/Legends)
**Galaxy atlas:** system `Tamazall`, Expansion Region, grid M-15 — map position (1961.7, -7903.1, -23.2)

Tamazall was a New Republic prison planet located in the Boeus sector of the Expansion Region. Zurga Pass was in its foothills. The planet was protected by the Tamazall Militia. Prisoners were transported via monorail.
