# Ketaris

**Continuity:** Legends  
**Source:** [Ketaris/Legends](https://starwars.fandom.com/wiki/Ketaris/Legends)
**Galaxy atlas:** system `Ketaris`, Outer Rim, grid L-5 — map position (1452.5, 6123.7, 247.3)

Ketaris was a planet in the Outer Rim which boasted the University of Ketaris. A major trade center, it had a few large continents surrounded by great oceans.
