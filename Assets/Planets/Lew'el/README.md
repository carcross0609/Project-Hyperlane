# Lew'el

**Continuity:** Canon  
**Source:** [Lew'el](https://starwars.fandom.com/wiki/Lew%27el)

Lew'el, which meant deluge, was an aquatic planet located in the Wild Space of the galaxy. Originally settled by humans a long time ago, Lew'el remained a largely forgotten world by those who craved power. Humans native to Lew'el were called Lew'elans.
