# Mytus VII

**Continuity:** Legends  
**Source:** [Mytus VII/Legends](https://starwars.fandom.com/wiki/Mytus_VII/Legends)
**Galaxy atlas:** system `Mytus VII`, Wild Space, grid S-3 — map position (11001.4, 10030.8, -62.5)

Mytus VII was the outermost planet of the Mytus system in Wild Space. Mytus VII was avoided, even by the Ocsin spacers, due to being the near the Corporate Sector Authority's Stars' End penal facility.
