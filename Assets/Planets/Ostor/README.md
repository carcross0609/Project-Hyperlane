# Ostor

**Continuity:** Legends  
**Source:** [Ostor](https://starwars.fandom.com/wiki/Ostor)

Ostor was an arid terrestrial planet located in the Ostor system, at the fringe of the Outer Rim Territories in the Koradin sector. It was a barren planet composed of red soil, deep canyons, and various wind-sculpted rock formations.
