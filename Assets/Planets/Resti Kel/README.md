# Resti Kel

**Continuity:** Legends  
**Source:** [Resti Kel](https://starwars.fandom.com/wiki/Resti_Kel)
**Galaxy atlas:** system `Resti Kel`, Mid Rim, grid L-18 — map position (127.4, -12027.5, 520.6)

Resti Kel was a planet located in the Resti Kel system of the Juvex sector, in the Mid Rim of the galaxy.

Resti Kel was an industrial world of House Kellermin. It was the location of the Kellermin Competition, staged every five years.
