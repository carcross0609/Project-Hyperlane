# Tirsa

**Continuity:** Legends  
**Source:** [Tirsa](https://starwars.fandom.com/wiki/Tirsa)
**Galaxy atlas:** system `Tirsa`, Outer Rim, grid S-4 — map position (10735.0, 8915.9, -48.3)

Tirsa was an industrial planet located within the Tirsa system of the Outer Rim Territories. It was home to the Tirsa Wargear armaments company that manufactured the Leviathan submersible carrier.
