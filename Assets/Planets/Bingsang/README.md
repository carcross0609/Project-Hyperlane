# Bingsang

**Continuity:** Legends  
**Source:** [Bingsang](https://starwars.fandom.com/wiki/Bingsang)

Bingsang was the sixth planet orbiting the star Striar in the Malastare system. Located in the Dustig sector of the Mid Rim, it was a gas giant.
