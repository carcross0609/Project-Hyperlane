# Kor Trinivii; (The Bootana Hutta region, with Kor Trinivii represented by the number 19)

**Continuity:** Legends  
**Source:** [Kor Trinivii](https://starwars.fandom.com/wiki/Kor_Trinivii)
**Galaxy atlas:** system `Kor Trinivii`, Hutt Space, grid S-11 — map position (11801.4, -1755.4, 214.9)

Kor Trinivii was a world located within the Kor Trinivii system, a part of the Bootana Hutta region of Hutt Space. It was situated in a part of the Slice section of the galaxy. It was connected by a hyperlane to the Kor Gejalli system.

Kor Trinivii was the throneworld of the Trinivii kajidic.
