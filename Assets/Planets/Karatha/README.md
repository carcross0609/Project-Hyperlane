# Karatha

**Continuity:** Legends  
**Source:** [Karatha](https://starwars.fandom.com/wiki/Karatha)
**Galaxy atlas:** system `Karatha`, Expansion Region, grid L-15 — map position (648.7, -8621.3, 205.0)

Karatha was a planet in the Expansion Region that was the location of the Rebel Alliance base Eyrie Base. The Eyrie was located in a natural sinkhole on the surface of Karatha.
