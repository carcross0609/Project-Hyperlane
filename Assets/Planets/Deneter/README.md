# Deneter

**Continuity:** Legends  
**Source:** [Deneter](https://starwars.fandom.com/wiki/Deneter)

Deneter was a planet located in Wild Space that was orbited by twenty uninhabited satellites. It was located in a nebula near the Red Twins.
