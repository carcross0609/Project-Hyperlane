# Anoat

**Continuity:** Canon  
**Source:** [Anoat](https://starwars.fandom.com/wiki/Anoat)
**Galaxy atlas:** system `Anoat`, Outer Rim, grid K-18 — map position (-1428.3, -12811.1, -327.6)

Anoat was a planet located in the Anoat system of the Outer Rim Territories. It was once a sprawling city-world that, as seat of the Nothoiin Noble Court, was the capital of the Anoat sector. However, after being gassed by the Galactic Empire, the planet was polluted and largely abandoned.
