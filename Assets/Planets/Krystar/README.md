# Krystar

**Continuity:** Canon  
**Source:** [Krystar](https://starwars.fandom.com/wiki/Krystar)

Krystar was a planet inhabited by a population of Ovissians. During the Clone Wars, the planet was a part of the Galactic Republic, represented by Vishar Koss and led by Regent Queb. Queb secretly held Republic clone troopers prisoner on Krystar, selling them to a Trandoshan hunter.
