# Molavar

**Continuity:** Legends  
**Source:** [Molavar/Legends](https://starwars.fandom.com/wiki/Molavar/Legends)
**Galaxy atlas:** system `Molavar`, Outer Rim, grid S-15 — map position (10984.4, -8374.6, -451.9)

Molavar was a backwater, desert world in the Outer Rim Territories, with a number of seedy spaceports and low-income moisture farms. It was inhabited by beings of various species, but especially by the native Molavaran race. Darca Nyl chased Lycan to the planet. During the Clone Wars, the planet lay within Separatist space.
