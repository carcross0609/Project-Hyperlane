# Shihon

**Continuity:** Legends  
**Source:** [Shihon/Legends](https://starwars.fandom.com/wiki/Shihon/Legends)
**Galaxy atlas:** system `Shihon`, Unknown Regions, grid E-8 — map position (-9273.0, 1663.8, 32.1)

Shihon was a terrestrial planet located in the Shihon system of the Unknown Regions' Chiss Space. A hyperlane linked the world to the Ool and Oyokal systems. The planet's surface featured several oceans.

Shihon was home to several animal species, all of which had boneless body structures. Two examples of Shihon's fauna were bulbous gas-bags that filled the planet's skies and city-sized jellies that were prevalent in the oceans.
