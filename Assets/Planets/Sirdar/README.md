# Sirdar

**Continuity:** Legends  
**Source:** [Sirdar](https://starwars.fandom.com/wiki/Sirdar)

Sirdar was a planet in a remote region of the galaxy. At some point, a small population of the insectivorous winged xendrites was placed on Sirdar to help with insect control. The xendrites reproduced at an astounding rate and soon overran the planet.
