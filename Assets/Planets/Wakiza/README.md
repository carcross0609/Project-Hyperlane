# Wakiza

**Continuity:** Legends  
**Source:** [Wakiza](https://starwars.fandom.com/wiki/Wakiza)
**Galaxy atlas:** system `Wakiza`, Core Worlds, grid K-10 — map position (-858.8, -542.1, -50.4)

Wakiza was a planet located within the Wakiza system of the Core Worlds of the galaxy. One of the original thirteen planets of the Duskhan League, it was located within the Koornacht Cluster. Wakiza was orbited by the Imperial Navy shipyard Black Eight. "Sleepy" Nagelson was shot down while flying a reconnaissance mission over Wakiza for the New Republic.
