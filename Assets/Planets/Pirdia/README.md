# Pirdia

**Continuity:** Legends  
**Source:** [Pirdia](https://starwars.fandom.com/wiki/Pirdia)
**Galaxy atlas:** system `Pirdia`, Mid Rim, grid R-16 — map position (9759.7, -10273.8, 537.0)

Pirdia was the third planet orbiting the star Tyrius in the Tyrius system. Located in the Savareen sector of the Outer Rim Territories, it was a ringed gas giant with green-blue gases striping its surface.
