# Thune

**Continuity:** Canon  
**Source:** [Thune](https://starwars.fandom.com/wiki/Thune)
**Galaxy atlas:** system `Thune`, Wild Space, grid Q-5 — map position (8439.1, 6187.7, 303.2)

Thune was a planet located in the Thune system in the Wazta sector of the Outer Rim Territories, situated in grid square I-18 of the Standard Galactic Grid along the Koda Spur. From space, it looked like a brown and blue orb.
