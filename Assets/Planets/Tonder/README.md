# Tonder

**Continuity:** Legends  
**Source:** [Tonder](https://starwars.fandom.com/wiki/Tonder)
**Galaxy atlas:** system `Tonder`, Mid Rim, grid P-15 — map position (6202.8, -8186.8, 113.5)

Tonder was the third planet in the Algaran system. It was a tectonically, seismically active world with incredible mining potential. It boasted one moon. The Algarian Bureau of Planetary Colonization and Bureau of Volcanoes disputed which bureau had jurisdiction over the planet.
