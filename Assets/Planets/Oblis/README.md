# Oblis

**Continuity:** Legends  
**Source:** [Oblis](https://starwars.fandom.com/wiki/Oblis)
**Galaxy atlas:** system `Oblis`, Mid Rim — map position (5487.2, -8375.5, -117.2)

Oblis was a technologically-advanced planet in the Cularin system. It included large crystal deposits.

Oblis was destroyed by a weapon powered by the Darkstaff before 1000 BBY. Its remnants became the Cularin asteroid belt.
