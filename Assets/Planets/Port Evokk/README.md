# Port Evokk

**Continuity:** Legends  
**Source:** [Port Evokk](https://starwars.fandom.com/wiki/Port_Evokk)
**Galaxy atlas:** system `Port Evokk`, Mid Rim, grid L-18 — map position (544.9, -12142.4, -164.1)

Port Evokk was the homeworld of con artist and gambler Tord Gamb. The locals of this planet would use ansmul-hide to make boots and jackets. The bounty hunter Sirenas Firil worked with a small guild out of Port Evokk.
