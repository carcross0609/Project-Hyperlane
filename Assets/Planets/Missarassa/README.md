# Missarassa

**Continuity:** Legends  
**Source:** [Missarassa](https://starwars.fandom.com/wiki/Missarassa)
**Galaxy atlas:** system `Missarassa`, Outer Rim — map position (7669.6, 7312.1, 209.5)

Missarassa was the fifth planet orbiting the binary stars Adega Prime and Adega Besh in the Adega system. Located in the Auril sector of the Outer Rim, it was an ice ball.
