# Veladine

**Continuity:** Legends  
**Source:** [Veladine](https://starwars.fandom.com/wiki/Veladine)
**Galaxy atlas:** system `Veladine`, Mid Rim, grid P-7 — map position (7199.8, 3745.3, 221.1)

Veladine was the sixth planet orbiting the star Velm. It was the outermost planet in the Velm system, which was located in the Halori sector in the Trans-Hydian portion of the Mid Rim. Veladine's surface consisted of ice, and it was orbited by three asteroid moonlets.
