# Aradian

**Continuity:** Legends  
**Source:** [Aradian](https://starwars.fandom.com/wiki/Aradian)
**Galaxy atlas:** system `Aradian`, Outer Rim, grid S-6 — map position (11512.0, 5625.6, -268.1)

Aradian was the third planet in the Lianna system known for its repulsorlift technology. The planet had an atmosphere mildly poisonous to most aliens, and it was orbited by three moons.
