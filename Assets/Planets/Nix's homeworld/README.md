# Nix's homeworld

**Continuity:** Canon  
**Source:** [Nix's homeworld](https://starwars.fandom.com/wiki/Nix%27s_homeworld)

The homeworld of the Merqaal, Nix, was a jungle planet. He lived there until he was captured by the Sixth Kin to be sold as an exotic pet.
