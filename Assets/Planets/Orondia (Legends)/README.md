# Orondia

**Continuity:** Legends  
**Source:** [Orondia/Legends](https://starwars.fandom.com/wiki/Orondia/Legends)
**Galaxy atlas:** system `Orondia`, Hutt Space, grid S-11 — map position (10837.3, -2710.8, -570.0)

Orondia was a bleak planet located in Hutt Space in the galaxy. A fueling depot was located on the planet's surface. The depot was run by a Bith scammer, in league with his brother on Nal Hutta.
