# Epsi Nadir

**Continuity:** Legends  
**Source:** [Epsi Nadir](https://starwars.fandom.com/wiki/Epsi_Nadir)
**Galaxy atlas:** system `Epsi Nadir`, Outer Rim — map position (-732.0, -12513.8, 473.3)

Epsi Nadir was an Expansion Region planet located in the Epsi Collective sector. It was purchased by the arms dealer group known as the Most Honourable Guild of Armourers, which established an auction house there. The bounty hunter Dej Vennor at one point acquired the interrogation droid IT-904 at the auction house.
