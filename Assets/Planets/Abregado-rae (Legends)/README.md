# Abregado-rae

**Continuity:** Legends  
**Source:** [Abregado-rae/Legends](https://starwars.fandom.com/wiki/Abregado-rae/Legends)
**Galaxy atlas:** system `Abregado-rae`, Core Worlds, grid K-13 — map position (-66.5, -4750.8, -7.3)

Abregado-rae was a major manufacturing and trade-oriented planet, the third of five worlds in the Abregado system in the Core Worlds and the homeworld of the Gados and the Moochers. It sat at the beginning of the Rimma Trade Route, and was also the starting point for the Shapani Bypass or the "Bacta Run". The planet had a reputation as one of the Core Worlds' more rough-and-tumble worlds. It was home to the infamous Abregado-rae Spaceport.
