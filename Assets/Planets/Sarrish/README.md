# Sarrish

**Continuity:** Canon  
**Source:** [Sarrish](https://starwars.fandom.com/wiki/Sarrish)
**Galaxy atlas:** system `Sarrish`, Expansion Region, grid K-16 — map position (-256.2, -9207.5, 17.8)

Sarrish was a planet located in the Sarrish system in the Vensensor sector of the Expansion Region where the Battle of Sarrish took place during the Clone Wars. The Galactic Republic lost the battle and suffered tremendous casualties, and it was considered a devastating loss.
