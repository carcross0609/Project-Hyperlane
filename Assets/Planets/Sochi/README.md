# Sochi

**Continuity:** Legends  
**Source:** [Sochi](https://starwars.fandom.com/wiki/Sochi)
**Galaxy atlas:** system `Sochi`, Inner Rim, grid M-9 — map position (2899.4, 970.0, -68.1)

Sochi was a vacation planet located in the Sochi system within the Slice portion of the Inner Rim. The Galactic Empire maintained the camp known as Troopers' Rest on Sochi, where Imperial stormtroopers who reached retirement age were eventually sent.
