# Borcorash

**Continuity:** Legends  
**Source:** [Borcorash](https://starwars.fandom.com/wiki/Borcorash)
**Galaxy atlas:** system `Borcorash`, Other, grid N-6 — map position (3773.4, 5283.6, 128.5)

Borcorash was a planet with incredibly beautiful sunsets with an ever-shifting array of colors brought about by atmospheric conditions. It was the blufferavian homeworld. The planet was the location of the high-tech Resinem Entertainment Complex. The bombing of a neighboring rival casino shortly before the Battle of Endor damaged the Complex's west wall, which was further damaged by erosion. The Complex was run by Mazzic. The Mistryl sent Karoly D'ulin to recover Shada D'ukal from the Complex. Shada defeated and escaped from Karoly, fleeing to Coruscant.
