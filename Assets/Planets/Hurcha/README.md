# Hurcha

**Continuity:** Legends  
**Source:** [Hurcha](https://starwars.fandom.com/wiki/Hurcha)
**Galaxy atlas:** system `Hurcha`, Mid Rim — map position (6352.4, -54.1, 147.2)

Hurcha was the eighth planet from the single star of the Churba system. Because of its cold climate and distance from the sun, it was regarded as having no civilized purpose.
