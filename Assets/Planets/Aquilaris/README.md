# Aquilaris

**Continuity:** Legends  
**Source:** [Aquilaris](https://starwars.fandom.com/wiki/Aquilaris)
**Galaxy atlas:** system `Aquilaris`, Outer Rim, grid O-17 — map position (5226.2, -10850.2, 111.1)

Aquilaris was an aquatic planet located in the Sanbra sector of the Outer Rim Territories. Once a flourishing resort world, the planet's economy largely revolved around podracing events by the time of the end of the Golden Age of the Galactic Republic.
