# Bleuf

**Continuity:** Canon  
**Source:** [Bleuf](https://starwars.fandom.com/wiki/Bleuf)

Bleuf was a planet in the Bleuf system of the Core Worlds that was a key manufacturing world for the Galactic Empire. In 4 ABY, after the Battle of Endor, the economist Kriz Tray projected how the fall of the Empire would affect Bleuf's economy, with Tray's data showing that the planet's economy would collapse.
