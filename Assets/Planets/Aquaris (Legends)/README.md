# Aquaris

**Continuity:** Legends  
**Source:** [Aquaris/Legends](https://starwars.fandom.com/wiki/Aquaris/Legends)
**Galaxy atlas:** system `Aquaris`, Expansion Region, grid N-7 — map position (4484.8, 3305.2, -238.2)

Aquaris was an inhabited aquatic planet located in the Cvetaen system of the Expansion Region's Sumitra sector. Devoid of any landmasses, the planet was one large ocean.
