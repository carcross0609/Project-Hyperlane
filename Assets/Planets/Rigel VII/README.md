# Rigel VII

**Continuity:** Legends  
**Source:** [Rigel VII](https://starwars.fandom.com/wiki/Rigel_VII)
**Galaxy atlas:** system `Rigel VII`, Outer Rim, grid U-11 — map position (14436.1, -1779.3, 385.5)

Rigel VII was a heavy-gravity planet in the Outer Rim Territories. Its native sentient species, the hulking Rigellians, were almost extinct at the time of the Galactic Civil War. The planet was also the homeworld of the Rigelian Iris.
