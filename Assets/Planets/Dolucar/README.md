# Dolucar

**Continuity:** Legends  
**Source:** [Dolucar](https://starwars.fandom.com/wiki/Dolucar)
**Galaxy atlas:** system `Dolucar`, Core Worlds — map position (-118.2, 268.8, 16.8)

Dolucar was the sixth planet of the Chandrila system, located in the Bormea sector of the Ringali Shell region of the Core Worlds. Dolucar was a gas giant and orbited the star Chandrila. Twelve moons circled the planet, the most of any planet in the system. The entirety of the Chandrila system lay on the Perlemian Trade Route, which served as a dividing line between the Northern Dependencies and the Arrowhead portion of the Slice.
