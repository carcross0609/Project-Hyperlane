# Rylorii Minor

**Continuity:** Canon  
**Source:** [Rylorii Minor](https://starwars.fandom.com/wiki/Rylorii_Minor)

Rylorii Minor was a neutral mining planet located in the Rylorii Minor system in the Rocantor sector of the Expansion Region. During the Clone Wars, a senator of the Galactic Republic held a meeting with mayor Lup about a trade agreement, which was signed after a failed assassination attempt against Lup.
