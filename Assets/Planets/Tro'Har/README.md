# Tro'Har

**Continuity:** Legends  
**Source:** [Tro'Har](https://starwars.fandom.com/wiki/Tro%27Har)
**Galaxy atlas:** system `Tro'Har`, Outer Rim, grid M-20 — map position (1837.5, -15610.9, -768.3)

Tro'Har was a planet located within the Coyn system of the Outer Rim Territories in the Elrood sector. Covered in methane ice, it boasted a navigation beacon to assist inbound traffic. The name "Tro'Har" meant "Farthest Blade" in the Coynite language.
