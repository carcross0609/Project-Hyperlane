# Carcel

**Continuity:** Legends  
**Source:** [Carcel](https://starwars.fandom.com/wiki/Carcel)
**Galaxy atlas:** system `Carcel`, Expansion Region, grid O-8 — map position (5677.7, 1650.0, 225.0)

Carcel was a planet located in the Expansion Region, and was described by Tobb Jadak as a miserable piece of rock. Carcel had a prison that Jadak and Flitcher Poste visited Rej Taunt in.
