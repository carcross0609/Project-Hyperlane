# Cala

**Continuity:** Legends  
**Source:** [Cala (planet)](https://starwars.fandom.com/wiki/Cala_%28planet%29)

Cala was an airless rock planet with no moons that occupied the third closest orbital position to the star Asar. It was located within the Ilum system, a part of the Unknown Regions' 7G sector.
