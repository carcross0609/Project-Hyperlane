# Pallaxides

**Continuity:** Legends  
**Source:** [Pallaxides](https://starwars.fandom.com/wiki/Pallaxides)
**Galaxy atlas:** system `Pallaxides`, Outer Rim, grid N-7 — map position (3324.1, 4319.0, -158.7)

Pallaxides was a planet of the Ojoster sector in the Outer Rim. It was owned by TaggeCo, who used it as a resort world.
