# Lanjer

**Continuity:** Legends  
**Source:** [Lanjer/Legends](https://starwars.fandom.com/wiki/Lanjer/Legends)

Lanjer was a remote planet that defied Emperor Palpatine shortly after the formation of the Galactic Empire. Like the other worlds that refused to cooperate, Lanjer suffered an unspecified devastation as a result.
