# Deyer

**Continuity:** Canon  
**Source:** [Deyer](https://starwars.fandom.com/wiki/Deyer)
**Galaxy atlas:** system `Deyer`, Outer Rim — map position (-5287.2, -10377.0, 11.7)

Deyer was a planet in the Anoat system in the Anoat sector of the galaxy. For years, Deyer was ruled by the Galactic Empire, which established prisons and outposts on the world. Prior to the Iron Blockade, the Data Seekers, wishing to learn more about the Anoat sector, placed undercover agents within the Empire's ranks, discovering the truths about Imperial workings on Anoat, Deyer's prisons, and more.
