# Nanth'ri

**Continuity:** Canon  
**Source:** [Nanth'ri](https://starwars.fandom.com/wiki/Nanth%27ri)
**Galaxy atlas:** system `Nanth'ri`, Mid Rim, grid Q-12 — map position (7939.3, -3109.3, -151.2)

Nanth'ri was a planet located in the Nanth'ri system in the Kurost sector within the galaxy's Mid Rim. It sat along the Trax Tube hyperspace route and was the western endpoint of the Nanth'ri Trade Route.
