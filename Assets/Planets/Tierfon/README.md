# Tierfon

**Continuity:** Canon  
**Source:** [Tierfon](https://starwars.fandom.com/wiki/Tierfon)
**Galaxy atlas:** system `Tierfon`, Expansion Region, grid O-7 — map position (4984.8, 3168.9, -94.6)

Tierfon was an Expansion Region planet that was home to a Rebel Alliance launch base, an outpost housing at least a hundred rebel pilots. The Tierfon Yellow Aces squadron used the base as its headquarters, defending the outpost and using it for many missions. The rebel activity attracted the Galactic Empire's attention to Tierfon's sector, however, and the increased pressure from Imperial patrols led to the rebels eventually scuttling the launch base and disbanding the Yellow Aces.
