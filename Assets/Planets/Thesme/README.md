# Thesme

**Continuity:** Legends  
**Source:** [Thesme](https://starwars.fandom.com/wiki/Thesme)
**Galaxy atlas:** system `Thesme`, Outer Rim, grid O-5 — map position (5490.9, 6108.5, -156.2)

Thesme was a planet located within the Thesme system of the Outer Rim Territories. An industrial world, it served as the lackluster sector capital of Thesme sector, on the Thesme Trace.
