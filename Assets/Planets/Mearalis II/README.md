# Mearalis II

**Continuity:** Canon  
**Source:** [Mearalis II](https://starwars.fandom.com/wiki/Mearalis_II)

Mearalis II was a planet located in the Mearalis system in the Bri'ahl sector of the Outer Rim Territories. The planet boasted a number of mountain ranges and was the source of varpeline crystals, which could be used as lightsaber crystals.

## Planetary data

- **Name:** Mearalis II
- **Region:** Outer Rim Territories
- **Sector:** Bri'ahl sector
- **System:** Mearalis system
- **Coordinates:** I-17
- **Class:** Terrestrial
