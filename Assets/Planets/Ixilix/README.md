# Ixilix

**Continuity:** Canon  
**Source:** [Ixilix](https://starwars.fandom.com/wiki/Ixilix)

Ixilix was a planet upon which, according to legend, Jedi Master Nil Idyth was killed by an assassin. Idyth's belongings were eventually recovered from Ixilix by a Jedi Order team.
