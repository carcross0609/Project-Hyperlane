# Ambria

**Continuity:** Canon  
**Source:** [Ambria](https://starwars.fandom.com/wiki/Ambria)
**Galaxy atlas:** system `Ambria`, Inner Rim, grid O-10 — map position (5560.6, -213.3, 291.7)

Ambria was an unpleasant desert planet, in tune with the dark side of the Force, that was located in the galaxy's Inner Rim. At some point, a human female was seen beside a lake on Ambria. It was rumored that Darth Bane, creator of the Rule of Two and the Great Plan, was killed by his Sith apprentice Darth Zannah in a duel on Ambria.
