# Vo Tunbren

**Continuity:** Legends  
**Source:** [Vo Tunbren](https://starwars.fandom.com/wiki/Vo_Tunbren)

Vo Tunbren was a planet in the Tadra sector a subsector of the Cegul sector in the Outer Rim Territories. It was the location of an Imperial communications research facility where Jeres Moridon was stationed.
