# Yablari

**Continuity:** Canon  
**Source:** [Yablari](https://starwars.fandom.com/wiki/Yablari)
**Galaxy atlas:** system `Yablari`, Outer Rim, grid R-6 — map position (10206.0, 5842.4, -58.5)

Yablari was a world in the Outer Rim Territories that was the homeworld of the Anomid species. Silvanie Phest led a handful of Anomids from their homeworld to the moon Jedha.
