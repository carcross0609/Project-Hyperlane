# Monhudle

**Continuity:** Legends  
**Source:** [Monhudle](https://starwars.fandom.com/wiki/Monhudle)
**Galaxy atlas:** system `Monhudle`, Outer Rim, grid K-5 — map position (-943.9, 6677.0, 110.7)

Monhudle was a mining planet in the Cassandran sectors region. During the Outer Rim Sieges of the Clone Wars, Jedi General Traavis led clone forces to war against the Separatists on this planet.
