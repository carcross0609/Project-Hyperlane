# Orchis

**Continuity:** Canon  
**Source:** [Orchis](https://starwars.fandom.com/wiki/Orchis)

Orchis was a planet located in the Orchis system of the Inner Rim and New Territories region, in grid square N-8 on the Standard Galactic Grid. In 34 ABY, the historian Eloc Throno included a map with the location of Orchis in his book Traveler's Guide to Batuu, a guide that detailed the planet Batuu. Orchis was located in the same system as the moon Orchis 2, home of the Graf Archive.
