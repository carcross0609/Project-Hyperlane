# Hota

**Continuity:** Legends  
**Source:** [Hota](https://starwars.fandom.com/wiki/Hota)

Hota was the sixth planet orbiting the star Bright Jewel in the Bright Jewel system. Located in the Bright Jewel sector of the Mid Rim, it was a gas giant.
