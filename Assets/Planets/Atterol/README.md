# Atterol

**Continuity:** Legends  
**Source:** [Atterol](https://starwars.fandom.com/wiki/Atterol)

Atterol was a celestial body in the Atterol system. It was near Atterol that the Battle of Atterol took place during the Galactic Civil War.
