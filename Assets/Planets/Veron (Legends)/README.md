# Veron

**Continuity:** Legends  
**Source:** [Veron/Legends](https://starwars.fandom.com/wiki/Veron/Legends)
**Galaxy atlas:** system `Veron`, Mid Rim, grid L-17 — map position (471.7, -11734.9, 95.2)

Veron was an agriworld located in the Veron system of the Senex sector, a part of the Senex-Juvex region in the Western Reaches portion of the Mid Rim. The Senex-Juvex Loop hyperlane linked it to the Cyimarra and Presteen systems, while the Veron Route connected it to the New Cylimba system of the D'Aelgoth sector.

Veron was dominated by nobles of the House Araba, which was based on the nearby planet of Cyimarra. The agriworld shared its name with Veron Minor, a planet in the Mektrun sector.
