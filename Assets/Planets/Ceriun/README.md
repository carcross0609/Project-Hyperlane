# Ceriun

**Continuity:** Legends  
**Source:** [Ceriun](https://starwars.fandom.com/wiki/Ceriun)
**Galaxy atlas:** system `Ceriun`, Outer Rim, grid Q-6 — map position (8154.9, 4919.4, 30.7)

Ceriun was a terrestrial world that was located in the Ceriun system of the Outer Rim Territories. Around 1000 BBY, a tattooed Sith journeyed to the planet to retrieve a Sith holocron that had been taken there by a Jedi.
