# Gabdor

**Continuity:** Canon  
**Source:** [Gabdor](https://starwars.fandom.com/wiki/Gabdor)

Gabdor was a wet terrestrial world located in the Gabdor system of the Expansion Region. It was situated in grid square H-14 of the Standard Galactic Grid. Gabdor was the homeworld of Quiggold, the Gabdorin first mate of the pirate captain Sidon Ithano's crew.
