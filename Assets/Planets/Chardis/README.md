# Chardis

**Continuity:** Canon  
**Source:** [Chardis](https://starwars.fandom.com/wiki/Chardis)

Chardis was a terrestrial planet in the Trilon sector of the Outer Rim Territories. At some point by 382 BBY, Jedi Master Lee Harro lost his starship in a gravity sink on Chardis.
