# Quadrant Seven

**Continuity:** Legends  
**Source:** [Quadrant Seven](https://starwars.fandom.com/wiki/Quadrant_Seven)
**Galaxy atlas:** system `Quadrant Seven`, Mid Rim, grid J-6 — map position (-1568.8, 5185.7, -254.9)

Quadrant Seven was a planet which was not part of the Galactic Republic. The planet's last war took place in about 612 BBY. It was a rocky world with canyons, caves, and hills.
