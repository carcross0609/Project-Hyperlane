# Vor Deo

**Continuity:** Legends  
**Source:** [Vor Deo](https://starwars.fandom.com/wiki/Vor_Deo)
**Galaxy atlas:** system `Vor Deo`, Outer Rim, grid R-17 — map position (9751.4, -10534.7, 175.8)

Vor Deo was an Outer Rim Territories trade world situated in the Arkanis sector. Located on the Old Corellian Run hyperlane and at the endpoint of the Cranan-Excarga Route, during the reign of the Galactic Empire, an increasing number of illegal cargoes smuggled to Vor Deo led the Imperial authorities to concentrate law enforcement efforts there.
