# Enarc

**Continuity:** Legends  
**Source:** [Enarc (Demophon system)](https://starwars.fandom.com/wiki/Enarc_%28Demophon_system%29)
**Galaxy atlas:** system `Enarc`, Mid Rim, grid O-17 — map position (5111.9, -10741.9, -220.7)

Enarc was a planet of the Demophon system. It was a frigid ball of rock. It was destroyed when the star Demophon exploded as a supernova during the Galactic Civil War.
