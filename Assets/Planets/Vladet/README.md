# Vladet

**Continuity:** Legends  
**Source:** [Vladet](https://starwars.fandom.com/wiki/Vladet)
**Galaxy atlas:** system `Vladet`, Colonies, grid N-11 — map position (3216.8, -1944.2, 8.0)

Vladet was a planet in the Colonies. It was the sector capital of Rachuk sector. An Imperial base was located on Grand Isle. Without vaccination, any visitor to the planet would catch Rachuk roseola. When Rogue Squadron attacked the planet, Imperial Admiral Devlia was killed.
