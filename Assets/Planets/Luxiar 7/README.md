# Luxiar 7

**Continuity:** Legends  
**Source:** [Luxiar 7](https://starwars.fandom.com/wiki/Luxiar_7)

Luxiar 7 was a planet located within the Luxiar system of the Outer Rim Territories. There, R'Ytha Myr dated a person called "Ace", most probably Ace Azzameen himself.
