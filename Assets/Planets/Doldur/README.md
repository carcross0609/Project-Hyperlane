# Doldur

**Continuity:** Legends  
**Source:** [Doldur](https://starwars.fandom.com/wiki/Doldur)
**Galaxy atlas:** system `Doldur`, Mid Rim, grid P-15 — map position (6458.0, -7868.6, 90.5)

Doldur was the Imperial-controlled sector capital of Doldur sector. Imperial Moff Eisen Kerioth considered it his personal territory and sponsored research of an antiblaster energy shield.
