# Alaris

**Continuity:** Canon  
**Source:** [Alaris](https://starwars.fandom.com/wiki/Alaris)
**Galaxy atlas:** system `Alaris`, Mid Rim, grid P-9 — map position (6642.2, 817.7, -214.6)

Alaris was a planet of the Mytaranor sector's Kashyyyk system in the galaxy's Mid Rim. One of its moons, Alaris Prime, was home to a colony of Wookiees from the neighboring planet Kashyyyk.
