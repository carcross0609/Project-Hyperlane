# Otunia

**Continuity:** Legends  
**Source:** [Otunia](https://starwars.fandom.com/wiki/Otunia)
**Galaxy atlas:** system `Otunia`, Outer Rim — map position (9404.9, 5686.1, 185.9)

Otunia was a planet that was the Galactic Empire sector capital of the Bosph sector, and the home of the Kabul family. It was covered in deserts and had mineral-rich soil, perfect for mining by Kabul Industries.
