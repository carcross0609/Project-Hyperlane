# Wobani

**Continuity:** Canon  
**Source:** [Wobani](https://starwars.fandom.com/wiki/Wobani)
**Galaxy atlas:** system `Wobani`, Mid Rim, grid R-8 — map position (10039.1, 2863.0, -263.9)

Wobani was a temperate planet partially hidden by a swirling dust cloud, located in the Wobani system, in the Bryx sector of the galaxy's Mid Rim. During the Imperial Era, the planet was used by the Galactic Empire as a site for labor and prison camps.
