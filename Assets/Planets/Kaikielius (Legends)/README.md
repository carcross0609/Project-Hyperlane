# Kaikielius

**Continuity:** Legends  
**Source:** [Kaikielius/Legends](https://starwars.fandom.com/wiki/Kaikielius/Legends)
**Galaxy atlas:** system `Kaikielius`, Core Worlds, grid L-10 — map position (22.1, -150.3, 59.6)

Kaikielius was a planet in the Kaikielius system of the Core Worlds. A regional power before the rise of the Republic and a Core Founder, it was situated on the Koros Trunk Line, just outside of the Deep Core. The planet was the homeworld of the influential political dynasty House Praji.
