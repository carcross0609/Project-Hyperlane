# Poytta

**Continuity:** Legends  
**Source:** [Poytta](https://starwars.fandom.com/wiki/Poytta)
**Galaxy atlas:** system `Poytta`, Hutt Space, grid T-12 — map position (12840.0, -3148.6, 473.1)

Poytta was a planet in Hutt Space along a small hyperspace route situated alongside the Shag Pabol; as such, it was used as a refueling stop by many slavers and smugglers who travelled along the bigger hyperlane. It also served as Tuga SalPivo's base of operations.
