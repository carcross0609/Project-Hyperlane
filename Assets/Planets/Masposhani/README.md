# Masposhani

**Continuity:** Legends  
**Source:** [Masposhani](https://starwars.fandom.com/wiki/Masposhani)

Masposhani was a planet in the Mid Rim. According to Beldorion the Hutt, the Jedi Order had once maintained a training facility in its caves.
