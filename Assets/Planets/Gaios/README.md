# Gaios

**Continuity:** Legends  
**Source:** [Gaios](https://starwars.fandom.com/wiki/Gaios)

Gaios was a planet in the Core Worlds within the grid coordinates K-9. Its philosophers' statement "a seed does not know the flower that produced it," was well known.

- **Region:** Core Worlds
