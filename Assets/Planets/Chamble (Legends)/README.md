# Chamble

**Continuity:** Legends  
**Source:** [Chamble/Legends](https://starwars.fandom.com/wiki/Chamble/Legends)
**Galaxy atlas:** system `Chamble`, Mid Rim, grid Q-10 — map position (7574.8, -195.2, -15.9)

Chamble was a planet in the Mid Rim where Bansche Tech was headquartered. After the Battle of Yavin, the corporation was nationalized by the Empire, dealing a heavy blow to the Ralltiir Exchange.
