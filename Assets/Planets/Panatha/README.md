# Panatha

**Continuity:** Legends  
**Source:** [Panatha](https://starwars.fandom.com/wiki/Panatha)
**Galaxy atlas:** system `Panatha`, Outer Rim, grid H-16 — map position (-5827.0, -9390.3, 20.9)

Panatha, also known as Epicanthix was a jungle planet in the Pacanth Reach in the Outer Rim Territories. It was the homeworld of the Epicanthix. It was close to the Unknown Regions.
