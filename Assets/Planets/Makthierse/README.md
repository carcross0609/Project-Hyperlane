# Makthierse

**Continuity:** Legends  
**Source:** [Makthierse](https://starwars.fandom.com/wiki/Makthierse)

Makthierse was a colony world noted for ranches, farms, crystal caves, and Quantrax Creek. Native creatures included lacas and preying makthiers.
