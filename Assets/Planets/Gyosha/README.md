# Gyosha

**Continuity:** Legends  
**Source:** [Gyosha](https://starwars.fandom.com/wiki/Gyosha)
**Galaxy atlas:** system `Gyosha`, Core Worlds — map position (-2094.8, -4060.3, 159.0)

Gyosha was an Imperial resort world in the Galactic Core. Wilek Nereus had hoped to be appointed Governor of Gyosha, but got stuck on Bakura instead. OrulShai III was a moon of Gyosha.
