# Risban

**Continuity:** Legends  
**Source:** [Risban](https://starwars.fandom.com/wiki/Risban)
**Galaxy atlas:** system `Risban`, Outer Rim, grid S-5 — map position (11217.4, 6803.2, 11.8)

Risban was a planet in the Tion Hegemony, and the location of the river town Keremark. The town was ruled by the Neolsse family, who opposed Imperial subjugation from Fortress Keremark.
