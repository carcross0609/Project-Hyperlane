# Kiros

**Continuity:** Legends  
**Source:** [Kiros/Legends](https://starwars.fandom.com/wiki/Kiros/Legends)
**Galaxy atlas:** system `Kiros`, Expansion Region, grid L-8 — map position (1100.8, 2688.6, -102.0)

Kiros was an idyllic world filled with vast green valleys and flowing waterfalls. Located in the Expansion Region, the planet served as the site of a colony of Togruta artists.
