# Ediorung

**Continuity:** Legends  
**Source:** [Ediorung](https://starwars.fandom.com/wiki/Ediorung)
**Galaxy atlas:** system `Ediorung`, Inner Rim, grid O-9 — map position (5241.6, 842.9, 128.8)

Ediorung was a planet in the Interior Regions of the Hapes Cluster. The planet was known for the dynamic holosculptures it produced; however, these were strictly judged by the Commission for the Preservation of the New Order Art Group. Porcellus, the chef for Jabba the Hutt, occasionally prepared Ediorung icefish for his master.
