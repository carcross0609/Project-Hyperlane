# Lamuir IV

**Continuity:** Legends  
**Source:** [Lamuir IV](https://starwars.fandom.com/wiki/Lamuir_IV)
**Galaxy atlas:** system `Lamuir IV`, Colonies — map position (4342.1, -1127.0, -13.2)

Lamuir IV was a planet in the Tapani sector's Freeworlds Territory. It was formerly part of the Herglic Trade Empire. The Priole Danna Festival was held there.

Lamuir IV was a voting member of the League of Tapani Freeworlds.
