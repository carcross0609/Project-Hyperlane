# Wielu

**Continuity:** Legends  
**Source:** [Wielu](https://starwars.fandom.com/wiki/Wielu)
**Galaxy atlas:** system `Wielu`, Inner Rim, grid N-13 — map position (4186.6, -4767.4, -152.2)

Wielu was a planet in the galaxy with two suns, and was well known for its famous beaches and thriving black market. During the Clone Wars, Obi-Wan Kenobi, Anakin Skywalker and Ahsoka Tano briefly vacationed here.
