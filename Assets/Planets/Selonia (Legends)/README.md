# Selonia

**Continuity:** Legends  
**Source:** [Selonia/Legends](https://starwars.fandom.com/wiki/Selonia/Legends)
**Galaxy atlas:** system `Selonia`, Core Worlds, grid M-11 — map position (2754.4, -1787.3, -140.3)

Selonia was an oceanic planet in the Corellian system. It was one of the Five Brothers, and the homeworld of the Selonian race.
