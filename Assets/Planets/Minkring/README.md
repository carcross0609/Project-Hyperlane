# Minkring

**Continuity:** Legends  
**Source:** [Minkring](https://starwars.fandom.com/wiki/Minkring)

Minkring was a planet in the Shelsha sector. By 0.5 ABY it was home to one of the only two remaining Imperial army garrisons in the sector (the other being located on Chaastern 4).
