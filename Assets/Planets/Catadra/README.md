# Catadra

**Continuity:** Canon  
**Source:** [Catadra](https://starwars.fandom.com/wiki/Catadra)

Catadra was a temple world located in the Deep Core's Cerberon system. It was home to a number of religious cults, the most notable of which was the Children of the Empty Sun.
