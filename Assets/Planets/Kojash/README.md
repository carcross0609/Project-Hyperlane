# Kojash

**Continuity:** Legends  
**Source:** [Kojash](https://starwars.fandom.com/wiki/Kojash)
**Galaxy atlas:** system `Kojash`, Deep Core — map position (1174.6, -1053.7, -77.8)

Kojash was one of two mining colonies on the perimeter of the Koornacht Cluster, founded by the Morath. Along with the other settlement on Elcorth, it was conquered and depopulated by the Yevetha during the Great Purge.
