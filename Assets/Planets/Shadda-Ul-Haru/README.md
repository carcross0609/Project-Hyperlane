# Shadda-Ul-Haru

**Continuity:** Legends  
**Source:** [Shadda-Ul-Haru](https://starwars.fandom.com/wiki/Shadda-Ul-Haru)

Shadda-Ul-Haru was the fourth planet orbiting the star Shadda in the Shadda-Bi-Boran system. Located in the Toblain sector of the Outer Rim Territories, it was a gas giant.
