# Callonia

**Continuity:** Legends  
**Source:** [Callonia](https://starwars.fandom.com/wiki/Callonia)
**Galaxy atlas:** system `Callonia`, Inner Rim, grid K-9 — map position (-616.1, 1166.3, -6.6)

Callonia was a planet in the Fakir sector of the Colonies. The GX1 Short Hauler, Long Shot, originally belonging to an Imperial admiral, was stolen by Reekeene's Roughnecks at Callonia's spaceport.
