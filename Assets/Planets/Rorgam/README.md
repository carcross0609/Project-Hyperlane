# Rorgam

**Continuity:** Legends  
**Source:** [Rorgam](https://starwars.fandom.com/wiki/Rorgam)
**Galaxy atlas:** system `Rorgam`, Mid Rim, grid P-10 — map position (7487.1, -376.1, 114.2)

Rorgam was a Mid Rim planet whose population consisted mainly of immigrants from other planets. Many of the world's elite were known to wear wrapped cloth headpieces.
