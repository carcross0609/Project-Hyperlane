# Sposia

**Continuity:** Legends  
**Source:** [Sposia/Legends](https://starwars.fandom.com/wiki/Sposia/Legends)
**Galaxy atlas:** system `Sposia`, Unknown Regions, grid F-8 — map position (-8878.5, 2131.3, -64.1)

Sposia was a planet located in the Sposia system of the Unknown Regions' Chiss Space. The hyperlane known as the Path of the Houses linked it to the Csilla and Naporar systems. Sposia was home to House Sabosen, one of the Ruling Families of the sentient Chiss species, and it was the site of the Chiss Ascendancy's top academies and medcenters.
