# Hutlar

**Continuity:** Legends  
**Source:** [Hutlar](https://starwars.fandom.com/wiki/Hutlar)
**Galaxy atlas:** system `Hutlar`, Mid Rim, grid L-18 — map position (567.2, -12007.6, -107.6)

Hutlar was a small, chilly world located in the Mid Rim's Senex sector. Orbiting a red dwarf star, it was the homeworld of the sentient Hutlarians. They served the aristocratic Ancient Houses of the Senex-Juvex region in various roles until 553 BBY, when their home was liberated from the nobles' control.
