# Sibensko

**Continuity:** Canon  
**Source:** [Sibensko](https://starwars.fandom.com/wiki/Sibensko)
**Galaxy atlas:** system `Sibensko`, Expansion Region — map position (-3565.3, 2554.5, 134.4)

Sibensko was an aquatic planet in the Sibensko system in the Bes Ber Bikade sector of the Expansion Region, situated along the Corellian Trade Spine between Cymoon and Kinyen. It was in an area affiliated with the Centrists, and it was one of the planets on which cartel leader Rinnrivin Di operated.
