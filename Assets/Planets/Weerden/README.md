# Weerden

**Continuity:** Legends  
**Source:** [Weerden](https://starwars.fandom.com/wiki/Weerden)
**Galaxy atlas:** system `Weerden`, Core Worlds, grid K-9 — map position (-206.5, 271.1, -0.3)

Weerden was an Imperial planet located within the Weerden system of the Core Worlds, near Coruscant. It was here that an assassin droid killed Grand Inquisitor Laddinare Torbin by crashing his shuttle, Sark-I into Torbin's palace.
