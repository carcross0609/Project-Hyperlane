# Ord Cestus

**Continuity:** Canon  
**Source:** [Ord Cestus](https://starwars.fandom.com/wiki/Ord_Cestus)
**Galaxy atlas:** system `Ord Cestus`, Outer Rim, grid O-6 — map position (4935.8, 5860.7, -430.9)

Ord Cestus, also referred to as simply Cestus, was a planet in the D'Astan sector of the Outer Rim Territories. Located in the vicinity of the Perlemian Trade Route, it was situated a considerable distance away from common routes between Geonosis and Coruscant. During the Clone Wars, the Galactic Republic established a medical station near Ord Cestus.
