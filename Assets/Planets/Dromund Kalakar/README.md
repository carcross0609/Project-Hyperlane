# Dromund Kalakar

**Continuity:** Legends  
**Source:** [Dromund Kalakar](https://starwars.fandom.com/wiki/Dromund_Kalakar)

Dromund Kalakar was a gas giant in the Dromund system. Its shipyards produced the VX-9 Mailoc gunship and F-T2 Quell, FT-3C Imperium and F-T6 Rycer strike fighters for the Sith Empire.
