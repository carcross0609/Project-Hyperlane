# Affadar

**Continuity:** Canon  
**Source:** [Affadar](https://starwars.fandom.com/wiki/Affadar)
**Galaxy atlas:** system `Affadar`, Other, grid M-13 — map position (2658.7, -5524.7, 9.4)

Affadar was a largely undeveloped planet in the galaxy that was the homeworld of the T'Laeem, a sentient but primitive amphibian species. Shortly after the Battle of Yavin, the Galactic Empire set up a mining operation on the planet.
