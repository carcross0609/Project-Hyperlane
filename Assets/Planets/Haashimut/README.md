# Haashimut

**Continuity:** Legends  
**Source:** [Haashimut](https://starwars.fandom.com/wiki/Haashimut)
**Galaxy atlas:** system `Haashimut`, Outer Rim — map position (8445.1, 6848.4, -522.4)

Haashimut was an Outer Rim planet. It was a Republic fortress world colonized c. 24,000 BBY from which the Jedi kept a watchful eye on the hostile Tion Cluster from their stronghold there.
