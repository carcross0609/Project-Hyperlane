# Havath Minor

**Continuity:** Legends  
**Source:** [Havath Minor](https://starwars.fandom.com/wiki/Havath_Minor)
**Galaxy atlas:** system `Havath Minor`, Outer Rim — map position (6835.3, 5542.0, 280.6)

Havath Minor was the fifth planet in the Muunilinst system. It was a gas giant inferior in size to Havath Prime and was orbited by 11 moons.
