# Pirralor

**Continuity:** Legends  
**Source:** [Pirralor](https://starwars.fandom.com/wiki/Pirralor)
**Galaxy atlas:** system `Pirralor`, Mid Rim, grid L-18 — map position (88.3, -12106.4, 179.7)

Pirralor was a planet located in the Pirralor system of the Juvex sector, in the Mid Rim of the galaxy. It was the homeworld of House Pilor, and its spaceports were thick with outsiders from the Ninth Quadrant and the Agarix sector. Imperial Captain Dor Reder hailed from Pirralor.
