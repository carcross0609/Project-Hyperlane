# Orinda

**Continuity:** Legends  
**Source:** [Orinda/Legends](https://starwars.fandom.com/wiki/Orinda/Legends)
**Galaxy atlas:** system `Orinda`, Mid Rim, grid K-6 — map position (-393.5, 5239.7, -63.2)

Orinda was a planet in the Irishi sector of the galaxy's Mid Rim. It was located along the Entralla Route. Orinda was on the border of the Mid Rim and the Outer Rim Territories.
