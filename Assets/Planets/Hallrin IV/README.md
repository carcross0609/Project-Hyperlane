# Hallrin IV

**Continuity:** Legends  
**Source:** [Hallrin IV](https://starwars.fandom.com/wiki/Hallrin_IV)
**Galaxy atlas:** system `Hallrin IV`, Mid Rim — map position (4325.5, -9978.9, -407.6)

Hallrin IV was an Expansion Region world in the Hallrin system. The Stratis Games, including the Multi-Sentient Unarmed Combat Rounds, were held on Hallrin IV. Clyngunn represented the ZeHethbra in these Rounds.
