# Zastiga

**Continuity:** Canon  
**Source:** [Zastiga](https://starwars.fandom.com/wiki/Zastiga)
**Galaxy atlas:** system `Zastiga`, Outer Rim, grid M-12 — map position (1981.7, -4000.8, -143.8)

Zastiga was a planet in the Zastiga system in the Kallea sector on the edge of the Outer Rim Territories, frequented by traders. It was the location of a secret Rebel Alliance meeting where Chancellor Mon Mothma and Admiral Gial Ackbar revealed to senior Rebel leaders that the Galactic Empire was constructing a second Death Star.
