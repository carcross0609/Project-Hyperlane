# Renforra

**Continuity:** Legends  
**Source:** [Renforra](https://starwars.fandom.com/wiki/Renforra)
**Galaxy atlas:** system `Renforra`, Outer Rim, grid K-20 — map position (-1307.1, -15573.2, -673.9)

Renforra was the site of an Alliance to Restore the Republic base during the height of the Galactic Civil War. Jon Vander led the BTL Y-wing starfighters of Specter Squadron from this headquarters.
