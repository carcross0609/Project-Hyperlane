# Procopia

**Continuity:** Canon  
**Source:** [Procopia](https://starwars.fandom.com/wiki/Procopia)
**Galaxy atlas:** system `Procopia`, Colonies, grid L-13 — map position (837.6, -4813.4, 42.6)

Procopia was the capital world of the Tapani sector of the Colonies. It was located in the Procopia system in grid square L-13 of the Standard Galactic Grid. At some point, House Reena hosted the Tapani Open on Procopia.
