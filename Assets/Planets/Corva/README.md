# Corva

**Continuity:** Legends  
**Source:** [Corva](https://starwars.fandom.com/wiki/Corva)
**Galaxy atlas:** system `Corva`, Outer Rim, grid P-4 — map position (7106.5, 7667.2, 495.1)

Corva was a planet in Corva sector's Galaan system. The Galactic Republic established a colony on the planet which was wiped out by clodhoppers which arrived in a grain shipment from Naboo. The clodhoppers ate all the vegetation on Corva as well as 87% of the colonists.
