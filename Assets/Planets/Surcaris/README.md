# Surcaris

**Continuity:** Legends  
**Source:** [Surcaris](https://starwars.fandom.com/wiki/Surcaris)
**Galaxy atlas:** system `Surcaris`, Mid Rim, grid O-7 — map position (4868.9, 3347.4, 9.0)

Surcaris was a planet in the Mid Rim's Trans-Vulta sector where a group of Mandalorian mercenaries, possibly under Munin Skirata, fought. It was also the location where Munin found a young Kal Skirata.
