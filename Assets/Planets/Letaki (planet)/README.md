# Letaki

**Continuity:** Legends  
**Source:** [Letaki (planet)](https://starwars.fandom.com/wiki/Letaki_%28planet%29)

Letaki was a planet in the Letaki system of Steniplis sector in the Outer Rim Territories. It was the homeworld of Evar Orbus, a member of the eponymous species.
