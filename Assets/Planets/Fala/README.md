# Fala

**Continuity:** Legends  
**Source:** [Fala](https://starwars.fandom.com/wiki/Fala)

Fala was the second planet of the Bestine system located in the Inner Rim Territories. Fala had one moon, and its surface was covered with volcanic rocks.
