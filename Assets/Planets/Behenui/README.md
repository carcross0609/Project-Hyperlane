# Behenui

**Continuity:** Legends  
**Source:** [Behenui](https://starwars.fandom.com/wiki/Behenui)
**Galaxy atlas:** system `Behenui`, Outer Rim, grid O-17 — map position (5130.8, -11725.2, -23.7)

Behenui was a planet in the fifth orbit around the star Beheboth. It was the only gas giant in the Beheboth system, which was located in the Sanbra sector, a part of the Trailing Sectors portion of the Outer Rim Territories. Behenui itself was circled by nine moons.
