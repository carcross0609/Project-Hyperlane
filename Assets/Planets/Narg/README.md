# Narg

**Continuity:** Legends  
**Source:** [Narg](https://starwars.fandom.com/wiki/Narg)
**Galaxy atlas:** system `Narg`, Outer Rim — map position (4764.3, 8542.2, 51.8)

Narg was an isolated planet in the Rayter sector of the Outer Rim Territories. Its Human inhabitants were known to be xenophobic. During the Galactic Civil War, the planet was controlled by TransGalMeg Industries, Incorporated.
