# Ilos

**Continuity:** Legends  
**Source:** [Ilos](https://starwars.fandom.com/wiki/Ilos)
**Galaxy atlas:** system `Ilos`, Hutt Space, grid R-10 — map position (10167.9, -395.3, 25.3)

Ilos was a bland agricultural world dotted with cities. It was located within the Ilos system of the galaxy's Hutt Space region and lay on the hyperlane called the Pabol Sleheyron, which connected it to the planets of Chalacta and Ilos Minor.

Ilos was the homeworld of the sentient Ilosian species, and millennia before the Battle of Yavin, the Ilosians ventured offworld and colonized hundreds of nearby planets.
