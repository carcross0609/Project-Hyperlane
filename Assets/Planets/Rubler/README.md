# Rubler

**Continuity:** Legends  
**Source:** [Rubler](https://starwars.fandom.com/wiki/Rubler)

Rubler was the eighth and outermost planet of the Bestine system located in the Inner Rim Territories. Rubler was one of the three gas giants in the star system and had twenty-nine moons.
