# Mulchoop

**Continuity:** Legends  
**Source:** [Mulchoop](https://starwars.fandom.com/wiki/Mulchoop)

Mulchoop was the fifth planet orbiting the star Prael in the Japrael system. Located in the Japrael sector of the Inner Rim, it was a gas giant.
