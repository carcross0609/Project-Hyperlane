# Therezar

**Continuity:** Canon  
**Source:** [Therezar](https://starwars.fandom.com/wiki/Therezar)

Therezar was a gas giant located in the Therezar system. The station Nightside was located in a fixed orbit of Therezar within the planet's ring system.
