# Ultaar

**Continuity:** Legends  
**Source:** [Ultaar/Legends](https://starwars.fandom.com/wiki/Ultaar/Legends)
**Galaxy atlas:** system `Ultaar`, Mid Rim, grid R-8 — map position (9694.1, 2246.0, 183.6)

Ultaar was a planet in the Mid Rim Bortele sector, covered in jungles of towering giant blossoms that covered the world with a thick scent. Ultaar was home to the four-armed sentient species known as the Ultaarian Greenback. During the Galactic Civil War, Ultaar became host to a small Rebel Alliance presence, which was wiped out in 0 ABY by cyborg bounty hunter Beilert Valance.
