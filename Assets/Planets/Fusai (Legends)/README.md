# Fusai

**Continuity:** Legends  
**Source:** [Fusai/Legends](https://starwars.fandom.com/wiki/Fusai/Legends)
**Galaxy atlas:** system `Fusai`, Outer Rim, grid H-16 — map position (-5375.8, -10398.9, 6.9)

Fusai was a planet in the remote Fusai sector. It was the location of a branch of the Obroa-skai library, where a BRT supercomputer called Mistress Mnemos was installed about 200 BBY. Although Obroa-skai closed the branch, it was maintained locally. Fusai became a Rebel Alliance safe world, and it was here C-3PO reported to Mistress Mnemos the incidents that occurred to Luke Skywalker and Leia Organa on Vorzyd V, where they faced the minion of Blackhole. In addition to recording mission details, Mistress Mnemos helped the Alliance with tactics and long-term planning.
