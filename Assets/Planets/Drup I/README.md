# Drup I

**Continuity:** Legends  
**Source:** [Drup I](https://starwars.fandom.com/wiki/Drup_I)
**Galaxy atlas:** system `Drup I`, Outer Rim — map position (-1098.6, -13019.1, 248.1)

Drup I was a searing hot rock planet devoid of moons. It occupied the closest orbital position around the binary stars Drup's Star and Drup's Companion in the Drup's Star system, a part of the Outer Rim Territories' Saijo sector.
