# Ques

**Continuity:** Legends  
**Source:** [Ques/Legends](https://starwars.fandom.com/wiki/Ques/Legends)
**Galaxy atlas:** system `Ques`, Hutt Space, grid S-8 — map position (11637.0, 1545.9, 48.2)

Ques was a planet in the Ques system in Hutt Space.

Ques was located in a system between Sriluur and the Si'Klaata Cluster, along the Ac'fren Spur of the Sisar Run. It was the connecting point for ships traveling from Varl toward the Sisar Run.

It was a motley spaceport planet at the edge of Hutt Space, typically used by ships heading for the Si'Klaata Cluster. Outlanders landing at Ques were interrogated extensively, as the Cluster was restricted to Outlanders.
