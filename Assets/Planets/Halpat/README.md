# Halpat

**Continuity:** Legends  
**Source:** [Halpat](https://starwars.fandom.com/wiki/Halpat)
**Galaxy atlas:** system `Halpat`, Core Worlds — map position (889.1, -81.3, 28.8)

Halpat was a planet in the Core Worlds, not far from the Koornacht Cluster. It was the New Republic supply depot for the New Republic Fifth Battle Group's blockade of the Cluster. Etahn A'baht did not consider it close enough to the Cluster.
