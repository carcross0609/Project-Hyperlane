# Teriona

**Continuity:** Canon  
**Source:** [Teriona](https://starwars.fandom.com/wiki/Teriona)

Teriona was a small, forested planet located in the Mid Rim Territories. Despite it being along several major trade routes, long history of war and violence kept it from being considered useful by the Galactic Republic.
