# Onderon

**Continuity:** Legends  
**Source:** [Onderon/Legends](https://starwars.fandom.com/wiki/Onderon/Legends)

One of eight planets in the Japrael system, Onderon had a temperate climate, and was once home to a primitive race of Humanoids.
