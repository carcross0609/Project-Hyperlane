# Ruul

**Continuity:** Legends  
**Source:** [Ruul (planet)](https://starwars.fandom.com/wiki/Ruul_%28planet%29)
**Galaxy atlas:** system `Ruul`, Core Worlds, grid M-10 — map position (2153.6, -1455.1, -26.9)

Ruul was a planet in the Ruul system of the Core Worlds. It fell into the hands of the Galactic Empire, which imported Human prisoners to the planet and strip-mined it.
