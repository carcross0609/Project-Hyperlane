# Inusagi

**Continuity:** Canon  
**Source:** [Inusagi](https://starwars.fandom.com/wiki/Inusagi)
**Galaxy atlas:** system `Inusagi`, Mid Rim, grid S-15 — map position (11591.4, -8380.6, 267.5)
