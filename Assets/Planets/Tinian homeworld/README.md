# Tinian homeworld

**Continuity:** Canon  
**Source:** [Tinian homeworld](https://starwars.fandom.com/wiki/Tinian_homeworld)

A planet in the Tinia system in the Zeemacht Cluster of the Inner Rim Territories was inhabited by a species known as the Tinians. Around 2000 BBY the Tinians forged the Tinian Codex on the planet.
