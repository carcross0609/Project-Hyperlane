# Axxila

**Continuity:** Canon  
**Source:** [Axxila](https://starwars.fandom.com/wiki/Axxila)
**Galaxy atlas:** system `Axxila`, Outer Rim, grid O-5 — map position (4695.2, 6230.0, -153.0)

Axxila was a sparsely-populated terrestrial planet located in the D'Astan sector of the Outer Rim Territories. An exporter of ores, the once prosperous world eventually fell into obscurity after outside forces like the Galactic Empire engaged in strip mining operations. Axxila was the homeworld of Imperial Admiral Firmus Piett.
