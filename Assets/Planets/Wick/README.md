# Wick

**Continuity:** Canon  
**Source:** [Wick](https://starwars.fandom.com/wiki/Wick)

Wick was a planet located in the Wick system of the Instrop sector, a part of the Outer Rim Territories and the Slice. It was situated in grid square S-16 of the Standard Galactic Grid and shared its name with the celestial body Wick 111 that was situated in the same star system. The historian Eloc Throno eventually noted Wick's position on a galactic map included in his book Traveler's Guide to Batuu, which was published in 34 ABY.
