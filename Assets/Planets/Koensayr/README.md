# Koensayr

**Continuity:** Legends  
**Source:** [Koensayr](https://starwars.fandom.com/wiki/Koensayr)
**Galaxy atlas:** system `Koensayr`, Colonies, grid N-12 — map position (3154.0, -3619.7, 9.5)

Koensayr was a planet in the Colonies region. It was the headquarters of Koensayr Manufacturing. A Gran colony, in addition to industrializing most of the planet, the lower latitudes contain a small, seaside tourism industry, with vibrant colorful sunsets being a standout feature.
