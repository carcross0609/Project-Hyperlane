# Ajara

**Continuity:** Canon  
**Source:** [Ajara](https://starwars.fandom.com/wiki/Ajara)

Ajara was a gas giant planet located in the Ajara system within the Cademimu sector of the galaxy's Outer Rim Territories, situated in a partially explored region of space off the Celanon Spur. It was orbited by the much smaller jungle moon Ajan Kloss, which had two moons itself. Ajara's intense magnetic field shielded Ajan Kloss from cosmic radiation.
