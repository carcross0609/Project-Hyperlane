# Bortras

**Continuity:** Legends  
**Source:** [Bortras](https://starwars.fandom.com/wiki/Bortras)
**Galaxy atlas:** system `Bortras`, Outer Rim, grid M-18 — map position (2165.0, -12138.5, -462.2)

Bortras was a tranquil world of lush valleys and fertile landscapes in the Brema sector of the Outer Rim Territories. It was known as the home planet of Jedi Master Jorus C'baoth.
