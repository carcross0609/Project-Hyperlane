# Birsingrial

**Continuity:** Legends  
**Source:** [Birsingrial](https://starwars.fandom.com/wiki/Birsingrial)

Birsingrial was a Core Worlds planet known for its jewel-caves. Besany Wennen's family once went there on a vacation when she was about ten years old.
