# Dallenor

**Continuity:** Canon  
**Source:** [Dallenor](https://starwars.fandom.com/wiki/Dallenor)
**Galaxy atlas:** system `Dallenor`, Mid Rim — map position (-1073.1, 3544.4, -83.8)

Dallenor was a desert planet located in the Aldino sector of the Mid Rim. An excavation led by the archaeologist Clatriffe discovered a Jedi holocron on the planet, notifying the Jedi Order. To inspect the holocron, Obi-Wan Kenobi and Anakin Skywalker traveled to Dallenor on behalf of the Jedi Council.
