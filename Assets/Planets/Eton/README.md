# Eton

**Continuity:** Legends  
**Source:** [Eton](https://starwars.fandom.com/wiki/Eton)

Eton was a gas giant–type planet with forty-one moons that occupied the seventh orbital position around the star Asar. It was located within the Ilum system, a part of the Unknown Regions' 7G sector.
