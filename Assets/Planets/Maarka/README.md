# Maarka

**Continuity:** Legends  
**Source:** [Maarka](https://starwars.fandom.com/wiki/Maarka)

Maarka was a planet located in the Perkell sector of the Mid Rim. During the Clone Wars, it was the site of a Republic base. While on a mission to deliver a data file with important intelligence for the Republic base on Maarka, Ahsoka Tano was ambushed by six Vulture droid starfighters in an asteroid field near the planet.
