# Mapuzo

**Continuity:** Legends  
**Source:** [Mapuzo/Legends](https://starwars.fandom.com/wiki/Mapuzo/Legends)
**Galaxy atlas:** system `Mapuzo`, Mid Rim — map position (8482.6, -7967.3, 270.8)

Mapuzo was a world located in the Mapuzo system in the Hollan sector, which lay in the New Territories portion of the Mid Rim. Via a hyperlane, Mapuzo was connected to the Nicandra system in the Nicandra sector and the Walin'or system in the Shiwal sector.

Mapuzo was the site of the Mapuzo break-in, which occurred sometime by 2 ABY. In 12 ABY, during the Orinda campaign by the Imperial Remnant, Mapuzo lay within the territory of the New Republic.
