# Simang

**Continuity:** Legends  
**Source:** [Simang](https://starwars.fandom.com/wiki/Simang)

Simang was the seventh planet orbiting the star Tive in the Taanab system. Located in the Inner Rim Territories, it was a gas giant with twelve moons.
