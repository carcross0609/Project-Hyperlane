# Anantapar

**Continuity:** Legends  
**Source:** [Anantapar/Legends](https://starwars.fandom.com/wiki/Anantapar/Legends)
**Galaxy atlas:** system `Anantapar`, Outer Rim, grid K-18 — map position (-1314.1, -12967.7, -256.6)

Anantapar was a tropical Outer Rim Territories waterworld located in the Yarith sector. Situated on the Corellian Trade Spine hyperlane, it had a primitive ecosystem that was based around shellfish and featured relatively small creatures.
