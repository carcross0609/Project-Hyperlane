# Zolan

**Continuity:** Canon  
**Source:** [Zolan](https://starwars.fandom.com/wiki/Zolan)
**Galaxy atlas:** system `Zolan`, Mid Rim, grid P-16 — map position (7065.6, -9417.2, -272.0)

Zolan was a planet located in the Zolan system in the Lambda sector of the Mid Rim Territories. It was the homeworld of the sentient reptilian Clawdite species, recognized throughout the galaxy for their innate shape-changing abilities.
