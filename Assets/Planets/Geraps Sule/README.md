# Geraps Sule

**Continuity:** Legends  
**Source:** [Geraps Sule](https://starwars.fandom.com/wiki/Geraps_Sule)

Geraps Sule was a gas giant–type planet with eleven moons that occupied the sixth orbital position around the star Abo. It was located within the Lehon system, a part of the Unknown Regions' area known as the Tempered Wastes.
