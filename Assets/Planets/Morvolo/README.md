# Morvolo

**Continuity:** Legends  
**Source:** [Morvolo](https://starwars.fandom.com/wiki/Morvolo)

Morvolo was the fourth planet orbiting the star Prael in the Japrael system. Located in the Japrael sector of the Inner Rim, it was made almost entirely of ice.
