# Worosta

**Continuity:** Canon  
**Source:** [Worosta](https://starwars.fandom.com/wiki/Worosta)

Worosta was a terrestrial planet in the galaxy that was aligned with the Galactic Republic. During the Clone Wars, it was invaded by the Confederacy of Independent Systems, and the Separatists' exploitation of the world continued under the rule of the Galactic Empire. The journalist Ricta Varsh visited Worosta long before the Clone Wars, and Taylo Mor grew up on Worosta.
