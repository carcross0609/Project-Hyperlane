# Ryndellia

**Continuity:** Legends  
**Source:** [Ryndellia/Legends](https://starwars.fandom.com/wiki/Ryndellia/Legends)
**Galaxy atlas:** system `Ryndellia`, Mid Rim, grid O-17 — map position (5655.1, -10591.8, 182.6)

Ryndellia was a celestial object in the Ryndellia system, in the Mid Rim's Ryndellian sector, close to the Outer Rim Territories. It was also close to the Kaliida Shoals Medical Center and the planet Naboo.

During the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems, the Subjugator-class heavy cruiser Malevolence destroyed a Republic medical convoy near Ryndellia.
