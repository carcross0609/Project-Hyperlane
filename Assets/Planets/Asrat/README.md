# Asrat

**Continuity:** Legends  
**Source:** [Asrat](https://starwars.fandom.com/wiki/Asrat)
**Galaxy atlas:** system `Asrat`, Inner Rim, grid N-8 — map position (4079.2, 2350.6, 113.7)

Asrat was a planet where the Holy Children of Asrat were worshiped. The Children opposed the New Order and were targeted for assassination by the Galactic Empire. Dengar left service as an Imperial assassin rather than kill the Children.
