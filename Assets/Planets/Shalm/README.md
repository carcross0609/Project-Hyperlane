# Shalm

**Continuity:** Legends  
**Source:** [Shalm](https://starwars.fandom.com/wiki/Shalm)
**Galaxy atlas:** system `Shalm`, Outer Rim, grid H-16 — map position (-5396.6, -10256.5, 329.3)

Shalm was the planet where Mount Ganton was located, the highest mountain in its range. An Imperial garrison on the western face of Ganton was abandoned after the Battle of Endor, only to become the base of the Pendarran's Revenge, led by Kolor Delan.
