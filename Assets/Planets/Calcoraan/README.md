# Calcoraan

**Continuity:** Canon  
**Source:** [Calcoraan](https://starwars.fandom.com/wiki/Calcoraan)
**Galaxy atlas:** system `Calcoraan`, Inner Rim, grid K-15 — map position (-313.6, -8144.7, -175.8)

Calcoraan was a planet located in the Calcoraan system in the Inner Rim. It was entirely covered by an ocean made out of chromyl chloride, which gave the planet its blood red color, mixed with several other acids, making it uninhabitable. However, substances in both the planetary ocean and the ocean floor had uses in manufacturing, resulting in the construction of multiple space stations in Calcoraan's orbit. Count Denetrius Vidian had a storage facility orbiting this planet.
