# Zaloriis

**Continuity:** Legends  
**Source:** [Zaloriis/Legends](https://starwars.fandom.com/wiki/Zaloriis/Legends)
**Galaxy atlas:** system `Zaloriis`, Expansion Region, grid P-12 — map position (6090.0, -3344.9, -69.1)

Zaloriis was an Expansion Region planet colonized by Humans from Fondor. By 0 ABY it was home to Camp Culroon, a hidden Galactic Empire research base. That year, the planet attempted to join the Rebel Alliance, but Darth Vader led a strike force to recapture the planet.
