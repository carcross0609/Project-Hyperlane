# Zoge Ver

**Continuity:** Legends  
**Source:** [Zoge Ver](https://starwars.fandom.com/wiki/Zoge_Ver)

Zoge Ver was the second planet orbiting the star Rek in the Guter Wade system. Located in the Trilon sector of the Outer Rim, it was a sulfuric rock.
