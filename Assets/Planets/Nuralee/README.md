# Nuralee

**Continuity:** Legends  
**Source:** [Nuralee](https://starwars.fandom.com/wiki/Nuralee)
**Galaxy atlas:** system `Nuralee`, Mid Rim, grid N-16 — map position (3661.0, -9467.3, -210.8)

Nuralee was a Mid Rim world in the Tyus sector. It had an economic breakdown shortly before the Clone Wars. It was represented in the Galactic Senate by Bog Divinian, a wealthy landowner with ties to the Commerce Guild.

In the years following the Invasion of Naboo, Senator Divinian's wife, Astri Oddo, set up a relief movement on Nuralee to petition the Galactic Republic for financial assistance. Oddo hoped the passage of the All Planets Relief Fund in the Senate would alleviate Nuralee's situation.
