# Noe'ha'on

**Continuity:** Canon  
**Source:** [Noe'ha'on](https://starwars.fandom.com/wiki/Noe%27ha%27on)
**Galaxy atlas:** system `Noe'ha'on`, Expansion Region, grid K-16 — map position (-1242.0, -9345.5, -138.0)

Noe'ha'on was a jungle world located in the Noe'ha'on system, a part of the Piryn Shar sector of the Expansion Region. It was situated in grid square K-16 of the Standard Galactic Grid and also lay on the hyperspace route known as the Great Gran Run, between the Kinyen system and the Mid Rim's Takodana system.
