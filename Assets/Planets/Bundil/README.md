# Bundil

**Continuity:** Legends  
**Source:** [Bundil](https://starwars.fandom.com/wiki/Bundil)

Bundil was a planet in the Outer Rim Territories. During the Galactic Civil War, it was orbited by the Imperial XQ2 Platform Bundil II, where Rebel prisoners from Hoth were brought.
