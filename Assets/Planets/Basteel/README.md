# Basteel

**Continuity:** Canon  
**Source:** [Basteel](https://starwars.fandom.com/wiki/Basteel)
**Galaxy atlas:** system `Basteel`, Outer Rim, grid P-3 — map position (6746.5, 9883.2, 91.8)

Basteel was a frigid and mountainous planet located in the Corva sector. It had almost no flat ground and little vegetation. Its inhabitants lived in subterranean cities, like its capital, Eladro City.
