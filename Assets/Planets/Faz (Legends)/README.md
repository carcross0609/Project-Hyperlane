# Faz

**Continuity:** Legends  
**Source:** [Faz/Legends](https://starwars.fandom.com/wiki/Faz/Legends)
**Galaxy atlas:** system `Faz`, Core Worlds, grid K-10 — map position (-1235.0, -858.9, 66.3)

Faz was one of the original 13 planets of the Duskhan League, and was one of the many colony worlds held by the Yevetha. It was located in the Koornacht Cluster, in the Farlax sector.
