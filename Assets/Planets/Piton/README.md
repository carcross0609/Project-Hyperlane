# Piton

**Continuity:** Legends  
**Source:** [Piton](https://starwars.fandom.com/wiki/Piton)
**Galaxy atlas:** system `Piton`, Core Worlds, grid K-12 — map position (-280.3, -3817.3, 219.5)

Piton was a terrestrial planet located in the Piton system of the Core Worlds. It was the homeworld of the sentient Piton species, which lived underground. Miro Daroon, who had become a member of the off-world Jedi Order at some point by approximately 53 BBY, was a Piton from the planet Piton.
