# Mathas

**Continuity:** Canon  
**Source:** [Mathas](https://starwars.fandom.com/wiki/Mathas)

Mathas was a planet in the Mathas system of the Inner Rim Territories whose inhabitants suffered from the Niffin plague at some time before the Clone Wars. The Jedi Order set up an outreach temple in response to the plague where individuals could go for emotional and spiritual aid. Jedi Master Kez Velaz was chosen to oversee the program before he disappeared and an individual known as Drooz, claiming to be a Jedi prophet and healer took up residence in the temple. Jedi Master Cyslin Myr and Padawan Mace Windu later traveled to Mathas to assess the situation.
