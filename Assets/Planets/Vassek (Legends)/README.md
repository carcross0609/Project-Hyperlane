# Vassek

**Continuity:** Legends  
**Source:** [Vassek/Legends](https://starwars.fandom.com/wiki/Vassek/Legends)
**Galaxy atlas:** system `Vassek`, Outer Rim, grid I-17 — map position (-3115.8, -11644.8, 468.9)

Vassek was a planet in the Vassek system of the Outer Rim Territories. The planet was located within Separatist space during the Clone Wars. General Grievous maintained a castle on its third moon.
