# Dandoran

**Continuity:** Canon  
**Source:** [Dandoran](https://starwars.fandom.com/wiki/Dandoran)
**Galaxy atlas:** system `Dandoran`, Outer Rim — map position (11254.5, 8997.2, 348.1)

Dandoran was a lush and watery planet located in the Doran system, within Hutt Space. Throughout history, it was often used to hide cartel smuggling operations. It was covered in crystal clear lakes and pristine forests.
