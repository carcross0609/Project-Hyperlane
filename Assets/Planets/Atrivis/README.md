# Atrivis

**Continuity:** Legends  
**Source:** [Atrivis](https://starwars.fandom.com/wiki/Atrivis)

Atrivis was a planet in the Generis system located in the Outer Rim sector of the same name. Homack, a starfighter pilot for the Alliance to Restore the Republic, was shot down over the planet and pursued by Imperial Storm commandos.
