# Repea

**Continuity:** Legends  
**Source:** [Repea](https://starwars.fandom.com/wiki/Repea)
**Galaxy atlas:** system `Repea`, Outer Rim, grid R-7 — map position (9677.1, 3909.6, -74.5)

Repea was an Outer Rim planet near the Cron Drift in the Auril sector. The planet was protected by the Crimson Aces until politicians on the planet feared the squadron might turn on them. The politicians sought aid from the Galactic Empire in razing the Aces' planet-side base.
