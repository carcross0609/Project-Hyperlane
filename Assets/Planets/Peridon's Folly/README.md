# Peridon's Folly

**Continuity:** Legends  
**Source:** [Peridon's Folly](https://starwars.fandom.com/wiki/Peridon%27s_Folly)
**Galaxy atlas:** system `Peridon's Folly`, Mid Rim, grid Q-11 — map position (8684.6, -2295.6, 200.7)

Peridon's Folly was a weapons depot that was operated by traders who sold obsolete arms to crime lords. Sectors were controlled by gunrunners and were separated by wastelands where the weapons were tested. IG-88B collected his first bounty there.
