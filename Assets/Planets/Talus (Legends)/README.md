# Talus

**Continuity:** Legends  
**Source:** [Talus/Legends](https://starwars.fandom.com/wiki/Talus/Legends)
**Galaxy atlas:** system `Talus`, Core Worlds, grid M-11 — map position (2771.6, -1711.0, 55.8)

Talus was one of the Twin Worlds located in the Corellian system that orbited Centerpoint Station, the other being Tralus, its sister planet.
