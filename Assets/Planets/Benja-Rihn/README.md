# Benja-Rihn

**Continuity:** Legends  
**Source:** [Benja-Rihn](https://starwars.fandom.com/wiki/Benja-Rihn)
**Galaxy atlas:** system `Benja-Rihn`, Other, grid Q-14 — map position (8562.3, -7120.4, -136.7)

Benja-Rihn was a planet in the Mid Rim. In its Temple of Tet-Ami was the Orb of Passage. At some point, Mace Windu traveled back in time using the Orb and saved Carthas from insectoids.
