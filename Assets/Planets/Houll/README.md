# Houll

**Continuity:** Legends  
**Source:** [Houll](https://starwars.fandom.com/wiki/Houll)
**Galaxy atlas:** system `Houll`, Deep Core — map position (-674.7, -1630.5, 3.6)

Houll was a terrestrial planet located in the Deep Core's Beshqek system before the planet Byss was destroyed. It occupied the seventh orbital position around the star Beshqek and had five moons. Houll featured a frigid climate and a rocky surface.
