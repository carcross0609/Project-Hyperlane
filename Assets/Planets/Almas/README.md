# Almas

**Continuity:** Legends  
**Source:** [Almas](https://starwars.fandom.com/wiki/Almas)
**Galaxy atlas:** system `Almas`, Mid Rim, grid P-14 — map position (7297.7, -6375.1, 27.4)

Almas was a terraformed planet in the Cularin system. Its moon, Dorumaa, was a captured satellite, which underwent its own terraforming.
