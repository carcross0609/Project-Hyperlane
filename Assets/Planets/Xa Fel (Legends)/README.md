# Xa Fel

**Continuity:** Legends  
**Source:** [Xa Fel/Legends](https://starwars.fandom.com/wiki/Xa_Fel/Legends)
**Galaxy atlas:** system `Xa Fel`, Core Worlds, grid K-9 — map position (-1390.5, 495.7, 23.5)

Xa Fel was a populated planet in the Kanchen sector of the Core Worlds. It was the homeworld of the Xa Fel. The planet readily supported all forms of life.
