# Threfal

**Continuity:** Legends  
**Source:** [Threfal](https://starwars.fandom.com/wiki/Threfal)
**Galaxy atlas:** system `Threfal`, Mid Rim, grid J-16 — map position (-2157.1, -10171.8, -449.1)

Threfal was a world located in the Threfal system, a part of the Mid Rim's Iska sector. Threfal had a Type I breathable atmosphere and was the homeworld of the plant known as the meatvine, which could be used as food.
