# Bedlam

**Continuity:** Canon  
**Source:** [Bedlam](https://starwars.fandom.com/wiki/Bedlam)
**Galaxy atlas:** system `Bedlam`, Mid Rim, grid O-7 — map position (5349.3, 3371.2, -301.9)

Bedlam was a mysterious planet of which little was known other than stories. Dok-Ondar once acquired a relic that was supposedly from the planet. The Gen'Dai Rayvis led a marauder group known as the Bedlam Raiders during the Imperial Era.
