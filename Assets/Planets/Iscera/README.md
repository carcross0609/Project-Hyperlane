# Iscera

**Continuity:** Legends  
**Source:** [Iscera](https://starwars.fandom.com/wiki/Iscera)
**Galaxy atlas:** system `Iscera`, Outer Rim, grid R-17 — map position (10197.0, -11208.6, 27.1)

Iscera was an Outer Rim planet near Issor and Nysza III. Fable Astin saw Jaalib Brandl perform in a play on this planet. It was a dry planet lacking any legal establishments that sold alcohol.
