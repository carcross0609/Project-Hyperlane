# Kidron

**Continuity:** Canon  
**Source:** [Kidron](https://starwars.fandom.com/wiki/Kidron)
**Galaxy atlas:** system `Kidron`, Outer Rim — map position (12461.4, 1914.5, 659.8)

Kidron was a planet located in the Kidron system in the Elrood sector of the Outer Rim Territories. During the Galactic Civil War, many Y-wing pilots trained on Kidron, soaring through its spectacular orange skies.
