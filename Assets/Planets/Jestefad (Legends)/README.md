# Jestefad

**Continuity:** Legends  
**Source:** [Jestefad/Legends](https://starwars.fandom.com/wiki/Jestefad/Legends)
**Galaxy atlas:** system `Jestefad`, Outer Rim — map position (11529.0, 5790.4, -614.0)

Jestefad was the second planet orbiting the star Priate in the Mustafar system. Located in the Atravis sector of the Outer Rim Territories, it was a gas giant. Located very close to the planet Mustafar, it was constantly in a gravitational tug-of-war with the gas giant Lefrani suspending Mustafar in between their orbits.
