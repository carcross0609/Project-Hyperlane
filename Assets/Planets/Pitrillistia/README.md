# Pitrillistia

**Continuity:** Legends  
**Source:** [Pitrillistia](https://starwars.fandom.com/wiki/Pitrillistia)
**Galaxy atlas:** system `Pitrillistia`, Outer Rim, grid O-3 — map position (5075.9, 9823.3, -316.9)

Pitrillistia was a remote terrestrial planet situated on the galactic periphery. It was a part of the Pitrillistia system, located in the Mieru'kar sector within the New Territories portion of the Outer Rim Territories. Pitrillistia was the homeworld of the sentient, bipedal Pitrillistian species, members of which spoke a mostly musical language produced by their small wings.
