# Fii

**Continuity:** Legends  
**Source:** [Fii](https://starwars.fandom.com/wiki/Fii)

Fii was the sixth planet orbiting the binary stars Toydar and Little Toydar in the Toydaria system. Located in Hutt Space of the galaxy, it was a barren rock.
