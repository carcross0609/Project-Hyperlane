# Thaldo

**Continuity:** Legends  
**Source:** [Thaldo](https://starwars.fandom.com/wiki/Thaldo)
**Galaxy atlas:** system `Thaldo`, Mid Rim, grid J-17 — map position (-1896.6, -11174.8, 34.8)

Thaldo was a planet located within the Thaldo system of the Mid Rim. The Rebel cell on Thaldo was one of many infiltrated by Nagai spies some time following the Battle of Yavin.
