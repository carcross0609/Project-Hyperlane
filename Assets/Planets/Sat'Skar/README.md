# Sat'Skar

**Continuity:** Legends  
**Source:** [Sat'Skar](https://starwars.fandom.com/wiki/Sat%27Skar)
**Galaxy atlas:** system `Sat'Skar`, Outer Rim, grid M-20 — map position (1938.0, -16170.4, -47.3)

Sat'Skar was a planet located within the Coyn system of the Outer Rim Territories. It was considered a sister planet to Coyn itself. The name "Sat'Skar" meant "Sword" in the Coynite language.

Sat'Skar was extremely hot due to increased levels of greenhouse gases. The planet's only life forms were primitive fungi, bacteria, and microbes.
