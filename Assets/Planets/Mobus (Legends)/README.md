# Mobus

**Continuity:** Legends  
**Source:** [Mobus/Legends](https://starwars.fandom.com/wiki/Mobus/Legends)
**Galaxy atlas:** system `Mobus`, Unknown Regions — map position (-6974.9, 633.0, -105.7)

Mobus, sometimes referred to as Sanctuary, and also known as Klasse A in the Chiss surveys, was a gas giant in the Klasse Ephemora system of the Unknown Regions. It orbited the star Klasse Ephemora.
