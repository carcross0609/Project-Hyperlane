# Unidentified overgrown mudball

**Continuity:** Legends  
**Source:** [Unidentified overgrown mudball](https://starwars.fandom.com/wiki/Unidentified_overgrown_mudball)

Located half-a-parsec from Kharzet III, this planet housed an Imperial base and communications beacon. Believing it to be devoid of any Imperial presence, Commander Luke Skywalker scouted the planet as a potential location for a Rebel Alliance base. He was ultimately driven off the world by Imperial forces under the command of Major Kuhru.
