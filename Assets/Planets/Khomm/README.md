# Khomm

**Continuity:** Canon  
**Source:** [Khomm](https://starwars.fandom.com/wiki/Khomm)
**Galaxy atlas:** system `Khomm`, Deep Core, grid L-12 — map position (187.6, -3827.1, -14.1)

Khomm was a planet located in the Khomm system of the galaxy's Deep Core. It had many oceans and was the homeworld of the Khommites and the Khommite striders. Khomm participated in cloning that left behind logo proteins. Those proteins could be used after the clone's creation to determine the clone hailed from Khomm.
