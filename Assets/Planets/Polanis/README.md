# Polanis

**Continuity:** Legends  
**Source:** [Polanis](https://starwars.fandom.com/wiki/Polanis)

Polanis was an agriworld in the Core Worlds of the galaxy, within the Corellian sector. It was known for the Polanis ale and the Polanis Wine produced on the planet.
