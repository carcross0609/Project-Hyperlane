# Messert

**Continuity:** Canon  
**Source:** [Messert](https://starwars.fandom.com/wiki/Messert)
**Galaxy atlas:** system `Messert`, Mid Rim, grid Q-10 — map position (7739.5, -361.8, 43.3)

Messert was a planet located in the Messert system within the Mytaranor sector of the Mid Rim and the Slice. It was situated in grid square Q-10 of the Standard Galactic Grid.

Messert was the homeworld of the human stunt pilot Seftin Vanik. Messert was part of the New Republic, which was formally established in 5 ABY, but eventually seceded from the Republic. Messert's secession stunned Vanik, as the pilot supported the galactic government. Sometime after the secession, by 35 ABY, Vanik accepted an invitation to join the Resistance by pilot Poe Dameron.
