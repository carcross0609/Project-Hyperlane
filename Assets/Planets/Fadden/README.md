# Fadden

**Continuity:** Legends  
**Source:** [Fadden](https://starwars.fandom.com/wiki/Fadden)
**Galaxy atlas:** system `Fadden`, Inner Rim, grid N-11 — map position (4453.3, -1974.3, -252.4)

Fadden was a world located in the Fadden system, a part of the Slice portion of the Inner Rim. It was settled by colonists of the Duros species, which was native to the Core Worlds planet Duro.

Fadden was situated in the territory of the Galactic Republic around 22,000 BBY. By that time, it was connected by a hyperlane to the Colonies' Commenor system. The hyperspace route had been extended to the Pyrshak system by 5000 BBY but had ceased to exist by the time of the Mandalorian Wars of 3976 BBY–3960 BBY.
