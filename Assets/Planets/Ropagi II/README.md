# Ropagi II

**Continuity:** Legends  
**Source:** [Ropagi II](https://starwars.fandom.com/wiki/Ropagi_II)
**Galaxy atlas:** system `Ropagi II`, Expansion Region, grid N-16 — map position (3782.6, -9028.6, -327.6)

Ropagi II was a planet in Kira sector, on the Enarc Run. It was an endpoint of the Kira Run and was home to two native species.
