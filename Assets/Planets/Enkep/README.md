# Enkep

**Continuity:** Legends  
**Source:** [Enkep](https://starwars.fandom.com/wiki/Enkep)

Enkep was the first planet in the Katorrs system. A molten ball of rock, it had no moons, life, or water and was therefore all but ignored by cartographers of the Galactic Empire.
