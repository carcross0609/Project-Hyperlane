# Usnia

**Continuity:** Legends  
**Source:** [Usnia](https://starwars.fandom.com/wiki/Usnia)
**Galaxy atlas:** system `Usnia`, Mid Rim, grid L-18 — map position (370.5, -12112.6, -75.5)

Usnia was a forested planet located in the Usnia system of the Senex sector, a part of the Senex-Juvex region in the Western Reaches portion of the Mid Rim. It was also situated close to the Tangles, an area of intersecting hyperlanes. Usnia was connected via hyperspace routes to the Dornean, Trenthellix, and Varadan systems. It was declared a nature reserve by House Petro, one of the aristocratic Ancient Houses of the Senex-Juvex region.
