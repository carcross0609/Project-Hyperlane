# Marmoth

**Continuity:** Legends  
**Source:** [Marmoth](https://starwars.fandom.com/wiki/Marmoth)
**Galaxy atlas:** system `Marmoth`, Outer Rim, grid K-4 — map position (-943.6, 7742.7, 337.4)

Marmoth was a planet located in the Albarrio sector of the Outer Rim Territories, and was a part of the Relgim Run. It was one of the ports of call of the luxury liner Kuari Princess.
