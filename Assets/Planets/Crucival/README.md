# Crucival

**Continuity:** Canon  
**Source:** [Crucival](https://starwars.fandom.com/wiki/Crucival)
**Galaxy atlas:** system `Crucival`, Outer Rim, grid M-11 — map position (2068.0, -1813.1, 87.5)

Crucival was an Old Tionese colonial backwater planet in the Outer Rim and the homeworld of Hazram Namir. Imperial defector Governor Everi Chalis considered settling there to avoid being found by the Galactic Empire. The world was almost constantly wracked by war between various factions, including the Malkhanis and their successors, the Opaline Creed.
