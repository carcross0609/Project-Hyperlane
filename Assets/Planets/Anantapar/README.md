# Anantapar

**Continuity:** Canon  
**Source:** [Anantapar](https://starwars.fandom.com/wiki/Anantapar)
**Galaxy atlas:** system `Anantapar`, Outer Rim, grid K-18 — map position (-1314.1, -12967.7, -256.6)

Anantapar was a planet located in the Anantapar system in the Yarith sector, which was located in grid square K-18 of the Standard Galactic Grid and in the Greater Javin region of the Outer Rim Territories. It was situated along the Corellian Trade Spine super-hyperroute.
