# Obinipor

**Continuity:** Legends  
**Source:** [Obinipor](https://starwars.fandom.com/wiki/Obinipor)
**Galaxy atlas:** system `Obinipor`, Outer Rim — map position (984.2, 7009.7, 222.0)

Obinipor was an unaligned planet in the Outer Rim, near Warlord Zsinj's territory. Its volcanoes spewed out metals used to fabricate power generators.
