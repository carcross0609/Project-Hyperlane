# Schesa

**Continuity:** Canon  
**Source:** [Schesa](https://starwars.fandom.com/wiki/Schesa)
**Galaxy atlas:** system `Schesa`, Unknown Regions, grid F-8 — map position (-8397.4, 2499.6, -206.2)

Schesa was a terrestrial planet in the Unknown Regions, situated in the Schesa system near the edge of the Chiss Ascendancy. It was a major Chiss world. Pirates connected to the Lioaoin Regime attacked shipping off of Schesa and Pesfavri.

The Schesa triad was a communications triad located on Schesa.
