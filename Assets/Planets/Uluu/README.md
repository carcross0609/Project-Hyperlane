# Uluu

**Continuity:** Legends  
**Source:** [Uluu](https://starwars.fandom.com/wiki/Uluu)
**Galaxy atlas:** system `Uluu`, Core Worlds, grid L-10 — map position (848.1, -638.7, -94.3)

Uluu was a planet in the Zug system. It was the farthest planet away from the system's star, Zug, and because of this, it was extremely cold. Uluu possessed a single natural satellite.
