# Bextar

**Continuity:** Legends  
**Source:** [Bextar](https://starwars.fandom.com/wiki/Bextar)
**Galaxy atlas:** system `Bextar`, Outer Rim, grid J-4 — map position (-1704.2, 7722.4, -196.3)

Bextar was one of four gas giants in the Velcar Free Commerce Zone's Bextar system. It was the site of several Amber Sun Mining Corporate gas mines. Amber Sun imported Entymal slaves as miners.
