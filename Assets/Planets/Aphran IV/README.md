# Aphran IV

**Continuity:** Legends  
**Source:** [Aphran IV](https://starwars.fandom.com/wiki/Aphran_IV)
**Galaxy atlas:** system `Aphran IV`, Inner Rim, grid K-8 — map position (-1469.0, 2207.9, 10.9)

Aphran IV was a warm planet in the Inner Rim's Aphran system. Located along the Namadii Corridor, Aphran IV was situated between Bilbringi and Carratos.
