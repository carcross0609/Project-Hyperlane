# R'terleD'er

**Continuity:** Legends  
**Source:** [R'terleD'er](https://starwars.fandom.com/wiki/R%27terleD%27er)
**Galaxy atlas:** system `R'terleD'er`, Outer Rim, grid J-18 — map position (-1788.5, -13391.4, 232.3)

R'terleD'er was a world located in the Kriz sector of the Outer Rim Territories. During the reign of the Galactic Empire, hunters on R'terleD'er were known to pay Baragwins handsomely to track large game.
