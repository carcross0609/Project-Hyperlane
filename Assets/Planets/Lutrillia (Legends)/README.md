# Lutrillia

**Continuity:** Legends  
**Source:** [Lutrillia/Legends](https://starwars.fandom.com/wiki/Lutrillia/Legends)
**Galaxy atlas:** system `Lutrillia`, Outer Rim, grid J-18 — map position (-1640.3, -12658.7, -451.1)

Lutrillia was a planet in the Yarith sector of the Outer Rim, on the Lutrillian Cross hyperlane. An important export of Lutrillia was ochroid dust.
