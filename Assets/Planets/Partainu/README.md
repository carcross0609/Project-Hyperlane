# Partainu

**Continuity:** Legends  
**Source:** [Partainu](https://starwars.fandom.com/wiki/Partainu)

Partainu was the fifth planet orbiting the star of Deel in the Neimoidia system. Located in the Colonies, it was a gas giant.
