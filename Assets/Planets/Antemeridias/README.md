# Antemeridias

**Continuity:** Legends  
**Source:** [Antemeridias](https://starwars.fandom.com/wiki/Antemeridias)
**Galaxy atlas:** system `Antemeridias`, Outer Rim, grid R-7 — map position (9661.4, 4086.5, 96.8)

Antemeridias was the capital of the Antemeridian sector. Located in the Outer Rim Territories, it was located along the Perlemian Trade Route.
