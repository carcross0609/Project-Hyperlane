# Stamia

**Continuity:** Legends  
**Source:** [Stamia](https://starwars.fandom.com/wiki/Stamia)

Stamia was the sixth planet orbiting the star Tive in the Taanab system. Located in the Inner Rim Territories, it was a gas giant, with 28 moons.
