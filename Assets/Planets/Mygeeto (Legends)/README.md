# Mygeeto

**Continuity:** Legends  
**Source:** [Mygeeto/Legends](https://starwars.fandom.com/wiki/Mygeeto/Legends)
**Galaxy atlas:** system `Mygeeto`, Outer Rim, grid K-5 — map position (-763.8, 7409.7, 157.9)

Mygeeto was a wealthy InterGalactic Banking Clan colony between Ord Biniir and Morishim under the control of the Confederacy of Independent Systems.
