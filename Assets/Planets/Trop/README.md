# Trop

**Continuity:** Legends  
**Source:** [Trop](https://starwars.fandom.com/wiki/Trop)

Trop was a gas giant–type planet with eleven moons that occupied the sixth orbital position around the star Asar. It was located within the Ilum system, a part of the Unknown Regions' 7G sector.
