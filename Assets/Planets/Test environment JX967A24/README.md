# Test environment JX967A24

**Continuity:** Legends  
**Source:** [Test environment JX967A24](https://starwars.fandom.com/wiki/Test_environment_JX967A24)

Test environment JX967A24 was the designation applied to a planet in Wild Space by a technologically-advanced species that dominated the region many centuries before the Galactic War between the Galactic Republic and the Sith Empire. The species, which tested weapons projects on unsuspecting worlds, deployed a number of new designs in a "test" against environment JX967A24, which saw them deploy numerous dropship waves and other forces against the planet's natives. The natives deployed "single-pilot aerial countermeasures" against the invaders, but ultimately surrendered after 28 standard hours; despite receiving a "compensation package" from the invaders, their infrastructure was so severely damaged that the invading species estimated it would take at least 2,000 years before the environment was ready to be "tested" again.
