# Diamal

**Continuity:** Legends  
**Source:** [Diamal (planet)](https://starwars.fandom.com/wiki/Diamal_%28planet%29)
**Galaxy atlas:** system `Diamal`, Core Worlds, grid L-13 — map position (151.7, -5137.3, -243.9)

Diamal was a planet located in the Diamal system of the Core Worlds. It was the homeworld of the Diamal. The planet was frequently in conflict with its neighbor, Isht.
