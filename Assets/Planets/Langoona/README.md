# Langoona

**Continuity:** Legends  
**Source:** [Langoona](https://starwars.fandom.com/wiki/Langoona)
**Galaxy atlas:** system `Langoona`, Hutt Space, grid S-10 — map position (11704.7, -1451.6, -44.0)

Langoona was a remote world located in the Bootana Hutta region of Hutt Space. Centuries ago, it was the homeworld of a once-favored slave species of the Hutts. However, after a failed rebellion, their masters drove them to the brink of extinction, preserving them only as targets for sadistic safaris.
