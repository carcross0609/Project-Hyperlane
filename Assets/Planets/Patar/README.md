# Patar

**Continuity:** Legends  
**Source:** [Patar](https://starwars.fandom.com/wiki/Patar)
**Galaxy atlas:** system `Patar`, Expansion Region, grid O-14 — map position (4799.8, -6468.0, 89.8)

Patar was the outermost planet in the Demar system.

Composed mostly of methane ice, Patar was the site of a mining operation which was discontinued due to marginal profitability. The world subsequently served as the site of a sensor station in the defenses of the Demar system.
