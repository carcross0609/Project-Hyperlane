# Veros

**Continuity:** Canon  
**Source:** [Veros](https://starwars.fandom.com/wiki/Veros)
**Galaxy atlas:** system `Veros`, Other, grid L-17 — map position (796.8, -11458.2, 260.9)

Veros was a planet located in the Veros system in the Dimean sector of the Expansion Region. It was also the homeworld of the Verosian species. It was once rich, but the Galactic Empire gained control of the planet and took the Verosians' wealth for itself.
