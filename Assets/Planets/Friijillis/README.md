# Friijillis

**Continuity:** Legends  
**Source:** [Friijillis](https://starwars.fandom.com/wiki/Friijillis)
**Galaxy atlas:** system `Friijillis`, Outer Rim, grid P-18 — map position (6833.0, -13276.6, -61.6)

Friijillis was a planet in the Dail sector. The Hutt-sponsored news network, the Friij News Services—the clearing house of illegal information and data replication, controlled by the Tenloss Criminal Syndicate—was based on this planet.
