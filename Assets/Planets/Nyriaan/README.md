# Nyriaan

**Continuity:** Canon  
**Source:** [Nyriaan](https://starwars.fandom.com/wiki/Nyriaan)

Nyriaan was a planet where the human Jenkes managed a gladiator arena during the early days of the Galactic Empire's rule. Nine years after operating the arena, Jenkes, now an Imperial officer in the Imperial Security Bureau, had two gladiators from Nyriaan transported via shuttle to the planet Lothal. The two fighters, Borbig Drob and Warjak, were to participate in Gladiator Night, a new gladiatorial event which Jenkes had set up on Lothal.
