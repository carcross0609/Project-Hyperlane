# Fostin

**Continuity:** Legends  
**Source:** [Fostin](https://starwars.fandom.com/wiki/Fostin)

Fostin was a black-colored world that was located in the Grumani sector, in the Outer Rim Territories. It was orbited by at least nine moons, including Fostin Nine.
