# Hoylin

**Continuity:** Legends  
**Source:** [Hoylin](https://starwars.fandom.com/wiki/Hoylin)
**Galaxy atlas:** system `Hoylin`, Mid Rim, grid P-13 — map position (7380.0, -5576.7, -33.1)

Hoylin was a world located in the Hoylin system, a part of the Fei Hu sector in the Slice portion of the Mid Rim. It was situated on the Gamor Run hyperlane, which connected it to the Aikhibba and Beris systems.

The Human spy Rodin Baem was born at Hoylin in 23 BBY, a fact that was noted in 7 ABY by New Republic General Airen Cracken in Wanted by Cracken, a datafile that served as a compilation of reports on various threats to the New Republic.
