# Noremac

**Continuity:** Legends  
**Source:** [Noremac](https://starwars.fandom.com/wiki/Noremac)

Noremac was a planet within the Kanz sector. Following the end of the Kanz Disorders in 3670 BBY, the Jedi Watchman Mari-Elan Nora was killed by slavers on that world.
