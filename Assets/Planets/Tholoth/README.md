# Tholoth

**Continuity:** Canon  
**Source:** [Tholoth](https://starwars.fandom.com/wiki/Tholoth)
**Galaxy atlas:** system `Tholoth`, Colonies, grid N-12 — map position (3356.0, -3520.8, 14.5)

Tholoth was an arboreal planet located in the Tholoth system in the galaxy's Colonies region that was the homeworld of the Tholothian species. Tholoth was also the homeworld of the Jedi Master Stass Allie, who fought and died during the Clone Wars.
