# Themis

**Continuity:** Legends  
**Source:** [Themis](https://starwars.fandom.com/wiki/Themis)

Themis was a planet located in the Themis system of the Inner Rim. It was the homeworld of the Themians. Themis was orbited by a moon which contained an explosive ore that was capable of acting as a power source.
