# Q'mara

**Continuity:** Legends  
**Source:** [Q'mara](https://starwars.fandom.com/wiki/Q%27mara)
**Galaxy atlas:** system `Q'mara`, Mid Rim, grid L-18 — map position (149.8, -12234.5, 654.8)

Q'mara, located in the Q'mara system of the Juvex sector, was a desert planet with a number of shabby spaceports, where all manner of smugglers and thugs sought illicit employment. Juvex nobles frequented Q'mara's houses of ill repute; foolish ones were drawn into its subterranean gambling and spice dens, sometimes never to return. Qellrin was attacked by pirates near Q'mara.
