# Mar'ta I

**Continuity:** Legends  
**Source:** [Mar'ta I](https://starwars.fandom.com/wiki/Mar%27ta_I)
**Galaxy atlas:** system `Mar'ta I`, Mid Rim — map position (1358.3, 3599.0, -20.1)

Mar'ta I was the sixth planet in the Kothlis system.

Centuries before the Galactic Civil War, Bothan mining guilds had operations on the planet, as well as its counterpart, Mar'ta II. Eventually it was deemed too costly to mine deeper and uncover useful ore in the inhospitable climate, the operations were abandoned.
