# Saberhing

**Continuity:** Legends  
**Source:** [Saberhing/Legends](https://starwars.fandom.com/wiki/Saberhing/Legends)

Saberhing was a planet in the Corellian sector which manufactured starships. Han Solo and Chewbacca worked as mechanics in a factory on Saberhing before becoming smugglers when Han was 20 years old.
