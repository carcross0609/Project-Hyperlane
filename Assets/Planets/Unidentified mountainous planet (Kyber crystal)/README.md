# Unidentified mountainous planet

**Continuity:** Unknown  
**Source:** [Unidentified mountainous planet (Kyber crystal)](https://starwars.fandom.com/wiki/Unidentified_mountainous_planet_%28Kyber_crystal%29)

This planet was covered in mountains and seas that had a rainy climate. Rowan Freemaker and R0-GR hid the last Kyber Saber kyber crystal on this planet, until Naare found it.
