# Almar

**Continuity:** Legends  
**Source:** [Almar](https://starwars.fandom.com/wiki/Almar)
**Galaxy atlas:** system `Almar`, Outer Rim, grid M-19 — map position (2696.4, -14432.3, -118.3)

Almar was a tropical planet located in the Elrood sector's Almaran system with beaches, oceans, rain forests, and wide plains of orange grasses. The planet was dedicated to the tourist trade and its surface was called Almar Downside. The planet was orbited by a space station known as Almar Upside, which was considered Almar's capital.
