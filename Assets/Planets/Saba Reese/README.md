# Saba Reese

**Continuity:** Legends  
**Source:** [Saba Reese](https://starwars.fandom.com/wiki/Saba_Reese)

Saba Reese was the first planet orbiting the star Striar in the Malastare system. Located in the Dustig sector of the Mid Rim, it was a searing rock.
