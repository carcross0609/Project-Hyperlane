# Tikath

**Continuity:** Legends  
**Source:** [Tikath](https://starwars.fandom.com/wiki/Tikath)

Tikath was a planet located in the Tikath system of the Outer Rim Territories. It was a fortress world with a notoriously strong defense. A group of rebel operatives traveled to the planet in pursuit of Imperial scientist Etha Naru.
