# New Alderaan

**Continuity:** Legends  
**Source:** [New Alderaan/Legends](https://starwars.fandom.com/wiki/New_Alderaan/Legends)
**Galaxy atlas:** system `New Alderaan`, Outer Rim, grid T-6 — map position (13032.4, 4594.6, 9.3)

New Alderaan was a planet in the Outer Rim Ash Worlds. It was home to thousands of former residents of Alderaan that moved there after the Destruction of Alderaan by the first Death Star.
