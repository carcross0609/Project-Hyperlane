# Zor Vlahu

**Continuity:** Legends  
**Source:** [Zor Vlahu (planet)](https://starwars.fandom.com/wiki/Zor_Vlahu_%28planet%29)
**Galaxy atlas:** system `Zor Vlahu`, Mid Rim, grid P-11 — map position (6896.8, -1741.6, -278.2)

Zor Vlahu was a gas giant located in the Ruusan system. It was named for the Jedi Zor Vlahu who fought in the Ruusan campaign during the New Sith Wars. It was the fifth planet in the system.
