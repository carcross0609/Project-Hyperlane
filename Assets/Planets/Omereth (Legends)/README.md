# Omereth

**Continuity:** Legends  
**Source:** [Omereth/Legends](https://starwars.fandom.com/wiki/Omereth/Legends)
**Galaxy atlas:** system `Omereth`, Outer Rim — map position (9313.1, 4382.4, -48.3)

Omereth was an aquatic planet located in the galaxy. During the rule of the Eternal Empire, seismic activity brought a new archipelago to the surface of the world's oceans.
