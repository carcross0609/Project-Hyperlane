# Stassia

**Continuity:** Legends  
**Source:** [Stassia](https://starwars.fandom.com/wiki/Stassia)
**Galaxy atlas:** system `Stassia`, Core Worlds, grid K-10 — map position (-199.2, -171.5, 12.8)

Stassia was a planet located in the Core Worlds. Its inhabitants were very tolerant under any circumstances. During the Galactic Civil War, Stassia was ruled by the Galactic Empire under the governorship of Tren Pergallis.
