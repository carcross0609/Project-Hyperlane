# Tralus

**Continuity:** Legends  
**Source:** [Tralus/Legends](https://starwars.fandom.com/wiki/Tralus/Legends)
**Galaxy atlas:** system `Tralus`, Core Worlds, grid M-11 — map position (2367.3, -2754.5, 24.3)

Tralus was the sister planet of Talus in the Corellian system. Together, they were known as the Twin Worlds. Both shared the same orbit around Centerpoint Station. Tralus was quite hospitable to most sentient beings of the galaxy due to its many climates.
