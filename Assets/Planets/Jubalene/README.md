# Jubalene

**Continuity:** Legends  
**Source:** [Jubalene](https://starwars.fandom.com/wiki/Jubalene)

Jubalene was was the capital world of the Odionate in the Grumani sector. It was a foundry world where millions of slave laborers of various species were used to build Odion's war machines.
