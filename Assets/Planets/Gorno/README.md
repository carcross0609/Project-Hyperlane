# Gorno

**Continuity:** Legends  
**Source:** [Gorno](https://starwars.fandom.com/wiki/Gorno)
**Galaxy atlas:** system `Gorno`, Outer Rim, grid R-17 — map position (9406.0, -10809.9, -333.2)

Gorno was a planet in the Outer Rim, along the Corellian Run near Tatooine. The Galactic Empire had a secret research facility used to design the superlaser for the second Death Star, codenamed Hammertong. A spaceport there was used as an embarkation point from which the Hammertong was to depart, shortly before the Battle of Yavin.
