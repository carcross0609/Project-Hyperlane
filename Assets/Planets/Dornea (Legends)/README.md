# Dornea

**Continuity:** Legends  
**Source:** [Dornea/Legends](https://starwars.fandom.com/wiki/Dornea/Legends)
**Galaxy atlas:** system `Dornea`, Outer Rim, grid U-7 — map position (14098.0, 4242.3, -0.0)

Dornea was the homeworld of the Dornean species. The planet was located in the Dornean system of the Dominus sector, which bordered the Calamari sector out on the Slice.
