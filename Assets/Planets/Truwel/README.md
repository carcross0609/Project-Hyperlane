# Truwel

**Continuity:** Canon  
**Source:** [Truwel](https://starwars.fandom.com/wiki/Truwel)

Truwel was a planet that was located in the Truwel system in the Outer Rim Territories. It was governed by the star system's government that was officially under the Galactic Empire but secretly supported the Alliance to Restore the Republic.

## Planetary data

- **Name:** Truwel
- **Region:** Outer Rim Territories
- **Sector:** Videnda sector
- **System:** Truwel system
- **Coordinates:** L-18
- **Government:** Truwel system government
- **Affiliation:**
  - Galactic Empire
  - Alliance to Restore the Republic (secretly)
  -   Truwel system rebels
