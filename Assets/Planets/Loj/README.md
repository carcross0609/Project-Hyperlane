# Loj

**Continuity:** Legends  
**Source:** [Loj](https://starwars.fandom.com/wiki/Loj)

Loj was a planet located in the Colonies' Loj system. It was the site of the Moss Caverns, near which the expensive intoxicating beverage known as T'iil-T'iil was manufactured.

- **Region:** Colonies
