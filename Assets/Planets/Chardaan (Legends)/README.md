# Chardaan

**Continuity:** Legends  
**Source:** [Chardaan/Legends](https://starwars.fandom.com/wiki/Chardaan/Legends)
**Galaxy atlas:** system `Chardaan`, Inner Rim, grid N-13 — map position (3508.0, -5987.4, -157.1)

Chardaan was an Inner Rim world that lay at the intersection of the Hydian Way and Shipwrights' Trace. The planet was orbited by the Chardaan Shipyards.
