# Ding Briar

**Continuity:** Legends  
**Source:** [Ding Briar](https://starwars.fandom.com/wiki/Ding_Briar)

Ding Briar was a gas giant–type planet with eighteen moons that occupied the eighth orbital position around the star Abo. It was located within the Lehon system, a part of the Unknown Regions' area known as the Tempered Wastes.
