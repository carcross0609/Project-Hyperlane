# Tertiary Kesmere

**Continuity:** Legends  
**Source:** [Tertiary Kesmere](https://starwars.fandom.com/wiki/Tertiary_Kesmere)
**Galaxy atlas:** system `Tertiary Kesmere`, Outer Rim, grid L-4 — map position (310.2, 8805.4, -17.1)

Tertiary Kesmere was a cloudy, storm-wracked world located in the Tertiary Kesmere system, a part of the Raioballo sector in the New Territories portion of the Outer Rim Territories. It was the homeworld of the winged hornagaunt species, including the wing-clipped pet Grendel. Between 4 ABY and 12 ABY, Tertiary Kesmere fell within the borders of the Pentastar Alignment.
