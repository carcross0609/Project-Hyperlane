# Kiva

**Continuity:** Legends  
**Source:** [Kiva](https://starwars.fandom.com/wiki/Kiva)
**Galaxy atlas:** system `Kiva`, Mid Rim, grid O-7 — map position (5862.4, 3115.1, -207.0)

Kiva was a planet that was located within the Mid Rim. Its indigenous Kivan people were wiped out by Project Starscream, to the utter horror of Shi'ido anthropologist Mammon Hoole. The only remnants of the people were shadowy wraiths.
