# Gologry

**Continuity:** Legends  
**Source:** [Gologry](https://starwars.fandom.com/wiki/Gologry)

Gologry was the third planet orbiting the star Julevia in the Julevian system. Located in the Dalonbian sector of the Outer Rim Territories, it was an airless rock.
