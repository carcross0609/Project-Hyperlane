# Pismaria

**Continuity:** Legends  
**Source:** [Pismaria](https://starwars.fandom.com/wiki/Pismaria)

Pismaria was the sixth planet orbiting the star Stisste in the Saleucami system. Located in the Suolriep sector of the Outer Rim Territories, it was a gas giant.
