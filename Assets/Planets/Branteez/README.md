# Branteez

**Continuity:** Legends  
**Source:** [Branteez](https://starwars.fandom.com/wiki/Branteez)
**Galaxy atlas:** system `Branteez`, Outer Rim, grid Q-17 — map position (8695.8, -11320.8, -223.4)

Branteez was a terrestrial world located in the Branteez system, a part of the Outer Rim Territories' Tolonda sector. At some point by the date 38:1:15, a Shrine of Kooroo, one of a number of stone structures of mysterious origins found on several Outer Rim worlds, had been uncovered on Branteez—a fact which the investigative reporter Andor Javin noted in a TriNebulon News report issued on that date.
