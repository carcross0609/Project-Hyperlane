# Karnak Alpha

**Continuity:** Legends  
**Source:** [Karnak Alpha](https://starwars.fandom.com/wiki/Karnak_Alpha)
**Galaxy atlas:** system `Karnak Alpha`, Deep Core, grid M-10 — map position (2057.7, -1325.4, 12.9)

Karnak Alpha was a planet situated beyond the Hapes Cluster and near the Core Worlds. It was the home of the Karnak Alphans. Because the Karnak Alphans were very fond of strange and exotic animals; the planet was home to a number of large alternate environment zoos.

In 23 ABY Karnak Alpha was a world of strategic importance due to its proximity to the Deep Core and by extension a number of Imperial strongholds. After an eventful diplomatic banquet during which a number of diplomatic gaffes on the New Republic's part were narrowly avoided, the Karnak Alphan ambassador agreed to form an alliance with the New Republic.
