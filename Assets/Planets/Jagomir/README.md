# Jagomir

**Continuity:** Legends  
**Source:** [Jagomir](https://starwars.fandom.com/wiki/Jagomir)
**Galaxy atlas:** system `Jagomir`, Outer Rim, grid Q-5 — map position (8697.2, 6973.2, 215.0)

Jagomir was a humid planet in the Jaga's Cluster of the Outer Rim Territories. The Rebel Alliance set up a base there after being forced to abandon their base on Arda I. While it had no known native sentient species, Jagomir was teeming with thousands of plants and animals, many of which were extremely dangerous.

The surface of the planet contained thirty continents and a number of seas. Nearly seventy-five percent of the planet's surface was swampland.
