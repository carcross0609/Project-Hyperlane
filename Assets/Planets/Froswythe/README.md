# Froswythe

**Continuity:** Legends  
**Source:** [Froswythe](https://starwars.fandom.com/wiki/Froswythe)
**Galaxy atlas:** system `Froswythe`, Colonies, grid M-13 — map position (2273.6, -4990.2, 49.0)

Froswythe was a planet in the Colonies. It was a major source of meat and animal-based textiles for the Colonies and Core Worlds. Roaming herds of livestock included banthas and nerfs. Ycaqt were used for transportation.

Its sparsely-populated rolling prairies were home to bandit hideaways and tourist-oriented ranches, where livestock had to be guarded against indigenous plains panthers.

During the New Jedi Order era, Core World criminal Fegred Ewd had a hideaway on Froswythe, and Jerren Durs owned a leisure ranch called Durs Ranch.
