# Zyzar

**Continuity:** Canon  
**Source:** [Zyzar](https://starwars.fandom.com/wiki/Zyzar)

Zyzar was a mountainous planet within the reaches of the galaxy. During the Age of the Empire, it hosted the headquarters of the Varluk Organization. Sand rains would sometimes occur on Zyzar.
