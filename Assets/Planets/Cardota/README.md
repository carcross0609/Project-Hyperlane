# Cardota

**Continuity:** Canon  
**Source:** [Cardota](https://starwars.fandom.com/wiki/Cardota)
**Galaxy atlas:** system `Cardota`, Core Worlds, grid R-7 — map position (9848.9, 3627.2, 92.6)

Cardota, also known as Hosnian Cardota, was one of the five planets that made up the Hosnian system, in the Core region of the galaxy. The system, including Cardota, was destroyed by the First Order in 34 ABY.
