# Bavva

**Continuity:** Canon  
**Source:** [Bavva](https://starwars.fandom.com/wiki/Bavva)
**Galaxy atlas:** system `Bavva`, Outer Rim, grid K-18 — map position (-985.7, -12619.2, -399.8)

Bavva was a planet in the Bavva system in the Anoat sector of the Outer Rim Territories, along a hyperspace route. Over several months during the Iron Blockade of the sector by the Galactic Empire, a merchant on Bavva was robbed several times. The merchant then offered payment for an experienced individual to provide them personal security.
