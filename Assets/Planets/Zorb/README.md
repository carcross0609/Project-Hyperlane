# Zorb

**Continuity:** Legends  
**Source:** [Zorb](https://starwars.fandom.com/wiki/Zorb)
**Galaxy atlas:** system `Zorb`, Outer Rim, grid O-4 — map position (5240.3, 8768.0, 13.7)

Zorb was a planet located in the Zorb system of the Outer Rim Territories.

A blue-tongued self-described "Rubenesque beauty" once placed a personal ad seeking a generous male from either Zorb or the planet Cryon.
