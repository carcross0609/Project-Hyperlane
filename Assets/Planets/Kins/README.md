# Kins

**Continuity:** Legends  
**Source:** [Kins](https://starwars.fandom.com/wiki/Kins)
**Galaxy atlas:** system `Kins`, Deep Core — map position (-246.4, -669.1, -28.7)

Kins was a terrestrial planet located in the Vulpter system of the Deep Core. It occupied the second orbital position around its star, Vulpter. The planet featured a toxic environment and a rocky surface, and it had one moon.
