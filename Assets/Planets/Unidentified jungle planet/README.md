# Unidentified jungle planet

**Continuity:** Canon  
**Source:** [Unidentified jungle planet](https://starwars.fandom.com/wiki/Unidentified_jungle_planet)

A jungle planet was located in the galaxy. During the Cold War, FN-2187 and a squad of First Order stormtroopers were deployed to this planet to search for any Resistance activity.

## Planetary data

- **Name:** Unidentified jungle planet
- **Terrain:** Jungle
