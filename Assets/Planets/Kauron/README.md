# Kauron

**Continuity:** Legends  
**Source:** [Kauron](https://starwars.fandom.com/wiki/Kauron)
**Galaxy atlas:** system `Kauron`, Outer Rim — map position (10361.3, -10123.9, 466.8)

Kauron was a planet that was located in Kauron system within Meram sector in the Outer Rim Territories of the galaxy. The world was home to the Kauronian species and served as a hideout for the Cavrilhu Pirates.
