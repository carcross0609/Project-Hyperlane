# Lopor Station

**Continuity:** Legends  
**Source:** [Lopor Station](https://starwars.fandom.com/wiki/Lopor_Station)

Lopor Station was a planet in the Spirva sector of the Mid Rim. The bounty hunter Quantana started out his career as a child in the streets of the planet.
