# Uluq

**Continuity:** Legends  
**Source:** [Uluq](https://starwars.fandom.com/wiki/Uluq)

Uluq was a gas giant with amber-striped clouds and twin of Qogo in the Hapes Cluster and shared the same system as Shedu Maad. Uroro Station was once built between Qogo and Uluq to serve as a transfer station for Hapan ships traveling along the Throat to the mining world of Shedu Maad.
