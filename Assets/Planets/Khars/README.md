# Khars

**Continuity:** Legends  
**Source:** [Khars](https://starwars.fandom.com/wiki/Khars)

Khars was the second planet orbiting the star Teth in the Teth system. Located in the Baxel sector of the Outer Rim Territories, it was a gas giant.
