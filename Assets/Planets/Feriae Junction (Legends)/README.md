# Feriae Junction

**Continuity:** Legends  
**Source:** [Feriae Junction/Legends](https://starwars.fandom.com/wiki/Feriae_Junction/Legends)
**Galaxy atlas:** system `Feriae Junction`, Outer Rim, grid O-5 — map position (4918.3, 6415.6, -134.2)

Feriae Junction (often simply called "Junction") was a tradeworld at the nexus of the Hydian Way, the Thesme Trace, and the Gordian Reach.
