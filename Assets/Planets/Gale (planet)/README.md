# Gale

**Continuity:** Legends  
**Source:** [Gale (planet)](https://starwars.fandom.com/wiki/Gale_%28planet%29)
**Galaxy atlas:** system `Gale`, Mid Rim — map position (-4223.3, 3417.0, -196.6)

Gale was an icy world that was located within the Hoth's Brand system on the Mid Rim of the galaxy. Situated in the star system's ninth orbit and the eight planet, it was named for Lord Gale, who fought in the Ruusan campaign. Gale was orbited by two moons.
