# Mokk IX

**Continuity:** Legends  
**Source:** [Mokk IX](https://starwars.fandom.com/wiki/Mokk_IX)
**Galaxy atlas:** system `Mokk IX`, Inner Rim, grid N-10 — map position (4285.5, -781.4, 27.0)

Mokk IX was a planet in the Inner Rim Territories. It was an Imperial labor camp covered in work settlements and wastelands. After stowing away in an Imperial shuttle, Sish Sadeet was left there to die, but rescued by Mirith Sinn when the New Republic liberated the world sometime before 11 ABY.
