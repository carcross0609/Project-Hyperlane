# Banchii

**Continuity:** Canon  
**Source:** [Banchii](https://starwars.fandom.com/wiki/Banchii)

Banchii was a planet in the Inugg system of the Outer Rim Territories. During the High Republic Era, it housed a Jedi outpost which Jedi Knight Lily Tora-Asi was stationed at in the aftermath of the Great Hyperspace Disaster.
