# Arganu

**Continuity:** Legends  
**Source:** [Arganu](https://starwars.fandom.com/wiki/Arganu)
**Galaxy atlas:** system `Arganu`, Inner Rim, grid J-14 — map position (-1689.1, -6170.5, -135.3)

Arganu was a planet in the Tasar system. It was close to the star and the heat and radiation made it uninhabitable. Despite have rich mineral deposits, it was impractical to set up mining operations.
