# Atoan tar-pit planet

**Continuity:** Legends  
**Source:** [Atoan tar-pit planet](https://starwars.fandom.com/wiki/Atoan_tar-pit_planet)

A planet located in the Atoan system, in the Ghost Nebula, was covered by tar pits generating oceans of boiling tar. It was inhabited by Atoans from the neighboring planet of Atoa.
