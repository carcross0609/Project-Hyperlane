# Makeb

**Continuity:** Legends  
**Source:** [Makeb](https://starwars.fandom.com/wiki/Makeb)
**Galaxy atlas:** system `Makeb`, Mid Rim, grid Q-13 — map position (8418.2, -4818.0, 409.7)

Makeb was a planet in the Mid Rim in the Aida sector close to the edges of Hutt Space. It was a major source of isotope-5, one of the rarest minerals in the galaxy.
