# Ammuud

**Continuity:** Canon  
**Source:** [Ammuud](https://starwars.fandom.com/wiki/Ammuud)
**Galaxy atlas:** system `Ammuud`, Outer Rim, grid S-4 — map position (10976.7, 8657.9, 11.3)

Ammuud was a cold planet located in the Ammuud system in the Corporate Sector of the galaxy's Outer Rim Territories. The planet saw decades of fighting between its seven resident family clans, who eventually united to govern Ammuud under the Code of Ammuud.
