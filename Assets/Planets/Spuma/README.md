# Spuma

**Continuity:** Legends  
**Source:** [Spuma](https://starwars.fandom.com/wiki/Spuma)

Spuma was a medium sized planet in the Seswenna sector of the Outer Rim. It had a number of prairies, mountains, and jungles located along its surface.
