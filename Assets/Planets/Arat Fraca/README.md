# Arat Fraca

**Continuity:** Legends  
**Source:** [Arat Fraca](https://starwars.fandom.com/wiki/Arat_Fraca)
**Galaxy atlas:** system `Arat Fraca`, Colonies, grid M-12 — map position (2673.1, -3980.4, 47.3)

Arat Fraca was a planet located in the Arat Fraca system of the Colonies. The Star Morning suddenly reappeared over Arat Fraca a year after leaving Motexx for Gowdawl. Arat Fraca was two sectors away from Motexx. From Arat Fraca, the Star Morning proceeded to Darepp, where it landed.
