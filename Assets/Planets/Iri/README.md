# Iri

**Continuity:** Legends  
**Source:** [Iri](https://starwars.fandom.com/wiki/Iri)
**Galaxy atlas:** system `Iri`, Outer Rim, grid Q-7 — map position (7804.0, 3965.2, 45.8)

Iri was a forested planet in the Epidimi system located in the mid-rim, discovered in 5000 BBY by the Galactic Republic, which crossbred its native avians with the similar avians of Disim, resulting in the Tarongs, who drove their mother species on both worlds extinct.
