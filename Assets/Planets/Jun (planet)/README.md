# Jun

**Continuity:** Legends  
**Source:** [Jun (planet)](https://starwars.fandom.com/wiki/Jun_%28planet%29)
**Galaxy atlas:** system `Jun`, Wild Space — map position (4631.3, 10548.1, 214.4)

Jun was a hot rock planet with no moons that was located within the Parthovian Cluster's Faarlsun system, in the Wild Space region of the galaxy. The planet occupied the closest orbit to its star, the yellow-white Faarlsun.
