# Arden

**Continuity:** Legends  
**Source:** [Arden](https://starwars.fandom.com/wiki/Arden)
**Galaxy atlas:** system `Arden`, Wild Space, grid G-16 — map position (-6656.0, -9544.3, 116.5)

Arden was the fourth planet and the only gas giant in the Bakura system. It was named after Deredith Arden, the founder of Bakura. Arden was orbited by seven moons.
