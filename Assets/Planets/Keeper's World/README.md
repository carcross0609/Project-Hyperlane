# Keeper's World

**Continuity:** Legends  
**Source:** [Keeper's World](https://starwars.fandom.com/wiki/Keeper%27s_World)
**Galaxy atlas:** system `Keeper's World`, Outer Rim, grid O-5 — map position (4784.7, 7249.7, 230.7)

Keeper's World, located in the Outer Rim Territories, was the homeworld of The Keeper. It used to be inhabited by the Keeper's makers until they fled the planet during an ancient war.
