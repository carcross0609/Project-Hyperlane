# Toola

**Continuity:** Legends  
**Source:** [Toola/Legends](https://starwars.fandom.com/wiki/Toola/Legends)
**Galaxy atlas:** system `Toola`, Outer Rim, grid S-5 — map position (11697.1, 6959.0, 397.7)

Toola was a cold planet located in the Kaelta system. It was the homeworld of the Whiphids and was located in the Slice.
