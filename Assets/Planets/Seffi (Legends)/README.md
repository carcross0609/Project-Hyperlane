# Seffi

**Continuity:** Legends  
**Source:** [Seffi/Legends](https://starwars.fandom.com/wiki/Seffi/Legends)
**Galaxy atlas:** system `Seffi`, Core Worlds, grid L-9 — map position (366.7, 247.1, 22.8)

Seffi was the third planet in the Rhinnal system. The planet's surface was covered by a toxic ocean. The Republic rocket-jumpers distinguished themselves through their actions on Seffi, which was later reflected in their motto.
