# Unidentified backwater planet

**Continuity:** Legends  
**Source:** [Unidentified backwater planet](https://starwars.fandom.com/wiki/Unidentified_backwater_planet)

A backwater planet hosted a vital Imperial communications hub on Sunfall Peak. A resistance group fought the Imperial presence there before joining with the Rebel Alliance to stage a raid on the hub.
