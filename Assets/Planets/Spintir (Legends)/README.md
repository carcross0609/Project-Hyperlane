# Spintir

**Continuity:** Legends  
**Source:** [Spintir/Legends](https://starwars.fandom.com/wiki/Spintir/Legends)
**Galaxy atlas:** system `Spintir`, Outer Rim, grid Q-6 — map position (8947.8, 5833.6, 106.0)

Spintir was a planet in the Spadja sector of the Outer Rim that was home to a Jedi temple known as the Dawn Temple, and an unusually high number of mammals. Spintir was a wealthy trade world.
