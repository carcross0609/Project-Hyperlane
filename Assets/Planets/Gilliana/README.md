# Gilliana

**Continuity:** Legends  
**Source:** [Gilliana](https://starwars.fandom.com/wiki/Gilliana)

Gilliana was a planet in the Tapani sector's Gilliana system in the Cadriaan Province. Settlers from Gilliana colonized Aleron.

Lanthe Artifice was based on Gilliana.
