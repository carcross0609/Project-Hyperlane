# Cmaoli Di

**Continuity:** Legends  
**Source:** [Cmaoli Di/Legends](https://starwars.fandom.com/wiki/Cmaoli_Di/Legends)
**Galaxy atlas:** system `Cmaoli Di`, Outer Rim, grid M-17 — map position (2748.9, -11586.0, 410.4)

Cmaoli Di was a world in the Brema sector. Between 3701 BBY and 3699 BBY, the Hydian Way was charted through the planet as part of the Seswenna Expansion. Cmaoli Di was known to receive broadcasts from the Brema News service.
