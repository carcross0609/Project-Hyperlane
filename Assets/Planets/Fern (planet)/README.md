# Fern

**Continuity:** Legends  
**Source:** [Fern (planet)](https://starwars.fandom.com/wiki/Fern_%28planet%29)

Fern was a gas giant–type planet with twenty moons that occupied the eighth orbital position around the star Asar. It was located within the Ilum system, a part of the Unknown Regions' 7G sector.
