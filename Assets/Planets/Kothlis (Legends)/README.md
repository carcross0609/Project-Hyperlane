# Kothlis

**Continuity:** Legends  
**Source:** [Kothlis/Legends](https://starwars.fandom.com/wiki/Kothlis/Legends)
**Galaxy atlas:** system `Kothlis`, Mid Rim, grid R-14 — map position (9364.7, -6879.9, -190.3)

Kothlis was a Bothan colony world located in the Kothlis system of the Bothan sector in the Mid Rim. It was the fourth of seven planets in the star system.
