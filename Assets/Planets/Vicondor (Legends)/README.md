# Vicondor

**Continuity:** Legends  
**Source:** [Vicondor/Legends](https://starwars.fandom.com/wiki/Vicondor/Legends)
**Galaxy atlas:** system `Vicondor`, Mid Rim, grid J-7 — map position (-1865.1, 3116.2, -47.0)

Vicondor was a planet located in the Vicondor system of the Mid Rim. Its inhabitants joined with the people of Junction V, Delaluna, and Bezim to build the Station 88 Spaceport. This coalition of planets chose to remain loyal to the Galactic Republic during the Clone Wars.
