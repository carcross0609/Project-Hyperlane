# Dermos

**Continuity:** Canon  
**Source:** [Dermos](https://starwars.fandom.com/wiki/Dermos)
**Galaxy atlas:** system `Dermos`, Outer Rim — map position (4281.5, -11366.7, -331.1)

Dermos was a planet in the Belsmuth sector of the Outer Rim Territories. A group of insurgents planning a raid on Dermos were apprehended by the Imperial Security Bureau in 3 ABY. When New Republic pilot Wedge Antilles went missing in 4 ABY, Ensign Ardin Deltura suggested Antilles might be at Dermos.
