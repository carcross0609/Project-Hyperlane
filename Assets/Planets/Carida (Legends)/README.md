# Carida

**Continuity:** Legends  
**Source:** [Carida/Legends](https://starwars.fandom.com/wiki/Carida/Legends)
**Galaxy atlas:** system `Carida`, Colonies, grid M-9 — map position (2275.5, 889.2, 95.8)

Carida, originally known as Ord Carida, was a planet of the Colonies region of the galaxy, near the Perlemian Trade Route, and the homeworld of the Caridan race.
