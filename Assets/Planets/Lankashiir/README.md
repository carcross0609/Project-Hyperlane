# Lankashiir

**Continuity:** Legends  
**Source:** [Lankashiir](https://starwars.fandom.com/wiki/Lankashiir)
**Galaxy atlas:** system `Lankashiir`, Colonies, grid N-11 — map position (3520.1, -2889.2, -36.2)

Lankashiir was a planet of the Lankashiir system, which was located along the Quellor Run hyperlane within the Colonies and the Slice regions of the galaxy. During the Imperial Era, Lankashiir was under the control of the Galactic Empire. A planet thriving with forests, Lankashiir was home to Adion Lang, a lieutenant serving with the Imperial Security Bureau, and the Durasha family, a Human family with strong Imperial ties.
