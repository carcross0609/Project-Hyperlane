# Skotla

**Continuity:** Legends  
**Source:** [Skotla](https://starwars.fandom.com/wiki/Skotla)

Skotla was the sixth planet orbiting the star Teth in the Teth system. Located in the Baxel sector of the Outer Rim Territories, it was a gas giant.
