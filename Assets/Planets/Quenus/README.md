# Quenus

**Continuity:** Legends  
**Source:** [Quenus](https://starwars.fandom.com/wiki/Quenus)
**Galaxy atlas:** system `Quenus`, Core Worlds, grid L-9 — map position (388.7, 1032.5, -23.5)

Quenus was the fourth planet of the Chandrila system, located in the Bormea sector of the Ringali Shell in the Core Worlds. A gas giant, the planet orbited the star Chandrila and was itself circled by three moons. The entirety of the Chandrila system lay on the Perlemian Trade Route, which served as a dividing line between the Northern Dependencies and the Arrowhead portion of the Slice.
