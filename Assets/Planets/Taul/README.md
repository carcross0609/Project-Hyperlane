# Taul

**Continuity:** Canon  
**Source:** [Taul](https://starwars.fandom.com/wiki/Taul)
**Galaxy atlas:** system `Taul`, Outer Rim, grid J-18 — map position (-1664.2, -13178.7, -158.3)

Taul was an acidic planet in the galaxy's Outer Rim Territories, in grid square J-18 on the Standard Galactic Grid, inhabited by several dangerous creatures, such as the steel-eating spice spiders.

During the Cold War, the Sterdic Star, a Resistance Sphyrna-class Hammerhead corvette commanded by Resistance Captain Hoff and carrying droids C-3PO, O-MR1, medical droid 2MED2, construction droid CO-34, VL-44, and security droid PZ-99 crashed on Taul, and the droids had to fend off native creatures such as spice spiders. Only C-3PO survived.
