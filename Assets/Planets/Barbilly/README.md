# Barbilly

**Continuity:** Legends  
**Source:** [Barbilly](https://starwars.fandom.com/wiki/Barbilly)

Barbilly was the sixth planet orbiting the star Utapau in the Utapau system. Located in the Tarabba sector of the Outer Rim Territories, it was a gas giant.
