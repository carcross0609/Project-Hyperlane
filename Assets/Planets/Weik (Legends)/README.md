# Weik

**Continuity:** Legends  
**Source:** [Weik/Legends](https://starwars.fandom.com/wiki/Weik/Legends)

Weik was a terrestrial planet located in Wild Space. Weik was far from established hyperlanes and was nearly disconnected from the rest of the galaxy.
