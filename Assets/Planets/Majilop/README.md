# Majilop

**Continuity:** Legends  
**Source:** [Majilop](https://starwars.fandom.com/wiki/Majilop)
**Galaxy atlas:** system `Majilop`, Outer Rim — map position (6931.5, 5045.6, 233.3)

Majilop was a world located within the star system of the same name, a part of the Outer Rim Territories' Lol sector. Around the year 10 ABY, it served as the homeworld of the Lucin Syndicate, a major producer and distributor of illegal holoporn.
