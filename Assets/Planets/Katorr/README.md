# Katorr

**Continuity:** Legends  
**Source:** [Katorr](https://starwars.fandom.com/wiki/Katorr)
**Galaxy atlas:** system `Katorr`, Wild Space, grid J-6 — map position (-2698.6, 5564.1, 17.2)

Katorr was a gas giant world, the fourth and last planet in the Katorrs system. The star system, which also contained Adumar, was located within the region of the galaxy known as Wild Space.
