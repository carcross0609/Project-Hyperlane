# Salliche

**Continuity:** Legends  
**Source:** [Salliche/Legends](https://starwars.fandom.com/wiki/Salliche/Legends)
**Galaxy atlas:** system `Salliche`, Core Worlds, grid K-10 — map position (-385.6, -278.1, -50.9)

Salliche was an agricultural world in the Core Worlds region. It was the headquarters of the Salliche Agricultural Corporation. The planet was one of 18 planets on the Agricultural Circuit.
