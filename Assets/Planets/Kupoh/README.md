# Kupoh

**Continuity:** Canon  
**Source:** [Kupoh](https://starwars.fandom.com/wiki/Kupoh)

Kupoh was a planet located in the Kupoh system in the Dohlbani sector of the Mid Rim Territories. It was the homeworld of the Kupohan species. The planet had mountains, valleys, an high winds, causing cities such as Tonekh to be built inside of the valleys to be protected against the wind.
