# Dohu VII

**Continuity:** Legends  
**Source:** [Dohu VII](https://starwars.fandom.com/wiki/Dohu_VII)
**Galaxy atlas:** system `Dohu VII`, Mid Rim, grid K-7 — map position (-368.4, 3658.3, -198.1)

Dohu VII was the seventh of eight planets in the Dohu system. It was the homeworld of the mineral-based species called the Silika. Linkaas Corporation had a warehouse near Docking Bay 71 in Skagras.
