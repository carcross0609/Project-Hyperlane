# Mooga

**Continuity:** Canon  
**Source:** [Mooga](https://starwars.fandom.com/wiki/Mooga)
**Galaxy atlas:** system `Mooga`, Mid Rim — map position (-3720.3, 4222.8, 160.6)

Mooga was a planet located in the Mooga system in the Perkell sector of the Mid Rim Territories that was homeworld of the sentient Moogan species. Controlled by the Commerce Guild during the Clone Wars, the Moogan smuggler Tee Va hailed from this world. The Commerce Guild operated ore facilities on the planet, which were protected by Gossam Commandos.
