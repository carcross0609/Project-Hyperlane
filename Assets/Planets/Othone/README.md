# Othone

**Continuity:** Legends  
**Source:** [Othone](https://starwars.fandom.com/wiki/Othone)
**Galaxy atlas:** system `Othone`, Mid Rim — map position (8170.0, -1977.4, 84.4)

Othone was a planet in the Hoth's Brand system. An ice ball, it was the ninth planet orbiting the star Hoth's Brand. It was named after Johun Othone, who was killed by Darth Zannah during the Duel on Tython.
