# Jamiron

**Continuity:** Legends  
**Source:** [Jamiron/Legends](https://starwars.fandom.com/wiki/Jamiron/Legends)
**Galaxy atlas:** system `Jamiron`, Unknown Regions, grid F-8 — map position (-8811.5, 2004.6, 109.3)

Jamiron was a Chiss Ascendancy planet in the Jamiron system of the Unknown Regions. The surface of Jamiron was barren, but its porous crust contained hydroponic agricultural facilities.
