# Worru'du

**Continuity:** Legends  
**Source:** [Worru'du](https://starwars.fandom.com/wiki/Worru%27du)
**Galaxy atlas:** system `Worru'du`, Core Worlds, grid K-10 — map position (-579.0, -267.7, -55.5)

Worru'du was a planet located within the Worru'du system of the Core Worlds and known for its grass fields. The grass from Worru'du could be used for basket weaving.
