# Juvex

**Continuity:** Legends  
**Source:** [Juvex](https://starwars.fandom.com/wiki/Juvex)
**Galaxy atlas:** system `Juvex`, Mid Rim, grid L-18 — map position (345.4, -12035.6, 297.2)

Juvex was the sector capital of Juvex sector. It was ruled by House Sreethyn which engaged in the slave trade, and thus was denied Galactic Republic membership until shortly before the formation of the New Order. It was later part of the New Republic.
