# Jovan III

**Continuity:** Legends  
**Source:** [Jovan III](https://starwars.fandom.com/wiki/Jovan_III)
**Galaxy atlas:** system `Jovan III`, Outer Rim, grid P-6 — map position (7219.2, 5688.1, 88.3)

Jovan III, often called simply Jovan, was a planet located in the Jovan system and was noted for the Jovan Station, built in orbit around the planet.

Jovan III was a fertile planet and one of the premier agriworld of the Gordian Reach. It was crisscrossed by robo-harvesters and dotted with agricultural research labs.
