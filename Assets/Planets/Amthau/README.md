# Amthau

**Continuity:** Legends  
**Source:** [Amthau](https://starwars.fandom.com/wiki/Amthau)
**Galaxy atlas:** system `Amthau`, Expansion Region, grid O-14 — map position (5404.9, -6993.0, 176.5)

Amthau was the third planet in the Genesia system. The surface was dominated by rocky canyons, which spoke of the water which used to run across the planet's surface. This made the terraforming project much easier. When the terraforming was complete, Amthau became a favorite vacation spot for the wealthy inhabitants of the planet Genesia.
