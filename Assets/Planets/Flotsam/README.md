# Flotsam

**Continuity:** Legends  
**Source:** [Flotsam](https://starwars.fandom.com/wiki/Flotsam)
**Galaxy atlas:** system `Flotsam`, Core Worlds, grid O-17 — map position (4658.2, -10869.9, -147.4)

Flotsam was the third planet of the Belgaroth system, located in the Core Worlds of the galaxy. Illuminated by binary stars Matanya A and Matanya B, Flotsam was a barren world with no moons. An asteroid field of the star system lay before Flotsam.
