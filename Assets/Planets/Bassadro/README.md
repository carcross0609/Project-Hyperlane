# Bassadro

**Continuity:** Legends  
**Source:** [Bassadro](https://starwars.fandom.com/wiki/Bassadro)
**Galaxy atlas:** system `Bassadro`, Colonies, grid L-13 — map position (933.7, -5613.3, -65.3)

Bassadro was a mining world with glassy crags on its dormant volcanoes. It was devastated in a battle in which it was taken from the Confederacy of Independent Systems during the Clone Wars by Empatojayos Brand.
