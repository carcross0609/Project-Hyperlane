# Falk

**Continuity:** Legends  
**Source:** [Falk (planet)](https://starwars.fandom.com/wiki/Falk_%28planet%29)
**Galaxy atlas:** system `Falk`, Expansion Region, grid O-14 — map position (4997.2, -6510.4, 260.2)

Falk was the last planet in the Genesia system. It was a blue-gray gas giant whose nine moons had been stripped-mined by the Lant Mining Corporation.
