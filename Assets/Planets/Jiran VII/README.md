# Jiran VII

**Continuity:** Legends  
**Source:** [Jiran VII](https://starwars.fandom.com/wiki/Jiran_VII)

Jiran VII was a planet in the Outer Rim. It contained a monastery, which was also the home of the Zabrak monk Dao Jodh.
