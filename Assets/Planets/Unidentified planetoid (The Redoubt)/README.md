# Unidentified planetoid

**Continuity:** Legends  
**Source:** [Unidentified planetoid (The Redoubt)](https://starwars.fandom.com/wiki/Unidentified_planetoid_%28The_Redoubt%29)

A planetoid was an irradiated world located within The Redoubt in the galaxy's Unknown Regions. In the year 27 BBY, the Outbound Flight crash-landed on the planetoid.
