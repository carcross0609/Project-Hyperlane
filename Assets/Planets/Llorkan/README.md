# Llorkan

**Continuity:** Legends  
**Source:** [Llorkan](https://starwars.fandom.com/wiki/Llorkan)

Llorkan was a planet and home to an Imperial army garrison. Llorkan was the original destination of Captain Norello's ship, Happer's Way, during his interrupted delivery of fifty AT-ST walkers.
