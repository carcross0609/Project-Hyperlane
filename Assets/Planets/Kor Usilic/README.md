# Kor Usilic; (The Bootana Hutta region, with Kor Usilic represented by the number 9)

**Continuity:** Legends  
**Source:** [Kor Usilic](https://starwars.fandom.com/wiki/Kor_Usilic)
**Galaxy atlas:** system `Kor Usilic`, Hutt Space, grid S-11 — map position (11271.9, -1690.4, -216.4)

Kor Usilic was a world located within the Kor Usilic system, a part of the Bootana Hutta region of Hutt Space. It was situated in the Slice section of the galaxy. It was connected by hyperlanes to the Gos Hutta and Kor Hunamma systems.

Kor Usilic was the throneworld of the Usilic kajidic.
