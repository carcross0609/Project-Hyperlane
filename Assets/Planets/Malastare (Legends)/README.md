# Malastare

**Continuity:** Legends  
**Source:** [Malastare/Legends](https://starwars.fandom.com/wiki/Malastare/Legends)
**Galaxy atlas:** system `Malastare`, Mid Rim, grid N-16 — map position (3124.9, -10253.5, -18.2)
