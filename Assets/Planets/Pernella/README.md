# Pernella

**Continuity:** Legends  
**Source:** [Pernella](https://starwars.fandom.com/wiki/Pernella)
**Galaxy atlas:** system `Pernella`, Colonies, grid L-13 — map position (281.9, -5764.0, -184.2)

Pernella was a planet in the Pernella system in Tapani sector. It was one of the Freeworlds. It was also one of the Three Ellas, with a liberal government looser about crime and smuggling than most Tapani worlds.
