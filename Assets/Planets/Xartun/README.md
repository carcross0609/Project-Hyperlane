# Xartun

**Continuity:** Legends  
**Source:** [Xartun](https://starwars.fandom.com/wiki/Xartun)
**Galaxy atlas:** system `Xartun`, Outer Rim — map position (11641.8, 6539.6, -335.5)

Xartun was an Outer Rim Territories planet in the Ojoster sector that was involved in manufacturing. A New Republic world, it was near warlord Zsinj's territory. Although the planet was a signatory to the New Republic, a deal brought about by a previous planetary leader, the governor of Xartun during 7 ABY, Nojin Koolb, had it secretly allied with Warlord Zsinj.

Zsinj's facility on Xartun was constructing the same type of experimental cell as those used in Project Chubar.
