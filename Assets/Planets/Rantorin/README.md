# Rantorin

**Continuity:** Legends  
**Source:** [Rantorin](https://starwars.fandom.com/wiki/Rantorin)
**Galaxy atlas:** system `Rantorin`, Colonies, grid J-16 — map position (-2119.1, -10105.3, -235.4)

Rantorin, also known as OM812, was a barren rock planet with two moons. It occupied the second closest orbital position around the red giant star Thrantin Major in the Thrantin OM81-A system, a part of the Ollonir Boundaries in the Negs portion of the Colonies.
