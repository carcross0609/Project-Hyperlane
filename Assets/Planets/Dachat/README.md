# Dachat

**Continuity:** Legends  
**Source:** [Dachat](https://starwars.fandom.com/wiki/Dachat)
**Galaxy atlas:** system `Dachat`, Core Worlds, grid K-9 — map position (-888.2, 568.2, -11.6)

Dachat was a planet in the area of the Core Worlds containing the Hyabb-Twith Corridor. The Nelori Marauders had a base on the planet which allowed them to prey upon both the populations on Hyabb and Twith. The base was destroyed by the Jedi in 4050 BBY.
