# Zenarita

**Continuity:** Unknown  
**Source:** [Zenarita](https://starwars.fandom.com/wiki/Zenarita)

Zenarita was a terrestrial planet that was occupied by the Galactic Empire. The planet's royal family was imprisoned, with only Prince Arluu avoiding capture. The smuggler Chita helped him escape the planet.
