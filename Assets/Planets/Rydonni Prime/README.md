# Rydonni Prime

**Continuity:** Legends  
**Source:** [Rydonni Prime](https://starwars.fandom.com/wiki/Rydonni_Prime)
**Galaxy atlas:** system `Rydonni Prime`, Core Worlds, grid M-11 — map position (2326.5, -2614.5, 103.1)

Rydonni Prime was the only habitable planet in the Namaryne system and home to Rythani Products, headed by the K'ntarr family. Moff Caerbellak ruled the planet during the Galactic Civil War and the early years of the New Republic. It was very wealthy and had very few disenfranchised inhabitants, which made it very loyal to the Galactic Empire.
