# Spira

**Continuity:** Legends  
**Source:** [Spira/Legends](https://starwars.fandom.com/wiki/Spira/Legends)
**Galaxy atlas:** system `Spira`, Core Worlds, grid L-10 — map position (130.1, -251.7, 26.7)

Spira was a planet in the Core Worlds. It had beautiful beaches and was a popular resort. It had a low axial tilt, which gave it a large temperate zone over much of its surface.
