# Gaulus

**Continuity:** Legends  
**Source:** [Gaulus/Legends](https://starwars.fandom.com/wiki/Gaulus/Legends)
**Galaxy atlas:** system `Gaulus`, Outer Rim, grid S-17 — map position (11067.8, -11632.8, -18.8)

Gaulus was a planet that at one time hosted a Alliance to Restore the Republic base. An espionage droid infiltrated the base and transmitted the location to the Galactic Empire, and thus the base was destroyed shortly after.
