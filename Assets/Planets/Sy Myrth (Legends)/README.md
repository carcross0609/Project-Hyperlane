# Sy Myrth

**Continuity:** Legends  
**Source:** [Sy Myrth/Legends](https://starwars.fandom.com/wiki/Sy_Myrth/Legends)
**Galaxy atlas:** system `Sy Myrth`, Outer Rim, grid S-7 — map position (10501.6, 3763.5, -84.7)

Sy Myrth, formerly known as Far Barseg, was a planet located in the Jospro sector of the Outer Rim Territories. It was the homeworld of the Sy Myrthians.
