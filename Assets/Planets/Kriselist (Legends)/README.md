# Kriselist

**Continuity:** Legends  
**Source:** [Kriselist/Legends](https://starwars.fandom.com/wiki/Kriselist/Legends)
**Galaxy atlas:** system `Kriselist`, Mid Rim, grid K-16 — map position (-933.9, -10467.9, 43.6)

Kriselist was a planet in the Wornal sector of the Mid Rim. It sat at the junction between the Corellian Trade Spine and the D'Aelgoth Trade Route.
