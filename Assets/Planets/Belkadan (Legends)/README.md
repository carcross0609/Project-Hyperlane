# Belkadan

**Continuity:** Legends  
**Source:** [Belkadan/Legends](https://starwars.fandom.com/wiki/Belkadan/Legends)
**Galaxy atlas:** system `Belkadan`, Outer Rim, grid L-1 — map position (931.4, 12140.7, -449.7)

Belkadan was a forested planet located in the Dalonbian sector of the Outer Rim Territories. It was a world of tall dalloralla trees and small natural bodies of water.
