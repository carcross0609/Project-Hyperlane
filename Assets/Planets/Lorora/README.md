# Lorora

**Continuity:** Legends  
**Source:** [Lorora](https://starwars.fandom.com/wiki/Lorora)
**Galaxy atlas:** system `Lorora`, Core Worlds — map position (-760.2, 716.4, -27.7)

Lorora was the third planet of the Chandrila system, located in the Bormea sector of the Ringali Shell in the Core Worlds. The planet orbited the star Chandrila and was composed of toxic rock. The world was itself orbited by a single moon. The entirety of the Chandrila system lay on the Perlemian Trade Route, which served as a dividing line between the Northern Dependencies and the Arrowhead portion of the Slice.
