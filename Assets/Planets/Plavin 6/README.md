# Plavin 6

**Continuity:** Legends  
**Source:** [Plavin 6](https://starwars.fandom.com/wiki/Plavin_6)
**Galaxy atlas:** system `Plavin 6`, Colonies, grid L-9 — map position (799.0, 1302.7, 5.9)

Plavin 6 was a Colonies jungle world whose native inhabitants preferred to wear loose-fitting clothing. It was the homeworld of the Humans Nashiak Llalik and Saren Llalik. Nashiak eventually became a renowned engineer and built a large mansion on Plavin 6, where he stored two incomplete prototypes of the Sunder 9 power armor suit. At some point, a number of smugglers and thieves set up residence on the world in order to locate Nashiak.
