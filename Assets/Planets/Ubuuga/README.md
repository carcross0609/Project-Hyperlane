# Ubuuga

**Continuity:** Legends  
**Source:** [Ubuuga](https://starwars.fandom.com/wiki/Ubuuga)
**Galaxy atlas:** system `Ubuuga`, Mid Rim, grid Q-7 — map position (7917.1, 4052.4, -22.0)

Ubuuga was a planet located in the Ubuuga system and the homeworld of the Ubuugans and the Ubuugan fleshborers. Ubuuga was well-known for its caviar.
