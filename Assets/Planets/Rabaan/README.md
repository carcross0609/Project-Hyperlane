# Rabaan

**Continuity:** Legends  
**Source:** [Rabaan](https://starwars.fandom.com/wiki/Rabaan)
**Galaxy atlas:** system `Rabaan`, Expansion Region, grid O-12 — map position (4746.4, -3846.5, -46.0)
