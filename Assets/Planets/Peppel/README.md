# Peppel

**Continuity:** Legends  
**Source:** [Peppel](https://starwars.fandom.com/wiki/Peppel)
**Galaxy atlas:** system `Peppel`, Outer Rim, grid P-3 — map position (7298.6, 10323.2, -19.7)

Peppel was an Outer Rim Territories planet in the Corva sector. In 17 ABY, the wanted Devaronian former army captain Kardue'sai'Malloc fled to Peppel, where for the following two years he resided in a simple hut that was protected by a sophisticated security system. Eventually, the bounty hunter Boba Fett tracked Kardue'sai'Malloc to Peppel, where, eschewing his combat armor and wielding only a bow and knife in order to bypass the Devaronian's security system, Fett captured the fugitive and went on to deliver him to the world Devaron for execution.
