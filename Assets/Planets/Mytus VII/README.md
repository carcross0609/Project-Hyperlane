# Mytus VII

**Continuity:** Canon  
**Source:** [Mytus VII](https://starwars.fandom.com/wiki/Mytus_VII)
**Galaxy atlas:** system `Mytus VII`, Wild Space, grid S-3 — map position (11001.4, 10030.8, -62.5)

Mytus VII was a planet located in the Mytus system in Wild Space. It was the site of Stars' End prison. Around 10 BBY, a job listing for security guard located at Mytus VII was put out by Stars' End Recruitment Office to employ under C.S.A. Security Police.
