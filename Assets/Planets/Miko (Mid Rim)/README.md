# Miko

**Continuity:** Legends  
**Source:** [Miko (Mid Rim)](https://starwars.fandom.com/wiki/Miko_%28Mid_Rim%29)
**Galaxy atlas:** system `Miko`, Wild Space — map position (6743.5, -15184.5, 266.8)
