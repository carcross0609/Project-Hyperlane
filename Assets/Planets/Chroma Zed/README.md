# Chroma Zed

**Continuity:** Legends  
**Source:** [Chroma Zed](https://starwars.fandom.com/wiki/Chroma_Zed)
**Galaxy atlas:** system `Chroma Zed`, Mid Rim, grid Q-12 — map position (7733.9, -4264.7, -75.0)

Chroma Zed was a terrestrial planet located in the Maerdocian sector of the galaxy's Mid Rim. Home to the wormlike humanoid Chromans, who lived in moist mountain burrows near water, the planet featured some of the most magnificent amphitheater facilities, including one with twin waterfalls.
