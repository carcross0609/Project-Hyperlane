# Budpock

**Continuity:** Legends  
**Source:** [Budpock](https://starwars.fandom.com/wiki/Budpock)
**Galaxy atlas:** system `Budpock`, Outer Rim, grid R-7 — map position (9821.6, 4399.9, 20.5)

Budpock was a long time supporter of the Rebel Alliance and a New Republic-aligned planet in the Meridian sector. However, the world was also a haven for pirate gangs. Many of these groups were provoked by Dzym to attack neighboring Ampliquen, breaking the truce between Budpock and Ampliquen.
