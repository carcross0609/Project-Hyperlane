# Drup III

**Continuity:** Legends  
**Source:** [Drup III](https://starwars.fandom.com/wiki/Drup_III)
**Galaxy atlas:** system `Drup III`, Outer Rim — map position (6773.2, 4946.7, 133.4)

Drup III was a volcanic planet with two moons. It occupied the third orbital position around the binary stars Drup's Star and Drup's Companion in the Drup's Star system, a part of the Outer Rim Territories' Saijo sector.
