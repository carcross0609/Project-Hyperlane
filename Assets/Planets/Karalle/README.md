# Karalle

**Continuity:** Canon  
**Source:** [Karalle](https://starwars.fandom.com/wiki/Karalle)

Karalle was a swamp planet located in the Outer Rim's Albanin sector. The force-sensitive Quermian Jarea Kaela once hid on Karalle to hide from bounty hunters and the Inquisitorius.
