# Sarrelon II

**Continuity:** Legends  
**Source:** [Sarrelon II](https://starwars.fandom.com/wiki/Sarrelon_II)
**Galaxy atlas:** system `Sarrelon II`, Expansion Region, grid O-15 — map position (4667.4, -7941.1, -21.2)

Sarrelon II was the second planet in the Sarrelon system of the Expansion Region. A desolate, searing ball of rock, Sarrelon II was orbited by three moons.
