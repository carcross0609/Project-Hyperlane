# Kalsunor

**Continuity:** Legends  
**Source:** [Kalsunor](https://starwars.fandom.com/wiki/Kalsunor)
**Galaxy atlas:** system `Kalsunor`, Outer Rim, grid R-4 — map position (9220.4, 7540.2, -31.0)

Kalsunor was a planet conquered by the Sith Empire sometime prior to the Golden Age of the Sith. It was close to Begeren and Ashas Ree and was located on the Kamat Aegit.
