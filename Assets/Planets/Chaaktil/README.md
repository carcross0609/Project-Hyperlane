# Chaaktil

**Continuity:** Canon  
**Source:** [Chaaktil](https://starwars.fandom.com/wiki/Chaaktil)
**Galaxy atlas:** system `Chaaktil`, Other, grid R-16 — map position (10089.5, -9207.3, 12.4)

Chaaktil was a desert planet located in the Chaaktil system in the Inner Rim, in grid square N-14 on the Standard Galactic Grid. It had many cities, such as Chaako City. The bounty hunter Bazine Netal grew up on Chaaktil, where she learned a range of deadly martial arts at Delphi Kloda's combat school. Chaaktil was also the homeworld of Vi Moradi.
