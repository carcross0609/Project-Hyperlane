# Sarapin Four

**Continuity:** Legends  
**Source:** [Sarapin Four](https://starwars.fandom.com/wiki/Sarapin_Four)

Sarapin Four was a planet in the Sarapin system of the Core Worlds. During the Cold War, the Galactic Republic Valor-class cruiser Enkindle retreated to the upper atmosphere of Sarapin Four, but was destroyed by Imperial forces.
