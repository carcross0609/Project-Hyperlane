# Abregado-taki

**Continuity:** Legends  
**Source:** [Abregado-taki](https://starwars.fandom.com/wiki/Abregado-taki)

Abregado-taki was a planet in the Abregado system within the Southern Core portion of the Core Worlds. It was the fifth and farthest planet away from the star, Anza, and because of this, it was very cold and icy. In addition to being icy, the planet's surface was also rocky. The planet was not orbited by any moons.
