# Sluis Van

**Continuity:** Legends  
**Source:** [Sluis Van/Legends](https://starwars.fandom.com/wiki/Sluis_Van/Legends)
**Galaxy atlas:** system `Sluis Van`, Outer Rim, grid M-19 — map position (2411.1, -13762.1, -3.7)

Sluis Van was the primary planet in the Sluis sector of the Outer Rim Territories. It was the homeworld of the Sluissi race and the location of the famous Sluis Van Shipyards.
