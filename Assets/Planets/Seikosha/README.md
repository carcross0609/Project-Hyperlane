# Seikosha

**Continuity:** Canon  
**Source:** [Seikosha](https://starwars.fandom.com/wiki/Seikosha)
**Galaxy atlas:** system `Seikosha`, Outer Rim, grid P-4 — map position (6650.5, 8585.9, -317.5)

Seikosha was the fourth planet in the Breago system, a star system located in the Trans-Hydian Borderlands region of the Outer Rim Territories. Cryospac Repulsorlift Corporation, who produced the Model 90 Ranger landspeeder, was based on the planet.
