# Maryx Minor

**Continuity:** Legends  
**Source:** [Maryx Minor/Legends](https://starwars.fandom.com/wiki/Maryx_Minor/Legends)
**Galaxy atlas:** system `Maryx Minor`, Outer Rim, grid O-19 — map position (5488.3, -14365.2, 85.9)

Maryx Minor was a volcanic planet in the Outer Rim Territories, covered in geysers and pits of lava. It was the location of the hermitage of the Ancient Order of Pessimists, beyond the Maryb Wastes. Abal Karda fled to the hermitage with the head of Selestrine the prophet; while there, the terrified Karda threatened the hermits living there and killed one, named Mabob. Later, Darth Vader destroyed the hermitage by Star Destroyer barrage.
