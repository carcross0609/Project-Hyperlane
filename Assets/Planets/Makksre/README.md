# Makksre

**Continuity:** Legends  
**Source:** [Makksre](https://starwars.fandom.com/wiki/Makksre)

Makksre was the planet located in the Uoti sector of the Core Worlds in the galaxy. Sansia Bardrin and her ship were captured by pirates some time prior to 18 ABY.
