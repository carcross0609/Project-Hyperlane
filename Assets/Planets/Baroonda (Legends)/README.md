# Baroonda

**Continuity:** Legends  
**Source:** [Baroonda/Legends](https://starwars.fandom.com/wiki/Baroonda/Legends)
**Galaxy atlas:** system `Baroonda`, Outer Rim, grid T-9 — map position (13109.3, 1305.3, 47.9)

Baroonda was a planet of varied geography. It was host to several podracing tracks which passed through many diverse locations, including volcanoes, swamps, wide, sandy beaches, spectacular waterfalls, thick jungles, sulfur geyser fields, and plateau-top cities. It had some inhabited moons.
