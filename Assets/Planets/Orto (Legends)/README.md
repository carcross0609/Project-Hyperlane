# Orto

**Continuity:** Legends  
**Source:** [Orto/Legends](https://starwars.fandom.com/wiki/Orto/Legends)
**Galaxy atlas:** system `Orto`, Outer Rim, grid M-19 — map position (2195.1, -13657.0, 42.9)

Orto was a small planet in the Orto system of the Sluis sector, located in the Outer Rim Territories. It was the homeworld of the Ortolan race.
