# Thule

**Continuity:** Canon  
**Source:** [Thule](https://starwars.fandom.com/wiki/Thule)
**Galaxy atlas:** system `Thule`, Outer Rim, grid Q-5 — map position (8845.8, 7394.3, -239.6)

Thule was an arid mountainous planet within the Thurra system in the Esstran sector of the Outer Rim Territories. The planet shared its name with a mercenary gang known as Thugs of Thule.
