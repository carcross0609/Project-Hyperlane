# Xxan

**Continuity:** Legends  
**Source:** [Xxan](https://starwars.fandom.com/wiki/Xxan)
**Galaxy atlas:** system `Xxan`, Outer Rim, grid R-7 — map position (9728.1, 4032.3, -524.9)

Xxan was a water-covered planet that was located in the Outer Rim Territories. The underwater city Acquos was located on the world, and was connected to a small spaceport on the surface of the planet, via a turbolift.
