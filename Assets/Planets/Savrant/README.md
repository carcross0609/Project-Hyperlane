# Savrant

**Continuity:** Legends  
**Source:** [Savrant](https://starwars.fandom.com/wiki/Savrant)
**Galaxy atlas:** system `Savrant`, Expansion Region, grid O-14 — map position (5397.0, -6163.8, -10.7)

Savrant was the outermost planet of the Bacrana system, and the smallest of the system's gas giants. The green-yellow planet had six moons. All six were strip-mined by Lant Mining Corporation and subsequently abandoned. Calito, the planet's third moon, was taken over by the Bacrana System Defense Force and converted into a surveillance post which serves to monitor the outermost regions of the system.
