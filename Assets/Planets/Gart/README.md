# Gart

**Continuity:** Legends  
**Source:** [Gart](https://starwars.fandom.com/wiki/Gart)
**Galaxy atlas:** system `Gart`, Expansion Region — map position (3519.1, -9541.0, 136.8)

Gart was the second planet in orbit in the Demar system. Over 30 years before the Battle of Yavin it had been reduced to an empty shell of rock by the Lant Mining Corporation. Gart was the first planet in the system to be mined by the LMC and was the first to be completely stripped of all available resources.

Although barren the planet was closely watched by LMC security ships and sensor droids. It was feared that the abandoned mines would be used as bases by pirates or the Rebel Alliance.
