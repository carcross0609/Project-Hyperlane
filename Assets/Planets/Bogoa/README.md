# Bogoa

**Continuity:** Legends  
**Source:** [Bogoa](https://starwars.fandom.com/wiki/Bogoa)
**Galaxy atlas:** system `Bogoa`, Expansion Region, grid N-14 — map position (3690.0, -6311.6, -87.4)

Bogoa was a planet covered in spires of durable coral, which could be used as ship-building materials. During the Clone Wars, the planet was under the protection of the Galactic Republic. Its coral made it a target for the Confederacy of Independent Systems, which battled the Galactic Republic for three long days and nights for control of the coral world.
