# Fosh homeworld

**Continuity:** Legends  
**Source:** [Fosh homeworld](https://starwars.fandom.com/wiki/Fosh_homeworld)

The homeworld of the Fosh species was a planet whose name and location were shrouded in mystery. Many xenobiologists believed that it was located in the Corporate Sector of the galaxy's Outer Rim Territories.
