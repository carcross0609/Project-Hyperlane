# Kilotowa

**Continuity:** Canon  
**Source:** [Kilotowa](https://starwars.fandom.com/wiki/Kilotowa)

Kilotowa was remote world home to the Kilotowan species. During the High Republic Era, the Romero Clan was from the world and developed a reputation throughout the Mid Rim.
