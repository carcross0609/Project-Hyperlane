# Baummu

**Continuity:** Legends  
**Source:** [Baummu](https://starwars.fandom.com/wiki/Baummu)
**Galaxy atlas:** system `Baummu`, Outer Rim, grid U-8 — map position (13842.5, 2667.2, 568.9)

Baummu was a planet located in the Shadola sector of the Outer Rim. It was violently attacked during the Galactic Civil War by Imperial forces led by Captain Briera. Briera was later known as the "Butcher of Baummu".
