# Orron III

**Continuity:** Legends  
**Source:** [Orron III](https://starwars.fandom.com/wiki/Orron_III)
**Galaxy atlas:** system `Orron III`, Outer Rim, grid S-4 — map position (11212.7, 8644.0, -105.3)

Orron III was an agricultural world located in the Orron system, in the Corporate Sector. An Authority Data Center was located there. Incoming traffic was restricted to drone barges for transporting crops and Authority fleet vessels. Orron III had three moons.
