# Bezim

**Continuity:** Legends  
**Source:** [Bezim](https://starwars.fandom.com/wiki/Bezim)
**Galaxy atlas:** system `Bezim`, Mid Rim, grid J-7 — map position (-1948.5, 3236.4, 52.7)

Bezim was a planet in the Mid Rim. The native Bezim joined with the people of Junction V, Delaluna, and Vicondor to build the Station 88 Spaceport. This coalition of planets chose to remain loyal to the Galactic Republic during the Clone Wars.
