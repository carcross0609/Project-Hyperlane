# Sy Myrth

**Continuity:** Canon  
**Source:** [Sy Myrth](https://starwars.fandom.com/wiki/Sy_Myrth)
**Galaxy atlas:** system `Sy Myrth`, Outer Rim, grid S-7 — map position (10501.6, 3763.5, -84.7)

Sy Myrth was a planet located in the Sy Myrth system in the Jospro sector of the Outer Rim Territories, in grid square S-7 of the Standard Galactic Grid. It was linked via hyperspace routes to Belderone, Boonta, Centares, and Jabiim. Sy Myrth was the homeworld of the Sy Myrthian Brookish Boon and the Sy Myrthian Senator Toonbuck Toora, who represented the world in the Galactic Senate of the Galactic Republic.
