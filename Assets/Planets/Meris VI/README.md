# Meris VI

**Continuity:** Legends  
**Source:** [Meris VI](https://starwars.fandom.com/wiki/Meris_VI)
**Galaxy atlas:** system `Meris VI`, Outer Rim — map position (12919.5, -8967.7, -293.6)

Meris VI was the outermost planet in the Meris system in Elrood sector. It was a frigid planet swept by constant ice storms. Meris VI had a breathable type II atmosphere in warmer seasons; in winter, the air was too cold to be safe without a heating mask filter.
