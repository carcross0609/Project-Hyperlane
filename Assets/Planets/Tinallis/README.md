# Tinallis

**Continuity:** Legends  
**Source:** [Tinallis](https://starwars.fandom.com/wiki/Tinallis)
**Galaxy atlas:** system `Tinallis`, Mid Rim, grid L-18 — map position (269.1, -12100.1, 241.6)

Tinallis was a planet located within the Tinallis system of the Mid Rim. Though it was an industrialized planet, it was noted for the wildlife in its oceans, seashores, and rainforests. One of its native creatures, the tresher, was a lucrative but illegal trade item.
