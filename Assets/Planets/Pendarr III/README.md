# Pendarr III

**Continuity:** Canon  
**Source:** [Pendarr III](https://starwars.fandom.com/wiki/Pendarr_III)
**Galaxy atlas:** system `Pendarr III`, Expansion Region, grid L-15 — map position (1102.2, -8970.1, -219.4)

Pendarr III was a planet located in the Pendarr system within the Alchenaut sector of the Expansion Region and Trailing Sectors. It was situated in grid square L-15 of the Standard Galactic Grid. Pendarr III was the homeworld of Davits Draven, a human general in the Alliance to Restore the Republic's Intelligence Service.
