# Salin

**Continuity:** Legends  
**Source:** [Salin](https://starwars.fandom.com/wiki/Salin)
**Galaxy atlas:** system `Salin`, Outer Rim, grid N-5 — map position (4137.7, 6332.4, 95.7)

Salin was an Outer Rim Territories world situated in the Sprizen sector. It served as the endpoint of the Salin Corridor and Veragi Trade Route hyperlanes. Salin was at one point part of territories controlled by the Kwa species before it was annexed by the Rakata species' Infinite Empire.
