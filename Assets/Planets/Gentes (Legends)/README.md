# Gentes

**Continuity:** Legends  
**Source:** [Gentes/Legends](https://starwars.fandom.com/wiki/Gentes/Legends)
**Galaxy atlas:** system `Gentes`, Outer Rim — map position (-5.4, 8705.0, 151.4)

Gentes was one of three habitable planets in the Anoat system of the Anoat sector, located in the Greater Javin of the Outer Rim. It was the homeworld of the Ugnaughts.
