# Di'wor

**Continuity:** Legends  
**Source:** [Di'wor](https://starwars.fandom.com/wiki/Di%27wor)
**Galaxy atlas:** system `Di'wor`, Outer Rim — map position (9800.6, -10357.4, -403.6)

Di'wor was a planet that was located in Di'wor system, in the Morshdine sector of the Outer Rim region of the galaxy. The planet's singfruit groves' pollination season attracted many tourists.

Mara Jade tracked the Cavrilhu Pirates that were fleeing their Kauron asteroid base to this planet before losing them completely.
