# Hettig

**Continuity:** Legends  
**Source:** [Hettig](https://starwars.fandom.com/wiki/Hettig)

Hettig was the sixth planet orbiting the star Rek in the Guter Wade system. Located in the Trilon sector of the Outer Rim, it was a gas giant.
