# Ryloon

**Continuity:** Legends  
**Source:** [Ryloon](https://starwars.fandom.com/wiki/Ryloon)
**Galaxy atlas:** system `Ryloon`, Outer Rim, grid J-5 — map position (-1981.4, 7383.7, -50.9)

Ryloon was Outer Rim Territories planet in Velcar sector, Ryloon systemand the site of several Imperial Remnant controlled orbital factories where captured prisoners were sent to work. The world remained part of the Remnant following its peace agreement with the New Republic.
