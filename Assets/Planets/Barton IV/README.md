# Barton IV

**Continuity:** Canon  
**Source:** [Barton IV](https://starwars.fandom.com/wiki/Barton_IV)

Barton IV was an icy planet where the Galactic Empire maintained a supply depot that stored armor and other equipment. The outpost was commanded by Clone Commander Mayday and his squad. When the squad's resources began to run low, Mayday put in a request for reinforcements, asking for more men and for new equipment, as the sensor beacons on the perimeter of the base were old and unreliable. It was not until many rotations later that a force led by Lieutenant Nolan and including the clone trooper CT-9904 "Crosshair" were sent to the outpost on the planet.
