# Bescane

**Continuity:** Legends  
**Source:** [Bescane/Legends](https://starwars.fandom.com/wiki/Bescane/Legends)
**Galaxy atlas:** system `Bescane`, Outer Rim, grid K-3 — map position (-1322.4, 9131.4, -285.8)

Bescane was a planet near Dantooine, run by Galentro Heavy Works. A cool, temperate world, it was overpopulated and covered in factories, its natural environment destroyed.
