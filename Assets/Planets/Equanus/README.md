# Equanus

**Continuity:** Legends  
**Source:** [Equanus](https://starwars.fandom.com/wiki/Equanus)
**Galaxy atlas:** system `Equanus`, Outer Rim, grid K-3 — map position (-159.2, 9557.1, 88.2)

Equanus was a planet located within the Nharl system of the Veragi sector, in the New Territories portion of the Outer Rim Territories. It was the homeworld of the Equani.
