# Maldra IV

**Continuity:** Legends  
**Source:** [Maldra IV](https://starwars.fandom.com/wiki/Maldra_IV)
**Galaxy atlas:** system `Maldra IV`, Outer Rim, grid U-8 — map position (13981.0, 2856.2, -25.3)

Maldra IV was a planet in the Maldra system of the Outer Rim's Shadola sector. Not long after the Battle of Yavin, the Galactic Empire sought to destroy a pirate base on the planet, but discovered the base actually belonged to the Rebels. The Empire claimed it was a munitions base; the Alliance claimed it was a refugee base. Regardless of the propaganda, Imperial forces led by the Imperial Star Destroyer Motivator under the command of Captain Briera demolished the base.
