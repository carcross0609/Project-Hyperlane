# Nyara

**Continuity:** Legends  
**Source:** [Nyara](https://starwars.fandom.com/wiki/Nyara)

Nyara was a planet containing a class-3 toxic weapons dump. In 13 ABY a team of thieves hired by Nom Anor raided the dump to retrieve a chunk of zinethium.
