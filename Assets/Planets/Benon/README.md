# Benon

**Continuity:** Legends  
**Source:** [Benon](https://starwars.fandom.com/wiki/Benon)

Benon was a planet in the Delantine system. It was the closest planet to Delantine itself. The Imperials were supposed to think Trux Zissu fled to Benon after abandoning the Timespan.
