# Tisht

**Continuity:** Legends  
**Source:** [Tisht](https://starwars.fandom.com/wiki/Tisht)
**Galaxy atlas:** system `Tisht`, Hutt Space, grid T-11 — map position (12741.2, -2659.6, -254.7)

Tisht was a planet that was located within the Tisht system in Hutt Space, a region of the galaxy controlled by the Hutt species. The planet lay on the hyperlane called the Dead Road, which connected it to the worlds of M'Hanna and Saqqar.

It was only possible to travel to Tisht with the authorization of the Hutt Grand Council, the ruling political body of the Hutt species. As a result, outsiders knew almost nothing about the planet.
