# Maltheen Divide

**Continuity:** Canon  
**Source:** [Maltheen Divide](https://starwars.fandom.com/wiki/Maltheen_Divide)

The Maltheen Divide was a planet in the Maltheen Divide system of the Mid Rim Territories' Trax sector where, in 4 BBY, a secret Imperial meeting occurred in a mountain lodge to discuss and plan for the Imperial suppression of the planet Ghorman.
