# Halm

**Continuity:** Legends  
**Source:** [Halm](https://starwars.fandom.com/wiki/Halm)
**Galaxy atlas:** system `Halm`, Mid Rim, grid J-16 — map position (-2564.3, -9452.3, -11.4)

Halm was an arid desert world in the Mid Rim, famous for its extensive mines. These mines contained rare Adegan crystals, which were used in the construction of lightsabers.
