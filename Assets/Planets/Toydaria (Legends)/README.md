# Toydaria

**Continuity:** Legends  
**Source:** [Toydaria/Legends](https://starwars.fandom.com/wiki/Toydaria/Legends)
**Galaxy atlas:** system `Toydaria`, Hutt Space, grid R-11 — map position (10070.4, -2562.2, -123.8)
