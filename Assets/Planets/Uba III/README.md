# Uba III

**Continuity:** Legends  
**Source:** [Uba III](https://starwars.fandom.com/wiki/Uba_III)

Uba III was a planet located within the Uba system of the Mid Rim. It was a home to an Ubese colony, which was destroyed by the Jedi in 1800 BBY during the New Sith Wars, an act that aroused massive amounts of contempt for the Order. It became an asteroid belt.
