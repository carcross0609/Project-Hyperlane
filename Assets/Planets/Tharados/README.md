# Tharados

**Continuity:** Legends  
**Source:** [Tharados](https://starwars.fandom.com/wiki/Tharados)

Tharados was a small, cold planet that was located within the Tharados system of the Mid Rim. The Zabrak Haast Aath ran a slave compound there for Riboga the Hutt. Twelve clone troopers were also sent there during the Clone Wars, due to an administrative error.
