# Nar Hekka

**Continuity:** Legends  
**Source:** [Nar Hekka](https://starwars.fandom.com/wiki/Nar_Hekka)
**Galaxy atlas:** system `Nar Hekka`, Mid Rim — map position (-4700.4, -7922.6, -20.6)

Nar Hekka was a cold planet located barely beyond the edge of the Y'Toub system, where it also orbited a dim red star. It was situated on the Ootmian Pabol hyperlane between the worlds of Nal Hutta and Du Hutta. Nar Hekka also sat on the Sheela Run.
