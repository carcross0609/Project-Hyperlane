# Ab'Bshingh

**Continuity:** Legends  
**Source:** [Ab'Bshingh](https://starwars.fandom.com/wiki/Ab%27Bshingh)
**Galaxy atlas:** system `Ab'Bshingh`, Outer Rim, grid O-19 — map position (5893.8, -14187.1, -27.6)

Ab'Bshingh was a planet in the Outer Rim Territories, home to the Farang and Waroot species, who fought each other continuously for centuries. At some point, the Imperial military strategist Crat Dakerno went to the planet to study the two native species.
