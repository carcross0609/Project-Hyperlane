# Rellnas

**Continuity:** Legends  
**Source:** [Rellnas](https://starwars.fandom.com/wiki/Rellnas)
**Galaxy atlas:** system `Rellnas`, Expansion Region, grid J-16 — map position (-2592.4, -9892.2, 36.9)

The gas giant Rellnas was the sixth planet in the Rell system. Its sole moon, Rellnas Minor, was the homeworld of the Rellarin people.
