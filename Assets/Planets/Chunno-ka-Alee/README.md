# Chunno-ka-Alee

**Continuity:** Legends  
**Source:** [Chunno-ka-Alee](https://starwars.fandom.com/wiki/Chunno-ka-Alee)

Chunno-ka-Alee was the third planet orbiting the star Shadda in the Shadda-Bi-Boran system. Located in the Toblain sector of the Outer Rim Territories, it was a barren rock.
