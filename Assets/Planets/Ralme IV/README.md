# Ralme IV

**Continuity:** Legends  
**Source:** [Ralme IV](https://starwars.fandom.com/wiki/Ralme_IV)
**Galaxy atlas:** system `Ralme IV`, Expansion Region, grid O-14 — map position (5500.2, -7018.9, 193.5)

Ralme IV was a planet in Brak sector's Ralme system. Ralme IV was the site of mining operation overseen by Lant Mining Corporation. Two of the miners were the parents of future Brak sector crimelord Qual'om Soach.
