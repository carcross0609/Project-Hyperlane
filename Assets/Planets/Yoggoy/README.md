# Yoggoy

**Continuity:** Legends  
**Source:** [Yoggoy](https://starwars.fandom.com/wiki/Yoggoy)
**Galaxy atlas:** system `Yoggoy`, Unknown Regions, grid H-7 — map position (-4892.2, 3558.5, -43.0)

Yoggoy was a planet in the Unknown Regions. It was covered in mounds similar to the Castle Lands, with flowers imported from Alderaan. The Tachyon Flier crashed on Yoggoy in 27 ABY in the location known as the Crash. It was home to the Killiks of the Yoggoy hive and the capital of the Colony.
