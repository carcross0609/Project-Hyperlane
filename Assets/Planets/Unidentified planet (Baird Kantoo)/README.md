# Unidentified planet

**Continuity:** Unknown  
**Source:** [Unidentified planet (Baird Kantoo)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Baird_Kantoo%29)

A planet was where Baird Kantoo built the Kyber Saber. It was orbited by a moon which Kantoo accidentally destroyed while testing the newly constructed weapon, and was also known to be rich in kyber crystals. The Freemakers visited the planet during their quest to build the Arrowhead starship.
