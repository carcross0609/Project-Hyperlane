# Muunilinst

**Continuity:** Legends  
**Source:** [Muunilinst/Legends](https://starwars.fandom.com/wiki/Muunilinst/Legends)
**Galaxy atlas:** system `Muunilinst`, Outer Rim, grid K-4 — map position (-1207.5, 8254.6, 224.6)

Muunilinst (pronounced "MYOON-il-ist", with a silent "n" near the end in Galactic Basic), nicknamed Moneylend, was the temperate, mineral-rich planet that was the homeworld of the Muun species and headquarters of the InterGalactic Banking Clan, which maintained a subdivision on-world. It was located on the Braxant Run. It was a member of the Confederacy of Independent Systems under Chairman San Hill.
