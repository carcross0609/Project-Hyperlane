# Endex

**Continuity:** Legends  
**Source:** [Endex](https://starwars.fandom.com/wiki/Endex)
**Galaxy atlas:** system `Endex`, Outer Rim, grid J-5 — map position (-1674.5, 7476.3, 165.6)

Endex was a world of rocky canyons. It was the Entymal homeworld. During the time of the Old Republic, the Entymals were renowned as excellent pilots across the galaxy. For centuries, many pilots were trained in the canyons which left a lot of wreckage behind.

After the rise of the Empire, however, the planet was subjugated and the Entymals were enslaved. This slavery and rule was continued by first the Pentastar Alignment, and then the Imperial Remnant.
