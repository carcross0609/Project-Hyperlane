# Patrolia

**Continuity:** Canon  
**Source:** [Patrolia](https://starwars.fandom.com/wiki/Patrolia)
**Galaxy atlas:** system `Patrolia`, Inner Rim, grid L-14 — map position (1297.7, -6357.3, -129.9)

Patrolia was an aquatic planet in the Patrolia system of the Inner Rim Territories that was the homeworld of the Patrolian species. The Patrolian bounty hunter Robonino, who was active during the Clone Wars, hailed from Patrolia.
