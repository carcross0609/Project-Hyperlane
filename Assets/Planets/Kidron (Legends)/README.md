# Kidron

**Continuity:** Legends  
**Source:** [Kidron/Legends](https://starwars.fandom.com/wiki/Kidron/Legends)
**Galaxy atlas:** system `Kidron`, Outer Rim — map position (12461.4, 1914.5, 659.8)

Kidron was a planet in Elrood sector, on the Elrood-Derilyn Trade Route. It was the homeworld of the sentient Orfite species as well as the quamin and slork creatures. Attakril Meats also operated on the planet.
