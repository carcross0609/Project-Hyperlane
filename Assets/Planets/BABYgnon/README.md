# BABYgnon

**Continuity:** Legends  
**Source:** [BABYgnon](https://starwars.fandom.com/wiki/BABYgnon)
**Galaxy atlas:** system `BABYgnon`, Outer Rim, grid O-6 — map position (5165.9, 5147.0, -65.5)

BABYgnon, alternatively known as Babygnon, was a gas giant–type planet that had eight moons and occupied the fifth orbital position around its sun, Domir, in the Dathomir system, a part of the Quelii sector in the New Territories portion of the Outer Rim Territories.
