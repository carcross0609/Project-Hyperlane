# Tsaokallus

**Continuity:** Canon  
**Source:** [Tsaokallus](https://starwars.fandom.com/wiki/Tsaokallus)

Tsaokallus was a planet located in the Mid Rim Territories that was the homeworld of the Heptooinian spy Haki Zeophrine. It was located along the Perlemian Trade Route, a few parsecs off Metalorn.
