# Dennogra

**Continuity:** Legends  
**Source:** [Dennogra/Legends](https://starwars.fandom.com/wiki/Dennogra/Legends)
**Galaxy atlas:** system `Dennogra`, Outer Rim, grid S-8 — map position (11642.3, 2856.7, -167.5)

Dennogra, formerly known as Tialvai, was an arid world in the Outer Rim Territories. One of its cities, Zio Snaffkin, was the home of Sprool the Trader.
