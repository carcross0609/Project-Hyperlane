# Caragon-Viner

**Continuity:** Canon  
**Source:** [Caragon-Viner](https://starwars.fandom.com/wiki/Caragon-Viner)

Caragon-Viner was a distant planet in the Caragon-Viner system of the Colonies that held a Jedi outpost during the High Republic Era. Jedi Master Stellan Gios was once stationed there alongside Jedi Knight Indeera Stokes.
