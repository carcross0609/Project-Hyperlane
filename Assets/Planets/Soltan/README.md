# Soltan

**Continuity:** Legends  
**Source:** [Soltan](https://starwars.fandom.com/wiki/Soltan)

Soltan was a planet in the Ansion system, which was located in the Mid Rim's Churnis sector. A ball of barren rock, it was in an area of space aligned with the Galactic Republic, and later the Galactic Empire.
