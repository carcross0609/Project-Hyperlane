# Ord Tessebok

**Continuity:** Legends  
**Source:** [Ord Tessebok](https://starwars.fandom.com/wiki/Ord_Tessebok)
**Galaxy atlas:** system `Ord Tessebok`, Mid Rim, grid K-6 — map position (-137.9, 4623.2, -298.2)

Ord Tessebok was a Mid Rim planet situated in the Irishi sector. Serving as a Galactic Republic Ordnance/Regional Depot outpost during the Pius Dea Era, millennia later it loosened its immigration restrictions for people displaced by the Separatist Crisis. Eventually the planet became a part of the New Republic.
