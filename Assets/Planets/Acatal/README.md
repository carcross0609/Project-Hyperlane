# Acatal

**Continuity:** Legends  
**Source:** [Acatal](https://starwars.fandom.com/wiki/Acatal)
**Galaxy atlas:** system `Acatal`, Outer Rim, grid M-20 — map position (2581.9, -15190.5, 315.8)

Acatal was a barren, rocky planet, and the second world in the Elrood system. It was owned by Radell Mining Corporation, which extracted raw ores.
