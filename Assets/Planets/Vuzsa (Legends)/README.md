# Vuzsa

**Continuity:** Legends  
**Source:** [Vuzsa/Legends](https://starwars.fandom.com/wiki/Vuzsa/Legends)
**Galaxy atlas:** system `Vuzsa`, Outer Rim, grid R-16 — map position (9636.3, -9861.8, -192.1)

Vuzsa was an Outer Rim Territories world located in the Arkanis sector. It served as a refueling point for starships traveling along the Trans Gulf Route hyperlane. During the Galactic Civil War, the Rebel Alliance maintained a safehouse at Vuzsa, at which the Rebel agent Tiree once hid in order to evade capture by the Galactic Empire.
