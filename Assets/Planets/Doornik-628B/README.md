# Doornik-628B

**Continuity:** Legends  
**Source:** [Doornik-628B](https://starwars.fandom.com/wiki/Doornik-628B)
**Galaxy atlas:** system `Doornik-628B`, Core Worlds — map position (2911.5, -672.1, 11.8)

Doornik-628B was the second planet in the Doornik-628 system, which was located in the Farlax sector, a part of the Negs portion of the Core Worlds. The planet orbited the star Doornik-628 and was itself circled by a single moon. Doornik-628B, like its neighbor Doornik-628C, featured acidic clouds.
