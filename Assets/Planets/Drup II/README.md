# Drup II

**Continuity:** Legends  
**Source:** [Drup II](https://starwars.fandom.com/wiki/Drup_II)
**Galaxy atlas:** system `Drup II`, Outer Rim — map position (3999.8, 5005.9, -126.6)

Drup II was a gas giant–type planet with five moons. It occupied the second closest orbital position around the binary stars Drup's Star and Drup's Companion in the Drup's Star system, a part of the Outer Rim Territories' Saijo sector.
