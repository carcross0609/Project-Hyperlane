# R-Duba

**Continuity:** Legends

**Galaxy atlas:** system `R-Duba`, Outer Rim, grid T-15 — map position (12748.8, -7811.3, -275.4)

R-Duba was a desert and ocean planet located in the R-Duba system, within the Quiberon sector of the galaxy's Outer Rim Territories. A minor trade world, it was located in a backwater province of the Galactic Empire.
