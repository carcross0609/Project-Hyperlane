# Galpos II

**Continuity:** Canon  
**Source:** [Galpos II](https://starwars.fandom.com/wiki/Galpos_II)
**Galaxy atlas:** system `Galpos II`, Outer Rim, grid S-15 — map position (11337.3, -8220.0, -413.2)

Galpos II was a planet home to a nest of Thalassian slavers that was located in the Galpos system in the Abrion sector of the Outer Rim Territories, in grid square S-15 of the Standard Galactic Grid. The 291st Legion cleared out the enslavers with the aid of the newly released AT-DPs.
