# Kwookrrr

**Continuity:** Legends  
**Source:** [Kwookrrr](https://starwars.fandom.com/wiki/Kwookrrr)
**Galaxy atlas:** system `Kwookrrr`, Mid Rim, grid Q-9 — map position (7856.0, 74.2, -219.1)

Kwookrrr was a planet where the Galactic Empire used enslaved Wookiee children for labor in factories and farms. It had previously been a Wookiee colony world.
