# Ushruu

**Continuity:** Canon  
**Source:** [Ushruu](https://starwars.fandom.com/wiki/Ushruu)

Ushruu was a forested planet in the Ushruu system in the Altier sector of the Expansion Region. It was also the homeworld of the Enchantress, a female Force-sensitive human.
