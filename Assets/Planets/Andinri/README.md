# Andinri

**Continuity:** Legends  
**Source:** [Andinri](https://starwars.fandom.com/wiki/Andinri)
**Galaxy atlas:** system `Andinri`, Colonies, grid M-9 — map position (1881.5, 1209.2, -7.1)

Andinri was a gas giant in the Carida system, a star system in the Colonies region of the galaxy. Andinri was the sixth and farthest planet in the system from the star Caridan, and Andinri was orbited by twenty moons.
