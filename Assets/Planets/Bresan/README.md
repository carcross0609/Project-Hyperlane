# Bresan

**Continuity:** Legends  
**Source:** [Bresan](https://starwars.fandom.com/wiki/Bresan)
**Galaxy atlas:** system `Bresan`, Outer Rim, grid M-21 — map position (2032.7, -16888.3, -626.2)

Bresan was one of three primary planets in the Pimbrellan League. It was not as hospitable as nearby Dolstan. Its atmosphere could not sustain most humanoid life. Sealed dome cities were built in underground cave systems. Profits from trade with Dolstan were used to support life support facilities.
