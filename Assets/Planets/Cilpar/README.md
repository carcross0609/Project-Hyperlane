# Cilpar

**Continuity:** Legends  
**Source:** [Cilpar](https://starwars.fandom.com/wiki/Cilpar)
**Galaxy atlas:** system `Cilpar`, Colonies, grid L-13 — map position (18.9, -5519.6, -145.7)

Cilpar was an agriworld in the Colonies, nearly covered in mountains, jungles, and forests. It was characterized by the near-indestructible ancient temples scattered across the surface. Local flora and fauna included the predatory ronk.
