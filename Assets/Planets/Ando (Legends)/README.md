# Ando

**Continuity:** Legends  
**Source:** [Ando/Legends](https://starwars.fandom.com/wiki/Ando/Legends)
**Galaxy atlas:** system `Ando`, Mid Rim, grid Q-15 — map position (7887.5, -8964.5, 140.7)

Ando was an oceanic planet located in the Ando system of the Mid Rim. It was also the homeworld of the Aqualish species.
