# Kurdavvia

**Continuity:** Legends  
**Source:** [Kurdavvia](https://starwars.fandom.com/wiki/Kurdavvia)

Kurdavvia was a planet in the Core Worlds of the galaxy known for its bright sunrises. Princess Kalieva K'ntarr's face lit up like one when Sienn Sconn agreed to help her gain passage off of Rydonni Prime.

- **Name:** Kurdavvia
- **Region:** Core Worlds
- **System:** Kurdavvia system
