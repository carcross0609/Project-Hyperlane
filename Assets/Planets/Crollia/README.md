# Crollia

**Continuity:** Legends  
**Source:** [Crollia](https://starwars.fandom.com/wiki/Crollia)
**Galaxy atlas:** system `Crollia`, Core Worlds, grid M-11 — map position (2185.5, -2015.7, -11.5)

Crollia was the sixth planet in the Corellian system; it was a barren, rocky world, unable to sustain life, and possessed no moons. Crollia and the other lifeless world in the star system, Soronia, were both located on the fringes of the system, and were believed to have naturally formed in orbit around the star Corell—unlike the other five worlds, which were placed in the system through the use of Centerpoint Station.
