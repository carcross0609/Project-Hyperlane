# Reamma

**Continuity:** Canon  
**Source:** [Reamma](https://starwars.fandom.com/wiki/Reamma)
**Galaxy atlas:** system `Reamma`, Outer Rim, grid T-15 — map position (12515.2, -7855.0, 123.9)

Reamma was a planet located in the Reamma system in the Corbett sector of the Mid Rim Territories. Sometime after the Battle of Yavin, the Alliance to Restore the Republic set up a temporary base, LX-Robynsun V, on Reamma. The Resistance used LX-Robynsun V as a base during the Cold War between the First Order and the Resistance.
