# Biewa

**Continuity:** Legends  
**Source:** [Biewa](https://starwars.fandom.com/wiki/Biewa)
**Galaxy atlas:** system `Biewa`, Outer Rim, grid S-4 — map position (10928.1, 8795.8, 93.5)

Biewa was an industrial planet in the Corporate Sector used as the headquarters of the Corporate Sector Authority Picket Fleet. It was a relatively poor world, and the Biewans spent what few credits they had on clothing, shelter and food.
