# Belthu

**Continuity:** Legends  
**Source:** [Belthu](https://starwars.fandom.com/wiki/Belthu)
**Galaxy atlas:** system `Belthu`, Outer Rim, grid O-7 — map position (5247.4, 3784.1, 25.5)

Belthu was a unaligned Outer Rim Territories world located near the territory of Warlord Zsinj. A wealthy planet being controlled by a coalition of mining companies led by corporate executives, it had a durasteel foundry that was owned by an alias of Zsinj. The facility was eventually destroyed by Wraith Squadron and the New Republic.
