# Verisin

**Continuity:** Legends  
**Source:** [Verisin](https://starwars.fandom.com/wiki/Verisin)
**Galaxy atlas:** system `Verisin`, Outer Rim, grid P-17 — map position (7000.8, -11586.0, -75.5)

Verisin was a world located within the star system of the same name, a part of the Outer Rim Territories' Bajic sector. Around the year 10 ABY, it served as the homeworld of the Tenloss Coalition, a criminal organization specializing in contract kidnapping.
