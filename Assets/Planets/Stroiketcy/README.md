# Stroiketcy

**Continuity:** Legends  
**Source:** [Stroiketcy](https://starwars.fandom.com/wiki/Stroiketcy)

Stroiketcy was a comet captured in the orbit of the star Yavin. The name "Stroiketcy" came from a Corellian word meaning "tailed one."
