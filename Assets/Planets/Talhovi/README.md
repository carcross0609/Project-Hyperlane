# Talhovi

**Continuity:** Legends  
**Source:** [Talhovi](https://starwars.fandom.com/wiki/Talhovi)
**Galaxy atlas:** system `Talhovi`, Mid Rim, grid K-18 — map position (-10.7, -12090.5, 469.4)

Talhovi was a Mid Rim world located in the Juvex sector. It was the homeworld of the Mekuun family, with whom the Ancient Houses of the Senex-Juvex region had prohibited trade. Talhovi nevertheless remained economically powerful and exported goods such as Talhovian ale.
