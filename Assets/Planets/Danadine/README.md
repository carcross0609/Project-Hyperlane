# Danadine

**Continuity:** Legends  
**Source:** [Danadine](https://starwars.fandom.com/wiki/Danadine)
**Galaxy atlas:** system `Danadine`, Outer Rim, grid Q-18 — map position (7614.7, -13090.3, -695.9)

Danadine was a world located in the Danadine system, a part of the Outer Rim Territories' Dail sector. Around 10 ABY, it served as the homeworld of Relekin Confidential, a collection agency that constituted a part of the Tenloss Syndicate.
