# Ryvellia

**Continuity:** Legends  
**Source:** [Ryvellia](https://starwars.fandom.com/wiki/Ryvellia)
**Galaxy atlas:** system `Ryvellia`, Expansion Region, grid O-14 — map position (5822.3, -6585.8, -101.9)

Ryvellia was a planet located in the Avhn-Bendara system. Its capital city, V'eldalv, was the site of a brutal uprising that was crushed by the Galactic Empire via orbital bombardment.
