# Valgauth

**Continuity:** Legends  
**Source:** [Valgauth/Legends](https://starwars.fandom.com/wiki/Valgauth/Legends)
**Galaxy atlas:** system `Valgauth`, Expansion Region, grid P-9 — map position (6084.9, 1245.0, 41.5)

Valgauth was one of three planets in the Valgauth system of the Expansion Region, and the only one to support any life. It was covered in barren wastelands and junk fields.
