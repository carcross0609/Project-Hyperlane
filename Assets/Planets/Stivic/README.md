# Stivic

**Continuity:** Canon  
**Source:** [Stivic](https://starwars.fandom.com/wiki/Stivic)

Stivic was a colony world of the Garwians located in the Stivic system of the Unknown Regions. Like other Garwian Unity worlds, it was a commerce center for a number of species.

Of all the Garwian worlds, Stivic was particularly close to Lioaoin space. That made Stivic an easy target for a Lioaoin pirate attack, where a Garwian merchant-hub station was attacked.
