# Jhosh

**Continuity:** Canon  
**Source:** [Jhosh](https://starwars.fandom.com/wiki/Jhosh)

Jhosh was a world located in the Fla'Nagan system. The First Order had a base on Jhosh, which the Resistance operatives Poe Dameron and BB-8 planned to break into to steal information on their troop movements. They used a stolen cargo ship to get onto Jhosh, where BB-8 infiltrated the base.
