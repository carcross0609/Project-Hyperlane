# Qogo

**Continuity:** Legends  
**Source:** [Qogo](https://starwars.fandom.com/wiki/Qogo)

Qogo was an amber clouded gas giant and twin of Uluq in the Hapes Cluster and shared the same system as Shedu Maad in the Transitory Mists. Uroro Station was once built between Qogo and Uluq to serve as a transfer station for Hapan ships traveling along the Throat to the mining world of Shedu Maad.
