# Dakot Seven

**Continuity:** Legends  
**Source:** [Dakot Seven](https://starwars.fandom.com/wiki/Dakot_Seven)

Dakot Seven was a planet in the Dakot system of the Mortex sector. An academically-minded world, it was the location of Dakot Tech, an Imperial Technical Branch Outpost. It was the site of the Battle on Dakot Seven.
