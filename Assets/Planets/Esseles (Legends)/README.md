# Esseles

**Continuity:** Legends  
**Source:** [Esseles/Legends](https://starwars.fandom.com/wiki/Esseles/Legends)
**Galaxy atlas:** system `Esseles`, Core Worlds, grid L-9 — map position (974.8, 574.7, 37.9)

Esseles was a planet located along the Perlemian Trade Route in Darpa sector of the Ringali Shell. It was the third in position in the Essesia system and had one moon.
