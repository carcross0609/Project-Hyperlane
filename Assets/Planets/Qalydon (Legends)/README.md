# Qalydon

**Continuity:** Legends  
**Source:** [Qalydon/Legends](https://starwars.fandom.com/wiki/Qalydon/Legends)
**Galaxy atlas:** system `Qalydon`, Outer Rim, grid R-5 — map position (10075.0, 7163.8, -2.7)

Qalydon was a planet located in the Qalydon system of the Outer Rim's Sertar sector. The planet served as the headquarters of the Fellowship of Kooroo.
