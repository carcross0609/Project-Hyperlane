# Erdo

**Continuity:** Canon  
**Source:** [Erdo](https://starwars.fandom.com/wiki/Erdo)

Erdo was a mining planet in the Erdo system in the Kriz sector of the Outer Rim Territories, situated in grid square K-19 along the Lipsec Run hyperspace route. Several decades before 160 BBY, Erdo's previously-prosperous mines shut down, leaving the fortunes of Erdo and other worlds along the route, such as Ruathi, on the downturn.
