# Commenor

**Continuity:** Canon  
**Source:** [Commenor](https://starwars.fandom.com/wiki/Commenor)
**Galaxy atlas:** system `Commenor`, Colonies, grid N-10 — map position (3466.5, -1474.4, -165.4)

Commenor was an ancient, conservative planet located in the Colonies region of the galaxy. It was located in the Commenor system along the Trellen Trade Route, and was an endpoint of the Commenor Run and the Quellor Run hyperspace routes.
