# Vinza

**Continuity:** Legends  
**Source:** [Vinza](https://starwars.fandom.com/wiki/Vinza)

Vinza was a hothouse world located in the Anoat sector of the Outer Rim Territories. It had no moons and was located in Separatist space during the Clone Wars.
