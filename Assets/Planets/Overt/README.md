# Overt

**Continuity:** Legends  
**Source:** [Overt](https://starwars.fandom.com/wiki/Overt)

Overt was the eighth planet orbiting the star Prael in the Japrael system. Located in the Japrael sector of the Inner Rim, it was a gas giant.
