# Spussion

**Continuity:** Legends  
**Source:** [Spussion](https://starwars.fandom.com/wiki/Spussion)

Spussion was the sixth planet of the Bestine system located in the Inner Rim Territories. Spussion was one of the three gas giants in the star system and had twenty-one moons.
