# Endelaan

**Continuity:** Legends  
**Source:** [Endelaan](https://starwars.fandom.com/wiki/Endelaan)

Endelaan was a lost planet in the Unknown Regions that the Nebula organization believed would bring about the destruction of the galaxy if discovered. The crew of the starship Spiral Dancer was sent to find it.
