# Ieria

**Continuity:** Legends  
**Source:** [Ieria](https://starwars.fandom.com/wiki/Ieria)
**Galaxy atlas:** system `Ieria`, Colonies, grid L-13 — map position (1319.2, -5518.5, 44.0)

Ieria was a planet in the Andaran system in the Core Worlds. It rivaled the wealthier planet Andara in production capability, but received nowhere near the income. The Ierians did not enjoy indirect senatorial representation through Andara, and attempted an attack on Andara in 26 BBY.
