# Neral

**Continuity:** Canon  
**Source:** [Neral](https://starwars.fandom.com/wiki/Neral)
**Galaxy atlas:** system `Neral`, Core Worlds — map position (890.5, 118.9, -49.8)

Neral was a planet located in the Neral system in the Corellian sector of the Core Worlds that was orbited by one moon. Neral had been a rich planet, with many natural resources, but volanic eruptions destabilized the planet's core and caused the planet to explode. Only an asteroid field and its moon remained in its place.
