# Butler's Cove

**Continuity:** Legends  
**Source:** [Butler's Cove](https://starwars.fandom.com/wiki/Butler%27s_Cove)
**Galaxy atlas:** system `Butler's Cove`, Mid Rim, grid M-10 — map position (2624.8, -153.8, -201.0)

Butler's Cove was a previously uninhabited planet in the Stribos system of the Core Worlds. The planet was chosen by Soron Hegerty as a refuge for the Ssither that managed to escape from the Demophon system. Unrecorded in Imperial records, it was named for the pirate who discovered it. He hoped to use the planet as a base from which to raid the Demophon system, but was killed on his first raid. All additional information on the planet perished with him.
