# Sarm

**Continuity:** Legends  
**Source:** [Sarm](https://starwars.fandom.com/wiki/Sarm)

Sarm was a yellow planet in Wild Space which had been inhabited by an unknown species which built a vast irrigation canal network across the planet. When the Utegetu Nebula erupted, however, it scoured the planet clean of its population, leaving only the canal network behind. The Killik fleet would later mass above it, setting the stage for the Battle of Sarm.
