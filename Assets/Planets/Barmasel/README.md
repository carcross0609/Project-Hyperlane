# Barmasel

**Continuity:** Legends  
**Source:** [Barmasel](https://starwars.fandom.com/wiki/Barmasel)
**Galaxy atlas:** system `Barmasel`, Outer Rim, grid O-6 — map position (5219.6, 5219.0, 215.0)

Barmasel was a gas giant in the Dathomir system, a part of the Quelii sector in the New Territories portion of the Outer Rim Territories. The planet occupied the sixth orbital position around the star Domir and was orbited by thirteen moons.
