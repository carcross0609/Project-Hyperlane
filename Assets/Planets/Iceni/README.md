# Iceni

**Continuity:** Canon  
**Source:** [Iceni](https://starwars.fandom.com/wiki/Iceni)

Iceni was a rainswept planet in the Iceni system in the Corporate Sector of the Outer Rim Territories. It was where the luxury landspeeder company Arlen-Dempler was based.
