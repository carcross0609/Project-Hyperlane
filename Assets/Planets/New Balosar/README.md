# New Balosar

**Continuity:** Legends  
**Source:** [New Balosar](https://starwars.fandom.com/wiki/New_Balosar)
**Galaxy atlas:** system `New Balosar`, Expansion Region, grid K-16 — map position (-482.0, -9002.4, -58.2)

New Balosar was a planet in the Expansion Region, located on the Great Gran Run. It shared its name with the Core Worlds planet Balosar, the homeworld of the eponymous sentient species. It was the location of The Kindest Cut, a beauty salon run by Zenn Bien, the former owner of the Millennium Falcon.
