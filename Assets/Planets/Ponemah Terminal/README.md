# Ponemah Terminal

**Continuity:** Canon  
**Source:** [Ponemah Terminal](https://starwars.fandom.com/wiki/Ponemah_Terminal)
**Galaxy atlas:** system `Ponemah Terminal`, Outer Rim, grid K-10 — map position (-1272.8, -1161.9, 21.6)

Ponemah Terminal, also known simply as Ponemah, was a remote desert planet located in the galaxy's Outer Rim Territories, near the planets Ogem and Jakku in the Mid Rim. It was located not too far from the edge of New Republic space, and so was postulated to be a good place to drop off Resistance-friendly passengers.
