# Nizon

**Continuity:** Legends  
**Source:** [Nizon](https://starwars.fandom.com/wiki/Nizon)
**Galaxy atlas:** system `Nizon`, Mid Rim — map position (5033.0, 3448.2, -57.2)

Nizon was the fifth planet in the Centares system. It was the homeworld of the Nazren species. Agents of Bail Organa provoked the local resistance to oust Imperial occupation and Trandoshan slavers some months after the end of the Clone Wars.
