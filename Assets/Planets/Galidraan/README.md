# Galidraan

**Continuity:** Canon  
**Source:** [Galidraan](https://starwars.fandom.com/wiki/Galidraan)
**Galaxy atlas:** system `Galidraan`, Outer Rim, grid R-6 — map position (10239.0, 5386.6, 228.0)

Galidraan was a planet located in the Galidraan system within the galaxy's Outer Rim Territories. It shared its name with Galidraan III and Galidraan IV, all of which were located in the same system.
