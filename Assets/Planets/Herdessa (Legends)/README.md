# Herdessa

**Continuity:** Legends  
**Source:** [Herdessa/Legends](https://starwars.fandom.com/wiki/Herdessa/Legends)
**Galaxy atlas:** system `Herdessa`, Mid Rim, grid Q-16 — map position (8097.2, -9569.7, 266.5)

Herdessa was a planet located in the Mid Rim on the Corellian Run. A peaceful world, many diplomats and others of affluence could remain neutral in debates. It was represented in the Galactic Senate by Shea Sadashassa.
