# Itapi Prime

**Continuity:** Canon  
**Source:** [Itapi Prime](https://starwars.fandom.com/wiki/Itapi_Prime)
**Galaxy atlas:** system `Itapi Prime`, Other, grid Q-11 — map position (8755.2, -2105.9, -238.7)

Itapi Prime was a prosperous planet in the Itapi Prime system of the Core Worlds near Coruscant. In 3 BBY, it was firmly loyal to the Galactic Empire. A significant amount of trade from the planet used to pass through Calderos Station.
