# Piroket

**Continuity:** Canon  
**Source:** [Piroket](https://starwars.fandom.com/wiki/Piroket)
**Galaxy atlas:** system `Piroket`, Outer Rim, grid R-16 — map position (9913.6, -9634.1, -307.7)

Piroket was a world located in the Piroket system in the Arkanis sector of the Outer Rim Territories, situated in grid square R-16 of the Standard Galactic Grid near the desert planet Tatooine, which was located in the Tatoo system of the Outer Rim Territories' Arkanis sector. Some of the residents and transients of Mos Eisley spaceport on Tatooine had travelled to the desert world from Piroket.
