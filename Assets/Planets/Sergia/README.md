# Sergia

**Continuity:** Canon  
**Source:** [Sergia](https://starwars.fandom.com/wiki/Sergia)
**Galaxy atlas:** system `Sergia`, Inner Rim, grid P-5 — map position (7340.4, 6481.9, 165.2)

Sergia was a desert planet in the Inner Rim of the galaxy. The Alliance to Restore the Republic operated a refueling station on the planet. When Imperial probes were reported to be close to the rebel refueling station, Luke Skywalker was sent to draw them away.
