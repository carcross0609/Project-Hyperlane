# Ord Bueri

**Continuity:** Legends  
**Source:** [Ord Bueri/Legends](https://starwars.fandom.com/wiki/Ord_Bueri/Legends)

Ord Bueri was a planet in the Ord Bueri system of the Outer Rim's Nilgaard sector. The Rebel Alliance's base on Yavin 4 used H-60 Tempest bombers from here.
