# Valahari

**Continuity:** Legends  
**Source:** [Valahari/Legends](https://starwars.fandom.com/wiki/Valahari/Legends)
**Galaxy atlas:** system `Valahari`, Outer Rim, grid N-5 — map position (3797.9, 7219.1, -50.1)

Valahari was an Outer Rim planet that claimed neutrality in the Clone Wars, but gave newer and advanced ships to the Confederacy of Independent Systems that gave the CIS an advantage over the Galactic Republic.

The people of Valahari had a strong reputation for being some of the best starfighter engineers in the galaxy.
