# Xo

**Continuity:** Legends  
**Source:** [Xo](https://starwars.fandom.com/wiki/Xo)
**Galaxy atlas:** system `Xo`, Outer Rim, grid N-2 — map position (3100.0, 10882.8, 152.7)

Xo was a planet located within the Xo system in the Spinward sector of the Outer Rim Territories. It was the homeworld of the Zanibar species and the site of their sacrificial rituals.
