# Bengat

**Continuity:** Legends  
**Source:** [Bengat](https://starwars.fandom.com/wiki/Bengat)
**Galaxy atlas:** system `Bengat`, Inner Rim, grid J-8 — map position (-1658.0, 2358.3, -107.1)
