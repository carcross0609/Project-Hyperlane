# Yasilor

**Continuity:** Legends  
**Source:** [Yasilor](https://starwars.fandom.com/wiki/Yasilor)
**Galaxy atlas:** system `Yasilor`, Outer Rim, grid P-17 — map position (6444.7, -10884.1, -405.4)

Yasilor was a world located within the star system of the same name, a part of the Outer Rim Territories' Bajic sector. Around the year 10 ABY, it served as the homeworld of the Palkandi Brokerage House, a front organization for the criminal Tenloss Syndicate.
