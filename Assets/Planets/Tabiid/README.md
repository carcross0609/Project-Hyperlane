# Tabiid

**Continuity:** Legends  
**Source:** [Tabiid](https://starwars.fandom.com/wiki/Tabiid)

Tabiid was a planet located in the Tabiid system of the Mid Rim that served as a base for the Antarian Rangers during the reign of the Galactic Empire.
