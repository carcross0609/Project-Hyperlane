# Hestria

**Continuity:** Legends  
**Source:** [Hestria](https://starwars.fandom.com/wiki/Hestria)
**Galaxy atlas:** system `Hestria`, Mid Rim, grid L-18 — map position (722.6, -12095.5, 15.7)

Hestria was a Mid Rim agriworld located in the Senex sector. It was known for the wines produced there. Around 3643 BBY, the government of Hestria shut down its secret police force that had been attempting to influence the governments of all the planets of the Hestria system.
