# Orondia

**Continuity:** Canon  
**Source:** [Orondia](https://starwars.fandom.com/wiki/Orondia)
**Galaxy atlas:** system `Orondia`, Hutt Space, grid S-11 — map position (10837.3, -2710.8, -570.0)

Orondia was a desolate world in the Orondia system in Hutt Space. During the Clone Wars, Obi-Wan Kenobi, disguised as Rako Hardeen, Cad Bane, and Moralo Eval were scammed into stopping there when a Bith gave him only enough fuel to reach Orondia, where his brother ran a fueling station.
