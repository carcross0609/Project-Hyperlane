# H'ratth

**Continuity:** Legends  
**Source:** [H'ratth](https://starwars.fandom.com/wiki/H%27ratth)
**Galaxy atlas:** system `H'ratth`, Inner Rim, grid N-10 — map position (3709.9, -208.5, 148.1)

H'ratth was a lush planet with a Jedi Academy where Jedi Master Chamma taught Andur Sunrider the Jedi ways in 4001 BBY. It was the homeworld of Vima Sunrider. The academy was known for its training of Jedi healers.
