# Abregado-fus

**Continuity:** Legends  
**Source:** [Abregado-fus](https://starwars.fandom.com/wiki/Abregado-fus)

Abregado-fus was the fourth planet from the star Anza in the Abregado system, within the Southern Core portion of the Core Worlds. It was a gas giant orbited by nine moons.
