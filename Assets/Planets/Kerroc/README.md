# Kerroc

**Continuity:** Unknown  
**Source:** [Kerroc](https://starwars.fandom.com/wiki/Kerroc)

Kerroc was an inhospitable planet allied with the First Order. During the Cold War, the Resistance hired Sidon Ithano and the crew of the Meson Martinet to infiltrate a First Order facility on Kerroc to steal an AAL-1971/9.1 Troop Transport needed to rescue Gial Ackbar, an important Resistance leader.
