# Baramorra

**Continuity:** Legends  
**Source:** [Baramorra](https://starwars.fandom.com/wiki/Baramorra)
**Galaxy atlas:** system `Baramorra`, Outer Rim, grid J-4 — map position (-2130.3, 8341.4, 11.2)

Baramorra was a temperate, dreary, rainsoaked Imperial Remnant planet governed by Admiral Llon Banjeer's nephew, the "Boss". He employed bounty hunters such as Jahnar-Kooda to keep the populace in line; when the planet's elders objected, he had them killed. The Boss was funded by Grappa the Hutt; when this was revealed, the Boss was executed as a traitor by Kir Kanos.
