# Unidentified planet

**Continuity:** Legends  
**Source:** [Unidentified planet (Enoth system)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Enoth_system%29)

A planet was located in the Enoth system. During the Clone Wars, the Confederacy of Independent Systems used the shipyards orbiting the planet to build a Subjugator-class heavy cruiser, while the heavy cruiser's deflector shield generator was located on the planet's surface.
