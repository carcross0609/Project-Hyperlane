# Ghorman

**Continuity:** Legends  
**Source:** [Ghorman/Legends](https://starwars.fandom.com/wiki/Ghorman/Legends)
**Galaxy atlas:** system `Ghorman`, Colonies, grid L-13 — map position (420.8, -5965.9, -285.6)

Ghorman was a planet in the Sern sector of the Colonies region. It was the site of the infamous Ghorman Massacre. Fang Zar had a residence on the planet.

It lay on the Rimma Trade Route.
