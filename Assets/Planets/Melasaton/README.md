# Melasaton

**Continuity:** Legends  
**Source:** [Melasaton](https://starwars.fandom.com/wiki/Melasaton)

Melasaton was a low-tech planet devastated by a great plague. It was saved from the plague when Arbor Industries developed an antidote, even though it was Arbor Industries that secretly unleashed the plague in the first place.
