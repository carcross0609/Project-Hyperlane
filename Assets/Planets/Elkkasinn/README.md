# Elkkasinn

**Continuity:** Legends  
**Source:** [Elkkasinn](https://starwars.fandom.com/wiki/Elkkasinn)

Elkkasinn was a world located in the Phelleem sector of the Outer Rim Territories. Many gunrunners of the Sendavé Shared Interest Collective were from Elkkasinn and Sunin.
