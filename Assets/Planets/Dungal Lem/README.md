# Dungal Lem

**Continuity:** Legends  
**Source:** [Dungal Lem](https://starwars.fandom.com/wiki/Dungal_Lem)

Dungal Lem was the third planet orbiting the star Tor in the Tobali system. Located in the Outer Rim Territories, it was a gas giant.
