# Cartao

**Continuity:** Canon  
**Source:** [Cartao](https://starwars.fandom.com/wiki/Cartao)
**Galaxy atlas:** system `Cartao`, Expansion Region, grid O-8 — map position (5653.6, 2117.9, 150.8)

Cartao was an Expansion Region astronomical object where the Galactic Empire kept a facility that became under threat from a potential dissident attack in 14 BBY. It was also the site of fighting during the Galactic Civil War, involving the Rebel Alliance's 61st Mobile Infantry.
