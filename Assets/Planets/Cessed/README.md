# Cessed

**Continuity:** Legends  
**Source:** [Cessed](https://starwars.fandom.com/wiki/Cessed)

Cessed was the planet closest to the sun in the Csilla system, which was located within Chiss Space in the Unknown Regions. It was uninhabited due to the searing hot temperatures emanating from the sun.
