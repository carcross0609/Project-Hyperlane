# Vasch

**Continuity:** Legends  
**Source:** [Vasch](https://starwars.fandom.com/wiki/Vasch)
**Galaxy atlas:** system `Vasch`, Outer Rim, grid R-17 — map position (9498.6, -10738.6, -503.2)

Vasch was a planet located within the Vasch system of the Outer Rim Territories. A world of lush, green, rolling hills, it was the source of Vaschean rye, and was possibly the homeworld of Sam Heggs.
