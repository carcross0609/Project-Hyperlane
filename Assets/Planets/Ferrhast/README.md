# Ferrhast

**Continuity:** Legends  
**Source:** [Ferrhast](https://starwars.fandom.com/wiki/Ferrhast)
**Galaxy atlas:** system `Ferrhast`, Core Worlds, grid L-13 — map position (494.7, -4824.7, 197.8)

Ferrhast was the planet in the Core Worlds and location of the Imperial Institute of Higher Studies. Despite its distance from the Sith Worlds, ruins built by members of the Massassi species were found on the world during the Galactic War.
