# Y'nybeth

**Continuity:** Legends  
**Source:** [Y'nybeth](https://starwars.fandom.com/wiki/Y%27nybeth)
**Galaxy atlas:** system `Y'nybeth`, Expansion Region, grid O-13 — map position (5723.7, -5422.8, 115.7)

Y'nybeth was a world located within the star system of the same name of the Expansion Region. It was the dark place and homeworld of the Plasmars, transparent amoebic creatures that absorbed any available warmth into their bodies.
