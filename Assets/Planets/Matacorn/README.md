# Matacorn

**Continuity:** Legends  
**Source:** [Matacorn](https://starwars.fandom.com/wiki/Matacorn)

Matacorn was a terrestrial world located in the Matacorn system, a part of the Mid Rim's Lambda sector. A nondescript trade world, it was the homeworld of the Human Hurst Romodi. Matacorn also shared its name with the Matacorn campaign, a part of the Galactic Civil War.
