# Sissubo

**Continuity:** Legends  
**Source:** [Sissubo/Legends](https://starwars.fandom.com/wiki/Sissubo/Legends)
**Galaxy atlas:** system `Sissubo`, Core Worlds, grid L-9 — map position (1113.6, 1082.3, 98.3)

Sissubo was the seventh planet of the Chandrila system, located in the Bormea sector of the Ringali Shell in the Core Worlds. The planet orbited the star Chandrila and was a frozen, rocky world circled by one moon. The Chandrila system lay on the Perlemian Trade Route, which served as a dividing line between the Northern Dependencies and the Arrowhead portion of the Slice.
