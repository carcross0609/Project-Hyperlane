# Bastion

**Continuity:** Canon  
**Source:** [Bastion](https://starwars.fandom.com/wiki/Bastion)
**Galaxy atlas:** system `Bastion`, Outer Rim, grid K-3 — map position (-1339.3, 9699.8, -169.1)

Bastion was an industrialized planet located in the Outer Rim Territories of the galaxy. Also part of the New Territories, it was connected via hyperspace route to Anthan Prime.

During the Clone Wars, Bastion fell within Separatist territory during the Outer Rim Sieges.

Sometime after the Galactic Civil War's end with the collapse of the Galactic Empire by the New Republic, the successor to the Imperial state began to formulate within the Outer Rim. The successor, known as the First Order, was formed around a string of industrialized worlds, which stretched from Bastion to the planet Yaga Minor.
