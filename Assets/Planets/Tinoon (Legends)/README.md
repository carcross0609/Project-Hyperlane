# Tinoon

**Continuity:** Legends  
**Source:** [Tinoon/Legends](https://starwars.fandom.com/wiki/Tinoon/Legends)
**Galaxy atlas:** system `Tinoon`, Outer Rim, grid K-18 — map position (-991.0, -13113.7, -12.8)

Tinoon was a planet located within the Tinoon system of the Outer Rim Territories relatively close to the Zephry Asteroid field. The planet's orbit was home to a customs check point and a Cargo Facility. It was raided by pirates after the Battle of Hoth.
