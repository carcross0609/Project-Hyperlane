# Colsassa

**Continuity:** Legends  
**Source:** [Colsassa](https://starwars.fandom.com/wiki/Colsassa)
**Galaxy atlas:** system `Colsassa`, Outer Rim, grid R-6 — map position (9953.4, 5760.6, 244.2)

Colsassa was the fourth planet orbiting the binary stars Adega Prime and Adega Besh in the Adega system. Located in the Auril sector in the Slice portion of the Outer Rim Territories, it was a gas giant orbited by eleven moons collectively known as the Colsassan moons.
