# Perilious

**Continuity:** Legends  
**Source:** [Perilious](https://starwars.fandom.com/wiki/Perilious)
**Galaxy atlas:** system `Perilious`, Outer Rim, grid R-17 — map position (10295.9, -11658.2, -238.7)

Perilious was a planet that was located within the Outer Rim Territories of the galaxy. It was home to a large criminal element, which including a large slaving ring that dealt in Twi'leks. The world was continually covered by storms.

During the Clone Wars, the Jedi, Vydel Dir'Nul, tracked a serial killer, called Kardem, to Perilious.
