# Unidentified planet

**Continuity:** Canon  
**Source:** [Unidentified planet (Jedi temple)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Jedi_temple%29)

A planet that was barely thought about and barely named was home to a Jedi temple. Dark Lord of the Sith Darth Vader travelled to the planet to steal a tablet from the Jedi temple.

## Planetary data

- **Name:** Unidentified planet
- **Atmosphere:** Breathable
- **Terrain:** Lush prarie
- **Interest:** Jedi temple
- **Otherspecies:**
  - Humans
  - Twi'leks
