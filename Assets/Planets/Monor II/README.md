# Monor II; (Kline Colony)

**Continuity:** Legends  
**Source:** [Monor II](https://starwars.fandom.com/wiki/Monor_II)
**Galaxy atlas:** system `Monor II`, Mid Rim — map position (-2293.9, 3711.9, -79.7)

Monor II, also called Kline Colony, was the Sunesi homeworld. It was ruled by a monarchy of priest-princes. The tenth, Agapos the Tenth, ascended in 24 ABY. This planet was where the mysterious Nom Anor infected various New Republic diplomats and Mara Jade Skywalker with coomb spores, killing many of them.
