# Dahyun

**Continuity:** Unknown  
**Source:** [Dahyun](https://starwars.fandom.com/wiki/Dahyun)

Dahyun was a terrestrial planet where an Imperial base was located. During the Galactic Civil War, Leia Organa stole plans for TIE/ln space superiority starfighter engines from the base and escaped in a Lambda-class T-4a shuttle.

## Planetary data

- **Name:** Dahyun
- **Class:** Terrestrial
- **Atmosphere:** Breathable
- **Affiliation:** Galactic Empire
