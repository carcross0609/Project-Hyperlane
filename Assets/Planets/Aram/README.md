# Aram

**Continuity:** Legends  
**Source:** [Aram](https://starwars.fandom.com/wiki/Aram)
**Galaxy atlas:** system `Aram`, Expansion Region, grid O-14 — map position (5806.4, -7289.2, 128.9)

Aram was the tropical homeworld of the Aramandi species. Located in the Aramand Cluster in the Brak sector; it was orbited by a lone moon. It possessed a higher than average gravity, which caused the Aramandi to be short and stout.
