# Tensor 4

**Continuity:** Legends  
**Source:** [Tensor 4](https://starwars.fandom.com/wiki/Tensor_4)

Tensor 4 was a world. During the Galactic War, there was a large processing project which caused for thousands of confiscated blasters, vibroswords and other weapons to be processed into useful metallic parts.
