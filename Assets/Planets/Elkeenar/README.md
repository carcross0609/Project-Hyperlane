# Elkeenar

**Continuity:** Canon  
**Source:** [Elkeenar](https://starwars.fandom.com/wiki/Elkeenar)

Elkeenar was a rocky wasteland planet located in the Penagosis system in Wild Space, in grid square K-21 of the Standard Galactic Grid. While a member of the Spice Runners of Kijimi, Poe Dameron visited the Marimkes Mountains on Elkeenar with Tomasso.
