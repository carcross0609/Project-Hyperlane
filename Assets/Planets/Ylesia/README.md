# Ylesia

**Continuity:** Canon  
**Source:** [Ylesia](https://starwars.fandom.com/wiki/Ylesia)
**Galaxy atlas:** system `Ylesia`, Hutt Space, grid T-12 — map position (12678.4, -3209.5, -49.9)

Ylesia was a terrestrial planet in the Ylesia system of Hutt Space that, along with the Codian Moon, was the homeworld of the reek species. It was situated along the Shag Pabol hyperspace route. The former pirate queen Maz Kanata marked it as a point of interest on a map she included in the book that would become known as the Smuggler's Guide.
