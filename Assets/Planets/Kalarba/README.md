# Kalarba

**Continuity:** Canon  
**Source:** [Kalarba](https://starwars.fandom.com/wiki/Kalarba)
**Galaxy atlas:** system `Kalarba`, Mid Rim, grid P-15 — map position (6060.2, -7754.2, 60.5)

Kalarba was a planet located in the Kalarba system in the Hevvrol sector of the Mid Rim. It was orbited by multiple moons, including one that had the Imperial space station Hosk Station built entirely around its surface. During the Galactic Civil War, the Ishi Tib pilot Sata Neek claimed that he and the Alliance to Restore the Republic RZ-1 A-wing interceptor squadron designated Riot Squadron and its commanding officer Creel had searched for a rebel base on Kalarba for six hours before realizing that Creel had mistaken a flight simulator mission for a set of redeployment orders. His squadron mate Kamala disputed the truth of this story.
