# Ergeshui

**Continuity:** Legends  
**Source:** [Ergeshui/Legends](https://starwars.fandom.com/wiki/Ergeshui/Legends)
**Galaxy atlas:** system `Ergeshui`, Inner Rim — map position (5666.4, 687.9, -99.8)
