# Balfron

**Continuity:** Legends  
**Source:** [Balfron/Legends](https://starwars.fandom.com/wiki/Balfron/Legends)
**Galaxy atlas:** system `Balfron`, Core Worlds, grid K-9 — map position (-1239.7, 1112.4, -42.5)

Balfron was a small terrestrial planet located in the Dolomar sector in the Core Worlds of the galaxy. It had several casinos where planets could be won or lost in a game of sabacc, including The High Stakes Casino, where Han Solo arranged for Lando Calrissian to meet the Tonnika sisters as part of an elaborate prank.
