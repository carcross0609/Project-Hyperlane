# Lish

**Continuity:** Legends  
**Source:** [Lish](https://starwars.fandom.com/wiki/Lish)
**Galaxy atlas:** system `Lish`, Expansion Region — map position (3056.6, -8708.3, -16.8)

Lish was the sixth planet in the Demar system of the Expansion Region. A large, blue-green gas giant, Lish was orbited by fifteen moons.

The Lant Mining Corporation set up mines on ten of the world's fifteen moons during the reign of the Galactic Empire, though eventually abandoned all but their mines on Lish V and Lish XI.
