# Frisal

**Continuity:** Legends  
**Source:** [Frisal](https://starwars.fandom.com/wiki/Frisal)
**Galaxy atlas:** system `Frisal`, Core Worlds, grid J-12 — map position (-1992.5, -3415.4, -3.3)

Frisal was a terrestrial planet located in the Frisal system, a part of the Atrisian Commonwealth in the Southern Core portion of the Core Worlds. It was the homeworld of loirbniggs, a species of eight-legged reptilian creatures.

The Galactic Empire maintained Frisal as a preserve world for affluent Imperial families. Members of the Imperial nobility also vacationed on the planet, and the aristocrats bred and trained loirbniggs for use as mounts.
