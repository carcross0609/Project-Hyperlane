# Ordaj

**Continuity:** Legends  
**Source:** [Ordaj](https://starwars.fandom.com/wiki/Ordaj)
**Galaxy atlas:** system `Ordaj`, Outer Rim — map position (2659.3, 4917.1, 194.9)

Ordaj was the fifth planet of the Hoth system in the Outer Rim Territories. It was a gas giant, orbited by seventeen moons, including Ordaj Besh.
