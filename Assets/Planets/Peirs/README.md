# Peirs

**Continuity:** Legends  
**Source:** [Peirs](https://starwars.fandom.com/wiki/Peirs)
**Galaxy atlas:** system `Peirs`, Outer Rim, grid M-21 — map position (2431.0, -17550.2, 621.3)

Peirs was a planet within the Peirs system of the Outer Rim Territories' Kathol sector. Connected to the neighboring planets of Gandle Ott, Shintel and Ivatch by hyperlanes, Peirs supported a small colony whose economy was based around supplying ore and natural resources to Gandle Ott.
