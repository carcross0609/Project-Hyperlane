# Yinchorr

**Continuity:** Legends  
**Source:** [Yinchorr/Legends](https://starwars.fandom.com/wiki/Yinchorr/Legends)
**Galaxy atlas:** system `Yinchorr`, Expansion Region, grid L-8 — map position (495.6, 2680.1, 24.1)

Yinchorr was a planet located in the Expansion Region and was homeworld of the Yinchorri species. It was first charted c. 500 BBY by the Galactic Republic.
