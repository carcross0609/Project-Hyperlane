# Kassa

**Continuity:** Legends  
**Source:** [Kassa](https://starwars.fandom.com/wiki/Kassa)

Kassa was the first planet orbiting the binary stars Adega Prime and Adega Besh in the Adega system. Located in the Auril sector of the Outer Rim, it was a searing rock.
