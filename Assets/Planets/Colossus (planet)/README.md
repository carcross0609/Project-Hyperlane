# Colossus

**Continuity:** Legends  
**Source:** [Colossus (planet)](https://starwars.fandom.com/wiki/Colossus_%28planet%29)
**Galaxy atlas:** system `Colossus`, Core Worlds, grid K-13 — map position (-1174.4, -5000.5, -4.3)

Colossus was the fifth and outermost planet in the Belgaroth system in the Core Worlds. It was the only gas giant in the star system, and it was orbited by twenty-four moons.
