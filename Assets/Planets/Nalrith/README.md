# Nalrith

**Continuity:** Legends  
**Source:** [Nalrith](https://starwars.fandom.com/wiki/Nalrith)

Nalrith was a terrestrial planet located in the Nalrith system, a part of the Outer Rim Territories' Rseik sector. It was the homeworld of the Nalrithians, a species of sentient insectoids.
