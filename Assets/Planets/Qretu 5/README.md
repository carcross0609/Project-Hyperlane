# Qretu 5

**Continuity:** Legends  
**Source:** [Qretu 5](https://starwars.fandom.com/wiki/Qretu_5)
**Galaxy atlas:** system `Qretu 5`, Inner Rim, grid L-15 — map position (1047.7, -8820.7, 142.3)

Qretu 5 was a bacta refinement planet in the Inner Rim's Qretu system, loyal to Ysanne Isard during the Bacta War.

The planet hosted the Q5A7 Bacta Refinement Plant, which was destroyed by a punitive strike conducted by Rogue Squadron soon after the Battle of Halanit.
