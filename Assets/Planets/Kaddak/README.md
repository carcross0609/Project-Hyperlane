# Kaddak

**Continuity:** Canon  
**Source:** [Kaddak](https://starwars.fandom.com/wiki/Kaddak)
**Galaxy atlas:** system `Kaddak`, Outer Rim, grid S-4 — map position (10762.7, 8442.1, -47.9)

Kaddak was a lawless planet located in the Kaddak system of the galaxy's Outer Rim Territories, near Rothana. In the years of the New Republic, it was controlled by the Ranc Gang.
