# Najiba

**Continuity:** Legends  
**Source:** [Najiba/Legends](https://starwars.fandom.com/wiki/Najiba/Legends)
**Galaxy atlas:** system `Najiba`, Outer Rim, grid R-17 — map position (9427.7, -10571.6, -371.7)

Najiba was the Najib homeworld. It was a remote world covered with wetlands and its surface was lashed with atmospheric electrical discharges and frequent rainstorms.
