# Uba II

**Continuity:** Legends  
**Source:** [Uba II](https://starwars.fandom.com/wiki/Uba_II)

Uba II was a planet located within the Uba system of the Mid Rim. It was a home to an Ubese colony, which was destroyed by the Jedi in the bombardment of the Uba system during the New Sith Wars.
