# Rohm

**Continuity:** Canon  
**Source:** [Rohm](https://starwars.fandom.com/wiki/Rohm)

Rohm was an agriworld in the Mid Rim Territories' Hevvrol sector that was inhabited by farmers. In 397 BBY, the Force-sensitive human Rooper Nitani was born on Rohm before eventually being taken to the Core Worlds planet Coruscant by the Jedi Order for training.
