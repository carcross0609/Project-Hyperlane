# Karalle

**Continuity:** Legends  
**Source:** [Karalle/Legends](https://starwars.fandom.com/wiki/Karalle/Legends)

Karalle was a swamp planet. It was on this planet that the force-sensitive Quermian Jarea Kaela hid from bounty hunters and the Inquisitorius.
