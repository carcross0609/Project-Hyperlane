# Utharis

**Continuity:** Legends  
**Source:** [Utharis](https://starwars.fandom.com/wiki/Utharis)
**Galaxy atlas:** system `Utharis`, Core Worlds, grid K-10 — map position (-1266.0, -553.7, 5.9)

Utharis was a planet located within the Utharis system of the Core Worlds.

It was a Tarrack colony bordering the Koornacht Cluster between Atzerri and J't'p'tan. The populace tuned in to the Utharis GridLink for news. Starway Services was headquartered on Utharis. Cities included Taldaak, which was served by the local starport, Taldaak Station. The New Republic Defense Fleet had a listening post there. The planet was the homeworld of the black-winged touret and the jack-a-dale.
