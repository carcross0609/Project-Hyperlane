# Azure

**Continuity:** Legends  
**Source:** [Azure/Legends](https://starwars.fandom.com/wiki/Azure/Legends)
**Galaxy atlas:** system `Azure`, Mid Rim, grid P-8 — map position (6732.6, 2591.5, -15.5)

Azure was a diminutive blue Mid Rim world at a non-strategic location where most of the landmass was taken up by a clandestine Galactic Republic spaceport. The planet was part of a Azure system and had no moons nor any useful resources. It was commanded by General Solomahal until conquered by the Confederacy of Independent Systems during the Clone Wars.

It was also the location of Jedi Siri Tachi's death.
