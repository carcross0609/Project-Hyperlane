# Annoo

**Continuity:** Legends  
**Source:** [Annoo (original)](https://starwars.fandom.com/wiki/Annoo_%28original%29)
**Galaxy atlas:** system `Annoo`, Outer Rim, grid S-8 — map position (10954.4, 1726.4, 404.8)

Annoo was an Outer Rim planet located in the Tharin sector. The homeworld of the original Annoo-dat species, they were referred to by xenobiologists as Annoo-dat Prime.
