# Karkaris

**Continuity:** Legends  
**Source:** [Karkaris/Legends](https://starwars.fandom.com/wiki/Karkaris/Legends)
**Galaxy atlas:** system `Karkaris`, Outer Rim, grid S-5 — map position (10773.1, 6637.5, -297.6)

Karkaris was a waterworld in the Nilgaard sector of the Outer Rim Territories. It was the homeworld of the Karkarodons, a species of fearless sentient aquatics.
