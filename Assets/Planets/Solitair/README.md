# Solitair

**Continuity:** Canon  
**Source:** [Solitair](https://starwars.fandom.com/wiki/Solitair)

Solitair was a planet in the Solitair system of the Unknown Regions, home to the Garwian species. It was the capital of the species' government, the Garwian Unity.
