# Scipio

**Continuity:** Legends  
**Source:** [Scipio/Legends](https://starwars.fandom.com/wiki/Scipio/Legends)
**Galaxy atlas:** system `Scipio`, Outer Rim, grid K-5 — map position (-968.0, 7229.4, -115.1)

Scipio was an ice- and snow-covered planet in the Outer Rim Territories' Albarrio sector. An important world for the Muuns and the InterGalactic Banking Clan, the world had frozen peaks dotted with towering columns and graceful arches.
