# D'pur

**Continuity:** Legends  
**Source:** [D'pur](https://starwars.fandom.com/wiki/D%27pur)
**Galaxy atlas:** system `D'Pur`, Core Worlds — map position (-1650.4, -623.0, 23.9)

D'pur was the seventh planet orbiting the star C'rel in the N'zoth system within the Koornacht Cluster of the Core Worlds. It was the only gas giant in the system.
