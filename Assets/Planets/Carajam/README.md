# Carajam

**Continuity:** Canon  
**Source:** [Carajam](https://starwars.fandom.com/wiki/Carajam)
**Galaxy atlas:** system `Carajam`, Outer Rim — map position (-1895.8, 7241.5, -367.6)

Carajam was a desert planet in the Carajam system in the Dalonbian sector of the Outer Rim Territories. The bounty hunter Boba Fett visited the planet to claim a bounty on a Rebel pilot, taking a job to target Zingo Gabnit.
