# Onod

**Continuity:** Canon  
**Source:** [Onod](https://starwars.fandom.com/wiki/Onod)

Onod was a planet located in the Onod system of the Irnaj sector, a part of the Mid Rim Territories and the Western Reaches. It was situated in grid square K-17 of the Standard Galactic Grid and shared its name with the celestial body Onod I that was situated in the same star system. A hyperspace route connected Onod to the Kriselist and Tiferep Major systems. The historian Eloc Throno eventually noted Onod's position on a galactic map included in his book Traveler's Guide to Batuu, which was published in 34 ABY.
