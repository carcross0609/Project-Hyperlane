# Cavas

**Continuity:** Canon  
**Source:** [Cavas](https://starwars.fandom.com/wiki/Cavas)

Cavas was a beige gas giant planet located within the Bormea sector of the Core Worlds. During the Galactic Civil War, the Galactic Empire carried out an incursion into the Bormea sector, using jamming ships to cause communications blackouts for the New Republic. Commander Lindon Javes sent Vanguard Squadron to investigate these blackouts over Cavas and re-establish communications.
