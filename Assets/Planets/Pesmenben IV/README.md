# Pesmenben IV

**Continuity:** Legends  
**Source:** [Pesmenben IV](https://starwars.fandom.com/wiki/Pesmenben_IV)
**Galaxy atlas:** system `Pesmenben IV`, Mid Rim, grid Q-11 — map position (7562.4, -1744.1, 100.3)

Pesmenben IV was an Imperial planet in the Mid Rim's Teraab sector that had ore deposits and dunes. At one point by 0 BBY, the businessman Lando Calrissian duped the planet's Imperial governor into leasing it by pulling a scam involving lithium.
