# Cogalle

**Continuity:** Legends  
**Source:** [Cogalle](https://starwars.fandom.com/wiki/Cogalle)

Cogalle was the fourth planet orbiting the star Striar in the Malastare system. Located in the Dustig sector of the Mid Rim, it was a toxic waterworld.
