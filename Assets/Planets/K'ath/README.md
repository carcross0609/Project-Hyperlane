# K'ath

**Continuity:** Legends  
**Source:** [K'ath](https://starwars.fandom.com/wiki/K%27ath)
**Galaxy atlas:** system `K'ath`, Mid Rim, grid L-18 — map position (24.1, -12129.8, 195.0)

K'ath was a planet located in the K'ath system of the Juvex sector, in the Mid Rim of the galaxy. An agriworld, K'ath was most notable for its seashells, which local artisans would craft into figurines. In addition to these trinkets, visitors knew K'ath for its wide beaches and terraced hills.
