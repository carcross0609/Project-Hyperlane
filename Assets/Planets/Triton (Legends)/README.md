# Triton

**Continuity:** Legends  
**Source:** [Triton/Legends](https://starwars.fandom.com/wiki/Triton/Legends)
**Galaxy atlas:** system `Triton`, Outer Rim, grid M-18 — map position (2403.3, -13282.9, 375.0)

Triton was a small, almost lifeless planet in the Mayagil sector of the Outer Rim Territories. It was orbited by the three Triton Moons. The moons were nefariously used by many in the galaxy to describe a dead thing—as dead as a Triton moon, due to the ban of stimulants of any kind.
