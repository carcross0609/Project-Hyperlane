# Vuma

**Continuity:** Legends  
**Source:** [Vuma/Legends](https://starwars.fandom.com/wiki/Vuma/Legends)
**Galaxy atlas:** system `Vuma`, Core Worlds, grid M-10 — map position (1689.8, -887.9, -109.1)

Vuma was a planet located within the Vuma system of the Core Worlds.

The humanoid gang from Mamendin called the "Slams" stole its planetary treasury in 25 BBY.
