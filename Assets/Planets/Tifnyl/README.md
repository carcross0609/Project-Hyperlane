# Tifnyl

**Continuity:** Legends  
**Source:** [Tifnyl](https://starwars.fandom.com/wiki/Tifnyl)
**Galaxy atlas:** system `Tifnyl`, Outer Rim, grid M-19 — map position (2470.8, -13679.6, -472.6)

Tifnyl was the fourth planet of the Tifnyl system. It was a gas giant located in the Elrood sector of the Outer Rim Territories. Its moon was the location of an Imperial listening post during the Galactic Civil War.
