# Tharkos

**Continuity:** Legends  
**Source:** [Tharkos](https://starwars.fandom.com/wiki/Tharkos)
**Galaxy atlas:** system `Tharkos`, Outer Rim, grid R-6 — map position (9958.4, 4674.6, 146.5)

Tharkos was a planet located in the Tharkos system of the Outer Rim Territories. It was the headquarters of Millennium Astro-Engineering. The planet was attacked by the Stenax during the Stenax Massacres of 5 ABY.
