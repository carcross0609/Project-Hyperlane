# Elriss

**Continuity:** Legends  
**Source:** [Elriss](https://starwars.fandom.com/wiki/Elriss)

Elriss was a Mid Rim planet.

Some time between 2 BBY and 0 BBY, the Galactic Empire sent stormtroopers including Daric LaRone to Elriss. While on it, the stormtroopers triple-checked the identities of the population of a village, and made all its inhabitants wait for six hours in the rain while doing so.
