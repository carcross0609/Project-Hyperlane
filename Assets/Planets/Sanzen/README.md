# Sanzen

**Continuity:** Legends  
**Source:** [Sanzen](https://starwars.fandom.com/wiki/Sanzen)

Sanzen was the seventh planet orbiting the star Rek in the Guter Wade system. Located in the Trilon sector of the Outer Rim, it was a gas giant.
