# Ayceezee

**Continuity:** Legends  
**Source:** [Ayceezee](https://starwars.fandom.com/wiki/Ayceezee)

Ayceezee was an inhabited world in the galaxy with rolling walkways and a university as of 44 ABY. Former Wraith Squadron member Voort saBinring retired there as a mathematics professor until re-recruited by Garik Loran in 44 ABY.
