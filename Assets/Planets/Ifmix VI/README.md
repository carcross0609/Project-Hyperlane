# Ifmix VI

**Continuity:** Legends  
**Source:** [Ifmix VI](https://starwars.fandom.com/wiki/Ifmix_VI)
**Galaxy atlas:** system `Ifmix VI`, Colonies, grid M-9 — map position (1814.4, 1079.0, 6.7)

Ifmix VI was a planet in the Colonies. It was known for its terrible windstorms, tornadoes, and Squalris merchants. It was located near the Perlemian Trade Route.
