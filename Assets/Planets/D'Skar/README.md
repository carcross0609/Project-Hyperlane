# D'Skar

**Continuity:** Legends  
**Source:** [D'Skar](https://starwars.fandom.com/wiki/D%27Skar)
**Galaxy atlas:** system `D'Skar`, Outer Rim, grid M-20 — map position (2239.0, -15220.2, -427.6)

D'Skar was a planet located within the Coyn system of the Outer Rim Territories and a rocky wasteland. The name of the planet meant "dagger" in the language of the Coynites and lent its name to a weapon.
