# Gelgelar

**Continuity:** Legends  
**Source:** [Gelgelar/Legends](https://starwars.fandom.com/wiki/Gelgelar/Legends)
**Galaxy atlas:** system `Gelgelar`, Outer Rim — map position (9901.7, 9059.8, -45.1)

Gelgelar was a cold, cloud-covered swamp planet in the Outer Rim Territories. It was the homeworld of the Glarsaurs.
