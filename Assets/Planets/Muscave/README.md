# Muscave

**Continuity:** Legends  
**Source:** [Muscave](https://starwars.fandom.com/wiki/Muscave)
**Galaxy atlas:** system `Muscave`, Core Worlds — map position (3084.7, -2233.7, 71.1)

Muscave was one of two gas giants in the Coruscant system. During the Battle of Yuuzhan'tar, the Galactic Alliance's Second Fleet engaged elements of the Yuuzhan Vong armada above Muscave.
