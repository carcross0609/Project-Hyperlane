# Taktos

**Continuity:** Legends  
**Source:** [Taktos](https://starwars.fandom.com/wiki/Taktos)

Taktos was the second planet orbiting the star Utapau in the Utapau system. Located in the Tarabba sector of the Outer Rim Territories, it was a searing rock.
