# Orooturoo

**Continuity:** Legends  
**Source:** [Orooturoo](https://starwars.fandom.com/wiki/Orooturoo)
**Galaxy atlas:** system `Orooturoo`, Core Worlds — map position (-2024.7, -120.8, -54.1)

Orooturoo was the home of a race of titanic purple-colored sluglike beings, most notably Princess Nampi. It was an endpoint of both the Metellos Trade Route and the Widek Bypass.

An obscure planet, the homeworld of an alien species, it suffered during the Imperial Era.
