# Vannix

**Continuity:** Legends  
**Source:** [Vannix](https://starwars.fandom.com/wiki/Vannix)
**Galaxy atlas:** system `Vannix`, Core Worlds, grid M-10 — map position (2471.1, -415.8, -64.6)

Vannix was a planet located within the Vankalay system of the Core Worlds, in a sector bordering the Kuat sector. It was represented in the New Republic Senate by Addath Gadan until she advocated appeasing the Yuuzhan Vong during the Yuuzhan Vong War.
