# Ember

**Continuity:** Legends  
**Source:** [Ember (planet)](https://starwars.fandom.com/wiki/Ember_%28planet%29)
**Galaxy atlas:** system `Ember`, Core Worlds — map position (2277.0, -954.5, 198.0)

Ember was the first planet of the Belgaroth system, located in the Core Worlds of the galaxy. Illuminated by binary stars Matanya A and Matanya B, Ember was a searing world with no moons.
