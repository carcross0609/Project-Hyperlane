# Langhesa

**Continuity:** Legends  
**Source:** [Langhesa](https://starwars.fandom.com/wiki/Langhesa)

Langhesa was the Langhesi homeworld situated in the Langhesa system in the Meram sector of the Outer Rim Territories. It was conquered in 129 BBY by the Tsinimals, leading to a mass migration of Langhesi offworld.
