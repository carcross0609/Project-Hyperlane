# Unidentified planet

**Continuity:** Legends  
**Source:** [Unidentified planet (Lorardia system)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Lorardia_system%29)

During the Cold War, a survey team was charting an uninhabited planet in the Lorardia system when they received unusual readings. The readings were determined to be caused by large deposits of maranium underneath the surface.
