# Kal'Shebbol

**Continuity:** Canon  
**Source:** [Kal'Shebbol](https://starwars.fandom.com/wiki/Kal%27Shebbol)
**Galaxy atlas:** system `Kal'Shebbol`, Outer Rim, grid M-21 — map position (2488.5, -16917.4, 149.3)

Kal'Shebbol was a planet located in the Kal'Shebbol system in the Kathol sector of the Outer Rim Territories. It was located close to one end of the Rimma Trade Route, which connected it to Septra. Cal Alder, an Alliance to Restore the Republic lieutenant, hailed from the planet.
