# Goratak III

**Continuity:** Legends  
**Source:** [Goratak III](https://starwars.fandom.com/wiki/Goratak_III)

Goratak III was a planet in the Goratak system covered in crystalline wilderness known as the Crystal Forests. It was the site of a messy conflict between Rebel and Imperial forces.
