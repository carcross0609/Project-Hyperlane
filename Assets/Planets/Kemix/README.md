# Kemix

**Continuity:** Legends  
**Source:** [Kemix](https://starwars.fandom.com/wiki/Kemix)

Kemix was a barren planet of the Kemix system in the Outer Rim Territories. It had some minor glitterstim deposits located on it and Riboga the Hutt established a spice mine there to mine these. However, the mines were destroyed during the Clone Wars, by the Heroes of Cularin.
