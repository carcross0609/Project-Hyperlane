# Teagan

**Continuity:** Legends  
**Source:** [Teagan](https://starwars.fandom.com/wiki/Teagan)

Teagan was a planet in the Kwymar sector of the Outer Rim.

It was the homeworld of the Devon species, owners of the Teagan Tech Consortium, a droid manufacturer.
