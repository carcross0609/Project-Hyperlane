# Prefsbelt IV

**Continuity:** Legends  
**Source:** [Prefsbelt IV/Legends](https://starwars.fandom.com/wiki/Prefsbelt_IV/Legends)
**Galaxy atlas:** system `Prefsbelt IV`, Outer Rim, grid K-5 — map position (-1420.6, 6976.3, -181.5)

Prefsbelt IV, also referred to as simply Prefsbelt, was a green planet in the Prefsbelt system, a star system in the Prefsbelt sector of the Outer Rim Territories. It was notably the site of the ancient Republic—and later Imperial—Naval Academy.
