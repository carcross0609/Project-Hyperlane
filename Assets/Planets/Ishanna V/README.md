# Ishanna V

**Continuity:** Legends  
**Source:** [Ishanna V](https://starwars.fandom.com/wiki/Ishanna_V)

Ishanna V was the fifth planet in the Ishanna system. It housed five moons. The aforementioned stellar objects followed their set individual orbital course, all similarly elliptical.
