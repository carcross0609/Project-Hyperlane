# Qat Chrystac

**Continuity:** Legends  
**Source:** [Qat Chrystac/Legends](https://starwars.fandom.com/wiki/Qat_Chrystac/Legends)
**Galaxy atlas:** system `Qat Chrystac`, Expansion Region, grid L-16 — map position (1385.8, -9841.0, 187.0)

Qat Chrystac was a volatile, radioactive, and volcanic world that was a point of contention between Rebel (later New Republic) and Imperial forces for over ten years.
