# Abraxas

**Continuity:** Legends  
**Source:** [Abraxas](https://starwars.fandom.com/wiki/Abraxas)
**Galaxy atlas:** system `Abraxas`, Mid Rim, grid K-17 — map position (-757.7, -11120.0, 297.2)

Abraxas was a planet in the Abraxas system situated within the Yushan sector of the Mid Rim Territories. Abraxas was run dry of its rich natural resources by overwhelming mining, and became a base for the Eiattu pirates. Soon after the Battle of Endor, the New Republic discovered and threw the pirates out.
