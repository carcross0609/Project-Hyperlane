# Drackmar

**Continuity:** Legends  
**Source:** [Drackmar](https://starwars.fandom.com/wiki/Drackmar)
**Galaxy atlas:** system `Drackmar`, Outer Rim, grid O-6 — map position (5014.4, 5593.8, 25.7)

Drackmar was the Drackmarian homeworld, located in the Drackmar system, in the Quelii sector of the Outer Rim Territories. The atmosphere of Drackmar was composed of methane, requiring native Drackmarians to wear special methane helmets when traveling off-world. On the other hand, oxygen-breathing species could use environmentally-sealed vehicles, such as the Orbitblade-2000, to visit the planet.
