# Corvis Minor IV

**Continuity:** Legends  
**Source:** [Corvis Minor IV](https://starwars.fandom.com/wiki/Corvis_Minor_IV)

Corvis Minor IV was a water-rich tropical planet in the Ciutric Hegemony. It produced exotic xenobiological products sold as luxury commodities. It was guarded by the Aspiration.
