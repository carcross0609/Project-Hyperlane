# Scipio

**Continuity:** Canon  
**Source:** [Scipio](https://starwars.fandom.com/wiki/Scipio)
**Galaxy atlas:** system `Scipio`, Outer Rim, grid K-5 — map position (-968.0, 7229.4, -115.1)

Scipio was an ice-covered planet located in the galaxy's Outer Rim Territories. It was positioned in the Scipio system, and served as the headquarters of the InterGalactic Banking Clan.
