# Kowak

**Continuity:** Canon  
**Source:** [Kowak](https://starwars.fandom.com/wiki/Kowak)
**Galaxy atlas:** system `Kowak`, Outer Rim, grid S-16 — map position (11878.2, -9031.1, -342.4)

Kowak was a planet located in the galaxy's Outer Rim Territories that was the homeworld of the Kowakian monkey-lizards, the kowakian ape-lizards, and mole-fleas. The Zygerrian Prince Sono Molec ruled over the Zygerrian Slave Empire from his palace on the planet Kowak.
