# Indar

**Continuity:** Legends  
**Source:** [Indar](https://starwars.fandom.com/wiki/Indar)

Indar was the eighth planet orbiting the star Tive in the Taanab system. Located in the Inner Rim Territories, Indar was a gas giant with five moons.
