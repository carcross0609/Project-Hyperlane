# Miekos

**Continuity:** Canon  
**Source:** [Miekos](https://starwars.fandom.com/wiki/Miekos)

Miekos was a small marshland planet on the edge of Wild Space. Formerly a San Tekka colony, the planet became a farming community. It had a diverse population that included Togruta, Mirialans, Nautolans, humans, and other species.
