# Ord Wylan

**Continuity:** Legends  
**Source:** [Ord Wylan](https://starwars.fandom.com/wiki/Ord_Wylan)

Ord Wylan was a world located in the Mid Rim's Oktos sector. During the Pius Dea Era, between 12,000 BBY and 11,000 BBY, it served as an Ordnance/Regional Depot outpost for the Galactic Republic. Shortly after the Battle of Yavin, the gambler Lando Calrissian won the license rights for the taxi service on Ord Wylan in a sabacc game but lost them shortly afterward.
