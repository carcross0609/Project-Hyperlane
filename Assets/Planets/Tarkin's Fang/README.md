# Tarkin's Fang

**Continuity:** Legends  
**Source:** [Tarkin's Fang](https://starwars.fandom.com/wiki/Tarkin%27s_Fang)
**Galaxy atlas:** system `Tarkin's Fang`, Deep Core, grid L-11 — map position (829.3, -2587.9, -46.4)

Tarkin's Fang was a planet located in the Deep Core, near the Treskov system. It was the location of a secret Galactic Empire base. However, the Empire abandoned it at the end of the Galactic Civil War, sealing it up well stocked for use as a base should another war with the New Republic break out.
