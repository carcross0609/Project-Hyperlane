# Galvoni III

**Continuity:** Legends  
**Source:** [Galvoni III](https://starwars.fandom.com/wiki/Galvoni_III)
**Galaxy atlas:** system `Galvoni III`, Core Worlds, grid K-9 — map position (-225.5, 443.8, -29.0)

Galvoni III was an Imperial planet in the Core Worlds' Galvoni system with a military communications complex.

Shortly after the Battle of Yavin, Voren Na'al infiltrated the Imperial Records Office to gather information about the construction, function, personnel and destruction of the Death Star.
