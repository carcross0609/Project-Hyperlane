# Edan II

**Continuity:** Legends  
**Source:** [Edan II/Legends](https://starwars.fandom.com/wiki/Edan_II/Legends)
**Galaxy atlas:** system `Edan II`, Expansion Region — map position (4434.0, -8310.2, -51.8)

Edan II was a planet in the Edan system. Although Edan Base was taken out by the Galactic Empire, the Rebel Alliance regained the planet, defeating the Imperial Dark Jedi natives Teles Jalahafi and Shela Jalahafi.
