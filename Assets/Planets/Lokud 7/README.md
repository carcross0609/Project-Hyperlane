# Lokud 7

**Continuity:** Canon  
**Source:** [Lokud 7](https://starwars.fandom.com/wiki/Lokud_7)

Lokud 7 was a jungle world in the Outer Rim Territories. During the Galactic Civil War, Rebel Alliance spies landed on Lokud 7 with Imperial intelligence. Darth Vader followed the Rebel spies to the planet in search of them.
