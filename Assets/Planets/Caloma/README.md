# Caloma

**Continuity:** Legends  
**Source:** [Caloma](https://starwars.fandom.com/wiki/Caloma)

Caloma was the sixth planet orbiting the star of Prael in the Japrael system. Located in the Japrael sector of the Inner Rim, it was a gas giant.
