# Baralou

**Continuity:** Legends  
**Source:** [Baralou](https://starwars.fandom.com/wiki/Baralou)
**Galaxy atlas:** system `Baralou`, Outer Rim, grid H-20 — map position (-4660.3, -15262.8, -464.0)

Baralou was a planet in the Varada sector of the Outer Rim Territories. It was the homeworld of the Krikthasi and the Multopos.
