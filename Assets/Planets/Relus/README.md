# Relus

**Continuity:** Legends  
**Source:** [Relus](https://starwars.fandom.com/wiki/Relus)
**Galaxy atlas:** system `Relus`, Deep Core, grid K-11 — map position (-553.3, -1660.1, -52.2)

Relus was the fourth planet of the Beshqek system, located within the Deep Core. It was one of two terrestrial planets in the system and was orbited by a single moon.

After the cataclysmic destruction of Relus's neighboring planet, Byss, in 11 ABY, the artificial Byss Run hyperlane connecting the Beshqek system to the Core Worlds began to collapse. Millions of Relus's inhabitants fled to nearby Prakith and beyond in an attempt to avoid being trapped in the system. Millions more, however, were believed to have been marooned on Relus when the Byss Run finally collapsed completely, leaving the Beshqek system all but unreachable.
