# Mumunubb

**Continuity:** Legends  
**Source:** [Mumunubb](https://starwars.fandom.com/wiki/Mumunubb)

Mumunubb was an planet which orbited the star Sullust in the Sullust system. Located in the Brema sector of the Outer Rim Territories, it shared the fifth orbit with Munumubb.
