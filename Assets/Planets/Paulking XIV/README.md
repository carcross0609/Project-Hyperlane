# Paulking XIV

**Continuity:** Legends  
**Source:** [Paulking XIV](https://starwars.fandom.com/wiki/Paulking_XIV)
**Galaxy atlas:** system `Paulking XIV`, Outer Rim, grid U-8 — map position (14806.8, 1962.1, -166.1)

Paulking XIV was a planet in the Paulking system of the Centrality. It was renowned for its unusual water life, which included fur-bearing trout, flying crabs, and talking algae.
