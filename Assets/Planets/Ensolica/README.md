# Ensolica

**Continuity:** Legends  
**Source:** [Ensolica](https://starwars.fandom.com/wiki/Ensolica)
**Galaxy atlas:** system `Ensolica`, Core Worlds — map position (1377.5, 62.7, -24.9)

Ensolica was a planet of ice and tundra located in the Core Worlds. It was the homeworld of the near-Human Enso species, members of which were experts in hydroponics. The Enso offworld merchant Teyora Rekab hailed from Ensolica.
