# Etai

**Continuity:** Canon  
**Source:** [Etai](https://starwars.fandom.com/wiki/Etai)

Etai was a planet located in the Mid Rim Territories within the galaxy. The etaan crystal was a powerful type gemstone found on Etai that was utilized to power lightsabers.

## Planetary data

- **Name:** Etai
- **Region:** Mid Rim Territories
- **Sector:** Druess sector
- **System:** Etai system
- **Coordinates:** O-15
- **Terrain:** Deep caverns
- **Exports:** Etaan crystal
