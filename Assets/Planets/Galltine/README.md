# Galltine

**Continuity:** Legends  
**Source:** [Galltine](https://starwars.fandom.com/wiki/Galltine)

Galltine was a Human-inhabited planet in the Galltine system of the Thesme sector.

Alliance to Restore the Republic operative and Bespin Motors Exex Elea Poista created a false identity—"Kel"—to sell contraband on the black market. The identity was highly detailed and indicated that Kel had been born on Galltine.
