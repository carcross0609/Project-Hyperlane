# Urubai

**Continuity:** Canon  
**Source:** [Urubai](https://starwars.fandom.com/wiki/Urubai)

Urubai was a planet that was home to Quarrant City. No earlier than 22 BBY, Senator Jar Jar Binks traveled to Urubai to meet with Ambassador Upsina.
