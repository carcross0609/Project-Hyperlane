# Rishal

**Continuity:** Legends  
**Source:** [Rishal](https://starwars.fandom.com/wiki/Rishal)
**Galaxy atlas:** system `Rishal`, Outer Rim, grid S-15 — map position (11699.5, -8603.0, -415.3)

Rishal was the second planet orbiting the star Rish in the Rishi system. Located in the Abrion sector of the Outer Rim, it was a barren, lifeless world that couldn't support life, but was rich in metal and ores. Rishal had no moons.
