# Mash Shareo

**Continuity:** Legends  
**Source:** [Mash Shareo](https://starwars.fandom.com/wiki/Mash_Shareo)

Mash Shareo was the second planet orbiting the star Tor in the Tobali system. Located in the Outer Rim Territories, it was a gas giant.
