# Sump

**Continuity:** Canon  
**Source:** [Sump](https://starwars.fandom.com/wiki/Sump)
**Galaxy atlas:** system `Sump`, Outer Rim, grid I-18 — map position (-3119.8, -13370.0, -684.8)

Sump was an Outer Rim Territories planet located in the Koradin sector. It was the homeworld of the sentient Nuknog species. In 382 BBY, Sump was affected by a war fought between planets Eiram and E'ronoh of the Eiram system, and it consequently submitted multiple aid requests to the Galactic Republic.
