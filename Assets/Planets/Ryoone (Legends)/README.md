# Ryoone

**Continuity:** Legends  
**Source:** [Ryoone/Legends](https://starwars.fandom.com/wiki/Ryoone/Legends)
**Galaxy atlas:** system `Ryoone`, Outer Rim, grid I-17 — map position (-3527.8, -11931.1, 494.9)

Ryoone was a dismal planet in the Outer Rim characterized by a "seemingly permanent suspension of ash in the upper atmosphere." It was inhabited by six sentient species, including the Lyunesi.
