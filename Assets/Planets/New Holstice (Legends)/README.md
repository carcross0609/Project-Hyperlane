# New Holstice

**Continuity:** Legends  
**Source:** [New Holstice/Legends](https://starwars.fandom.com/wiki/New_Holstice/Legends)
**Galaxy atlas:** system `New Holstice`, Mid Rim, grid R-7 — map position (9784.7, 3389.6, 453.0)

New Holstice was a Mid Rim hospital world between Belderone and Roche. It was part of the Galactic Republic since before 4000 BBY, and contained a monument to all Jedi killed since the formation of the Republic.

The Mandalorian Protectors unsuccessfully attacked the world in 22 BBY.

The planet was the memory moth homeworld.
