# Lanthe

**Continuity:** Legends  
**Source:** [Lanthe](https://starwars.fandom.com/wiki/Lanthe)
**Galaxy atlas:** system `Lanthe`, Mid Rim, grid M-16 — map position (2143.3, -10134.3, 350.4)

Lanthe was a planet in the Mid Rim's Var Hagen sector. It was the original headquarters of Lanthe Artifice, but when the local Imperial Moff nationalized all corporations, Lanthe Artifice relocated to the Tapani sector.
