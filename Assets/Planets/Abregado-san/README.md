# Abregado-san

**Continuity:** Legends  
**Source:** [Abregado-san](https://starwars.fandom.com/wiki/Abregado-san)

Abregado-san was the second planet from the star Anza in the Abregado system within the Southern Core portion of the Core Worlds. It was a barren world, having a desert for a surface, and had no moons.
