# Domgrin

**Continuity:** Legends  
**Source:** [Domgrin](https://starwars.fandom.com/wiki/Domgrin)
**Galaxy atlas:** system `Domgrin`, Outer Rim — map position (7778.6, 7940.3, 231.3)

Domgrin was a planet that was located within the Domgrin system, a part of the Prefsbelt sector in the galaxy's Outer Rim Territories. It was located relatively close to the planet Gonmore.
