# H'ken

**Continuity:** Legends  
**Source:** [H'ken](https://starwars.fandom.com/wiki/H%27ken)

H'ken was the primary planet in the H'ken system. Located within the H'ken asteroid belt, a 20 kilometer wide navigational nightmare, the planet was difficult to access.
