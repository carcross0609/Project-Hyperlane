# Sullumun

**Continuity:** Legends  
**Source:** [Sullumun](https://starwars.fandom.com/wiki/Sullumun)

Sullumun was the first planet orbiting the star Sullust in the Sullust system. Located in the Brema sector of the Outer Rim Territories, it was a gas giant with eighteen moons.
