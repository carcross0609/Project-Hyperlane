# Weken

**Continuity:** Legends  
**Source:** [Weken](https://starwars.fandom.com/wiki/Weken)
**Galaxy atlas:** system `Weken`, Wild Space, grid T-4 — map position (12267.7, 8698.7, -243.3)

Weken was a terrestrial planet with two moons that was located within the Parthovian Cluster's Faarlsun system, in the Wild Space region of the galaxy. The planet occupied the third orbit around its star, the yellow-white Faarlsun, and had a poisonous environment.
