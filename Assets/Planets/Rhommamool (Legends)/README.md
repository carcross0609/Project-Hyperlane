# Rhommamool

**Continuity:** Legends  
**Source:** [Rhommamool/Legends](https://starwars.fandom.com/wiki/Rhommamool/Legends)
**Galaxy atlas:** system `Rhommamool`, Expansion Region, grid N-13 — map position (4192.7, -5442.2, -140.4)

Rhommamool was an impoverished mining world in the Expansion Region, along the Corellian Run. It was in the same system as Osarian.
