# Honoghr

**Continuity:** Legends  
**Source:** [Honoghr/Legends](https://starwars.fandom.com/wiki/Honoghr/Legends)
**Galaxy atlas:** system `Honoghr`, Outer Rim, grid T-10 — map position (12716.2, -443.5, 221.6)

Honoghr was the homeworld of the Noghri, and the only one of the Honoghr system's seven planets with a permanent population.

Honoghr was covered by a single globe-spanning continent.
