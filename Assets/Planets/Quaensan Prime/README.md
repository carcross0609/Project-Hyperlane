# Quaensan Prime

**Continuity:** Legends  
**Source:** [Quaensan Prime](https://starwars.fandom.com/wiki/Quaensan_Prime)
**Galaxy atlas:** system `Quaensan Prime`, Mid Rim, grid J-17 — map position (-1549.4, -11405.9, -28.6)

Quaensan Prime was a Gendius sector, Mid Rim world on the Cerean Reach, near the Jiroch system. Its inhabitants were wiped out by the Reslian Purge, similar to what happened to the Tunroth.
