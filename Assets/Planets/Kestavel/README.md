# Kestavel

**Continuity:** Legends  
**Source:** [Kestavel](https://starwars.fandom.com/wiki/Kestavel)

Kestavel was a planet located in the Colonies, near Borleias. It was the location of The Lucky Twi'lek. The crew of the Uhumele ambushed Darth Vader there in 19 BBY.
