# Viis

**Continuity:** Legends  
**Source:** [Viis](https://starwars.fandom.com/wiki/Viis)

Viis was a planet located within the Viis system of the Unknown Regions. It was home to the Viis Empire. It was decimated by a prolonged outbreak of Mnggal-Mnggal.
