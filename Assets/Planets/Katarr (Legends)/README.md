# Katarr

**Continuity:** Legends  
**Source:** [Katarr/Legends](https://starwars.fandom.com/wiki/Katarr/Legends)
**Galaxy atlas:** system `Katarr`, Mid Rim, grid O-8 — map position (5799.8, 2539.7, -109.6)

Katarr was a planet in the Mid Rim and a Miraluka colony world. It was completely devastated in 3952 BBY, during the First Jedi Purge.
