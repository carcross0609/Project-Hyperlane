# Herzob

**Continuity:** Legends  
**Source:** [Herzob](https://starwars.fandom.com/wiki/Herzob)
**Galaxy atlas:** system `Herzob`, Colonies, grid N-12 — map position (3048.5, -3296.1, 76.4)

Herzob was an agriworld in the Colonies. It exported grains to several worlds in the Galactic Core and Mid Rim. The planet was infested with jevesects, which tore through the planet-spanning farms.
