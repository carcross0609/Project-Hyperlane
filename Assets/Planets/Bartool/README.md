# Bartool

**Continuity:** Canon  
**Source:** [Bartool](https://starwars.fandom.com/wiki/Bartool)

Bartool was a planet located in the galaxy that was home to a monastery owned by Phoolian Monks. At some point, a Jedi named Joria Skarl visited the monastery and learned of the story of Darth Ravi.
