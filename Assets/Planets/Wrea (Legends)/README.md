# Wrea

**Continuity:** Legends  
**Source:** [Wrea/Legends](https://starwars.fandom.com/wiki/Wrea/Legends)
**Galaxy atlas:** system `Wrea`, Outer Rim, grid S-17 — map position (10652.3, -11898.2, -415.3)

Wrea was an inhabited planet located within the Wrea system of the Outer Rim Territories near the Smuggler's Run. When Kueller's explosive droids decimated the inhabitants of the Run, the Wreans offered medical assistance. Wrea also contained a Republic outpost during the Clone Wars.
