# Jussafet Four

**Continuity:** Legends  
**Source:** [Jussafet Four](https://starwars.fandom.com/wiki/Jussafet_Four)
**Galaxy atlas:** system `Jussafet Four`, Outer Rim — map position (4944.1, 5848.9, 169.6)

Jussafet Four was a planet in the Outer Rim attacked by warlord Zsinj. It was a mining world under the Galactic Empire, and its inhabitants also mined the Jussafet asteroids.
