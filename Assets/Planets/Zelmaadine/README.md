# Zelmaadine

**Continuity:** Legends  
**Source:** [Zelmaadine](https://starwars.fandom.com/wiki/Zelmaadine)
**Galaxy atlas:** system `Zelmaadine`, Mid Rim, grid P-7 — map position (7178.8, 3837.2, 115.5)

Zelmaadine was a moonless volcanic planet that occupied the first orbital position around the star Velm. It was located in the Velm system, a part of the Halori sector in the Trans-Hydian portion of the Mid Rim.
