# Khomm

**Continuity:** Legends  
**Source:** [Khomm/Legends](https://starwars.fandom.com/wiki/Khomm/Legends)
**Galaxy atlas:** system `Khomm`, Deep Core, grid L-12 — map position (187.6, -3827.1, -14.1)

Khomm was a planet in the Khomm system in the Deep Core of the galaxy with wide blue seas, great land masses, and an abundance of oxygen. It was the home planet to the Khommites and the Khommite striders.
