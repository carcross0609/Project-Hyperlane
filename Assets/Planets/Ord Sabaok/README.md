# Ord Sabaok

**Continuity:** Legends  
**Source:** [Ord Sabaok](https://starwars.fandom.com/wiki/Ord_Sabaok)
**Galaxy atlas:** system `Ord Sabaok`, Core Worlds — map position (1526.9, -3242.8, 59.8)

Ord Sabaok was a Core Worlds planet. During the Pius Dea Era, it served as an Ordnance/Regional Depot outpost for the Galactic Republic. It came to be orbited by Imperial Star Destroyers by the time of the Battle of Yavin and was the home of Rebel spy Barthalemew Windsloe, who worked undercover to gather information from the Imperials while living there.
