# Ord Grovner

**Continuity:** Legends  
**Source:** [Ord Grovner](https://starwars.fandom.com/wiki/Ord_Grovner)
**Galaxy atlas:** system `Ord Grovner`, Outer Rim, grid O-18 — map position (5081.3, -13175.2, -326.3)

Ord Grovner was a planet in the Outer Rim Territories near Courkrus. Originally an Ordnance/Regional Depot, the planet served as a staging area for the Imperial task force, led by Admiral Freeda, which wiped out the Eyttyrmin Batiiv pirates.
