# Jalindi

**Continuity:** Canon  
**Source:** [Jalindi](https://starwars.fandom.com/wiki/Jalindi)

Jalindi was a planet located in the Jalindi system of the Outer Rim Territories with a landscape of red rock pillars surrounded by mist amidst an atmosphere breathable to humans. Around 1 BBY, the Galactic Empire had a relay station there which was destroyed during a mission carried out by the Rebel Alliance, which had originally intended to only hack the relay.
