# Oyokal

**Continuity:** Legends  
**Source:** [Oyokal/Legends](https://starwars.fandom.com/wiki/Oyokal/Legends)
**Galaxy atlas:** system `Oyokal`, Unknown Regions, grid E-8 — map position (-9446.3, 1601.5, -313.5)

Oyokal was a terrestrial planet located in the Oyokal system of the Unknown Regions' Chiss Space. A hyperlane linked the world to the Shihon system. A quadrupedal species was native to Oyokal.

The sentient Chiss of the Chiss Ascendancy maintained Oyokal as an aquaculture colony. The planet's surface featured wave-riding algal beds and pools stocked with fish.
