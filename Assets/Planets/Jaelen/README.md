# Jaelen

**Continuity:** Canon  
**Source:** [Jaelen](https://starwars.fandom.com/wiki/Jaelen)

Jaelen was a peaceful planet in the galaxy. In 34 ABY, on the orders of Agent Terex, the First Order was using civilian transports to smuggle arms from the Outer Rim to planets like Jaelen.

## Planetary data

- **Name:** Jaelen
- **Region:** Mid Rim Territories
- **Sector:** Irishi sector
- **System:** Jaelen system
- **Coordinates:** K-6
- **Imports:** Weapons and explosives
