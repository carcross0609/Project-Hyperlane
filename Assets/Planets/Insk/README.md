# Insk

**Continuity:** Canon  
**Source:** [Insk](https://starwars.fandom.com/wiki/Insk)
**Galaxy atlas:** system `Insk`, Other, grid M-11 — map position (2591.8, -2337.2, 26.5)

Insk was a silicon-based planet located in the galaxy's Wild Space. General Jan Dodonna of the Alliance to Restore the Republic briefly studied it as a potential location for a new Rebel base after the evacuation of the Great Temple on Yavin 4, but quickly rejected it due to being silicon-based, rather than carbon-based, and because it did not have resources that the Rebels could mine.
