# Jarnollen

**Continuity:** Legends  
**Source:** [Jarnollen](https://starwars.fandom.com/wiki/Jarnollen)
**Galaxy atlas:** system `Jarnollen`, Mid Rim, grid L-7 — map position (56.8, 3592.2, 79.3)

Jarnollen was a planet in close proximity to Ord Mantell in the Mid Rim. It was covered in tropical jungle, and its trees possessed overgrown vines.
