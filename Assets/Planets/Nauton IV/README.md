# Nauton IV

**Continuity:** Legends  
**Source:** [Nauton IV](https://starwars.fandom.com/wiki/Nauton_IV)
**Galaxy atlas:** system `Nauton IV`, Mid Rim — map position (-364.8, -11932.5, 445.9)

Nauton IV was a planet located in the Nauton system of the Taldot sector in the Mid Rim. In 20 BBY, Jedi Master Ruati was beheaded by an assassin on Nauton IV, and fellow Jedi Obi-Wan Kenobi suspected the Dark Jedi Asajj Ventress to be the murderer.
