# Doornik-628F

**Continuity:** Legends  
**Source:** [Doornik-628F](https://starwars.fandom.com/wiki/Doornik-628F)
**Galaxy atlas:** system `Doornik-628F`, Core Worlds — map position (2553.7, -1863.8, 52.5)

Doornik-628F was the sixth planet in the Doornik-628 system, located in the Farlax sector, which was in turn a part of the Koornacht Cluster, a region of the Negs portion of the Core Worlds. The system was centered around the star Doornik-628. Doornik-628F was a gas giant and was circled by eleven moons.
