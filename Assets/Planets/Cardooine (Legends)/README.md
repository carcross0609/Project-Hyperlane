# Cardooine

**Continuity:** Legends  
**Source:** [Cardooine/Legends](https://starwars.fandom.com/wiki/Cardooine/Legends)
**Galaxy atlas:** system `Cardooine`, Outer Rim, grid R-7 — map position (9740.8, 3584.7, 103.9)

Cardooine was a planet in the Jospro sector of the Outer Rim. It was where the Rebel Alliance built A-wings used in the Battle of Endor. It was also the home of Fijisi wood, used in sections of the Imperial Palace on Coruscant and other high-class buildings. Less pleasantly, the disease Cardooine Chills also originated on this planet.

In 0 ABY, there was a Rebel base on the planet which hosted the prototype A-wings. The squadron Soaring Dactillions was assigned there to test the starfighters. After a week, the base was assaulted by the Empire. Although the squadron defended the base, only two pilots survived.
