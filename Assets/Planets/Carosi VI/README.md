# Carosi VI

**Continuity:** Legends  
**Source:** [Carosi VI](https://starwars.fandom.com/wiki/Carosi_VI)

Carosi VI was a planet in the Carosus system. Originally the sixth orbit in the system, it became the first following the expansion of the star Carosi into a red giant and the subsequent destruction of system's first five planets. Prior to the expansion, it was considered to be a world suitable for terraforming, but Carosi's expansions burned away any life-sustaining potential.
