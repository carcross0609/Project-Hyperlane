# Unidentified planet

**Continuity:** Canon  
**Source:** [Unidentified planet (Galactic Frontier)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Galactic_Frontier%29)

A world located in the Outer Rim Territories was where the Witherbloom Pathfinder ship and a ship used by the Path of the Open Hand crashed after colliding in space above it. It had a breathable atmosphere and rocky terrain.

- **Name:** Unidentified planet
