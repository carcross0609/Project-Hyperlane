# Orline

**Continuity:** Legends  
**Source:** [Orline](https://starwars.fandom.com/wiki/Orline)
**Galaxy atlas:** system `Orline`, Colonies — map position (1477.3, -5617.3, -199.9)

Orline was the third planet in the Carida system. It was a world composed of methane seas, and had one moon. Like all the planets in the Carida system, it was destroyed by the Sun Crusher.
