# Thaere Privo

**Continuity:** Legends  
**Source:** [Thaere Privo](https://starwars.fandom.com/wiki/Thaere_Privo)
**Galaxy atlas:** system `Thaere Privo`, Expansion Region, grid O-14 — map position (4953.0, -6786.5, -205.9)

Thaere Privo was a planet located within the Thaereian system of the Expansion Region. The Galactic Senate tasked Thaere with protecting the Cularin system in a neighboring sector. Thaere joined the Confederacy of Independent Systems during the Clone Wars.
