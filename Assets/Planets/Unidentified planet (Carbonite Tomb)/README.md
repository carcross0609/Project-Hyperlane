# Unidentified planet

**Continuity:** Legends  
**Source:** [Unidentified planet (Carbonite Tomb)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Carbonite_Tomb%29)

A rocky planet was the location of the Carbonite Sith Tomb, which housed a Carbonite Sith Army along with a Carbonite Sith Master. It was found by the Nightsister Silri after she studied a holocron acquired by Tyber Zann.
