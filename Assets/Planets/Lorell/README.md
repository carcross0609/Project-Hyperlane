# Lorell

**Continuity:** Legends  
**Source:** [Lorell](https://starwars.fandom.com/wiki/Lorell)
**Galaxy atlas:** system `Lorell`, Inner Rim — map position (2531.7, -5464.4, -119.4)

Lorell was a planet located in the Inner Rim of the galaxy. It lay in a system just outside the Hapes Cluster. It was once base of the Lorell Raiders and was later known for its kickboxing.
