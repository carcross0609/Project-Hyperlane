# Yeshocq

**Continuity:** Legends  
**Source:** [Yeshocq](https://starwars.fandom.com/wiki/Yeshocq)
**Galaxy atlas:** system `Yeshocq`, Mid Rim, grid N-16 — map position (3823.0, -9914.8, 168.1)

Yeshocq was a planet located within the Yeshocq system of the Mid Rim. It was a colonized, forested, temperate planet with a local year that lasted 13 standard months: the local year was divided into 455 local days. Yeshocq was the homeworld qormot species.
