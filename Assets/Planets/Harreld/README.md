# Harreld

**Continuity:** Canon  
**Source:** [Harreld](https://starwars.fandom.com/wiki/Harreld)

Harreld was a gemstone-rich planet in the galaxy. During the construction of the Death Star, Director Orson Callan Krennic negotiated with the planet's leader Harqque in an effort to secure Harreld's kyber crystal deposits for the Galactic Empire, but such negotiations yielded no results, prompting Emperor Palpatine to dispatch Darth Vader to Harreld in order to take the planet's kyber by force.
