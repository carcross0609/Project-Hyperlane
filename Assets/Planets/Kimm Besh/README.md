# Kimm Besh

**Continuity:** Legends  
**Source:** [Kimm Besh](https://starwars.fandom.com/wiki/Kimm_Besh)
**Galaxy atlas:** system `Kimm Besh`, Mid Rim, grid L-18 — map position (293.6, -12063.0, 69.1)

Kimm Besh was a planet located in the Kimm Besh system of the Juvex sector, in the Mid Rim of the galaxy. It was one of a trio of dingy industrial worlds belonging to House Sreethyn.
