# Gyndine

**Continuity:** Legends  
**Source:** [Gyndine/Legends](https://starwars.fandom.com/wiki/Gyndine/Legends)
**Galaxy atlas:** system `Gyndine`, Expansion Region, grid O-12 — map position (4695.5, -3352.3, 18.0)

Gyndine was a planet in the Expansion Region. It was a local administrative center, and had mid-sized, advanced shipyards.
