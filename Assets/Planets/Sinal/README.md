# Sinal

**Continuity:** Legends  
**Source:** [Sinal](https://starwars.fandom.com/wiki/Sinal)

Sinal was the innermost planet of the Bacrana system. An uninhabitable ball of searing hot rock, Sinal orbited close to the system's star, Bacrana. Starships approaching Sinal had to be heavily shielded, and could only remain for a short amount of time.
