# Siquay

**Continuity:** Legends  
**Source:** [Siquay/Legends](https://starwars.fandom.com/wiki/Siquay/Legends)

Siquay was the sixth planet orbiting the star Sriluur in the Sriluur system. Located in the Tharin sector of the Outer Rim Territories, it was a gas giant.
