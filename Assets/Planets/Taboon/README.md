# Taboon

**Continuity:** Legends  
**Source:** [Taboon](https://starwars.fandom.com/wiki/Taboon)
**Galaxy atlas:** system `Taboon`, Inner Rim, grid O-10 — map position (5534.3, -346.5, 55.6)

Taboon was a gas giant in the Aweris system. It shared its name with the Taboon hardwood. Bogga the Hutt's palace was on Vo Dasha, a moon orbiting Taboon.
