# Vonak

**Continuity:** Legends  
**Source:** [Vonak](https://starwars.fandom.com/wiki/Vonak)

Vonak was a planet home to the Cilare species which subscribed to martial values and savored combat around 25 ABY. It had wide open grassy plains and was home to canine and a reptilian species which were hunted by the warriors.
