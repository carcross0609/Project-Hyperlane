# Laazrau

**Continuity:** Legends  
**Source:** [Laazrau](https://starwars.fandom.com/wiki/Laazrau)
**Galaxy atlas:** system `Laazrau`, Core Worlds — map position (2526.5, -3056.2, 82.3)

Laazrau was a planet in the Zug system. It was one of four gas giants in that star system, along with Zauhu, Urazuun, and Faargau. It was the outermost of them and had the fewest natural satellites – thirteen in total.
