# Hijado

**Continuity:** Legends  
**Source:** [Hijado](https://starwars.fandom.com/wiki/Hijado)
**Galaxy atlas:** system `Hijado`, Outer Rim, grid O-6 — map position (5364.6, 5546.2, -134.4)

Hijado was a planet on the Hydian Way, halfway to Bonadan. The Human natives of Hijado were called Hijadoans. It was located in the Hijado system of the Thesme sector.
