# Socorro

**Continuity:** Legends  
**Source:** [Socorro/Legends](https://starwars.fandom.com/wiki/Socorro/Legends)
**Galaxy atlas:** system `Socorro`, Outer Rim, grid Q-17 — map position (7727.8, -11533.5, 316.2)

Socorro was a planet in the Outer Rim Territories with a reputation as a smuggler haven. It was the homeworld of Lando Calrissian.
