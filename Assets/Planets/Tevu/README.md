# Tevu

**Continuity:** Canon  
**Source:** [Tevu](https://starwars.fandom.com/wiki/Tevu)

Tevu was a terrestrial planet where the battle on Tevu, in which Jedi Padawan Yaddle fought, took place. Around 160 BBY, Tevu was planning a celebration for an upcoming anniversary of the battle.

- **Name:** Tevu
- **Region:** Expansion Region
