# Khaërn VII

**Continuity:** Unknown  
**Source:** [Khaërn VII](https://starwars.fandom.com/wiki/Kha%C3%ABrn_VII)

Khaërn VII was an abandoned mining planet, occupied by natives and colonists. The colonists maintained a hyperspace communications relay. The planet was covered in swampy plains and bayous, with the occasional jungle.
