# Unidentified planet

**Continuity:** Canon  
**Source:** [Unidentified planet (Fantanines)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Fantanines%29)

A rocky planet was the location of a mining colony ran by the Fantanines. The planet was strip-mined, destroying its environment. A sentient species native to the planet impeded the mining operation, leading the Fantanines to exploit them for resources.
