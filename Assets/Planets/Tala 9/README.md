# Tala 9

**Continuity:** Legends  
**Source:** [Tala 9](https://starwars.fandom.com/wiki/Tala_9)
**Galaxy atlas:** system `Tala 9`, Inner Rim, grid N-9 — map position (3142.1, 900.6, -90.6)

Tala 9 was located within the Tala system of the Inner Rim. It was the location of a droid-controlled factory. The droids discouraged sentients from visiting by only using droid languages to issue landing codes. The system was discontinued after two fully laden passenger liners collided in orbit. The equipment aboard the ships was of an older model, and misinterpreted a landing signal that was intended for vessels with upgraded systems.
