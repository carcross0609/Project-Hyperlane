# Rampa III

**Continuity:** Legends  
**Source:** [Rampa III](https://starwars.fandom.com/wiki/Rampa_III)

Rampa III, commonly known as Rampa, was a heavily industrialized planet in the Corporate Sector, which had a landscape so barren and polluted that drinkable water was an extremely precious resource. The need for water set up a thriving smuggling route known as the Rampa Rapids between Rampa III and nearby R'alla, which had an abundance of clear, refreshing water.
