# Varlinaar

**Continuity:** Legends  
**Source:** [Varlinaar](https://starwars.fandom.com/wiki/Varlinaar)
**Galaxy atlas:** system `Varlinaar`, Outer Rim, grid J-18 — map position (-2413.8, -13194.1, -633.7)

Varlinaar was a planet located within the Varlinaar system of the Outer Rim Territories. Rorworr once smuggled a team of Rebels into the Imperial base on the planet under the pretense of bringing the Imperials rare foods.
