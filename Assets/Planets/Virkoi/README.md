# Virkoi

**Continuity:** Canon  
**Source:** [Virkoi](https://starwars.fandom.com/wiki/Virkoi)

Virkoi was an aquatic world located in the Virkoi system of the Inner Rim Territories that housed a Imperial training academy known as Viper's Nest. Sinjir Rath Velus uncovered a plot to assassinate Darth Vader whilst on Virkoi.
