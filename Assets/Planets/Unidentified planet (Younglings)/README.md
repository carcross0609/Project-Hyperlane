# Unidentified planet

**Continuity:** Legends  
**Source:** [Unidentified planet (Younglings)](https://starwars.fandom.com/wiki/Unidentified_planet_%28Younglings%29)

This unidentified planet was a planet in the galaxy. During the Clone Wars, Jedi Knight Anakin Skywalker took a Jedi Initiate Clan on a training mission to this planet. Members of the group included Jedi younglings Ammon, Cryle and Tryla.
