# Kethmandi

**Continuity:** Canon  
**Source:** [Kethmandi](https://starwars.fandom.com/wiki/Kethmandi)

Kethmandi was a planet in the Kethmandi system of the Expansion Region's Hangshan sector. Sometime between 19 BBY and 10 BBY, Chewbacca was an Imperial prisoner on Kethmandi.
