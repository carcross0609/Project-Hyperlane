# Koboth

**Continuity:** Legends  
**Source:** [Koboth](https://starwars.fandom.com/wiki/Koboth)

Koboth was the Kobok homeworld. It was located in the Outer Rim Territories, on the fringe of the Tingel Arm. It bordered the Corporate Sector.
