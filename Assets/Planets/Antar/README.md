# Antar

**Continuity:** Canon  
**Source:** [Antar](https://starwars.fandom.com/wiki/Antar)
**Galaxy atlas:** system `Antar`, Inner Rim, grid N-12 — map position (4242.5, -3156.0, -206.1)

Antar was a gas giant located in the galaxy's Inner Rim, located in grid square N-12 on the Standard Galactic Grid, that was orbited by Antar 4, homeworld of the sentient Gotal species, and the Dead Moon of Antar.
