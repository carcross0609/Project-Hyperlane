# Shi'kar homeworld

**Continuity:** Legends  
**Source:** [Shi'kar homeworld](https://starwars.fandom.com/wiki/Shi%27kar_homeworld)

The Shi'kar homeworld was inhabited by the Shi'kar species. It was destroyed by a comet prior to the Clone Wars, and became an asteroid belt known as the Shi'kar Straits. It was located in the Nembus sector.
