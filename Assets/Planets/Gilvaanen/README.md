# Gilvaanen

**Continuity:** Canon  
**Source:** [Gilvaanen](https://starwars.fandom.com/wiki/Gilvaanen)
**Galaxy atlas:** system `Gilvaanen`, Inner Rim — map position (5624.1, 959.4, 129.3)

Gilvaanen was a backwater planet located in the Gilvaanen system in the Inner Rim Territories. Prior to the Galactic Civil War, Gilvaanen housed production facilities for Imperial stormtrooper armor. When Count Denetrius Vidian and Grand Moff Wilhuff Tarkin discovered and prevented an insurgence in the facilities, Vidian placed the production chain under the direction of Lieutenant Everi Chalis.
