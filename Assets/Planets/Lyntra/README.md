# Lyntra

**Continuity:** Legends  
**Source:** [Lyntra](https://starwars.fandom.com/wiki/Lyntra)

Lyntra was the fourth planet orbiting the star of Sriluur in the Sriluur system. Located in the Tharin sector of the Outer Rim, it was a barren rock.
