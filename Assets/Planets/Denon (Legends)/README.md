# Denon

**Continuity:** Legends  
**Source:** [Denon/Legends](https://starwars.fandom.com/wiki/Denon/Legends)
**Galaxy atlas:** system `Denon`, Inner Rim, grid N-13 — map position (3418.6, -4748.4, 237.7)

Denon, a planet located between Osarian and Nubia, was an ecumenopolis world, with city growth covering the entire surface, similar to Coruscant.
