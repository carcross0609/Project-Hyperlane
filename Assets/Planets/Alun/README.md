# Alun

**Continuity:** Canon  
**Source:** [Alun](https://starwars.fandom.com/wiki/Alun)

Alun was a planet located in the Mid Rim of the galaxy. Because no useful hyperspace routes connected it to other systems, Alun was relatively isolated, and escaped Imperial rule. The planet was ruled by a royal family.

## Planetary data

- **Name:** Alun
- **Region:** Mid Rim Territories
- **Sector:** Oriolan sector
- **System:** Alun system
- **Coordinates:** J-16
- **Affiliation:** Royal family of Alun
