# Jatee

**Continuity:** Legends  
**Source:** [Jatee](https://starwars.fandom.com/wiki/Jatee)
**Galaxy atlas:** system `Jatee`, Mid Rim — map position (386.3, -12182.4, -307.7)

Jatee was the third planet of the Demophon system. It was the site of a Galactic Empire mining operation for rutgar-4. It was destroyed when its sun went supernova.
