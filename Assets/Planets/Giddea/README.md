# Giddea

**Continuity:** Legends  
**Source:** [Giddea](https://starwars.fandom.com/wiki/Giddea)

Giddea was a planet in the galaxy whose sun died during the Cold War. Bioanalysts managed to harvest specimens from the world before it became permanently shrouded in darkness.
