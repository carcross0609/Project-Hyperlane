# Sarapin

**Continuity:** Canon  
**Source:** [Sarapin](https://starwars.fandom.com/wiki/Sarapin)
**Galaxy atlas:** system `Sarapin`, Core Worlds, grid M-10 — map position (2400.9, -1356.7, -57.2)

Sarapin was a planet located in the Sarapin system in the Core Worlds. At some point prior to the attack on the EF76 Nebulon-B escort frigate Hellion's Dare over Jiruus, a fleet battle occurred at Sarapin during which Riot Squadron members Wyl Lark and Sonogari were present, but grounded.
