# Nimba Five

**Continuity:** Legends  
**Source:** [Nimba Five](https://starwars.fandom.com/wiki/Nimba_Five)

Nimba Five was a planet in the Nimba system in Wild Space with which the hunter Sam Heggs was familiar. According to Heggs, Nimba Five had a time warp, with one time tropical and the other frozen in ice. It was located on the same hyperroute as Beta Rhama.
