# Thila

**Continuity:** Legends  
**Source:** [Thila/Legends](https://starwars.fandom.com/wiki/Thila/Legends)
**Galaxy atlas:** system `Thila`, Outer Rim, grid Q-4 — map position (7883.6, 7981.2, -17.5)

Thila was a small planet in the Thila system of the Outer Rim Territories. It was home to a major Alliance to Restore the Republic base, Thila Command. The planet had relatively huge mountain ranges, of which the peaks of its gigantic mountains were visible from orbit.
