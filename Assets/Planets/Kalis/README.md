# Kalis

**Continuity:** Legends  
**Source:** [Kalis](https://starwars.fandom.com/wiki/Kalis)
**Galaxy atlas:** system `Kalis`, Outer Rim, grid M-19 — map position (2688.5, -13850.0, -576.1)

Kalis was the third planet in the Derilyn system. It was a harsh and remote world with a thick, boiling atmosphere. There was no life on the world.
