# Fahariyn

**Continuity:** Legends  
**Source:** [Fahariyn](https://starwars.fandom.com/wiki/Fahariyn)

Fahariyn was a gas giant occupying the first orbital position in the Ansion system, which was located in the Churnis sector in the Mid Rim. It had three moons.
