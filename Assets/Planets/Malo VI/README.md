# Malo VI

**Continuity:** Legends  
**Source:** [Malo VI](https://starwars.fandom.com/wiki/Malo_VI)

Malo VI was a planet in the Malo system where a warrant was issued for the arrest of Tegist Byrg.

Jensaarai Mei and Bpfasshi Fomadu, both mourning the deaths of family members lost to the Jedi, first met on Malo VI, where they joined forces in search of revenge.
