# AX-12

**Continuity:** Legends  
**Source:** [AX-12](https://starwars.fandom.com/wiki/AX-12)

AX-12 was the outermost planet in the AX system. It was a barren planet located in the Barma sector. It had two moons and orbited the system's dwarf star.
