# Artiod Minor

**Continuity:** Canon  
**Source:** [Artiod Minor](https://starwars.fandom.com/wiki/Artiod_Minor)
**Galaxy atlas:** system `Artiod Minor`, Other, grid L-6 — map position (552.9, 5649.4, -43.9)

Artiod Minor was a Wild Space planet that was the homeworld of the sentient Artiodac species. At one point, the inhabitants of the cold and swampy world became enslaved for centuries by the Zygerrian Slave Empire, which led to the scattering of the Artiodacs across the galaxy. Nevertheless, the Artiodac chef Strono Tuggs spent his childhood on Artiod Minor.
