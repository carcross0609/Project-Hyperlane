# Valboraan

**Continuity:** Canon  
**Source:** [Valboraan](https://starwars.fandom.com/wiki/Valboraan)

Valboraan was a desert planet located in the Valboraan system, in the Kastolar sector of the Mid Rim Territories. It was situated along the Ootmian Pabol near the planets Kwenn and Keldooine. The planet was home to many cave systems, which made it attractive as a hideout. It was home to the headquarters of the Riftwalkers pirate gang.
