# Sorjus

**Continuity:** Legends  
**Source:** [Sorjus](https://starwars.fandom.com/wiki/Sorjus)
**Galaxy atlas:** system `Sorjus`, Outer Rim, grid R-7 — map position (9148.7, 4421.9, -195.7)

Sorjus was an Outer Rim Territories planet located in the Meridian sector. It was the homeworld of the Paaerduag species. The spacer Ja'Gatcha and merchant Mic'tunan'jus Orgu were two Paaerduag who had left their home planet by 3956 BBY.
