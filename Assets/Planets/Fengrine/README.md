# Fengrine

**Continuity:** Canon  
**Source:** [Fengrine](https://starwars.fandom.com/wiki/Fengrine)
**Galaxy atlas:** system `Fengrine`, Mid Rim, grid L-18 — map position (637.3, -12032.4, -501.4)

Fengrine was an agri-industrial world that had hydroponic shells around it. It was located in the Fengrine system in the Senex sector of the Mid Rim Territories, in grid square L-18 of the Standard Galactic Grid. The common image of armchair farming in these shells was far removed from the moisture farming that occurred on the searing desert planet Tatooine in 22 BBY.
