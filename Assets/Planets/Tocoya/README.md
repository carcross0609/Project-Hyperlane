# Tocoya

**Continuity:** Legends  
**Source:** [Tocoya](https://starwars.fandom.com/wiki/Tocoya)
**Galaxy atlas:** system `Tocoya`, Inner Rim, grid N-9 — map position (3889.4, 1260.8, 261.4)

Tocoya was a planet located within the Tocoya system of the Inner Rim and the homeworld of the Tocoyan race. Neb Dulo, a disciple of the religion Davrilat, was from the planet.
