# Kwenn

**Continuity:** Legends  
**Source:** [Kwenn/Legends](https://starwars.fandom.com/wiki/Kwenn/Legends)
**Galaxy atlas:** system `Kwenn`, Mid Rim, grid R-10 — map position (9785.2, -1242.6, -457.1)

Kwenn was a planet located in the Kastolar sector of the Mid Rim. It was situated along the Ootmian Pabol hyperlane. Kwenn was orbited by the Kwenn Space Station.
