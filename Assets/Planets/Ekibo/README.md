# Ekibo

**Continuity:** Legends  
**Source:** [Ekibo](https://starwars.fandom.com/wiki/Ekibo)
**Galaxy atlas:** system `Ekibo`, Wild Space, grid R-3 — map position (10269.0, 9426.4, -350.7)

Ekibo was a Trianii colony planet in Trianii Space, famous for its farms and herdbeasts. Trianii Rangers Atuarre and Keeheen were responsible for overthrowing a herdbeast-rustling ring there.
