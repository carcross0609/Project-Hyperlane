# Nadhe

**Continuity:** Legends  
**Source:** [Nadhe](https://starwars.fandom.com/wiki/Nadhe)

Nadhe was a remote planet that defied Emperor Palpatine shortly after the formation of the Galactic Empire. Like the other worlds that refused to cooperate, Nadhe suffered an unspecified devastation as a result.
