# Prine

**Continuity:** Legends  
**Source:** [Prine](https://starwars.fandom.com/wiki/Prine)

Prine was a mostly-uninhabited desert-covered planet situated on the way between Telerath and Vondarc. It also possessed grasslands where agriculture was possible.
