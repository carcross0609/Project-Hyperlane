# Rakhuuun

**Continuity:** Legends  
**Source:** [Rakhuuun](https://starwars.fandom.com/wiki/Rakhuuun)
**Galaxy atlas:** system `Rakhuuun`, Mid Rim, grid P-9 — map position (7346.2, 60.4, -111.7)

Rakhuuun was a planet that was located in the Rakhuuun system of the Mytaranor sector. It was a part of the Kashyyyk Region, in the Slice portion of the Mid Rim. The Randon Run hyperlane connected the planet to the worlds of Chamble and Kashyyyk.

Rakhuuun was colonized by members of the sentient Wookiee species from nearby Kashyyyk, and was known for a small shipyard in which freighters and yachts of aesthetically pleasing design were manufactured.
