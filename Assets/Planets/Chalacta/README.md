# Chalacta

**Continuity:** Canon  
**Source:** [Chalacta](https://starwars.fandom.com/wiki/Chalacta)
**Galaxy atlas:** system `Chalacta`, Mid Rim, grid R-10 — map position (9822.6, -310.7, 169.2)

Chalacta was a planet located in the Metatessu sector's Chalacta system within the Mid Rim. that was the homeworld of the Chalactan people. The human Jedi Master Depa Billaba was born on Chalacta. In the C.R.C. year 7941, Chalacta was represented in the Galactic Senate of the Galactic Republic by Yudrish Sedran.
