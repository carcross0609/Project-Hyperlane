# Lantaana

**Continuity:** Canon  
**Source:** [Lantaana](https://starwars.fandom.com/wiki/Lantaana)

Lantaana was a lush jungle planet with lakes and volcanoes on which the racing organization Galactic League held unsanctioned racing matches during the New Republic Era.
