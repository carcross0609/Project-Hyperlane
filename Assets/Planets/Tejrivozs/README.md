# Tejrivozs

**Continuity:** Legends  
**Source:** [Tejrivozs](https://starwars.fandom.com/wiki/Tejrivozs)
**Galaxy atlas:** system `Tejrivozs`, Mid Rim, grid J-16 — map position (-2367.6, -9625.3, -336.3)

Tejrivozs was a planet in the trinary star system of Riflorii. It was a colony of the Advozsec and was controlled by a powerful crime family. It was left alone by the Yuuzhan Vong.
