# Kor Hestilic; (The Bootana Hutta region, with Kor Hestilic represented by the number 4)

**Continuity:** Legends  
**Source:** [Kor Hestilic](https://starwars.fandom.com/wiki/Kor_Hestilic)
**Galaxy atlas:** system `Kor Hestilic`, Hutt Space, grid S-10 — map position (11205.6, -1211.4, 197.9)

Kor Hestilic was a world located within the Kor Hestilic system, a part of the Bootana Hutta region of Hutt Space, and was part of the Slice section of the galaxy. It was connected by hyperlanes to the Kor Besadii, Kor Nijiladii, Kor Vosadii, Mulatan and Nar Chunna systems.

Kor Hestilic was the throneworld of the Hestilic kajidic.
