# Narth

**Continuity:** Legends  
**Source:** [Narth](https://starwars.fandom.com/wiki/Narth)
**Galaxy atlas:** system `Narth`, Outer Rim — map position (-4786.9, -9674.1, 66.9)

Narth was a planet evacuated along with Ihopek after the Battle of Endor by the Galactic Empire. The Star Destroyer Gnisnal was crippled by internal explosions and had to be scuttled. The wreckage later gave the New Republic the complete copy of the Imperial Order of battle.
