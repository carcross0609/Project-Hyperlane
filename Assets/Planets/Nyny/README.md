# Nyny

**Continuity:** Legends

**Galaxy atlas:** system `Nyny`, Outer Rim, grid T-7 — map position (12573.6, 4146.3, -203.4)

Nyny was a homeworld of a three-headed sentient species located in the Ash Worlds. Thirteen years after the Battle of Endor, Nyny was represented in the New Republic Senate.
