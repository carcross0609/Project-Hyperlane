# Varonat

**Continuity:** Legends  
**Source:** [Varonat/Legends](https://starwars.fandom.com/wiki/Varonat/Legends)
**Galaxy atlas:** system `Varonat`, Outer Rim, grid K-18 — map position (-1411.4, -12719.1, -135.9)

Varonat was a planet located in the Anoat sector of the Outer Rim Territories, situated along the Ison Corridor. It was a steaming jungle and adopted home of the Morodin species.
