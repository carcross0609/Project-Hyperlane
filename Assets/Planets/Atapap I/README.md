# Atapap I

**Continuity:** Legends  
**Source:** [Atapap I](https://starwars.fandom.com/wiki/Atapap_I)
**Galaxy atlas:** system `Atapap I`, Inner Rim, grid N-12 — map position (3833.3, -3740.0, -186.0)

Atapap I was part of the Atapap system in the Inner Rim. At the dawn of the Old Republic, centuries before the rise of the Galactic Empire, it was, along with Fadden and Aquilae, settled by colonists of the Duros species, which was native to the Core Worlds planet Duro.
