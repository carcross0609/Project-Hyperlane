# Sikurd

**Continuity:** Legends  
**Source:** [Sikurd](https://starwars.fandom.com/wiki/Sikurd)
**Galaxy atlas:** system `Sikurd`, Outer Rim, grid Q-4 — map position (8417.3, 8181.3, 636.7)

Sikurd was a planet located in the Sikurd system within the Tynquay sector in the Outer Rim Territories, and it was the homeworld of the Sikurdian species. It was also where Sikurdian battle-axes were made.
