# Jenenma

**Continuity:** Legends  
**Source:** [Jenenma](https://starwars.fandom.com/wiki/Jenenma)

Jenenma was a planet with many starshipwrights. The Hutt's Last Laugh cantina was on the planet, as was the headquarters of a syndicate run by Pal-Nada, a Cerean Force adept.
