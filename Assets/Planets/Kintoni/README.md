# Kintoni

**Continuity:** Canon  
**Source:** [Kintoni](https://starwars.fandom.com/wiki/Kintoni)
**Galaxy atlas:** system `Kintoni`, Outer Rim — map position (140.8, 7153.5, 299.6)

Kintoni was a planet under the rule of the Galactic Empire and governed by Governor Sanz. It was located in the Kintoni system in the Ash Worlds of the Outer Rim Territories, in grid square S-6 of the Standard Galactic Grid. Kintoni competed against Lothal, led by Governor Arihnda Pryce, to be awarded contracts by the Select Committee of Imperial High Command in order to build new facilities and factories to expand naval operations in the Outer Rim Territories. Sanz removed Kintoni from the list of potential candidates after Senator Domus Renking bribed Sanz into doing so. Pryce then informed the Imperial Security Bureau of the bribery and the ISB arrested Sanz and Renking, removing any potential enemies or competition for Pryce.
