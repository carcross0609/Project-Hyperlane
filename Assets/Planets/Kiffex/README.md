# Kiffex

**Continuity:** Canon  
**Source:** [Kiffex](https://starwars.fandom.com/wiki/Kiffex)
**Galaxy atlas:** system `Kiffex`, Inner Rim — map position (4741.4, -738.2, 80.0)

Kiffex, alongside Kiffu, was one of the home planets of the Kiffar species. It was located in the Kiffex system in the Kiffu sector of the Inner Rim. Kiffex was the homeworld of Jedi Vildar Mac.
