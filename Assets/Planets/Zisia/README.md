# Zisia

**Continuity:** Legends  
**Source:** [Zisia](https://starwars.fandom.com/wiki/Zisia)
**Galaxy atlas:** system `Zisia`, Hutt Space, grid S-10 — map position (11965.5, -694.1, -106.2)

Zisia was a rich planet that was located within the Zisia system in Hutt Space, a region of the galaxy controlled by the Hutt species. The planet lay on the hyperlane called the Dead Road, which connected it to the worlds of Elgit and Ulmatra. Zisia was the homeworld of the sentient Zisian species, members of which served as pliant slaves for millennia.
