# Argoon

**Continuity:** Legends  
**Source:** [Argoon](https://starwars.fandom.com/wiki/Argoon)
**Galaxy atlas:** system `Argoon`, Outer Rim, grid S-6 — map position (10809.8, 5595.8, -32.4)

Argoon was an Outer Rim planet in the Argoon system, near Pakuuni. It was the site of an Imperial manufacturing facility abandoned after numerous Rebel attacks.
