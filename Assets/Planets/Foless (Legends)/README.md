# Foless

**Continuity:** Legends  
**Source:** [Foless/Legends](https://starwars.fandom.com/wiki/Foless/Legends)
**Galaxy atlas:** system `Foless`, Colonies, grid M-13 — map position (1653.4, -5727.6, 177.2)

Foless was a planet located in the Southern Core portion of the Colonies. It was situated on the periphery of the Trailing Sectors portion of the Inner Rim.

Foless sat at the intersection of the Corellian Trade Spine and Shipwrights' Trace hyperlanes, known as the Foless Crossroads.
