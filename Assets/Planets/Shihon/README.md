# Shihon

**Continuity:** Canon  
**Source:** [Shihon](https://starwars.fandom.com/wiki/Shihon)
**Galaxy atlas:** system `Shihon`, Unknown Regions, grid E-8 — map position (-9273.0, 1663.8, 32.1)

Shihon was a planet in the Shihon system in Chiss Space, in grid square E-8 of the Standard Galactic Grid in the Unknown Regions. Home to a number of bird species, Shihon was host to the Grand Migration, a yearly event that saw the confluence of a number of different birds' migratory patterns. Haplif of the Agbui, while traveling with the Chiss Yoponek and Yomie in an attempt to study the Ascendancy prior to orchestrating its fall by sparking a civil war, was forced to remain on Shihon so that Yomie could view the Grand Migration.
