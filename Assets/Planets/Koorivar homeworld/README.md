# Koorivar homeworld

**Continuity:** Canon  
**Source:** [Koorivar homeworld](https://starwars.fandom.com/wiki/Koorivar_homeworld)

A planet served as the original homeworld of the Koorivar species. It was later abandoned when the Koorivars settled on the Inner Rim planet Kooriva.
