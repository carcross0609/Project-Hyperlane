# Thraisai

**Continuity:** Legends  
**Source:** [Thraisai/Legends](https://starwars.fandom.com/wiki/Thraisai/Legends)
**Galaxy atlas:** system `Thraisai`, Wild Space, grid U-9 — map position (14420.2, 997.4, -747.3)

Thraisai was a planet located in the Thraisai system of Wild Space. At some point between 17 BBY and 0 ABY, the Human bounty hunter Beilert Valance led a group of mercenaries in capturing a ring of enslavers on Thraisai, a mission that helped Valance attain the status of an elite hunter.
