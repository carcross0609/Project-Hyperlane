# Zhotta 3

**Continuity:** Legends  
**Source:** [Zhotta 3](https://starwars.fandom.com/wiki/Zhotta_3)
**Galaxy atlas:** system `Zhotta 3`, Outer Rim, grid M-18 — map position (2546.3, -12909.2, -485.3)

Zhotta 3 was a planet located in the Zhotta system of the Outer Rim Territories' Mayagil sector. After the Battle of Endor, the Rebel Alliance sent Han Solo and Chewbacca to invite the planetary leaders of this world to a congress to determine the fate of the galaxy.
