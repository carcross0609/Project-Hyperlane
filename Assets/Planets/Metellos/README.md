# Metellos

**Continuity:** Canon  
**Source:** [Metellos](https://starwars.fandom.com/wiki/Metellos)
**Galaxy atlas:** system `Metellos`, Core Worlds, grid K-9 — map position (-202.6, 18.4, -18.9)

Metellos was a planet in the Metellos system, a star system in the Corusca sector of the Core Worlds. It was connected via a hyperspace route to the distant planet Ilum in the Unknown Regions. The route was mapped by hyperspace surveyors hired by the Jedi Order as Ilum was a world important to the training of a Jedi.
