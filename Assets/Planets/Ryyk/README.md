# Ryyk

**Continuity:** Legends  
**Source:** [Ryyk](https://starwars.fandom.com/wiki/Ryyk)
**Galaxy atlas:** system `Ryyk`, Mid Rim, grid N-7 — map position (3870.2, 3239.9, -86.5)

Ryyk was a Neti colony. It was wrongly considered by some to be the original Neti homeworld, which was Myrkr. Some time prior to the Great Sith War, Ryyk was destroyed when its star went supernova. The remnants formed the Ryyk Nebula.
