# Virmeude

**Continuity:** Legends  
**Source:** [Virmeude](https://starwars.fandom.com/wiki/Virmeude)
**Galaxy atlas:** system `Virmeude`, Outer Rim, grid M-18 — map position (2266.8, -12849.7, 286.9)

Virmeude was a planet in the Mayagil sector. It was the headquarters of Issham Mining Corporation, which was actually a cover for a Rebel Alliance base.
