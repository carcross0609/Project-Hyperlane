# Gwongdeen

**Continuity:** Canon  
**Source:** [Gwongdeen](https://starwars.fandom.com/wiki/Gwongdeen)

Gwongdeen was a planet located in the Colonies and the Interior regions, covered by a membranous biological sea that protected the rocky core. The Undervaults of Gwongdeen lay beneath the surface of the living sea, which was opened up using force fields to let starships pass through to the spaceport.
