# Chad

**Continuity:** Legends  
**Source:** [Chad/Legends](https://starwars.fandom.com/wiki/Chad/Legends)
**Galaxy atlas:** system `Chad`, Outer Rim, grid R-7 — map position (10065.1, 3958.7, 408.3)

The planet Chad (also known as Chadra or Chad III) was the homeworld of the Chadra-Fan race. It was in the Outer Rim Territories, more specifically in the Slice.
