# Ord Varee

**Continuity:** Legends  
**Source:** [Ord Varee](https://starwars.fandom.com/wiki/Ord_Varee)
**Galaxy atlas:** system `Ord Varee`, Mid Rim, grid J-7 — map position (-2899.6, 3950.4, -73.8)

Ord Varee was a Mid Rim planet situated in the Belshar sector. Serving as a Galactic Republic Ordnance/Regional Depot outpost during the Pius Dea Era, millennia later it loosened its immigration restrictions for people displaced by the Separatist Crisis. Eventually the planet became a part of the New Republic.
