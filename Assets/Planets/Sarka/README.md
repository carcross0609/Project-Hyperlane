# Sarka

**Continuity:** Canon  
**Source:** [Sarka](https://starwars.fandom.com/wiki/Sarka)
**Galaxy atlas:** system `Sarka`, Mid Rim, grid Q-8 — map position (8824.5, 2265.1, 194.8)

Sarka was a planet located in the galaxy's Mid Rim, in grid square Q-8 on the Standard Galactic Grid. It was the homeworld of the reptilian Sarkan species. By the time of the Galactic Civil War, Sarka was ruled by Queen Zil.
