# Belderone

**Continuity:** Legends  
**Source:** [Belderone/Legends](https://starwars.fandom.com/wiki/Belderone/Legends)
**Galaxy atlas:** system `Belderone`, Outer Rim, grid R-6 — map position (10167.0, 4688.2, -5.0)

Belderone, originally known as Vartholium, was the sector capital of Belderone sector in the Outer Rim Territories. Located on the Salin Corridor, Belderone had two inhabited moons.
