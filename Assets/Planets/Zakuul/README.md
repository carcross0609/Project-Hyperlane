# Zakuul

**Continuity:** Legends  
**Source:** [Zakuul](https://starwars.fandom.com/wiki/Zakuul)
**Galaxy atlas:** system `Zakuul`, Unknown Regions, grid D-13 — map position (-11165.3, -5185.4, -281.5)

Zakuul was a planet located in Wild Space that had a unique connection to the Force being balanced between the light and dark sides of the Force. Zakuul served as the capital planet of the Eternal Empire.
