# Romm

**Continuity:** Legends  
**Source:** [Romm](https://starwars.fandom.com/wiki/Romm)
**Galaxy atlas:** system `Romm`, Outer Rim, grid I-19 — map position (-4264.5, -14287.2, 338.7)

Romm was a planet in the Delantine system with a small Rebel cell. Trux Zissu intended to rally support from Romm, but was captured by the Empire when he entered the system. From Da'nor, another planet in the system, Stuart Zissu, C-3PO, R2-D2, and 4B-X were directed to go to Romm.
