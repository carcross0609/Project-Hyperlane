# Davnar II

**Continuity:** Legends  
**Source:** [Davnar II/Legends](https://starwars.fandom.com/wiki/Davnar_II/Legends)
**Galaxy atlas:** system `Davnar II`, Core Worlds, grid K-9 — map position (-1067.9, 625.8, 48.4)

Davnar II, or simply Davnar, was a little-known planet in the Davnar system of the Kanchen sector, located in the Core Worlds.

It was the Kalidor and another native species' homeworld. The Kalidor Crescent was a Rebel Alliance medal of honor, named in honor the creature of this planet.
