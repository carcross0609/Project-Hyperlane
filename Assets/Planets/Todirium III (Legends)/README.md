# Todirium III

**Continuity:** Legends  
**Source:** [Todirium III/Legends](https://starwars.fandom.com/wiki/Todirium_III/Legends)
**Galaxy atlas:** system `Todirium III`, Outer Rim, grid P-7 — map position (7240.8, 3203.0, -8.1)

Todirium III was a planet located within the Todirium system of the Outer Rim Territories. Located near warlord Zsinj's territory, it was a bleak iron mining colony that refined durasteel. Wraith Squadron raided the planet in the guise of Rogue Squadron during their campaign against Zsinj.
