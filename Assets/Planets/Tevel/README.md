# Tevel

**Continuity:** Canon  
**Source:** [Tevel](https://starwars.fandom.com/wiki/Tevel)
**Galaxy atlas:** system `Tevel`, Other, grid K-10 — map position (-717.8, -760.0, 22.4)

Tevel was a grassland planet in the Outer Rim Territories that was home to the Tevellan species. It was the location of a New Republic bacta production plant. The First Order annexed the planet, and the Tevellans requested assistance from the Resistance. Finn and Poe Dameron were sent to Tevel, and managed to liberate the bacta production plant from the First Order. The Resistance acquired a supply of bacta from Tevel, which was delivered elsewhere by Finn and Chewbacca.
