# Dinlo

**Continuity:** Legends  
**Source:** [Dinlo](https://starwars.fandom.com/wiki/Dinlo)
**Galaxy atlas:** system `Dinlo`, Expansion Region — map position (5326.0, -2511.9, -9.4)

Dinlo was a forest planet in the Dinlo system. It was the site of a rescue mission undertaken by Jedi Knight Etain Tur-Mukan to rescue a thousand clone troopers during the Clone Wars.
