# Galidraan

**Continuity:** Legends  
**Source:** [Galidraan/Legends](https://starwars.fandom.com/wiki/Galidraan/Legends)
**Galaxy atlas:** system `Galidraan`, Outer Rim, grid R-6 — map position (10239.0, 5386.6, 228.0)

Galidraan was a planet of snow-capped mountains and large pine forests, and was controlled by a planetary governor, who resided in an opulent castle in the midst of a forest.
