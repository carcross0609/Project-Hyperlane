# Dorin

**Continuity:** Legends  
**Source:** [Dorin/Legends](https://starwars.fandom.com/wiki/Dorin/Legends)
**Galaxy atlas:** system `Dorin`, Expansion Region, grid J-8 — map position (-2125.4, 2890.8, 162.5)

Dorin was a dark and dusty planet in the Expansion Region. It was the homeworld of the Kel Dors, with an atmosphere of a unique gas and helium.
