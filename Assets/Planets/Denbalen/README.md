# Denbalen

**Continuity:** Legends  
**Source:** [Denbalen](https://starwars.fandom.com/wiki/Denbalen)
**Galaxy atlas:** system `Denbalen`, Mid Rim — map position (-2721.8, 4129.3, 225.6)

Denbalen was the fourth planet in the Goroth system. It was a gas giant with a 147,100-kilometer diameter. Its seven moons included P'Chek, and the moons were orbited by the remains of an ancient fleet.
