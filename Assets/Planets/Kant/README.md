# Kant

**Continuity:** Legends  
**Source:** [Kant](https://starwars.fandom.com/wiki/Kant)

Kant was a planet located deep within Bothan space. Kant had two moons, which themselves had many asteroid companions. In 3643 BBY, Sith Lord Darth Chratis stationed his division near there.

## Planetary data

- **Name:** Kant
- **Region:** Mid Rim
- **Sector:** Bothan sector
- **System:** Kant system
