# Albecus

**Continuity:** Legends  
**Source:** [Albecus](https://starwars.fandom.com/wiki/Albecus)
**Galaxy atlas:** system `Albecus`, Core Worlds, grid L-9 — map position (723.1, 609.6, -14.8)

Albecus was a planet in the Galactic Core friendly to the Jedi Order during the last years of the Galactic Republic. It was situated close to the world Ralltiir. The planet saw the establishment of a Rebel Alliance safe-house after the Battle of Yavin. The criminal Kikow tried and failed to set up an underworld empire on Albecus during the Galactic Civil War.
