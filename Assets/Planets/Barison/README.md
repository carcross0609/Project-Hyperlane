# Barison

**Continuity:** Legends  
**Source:** [Barison](https://starwars.fandom.com/wiki/Barison)
**Galaxy atlas:** system `Barison`, Outer Rim, grid Q-6 — map position (8081.2, 5982.1, -420.7)

Barison was a water world along the Feena Run in the Gordian Reach. It supplied fish, seafood, and kelp to worlds in the Back Reach. Its inhabitants were known as the Barisoni. For religious reasons, many of the Barisoni had renounced technology.

At one time, Airen Cracken visited Barison. His droid Vee Gee was captured by Barisoni pirates until Cracken rescued the droid using a restraining bolt deactivator.
