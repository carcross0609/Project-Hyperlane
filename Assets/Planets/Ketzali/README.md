# Ketzali

**Continuity:** Canon  
**Source:** [Ketzali](https://starwars.fandom.com/wiki/Ketzali)

Ketzali was a planet located in the Ketzali system within the Lannik Wilds sector of the galaxy's Mid Rim and the Slice regions. It was situated in grid square R-13 on the Standard Galactic Grid. In 34 ABY, the historian Eloc Throno included a map with the location of Ketzali in the book Traveler's Guide to Batuu, a book authored by Throno that detailed the planet Batuu. The planet shared its name with the Ketzalian species, which originated from the same star system as the planet.
