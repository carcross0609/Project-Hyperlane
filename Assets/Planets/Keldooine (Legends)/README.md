# Keldooine

**Continuity:** Legends  
**Source:** [Keldooine/Legends](https://starwars.fandom.com/wiki/Keldooine/Legends)
**Galaxy atlas:** system `Keldooine`, Hutt Space, grid R-10 — map position (9853.8, -1260.7, -495.5)

Keldooine was a minor trade world that was located within the Keldooine system in Hutt Space, a region of the galaxy controlled by the Hutt species. The planet lay on the Ootmian Pabol hyperlane, which connected it to the planets of Kwenn and Nar Bo Sholla. During the rule of the Galactic Empire, Keldooine served as a customs stop for starships that left Hutt Space.
