# Kuan

**Continuity:** Legends  
**Source:** [Kuan](https://starwars.fandom.com/wiki/Kuan)
**Galaxy atlas:** system `Kuan`, Outer Rim — map position (11110.2, 9227.6, 51.8)

Kuan was a planet in the Outer Rim Territories. It had a war with neighboring Bordal in 20 BBY, in which the Galactic Empire had to intervene by sending an Imperial Navy fleet under Admiral Mordon. An ace TIE pilot, Maarek Stele, was from Kuan. The planet stayed in Imperial control throughout the Galactic Civil War.
