# Glottal

**Continuity:** Legends  
**Source:** [Glottal](https://starwars.fandom.com/wiki/Glottal)
**Galaxy atlas:** system `Glottal`, Outer Rim, grid U-11 — map position (13903.9, -2279.9, -421.9)

Glottal was a planet located within the Glottal system in the Baxel sector of the Outer Rim region of the galaxy. It was the Glottalphib homeworld. It was a hot and humid planet, making it a perfect habitat for the Glottalphibs.
