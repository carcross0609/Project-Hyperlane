# Calipp

**Continuity:** Legends  
**Source:** [Calipp](https://starwars.fandom.com/wiki/Calipp)
**Galaxy atlas:** system `Calipp`, Wild Space, grid T-4 — map position (12510.0, 8092.9, 535.7)

Calipp was a gas giant–type planet with twelve moons that was located in the Faarlsun system, a part of the Parthovian Cluster in Wild Space. The planet occupied the sixth and outermost orbit around its star, the yellow-white Faarlsun.
