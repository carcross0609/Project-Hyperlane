# Csaus

**Continuity:** Legends  
**Source:** [Csaus/Legends](https://starwars.fandom.com/wiki/Csaus/Legends)
**Galaxy atlas:** system `Csaus`, Unknown Regions, grid F-9 — map position (-8722.2, 1337.3, -382.3)

Csaus was a planet located in the Csaus system in the core territory of the Chiss Ascendancy in the Unknown Regions. It was home of the House Inrokini, one of the Chiss Ruling Families. Like other homeworlds of Ruling Families, Csaus was located on the Path of the Houses, a hyperlane that ran through the Ascendancy. The planet was the Ascendancy's hub of sciences and communications.
