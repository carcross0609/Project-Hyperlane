# Xal 3

**Continuity:** Legends  
**Source:** [Xal 3](https://starwars.fandom.com/wiki/Xal_3)
**Galaxy atlas:** system `Xal 3`, Outer Rim, grid H-16 — map position (-5231.5, -10369.2, -147.4)

Xal 3 was a planet located within the Xal system of the Ablajeck sector, not far from Endor. It served as the base for the Armorers' Confederacy.
