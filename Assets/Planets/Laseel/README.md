# Laseel

**Continuity:** Legends  
**Source:** [Laseel](https://starwars.fandom.com/wiki/Laseel)
**Galaxy atlas:** system `Laseel`, Outer Rim — map position (9838.4, 3571.5, -57.9)

Laseel was a hot jungle planet in the Dathomir system, located in the Quelii sector in the New Territories portion of the Outer Rim Territories. Laseel had two moons and occupied the third orbital position around the star Domir.
