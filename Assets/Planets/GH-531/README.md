# GH-531

**Continuity:** Canon  
**Source:** [GH-531](https://starwars.fandom.com/wiki/GH-531)

GH-531 was a planet in the GH-531 system in the Unknown Regions that was the site of a Galactic Empire communications station, which was later taken over by the First Order by the time of the outbreak of war between the First Order and the Resistance.
