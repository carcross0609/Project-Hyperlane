# Laramus

**Continuity:** Legends  
**Source:** [Laramus](https://starwars.fandom.com/wiki/Laramus)
**Galaxy atlas:** system `Laramus`, Outer Rim — map position (-256.3, 4976.3, -245.2)

Laramus was the location of Laramus Base, headquarters of the Laramus Base Irregulars, as well as a rapidly-growing Rebel cell. The Visseon II led a Rebel ambush of an Imperial convoy over Laramus. The Empire later destroyed much of the planet's surface, forcing the Irregulars to leave.
