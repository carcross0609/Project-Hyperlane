# Nilrebmah IX

**Continuity:** Unknown  
**Source:** [Nilrebmah IX](https://starwars.fandom.com/wiki/Nilrebmah_IX)

Nilrebmah IX was once a planet in the Nilrebmah system. After some cataclysm in the galaxy's ancient past, the planet was reduced to rubble, falling into its old orbit as an asteroid belt. Flocks of mynocks flitted about the belt.
