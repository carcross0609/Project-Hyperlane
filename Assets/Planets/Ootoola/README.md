# Ootoola

**Continuity:** Legends  
**Source:** [Ootoola](https://starwars.fandom.com/wiki/Ootoola)
**Galaxy atlas:** system `Ootoola`, Outer Rim — map position (-392.3, 5703.5, -165.8)

Ootoola was the vastly oceanic homeworld of the Ootoolan race. The world was located in the Morshdine sector of the Outer Rim Territories.
