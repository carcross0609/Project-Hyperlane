# Columex

**Continuity:** Legends  
**Source:** [Columex/Legends](https://starwars.fandom.com/wiki/Columex/Legends)
**Galaxy atlas:** system `Columex`, Outer Rim, grid R-6 — map position (10132.1, 4916.9, 37.5)

Columex, originally known as Nardolin, was a trade planet located in relative proximity to the Vorzyd Cluster of the Outer Rim Territories, on the Perlemian Trade Route.
