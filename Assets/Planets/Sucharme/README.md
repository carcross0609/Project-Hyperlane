# Sucharme

**Continuity:** Legends  
**Source:** [Sucharme](https://starwars.fandom.com/wiki/Sucharme)

Sucharme was a planet affiliated with the Trade Federation prior to the Invasion of Naboo. The Federation's primary garrison, Tallaga Garrison, was located in the city of Tallaga.
