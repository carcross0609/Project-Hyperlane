# Risha

**Continuity:** Legends  
**Source:** [Risha](https://starwars.fandom.com/wiki/Risha)
**Galaxy atlas:** system `Risha`, Outer Rim, grid S-15 — map position (11104.2, -7750.9, -183.4)

Risha was the first planet orbiting the star Rish in the Rishi system. Located in the Abrion sector of the Outer Rim Territories, it was a toxic hothouse. The planet did not support Human-like life, as its surface was covered with molten rivers and steaming lakes of chemicals.
