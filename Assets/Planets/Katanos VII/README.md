# Katanos VII

**Continuity:** Legends  
**Source:** [Katanos VII](https://starwars.fandom.com/wiki/Katanos_VII)
**Galaxy atlas:** system `Katanos VII`, Mid Rim, grid Q-15 — map position (8812.5, -8681.8, 119.9)

Katanos VII was a mining colony located in the Xan sector of the Mid Rim. After its cortosis mines became depleted, its plight was ignored by the Galactic Senate, so the colonists betrayed the Jedi to the Confederacy.
