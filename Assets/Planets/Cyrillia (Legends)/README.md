# Cyrillia

**Continuity:** Legends  
**Source:** [Cyrillia/Legends](https://starwars.fandom.com/wiki/Cyrillia/Legends)
**Galaxy atlas:** system `Cyrillia`, Expansion Region, grid O-12 — map position (5551.8, -4389.8, 15.6)

Cyrillia was the homeworld of the Cyrillians, in the Expansion Region of the galaxy. It was a very industrialized world where Serv-O-Droid, Inc. constructed its DUM pit droids in large quantities.
