# Contruum

**Continuity:** Legends  
**Source:** [Contruum/Legends](https://starwars.fandom.com/wiki/Contruum/Legends)
**Galaxy atlas:** system `Contruum`, Mid Rim, grid O-8 — map position (5959.1, 2088.3, 159.8)

Contruum was a planet in the Mid Rim, and was the most developed planet in the dense system of inhabited worlds that made up the Contruum system.
