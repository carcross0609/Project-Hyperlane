# Thabeska

**Continuity:** Canon  
**Source:** [Thabeska](https://starwars.fandom.com/wiki/Thabeska)
**Galaxy atlas:** system `Thabeska`, Outer Rim, grid K-10 — map position (-928.8, -434.5, 42.6)

Thabeska was a planet located in the Outer Rim Territories where the Fardi clan operated. It was windy and dusty, and newcomers to the planet could be identified by having clean, dust-free clothing. After surviving Order 66, former Jedi Padawan Ahsoka Tano spent the first year of the Imperial Era in hiding on Thabeska, working for the Fardis as a mechanic.
