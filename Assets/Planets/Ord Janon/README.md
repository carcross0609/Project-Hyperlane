# Ord Janon

**Continuity:** Legends  
**Source:** [Ord Janon](https://starwars.fandom.com/wiki/Ord_Janon)
**Galaxy atlas:** system `Ord Janon`, Outer Rim — map position (8454.4, 5777.5, -139.1)

Ord Janon was an Outer Rim Territories planet located within the Spinward sector. At some point, Ord Janon served as an Ordnance/Regional Depot for the Galactic Republic, and during the Clone Wars, it was occupied by military forces of the Confederacy of Independent Systems.
