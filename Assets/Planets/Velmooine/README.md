# Velmooine

**Continuity:** Legends  
**Source:** [Velmooine](https://starwars.fandom.com/wiki/Velmooine)
**Galaxy atlas:** system `Velmooine`, Mid Rim, grid P-7 — map position (6224.7, 4161.1, -83.5)

Velmooine was a desert planet with four moons that occupied the second orbital position around the star Velm. It was located in the Velm system, a part of the Halori sector in the Trans-Hydian portion of the Mid Rim.
