# Vintrus

**Continuity:** Legends  
**Source:** [Vintrus](https://starwars.fandom.com/wiki/Vintrus)
**Galaxy atlas:** system `Vintrus`, Mid Rim, grid R-15 — map position (9600.2, -8418.2, -187.0)

Vintrus was a planet located in the Manda Sector in the Mid Rim.

The Planet was known to host the Semi-summer festival. Ebenn Q3 Baobab claimed that he acquired his "Q3" alias by undergoing the ceremonial Passage Rite at this festival.
