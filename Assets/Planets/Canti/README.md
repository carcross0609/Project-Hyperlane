# Canti

**Continuity:** Legends  
**Source:** [Canti](https://starwars.fandom.com/wiki/Canti)
**Galaxy atlas:** system `Canti`, Colonies, grid L-13 — map position (1015.4, -5672.1, -198.6)

Canti was a planet located in the Tapani sector's Canti system. A secret hyperlane ran from Canti out of the sector. The existence of the route was closely guarded by House Reena.
