# Trancret

**Continuity:** Legends  
**Source:** [Trancret](https://starwars.fandom.com/wiki/Trancret)
**Galaxy atlas:** system `Trancret`, Mid Rim, grid Q-7 — map position (8059.7, 3944.7, 99.2)

Trancret was a planet in the Trancret system and the sector capital of the Perkell sector. It was home to the Trancretes. The Trancret Stock Exchange Swindle was pulled off by the Red & Black League of Herstell V.
