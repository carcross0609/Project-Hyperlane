# Iychtor

**Continuity:** Legends  
**Source:** [Iychtor](https://starwars.fandom.com/wiki/Iychtor)
**Galaxy atlas:** system `Iychtor`, Core Worlds, grid L-9 — map position (443.4, 1159.2, -13.4)

Iychtor was the fifth, outermost planet that orbited the sun Velus. It was located in the Velus system of the Northern Dependencies portion of the Core Worlds. The frozen rock planet had one moon. Iychtor, along with the rest of its system, was located along the Shawken Spur hyperlane, connecting it to the Shawken and Thokos systems. The Velusia system, and therefore Iychtor itself, was also connected by another hyperlane to the Scipio system.
