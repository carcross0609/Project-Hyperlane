# Parshoone

**Continuity:** Legends  
**Source:** [Parshoone](https://starwars.fandom.com/wiki/Parshoone)
**Galaxy atlas:** system `Parshoone`, Wild Space, grid J-4 — map position (-2701.1, 7963.7, -18.3)

Parshoone was a planet in the Outer Rim Territories, controlled by the Imperial Remnant. It was an Ubiqtorate contact station.

Parshoone was the homeworld of Isila Drutch.
