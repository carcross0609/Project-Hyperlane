# Phateem

**Continuity:** Canon  
**Source:** [Phateem](https://starwars.fandom.com/wiki/Phateem)
**Galaxy atlas:** system `Phateem`, Inner Rim, grid N-8 — map position (3153.0, 2768.1, -179.3)

Phateem was an uninhabited planet in the Phateem system in the Inner Rim Territories. It was located in the Nouane sector near Telerath, and was covered in bamboo forests and mountains. The Ashlendu Mountains on Phateem contained the Halls of Knowledge, a former Jedi artifact cache. A tournament was held at the Halls of Knowledge, though it was a front for an operation led by Imperial Security Bureau Colonel Sadao Emtri to catch Force-sensitive individuals.
