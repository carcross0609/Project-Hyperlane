# Palawa

**Continuity:** Legends  
**Source:** [Palawa](https://starwars.fandom.com/wiki/Palawa)
**Galaxy atlas:** system `Palawa`, Core Worlds, grid L-10 — map position (1388.2, -228.1, -3.3)

Palawa was a planet in the Core Worlds. It was the planet of origin of two mystic Force traditions, the Followers of Palawa and the Chatos Academy.
