# Troithe

**Continuity:** Canon  
**Source:** [Troithe](https://starwars.fandom.com/wiki/Troithe)

Troithe was a planet in the Cerberon system of the galaxy's Deep Core. As a ecumenopolis, it once rivaled the galactic capital of Coruscant as the jewel of the Old Republic, centuries before the Galactic Civil War.
