# Ithull

**Continuity:** Legends  
**Source:** [Ithull](https://starwars.fandom.com/wiki/Ithull)
**Galaxy atlas:** system `Ithull`, Inner Rim, grid O-10 — map position (5642.5, -365.9, -24.6)

Ithull was the gigantic homeworld of the Ithullans and the colossus wasps. The Ithullans were almost wiped out by the Mandalorians in the year 200 BBY.

Ithull had a 25-month year.
