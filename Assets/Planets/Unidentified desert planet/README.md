# Unidentified desert planet

**Continuity:** Canon  
**Source:** [Unidentified desert planet](https://starwars.fandom.com/wiki/Unidentified_desert_planet)

A desert planet was located in the Fjor system in the Grohl sector of the Outer Rim Territories. In 34 ABY, it was the site of a battle between the Resistance, the Ranc Gang, and the First Order.
