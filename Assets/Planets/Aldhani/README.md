# Aldhani

**Continuity:** Canon  
**Source:** [Aldhani](https://starwars.fandom.com/wiki/Aldhani)

Aldhani was a planet located in the Cademimu sector in the Outer Rim Territories of the galaxy. During the Imperial Era, Cassian Andor joined the Aldhani rebel infiltration team for a mission to rob the Imperial base there.
