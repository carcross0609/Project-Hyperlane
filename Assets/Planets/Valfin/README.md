# Valfin

**Continuity:** Canon  
**Source:** [Valfin](https://starwars.fandom.com/wiki/Valfin)

Valfin was an astronomical object in the Valfin system in the Meram sector of the Outer Rim Territories. During the New Republic Era, it hosted a penitentiary outpost by the New Republic Correctional Corps and N5 sentry droids were deployed as prison guards there.
