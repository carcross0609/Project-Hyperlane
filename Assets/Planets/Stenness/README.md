# Stenness

**Continuity:** Canon  
**Source:** [Stenness](https://starwars.fandom.com/wiki/Stenness)

Stenness was a terrestrial planet in the Airon sector of the Inner Rim Territories. A crime lord operated a massive gambling den on Stenness. The smugglers Han Solo and Sana Starros illegitimately got married on Stenness while robbing the crime lord's gambling den.
