# Dorella

**Continuity:** Legends  
**Source:** [Dorella](https://starwars.fandom.com/wiki/Dorella)
**Galaxy atlas:** system `Dorella`, Colonies — map position (-637.5, 1243.8, -3.3)

Dorella was a planet in the Dorella system in the Tapani sector. It was one of the Freeworlds Territory and one of the Three Ellas. It had a liberal government that was looser about crime and smuggling than most Tapani worlds.
