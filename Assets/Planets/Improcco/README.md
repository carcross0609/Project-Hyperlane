# Improcco

**Continuity:** Legends  
**Source:** [Improcco](https://starwars.fandom.com/wiki/Improcco)
**Galaxy atlas:** system `Improcco`, Core Worlds, grid L-9 — map position (1163.7, 1253.5, 133.7)

Improcco was an icy planet in the Coruscant system. It was the ninth planet from the star Coruscant Prime. Improcco had one moon, known as the Frozen Moon of Improcco.
