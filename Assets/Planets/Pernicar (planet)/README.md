# Pernicar

**Continuity:** Legends  
**Source:** [Pernicar (planet)](https://starwars.fandom.com/wiki/Pernicar_%28planet%29)
**Galaxy atlas:** system `Pernicar`, Mid Rim, grid P-11 — map position (7022.1, -2665.8, 103.2)

Pernicar was the first planet orbiting the star Hoth's Brand in the Ruusan system. Located in the Teraab sector of the Mid Rim, it was a scorching rock.

It was named after the Jedi Master Pernicar.
