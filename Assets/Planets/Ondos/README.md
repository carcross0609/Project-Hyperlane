# Ondos

**Continuity:** Legends  
**Source:** [Ondos](https://starwars.fandom.com/wiki/Ondos)

Ondos was a planet lost long ago. It was located in the Core Worlds. Along with Had Abbadon, it was one of a handful of candidates believed to be the planet of origin for either the Jedi Order or their Force-using predecessors.
