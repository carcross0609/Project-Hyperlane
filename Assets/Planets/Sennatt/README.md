# Sennatt

**Continuity:** Legends  
**Source:** [Sennatt](https://starwars.fandom.com/wiki/Sennatt)
**Galaxy atlas:** system `Sennatt`, Mid Rim, grid R-14 — map position (9275.4, -6619.0, 387.2)

Sennatt was a world located within the Bothan sector, on the Mid Rim of the galaxy. Colonized by the Bothans, it was one of their industrial hubs. Publictechnic's main manufacturing plant was located on Sennatt.
