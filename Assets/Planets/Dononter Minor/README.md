# Dononter Minor

**Continuity:** Legends  
**Source:** [Dononter Minor](https://starwars.fandom.com/wiki/Dononter_Minor)

Dononter Minor was a world located in the Dononter Minor system, a part of the Mid Rim's Dononter sector. Dononter Minor had a Type I breathable atmosphere, and it was the homeworld of the plant known as the widowmaker, which could be used as a weapon.

## Planetary data

- **Name:** Dononter Minor
- **Region:** Mid Rim
- **Sector:** Dononter sector
- **System:** Dononter Minor system
- **Coordinates:** I-16
- **Atmosphere:** Type I (breathable)
- **Flora:** Widowmaker
