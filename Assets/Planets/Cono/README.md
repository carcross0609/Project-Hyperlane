# Cono

**Continuity:** Legends  
**Source:** [Cono](https://starwars.fandom.com/wiki/Cono)

Cono was the innermost planet of the Bestine system located in the Inner Rim Territories. Cono had no moons, and its surface was covered with scorched rocks.
