# Orto Plutonia

**Continuity:** Legends  
**Source:** [Orto Plutonia/Legends](https://starwars.fandom.com/wiki/Orto_Plutonia/Legends)
**Galaxy atlas:** system `Orto Plutonia`, Outer Rim, grid P-19 — map position (6473.7, -14529.9, 357.1)

Orto Plutonia was a desolate icy planet in the Pantora system, home to the native Talz and a number of narglatches. It was considered a protectorate of the orbiting moon Pantora until the Clone Wars, when the Talz inhabitants were granted political supremacy by the Pantoran Assembly following a brief conflict with Galactic Republic forces.
