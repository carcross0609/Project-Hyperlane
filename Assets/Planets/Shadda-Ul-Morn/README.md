# Shadda-Ul-Morn

**Continuity:** Legends  
**Source:** [Shadda-Ul-Morn](https://starwars.fandom.com/wiki/Shadda-Ul-Morn)

Shadda-Ul-Morn was the fifth planet orbiting the star Shadda in the Shadda-Bi-Boran system. Located in the Toblain sector of the Outer Rim Territories, it was a gas giant.
