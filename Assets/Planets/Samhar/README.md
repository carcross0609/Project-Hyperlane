# Samhar

**Continuity:** Legends  
**Source:** [Samhar](https://starwars.fandom.com/wiki/Samhar)

Samhar was a forest-covered world that was located in the Grumani sector, in the Outer Rim Territories. It was inhabited by the Samhari, a Near-Human species.
