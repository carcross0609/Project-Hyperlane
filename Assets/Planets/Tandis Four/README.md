# Tandis Four

**Continuity:** Legends  
**Source:** [Tandis Four](https://starwars.fandom.com/wiki/Tandis_Four)
**Galaxy atlas:** system `Tandis Four`, Inner Rim, grid N-8 — map position (4188.9, 2041.9, -106.8)

Tandis Four was a planet in the Galactic Republic. It was the location of the Museum of Light, which on Count Dooku's orders was destroyed by the Separatists during the Clone Wars, prior to the conclusion of the struggle for control of Drongar. This attack hurt Loyalist morale in the region, and Tannon Praji considered it the greatest tragedy of the Clone Wars, and a heathen act on behalf of Dooku.
