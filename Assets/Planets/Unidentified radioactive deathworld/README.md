# Unidentified radioactive deathworld

**Continuity:** Canon  
**Source:** [Unidentified radioactive deathworld](https://starwars.fandom.com/wiki/Unidentified_radioactive_deathworld)

A radioactive deathworld was located in the Ghonoath system, within the Inner Rim Territories' Croynar sector. The planet's atmosphere was highly radioactive and had fierce winds.
