# M2398

**Continuity:** Legends  
**Source:** [M2398](https://starwars.fandom.com/wiki/M2398)

M2398 was a gas giant, in the M2398 system, near warlord Zsinj's territory. It was orbited by the Blood Nest moon which was controlled by pirates. Furthermore, it was the place where Wraith Squadron suffered its first loss, Jesmin Ackbar.
