# Boonta

**Continuity:** Legends  
**Source:** [Boonta/Legends](https://starwars.fandom.com/wiki/Boonta/Legends)
**Galaxy atlas:** system `Boonta`, Outer Rim, grid S-8 — map position (11184.9, 2240.1, -52.0)

Boonta, formerly known as Ko Vari, was a planet in the Outer Rim Territories that had been colonized by the Hutts long ago. Despite it being a devastated world, Boonta was famous in the galaxy for its podracing and speeder races.
