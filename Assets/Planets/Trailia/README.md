# Trailia

**Continuity:** Legends  
**Source:** [Trailia](https://starwars.fandom.com/wiki/Trailia)
**Galaxy atlas:** system `Trailia`, Outer Rim, grid U-7 — map position (13972.0, 3652.1, 103.7)

Trailia was a low-tech planet, located in the Trailia system of the Outer Rim Territories, on the fringes of known space. It was the homeworld of the Trailians. It was a technologically primitive world with thick jungles.
