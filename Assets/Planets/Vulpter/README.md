# Vulpter

**Continuity:** Canon  
**Source:** [Vulpter](https://starwars.fandom.com/wiki/Vulpter)
**Galaxy atlas:** system `Vulpter`, Deep Core, grid L-10 — map position (876.1, -735.7, -96.6)

Vulpter was a planet located in the galaxy's Deep Core that was the homeworld of the Vulptereen podracer Dud Bolt. The KX-series security droid K-2SO was constructed on Vulpter, as were many of the Galactic Empire's probe droids.
