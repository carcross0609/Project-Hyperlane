# Loken III

**Continuity:** Legends  
**Source:** [Loken III](https://starwars.fandom.com/wiki/Loken_III)

The planet of Loken III was the headquarters of TransTech Droidworks. It was the location of Power Station TD-332, which Separatist Geonosians failed to protect from a Republic assault during the Clone Wars.
