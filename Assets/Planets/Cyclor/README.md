# Cyclor

**Continuity:** Canon  
**Source:** [Cyclor](https://starwars.fandom.com/wiki/Cyclor)

Cyclor was a planet located in the Cyclor system in the Alui sector of the Mid Rim that was home to the insectoid Cyclorrian species. A relatively small planet, Cyclor appeared green and brown from space and was orbited by vast shipyards.
