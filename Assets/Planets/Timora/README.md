# Timora

**Continuity:** Legends  
**Source:** [Timora](https://starwars.fandom.com/wiki/Timora)
**Galaxy atlas:** system `Timora`, Outer Rim, grid G-16 — map position (-6059.7, -10299.4, -178.9)

Timora was a planet located in the Timora system of the Outer Rim Territories. Timora was the inner endpoint of the Shiritoku Way and the closest planet to Bakura in Wild Space. Its people exported sunpetals. It also served as a shipping point for repulsorlift products from Bakura.
