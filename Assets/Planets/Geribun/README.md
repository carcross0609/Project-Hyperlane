# Geribun

**Continuity:** Legends  
**Source:** [Geribun](https://starwars.fandom.com/wiki/Geribun)

Geribun was the ninth planet orbiting the star Rek in the Guter Wade system. Located in the Trilon sector of the Outer Rim, it was a gas giant.
