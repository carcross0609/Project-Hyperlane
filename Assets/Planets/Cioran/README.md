# Cioran

**Continuity:** Legends  
**Source:** [Cioran](https://starwars.fandom.com/wiki/Cioran)

Cioran was a planet located in the Saavin system, a part of the Southern Core portion of the Core Worlds. During the Galactic Civil War, the Imperial-class Star Destroyer Ravenous monitored the traffic around Cioran.
