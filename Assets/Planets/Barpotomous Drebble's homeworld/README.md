# Barpotomous Drebble's homeworld

**Continuity:** Legends  
**Source:** [Barpotomous Drebble's homeworld](https://starwars.fandom.com/wiki/Barpotomous_Drebble%27s_homeworld)

The homeworld of Barpotomous Drebble was a planet located somewhere near Keyorin and Stenos. Drebble claimed that Lando Calrissian had first cheated him there, which had ignited their long feud.
