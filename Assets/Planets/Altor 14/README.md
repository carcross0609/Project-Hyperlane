# Altor 14

**Continuity:** Legends  
**Source:** [Altor 14](https://starwars.fandom.com/wiki/Altor_14)
**Galaxy atlas:** system `Altor 14`, Outer Rim, grid U-13 — map position (13866.1, -5598.4, 87.5)

Altor 14 was a planet in the Zoraster sector, and the homeworld of the Avogwi and Nuiwit. It was subjugated by the Galactic Empire.
