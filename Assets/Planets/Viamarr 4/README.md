# Viamarr 4

**Continuity:** Legends  
**Source:** [Viamarr 4](https://starwars.fandom.com/wiki/Viamarr_4)
**Galaxy atlas:** system `Viamarr 4`, Inner Rim, grid N-7 — map position (3380.5, 3813.7, -90.5)

Viamarr 4 was a planet located within the Viamarr system of the Inner Rim. Its capital city was Velery. Viamarr Blackroot fungus was grown in the planet's subterranean caves.
