# Chiron

**Continuity:** Legends  
**Source:** [Chiron (planet)](https://starwars.fandom.com/wiki/Chiron_%28planet%29)
**Galaxy atlas:** system `Chiron`, Outer Rim, grid T-7 — map position (13416.1, 3942.2, -43.4)

Chiron was a planet located in the Chiron system, in the large sector known as the Ash Worlds. It was the homeworld of a sentient species, the Chironians.

One Chironian, Lusa, joined Luke Skywalker's New Jedi Order and became a Jedi Knight. Shortly before the Yuuzhan Vong conquest of Coruscant, Lusa was killed on Chiron by a voxyn.
