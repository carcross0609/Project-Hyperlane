# Hakara

**Continuity:** Legends  
**Source:** [Hakara/Legends](https://starwars.fandom.com/wiki/Hakara/Legends)

Hakara was a swamp planet native to the insectoid Hakaranss. Hakara was previously believed to be uninhabited by the Galactic Republic.
