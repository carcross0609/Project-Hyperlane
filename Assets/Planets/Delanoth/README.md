# Delanoth

**Continuity:** Legends  
**Source:** [Delanoth](https://starwars.fandom.com/wiki/Delanoth)
**Galaxy atlas:** system `Delanoth`, Deep Core — map position (443.5, -3836.3, -172.5)

Delanoth was a tiny gas giant in the Prakith system of the Deep Core's Sector 5. The planet occupied the fourth orbital position around the star Prak and had eight moons.
