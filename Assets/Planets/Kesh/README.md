# Kesh

**Continuity:** Canon  
**Source:** [Kesh](https://starwars.fandom.com/wiki/Kesh)
**Galaxy atlas:** system `Kesh`, Wild Space, grid U-10 — map position (14564.9, -499.3, 617.0)

Kesh was a planet located in the Kesh system in Wild Space, in grid square U-10 of the Standard Galactic Grid, past the eastern edge of the Outer Rim Territories. It was the homeworld of the Keshiri species, and the planet never joined the Galactic Republic.
