# G'wenee

**Continuity:** Legends  
**Source:** [G'wenee/Legends](https://starwars.fandom.com/wiki/G%27wenee/Legends)
**Galaxy atlas:** system `G'wenee`, Outer Rim, grid N-6 — map position (3745.3, 4967.2, 8.1)

G'wenee was an Imperial tradeworld whose operations were overseen by Tarrant Snil, who proved to be an adversary to Grappa the Hutt. Snil was captured by bounty hunter Kenix Kil.
