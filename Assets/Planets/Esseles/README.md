# Esseles

**Continuity:** Canon  
**Source:** [Esseles](https://starwars.fandom.com/wiki/Esseles)
**Galaxy atlas:** system `Esseles`, Core Worlds, grid L-9 — map position (974.8, 574.7, 37.9)

Esseles was a planet located in the Esseles system in the Darpa sector of the Core Worlds that had been contested territory throughout the Galactic Civil War and had a secret Imperial listening post concealed in its icy rings. The Carrack-class light cruiser was designed and manufactured on Esseles by the Damorian Manufacturing Corporation.
