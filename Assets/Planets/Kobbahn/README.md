# Kobbahn

**Continuity:** Legends  
**Source:** [Kobbahn](https://starwars.fandom.com/wiki/Kobbahn)
**Galaxy atlas:** system `Kobbahn`, Outer Rim — map position (5258.0, -13038.4, 566.3)

Kobbahn was an Outer Rim planet near the border of the Unknown Regions. It was the location of one of the earliest Rebel cells in the days following the declaration of the New Order.
