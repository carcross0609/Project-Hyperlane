# Koss

**Continuity:** Legends  
**Source:** [Koss](https://starwars.fandom.com/wiki/Koss)
**Galaxy atlas:** system `Koss`, Wild Space — map position (5684.2, -15591.0, 150.2)

Koss was a gas giant–type planet with eight moons that was located in the Faarlsun system, a part of the Parthovian Cluster in Wild Space. The planet occupied the fifth orbit around its star, the yellow-white Faarlsun.
