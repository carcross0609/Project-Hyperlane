# Jereth VI

**Continuity:** Canon  
**Source:** [Jereth VI](https://starwars.fandom.com/wiki/Jereth_VI)

Jereth VI was a forest planet that was home to the Jerethian clamberwolf. It was located in the Jereth system in the Bozhnee sector of the Outer Rim Territories.
