# Oba Diah

**Continuity:** Legends  
**Source:** [Oba Diah/Legends](https://starwars.fandom.com/wiki/Oba_Diah/Legends)
**Galaxy atlas:** system `Oba Diah`, Outer Rim, grid T-10 — map position (13272.4, -216.6, 463.6)

Oba Diah was a planet located close to Kessel, in the Kessel sector of the galaxy's Outer Rim Territories. The homeworld of the Pyke species, it was the base of operations the Pyke Syndicate, a criminal organization of spice dealers.
