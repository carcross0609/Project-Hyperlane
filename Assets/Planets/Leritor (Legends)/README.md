# Leritor

**Continuity:** Legends  
**Source:** [Leritor/Legends](https://starwars.fandom.com/wiki/Leritor/Legends)
**Galaxy atlas:** system `Leritor`, Mid Rim, grid Q-15 — map position (8673.7, -8009.2, -244.5)

Leritor was a mineral-rich Mid Rim planet of rolling plains and oceans. The native Sauvax engaged in aquaculture; Human colonists mined the minerals. Amid a brewing war between the colonists and the Sauvax, Profex Rynalla attempted to excavate a Sith artifact buried within the planet's mountainous Bleaks.
