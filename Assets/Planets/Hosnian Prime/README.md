# Hosnian Prime

**Continuity:** Canon  
**Source:** [Hosnian Prime](https://starwars.fandom.com/wiki/Hosnian_Prime)
**Galaxy atlas:** system `Hosnian Prime`, Core Worlds, grid M-12 — map position (2246.5, -4160.2, -226.0)

Hosnian Prime was a planet in the Hosnian system of the Core Worlds, located along the Corellian Trade Spine. By 28 ABY, it served as the capital of the New Republic and the headquarters of the New Republic Senate.

In 34 ABY during the Cold War with the First Order, that sought to rid the galaxy of the New Republic which it saw as illegitimate, the First Order used its superweapon, Starkiller Base, to destroy Hosnian Prime and all other planetary bodies in the system. The superweapon caused the ignition of Hosnian Prime's core, transforming the planet into a star in a pocket nova.
