# Circumtore

**Continuity:** Canon  
**Source:** [Circumtore](https://starwars.fandom.com/wiki/Circumtore)
**Galaxy atlas:** system `Circumtore`, Hutt Space, grid S-12 — map position (10630.5, -3666.8, -179.7)

Circumtore was a ring-shaped planet located in the Hutt Space region of the galaxy. It was connected to the Hutt Space worlds Rorak, Nar Kaaga and Hollastin by hyperspace routes as well as Daalang outside of the region. Circumtore was located at galactic coordinates S-12. Despite the planet's unusual shape, the chef Strono Tuggs was unsure if Circumtore was formed naturally or constructed artificially.
