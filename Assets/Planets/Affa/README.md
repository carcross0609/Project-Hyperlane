# Affa

**Continuity:** Canon  
**Source:** [Affa](https://starwars.fandom.com/wiki/Affa)
**Galaxy atlas:** system `Affa`, Inner Rim, grid M-13 — map position (2295.9, -5879.1, 183.3)

Affa was a terrestrial planet that housed great droid factories. Located in the Affa system in the Inner Rim Territories, it was situated in grid square M-13 and was located along the Shipwrights' Trace hyperspace route.

Arakyd Industries's RA-7 protocol droids, including DK-RA-43, were manufactured in the factories, while parts for Cybot Galactica's 3PO-series protocol droid were also manufactured on the planet.
