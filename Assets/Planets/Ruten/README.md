# Ruten

**Continuity:** Legends  
**Source:** [Ruten](https://starwars.fandom.com/wiki/Ruten)
**Galaxy atlas:** system `Ruten`, Expansion Region, grid N-15 — map position (4406.8, -8699.8, -356.7)

Ruten was a planet in the Cerenia system of the Expansion Region. The New Republic liberated the planet from Imperial Governor Bursthed. The planet hosted the Ruten Pet Show.
