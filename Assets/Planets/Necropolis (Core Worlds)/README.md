# Necropolis; Dahrtag

**Continuity:** Legends  
**Source:** [Necropolis (Core Worlds)](https://starwars.fandom.com/wiki/Necropolis_%28Core_Worlds%29)
**Galaxy atlas:** system `Necropolis`, Core Worlds, grid J-13 — map position (-1584.2, -4721.9, 51.5)

Necropolis, originally named Dahrtag, was a planet in the Core Worlds of the galaxy. Located on the Giju Run, it was a tombworld of that served as a mass burial place for beings from all over the Galactic Core. It was also the home of boneworms and cryptberries.
