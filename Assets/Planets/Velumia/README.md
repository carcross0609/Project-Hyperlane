# Velumia

**Continuity:** Legends  
**Source:** [Velumia](https://starwars.fandom.com/wiki/Velumia)
**Galaxy atlas:** system `Velumia`, Core Worlds, grid L-9 — map position (1250.9, 704.4, 44.2)

Velumia was the third planet that orbited Velus, the Velus system's sun. The planet, like the rest of its system, was located in the Northern Dependencies portion of the Core Worlds. Velumia was a gas giant with seven moons. The planet, along with the rest of its system, was located along the Shawken Spur hyperlane, connecting it to the Shawken and Thokos systems. The Velusia system, and therefore Velumia itself, was additionally connected by another hyperlane to the Scipio system.
