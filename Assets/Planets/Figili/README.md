# Figili

**Continuity:** Legends  
**Source:** [Figili](https://starwars.fandom.com/wiki/Figili)

Figili was the first planet orbiting the star Shadda in the Shadda-Bi-Boran system. Located in the Toblain sector of the Outer Rim Territories, it was a desert world.
