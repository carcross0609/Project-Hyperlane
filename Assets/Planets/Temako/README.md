# Temako

**Source:** [Temako](https://starwars.fandom.com/wiki/Temako)
**Galaxy atlas:** system `Temako`, Outer Rim — map position (1642.5, 7121.6, 263.2)

Temako was a planet in the Temako system in the Antemeridian sector of the Outer Rim Territories. The planet was the location of Voltec's manufacturing headquarters during the Galactic Civil War.
