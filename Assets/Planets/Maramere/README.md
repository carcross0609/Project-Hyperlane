# Maramere

**Continuity:** Legends  
**Source:** [Maramere](https://starwars.fandom.com/wiki/Maramere)
**Galaxy atlas:** system `Maramere`, Outer Rim — map position (4969.3, -11898.5, 142.7)

Maramere was a planet located in the Outer Rim Territories. It was the homeworld of the sentient Mere species. The planet fell under the domination of Lord Toat of the Trade Federation, which used it as a repository of stygium crystals from Aeten II.
