# Zoma V

**Continuity:** Legends  
**Source:** [Zoma V](https://starwars.fandom.com/wiki/Zoma_V)
**Galaxy atlas:** system `Zoma V`, Outer Rim, grid S-17 — map position (10748.2, -10874.9, -133.9)

Zoma V was a jungle planet in the Zoma system, probably near Tatooine. It was inhabited by the primitive Felinians, to whom Imperial weapons were smuggled by Sithless Leethe.
