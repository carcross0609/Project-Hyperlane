# Tinnel IV

**Continuity:** Canon  
**Source:** [Tinnel IV](https://starwars.fandom.com/wiki/Tinnel_IV)
**Galaxy atlas:** system `Tinnel IV`, Core Worlds, grid M-12 — map position (2557.6, -3201.7, -4.4)

Tinnel IV, also known as Tinnel, was an ancient, conservative planet located in the Tinnel system in the Quanta sector of Core Worlds, along the Corellian Run. Tinnel IV was the homeworld of Jothan Tiaan Jerjerrod, Jax Jerjerrod, and Tiaan Jerjerrod. During the Imperial Era, Tinnel IV supported the Galactic Emperor Sheev Palpatine. After the signing of the Galactic Concordance, which conditionally allowed the remnants of the Empire to peacefully co-exist with the New Republic, Tinnel IV came under control of the Inner systems' Imperial remnant.
