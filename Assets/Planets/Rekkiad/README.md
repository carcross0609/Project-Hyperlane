# Rekkiad

**Continuity:** Legends  
**Source:** [Rekkiad](https://starwars.fandom.com/wiki/Rekkiad)
**Galaxy atlas:** system `Rekkiad`, Outer Rim, grid S-4 — map position (11058.4, 8114.5, -72.1)

Rekkiad was a planet in the remote Rekkiad system, located in the Outer Rim region of the galaxy. A desolate world covered in ice and snow, it was where the Jedi Knights Revan and Malak hid Mandalore's Mask following the Mandalorian Wars.
