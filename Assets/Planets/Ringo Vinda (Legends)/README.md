# Ringo Vinda

**Continuity:** Legends  
**Source:** [Ringo Vinda/Legends](https://starwars.fandom.com/wiki/Ringo_Vinda/Legends)
**Galaxy atlas:** system `Ringo Vinda`, Mid Rim, grid R-7 — map position (9135.3, 3228.4, 309.0)

Ringo Vinda was a planet found in the Ringo Vinda system, within the Eucer sector of the galaxy's Mid Rim. An important industrial production center, it was encircled by a massive space station that served as a distribution point for all incoming and outgoing resources.
