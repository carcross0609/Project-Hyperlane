# Althir III

**Continuity:** Legends  
**Source:** [Althir III](https://starwars.fandom.com/wiki/Althir_III)
**Galaxy atlas:** system `Althir III`, Outer Rim, grid P-6 — map position (7421.3, 4612.1, 192.8)

Althir III, or Althir, was a remote, independent planet in the Althir system that was located outside of the borders of the Galactic Republic. It had a system of rocky planetary rings.
