# Skaradosh

**Continuity:** Canon  
**Source:** [Skaradosh](https://starwars.fandom.com/wiki/Skaradosh)

Skaradosh was a desert planet located in the Skaradosh system in the Inner Rim Territories. During the Galactic Civil War, between the Galactic Empire and the Alliance to Restore the Republic, Skaradosh served as neutral-ground for a prisoner transfer during Princess Leia Organa's rescue mission.
