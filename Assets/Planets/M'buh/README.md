# M'buh

**Continuity:** Legends  
**Source:** [M'buh](https://starwars.fandom.com/wiki/M%27buh)
**Galaxy atlas:** system `M'buh`, Deep Core — map position (547.7, -1088.0, -25.4)

M'buh was the sixth planet orbiting the star C'rel in the N'zoth system. Located in the Koornacht Cluster of the Core Worlds, it was a barren rock.
