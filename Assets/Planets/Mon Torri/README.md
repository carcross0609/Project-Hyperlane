# Mon Torri

**Continuity:** Legends  
**Source:** [Mon Torri](https://starwars.fandom.com/wiki/Mon_Torri)
**Galaxy atlas:** system `Mon Torri`, Mid Rim — map position (-932.7, -9982.4, -391.9)

Mon Torri was a snowy, mountainous and glacier-covered world that was located within the Mid Rim of the galaxy. Situated between Ord Mantell and Tatooine, it was surrounded by seven rings, each of them a different color and composition.

In 0 ABY, the Eradicator was in the process of impounding a starship near Mon Torri when the Millennium Falcon came out of hyperspace.
