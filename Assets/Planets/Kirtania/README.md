# Kirtania

**Continuity:** Legends  
**Source:** [Kirtania](https://starwars.fandom.com/wiki/Kirtania)
**Galaxy atlas:** system `Kirtania`, Outer Rim, grid P-4 — map position (6644.6, 7793.4, 101.6)

Kirtania was the homeworld of the spider-like, pacifist Araquia people. The Kubaz crime lord Schnil Hakoon settled on the planet and centered his operations in Kinkosa City.
