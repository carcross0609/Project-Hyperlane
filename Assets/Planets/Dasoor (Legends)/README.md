# Dasoor

**Continuity:** Legends  
**Source:** [Dasoor/Legends](https://starwars.fandom.com/wiki/Dasoor/Legends)
**Galaxy atlas:** system `Dasoor`, Mid Rim, grid K-18 — map position (-89.3, -12211.6, 137.9)

Dasoor was a world located in the Dasoor system of the Agarix sector, a part of the Western Reaches portion of the Mid Rim. A hyperlane known as the Agarix Trade Route connected it to the Umthyg system of the nearby Juvex sector.

Dasoor was a popular location for various circuits of the Podracing sport, including the Dasoor Challenge, one of the best-known such events in the Mid Rim. One instance of that race was scheduled, weather permitting, for the date 13:5:16. By 43 ABY, Dasoor's fame had given way to it becoming largely lawless and ruled by criminal gangs that were financed by parties in the Juvex sector.
