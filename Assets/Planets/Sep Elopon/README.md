# Sep Elopon

**Continuity:** Legends  
**Source:** [Sep Elopon](https://starwars.fandom.com/wiki/Sep_Elopon)

Sep Elopon held the sixth orbital position in the Calamari system. It was a gas giant with a beautiful system of rings and was also orbited by 32 moons. It was used as a Galactic Alliance staging area during the Defense of Mon Calamari.
