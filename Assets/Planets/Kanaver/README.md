# Kanaver

**Continuity:** Legends  
**Source:** [Kanaver](https://starwars.fandom.com/wiki/Kanaver)
**Galaxy atlas:** system `Kanaver`, Outer Rim, grid S-5 — map position (10860.1, 6090.6, -450.0)

Kanaver was an Outer Rim Territories world located in the Tion Cluster's Tion Hegemony sector. By around 25,130 BBY, it was one of the leading worlds of the Livien League confederation, which later became a part of the empire of the Tionese conqueror Xim. Millennia later, Kanaver emerged from a long period of isolation and economic stagnation to become an active regional port.
