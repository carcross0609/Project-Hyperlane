# Haverling

**Continuity:** Legends

**Galaxy atlas:** system `Haverling`, Outer Rim, grid K-5 — map position (-484.5, 7172.3, -26.3)

Haverling was a planet in the Albarrio sector of the Outer Rim Territories, near the world of Morishim. It joined the New Republic, aiding the government by providing new shipyards to support the New Republic Navy.
