# Zoraster

**Continuity:** Legends  
**Source:** [Zoraster](https://starwars.fandom.com/wiki/Zoraster)
**Galaxy atlas:** system `Zoraster`, Outer Rim, grid U-13 — map position (13756.0, -5430.3, -66.4)

Zoraster was a planet located within the Zoraster system. It was situated in the Zoraster sector, a part of the Slice portion of the Outer Rim Territories. It was the homeworld of the Human Condi. At some point by 28 BBY, the slaver Krayn captured Condi, taking him off-world and forcing him to work aboard his starship among other slaves.
