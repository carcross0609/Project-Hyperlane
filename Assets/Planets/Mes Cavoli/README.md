# Mes Cavoli

**Continuity:** Legends  
**Source:** [Mes Cavoli](https://starwars.fandom.com/wiki/Mes_Cavoli)

Mes Cavoli was a planet in the Mid Rim.

Training Sergeant Kal Skirata once spent some time there with the Mandalorians fifty years before the first battle of Geonosis.
