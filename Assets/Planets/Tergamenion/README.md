# Tergamenion

**Continuity:** Legends  
**Source:** [Tergamenion](https://starwars.fandom.com/wiki/Tergamenion)

Tergamenion was a planet located in the Grumani sector of the Outer Rim Territories. A darkworld, it served as a base for the Daimanite military industrial complex during the Republic’s Dark Age.
