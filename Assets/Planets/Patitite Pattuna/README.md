# Patitite Pattuna

**Continuity:** Canon  
**Source:** [Patitite Pattuna](https://starwars.fandom.com/wiki/Patitite_Pattuna)
**Galaxy atlas:** system `Patitite Pattuna`, Mid Rim, grid L-7 — map position (358.1, 3370.0, 51.8)

Patitite Pattuna was a planet in the Patitite Pattuna system in the Bright Jewel sector of Mid Rim, not far from Balnab, that was the homeworld of the tiny Patitite species.
