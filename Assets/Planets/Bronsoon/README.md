# Bronsoon

**Continuity:** Legends  
**Source:** [Bronsoon](https://starwars.fandom.com/wiki/Bronsoon)
**Galaxy atlas:** system `Bronsoon`, Outer Rim, grid P-6 — map position (7458.9, 5475.4, -8.8)

Bronsoon was a trading port on the original Gordian Reach founded by Human colonists from the Core in ancient times. Bronsoonians had strict rules about gender relations, with laws governing everything from marriage between casts to making eye contact and who could walk where. Inevitably, Bronsoonian drama was all about forbidden love between different casts. A slow, little-used route connected Bronsoon with the Maridun system.
