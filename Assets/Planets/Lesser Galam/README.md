# Lesser Galam

**Continuity:** Legends  
**Source:** [Lesser Galam](https://starwars.fandom.com/wiki/Lesser_Galam)
**Galaxy atlas:** system `Lesser Galam`, Outer Rim — map position (12379.1, -121.5, 100.0)

Lesser Galam was a moonless planet, the first from the star Lan of the Lan system. By the time of the Galactic Empire, underground mining colonies had been constructed on the planet. The export of ore from mines on Lesser Galam and the other inner planets was the system's only real source of income during that time.
