# Pesfavri

**Continuity:** Canon  
**Source:** [Pesfavri](https://starwars.fandom.com/wiki/Pesfavri)
**Galaxy atlas:** system `Pesfavri`, Unknown Regions, grid G-8 — map position (-6350.9, 2831.2, -73.2)

Pesfavri was a planet located in the Pesfavri system within the Unknown Regions' Chiss Ascendancy. It was situated in grid square G-8 of the Standard Galactic Grid. Months before 36 BBY, pirates state-sanctioned by the Lioaoin Regime attacked several shipping freighters traveling from Pesfavri. Months later, Ascendancy Junior Commander Mitth'raw'nuruodo, core name "Thrawn," was certain of the pirates' affiliation with the Regime, which he later proved during a skirmish in the Kinoss system.
