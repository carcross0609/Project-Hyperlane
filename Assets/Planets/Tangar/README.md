# Tangar

**Continuity:** Legends  
**Source:** [Tangar](https://starwars.fandom.com/wiki/Tangar)

Tangar was a site of CIS activity during the Clone Wars. A flotila of starships dropped out of hyperspace off Tangar, then jumped again.

It was located near Dantus sector.
