# Baltimn

**Continuity:** Legends  
**Source:** [Baltimn](https://starwars.fandom.com/wiki/Baltimn)
**Galaxy atlas:** system `Baltimn`, Outer Rim, grid S-4 — map position (11714.0, 8514.0, -680.8)

Baltimn was an Outer Rim planet. It was here that Ephaan Kenzon established the School of Hidden Wisdom, the only dueling academy to survive the Clone Wars and the rise of Emperor Palpatine. Despite its pleasant environment, Baltimn's remote location made it inaccessible for many tourists.
