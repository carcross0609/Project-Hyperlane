# Atoa

**Continuity:** Legends  
**Source:** [Atoa/Legends](https://starwars.fandom.com/wiki/Atoa/Legends)

Atoa was a little-known ice planet in the Atoan system, in the Ghost Nebula. It was the homeworld of the near-Human Atoans.
