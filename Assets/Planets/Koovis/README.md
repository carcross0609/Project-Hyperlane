# Koovis

**Continuity:** Legends  
**Source:** [Koovis](https://starwars.fandom.com/wiki/Koovis)

Koovis was a planet in the Inner Rim. During the Galactic Civil War, Alliance operative Klev Natasken was captured by Imperial forces on the world, prompting the Alliance to commit Infiltrator squads to try and rescue him.
