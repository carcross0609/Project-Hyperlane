# Venaari

**Continuity:** Legends  
**Source:** [Venaari](https://starwars.fandom.com/wiki/Venaari)
**Galaxy atlas:** system `Venaari`, Mid Rim, grid O-8 — map position (5653.3, 2834.5, 34.5)

Venaari was a Mid Rim world, and the third planet in the Vellakiya system. It was the headquarters of Venaari Enterprises. The Galactic Empire increased its presence on the planet following the Battle of Endor due to Project Orrad, which was exposed by Shandria L'hnnar. The heightened Imperial security made it difficult for the New Republic to gain a foothold on Venaari.

The local day lasted 28 standard hours; the local year lasted 300 local days.
