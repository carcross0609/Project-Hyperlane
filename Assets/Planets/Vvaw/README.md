# Vvaw

**Continuity:** Canon  
**Source:** [Vvaw](https://starwars.fandom.com/wiki/Vvaw)
**Galaxy atlas:** system `Vvaw`, Outer Rim, grid U-9 — map position (14251.8, 597.2, -132.0)

Vvaw was a planet in the Calaron sector's Vvaw system, which was part of both the Outer Rim Territories and the Slice. It fell within square U-9 of the Standard Galactic Grid. Vvaw was the homeworld of Jedi Master Jmmaar, a ten-legged, crablike Jedi who had been slain by the Separatist General Grievous by 19 BBY.
