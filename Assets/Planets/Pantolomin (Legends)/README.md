# Pantolomin

**Continuity:** Legends  
**Source:** [Pantolomin/Legends](https://starwars.fandom.com/wiki/Pantolomin/Legends)
**Galaxy atlas:** system `Pantolomin`, Core Worlds, grid K-9 — map position (-558.4, 666.6, 28.1)

Pantolomin was the primary planet of the Panto system, in the Dolomar sector of the Core Worlds. It was an aquatic world known as one of the greatest tourist places of the galaxy.
