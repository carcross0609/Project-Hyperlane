# Storthus

**Continuity:** Legends  
**Source:** [Storthus](https://starwars.fandom.com/wiki/Storthus)

Storthus was a desolate planet in the Churba sector of the Mid Rim. It was the homeworld of the giant stone eels, an indigenous species composed of living rock.

- **Region:** Mid Rim
