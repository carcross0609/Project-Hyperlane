# Sinton

**Continuity:** Legends  
**Source:** [Sinton](https://starwars.fandom.com/wiki/Sinton)
**Galaxy atlas:** system `Sinton`, Mid Rim, grid I-7 — map position (-3531.0, 4133.8, 43.0)

The planet Sinton was located in the Sinton system, a part of the Mid Rim's Rago sector. It lay along the Rago Run hyperlane, which connected it to the Moro and Gilatter systems. Sinton was populated by non-Humans, and at some point by 3 ABY, the planet was subjugated by the Galactic Empire, which subjected the planet's inhabitants to slave labor.

By 12 ABY, Sulamar, a fraudulently self-titled Imperial general, claimed to have participated in the Subjugation of Sinton, among many other purported military conquests—some nonexistent. In reality, Sulamar was a low-level Imperial technician with a failed military career. By that same year, Sinton lay within the borders of the New Republic.
