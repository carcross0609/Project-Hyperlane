# Adamastor

**Continuity:** Legends  
**Source:** [Adamastor](https://starwars.fandom.com/wiki/Adamastor)
**Galaxy atlas:** system `Adamastor`, Core Worlds, grid L-9 — map position (679.8, 163.0, 38.5)

Adamastor was a largely aquatic world situated in the Adamastor system of the Core Worlds. Its surface featured a number of oceans.

The male Human Doctor Tolum Harous hailed from Adamastor, harboring an ever-lasting love for oceans. He went on to hold several honorary degrees from technological institutes throughout the galaxy and worked as an engineer for Hydrospeare Corporation beginning nearly thirty years prior to a point in approximately 2 ABY.
