# Tamban

**Continuity:** Legends  
**Source:** [Tamban](https://starwars.fandom.com/wiki/Tamban)
**Galaxy atlas:** system `Tamban`, Core Worlds, grid K-10 — map position (-1428.4, -682.1, 17.1)

Tamban was an inhabited planet in Core Worlds. From Tamban, the Koornacht Cluster near the Deep Core could be observed through a telescope. It was ruled by Emperor Preedu III before Palpatine rose to power.
