# Geminor

**Continuity:** Legends  
**Source:** [Geminor](https://starwars.fandom.com/wiki/Geminor)
**Galaxy atlas:** system `Geminor`, Outer Rim — map position (1894.0, -14332.9, -16.1)

Geminor was the second planet in the Lianna system. Its atmosphere consisted of a hot, dense poisonous gas and the planet was orbited by one single moon.
