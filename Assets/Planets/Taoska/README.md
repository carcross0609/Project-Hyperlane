# Taoska

**Continuity:** Legends

**Galaxy atlas:** system `Taoska`, Outer Rim, grid R-16 — map position (9962.4, -10032.5, 644.0)

Taoska was the fifth planet orbiting the star Tyrius in the Tyrius system. Located in the Savareen sector of the Outer Rim Territories, it was an ice ball that was visible from Rodia.
