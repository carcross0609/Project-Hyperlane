# Kor Desilijic; (The Bootana Hutta region, with Kor Desilijic represented by the number 12)

**Continuity:** Legends  
**Source:** [Kor Desilijic](https://starwars.fandom.com/wiki/Kor_Desilijic)
**Galaxy atlas:** system `Kor Desilijic`, Hutt Space, grid S-11 — map position (11482.9, -1645.3, -37.6)

Kor Desilijic was a Hutt Space planet situated in the Bootana Hutta region. It featured expansive swamps as well as great mountain ranges. The Hutt Desilijic clan established Kor Desilijic as a throneworld while the clan was regaining its power and prestige following the end of the Hutt Cataclysms around 15,000 BBY. The planet housed vast estates, including the ancient Rasmal Valley Palace, that the Desilijic used to store their large amount of accumulated treasure as well as a vacation site and a secure hideout when needed.
