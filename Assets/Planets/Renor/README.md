# Renor

**Continuity:** Unknown  
**Source:** [Renor](https://starwars.fandom.com/wiki/Renor)
**Galaxy atlas:** system `Renor`, Inner Rim — map position (-1800.6, -6375.1, 19.4)

Renor was an Inner Rim planet, and location of a Republic supply depot, where Mon Mothma attempted to meet with a contact, to gain transport to the Outer Rim, prior to being abducted by Senator Pel Talon.
