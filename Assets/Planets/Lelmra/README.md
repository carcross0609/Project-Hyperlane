# Lelmra

**Continuity:** Legends  
**Source:** [Lelmra](https://starwars.fandom.com/wiki/Lelmra)
**Galaxy atlas:** system `Lelmra`, Mid Rim, grid P-14 — map position (6672.5, -7265.8, 25.9)

Lelmra was a mountainous planet in the Churba sector of the Mid Rim. At one time, it was the headquarters of Garm Bel Iblis, and also served as a backup base for the smuggler organization of Mazzic.
