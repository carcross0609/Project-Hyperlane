# Dagobah

**Continuity:** Legends  
**Source:** [Dagobah/Legends](https://starwars.fandom.com/wiki/Dagobah/Legends)
**Galaxy atlas:** system `Dagobah`, Outer Rim, grid M-19 — map position (2460.9, -14267.5, 134.2)

Dagobah (/'deɪgəbə/; ) was an Outer Rim planet in the Dagobah system. A remote world of swamps and forests, it served as a refuge for Jedi Grand Master Yoda during his exile after the events of Order 66 had taken place.
