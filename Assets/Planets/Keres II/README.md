# Keres II

**Continuity:** Legends  
**Source:** [Keres II](https://starwars.fandom.com/wiki/Keres_II)
**Galaxy atlas:** system `Keres II`, Deep Core — map position (61.3, -828.1, 74.3)

Keres II, alternatively known as Keres Two, was a frozen rock planet. The planet was located in the Empress Teta system of the Deep Core's Koros sector. By 3643 BBY, a mining outpost was set up to harvest carbonite deposits, though it was abruptly abandoned.
