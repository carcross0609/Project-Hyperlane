# Tonjumi

**Continuity:** Legends  
**Source:** [Tonjumi](https://starwars.fandom.com/wiki/Tonjumi)

Tonjumi was the seventh planet orbiting the star Stisste in the Saleucami system. Located in the Suolriep sector of the Outer Rim Territories, it was a frozen rock.
