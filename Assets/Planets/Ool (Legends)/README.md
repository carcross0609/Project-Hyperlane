# Ool

**Continuity:** Legends  
**Source:** [Ool/Legends](https://starwars.fandom.com/wiki/Ool/Legends)
**Galaxy atlas:** system `Ool`, Unknown Regions, grid E-8 — map position (-9302.6, 1736.8, -180.7)

Ool was a forested planet located in the Ool system of the Unknown Regions' Chiss Space. A hyperlane linked the world to the Avidich and Shihon systems. The sentient Chiss of the Chiss Ascendancy established large circular plots of farmland across the surface of Ool.
