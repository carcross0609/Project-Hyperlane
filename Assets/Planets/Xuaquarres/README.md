# Xuaquarres

**Continuity:** Legends  
**Source:** [Xuaquarres](https://starwars.fandom.com/wiki/Xuaquarres)
**Galaxy atlas:** system `Xuaquarres`, Outer Rim, grid S-7 — map position (10704.4, 3205.1, 106.4)

Xuaquarres was a planet located within the Xuaquarres system of the Outer Rim Territories. It was the location of both the Graveyard of the Dragons and a secret storehouse of Emperor Palpatine.
