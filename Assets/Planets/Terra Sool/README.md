# Terra Sool

**Continuity:** Legends  
**Source:** [Terra Sool](https://starwars.fandom.com/wiki/Terra_Sool)
**Galaxy atlas:** system `Terra Sool`, Expansion Region, grid O-14 — map position (5795.4, -6569.7, 186.2)

Terra Sool was a planet located within the Terra Sool system of the Expansion Region. It was liberated from the Confederacy of Independent Systems by Anakin Skywalker and Obi-Wan Kenobi in 22 BBY, during the Clone Wars.
