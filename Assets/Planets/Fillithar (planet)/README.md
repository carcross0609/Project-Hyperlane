# Fillithar

**Continuity:** Canon  
**Source:** [Fillithar (planet)](https://starwars.fandom.com/wiki/Fillithar_%28planet%29)

Fillithar was a planet in the galaxy that was the homeworld of the snake-like Fillithar species. Twenty years into the reign of the New Republic, it was represented in the Galactic Senate.
