# Strokill Prime

**Continuity:** Canon  
**Source:** [Strokill Prime](https://starwars.fandom.com/wiki/Strokill_Prime)

Strokill Prime was a waterworld in the Outer Rim Territories where the Galactic Empire operated an underwater base. The Mon Calamari king Lee-Char was kept prisoner in the base on Strokill Prime, but was killed by stormtroopers during a Rebel Alliance rescue attempt.
