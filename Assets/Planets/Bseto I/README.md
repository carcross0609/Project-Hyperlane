# Bseto I

**Continuity:** Legends  
**Source:** [Bseto I](https://starwars.fandom.com/wiki/Bseto_I)

Bseto I was the first planet orbiting the white dwarf Bseto of the Mid Rim. It was a rocky, desert planet, and located in the Bseto system.
