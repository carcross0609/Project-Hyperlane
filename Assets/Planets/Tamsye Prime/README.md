# Tamsye Prime

**Continuity:** Canon  
**Source:** [Tamsye Prime](https://starwars.fandom.com/wiki/Tamsye_Prime)
**Galaxy atlas:** system `Tamsye Prime`, Outer Rim, grid T-14 — map position (12432.4, -6482.6, 636.8)

Tamsye Prime was a planet located in the Tamsye Prime system in the Thanium sector in the Outer Rim Territories. During the Clone Wars, the planet produced shell munitions for the Galactic Republic. In 5 BBY, Saw Gerrera abandoned Jyn Erso on the planet whilst on a mission there.
