# Sty

**Continuity:** Legends  
**Source:** [Sty](https://starwars.fandom.com/wiki/Sty)
**Galaxy atlas:** system `Sty`, Outer Rim, grid M-19 — map position (2532.9, -14387.6, 186.8)

Sty was a gas giant in the Dagobah system of the Outer Rim Territories' Sluis sector. Along with the rest of the star system, it lay on the hyperlane known as the Rimma Trade Route. The planet occupied the fifth orbital position around the star Darlo and had fifty-five moons.
