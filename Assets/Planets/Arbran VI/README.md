# Arbran VI

**Continuity:** Legends  
**Source:** [Arbran VI](https://starwars.fandom.com/wiki/Arbran_VI)

Arbran VI was a moonless ice planet that occupied the sixth orbit around the star Arbran. It was the outermost planet in the Arbran system, which was located in the Bon'nyuw-Luq sector, a part of the Trailing Sectors portion of the Outer Rim Territories.
