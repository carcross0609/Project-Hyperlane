# Quermia

**Continuity:** Legends  
**Source:** [Quermia/Legends](https://starwars.fandom.com/wiki/Quermia/Legends)
**Galaxy atlas:** system `Quermia`, Outer Rim, grid S-5 — map position (11426.2, 6944.7, -122.5)

Quermia was a terraformed planet and the homeworld of the Quermian species. It was located near the end of the Perlemian Trade Route.
