# Iwar

**Continuity:** Legends  
**Source:** [Iwar](https://starwars.fandom.com/wiki/Iwar)

Iwar was a searing rock planet with no moons that occupied the closest orbital position to the star Abo. It was located within the Lehon system, a part of the Unknown Regions' area known as the Tempered Wastes.
