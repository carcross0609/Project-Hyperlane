# Far Ziux

**Continuity:** Legends  
**Source:** [Far Ziux](https://starwars.fandom.com/wiki/Far_Ziux)

Far Ziux was the fifth planet orbiting the binary stars Toydar and Little Toydar in the Toydaria system. Located in Hutt Space of the galaxy, it was a gas giant.
