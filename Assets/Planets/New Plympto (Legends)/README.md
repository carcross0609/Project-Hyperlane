# New Plympto

**Continuity:** Legends  
**Source:** [New Plympto/Legends](https://starwars.fandom.com/wiki/New_Plympto/Legends)
**Galaxy atlas:** system `New Plympto`, Core Worlds — map position (-188.2, -4321.9, 62.4)

New Plympto was a temperate terrestrial planet in the Core Worlds region populated by Nosaurians. It was discovered by Corellians around 10,000 BBY - although the Jedi Order apparently had contact with it since at least 25,000 BBY, using the native population as potential recruits. The planet was also the homeworld of podracer pilot Clegg Holdfast. Its capital was the city of Phemiss.
