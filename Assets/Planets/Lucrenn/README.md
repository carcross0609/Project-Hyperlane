# Lucrenn

**Continuity:** Legends  
**Source:** [Lucrenn](https://starwars.fandom.com/wiki/Lucrenn)
**Galaxy atlas:** system `Lucrenn`, Outer Rim — map position (11819.7, 4443.8, -254.7)

Lucrenn was a world located within the star system of the same name, a part of the Outer Rim Territories' Skine sector. Around the year 10 ABY, it served as the homeworld of Galindas Exports, a fencing operation and member of the criminal Tenloss Syndicate.
