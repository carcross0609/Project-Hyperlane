# Aargau

**Continuity:** Canon  
**Source:** [Aargau](https://starwars.fandom.com/wiki/Aargau)
**Galaxy atlas:** system `Aargau`, Core Worlds, grid L-10 — map position (603.1, -298.1, 45.6)

Aargau was a planet in the galaxy's Core Worlds, in grid square L-10 on the Standard Galactic Grid, that was headquarters of the Bank of Aargau. Colossal seventh-stage bank-courier repulsor-trucks were used on Aargau. It was considered one of the financial centers of the galaxy. In 9 ABY, Aargau was mentioned on credits given to Boba Fett.
