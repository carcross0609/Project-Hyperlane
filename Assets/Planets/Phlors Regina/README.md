# Phlors Regina

**Continuity:** Legends  
**Source:** [Phlors Regina](https://starwars.fandom.com/wiki/Phlors_Regina)
**Galaxy atlas:** system `Phlors Regina`, Core Worlds, grid L-9 — map position (1079.2, 1342.4, -70.1)

Phlors Regina was a gas giant planet located within the Azure sector of the galaxy's Core Worlds. Phlors Regina held the seventh position in the Axum system, orbiting the star Solis Axum. It itself was host to fifteen moons.
