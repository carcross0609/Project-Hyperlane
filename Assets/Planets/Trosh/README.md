# Trosh

**Continuity:** Legends  
**Source:** [Trosh](https://starwars.fandom.com/wiki/Trosh)
**Galaxy atlas:** system `Trosh`, Outer Rim, grid L-20 — map position (1150.5, -15490.5, -211.1)

Trosh was a planet located within the Trosh system of the Outer Rim Territories. It was one of many planets where the Galactic Empire enslaved the native people, claiming that it was protecting the rights of the inhabitants.
