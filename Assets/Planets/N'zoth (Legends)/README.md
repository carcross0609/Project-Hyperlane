# N'zoth

**Continuity:** Legends  
**Source:** [N'zoth](https://starwars.fandom.com/wiki/N%27zoth)
**Galaxy atlas:** system `N'Zoth`, Core Worlds, grid K-10 — map position (-1435.4, -866.5, 116.3)

N'zoth was the fifth planet in the N'zoth system, located in the Farlax sector in the Koornacht Cluster of the Core Worlds. It was the homeworld of the Yevetha.
