# Mearalis II

**Continuity:** Legends  
**Source:** [Mearalis II/Legends](https://starwars.fandom.com/wiki/Mearalis_II/Legends)

Mearalis II was a planet located in the Outer Rim Territories. The planet boasted a number of mountain ranges and was the source of varpeline crystal, which could be used as lightsaber crystals.
