# Elbara Nine

**Continuity:** Legends  
**Source:** [Elbara Nine](https://starwars.fandom.com/wiki/Elbara_Nine)
**Galaxy atlas:** system `Elbara Nine`, Mid Rim, grid J-17 — map position (-1801.9, -10991.4, -107.0)

Elbara Nine was a Mid Rim world on the Cerean Reach of the galaxy. It was an icy world and home to the Rebel GlitterFall base. The planet was near a little-used Imperial Navy staging area.
