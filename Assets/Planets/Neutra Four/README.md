# Neutra Four

**Continuity:** Legends  
**Source:** [Neutra Four](https://starwars.fandom.com/wiki/Neutra_Four)

Neutra Four was a planet in the Neutra system, located in the Expansion Region's Oeiros sector. The Galactic Empire forcibly seized Neutra Four during the Galactic Civil War, leading one native, Human Rad Torlent, to join the Rebel Alliance as a junior officer.
