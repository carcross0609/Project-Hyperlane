# Raysho

**Continuity:** Canon  
**Source:** [Raysho](https://starwars.fandom.com/wiki/Raysho)
**Galaxy atlas:** system `Raysho`, Core Worlds, grid T-15 — map position (12575.7, -8502.2, -317.3)

Raysho was one of five planets that orbited the same sun, making up the Hosnian system, in the Core region of the galaxy. The system, including Raysho, was destroyed by the First Order in 34 ABY.
