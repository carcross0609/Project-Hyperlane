# Outpost

**Continuity:** Legends  
**Source:** [Outpost](https://starwars.fandom.com/wiki/Outpost)
**Galaxy atlas:** system `Outpost`, Mid Rim — map position (7770.1, -165.9, -353.0)

Outpost was a small frozen planet located in the Bissillirus system. It was the outermost planet and covered in frozen ammonia. Unilliten Industries once established a large research facility on the world, the purpose of which was kept secret.
