# Hrthging

**Continuity:** Legends  
**Source:** [Hrthging](https://starwars.fandom.com/wiki/Hrthging)

Hrthging was a planet in the Hrthging system of Mandalore sector in the Outer Rim. It was home to the Hrthgingian Firegem. It became part of Mandalorian Space.
