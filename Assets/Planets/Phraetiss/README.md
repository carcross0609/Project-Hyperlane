# Phraetiss

**Continuity:** Legends  
**Source:** [Phraetiss](https://starwars.fandom.com/wiki/Phraetiss)
**Galaxy atlas:** system `Phraetiss`, Core Worlds, grid K-9 — map position (-587.8, 648.7, 82.5)

Phraetiss was a planet in the Farrfin sector of the Galactic Core with thick and very tall grasslands.

Lando Calrissian ran a botched operation on Phraetiss about ten years before the rise of Grand Admiral Thrawn. It was there that he made the acquaintance of the smuggler Niles Ferrier.
