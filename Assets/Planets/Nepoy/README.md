# Nepoy

**Continuity:** Legends  
**Source:** [Nepoy](https://starwars.fandom.com/wiki/Nepoy)
**Galaxy atlas:** system `Nepoy`, Mid Rim, grid L-17 — map position (532.5, -11937.8, 16.3)

Nepoy was a Mid Rim planet in the Nepoy system, Senex sector known for its legendary fruit fields. Nectarwine and other sugary alcoholic beverages were the planets' chief exports.
