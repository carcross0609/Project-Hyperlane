# Mirani

**Continuity:** Legends  
**Source:** [Mirani](https://starwars.fandom.com/wiki/Mirani)
**Galaxy atlas:** system `Mirani`, Expansion Region, grid O-14 — map position (5667.0, -6883.0, -48.3)

Mirani was the fourth planet in the Aramand system, located within the Expansion Region of the galaxy. It was a gas giant that was orbited by nineteen moons. The Aramandi species colonized some of them.
