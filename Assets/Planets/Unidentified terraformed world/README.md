# Unidentified terraformed world

**Continuity:** Legends  
**Source:** [Unidentified terraformed world](https://starwars.fandom.com/wiki/Unidentified_terraformed_world)

This Unidentified terraformed world was an inhabited astronomical object terraformed during the Clone Wars.
