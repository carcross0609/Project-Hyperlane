# Gowdawl

**Continuity:** Legends  
**Source:** [Gowdawl](https://starwars.fandom.com/wiki/Gowdawl)

Gowdawl was a planet to which the Koqus liner Star Morning, fully loaded with passengers, was headed from Motexx. The ship never arrived, rather appearing at Arat Fraca empty of passengers 300 days later.

## Planetary data

- **Name:** Gowdawl
- **Region:**

- **System:** Gowdawl system
