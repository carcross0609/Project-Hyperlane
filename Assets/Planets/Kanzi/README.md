# Kanzi

**Continuity:** Canon  
**Source:** [Kanzi](https://starwars.fandom.com/wiki/Kanzi)
**Galaxy atlas:** system `Kanzi`, Other, grid S-5 — map position (10838.4, 7024.2, 459.3)

Kanzi was a planet located in the Colonies region. A few months after the end of the Clone Wars, the scientist Galen Erso, his wife Lyra and their daughter Jyn rendezvoused with Lieutenant Commander Orson Krennic on Kanzi in the Orona Hotel, where Krennic used kyber crystals to persuade Galen to join Project Celestial Power, an initiative of the Galactic Empire.
