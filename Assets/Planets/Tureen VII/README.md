# Tureen VII

**Continuity:** Canon  
**Source:** [Tureen VII](https://starwars.fandom.com/wiki/Tureen_VII)
**Galaxy atlas:** system `Tureen VII`, Other, grid O-18 — map position (5712.6, -12287.5, 44.7)

Tureen VII, was a planet in the Outer Rim Territories that was orbited by twin moons. Following the destruction of the Death Star at Yavin, the people of Tureen VII started aiding the Alliance to Restore the Republic in secret. However, having learned of Tureen VII's sympathy to the Alliance's cause, the Galactic Empire set up a blockade around the planet and establishing bases on the planet's twin moons.
