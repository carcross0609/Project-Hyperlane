# Cona

**Continuity:** Legends  
**Source:** [Cona/Legends](https://starwars.fandom.com/wiki/Cona/Legends)
**Galaxy atlas:** system `Cona`, Inner Rim, grid O-11 — map position (4904.1, -1802.3, 16.3)

Cona, also known as Arcona, was an arid, desert world which orbited the blue giant Teke Ro, located in the Teke Ro system of the Inner Rim. The homeworld of the serpent-like Arcona species, Cona had a minimal water supply due to a geological catastrophe early in its history.
