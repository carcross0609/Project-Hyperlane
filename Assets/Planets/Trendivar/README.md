# Trendivar

**Continuity:** Legends  
**Source:** [Trendivar](https://starwars.fandom.com/wiki/Trendivar)

Trendivar was a planet in the Hunnoverrs sector of the Outer Rim. A skirmish occurred here between the forces of the Vanderijar kajidic and the bounty hunters of Grim Destiny.
