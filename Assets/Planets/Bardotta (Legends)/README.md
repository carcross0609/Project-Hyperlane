# Bardotta

**Continuity:** Legends  
**Source:** [Bardotta/Legends](https://starwars.fandom.com/wiki/Bardotta/Legends)
**Galaxy atlas:** system `Bardotta`, Colonies, grid J-13 — map position (-1783.5, -5184.3, -30.8)

Bardotta was a planet located in the Colonies' Bardotta system that was ruled by the much beloved Queen Julia during the Clone Wars. Its inhabitants were reputed for their mysticism and attention to spiritual matters.
