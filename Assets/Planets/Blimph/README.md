# Blimph

**Continuity:** Legends  
**Source:** [Blimph](https://starwars.fandom.com/wiki/Blimph)
**Galaxy atlas:** system `Blimph`, Mid Rim, grid Q-10 — map position (8175.0, -679.3, 146.3)

Blimph was a Mid Rim gas giant in the Blimph system. One of its moons was Blimph 3, which was strategically important to the Rebel Alliance due to trading with the Jokhalli.
