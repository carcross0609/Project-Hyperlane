# Thobek

**Continuity:** Legends  
**Source:** [Thobek](https://starwars.fandom.com/wiki/Thobek)
**Galaxy atlas:** system `Thobek`, Core Worlds, grid K-10 — map position (-461.6, -750.3, 70.9)

Thobek was an obscure terrestrial planet situated in the Thobek system, a part of the Core Worlds' Farlax sector. It was situated along the Widek Bypass, a hyperlane connecting the planets Orooturoo and Widek in the Farlax sector.

The Thobek language was spoken on Thobek and also on the Widek Bypass planet Wehttam. Thobek was one of the stops taken by travelers journeying along the Widek Bypass between Orooturoo and Widek.
