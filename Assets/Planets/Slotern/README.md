# Slotern

**Continuity:** Legends  
**Source:** [Slotern](https://starwars.fandom.com/wiki/Slotern)

Slotern was a world where a battle was fought between the Galactic Empire and a resistance group sometime between the years 19 BBY and 1 BBY. The world was located in the Slotern system of the Wazta sector, which was located in the Outer Rim Territories.

- **Region:** Outer Rim Territories
- **Sector:** Wazta sector
- **System:** Slotern system
