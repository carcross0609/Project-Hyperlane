# Baratia

**Continuity:** Legends  
**Source:** [Baratia](https://starwars.fandom.com/wiki/Baratia)

Baratia was the first planet orbiting the star Julevia in the Julevian system. Located in the Dalonbian sector of the Outer Rim Territories, it was a molten rock.
