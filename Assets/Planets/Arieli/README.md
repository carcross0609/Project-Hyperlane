# Arieli

**Continuity:** Canon  
**Source:** [Arieli](https://starwars.fandom.com/wiki/Arieli)
**Galaxy atlas:** system `Arieli`, Other, grid O-14 — map position (5591.8, -7280.7, 382.6)

Arieli was an Expansion Region planet under the Galactic Empire's rule. After a local insurgency sabotaged the Imperial Arquitens-class light cruiser Peacemaker there, the cruiser began firing on the world's municipal buildings. The light freighter Mighty Oak Apocalypse did a supply run to the planet during the Galactic Civil War.
