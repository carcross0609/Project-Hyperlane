# Jabiim

**Continuity:** Canon  
**Source:** [Jabiim](https://starwars.fandom.com/wiki/Jabiim)
**Galaxy atlas:** system `Jabiim`, Outer Rim, grid S-7 — map position (11327.8, 3413.7, 393.4)

Jabiim was a terrestrial planet situated within the regions known as the Outer Rim Territories and the Slice. Connected to Sy Myrth and Taskeed by hyperspace routes, it was positioned at the coordinates S-7 on the Standard Galactic Grid. Ore was one of the main exports of Jabiim.
