# Womrik

**Continuity:** Legends  
**Source:** [Womrik](https://starwars.fandom.com/wiki/Womrik)
**Galaxy atlas:** system `Womrik`, Mid Rim, grid Q-15 — map position (8766.7, -8366.5, 125.7)

Womrik was a planet located within the Womrik system in the Dufilvian sector of the Mid Rim, near New Cov. The sights of its ice-capped mountain peaks, which were second to none, attracted many tourists and were a source of pride the planet's inhabitants.

Garm Bel Iblis used it as a location for Peregrine's Nest.
