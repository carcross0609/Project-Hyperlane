# Farboon

**Continuity:** Legends  
**Source:** [Farboon](https://starwars.fandom.com/wiki/Farboon)
**Galaxy atlas:** system `Farboon`, Outer Rim, grid M-19 — map position (2486.6, -14004.2, 528.0)

Farboon was a planet that appeared green-blue from space. It was the site where Maarek Stele, a TIE/LN starfighter pilot, rescued Imperial Admiral Mordon's shuttle from a Rebel attack of X-wing and Y-wing fighters.
