# Anoth

**Continuity:** Legends  
**Source:** [Anoth/Legends](https://starwars.fandom.com/wiki/Anoth/Legends)
**Galaxy atlas:** system `Anoth`, Wild Space, grid J-20 — map position (-2605.3, -16467.2, -522.5)

Anoth was a planet located in Wild Space. The world was shattered at some point during an unknown cataclysm, but remained largely together due to its gravitational pull.
