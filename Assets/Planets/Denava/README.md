# Denava

**Continuity:** Legends  
**Source:** [Denava](https://starwars.fandom.com/wiki/Denava)
**Galaxy atlas:** system `Denava`, Mid Rim — map position (1741.4, 4045.6, 157.8)

Denava was a gas giant with six moons. It was the third planet in the Goroth system. It measured 153,050 kilometers in diameter and had strong magnetic and radio fields. The upper atmosphere was home to a beldon-like species of gas-filled creatures.
