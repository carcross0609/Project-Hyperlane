# Asuin

**Continuity:** Legends  
**Source:** [Asuin](https://starwars.fandom.com/wiki/Asuin)

Asuin was a frost-covered planet located in Hutt Space that was populated by wampas. While the surface was besieged by icestorms, there were underground caverns filled with lava.
