# Arro

**Continuity:** Legends  
**Source:** [Arro](https://starwars.fandom.com/wiki/Arro)
**Galaxy atlas:** system `Arro`, Outer Rim, grid O-6 — map position (4659.3, 4776.1, 175.7)

Arro was the first planet of the Dathomir system, a part of the Quelii sector in the New Territories portion of the Outer Rim Territories. A hot world made of molten rock, it had no moons and orbited the star Domir.
