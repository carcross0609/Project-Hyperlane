# Ijol

**Continuity:** Legends  
**Source:** [Ijol](https://starwars.fandom.com/wiki/Ijol)
**Galaxy atlas:** system `Ijol`, Mid Rim, grid N-8 — map position (3709.0, 2197.4, 46.8)

Ijol was the fourth planet that orbited Tirahnn, the Tirahnn system's sun. The planet, along with the rest of its system, was situated in the Inner Rim's Zeemacht Cluster along the Perlemian Trade Route, which served as the dividing line between the Northern Dependencies and the Slice. By 17,000 BBY, Ijol's system also resided along a hyperspace route, that linked it to the Filordis and Ktil systems, that ceased to exist by 3976 BBY. Ijol was a gas giant with twenty-four moons.
