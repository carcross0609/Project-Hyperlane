# Argovia

**Continuity:** Legends  
**Source:** [Argovia](https://starwars.fandom.com/wiki/Argovia)
**Galaxy atlas:** system `Argovia`, Mid Rim, grid S-14 — map position (10575.0, -7163.4, 337.6)

Argovia was a planet of stormy, misty, marshy wetlands in the Endocray sector, rich in minerals and ores. It was the location of an Imperial sensor network complex that analyzed data from thousands of sensor buoys, ships, and probe droids in the sector. To protect both the sensor complex and the valuable ore, the mining companies and the Empire mutually restricted any non-personnel from immigrating to the planet.
