# Aloxor

**Continuity:** Legends  
**Source:** [Aloxor/Legends](https://starwars.fandom.com/wiki/Aloxor/Legends)

Aloxor was a planet that applied for Galactic Alliance membership in 44 ABY. It missed being the fourteenth planet to submit the request by eighteen and a half standard seconds.
