# Oshetti IV

**Continuity:** Legends  
**Source:** [Oshetti IV](https://starwars.fandom.com/wiki/Oshetti_IV)
**Galaxy atlas:** system `Oshetti IV`, Outer Rim, grid R-3 — map position (9532.8, 9213.0, -359.7)

Oshetti IV was a swampy planet in the Outer Rim Territories. Its inhabitants used dried swamp hemp, which contained bioluminescent bacteria, to create the glowing fabric known as illuminescence.
