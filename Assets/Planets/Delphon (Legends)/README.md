# Delphon

**Continuity:** Legends  
**Source:** [Delphon/Legends](https://starwars.fandom.com/wiki/Delphon/Legends)
**Galaxy atlas:** system `Delphon`, Outer Rim, grid K-18 — map position (-1012.0, -13024.4, -77.0)

Delphon was a planet in the Outer Rim Territories, near the Ison Corridor. It was headquarters of the Black Hole Gang, which the Galactic Empire attempted to wipe out. The planet was represented in the Imperial Senate by Ilov Maas.
