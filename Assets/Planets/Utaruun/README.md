# Utaruun

**Continuity:** Legends  
**Source:** [Utaruun](https://starwars.fandom.com/wiki/Utaruun)
**Galaxy atlas:** system `Utaruun`, Outer Rim, grid R-16 — map position (9440.5, -10002.2, 621.0)

Utaruun was a terrestrial planet located in the Utaruun system, a part of the Arkanis sector in the Slice portion of the Outer Rim Territories. Utaruun was located on the Old Corellian Run hyperlane between the Austan and Tatoo systems.

Utaruun originally served as a minor agriworld situated on the super-hyperroute known as the Corellian Run. When that hyperspace route changed its course at some point between 11,000 BBY and 4000 BBY and as a result no longer ran through Utaruun, the world remained on the Old Corellian Run but became abandoned. During the century leading up to 43 ABY, however, Rodian colonists began to move there.
