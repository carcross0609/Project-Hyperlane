# Kor Oktanivii; (The Bootana Hutta region, with Kor Oktanivii represented by the number 11)

**Continuity:** Legends  
**Source:** [Kor Oktanivii](https://starwars.fandom.com/wiki/Kor_Oktanivii)
**Galaxy atlas:** system `Kor Oktanivii`, Hutt Space, grid S-11 — map position (11287.9, -1878.9, -211.0)

Kor Oktanivii was a world located within the Kor Oktanivii system, a part of the Bootana Hutta region of Hutt Space. It was part of the Slice section of the galaxy. It was connected by hyperlanes to the Gos Hutta and Pybus systems.

Kor Oktanivii was the throneworld of the Oktanivii kajidic.
