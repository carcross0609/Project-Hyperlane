# Behpour

**Continuity:** Canon  
**Source:** [Behpour](https://starwars.fandom.com/wiki/Behpour)

Behpour was a planet in the Naboo system within the Mid Rim's Chommell sector. It possessed a relatively small population. Behpour was represented by Olan Carrus at a summit held by Queen Padmé Amidala of Naboo.
