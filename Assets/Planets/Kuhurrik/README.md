# Kuhurrik

**Continuity:** Legends  
**Source:** [Kuhurrik](https://starwars.fandom.com/wiki/Kuhurrik)

Kuhurrik was the seventh planet in the Kashyyyk system. A gas giant, it occupied the eighth orbital position around the star Kashyyyk, and had twenty-five moons in its own orbit.
