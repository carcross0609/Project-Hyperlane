# Almania

**Continuity:** Legends  
**Source:** [Almania](https://starwars.fandom.com/wiki/Almania)
**Galaxy atlas:** system `Almania`, Outer Rim, grid S-5 — map position (10756.8, 7416.4, -27.8)

Almania was a cold and windy planet located in the Almanian system. It had three moons, Pydyr, Auyemesh, and Drewwa.
