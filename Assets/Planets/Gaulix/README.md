# Gaulix

**Continuity:** Legends  
**Source:** [Gaulix](https://starwars.fandom.com/wiki/Gaulix)

Gaulix was a planet in the Ansion system, which was located in the Mid Rim's Churnis sector. Gaulix occupied the second position in orbit of the star Ansion, and had one moon. Its atmosphere was a broiling toxic soup, rendering it uninhabitable.
