# Durkteel

**Continuity:** Canon  
**Source:** [Durkteel](https://starwars.fandom.com/wiki/Durkteel)
**Galaxy atlas:** system `Durkteel`, Mid Rim, grid Q-10 — map position (8689.8, -332.9, -150.4)

Durkteel was an agricultural planet located in the galaxy's Mid Rim that was the homeworld of the reptilian Saurin species. Durkteel was also the homeworld of Mattis Banz, a Force-sensitive human who joined the Resistance. Lund Gourley and Lund Berlo were cities located on Durkteel.
