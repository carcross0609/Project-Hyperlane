# Ash

**Continuity:** Legends  
**Source:** [Ash](https://starwars.fandom.com/wiki/Ash)
**Galaxy atlas:** system `Ash`, Core Worlds, grid O-17 — map position (5597.1, -10801.7, 281.1)

Ash was the second planet of the Belgaroth system, located in the Core Worlds of the galaxy. Illuminated by binary stars Matanya A and Matanya B, Ash was a searing world with no moons.
