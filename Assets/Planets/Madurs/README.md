# Madurs

**Continuity:** Canon  
**Source:** [Madurs](https://starwars.fandom.com/wiki/Madurs)

Madurs was an ice moon in the Lenguin system in the Maldrood sector of the Mid Rim Territories that orbited a gas giant. The inhabitants of the moon built ice palaces and had a great value for art.
