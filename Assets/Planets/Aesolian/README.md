# Aesolian

**Continuity:** Legends  
**Source:** [Aesolian](https://starwars.fandom.com/wiki/Aesolian)
**Galaxy atlas:** system `Aesolian`, Mid Rim, grid I-15 — map position (-4024.7, -7927.3, -70.9)

Aesolian was a planet located within the Aesolian system, a part of the galaxy's Wild Space region. It was the homeworld of bulky creatures known as tretons. They had pointed ears and were capable of emitting fierce snarls.
