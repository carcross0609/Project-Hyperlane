# Sha Qarot

**Continuity:** Canon  
**Source:** [Sha Qarot](https://starwars.fandom.com/wiki/Sha_Qarot)
**Galaxy atlas:** system `Sha Qarot`, Deep Core, grid P-18 — map position (6207.9, -13224.6, 30.3)

Sha Qarot was a planet located in the Sha Qarot system in the Deep Core that orbited a red sun. It had a moon named Fex. Due to its poisonous atmosphere and heavy volcanic activity, Nakari Kelen thought nobody would ever want to set foot on the planet.
