# Carosi VIII

**Continuity:** Legends  
**Source:** [Carosi VIII](https://starwars.fandom.com/wiki/Carosi_VIII)

Carosi VIII was a planet in the Carosus system. It was a hot, jungle planet deemed suitable for future Carosite colonization efforts. It had two moons.
