# Jech

**Continuity:** Legends  
**Source:** [Jech](https://starwars.fandom.com/wiki/Jech)

Jech was the fourth planet orbiting the star Tive in the Taanab system. Located in the Inner Rim Territories, it was a gas giant and had four moons.
