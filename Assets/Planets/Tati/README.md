# Tati

**Continuity:** Legends  
**Source:** [Tati](https://starwars.fandom.com/wiki/Tati)
**Galaxy atlas:** system `Tati`, Core Worlds, grid M-11 — map position (2428.2, -2690.3, 22.1)
