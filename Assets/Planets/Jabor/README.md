# Jabor

**Continuity:** Legends  
**Source:** [Jabor](https://starwars.fandom.com/wiki/Jabor)
**Galaxy atlas:** system `Jabor`, Mid Rim — map position (10212.2, 1623.4, -310.4)

Jabor was a planet where Ferus Olin worked for the Galactic Republic during the Clone Wars. Ferus sent double agent Clive Flax undercover into the local Separatist base, thus disrupting a spy ring that had taken root throughout the Mid Rim. Its subsequent destruction saved many lives.
