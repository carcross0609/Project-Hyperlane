# Olanet

**Continuity:** Legends  
**Source:** [Olanet](https://starwars.fandom.com/wiki/Olanet)
**Galaxy atlas:** system `Olanet`, Outer Rim — map position (10861.4, 8566.6, 95.2)

Olanet was a planet in the Outer Rim's Siskeen system that sided with the Confederacy of Independent Systems during the Clone Wars. It was said to be home to the second largest droid factory since Geonosis. One of the most important sectors of the economy was the nerf-meat industry.
