# Taboth

**Continuity:** Legends  
**Source:** [Taboth](https://starwars.fandom.com/wiki/Taboth)
**Galaxy atlas:** system `Taboth`, Mid Rim, grid R-14 — map position (9744.3, -6361.0, -201.5)

Taboth was the second planet in the Both system.

It was a barren world with a thin atmosphere, where only simple life-forms, if any, could live. It was orbited by two satellites.
