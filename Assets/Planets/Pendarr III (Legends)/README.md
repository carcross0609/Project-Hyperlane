# Pendarr III

**Continuity:** Legends  
**Source:** [Pendarr III/Legends](https://starwars.fandom.com/wiki/Pendarr_III/Legends)
**Galaxy atlas:** system `Pendarr III`, Expansion Region, grid L-15 — map position (1102.2, -8970.1, -219.4)

Pendarr III was the homeworld of the Pendarran Warriors, a military organization headed by Gendal Delan which worked alongside the Jedi of the Republic. The Emperor ordered the Pendarran Warriors killed in the Great Jedi Purge. The survivors formed Pendarran's Revenge.
