# Chanosant

**Continuity:** Legends  
**Source:** [Chanosant](https://starwars.fandom.com/wiki/Chanosant)
**Galaxy atlas:** system `Chanosant`, Expansion Region, grid O-11 — map position (5318.8, -2512.7, -135.4)

Chanosant was a world in the Expansion Region's Chanosant system. During the Clone Wars, it was the site of a Separatist convention which was attended by Count Dooku and held during the Clone Wars. Dooku and Kob Mondray attended it and tried to use it to rally more support for the CIS.
