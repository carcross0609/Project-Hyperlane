# Qualtrough

**Continuity:** Legends  
**Source:** [Qualtrough](https://starwars.fandom.com/wiki/Qualtrough)
**Galaxy atlas:** system `Qualtrough`, Outer Rim, grid O-6 — map position (5723.9, 5562.0, -152.9)

Qualtrough was a terrestrial planet located in the Qualtrough system of the Outer Rim Territories' Belsmuth sector. Its native population was at one point engaged in an intense worldwide civil war.

The planet was first discovered by the wider galactic community at some point between 400 BBY and 300 BBY, when the Jedi Order's starship Chu'unthor arrived there. The Jedi aboard the vessel negotiated a truce between Qualtrough's conflicting parties—an accomplishment that attracted the attention of the galactic media and allowed the planet's inhabitants to join the Galactic Republic.
