# Adrafar

**Continuity:** Canon  
**Source:** [Adrafar](https://starwars.fandom.com/wiki/Adrafar)

Adrafar was a planet located in the Abafar system of the Quelii sector within the Outer Rim Territories. The sister world of the desert planet Abafar, Adrafar orbited the yellow star Abafed on an identical orbit, though four months behind. Despite the similarity, Abafar was the only inhabited world in the system.
