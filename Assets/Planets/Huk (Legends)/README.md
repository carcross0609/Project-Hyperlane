# Huk

**Continuity:** Legends  
**Source:** [Huk/Legends](https://starwars.fandom.com/wiki/Huk/Legends)
**Galaxy atlas:** system `Huk`, Wild Space, grid J-4 — map position (-2784.2, 8406.1, 110.2)

Huk was the home planet of the Yam'rii species, also known as the Huk (a Kaleesh slur translating as "soulless bug"). The planet was mostly covered with dense forests.
