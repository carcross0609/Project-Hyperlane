# Ganath

**Continuity:** Canon  
**Source:** [Ganath](https://starwars.fandom.com/wiki/Ganath)
**Galaxy atlas:** system `Ganath`, Hutt Space, grid R-12 — map position (10297.9, -3294.9, -294.7)

Ganath was a planet located in Hutt Space and the Slice's Ganath system. It was situated in grid square R-12 of the Standard Galactic Grid. At Ganath, members of the sentient Hutt species engaged in illicit activities. It shared its name with the Ganath Cloud nebula.
