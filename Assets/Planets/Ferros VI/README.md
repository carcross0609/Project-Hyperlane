# Ferros VI

**Continuity:** Legends  
**Source:** [Ferros VI](https://starwars.fandom.com/wiki/Ferros_VI)
**Galaxy atlas:** system `Ferros VI`, Outer Rim, grid N-7 — map position (4140.5, 4166.2, -344.7)

Ferros VI was a planet that occupied the sixth orbital position in the Ferros system, a part of the Outer Rim Territories' Ojoster sector. The Galactic Empire maintained a prison camp on the planet during the Galactic Civil War.
