# Chokan

**Continuity:** Legends  
**Source:** [Chokan](https://starwars.fandom.com/wiki/Chokan)
**Galaxy atlas:** system `Chokan`, Mid Rim, grid Q-13 — map position (7818.4, -4952.4, -478.1)

Chokan was a planet on the Gamor Run in the Mid Rim's Maerdocian sector.

At some point Han Solo visited Chokan during his smuggling career. Isolder also visited this place and remembered the local Imperial port authority code.
