# Trif

**Continuity:** Legends  
**Source:** [Trif](https://starwars.fandom.com/wiki/Trif)

Trif was a planet located within the Trif system of the Outer Rim Territories. It was under the control of the Imperial Remnant during the Black Fleet Crisis.
