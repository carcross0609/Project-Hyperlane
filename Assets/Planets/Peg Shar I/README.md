# Peg Shar I

**Continuity:** Canon  
**Source:** [Peg Shar I](https://starwars.fandom.com/wiki/Peg_Shar_I)
**Galaxy atlas:** system `Peg Shar I`, Mid Rim, grid R-8 — map position (10382.7, 1664.7, -296.2)

Peg Shar I was an industrial world in the Peg Shar system of the Halla sector in the Mid Rim Territories and the Slice. It fell within grid square R-8 of the Standard Galactic Grid. It was represented by a senator in the Senate of the Galactic Republic by 32 BBY. That year, the senator for the world had an office in a lower level of the Galactic Senate Building on the Republic capital, Coruscant.
