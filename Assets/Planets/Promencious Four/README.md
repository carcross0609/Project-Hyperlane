# Promencious Four

**Continuity:** Legends  
**Source:** [Promencious Four](https://starwars.fandom.com/wiki/Promencious_Four)

Promencious Four was a planet. Around the time of the rule of the Eternal Empire, the centuries old wreck of the Splendor, a lost Mirialan luxury cruiser, was discovered in the lava fields of Promencious Four.
