# Unidentified swamp planet

**Continuity:** Legends  
**Source:** [Unidentified swamp planet (assassin)](https://starwars.fandom.com/wiki/Unidentified_swamp_planet_%28assassin%29)

A swamp planet served as home to an elite assassin and his base around 19 BBY. The base was infiltrated by a mercenary group led by a wealthy industrialist, intending to hire the assassin's services to kill Darth Vader.

## Planetary data

- **Terrain:** Swamps and jungles
- **Interest:** Assassin's base
