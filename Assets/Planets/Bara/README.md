# Bara

**Continuity:** Legends  
**Source:** [Bara](https://starwars.fandom.com/wiki/Bara)

Bara was the first planet orbiting the star Prael in the Japrael system. Located in the Japrael sector of the Inner Rim, it was a scorched ball.
