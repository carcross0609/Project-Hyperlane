# Lolnar

**Continuity:** Legends  
**Source:** [Lolnar](https://starwars.fandom.com/wiki/Lolnar)
**Galaxy atlas:** system `Lolnar`, Core Worlds, grid M-11 — map position (2075.9, -1763.3, 56.1)

Lolnar was a planet located in the Lolnar system, in the Slice portion of the Core Worlds that was known as the Arrowhead. It was situated on the Corellian Run super-hyperroute, between the Perma and Rehemsa systems. The Human Lesan Ramier, who was a Moff of the Galactic Empire, hailed from Lolnar.
