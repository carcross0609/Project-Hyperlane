# Odynnia Gavo

**Continuity:** Canon  
**Source:** [Odynnia Gavo](https://starwars.fandom.com/wiki/Odynnia_Gavo)

Odynnia Gavo was a terrestrial world located in the Odynnia Gavo system within the Bryx sector of the Mid Rim and the Slice. It was situated in grid square R-7 of the Standard Galactic Grid.

By 35 ABY, during the war between the First Order and the Resistance, Odynnia Gavo was one of the worlds not under First Order control. As such, the world was a contested site where General Bellava Parnadee of the First Order directed ground forces.
