# Vestar

**Continuity:** Legends  
**Source:** [Vestar/Legends](https://starwars.fandom.com/wiki/Vestar/Legends)
**Galaxy atlas:** system `Vestar`, Outer Rim, grid N-20 — map position (3908.1, -16055.8, -66.2)

Vestar was the Icarii homeworld located within the Vestar system of the Outer Rim Territories.

In 3 BBY, the planet was invaded by the Galactic Empire in a campaign to subdue the Icarii, a conflict that ended in the extermination of the entire species through biological warfare.
