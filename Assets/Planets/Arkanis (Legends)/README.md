# Arkanis

**Continuity:** Legends  
**Source:** [Arkanis/Legends](https://starwars.fandom.com/wiki/Arkanis/Legends)
**Galaxy atlas:** system `Arkanis`, Outer Rim, grid R-17 — map position (9210.8, -10632.8, -22.6)

Arkanis was the sector capital of the Arkanis sector. It was inhabited by Humans such as Devon Fuller. It was the capital of the Arkanis Regency, which included the ancient Empress Teeda. The planet was part of the Galactic Empire. It was the location of Vensenor Flight Academy.
