# Cificap VIII

**Continuity:** Legends  
**Source:** [Cificap VIII](https://starwars.fandom.com/wiki/Cificap_VIII)
**Galaxy atlas:** system `Cificap VIII`, Other, grid Q-16 — map position (8452.0, -9578.2, 238.2)

Cificap VIII was a planet in the Cificap system. After the Battle of Yavin, the Rebel Alliance freed Habassa slaves from the Galactic Empire near that planet, before the slaves could be loaded onto the Mayhem.
