# Mandell

**Continuity:** Legends  
**Source:** [Mandell](https://starwars.fandom.com/wiki/Mandell)
**Galaxy atlas:** system `Mandell`, Mid Rim, grid R-14 — map position (9295.6, -6117.5, -30.8)

Mandell was a Bothan colony world. It was once devastated by drought, requiring grain shipments from Bothawui. Unfortunately, these shipments contained radarks, which infested the planet.
