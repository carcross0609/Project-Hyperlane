# Doornik-628A

**Continuity:** Legends  
**Source:** [Doornik-628A](https://starwars.fandom.com/wiki/Doornik-628A)
**Galaxy atlas:** system `Doornik-628A`, Core Worlds — map position (1138.9, 600.1, 35.8)

Doornik-628A was the first planet in the Doornik-628 system, located in the Farlax sector. It was a part of the Koornacht Cluster, itself a region of the Negs portion of the Core Worlds. One of the three gas giants in the system, which was centered around the star Doornik-628, Doornik-628A was orbited by three moons.
