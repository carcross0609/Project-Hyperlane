# Avidich

**Continuity:** Legends  
**Source:** [Avidich/Legends](https://starwars.fandom.com/wiki/Avidich/Legends)
**Galaxy atlas:** system `Avidich`, Unknown Regions, grid E-8 — map position (-9151.2, 1805.6, 71.7)

Avidich was a planet located in the Avidich system in the Unknown Regions within the core territory of the Chiss Ascendancy. It was located on the Vagaari Corridor, a hyperlane that ran through the Unknown Regions. Avidich was a mountainous world with peaks that were considered impressive. The planet was used by the Chiss species to cultivate edible lichens.
