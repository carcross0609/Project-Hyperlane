# Alk'Lellish III

**Continuity:** Legends  
**Source:** [Alk'Lellish III](https://starwars.fandom.com/wiki/Alk%27Lellish_III)
**Galaxy atlas:** system `Alk'lellish III`, Outer Rim, grid N-7 — map position (4114.2, 3631.1, -3.4)

Alk'Lellish III was a planet in the Alk'Lellish system of the Sumitra sector. It was the homeworld of the Lellish, as well as the dangerous carnivore known as the ketrann. Wilek Nereus hunted the ketrann at one point.
