# Gaaten

**Continuity:** Canon  
**Source:** [Gaaten](https://starwars.fandom.com/wiki/Gaaten)

Gaaten was a planet located in the Garis sector. It was home to an orphanage that became the home of a Force-sensitive girl named Elish in the aftermath of the Clone Wars.
