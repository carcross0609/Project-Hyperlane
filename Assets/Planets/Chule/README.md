# Chule

**Continuity:** Legends  
**Source:** [Chule](https://starwars.fandom.com/wiki/Chule)
**Galaxy atlas:** system `Chule`, Outer Rim, grid Q-10 — map position (8847.6, -1077.4, -15.6)

Chule was the second planet in the Bissillirus system. It was a cold planet with no geological activity, covered in oceans and barren plains. Its local day lasted 49 standard hours; its year lasted 145 local days.
