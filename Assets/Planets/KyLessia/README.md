# KyLessia

**Continuity:** Legends  
**Source:** [KyLessia](https://starwars.fandom.com/wiki/KyLessia)
**Galaxy atlas:** system `KyLessia`, Outer Rim — map position (5452.3, -14214.7, 74.7)

KyLessia was located within the KyLessia system. It was the homeworld of wulfruit trees, KyLessian fruit bats, and KyLessian feather mites. Its exports included KyLessian Fruit Distillate, a popular Outer Rim alcohol.
