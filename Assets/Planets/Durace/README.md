# Durace

**Continuity:** Legends  
**Source:** [Durace](https://starwars.fandom.com/wiki/Durace)

Durace was a toxic, barren planet in a hostile region of space in the Unknown Regions. Although the atmosphere was breathable, Durace's hostile weather made colonization difficult.
