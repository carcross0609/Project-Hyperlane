# Skuumaa

**Continuity:** Legends  
**Source:** [Skuumaa](https://starwars.fandom.com/wiki/Skuumaa)

Skuumaa was a planet contested during the Clone Wars. Delta Squad traveled there ahead of the main Republic assault in order to sabotage strategic targets and "prepare the battlefield", shortly after their involvement in an anti-terror operation on Coruscant.

## Planetary data

- **Name:** Skuumaa
- **Region:** Mid Rim
- **Sector:** Mytaranor sector
- **System:** Skuumaa system
- **Coordinates:** Q-9
- **Affiliation:** Confederacy of Independent Systems
