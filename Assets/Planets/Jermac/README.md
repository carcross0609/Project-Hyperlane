# Jermac

**Continuity:** Legends  
**Source:** [Jermac](https://starwars.fandom.com/wiki/Jermac)

Jermac was a world located in the Portmoak sector of the Outer Rim. Located along the Llanic Spice Run, Jermac was a notable spice producer.
