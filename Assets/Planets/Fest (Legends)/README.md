# Fest

**Continuity:** Legends  
**Source:** [Fest/Legends](https://starwars.fandom.com/wiki/Fest/Legends)
**Galaxy atlas:** system `Fest`, Outer Rim, grid L-5 — map position (1207.5, 6596.8, -97.2)

Fest was the primary planet in the Fest system. It was a frozen and densely populated world with few wilderness areas beyond several steep-ridged mountain ranges and deep valleys.
