# Aefao

**Continuity:** Legends  
**Source:** [Aefao](https://starwars.fandom.com/wiki/Aefao)
**Galaxy atlas:** system `Aefao`, Outer Rim, grid N-5 — map position (3636.3, 6132.2, 285.0)

Aefao was the Aefan homeworld, located in the Aefao system. A remote planet, it was on the other side of the galaxy from Nar Shaddaa.
