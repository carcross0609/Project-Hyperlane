# Choss

**Continuity:** Canon  
**Source:** [Choss](https://starwars.fandom.com/wiki/Choss)

Choss was a planet located in the Choss system in the Colonies. Rey, Chewbacca, Moebin Faltus, and Finn visited the planet to get repairs for the Millennium Falcon. The planet had forests and a large city.
