# Kor Anjiliac; (The Bootana Hutta region, with Kor Anjiliac represented by the number 14)

**Continuity:** Legends  
**Source:** [Kor Anjiliac](https://starwars.fandom.com/wiki/Kor_Anjiliac)
**Galaxy atlas:** system `Kor Anjiliac`, Hutt Space, grid S-11 — map position (11650.1, -1528.5, -512.6)

Kor Anjiliac was a world located in the Kor Anjiliac system, a part of the Bootana Hutta area in the Hutt Space portion of the Slice. It was connected by a hyperlane to the Huloon and Langoona systems. Kor Anjiliac served as the throneworld of the Anjiliac clan of the Hutt species.
