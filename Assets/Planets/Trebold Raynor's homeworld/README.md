# Trebold Raynor's homeworld

**Continuity:** Legends  
**Source:** [Trebold Raynor's homeworld](https://starwars.fandom.com/wiki/Trebold_Raynor%27s_homeworld)

The homeworld of Trebold Raynor was the rumored resting place of the Platinum Pickaxe. Gan Alno, head of Raynor Mining Enterprises during the Galactic War, hired treasure hunters to search Raynor's homeworld for the pickaxe.
