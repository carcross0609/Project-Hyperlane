# Listehol

**Continuity:** Legends  
**Source:** [Listehol/Legends](https://starwars.fandom.com/wiki/Listehol/Legends)
**Galaxy atlas:** system `Listehol`, Outer Rim, grid Q-4 — map position (8029.0, 8869.8, 106.5)

Listehol was a planet located in the Listehol system within the Outer Rim Territories.

During the Clone Wars, the planet was located within Separatist space. Later on it fell under control of the Galactic Empire.
