# Polneye

**Continuity:** Legends  
**Source:** [Polneye](https://starwars.fandom.com/wiki/Polneye)
**Galaxy atlas:** system `Polneye`, Core Worlds, grid K-10 — map position (-196.1, -982.2, -63.9)

Polneye was a planet in the Farlax sector of the Core Worlds. Polneye was established under the Galactic Empire as a Grannan colony. It was then taken over by the Yevetha during the Yevethan Purge in the Koornacht Cluster, and later admitted as an empty world to the New Republic as a memorial to the Yevethan atrocities.

Plat Mallar was the sole survivor.
