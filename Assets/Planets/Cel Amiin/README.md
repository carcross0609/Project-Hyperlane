# Cel Amiin

**Continuity:** Legends  
**Source:** [Cel Amiin](https://starwars.fandom.com/wiki/Cel_Amiin)

Cel Amiin was a remote planet in the Expansion Region of the galaxy that defied Emperor Palpatine shortly after the formation of the Galactic Empire. Like the other worlds that refused to cooperate, Cel Amiin suffered an unspecified devastation as a result.

- **Name:** Cel Amiin
- **Region:** Expansion Region
