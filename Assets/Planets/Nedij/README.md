# Nedij

**Continuity:** Legends  
**Source:** [Nedij](https://starwars.fandom.com/wiki/Nedij)
**Galaxy atlas:** system `Nedij`, Outer Rim, grid Q-19 — map position (7975.7, -14325.2, 503.2)

Nedij was a planet in the Outer Rim on the eastern spiral arm of the galaxy. It had thin air in which its native species evolved. Natural terrain included snowy mountains which the Nediji preferred, and lowlands. The planet was inhabited by a species of humanoids which served as prey for the Nediji. The Black Sun operative Kaird hailed from this planet.
