# Ralgos

**Continuity:** Legends  
**Source:** [Ralgos](https://starwars.fandom.com/wiki/Ralgos)

Ralgos was a planet located somewhere in the Outer Rim. During the Galactic Civil War, a bombardment took place on this planet, and destroyed multiple cities. This caused a local lawman, Danel Qurno, to join the Rebel Alliance.
