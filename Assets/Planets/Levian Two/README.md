# Levian Two

**Continuity:** Legends  
**Source:** [Levian Two](https://starwars.fandom.com/wiki/Levian_Two)
**Galaxy atlas:** system `Levian Two`, Inner Rim, grid N-8 — map position (3876.6, 2891.5, -34.9)

Levian Two was an orange, inhospitable world that was located within the Inner Rim of the galaxy, near warlord Zsinj-controlled territory. It was the location of the New Republic's Beta Sector Base.
