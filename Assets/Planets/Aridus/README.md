# Aridus

**Continuity:** Canon  
**Source:** [Aridus](https://starwars.fandom.com/wiki/Aridus)
**Galaxy atlas:** system `Aridus`, Expansion Region, grid O-14 — map position (5491.9, -6312.6, -187.6)

Aridus was a planet located in the Aridus system, a star system in the Narvath sector of the Expansion Region along the Gamor Run. During the Clone Wars, it was under Separatist control and Republic High Command sent at least one commando squad to Aridus in hopes of coordinating with local freedom fighters.
