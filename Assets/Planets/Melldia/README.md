# Melldia

**Continuity:** Legends  
**Source:** [Melldia](https://starwars.fandom.com/wiki/Melldia)

Melldia was a planet located in the Melldia system of the Outer Rim Territories's Esstran sector. In 3950 BBY, the Sith Lord Darth Nyriss claimed to be "the destroyer of Melldia."

## Planetary data

- **Name:** Melldia
- **Region:** Outer Rim Territories
- **Sector:** Esstran sector
- **System:** Melldia system
