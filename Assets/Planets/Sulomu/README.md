# Sulomu

**Continuity:** Legends  
**Source:** [Sulomu](https://starwars.fandom.com/wiki/Sulomu)

Sulomu was an ice planet in the Ansion system, which was located in the Mid Rim's Churnis sector. Its atmosphere was freezing, rendering it uninhabitable.
