# Belukat

**Continuity:** Legends  
**Source:** [Belukat](https://starwars.fandom.com/wiki/Belukat)

Belukat was a planet in the Belukat system of the Expansion Region ruled by kings. It was said that Belukat's royal tomb builders were killed by the kings so that they would not be able to divulge the tomb's secrets to robbers.
