# Jinet

**Continuity:** Legends  
**Source:** [Jinet](https://starwars.fandom.com/wiki/Jinet)
**Galaxy atlas:** system `Jinet`, Expansion Region — map position (5612.8, -7537.1, -304.2)

Jinet was an uninhabited planet in the Jinet system of the Brak sector in the Expansion Region. The Alliance to Restore the Republic established a starfighter base on the planet shortly before the Battle of Yavin. The base was home to a squadron of BTL Y-wing starfighters.
