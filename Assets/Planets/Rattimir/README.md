# Rattimir

**Continuity:** Canon  
**Source:** [Rattimir](https://starwars.fandom.com/wiki/Rattimir)

Rattimir was a planet located in a star system next to Vardos, a world in the Jinata system of the Core Worlds within grid square L-9 of the Standard Galactic Grid. The girl Deeta Kardon was from Rattimir, but joined a Vardos Star Scouts troupe in Kestro City on Vardos during the reign of the Galactic Empire.

## Planetary data

- **Name:** Rattimir
- **Region:** Core Worlds
- **System:** Rattimir's star system
