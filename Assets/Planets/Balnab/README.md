# Balnab

**Continuity:** Canon  
**Source:** [Balnab](https://starwars.fandom.com/wiki/Balnab)
**Galaxy atlas:** system `Balnab`, Mid Rim, grid L-7 — map position (125.8, 3424.2, 29.4)

Balnab was a temperate planet located in the Bright Jewel sector of the Mid Rim, near Patitite Pattuna. During the Clone Wars, it served as a home to a group of alien castaways.
