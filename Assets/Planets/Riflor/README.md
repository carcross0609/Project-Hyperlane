# Riflor

**Continuity:** Canon  
**Source:** [Riflor](https://starwars.fandom.com/wiki/Riflor)
**Galaxy atlas:** system `Riflor`, Mid Rim, grid J-16 — map position (-2747.7, -10474.4, -146.8)

Riflor was a volcanic planet located in the Riflor system in the Narrant sector of the Mid Rim Territories, connected by the Cerean Reach hyperspace route to Cerea and Lorta. It was home to the Advozse species. On Riflor, volcanic eruptions frequently destroyed Advozsec settlements, so the Advozsec tended to care very little about material goods.
