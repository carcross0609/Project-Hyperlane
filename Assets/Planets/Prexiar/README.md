# Prexiar

**Continuity:** Legends  
**Source:** [Prexiar](https://starwars.fandom.com/wiki/Prexiar)

Prexiar was a planet located in the Steniplis sector of the Outer Rim Territories. The planet had great freshwater seas and vast jungles. The Pirates of Prexiar operated an outpost there.
