# Betha II

**Continuity:** Legends  
**Source:** [Betha II](https://starwars.fandom.com/wiki/Betha_II)
**Galaxy atlas:** system `Betha II`, Outer Rim, grid P-4 — map position (6373.4, 8654.1, 472.8)

Betha II was a barren, dry low-gravity planet covered in yellow-orange rock with very little atmospheric moisture. The planet was located in the Betha system in Corva sector, at the midpoint of the Daranc Run.
