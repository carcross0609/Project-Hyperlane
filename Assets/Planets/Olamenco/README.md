# Olamenco

**Continuity:** Legends  
**Source:** [Olamenco](https://starwars.fandom.com/wiki/Olamenco)

Olamenco was the third planet orbiting the star Stisste in the Saleucami system. Located in the Suolriep sector of the Outer Rim Territories, it was an airless rock.
