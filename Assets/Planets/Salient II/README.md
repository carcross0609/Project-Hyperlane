# Salient II

**Continuity:** Canon  
**Source:** [Salient II](https://starwars.fandom.com/wiki/Salient_II)
**Galaxy atlas:** system `Salient II`, Outer Rim, grid S-3 — map position (11289.5, 9211.5, -161.2)

Salient II was a planet located in the autonomous Salient system, on the edge the Corporate Sector. In 18 BBY, the planet, along with the rest of the system, resisted what they perceived as intrusion by the Galactic Empire in a hard-fought, prolonged campaign. Nevertheless, the planet's government was bombed into submission, despite several guerrilla groups forestalling the imposition of an occupying force
