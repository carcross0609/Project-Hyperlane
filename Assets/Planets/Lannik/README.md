# Lannik

**Continuity:** Canon  
**Source:** [Lannik](https://starwars.fandom.com/wiki/Lannik)
**Galaxy atlas:** system `Lannik`, Mid Rim, grid R-13 — map position (9155.6, -4957.7, 177.2)

Lannik was a planet with a long history of war that was located in the galaxy's Mid Rim and was the homeworld of the Lannik species.
