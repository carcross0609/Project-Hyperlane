# Tibrin

**Continuity:** Canon  
**Source:** [Tibrin](https://starwars.fandom.com/wiki/Tibrin)
**Galaxy atlas:** system `Tibrin`, Mid Rim, grid L-18 — map position (1073.7, -12023.0, 263.8)

Tibrin was an aquatic planet covered in phosphorescent seas with towering coral reefs as tall as the sky. It was located in the Tibrin system, a trinary star system on the edge of the Hadar sector in the Mid Rim. It was the homeworld of the Ishi Tib species.
