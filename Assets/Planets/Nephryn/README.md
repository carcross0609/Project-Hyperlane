# Nephryn

**Continuity:** Canon  
**Source:** [Nephryn](https://starwars.fandom.com/wiki/Nephryn)

Nephryn was a planet in the Nephryn system in the Prackla sector of the Expansion Region. The Nephryn Cloud Bread was a type of food made from the refined gases of the planet's stratosphere.

## Planetary data

- **Name:** Nephryn
- **Region:** Expansion Region
- **Sector:** Prackla sector
- **System:** Nephryn system
- **Coordinates:** O-8
- **Exports:** Nephryn Cloud Bread
