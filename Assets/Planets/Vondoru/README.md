# Vondoru

**Continuity:** Legends  
**Source:** [Vondoru](https://starwars.fandom.com/wiki/Vondoru)

Vondoru was a planet in the Unknown Regions. During the Galactic War between the Galactic Republic and the reconstituted Sith Empire, an Imperial fleet ambushed the Valor-class cruiser Intercessor over Vondoru and destroyed it.
