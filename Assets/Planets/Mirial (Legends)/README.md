# Mirial

**Continuity:** Legends  
**Source:** [Mirial/Legends](https://starwars.fandom.com/wiki/Mirial/Legends)
**Galaxy atlas:** system `Mirial`, Outer Rim, grid Q-4 — map position (8164.8, 8474.3, 284.4)

Mirial was a cold, dry planet located near the Hydian Way. It was the homeworld of the Mirialans, including Luminara Unduli.
