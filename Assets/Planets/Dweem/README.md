# Dweem

**Continuity:** Legends  
**Source:** [Dweem](https://starwars.fandom.com/wiki/Dweem)
**Galaxy atlas:** system `Dweem`, Outer Rim, grid T-9 — map position (13043.7, 152.5, -252.0)

Dweem was a planet in the Outer Rim Territories used as a base of operations for the Galactic Republic until abandoned because of the Order of the Terrible Glare. Around 60 BBY, Aqinos trained the Iron Knights on Dweem, where he hid with them during the later Great Jedi Purge.
