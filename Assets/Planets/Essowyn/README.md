# Essowyn

**Continuity:** Legends  
**Source:** [Essowyn](https://starwars.fandom.com/wiki/Essowyn)
**Galaxy atlas:** system `Essowyn`, Outer Rim — map position (-800.1, -12425.0, -641.4)

Essowyn was the only planet in the Saurton system. The planet was located in the Trax sector, situated between the Kanawyn and Greawyn asteroid belts.
