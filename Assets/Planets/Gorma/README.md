# Gorma

**Continuity:** Canon  
**Source:** [Gorma](https://starwars.fandom.com/wiki/Gorma)

Gorma was a world that at some point during the Galactic Civil War was liberated by the Alliance to Restore the Republic. It was located in the Gorma system in the Majoor sector of the Expansion Region.
