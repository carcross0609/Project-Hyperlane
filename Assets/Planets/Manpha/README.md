# Manpha

**Continuity:** Canon  
**Source:** [Manpha](https://starwars.fandom.com/wiki/Manpha)
**Galaxy atlas:** system `Manpha`, Outer Rim, grid K-20 — map position (-1195.1, -15214.1, 327.2)

Manpha was a wet and swampy planet located in Manpha system of the Seitia sector, a part of the Outer Rim Territories and the Western Reaches. Situated in grid square K-20 of the Standard Galactic Grid, it was located on the super-hyperroute known as the Corellian Trade Spine, which linked it to the Tureen and Zastiga systems. Manpha was the homeworld of the amphibious Shawda Ubb species, including the musician Rappertunie.
