# Vatleria

**Continuity:** Legends  
**Source:** [Vatleria](https://starwars.fandom.com/wiki/Vatleria)
**Galaxy atlas:** system `Vatleria`, Outer Rim, grid T-9 — map position (12607.4, 738.5, -47.6)

Vatleria was a dark and foggy planet located within the Vatleria system of the Outer Rim Territories. Long abandoned by its inhabitants, the world eventually became the site of an Imperial base in its stone ruins. By 0 BBY, the base was assaulted by the Rebel Four, an Alliance to Restore the Republic team, but they were defeated by machinations of the Sith Lord Darth Vader.
