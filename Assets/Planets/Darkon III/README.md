# Darkon III

**Continuity:** Legends  
**Source:** [Darkon III](https://starwars.fandom.com/wiki/Darkon_III)
**Galaxy atlas:** system `Darkon III`, Mid Rim, grid J-7 — map position (-1940.8, 3804.6, 11.2)

Darkon III was a planet of the Darkon system, within the Chaama sector, in the Mid Rim and Northern Dependencies regions of the galaxy. In 0 BBY, the corporate criminal Linkaas requested that his employee, the smuggler Dannen Lifehold, make a stop in Darkon III, before proceeding to his destination, the planet Dohu VII. This was in order for Linkaas to gain time to organize a trap on Dohu VII for the smuggler.
