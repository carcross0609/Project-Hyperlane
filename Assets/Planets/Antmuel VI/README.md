# Antmuel VI

**Continuity:** Legends  
**Source:** [Antmuel VI](https://starwars.fandom.com/wiki/Antmuel_VI)
**Galaxy atlas:** system `Antmuel VI`, Outer Rim, grid M-3 — map position (2116.9, 9397.7, 67.4)

Antmuel VI was a world that occupied the sixth orbital position within the Antmuel system, a part of the Chopani sector in the New Territories portion of the Outer Rim Territories.

Antmuel VI was the site of the Ch'hosk Cave Drawings that were discovered by the Human male xenoarchaeologist Doctor Angrail Ryhl at some point during his career. That discovery was later considered to be a remarkable find.
