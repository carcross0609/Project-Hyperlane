# Ord Radama

**Continuity:** Legends  
**Source:** [Ord Radama/Legends](https://starwars.fandom.com/wiki/Ord_Radama/Legends)
**Galaxy atlas:** system `Ord Radama`, Outer Rim, grid Q-5 — map position (7552.5, 7361.7, 158.2)

Ord Radama was a planet in the Radama Void of the Outer Rim Territories' Esstran sector. Once a world of marshes and wetlands, it was built up with cities and streets over the years. The planet was the homeworld of the Devlikk species.
