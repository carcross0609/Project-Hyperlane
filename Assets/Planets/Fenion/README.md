# Fenion

**Continuity:** Legends  
**Source:** [Fenion](https://starwars.fandom.com/wiki/Fenion)
**Galaxy atlas:** system `Fenion`, Outer Rim, grid P-7 — map position (7084.3, 3168.7, -27.8)

Fenion was an unaligned Outer Rim planet, near warlord Zsinj's territory. It was the only planet on the Night Caller agenda not visited by Wraith Squadron.
