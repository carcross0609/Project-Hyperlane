# Tei-Untis

**Continuity:** Canon  
**Source:** [Tei-Untis](https://starwars.fandom.com/wiki/Tei-Untis)
**Galaxy atlas:** system `Tei-Untis`, Other, grid M-20 — map position (2514.0, -15540.5, 673.4)

Tei-Untis was a planet inhabited by Zabraks that was located in the Tei-Untis system of the Core Worlds and the Interior. It was situated in grid square K-10 of the Standard Galactic Grid. A kleptocracy, it was governed by thieves. Some of the most skilled pickpockets in the galaxy were trained at the Tei-Untisian School of Ribbons.
