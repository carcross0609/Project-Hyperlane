# Lacca

**Continuity:** Legends  
**Source:** [Lacca](https://starwars.fandom.com/wiki/Lacca)

Lacca was the second planet orbiting the star Striar in the Malastare system. Located in the Dustig sector of the Mid Rim, it was a volcanic rock.
