# Menias

**Continuity:** Legends  
**Source:** [Menias](https://starwars.fandom.com/wiki/Menias)
**Galaxy atlas:** system `Menias`, Core Worlds — map position (433.9, -3575.1, 50.1)

Menias was the first planet in the Metellos system, a star system in the Corusca sector of the Core Worlds. It was a searing rock with no moons.
