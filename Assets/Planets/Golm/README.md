# Golm; Bothawui Prime

**Continuity:** Legends  
**Source:** [Golm](https://starwars.fandom.com/wiki/Golm)
**Galaxy atlas:** system `Golm`, Mid Rim — map position (7687.6, -4388.2, -77.3)

Golm, also known as Bothawui Prime, was a planet in the Both system. A purple gas giant, it was the fourth planet in the star system and was orbited by 23 moons, as well as an asteroid belt.
