# Kintoni

**Continuity:** Legends  
**Source:** [Kintoni/Legends](https://starwars.fandom.com/wiki/Kintoni/Legends)
**Galaxy atlas:** system `Kintoni`, Outer Rim — map position (140.8, 7153.5, 299.6)

Kintoni was a planet in the Outer Rim Territories that contained a single city with several towns, the rest being farmland. It contained Tinegris Street. New Republic forces occupied a former Imperial garrison on Kintoni circa 4 ABY, where Governor Barkale was held prisoner. Mara Jade infiltrated the base and assassinated Barkale on the behalf of Palpatine for stealing credits over the past ten years.
