# Ulicia

**Continuity:** Legends  
**Source:** [Ulicia](https://starwars.fandom.com/wiki/Ulicia)
**Galaxy atlas:** system `Ulicia`, Outer Rim, grid S-3 — map position (11053.3, 9347.8, -61.2)

Ulicia was an industrial planet located in the Ulicia system of the Outer Rim Territories' Corporate Sector, which was governed by the Corporate Sector Authority. It was positioned along the hyperlane known as the Shaltin Tunnels. In 0 ABY, the CSA executive Hart-and-Parn Gorra-Fiolla recovered a prisoner named Naven Crel from the headquarters of the Commex corporation located at Ulicia.
