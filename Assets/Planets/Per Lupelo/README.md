# Per Lupelo

**Continuity:** Legends  
**Source:** [Per Lupelo](https://starwars.fandom.com/wiki/Per_Lupelo)
**Galaxy atlas:** system `Per Lupelo`, Inner Rim, grid L-8 — map position (1314.7, 2315.0, -39.1)

Per Lupelo was a cosmopolitan planet in the Per Lupelo system. It was dotted by a number of clean cities and bodies of water, and it was also dotted with a number of mountain ranges. A crime organization led by the gangster Raze had its headquarters on the planet at the height of the Galactic Civil War.

The planet was part of the Galactic Empire and was used as a gathering point for Imperial cargo carriers to jump into hyperspace. A Rebel spy system infiltrated Raze's crime syndicate and slipped the Imperial information to Rebel Intelligence, starting the Battle of Per Lupelo.
