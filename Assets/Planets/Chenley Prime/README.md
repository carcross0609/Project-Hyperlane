# Chenley Prime

**Continuity:** Canon  
**Source:** [Chenley Prime](https://starwars.fandom.com/wiki/Chenley_Prime)

Chenley Prime was a gas giant that contained Shingcu Station, the lair of Boolan. Keeve Trennis, Sskeer, Terec, Ceret, OrbaLin, Lourna Dee, and Tey Sirrek ventured to this station to save a Yacombe girl.
