# Zyluria

**Continuity:** Legends  
**Source:** [Zyluria](https://starwars.fandom.com/wiki/Zyluria)
**Galaxy atlas:** system `Zyluria`, Mid Rim, grid L-18 — map position (63.5, -12007.1, 422.6)

Zyluria was a world located in the Zyluria system of the Juvex sector, a part of the Senex-Juvex region in the Western Reaches portion of the Mid Rim. A hyperlane linked it to the Carsanza system. Zyluria's surface featured gentle plains, and it was the homeworld of the Zylurians, a sentient species that, by 43 ABY, had long served the aristocratic Ancient Houses of the Senex-Juvex.
