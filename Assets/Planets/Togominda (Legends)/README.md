# Togominda

**Continuity:** Legends  
**Source:** [Togominda/Legends](https://starwars.fandom.com/wiki/Togominda/Legends)
**Galaxy atlas:** system `Togominda`, Outer Rim, grid K-18 — map position (-1243.5, -13466.7, 345.9)

Togominda was a world situated in the Outer Rim Territories' Yarith sector. It featured salt geysers, which attracted both free-traders and pilots to the world. Lynciro Corporation owned a private retreat on Togominda known as "Master of Coins."
