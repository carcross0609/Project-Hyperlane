# Thearterra

**Continuity:** Legends  
**Source:** [Thearterra/Legends](https://starwars.fandom.com/wiki/Thearterra/Legends)
**Galaxy atlas:** system `Thearterra`, Unknown Regions, grid E-8 — map position (-9306.6, 2034.9, -285.0)

Thearterra was an obscure planet located in the S-K system of the Unknown Regions' Chiss Space. A hyperlane linked the world to the Avidich system. The surface of Thearterra was constantly racked by volcanoes, hailstorms, and groundquakes. The world was part of the Chiss sentient species' government of the Chiss Ascendancy.
