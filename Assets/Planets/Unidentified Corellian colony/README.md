# Unidentified Corellian colony

**Continuity:** Legends  
**Source:** [Unidentified Corellian colony](https://starwars.fandom.com/wiki/Unidentified_Corellian_colony)

This Corellian colony was the homeworld of the criminal Sufar. In 2 BBY, the colony exiled him for a series of murders he committed.
