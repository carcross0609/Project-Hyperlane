# Ansion

**Continuity:** Canon  
**Source:** [Ansion](https://starwars.fandom.com/wiki/Ansion)
**Galaxy atlas:** system `Ansion`, Mid Rim, grid I-6 — map position (-3099.7, 4500.7, 192.7)

Ansion was a planet located in the Ansion system, a star system located in the Churnis sector of the Mid Rim Territories that was the junction of the Namadii Corridor hyperspace route and another route that ran from Keitum to the Rago system.

A border dispute occurred on Ansion during the Separatist Crisis, which, along with turmoil on the planet Ando, was enough to stagger the galaxy.
