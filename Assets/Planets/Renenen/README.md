# Renenen

**Continuity:** Legends  
**Source:** [Renenen](https://starwars.fandom.com/wiki/Renenen)

Renenen was the third planet orbiting the star Rek in the Guter Wade system. Located in the Trilon sector of the Outer Rim Territories, it was a poisoned rock.
