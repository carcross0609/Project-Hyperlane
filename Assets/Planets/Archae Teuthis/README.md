# Archae Teuthis

**Continuity:** Legends  
**Source:** [Archae Teuthis](https://starwars.fandom.com/wiki/Archae_Teuthis)
**Galaxy atlas:** system `Archae Teuthis`, Other, grid O-14 — map position (5168.7, -7016.1, -109.9)

Archae Teuthis was the Sulituan homeworld. It was covered in deep oceans and the Sulituans lived in large float-cities built of phrnnoc, a type of coral.
