# Harrandarr

**Continuity:** Legends  
**Source:** [Harrandarr](https://starwars.fandom.com/wiki/Harrandarr)
**Galaxy atlas:** system `Harrandarr`, Outer Rim — map position (4349.6, 6189.0, -113.9)

Harrandarr was a planet located in the Harrandarr system, a part of the Outer Rim Territories' Bosph sector. It was the homeworld of the sentient Buzchub species. Und'l, a Buzchub who worked for Galactic Empire sympathizers on the Expansion Region astronomical object Roldalna shortly after the establishment of the New Republic in 4 ABY, hailed from Harrandarr.
