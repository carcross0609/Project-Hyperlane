# Deris-plata

**Continuity:** Canon  
**Source:** [Deris-plata](https://starwars.fandom.com/wiki/Deris-plata)

Deris-plata was a planet located in the Eucer sector within the Mid Rim Territories. Incognito Cassian Andor claimed to be from Deris-plata during his time on Niamos. In reality, Andor was from Kenari.

## Planetary data

- **Name:** Deris-plata
- **Region:** Mid Rim Territories
- **Sector:** Eucer sector
- **System:** Deris-plata system
- **Coordinates:** R-7
