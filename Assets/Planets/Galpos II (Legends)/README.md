# Galpos II

**Continuity:** Legends  
**Source:** [Galpos II/Legends](https://starwars.fandom.com/wiki/Galpos_II/Legends)
**Galaxy atlas:** system `Galpos II`, Outer Rim, grid S-15 — map position (11337.3, -8220.0, -413.2)

Galpos II was a desolate planet in the Abrion sector of the Outer Rim Territories. It was suspected to be a base for pirate groups operating in the sector. The pirate vessel GrimDeath I was once tracked traveling to the world.
