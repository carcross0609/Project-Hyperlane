# Dadrus

**Continuity:** Legends  
**Source:** [Dadrus](https://starwars.fandom.com/wiki/Dadrus)
**Galaxy atlas:** system `Dadrus`, Outer Rim, grid N-6 — map position (4334.5, 4560.0, -168.0)

Dadrus was a gas giant that was orbited by five moons. It was the third planet in the Marcellus system, which resided in the Marcellus Nebula. Dadrus circled the yellow sun Marcellus. The gas giant, along with the rest of the Marcellus system, was located in the Meerian sector of the New Territories portion of the Outer Rim Territories.
