# Hishyim

**Continuity:** Legends  
**Source:** [Hishyim](https://starwars.fandom.com/wiki/Hishyim)
**Galaxy atlas:** system `Hishyim`, Outer Rim, grid S-15 — map position (10611.9, -7648.4, -406.0)

Hishyim was a planet covered by a vast desert, located in the Abrion sector of the Outer Rim Territories.

It was the site of an Imperial patrol station during the Thrawn crisis.
