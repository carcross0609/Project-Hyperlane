# Denash

**Continuity:** Canon  
**Source:** [Denash](https://starwars.fandom.com/wiki/Denash)
**Galaxy atlas:** system `Denash`, Outer Rim — map position (-749.6, 8402.3, 366.5)

Denash was a planet in the Outer Rim Territories' Batonn sector. During the Imperial Era, it was governed by Governor Wistran. The planet was home to an insurgent movement. During the Batonn sector insurgency, the Denash insurgents were defeated by Admiral Kinshara.
