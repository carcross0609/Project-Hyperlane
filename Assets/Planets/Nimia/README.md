# Nimia

**Continuity:** Legends  
**Source:** [Nimia](https://starwars.fandom.com/wiki/Nimia)
**Galaxy atlas:** system `Nimia`, Hutt Space, grid S-9 — map position (11710.3, 1470.0, -228.6)

Nimia was a planet located in the Hutt Space between Klatooine and Yoribuunt. It was located near the Si'Klaata Cluster. A lackluster industrial world, Nimia was occasionally used as a meeting place between Hutt servants and outlanders who had failed to attract much favor with the Hutts.
