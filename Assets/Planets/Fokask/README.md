# Fokask

**Continuity:** Legends  
**Source:** [Fokask](https://starwars.fandom.com/wiki/Fokask)
**Galaxy atlas:** system `Fokask`, Outer Rim, grid S-13 — map position (11561.3, -4749.6, 416.5)

Fokask was a planet within the Fokask system in Outer Rim Territories. It was home to one of Han Solo's old smuggling friends. This retired smuggler sent Solo a copy of the Fokask Banner, which had a rather slanderous article written about Chief of State Leia Organa Solo.
