# Beckoning Call Starr 3

**Continuity:** Legends  
**Source:** [Beckoning Call Starr 3](https://starwars.fandom.com/wiki/Beckoning_Call_Starr_3)
**Galaxy atlas:** system `Beckoning Call Starr 3`, Inner Rim, grid O-10 — map position (4831.3, -220.2, 248.0)

Beckoning Call Starr 3 was the third planet of the Beckoning Call Starr system, located in the Slice portion of the Inner Rim. The planet had a reputation for beautiful women, with which the smuggler Han Solo was familiar.
