# Pencael IV

**Continuity:** Legends  
**Source:** [Pencael IV](https://starwars.fandom.com/wiki/Pencael_IV)
**Galaxy atlas:** system `Pencael IV`, Colonies, grid M-12 — map position (2980.1, -4128.3, -131.4)

Pencael IV was an Imperial planet in the Pencael system. It was the homeworld of the wealthy Cholus family, including Imperial Commander Senn Cholus and Rebel Scandium Team member Aven Cholus.
