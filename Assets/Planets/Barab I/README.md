# Barab I

**Continuity:** Canon  
**Source:** [Barab I](https://starwars.fandom.com/wiki/Barab_I)
**Galaxy atlas:** system `Barab I`, Outer Rim, grid U-12 — map position (13571.6, -4437.8, 507.3)

Barab I, also known simply as Barab, was an irradiated planet in the Barab system in the Albanin sector of the Outer Rim Territories. It was located along the Triellus Trade Route between Teth and Dubrava, in grid square U-12 on the Standard Galactic Grid and was the homeworld of the Barabel species.
