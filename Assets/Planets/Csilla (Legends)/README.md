# Csilla

**Continuity:** Legends  
**Source:** [Csilla/Legends](https://starwars.fandom.com/wiki/Csilla/Legends)
**Galaxy atlas:** system `Csilla`, Unknown Regions, grid F-8 — map position (-8893.8, 1832.0, 97.4)

Csilla, the homeworld of the Chiss, was a cold world of glaciers and snowy wastes located deep within Chiss Space, and served as the capital of the Chiss Ascendancy.
