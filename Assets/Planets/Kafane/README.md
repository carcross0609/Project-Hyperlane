# Kafane

**Continuity:** Legends  
**Source:** [Kafane](https://starwars.fandom.com/wiki/Kafane)
**Galaxy atlas:** system `Kafane`, Hutt Space, grid S-9 — map position (11683.5, 743.2, 182.8)

Kafane was a poor agricultural planet that was located within the Kafane system of the galaxy's Hutt Space region. Kafane was connected to the worlds of Nimia and Ulmatra by the hyperlane called the Dead Road.
