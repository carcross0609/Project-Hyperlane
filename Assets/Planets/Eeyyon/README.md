# Eeyyon

**Continuity:** Legends  
**Source:** [Eeyyon](https://starwars.fandom.com/wiki/Eeyyon)
**Galaxy atlas:** system `Eeyyon`, Mid Rim — map position (7586.1, -8628.3, -132.7)

Eeyyon was the Mid Rim planet saved by the Jedi prior to the Clone Wars. It was inhabited by a species of tall, pale-skinned humanoids. Native of Eeyyon, Teluron Thacker swore to aid the Jedi Order wherever he was, in gratitude for the help given to his homeworld.
