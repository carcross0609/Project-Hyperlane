# Kaisa

**Continuity:** Legends  
**Source:** [Kaisa](https://starwars.fandom.com/wiki/Kaisa)
**Galaxy atlas:** system `Kaisa`, Outer Rim, grid P-3 — map position (6668.7, 10137.7, 205.1)

Kaisa was a planet that was once home to the Buro species. However, it was accidentally driven to extinction by the actions of Human geologists.
