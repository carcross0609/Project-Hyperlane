# Phaseera

**Continuity:** Legends  
**Source:** [Phaseera](https://starwars.fandom.com/wiki/Phaseera)
**Galaxy atlas:** system `Phaseera`, Mid Rim, grid P-8 — map position (6802.8, 1593.3, -84.5)

Phaseera was a manufacturing planet that was the location of a battle near the end of the New Sith Wars. It had been occupied by the Galactic Republic before the conflict, but after the Republic defeat, it became Sith occupied. Its terrain included jungles, valleys, and plateaus. It orbited a yellow sun, and cydera trees grew on it.
