# Teevan

**Continuity:** Legends  
**Source:** [Teevan (planet)](https://starwars.fandom.com/wiki/Teevan_%28planet%29)
**Galaxy atlas:** system `Teevan`, Outer Rim, grid P-5 — map position (6942.9, 6736.9, -244.4)

Teevan was a planet with silvery seas located within the Teevan system of the Outer Rim Territories. It was the homeworld of the Teevan species. Jedi Padawan Tru Veld came from this world.
