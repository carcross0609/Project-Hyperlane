# Halowan

**Continuity:** Legends  
**Source:** [Halowan](https://starwars.fandom.com/wiki/Halowan)
**Galaxy atlas:** system `Halowan`, Inner Rim — map position (2473.7, 1263.4, -128.7)

Halowan was a barren planet in the Fakir sector of the Bakchou arm. It was the location of Holowan Laboratories, the creators of the IG-series droids.
