# Katchan

**Continuity:** Legends  
**Source:** [Katchan](https://starwars.fandom.com/wiki/Katchan)

Katchan was a world that was located on the edge the Outer Rim Territories.

The royal family of Katchan owned an A9G-series Data Storage Unit, until it was stolen by pirates.
