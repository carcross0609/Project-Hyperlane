# Guiteica

**Continuity:** Canon  
**Source:** [Guiteica](https://starwars.fandom.com/wiki/Guiteica)
**Galaxy atlas:** system `Guiteica`, Wild Space, grid J-4 — map position (-2645.9, 8762.2, 124.7)

Guiteica was a planet within the Guiteica system in the Kadok Regions of Wild Space that was the homeworld of the Bitthævrian species. Historically, Kaleesh warlords, from the neighboring planet Kalee, took roggwarts from Guiteica as trophies.
