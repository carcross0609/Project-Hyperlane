# Stygeon Prime

**Continuity:** Canon  
**Source:** [Stygeon Prime](https://starwars.fandom.com/wiki/Stygeon_Prime)
**Galaxy atlas:** system `Stygeon Prime`, Outer Rim, grid Q-7 — map position (8584.0, 4346.2, -94.8)

Stygeon Prime, also known simply as Stygeon, was a mountainous, snowy planet located in the Stygeon system of the Outer Rim Territories' Nuiri sector. The world's blizzard conditions made it the perfect location for a prison, as prisoners attempting escape would not survive outside the prison walls unless they could use a local tibidee to fly them to safety.
