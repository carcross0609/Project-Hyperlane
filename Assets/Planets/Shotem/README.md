# Shotem

**Continuity:** Legends  
**Source:** [Shotem](https://starwars.fandom.com/wiki/Shotem)

The planet Shotem was the mining site for specialized lightsaber crystals which pulsed and caused the lightsaber to be more powerful. The Jedi of the planet were known to wear visors, robes, gloves, and boots which were unique to the planet in addition to using a different type of lightsaber hilt to that of other Jedi.

## Planetary data

- **Name:** Shotem
- **Region:** Colonies
- **System:** Shotem system
- **Coordinates:** J-13
- **Exports:** Lightsaber crystals
- **Affiliation:** Jedi Order
