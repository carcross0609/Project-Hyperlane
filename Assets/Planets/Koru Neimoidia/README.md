# Koru Neimoidia

**Continuity:** Canon  
**Source:** [Koru Neimoidia](https://starwars.fandom.com/wiki/Koru_Neimoidia)
**Galaxy atlas:** system `Koru Neimoidia`, Colonies — map position (3103.0, -829.1, -183.2)

Koru Neimoidia was a Purse World located in the Colonies region of the galaxy. After being imprisoned by the Galactic Empire, the former journalist Caern Adan hoped that a new warden would be appointed and release him back into the streets of Koru Neimoidia.
