# Elegasso

**Continuity:** Legends  
**Source:** [Elegasso](https://starwars.fandom.com/wiki/Elegasso)

Elegasso was a minor planet under the control of the Galactic Empire. In 0 ABY, a local election was blatantly rigged, drawing the attention of the Hand of Judgment stormtrooper team and Imperial agent Mara Jade.
