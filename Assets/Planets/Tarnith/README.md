# Tarnith

**Continuity:** Legends  
**Source:** [Tarnith](https://starwars.fandom.com/wiki/Tarnith)

Tarnith was an Outer Rim Territories world situated in the Ojoster sector. It was a resource world for the planet Taris, and in 3966 BBY, it began to be threatened by the Mandalorian Neo-Crusader warriors. Subsequently the Galactic Republic established a protective security cordon, the Jebble-Vanquo-Tarnith line, around Taris. The Mandalorians nevertheless eventually established both a staging area and an armor-and-weapons-producing War Forge on Tarnith.
