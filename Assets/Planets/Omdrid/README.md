# Omdrid

**Continuity:** Legends  
**Source:** [Omdrid](https://starwars.fandom.com/wiki/Omdrid)
**Galaxy atlas:** system `Omdrid`, Outer Rim — map position (9406.0, -10765.0, -449.7)

Omdrid was a planet that occupied the seventh orbit around the star Beheboth. It was the outermost celestial body in the Beheboth system, a star system that was located in the Sanbra sector, a part of the Trailing Sectors in the Outer Rim Territories. Like its inner neighbor Derenath, Omdrid was classified as an ice planet and had no moons.
