# Celanon

**Continuity:** Legends  
**Source:** [Celanon/Legends](https://starwars.fandom.com/wiki/Celanon/Legends)
**Galaxy atlas:** system `Celanon`, Outer Rim, grid O-6 — map position (5536.2, 5834.5, -249.3)

Celanon was an important spaceport on the Celanon Spur, in the Outer Rim Territories, and was the Nalroni homeworld.
