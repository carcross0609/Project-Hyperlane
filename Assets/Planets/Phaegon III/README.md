# Phaegon III

**Continuity:** Legends  
**Source:** [Phaegon III](https://starwars.fandom.com/wiki/Phaegon_III)
**Galaxy atlas:** system `Phaegon III`, Outer Rim, grid N-17 — map position (3221.6, -11076.9, -94.4)

The planet Phaegon III was in the Phaegon system in the Grumani sector. Its largest moon was the main source of Lignan ore. In 5000 BBY, Sith Lord Naga Sadow ordered that the Lignan be mined, and Saes Rrogon and Yaru Korsin led a Sith force to the moon shortly before the Battle of Kirrek.
