# Metellos

**Continuity:** Legends  
**Source:** [Metellos/Legends](https://starwars.fandom.com/wiki/Metellos/Legends)
**Galaxy atlas:** system `Metellos`, Core Worlds, grid K-9 — map position (-202.6, 18.4, -18.9)

Metellos was the fourth of seven planets in the Metellos system of the Corusca sector in the Core Worlds region. The planet orbited one star, also called Metellos, and in turn was orbited by three moons.
