# Mestare

**Continuity:** Legends  
**Source:** [Mestare](https://starwars.fandom.com/wiki/Mestare)

Mestare was a planet where unique lightsaber crystals were mined. It was said that lightsabers which utilized these crystals could cut through cortosis, a lightsaber-resistant metal. The unique crystals were also known to make the lightsaber blades curved, similar to ancient Jedi katanas. Mestare Jedi also wore protective armor for an unknown reason.

## Planetary data

- **Name:** Mestare
- **Coordinates:** Canon-only
- **Exports:** Lightsaber crystals
- **Affiliation:** Jedi Order
