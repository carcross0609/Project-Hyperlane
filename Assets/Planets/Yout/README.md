# Yout

**Continuity:** Canon  
**Source:** [Yout](https://starwars.fandom.com/wiki/Yout)
**Galaxy atlas:** system `Yout`, Mid Rim, grid L-7 — map position (12.2, 4164.0, 166.8)

Yout was a planet located in the Yout system, which was in the Mid Rim Territories' Qiilura sector. It was situated in grid square L-7 of the Standard Galactic Grid and had at least twelve moons. located in the Yout system. In 22 BBY, the assassin droid KRONOS-327, an employee of the crime lord Ziro the Hutt, returned to Ziro's Palace on the planet Coruscant after an unsuccessful mission to the twelfth moon of Yout. When KRONOS-327 reported the failure to Ziro, the Hutt sentenced the droid to be scrapped.
