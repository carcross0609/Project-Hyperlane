# Harbin-re

**Continuity:** Legends  
**Source:** [Harbin-re](https://starwars.fandom.com/wiki/Harbin-re)

Harbin-re was a planet located in the Harbin-re system of the Inner Rim. It was famous for productions of operas from the Neoclassical period, including several compositions favored by the Galactic Emperor Palpatine. On the date 35:10:16, the Harbin-re opera was mentioned in an Imperial HoloVision news report.
