# Nam Chorios

**Continuity:** Canon  
**Source:** [Nam Chorios](https://starwars.fandom.com/wiki/Nam_Chorios)
**Galaxy atlas:** system `Nam Chorios`, Outer Rim, grid R-6 — map position (9543.3, 4567.0, 191.2)

Nam Chorios was a planet located in the galaxy's Outer Rim Territories that housed both an Imperial mining colony and prison facility by the fifth year of Darth Sidious' reign as Emperor. The primary star in its planetary system provided barely enough sunshine to illuminate Nam Chorios properly, conferring it a bleak appearance. For that reason, Nam Chorios was considered too cold and unwelcoming by human standards.
