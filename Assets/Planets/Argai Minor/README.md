# Argai Minor

**Continuity:** Canon  
**Source:** [Argai Minor](https://starwars.fandom.com/wiki/Argai_Minor)
**Galaxy atlas:** system `Argai Minor`, Colonies, grid M-9 — map position (2114.6, 787.4, -69.3)

Argai Minor was a terrestrial planet. The Galactic Empire had forces within the Treinhaus Citadel on Argai Minor, and when the New Republic attacked the citadel, the Barma Battle Group sent Meteor Squadron, Hail Squadron, and Vanguard Squadron to support their ground forces.
