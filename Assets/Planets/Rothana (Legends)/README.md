# Rothana

**Continuity:** Legends  
**Source:** [Rothana/Legends](https://starwars.fandom.com/wiki/Rothana/Legends)
**Galaxy atlas:** system `Rothana`, Outer Rim, grid T-15 — map position (12874.5, -8337.4, 588.8)

Rothana was a remote planet in the Rothana system located in Quiberon sector, near the edge of the Outer Rim Territories and Wild Space, most famous for being the headquarters of Rothana Heavy Engineering and the source of military materiel for the Grand Army of the Republic during the Clone Wars.
