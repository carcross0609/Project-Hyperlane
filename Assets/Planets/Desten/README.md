# Desten

**Continuity:** Legends  
**Source:** [Desten](https://starwars.fandom.com/wiki/Desten)

Desten was an airless rock planet with five moons that occupied the fifth orbital position around the star Abo. It was located within the Lehon system, a part of the Unknown Regions' area known as the Tempered Wastes.
