# Vjun

**Continuity:** Legends  
**Source:** [Vjun/Legends](https://starwars.fandom.com/wiki/Vjun/Legends)
**Galaxy atlas:** system `Vjun`, Outer Rim, grid Q-6 — map position (8193.8, 4708.3, -39.4)

Vjun (or Vijjun) was a dark, almost lifeless planet in the Vjun system, known for its acidic rainfalls. It was also renowned for its expensive hand-woven tunics. It was the location of Bast Castle, a fortress used by Count Dooku, and later a place where Darth Vader studied the dark side of the Force.
