# Gorobei

**Continuity:** Legends  
**Source:** [Gorobei/Legends](https://starwars.fandom.com/wiki/Gorobei/Legends)
**Galaxy atlas:** system `Gorobei`, Inner Rim — map position (1243.4, -6097.3, 13.8)

Gorobei was a planet located in the Inner Rim's Gorobei system. It was the homeworld of the sentient humanoid Frenk species, including the bounty hunters Rumi Paramita and Twazzi.
