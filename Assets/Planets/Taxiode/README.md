# Taxiode

**Continuity:** Legends  
**Source:** [Taxiode](https://starwars.fandom.com/wiki/Taxiode)

Taxiode was a toxic rock planet that lacked moons and occupied the third closest orbital position to the star Abo. It was located within the Lehon system, a part of the Unknown Regions' area known as the Tempered Wastes.
