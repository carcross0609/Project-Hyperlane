# Zhanox

**Continuity:** Canon  
**Source:** [Zhanox](https://starwars.fandom.com/wiki/Zhanox)
**Galaxy atlas:** system `Zhanox`, Outer Rim, grid K-18 — map position (-1337.4, -12808.6, -201.5)

Zhanox was a mining planet located in the Anoat sector of the galaxy. Ugnaught miners were known to work there, although they feared the presence of spiny nexus. During the Iron Blockade, one Zhanox mining outpost requested specific off-world supplies to be delivered by a young smuggler.
