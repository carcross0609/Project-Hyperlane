# Malagarr

**Continuity:** Legends  
**Source:** [Malagarr/Legends](https://starwars.fandom.com/wiki/Malagarr/Legends)
**Galaxy atlas:** system `Malagarr`, Wild Space, grid V-8 — map position (15076.4, 2434.4, -430.5)

Malagarr was located in Wild Space. Its primary terrain was red sand. It was home to droids of Q-7N's type. In 0 ABY, the Galactic Empire made an incursion there.
