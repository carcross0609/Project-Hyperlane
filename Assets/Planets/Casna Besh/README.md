# Casna Besh

**Continuity:** Legends  
**Source:** [Casna Besh](https://starwars.fandom.com/wiki/Casna_Besh)
**Galaxy atlas:** system `Casna Besh`, Wild Space, grid S-15 — map position (11414.5, -8715.5, 155.7)

Casna Besh was the tenth planet in the Kamino system. It was an enormous gas giant orbited by a staggering 43 moons and captured wandering comets and asteroids at a rate of roughly two every millennium.
