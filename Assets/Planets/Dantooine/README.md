# Dantooine

**Continuity:** Canon  
**Source:** [Dantooine](https://starwars.fandom.com/wiki/Dantooine)
**Galaxy atlas:** system `Dantooine`, Outer Rim, grid L-4 — map position (14.7, 8378.3, 160.8)

Dantooine was a planet in the Dantooine system, in the Raioballo sector of the Outer Rim Territories' northern New Territories region. Dantooine was affiliated with both the Galactic Republic and later, the Galactic Empire.
