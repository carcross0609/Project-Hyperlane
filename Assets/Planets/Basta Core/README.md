# Basta Core

**Continuity:** Canon  
**Source:** [Basta Core](https://starwars.fandom.com/wiki/Basta_Core)

Basta Core was a frigid scrub-covered planet that possessed blue vegetation. In 21 ABY Enric Pryde, Viceprex Coromun and a group of CSA troopers participated in a mission to eliminate a syndicate of insurgents and capture a cache of arms.
