# Anchoron

**Continuity:** Legends  
**Source:** [Anchoron](https://starwars.fandom.com/wiki/Anchoron)
**Galaxy atlas:** system `Anchoron`, Outer Rim, grid M-18 — map position (2503.6, -12307.3, 272.8)

Anchoron was planet in the Anchoron system of the Mayagil sector. The Human Anchoroni were known for their flowery speech, genteel decorum, and politeness.
