# Udrin Cara

**Continuity:** Legends  
**Source:** [Udrin Cara](https://starwars.fandom.com/wiki/Udrin_Cara)

Udrin Cara was a secret Imperial military design center in the Mid Rim. Jeres Moridon was stationed there as a researcher, where he was exposed to Maladeria II, a toxic gas that was being researched at the facility for possible military applications.
