# Hebeth

**Continuity:** Legends  
**Source:** [Hebeth](https://starwars.fandom.com/wiki/Hebeth)
**Galaxy atlas:** system `Hebeth`, Outer Rim — map position (12009.8, 1571.6, -181.0)

Hebeth was a moonless planet that occupied the third orbit around the star Beheboth in the Beheboth system, which was located in the Sanbra sector, a part of the Trailing Sectors portion of the Outer Rim Territories. Hebeth's surface consisted of molten rock.
