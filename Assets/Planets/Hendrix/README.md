# Hendrix

**Continuity:** Legends  
**Source:** [Hendrix](https://starwars.fandom.com/wiki/Hendrix)

Hendrix was a world located in the Iska sector of the Mid Rim. Prior to the Battle of Hoth, Han Solo planned to run weapons from Minoth to Hendrix for the Rebel Alliance.

## Planetary data

- **Name:** Hendrix
- **Region:** Mid Rim
- **Sector:** Iska sector
- **System:** Hendrix system
