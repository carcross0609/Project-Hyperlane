# Draenell's Point

**Continuity:** Legends  
**Source:** [Draenell's Point](https://starwars.fandom.com/wiki/Draenell%27s_Point)
**Galaxy atlas:** system `Draenell's Point`, Outer Rim — map position (7083.0, 6687.4, 30.3)

Draenell's Point was an agriworld in the Trax sector in the Mid Rim. The planet supplied food to both sides during the Galactic Civil War.
