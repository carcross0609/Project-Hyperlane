# Vilimia

**Continuity:** Legends  
**Source:** [Vilimia](https://starwars.fandom.com/wiki/Vilimia)
**Galaxy atlas:** system `Vilimia`, Core Worlds, grid L-9 — map position (435.4, 436.5, -60.9)

Vilimia was the fourth planet that orbited the sun Velus. The planet was located within the Velus system of the Northern Dependencies portion of the Core Worlds. Vilimia was a gas giant with thirteen moons. The planet, along with the rest of its system, was located along the Shawken Spur hyperlane, connecting it to the Shawken and Thokos systems. The Velus system, and therefore Vilimia itself, was additionally connected by another hyperlane to the Scipio system.
