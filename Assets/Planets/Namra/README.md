# Namra

**Continuity:** Legends  
**Source:** [Namra](https://starwars.fandom.com/wiki/Namra)
**Galaxy atlas:** system `Namra`, Expansion Region — map position (6802.9, -2397.7, 102.7)

Namra was the second-largest gas giant of the system. A yellow and orange planet, Namra had ten moons, four of which were asteroids. The remaining moons were relatively the same size and composition, with thin atmospheres and a cratered coating of ice.
