# Spunchina

**Continuity:** Legends  
**Source:** [Spunchina](https://starwars.fandom.com/wiki/Spunchina)

Spunchina was a planet in Wild Space known for its wild orgies. Jabba Desilijic Tiure once participated in one of these orgies and survived.
