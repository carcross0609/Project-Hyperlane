# Yugami

**Continuity:** Legends  
**Source:** [Yugami](https://starwars.fandom.com/wiki/Yugami)
**Galaxy atlas:** system `Yugami`, Outer Rim, grid L-19 — map position (558.8, -14050.0, -570.1)

Yugami was a planet located within the Yugami system of the Outer Rim Territories. Its people were in a constant state of conflict with the Pursian species of Pursin.
