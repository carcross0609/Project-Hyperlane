# Mogoshyn

**Continuity:** Legends  
**Source:** [Mogoshyn](https://starwars.fandom.com/wiki/Mogoshyn)
**Galaxy atlas:** system `Mogoshyn`, Outer Rim, grid P-5 — map position (7255.6, 6791.6, 145.5)

Mogoshyn was a run-down industrial world located in the Mogoshyn system, a part of the Gordian Reach sector in the Trans-Hydian portion of the Outer Rim Territories. The world lay between the Betshish and Kushibah systems on the Pinooran Spur hyperlane.
