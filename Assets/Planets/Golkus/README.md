# Golkus

**Continuity:** Legends  
**Source:** [Golkus](https://starwars.fandom.com/wiki/Golkus)
**Galaxy atlas:** system `Golkus`, Colonies — map position (3283.4, -3275.9, 8.9)

Golkus was a planet between Carratos and Coruscant. Akanah Norand Goss Pell stopped there to get false identification papers from Talon Karrde's organization before she first met Luke Skywalker on Coruscant.
