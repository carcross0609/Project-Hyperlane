# Neka

**Continuity:** Legends  
**Source:** [Neka](https://starwars.fandom.com/wiki/Neka)
**Galaxy atlas:** system `Neka`, Outer Rim — map position (8678.6, 5899.5, -126.0)

Neka was a planet in the Outer Rim. During the Jedi Civil War, it was subject to a Sith blockade which stopped incoming and outgoing space traffic. The Sith then virus-bombed the world, killing all of its intelligent life. Only a few fortunate individuals, including the Hutt businessman Shuma, were able to bypass the blockade and escape the devastation. It shares its name with the Neka nut.
