# Harpori

**Continuity:** Legends  
**Source:** [Harpori](https://starwars.fandom.com/wiki/Harpori)
**Galaxy atlas:** system `Harpori`, Mid Rim — map position (3859.3, 3891.6, 33.4)

Harpori was a planet that was located in the Druess sector near the Balowa system within the Mid Rim of the galaxy. It hosted a Duros colony that was wiped out by Kaox Krul in 1000 BBY, shortly before the Battles of Ruusan.
