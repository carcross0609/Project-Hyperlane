# Kaliida Shoals

**Continuity:** Legends  
**Source:** [Kaliida Shoals/Legends](https://starwars.fandom.com/wiki/Kaliida_Shoals/Legends)
**Galaxy atlas:** system `Kaliida Shoals`, Mid Rim, grid O-17 — map position (5779.0, -10975.4, -248.2)

Kaliida Shoals was a celestial object in the Ryndellia system, in the Mid Rim's Ryndellian sector, near the Kaliida Nebula and the Kaliida Shoals Medical Center. During the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems, a battle took place close to the Kaliida Shoals Medical Center.
