# Ylesia

**Continuity:** Legends  
**Source:** [Ylesia/Legends](https://starwars.fandom.com/wiki/Ylesia/Legends)
**Galaxy atlas:** system `Ylesia`, Hutt Space, grid T-12 — map position (12678.4, -3209.5, -49.9)

Ylesia was a tropical world located in Hutt Space. It was controlled by the Besadii Hutts. The planet was used as a slave colony dedicated to spice production covered up as a religious retreat.
