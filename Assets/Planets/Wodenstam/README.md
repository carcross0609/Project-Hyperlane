# Wodenstam

**Continuity:** Legends  
**Source:** [Wodenstam](https://starwars.fandom.com/wiki/Wodenstam)
**Galaxy atlas:** system `Wodenstam`, Outer Rim, grid Q-19 — map position (7687.4, -13905.7, -222.2)

Wodenstam was a world located within the star system of the same name, a part of the Outer Rim Territories' Skine sector. Around 10 ABY, it served as the homeworld of Lucross Collections, a loan sharking and credit laundering operation and member of the criminal Tenloss Syndicate.
