# Enthenium

**Continuity:** Canon  
**Source:** [Enthenium](https://starwars.fandom.com/wiki/Enthenium)

Enthenium was a jungle planet located in the Enthenium system in the Jjannex sector of the Outer Rim Territories. It was situated in grid square K-19 of the Standard Galactic Grid along the Lipsec Run in the Western Reaches. A Separatist base was located on the planet.
