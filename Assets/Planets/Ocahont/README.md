# Ocahont

**Continuity:** Canon  
**Source:** [Ocahont](https://starwars.fandom.com/wiki/Ocahont)

Ocahont was a planet in the galaxy that was six hours' hyperspace travel from Pamarthe. In 3 BBY, it was the location of a large rebel base.
