# Tammuz-an

**Continuity:** Legends  
**Source:** [Tammuz-an/Legends](https://starwars.fandom.com/wiki/Tammuz-an/Legends)
**Galaxy atlas:** system `Tammuz-an`, Outer Rim, grid T-14 — map position (13135.2, -6725.1, -38.0)

Tammuz-an was a double-ringed planet in the Outer Rim Territories. The planet's inhabitants, called Tammuz-an, were tall blue- or purple-skinned humanoids governed by a monarchy. The planet was the homeworld of Mon Julpa.
