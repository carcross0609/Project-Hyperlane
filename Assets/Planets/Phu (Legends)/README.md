# Phu

**Continuity:** Legends  
**Source:** [Phu/Legends](https://starwars.fandom.com/wiki/Phu/Legends)
**Galaxy atlas:** system `Phu`, Colonies, grid J-13 — map position (-1606.1, -5610.9, -25.7)

Phu was a world inhabited by the Phuii species of aliens. It was located in the Colonies, near the Aur system. Phu was a planet famous for its gambling industry.
