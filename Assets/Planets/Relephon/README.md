# Relephon

**Continuity:** Legends  
**Source:** [Relephon](https://starwars.fandom.com/wiki/Relephon)
**Galaxy atlas:** system `Relephon`, Inner Rim, grid O-9 — map position (5164.1, 839.7, -5.0)

Relephon was a gas giant in the Hapes Cluster orbited by the Relephon Moons, of which several were populated.

In 40 ABY Relephon's military forces under Ducha AlGray spearheaded a coup against Queen Mother Tenel Ka Djo.
