# Ymura

**Continuity:** Unknown  
**Source:** [Ymura](https://starwars.fandom.com/wiki/Ymura)
**Galaxy atlas:** system `Ymura`, Core Worlds — map position (765.6, -53.3, 42.8)

Ymura was one of two planets in the Karlatt system terraformed by the Machinist Theocracy that served as home to ultra-wealthy Morses. It was in the Karlatt system of the Galactic Core.
