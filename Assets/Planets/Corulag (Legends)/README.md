# Corulag

**Continuity:** Legends  
**Source:** [Corulag/Legends](https://starwars.fandom.com/wiki/Corulag/Legends)
**Galaxy atlas:** system `Corulag`, Core Worlds, grid L-9 — map position (745.2, 443.4, 65.5)

Corulag (pronounced /'kʊɹalæg/) was a populated terrestrial planet located on the Perlemian Trade Route in the Corulus system in the Bormea sector, part of the Ringali Shell. It was the endpoint of the Corulag-Jatir Hyperroute. The planet boasted urban sprawls with the underdeveloped areas filled with bamboo forests.

It was near the Ringali Nebula and shared the sun Corulus with Solag, Biolag, and Garulag.
