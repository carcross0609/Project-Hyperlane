# Calline system's first planet

**Continuity:** Legends  
**Source:** [Calline system's first planet](https://starwars.fandom.com/wiki/Calline_system%27s_first_planet)

The first planet of the Calline system orbited so close to the primary, it was hazardously hot and uninhabitable. The world had a dense metal core, making it, in theory, suitable for mining with extensive precautions. Calline I was surveyed by Rebel Alliance scouts searching for possible alternate bases around 2 ABY.
