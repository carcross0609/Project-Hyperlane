# Tof

**Continuity:** Legends  
**Source:** [Tof (planet)](https://starwars.fandom.com/wiki/Tof_%28planet%29)
**Galaxy atlas:** system `Tof`, Unknown Regions — map position (-9084.4, 2024.8, -111.5)

Tof was a planet located within the Tof system of the Firefist satellite galaxy on the peripheral halo of the galactic disk and was part of the Unknown Regions. It was the homeworld of the near-Human Tofs, a green-skinned race of space pirates.
