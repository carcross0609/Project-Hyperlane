# Aaghra

**Continuity:** Legends  
**Source:** [Aaghra](https://starwars.fandom.com/wiki/Aaghra)
**Galaxy atlas:** system `Aaghra`, Core Worlds, grid L-10 — map position (1445.9, -464.0, -37.3)

Aaghra was the first planet orbiting the star Zug in the Zug system, which was located in the Arrowhead, the intersection of the Core Worlds and the Slice. It was a moonless world of molten rock.
