# Aris

**Continuity:** Legends  
**Source:** [Aris/Legends](https://starwars.fandom.com/wiki/Aris/Legends)
**Galaxy atlas:** system `Aris`, Outer Rim, grid K-5 — map position (-467.3, 7463.3, -34.3)

Aris was a planet in the Albarrio system of the Albarrio sector of the Outer Rim Territories. It was a world of rainforests, and home to the monkey-like scavenger known as the Wok-Wok. It served as the sector capital of the Albarrio sector, and was a stop along the Relgim Run. It had no native intelligent life, but had been colonized.
