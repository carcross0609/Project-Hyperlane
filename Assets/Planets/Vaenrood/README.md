# Vaenrood

**Continuity:** Legends  
**Source:** [Vaenrood](https://starwars.fandom.com/wiki/Vaenrood)
**Galaxy atlas:** system `Vaenrood`, Outer Rim, grid T-6 — map position (13289.1, 5294.5, -506.4)

Vaenrood was a planet in the Vaenrood system, which was located in the Pakuuni sector of the Outer Rim Territories. Several months before the liberation of Kal'Shebbol, capital of the Kathol sector, the New Republic fought the Galactic Empire on Vaenrood.
