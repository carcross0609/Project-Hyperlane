# Averill

**Continuity:** Legends  
**Source:** [Averill](https://starwars.fandom.com/wiki/Averill)
**Galaxy atlas:** system `Averill`, Mid Rim, grid P-11 — map position (6252.2, -1879.5, 41.0)

Averill was a mining world in the Averill system where the Galactic Empire discovered a rich quadrenium lode beneath the crust; quadrenium was refined for starship construction. The native Humans were originally divided into autonomous mine-clans dwelling in inherited mineholds. After the Empire nationalized the local mining operations, a preventable mining accident crippled Selby Jarrad's father. Selby and her cousin failed to create a resistance cell on the planet, so Selby joined New Republic Intelligence.
