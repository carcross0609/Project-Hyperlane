# Abregado-dai

**Continuity:** Legends  
**Source:** [Abregado-dai](https://starwars.fandom.com/wiki/Abregado-dai)

Abregado-dai was the innermost planet from the sun Anza of the Abregado system within the Southern Core portion of the Core Worlds region. Located at the head of the Rimma Trade Route like the rest of the system, it was a volcanic planet without any moons.
