# Derenzil

**Continuity:** Legends  
**Source:** [Derenzil/Legends](https://starwars.fandom.com/wiki/Derenzil/Legends)

Derenzil was a swamp planet located in the galaxy. Prior to the Clone Wars, it was the site of a brief civil war during which the Geonosians manufactured and supplied sonic weapons that had been specialized for aquatic environments to both sides.
