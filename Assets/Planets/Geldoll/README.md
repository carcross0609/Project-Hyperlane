# Geldoll

**Continuity:** Legends  
**Source:** [Geldoll](https://starwars.fandom.com/wiki/Geldoll)

Geldoll was a planet in the galaxy. During the Cold War between the Sith Empire and the Galactic Republic, Geldoll banned all Hutt starships and representatives from the planet in order to fight smuggling.
