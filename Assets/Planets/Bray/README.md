# Bray

**Continuity:** Canon  
**Source:** [Bray](https://starwars.fandom.com/wiki/Bray)
**Galaxy atlas:** system `Bray`, Other, grid O-3 — map position (5098.9, 9423.9, -236.1)

Bray was a dark planet home to the Brayan species. It was located in the Piryn Shar sector in the Expansion Region. During the Clone Wars, Count Dooku resided in a citadel along with Ravna, a mutated creature who could convert others into his kind. Dooku planned to allow Ravna to infect the Brayan population in exchange for using converted clone troopers to infiltrate the ranks of the Republic army, but their plans were halted by the Jedi Council.
