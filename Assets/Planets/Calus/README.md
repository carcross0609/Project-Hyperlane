# Calus

**Continuity:** Legends  
**Source:** [Calus](https://starwars.fandom.com/wiki/Calus)
**Galaxy atlas:** system `Calus`, Inner Rim, grid L-15 — map position (1022.5, -7887.5, 298.7)

Calus was a planet in the Calus system of the Inner Rim, near Bestine IV. Sweet-sand cookies were made on Calus. It was located at the end of Keller's Void, opposite Wroona.
