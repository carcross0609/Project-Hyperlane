# Unidentified Gelviddis Cluster planet

**Continuity:** Legends  
**Source:** [Unidentified Gelviddis Cluster planet](https://starwars.fandom.com/wiki/Unidentified_Gelviddis_Cluster_planet)

A planet in the Gelviddis Cluster had sand with a unique property. The Jedi Order discovered this sand would assume the shape of whatever an observer was thinking.
