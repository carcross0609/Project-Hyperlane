# Expora

**Continuity:** Legends  
**Source:** [Expora](https://starwars.fandom.com/wiki/Expora)
**Galaxy atlas:** system `Expora`, Core Worlds — map position (230.2, 211.8, -47.0)

Expora was the first planet of the Chandrila system, located in the Bormea sector of the Ringali Shell in the Core Worlds. The planet orbited the star Chandrila and was composed of searing rock. Expora was the only one of the system's planets to have no moons. The entirety of the Chandrila system lay on the Perlemian Trade Route, which served as a dividing line between the Northern Dependencies and the Arrowhead portion of the Slice.
