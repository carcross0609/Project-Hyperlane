# Seft

**Continuity:** Legends  
**Source:** [Seft](https://starwars.fandom.com/wiki/Seft)
**Galaxy atlas:** system `Seft`, Expansion Region, grid O-14 — map position (5105.5, -6869.6, -79.4)

Seft was a planet in the Genesia system. The system's largest gas giant, Seft was orbited by six moons which had been stripped of all resources by the Lant Mining Corporation. LMC occasionally used the planet's atmospheric gases for use in Genesia's industrial plants.
