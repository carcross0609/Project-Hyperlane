# Rentor

**Continuity:** Legends  
**Source:** [Rentor/Legends](https://starwars.fandom.com/wiki/Rentor/Legends)
**Galaxy atlas:** system `Rentor`, Unknown Regions, grid F-8 — map position (-8766.0, 1899.8, -280.8)

Rentor was a terrestrial planet located in the Rentor system of the Unknown Regions' Chiss Space. It was linked via hyperlanes to the Csilla and Jamiron systems. Rentor's surface featured oceans as well as icebergs that slowly cruised the currents of the open seas. The sentient Chiss of the Chiss Ascendancy had colonized Rentor, establishing settlements atop the world's icebergs.
