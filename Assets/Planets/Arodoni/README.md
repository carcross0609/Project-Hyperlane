# Arodoni

**Continuity:** Legends  
**Source:** [Arodoni](https://starwars.fandom.com/wiki/Arodoni)
**Galaxy atlas:** system `Arodoni`, Outer Rim, grid O-6 — map position (4924.0, 5798.2, 9.9)

Arodoni was a gas giant in the Dathomir system, located in the Quelii sector in the New Territories portion of the Outer Rim Territories. It occupied the eighth orbital position around the star Domir and was orbited by eighteen moons.
