# Krylon

**Continuity:** Legends  
**Source:** [Krylon](https://starwars.fandom.com/wiki/Krylon)
**Galaxy atlas:** system `Krylon`, Outer Rim, grid P-5 — map position (6620.9, 6024.2, -100.7)

Krylon was a planet in the Gordian Reach. It was the dominant planet of the Pinooran Spur, a polluted, industrial world dominated by Hynese companies, however it was not very important in this region of space.
