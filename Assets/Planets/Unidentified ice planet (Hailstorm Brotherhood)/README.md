**Continuity:** Legends  
**Source:** [Unidentified ice planet (Hailstorm Brotherhood)](https://starwars.fandom.com/wiki/Unidentified_ice_planet_%28Hailstorm_Brotherhood%29)
**Galaxy atlas:** system `Unidentified ice planet`, Other, grid K-18 — map position (-1220.1, -12162.1, -158.9)
