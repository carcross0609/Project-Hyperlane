# Carosi VII

**Continuity:** Legends  
**Source:** [Carosi VII](https://starwars.fandom.com/wiki/Carosi_VII)

Carosi VII was a planet in the Carosus system. Following the expansion of Carosi into a red giant, Carosi VII became a hot, swampy planet that was deemed suitable for colonization by the Carosites at a later date. It was orbited by a single moon.
