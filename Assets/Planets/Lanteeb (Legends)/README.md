# Lanteeb

**Continuity:** Legends  
**Source:** [Lanteeb/Legends](https://starwars.fandom.com/wiki/Lanteeb/Legends)
**Galaxy atlas:** system `Lanteeb`, Outer Rim, grid I-17 — map position (-3821.1, -11243.2, 313.3)

Lanteeb was a neutral pastoral planet in the Malor-77 system. While aligned with the Galactic Republic, it did not have a representative in the Galactic Senate. It was located equidistant between Rattatak and Bespin. It was located in Bri'ahl sector.
