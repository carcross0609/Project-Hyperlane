# Tatrang III

**Continuity:** Legends  
**Source:** [Tatrang III](https://starwars.fandom.com/wiki/Tatrang_III)

Tatrang III was a poisonous jungle planet with three moons that was located within the Tatrang system, a part of the Outer Rim Territories' Tammuz sector. It occupied the third closest orbit around the system's star, the red giant Tatrang. The planet was uninhabitable and considered to be commercially worthless.
