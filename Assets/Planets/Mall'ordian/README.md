# Mall'ordian

**Continuity:** Legends  
**Source:** [Mall'ordian](https://starwars.fandom.com/wiki/Mall%27ordian)
**Galaxy atlas:** system `Mall'ordian`, Outer Rim, grid R-3 — map position (10405.4, 9164.8, 373.3)

Mall'ordian was a planet in the Corporate Sector. A popular tourist destination, it was renown for its crystalline forests. The Corporate Sector Authority was interested in the planet for its potential resources.
