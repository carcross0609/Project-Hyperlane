# Decepino

**Continuity:** Legends  
**Source:** [Decepino](https://starwars.fandom.com/wiki/Decepino)

Decepino was the fifth planet orbiting the star Stisste in the Saleucami system. Located in the Suolriep sector of the Outer Rim Territories, it was a gas giant.
