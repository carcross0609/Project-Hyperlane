# Aris

**Continuity:** Canon  
**Source:** [Aris](https://starwars.fandom.com/wiki/Aris)
**Galaxy atlas:** system `Aris`, Outer Rim, grid K-5 — map position (-467.3, 7463.3, -34.3)

Aris was a rustic terrestrial planet located in the Aris system in the Outer Rim Territories' Albarrio sector, along the Braxant Run hyperspace route. During the High Republic Era, Aris was one of the locations where the Unified Republic Task Force dealt with Nihil marauders in the aftermath of the attack on Valo. It was the homeworld of the human Resistance member Byrco Hansid.
