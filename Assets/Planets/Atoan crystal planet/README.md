# Atoan crystal planet

**Continuity:** Legends  
**Source:** [Atoan crystal planet](https://starwars.fandom.com/wiki/Atoan_crystal_planet)

This planet located in the Atoan system, in the Ghost Nebula, was covered by crystals. It was inhabited by Atoans from the neighboring planet Atoa.
