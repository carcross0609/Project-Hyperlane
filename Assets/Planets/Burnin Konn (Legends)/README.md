# Burnin Konn

**Continuity:** Legends  
**Source:** [Burnin Konn/Legends](https://starwars.fandom.com/wiki/Burnin_Konn/Legends)
**Galaxy atlas:** system `Burnin Konn`, Outer Rim, grid K-18 — map position (-1225.6, -12883.5, -340.0)

Burnin Konn was an Outer Rim Territories mining planet located in the Anoat sector. It possessed rich deposits of various ores and was one of the four Mining Worlds controlled by the Figg family's corporate interests. Burnin Konn's native plants had all been stripped by the mining operations on the world.
