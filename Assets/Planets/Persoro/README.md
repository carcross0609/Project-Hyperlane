# Persoro

**Continuity:** Legends  
**Source:** [Persoro](https://starwars.fandom.com/wiki/Persoro)

Persoro was the first planet orbiting the star Utapau in the Utapau system. Located in the Tarabba sector of the Outer Rim Territories, it was a searing rock.
