# Ojom

**Continuity:** Canon  
**Source:** [Ojom](https://starwars.fandom.com/wiki/Ojom)
**Galaxy atlas:** system `Ojom`, Deep Core, grid M-11 — map position (1617.8, -2449.2, -109.4)

Ojom was a frozen planet located in the Ojom system in the the galaxy's Deep Core that was the homeworld of the Besalisk species. A frigid world, the native Besalisks lived in communities atop floating glaciers, and the planet rarely received visitors, which made the discovery of the Force-sensitive Pong Krell by the Jedi Order an exceptional occurrence.
