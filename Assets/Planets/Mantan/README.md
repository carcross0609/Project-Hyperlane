# Mantan

**Continuity:** Legends  
**Source:** [Mantan](https://starwars.fandom.com/wiki/Mantan)
**Galaxy atlas:** system `Mantan`, Outer Rim, grid U-6 — map position (13673.1, 4713.0, -132.2)

Mantan was a terrestrial world located in the Mantan system, a part of the Calamari sector in the Slice portion of the Outer Rim Territories. The Prously's Rim Run hyperlane linked it to the New Heurkea and Pammant systems. Members of the Mon Calamari species of the planet Dac settled Mantan at some point between 4400 BBY and 4200 BBY, and the former world shared its name with the Mon Calamari cruiser Mantan Wanderer of the Rebel Alliance.
