# Barnaba

**Continuity:** Legends  
**Source:** [Barnaba](https://starwars.fandom.com/wiki/Barnaba)
**Galaxy atlas:** system `Barnaba`, Colonies, grid L-13 — map position (554.3, -5715.2, 94.3)

Barnaba was a warm, mountainous planet in Barnaba Province. It was an important exporter of agricultural produce in the Tapani sector.
