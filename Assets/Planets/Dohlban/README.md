# Dohlban

**Continuity:** Legends  
**Source:** [Dohlban](https://starwars.fandom.com/wiki/Dohlban)
**Galaxy atlas:** system `Dohlban`, Mid Rim, grid R-13 — map position (10196.1, -5862.6, 288.9)

Dohlban was a terrestrial planet located in the Dohlban system, a part of the Dohlbani sector in the Slice portion of the Mid Rim. The Kaaga Run hyperlane connected it to the Void Station in the Bothan sector and the Nar Kaaga system in Hutt Space.

Dohlban was the homeworld of the sentient Guineo species. Due to their low intelligence, Guineo on Dohlban were mostly employed as manual laborers or hired as thugs to off-world criminal organizations.
