# Tallek

**Continuity:** Legends  
**Source:** [Tallek](https://starwars.fandom.com/wiki/Tallek)
**Galaxy atlas:** system `Tallek`, Outer Rim, grid K-19 — map position (-962.8, -13987.3, 327.3)

Tallek was a planet once plagued by thorn fever. The Galactic Empire rounded up anyone who caught the disease and let them die in isolation camps.
