# Savage Opress

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Savage Opress](https://starwars.fandom.com/wiki/Savage_Opress)

Savage Opress ( pronounced /sə'vɑʒ oʊ'prεs/) was the brother of Maul and Feral. A Force-sensitive Dathomirian Nightbrother, he became a Sith apprentice under Count Dooku and later became a renegade Sith Lord, apprenticed to Maul, during the Clone Wars.
