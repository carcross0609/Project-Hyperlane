# Unidentified protocol droid (bioscan)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified protocol droid (bioscan)](https://starwars.fandom.com/wiki/Unidentified_protocol_droid_%28bioscan%29)

A protocol droid reported the results of the bioscan of a family to regent-captain Zargo Anaximander in 21 ABY. This droid along with two others then destroyed each other with blasters as the information and data analysis contained privileged information.

## Specifications

- **Name:** Unidentified protocol droid
- **Death:** 21 ABY, Nightside over Therezar
- **Class:** Protocol droid
- **Affiliation:** Zargo Anaximander
