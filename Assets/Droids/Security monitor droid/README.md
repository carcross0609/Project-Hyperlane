# Security monitor droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Security monitor droid](https://starwars.fandom.com/wiki/Security_monitor_droid)

Security monitor droids were a model of small fourth class security droid. As security droids, a security monitor droid's job was to screen passers-by and report to its master.

## Specifications

- **Name:** Security monitor droid
- **Class:** Security droid
- **Degree:** Class three droid
- **Sensor:** Red
