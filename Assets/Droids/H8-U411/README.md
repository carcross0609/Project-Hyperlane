# H8-U411

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [H8-U411](https://starwars.fandom.com/wiki/H8-U411)

H8-U411, or H8 for short, was a murder droid that had tried to start a galaxy-wide purge of all organics. The droid's core and voice modulator was salvaged by Reveth and rewired into a red-painted, physically helpless MSE droid for laughs.

## Specifications

- **Name:** H8-U411
- **Class:** Murder droid
- **Pronouns:** He/him
- **Affiliation:** Sidon Ithano's pirate crew (unwillingly)
