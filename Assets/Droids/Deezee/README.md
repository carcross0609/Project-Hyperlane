# Deezee

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Deezee](https://starwars.fandom.com/wiki/Deezee)

Deezee was an R-series astromech droid that served the Resistance. Deezee flew in the X-wing starfighter of Black Squadron pilot Karé Kun during the search for Lor San Tekka.
