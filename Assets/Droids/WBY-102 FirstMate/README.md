# WBY-102 FirstMate

**Kind:** Series  
**Continuity:** Legends  
**Source:** [WBY-102 FirstMate](https://starwars.fandom.com/wiki/WBY-102_FirstMate)

The WBY-102 FirstMate was a specialized third-degree droid programmed to instruct people in sailing, caring for and navigating a multi-crewed sailing vessel. It was sheathed in waterproof hard plastic. It has an inflatable flotation bag designed to deploy if the droid was submerged in water.

## Specifications

- **Name:** WBY-102 FirstMate
- **Line:** WBY series
- **Class:** Sailing droid
- **Height:** 1.6 meters
- **Plating:** Deep blue
- **Equipment:**
  - Emergency inflatable flotation bag
  - Visual sensor recorders
  - Auditory sensor recorders
  - Vocabulator speech/sound system
  - Comlink
  - AA-1 VerboBrain
  - Inertial compensators
  - Waterproof hard-impact plastic shell
