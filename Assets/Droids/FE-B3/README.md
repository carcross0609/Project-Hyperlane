# FE-B3

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [FE-B3](https://starwars.fandom.com/wiki/FE-B3)

FE-B3, often referred to as Fee-Bee, was a protocol droid designed to work as a translator for the Haddrex Gang.

- **Death:** 33 BBY, Moon of Drazkel
- **Class:** Protocol droid
- **Plating:** Green
- **Affiliation:**
