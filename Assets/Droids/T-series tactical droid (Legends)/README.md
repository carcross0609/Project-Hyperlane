# T-series tactical droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [T-series tactical droid/Legends](https://starwars.fandom.com/wiki/T-series_tactical_droid/Legends)

The T-series tactical droid, formerly known as the CDE-T unit or standard tactical droid, was a model of tactical droid serving the Confederacy of Independent Systems (CIS) during the Clone Wars. The super tactical droid was later created as an upgraded tactical droid model.

## Specifications

- **Name:** T-series tactical droid
- **Manufacturer:** Baktoid Combat Automata
- **Line:** T-series
- **Class:** Tactical droid
- **Height:** 1.93 meters
- **Gender:** Masculine programming
- **Equipment:**
  - Synchronized fire circuits
  - Durasteel plating
- **Affiliation:**
  - Confederacy of Independent Systems
  -   Separatist Droid Army
  - Dark Worlds
  - Zygerrian Slave Empire
