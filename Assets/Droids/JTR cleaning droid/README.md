# JTR cleaning droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [JTR cleaning droid](https://starwars.fandom.com/wiki/JTR_cleaning_droid)

The JTR cleaning droid was a SoroSuub Corporation cleaning droid and was considered as an abysmal failure. In 45 ABY, Galactic Alliance Senator Luewet Wuul was in possession of one since he did not want to be seen owning an item made by SoroSuub's competitors.

- **Manufacturer:** SoroSuub Corporation
