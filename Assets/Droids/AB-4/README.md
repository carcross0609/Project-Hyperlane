# AB-4

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [AB-4](https://starwars.fandom.com/wiki/AB-4)

AB-4 was a protocol droid that served at the Advance Base Baskarn on Baskarn. It was programmed for bureaucracy and was in charge of base logistics and equipment. More often than not, Rebels serving at the base would receive reprimands for damaging valuable equipment, even if it was not valuable.

## Specifications

- **Type:** Rebel
- **Name:** AB-4
- **Class:** Protocol droid
- **Gender:** Masculine programming
- **Pronouns:** new
- **Affiliation:** Alliance to Restore the Republic
