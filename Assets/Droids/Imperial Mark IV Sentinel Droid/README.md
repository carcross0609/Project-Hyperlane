# Imperial Mark IV Sentinel Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Imperial Mark IV Sentinel Droid](https://starwars.fandom.com/wiki/Imperial_Mark_IV_Sentinel_Droid)

The Imperial Mark IV Sentinel Droid was a type of security droid used by the forces of the reconstituted Sith Empire during the Cold War and Galactic War against the Galactic Republic. A number of Mark IV Sentinels were among the Imperial forces stationed at the Imperial base on the planet Taral V.

## Specifications

- **Name:** Imperial Mark IV Sentinel Droid
- **Class:** Security droid
- **Sensor:** Red
- **Plating:** Gray
- **Armament:** Blaster cannons
- **Affiliation:** Sith Empire
