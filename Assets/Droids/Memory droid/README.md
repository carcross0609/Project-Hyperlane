# Memory droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Memory droid](https://starwars.fandom.com/wiki/Memory_droid)

The Memory droid was created by SoroSuub as a droid library. It stood about 2 meters high, and was hexagonal. They contained computers detailed enough to store a multitude of information. They were used by the Galactic Empire to record information such as the Death Star blueprints.

## Specifications

- **Name:** Memory droid
- **Manufacturer:** SoroSuub Corporation
- **Class:** Data storage droid
- **Height:** 1.8 meters
