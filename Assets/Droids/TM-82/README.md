# TM-82

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [TM-82](https://starwars.fandom.com/wiki/TM-82)

TM-82 was an astromech droid used by the Sith Empire. During the Galactic War it was posted at the Outpost Overseer on Voss, where the droid asked an Imperial for assistance.
