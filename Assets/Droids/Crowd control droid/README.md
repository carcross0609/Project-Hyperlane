# Crowd control droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Crowd control droid](https://starwars.fandom.com/wiki/Crowd_control_droid)

A crowd control droid was a model of droid built to control crowds. When Iden Versio was taken to Vardos after being accused of treason, a crowd attempted to see her, and was held back by Jinata Security crowd control droids.

## Specifications

- **Name:** Crowd control droid
- **Affiliation:** Jinata Security
