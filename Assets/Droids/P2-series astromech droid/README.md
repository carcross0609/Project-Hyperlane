# P2-series astromech droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [P2-series astromech droid](https://starwars.fandom.com/wiki/P2-series_astromech_droid)

The P2-series astromech droid was Industrial Automaton's first astromech droid prototype for the R-series, using a rounded body design that would later prove popular with the R2-series astromech droids.

## Specifications

- **Name:** P2-series astromech droid
- **Manufacturer:** Industrial Automaton
- **Class:** Astromech droid
- **Degree:** Class two droid
- **Cost:** 2,500—3,000 credits
- **Height:** 2.2 meters
- **Equipment:**
  - Armored hull
  - Buzzsaw
  - Heavy grasper arm
  - Intellex II
  - Laser welder
  - Three medium arms
  - Three wheeled legs
  - Video display screen
