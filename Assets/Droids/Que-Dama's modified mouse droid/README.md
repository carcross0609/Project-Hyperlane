# Que-Dama's modified mouse droid

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Que-Dama's modified mouse droid](https://starwars.fandom.com/wiki/Que-Dama%27s_modified_mouse_droid)

The Anzellan Que-Dama rode a modified mouse droid. The MSE series droid was equipped with a scrolling display screen and blaster armament, the latter being employed in a battle on Tkoku Island on the planet Olcatz.
