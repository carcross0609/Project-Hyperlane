# XJ9-GM02

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [XJ9-GM02](https://starwars.fandom.com/wiki/XJ9-GM02)

XJ9-GM02 was an Imperial Viper probe droid that was stationed in one of the asteroid belts orbiting the planet Alistan Nor. XJ9-GM02 sighted the StarScavenger approaching the planet and reported the ship's whereabouts to the Imperial database. This enabled M-OC to pursue Rowan Freemaker to Alistan Nor.
