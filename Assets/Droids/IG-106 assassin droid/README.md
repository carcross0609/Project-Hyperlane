# IG-106 assassin droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IG-106 assassin droid](https://starwars.fandom.com/wiki/IG-106_assassin_droid)

The IG-106 assassin droid was a model of assassin droid line of the IG-series. It resembled the IG-88 assassin droid line and featured a blaster cannon mounted on its right arm.

- **Name:** IG-106 assassin droid
- **Manufacturer:** Holowan Mechanicals
- **Line:** IG-series
- **Class:** Assassin droid
- **Armament:** Built-in blaster cannon (1)
