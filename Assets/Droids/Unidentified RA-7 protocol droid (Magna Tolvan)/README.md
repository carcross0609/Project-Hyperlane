# Unidentified RA-7 protocol droid (Magna Tolvan)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified RA-7 protocol droid (Magna Tolvan)](https://starwars.fandom.com/wiki/Unidentified_RA-7_protocol_droid_%28Magna_Tolvan%29)

An RA-7 protocol droid served Captain Magna Tolvan of the Galactic Empire. While on the Citadel of Rur, the RA-7 protocol droid was briefly possessed by Eternal Rur, attacking both the crew of Tolvan's shuttle and later Tolvan herself, but returned to normal after the destruction of the Citadel.
