# STALKER-1

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [STALKER-1](https://starwars.fandom.com/wiki/STALKER-1)

STALKER-1 was a masculine-programmed mining droid that served as a sentry for a chromium mine on Burnin Konn. After serving in the mines for years without a memory wipe, the droid developed an uncontrollable desire to hunt new enemies, so he joined the crew of The Smuggler, leader of the Uprising.

## Specifications

- **Name:** STALKER-1
- **Homeworld:** Burnin Konn
- **Class:** Mining droid
- **Gender:** Masculine programming
- **Pronouns:** new
- **Sensor:** Red
- **Armament:** Blaster rifle
