# VL-44

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [VL-44](https://starwars.fandom.com/wiki/VL-44)

VL-44, also called "Vee-El Forty-Four," was a security droid who appeared to have originally been a PK-series worker droid. He served the Resistance during the Cold War.
