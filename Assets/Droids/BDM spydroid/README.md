# BDM spydroid

**Kind:** Series  
**Continuity:** Uncategorized  
**Source:** [BDM spydroid](https://starwars.fandom.com/wiki/BDM_spydroid)

BDM spydroids were surveillance droids employed by the Star Tours travel agency. They were used to make sure the agency's repair droids were doing their jobs.
