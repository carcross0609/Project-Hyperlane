# Architect droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Architect droid/Legends](https://starwars.fandom.com/wiki/Architect_droid/Legends)

The architect droid was a model of construction droid created during the time of the Old Republic. Professor Huyang was an architect droid who served the Jedi Order as an instructor for lightsaber construction.

## Specifications

- **Name:** Architect droid
- **Degree:** Class three
- **Gender:** Masculine programming
- **Sensor:** Yellow
- **Affiliation:** Jedi Order
