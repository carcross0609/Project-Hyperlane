# Droideka Alpha

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Droideka Alpha](https://starwars.fandom.com/wiki/Droideka_Alpha)

Droideka Alpha was a droideka that survived the Clone Wars and was later reprogrammed to serve in IG-88's Droid Army during the Galactic Civil War. It was part of a group of droids led by IG-88 to start a Droid Revolution, which was destroyed in 4 ABY.
