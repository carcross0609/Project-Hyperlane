# Unidentified BX-series droid commando (Parlin)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified BX-series droid commando (Parlin)](https://starwars.fandom.com/wiki/Unidentified_BX-series_droid_commando_%28Parlin%29)
