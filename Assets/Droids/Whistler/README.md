# Whistler

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Whistler](https://starwars.fandom.com/wiki/Whistler)

Whistler, also called Xeno, was the astromech droid of Corran Horn. He was the same R-series model as the legendary R2-D2.
