# IM4-822

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [IM4-822](https://starwars.fandom.com/wiki/IM4-822)

IM4-822 was a Mark IV sentry droid. A holorecording made by IM4-822 was used at the murder trial of Doctor Cornelius Evazan.
