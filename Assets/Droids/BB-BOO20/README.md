# BB-BOO20

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BB-BOO20](https://starwars.fandom.com/wiki/BB-BOO20)

BB-BOO20 was a BB-series astromech droid that had a orange, green, and silver body, with a black sensor. The droid resided on the dunes of Pasaana amongst the native Aki-Aki.
