# IT-4 Warning Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IT-4 Warning Droid](https://starwars.fandom.com/wiki/IT-4_Warning_Droid)

The IT-4 Warning Droid was a type of modified DZ-70 fugitive tracker droid used during the Galactic Civil War. Droids of this kind was unarmed as it primarily filled a reconnaissance role. IT-4 Warning Droids were used by the Rak'qua on Station Gamma above Ord Mantell following the Battle of Yavin. In 1 ABY, a number of spacers who explored Station Gamma fought and destroyed multiple IT-4 Warning Droids.

## Specifications

- **Name:** IT-4 Warning Droid
- **Line:** DZ-70 fugitive tracker droid
- **Class:** Assassin droid
- **Plating:** Metallic gray
- **Armament:** None
- **Affiliation:** Rak'qua
