# EX-49 Mining Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [EX-49 Mining Droid](https://starwars.fandom.com/wiki/EX-49_Mining_Droid)

The EX-49 Mining Droid was a mining droid model in use during the Galactic War. Several EX-49 Mining Droids were usied to mine Exonium on Rishi.
