# 3Z3 medical droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [3Z3 medical droid](https://starwars.fandom.com/wiki/3Z3_medical_droid)

The 3Z3 medical droid was a medical droid manufactured by Industrial Automaton, that was mainly used by the Darth Krayt's Galactic Empire. At the request of the Imperial bureaucrats, Industrial Automaton installed combat scenario programming, allowing it to be used on battlefields.

## Specifications

- **Name:** 3Z3 medical droid
- **Manufacturer:** Industrial Automaton
- **Model:** 3Z3 medical droid
- **Class:** Medical droid
- **Degree:** Class one droid
- **Cost:** 5,000 credits
- **Affiliation:** Darth Krayt's Galactic Empire
