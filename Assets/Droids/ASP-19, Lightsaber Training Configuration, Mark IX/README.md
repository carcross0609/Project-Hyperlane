# ASP-19, Lightsaber Training Configuration, Mark IX

**Kind:** Individual

**Source:** [ASP-19, Lightsaber Training Configuration, Mark IX](https://starwars.fandom.com/wiki/ASP-19%2C_Lightsaber_Training_Configuration%2C_Mark_IX)
