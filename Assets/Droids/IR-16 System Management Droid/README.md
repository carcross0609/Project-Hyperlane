# IR-16 System Management Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IR-16 System Management Droid](https://starwars.fandom.com/wiki/IR-16_System_Management_Droid)

The IR-16 System Management Droid was a model of droid used by the the Shroud, a freelance spy active during the Galactic War. An IR-16 System Management Droid oversaw the Shroud's factory on the moon Nar Shaddaa.

## Specifications

- **Name:** IR-16 System Management Droid
- **Sensor:** Yellow
- **Plating:** Dark
- **Affiliation:** The Shroud's organization
