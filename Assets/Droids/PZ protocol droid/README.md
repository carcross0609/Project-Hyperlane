# PZ protocol droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [PZ protocol droid](https://starwars.fandom.com/wiki/PZ_protocol_droid)

The PZ protocol droid were a model of protocol droid manufactured by Serv-O-Droid, Inc.. Its anatomy was specifically modeled after the long-necked Tofallid species. A PZ protocol droid designated PZ-4CO served as a communications droid in the Resistance.

## Specifications

- **Name:** PZ protocol droid
- **Manufacturer:** Serv-O-Droid, Inc.
- **Class:** Protocol droid
- **Degree:** Class three
- **Height:** 2.06 meter
