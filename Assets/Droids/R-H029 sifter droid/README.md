# R-H029 sifter droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [R-H029 sifter droid](https://starwars.fandom.com/wiki/R-H029_sifter_droid)

The R-H029 sifter droid was a model of gray-colored, fifth-degree sifter droid equipped with a sand vacuum-head. It stood taller than a fully grown human and moved about on four ambulatory struts.
