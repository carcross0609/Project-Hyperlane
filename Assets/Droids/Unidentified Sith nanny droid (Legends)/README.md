# Unidentified Sith nanny droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified Sith nanny droid/Legends](https://starwars.fandom.com/wiki/Unidentified_Sith_nanny_droid/Legends)

This Sith Nanny droid worked in Darth Sidious's base on Mustafar. She was destroyed along with the station and RO-Z67 when Sidious ordered the station's gravity supports to be deactivated, allowing the base to sink into the lava below.

- **Type:** Sith

- **Model:** RO-Z67's model
