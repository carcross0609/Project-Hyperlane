# Wembly's BLX droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Wembly's BLX droid](https://starwars.fandom.com/wiki/Wembly%27s_BLX_droid)

Wembly's BLX Droid served aboard the Imperial prison barge Purge during the time of the Galactic Civil War. He followed ICO Wembly everywhere, an accompaniment that other officers on board the Purge would not have tolerated.
