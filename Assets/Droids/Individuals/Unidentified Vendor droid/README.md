# Unidentified Vendor droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified Vendor droid](https://starwars.fandom.com/wiki/Unidentified_Vendor_droid)

A vendor droid was present on a Weequay pirate ship, the Marauder, during the events of the Clone Wars around 21 BBY. This droid was used for entertainment as a gladiator droid and fought ASP-series labor droid K0-5D.
