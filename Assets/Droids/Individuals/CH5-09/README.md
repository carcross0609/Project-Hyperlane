# CH5-09

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [CH5-09](https://starwars.fandom.com/wiki/CH5-09)

CH5-09, nicknamed Zero, was a LEP-series service droid who was the primary security officer to the Pa'lowick Sy Snootles. His programming had been altered by Snootles herself, who had erased his memory and tried and failed to make CH5 less cheerful.
