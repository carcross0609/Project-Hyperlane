# IM4-821

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [IM4-821](https://starwars.fandom.com/wiki/IM4-821)

IM4-821 was a Mark IV sentry droid. A holorecording made by IM4-821 was used at the murder trial of Cornelius Evazan.
