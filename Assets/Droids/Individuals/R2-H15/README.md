# R2-H15

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R2-H15](https://starwars.fandom.com/wiki/R2-H15)

R2-H15 was an R2-series astromech droid that was optimized to function in cold weather. The droid's distinctive red-and-white "hat" was an auxiliary thermal guard that included a cylindrical atmospheric gauge on top. It also included a Burtt acoustic signaller.

## Specifications

- **Name:** R2-H15
- **Model:** R2-series astromech droid
- **Class:** Astromech droid
- **Pronouns:** He/him
- **Sensor:** Black, gold
- **Plating:** Red, green, white
