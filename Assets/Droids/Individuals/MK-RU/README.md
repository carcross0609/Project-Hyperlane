# MK-RU

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [MK-RU](https://starwars.fandom.com/wiki/MK-RU)

MK-RU was a droid that was part of Imperial Intelligence on Dromund Kaas in Kaas City. An unidentified Imperial delivered a package to this droid while it was in Kaas City. They worked with Manda and Minder Twenty.
