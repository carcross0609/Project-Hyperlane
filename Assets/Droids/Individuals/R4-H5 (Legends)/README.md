# R4-H5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R4-H5/Legends](https://starwars.fandom.com/wiki/R4-H5/Legends)

R4-H5 was an R4-P astromech droid used by Jedi Master Kit Fisto in his Delta-7 Jedi starfighter. R4-H5 had a dome painted a red-orange with a body that was green and yellow-green in color.
