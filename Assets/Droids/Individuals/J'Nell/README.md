# J'Nell

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [J'Nell](https://starwars.fandom.com/wiki/J%27Nell)

"J'Nell" was a BD-3000 luxury droid who, along with the BD-3000 known as "Carly," worked in the kitchen of Takodana Castle on Takodana.
