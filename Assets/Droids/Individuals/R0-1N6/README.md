# R0-1N6

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R0-1N6](https://starwars.fandom.com/wiki/R0-1N6)

R0-1N6 was an R0-series astromech droid that played the drums as part of a performance by Maximilian Rebo alongside a Bith musician at Garsa Fwip's Sanctuary on the planet Tatooine. R0-1N6 was destroyed when the Pyke Syndicate bombed Fwip's sanctuary in 9 ABY.

- **Type:** Musician
