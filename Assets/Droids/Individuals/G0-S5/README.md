# G0-S5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [G0-S5](https://starwars.fandom.com/wiki/G0-S5)

G0 S5 was an astromech droid of the reconstituted Sith Empire during the Galactic War between the Empire and the Galactic Republic, stationed at the Imperial command center in the Drift Hills Imperial Outpost on planet Hoth.
