# Lando Calrissian's R5 unit

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Lando Calrissian's R5 unit](https://starwars.fandom.com/wiki/Lando_Calrissian%27s_R5_unit)

Lando Calrissian's R5 unit was an old astromech droid into which Lando Calrissian had encoded all access codes to all doors in Cloud City. Kyle Katarn used it to get access to the upper levels of Cloud City during the Battle of Bespin.
