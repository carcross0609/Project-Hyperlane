# Unidentified torture droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified torture droid](https://starwars.fandom.com/wiki/Unidentified_torture_droid)

This torture droid used by Ban Papeega to torture Thurlow Harris to extract the name of the pilot who destroyed the Death Star. It was destroyed when Vader flew into a rage and killed all the bounty hunters, except for Mala Mala.
