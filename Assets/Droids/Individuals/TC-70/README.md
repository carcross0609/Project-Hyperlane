# TC-70

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [TC-70](https://starwars.fandom.com/wiki/TC-70)

TC-70 was a TC-series protocol droid who served as a translator for Jabba the Hutt during the Clone Wars and into the Imperial Era. However, by 2 ABY, Jabba had a different protocol unit serving as his translator droid.

## Specifications

- **Type:** Hutt Cartel
- **Name:** TC-70
- **Manufacturer:** Cybot Galactica
- **Model:** TC-series protocol droid
- **Class:** Protocol droid
- **Height:** 1.67 meters
- **Pronouns:** She/her
- **Sensor:** Yellow
- **Plating:** Copper
- **Affiliation:**
  - Hutt Clan
  -   Jabba's criminal empire
