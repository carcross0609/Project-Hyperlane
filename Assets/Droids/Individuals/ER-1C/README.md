# ER-1C

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ER-1C](https://starwars.fandom.com/wiki/ER-1C)

ER-1C was an ER-1 probe droid built by Graf Zapalo and a team of Naboo engineers. ER-1C was put to work on Ohma-D'un, aiding in the Gungan colonization of the moon.
