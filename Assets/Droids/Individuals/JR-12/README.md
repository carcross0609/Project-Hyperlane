# JR-12

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [JR-12](https://starwars.fandom.com/wiki/JR-12)

JR-12 was a fourth degree security droid programmed with a masculine personality. Bipedal and humanoid in structure, JR-12 operated as an independent security contractor on the Mid Rim world Ord Mantell during the Galactic Civil War.

## Specifications

- **Name:** JR-12
- **Class:** Security droid
- **Gender:** Masculine programming
- **Pronouns:** new
- **Sensor:** Yellow
