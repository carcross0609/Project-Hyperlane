# Unidentified protocol droid envoy

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified protocol droid envoy](https://starwars.fandom.com/wiki/Unidentified_protocol_droid_envoy)

A protocol droid was an envoy who served Orlen Mollo and the Galactic Republic. In 382 BBY, the droid was sent to the planet E'ronoh but he was destroyed when the Eroni fleet explosed the droid's ship.

## Specifications

- **Type:** Galactic Republic
- **Name:** Unidentified protocol droid envoy
- **Death:** 382 BBY, over E'ronoh
- **Class:** Protocol droid
