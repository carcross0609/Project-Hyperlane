# Unidentified RA-7 protocol droid (Nar Shaddaa)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified RA-7 protocol droid (Nar Shaddaa)](https://starwars.fandom.com/wiki/Unidentified_RA-7_protocol_droid_%28Nar_Shaddaa%29)

A RA-7 protocol droid was active on the Smuggler's Moon, Nar Shaddaa, shortly before the skirmish in Grakkus the Hutt's arena. The droid was destroyed by Chewbacca after another droid attempted to cut off C-3PO's head.
