# ISD-80

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ISD-80](https://starwars.fandom.com/wiki/ISD-80)

ISD-80 was a medical droid of the reconstituted Sith Empire. It oversaw Shara Jenn's neurochemical levels after her recovery from a coma induced by Star Cabal.
