# Clink

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Clink](https://starwars.fandom.com/wiki/Clink)

Clink was an LE-series droid owned by a Gran trader on Pantora. Along with the astromech droids 225 and DK-3, Clink was supervised by the protocol droid CG-67. The small droid did not suffer fools.

## Specifications

- **Name:** Clink
- **Model:** LE-series droid
- **Class:** Astromech droid
- **Gender:** Masculine programming
- **Plating:** White, blue, yellow, and green
