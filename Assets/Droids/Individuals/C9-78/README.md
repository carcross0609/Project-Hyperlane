# C9-78

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [C9-78](https://starwars.fandom.com/wiki/C9-78)

C9-78 was a C-series astromech droid manufactured by Industrial Automaton. By 34 ABY, the droid had resided in Black Spire Outpost on the planet Batuu for some time, but had never left the outpost.

## Specifications

- **Name:** C9-78
- **Manufacturer:** Industrial Automaton
- **Line:** C-series
