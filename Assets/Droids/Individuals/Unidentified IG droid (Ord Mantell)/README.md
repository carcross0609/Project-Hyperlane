# Unidentified IG droid (Ord Mantell)

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Unidentified IG droid (Ord Mantell)](https://starwars.fandom.com/wiki/Unidentified_IG_droid_%28Ord_Mantell%29)

An IG droid was guarding a shipment of prototype blaster pistols on a 20-T Railcrawler conveyex transport on Ord Mantell. Boba Fett, sent by Jabba Desilijic Tiure to steal the prototypes, disabled the droid using a reprogrammed MSE-6 series repair droid.
