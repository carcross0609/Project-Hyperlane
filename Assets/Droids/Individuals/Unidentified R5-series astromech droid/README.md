# Unidentified R5-series astromech droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified R5-series astromech droid](https://starwars.fandom.com/wiki/Unidentified_R5-series_astromech_droid)

An R5-series astromech droid accompanied the elite Rebel Alliance fighting force Renegade Squadron on a mission to rescue enslaved Rebel prisoners on the planet Tatooine around 0.5 ABY. The bounty hunter Boba Fett secretly placed a tracking device on the R5 unit, which allowed the Galactic Empire to track the Rebels back to their base on Boz Pity following the mission.
