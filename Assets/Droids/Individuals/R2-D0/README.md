# R2-D0

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-D0](https://starwars.fandom.com/wiki/R2-D0)

R2-D0 (Artoo-Deo), or Deo, was Tiree's R2-model astromech utility droid. Deo escaped from the various scrapes Tiree was caught in, and assisted several groups of Rebel agents in rescuing Tiree.
