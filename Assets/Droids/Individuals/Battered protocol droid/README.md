# Battered protocol droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Battered protocol droid](https://starwars.fandom.com/wiki/Battered_protocol_droid)

A battered protocol droid was on the planet Dantooine during the Dark Wars. The Jedi Knight Meetra Surik repaired him and watched a holovid of a conversation between Jedi Masters Vandar Tokare and Vrook Lamar.

## Specifications

- **Name:** Battered protocol droid
- **Homeworld:** Dantooine
- **Class:** Protocol droid
- **Gender:** Masculine programming
- **Pronouns:** new
