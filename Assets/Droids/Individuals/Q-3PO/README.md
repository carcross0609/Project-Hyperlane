# Q-3PO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Q-3PO](https://starwars.fandom.com/wiki/Q-3PO)

Q-3PO was a protocol droid that worked as a species relations droid for the Galactic Republic during the Clone Wars. Later he was given to Doctor Deena Kinnet, after she became a spy for the Galactic Empire.

## Specifications

- **Name:** Q-3PO
- **Class:** Protocol droid
- **Gender:** Masculine programming
- **Pronouns:** new
- **Sensor:** Yellow
- **Plating:** Silver
- **Affiliation:**
  - Galactic Republic
  - Deena Kinnet
  - Galactic Empire
