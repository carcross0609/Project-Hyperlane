# C-9PO (Brakiss)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [C-9PO (Brakiss)](https://starwars.fandom.com/wiki/C-9PO_%28Brakiss%29)

C-9PO, pronounced as See-Ninepio or Ninepio for short, was a copper-colored protocol droid that was purchased and modified by Brakiss for use on Telti.
