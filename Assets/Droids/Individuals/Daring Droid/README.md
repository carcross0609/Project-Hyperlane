# Daring Droid

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Daring Droid](https://starwars.fandom.com/wiki/Daring_Droid)

Daring Droid was an astromech droid found in Exegol space that was aligned with the Resistance. As the First Order was pinning down the Resistance, this droid, along with a protocol droid, went out to rescue soldiers nearby. After the droid saved Resistance pilots, the droid disappeared and couldn't be found.
