# Copero Jubilee Miniprobe

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Copero Jubilee Miniprobe](https://starwars.fandom.com/wiki/Copero_Jubilee_Miniprobe)

The Copero Jubilee Miniprobe was a model of floating miniprobe probe droid available around 3627 BBY. This droid had ties to both Life Day and Copero of the Chiss Ascendancy.

## Specifications

- **Name:** Copero Jubilee Miniprobe
- **Class:**

  -   Miniprobe
- **Plating:** Silver
- **Armament:** 3 kites
