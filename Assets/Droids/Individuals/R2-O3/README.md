# R2-O3

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R2-O3](https://starwars.fandom.com/wiki/R2-O3)

R2-O3 was a R2-series astromech droid with masculine-programming. One of the first R2 units created on Anoat, R2-O3 spent a majority of his existence as a demolitions droid.
