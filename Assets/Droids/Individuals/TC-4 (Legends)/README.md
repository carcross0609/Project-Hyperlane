# TC-4

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [TC-4/Legends](https://starwars.fandom.com/wiki/TC-4/Legends)

TC-4 was a red TC-series protocol droid owned by Senator Palpatine. TC-4 was programmed with vast knowledge of the money loving culture of the Swokes Swokes and served the Swokes Swokes delegate to the Galactic Senate, Yeb Yeb Adem'thorn.
