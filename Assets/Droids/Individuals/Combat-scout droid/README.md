# Combat-scout droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Combat-scout droid](https://starwars.fandom.com/wiki/Combat-scout_droid)

This combat-scout droid was a droid that was once lost in a desert planet until it encountered C-3PO, R2-D2 and a man mounted on a CRILOC Horse. Despite its combat-oriented programming, this droid merely wanted to greet the astonished droids instead of destroying them.
