# Unidentified B1 battle droid sergeant (Ryloth)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified B1 battle droid sergeant (Ryloth)/Legends](https://starwars.fandom.com/wiki/Unidentified_B1_battle_droid_sergeant_%28Ryloth%29/Legends)

A battle droid sergeant was present on Ryloth, along with Droid Commander TX-20. The droid was used as a test by TX-20 to see if the gutkurrs would require organic meat only or not, the sergeant survived the test and verified TX-20's theory.
