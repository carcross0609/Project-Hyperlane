# LR-5 sentinel droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [LR-5 sentinel droid](https://starwars.fandom.com/wiki/LR-5_sentinel_droid)

LR-5 sentinel droid was a battle droid used by doctor Sannus Lorrick during the Galactic War between the reconstituted Sith Empire and the Galactic Republic. It was destroyed in 3639 BBY, by a strike team that stormed Lorrick's lab on Ord Mantell.

- **Name:** LR-5 sentinel droid
- **Death:** 3639 BBY, Ord Mantell
- **Class:** Battle droid
