# U2-C1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [U2-C1](https://starwars.fandom.com/wiki/U2-C1)

U2-C1 was a U2-C1-series housekeeping droid manufactured by Publictechnic and employed at Jabba's Palace. The blue-colored droid informed the Whiphid J'Quille about a threat to him.
