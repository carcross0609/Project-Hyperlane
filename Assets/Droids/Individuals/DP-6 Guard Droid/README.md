# DP-6 Guard Droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [DP-6 Guard Droid](https://starwars.fandom.com/wiki/DP-6_Guard_Droid)

DP-6 Guard Droid was a security droid of the reconstituted Sith Empire in use during the Galactic War with the Galactic Republic. During the Battle of Corellia in 3640 BBY it protected the base of Darth Thanaton in the Museum of Corellian Industry, where it was destroyed by Thanaton's rival Kallig.

- **Death:** 3640 BBY, Corellia
- **Class:** Security droid
