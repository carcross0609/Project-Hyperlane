# R4-X2

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R4-X2](https://starwars.fandom.com/wiki/R4-X2)

R4-X2 was a green R4 astromech droid operating during the First Order-Resistance War. It served on board the main cruiser of the Resistance.

## Specifications

- **Type:** Resistance
- **Name:** R4-X2
- **Model:** R4 astromech
- **Class:** Astromech droid
- **Sensor:** Black
- **Plating:** Green and white
- **Equipment:**
  - Burtt acoustic signaler
  - Durasteel shell legs & chest frames
  - Hi-power recharge coupling
  - Holographic computer
  - Interference Pulse Stabilizers
  - Motorized treads
  - Primary photo-receptor and radar eye
  - Repair arms
  - Retractable leg
  - System ventilation
- **Affiliation:** Resistance
