# IL-SA

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [IL-SA](https://starwars.fandom.com/wiki/IL-SA)

IL-SA was a feminine Human replica droid created by the Sluissi scientist Alessi Quon. She was to be a full HRD with synthskin and hair.
