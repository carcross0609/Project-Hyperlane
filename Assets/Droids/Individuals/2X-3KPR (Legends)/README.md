# 2X-3KPR

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [2X-3KPR/Legends](https://starwars.fandom.com/wiki/2X-3KPR/Legends)

2X-3KPR was a KPR security droid manufactured by Lerrimore Droids. The droid was one of several KPR servant droids owned by Owen Lars prior to the Battle of Yavin. 2X-3KPR was responsible for patrolling the perimeter of the Lars homestead, and was programmed to activate alarm sensors, security lights, and power fences.
