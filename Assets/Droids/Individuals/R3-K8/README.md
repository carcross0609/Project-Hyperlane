# R3-K8

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R3-K8](https://starwars.fandom.com/wiki/R3-K8)

R3-K8 was an R3 astromech droid assigned to the New Republic corvette FarStar. Assigned to the hangar control room on the ship, the droid was fitted with an astromech voice box to facilitate communication between itself and the living controller on duty.
