# Neufie

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Neufie](https://starwars.fandom.com/wiki/Neufie)

Neufie was the nickname given by Jacen Solo for his R9-series astromech droid. The droid was used in his StealthX starfighter during the height of the Swarm War.
