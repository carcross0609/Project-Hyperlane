# D-3P-O2

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [D-3P-O2](https://starwars.fandom.com/wiki/D-3P-O2)

D-3P-O2 was a specially-programmed 3PO-series protocol droid responsible for managing Managing Director Vost Tyne's schedule while he was assigned to the hyperbaride plant on Marca. It had a thick accent as it had been programmed by Imperials from the Core Worlds.

## Specifications

- **Name:** D-3P-O2
- **Model:** 3PO-series protocol droid
- **Pronouns:** new
- **Plating:** Dull silver with blue metallic highlights
- **Affiliation:** Galactic Empire
