# QS-2D

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [QS-2D](https://starwars.fandom.com/wiki/QS-2D)

QS-2D was a heavily-modified protocol droid-turned-entrepreneur. Its left hand had been turned into a weapon mount for a blaster pistol, it had been fitted with deep black armor plating, and it had been reprogrammed to serve as an administrative droid. It had been altered to serve basically as a combination of personal assistant and body guard, and was given a heuristic processor which gave it a capacity for a great deal of independence.
