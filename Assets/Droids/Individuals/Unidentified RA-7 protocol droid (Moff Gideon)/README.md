# Unidentified RA-7 protocol droid (Moff Gideon)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified RA-7 protocol droid (Moff Gideon)](https://starwars.fandom.com/wiki/Unidentified_RA-7_protocol_droid_%28Moff_Gideon%29)

An RA-7 protocol droid served on board Gideon's light cruiser in 9 ABY. During the Second rescue of Grogu, the droid was roaming the halls of the light cruiser when the Mandalorian Din Djarin hid himself to avoid detection by the droid.
