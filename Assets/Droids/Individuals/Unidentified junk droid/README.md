# Unidentified junk droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified junk droid](https://starwars.fandom.com/wiki/Unidentified_junk_droid)

This monster droid was one of several repurposed battle droids that were built by the Mandalorian extremist organization, Death Watch to be used as target practice by their soldiers.

## Specifications

- **Type:** Mandalorian
- **Name:** Unidentified junk droid
- **Death:** c. 20 BBY, Carlac
- **Model:** Cobbled together from an IG-100 MagnaGuard, a BX-series droid commando, a T-series military strategic analysis and tactics droid and a B1-series battle droid
- **Class:** Monster droid
- **Equipment:** Vocabulator
- **Affiliation:**
  - Confederacy of Independent Systems
  - Death Watch
  - R2-D2
