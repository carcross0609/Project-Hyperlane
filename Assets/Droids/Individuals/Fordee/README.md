# Fordee

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Fordee](https://starwars.fandom.com/wiki/Fordee)

Fordee was a droid built by Mala Mala as a friend, protector, and personal transport. Fordee was armed with several blasters and would defend Mala to the death.
