# Geegee

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Geegee](https://starwars.fandom.com/wiki/Geegee)

Geegee was a droid who served at the temple of the rebuilt Jedi Order, led by Jedi Master Luke Skywalker. Geegee operated aboard the Grimtaash, the vessel of Skywalker's nephew Ben Solo.

## Specifications

- **Type:** Jedi
- **Name:** Geegee
- **Model:** Modified RA-7 protocol droid
- **Sensor:** Yellow
- **Plating:** Silver
- **Affiliation:** Jedi Order
