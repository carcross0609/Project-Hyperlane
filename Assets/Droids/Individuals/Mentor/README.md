# Mentor

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Mentor](https://starwars.fandom.com/wiki/Mentor)

Mentor was the self-given name of a droid consciousness that became self-aware around 3640 BBY and started planning a droid revolution. As one of the founders of the Directive 7 movement, he set up a base on the moon Zadd in the Unknown Regions.

## Specifications

- **Name:** Mentor
- **Homeworld:** Zadd
- **Death:** 3640 BBY
- **Pronouns:** He/him
- **Affiliation:** Directive 7
