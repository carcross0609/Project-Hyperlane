# Nine

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Nine](https://starwars.fandom.com/wiki/Nine)

"Nine" was the designated name given to Mara Jade Skywalker's R9-series astromech droid. The droid was used aboard her StealthX starfighter during the height of the Swarm War.
