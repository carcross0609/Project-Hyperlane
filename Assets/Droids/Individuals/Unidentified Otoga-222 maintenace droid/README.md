# Unidentified Otoga-222 maintenace droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified Otoga-222 maintenace droid](https://starwars.fandom.com/wiki/Unidentified_Otoga-222_maintenace_droid)

A droid worked for the Toydarian junk dealer Watto. The Otoga-222 maintenance droid once went to the Skywalker home to tell Shmi and Anakin Skywalker to get to work, since Watto was busy in Anchorhead. The droid also spent time in Watto's junkshop waiting for Anakin to return from an errand in Mos Eisley.
