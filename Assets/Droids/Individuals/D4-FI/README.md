# D4-FI

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [D4-FI](https://starwars.fandom.com/wiki/D4-FI)

D4-FI was a B1-series battle droid with old programming that served in the Confederacy of Independent Systems on a Trade Federation battleship. During a raid on the battleship, Captain Nuno Tuuk built a trap to trick the ship's attackers. However, D4-FI was able to solve the trap in sixty seconds despite his old programming.
