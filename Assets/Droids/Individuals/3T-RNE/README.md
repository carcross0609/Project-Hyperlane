# 3T-RNE

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [3T-RNE](https://starwars.fandom.com/wiki/3T-RNE)

3T-RNE was a droid that worked for the Star Tours travel agency. A broken droid, he could be found waiting for R3-D3 and another droid to be repaired.

- **Name:** 3T-RNE
