# DC-GNK

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [DC-GNK](https://starwars.fandom.com/wiki/DC-GNK)

DC-GNK was a originally a GNK-series power droid, later heavily modified to serve as a translator by Jawa Empideera Kkek. DC-GNK was outfitted with a number of salvaged protocol droid parts, allowing him to help Kkek in trade negotiations. Although DC-GNK was grateful for his transformation into a more intelligent droid, he longed to have his own life, away from the Jawas.

## Specifications

- **Name:** DC-GNK
- **Homeworld:** Unknown, later Tatooine
- **Creator:** Modified by Empideera Kkek
- **Manufacturer:** Veril Line Systems
- **Model:** GNK power droid
- **Class:** Translator/assistant (modified, originally Power Droid)
- **Height:** 1.1 meters
- **Gender:** Masculine programming
