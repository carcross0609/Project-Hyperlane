# MMV-608

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [MMV-608](https://starwars.fandom.com/wiki/MMV-608)

MMV-608 was a tracked security droid from the MMV security droid series. MMV-608 was active and protecting the mines of Outer Rim Oreworks Company in Lamaredd as of 29 BBY.

## Specifications

- **Name:** MMV-608
- **Pronouns:** new
- **Armament:**
  - 2 repeating blaster rifles
  - 2 vibro-axes
- **Equipment:**
  - Infrared vision
  - Locked access
  - Vocabulator
- **Affiliation:** Outer Rim Oreworks Company
