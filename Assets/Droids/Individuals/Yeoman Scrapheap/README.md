# Yeoman Scrapheap

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Yeoman Scrapheap](https://starwars.fandom.com/wiki/Yeoman_Scrapheap)

"Yeoman Scrapheap" was the name the crew of the Mandian gave their protocol droid. It got the name due to the fact that a crewman had stenciled yeoman's stripes onto its forehead.
