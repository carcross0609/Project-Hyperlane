# R5-D33R

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R5-D33R](https://starwars.fandom.com/wiki/R5-D33R)

R5-D33R was an R5 series astromech droid optimized to function in the sub-zero environments of Hoth. He had a white, red, and gold body, and also wore a festive hat decorated with antlers.
