# Unidentified R2 unit (Rookie One)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified R2 unit (Rookie One)](https://starwars.fandom.com/wiki/Unidentified_R2_unit_%28Rookie_One%29)

An R2-series astromech droid was plugged into the T-65 X-wing starfighter "Rookie One" used to escape from the Imperial-overrun Gamma Base. The Rebel pilot subsequently employed this droid in the escort of a GR-75 medium transport fleeing Hoth, as well as in the Battle of Yavin.
