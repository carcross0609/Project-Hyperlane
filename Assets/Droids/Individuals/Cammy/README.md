# Cammy

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Cammy](https://starwars.fandom.com/wiki/Cammy)

Cammy was a Holocam E-series droid who helped a Rebel agent to find and infiltrate an assassin droid factory on Tatooine. She also helped test the droids that the agent built, following them around as they went about their objectives.
