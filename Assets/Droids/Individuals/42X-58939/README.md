# 42X-58939

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [42X-58939](https://starwars.fandom.com/wiki/42X-58939)

42X-58939 was a BX-series droid commando that served the Confederacy of Independent Systems during the Clone Wars. Sometime prior to 9 BBY, the Lucrehulk Primacy crashed on the planet Koboh, where they, along with the rest of the droid army, were reactivated to serve the Bedlam Raiders.
