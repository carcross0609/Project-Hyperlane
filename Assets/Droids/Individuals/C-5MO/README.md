# C-5MO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [C-5MO](https://starwars.fandom.com/wiki/C-5MO)

C-5MO was a silver protocol droid that served as a clerk in a droid shop on the Imperial Remnant capital of Bastion. When trying to escape Imperial forces, C-5MO gave Lando Calrissian and Han Solo permission to use several astromech droids to transmit multitonal signals to jam Imperial frequencies.
