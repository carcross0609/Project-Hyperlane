# EG-07

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [EG-07](https://starwars.fandom.com/wiki/EG-07)

EG-07 was an EG droid purchased by General Grievous in order to be used for covert operations during the Clone Wars. On Mustafar, he was in battle with Jedi Knight Anakin Skywalker. Skywalker and his Padawan, Ahsoka Tano, ensured that EG-07 was destroyed.
