# R5-D8

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-D8/Legends](https://starwars.fandom.com/wiki/R5-D8/Legends)

R5-D8 was an R5-series astromech droid used by Rebel Alliance pilot Jek Tono Porkins. The R5 unit assisted in navigation, in-flight maintenance, and repairs. Porkins had used the droid since he was a part of the Tierfon Yellow Aces. R5-D8 exploded together with Porkins's X-wing during the assault on the first Death Star.
