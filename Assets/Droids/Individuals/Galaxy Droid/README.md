# Galaxy Droid

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Galaxy Droid](https://starwars.fandom.com/wiki/Galaxy_Droid)

The Galaxy Droid was a mysterious droid that had incredible knowledge of the galaxy. It was found by Revan after escaping the Leviathan, the droid was able to find the planet Lehon and even the Star Forge itself.

- **Type:** Sith Empire

- **Model:** Municipal patrol droid Mark I
- **Pronouns:** new

- **Armament:** 2 Blaster pistols
- **Equipment:** None
