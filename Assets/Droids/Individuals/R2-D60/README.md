# R2-D60

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R2-D60](https://starwars.fandom.com/wiki/R2-D60)

R2-D60 was an R2-series astromech droid that was a spy for the Rebel Alliance, but worked on Coruscant serving various members of the Imperial Senate. He was a typical R2 but had an unusual, frosted dome, and included a Burtt acoustic signaller.
