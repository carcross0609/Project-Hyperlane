# Shi-Fara's droid

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Shi-Fara's droid](https://starwars.fandom.com/wiki/Shi-Fara%27s_droid)

A droid was created by the Jedi padawan Shi-Fara in 196 BBY for the science fair at the Jedi academy on Coruscant. After Roan Novachez's baking soda volcano exploded, Shi-Fara's droid cleaned up the mess in fifteen minutes.
