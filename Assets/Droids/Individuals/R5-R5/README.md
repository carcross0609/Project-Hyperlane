# R5-R5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-R5](https://starwars.fandom.com/wiki/R5-R5)

R5-R5 was an R5-series astromech droid produced by Industrial Automaton. Owned by the Gungan trader Toba, R5-R5 helped fly the Gungan's freighter, Sea Killer.
