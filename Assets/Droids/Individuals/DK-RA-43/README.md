# DK-RA-43

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [DK-RA-43](https://starwars.fandom.com/wiki/DK-RA-43)

DK-RA-43 was an RA-7 protocol droid. Originally built for the Galactic Empire in the droid factories of Affa, he ended up with a new master, the Weequay pirate Hondo Ohnaka, under unclear circumstances—the droid was either won in a sabacc game or exchanged for a purebreed Loth-cat and a barrel of Savareen brandy. After a memory wipe, DK-RA-43 was outfitted with databanks extracted from several tourism droids, and ordered to prepare dossiers for a book titled the Galactic Explorer's Guide.
