# Annihilator 6K-A2

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Annihilator 6K-A2](https://starwars.fandom.com/wiki/Annihilator_6K-A2)

Annihilator 6K-A2 was the designation of a Colicoid battle droid that organized war games on the behalf of the Colicoid Creation Nest. It was destroyed around 3642 BBY.
