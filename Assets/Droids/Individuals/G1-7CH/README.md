# G1-7CH

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [G1-7CH](https://starwars.fandom.com/wiki/G1-7CH)

G1-7CH, commonly known as "Glitch," was a hospitality droid that worked at Aunt Z's Tavern. There, he served the clients, and, when necessary, also simulated various odds about the races while Aunt Z managed bets.

- **Type:** Resistance

- **Equipment:** Four DL-44 heavy blaster pistols
- **Affiliation:**
