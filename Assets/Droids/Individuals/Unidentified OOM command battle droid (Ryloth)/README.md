# Unidentified OOM command battle droid (Ryloth)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified OOM command battle droid (Ryloth)](https://starwars.fandom.com/wiki/Unidentified_OOM_command_battle_droid_%28Ryloth%29)

During the Clone Wars, an OOM command battle droid served within the droid army of the Confederacy of Independent Systems. In 22 BBY, the OOM command battle droid participated in the Confederacy's takeover of the planet Ryloth, where they commanded several B1-series battle droids and B2-series super battle droids against a small Galactic Republic garrison of clone troopers.
