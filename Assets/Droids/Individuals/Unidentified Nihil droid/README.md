# Unidentified Nihil droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified Nihil droid](https://starwars.fandom.com/wiki/Unidentified_Nihil_droid)

A droid served in a Cloud within the Nihil marauder organization during the High Republic Era. In 228 BBY, the Cloud kidnapped several Force-sensitive children from a small settlement on the planet Temerancé in the Occlusion Zone, which led the inhabitants of the settlement to request assistance from the Tholothian monster hunter Ty Yorrick to rescue their children.
