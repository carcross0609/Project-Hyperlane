# Jin-Sim's protocol droid

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Jin-Sim's protocol droid](https://starwars.fandom.com/wiki/Jin-Sim%27s_protocol_droid)

Jin-Sim's protocol droid was a protocol droid that served Jin-Sim Canbelon, the CEO of the Zonus Corporation. The droid escorted the bounty hunters Sevn and IV-A4 to Canbelon's office, where he hired them for a job.
