# R4-M9

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R4-M9](https://starwars.fandom.com/wiki/R4-M9)

R4-M9 was an R4 astromech that was a part of the Galactic Empire. It was aboard the Tantive IV after it was disabled in orbit of the planet Tatooine.
