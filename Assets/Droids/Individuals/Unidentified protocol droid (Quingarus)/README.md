# Unidentified protocol droid (Quingarus)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified protocol droid (Quingarus)](https://starwars.fandom.com/wiki/Unidentified_protocol_droid_%28Quingarus%29)

This protocol droid was a protocol droid that served at the Quingarus Deluxe Droid Systems Factory, a droid factory located on a planet close to the Coruscant system. During the Clone Wars, this protocol droid welcomed Obi-Wan Kenobi upon his arrival on the planet.
