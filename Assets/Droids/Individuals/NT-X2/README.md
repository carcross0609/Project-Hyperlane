# NT-X2

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [NT-X2](https://starwars.fandom.com/wiki/NT-X2)

NT-X2 or Entax and his counterpart BT-X2 were designed as a top-of-the-line Imperial assassin droids, however they were stolen mid-transport and ended up working for Luskin Exovar as security guards at Exovar's Emporium.
