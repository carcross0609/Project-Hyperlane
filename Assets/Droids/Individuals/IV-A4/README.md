# IV-A4

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [IV-A4](https://starwars.fandom.com/wiki/IV-A4)

IV-A4 was a droid who worked with the bounty hunter Sevn. He had a split personality and operated as both an assassin droid and a medical droid.
