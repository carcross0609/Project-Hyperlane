# T8-C3

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [T8-C3](https://starwars.fandom.com/wiki/T8-C3)

T8-C3 was an astromech droid belonging to Cin Tykan's expedition on Taris. It survived the attack on the expedition by the Death's Claw pirates and helped a Jedi Knight track Tykan before returning to the Republic base.
