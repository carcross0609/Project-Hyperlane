# 22-X

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [22-X](https://starwars.fandom.com/wiki/22-X)

22-X was a protocol droid that negotiated with the Trade Federation, a galactic megacorporation, and was eventually salvaged by 3 ABY by a group of Jawas on the Outer Rim desert planet Tatooine.
