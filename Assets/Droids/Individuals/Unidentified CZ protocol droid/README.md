# Unidentified CZ protocol droid

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Unidentified CZ protocol droid](https://starwars.fandom.com/wiki/Unidentified_CZ_protocol_droid)

A CZ protocol droid accompanied an R4 astromech droid while the two searched for a village on a planet. Throughout their search, the CZ protocol droid complained and argued with the astromech. At night, the two droids saw a distant fire that the former Sith known as the Ronin had set to burn the body of the Sith Okinaa, the last member of the village. The protocol droid realized they had returned to the same path they had been on previously and continued arguing with the astromech droid.
