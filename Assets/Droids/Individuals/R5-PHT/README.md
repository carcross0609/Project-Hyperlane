# R5-PHT

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R5-PHT](https://starwars.fandom.com/wiki/R5-PHT)

R5-PHT was a black and silver plated R5 series astromech droid that served the Galactic Empire. It was equipped with a Kerner Optical holographic projector and had black sensors. Like all R5 astromech droids, it was manufactured by Industrial Automaton and stood ninety-seven centimeters tall.
