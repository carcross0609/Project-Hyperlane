# ZAN-3L0

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ZAN-3L0](https://starwars.fandom.com/wiki/ZAN-3L0)

ZAN-3LO was a protocol droid that was stationed on Keylander Station. The droid assisted Supreme Chancellor Leontyne Saresh in enlisting the help of the Republic strike force during the time of the Conquest of Makeb.

- **Class:** Protocol droid
