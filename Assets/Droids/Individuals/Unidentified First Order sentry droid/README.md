# Unidentified First Order sentry droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified First Order sentry droid](https://starwars.fandom.com/wiki/Unidentified_First_Order_sentry_droid)

A First Order sentry droid was stationed on the First Order's Station Theta Black, a mining space station. It encountered Resistance members Poe Dameron and Kazuda Xiono in 34 ABY, resulting in its destruction.
