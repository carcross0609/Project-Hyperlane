# Ch'Unkk's protocol droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Ch'Unkk's protocol droid](https://starwars.fandom.com/wiki/Ch%27Unkk%27s_protocol_droid)

A silver protocol droid served as a translator for Spearmaster Ch'Unkk, a Whiphid who sat on the Imperial Interim Ruling Council in 11 ABY. The protocol droid witnessed Ch'Unkk get gunned down by Council head Xandel Carivus's Private Guard.
