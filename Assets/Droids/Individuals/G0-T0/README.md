# G0-T0

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [G0-T0](https://starwars.fandom.com/wiki/G0-T0)

G0-T0, also known as "Goto," was a G0-T0 infrastructure planning system operational circa 3955 – 3951 BBY. He later became head of the Exchange criminal organization on Nar Shaddaa and traveled with the Jedi Exile, Meetra Surik.
