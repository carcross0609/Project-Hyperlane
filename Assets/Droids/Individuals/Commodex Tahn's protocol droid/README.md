# Commodex Tahn's protocol droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Commodex Tahn's protocol droid](https://starwars.fandom.com/wiki/Commodex_Tahn%27s_protocol_droid)

Commodex Tahn owned a protocol droid which he kept at his home on the planet Naboo. The droid was destroyed by BT-1 when Chelli Lona Aphra invaded Tahn's home to forcibly extract information from him. After giving up information under torture, Tahn was killed.

- **Name:** Commodex Tahn's protocol droid

- **Class:** Protocol droid
