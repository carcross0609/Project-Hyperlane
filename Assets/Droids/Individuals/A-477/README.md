# A-477

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [A-477](https://starwars.fandom.com/wiki/A-477)

A-477 was a security droid that worked for the casino cruiser Morenia in 3 ABY. That year, A-477 dispatched a report to the ship's database which detailed the cheating habits of a Quarren gambler named Ultus. The report noted that Ultus was a habitual cheater who played with his chips to distract other players when he was palming a card with his other hand.

## Specifications

- **Name:** A-477
- **Class:** Security droid
- **Affiliation:** Morenia
