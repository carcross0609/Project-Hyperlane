# Lux

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Lux](https://starwars.fandom.com/wiki/Lux)

Lux was a modified Seeker droid who was used for security in the Glow Dome a nightclub located on the planet Adarlon. He was heavily armed and modified by Dr. Lytos Urtell.
