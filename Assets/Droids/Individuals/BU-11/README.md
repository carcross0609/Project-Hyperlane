# BU-11

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BU-11](https://starwars.fandom.com/wiki/BU-11)

BU-11 was a BU-series bartender droid who worked in Ziro's Palace during the Clone Wars. It served a Trandoshan a glowing green cup. It reacted as Senator Padmé Amidala entered the room with HELIOS-3D.
