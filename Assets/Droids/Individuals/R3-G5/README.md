# R3-G5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R3-G5](https://starwars.fandom.com/wiki/R3-G5)

R3-G5 was an astromech droid in service of the Sith Empire. Stationed on Onderon, it urged imperials to contact Major Annette Miran.
