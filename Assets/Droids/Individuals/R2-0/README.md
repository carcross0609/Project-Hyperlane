# R2-0

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-0](https://starwars.fandom.com/wiki/R2-0)

R2-0, known as Artoo-Oh or ArOh, was the original prototype of the R2-series astromech droid. It was an ancient astromech droid with a brass casing, probably built well before 32 BBY.

- **Name:** R2-0
- **Manufacturer:** Industrial Automaton
- **Line:** R-series
- **Model:** R2-series astromech droid
