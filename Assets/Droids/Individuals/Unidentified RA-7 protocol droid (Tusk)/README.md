# Unidentified RA-7 protocol droid (Tusk)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified RA-7 protocol droid (Tusk)](https://starwars.fandom.com/wiki/Unidentified_RA-7_protocol_droid_%28Tusk%29)

An RA-7 protocol droid served the criminal Tusk on the world Ergeshui during the Imperial Era. Between 2 BBY and 4 ABY, the protocol droid gave the bounty hunter Boba Fett credits after he had delivered a human bounty to Tusk.
