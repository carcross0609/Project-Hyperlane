# TD-H4

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [TD-H4](https://starwars.fandom.com/wiki/TD-H4)

TD-H4, nicknamed "Tool" or "Die," was a droid believed to be centuries old. He was part of the Droid Gotra and befriended a young Han Solo on Corellia.
