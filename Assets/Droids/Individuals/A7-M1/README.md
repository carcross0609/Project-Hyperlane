# A7-M1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [A7-M1](https://starwars.fandom.com/wiki/A7-M1)

A7-M1 was an astromech droid that served the Sith Lord Lana Beniko as a messenger on Vaiken Spacedock during the Galactic War between the reconsituted Sith Empire and the Galactic Republic.
