# C1-MNST4

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [C1-MNST4](https://starwars.fandom.com/wiki/C1-MNST4)

C1-MNST4 was a C1-series astromech droid that was constructed using spare parts of other droids on the planet Coruscant. The droid was colored in green, purple, brown and black.

## Specifications

- **Name:** C1-MNST4
- **Homeworld:** Coruscant
- **Line:** C-series
- **Model:** C1-series astromech droid
- **Class:** Astromech droid
- **Gender:** Masculine programming
- **Pronouns:** He/him
- **Sensor:** Black
- **Plating:** Green, purple, brown, black
- **Equipment:**
  - Communications array
  - Electro-shock prods
  - Front repair arm
  - Retractable arms
  - Rocket booster
