# R77

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R77](https://starwars.fandom.com/wiki/R77)

R77 was one of the many super battle droids active in the Confederacy military. R77 served aboard the Invisible Hand, the command ship of General Grievous.
