# Fern's nanny droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Fern's nanny droid](https://starwars.fandom.com/wiki/Fern%27s_nanny_droid)

Fern's nanny droid was a nanny droid that belonged to Fara and Fern. Fern was able to override the droids memory to convince it of false events. Around 9 ABY, Fern used an memory override to plant the false idea that she was upstairs studying, despite getting home after her mom got home early.

## Specifications

- **Name:** Fern's nanny droid
- **Homeworld:** At Attin
- **Model:** Service droid
- **Affiliation:**
  - Fara
  - Fern
