# C1-D1

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [C1-D1](https://starwars.fandom.com/wiki/C1-D1)

C1-D1, or See-One for short, was a protocol droid working at the control centre for the Santhe Shipyards in Coronet City, on the planet Corellia during the dismantling of the Imperial fleet for the New Republic. Her function was catalogue inventory on arriving transports.
