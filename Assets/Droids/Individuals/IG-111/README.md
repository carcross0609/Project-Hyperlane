# IG-111

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [IG-111](https://starwars.fandom.com/wiki/IG-111)

IG-111, nicknamed "One Eye," was an IG-100 MagnaGuard of the Confederacy of Independent Systems, serving during the pan-galactic Clone Wars against the Galactic Republic. IG-111 piloted a Rogue-class Porax-38 starfighter above a terrestrial object in space, and fired the starfighter's weaponry.
