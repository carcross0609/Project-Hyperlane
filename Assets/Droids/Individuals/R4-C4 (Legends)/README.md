# R4-C4

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R4-C4/Legends](https://starwars.fandom.com/wiki/R4-C4/Legends)

R4-C4 was an astromech droid that served during the time of the Clone Wars. A unit with a "flower pot"–shaped head almost as tall as its body, the droid was fitted with extra processing power to calculate hyperspace coordinates.
