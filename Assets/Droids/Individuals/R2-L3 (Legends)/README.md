# R2-L3

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-L3/Legends](https://starwars.fandom.com/wiki/R2-L3/Legends)

R2-L3 was an astromech droid present in Mos Espa during the time that Anakin Skywalker went to ask Watto about Shmi Skywalker's whereabouts. R2-L3 had a red body with blue and yellow panels.
