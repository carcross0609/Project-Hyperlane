# MZ-12

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [MZ-12](https://starwars.fandom.com/wiki/MZ-12)

MZ-12 was an astromech droid that once served under Darth Immern. Despite not being programmed for it, MZ-12 was used by Immern as a navigator.
