# Toborro's Glittering Fury

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Toborro's Glittering Fury](https://starwars.fandom.com/wiki/Toborro%27s_Glittering_Fury)

Toborro's Glittering Fury was a golden isotope-5 droid built for the personal use of Supreme Mogul Toborro. It was ultimately destroyed in Toborro's Palace shortly before Toborro's own death.
