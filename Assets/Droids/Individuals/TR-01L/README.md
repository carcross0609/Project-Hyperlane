# TR-01L

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [TR-01L](https://starwars.fandom.com/wiki/TR-01L)

TR-01L was a security droid owned by the Guavian Death Gang on Batuu. In 34 ABY, TR-01L was encountered by C-3PO and a droid repair technician, who attempted to negotiate with it in order to rescue R2-D2 from the Guavian Death Gang.
