# Unidentified OOM-series security droid corporal

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified OOM-series security droid corporal](https://starwars.fandom.com/wiki/Unidentified_OOM-series_security_droid_corporal)

An OOM-series security droid was stationed on the Saak'ak before the Invasion of Naboo. It held the rank of corporal, and was destroyed when the Jedi Master Qui-Gon Jinn used his Lightsaber to deflect energy blasts at it.
