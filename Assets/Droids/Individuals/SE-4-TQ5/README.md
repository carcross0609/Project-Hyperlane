# SE-4-TQ5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [SE-4-TQ5](https://starwars.fandom.com/wiki/SE-4-TQ5)

SE-4-TQ5 was an SE4 servant droid assigned to the New Republic CR90 corvette FarStar. It had a "smashing way" with fruit, and was assigned on a semi-permanent basis to the ship's mess hall.
