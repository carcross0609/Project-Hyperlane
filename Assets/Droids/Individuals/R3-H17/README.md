# R3-H17

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R3-H17](https://starwars.fandom.com/wiki/R3-H17)

R3-H17 was an R3-series astromech droid bearing festive gold, green and white color plating. The droid had a grasping arm extending from his head, which in one instance held a leafy branch with a red bow tied to it. The astromech was optimized to serve Naboo's Royal Advisory Council.
