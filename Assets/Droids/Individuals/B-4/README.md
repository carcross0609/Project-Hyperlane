# B-4

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [B-4](https://starwars.fandom.com/wiki/B-4)

B-4 was a droid who served the Galactic Republic, and was supposed to be assigned to Colonel Meebur Gascon to be part of D-Squad during the Clone Wars. However, B-4 was not present for the meeting.
