# Unidentified OOM security battle droid (Dathomir)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified OOM security battle droid (Dathomir)](https://starwars.fandom.com/wiki/Unidentified_OOM_security_battle_droid_%28Dathomir%29)

An unidentified OOM security battle droid was stationed inside Separatist Supreme Commander General Grievous's Providence-class carrier/destroyer. Around 21 BBY, during the Battle of Dathomir, he reported to Grievous that the fleet was approaching the planet of Dathomir.
