# R4-I9

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R4-I9/Legends](https://starwars.fandom.com/wiki/R4-I9/Legends)

R4-I9 was an R4 astromech droid painted a dark blue. It was owned by the Galactic Empire. R4 patrolled the halls of the first Death Star during 0 BBY, where it performed maintenance tasks.
