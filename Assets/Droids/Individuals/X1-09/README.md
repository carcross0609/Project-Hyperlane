# X1-09

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [X1-09](https://starwars.fandom.com/wiki/X1-09)

X1-09 was an astromech droid during the Galactic War. Stationed on the Vaiken Spacedock, X1-09 asked an Imperial to rendezvous with Moff Phennir on the cruiser White Nova.
