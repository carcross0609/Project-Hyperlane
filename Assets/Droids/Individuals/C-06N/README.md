# C-06N

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [C-06N](https://starwars.fandom.com/wiki/C-06N)

C-06N, also know as See-Zerosixen, See-Ohsixen, Sixen, or Six-En, for short, was a protocol droid who was stranded inside the Nihil Occlusion Zone with Republic Defense Coalition Lieutenant Visma Tarko and Corporal Elping Tsoo.
