# I4-K8

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [I4-K8](https://starwars.fandom.com/wiki/I4-K8)

I4-K8 was a Battle droid produced at some point before the war against Zakuul. By 3630 BBY it was used by renegade Sith Lords Adacin and Zanisk to guard the base they set in the former Separatist stronghold on Ord Mantell. When the Eternal Alliance forces attacked the base, I4-K8 was deployed to stop them, but was destroyed.
