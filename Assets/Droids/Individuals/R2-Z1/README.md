# R2-Z1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-Z1](https://starwars.fandom.com/wiki/R2-Z1)

R2-Z1, pronounced Artoo-ZeeOne, was an astromech droid owned by a Bothan diplomat by the name of Tereb Ab'Lon. The droid was nicknamed Fweep.
