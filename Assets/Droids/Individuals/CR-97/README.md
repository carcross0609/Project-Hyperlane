# CR-97

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [CR-97](https://starwars.fandom.com/wiki/CR-97)

CR-97 was a personal droid of the Sith Lord Darth Zhorrid during the Cold War. In 3643 BBY it contacted an Imperial Agent Cipher Nine through a hologram, after which his master sent the agent to find Vyord Yanol on Nar Shaddaa.
