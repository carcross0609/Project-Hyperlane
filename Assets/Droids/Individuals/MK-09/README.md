# MK-09

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [MK-09](https://starwars.fandom.com/wiki/MK-09)

MK-09 was a droid owned by Ace Azzameen, a member of the Azzameen family. At some point, MK-09 began to co-pilot the family's YT-2000 Otana.
