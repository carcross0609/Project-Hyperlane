# Xenoanalyst II

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Xenoanalyst II](https://starwars.fandom.com/wiki/Xenoanalyst_II)

Xenoanalyst II was the designation of a Gree battle droid that was present in 3638 BBY aboard the Gray Secant. It was programmed to challenge visitors to combat for ability evaluation.
