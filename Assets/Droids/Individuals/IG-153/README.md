# IG-153

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [IG-153](https://starwars.fandom.com/wiki/IG-153)

IG-153 was an IG-100 MagnaGuard that survived the Clone Wars. During the Galactic Civil War, it fell into the service of Grand Moff 4-8C as a bodyguard.
