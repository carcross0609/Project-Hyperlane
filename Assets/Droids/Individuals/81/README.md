# 81

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [81](https://starwars.fandom.com/wiki/81)

81 was the designation of an OG-9 homing spider droid produced by Baktoid Armor Workshop for the Commerce Guild. Unit 81 fought in the Battle of Geonosis that marked the beginning of the Clone Wars.
