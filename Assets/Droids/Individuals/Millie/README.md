# Millie

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Millie](https://starwars.fandom.com/wiki/Millie)

"Millie" was the name given to a MILL-247-EE emergency service droid on Tem Chesko's freighter. She had a female personality, and was built to resemble a green-skinned humanoid female. She had blue sensors.

- **Model:** MILL-247-EE industrial droid
