# L6-2O

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [L6-2O](https://starwars.fandom.com/wiki/L6-2O)

L6-2O was a droid that worked for the casino cruiser Morenia in 3 ABY. That year, L6-2O wrote a maintenance report about the status of the cruiser's luggage conveyor after its main motivator abruptly halted. In the report, the droid explained that convey would be a complex repair since the original parts were manufactured by Gallofree Yards, Inc. which was bankrupt by that year.
