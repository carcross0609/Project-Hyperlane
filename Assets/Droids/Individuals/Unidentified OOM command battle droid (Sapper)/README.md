# Unidentified OOM command battle droid (Sapper)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified OOM command battle droid (Sapper)](https://starwars.fandom.com/wiki/Unidentified_OOM_command_battle_droid_%28Sapper%29)

A OOM command battle droid served the Confederacy of Independent Systems in the Separatist Droid Army during the Clone Wars. While stationed on Sapper, the droid was destroyed by Clone Force 99 in their mission to rescue a ghost agent stationed at the Separatist waystation on the world.
