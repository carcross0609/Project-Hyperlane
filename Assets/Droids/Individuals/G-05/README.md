# G-05

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [G-05](https://starwars.fandom.com/wiki/G-05)

G-05 was a probe droid located by Corellia's Coronet Spaceport during the Galactic War. It was used by the Imperial agent Hazeen to contact an Imperial-affiliated individual regarding Corellian rebel activities.
