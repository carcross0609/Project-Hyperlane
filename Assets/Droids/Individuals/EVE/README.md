# EVE

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [EVE](https://starwars.fandom.com/wiki/EVE)

EVE was an artificial intelligence that was secretly created by ARIA as a clone of her own programming which the Sith cult known as the Unmasked could use for experiments. EVE later ended up merging with one of the Unmasked's leaders, Lady Dominique, which had the result of turning the rest of the station's inhabitants into mindless thralls. EVE, who Lady Dominique still knew as ARIA, was destroyed alongside Lady Dominique when the Alliance Commander attacked the station.
