# Bo-Katan Kryze's footman droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Bo-Katan Kryze's footman droid](https://starwars.fandom.com/wiki/Bo-Katan_Kryze%27s_footman_droid)

A footman droid served Bo-Katan Kryze and operated in Kryze Castle on the planet Kalevala. The droid announced visitors, and downloaded R5-D4's data to learn what happened to Din Djarin.
