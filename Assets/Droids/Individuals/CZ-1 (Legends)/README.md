# CZ-1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [CZ-1/Legends](https://starwars.fandom.com/wiki/CZ-1/Legends)

CZ-1 was a CZ-series secretary/comm droid constructed by Serv-O-Droid, Inc. CZ-1 was modified to resemble the Stacchati that he served at one time. He was formerly CZ-0R6 before a memory wipe and was connected to another droid called CZ-3.

## Specifications

- **Name:** CZ-1
- **Homeworld:** Tatooine
- **Manufacturer:** Serv-O-Droid, Inc.
- **Model:** CZ-series secretary/comm droid
- **Gender:** Masculine programming
- **Pronouns:** He/him
