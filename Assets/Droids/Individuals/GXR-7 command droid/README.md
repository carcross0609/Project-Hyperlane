# GXR-7 command droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [GXR-7 command droid](https://starwars.fandom.com/wiki/GXR-7_command_droid)

GXR-7 command droid was a battle droid of the Galactic Republic active during the Cold War. In 3643 BBY it was aboard the Thranta-class corvette Brentaal Star during the Attack on the Brentaal Star by the Gage-class transport Black Talon and was destroyed by an Imperial boarding party.
