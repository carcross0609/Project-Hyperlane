# R5-D7

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-D7](https://starwars.fandom.com/wiki/R5-D7)

R5-D7 was a Republic droid that captured the blueprints of the battle droid and the data of the Lucrehulk-class Droid Control Ship for the Republic. He was probably destroyed by Anakin Skywalker when he destroyed the Droid Control Ship over Naboo.
