# ISO-5R

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ISO-5R](https://starwars.fandom.com/wiki/ISO-5R)

ISO-5R was a type of battle droid that Hutt-employed scientists had designed and manufactured. It was later decommissioned from Makeb and used to serve more civilian needs.
