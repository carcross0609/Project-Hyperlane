# R1-Q10

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [R1-Q10](https://starwars.fandom.com/wiki/R1-Q10)

R1-Q10 was an R1-series astromech droid who wore a hat. The R-series astromech droid was at some point present near moisture vaporators in a village on the Outer Rim planet Genbara sometime after the Sith rebellion.
