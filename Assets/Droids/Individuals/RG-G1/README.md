# RG-G1

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [RG-G1](https://starwars.fandom.com/wiki/RG-G1)

RG-G1, nicknamed G-G, was an astromech droid with feminine programming that served the Galactic Republic during the Clone Wars. When Order 66 was executed, G-G assisted the former Jedi Padawan Ahsoka Tano, alongside astromech droids CH-33P and R7-A7, in locating information on ARC trooper CT-5555 "Fives" and later capturing Clone Commander CT-7567 "Rex" to remove his control chip. G-G, alongside Cheep, was subsequently destroyed by mind-controlled clones while assisting Tano and Rex's escape from the doomed Star Destroyer.
