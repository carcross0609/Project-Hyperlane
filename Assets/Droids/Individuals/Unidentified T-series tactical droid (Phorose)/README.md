# Unidentified T-series tactical droid (Phorose)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified T-series tactical droid (Phorose)](https://starwars.fandom.com/wiki/Unidentified_T-series_tactical_droid_%28Phorose%29)
