# Roll-On

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Roll-On](https://starwars.fandom.com/wiki/Roll-On)

Roll-On was the name given to the R2 astromech droid used by Wedge Antilles as of 43.5 ABY. He was present when Antilles assisted during a hasty operation to prevent the destruction of Kessel.

## Specifications

- **Name:** "Roll-On"
- **Manufacturer:** Industrial Automaton

- **Model:** R2-series astromech droid
- **Class:** Astromech droid

- **Pronouns:** new
