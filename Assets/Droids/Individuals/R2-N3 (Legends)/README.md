# R2-N3

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-N3/Legends](https://starwars.fandom.com/wiki/R2-N3/Legends)

R2-N3 was a green R2-series astromech droid. This droid, along with R2-M5, was blasted off the hull while fixing an imbalance on the starboard engines on Queen Padmé Amidala's ship while escaping the Trade Federation blockade of Naboo. The other droids R2-R9, R2-B1 and G8-R3 were destroyed outright.
