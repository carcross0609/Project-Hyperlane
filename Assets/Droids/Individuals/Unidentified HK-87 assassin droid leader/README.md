# Unidentified HK-87 assassin droid leader

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified HK-87 assassin droid leader](https://starwars.fandom.com/wiki/Unidentified_HK-87_assassin_droid_leader)

An HK-87 droid leader was in command of a unit of HK-87 assassin droids serving Witch Morgan Elsbeth. The droid had a dark grey photoreceptor and was painted in dark red. It carried an electrostaff and wore a tattered grey cloak.
