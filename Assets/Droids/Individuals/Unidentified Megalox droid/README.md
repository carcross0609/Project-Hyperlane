# Unidentified Megalox droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified Megalox droid](https://starwars.fandom.com/wiki/Unidentified_Megalox_droid)

During the Mission to Megalox Beta, BB-8 and the other Black Squadron astromech droids O-R10N, R2-HA, and R4 encountered a large security droid. The droid destroyed O-R10N but was electrocuted and disabled by BB-8.
