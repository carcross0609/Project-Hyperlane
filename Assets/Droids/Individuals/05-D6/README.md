# 05-D6

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [05-D6](https://starwars.fandom.com/wiki/05-D6)

05-D6 was a protocol droid affiliated with the Galactic Republic active during the Galactic War with the reconstituted Sith Empire. It was stationed on the Macula Station above Belsavis around 3641 BBY, where he gave information about the prison to the newly-arrived and authorized personnel.
