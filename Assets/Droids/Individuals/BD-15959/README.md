# BD-15959

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BD-15959](https://starwars.fandom.com/wiki/BD-15959)

BD-15959 was an OOM-series security droid in the Separatist Droid Army stationed on a Dual Hemisphere-Omni Support Vessel during the Clone Wars. The droid was destroyed by Anakin Skywalker when Obi-Wan Kenobi escaped from his prison cell.
