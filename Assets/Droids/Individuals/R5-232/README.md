# R5-232

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R5-232](https://starwars.fandom.com/wiki/R5-232)

R5-232 was an R5 series astromech droid with white, black, grey and blue plating and silver sensors. Like all R5 astromech droids, it was manufactured by Industrial Automaton and stood ninety-seven centimeters tall.
