# R-C92

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R-C92](https://starwars.fandom.com/wiki/R-C92)

R-C92 was a model of protocol droid that was stationed on the Imperial Orbital Station orbiting the planet Makeb. The droid assisted Darth Marr in enlisting the help of the Imperial strike team during the time of the Conquest of Makeb.
