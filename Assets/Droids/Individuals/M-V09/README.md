# M-V09

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [M-V09](https://starwars.fandom.com/wiki/M-V09)

M-V09 was a protocol droid used by the Sith Empire during the Galactic War. In 3639 BBY it was stationed on the Harrower-class dreadnought Ziost Shadow.
