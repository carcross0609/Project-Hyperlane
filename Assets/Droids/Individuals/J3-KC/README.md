# J3-KC

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [J3-KC](https://starwars.fandom.com/wiki/J3-KC)

J3-KC was an R5 series astromech droid owned by Jat Kaa's Coolers on Batuu. The droid drove a ground vehicle that carried Coca-Cola beverages that were sold in Black Spire Outpost. The droid's red-and-white color scheme matched that of the vehicle, themed to the Coca-Cola logo.
