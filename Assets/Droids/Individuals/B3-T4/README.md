# B3-T4

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [B3-T4](https://starwars.fandom.com/wiki/B3-T4)

B3-T4 was an R2-series astromech droid with blue and white plating. Active during the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems, it was built by Industrial Automaton like all R-series astromech droids. B3-T4 stood at 0.96 meters tall.
