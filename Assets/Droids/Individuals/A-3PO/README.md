# A-3PO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [A-3PO](https://starwars.fandom.com/wiki/A-3PO)

A-3PO was a silver protocol droid that was owned by Retter Lewis aboard the Cal Ambre and was an assistant and translator at Callia's.
