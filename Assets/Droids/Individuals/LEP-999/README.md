# LEP-999

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [LEP-999](https://starwars.fandom.com/wiki/LEP-999)

LEP-999, or "LEP" for short, was an LEP-series service droid that worked for the Hassarian Separatist general Kazameer.
