# DUM-22

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [DUM-22](https://starwars.fandom.com/wiki/DUM-22)

DUM-22 was a DUM-series pit droid that was manufactured by Serv-O-Droid. The repair droid could fold itself up like all pit droids and was skilled in maintaining airspeeders. The droid stood at 1.19 meters, or 3 feet and 11 inches, tall. DUM-22 had a yellow sensor and copper plating. It carried a wrench.
