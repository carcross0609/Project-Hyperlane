# R4 (Rebel Alliance)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R4 (Rebel Alliance)](https://starwars.fandom.com/wiki/R4_%28Rebel_Alliance%29)

R4 was an R-series astromech droid that flew with Scout Two. Along with Scout Two and Scout Three, R4 was destroyed when they discovered the First Death Star.
