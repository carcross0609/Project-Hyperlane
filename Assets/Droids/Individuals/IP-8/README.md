# IP-8

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [IP-8](https://starwars.fandom.com/wiki/IP-8)

IP-8 was an astromech droid at an Imperial base on Argavat. Rebel spy, Ensign Waldron was undercover in the base as a stormtrooper, where he stole Imperial Battle Codes. When the theft (but not the culprit) was discovered, Waldron hid the codes inside IP-8 until Luke Skywalker infiltrated the base and retrieved them.
