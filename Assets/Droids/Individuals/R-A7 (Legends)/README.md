# R-A7

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R-A7/Legends](https://starwars.fandom.com/wiki/R-A7/Legends)

R-A7 was an RA-7 protocol droid that accompanied MR-T3, an astromech droid in the Republic military base in 20 BBY, when Padawan Ahsoka Tano escaped from the base, after being suspected with murdering Letta Turmond. As Tano was running away from the clone shock troopers, she quickly jumped over MR-T3, causing the droid to spin around.
