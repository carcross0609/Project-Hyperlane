# R4-6D0

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R4-6D0](https://starwars.fandom.com/wiki/R4-6D0)

R4-6D0 was the personal R4 astromech droid of High Magistrate Greef Karga on Nevarro. When the Pirate Nation attacked Nevarro, the droid sent a message to the New Republic asking for aid.
