# AG-15

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [AG-15](https://starwars.fandom.com/wiki/AG-15)

AG-15 was a droid used by Doctor Larek on Belsavis during the Galactic War. AG-16, AG-15, and a number of additional droids were sent out to locate ancient Rakata security droids and extract their memory cores, but the droids were destroyed before they could do so.

## Specifications

- **Name:** AG-15
- **Death:** c. 3641 BBY, Belsavis
- **Pronouns:** new
- **Affiliation:** Galactic Republic
