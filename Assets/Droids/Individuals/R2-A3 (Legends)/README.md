# R2-A3

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-A3/Legends](https://starwars.fandom.com/wiki/R2-A3/Legends)

R2-A3 was an R2 series astromech droid used aboard Wedge Antilles' X-wing starfighter during his time stationed at the Massassi Base on Yavin 4, and aboard the Mon Calamari Star Cruiser Home One.
