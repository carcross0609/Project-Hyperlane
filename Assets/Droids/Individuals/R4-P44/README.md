# R4-P44

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R4-P44](https://starwars.fandom.com/wiki/R4-P44)

R4-P44 was a R4-P Astromech that was assigned to Jedi General Obi-Wan Kenobi's clone trooper forces while stationed on Utapau. The droid, like R4-P17 and R4-G9, had the dome of a R2 unit.
