# ST0-48

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ST0-48](https://starwars.fandom.com/wiki/ST0-48)

ST0-48, or Esteeoh-Four Eight, was an Imperial medical droid later repurposed to be a mixicologist at Chabak's casino in the Zirtran's Anchor space station.

- **Type:** Galactic Empire
- **Name:** ST0-48
- **Homeworld:** Coruscant

  - Vocabulator
- **Affiliation:**
