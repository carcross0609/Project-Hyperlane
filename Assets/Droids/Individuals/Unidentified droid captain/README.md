# Unidentified droid captain

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified droid captain](https://starwars.fandom.com/wiki/Unidentified_droid_captain)

A droid served as a captain aboard Count Dooku's frigate during the Clone Wars. When the frigate came across Anakin Skywalker's damaged Delta-7B aethersprite-class light interceptor drifting in an ice field, the droid ordered that the starfighter be brought aboard for closer inspection. The captain also prepared a security detachment in the event of any surprises; this proved to be a useful precaution as it turned out that the starfighter belonged to Anakin Skywalker, who was still aboard.
