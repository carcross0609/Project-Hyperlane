# Sevens

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Sevens](https://starwars.fandom.com/wiki/Sevens)

Sevens was a droid that served as the personnel aide to Field Marshal Tozen in the Bethune army. It had a wired communication device that was stored in its head.

- **Name:** Sevens
- **Sensor:** Blue
