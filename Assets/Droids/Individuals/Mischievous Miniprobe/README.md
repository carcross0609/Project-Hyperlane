# Mischievous Miniprobe

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Mischievous Miniprobe](https://starwars.fandom.com/wiki/Mischievous_Miniprobe)

The Mischievous Miniprobe was a model of floating miniprobe probe droid available around 3627 BBY. This small droid came equipped with a confetti launcher attached to its underside.
