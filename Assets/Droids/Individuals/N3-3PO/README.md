# N3-3PO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [N3-3PO](https://starwars.fandom.com/wiki/N3-3PO)

N3-3PO was a metallic green protocol droid owned by Tol Pirilian. N3-3PO and Pirilian's other droid, N4-3PO, could use over six million forms of communication, and often communicated using obscure languages.

## Specifications

- **Name:** N3-3PO
- **Class:** Protocol droid.
- **Pronouns:** new
- **Plating:** Metallic green
