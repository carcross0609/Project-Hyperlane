# R4-P44

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R4-P44/Legends](https://starwars.fandom.com/wiki/R4-P44/Legends)

R4-P44 was a R4-series astromech droid that was assigned to Jedi General Obi-Wan Kenobi's clone trooper forces while stationed on Utapau. It was used aboard an ARC-170 starfighter of the Fifth Fleet. The droid, like R4-P17 and R4-G9, had the dome of an R2 unit.
