# J-9SB

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [J-9SB](https://starwars.fandom.com/wiki/J-9SB)

J-9SB was a protocol droid that acted as an informal ambassador at the Soco-Jarel Spaceport on Socorro. The glossy-black plated droid tended to the needs of visiting VIPs while also serving as an undercover agent searching for Imperial custom officers and police.
