# SE-4-17

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [SE-4-17](https://starwars.fandom.com/wiki/SE-4-17)

SE-4-17 was an SE4 servant droid assigned to the New Republic CR90 corvette FarStar. It had a matte black finish, and was the assistant to DD-19 in the ship's droid repair bay.
