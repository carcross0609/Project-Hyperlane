# SD-7 (Galactic Empire)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [SD-7 (Galactic Empire)](https://starwars.fandom.com/wiki/SD-7_%28Galactic_Empire%29)

SD-7 was an Imperial Communications droid, serving as assistant to IMP-22. SD-7's main function was to relay messages from Imperial agents around the galaxy to a high ranking Imperial commander that IMP-22 and SD-7 served. SD-7 communicated in droidspeak.
