# R2-Q8

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-Q8](https://starwars.fandom.com/wiki/R2-Q8)

R2-Q8 was an R2-series astromech droid. The companion of Rebel agent Shaparo, R2-Q8's Intellex IV droid brain was modified by his owner to access the prison records of the Dnalvec garrison on Sriluur.
