# Unidentified OOM command battle droid (Anaxes)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified OOM command battle droid (Anaxes)](https://starwars.fandom.com/wiki/Unidentified_OOM_command_battle_droid_%28Anaxes%29)

This OOM command battle droid served as a guard at the Cyber Center on the planet Anaxes in the Azure system. Admiral Trench informed the droid that a group of clones were approaching to attack the center. Trench advised that the battle droids stay alert for the clones. The OOM droid asked Trench when the attack would begin, but was destroyed by CT-7567 "Rex".
