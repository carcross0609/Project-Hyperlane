# X1-02

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [X1-02](https://starwars.fandom.com/wiki/X1-02)

X1-02 was the designation of a astromech droid of the reconstituted Sith Empire during the Cold War. It relayed to Imperial forces a transmission from Darth Malgus.

- **Type:** Sith Empire

- **Class:** Astromech droid
