# SCr-114

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [SCr-114](https://starwars.fandom.com/wiki/SCr-114)

SCr-114 or "Skar" was originally a maintenance droid aboard the pleasure cruiser Malka'an Eternal, who turned into an assassin droid.

## Specifications

- **Name:** SCr-114"Skar"
- **Model:** Maintenance droid model
- **Class:** Assassin droid (originally maintenance droid)
- **Gender:** Masculine programming
- **Sensor:** Human and infrared range
- **Armament:**
  - Various built-in weapons
  - Blaster rifle
  - 2 heavy blaster pistols
  - Grenade launcher
- **Equipment:**
  - Human range sensor recorder
  - Infrared sensor recorder
  - High-sensitivity audio receptors
  - Fire extinguisher
  - Comlink
  - Electronic lockpick
- **Affiliation:** Neutral
