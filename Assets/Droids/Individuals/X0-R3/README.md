# X0-R3

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [X0-R3](https://starwars.fandom.com/wiki/X0-R3)

X0-R3 was a kitchen droid that served the Rebel Alliance at Echo Base on the planet Hoth under Lieutenant Harlize Dana. The droid worked alongside Chase Wilsorr during one shift, dicing peeled tubers.

## Specifications

- **Type:** Rebel
- **Name:** X0-R3
- **Class:** Kitchen droid
- **Affiliation:** Alliance to Restore the Republic
