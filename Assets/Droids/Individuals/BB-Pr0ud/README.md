# BB-Pr0ud

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BB-Pr0ud](https://starwars.fandom.com/wiki/BB-Pr0ud)

BB-PR0UD was a multicolored BB-series astromech droid. The droid once attended a large celebration on Naboo's capital, Theed, where the Great Municipal Band performed.
