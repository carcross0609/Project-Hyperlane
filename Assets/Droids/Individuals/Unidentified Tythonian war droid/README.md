# Unidentified Tythonian war droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified Tythonian war droid](https://starwars.fandom.com/wiki/Unidentified_Tythonian_war_droid)

A Tythonian War Droid guarded the grave of the Weapon Master on the planet Tython. It directed the Padawan of Jedi Master Yuon Par to a set of challenges in order to be granted access to the hilt of the First Blade.
