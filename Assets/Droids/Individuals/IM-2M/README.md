# IM-2M

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [IM-2M](https://starwars.fandom.com/wiki/IM-2M)

IM-2M was an IM series security droid manufactured by Droid Security Systems and stationed in the Star Tours terminal of Spaceport THX1138 by about the year 1 BBY. It had multiple black, red, and white sensors, as well as blue and silver plating.

## Specifications

- **Name:** IM-2M

- **Model:** IM series
- **Class:** Security droid

- **Plating:** Blue and silver
- **Affiliation:** Spaceport THX1138
