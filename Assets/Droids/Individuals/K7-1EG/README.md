# K7-1EG

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [K7-1EG](https://starwars.fandom.com/wiki/K7-1EG)

K7-1EG, known as "Wuniji," was a server droid who worked at the Lomi Usqi Noodle Shop in Point Ueda on the planet Ueda during the High Republic Era. In 132 BBY, the droid carried menbachi bowls through the shop before pausing to re-estimate the appetite of patron Kesmer Faloodi.

## Specifications

- **Name:** K7-1EG
- **Class:** Server droid
- **Sensor:** Red
- **Plating:** Bronze
- **Affiliation:** Lomi Usqi Noodle Shop
