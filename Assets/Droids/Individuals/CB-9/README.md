# CB-9

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [CB-9](https://starwars.fandom.com/wiki/CB-9)

CB-9 was an astromech droid who served the New Republic's Alphabet Squadron as the droid of Yrica Quell. CB-9 replaced Quell's previous astromech D6-L after it was destroyed in a crash on Pandem Nai.
