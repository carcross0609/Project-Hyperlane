# Unidentified baker droid

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified baker droid/Legends](https://starwars.fandom.com/wiki/Unidentified_baker_droid/Legends)

This baker droid was employed by Senator Padmé Amidala to cater a function in honor of Senator Aang, whom she was trying to sway as the deciding vote on a bill she hoped to pass in the Senate. The droid shared the same design as a 2-1B surgical droid.
