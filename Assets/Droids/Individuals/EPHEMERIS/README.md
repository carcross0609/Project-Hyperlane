# EPHEMERIS

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [EPHEMERIS](https://starwars.fandom.com/wiki/EPHEMERIS)

EPHEMERIS droids was a series of multi-tasking droids used by the Eternal Empire of Zakuul. Combining the mathematical features of Class one droids, administrative functions of Class three droids and combat capabilities of Class four droids, EPHEMERIS droids were used to run the Star Fortresses, a series of battlestation placed in orbit of multiple galactic worlds following the Eternal Empire conquest.
