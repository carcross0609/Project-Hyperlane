# J5-KC

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [J5-KC](https://starwars.fandom.com/wiki/J5-KC)

J5-KC was an R2-series astromech droid owned by Jat Kaa's Coolers on Batuu. The droid drove a ground vehicle that carried Diet Coke beverages that were sold in Black Spire Outpost. The droid's red-and-white color scheme matched that of the vehicle, themed to the Diet Coke logo.

## Specifications

- **Name:** J5-KC
- **Line:** R-series
- **Model:** R2-series astromech droid
- **Class:** Astromech droid
- **Sensor:** Black
- **Plating:** Red and white
- **Affiliation:** Jat Kaa's Coolers
