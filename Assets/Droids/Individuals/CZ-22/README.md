# CZ-22

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [CZ-22](https://starwars.fandom.com/wiki/CZ-22)

CZ-22 was a battered CZ-series secretary/comm droid that served as the controller of the spaceport on Engebo V. The droid's work involved welcoming committee and customs inspections.
