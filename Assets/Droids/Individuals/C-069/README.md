# C-069

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [C-069](https://starwars.fandom.com/wiki/C-069)

C-069 was a protocol droid seen in the Senate along with senator Mee Deechi. He was later serving drinks to Deechi and Senator Burtoni when Padmé Amidala and Bail Prestor Organa came to talk to them about Onaconda Farr's death.
