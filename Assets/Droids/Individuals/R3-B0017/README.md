# R3-B0017

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R3-B0017](https://starwars.fandom.com/wiki/R3-B0017)

R3-B0017 was an R3-series astromech droid that was programmed to scavenge the planet Dathomir and serve the Dathomirian Zabrak Darth Maul. The droid was equipped with green durasteel plating.
