# R2-B1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-B1/Legends](https://starwars.fandom.com/wiki/R2-B1/Legends)

R2-B1 was an R2-series astromech droid. His last assigned duty was on Naboo, in the repair droid pool on the royal cruiser belonging to Queen Amidala. There the droid worked alongside the famed R2-D2.
