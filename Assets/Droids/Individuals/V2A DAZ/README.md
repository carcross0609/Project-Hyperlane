# V2A DAZ

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [V2A DAZ](https://starwars.fandom.com/wiki/V2A_DAZ)

V2A DAZ was a droid that served as a forensic science commander in the Coruscant Security Force during the Clone Wars. Following the death of Senator Onaconda Farr, the droid made a report on the Rodian's autopsy, concluding that Farr had been murdered with a poison of Kaminoan origin that only worked on Rodian blood, leading Inspector Tan Divo to open an investigation.
