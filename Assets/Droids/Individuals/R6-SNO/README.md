# R6-SNO

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R6-SNO](https://starwars.fandom.com/wiki/R6-SNO)

R6-SNO was an R6 astromech droid, optimized to function on the frigid frontier planet Vandor. The droid was colored in white, orange, and brown, and wore a tall black hat and a red scarf.
