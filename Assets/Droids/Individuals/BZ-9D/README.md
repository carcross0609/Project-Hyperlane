# BZ-9D

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [BZ-9D](https://starwars.fandom.com/wiki/BZ-9D)

BZ-9D was a traffic control droid that was in service at Mos Ila Spaceport. In 3643 BBY, a bounty hunter in the Great Hunt questioned the droid about the Devaronian Tyresius Lokai.

- **Model:** Traffic control droid
