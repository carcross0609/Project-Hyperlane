# R3-D5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R3-D5](https://starwars.fandom.com/wiki/R3-D5)

R3-D5 was an R3 series astromech droid that saw operation during the Clone Wars. The droid was assigned to Saesee Tiin's starfighter and saw combat over Lola Sayu during a dangerous mission.
