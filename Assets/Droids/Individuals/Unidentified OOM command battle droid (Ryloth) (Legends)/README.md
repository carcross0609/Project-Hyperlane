# Unidentified OOM command battle droid (Ryloth)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified OOM command battle droid (Ryloth)/Legends](https://starwars.fandom.com/wiki/Unidentified_OOM_command_battle_droid_%28Ryloth%29/Legends)

This OOM command droid led the droid forces against Jedi Master Di and Captain Keeli in 22 BBY. The droid ordered 2 B1 battle droids to check out a gunship blocking the road. After the inspection from OM-5 and OM-7, the gunship's hidden explosives were triggered destroying both the unsuspecting droids and the nearby pillars which ultimatley led to the road being buried.
