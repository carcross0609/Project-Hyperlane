# 4A-7

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [4A-7/Legends](https://starwars.fandom.com/wiki/4A-7/Legends)

4A-7 was an early RA-7 protocol droid prototype manufactured by Arakyd Industries on the planet Mechis III. He had the body of a Cybot Galactica protocol droid and an over-sized head containing surveillance equipment.
