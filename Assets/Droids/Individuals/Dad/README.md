# Dad

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Dad](https://starwars.fandom.com/wiki/Dad)

Dad was a pilot droid working for the Star Tours travel company, until he suffered an accident that destroyed him to some extent. Fellow working droid G2-9T considered Dad Star Tours' best pilot.
