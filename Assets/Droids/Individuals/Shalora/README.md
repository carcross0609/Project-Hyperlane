# Shalora

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Shalora](https://starwars.fandom.com/wiki/Shalora)

Shalora was a Probe droid of the Sith Empire used by the Imperial Reclamation Service team led by Talos Drellik during the Galactic War. In 3642 BBY, Talos and Engineer Qualus Sorrel used Shalora to track down the wreckage of the Starrunner on Hoth.

- **Class:** Probe droid
