# N0-HX

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [N0-HX](https://starwars.fandom.com/wiki/N0-HX)

N0-HX was an astromech droid that worked for Agent Fauler of the Republic Strategic Information Service. N0 worked as a messenger for Fauler during the Cold War between the Galactic Republic and the Sith Empire, when the agent was stationed on Tatooine. Fauler used N0-HX to contact a Republic-allied individual and asked for their help on an issue with a doomsday device dealing with Czerka.
