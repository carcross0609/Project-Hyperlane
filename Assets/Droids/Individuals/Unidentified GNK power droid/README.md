# Unidentified GNK power droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified GNK power droid](https://starwars.fandom.com/wiki/Unidentified_GNK_power_droid)

A GNK-series power droid was stationed aboard the Renown during the Clone Wars when the ship was captured by the Confederacy of Independent Systems. This droid survived the hijacking along with several other republic droids, including BNI-393.
