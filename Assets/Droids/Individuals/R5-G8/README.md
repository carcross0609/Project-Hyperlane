# R5-G8

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R5-G8](https://starwars.fandom.com/wiki/R5-G8)

R5-G8, nicknamed Arfive, was the astromech droid of Rebel Alliance pilot Wedge Antilles. R5-G8 had developed numerous personality quirks, including communicating in a way that Antilles described as "screeching" and the insistence to cite regulations. The droid accompanied Antilles in the reformed Red Squadron after the Battle of Hoth.
