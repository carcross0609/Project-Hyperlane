# ZP-U1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ZP-U1](https://starwars.fandom.com/wiki/ZP-U1)

ZP-U1 was a probe droid and one of three droids created by an eccentric droid engineer on Ord Mantell with the help of a Republic-aligned individual. The engineer did this in an attempt to prove to the Republic that he could be useful to them, and the individual used the droid to defeat a number of Mantellian Separatists in Mannett Point.
