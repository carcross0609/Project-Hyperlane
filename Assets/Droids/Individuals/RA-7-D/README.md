# RA-7-D

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [RA-7-D](https://starwars.fandom.com/wiki/RA-7-D)

RA-7-D was a RA-7 protocol droid which acted as an engineer and saboteur for the Rebel Alliance. He believed that he was in love with a medical droid, although it was unknown if this is due to a programming glitch or a form of emergent behavior. RA-7-D also believed that the best way to demonstrate this love was to blow up Imperial targets, preferably in a showy fashion.
