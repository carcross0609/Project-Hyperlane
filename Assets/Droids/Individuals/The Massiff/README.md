# The Massiff

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [The Massiff](https://starwars.fandom.com/wiki/The_Massiff)

"The Massiff" was a highly-modified MagnaGuard droid which was a personal project of the Gen'Dai Rayvis. The modifications led to a ruthless, hyper-enhanced 'killing machine'. It would not stop fighting until the last of its processes failed.
