# Unidentified server droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified server droid](https://starwars.fandom.com/wiki/Unidentified_server_droid)

A droid served as a server droid for a luxury hotel on the planet Coruscant during the High Republic Era. In 231 BBY, the droid was in the middle of serving the human Sylvestri Yarrow before a Mon Calamari assassin shot the droid before attempting to kill Yarrow.

## Specifications

- **Name:** Unidentified server droid
- **Death:** 231 BBY, Coruscant
- **Class:** Server droid
- **Gender:** Masculine programming
- **Pronouns:** new
- **Plating:** Silver
