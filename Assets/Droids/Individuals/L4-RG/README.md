# L4-RG

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [L4-RG](https://starwars.fandom.com/wiki/L4-RG)

L4-RG was a battle droid and one of three droids created by an eccentric droid engineer on Ord Mantell with the help of a Republic-aligned individual. The engineer did this in an attempt to prove to the Republic that he could be useful to them, and the individual used the droid to defeat a number of Mantellian Separatists in Mannett Point.
