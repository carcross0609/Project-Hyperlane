# R7-TNO

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R7-TNO](https://starwars.fandom.com/wiki/R7-TNO)

R7-TNO was an astromech droid. The droid was colored in white, orange and blue. The droid was optimized to function among the artisans of the planet Kiros.
