# IT-904

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [IT-904](https://starwars.fandom.com/wiki/IT-904)

IT-904 was an Imperial Interrogation droid who was purchased by the bounty hunter Dej Vennor in an auction. Vennor modified the droid, which included giving it new programming and additional armaments, allowing him to use it to help him in collecting bounties. However, the programming changes did result in the droid developing a sarcastic personality.
