# 4-B4

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [4-B4](https://starwars.fandom.com/wiki/4-B4)

4-B4 was a droid. It accompanied Jedi Master Dajjun, his Padawan Karii, and a number of other Jedi on a mission to the planet Kailion. It was caught with the Jedi when they were trapped in a cave-in.
