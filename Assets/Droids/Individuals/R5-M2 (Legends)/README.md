# R5-M2

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-M2/Legends](https://starwars.fandom.com/wiki/R5-M2/Legends)

R5-M2 (Arfive-Emmtoo) was an R5-series astromech droid belonging to Rebel Alliance Captain Shawn Valdez, an evacuation officer assigned to Echo Base on the Outer Rim Territories ice planet Hoth during the Galactic Civil War. Specially programmed to plot sublight tactical courses for starships, R5-M2 played an invaluable role during the Battle of Hoth in 3 ABY by assisting Valdez in planning evacuation routes from Echo Base.
