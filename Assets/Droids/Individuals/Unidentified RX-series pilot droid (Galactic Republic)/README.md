# Unidentified RX-series pilot droid (Galactic Republic)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified RX-series pilot droid (Galactic Republic)](https://starwars.fandom.com/wiki/Unidentified_RX-series_pilot_droid_%28Galactic_Republic%29)
