# The Catastrophonator

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [The Catastrophonator](https://starwars.fandom.com/wiki/The_Catastrophonator)

The Catastrophonator was a custom MSE-6 series repair droid created by members of the Orbak Tribe on Kef Bir. The mouse droid had modifications that allowed it to discharge electricity and fire projectiles. The reigning champion, it participated in the Kef Bir's Battle Gears battling contest, where it lost to Emperor Painpatine.
