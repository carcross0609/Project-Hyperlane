# Unidentified OOM-series security droid (gone)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified OOM-series security droid (gone)](https://starwars.fandom.com/wiki/Unidentified_OOM-series_security_droid_%28gone%29)

A OOM-series security droid was a member of a Separatist crew that operated on the planet Loradil during the New Republic Era after their Providence-class carrier was shot down. Around 6 ABY, the OOM-series security droid observed another security droid attempt to locate the human Jedi Luke Skywalker underneath a Armored Assault Tank before they were flown using the Force into the pilot of the tank.
