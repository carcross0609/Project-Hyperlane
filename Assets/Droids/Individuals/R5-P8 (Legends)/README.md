# R5-P8

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-P8/Legends](https://starwars.fandom.com/wiki/R5-P8/Legends)

R5-P8 was an R5-series astromech droid produced by Industrial Automaton. It served as an assassin droid of Hondo Ohnaka's pirate gang during the Clone Wars. It had a Weequay blaster pistol fixed on its head, so it could serve both repair's and security purposes.
