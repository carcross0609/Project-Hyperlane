# Unidentified spaceport police droid (Stobar)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified spaceport police droid (Stobar)](https://starwars.fandom.com/wiki/Unidentified_spaceport_police_droid_%28Stobar%29)

Around 21 BBY, a Spaceport police droid responded to an emergency call from a spaceport restaurant, Plop Dribble's on planet Stobar's spaceport, after a Dathomirian Zabrak, Savage Opress, nearly choked a waitress to death. By the time the droid arrived, Savage had already fled the scene.
