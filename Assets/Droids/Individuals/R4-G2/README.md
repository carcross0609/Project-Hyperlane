# R4-G2

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R4-G2](https://starwars.fandom.com/wiki/R4-G2)

R4-G2 was an astromech droid in service of the Galactic Republic. Stationed on Onderon, it urged Republic heroes to contact Adjudicator Refain.
