# R7-FNG

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R7-FNG](https://starwars.fandom.com/wiki/R7-FNG)

R7-FNG was an R7 droid that was optimized to function on the dark and desolate planet Exegol. The astromech droid was colored in white, purple, red and black. It notably had a glow-in-the-dark head for easy navigation through dark parts of the galaxy.
