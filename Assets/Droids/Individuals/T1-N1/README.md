# T1-N1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [T1-N1](https://starwars.fandom.com/wiki/T1-N1)

T1-N1 was a T1-series utility droid that was owned by Czerka executive Jana Lorso of the Citadel Station branch of the Czerka Corporation in 3951 BBY.

## Specifications

- **Name:** T1-N1
- **Homeworld:** Telos IV
- **Manufacturer:** Duwani Mechanical Products
- **Model:** T1-series utility droid
- **Class:** Utility droid
- **Height:** 0.96 meters
- **Gender:** Masculine programming

- **Sensor:** Green, yellow and blue
- **Equipment:**

  - Hidden blaster
- **Affiliation:** Czerka Corporation
