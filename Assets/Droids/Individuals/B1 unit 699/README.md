# B1 unit 699

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [B1 unit 699](https://starwars.fandom.com/wiki/B1_unit_699)

B1 Unit 699 was a B1-series battle droid active during the Clone Wars on the planet Akiva, where they were destroyed. In 3 ABY, glitching BX-series droid commando ND-5 saw memory issues and called for B1 unit 699 to respond as he passed his remains.
