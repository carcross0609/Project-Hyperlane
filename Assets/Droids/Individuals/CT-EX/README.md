# CT-EX

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [CT-EX](https://starwars.fandom.com/wiki/CT-EX)

CT-EX, known as Teex, was a protocol droid serving aboard the Executor-class Star Dreadnought Guardian. After being reprogrammed by ship thief Cryle Cavv, CT-EX helped him reprogram the vessel's hyperdrive to leap into New Republic territory, ultimately allowing the Republic to capture the Guardian.
