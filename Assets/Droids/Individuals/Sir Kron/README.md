# Sir Kron

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Sir Kron](https://starwars.fandom.com/wiki/Sir_Kron)

Sir Kron was Protocol droid who assisted Mila while giving Bakurat readings. By the time of the First Order Sir Kron was just a Bodyless copper colored head with vivid yellow eyes.

- **Name:** Sir Kron
- **Class:** Protocol droid
