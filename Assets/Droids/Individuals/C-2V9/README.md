# C-2V9

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [C-2V9](https://starwars.fandom.com/wiki/C-2V9)

C-2V9 was a one-meter tall 2V9 cargo lifter droid produced by Industrial Automaton. It was cylindrical and hovered on repulsorlifts. The droid was equipped with a computer jack, high pitch acoustic signaller, broad-band antenna receiver, and a durasteel lifting arm. It cost 2,500 credits new and 1,750 credits used. It was present on an Imperial communications outpost on Endor in 4 ABY.
