# R2-H16

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R2-H16](https://starwars.fandom.com/wiki/R2-H16)

R2-H16 was an R2-series astromech droid that was optimized to function in cold weather. The droid's distinctive red-and-green "hat" was an external radiant heating array. He also included a Burtt acoustic signaler.

## Specifications

- **Name:** R2-H16

- **Class:** Astromech droid
