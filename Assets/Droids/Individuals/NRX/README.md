# NRX

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [NRX](https://starwars.fandom.com/wiki/NRX)

NRX, or "Enarex," was an enigmatic assassin droid and one of the leaders of the Princes of Hell. NRX wore purple robes to hide it's true nature from strangers.
