# R4-G9

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R4-G9/Legends](https://starwars.fandom.com/wiki/R4-G9/Legends)

R4-G9, also known as Geenine, was a bronze-domed R4-P astromech droid maintained by the Jedi Order on Coruscant during the Clone Wars. Like many Jedi R4-series droids, Geenine had an R2 series dome, instead of the conical R4-series head.
