# R5-TK

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-TK](https://starwars.fandom.com/wiki/R5-TK)

R5-TK was a salvaged R5-series astromech droid operating during the Galactic Civil War. The droid specialized in acquiring target locks on other ships during space combat.

- **Name:** R5-TK
- **Line:** R-series
- **Model:** R5-series astromech droid
- **Class:** Astromech droid
