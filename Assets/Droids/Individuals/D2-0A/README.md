# D2-0A

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [D2-0A](https://starwars.fandom.com/wiki/D2-0A)

D2-0A was a protocol droid active during the Galactic War. In 3637 BBY, it was used by the Minister of Intelligence to send a covert message to Cipher Nine on Rishi.
