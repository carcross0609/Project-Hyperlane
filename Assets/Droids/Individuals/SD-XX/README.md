# SD-XX

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [SD-XX](https://starwars.fandom.com/wiki/SD-XX)

SD-XX, or Double-Ex, was a fourth-degree SD-X-series personal security droid built by Tendrando Arms. Jacen Solo had him onboard his personal Star Destroyer in 40 ABY.
