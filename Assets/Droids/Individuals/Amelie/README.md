# Amelie

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Amelie](https://starwars.fandom.com/wiki/Amelie)

Amelie was a Millicreep droid that served the Umbaran militia during the Clone Wars. It was captured during the Battle of Umbara and re-programmed to be the companion of a Jedi Knight.
