# R5-G9

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R5-G9](https://starwars.fandom.com/wiki/R5-G9)

R5-G9 was an astromech droid belonging to Griff Halloran of Ace Squadron. Like Halloran's ship, the Black Ace, R5-G9 was cobbled together from old Imperial-issue droids and other assorted parts, including an old R2 unit.
