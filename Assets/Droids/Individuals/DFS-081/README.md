# DFS-081

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [DFS-081](https://starwars.fandom.com/wiki/DFS-081)

DFS-081 was a Vulture-class starfighter that served in the Separatist Alliance during the Clone Wars. At one point, DFS-081 was visibly damaged while flying in an atmosphere.
