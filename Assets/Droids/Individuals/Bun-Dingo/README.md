# Bun-Dingo

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Bun-Dingo](https://starwars.fandom.com/wiki/Bun-Dingo)

Bun-Dingo was an assassin droid that was hired by Governor Bisad Koong to sabotage the Umboo Racing Team and win the Drainsweeper race.
