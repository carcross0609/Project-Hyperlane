# Fenbolt

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Fenbolt](https://starwars.fandom.com/wiki/Fenbolt)

Fenbolt was a service droid of Cli Pastayra and reprogrammed by Fyzen Gor. Around 3 BBY, Fyzen betrayed the leaders of Wandering Star and killed them with the droids. Fenbolt killed Cli Pastayra.

## Specifications

- **Name:** Fenbolt
- **Creator:** Fyzen Gor
- **Class:** Service droid
- **Affiliation:** Wandering Star
