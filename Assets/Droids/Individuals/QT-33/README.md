# QT-33

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [QT-33](https://starwars.fandom.com/wiki/QT-33)

QT-33 was an astromech droid and one of three droids created by an eccentric droid engineer on Ord Mantell with the help of a Republic-aligned individual. The engineer did this in an attempt to prove to the Republic that he could be useful to them, and the individual used the droid to defeat a number of Mantellian Separatists on Mannett Point.
