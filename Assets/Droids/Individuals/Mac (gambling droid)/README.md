# Mac (gambling droid)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Mac (gambling droid)](https://starwars.fandom.com/wiki/Mac_%28gambling_droid%29)

Mac was an old gambling droid that worked at the Last Stand Casino. Mac would play sabacc with the owner, Mortimon Galli, and exchange barbs, puns, and anti-Imperial cracks.

## Specifications

- **Name:** Mac
- **Class:** Gambling droid
- **Affiliation:** Last Stand Casino
