# R5-C7

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R5-C7](https://starwars.fandom.com/wiki/R5-C7)

R5-C7 was an R5-series astromech droid. In 22 BBY, the droid was present on the streets of Coruscant as Obi-Wan Kenobi and Anakin Skywalker hunted down Zam Wesell.
