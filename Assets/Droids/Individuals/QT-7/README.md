# QT-7

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [QT-7](https://starwars.fandom.com/wiki/QT-7)

QT-7 was a small, rectangle computer access Droid who served the Alliance to Restore the Republic during the Galactic Civil War. Covered with synthetic banthaskin and fitted with a handle, QT-7 could pass for a standard suitcase with sensor receptors and computer access port retracted. He was part of the Alliance team that infiltrated the Technical Branch Outpost on Lotide.
