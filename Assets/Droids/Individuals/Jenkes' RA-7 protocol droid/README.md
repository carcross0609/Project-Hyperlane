# Jenkes' RA-7 protocol droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Jenkes' RA-7 protocol droid](https://starwars.fandom.com/wiki/Jenkes%27_RA-7_protocol_droid)

By the year 5 BBY, an RA-7 protocol droid was owned by Jenkes, a lieutenant in the Imperial Security Bureau. Working as his receptionist, it was destroyed by the lieutenant when it accidentally stumbled upon his criminal activities.
