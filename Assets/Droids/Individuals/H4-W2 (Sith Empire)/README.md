# H4-W2 (Sith Empire)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [H4-W2 (Sith Empire)](https://starwars.fandom.com/wiki/H4-W2_%28Sith_Empire%29)

H4-W2 was an astromech droid active around the time of the Galactic War. During the Invasion of Ziost it transmitted an emergency signal to field operatives, urging them to respond to the Code Omega event. It later broadcast a priority message from Darth Marr to rally a hunt for Vitiate.
