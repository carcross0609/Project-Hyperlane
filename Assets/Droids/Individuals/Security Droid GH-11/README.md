# Security Droid GH-11

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Security Droid GH-11](https://starwars.fandom.com/wiki/Security_Droid_GH-11)

The Security Droid GH-11 was a powerful security droid that was stationed in the assembly line of the Okara Droid Factory on the planet Balmorra. During the Cold War, it was destroyed by Imperial forces that invaded the factory.

## Specifications

- **Name:** Security Droid GH-11
- **Death:** 3643 BBY, Balmorra
- **Class:** Security droid
- **Pronouns:** new
- **Sensor:** Blue
- **Plating:** Black
- **Armament:** Personal blaster cannon
