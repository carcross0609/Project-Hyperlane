# MK-8

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [MK-8](https://starwars.fandom.com/wiki/MK-8)

MK-8 was an RA-7 protocol droid manufactured on the planet Vulpter by Arakyd Industries. The protocol droid had silver plating, black sensors, and stood 1.7 meters tall. During the First Order occupation of the planet Batuu in 34 ABY, there was an outstanding bounty posting of 1375 credits for MK-8 which listed its crimes as conspiracy, illegal programming, smuggling, and slicing, with an order to dismantle the droid upon acquisition.
