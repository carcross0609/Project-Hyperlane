# J0-N0

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [J0-N0](https://starwars.fandom.com/wiki/J0-N0)

J0-N0 was an 8D-series smelter droid who worked for Cad Bane during the Clone Wars. He attempted to acquire the plans for the Republic Senate Building from C-3PO, Senator Padmé Amidala's protocol droid.
