# E3-VE3

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [E3-VE3](https://starwars.fandom.com/wiki/E3-VE3)

E3-VE3 was a custom-modified Droideka found on the planet of Koboh. The droid was modified to have enhanced offensive capabilities and heightened belligerence algorithms. Instead of serving the Bedlam Raiders, this droid was reprogrammed a second time with new logic and loyalty protocols, which overrode Rayvis' programming.
