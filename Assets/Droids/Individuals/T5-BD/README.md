# T5-BD

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [T5-BD](https://starwars.fandom.com/wiki/T5-BD)

T5-BD was an astromech droid posted at the Kri-Ta Outpost on Voss during the Galactic War. There it requested the assistance of a Republic individual to lend help to the Voss commando Abdan-Sho.
