# C-E29

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [C-E29](https://starwars.fandom.com/wiki/C-E29)

C-E29 was a protocol droid that operated during the time of the Galactic War between the Galactic Republic and the reconstituted Sith Empire. The droid was present on CZ-198 as a mission courier for Republic forces fighting during the Seizure of CZ-198.
