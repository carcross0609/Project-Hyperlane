# KP-1

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [KP-1](https://starwars.fandom.com/wiki/KP-1)

KP-1 was a masculine K-series astromech droid associated with the Hidden Path. In 9 BBY, the droid was found on the planet Jabiim.
