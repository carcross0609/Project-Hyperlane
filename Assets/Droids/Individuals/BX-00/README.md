# BX-00

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [BX-00](https://starwars.fandom.com/wiki/BX-00)

BX-00 served as Baron Gavern Starlock's driver, guard, aide, and assassin. It tried to run over C-3PO and R2-D2 in Baron Starlock's hovercraft. It later tried to assassinate Prince Jagoda on Starlock's orders, but was stopped by C-3PO.
