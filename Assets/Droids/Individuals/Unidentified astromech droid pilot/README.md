# Unidentified astromech droid pilot

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified astromech droid pilot](https://starwars.fandom.com/wiki/Unidentified_astromech_droid_pilot)

An astromech droid pilot operated a landspeeder on the planet Pagodon. The droid was signaled by the Kubaz ferryman Barlidan to escort Din Djarin and a Mythrol to the Razor Crest, but Djarin refused.

- **Line:** R-series

- **Sensor:** Black
