# Scarab droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Scarab droid](https://starwars.fandom.com/wiki/Scarab_droid)

Scarab droids were small assassin droids manufactured by Sienar Intelligence Systems. There were eighteen versions of the scarab droid, and all could fit in the palm of a hand. Each version had a different set of weapons and equipment, including spines, claws, and flesh-eating shredders. Specific models included the Scarab Mark VI assassin droid.

## Specifications

- **Name:** Scarab droid
- **Manufacturer:** Sienar Intelligence Systems
- **Model:** Assassin droid
- **Affiliation:** Galactic Empire
