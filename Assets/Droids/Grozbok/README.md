# Grozbok

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Grozbok](https://starwars.fandom.com/wiki/Grozbok)

Grozbok was a reprogrammed GRZ-6B wrecker droid and worked under the command of Olag Greck. Wreaking havoc on Hosk Station, it was destroyed by Unit Zed's security droids.

## Specifications

- **Name:** Grozbok
- **Manufacturer:** Serv-O-Droid, Inc.
- **Model:** GRZ-6B wrecker droid
- **Height:** 6 meters
- **Gender:** Masculine programing
- **Pronouns:** new
- **Sensor:** Orange
- **Equipment:**

  - Laser cutter
  - Internal fusion furnace
- **Affiliation:** Olag Greck
