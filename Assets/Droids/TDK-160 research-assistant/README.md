# TDK-160 research-assistant

**Kind:** Series  
**Continuity:** Canon  
**Source:** [TDK-160 research-assistant](https://starwars.fandom.com/wiki/TDK-160_research-assistant)

A TDK-160 research-assistant was a model of re-configurable droid, whose locomotive apparatus could be changed out for two slender legs, a twin-tread module for rolling over rough terrain, or possibly other options. The droid was described as having "sloping shoulders". One such unit, which assisted Galen and Lyra Erso on the planet Vallt, was nicknamed "Assis."
