# G4-0M

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [G4-0M](https://starwars.fandom.com/wiki/G4-0M)

G4-0M was an astromech droid active during the Cold War. G4 served the Galactic Republic as a courier on Carrick Station, delivering messages and mission briefings from the Emergency Response Corps to Republic personnel aboard.
