# BX-778

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BX-778](https://starwars.fandom.com/wiki/BX-778)

BX-778, abbreviated BX or Beex, was a Class three culinary septoid droid with masculine programming, that belonged to Han Solo and his wife Leia Organa.

## Specifications

- **Name:** BX-778
- **Homeworld:** Chandrila
- **Manufacturer:** Calrissian Enterprises
- **Model:** Culinary septoid droid
- **Class:** Kitchen droid
- **Gender:** Masculine programming
- **Sensor:** Yellow
- **Affiliation:** Solo family
