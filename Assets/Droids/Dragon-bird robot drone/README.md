# Dragon-bird robot drone

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Dragon-bird robot drone](https://starwars.fandom.com/wiki/Dragon-bird_robot_drone)

Dragon-bird robot drones were flying droids that were fashioned after the dragon-birds that were native to Onderon. They were used for target practice by Jedi starfighter pilots on Ossus.

## Specifications

- **Name:** Dragon-bird robot drone
- **Homeworld:** Ossus
- **Affiliation:** Jedi Order
