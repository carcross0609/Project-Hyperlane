# BS-1119

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BS-1119](https://starwars.fandom.com/wiki/BS-1119)

BS-1119 was a droid bouncer of the criminal group known as The Family. Resembling a modified HK assassin unit, it oversaw the Family's illegal racetracks within the Coruscant Underworld, where it encountered newlyweds Anakin Skywalker and Padmé Amidala during a secret rendezvous. Despite being designed as an enforcer, BS-1119 came across as particularly polite, a quirk that Skywalker attributed to it being programmed for both security and business. The droid wielded twin blaster pistols that it stored in holsters on its hips.

## Specifications

- **Name:** BS-1119
- **Armament:** Twin blaster pistols
- **Affiliation:** The Family
