# Stage VI Bio-Desolator Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Stage VI Bio-Desolator Droid](https://starwars.fandom.com/wiki/Stage_VI_Bio-Desolator_Droid)
