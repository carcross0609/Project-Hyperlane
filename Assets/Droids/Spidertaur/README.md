# Spidertaur

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Spidertaur](https://starwars.fandom.com/wiki/Spidertaur)

Spidertaur were droids used for protection on the first Death Star in 0 BBY. They had blaster weapons with which to fight.

## Specifications

- **Name:** Spidertaur
- **Class:** Security droid
- **Plating:** Gray
- **Armament:** Blasters
- **Affiliation:** Galactic Empire
