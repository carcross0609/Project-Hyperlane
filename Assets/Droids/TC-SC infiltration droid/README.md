# TC-SC infiltration droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [TC-SC infiltration droid](https://starwars.fandom.com/wiki/TC-SC_infiltration_droid)

The TC-SC infiltration droid was an espionage droid manufactured by Cybot Galactica and designed for obtaining intelligence from areas too difficult to breach by less-advanced espionage droids.

## Specifications

- **Name:** TC-SC infiltration droid
- **Manufacturer:** Cybot Galactica
- **Class:**
  - Assassin droid
  - Espionage droid
- **Degree:** Class four droid
- **Cost:** 15,600 – 20,380 credits
- **Height:** <2 meters
- **Gender:** Variety
- **Sensor:** Red
- **Armament:**
  - Concealed blaster pistol
  - Concealed knife
- **Equipment:** CQ-3.80 multispectrum disguise suite
