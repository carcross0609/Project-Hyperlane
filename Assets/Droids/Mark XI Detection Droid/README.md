# Mark XI Detection Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mark XI Detection Droid](https://starwars.fandom.com/wiki/Mark_XI_Detection_Droid)

The Mark XI Detection Droid was a model of probe droid that was used by the forces of the Specialists, a mercenary unit. Mark XI Detection Droids were deployed under the control of QO-99 to the planet Makeb during the Conquest of Makeb.

## Specifications

- **Name:** Mark XI Detection Droid
- **Class:** Probe droid
- **Affiliation:** Specialists
