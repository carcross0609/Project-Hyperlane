# R6-D23

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R6-D23](https://starwars.fandom.com/wiki/R6-D23)

R6-D23 was an R6 astromech droid operating in Bespin's Cloud City, maintaining starships. The droid was a typical R6, but also wore a blue cone-shaped hat with star and moon shapes. This astromech droid included a Herner optical holographic projector.
