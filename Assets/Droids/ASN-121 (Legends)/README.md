# ASN-121

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ASN-121/Legends](https://starwars.fandom.com/wiki/ASN-121/Legends)

ASN-121 was a hovering ASN courier droid similar in appearance to a remote. It could wield a number of weapons and was designed by the Malkite Poisoners to operate as an assassin droid.
