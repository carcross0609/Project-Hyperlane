# Assassin probe

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Assassin probe/Legends](https://starwars.fandom.com/wiki/Assassin_probe/Legends)

Assassin probes were assassin droids used during the Clone Wars. They resembled large spiders with eight spindly legs and multiple red photoreceptors.
