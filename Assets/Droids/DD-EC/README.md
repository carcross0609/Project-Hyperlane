# DD-EC

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [DD-EC](https://starwars.fandom.com/wiki/DD-EC)

DD-EC was a droid Cal Kestis recruited on the planet Koboh together with Ashe Javi to work at Pyloon's Saloon. Together, they played multiple songs including the song Sugaan Essena at the establishment.

## Specifications

- **Type:** Musician
- **Name:** DD-EC
- **Gender:** Masculine programming
- **Pronouns:** He/him
- **Plating:** Red and teal
- **Affiliation:** Pyloon's Saloon
