# Unidentified RA-7 protocol droid (Renzoh Silliac)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified RA-7 protocol droid (Renzoh Silliac)](https://starwars.fandom.com/wiki/Unidentified_RA-7_protocol_droid_%28Renzoh_Silliac%29)

An RA-7 protocol droid served the Blood Oath Syndicate member Renzoh Silliac on the planet Hallitron-7. After a brief skirmish, the protocol droid was interrogated by the Palliduvan bounty hunter Aurra Sing and coerced into unlocking Silliac's computer.
