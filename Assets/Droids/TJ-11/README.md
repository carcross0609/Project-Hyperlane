# TJ-11

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [TJ-11](https://starwars.fandom.com/wiki/TJ-11)

TJ-11 was a T-series tactical droid refurbished by Imperial Intelligence during the Galactic Civil War. It was tasked with capturing the Alliance Intelligence EF76 Nebulon-B escort frigate Shadow Raptor in the Trans-Hydian Borderlands.
