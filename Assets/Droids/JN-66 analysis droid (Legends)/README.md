# JN-66 analysis droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [JN-66 analysis droid/Legends](https://starwars.fandom.com/wiki/JN-66_analysis_droid/Legends)

The JN-66 was a model of analysis droid produced by Cybot Galactica as a high-end utility droid as early as the Ruusan Reformations of the Galactic Republic. The Jedi Order made a large purchase of JN-66 units for use in the Jedi Temple's analysis wing.

## Specifications

- **Name:** JN-66 analysis droid
- **Manufacturer:** Cybot Galactica
- **Homeworld:** Coruscant
- **Class:** Analysis droid
- **Height:** 1 meter
- **Armament:** None
- **Equipment:**
  - Sensor apparatus
  - Repulsorlift
- **Affiliation:**
  - Galactic Republic
  -   Coruscant Security Force
  - Jedi Order
