# GE3-series protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [GE3-series protocol droid](https://starwars.fandom.com/wiki/GE3-series_protocol_droid)

The GE3-series protocol droid was a bipedal protocol droid manufactured by Czerka Corporation. Vaguely resembling later models from Cybot Galactica, GE3s were one of the most common and best-selling droids in the galaxy during both the Jedi Civil War and Dark Wars.

## Specifications

- **Name:** GE3-series protocol droid
- **Manufacturer:** Czerka Corporation
- **Class:** Protocol droid
- **Cost:** 2,500 credits
- **Gender:** Both masculine and feminine programming
- **Sensor:** Blue, yellow, and white
- **Armament:** None
- **Equipment:**
  - Audio recorder
  - comlink
