# Sartorifex Robo-Valet

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Sartorifex Robo-Valet](https://starwars.fandom.com/wiki/Sartorifex_Robo-Valet)

Sartorifex Robo-Valets were droids manufactured by Cybot Galactica that served as personal attendants. These were usually encountered in hotels and luxury StarLiners.

## Specifications

- **Name:** Sartorifex Robo-Valet
- **Creator:** Cybot Galactica
- **Cost:** 5,600 credits
- **Height:** 1.5 meters
- **Equipment:**
  - Galactic fashion database
  - Internal steam press
  - Internal Vibrosound dry cleaning device
  - Photoreceptors
  - Rethreading/reweaving micro manipulators
