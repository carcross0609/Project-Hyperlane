# Geth

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Geth](https://starwars.fandom.com/wiki/Geth)

Geth was a Science Research Droid modified by former Rebel general Reesen Jivrak. He used Geth to create toxins that would strengthen and enrage the docile deripors of Ohratuu for use as mounts in hit-and-run attacks.
