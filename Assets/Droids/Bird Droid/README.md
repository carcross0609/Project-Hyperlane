# Bird Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Bird Droid](https://starwars.fandom.com/wiki/Bird_Droid)

Bird Droid was a type of droid present in Star Tours' Tomorrowland Starport. They built nests and hatched silver eggs. SK-Z38 was one such droid.
