# R7 (Carson Teva)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R7 (Carson Teva)](https://starwars.fandom.com/wiki/R7_%28Carson_Teva%29)

R7 was an R2-series astromech droid that served with Captain Carson Teva of the Adelphi Rangers on the planet Adelphi during the New Republic Era. The droid later served Colonel Ward in an X-wing starfighter.
