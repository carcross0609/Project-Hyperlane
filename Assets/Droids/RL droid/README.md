# RL droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [RL droid](https://starwars.fandom.com/wiki/RL_droid)

The RL droid was a type of pilot droid that existed in the galaxy, serving as a precursor to RX-series pilot droids. During the High Republic Era, one such model of droid, RL-18, piloted the Tycoon Trader for the Hutt Cartel.

- **Name:** RL droid
