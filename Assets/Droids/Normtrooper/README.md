# Normtrooper

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Normtrooper](https://starwars.fandom.com/wiki/Normtrooper)

Normtroopers were a type of droid under the command of Heinz Darthenshmirtz found aboard the Death Star. They wore modified stormtrooper armor and carried a pair of E-11 blaster rifles.
