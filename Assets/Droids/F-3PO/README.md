# F-3PO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [F-3PO](https://starwars.fandom.com/wiki/F-3PO)

F-3PO was a protocol droid in Cloud City on Bespin. When X0-X1 took control of the city, F-3PO was forced to kill Doctor Issan Len, despite its regrets.

## Specifications

- **Name:** F-3PO
- **Model:** 3PO-series protocol droid
