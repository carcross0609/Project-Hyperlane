# C9-T9-GE3

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [C9-T9-GE3](https://starwars.fandom.com/wiki/C9-T9-GE3)

C9-T9-GE3 was a GE3-series protocol droid that was modified to become a swoop racing droid. Due to the installed protocols, it was unbeatable by any other racer.
