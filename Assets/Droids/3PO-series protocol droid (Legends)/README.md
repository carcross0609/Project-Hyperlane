# 3PO-series protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [3PO-series protocol droid/Legends](https://starwars.fandom.com/wiki/3PO-series_protocol_droid/Legends)

The 3PO-series protocol droid was a Human-cyborg relations protocol droid produced by Cybot Galactica. The model series had very similar aesthetic design in its casing to other Cybot Galactica droid model series such as the TC-series, 3PX-series, and 5YQ-series protocol droids.

## Specifications

- **Name:** 3PO-series protocol droid
- **Manufacturer:** Cybot Galactica
- **Class:** Protocol droid
- **Degree:** Class three droid
- **Cost:** 3,000 credits
- **Height:** 1.7 meters
- **Equipment:**
  - 2 photoreceptors (Human range)
  - 2 auditory receptors (Human range)
  - 1 Olfactory sensor
  - Vocabulator
  - AA-1 VerboBrain
  - TranLang III communications module
