# Resource probe droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Resource probe droid](https://starwars.fandom.com/wiki/Resource_probe_droid)

The resource probe droid was manufactured by Arakyd Industries, and was based on their standard probe droid design. The resource probe droid was designed to find and analyze potential mining sites. The droid was deployed via hyperdrive pod to a target planet.

## Specifications

- **Name:** Resource probe droid
- **Manufacturer:** Arakyd Industries
- **Cost:** 10,000 credits
- **Height:** 1.5 meters
- **Equipment:**
  - Beamdrill
  - Broad-band transceiver
  - Investigation and analytical computer
  - Mineral sampler
  - Multi-purpose appendages
  - Planetary sensor array with long range sensors
  - Recording devices
  - Repulsorlift engine
