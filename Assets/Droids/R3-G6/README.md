# R3-G6

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R3-G6](https://starwars.fandom.com/wiki/R3-G6)

R3-G6 was an R3 astromech droid. During the Clone Wars, R3-G6 assisted Ahsoka Tano on her mission to Ryloth. It later died on this mission.
