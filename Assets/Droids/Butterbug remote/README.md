# Butterbug remote

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Butterbug remote](https://starwars.fandom.com/wiki/Butterbug_remote)

A butterbug remote was a type of small, palm-sized remote that could be linked together in batches as a networked swarm. Used to transmit localized information to one another and the user, the remotes came equipped with micro-tools, including drills. Butterbug remotes were vulnerable to blasts. Around the Galactic Civil War, a butterbug remote cost 700 credits.
