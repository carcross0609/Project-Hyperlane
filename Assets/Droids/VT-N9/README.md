# VT-N9

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [VT-N9](https://starwars.fandom.com/wiki/VT-N9)

VT-N9 was the designation of a astromech droid used by the Sith Empire during the Cold War. It relayed to Imperial forces an urgent transmission from Darth Malgus.
