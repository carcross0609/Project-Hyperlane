# LX-R5

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [LX-R5](https://starwars.fandom.com/wiki/LX-R5)

LX-R5, also known as Ellex, was an R5 series astromech droid that served the Jedi Order, working alongside the Jedi Master Kelleran Beq and the protocol droid AD-3.
