# Rodor Keen's droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Rodor Keen's droid](https://starwars.fandom.com/wiki/Rodor_Keen%27s_droid)

A droid served the human Rodor Keen during the High Republic Era. The droid told the Mon Calamari Chief of Security Ghal Tarpfen that Keen was currently resting on the space station Starlight Beacon.
