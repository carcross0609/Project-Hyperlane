# Dwarf probe droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Dwarf probe droid](https://starwars.fandom.com/wiki/Dwarf_probe_droid)

The dwarf probe droid, also known as an Imperial probe droid or Viper probot, was a model of probe droid manufactured by Arakyd Industries. It was fitted with a pair of blaster barrels, which it could fire with deadly accuracy.

## Specifications

- **Name:** Dwarf probe droid
- **Manufacturer:** Arakyd Industries
- **Class:** Probe droid
- **Armament:** Blasters (2)
- **Affiliation:** Galactic Empire
