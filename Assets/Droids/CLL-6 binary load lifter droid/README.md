# CLL-6 binary load lifter droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [CLL-6 binary load lifter droid](https://starwars.fandom.com/wiki/CLL-6_binary_load_lifter_droid)

The CLL-6 was a binary loadlifter droid produced by Cybot Galactica during the last decades of the Galactic Republic. The basic processor kept the droid moving and carrying out its orders. It took orders in Basic literally, and as such often required a protocol droid to correctly translate instruction into Binary.

- **Line:** CLL-series load lifter

- **Class:** Binary load lifter

- **Cost:** 4,200 credits (used)
