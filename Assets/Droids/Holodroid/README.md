# Holodroid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Holodroid](https://starwars.fandom.com/wiki/Holodroid)

A holo-droid or holodroid was a model of mobile droid that could project holograms. Everi Chalis used a holo-droid when presenting the plan for Operation Ringbreaker. The Maya-series holodroids were holodroids that could morph their appearance.
