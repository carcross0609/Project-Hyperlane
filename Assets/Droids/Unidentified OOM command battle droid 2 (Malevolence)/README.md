# Unidentified OOM command battle droid 2 (Malevolence)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified OOM command battle droid 2 (Malevolence)](https://starwars.fandom.com/wiki/Unidentified_OOM_command_battle_droid_2_%28Malevolence%29)

This OOM command battle droid was stationed on board the Malevolence during the Battle of the Kaliida Nebula, being aboard the ship's bridge to make sure the repairs to the ship's hyperdrive were completed. Moments later, Senator Padmé Amidala and Jedi Knight Anakin Skywalker entered the bridge and killed all the droids stationed there, including the OOM commander.
