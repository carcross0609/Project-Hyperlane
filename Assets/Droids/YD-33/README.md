# YD-33

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [YD-33](https://starwars.fandom.com/wiki/YD-33)

YD-33 was a protocol droid used by the Imperial Diplomatic Service during the Galactic War. Stationed on the Ziost Shadow, YD-33 asked an Imperial to rendezvous with Ambassador Rove regarding the situation with the Hutt Cartel.
