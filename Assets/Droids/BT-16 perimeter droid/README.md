# BT-16 perimeter droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [BT-16 perimeter droid](https://starwars.fandom.com/wiki/BT-16_perimeter_droid)

The BT-16 perimeter droid, also known as the VT-16, was a bulbous, spider-like droid manufactured by Arakyd Industries.

- **Name:** BT-16 perimeter droid
- **Manufacturer:** Arakyd Industries
- **Class:** Fourth degree
- **Cost:**

  - 3,100 credits (refurbished)
- **Height:** 2.3 meters
- **Mass:** 75 kilograms
- **Armament:** Taim & Bak repeating blaster
- **Equipment:**

  - Comlink
  - Sensor package

  -   Fabritech seismic sensor

  - Video sensor
