# Pip

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Pip](https://starwars.fandom.com/wiki/Pip)

Pip was a PIP repair droid who accompanied Verosha "Osha" Aniseya and later her sister Mae-ho "Mae" Aniseya during the High Republic Era.
