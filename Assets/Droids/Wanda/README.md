# Wanda

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [Wanda](https://starwars.fandom.com/wiki/Wanda)

Wanda was a WA-7 waitress droid that worked in Dex's Diner on Coruscant shortly before the Battle of Yavin. She was friends with Harmony.
