# MD-3 medical droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [MD-3 medical droid](https://starwars.fandom.com/wiki/MD-3_medical_droid)

The MD-3 was a model of medical droid and a part of the MD-series that was manufactured by Industrial Automaton. It was slightly humanoid in appearance.

## Specifications

- **Name:** MD-3 medical droid
- **Manufacturer:** Industrial Automaton
- **Homeworld:** Telti
- **Line:** MD-series medical droid
- **Class:** Class one droid
- **Cost:** 2,000 credits
- **Height:** 1.5 meters
- **Sensor:** Yellow
- **Plating:** Gray
- **Equipment:**
  - Detachable hands
  - Medical diagnostic computer
  - Photoreceptors
  - Surgical gown
  - Tool mount
  - Vocabulator
