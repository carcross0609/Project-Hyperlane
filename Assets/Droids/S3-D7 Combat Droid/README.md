# S3-D7 Combat Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [S3-D7 Combat Droid](https://starwars.fandom.com/wiki/S3-D7_Combat_Droid)

The S3-D7 Combat Droid was a model of humanoid battle droid used by the Exchange on the moon Nar Shaddaa during the Cold War between the Galactic Republic and the reconstituted Sith Empire. The Exchange used a number of S3-D7 droids to patrol the Chemical Refinement District of the Corellian Sector.

## Specifications

- **Name:** S3-D7 Combat Droid
- **Class:** Battle droid
- **Degree:** Class four droid
- **Sensor:** Red
- **Plating:** Tan
- **Armament:** Blaster rifle
- **Affiliation:** Exchange
