# Baker droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Baker droid/Legends](https://starwars.fandom.com/wiki/Baker_droid/Legends)

Baker droids were a model of cooking droid built using the frames of 2-1B surgical droids that catered social events. During the Clone Wars, one baker droid assisted Senator Padmé Amidala with a gathering held for Senator Aang.

## Specifications

- **Name:** Baker droid
- **Class:** Cooking droid
- **Gender:** Masculine programming
- **Sensor:** Blue
- **Affiliation:** Galactic Republic
