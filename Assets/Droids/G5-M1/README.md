# G5-M1

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [G5-M1](https://starwars.fandom.com/wiki/G5-M1)

G5-M1 was a protocol droid of the Galactic Republic active during the Cold War. In 3643 BBY it was stationed aboard the Wanderer-class transport Esseles when it was attacked by the Harrower-class dreadnought Emperor's Glory.

## Specifications

- **Name:** G5-M1
- **Class:** Protocol droid
- **Sensor:** Yellow
- **Plating:** Gold
