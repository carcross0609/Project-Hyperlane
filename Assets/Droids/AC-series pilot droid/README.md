# AC-series pilot droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [AC-series pilot droid](https://starwars.fandom.com/wiki/AC-series_pilot_droid)

The AC-series pilot droid was a model of commuter ship pilot droid that predated the better-known RX-series. One day, one such droid designated AC-38 allowed its StarSpeeder to be hijacked by a rogue protocol droid and taken to a dangerous trip across the galaxy. Because of that incident, all AC-series units were retired from service and replaced by RX-series droids, which proved to be only slightly more reliable.
