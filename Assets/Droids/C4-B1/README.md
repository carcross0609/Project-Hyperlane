# C4-B1

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [C4-B1](https://starwars.fandom.com/wiki/C4-B1)

C4-B1 was a DUM-series pit droid with masculine programming that worked in a galaxy-wide taxi service. On Kef Bir, C4-B1 facilitated the use of a sea skiff rather than a taxi.
