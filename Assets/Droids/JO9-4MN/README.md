# JO9-4MN

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [JO9-4MN](https://starwars.fandom.com/wiki/JO9-4MN)

JO9-4MN was a boxy, primitive model of power droid manufactured by Veril Line Systems that was repurposed by the Trade Federation to act as a repair droid and foreman on the WD-2550 Whydah-class Yield Conveyer Fallon. It was responsible for work assignments and monitoring billable work hours and kept an active telemetric diagnostic link to each of the spacesuits used by the starship's mekneks.
