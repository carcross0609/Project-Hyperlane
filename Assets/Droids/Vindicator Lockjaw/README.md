# Vindicator Lockjaw

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Vindicator Lockjaw](https://starwars.fandom.com/wiki/Vindicator_Lockjaw)

The Vindicator Lockjaw was a model of guard droid. It was a four-legged machine known for being fierce when attacking. The Vindicator Lockjaw had a built-in heavy blaster pistol, duramite-tipped fangs, and an enhanced sensor package.

## Specifications

- **Name:** Vindicator Lockjaw
- **Class:** Guard droid
- **Armament:**
  - Built in heavy blaster pistol
  - Duramite-tipped fangs
- **Equipment:** Enhanced sensor package
