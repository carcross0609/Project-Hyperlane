# T4-9K Excavator

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [T4-9K Excavator](https://starwars.fandom.com/wiki/T4-9K_Excavator)

T4-9K Excavator was an Isotope-5 droid produced at some point during the Galactic War. By 3630 BBY it was used by renegade Sith Lords Adacin and Zanisk to guard the base they set in the former Separatist stronghold on Ord Mantell. When the Eternal Alliance forces attacked the base, T4-9K Excavator was deployed to stop them, but was destroyed.
