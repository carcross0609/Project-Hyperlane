# FE-3PO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [FE-3PO](https://starwars.fandom.com/wiki/FE-3PO)

FE-3PO was a 3PO-series protocol droid active during the Galactic Civil War. Programmed for Human-Cyborg relations, FE-3PO was also an expert on the other prominent individual droids and droid models in the galaxy at the time.

- **Name:** FE-3PO
- **Model:** 3PO-series protocol droid
- **Class:** Protocol droid
