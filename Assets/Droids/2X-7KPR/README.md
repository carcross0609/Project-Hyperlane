# 2X-7KPR

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [2X-7KPR](https://starwars.fandom.com/wiki/2X-7KPR)

2X-7KPR ("Tooex") was a green domed KPR security droid operational during the Galactic Civil War. It was capable of monitoring floodlights and perimeter sensors as well as maintaining security devices. The droid was originally owned by Jabba the Hutt until it was stolen, ending up in the possession of the Jawa tribe led by Nebit on the planet Tatooine.
