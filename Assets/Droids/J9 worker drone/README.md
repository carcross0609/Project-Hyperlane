# J9 worker drone

**Kind:** Series  
**Continuity:** Canon  
**Source:** [J9 worker drone](https://starwars.fandom.com/wiki/J9_worker_drone)

A J9 worker drone was a type of droid with a pointed face and large insect-like eyes resembling those of the Verpine species. The "monster droid" AG-90 had the head of a J9. BG-J38 was another J9 worker drone affiliated with Jabba Desilijic Tiure's criminal empire.
