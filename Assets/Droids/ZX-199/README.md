# ZX-199

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [ZX-199](https://starwars.fandom.com/wiki/ZX-199)

ZX-199 was an elite Skytrooper, a type of battle droid used by the Eternal Empire of Zakuul. In 3631 BBY, it was destroyed by Lana Beniko and The Commander inside the skytrooper droid factory on Zakuul.
