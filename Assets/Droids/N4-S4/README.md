# N4-S4

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [N4-S4](https://starwars.fandom.com/wiki/N4-S4)

N4-S4 was a protocol droid during the Galactic War. Stationed on the Vaiken Spacedock, N4-S4 asked an Imperial to rendezvous with Moff Altiss regarding the situation on Denova.
