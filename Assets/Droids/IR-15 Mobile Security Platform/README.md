# IR-15 Mobile Security Platform

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IR-15 Mobile Security Platform](https://starwars.fandom.com/wiki/IR-15_Mobile_Security_Platform)

The IR-15 Mobile Security Platform was a model of six-legged battle droid used by the the Shroud, a freelance spy active during the Galactic War between the Galactic Republic and the reconstituted Sith Empire. The Shroud's lieutenant Stangg employed IR-15 droids among the forces that defended the Shroud's base on the planet Quesh.

## Specifications

- **Name:** IR-15 Mobile Security Platform
- **Class:** Battle droid
- **Sensor:** Yellow
- **Plating:** Rusty brown
- **Affiliation:** The Shroud's organization
