# Lamp droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Lamp droid](https://starwars.fandom.com/wiki/Lamp_droid)

The Lamp droid was a droid that lit up the surrounding using lamps. A lamp droid was once used by Law's squad of clone troopers.
