# BG-J38

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [BG-J38](https://starwars.fandom.com/wiki/BG-J38)

BG-J38 was a bug-headed, yellow-plated J9 worker drone who served in the Hutt crime lord Jabba Desilijic Tiure's criminal empire. Within Jabba's Palace, the droid was stationed near the entrance to the throne room.
