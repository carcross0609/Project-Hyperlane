# H2-WF

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [H2-WF](https://starwars.fandom.com/wiki/H2-WF)

H2-WF was a "hunter-seeker" probe droid from Nathema refurbished for use by Eternal Alliance engineers. The droid utilized technology from Nathema's original inhabitants.

- **Homeworld:** Nathema
