# AD-304

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [AD-304](https://starwars.fandom.com/wiki/AD-304)

AD-304 was a droid that served the Imperial Reclamation Service of the reconstituted Sith Empire during the Galactic War. AD-304 delivered messages for officers such as Colonel Jadick.

## Specifications

- **Type:** Sith Empire
- **Name:** AD-304
- **Class:** Protocol droid
- **Gender:** Masculine programming
- **Sensor:** Red
- **Plating:** Silver
- **Affiliation:**
  - Sith Empire
  -   Imperial Reclamation Service
