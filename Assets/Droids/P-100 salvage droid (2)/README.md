# P-100 salvage droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [P-100 salvage droid](https://starwars.fandom.com/wiki/P-100_salvage_droid)

The P-100 salvage droid, also known as the maintenance spider droid, was a small repulsorlift droid, produced by Serv-O-Droid, Inc., in operation during the last decades of the Galactic Republic.

## Specifications

- **Name:** P-100 salvage droid
- **Manufacturer:** Serv-O-Droid, Inc.
- **Class:** Salvage droid
- **Degree:** Class five droid
- **Width:**
  - 3 meters
  - Smaller models
- **Height:** 2.4 meters
- **Armament:** None
- **Equipment:**
  - Visual sensor
  - Terrain-mapping sensor
  - Heavy-duty manipulator arms
  - Repulsorlift
- **Affiliation:** Podracing
