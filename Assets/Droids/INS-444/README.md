# INS-444

**Kind:** Series  
**Continuity:** Canon  
**Source:** [INS-444](https://starwars.fandom.com/wiki/INS-444)

The INS-444, also known as the window installer droid, was a model of installer droid designed to install the windows of buildings with their magnatomic grip pads. Part of the world's small army of maintenance droids, they were used on the planet Coruscant to install the windows of buildings many levels above the planet's surface. As seen through the unit Mick, window installer droids were given individual names that were placed on their bodies.

## Specifications

- **Name:** INS-444
- **Manufacturer:** Publitechnic
- **Class:** Maintenance droid
- **Degree:** Class five
