# B3-C4

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [B3-C4](https://starwars.fandom.com/wiki/B3-C4)

B3-C4 was a water scout droid built by the Besalisk Braygh to find underground water on Kundu Minor.

- **Birth:** 232 BBY
- **Creator:** Braygh
- **Class:** Survey droid
