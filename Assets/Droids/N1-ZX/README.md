# N1-ZX

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [N1-ZX](https://starwars.fandom.com/wiki/N1-ZX)

N1-ZX, nicknamed "Nunzix," was a BX-series droid commando who served in the Resistance's spy network during their conflict with the First Order. Nunzix was working on the Outer Rim world Kaddak where he acquired information about the First Order, including the location of Supreme Leader Snoke. Nunzix had a strong self-preservation programming that made it impossible for him to fight. This programming led him to view others as expendable.
