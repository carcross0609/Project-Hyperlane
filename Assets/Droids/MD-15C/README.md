# MD-15C

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [MD-15C](https://starwars.fandom.com/wiki/MD-15C)

MD-15C was an MD-15C medical droid. In 34 ABY, the medical droid was stationed aboard the Resistance Star Cruiser Raddus where the droid treated General Leia Organa.
