# FX-7 medical assistant droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [FX-7 medical assistant droid/Legends](https://starwars.fandom.com/wiki/FX-7_medical_assistant_droid/Legends)

The FX-7 medical assistant droid was a medical droid manufactured by Medtech Industries as part of the FX-series of surgical assistants and nursing droids. Typically, an FX-7 droid cost 3,500 credits. After the FX-7's manufacturing ended, it was only available as used by the time of the Galactic Civil War.

- **Name:** FX-7 medical assistant droid
- **Manufacturer:** Medtech Industries
- **Line:** FX-series medical assistant droid
- **Class:** Medical droid
- **Height:** 1.7 meters
- **Gender:** Masculine programming
- **Armament:** None
- **Equipment:**
  - Medical computer scomp link
  - Medical diagnostic computer and sensor
  - Light manipulator arms (20)
  - Main manipulator arm
  - Surgical attachments
  - Hypodermic injectors
  - Medicine dispensers
