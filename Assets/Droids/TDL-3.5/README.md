# TDL-3.5

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [TDL-3.5](https://starwars.fandom.com/wiki/TDL-3.5)

TDL-3.5 was a TDL nanny droid that was purchased by Anakin Solo. It tried to replace C-3PO as caretaker of the Solo children under a code invented by Anakin, "Bantha four five six." Winter Celchu, who was taking care of the children with C-3PO, recognized that "Bantha four five six" was not the Solo family recognition code for their droids.
