# N4-3PO

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [N4-3PO](https://starwars.fandom.com/wiki/N4-3PO)

N4-3PO was a metallic green protocol droid owned by Tol Pirilian. N4-3PO and Pirilian's other droid, N3-3PO, could use over six million forms of communication, and often communicated using obscure languages.

## Specifications

- **Name:** N4-3PO
- **Class:** Protocol droid
- **Pronouns:** new
- **Plating:** Metallic green
