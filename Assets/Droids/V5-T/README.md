# V5-T

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [V5-T](https://starwars.fandom.com/wiki/V5-T)

V5-T was a V-5 transport droid and one of the three droid brains within the computer of the starship Millennium Falcon. She was the first of the three to be uploaded onto the ship's consciousness.

## Specifications

- **Name:** V5-T
- **Class:** V-5 transport droid
- **Gender:** Feminine programming
- **Pronouns:** She/her
- **Affiliation:** Millennium Collective
