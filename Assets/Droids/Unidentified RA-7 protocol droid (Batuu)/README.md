# Unidentified RA-7 protocol droid (Batuu)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified RA-7 protocol droid (Batuu)](https://starwars.fandom.com/wiki/Unidentified_RA-7_protocol_droid_%28Batuu%29)
