# J4-KC

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [J4-KC](https://starwars.fandom.com/wiki/J4-KC)

J4-KC was an R2-series astromech droid owned by Jat Kaa's Coolers on Batuu. The droid drove a ground vehicle that carried Sprite beverages that were sold in Black Spire Outpost. The droid's green-and-white color scheme matched that of the vehicle, themed to the Sprite logo.

## Specifications

- **Name:** J4-KC
- **Line:** R-series
- **Model:** R2-series astromech droid
- **Class:** Astromech droid
- **Sensor:** Black
- **Plating:** Green and white
- **Affiliation:** Jat Kaa's Coolers
