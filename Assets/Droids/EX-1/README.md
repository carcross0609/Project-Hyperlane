# EX-1

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [EX-1](https://starwars.fandom.com/wiki/EX-1)

EX-1, or Ex-Wun, formerly Eeex-Zerogee, was an EX droid. In 229 BBY, EX-1 was reassembled by Jedi Master Porter Engle.

- **Type:** Galactic Republic

- **Death:** By 229 BBY (rebuilt)
- **Model:** EX communication droid
- **Class:** Communications droid
- **Height:** 97 centimeters (3 ft, 2 in)
- **Affiliation:** Jedi Order
