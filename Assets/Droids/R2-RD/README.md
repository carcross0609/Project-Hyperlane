# R2-RD

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [R2-RD](https://starwars.fandom.com/wiki/R2-RD)

R2-RD was an Alliance astromech droid paired with C-D20, a Human-cyborg relations droid. They were assigned to Commander Dauntarist aboard a newly-manufactured HT-2200 medium freighter.
