# D-1G

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [D-1G](https://starwars.fandom.com/wiki/D-1G)

D-1G, or Dee-Onegee, was an astromech droid that served as a pilot droid for the Rampart. Tobias Beckett spliced into the console of the Rampart. The droid was aboard the Rampart when the ship was destroyed by Beckett on the space station Munt Ontdal.

## Specifications

- **Name:** D-1G
- **Death:** 11 BBY, Munt Ontdal
- **Line:** R-series astromech droid
- **Class:** Pilot droid
- **Affiliation:** Beckett's gang
