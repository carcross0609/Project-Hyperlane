# Unidentified protocol droid (Shu-Torun)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified protocol droid (Shu-Torun)](https://starwars.fandom.com/wiki/Unidentified_protocol_droid_%28Shu-Torun%29)

A protocol droid served in the royal palace on Shu-Torun. While accompanying Darth Vader on a mission to the planet, the assassin droids 0-0-0 and BT-1 encountered the protocol droid. Triple-Zero asked the droid if it could help them get through a door, but it told them that only droids with the correct clearance codes were allowed to enter the palace grounds. As the droid walked away, Beetee suggested torturing it, which Triple-Zero refused, stating that he did not torture droids. However, this gave him an idea, and he lured the protocol droid into an empty room. When the droid entered, Triple-Zero disabled its pain receptors and stripped its data core, using it to open the door.
