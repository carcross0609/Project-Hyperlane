# R8-B7

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [R8-B7](https://starwars.fandom.com/wiki/R8-B7)

R8-B7 was a R-series astromech droid, used as a co-pilot by Jedi Master Mace Windu. He shared his coloration with Windu's lightsaber.
