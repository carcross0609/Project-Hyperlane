# P-3DB

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [P-3DB](https://starwars.fandom.com/wiki/P-3DB)

P-3DB was a protocol droid used by the Galactic Republic during the Galactic War. In 3639 BBY it was stationed on the Valor-class cruiser Gav Daragon.
