# Decon III

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Decon III](https://starwars.fandom.com/wiki/Decon_III)

The Decon III was a variant of Industrial Automaton's Decon series, a type of decon droid. The name was short for decontamination droid.

## Specifications

- **Name:** Decon III
- **Manufacturer:** Industrial Automaton
- **Line:** Decon series
- **Class:** Decon droid
- **Height:** 1.3 meters
- **Equipment:**
  - Discharge fan
  - Binary Vocabulator
  - Optical/analytical sensor cluster
  - Reinforced legs
  - System ventilation
  - Internal catalytic cleansing chambers
  - Retractable manipulator arm
  - Intake hopper
  - Forward soil shovel
  - Rear discharge chute
  - Diagnostic access hatch
- **Affiliation:**
  - Galactic Republic
  - Galactic Empire
  - New Republic
