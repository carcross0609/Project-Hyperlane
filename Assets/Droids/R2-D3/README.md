# R2-D3

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [R2-D3](https://starwars.fandom.com/wiki/R2-D3)

R2-D3 was one of the astromech droids on D'Qar. When R6-D8 malfunctioned right before the Battle of Starkiller Base, R2-D3 took his place as Temmin Wexley's astromech for the battle.
