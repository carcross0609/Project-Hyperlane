# Mark IV architect droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Mark IV architect droid](https://starwars.fandom.com/wiki/Mark_IV_architect_droid)

The Mark IV architect droid was an ancient model of architect droid which was over 25,000 standard years old predating the Galactic Republic itself, it was considered an antique by the Imperial Era.
