# Unidentified DT-series sentry droid (Kylo Ren)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified DT-series sentry droid (Kylo Ren)](https://starwars.fandom.com/wiki/Unidentified_DT-series_sentry_droid_%28Kylo_Ren%29)
