# Mataou Hutt security droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Mataou Hutt security droid](https://starwars.fandom.com/wiki/Mataou_Hutt_security_droid)

The Mataou Hutt security droid was a security droid found on the planet Mataou. These droids roamed through the long-abandoned Hutt settlements and attacked any being they perceived to be a threat. Each droid wielded a Blaster rifle and occasionally a quarterstaff.

## Specifications

- **Name:** Mataou Hutt security droid
- **Class:** Security droid
- **Sensor:** Red
- **Armament:**
  - Blaster rifle
  - Quarterstaff
