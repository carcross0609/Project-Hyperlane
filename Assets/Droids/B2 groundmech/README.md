# B2 groundmech

**Kind:** Series  
**Continuity:** Canon  
**Source:** [B2 groundmech](https://starwars.fandom.com/wiki/B2_groundmech)

The B2 groundmech was a model of salvage assist unit manufactured by Cybot Galactica. It was intended for use in salvage operations and as such was equipped with many tools to assist human operators, including a storage tray, a powerful engine capable of tugging many kilograms of cargo as well as high-torque mobility wheels.

## Specifications

- **Model:** Salvage assist unit
- **Class:** Groundmech
