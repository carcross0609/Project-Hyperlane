# MMV security droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [MMV security droid](https://starwars.fandom.com/wiki/MMV_security_droid)

The MMV security droid was a series of tracked security droids used by Outer Rim Oreworks around five hundred years before the Battle of Naboo.

## Specifications

- **Name:** MMV security droid
- **Class:** Security droid
- **Armament:**
  - 2 repeating blaster rifles
  - 2 vibro-axes
- **Equipment:**
  - Infrared vision
  - Locked access
  - Vocabulator
- **Affiliation:** Outer Rim Oreworks
