# Mechthorian

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mechthorian](https://starwars.fandom.com/wiki/Mechthorian)

The Mechthorian was a model of security droid manufactured by the Stonewall Labs company during the Imperial Era. The droid resembled the Ithorian species and was taller than a medium-sized Human. The Mechthorian was able to fight using ranged weapons.

## Specifications

- **Name:** Mechthorian
- **Manufacturer:** Stonewall Labs
- **Class:** Security droid
- **Sensor:** Gray
- **Plating:** Brown, gray
- **Affiliation:** Stonewall Labs
