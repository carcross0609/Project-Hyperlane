# Rescind E.R. Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Rescind E.R. Droid](https://starwars.fandom.com/wiki/Rescind_E.R._Droid)

The Rescind E.R. Droid was a type of modified DZ-70 fugitive tracker droid used during the Galactic Civil War. Droids of this kind was unarmed as it primarily filled a reconnaissance role. Rescind E.R. Droids were used by the Rak'qua on Station Gamma above Ord Mantell following the Battle of Yavin. In 1 ABY, a number of spacers who explored Station Gamma fought and destroyed multiple Rescind E.R. Droids.

## Specifications

- **Name:** Rescind E.R. Droid
- **Line:** DZ-70 fugitive tracker droid
- **Class:** Assassin droid
- **Plating:** Metallic red
- **Armament:** None
- **Affiliation:** Rak'qua
