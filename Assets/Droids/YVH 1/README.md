# YVH 1

**Kind:** Series  
**Continuity:** Legends  
**Source:** [YVH 1](https://starwars.fandom.com/wiki/YVH_1)

The YVH 1, or Yuuzhan Vong Hunter One combat droid, was a battle droid developed by Tendrando Arms as a means to effectively combat Yuuzhan Vong warriors.

## Specifications

- **Name:** YVH 1
- **Manufacturer:** Tendrando Arms
- **Line:** YVH-Series battle droid
- **Class:** Battle droid
- **Degree:** Class four droid
- **Height:** 1.9 meters
- **Gender:** Masculine programming
- **Sensor:** Yellow or red
- **Armament:**
  - Variable-output blaster cannon (right arm)
  - Concealed grenade launcher (elbow, 2 grenades)
  - Electroray discharger
  - Class-C thermal detonators
  - Coma gas canisters
  - Self-guiding minirockets
- **Equipment:**
  - Telescopic photoreceptors
  - Advanced sensor package
  - Repulsorlift boosters
  - Laminanium armor
- **Affiliation:**
  - New Republic
  - Galactic Federation of Free Alliances
  - Five Worlds
  - Heritage Council
