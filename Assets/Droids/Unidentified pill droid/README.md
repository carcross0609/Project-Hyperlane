# Unidentified pill droid

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified pill droid](https://starwars.fandom.com/wiki/Unidentified_pill_droid)

This pill droid served on the Longbeam cruiser Aurora IX in 232 BBY. During a rescue operation on Solar Array 22-X, the Republic Defense Coalition Captain Finial Bright utilized this pill droid in gathering survivors from the wrecked space station.
