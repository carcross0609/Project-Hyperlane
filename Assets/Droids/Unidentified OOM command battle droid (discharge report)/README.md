# Unidentified OOM command battle droid (discharge report)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Unidentified OOM command battle droid (discharge report)](https://starwars.fandom.com/wiki/Unidentified_OOM_command_battle_droid_%28discharge_report%29)

During the Clone Wars, an OOM command battle droid led at least two B1-series battle droids on a desert planet resembling Tatooine. One of the B1 battle droids under his command; however, ended up blasting the head off another B1 droid due to a programming glitch, causing the OOM droid to clutch its face in exasperation and presumably file another suboptimal weapon discharge report, which it had done at least one day prior.
