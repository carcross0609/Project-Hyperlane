# Razor droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Razor droid](https://starwars.fandom.com/wiki/Razor_droid)

Razor droids were spherical hovering droids that were equipped with a circular saw blade. At the time of the early rebellion against the Galactic Empire, the Galactic Empire used such droids.

## Specifications

- **Name:** Razor droid
- **Class:** Security droid
- **Degree:** Class three droid
- **Affiliation:** Galactic Empire
