# P2 astromech unit

**Kind:** Series  
**Continuity:** Canon  
**Source:** [P2 astromech unit](https://starwars.fandom.com/wiki/P2_astromech_unit)

The P2 astromech unit was the first droid purposely-built and marketed as an astromech droid. Launched by developer-manufacturer Industrial Automaton some decades before the Clone Wars of 22 BBY–19 BBY, the model was sold exclusively to the Republic merchant fleet. Stood at 2.3 meters tall, the P2's head and shoulders towered average humans and droids. The astromech unit was very effective as a shipboard tool, possessing a barrel-chested body, retractable manipulator arms, a trio of wheeled legs, a sensor-filled domed head, and a video display for communication.
