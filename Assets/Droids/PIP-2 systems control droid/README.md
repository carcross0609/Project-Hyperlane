# PIP/2 systems control droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [PIP/2 systems control droid](https://starwars.fandom.com/wiki/PIP/2_systems_control_droid)

The PIP/2 systems control droid was produced by Genetech Corporation with the intention to replace organic operators running control boards. It was advertised as glitch-proof, and was heavily hyped, but failed miserably. Although it handled simple tasks with ease, it was unable to handle excessive stimuli, such as bells or flashing lights, constantly malfunctioning. Genetech quickly responded to complaints and recalled as many of these droids as possible. These recalled droids were given programming patches, and operated almost perfectly. It was not enough, however, as the droid was discontinued after two years.

## Specifications

- **Name:** PIP/2 systems control droid
- **Manufacturer:** Genetech Corporation
- **Equipment:**
