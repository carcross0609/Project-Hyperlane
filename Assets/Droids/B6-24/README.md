# B6-24

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [B6-24](https://starwars.fandom.com/wiki/B6-24)

B6-24 was a protocol droid with feminine programming who hosted Droid Station Frequency 3-7-6-4-3-7, a classified radio station where droids helped droids. The station played in Black Spire Outpost on the planet Batuu.
