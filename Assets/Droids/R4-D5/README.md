# R4-D5

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [R4-D5](https://starwars.fandom.com/wiki/R4-D5)

R4-D5 was an R-series astromech droid. R4 served in both the Clone Wars aboard an Aggressive ReConnaissance-170 starfighter, then later in the Galactic Civil War aboard a BTL Y-wing starfighter. R4 was present for the Battle of Yavin.
