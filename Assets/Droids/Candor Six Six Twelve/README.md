# Candor Six Six Twelve

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Candor Six Six Twelve](https://starwars.fandom.com/wiki/Candor_Six_Six_Twelve)

Candor Six Six Twelve was an old protocol droid. The artificial intelligence computer Stoneheart chose Candor Six Six Twelve to transport its primary command module to the Ord Mynock Freeport.
