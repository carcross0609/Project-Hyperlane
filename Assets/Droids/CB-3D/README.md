# CB-3D

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [CB-3D](https://starwars.fandom.com/wiki/CB-3D)

CB-3D was Flynn Kybo's astromech droid during the Clone Wars. Attempting to assassinate General Grievous on Belsus, CB-3D came along in case the Trade Federation codes they were planning to use should fail.
