# BB-5

**Kind:** Individual  
**Continuity:** Uncategorized  
**Source:** [BB-5](https://starwars.fandom.com/wiki/BB-5)

BB-5 was a BB-wing droid starfighter created by Sig Greebling. It was piloted by Jedi Vader during a battle against Solitus, alongside BB-2 and BB-8.
