# CLL-M2 binary loadlifter

**Kind:** Series  
**Continuity:** Legends  
**Source:** [CLL-M2 binary loadlifter/Legends](https://starwars.fandom.com/wiki/CLL-M2_binary_loadlifter/Legends)
