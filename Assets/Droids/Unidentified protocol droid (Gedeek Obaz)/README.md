# Unidentified protocol droid (Gedeek Obaz)

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [Unidentified protocol droid (Gedeek Obaz)](https://starwars.fandom.com/wiki/Unidentified_protocol_droid_%28Gedeek_Obaz%29)

A protocol droid was worked on by the Rodian droidsmith Gedeek Obaz in 3 ABY. When Kay Vess approached Obaz to help her with a job, the Rodian took control of the droid to attack her.
