# 2JTJ

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [2JTJ](https://starwars.fandom.com/wiki/2JTJ)

2JTJ, usually referred to as TooJay, was a navigation droid provided by the Jedi Order to Master Tahl after she was blinded on Melida/Daan.
