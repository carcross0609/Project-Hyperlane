# B1 grapple droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [B1 grapple droid](https://starwars.fandom.com/wiki/B1_grapple_droid)

The B1 grapple droid was a type of B1-series battle droid used by the Separatist Droid Army during the Clone Wars, a galactic conflict between the Confederacy of Independent Systems and the Galactic Republic. Like its B2 counterpart, the B1 grapple droid was armed with grapple claws for hand-to-hand combat.

- **Name:** B1 grapple droid
