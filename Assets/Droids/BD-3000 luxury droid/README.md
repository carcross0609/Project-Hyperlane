# BD-3000 luxury droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [BD-3000 luxury droid](https://starwars.fandom.com/wiki/BD-3000_luxury_droid)

BD-3000 luxury droids, also known as attendant droids, BD units, and nicknamed "Bettie Bots", were a model of high-end "secretary droid" used by the Galactic Republic, Trade Federation, and Hutt Clan during the Clone Wars.

## Specifications

- **Name:** BD-3000 luxury droid
- **Manufacturer:** LeisureMech Enterprises
- **Class:** Secretary droid
- **Degree:** Class Three
- **Cost:** 25,000 Credits (basic model)
- **Height:** 1.76 meters
- **Gender:** Feminine programming
- **Affiliation:**
  - Galactic Republic
  - Trade Federation
  - Hutt Clan
