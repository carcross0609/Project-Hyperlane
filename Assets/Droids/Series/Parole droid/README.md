# Parole droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Parole droid](https://starwars.fandom.com/wiki/Parole_droid)

A parole droid was a type of humanoid droid. A parole droid supervised Penn Pershing when he was part of the New Republic Amnesty Program.
