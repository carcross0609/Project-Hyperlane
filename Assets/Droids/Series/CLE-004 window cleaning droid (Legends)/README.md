# CLE-004 window cleaning droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [CLE-004 window cleaning droid/Legends](https://starwars.fandom.com/wiki/CLE-004_window_cleaning_droid/Legends)

The CLE-004 window cleaning droid, also known simply as a cleaner droid, was a fifth-degree window cleaning droid produced by Publictechnic during the time of the Galactic Republic. It commonly worked alongside INS-444 window installation droids.

- **Name:** CLE-004 window cleaning droid
- **Manufacturer:** Publictechnic
- **Line:** CLE-004
- **Class:** Class five droid
- **Height:** 0.3 meters
- **Sensor:** Yellow
- **Armament:** None
- **Equipment:**

  - Broadcast signal and power receiver
  - Repulsorlift
