# HV-7 loading droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [HV-7 loading droid](https://starwars.fandom.com/wiki/HV-7_loading_droid)

The HV-7 loading droid was a small hovering utility droid that utilized repulsor technology to lift heavy loads, eliminating the need for the huge bulk-loader droids used previously. They could fold up into a disc, which made them take up less space.

## Specifications

- **Name:** HV-7 loading droid
- **Manufacturer:** Baktoid Industrial Systems
- **Class:** Labor droid
- **Degree:** Class 5
- **Cost:** 1,950 credits
- **Armament:** none
- **Equipment:**
  - diagnostic package
  - repulsor-assisted lifting system
  - 2 claw appendages
- **Affiliation:** Mon Calamari Shipyards
