# RA-7 protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [RA-7 protocol droid/Legends](https://starwars.fandom.com/wiki/RA-7_protocol_droid/Legends)

The RA-7 protocol droid, nicknamed the "Death Star droid," was a low-intelligence model of protocol droid produced by Arakyd Industries specifically for the Galactic Empire.

## Specifications

- **Name:** RA-7 protocol droid
- **Manufacturer:** Arakyd Industries
- **Class:** Protocol droid
- **Height:** 1.7 meters
- **Sensor:** Silver, gold, green or black
- **Equipment:** Interface connection port
- **Affiliation:**
  - Confederacy of Independent Systems
  - Galactic Republic
  - Galactic Empire
