# IR-5B Stealth Security Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IR-5B Stealth Security Droid](https://starwars.fandom.com/wiki/IR-5B_Stealth_Security_Droid)

The IR-5B Stealth Security Droid was a model of humanoid battle droid used by the the Shroud, a freelance spy active during the Galactic War. Equipped with a blaster rifle and stealth field generator, IR-5B Security Droids were among the forces guarding B-NK1's base in the back room of the Dealer's Den cantina on Coruscant.

## Specifications

- **Name:** IR-5B Stealth Security Droid
- **Class:** Battle droid
- **Sensor:** Blue
- **Armament:** Blaster rifle
- **Equipment:** Stealth field generator
- **Affiliation:** The Shroud's organization
