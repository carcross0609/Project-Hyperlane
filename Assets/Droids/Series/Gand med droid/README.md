# Gand med droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Gand med droid](https://starwars.fandom.com/wiki/Gand_med_droid)

The Gand med droid was a medical droid model. It had a thin frame and a head similar in appearance to that of a member of the Gand species. One of these units was present in a smelting room in Cloud City on Bespin when Chewbacca arrived in search of C-3PO prior to the escape from Cloud City.

- **Name:** Gand med droid
- **Class:** Medical droid
