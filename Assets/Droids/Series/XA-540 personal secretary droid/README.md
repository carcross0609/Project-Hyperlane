# XA-540 personal secretary droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [XA-540 personal secretary droid](https://starwars.fandom.com/wiki/XA-540_personal_secretary_droid)

The XA-540 personal secretary droid was a model of secretary droids manufactured by Opti-Prime.

## Specifications

- **Name:** XA-540 personal secretary droid
- **Manufacturer:** Opti-Prime
- **Class:** Secretary droid
- **Degree:** Class three droid
- **Cost:** 2,500 credits
- **Height:** 1.6 meters
- **Equipment:**
  - Two visual and auditory sensors (Human range)
  - Vocabulator
  - TranLang I Communication module
  - Business administration policies and procedures database
