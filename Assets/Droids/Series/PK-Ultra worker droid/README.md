# PK-Ultra worker droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [PK-Ultra worker droid](https://starwars.fandom.com/wiki/PK-Ultra_worker_droid)

The PK-Ultra worker droid was a model of worker droid. One such droid, nicknamed Pook, served the Resistance. It had a similar name to the PK-series worker droids that had been used by the Trade Federation and Confederacy of Independent Systems.

## Specifications

- **Name:** PK-Ultra worker droid
- **Class:** Labor droid
- **Sensor:** Black
- **Plating:** Silvery white
