# ISF-E4 Eliminator Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [ISF-E4 Eliminator Droid](https://starwars.fandom.com/wiki/ISF-E4_Eliminator_Droid)

ISF-E4 Eliminator Droid was a battle droid model used by the reconstituted Sith Empire during the Cold War. In 3643 BBY droids of this model were used by the Shadow Fist in their trap set for the Havoc Squad.
