# KXFO-series security droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [KXFO-series security droid](https://starwars.fandom.com/wiki/KXFO-series_security_droid)

The KXFO-series security droid, also known as the First Order security droid, was a model of security droid manufactured by Arakyd Industries and utilized by the First Order during their war with the Resistance. These droids had a humanoid shape with white plating and red sensors. Some of the droids were stationed on the Titan refueling depot, manning the supply depot and patrolling the corridors for intruders. Two KXFO security droids also worked on the engineering deck in the Thunderer, before Resistance pilot Kazuda Xiono, former First Order pilot Tamara Ryvora, and Jarek Yeager blasted the two.
