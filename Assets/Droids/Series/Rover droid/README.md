# Rover droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Rover droid](https://starwars.fandom.com/wiki/Rover_droid)

Rover droids were a model of security droid. Built on the same platform as the MSE-6-series repair droid, the droids were armed with a blaster pistol. Rover droids were employed extensively by the ComNet Corporation at the Ord Mynock Freeport.

## Specifications

- **Name:** Rover droid
- **Class:** Security droid
- **Armament:** Blaster pistol
- **Affiliation:** ComNet Corporation
