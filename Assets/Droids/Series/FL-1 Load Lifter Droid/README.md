# FL-1 Load Lifter Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [FL-1 Load Lifter Droid](https://starwars.fandom.com/wiki/FL-1_Load_Lifter_Droid)

The FL-1 Load Lifter Droid was a humanoid-shaped labor droid model that was used at the Balmorran Arms Factory on the planet Balmorra during the Cold War, a proxy conflict between the Galactic Republic and the reconstituted Sith Empire.

## Specifications

- **Name:** FL-1 Load Lifter Droid
- **Class:** Labor droid
- **Sensor:** Blue
