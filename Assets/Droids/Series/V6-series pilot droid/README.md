# V6-series pilot droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [V6-series pilot droid](https://starwars.fandom.com/wiki/V6-series_pilot_droid)

The V6-series pilot droid model was Industrial Automaton's followup to their successful V1-series pilot droid model. Like other pilot droids, they were designed to supplement or replace biological pilots for spacecraft and starships.

## Specifications

- **Name:** V6-series pilot droid
- **Manufacturer:** Industrial Automaton
- **Line:** V-series pilot droid
- **Class:** Astromech droid
- **Degree:** Class two droid
- **Cost:**
  - 17,800 credits (new)
  - 12,000 credits (used)
- **Height:** 1 meter
- **Equipment:**
  - 1 retractable arm
  - Starship interface jack
  - Video display screen
  - 1 visual sensor (Human range)
  - Memory for five hyperspace jumps
