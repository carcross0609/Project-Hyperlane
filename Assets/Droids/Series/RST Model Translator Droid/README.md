# RST Model Translator Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [RST Model Translator Droid](https://starwars.fandom.com/wiki/RST_Model_Translator_Droid)

Created by the Plintep Cybernetics Corporation, the RST Model Translator Droid was designed to be a pure translation droid. Built with feminine programming and large breasts due to the prominence of females in Mephout politics, the RST Model was made to translate languages without the subtlety and nuances of a protocol droid.
