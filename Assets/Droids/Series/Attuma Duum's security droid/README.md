# Attuma Duum's security droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Attuma Duum's security droid](https://starwars.fandom.com/wiki/Attuma_Duum%27s_security_droid)

Security droids were used by the war-profiteer Attuma Duum during the Clone Wars. In 21 BBY, Jedi Knight Aayla Secura, along with the rogue Force-user Shon-Ju, attacked Duum and destroyed several of these droids.
