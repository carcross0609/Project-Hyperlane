# N5 sentry droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [N5 sentry droid](https://starwars.fandom.com/wiki/N5_sentry_droid)

The N5 sentry droid, also known as the New Republic Security Droid, was a model of security droid manufactured by SoroSuub Corporation that existed in the Imperial Era and the later New Republic Era, where it would be used by the New Republic Correctional Corps.

## Specifications

- **Name:** N5 sentry droid
- **Manufacturer:** SoroSuub Corporation
- **Model:** N5
- **Class:**
  - Security droid
  - Sentry droid
- **Height:** 1.95 meters (6 ft, 5 in)
- **Sensor:** Yellow
- **Plating:** Gray
- **Armament:**
  - DH-17 blaster pistol
  - Stun baton
- **Affiliation:**
  - Second Revelation
  - New Republic
  -   New Republic Correctional Corps
  - Droid Gotra
  - The Twins
