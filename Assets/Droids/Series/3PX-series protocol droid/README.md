# 3PX-series protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [3PX-series protocol droid](https://starwars.fandom.com/wiki/3PX-series_protocol_droid)

The 3PX-series protocol droid or 3PX series droids were third-degree protocol droids produced by Cybot Galactica in 50 BBY as an extension of the company's 3PO-series protocol droid line.

## Specifications

- **Name:** 3PX-series protocol droid
- **Manufacturer:** Cybot Galactica
- **Class:** Protocol droid
- **Degree:** Class three droid
- **Cost:** 7,750 credits
- **Height:** 1.67 meters
- **Gender:** Masculine programming
- **Sensor:** Yellow
- **Equipment:**
  - 2 Photoreceptors
  - Vocabulator
