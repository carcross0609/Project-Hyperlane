# ZH-28 guard

**Kind:** Series  
**Continuity:** Legends  
**Source:** [ZH-28 guard](https://starwars.fandom.com/wiki/ZH-28_guard)

The ZH-28 guard was a model of security droids manufactured by the Stonewall Labs company during the Imperial Period. This droid had a humanoid shape and was as tall as a medium-sized Human. The ZH-28 guard was able to fight using ranged weapons.

## Specifications

- **Name:** ZH-28 guard
- **Manufacturer:** Stonewall Labs
- **Class:** Security droid
- **Sensor:** Red
- **Plating:** Brown, gray
- **Equipment:** E-5 blaster rifle
- **Affiliation:** Stonewall Labs
