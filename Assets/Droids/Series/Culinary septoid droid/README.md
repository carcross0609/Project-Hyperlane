# Culinary septoid droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Culinary septoid droid](https://starwars.fandom.com/wiki/Culinary_septoid_droid)

A culinary septoid droid was a model of cooking droid. It was an expert gourmet chef in more than fifteen thousand different styles of cuisine. The Solo family owned a class 3 culinary septoid droid called BX-778.

## Specifications

- **Name:** Culinary septoid droid
- **Class:** Cooking droid
- **Degree:** Class 3
- **Equipment:** 7 arms
