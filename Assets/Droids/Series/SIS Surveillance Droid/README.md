# SIS Surveillance Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [SIS Surveillance Droid](https://starwars.fandom.com/wiki/SIS_Surveillance_Droid)

The SIS Surveillance Droid was a model of surveillance droid manufactured by Taptronics. They were simple units intended to supplement organic security forces. The main role of the droid was to notice criminal activity and report it to Human police officers.

## Specifications

- **Name:** SIS Surveillance Droid
- **Manufacturer:** Taptronics
- **Class:** Surveillance droid
- **Cost:** 5,000 credits
- **Length:** 1 meter
- **Width:** 1 meter
- **Height:** 1 meter
- **Equipment:**
  - Holographic/audio recorder
  - Internal comlink
  - Repulsorlift
