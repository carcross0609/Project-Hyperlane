# S19 astromech droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [S19 astromech droid](https://starwars.fandom.com/wiki/S19_astromech_droid)

The S19 astromech droid was a droid designed by LesTech to attempt a foray into the lucrative astromech market.

## Specifications

- **Name:** S19 astromech droid
- **Manufacturer:** LesTech
- **Class:** astromech droid
- **Degree:** Class two droid
- **Cost:** 8625 credits
- **Height:** 1 meter
- **Armament:**
  - Claw appendage
  - Six tool appendages
  - Five-jump astrogation buffer
  - Internal Comlink
  - Holorecorder
  - Shield generator (modified)
