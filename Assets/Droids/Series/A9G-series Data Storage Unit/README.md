# A9G-series Data Storage Unit

**Kind:** Series  
**Continuity:** Legends  
**Source:** [A9G-series Data Storage Unit](https://starwars.fandom.com/wiki/A9G-series_Data_Storage_Unit)

The A9G-series Data Storage Unit was a humanoid droid produced by Industrial Automaton during the time of the Galactic Empire. The market cost for such a unit normally was around 8,000 credits if the droid was second-hand.

## Specifications

- **Name:** A9G-series Data Storage Unit
- **Manufacturer:** Industrial Automaton
- **Class:** Data storage unit
- **Degree:** Class one droid
- **Cost:** 6,880 – 8,000 credits
- **Height:** 1.7 meters
- **Equipment:**
  - Cybot Galactica Data-Sifter software package
  - Kraren XI Superprocessor
