# LC-92 antagonist

**Kind:** Series  
**Continuity:** Legends  
**Source:** [LC-92 antagonist](https://starwars.fandom.com/wiki/LC-92_antagonist)

The LC-92 antagonist was a model of security droids manufactured by the Stonewall Labs company during the Imperial Era. This droid had a humanoid shape and was as tall as a medium-sized Human. The LC-92 antagonist was able to fight using ranged weapons.

## Specifications

- **Name:** LC-92 antagonist
- **Manufacturer:** Stonewall Labs
- **Class:** Security droid
- **Sensor:** Red
- **Plating:** Red, gray
- **Affiliation:** Stonewall Labs
