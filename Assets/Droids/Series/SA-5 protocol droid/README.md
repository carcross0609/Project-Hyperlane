# SA-5 protocol droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [SA-5 protocol droid](https://starwars.fandom.com/wiki/SA-5_protocol_droid)

The SA-5 protocol droid was a model of protocol droid with red plating. S1D6-SA-5 was a SA-5 protocol droid that worked in the spice mines on Kessel. S1D6-SA-5 was freed when the droid L3-37 initiated a slave uprising by removing the restraining bolts of droids in the Pyke Syndicate's control room. During the Cold War, at least two SA-5 protocol droids worked in the cantina on the New Republic's Brooksdion Space Station as servers.

## Specifications

- **Name:** SA-5 protocol droid
- **Class:** Protocol droid
- **Degree:** Class One
- **Plating:** Red
