# J8O soldier droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [J8O soldier droid](https://starwars.fandom.com/wiki/J8O_soldier_droid)

The J-Eight-O soldier droid was a combat droid class that was discontinued prior to the Cold War. Despite this, smuggler Jet Nebula owned a J-Eight-O called Clunker.
