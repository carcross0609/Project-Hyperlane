# X2-R Lookout Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [X2-R Lookout Droid](https://starwars.fandom.com/wiki/X2-R_Lookout_Droid)

X2-R Lookout Droid was a security droid model used by the Hutt Cartel during the Cold War. These droids patrolled Hutt power generator tower in the Upper Industrial Sector on Nar Shaddaa.
