# ODX-series protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [ODX-series protocol droid](https://starwars.fandom.com/wiki/ODX-series_protocol_droid)

The ODX-series protocol droid was a model of protocol droid that was available during the Cold War between the Sith Empire and the Galactic Republic. Imperial Lieutenant Major Pirrell used an ODX-series, ODX-9, as his secretary.
