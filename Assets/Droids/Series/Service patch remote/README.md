# Service patch remote

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Service patch remote](https://starwars.fandom.com/wiki/Service_patch_remote)

A service patch remote was a type of remote that repaired broken circuits and analyzed damage to a starship's systems. Slicers used service patch remotes to compromise a computer's physical security measures. Service patch remotes came with a built-in toolkit and cost 900 credits around the Galactic Civil War.

## Specifications

- **Name:** Service patch remote
- **Class:** Remote
- **Cost:** 900 credits
- **Equipment:** Built-in toolkit
