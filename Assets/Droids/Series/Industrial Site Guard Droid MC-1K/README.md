# Industrial Site Guard Droid MC-1K

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Industrial Site Guard Droid MC-1K](https://starwars.fandom.com/wiki/Industrial_Site_Guard_Droid_MC-1K)

The Industrial Site Guard Droid MC-1K was a model of humanoid security droid used by the reconstituted Sith Empire as guard units on the moon Nar Shaddaa during the Cold War between the Galactic Republic and the Sith Empire. A number of MC-1K units were deployed in the Empire's warehousing facilities in the Lower Industrial Sector.

## Specifications

- **Name:** Industrial Site Guard Droid MC-1K
- **Class:** Security droid
- **Degree:** Class four droid
- **Sensor:** Red
- **Plating:** Black
- **Armament:** Blaster rifle
- **Affiliation:** Sith Empire
