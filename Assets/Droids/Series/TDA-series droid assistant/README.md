# TDA-series droid assistant

**Kind:** Series  
**Continuity:** Canon  
**Source:** [TDA-series droid assistant](https://starwars.fandom.com/wiki/TDA-series_droid_assistant)

The TDA-series droid assistant was a model of protocol droid with a humanoid frame. A number of modified TDA-series droid assistants were utilized command bridge droids to crew the command bridge of the Colossus, a supertanker fuel depot. 4D-M1N, Captain Imanuel Doza's liaison, was a TDA-series droid assistant, and the Colossus more basic and pared down command droids answered to her.

## Specifications

- **Model:** TDA-series
