# Wall Crawler Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Wall Crawler Droid](https://starwars.fandom.com/wiki/Wall_Crawler_Droid)

The Wall Crawler Droid was a model of security droid that traveled along walls. The droid defended its assigned area with a built in blaster and missile launcher. Wall Crawler Droids could be found on the first Death Star.

## Specifications

- **Name:** Wall Crawler Droid
- **Class:** Security droid
- **Plating:** Silver/Gray
- **Armament:**
  - Blaster
  - missile launcher
- **Affiliation:** Galactic Empire
