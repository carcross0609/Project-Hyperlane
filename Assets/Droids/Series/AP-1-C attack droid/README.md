# AP-1-C attack droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [AP-1-C attack droid](https://starwars.fandom.com/wiki/AP-1-C_attack_droid)

The AP-1-C attack droid (Armored Platform, model 1, command) was a battle droid used by the Imperial Remnant. It was created by Arakyd, makers of the Arakyd Viper. The AP-1-C was armed with a repeating blaster, but more commonly was used, as its name suggests, as a commander for its ally AP-2 and AP-3 attack droids.

## Specifications

- **Name:** AP-1-C attack droid
- **Manufacturer:** Arakyd Industries
- **Class:** Battle droid
- **Degree:** Class four droid
- **Affiliation:** Galactic Empire
