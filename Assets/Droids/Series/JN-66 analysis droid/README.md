# JN-66 analysis droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [JN-66 analysis droid](https://starwars.fandom.com/wiki/JN-66_analysis_droid)

The JN-66 analysis droid was a model of analysis droid used by the Jedi Temple's Analysis Rooms. JN-66 analysis droids had the same magnification and scanning abilities as SP-4 ISC units had with their optics and scanning visors.

## Specifications

- **Name:** JN-66 analysis droid
- **Manufacturer:** Cybot Galactica
- **Designer:** Cybot Galactica
- **Class:** Analysis droid
- **Degree:** Class one
- **Sensor:** Blue, green
- **Plating:** Silver and gold
- **Equipment:**
  - Micro field generator
  - Fingers with olfactory and gustatory sensors
  - Repulsorlift
- **Affiliation:** Jedi Order
