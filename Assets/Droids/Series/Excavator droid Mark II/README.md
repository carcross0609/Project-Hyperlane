# Excavator droid Mark II

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Excavator droid Mark II](https://starwars.fandom.com/wiki/Excavator_droid_Mark_II)

The Excavator droid Mark II was a bipedal mining droid model that was used at the Peragus Mining Facility during and prior to 3951 BBY. It was similar to the Mining droid Mark II, but was painted red.

## Specifications

- **Name:** Excavator droid Mark II
- **Class:** Mining droid
- **Degree:** Class five
- **Plating:** Pinkish-Red
- **Affiliation:** Peragus Mining Facility
