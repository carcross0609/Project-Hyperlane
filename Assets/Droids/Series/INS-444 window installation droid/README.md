# INS-444 window installation droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [INS-444 window installation droid](https://starwars.fandom.com/wiki/INS-444_window_installation_droid)

The INS-444 window installation droid, sometimes referred to as an installer droid, was a fifth-degree installer droid produced by Publictechnic during the time of the Galactic Republic. INS-444 units commonly worked alongside CLE-004 window cleaning droids.

## Specifications

- **Name:** INS-444 window installation droid
- **Manufacturer:** Publictechnic
- **Class:** Window installation droid
- **Degree:** Class five droid
- **Height:** 0.7 meters
- **Sensor:** Red
- **Armament:** None
- **Equipment:**
  - Magnatomic grip pad (2)
  - Manipulator arm (3)
  - Testing probe (2)
  - Repulsorlift
