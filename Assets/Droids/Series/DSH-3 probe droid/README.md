# DSH-3 probe droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [DSH-3 probe droid](https://starwars.fandom.com/wiki/DSH-3_probe_droid)

The DSH-3 probe droid was a spherical probe droid related to the DRK-1 Dark Eye probe droid.

## Specifications

- **Name:** DSH-3 probe droid
- **Manufacturer:** Arakyd Industries
- **Class:** 4th-degree probe droid
- **Cost:** 13,000 credits (licensed)
- **Equipment:**
  - Heuristic processor
  - Improved sensor package
  - Audio/video recording packages
  - Internal comlink
  - Locked access
  - Secondary backup battery
