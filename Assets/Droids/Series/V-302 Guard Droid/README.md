# V-302 Guard Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [V-302 Guard Droid](https://starwars.fandom.com/wiki/V-302_Guard_Droid)

The V-302 Guard Droid was a model of security droid used as security units on the Red Light Sector Concourse on the moon Nar Shaddaa during the Cold War between the Galactic Republic and the reconstituted Sith Empire.

## Specifications

- **Name:** V-302 Guard Droid
- **Class:** Security droid
- **Degree:** Class four droid
- **Sensor:** Blue
- **Plating:** Dark gray
