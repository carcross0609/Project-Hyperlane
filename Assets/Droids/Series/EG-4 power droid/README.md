# EG-4 power droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [EG-4 power droid](https://starwars.fandom.com/wiki/EG-4_power_droid)

The Veril Line Systems EG-4 power droid was the galaxy's first modern power droid model. Along with the EG-6 power droid, the EG-4 model dominated the energy-supply market.
