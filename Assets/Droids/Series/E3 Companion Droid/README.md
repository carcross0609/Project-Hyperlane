# E3 Companion Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [E3 Companion Droid](https://starwars.fandom.com/wiki/E3_Companion_Droid)

The E3 Companion Droid was a model of droid manufactured by Cybot Galactica. Spanner, Luskin Exovar's droid, was an E3 Companion Droid.

## Specifications

- **Name:** E3 Companion Droid
- **Manufacturer:** Cybot Galactica
- **Height:** 1 meter
- **Armament:** Retractable blaster
- **Equipment:**
  - Four legs
  - Heavy grasping jaw
  - Video, hearing, and olfactory sensor arrays
  - Movement sensor
  - Infrared detector
  - Vocabulator
