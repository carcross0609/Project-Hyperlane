# B2 grapple droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [B2 grapple droid/Legends](https://starwars.fandom.com/wiki/B2_grapple_droid/Legends)

The B2 grapple droid, based on the B2 super battle droid model, was a droid model specifically designed for the Separatists' attack on Coruscant.

## Specifications

- **Name:** B2 grapple droid
- **Manufacturer:** Baktoid Combat Automata
- **Class:** Battle droid
- **Height:** 1.93 meters
- **Sensor:** Red
- **Armament:** Electrified pincers (built-in), fireball throwers (Red)
- **Affiliation:** Confederacy of Independent Systems
