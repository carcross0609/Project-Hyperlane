# AP-2 attack droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [AP-2 attack droid](https://starwars.fandom.com/wiki/AP-2_attack_droid)

The AP-2 attack droid (Assault Platform-2) was a battle droid used by the Imperial Remnant. The droid was armed with a pair of repeating blasters situated on a head turret, two blaster rifles, and a grenade launcher installed in each arm.

## Specifications

- **Name:** AP-2 attack droid
- **Class:** Battle droid
- **Degree:** Class four droid
- **Affiliation:** Galactic Empire
