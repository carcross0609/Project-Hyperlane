# Je'daii droid sentry

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Je'daii droid sentry](https://starwars.fandom.com/wiki/Je%27daii_droid_sentry)

An unidentified sentry droid model was used to monitor the status of Je'daii prisoners on Bogan to see that if they find balance and to inform the Je'daii if the prisoners would try to escape. The droid was spider-like, having six legs to walk around and it was not armed.

## Specifications

- **Name:** Je'daii droid sentry
- **Homeworld:** Bogan
- **Equipment:** Tracking device
- **Affiliation:** Je'daii Order
