# 4XB programming droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [4XB programming droid](https://starwars.fandom.com/wiki/4XB_programming_droid)

The 4XB programming droid was a type of programmer droid. One 4XB programming droid, DA1-4XB, worked for the Pyke Syndicate at the spice mines of Kessel. DA1-4XB was freed during a uprising initiated by the droid L3-37.

## Specifications

- **Name:** 4XB programming droid
- **Class:** Programmer droid
- **Degree:** Class 2
- **Plating:** White
