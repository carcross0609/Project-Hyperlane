# GK-5 sentry droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [GK-5 sentry droid](https://starwars.fandom.com/wiki/GK-5_sentry_droid)

The GK-5 sentry droid was a squat, multi-legged droid in operation during the Galactic Civil War. It was similar in appearance to the DSD1 dwarf spider droids and LM-432 crab droids that were part of the Separatist Droid Army during the Clone Wars.

## Specifications

- **Name:** GK-5 sentry droid
- **Line:** Union Sentry Droid
- **Class:** Sentry droid
- **Armament:** Blaster cannon (2)
- **Affiliation:** HK-47
