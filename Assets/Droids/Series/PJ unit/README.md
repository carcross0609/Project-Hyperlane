# PJ unit

**Kind:** Series  
**Continuity:** Canon  
**Source:** [PJ unit](https://starwars.fandom.com/wiki/PJ_unit)

PJ units were a type of droid mainly used in mines, like the spice mines on Kessel. By the time of the Galactic Empire, the PJ unit was already an old model. Esstee-Ninety-Three was a PJ unit.

- **Name:** PJ unit
- **Sensor:** Red
