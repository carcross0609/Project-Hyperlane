# 4XB Programmer Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [4XB Programmer Droid](https://starwars.fandom.com/wiki/4XB_Programmer_Droid)

The 4XB Programmer Droid model was designed by Cybot Galactica to oversee and program other droids. 4XB units used complicated electronic sound patterns to program other droids, which must be fitted with a CG1XB Translator Module. It was not uncommon that a 4XB unit would handle the day-to-day operation of automated mines, factories, prisons, and law enforcing agencies. It was a 4XB unit that administrated the prison colony of Balis-Baurgh.
