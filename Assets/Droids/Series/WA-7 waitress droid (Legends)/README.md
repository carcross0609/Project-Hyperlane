# WA-7 waitress droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [WA-7 waitress droid/Legends](https://starwars.fandom.com/wiki/WA-7_waitress_droid/Legends)

The WA-7 waitress droid, also called the WA-7 service unit, was a third-degree service droid produced by GoCorp and Utilitech during the Mondeo Modernist era.

## Specifications

- **Name:** WA-7 waitress droid
- **Manufacturer:** GoCorp/Utilitech
- **Line:** WA-series
- **Class:** Service droid
- **Degree:** Class three droid
- **Height:** 1.7 meters
- **Gender:** Feminine programming
- **Sensor:** Yellow
- **Armament:** None
- **Equipment:**
  - Gyro-balanced unipod
  - Head fins
  - Repulsor stabilizer
  - Drive wheel
  - Order transmitter
  - Facial-recognition software
