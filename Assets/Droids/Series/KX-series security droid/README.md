# KX-series security droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [KX-series security droid](https://starwars.fandom.com/wiki/KX-series_security_droid)

KX-series security droids, also known as KX-series enforcer droids, KX enforcer droids, KX units, KX droids, or executor droids, were a model of security droid manufactured by Arakyd Industries that was in service to the Galactic Empire during the Galactic Civil War.
