# XC2 administration droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [XC2 administration droid](https://starwars.fandom.com/wiki/XC2_administration_droid)

The XC2 administration droid was an model of administrative droid made by Cybot Galactica. Kina Margath used two of these units to help her manage Margath's on Elshandruu Pica
