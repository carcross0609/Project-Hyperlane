# X10-D draft droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [X10-D draft droid](https://starwars.fandom.com/wiki/X10-D_draft_droid)

The X10-D draft droid was a droid developed by the Trandoshan species for labor. They were able to pick up things that Trandoshans—due to their claws—could not. Only those deemed worthy by the Scorekeeper—those who had achieved a significant number of Wookiee kills—could own a draft droid.

## Specifications

- **Name:** X10-D draft droid
- **Creator:** Trandoshans
- **Manufacturer:** Hsskor Dominion
- **Homeworld:** Trandosha
- **Class:** Draft droid
- **Degree:** Class five droid
- **Height:** 3 meters
