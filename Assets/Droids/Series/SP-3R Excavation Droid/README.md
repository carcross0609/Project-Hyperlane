# SP-3R Excavation Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [SP-3R Excavation Droid](https://starwars.fandom.com/wiki/SP-3R_Excavation_Droid)

The SP-3R Excavation Droid was a model of humanoid-shaped Mining droid produced during the Cold War. Some of these droids were used by Voontara Fa'athra in his operations in the Rust Yards.

## Specifications

- **Name:** SP-3R Excavation Droid
- **Class:** Mining droid
- **Sensor:** Blue
- **Plating:** Orange
