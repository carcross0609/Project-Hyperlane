# TT-8L/Y7 gatekeeper droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [TT-8L/Y7 gatekeeper droid/Legends](https://starwars.fandom.com/wiki/TT-8L/Y7_gatekeeper_droid/Legends)

The TT-8L/Y7 was an variant model of the standard TT-8L gatekeeper droid designed for installation in a door or a door frame. It was nicknamed the "Tattletale" droid.

## Specifications

- **Name:** TT-8L/Y7 gatekeeper droid
- **Manufacturer:** Serv-O-Droid, Inc.
- **Line:** TT-8L gatekeeper droid
- **Plating:** Black durasteel
