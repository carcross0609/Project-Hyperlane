# SB-20 Slicer Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [SB-20 Slicer Droid](https://starwars.fandom.com/wiki/SB-20_Slicer_Droid)

The SB-20 Slicer Droid, also known as a SB-20 security breach droid, was a type of droid produced by the underground company Illicit Electronics.

## Specifications

- **Name:** SB-20 Slicer Droid
- **Manufacturer:** Illicit Electronics
- **Line:** Built from R-series astromech droids
- **Class:** Espionage/slicer droid
- **Cost:** 12,000 credits
- **Height:** 1 meter
- **Equipment:**
  - Retractable heavy grasper arm
  - Retractable fine work grasper arm
  - Extendable video sensor (360º rotation)
  - Electric arc welder
  - Circular saw
  - Video display screen
  - Holographic projector/recorder
  - Fire extinguisher
  - Small internal cargo area (20cm by 8cm)
  - CodeRifter Encryption Equipment
  - SecurityViolator security programming
