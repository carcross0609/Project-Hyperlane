# SP-4 analysis droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [SP-4 analysis droid/Legends](https://starwars.fandom.com/wiki/SP-4_analysis_droid/Legends)

The SP-4 analysis droid, also known as the ISC droid, was an analysis droid model that was used to provide analysis assistance to organic beings as early as the Ruusan Reformations of the Galactic Republic. The Jedi Order made a large purchase of SP-4 units for use in the Jedi Temple's analysis wing.

## Specifications

- **Name:** SP-4 analysis droid
- **Manufacturer:** Cybot Galactica
- **Homeworld:** Coruscant
- **Class:** Analysis droid
- **Height:** 1.46 meters
- **Equipment:** Repulsorlifts (CIS version only)
- **Affiliation:**
  - Confederacy of Independent Systems
  - Galactic Republic
  -   Coruscant Security Force
  - Jedi Order
