# Unidentified labor droid model

**Kind:** Series  
**Continuity:** Uncategorized  
**Source:** [Unidentified labor droid model](https://starwars.fandom.com/wiki/Unidentified_labor_droid_model)

A labor droid model was utilized by the Galactic Empire on the planet Corellia by 13 BBY. BL-OX was a member of this droid model and was led by Jek-14 at some point between 3 ABY and 4 ABY.
