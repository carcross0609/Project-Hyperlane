# Small Size Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Small Size Droid](https://starwars.fandom.com/wiki/Small_Size_Droid)

This Small Size Droid was a small wheeled droid that at rest looked similar to the MSE-series "Mouse" droids, but could raise up and fire a jolt of energy at an enemy. These droids could be found on the first Death Star.

## Specifications

- **Name:** Small Size Droid
- **Affiliation:** Galactic Empire
