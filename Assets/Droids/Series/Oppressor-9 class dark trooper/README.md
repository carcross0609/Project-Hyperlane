# Oppressor-9 class dark trooper

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Oppressor-9 class dark trooper](https://starwars.fandom.com/wiki/Oppressor-9_class_dark_trooper)

The Oppressor-9 class dark trooper was a dark trooper variant used by the Galactic Empire. It was similar to the Oppressor-7 class dark trooper in that its duties were virtually the same, although it could both inflict and absorb more damage.

## Specifications

- **Name:** Oppressor-9 class dark trooper
- **Line:** Dark trooper
- **Class:** Battle droid
- **Sensor:** Black
- **Plating:** White
- **Armament:** Virtually any rifle wielded by humanoids
- **Affiliation:**
  - Galactic Empire
  -   Imperial Military
