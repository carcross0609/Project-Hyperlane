# Kaon Sentinel Mk. III

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Kaon Sentinel Mk. III](https://starwars.fandom.com/wiki/Kaon_Sentinel_Mk._III)

Kaon Sentinel Mk. III was a battle droid model used by the Kaon City security forces on Kaon during the Galactic War. During the Tion Hegemony rakghoul outbreak on Kaon in 3639 BBY, many Mk. III Sentinels were deployed to contain the Rakghouls.

## Specifications

- **Name:** Kaon Sentinel Mk. III
- **Line:** Battle droid
- **Degree:** Class four droid
- **Sensor:** Red
- **Plating:** Yellow
- **Armament:** Blaster rifle
- **Affiliation:** Kaon Security
