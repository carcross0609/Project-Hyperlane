# Security Droid BX

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Security Droid BX](https://starwars.fandom.com/wiki/Security_Droid_BX)

The Sentry Droid X-5 was a model of security droid produced by the Okara Droid Company at the Okara Droid Factory on the planet Balmorra. A number of them were used to defend the exterior of the factory during the Cold War between the Galactic Republic and the reconstituted Sith Empire.

## Specifications

- **Name:** Security Droid BX
- **Manufacturer:** Okara Droid Company
- **Homeworld:** Balmorra
- **Class:** Security droid
- **Plating:** Dull green-brown
