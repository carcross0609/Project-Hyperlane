# Stevedore droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Stevedore droid](https://starwars.fandom.com/wiki/Stevedore_droid)

Stevedore droids were labor droids used by the Galactic Empire to load and manage cargo aboard All Terrain Armored Cargo Transport walkers by dividing partial holds of ultradense materials into manageable trips.

## Specifications

- **Name:** Stevedore droid
- **Class:** Labor droid
- **Affiliation:** Galactic Empire
