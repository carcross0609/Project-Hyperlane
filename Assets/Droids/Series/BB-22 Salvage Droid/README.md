# BB-22 Salvage Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [BB-22 Salvage Droid](https://starwars.fandom.com/wiki/BB-22_Salvage_Droid)

The BB-22 Salvage Droid was a model of humanoid-shaped salvage droid that saw use during the Cold War. A number of BB-22 droids worked with S7-H7 Slicing Droids and JT-65 Salvage Droids in the Barasin Refuse Yards on the planet Balmorra.

## Specifications

- **Name:** BB-22 Salvage Droid
- **Class:** Salvage droid
- **Sensor:** Red
- **Plating:** Green
