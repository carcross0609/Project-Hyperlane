# Assassination Unit Mark IV

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Assassination Unit Mark IV](https://starwars.fandom.com/wiki/Assassination_Unit_Mark_IV)

The Assassination Unit Mark IV was an assassin droid model manufactured by the Czerka Corporation. Such droids were deployed by Gayem Leksende to Grommik's Residence in the Northern Jundland Wastes on Tatooine.
