# Refuse incinerator droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Refuse incinerator droid](https://starwars.fandom.com/wiki/Refuse_incinerator_droid)

Refuse incinerator droids, also known simply as Fire-breathers, were a type of droid used to incinerate garbage on the planet Lotho Minor.

## Specifications

- **Name:** Refuse incinerator droid
- **Homeworld:** Lotho Minor
- **Class:** Scavenger droid
- **Degree:** Class five
- **Height:** 34.35 meters
- **Sensor:** Orange
- **Plating:** Gray and brown
- **Equipment:** Powerful jaws and furnace breath
