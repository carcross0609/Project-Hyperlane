# M-3PO military protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [M-3PO military protocol droid](https://starwars.fandom.com/wiki/M-3PO_military_protocol_droid)

The M-3PO military protocol droid, also known as the standard military protocol unit, was a variant of Cybot Galactica's successful 3PO-series protocol droid, designed for military applications. These droids were common sights in planetary garrisons and starfighter bases.

## Specifications

- **Name:** M-3PO military protocol droid
- **Manufacturer:** Cybot Galactica
- **Class:** Military protocol droid
- **Degree:** Class three
- **Cost:** 3,700—12,000 credits
- **Sensor:** Red
- **Plating:** Black
- **Equipment:** AA-1 VerboBrain
