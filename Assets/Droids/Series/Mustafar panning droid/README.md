# Mustafar panning droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mustafar panning droid](https://starwars.fandom.com/wiki/Mustafar_panning_droid)

The Mustafar panning droid, also known as the droid lava collector, was a fifth-degree droid modified by the Techno Union from the Kalibac Industries information cataloging droid. These so-called panning droids operated on Mustafar, mining minerals from the planet's lava rivers.

## Specifications

- **Name:** Mustafar panning droid
- **Manufacturer:** Kalibac Industries/Techno Union
- **Class:** Mining droid
- **Degree:** Class five
- **Height:** 1.5 meters
- **Sensor:** Blue
- **Armament:** None
- **Equipment:**
  - Deflector shield generator
  - High torque manipulator arm (2)
  - Lava collection bucket
  - Repulsorlift
  - Stereoscopic binocular sensor (2)
- **Affiliation:**
  - Techno Union
  - Tagge Company
  - Klegger Corporation
