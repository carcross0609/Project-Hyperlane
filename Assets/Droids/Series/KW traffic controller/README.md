# KW traffic controller

**Kind:** Series  
**Continuity:** Legends  
**Source:** [KW traffic controller](https://starwars.fandom.com/wiki/KW_traffic_controller)

The KW traffic controller was a model of Class 3 spaceport control droid manufactured by Cybot Galactica. After the series was discontinued, their clamshell-shaped heads were appropriated for the M-3PO military protocol droid.

## Specifications

- **Name:** KW traffic controller
- **Manufacturer:** Cybot Galactica
- **Class:** Spaceport control droid
- **Degree:** Class 3
