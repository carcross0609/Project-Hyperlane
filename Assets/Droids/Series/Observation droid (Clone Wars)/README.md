# Observation droid (Clone Wars)

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Observation droid (Clone Wars)](https://starwars.fandom.com/wiki/Observation_droid_%28Clone_Wars%29)

The observation droid was a model of probe droid manufactured by Arakyd Industries. It was utilized by a multitude of factions during the Clone Wars, including the Galactic Republic, the Pyke Syndicate, and the Zygerrian Slave Empire. A sentry droid model used by the Galactic Empire was visually similar to the observation droid.

## Specifications

- **Name:** Observation droid
- **Manufacturer:** Arakyd Industries
- **Class:** Probe droid
- **Sensor:** Red
- **Plating:** Black
- **Affiliation:**
  - Galactic Republic
  -   Kamino security
  - Pyke Syndicate
  - Zygerrian Slave Empire
