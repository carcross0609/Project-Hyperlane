# Proto-Roller

**Kind:** Series  
**Continuity:** Uncategorized  
**Source:** [Proto-Roller](https://starwars.fandom.com/wiki/Proto-Roller)

The Proto-Roller was a model of worker droid that consisted of a BDX droid head and torso with the treads of an A-LT Utility Droid, making it a type of monster droid. It had red and white plating with two white photoreceptors. The Sandcrawler Shop, which was run by Jawas and located beside the Junkers Cantina on the planet Tatooine, sold blueprints for Proto-Rollers. A blueprint for the Proto-Roller's default design cost 22,000,000 credits, a golden design cost 88,000,000 credits, a diamond-colored version cost 176,000,000 credits, and a rainbow-colored design cost 352,000,000 credits.
