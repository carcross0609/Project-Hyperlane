# Spelunker probe droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Spelunker probe droid](https://starwars.fandom.com/wiki/Spelunker_probe_droid)

Spelunker probe droids were a type of probe droid. During the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems, the Punitive Security Forces of the Separatist Commerce Guild deployed converted Spelunker probe droids known as chameleon droids to provide reconnaissance and carry out sabotage.

- **Name:** Spelunker probe droid
- **Manufacturer:** Arakyd Industries

- **Equipment:** Heavy mining gear
- **Affiliation:**

  - Commerce Guild
