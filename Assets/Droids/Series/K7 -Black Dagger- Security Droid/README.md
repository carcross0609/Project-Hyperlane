# K7 "Black Dagger" Security Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [K7 "Black Dagger" Security Droid](https://starwars.fandom.com/wiki/K7_%22Black_Dagger%22_Security_Droid)

The K7 "Black Dagger" Security Droid was a model of security droid produced by Rim Securities. The Galactic Empire employed K7s as security at the Imperial military facility at Graith starport.

## Specifications

- **Name:** K7 "Black Dagger" Security Droid
- **Manufacturer:** Rim Securities
- **Class:** Security droid
- **Height:** 1.7 meters
- **Plating:** Armor plating
- **Armament:** Internal blaster rifle
