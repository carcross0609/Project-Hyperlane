# R2-D5

**Kind:** Series  
**Continuity:** Legends  
**Source:** [R2-D5](https://starwars.fandom.com/wiki/R2-D5)

R2-D5 was a multiple use R2 unit used by the Rebel Alliance. It generally worked as an astromech droid, but could also be used as a labor droid. Its versatility made it an essential part of almost all technical aspects, from gathering resources like extracting and processing carbon, to repairing and building structures.

## Specifications

- **Name:** R2-D5
- **Manufacturer:** Industrial Automaton
- **Line:** R-series
- **Class:** Astromech droid
- **Affiliation:** Alliance to Restore the Republic
