# B-T3 Guard Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [B-T3 Guard Droid](https://starwars.fandom.com/wiki/B-T3_Guard_Droid)

B-T3 Guard Droid was a battle droid model used by the Hutt Cartel during the Cold War between the Galactic Republic and the reconstituted Sith Empire. These droids patrolled the Hutt power generator tower in the Upper Industrial Sector on the moon Nar Shaddaa.

## Specifications

- **Name:** B-T3 Guard Droid
- **Model:** Security droid
- **Plating:** Rust
- **Affiliation:** Hutt Cartel
