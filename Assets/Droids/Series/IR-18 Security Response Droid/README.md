# IR-18 Security Response Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IR-18 Security Response Droid](https://starwars.fandom.com/wiki/IR-18_Security_Response_Droid)

The IR-18 Security Response Droid was a model of bipedal battle droid used by the the Shroud, a freelance spy active during the Galactic War. The Shroud's lieutenant Stangg employed IR-18 droids among the forces that defended the Shroud's base on the planet Quesh.

## Specifications

- **Name:** IR-18 Security Response Droid
- **Class:** Battle droid
- **Sensor:** Blue
- **Plating:** Dark
- **Affiliation:** The Shroud's organization
