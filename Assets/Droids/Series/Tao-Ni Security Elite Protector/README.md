# Tao-Ni Security Elite Protector

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Tao-Ni Security Elite Protector](https://starwars.fandom.com/wiki/Tao-Ni_Security_Elite_Protector)

The Tao-Ni Security Elite Protector was a type of security droid that was used in IG-88's Droid Army. When IG-88 took control of Nym's Factory Compound in 1 ABY, some Tao-Ni Security Elite Protectors were stationed outside it. Some spacers attacked and defeated them, before entering the compound and starting the Battle of Nym's Factory Compound.

## Specifications

- **Name:** Tao-Ni Security Elite Protector
- **Manufacturer:** Tao-Ni Security
- **Class:** Security droid
- **Sensor:** Red
- **Plating:** Grey, red
- **Affiliation:** IG-88's Droid Army
