# P2F hostile environment remote

**Kind:** Series  
**Continuity:** Canon  
**Source:** [P2F hostile environment remote](https://starwars.fandom.com/wiki/P2F_hostile_environment_remote)

The P2F hostile environment remote was a type of remote droid produced by Haor Chall Engineering Corporation. It was designed for use by diplomats who required direct contact in hostile environments. The P2F could be controlled remotely, it possessed a level of initiative and awareness so that the remotes could deliver themselves to their contact.

## Specifications

- **Name:** P2F hostile environment remote
- **Manufacturer:** Haor Chall Engineering Corporation
- **Class:** Remote
