# P4T protocol droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [P4T protocol droid](https://starwars.fandom.com/wiki/P4T_protocol_droid)

The P4T protocol was a model of protocol droid. The P4T protocol droid P4T-GM worked in the spice mines of Kessel, but was freed during a droid uprising led by L3-37.

## Specifications

- **Name:** P4T protocol droid
- **Class:** Protocol droid
- **Degree:** Class 3
- **Plating:** Red and white
