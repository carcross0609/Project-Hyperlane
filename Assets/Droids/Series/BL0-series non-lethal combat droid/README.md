# BL0-series non-lethal combat droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [BL0-series non-lethal combat droid](https://starwars.fandom.com/wiki/BL0-series_non-lethal_combat_droid)

The BL0-series non-lethal combat droid was a model of combat droid created by Arakyd Industries for non-lethal enforcement. The BL0-series was designed to neutralize its targets rather than killing them, using an array of non-lethal countermeasures including stun whips. The droid scuttled on three legs and had robust hyperarticulated arms. Their effectiveness in combat led many of them to be repurposed as security droids.

## Specifications

- **Name:** BL0-series non-lethal combat droid
- **Manufacturer:** Arakyd Industries
- **Class:** Combat droid
- **Armament:**
  - Non-lethal countermeasures
  - Stun whips
