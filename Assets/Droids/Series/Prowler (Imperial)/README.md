# Prowler (Imperial)

**Kind:** Series  
**Continuity:** Uncategorized  
**Source:** [Prowler (Imperial)](https://starwars.fandom.com/wiki/Prowler_%28Imperial%29)

A prowler was a flying reconnaissance droid used by the Galactic Empire to patrol the walkways in their first Death Star. Resembling a rectangular prism with two protruding panels, one on each side, this droid was equipped with a camera. The protruding panels were used for flight through flapping them quickly, similar to an ornithopter.

## Specifications

- **Name:** Prowler
- **Class:** Security droid
- **Affiliation:** Galactic Empire
