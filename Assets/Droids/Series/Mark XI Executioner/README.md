# Mark XI Executioner

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mark XI Executioner](https://starwars.fandom.com/wiki/Mark_XI_Executioner)

The Mark XI Executioner was a gladiator droid created by Arakyd Industries. It was Arakyd's follow-up design to the popular Mark X Executioner droid, and was available as early as 0 BBY.

## Specifications

- **Name:** Mark XI Executioner
- **Manufacturer:** Arakyd Industries
- **Class:** Gladiator droid
