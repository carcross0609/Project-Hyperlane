# R2-M3

**Kind:** Series  
**Continuity:** Legends  
**Source:** [R2-M3](https://starwars.fandom.com/wiki/R2-M3)

R2-M3 was a droid used as a ship's "captain" for the Tech 4 PDV used by Imperial Intelligence. It was based on the R2-series astromech droid.
