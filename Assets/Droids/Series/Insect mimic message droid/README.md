# Insect mimic message droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Insect mimic message droid](https://starwars.fandom.com/wiki/Insect_mimic_message_droid)

Insect mimic message droids were small droids which, if not observed too closely, seemed to be small winged insects. They used a dorsal holoprojector to relay messages.

## Specifications

- **Name:** Insect mimic message droid
- **Class:** Courier droid
- **Equipment:** Holoprojector
