# RO-D-series droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [RO-D-series droid](https://starwars.fandom.com/wiki/RO-D-series_droid)

The RO-D-series droid was designed and manufactured by Balmorran Arms to serve as both a labor droid and security droid for touring musicians throughout the galaxy.

## Specifications

- **Name:** RO-D-series droid
- **Manufacturer:** Balmorran Arms
- **Class:** Labor droid/Security droid
- **Degree:** Class five droid
- **Cost:** 14,800 credits
- **Armament:** concealed Stun baton
