# Supreme-Class Servant Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Supreme-Class Servant Droid](https://starwars.fandom.com/wiki/Supreme-Class_Servant_Droid)

The Supreme-Class Servant Droid was an elegant droid manufactured by Lovolan to cater to high society in places like Coruscant and Cloud City. The Supreme-Class is able to speak multiple languages and dialects, has an extensive knowledge of upper-class interests and activities, and a communication system that keeps it in contact with news and financial databases. One Servant-Class droid, Threna, ended up misplaced on the planet Grathus, and ended up serving drinks at Xig Rollem's tavern.

## Specifications

- **Name:** Supreme-Class Servant Droid
- **Manufacturer:** Lovolan
- **Class:** Servant droid
