# MP droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [MP droid](https://starwars.fandom.com/wiki/MP_droid)

The MP-series protocol droid was a model of droid employed by Fleet Admiral Oteg as messengers. MP droids, such as MP-77, were equipped with holochannel scramblers and facial scanners for authentication.
