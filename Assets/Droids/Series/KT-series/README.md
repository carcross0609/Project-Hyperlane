# KT-series

**Kind:** Series  
**Continuity:** Legends  
**Source:** [KT-series](https://starwars.fandom.com/wiki/KT-series)

The KT-series was a model of second-degree astromech droid that served the Galactic Republic during the Clone Wars. KT-10 was an offshoot of this series.

## Specifications

- **Name:** KT-series
- **Class:** Astromech droid
- **Degree:** Class two droid
