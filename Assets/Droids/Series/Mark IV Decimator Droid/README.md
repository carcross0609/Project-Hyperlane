# Mark IV Decimator Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mark IV Decimator Droid](https://starwars.fandom.com/wiki/Mark_IV_Decimator_Droid)

The Mark IV Decimator Droid was a battle droid model used by the Sith Empire. Droids of this model were deployed on the Harrower-class dreadnought Javelin.
