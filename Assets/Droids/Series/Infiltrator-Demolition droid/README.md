# Infiltrator/Demolition droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Infiltrator/Demolition droid](https://starwars.fandom.com/wiki/Infiltrator/Demolition_droid)

The Infiltrator/Demolition droid (I/D droid) was a model of transforming droid that the Confederacy of Independent Systems used during the Clone Wars.

## Specifications

- **Name:** Infiltrator/Demolition droid
- **Manufacturer:** LIN demolitionmech
- **Class:** Battle droid
- **Height:** 2.43 meters
- **Mass:** 158 kilograms
- **Gender:** Masculine programing
- **Sensor:**
  - Red
  - Blue (when holoprojector is activated)
- **Armament:**
  - Laser cannons (2)
  - Explosive charges
- **Equipment:** Holoprojector
- **Affiliation:** Confederacy of Independent Systems
