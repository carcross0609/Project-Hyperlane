# Lantern droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Lantern droid](https://starwars.fandom.com/wiki/Lantern_droid)

Several droids of an unknown model were used as lanterns to illuminate Rish Loo's secret laboratory on Naboo. The droids levitated above the ground using repulsorlifts, and also had the capacity to walk using short appendages on their underside.

## Specifications

- **Name:** Lantern droid
- **Armament:** Built-in lantern
- **Affiliation:**
  - Confederacy of Independent Systems
  - Preigo's Traveling World of Wonder
