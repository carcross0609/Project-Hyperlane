# Treadwell Harvester Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Treadwell Harvester Droid](https://starwars.fandom.com/wiki/Treadwell_Harvester_Droid)

The Treadwell Harvester Droid was a model of agricultural droid. The harvester droid was equipped with cutter blades, and had a protective blast-plate that covered the unit's crawler treads. Treadwell Harvester Droids were used on the planet Chrona.

## Specifications

- **Name:** Treadwell Harvester Droid
- **Model:** Harvester droid
- **Equipment:**
  - Cutter blades
  - Protective blast-plate
