# Policebot

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Policebot](https://starwars.fandom.com/wiki/Policebot)

The Policebot was a police droid utilized by the Coruscant Security Force during the Galactic Alliance as a basic patrol unit. The policebots had dark visors and were able to perform retinal scans and had all laws relevant to police operations uploaded and updated continually.

## Specifications

- **Name:** Policebot
- **Class:** Police droid
- **Affiliation:** Coruscant Security Force
