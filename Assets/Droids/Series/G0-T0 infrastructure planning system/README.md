# G0-T0 infrastructure planning system

**Kind:** Series  
**Continuity:** Legends  
**Source:** [G0-T0 infrastructure planning system](https://starwars.fandom.com/wiki/G0-T0_infrastructure_planning_system)

The G0-T0 infrastructure planning system was a second-degree planning droid produced by the Aratech Repulsor Company and designed and programmed to serve as a central organizational hub for planetary rebuilding efforts.

- **Name:** G0-T0 infrastructure planning system
- **Manufacturer:** Aratech Repulsor Company
- **Class:** Planning droid
- **Cost:** 60,000 credits
- **Width:** 0.3 meters
- **Sensor:** Red
- **Armament:** None
- **Equipment:**

  - Deflector shield generator node
  - Holographic representation imaging
  - Repulsorlift
- **Affiliation:** Galactic Republic
