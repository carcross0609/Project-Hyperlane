# S94-T Dealer Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [S94-T Dealer Droid](https://starwars.fandom.com/wiki/S94-T_Dealer_Droid)

The S94-T Dealer Droid was a model of dealer droid that oversaw sabacc card games. A S94-T droid was used in the Dealer's Den cantina on the planet Coruscant, in the back room occupied by Darmas Pollaran.
