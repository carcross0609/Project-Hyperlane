# GB-IB

**Kind:** Series  
**Continuity:** Uncategorized  
**Source:** [GB-IB](https://starwars.fandom.com/wiki/GB-IB)

The GB-IB was a hovering droid used by the Galactic Empire on Kessel and Yavin 4 in 0 BBY. They were shaped roughly like a half-sphere with manipulator arms underneath.
