# RA-9O protocol droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [RA-9O protocol droid](https://starwars.fandom.com/wiki/RA-9O_protocol_droid)

RA-9O protocol droid was a model of protocol droid manufactured by Arakyd Industries. It was meant to be an alternative to Arakyd's RA-7 protocol droid meant for more remote worlds with worse infrastructure and it had an improved pelvic servomotor for better balance. It's neural harness could also accommodate warranty voiding combat upgrades. The droid bounty hunter Q9-0 was a modified RA-9O.

## Specifications

- **Name:** RA-9O protocol droid
- **Manufacturer:** Arakyd Industries
- **Class:** Protocol droid
- **Height:** 1.8 meters (5 ft 11 in)
- **Affiliation:**
