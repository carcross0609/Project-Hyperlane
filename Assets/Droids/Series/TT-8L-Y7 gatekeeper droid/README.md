# TT-8L/Y7 gatekeeper droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [TT-8L/Y7 gatekeeper droid](https://starwars.fandom.com/wiki/TT-8L/Y7_gatekeeper_droid)

The TT-8L/Y7 gatekeeper droid, also known simply as the Y7 droid and nicknamed the "tattletale droid," was a model of security droid manufactured by Serv-O-Droid, Inc.

- **Equipment:** Speaker
- **Affiliation:**
