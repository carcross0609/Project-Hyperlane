# SWL-5 overseer

**Kind:** Series  
**Continuity:** Legends  
**Source:** [SWL-5 overseer](https://starwars.fandom.com/wiki/SWL-5_overseer)

The SWL-5 overseer was a model of security droid manufactured by the Stonewall Labs company during the Imperial Era. This droid had a humanoid shape and was as tall as a medium-sized Human. The SWL-5 overseer was able to fight using ranged weapons.

## Specifications

- **Name:** SWL-5 overseer
- **Manufacturer:** Stonewall Labs
- **Class:** Security droid
- **Sensor:** Black
- **Plating:** Blue, gray
- **Affiliation:** Stonewall Labs
