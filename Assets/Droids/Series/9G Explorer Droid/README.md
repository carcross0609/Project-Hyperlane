# 9G Explorer Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [9G Explorer Droid](https://starwars.fandom.com/wiki/9G_Explorer_Droid)

The 9G Explorer Droid was a model of explorer droid manufactured by DeepSpace. The model was 1.3-meter-tall automaton was designed to quickly investigate new-found planets and determine their habitability.

## Specifications

- **Name:** 9G Explorer Droid
- **Manufacturer:** DeepSpace
- **Height:** 1.3 meters
- **Equipment:**
  - Atmosphere sensor
  - Heavy grasper arm
  - Holorecorder
  - Movement sensor
  - Repulsorlift unit
