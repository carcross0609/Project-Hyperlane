# MK line droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [MK line droid](https://starwars.fandom.com/wiki/MK_line_droid)

The MK line droid was a model of protocol droid used by the reconstituted Sith Empire that was similar to the 2V-series factotum droid. MK-RU was a MK line droid.

## Specifications

- **Name:** MK line droid
- **Class:** Protocol droid
- **Sensor:** Red
- **Plating:** Silver
- **Affiliation:** Sith Empire
