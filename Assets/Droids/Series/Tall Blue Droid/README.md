# Tall Blue Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Tall Blue Droid](https://starwars.fandom.com/wiki/Tall_Blue_Droid)

This Tall Blue Droid is a model of wheeled security droid armed with a blaster. It had a snout-like head and a long neck, and had wheels for locomotion. One such droid patrolled a Jawa sandcrawler on Tatooine, while another served on the first Death Star.

## Specifications

- **Name:** Tall Blue Droid
- **Class:** Security droid
- **Plating:** Blue
- **Armament:** Blaster
- **Affiliation:**
  - Galactic Empire
  - Jawas
