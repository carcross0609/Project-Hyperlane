# OR-B5 Security Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [OR-B5 Security Droid](https://starwars.fandom.com/wiki/OR-B5_Security_Droid)

OR-B5 Security Droid was a security droid model used by the Galactic Republic during the Cold War. In 3643 BBY several OR-B5 Security Droid protected the orbital station that was used by Nomen Karr to spy on the apprentice of Darth Baras and were destroyed when the Sith discovered the station and assaulted its personnel.

- **Plating:** Blue
