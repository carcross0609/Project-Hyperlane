# Mark X Executioner droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mark X Executioner droid/Legends](https://starwars.fandom.com/wiki/Mark_X_Executioner_droid/Legends)

The Mark X Executioner droid was a gladiator droid built by Arakyd Industries. The tall droid moved on two caterpillar tracks—a dual-tread drive system—and was outfitted with a variety of weapons.

## Specifications

- **Name:** Mark X Executioner droid
- **Manufacturer:** Arakyd Industries
- **Class:** Gladiator droid
- **Cost:** 35,000 credits
- **Height:** 2.4 meters
- **Armament:**
  - Blaster rifle
  - Flame projector
  - Flechette canister
  - Force pike
  - Missile launcher
  - Neuronic whip
  - Spiked club
  - Sonic cannon
  - Vibro-ax
  - Vibrosaw blades
