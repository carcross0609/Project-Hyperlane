# Command bridge droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Command bridge droid](https://starwars.fandom.com/wiki/Command_bridge_droid)

The command bridge droid, also known simply as the command droid, were modified TDA-series droid assistant, a model of protocol droid used to crew the command bridge of the Colossus, a supertanker fuel depot. 4D-M1N, Captain Imanuel Doza's liaison, was a command bridge droid, and the Colossus more basic and pared down command droids answered to her.

## Specifications

- **Name:** Command bridge droid
- **Manufacturer:** AccuTronics
- **Model:** Modified TDA-series droid assistant
- **Class:** Protocol droid
- **Affiliation:** The Colossus
