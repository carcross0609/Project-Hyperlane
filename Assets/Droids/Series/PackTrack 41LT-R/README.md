# PackTrack 41LT-R

**Kind:** Series  
**Continuity:** Legends  
**Source:** [PackTrack 41LT-R](https://starwars.fandom.com/wiki/PackTrack_41LT-R)

The PackTrack 41LT-R, also known as the Mechanical Universal Labor Eliminating Droid (MULE), was a droid version of a beast of burden intended for use by scouts.

## Specifications

- **Name:** PackTrack 41LT-R
- **Manufacturer:** LesTech
- **Degree:** Class five droid
- **Cost:** 7,500 credits
- **Height:** 1.5—1.84 meters
- **Equipment:**

  - Optical port
  - Auditory sensors
  - Terrain scanner
  - Long-range antenna
  - Body
  - Heavy lifting claw
  - Repulsorlift
  - Storage bay
