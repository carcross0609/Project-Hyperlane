# IR-22 Security Response Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [IR-22 Security Response Droid](https://starwars.fandom.com/wiki/IR-22_Security_Response_Droid)

The IR-22 Security Response Droid was a model of humanoid battle droid used by the the Shroud, a freelance spy active during the Galactic War. IR-22 Security Response Droids were among the forces that defended the Shroud's factory on the moon Nar Shaddaa.

## Specifications

- **Name:** IR-22 Security Response Droid
- **Class:** Battle droid
- **Sensor:** Blue
- **Plating:** Dark
- **Armament:** Blaster rifle
- **Affiliation:** The Shroud's organization
