# 301-MAX Nightlight

**Kind:** Series  
**Continuity:** Legends  
**Source:** [301-MAX Nightlight](https://starwars.fandom.com/wiki/301-MAX_Nightlight)

301-MAX Nightlight was a sophisticated model of security droid produced by Kalibac Industries. They had a market value of 8,000 credits.

## Specifications

- **Name:** 301-MAX Nightlight
- **Manufacturer:** Kalibac Industries
- **Class:** Security droid
- **Height:** 0.5 meters
- **Equipment:**
  - Repulsorlift generator
  - Visual, audio and combat sensors
  - Ionization buffer
  - Retractable fine work grasper arm
  - Computer I/O jack
  - Stun blaster
  - Anti-Programming Package
