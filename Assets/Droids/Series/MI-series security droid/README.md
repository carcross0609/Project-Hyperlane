# MI-series security droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [MI-series security droid](https://starwars.fandom.com/wiki/MI-series_security_droid)

MI-series security droids were a make of security droid produced by Holowan Mechanicals during the reign of the Galactic Empire as guards for the homes of wealthy Imperial citizens and small planetary governments.

- **Name:** MI-series security droid
- **Manufacturer:** Holowan Mechanicals
- **Class:** Security droid
- **Degree:** Class four droid
- **Cost:** 41,225 credits
- **Height:** >2 meters
- **Gender:** masculine programming

- **Armament:**
