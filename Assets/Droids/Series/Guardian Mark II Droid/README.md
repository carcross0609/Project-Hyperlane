# Guardian Mark II Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Guardian Mark II Droid](https://starwars.fandom.com/wiki/Guardian_Mark_II_Droid)

The Guardian Mark II Droid was a model of canine-shaped security droid developed by Cybot Galactica. It was a variation of the famous GV/3-series guardian droid.
