# Assassination Unit Mark X

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Assassination Unit Mark X](https://starwars.fandom.com/wiki/Assassination_Unit_Mark_X)

The Assassination Unit Mark X was an assassin droid model manufactured by the Czerka Corporation. Such droids were deployed by Gayem Leksende to Grommik's Residence in the Northern Jundland Wastes on Tatooine.
