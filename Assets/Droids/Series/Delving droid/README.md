# Delving droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Delving droid](https://starwars.fandom.com/wiki/Delving_droid)

Delving droids were a class of mining droid. The droids had a number of different functions, including sorting, digging, carrying debris, and detonating explosives. When the Nihil attacked the Blythe homestead on Elphrona, Erika Blythe used the family's delving droids to resist the attackers.

## Specifications

- **Name:** Delving droid
- **Class:** Mining droid
- **Plating:** Red
- **Affiliation:** Blythe family
