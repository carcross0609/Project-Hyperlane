# Phase III Dark Trooper

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Phase III Dark Trooper](https://starwars.fandom.com/wiki/Phase_III_Dark_Trooper)

The Phase III Dark Trooper was the last and most powerful dark trooper exoskeleton/droid. Although in equal height to the Phase II dark trooper, it was far stronger and more durable. This culminated into the fact it was intended to be the armor of the next generation of stormtroopers. It was sometimes even classified as a bipedal tank.
