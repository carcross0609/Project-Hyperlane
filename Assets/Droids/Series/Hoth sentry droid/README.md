# Hoth sentry droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Hoth sentry droid](https://starwars.fandom.com/wiki/Hoth_sentry_droid)

The Hoth sentry droid was a small, treaded tank droid used by the Rebel Alliance on Hoth. The droid included a turret that fired missiles. It was operated via remote control by rebel soldiers, and came in green and tan colors.

## Specifications

- **Name:** Hoth sentry droid
- **Plating:**
  - Tan
  - Green
- **Affiliation:** Alliance to Restore the Republic
- **Class:** Droid tank
- **Armament:** One cannon
- **Equipment:**
  - Missiles
  - Integrated droid brain
- **Sensor:** None
- **Degree:** Fourth-degree droid
