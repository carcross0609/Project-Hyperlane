# CM3-series protocol droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [CM3-series protocol droid](https://starwars.fandom.com/wiki/CM3-series_protocol_droid)

The CM3-series protocol droid was a model of protocol droid with a humanoid frame. TAY-0 was a refurbished CM3-series protocol droid equipped for racing who was destroyed and rebuilt sometime between 19 BBY and 18 BBY.

## Specifications

- **Name:** CM3-series protocol droid
- **Manufacturer:** Czerka Arms
- **Class:** Protocol droid
- **Height:** Taller than 1.93 meters
- **Sensor:** Teal
- **Plating:** Teal, gray, and orange
