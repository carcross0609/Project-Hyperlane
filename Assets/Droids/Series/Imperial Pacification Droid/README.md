# Imperial Pacification Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Imperial Pacification Droid](https://starwars.fandom.com/wiki/Imperial_Pacification_Droid)

The Imperial Pacification Droid was a probe droid model that could be seen throughout Sith planets during the Cold War. There were several varieties of this droid type.
