# 6G2 DeepSpace explorer droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [6G2 DeepSpace explorer droid](https://starwars.fandom.com/wiki/6G2_DeepSpace_explorer_droid)

The 6G2 DeepSpace explorer droid was a 1.3-meter a model from Arakyd Industries. They were assigned to scout vessels for the purpose of investigating new planets. Each was equipped with a repulsor unit with a three-meter flight ceiling, a retractable heavy grasper arm, a holographic/audio recorder, a long-range sensor, and an atmospheric sensor which could determine a planet's atmosphere class within half an hour. A 6G2 cost 6,700 credits new.

## Specifications

- **Name:** 6G2 DeepSpace explorer droid
