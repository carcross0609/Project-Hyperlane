# NS-7 Guardian Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [NS-7 Guardian Droid](https://starwars.fandom.com/wiki/NS-7_Guardian_Droid)

The NS-7 Guardian Droid was a security droid model used for security by the Hutt Cartel on Nar Shaddaa during the Cold War. The model was bipedal and armed with a blaster rifle.

## Specifications

- **Name:** NS-7 Guardian Droid
- **Class:** Security droid
- **Plating:** Silver
- **Armament:** Blaster rifle
- **Affiliation:** Hutt Cartel
