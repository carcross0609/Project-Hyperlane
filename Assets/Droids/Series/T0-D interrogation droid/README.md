# T0-D interrogation droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [T0-D interrogation droid](https://starwars.fandom.com/wiki/T0-D_interrogation_droid)

The T0-D interrogation droid was a wheeled model used by Imperial Intelligence and the Imperial Security Bureau, including aboard the Death Star I. It was equipped with two claws, a stun baton, a sonic stunner, a basic processor, two tool mounts, an improved sensor package, twenty kilograms of internal storage, a durasteel shell, and a vocabulator.
