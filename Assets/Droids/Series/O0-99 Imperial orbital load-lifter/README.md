# O0-99 Imperial orbital load-lifter

**Kind:** Series  
**Continuity:** Canon  
**Source:** [O0-99 Imperial orbital load-lifter](https://starwars.fandom.com/wiki/O0-99_Imperial_orbital_load-lifter)

O0-99 Imperial orbital load-lifters were a series of loadlifter droid used by the Galactic Empire. One O0-99 Imperial load-lifter working on the construction of the Death Star was sabotaged by Geonosians working for a rogue queen, and had to be shot down with a TIE fighter.

- **Name:** O0-99 Imperial orbital load-lifter
- **Class:** Loader droid
- **Plating:** Gray
