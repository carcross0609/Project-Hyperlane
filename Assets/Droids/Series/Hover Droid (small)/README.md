# Hover Droid (small)

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Hover Droid (small)](https://starwars.fandom.com/wiki/Hover_Droid_%28small%29)

Hover Droids were small floating combat droids that were deployed at Cloud City shortly before the Occupation of Bespin. A Hover Droid would rotate as it remained suspended in the air. The Hover Droid existed alongside a larger model.

## Specifications

- **Name:** Hover Droid
- **Degree:** Class four droid
