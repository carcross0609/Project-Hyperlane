# Royal med droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Royal med droid](https://starwars.fandom.com/wiki/Royal_med_droid)

The Royal med droid was a model of medical droid used by the Royal Naboo Security Forces. The healers had feminine voices with a synthesized edge.

- **Homeworld:** Naboo
- **Class:** Medical droid
