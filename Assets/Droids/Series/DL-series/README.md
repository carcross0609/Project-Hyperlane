# DL-series

**Kind:** Series  
**Continuity:** Legends  
**Source:** [DL-series](https://starwars.fandom.com/wiki/DL-series)

The DL-series was a model of security droid manfactured by Veril Line Systems. One of these droids, DL-X2 provided security at the Star Tours travel agency's Tomorrowland Starport.

- **Manufacturer:** Veril Line Systems
