# Jedi security droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Jedi security droid](https://starwars.fandom.com/wiki/Jedi_security_droid)

During the High Republic Era, the Jedi Order used security droids in their temple on the planet Batuu. In that time, an incident within the temple occurred when the discovered Ancient Sith Runestone corrupted and turned the Jedi against one another. The security droids helped the Padawan Ady Sun'Zee eliminate corrupted demlins within the temple.
