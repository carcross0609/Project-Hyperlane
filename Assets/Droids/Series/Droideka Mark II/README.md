# Droideka Mark II

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Droideka Mark II](https://starwars.fandom.com/wiki/Droideka_Mark_II)

The droideka Mark II was an upgraded variant of the droideka developed by the Confederacy of Independent Systems and employed by the Zann Consortium during the Galactic Civil War.

- **Name:** Droideka Mark II
- **Creator:** Baktoid Combat Automata
- **Manufacturer:**

  - Zann Consortium Droid Works
- **Line:** Droideka
- **Class:** Battle droid
- **Degree:** Class four droid
- **Cost:** 31,435 credits
- **Height:** 1.83 meters
- **Gender:** Unisex programming
- **Armament:**
  - Twin built-in blaster cannons (2)
  - Triple built-in blaster cannon
  - Twin Ion cannons
- **Equipment:** Built-in shield projector
- **Affiliation:**
  - Confederacy of Independent Systems
  - Separatist holdout
  - Zann Consortium
