# C-1 protocol droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [C-1 protocol droid](https://starwars.fandom.com/wiki/C-1_protocol_droid)

The C-1 protocol droid was a model of protocol droid produced by Cybot Galactica and manufactured on the droid factory moon of Telti. Part of the C series, C-1 droids were boutique models.

## Specifications

- **Name:** C-1 protocol droid
- **Manufacturer:** Cybot Galactica
- **Homeworld:** Telti
- **Line:** C-series protocol droid
- **Class:** Protocol droid
