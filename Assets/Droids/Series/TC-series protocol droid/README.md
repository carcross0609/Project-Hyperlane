# TC-series protocol droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [TC-series protocol droid](https://starwars.fandom.com/wiki/TC-series_protocol_droid)

The TC-series protocol droid was a model of protocol droid manufactured by Cybot Galactica. The predecessor of the popular 3PO-series, it had the same overall appearance and size as that model, but presented a few differences: notably, the manufacturer advertised TC units as being cooler and more unflappable than their 3PO cousins.

## Specifications

- **Name:** TC-series protocol droid
- **Manufacturer:** Cybot Galactica
- **Class:** Protocol droid
- **Degree:** Class three
- **Height:** 1.67 meters
