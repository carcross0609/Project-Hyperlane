# Purge trooper

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Purge trooper](https://starwars.fandom.com/wiki/Purge_trooper)

The purge trooper was an early design-result of the Imperial Dark Trooper Project meant to be used against Force-sensitives. Parts of the droid's model would later be used to create the Phase III dark trooper.

## Specifications

- **Name:** Purge trooper
- **Line:** Dark Trooper
- **Model:** Purge trooper
- **Class:** Battle droid
- **Degree:** Class four droid
- **Cost:** 31,900 credits
- **Height:** Nearly three meters
- **Plating:** Dark blue
- **Armament:**
  - Energy blade
  - Rocket launcher
- **Affiliation:** Galactic Empire
- **Firstmade:** Prior to 17 BBY
