# NP-unit

**Kind:** Series  
**Continuity:** Canon  
**Source:** [NP-unit](https://starwars.fandom.com/wiki/NP-unit)

NP-units were a model of servo-droid. They looked like floating spheres with a single large "eye," antennae on top, and a set of three manipulator arms underneath.
