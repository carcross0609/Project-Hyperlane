# Marksman-H combat remote

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Marksman-H combat remote](https://starwars.fandom.com/wiki/Marksman-H_combat_remote)

The Marksman-H combat remote, also referred to as a seeker droid and training remote, was a remote used for military training. Manufactured by Industrial Automaton, it was equipped with non-lethal blasters to prevent injuries to the target.

## Specifications

- **Name:** Marksman-H combat remote
- **Manufacturer:** Industrial Automaton
- **Class:** Remote
- **Degree:** Class four droid
- **Cost:** 350 credits.
- **Height:** 32 centimeters (diameter)
- **Armament:** Stun blaster
