# FA-4 pilot droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [FA-4 pilot droid/Legends](https://starwars.fandom.com/wiki/FA-4_pilot_droid/Legends)

The FA-4 pilot droid was a model of wheeled pilot droid in operation during the last decades of the Galactic Republic. It was the predecessor of the FA-5 valet droid, both of which were produced by SoroSuub.

## Specifications

- **Name:** FA-4 pilot droid
- **Manufacturer:** SoroSuub Corporation
- **Line:** FA-series
- **Class:** Pilot droid
- **Height:** 2.1 meters
- **Sensor:** Red
- **Armament:** None
- **Equipment:**
  - Extensible neck
  - Fine-motor graspers
  - Heavy-duty treads
  - High-torque shoulder motor
  - Logic processor module
  - Manipulator arms
  - Power axis
- **Affiliation:**
  - Galactic Republic
  - Confederacy of Independent Systems
