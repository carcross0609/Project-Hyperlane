# DCM-8 Missile Platform Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [DCM-8 Missile Platform Droid](https://starwars.fandom.com/wiki/DCM-8_Missile_Platform_Droid)

The DCM-8 Missile Platform Droid was designed by Arakyd Patrol. It moved around using tank-like magnetic treads and had twelve turret-mounted mini-concussion missiles.

## Specifications

- **Name:** DCM-8 Missile Platform Droid
- **Manufacturer:** Arakyd Patrol
- **Class:** Missile platform droid
- **Height:** 1 meter
- **Armament:** 12 mini-concussion missiles
- **Affiliation:** Galactic Empire
