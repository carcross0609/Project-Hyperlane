# J9 worker drone

**Kind:** Series  
**Continuity:** Legends  
**Source:** [J9 worker drone/Legends](https://starwars.fandom.com/wiki/J9_worker_drone/Legends)

The J9 worker drone was a droid produced by Roche. It was originally designed to be a protocol droid but failed in that role due to design choices by the manufacturer.

## Specifications

- **Name:** J9 worker drone
- **Manufacturer:** Roche Hive Mechanical Apparatus Design and Construction Activity for Those Who Need the Hive's Machines
- **Degree:** Class one droid
- **Cost:**
  - 1,200 credits
  - 900 credits(used)
- **Height:** 1.9 meters
- **Equipment:**
  - Arjan vocabulator
  - Olfactory sensor
  - Photoreceptors (2) (Verpine range)
  - Torplex microwave sensor
  - TranLang II Communication module
