# RS-D04 Assault Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [RS-D04 Assault Droid](https://starwars.fandom.com/wiki/RS-D04_Assault_Droid)

RS-D04 Assault Droid was a model of humanoid-shaped battle droid used by the Galactic Republic during the war against Zakuul. Many droids of this model were used by the Rike's Raiders unit led by Republic General Amos Rike during the Assault on Denova in 3630 BBY.

## Specifications

- **Name:** RS-D04 Assault Droid
- **Class:** Battle droid
- **Degree:** Class four droid
- **Sensor:** Red
- **Plating:** Rust
- **Armament:** Blaster rifle
- **Affiliation:**
  - Galactic Republic
  - Rike's Raiders
