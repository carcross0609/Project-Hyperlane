# First Order probe droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [First Order probe droid](https://starwars.fandom.com/wiki/First_Order_probe_droid)

The First Order Probe Droid was a model of probe droid utilized by the First Order during their war with the Resistance. One such droid was aboard the Resurgent-class Star Destroyer Finalizer during a prison break aboard the ship.

## Specifications

- **Name:** First Order probe droid
- **Class:** Probe droid
- **Degree:** Class three droid
- **Sensor:** Red
- **Plating:** Black
- **Affiliation:** First Order
