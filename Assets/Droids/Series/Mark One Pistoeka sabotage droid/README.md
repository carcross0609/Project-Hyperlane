# Mark One Pistoeka sabotage droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Mark One Pistoeka sabotage droid](https://starwars.fandom.com/wiki/Mark_One_Pistoeka_sabotage_droid)

The Mark One Pistoeka sabotage droid was one of the first generation models of the droids that were known as buzz droids. They were fairly similar to the later versions to the point that many couldn't distinguish the different models from each other. The major difference between the Mark One and the later versions was that the Mark One's had a doonium casing that protected the droid brain. This made them extremely valuable to both collectors and those looking for the valuable doonium inside. Mitth'raw'nuruodo once purchased non-functional Mark Ones for 500 credits which he later fixed and brought with him on the Blood Crow whilst serving in the Imperial Military.
