# 12-4C-41 traffic control droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [12-4C-41 traffic control droid](https://starwars.fandom.com/wiki/12-4C-41_traffic_control_droid)

12-4C-41 traffic control droids were a series of traffic controller droids produced by SoroSuub Corporation. These droids were humanoid in stature, with many similarities to the 3PO-series protocol droids.

## Specifications

- **Name:** 12-4C-41 traffic control droid
- **Manufacturer:** SoroSuub Corporation
- **Class:** Controller droid
- **Height:** 1.65 meters
- **Equipment:**
  - Optic/recorder system
  - Omnidirectional floodlight
  - Retractable data probe
