# TDL-501 unipod waitress droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [TDL-501 unipod waitress droid](https://starwars.fandom.com/wiki/TDL-501_unipod_waitress_droid)

The TDL-501 unipod waitress droid was a service droid developed by AccuTronics shortly before the outbreak of the Clone Wars. The TDL-501 was manufactured to compete with the WA-7 service unit. It did enjoy moderate success but was later outdated.
