# KPR security droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [KPR security droid](https://starwars.fandom.com/wiki/KPR_security_droid)

The KPR security droid, also known as the KPR servant droid, was a model of security droid. During the Galactic Civil War, several KPR units were active on the planet Tatooine. Owen Lars had a KPR unit at his moisture farm. A couple of KPRs were aboard the sandcrawler which captured C-3PO and R2-D2.

## Specifications

- **Name:** KPR security droid
- **Class:** Security droid
- **Affiliation:** Lars family
