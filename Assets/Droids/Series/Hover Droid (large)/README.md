# Hover Droid (large)

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Hover Droid (large)](https://starwars.fandom.com/wiki/Hover_Droid_%28large%29)

Hover Droids were floating combat droids that were deployed at Cloud City before the Occupation of Bespin. Hover Droid would rotate while levitating. The Hover Droid existed alongside a smaller model.

## Specifications

- **Name:** Hover Droid
- **Degree:** Class four droid
