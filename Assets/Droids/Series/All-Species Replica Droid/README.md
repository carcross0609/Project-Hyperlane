# All-Species Replica Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [All-Species Replica Droid](https://starwars.fandom.com/wiki/All-Species_Replica_Droid)

The All-Species Replica Droid, or simply ARD, was a sophisticated model of droid that was designed to be nearly indistinguishable from any species of sentient being that it was created to look like, both in form and function. These droids were, as far as was known, only a work in progress, the concept being researched by the Onadax Droid Technologies Corporation.

## Specifications

- **Name:** All-Species Replica Droid
- **Manufacturer:** Onadax Droid Technologies
- **Class:** Human replica droid
- **Degree:** Class four droid
