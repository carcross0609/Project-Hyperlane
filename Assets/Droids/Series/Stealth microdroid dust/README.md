# Stealth microdroid dust

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Stealth microdroid dust](https://starwars.fandom.com/wiki/Stealth_microdroid_dust)

Stealth microdroid dust was a type of droid. The archaeologist Chelli Aphra used them to locate traps on her daring mission to retrieve the Triple-Zero protocol personality matrix on Quarantine World III.
