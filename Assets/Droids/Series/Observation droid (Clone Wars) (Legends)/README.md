# Observation droid (Clone Wars)

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Observation droid (Clone Wars)/Legends](https://starwars.fandom.com/wiki/Observation_droid_%28Clone_Wars%29/Legends)

The observation droid was a model of probe droid which saw use during the Clone Wars. It was capable of speech to relay messages and was employed by the Zygerrians of the Zygerrian Slave Empire, as well as by the Coruscant Security Force.

## Specifications

- **Name:** Observation droid
- **Class:** Probe droid
- **Affiliation:**
  - Galactic Republic
  - Pyke Syndicate
  - Zygerrian Slave Empire
