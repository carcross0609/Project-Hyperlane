# Hunter droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Hunter droid](https://starwars.fandom.com/wiki/Hunter_droid)

The hunter droid was a type of assassin droid. One known hunter droid was M-OC, who was built by Emperor Sheev Palpatine to locate a legendary weapon, even if it meant destroying the Freemaker family, as R0-GR recalled.

## Specifications

- **Name:** Hunter droid
- **Class:** Assassin droid
- **Sensor:** Red
- **Armament:**
  - Blasters
  - Lightsabers
  - Buzz saw
  - Flamethrowers
  - Grappling arms
  - Missile launcher
  - Sonic cannon
  - Rocket boosters
- **Affiliation:**
  - Galactic Empire
  - Sith
