# Mark IX Executioner

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mark IX Executioner](https://starwars.fandom.com/wiki/Mark_IX_Executioner)

The Mark IX Executioner was an assassin droid engineered by Arakyd Industries. This droid was distributed on Vulpter and was succeeded by the Mark X Executioner and Mark XI Executioner.

## Specifications

- **Name:** Mark IX Executioner
- **Manufacturer:** Arakyd Industries
