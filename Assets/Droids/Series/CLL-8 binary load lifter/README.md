# CLL-8 binary load lifter

**Kind:** Series  
**Continuity:** Legends  
**Source:** [CLL-8 binary load lifter](https://starwars.fandom.com/wiki/CLL-8_binary_load_lifter)

CLL-8 binary load lifters were labor droids designed by Cybot Galactica that had been used for several thousand years, but particularly during the Galactic Civil War. An example of the CLL-8 was QT-QC.
