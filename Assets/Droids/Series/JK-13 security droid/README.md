# JK-13 security droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [JK-13 security droid](https://starwars.fandom.com/wiki/JK-13_security_droid)

The JK-13 security droid, unofficially known as the "Jedi Killer," was a JK-series security droid manufactured on the planet Ord Cestus. These droids rose to prominence during a time when they were threatened to be converted into combat droids.

## Specifications

- **Name:** JK-13 security droid
- **Manufacturer:** Cestus Cybernetics
- **Homeworld:** Ord Cestus
- **Line:** JK security droid
- **Class:** Security droid
- **Height:** 1.5 meters
- **Armament:** Stun tentacles
- **Equipment:** Xythan force shield
- **Affiliation:**
  - Crime lords
  - Confederacy of Independent Systems
