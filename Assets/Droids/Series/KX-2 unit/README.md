# KX-2 unit

**Kind:** Series  
**Continuity:** Canon  
**Source:** [KX-2 unit](https://starwars.fandom.com/wiki/KX-2_unit)

The KX-2 unit was a model of droid derived from the KX-series security droid. Mubo of Black Spire Outpost's Droid Depot worked on rebuilding a KX-2 unit, which Kriki interrogated in order to learn about technology used by the First Order.

## Specifications

- **Name:** KX-2 unit
- **Class:** Security droid
