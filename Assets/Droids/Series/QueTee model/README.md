# QueTee model

**Kind:** Series  
**Continuity:** Legends  
**Source:** [QueTee model](https://starwars.fandom.com/wiki/QueTee_model)

The QueTee model was a small, rectangular model of computer access droid about the size of a standard suitcase.> The QueTee's face was covered with several blinking lights, screens of various sizes, and input and output jacks. These droids were capable of communicating in Basic.

## Specifications

- **Name:** QueTee model
- **Line:** Computer access droid
- **Equipment:** computer access port
- **Firstmade:** Prior to 0 ABY
