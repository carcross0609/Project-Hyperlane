# Mark VIII Sentinel

**Kind:** Series  
**Continuity:** Legends  
**Source:** [Mark VIII Sentinel](https://starwars.fandom.com/wiki/Mark_VIII_Sentinel)

The Mark VIII Sentinel was a model of three-legged battle droid produced by Holowan Laboratories on the moon Nar Shaddaa during the Cold War between the Galactic Republic and the reconstituted Sith Empire. Produced at their Holowan Labs facility in the Network Security District, a number of Mark VIII Sentinel units were used to patrol the facility.

## Specifications

- **Name:** Mark VIII Sentinel
- **Manufacturer:** Holowan Laboratories
- **Homeworld:** Nar Shaddaa
- **Class:** Battle droid
- **Degree:** Class four droid
- **Sensor:** Yellow
- **Plating:** Gray
- **Armament:** Arm-mounted blaster cannons
- **Affiliation:** Holowan Laboratories
