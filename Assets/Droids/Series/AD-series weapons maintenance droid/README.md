# AD-series weapons maintenance droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [AD-series weapons maintenance droid](https://starwars.fandom.com/wiki/AD-series_weapons_maintenance_droid)

The AD-series weapons maintenance droid was Arakyd Industries's answer to small arms maintenance for large armies.

## Specifications

- **Name:** AD-series weapons maintenance droid
- **Manufacturer:** Arakyd Industries
- **Class:** Armorer droid
- **Degree:** Class two droid
- **Cost:** 7,700 – 13,840 credits
- **Height:** 1.5 meters
- **Equipment:**
  - AA-12X VerboBrain
  - Auditory sensors
  - Communications link with base computer
  - Repulsorlift unit
  - Visual sensor (Human range)
  - Vocabulator speech/sound system
