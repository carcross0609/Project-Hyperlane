# Programmer droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Programmer droid](https://starwars.fandom.com/wiki/Programmer_droid)

The programmer droid was a type of droid that worked in programming. One programmer droid was CM-3XB, who worked for the Pyke Syndicate at the spice mines of Kessel alongside a 4XB programming droid.

## Specifications

- **Name:** Programmer droid
- **Affiliation:** Pyke Syndicate
