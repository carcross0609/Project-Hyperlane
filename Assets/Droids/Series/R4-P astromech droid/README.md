# R4-P astromech droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [R4-P astromech droid](https://starwars.fandom.com/wiki/R4-P_astromech_droid)

The R4-P astromech droid was a truncated Industrial Automaton R4-series astromech droid incorporated into the Delta-7 Aethersprite-class light interceptors of the Jedi Order, which had fuselages too slim to house full-sized astromech droids.
