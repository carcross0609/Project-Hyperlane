# N5-R3

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [N5-R3](https://starwars.fandom.com/wiki/N5-R3)

N5-R3 was an astromech droid in service to the reconstituted Sith Empire. During the Cold War it was stationed at the Outpost Talarn on Alderaan.
