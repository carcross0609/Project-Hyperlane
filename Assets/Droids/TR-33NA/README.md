# TR-33NA

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [TR-33NA](https://starwars.fandom.com/wiki/TR-33NA)

TR-33NA was an SP-4 analysis unit that worked as an archive droid at the Graf Archive on the moon Orchis 2. During the archive's restoration effort, TR-33NA led a task force that searched the darkest corners of the library for documents and artifacts of interest, which led to the rediscovery of an old journal filled with sketches and accounts of various alien species.

## Specifications

- **Name:** TR-33NA
- **Model:** SP-4 analysis droid
- **Affiliation:** Graf Archive
