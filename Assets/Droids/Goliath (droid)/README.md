# Goliath (droid)

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [Goliath (droid)](https://starwars.fandom.com/wiki/Goliath_%28droid%29)

The Goliath was a monstrous battle droid owned by the Yahk-Tosh Lord Gar-Oth. The droid was remotely controlled by telepathic commands from Gar-Oth only. When newly knighted Jedi Yoshi Raph-Elan attempted to break up the forced wedding between Gar-Oth and Princess Lourdes, Gar-Oth sent the Goliath after him, but Raph-Elan was able to disable it.
