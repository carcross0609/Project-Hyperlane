# Unidentified power droid (Jabba's Palace)

**Continuity:** Canon  
**Source:** [Unidentified power droid (Jabba's Palace)](https://starwars.fandom.com/wiki/Unidentified_power_droid_%28Jabba%27s_Palace%29)
