# KM1 mining droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [KM1 mining droid](https://starwars.fandom.com/wiki/KM1_mining_droid)

The KM1 mining droid, also referred to as a crab droid, was a quadrupedal mining droid designed for the mining and excavation of valuable ores.

## Specifications

- **Name:** KM1 mining droid
- **Manufacturer:** Duwani Mechanical Products
- **Class:** Mining droid
- **Degree:** Class five droid
- **Armament:** Laser cutters (two)
- **Equipment:** Duranium plating
