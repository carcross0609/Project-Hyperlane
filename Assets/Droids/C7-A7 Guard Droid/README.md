# C7-A7 Guard Droid

**Kind:** Series  
**Continuity:** Legends  
**Source:** [C7-A7 Guard Droid](https://starwars.fandom.com/wiki/C7-A7_Guard_Droid)

The C7-A7 Guard Droid was a security droid model that saw use during the Cold War. The droid was bipedal with a roughly humanoid shape and was armed with a blaster pistol.
