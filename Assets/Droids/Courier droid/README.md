# Courier droid

**Kind:** Series  
**Continuity:** Canon  
**Source:** [Courier droid](https://starwars.fandom.com/wiki/Courier_droid)

Courier droids, also called messenger droids, were droids used to physically transport messages between locations. Several distinct models of messenger droids saw manufacturing, including the ASN courier droid, and the KUP24 messenger. Modified R4-series astromech droids saw use as courier droids by the Galactic Empire.

## Specifications

- **Name:** Courier droid
- **Class:** Messenger droid
- **Affiliation:**
