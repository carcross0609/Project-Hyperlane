# Unidentified BX-series droid commando 2 (Cad Bane)

**Kind:** Individual

**Source:** [Unidentified BX-series droid commando 2 (Cad Bane)](https://starwars.fandom.com/wiki/Unidentified_BX-series_droid_commando_2_%28Cad_Bane%29)
