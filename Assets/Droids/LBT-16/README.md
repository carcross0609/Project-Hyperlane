# LBT-16

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [LBT-16](https://starwars.fandom.com/wiki/LBT-16)

LBT-16 was a BT-16 perimeter droid for sale at Jawa Traders in Mos Eisley. When it arrived it was a psychological mess, requiring a complete memory wipe to overcome its trauma. It was refurbished and in excellent physical condition as of 0 ABY.
