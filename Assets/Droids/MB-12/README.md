# MB-12

**Kind:** Individual  
**Continuity:** Canon  
**Source:** [MB-12](https://starwars.fandom.com/wiki/MB-12)

MB-12 was a BB-series astromech droid that served the Resistance on board the MC85 Star Cruiser Raddus at some point prior to the starship's destruction in 34 ABY. While on board the Raddus, the droid was ordered to report to the vessel's repair bay in order to have a performance chip replaced and diagnostics run. MB-12 recorded the order and an image of the repair bay on an Internal Data Recorder.
