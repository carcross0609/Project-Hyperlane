# 6Y-2KPR

**Kind:** Individual  
**Continuity:** Legends  
**Source:** [6Y-2KPR](https://starwars.fandom.com/wiki/6Y-2KPR)

6Y-2KPR was a green-domed KPR security droid manufactured by Lerrimore Droids. In 0 BBY, this droid was in the possession of Nebit's Jawa tribe and it was stored on the same sandcrawler that held R2-D2 and C-3PO captive after they escaped from the Tantive IV. When the sandcrawler arrived at Owen Lars' moisture farm, the Jawas lined up several droids to sell, including R2-D2 and C-3PO. 6Y-2KPR was not one of the droids selected to be shown.

## Specifications

- **Model:** KPR security droid
