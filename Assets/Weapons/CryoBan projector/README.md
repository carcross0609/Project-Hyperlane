# CryoBan projector

**Kind:** Model  
**Continuity:** Canon  
**Source:** [CryoBan projector](https://starwars.fandom.com/wiki/CryoBan_projector)

The CryoBan projector, manufactured by Tagge Corporation, was originally designed to extinguish fires aboard starships using a supercooling chemical agent. However, independent operators soon discovered that removing the safety nozzles from CryoBan projectors could convert them into lethal weapons.

## Specifications

- **Name:** CryoBan projector
- **Manufacturer:** Tagge Corporation
- **Cost:** 500 credits
- **Range:** Short
