# Pulse-wave rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Pulse-wave rifle](https://starwars.fandom.com/wiki/Pulse-wave_rifle)

The pulse-wave rifle was a larger, rifle version of the pulse-wave pistol. Like the pistol version, the pulse-wave rifle was able to deal more damage at close range, but was less effective at long range.

## Specifications

- **Name:** Pulse-wave rifle
- **Type:** Pulse-wave rifle
- **Cost:** 550 credits
- **Size:** Medium
- **Weight:** 4 kg
- **Capacity:**
  - 50 shots
  - Autofire mode available
- **Range:**
  - Optimum: up to 45 meters
  - Maximum: up to 225 meters
- **Affiliation:**
  - Galactic Republic
  -   Juggernaut war droids
