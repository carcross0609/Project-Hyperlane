# Flechette micro-rocket

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Flechette micro-rocket](https://starwars.fandom.com/wiki/Flechette_micro-rocket)

Flechette micro-rockets were a class of micro-rocket that were designed to destroy groups of infantry. The rockets typically sold for 175 credits and were the most popular class of micro-rocket on the market. Flechette micro-rockets released a wave of sharp needles that could easily kill unarmored individuals.

## Specifications

- **Name:** Flechette micro-rocket
- **Type:** Micro-rocket
- **Cost:** 175 credits
