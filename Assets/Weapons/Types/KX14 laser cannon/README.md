# KX14 laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KX14 laser cannon](https://starwars.fandom.com/wiki/KX14_laser_cannon)

The KX14 was a laser cannon manufactured by Taim & Bak and was installed on the T-85 X-wing starfighter. Due to advances in laser cannon technology, they notably lacked magnetic flashback suppressors, though some New Republic Defense Fleet pilots would install customized suppressors as precautionary measures.
