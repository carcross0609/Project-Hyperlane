# Shard shooter

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Shard shooter](https://starwars.fandom.com/wiki/Shard_shooter)

Shard shooters were a unique Selonian slugthrower which functioned similarly to that of standard slugthrowers, but used electromagnetic propulsion to fire razor-sharp crystalline ammunition instead of metal slugs. The weapon fired in rapid bursts, unleashing a storm of lethal shards at opponents. The crystalline ammunition was quite small, which enabled massive ammunition capacities for sustained fire.

## Specifications

- **Name:** Shard shooter
- **Type:** Slugthrower
- **Cost:** 1,500 credits
- **Weight:** 4 kg
- **Range:** Medium-ranged
