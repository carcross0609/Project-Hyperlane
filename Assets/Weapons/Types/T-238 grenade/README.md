# T-238 grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [T-238 grenade](https://starwars.fandom.com/wiki/T-238_grenade)

The T-238 grenade was a model of gas grenade. It was filled with the chemical Agent T-238, which attacked an individual's digestive tract and induced nausea in its victims for several hours. T-238 grenades were commonly deployed for crowd control or riot suppression operations.

- **Type:** Gas grenade
