# GSI-B4 blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [GSI-B4 blaster pistol](https://starwars.fandom.com/wiki/GSI-B4_blaster_pistol)

The GSI-B4 blaster pistol was the first blaster pistol produced by Galactic Solutions Industries. A hold-out blaster, the GSI-B4 was praised for packing significant firepower into a small and easily-concealed weapon.

## Specifications

- **Name:** GSI-B4 blaster pistol
- **Manufacturer:** Galactic Solutions Industries
- **Type:** Holdout blaster pistol
- **Created:** c. 3642 BBY
