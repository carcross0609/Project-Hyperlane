# Damotite bioweapon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Damotite bioweapon](https://starwars.fandom.com/wiki/Damotite_bioweapon)

In 21 BBY, General Lok Durd created a damotite bioweapon for the Confederacy of Independent Systems using a captive scientist, Bant'ena Fhernan. The damotite weapon was unleashed on Chandrila's Hanna City before its store houses were destroyed by the Galactic Republic during the Clone Wars.
