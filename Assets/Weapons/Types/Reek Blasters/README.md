# Reek Blasters

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Reek Blasters](https://starwars.fandom.com/wiki/Reek_Blasters)

The Reek Blasters was a pair of blaster pistols owned by the Mandalorian Hunter Aran Tal that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard blaster pistols. These pistols featured twin barrels, as well as small spikes resembling Reek horns suspended on each side.
