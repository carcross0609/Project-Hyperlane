# Mark 4e/S heavy laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mark 4e/S heavy laser cannon](https://starwars.fandom.com/wiki/Mark_4e/S_heavy_laser_cannon)

The Mark 4e/S heavy laser cannon was manufactured by Merr-Sonn Munitions, Inc. It was developed to be used on the Imperial Repulsortank 1-H, employed as the vehicle's main gun.
