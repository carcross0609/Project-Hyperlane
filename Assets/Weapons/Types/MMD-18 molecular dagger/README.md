# MMD-18 molecular dagger

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MMD-18 molecular dagger](https://starwars.fandom.com/wiki/MMD-18_molecular_dagger)

The MMD-18 molecular dagger was a type of dagger manufactured by Xana Exotic Arms and was a larger, more durable version of the MSW-9 molecular stiletto. Roughly the same size as a combat knife, the MMD-18 had a long and thin double-edged, crystalline matrix blade that was set into a polycarbonate hilt with a short, straight quillon. Its edges were honed to mono-molecular thickness, and while the dagger was sturdier than the MSW-9, the blade could have still been easily shattered as a result of an incorrect attack.
