# Blast cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blast cannon](https://starwars.fandom.com/wiki/Blast_cannon)

The blast cannon was a type of blaster shotgun weapon. A blast cannon could fire up to seven shots at once. One type of blast cannon was the CR-1 model used by members of the Alliance to Restore the Republic. A blast cannon that looked strikingly similar to the E-11 blaster rifle was used by Phase Zero dark troopers.
