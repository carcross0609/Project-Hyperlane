# D-24 Inferno Grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [D-24 Inferno Grenade/Legends](https://starwars.fandom.com/wiki/D-24_Inferno_Grenade/Legends)

The D-24 Inferno Grenade was a type of incendiary grenade manufactured by Merr-Sonn Munitions, Inc. during the Galactic Civil War and cost 75 credits. It was restricted to military use but the most ruthless mercenaries employed it due to the panic it generated.

## Specifications

- **Name:** D-24 Inferno Grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** D-24 Inferno
- **Type:** Grenade
