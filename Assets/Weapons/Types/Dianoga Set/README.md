# Dianoga Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dianoga Set](https://starwars.fandom.com/wiki/Dianoga_Set)

The Dianoga Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These weathered algae-covered weapons featured a brown, gray, and silver color scheme, with many circular components, exposed red and blue wires, and fake bright red dianoga tentacles wrapped around them.
