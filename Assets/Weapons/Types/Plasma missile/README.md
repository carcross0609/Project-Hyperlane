# Plasma missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Plasma missile](https://starwars.fandom.com/wiki/Plasma_missile)

Plasma missiles were a class of missile that contained a volatile gas that could easily be transformed into destructive plasma. The warheads cost 160 credits each and had a very short range.

## Specifications

- **Name:** Plasma missile
- **Type:** Missile
- **Cost:** 160 credits
