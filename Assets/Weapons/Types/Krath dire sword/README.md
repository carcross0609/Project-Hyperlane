# Krath dire sword

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Krath dire sword](https://starwars.fandom.com/wiki/Krath_dire_sword)

The Krath dire sword was a weapon of the Krath Cult which used metal weaved with cortosis ore. These weapons were only given to the most loyal warriors.
