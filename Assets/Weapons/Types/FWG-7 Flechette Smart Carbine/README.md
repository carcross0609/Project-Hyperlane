# FWG-7 Flechette Smart Carbine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [FWG-7 Flechette Smart Carbine](https://starwars.fandom.com/wiki/FWG-7_Flechette_Smart_Carbine)

The FWG-7 Flechette Smart Carbine was a blaster carbine produced by Malaxan Firepower Incorporated. Derived from the FWG-5 smart pistol, the FWG-7 fired small canisters that exploded upon reaching their target, releasing a deadly cloud of flechettes.

## Specifications

- **Name:** FWG-7 Flechette Smart Carbine
- **Manufacturer:** Malaxan Firepower Incorporated
- **Type:** Blaster carbine
- **Cost:** 1,800 credits
- **Range:** Medium
