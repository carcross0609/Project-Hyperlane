# Cluster bomb launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Cluster bomb launcher](https://starwars.fandom.com/wiki/Cluster_bomb_launcher)

The cluster bomb launcher was a capital ship-based weapon deployed by the Alliance to Restore the Republic and fitted into their MC30c frigates during the Galactic Civil War. The projectiles fired were cluster bombs, which were deadly against starfighters.

- **Name:** Cluster bomb launcher
- **Type:** Capital ship-based launcher
