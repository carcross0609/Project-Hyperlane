# Gand silencer

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Gand silencer](https://starwars.fandom.com/wiki/Gand_silencer)

It was unclear whether Gand silencers had been created by the Gand or to silence them. It was theorized that these energy batons may have been carried by Gand bounty hunters or findsmen and used in a similar fashion to ordinary stun batons.
