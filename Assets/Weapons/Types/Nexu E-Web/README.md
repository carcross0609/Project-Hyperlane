# Nexu E-Web

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Nexu E-Web](https://starwars.fandom.com/wiki/Nexu_E-Web)

The Nexu E-Web was an E-Web heavy repeating blaster cannon owned by the human Hunter Sentinel that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard E-Web.

- **Type:** Heavy repeating blaster
- **Owners:** Sentinel
