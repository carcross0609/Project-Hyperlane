# Sayormi Heartstriker

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sayormi Heartstriker/Legends](https://starwars.fandom.com/wiki/Sayormi_Heartstriker/Legends)

The Sayormi Heartstriker was a small, bladed weapon utilized by the Sayormi monks of Kashyyyk, virtually identical in appearance to basic vibroknucklers. It was named for its ability to break through the rib cage and pierce the heart of an enemy.

- **Name:** Sayormi Heartstriker
- **Culture:** Sayormi
- **Locations:** Kashyyyk
