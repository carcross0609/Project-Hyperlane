# Sticky explosive

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sticky explosive/Legends](https://starwars.fandom.com/wiki/Sticky_explosive/Legends)

Sticky explosives were adhesive demolitions that were used by the bounty hunter Dengar when he fought the Kage Warriors on the planet Quarzite. Once these devices were attached to the target, Dengar would detonate them.

- **Name:** Sticky explosive
- **Type:** Explosive
