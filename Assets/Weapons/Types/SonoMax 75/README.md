# SonoMax 75

**Kind:** Model  
**Continuity:** Legends  
**Source:** [SonoMax 75](https://starwars.fandom.com/wiki/SonoMax_75)

The SonoMax 75 was a sonic pistol created by SonoMax for use by the Corporate Sector Espos, primarily for crowd control and anti-riot purposes.

## Specifications

- **Name:** SonoMax 75
- **Manufacturer:** SonoMax
- **Type:** Sonic pistol
- **Size:** Pistol
- **Capacity:** 20 shots (cone or bolt)
- **Range:** 20 meters
- **Affiliation:** Security Police
