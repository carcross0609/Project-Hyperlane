# A350 blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [A350 blaster rifle](https://starwars.fandom.com/wiki/A350_blaster_rifle)

The A350 blaster rifle was a blaster rifle manufactured by BlasTech Industries. The rifle was used by soldiers loyal to Morgan Elsbeth in the city of Calodan. The blaster rifle feature a double-barreled design and a scope. It can also fire projectiles like sticky bombs.
