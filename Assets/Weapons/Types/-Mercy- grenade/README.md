# "Mercy" grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** ["Mercy" grenade](https://starwars.fandom.com/wiki/%22Mercy%22_grenade)

The "Mercy" grenade was a model of stun grenade produced by Goseia Heavy Industries Concern. The grenades cost 175 credits per unit and used a gas to incapacitate enemies. Originally designed as a riot-control device, the grenade was eventually shelved after it began to cause psychological symptoms in the people that it was used against.

## Specifications

- **Name:** "Mercy" grenade
- **Manufacturer:** Goseia Heavy Industries Concern
- **Type:** Stun grenade
- **Cost:** 175 credits
