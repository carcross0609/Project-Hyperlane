# Great force pike

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Great force pike](https://starwars.fandom.com/wiki/Great_force_pike)

The Great force pike was a longer version of the standard force pike. It was commissioned by the Imperial throne for use by ceremonial guards. It required 4 power cells to operate.

## Specifications

- **Name:** Great force pike
- **Manufacturer:** Czerka Arms
- **Cost:** 1,000 credits
- **Weight:** 2.8 kilograms
