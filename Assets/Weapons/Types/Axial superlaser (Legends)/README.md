# Axial superlaser

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Axial superlaser/Legends](https://starwars.fandom.com/wiki/Axial_superlaser/Legends)

Axial superlasers were powerful weapons featured aboard some of the Imperial Starfleet's Super Star Destroyers, including those of the Sovereign-class and Eclipse-class.

## Specifications

- **Name:** Axial superlaser
- **Type:** Superlaser
- **Purpose:**
  - Penetrate planetary shields
  - Destroy cities
- **Affiliation:**
  - Galactic Empire
  -   Imperial Navy
