# Cluster Homing Torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Cluster Homing Torpedo](https://starwars.fandom.com/wiki/Cluster_Homing_Torpedo)

A Cluster Homing Torpedo was a type of homing torpedo which could be carried onboard N-1 starfighters of the Royal Naboo Security Forces. Once fired, the projectile split into smaller projectiles which sought out targets.

## Specifications

- **Name:** Cluster Homing Torpedo
- **Model:** Cluster homing torpedo
- **Type:** Proton torpedo
- **Affiliation:** Royal Naboo Security Forces
