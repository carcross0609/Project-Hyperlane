# KX Clubs

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KX Clubs](https://starwars.fandom.com/wiki/KX_Clubs)

The KX Clubs were an improvised pair of KX-series security droid's arm melee weapons utilized by the Wookiee Hunter Grozz that he could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara. They were made from a pair of KX-series security droid's arms, specifically belonging to fellow Hunter K-A0S, who sought revenge on the Wookiee for the attack, now equipped with a new set of custom shield arms.
