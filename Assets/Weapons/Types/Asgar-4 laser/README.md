# Asgar-4 laser

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Asgar-4 laser](https://starwars.fandom.com/wiki/Asgar-4_laser)

The Asgar-4 laser was a type of laser cannon created by Zija. The Red Ace, a custom racing starfighter flown by Freya Fenris, was equipped with a pair of Asgar-4 lasers on its bow.
