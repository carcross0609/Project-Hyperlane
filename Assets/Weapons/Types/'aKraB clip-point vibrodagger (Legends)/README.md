# 'aKraB clip-point vibrodagger

**Kind:** Model  
**Continuity:** Legends  
**Source:** ['aKraB clip-point vibrodagger/Legends](https://starwars.fandom.com/wiki/%27aKraB_clip-point_vibrodagger/Legends)

The aKraB clip-point vibrodagger was an 18cm long vibroweapon able to cut through Katarn-class commando armor with relative ease. It was the favored close combat weapon of the New Republic Marines, and was standard issue at the time of the Battle of Mindor; being more than a match for the shadow stormtrooper's vibroknucklers.
