# S-1 Vamblade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [S-1 Vamblade](https://starwars.fandom.com/wiki/S-1_Vamblade)

The S-1 Vamblade was a type of vamblade produced by Prax Arms. It possessed a magnetic locking mechanism that enabled the extension or retraction of a long blade via the flick of a user's wrist. When the blade is retracted, a heavy coat or similar garb could easily conceal the vambrace it was held in, making it a favored weapon by assassins. The cost of the S-1 Vamblade was 500 credits.
