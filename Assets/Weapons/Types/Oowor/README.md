# Oowor

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Oowor](https://starwars.fandom.com/wiki/Oowor)

The oowor was a ranged stun weapon utilized by hunters of the Ithorian species native to the planet Ithor. By the time the weapon was archaic, "Oowor" was a given name for some Ithorian males.

## Specifications

- **Name:** Oowor
- **Type:** Stun weapon
- **Purpose:** Hunting
