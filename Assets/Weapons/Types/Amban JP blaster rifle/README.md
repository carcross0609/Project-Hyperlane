# Amban JP blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Amban JP blaster rifle](https://starwars.fandom.com/wiki/Amban_JP_blaster_rifle)

The Amban JP blaster rifle was a model of two-pronged blaster rifle used around the time of the Third Galactic War. It was very similar in appearance to the Amban phase-pulse blaster used millennia later.
