# Stun bayonet

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Stun bayonet](https://starwars.fandom.com/wiki/Stun_bayonet)

A stun bayonet was a bayonet that was mounted on the end of a blaster rifle, allowing it to be used as a stunning melee weapon. It had a self-contained energy cell that allowed it to operate without draining any energy from the rifle's power pack. It was generally used by military and police organizations, as well as Elite Senate Guards.

## Specifications

- **Name:** Stun bayonet
- **Type:** Bayonet
- **Cost:** 500 credits
- **Shape:** Bayonet-like
- **Weight:** 2 kg
- **Purpose:** To use blaster rifle as a stunning melee weapon
- **Affiliation:**
