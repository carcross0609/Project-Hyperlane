# Awdrysta Pina's blades

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Awdrysta Pina's blades](https://starwars.fandom.com/wiki/Awdrysta_Pina%27s_blades)

Awdrysta Pina's blades were a pair of Force-imbued blades created in the forges of Vur Tepe. The blades were curved and emitted a soft green glow. Their hilts were set with emeralds. According to legend, the blades were used to kill Xendor, who led the Legions of Lettow, but disappeared with Pina in the Unknown Regions.
