# Thermal annihilator bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Thermal annihilator bomb](https://starwars.fandom.com/wiki/Thermal_annihilator_bomb)

The thermal annihilator bomb was an explosive device used by the Zygerrians on Kiros that could be detonated remotely. As the Republic did not realize all of the Togruta on Kiros had been kidnapped, Darts D'Nar used the bombs to create a hostage situation. Obi-Wan Kenobi engaged D'Nar in combat to distract him while Anakin Skywalker and Ahsoka Tano disarmed the bombs with their lightsabers.
