# XI7 Turbolaser

**Kind:** Model  
**Continuity:** Canon  
**Source:** [XI7 Turbolaser](https://starwars.fandom.com/wiki/XI7_Turbolaser)

The XI7 Turbolaser was a type of single-barreled turbolaser cannon. It could be equipped on MC-series star cruisers as well as EF76 Nebulon-B escort frigates.
