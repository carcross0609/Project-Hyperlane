# Systech static blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Systech static blaster](https://starwars.fandom.com/wiki/Systech_static_blaster)

The Systech static blaster was an unusual weapon developed by the Systech Corporation for use against veermok, a ferocious primate found on the planet of Naboo. These primates were highly resistant to blaster fire, therefore this weapon's damage was mostly electrical, allowing it to bypass the resistance.

## Specifications

- **Name:** Systech static blaster
- **Manufacturer:** Systech Corporation
- **Type:** Blaster pistol
- **Range:** 23 meters
