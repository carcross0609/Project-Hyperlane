# Negotiator (DC-17 hand blaster)

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Negotiator (DC-17 hand blaster)](https://starwars.fandom.com/wiki/Negotiator_%28DC-17_hand_blaster%29)

The Negotiator was a custom DC-17 hand blaster manufactured by Theed Arms and later awarded to Clone Captain CT-7567, nicknamed "Rex," during the Clone Wars, for his part in preventing the release of the Blue Shadow Virus on Naboo. The Negotiator—like its counterpart, the Vigilance—was specially plated with chromium.
