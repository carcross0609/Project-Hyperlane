# C-35 fragmentation grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [C-35 fragmentation grenade](https://starwars.fandom.com/wiki/C-35_fragmentation_grenade)

The C-35 fragmentation grenade was a fragmentation grenade manufactured by Merr-Sonn Munitions, Inc. as the successor to the C-25 fragmentation grenade. Alliance SpecForces officers, such as Lieutenant Taidu Sefla, used such grenades.

## Specifications

- **Name:** C-35 fragmentation grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** C-35
- **Type:** Fragmentation grenade
- **Affiliation:**
