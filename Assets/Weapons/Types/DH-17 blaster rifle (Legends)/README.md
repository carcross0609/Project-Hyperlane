# DH-17 blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DH-17 blaster rifle/Legends](https://starwars.fandom.com/wiki/DH-17_blaster_rifle/Legends)

The DH-17 blaster rifle was a blaster rifle manufactured by BlasTech Industries that resembled BlasTech's blaster pistol of the same name and its carbine variant, albeit with an extended barrel and an added stock. The rifle had two firing modes: fully automatic and a charged-shot mode that was relatively unique for its time.

- **Model:** DH-17 blaster rifle
