# Net mini-torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Net mini-torpedo](https://starwars.fandom.com/wiki/Net_mini-torpedo)

An net mini-torpedo was a type of mini-torpedo that released a net. Like other mini-torpedoes, it only functioned underwater.
