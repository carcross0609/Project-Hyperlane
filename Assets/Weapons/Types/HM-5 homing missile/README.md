# HM-5 homing missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [HM-5 homing missile](https://starwars.fandom.com/wiki/HM-5_homing_missile)

The HM-5 homing missile was a type of missile manufactured by Dymek. It consisted of a warhead, guidance fins, a baradium charge, a sensor flange, and a pressure engine. Under Jango Fett's ownership, the Slave I was equipped with such missiles, among other weapons.

- **Name:** HM-5 homing missile
- **Manufacturer:** Dymek
- **Model:** HM-5
