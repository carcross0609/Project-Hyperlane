# MGL-9

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MGL-9](https://starwars.fandom.com/wiki/MGL-9)

The MGL-9 was a model of micro-grenade launcher. The Wookiee, Drokkatta, a munitions expert for the Alliance to Restore the Republic, favored a MGL-9 which was nicknamed "Boomer."

## Specifications

- **Name:** MGL-9
- **Model:** Micro-grenade launcher
- **Type:** Grenade launcher
- **Owners:** Drokkatta
