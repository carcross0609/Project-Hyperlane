# Dymek concussion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dymek concussion missile](https://starwars.fandom.com/wiki/Dymek_concussion_missile)

The Dymek concussion missile was a model of concussion missile used in the Millennium Falcon, which Han Solo modified with a pair of Arakyd ST2 concussion missile tubes that could launch either ST2 concussion missiles or Dymek concussion missiles.

## Specifications

- **Name:** Dymek concussion missile
- **Manufacturer:** Dymek
- **Type:** Concussion missile
- **Range:**
  - 260 meters (optimum)
  - 750 meters (max)
