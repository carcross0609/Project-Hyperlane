# Untarr

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Untarr](https://starwars.fandom.com/wiki/Untarr)

An Untarr was a type of double-pointed spear. The Ebranite Rith Tar'ak used an Untarr during the Galactic Civil War between the Galactic Empire and the Alliance to Restore the Republic.
