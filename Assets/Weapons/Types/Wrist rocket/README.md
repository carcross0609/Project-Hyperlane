# Wrist rocket

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Wrist rocket](https://starwars.fandom.com/wiki/Wrist_rocket)

Wrist rockets, also known as micro-rockets, were small—though powerful—missiles that came in a number of varieties, including explosive micro-rockets. Boba Fett's Mandalorian armor was equipped with a MM9 mini concussion rocket launcher produced by Kelvarek Consolidated Arms. The team Slingshot droideka was capable of shooting an array of micro-rockets.
