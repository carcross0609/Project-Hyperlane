# DC-15LE

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DC-15LE](https://starwars.fandom.com/wiki/DC-15LE)

The DC-15LE was a blaster rifle and variant of the standard DC-15A blaster rifle, which could be modified for long-range engagements or to fire explosive blaster bolts. This variant was utilized by Republic heavy weapons clone troopers and Imperial Purge Trooper commanders. The weapons were also used by Imperial clone troopers and TK stormtroopers, as well as members of the Clone Underground.
