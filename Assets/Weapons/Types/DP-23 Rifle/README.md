# DP-23 Rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DP-23 Rifle](https://starwars.fandom.com/wiki/DP-23_Rifle)

The DP-23 Rifle was a type of blaster. Sometime following 0 BBY, Pletus Croix gave one to a spacer on Mustafar, for helping him with a number of tasks. The stock was similar to that of the DC-15A.
