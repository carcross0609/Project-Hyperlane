# Heavy blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Heavy blaster pistol/Legends](https://starwars.fandom.com/wiki/Heavy_blaster_pistol/Legends)

A heavy blaster pistol, or heavy blaster, was a more powerful version of the standard blaster pistol.

## Specifications

- **Name:** Heavy blaster pistol
- **Type:** Blaster
- **Cost:** 750 credits (Available for military use only)
- **Size:** One-handed weapon
- **Weight:** 1.3 kg
- **Capacity:**
  - 50 shots
  - Close-range stun setting available
- **Range:**
  - Optimum: up to 25 m
  - Maximum: up to 50 m
- **Affiliation:** Alliance to Restore the Republic
