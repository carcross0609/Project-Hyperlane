# Chakram

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Chakram](https://starwars.fandom.com/wiki/Chakram)

The chakram was a bladed melee weapon used by the Dressellian warriors. It was a flat, open-centered metal discus with a sharpened edge. The warriors in the employ of the Alliance to Restore the Republic fought with one chakram in each hand.

## Specifications

- **Name:** Chakram
- **Type:** Cutting-edge weapon
- **Culture:** Dressellian
