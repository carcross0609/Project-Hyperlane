# CryoBan grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [CryoBan grenade](https://starwars.fandom.com/wiki/CryoBan_grenade)

CryoBan grenades were a type of grenade that used CryoBan chemicals to absorb most of the heat within a given area. The WW-41 CryoBan grenade was a model of CryoBan grenade created by Merr-Sonn Munitions, Inc. for fire supression of shipboard fires, although several bounty hunters and mercenaries added it to their inventory as it could encase a targeted being in icy frost.

## Specifications

- **Name:** CryoBan grenade
- **Type:** Grenade
- **Purpose:** Fire supression
