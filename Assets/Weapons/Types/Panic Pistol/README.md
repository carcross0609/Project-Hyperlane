# Panic Pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Panic Pistol](https://starwars.fandom.com/wiki/Panic_Pistol)

The Panic Pistol was a type of slugthrower pistol manufactured by Oriolanis Defense Systems as a compact civilian self-defense pistol. The squat weapon fired a high-caliber round, but the barrel could barely extend past most species' knuckles. This made it easy to wield in close-quarters combat, but wildly inaccurate. Further, the extractor required constant tension adjustments, which made jammings and misfires common.
