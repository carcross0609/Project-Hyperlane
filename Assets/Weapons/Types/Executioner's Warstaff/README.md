# Executioner's Warstaff

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Executioner's Warstaff](https://starwars.fandom.com/wiki/Executioner%27s_Warstaff)

The Executioner's Warstaff was an electrostaff used around the time of the Third Galactic War between the Galactic Republic and the Sith Empire. Executioner's Warstaffs were used by the Brothers on Mek-Sha.

## Specifications

- **Name:** Executioner's Warstaff
- **Type:** Electrostaff
- **Purpose:** Melee combat
- **Affiliation:** The Brothers
