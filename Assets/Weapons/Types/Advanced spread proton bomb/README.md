# Advanced spread proton bomb

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Advanced spread proton bomb](https://starwars.fandom.com/wiki/Advanced_spread_proton_bomb)

Advanced spread proton bombs were spread proton bombs that were used by the Rebel Alliance's Y-wing bombers. They were upgraded to possess a more powerful explosive yield and radius within each cluster.
