# S-5 Security-grade blaster/ascension gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [S-5 Security-grade blaster/ascension gun](https://starwars.fandom.com/wiki/S-5_Security-grade_blaster/ascension_gun)

The S-5 Security-grade blaster/ascension gun, S-5 blaster pistol, simply known as a Naboo blaster, and nicknamed the "climbing pistol," was a model of heavy blaster pistol and ascension gun that was used by some members of the Royal Naboo Security Forces, including Captain Quarsh Panaka. Perosei could disassemble and reassemble a Naboo blaster in sixty seconds.
