# V-1 thermal detonator

**Kind:** Model  
**Continuity:** Legends  
**Source:** [V-1 thermal detonator](https://starwars.fandom.com/wiki/V-1_thermal_detonator)

The V-1 thermal detonator was a small thermal detonator manufactured by Merr-Sonn Munitions, Inc. for service on the battlefield, becoming the primary grenade of choice for both sides of the Clone Wars.
