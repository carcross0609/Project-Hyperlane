# Cloud Blades

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Cloud Blades](https://starwars.fandom.com/wiki/Cloud_Blades)

The Cloud Blades were a set of unique Dual Vibroblades owned by the Kubaz Hunter Glikkin that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard vibroblades.

## Specifications

- **Name:** Cloud Blades
- **Type:** Dual vibroblades (Glikkin's vibroblades)
- **Owners:** Glikkin
- **Affiliation:** Hunters of the Outer Rim
