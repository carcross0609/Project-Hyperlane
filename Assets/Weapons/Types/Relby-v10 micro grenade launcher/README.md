# Relby-v10 micro grenade launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Relby-v10 micro grenade launcher](https://starwars.fandom.com/wiki/Relby-v10_micro_grenade_launcher)

The Relby-v10 micro grenade launcher, also known as the Relby-v10 mortar gun and Relby V-10 Grenade Launcher, was a hybrid model of blaster rifle/grenade launcher that was used by the Trandoshan bounty hunter Bossk. It was also used by Bossk's father, Cradossk. Aside from Bossk famously using the weapon, some marksmen of both the Rebel Alliance and the Galactic Empire used the Relby-v10. The Relby-v10 can be configured firing micro-grenades to firing blaster bolts. One bounty hunter used a Rebly-v10 during the incident on Nevarro. Din Djarin had a Relby-v10 in his arsenal and loaned it to Omera on Sorgan.
