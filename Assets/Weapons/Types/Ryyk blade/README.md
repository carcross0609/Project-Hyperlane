# Ryyk blade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ryyk blade](https://starwars.fandom.com/wiki/Ryyk_blade)

Ryyk blades were scythe-like, curved blades used by the Wookiees of Kashyyyk. The tribal diplomat Greybok notably owned one, which he used to fight Imperials.

- **Name:** Ryyk blade
