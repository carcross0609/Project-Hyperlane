# Ion smoke bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ion smoke bomb](https://starwars.fandom.com/wiki/Ion_smoke_bomb)

An ion smoke bomb was a type of smoke grenade that released a burst of ion particles along with its smoke payload allowing the grenade to effect droids as well as organics. Flux compressors were a key component in constructing ion smoke bomb. By 3 ABY, a flux compressor had been stored in a smuggler hideout on a cliff overlooking Lake Amari on the Outer Rim Territories planet Akiva.
