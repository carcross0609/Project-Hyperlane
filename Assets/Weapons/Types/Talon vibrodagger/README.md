# Talon vibrodagger

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Talon vibrodagger](https://starwars.fandom.com/wiki/Talon_vibrodagger)

The LaserHone Talon vibrodagger was a vibroweapon that vibrated at ultrasonic frequencies, and thus did not emit the characteristic whine that many vibroweapons did. It was favored by those looking for a silent, functional weapon such as Infiltrators, storm commandos, and pirates. The weapons lacked aesthetic features but were efficient in the hands of an expert.

## Specifications

- **Name:** Talon vibrodagger
- **Manufacturer:** LaserHone
- **Type:** Vibrodagger
- **Cost:** 50 credits
