# Harpoon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Harpoon](https://starwars.fandom.com/wiki/Harpoon)

Harpoons were a type of weapon used by the Nihil pirates during the High Republic Era. The weapons fired projectiles attached to cables which allowed them to be used to rip starships apart.

- **Name:** Harpoon
- **Type:** Projectile
- **Size:** Handheld
