# HBt-4 hunting blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [HBt-4 hunting blaster/Legends](https://starwars.fandom.com/wiki/HBt-4_hunting_blaster/Legends)

The HBt-4 hunting blaster was a slightly larger and heavier sporting blaster rifle, that had a shorter range than most models. It was favored on worlds where heavy vegetation meant that longer range shots weren't needed.

## Specifications

- **Name:** HBt-4 hunting blaster
- **Manufacturer:** Herloss
- **Type:**
  - Hunting blaster
  - Sporting blaster rifle
- **Cost:** 500—880 credits
- **Size:** Medium
- **Weight:** 6 kilograms
- **Capacity:** 50
- **Range:** 300 meters
