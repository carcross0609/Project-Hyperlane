# RK-77 cluster missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [RK-77 cluster missile](https://starwars.fandom.com/wiki/RK-77_cluster_missile)

The RK-77 cluster missile was a type of cluster missile produced by Czerka Arms during the Galactic War between the Republic and the Sith Empire. Well-known for their quick lock-on time, RK-77 missiles were favorites for many pilots in dogfights; the missiles' small frame sacrificed fuel and payload in exchange for the ability to carry large numbers of the missiles into battle.
