# Ionizing warhead

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ionizing warhead](https://starwars.fandom.com/wiki/Ionizing_warhead)

Ionizing warheads were a type of warhead equipped on the intruder missiles manufactured by Slayn & Korpil. The warhead was designed to disrupt a target's onboard systems and overload the shield generators.
