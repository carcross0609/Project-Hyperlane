# Witches' War Fan

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Witches' War Fan](https://starwars.fandom.com/wiki/Witches%27_War_Fan)

The Witches' War Fan was a melee weapon which saw use during the time of the Galactic Civil War. The fan, which doubled as a weapon, was commonly used by the Witches of Dathomir.
