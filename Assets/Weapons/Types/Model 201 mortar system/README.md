# Model 201 mortar system

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Model 201 mortar system](https://starwars.fandom.com/wiki/Model_201_mortar_system)

The Model 201 mortar system, also referred to as the Model 201 mortar, or simply, as the 201 mortar, was a type of portable mortar artillery system manufactured by Merr-Sonn Munitions, Inc. which cost 5,400 credits to purchase.
