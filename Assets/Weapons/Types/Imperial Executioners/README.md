# Imperial Executioners

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Imperial Executioners](https://starwars.fandom.com/wiki/Imperial_Executioners)

The Imperial Executioners was a pair of MT-97 blaster pistols owned by the Mandalorian Hunter Aran Tal that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard blaster pistols. Each of these pistols featured a red Imperial crest displayed on the side.
