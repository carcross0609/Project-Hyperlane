# Elite watchman blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Elite watchman blaster](https://starwars.fandom.com/wiki/Elite_watchman_blaster)

The Elite watchman blaster was a slightly more powerful version of the Watchman blaster. The stun capability of this weapon rendered it useful as an off-hand weapon for those beings who preferred combat with two ranged weapons.

## Specifications

- **Name:** Elite watchman blaster
- **Type:** Blaster pistol
- **Range:** 23 meters
