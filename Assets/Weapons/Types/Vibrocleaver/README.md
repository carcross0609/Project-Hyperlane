# Vibrocleaver

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vibrocleaver](https://starwars.fandom.com/wiki/Vibrocleaver)

The vibrocleaver or Vibro-Cleaver was a large bladed vibro weapon. Trudgen, a member of the Knights of Ren, carried a vibrocleaver, as did the assassin droid IG-88.
