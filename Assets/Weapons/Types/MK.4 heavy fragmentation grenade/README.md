# MK.4 heavy fragmentation grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MK.4 heavy fragmentation grenade](https://starwars.fandom.com/wiki/MK.4_heavy_fragmentation_grenade)

The MK.4 was a model of heavy fragmentation grenade produced by Golan Arms during the Galactic Civil War and cost 75 credits. It contained a stronger detonite charge.
