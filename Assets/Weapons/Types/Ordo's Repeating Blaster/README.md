# Ordo's Repeating Blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ordo's Repeating Blaster](https://starwars.fandom.com/wiki/Ordo%27s_Repeating_Blaster)

In the latter part of the Mandalorian Wars a prototype heavy repeater was developed but never saw general production. Canderous Ordo owned and carried one when an amnesiac Revan first encountered him in the Tarisian Lower City.

## Specifications

- **Name:** Ordo's Repeating Blaster
- **Type:** Heavy repeating blaster
- **Culture:** Mandalorians
- **Owners:** Canderous Ordo
