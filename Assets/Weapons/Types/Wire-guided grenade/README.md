# Wire-guided grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Wire-guided grenade](https://starwars.fandom.com/wiki/Wire-guided_grenade)

A wire-guided grenade was a type of Grenade that was fired from a launcher with a trailing wire. In the case of the RGL-80 electronet grenade, the guide wire delivered an electrical charge to a net that was deployed from the grenade.
