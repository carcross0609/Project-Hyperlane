# Rodian blade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Rodian blade](https://starwars.fandom.com/wiki/Rodian_blade)

The Rodian blade was a sword-like gauntlet mainly used by Rodian mercenaries and bounty hunters. Its more deadly variant was the Rodian death blade.
