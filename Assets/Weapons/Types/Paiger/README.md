# Paiger

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Paiger](https://starwars.fandom.com/wiki/Paiger)

The "Paiger" was a customized proton bomb developed by Rose Tico of the Resistance's Engineering Corps in 35 ABY. It was designed to be compatible with B-wing and Y-wing starfighters. The weapon was nicknamed after Rose's late sister, Paige Tico.

## Specifications

- **Name:** "Paiger"
- **Type:** Proton bomb
- **Creators:** Rose Tico
- **Created:** 35 ABY
