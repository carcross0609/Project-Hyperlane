# Vectored cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vectored cannon](https://starwars.fandom.com/wiki/Vectored_cannon)

A vectored cannon was a model of laser cannon that was installed on some RZ-1 A-wing interceptors and allowed the weapon to rotate in a 360 degree firing arc.

- **Type:** Laser cannon
