# Incendiary grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Incendiary grenade](https://starwars.fandom.com/wiki/Incendiary_grenade)

Incendiary grenades were a type of grenade, that, rather than using an explosive charge, burst into flames when detonated. The volatile gel inside incendiary grenades stuck to both structures and enemy combatants, setting both alight. They were highly restricted, and banned on many civilized worlds. Models of incendiary grenade included the Wynz-Tek Mk IV Firestorm, and both the D-24 Inferno Grenade and WP-19 incendiary grenade manufactured by Merr-Sonn Munitions, Inc.
