# Heavy repeating blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Heavy repeating blaster](https://starwars.fandom.com/wiki/Heavy_repeating_blaster)

A heavy repeating blaster, also known as a heavy repeater blaster, was a type of powerful repeating blaster. E-Web heavy repeating blaster cannons, "Roba" M-45 repeating ion blasters, MWC-35c "Staccato Lightning" repeating cannons, and TL-50 Heavy Repeaters were heavy repeating blasters that saw use in the galaxy.

- **Name:** Heavy repeating blaster
- **Type:** Repeating blaster
- **Cost:** 6,000 credits
- **Range:** Long-ranged
