# Shaped charge

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Shaped charge](https://starwars.fandom.com/wiki/Shaped_charge)

Shaped charges were a class of demolition device that made use of an explosive placed inside a conical plasteel case. The case's shape meant that when the device detonated, the blast's kinetic energy would all be directed into the same point. A single shaped charge cost 500 credits.

## Specifications

- **Name:** Shaped charge
- **Type:** Demolition device
- **Cost:** 500 credits
