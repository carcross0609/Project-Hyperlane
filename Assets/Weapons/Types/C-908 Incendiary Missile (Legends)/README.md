# C-908 Incendiary Missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [C-908 Incendiary Missile/Legends](https://starwars.fandom.com/wiki/C-908_Incendiary_Missile/Legends)

The C-908 Incendiary Missile was a model of incendiary missile produced by Merr-Sonn Munitions, Inc. during the Galactic Civil War and cost 145 credits. A devastating weapon, it combined the power of a flamethrower with the range of a missile.
