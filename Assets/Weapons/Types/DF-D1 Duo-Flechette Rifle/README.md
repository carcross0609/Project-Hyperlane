# DF-D1 Duo-Flechette Rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DF-D1 Duo-Flechette Rifle](https://starwars.fandom.com/wiki/DF-D1_Duo-Flechette_Rifle)

The DF-D1 Duo-Flechette Rifle was a type of flechette launcher produced by Salus Corporation, who took inspiration from Golan Arms' FC-1 flechette launcher. Salus's goal for designing the DF-D1 was to reduce the FC-1 to a rifle-sized platform. As a result, the DF-D1 possessed twin canisters of needlelike flechettes, which would detonate and create a cloud of fast-moving razor-sharp debris.

## Specifications

- **Name:** DF-D1 Duo-Flechette Rifle
- **Manufacturer:** Salus Corporation
- **Type:** Flechette launcher
- **Cost:** 1,000 credits
- **Range:** Short-ranged
