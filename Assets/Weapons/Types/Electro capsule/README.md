# Electro capsule

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro capsule](https://starwars.fandom.com/wiki/Electro_capsule)

The electro capsule or suicide shocker was a suicide-assisting weapon that could be implanted inside an individual's mouth. It consisted of a triangular tooth implant that was activated by biting down, resulting in an electric shock that killed the user.

## Specifications

- **Name:** Electro capsule
- **Type:** Electric shock device
- **Locations:**
  - Coruscant
  - Pantora
  - Trask
- **Purpose:** Suicide
- **Affiliation:**
  - Galactic Empire
  - Gideon's Imperial remnant
