# Superheavy Composite Beam Turbolaser

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Superheavy Composite Beam Turbolaser](https://starwars.fandom.com/wiki/Superheavy_Composite_Beam_Turbolaser)

The Superheavy Composite Beam Turbolaser was a model of turbolaser that was supposedly powered by kyber crystals and considered by the Rebel Alliance to be a superweapon. Each Onager-class Star Destroyer could be outfitted with a pair of these turbolasers which could be used in long-range attacks on starships, although they had a shorter range than Orbital Bombardment Particle Cannons.
