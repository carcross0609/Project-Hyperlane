# Verpine Sniper Rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Verpine Sniper Rifle](https://starwars.fandom.com/wiki/Verpine_Sniper_Rifle)

A Verpine Sniper Rifle was a projectile weapon reliant on magnetic field technology, making its operation nearly silent. One such Sniper Rifle was carried by a Kyuzo trailblazer in a forested environment.
