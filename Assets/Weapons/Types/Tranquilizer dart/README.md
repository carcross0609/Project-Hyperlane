# Tranquilizer dart

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Tranquilizer dart](https://starwars.fandom.com/wiki/Tranquilizer_dart)

A tranquilizer dart was a small non-lethal projectile. The Ugnaught Kuiil used two tranquilizer darts on blurrgs that attacked the Mandalorian bounty hunter Din Djarin.
