# SE-44C blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [SE-44C blaster pistol](https://starwars.fandom.com/wiki/SE-44C_blaster_pistol)

The SE-44C blaster pistol, also known as the SE-44C officer's blaster pistol, was a blaster pistol manufactured by Sonn-Blas Corporation for the First Order. The pistol alerted the user with a vibrating pulser to indicate low ammunition.
