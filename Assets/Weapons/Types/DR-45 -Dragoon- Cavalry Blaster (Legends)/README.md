# DR-45 "Dragoon" Cavalry Blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DR-45 "Dragoon" Cavalry Blaster/Legends](https://starwars.fandom.com/wiki/DR-45_%22Dragoon%22_Cavalry_Blaster/Legends)

The DR-45 "Dragoon" Cavalry Blaster was a convertible blaster carbine that was sold by Merr-Sonn Munitions, Inc. for 1,900 credits. The blaster was based on Merr-Sonn's DD6 blaster pistol and could be used in pistol or carbine form.

## Specifications

- **Name:** DR-45 "Dragoon" Cavalry Blaster

- **Type:** Convertible blaster carbine
