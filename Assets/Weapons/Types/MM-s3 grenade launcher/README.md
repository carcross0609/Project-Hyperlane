# MM-s3 grenade launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MM-s3 grenade launcher](https://starwars.fandom.com/wiki/MM-s3_grenade_launcher)

The MM-s3 grenade launcher was a long-range grenade launcher manufactured by Merr-Sonn Munitions, Inc.. The MM-s3 was frequently combined with the WW-676 repulsorlift sled to form a combined artillery system known as the MobileMortar-3.

## Specifications

- **Name:** MM-s3 grenade launcher
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Grenade mortar
- **Cost:** 4,000 credits
- **Weight:** 20 kilograms (reduced to 2 kilograms with use of microrepulsorlift unit)
- **Capacity:** 12 (internal magazine)
- **Range:**
  - 500 meters (optimum)
  - 1 kilometer (maximum)
