# Shinbone blade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Shinbone blade](https://starwars.fandom.com/wiki/Shinbone_blade)

Shinbone blade was a dagger forged from beskar owned by the bounty hunter Beilert Valance. It was an effective last resort in case Valance's cyborg systems were incapacitated.
