# Mythosaur axe

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Mythosaur axe](https://starwars.fandom.com/wiki/Mythosaur_axe)

The mythosaur axe was a melee weapon used by the Mandalorians. One of these was owned by Vera Beroya and her father. It shared its name with the mythosaur, a creature of gigantic proportions found on the Outer Rim world of Mandalore.

## Specifications

- **Name:** Mythosaur axe
- **Type:** Melee weapon
- **Culture:** Mandalorians
- **Locations:** Arumorut, Vlemoth Port
- **Shape:** Axe-like
- **Affiliation:** Mandalorians
