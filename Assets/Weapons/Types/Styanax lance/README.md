# Styanax lance

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Styanax lance](https://starwars.fandom.com/wiki/Styanax_lance)

Styanax lance was a type of harpoon used by stabmen during the Galactic Civil War to hunt the styanax, an aquatic predatory native to the Sea of Jarad on the planet Tralus.

## Specifications

- **Name:** Styanax lance
- **Type:** Harpoon
- **Locations:** Tralus
- **Cost:** 200 credits
- **Length:** 1.5 meter
