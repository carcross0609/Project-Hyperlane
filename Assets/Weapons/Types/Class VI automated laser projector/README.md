# Class VI automated laser projector

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Class VI automated laser projector](https://starwars.fandom.com/wiki/Class_VI_automated_laser_projector)

The BlasTech Class VI automated laser projector was an automated laser trap used by the Empire in the detention blocks of the first Death Star.

## Specifications

- **Name:** Class VI automated laser projector
- **Manufacturer:** BlasTech Industries
- **Type:** Automated laser trap
- **Capacity:**
  - 50 shots (internal power cell)
  - Unlimited (power generator)
- **Range:**
  - 10 meters (optimum)
  - 25 meters (maximum)
