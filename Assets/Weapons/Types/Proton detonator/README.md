# Proton detonator

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Proton detonator](https://starwars.fandom.com/wiki/Proton_detonator)

Proton detonators were a type of dangerous explosive. The Alliance to Restore the Republic planned to use proton detonators to destroy the unstable planet K43 after luring Imperial Star Destroyers close to it.
