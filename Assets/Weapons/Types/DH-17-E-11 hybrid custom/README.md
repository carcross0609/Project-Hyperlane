# DH-17/E-11 hybrid custom

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DH-17/E-11 hybrid custom](https://starwars.fandom.com/wiki/DH-17/E-11_hybrid_custom)

A DH-17/E-11 hybrid custom was a hybridized blaster rifle built from an E-11 medium blaster rifle and a DH-17 blaster pistol. Weeteef Cyu-Bee owned one such customized blaster, which was "tibanna-jacked."

- **Model:** Custom hybrid
- **Type:** Blaster rifle
- **Material:** Scavenge material from a E-11 medium blaster rifle and a DH-17 blaster pistol
