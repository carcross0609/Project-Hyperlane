# Sanchi Kan

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Sanchi Kan](https://starwars.fandom.com/wiki/Sanchi_Kan)

The Sanchi Kan, or Triple Irons in Farakai, was a three-sectioned staff that the Farakai believed to be the weapon of the gods. Chulok, a gangster who was the Farakai Chu bonded with the Rodian Lok, possessed a Sanchi Kan made of a durasteel core wrapped in Zillo Beast hide.
