# Bayonet

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bayonet/Legends](https://starwars.fandom.com/wiki/Bayonet/Legends)

A bayonet was a sharp blade that could be mounted on the end of a blaster rifle or other long-barreled rifle. This allowed the wielder to use the rifle in close combat as a spear-like melee weapon.

## Specifications

- **Name:** Bayonet
- **Type:** Melee weapon
- **Culture:** Soldiers and Infantry
- **Cost:** 50 credits
- **Weight:** 1 kg
- **Purpose:** Use rifle as spear-like melee weapon
