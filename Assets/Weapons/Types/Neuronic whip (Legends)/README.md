# Neuronic whip

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Neuronic whip/Legends](https://starwars.fandom.com/wiki/Neuronic_whip/Legends)

The neuronic whip was a creation of TholCorp, the purpose of which was to send powerful electrical charges into a being's nerve cells, causing a great deal of pain and trauma.

## Specifications

- **Name:** Neuronic whip
- **Manufacturer:** TholCorp
- **Type:** Exotic melee weapon
- **Cost:** 500–700 credits
- **Weight:** 0.5–1.8 kilograms
