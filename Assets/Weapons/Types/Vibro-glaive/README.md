# Vibro-glaive

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vibro-glaive](https://starwars.fandom.com/wiki/Vibro-glaive)

Vibro-glaive was a type of vibro weapon, with a heavy, single-edged head affixed to the pole up to two meters in length. One popular model among dark wolf beastmasters of Sriluur was Beastmaster's vibro-glaive.
