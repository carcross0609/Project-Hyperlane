# DX-2 disruptor blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DX-2 disruptor blaster pistol](https://starwars.fandom.com/wiki/DX-2_disruptor_blaster_pistol)

The DX-2 disruptor blaster pistol or the DX-2 disruptor pistol was a type of disruptor blaster pistol capable of disintegrating organic beings. Although the DX-2 was prohibited by the Rebel Alliance, some members still used the weapon, including Brand of the Alliance's 61st Mobile Infantry.
