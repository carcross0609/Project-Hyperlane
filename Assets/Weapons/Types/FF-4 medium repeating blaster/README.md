# FF-4 medium repeating blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [FF-4 medium repeating blaster](https://starwars.fandom.com/wiki/FF-4_medium_repeating_blaster)

The FF-4 medium repeating blaster was a type of medium blaster cannon produced by Taim & Bak. The Kuat Drive Yards All Terrain Armored Transport was equipped with two FF-4s mounted on either side of the walker's command module.
