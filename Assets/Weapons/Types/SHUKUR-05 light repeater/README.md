# SHUKUR-05 light repeater

**Kind:** Model  
**Continuity:** Legends  
**Source:** [SHUKUR-05 light repeater](https://starwars.fandom.com/wiki/SHUKUR-05_light_repeater)

The SHUKUR-05 was a light repeating blaster in production by the time of the Galactic Civil War. The origins of the repeater's name could be found in the Mandalorian language, specifically the Mando'a word shukur, which translated to "break" in Galactic Basic Standard.

- **Model:** SHUKUR-05
- **Type:** Light repeating blaster
- **Culture:** Mandalorian
