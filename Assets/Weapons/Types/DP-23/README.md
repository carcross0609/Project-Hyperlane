# DP-23

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DP-23](https://starwars.fandom.com/wiki/DP-23)

The DP-23 was a type of blaster that could pierce through enemy defenses. It was used by the Grand Army of the Republic's clone troopers during the Clone Wars between the Galactic Republic and the Confederacy of Independent Systems. The DP-23 fired blue blaster bolts, and had a ridged barrel with a pointed muzzle, a black stock, and a small foregrip. At one point during the war, a clone trooper wearing Phase I clone trooper armor fired the DP-23 on the jungle planet Felucia.
