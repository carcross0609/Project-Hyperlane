# Ion relic pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ion relic pistol](https://starwars.fandom.com/wiki/Ion_relic_pistol)

The ion relic pistol was a rare pistol which used ion particles to puncture the target, causing severe damage. It could be constructed using the Chu-Gon Dar cube. A slight variant was the Oppressor pistol in possession of the GK Oppressor.
