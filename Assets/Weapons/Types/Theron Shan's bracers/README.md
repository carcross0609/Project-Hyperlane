# Theron Shan's bracers

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Theron Shan's bracers](https://starwars.fandom.com/wiki/Theron_Shan%27s_bracers)

The Republic Strategic Information Service agent Theron Shan utilized a pair of bracers that stored and fired darts with various properties. The bracers were activated by voice commands, and Shan could trigger any of the "Toxicities"—of which there were at least ten—by stating the dart's number.

## Specifications

- **Name:** Theron Shan's bracers
- **Type:** Wrist-mounted weapons
- **Owners:** Theron Shan
- **Shape:** Cylindrical bracers
- **Purpose:** Combat and infiltration
- **Affiliation:** Republic Strategic Information Service
