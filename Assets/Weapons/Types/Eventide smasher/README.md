# Eventide smasher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Eventide smasher](https://starwars.fandom.com/wiki/Eventide_smasher)

The Eventide smasher was a heavy sword of incredible strength. Only the strongest of warriors were able to wield them, and only the most extremely skilled fencers were able to use them effectively in battle.
