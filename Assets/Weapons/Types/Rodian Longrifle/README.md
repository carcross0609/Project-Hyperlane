# Rodian Longrifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Rodian Longrifle](https://starwars.fandom.com/wiki/Rodian_Longrifle)

The Rodian Longrifle was a precision rifle made on the planet of Rodia.

## Specifications

- **Name:** Rodian Longrifle
- **Manufacturer:** Rodian Artisans
- **Type:** Blaster rifle
- **Cost:** 1,500 - 6,000+ credits, depending on quality
- **Size:** Medium
- **Weight:** 3.5 kg
- **Capacity:** 25 Blaster bolts
- **Range:** 50 meters (optimum), 100 meters (maximum)
