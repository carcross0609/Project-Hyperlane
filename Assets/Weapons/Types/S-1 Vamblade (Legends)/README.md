# S-1 Vamblade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [S-1 Vamblade/Legends](https://starwars.fandom.com/wiki/S-1_Vamblade/Legends)

The S-1 Vamblade was a melee weapon produced by Prax Arms during the Galactic Civil War and cost 500 credits. It was dagger-length blade extending from durasteel vambrace.
