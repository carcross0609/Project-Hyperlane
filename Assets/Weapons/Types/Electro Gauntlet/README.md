# Electro Gauntlet

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro Gauntlet](https://starwars.fandom.com/wiki/Electro_Gauntlet)

An Electro Gauntlets was a type of shock glove that produced a debilitating electric shock to whomever the wearer touched. Bounty hunter Cad Bane owned a pair of Electro Gauntlets which he used to immobilize Obi-Wan Kenobi on Teth while attempting to evade capture.
