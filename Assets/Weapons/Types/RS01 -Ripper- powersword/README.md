# RS01 "Ripper" powersword

**Kind:** Model  
**Continuity:** Canon  
**Source:** [RS01 "Ripper" powersword](https://starwars.fandom.com/wiki/RS01_%22Ripper%22_powersword)

The RS01 "Ripper" powersword was a powersword manufactured by SoroSuub Corporation. A massive weapon, the RS01 required two hands to wield, and was designed for heavy blows rather than precise dueling.
