# Blaster Buster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blaster Buster](https://starwars.fandom.com/wiki/Blaster_Buster)

The Blaster Buster was a small and highly specialized niche slugthrower produced by Oriolanis Defense Systems.

## Specifications

- **Name:** Blaster Buster
- **Manufacturer:** Oriolanis Defense Systems
- **Type:** Anti-energy weapon
- **Cost:** 350—700 credits (30 credits per ammunition clip)
- **Size:** Small
- **Weight:** 1.4 kilograms
- **Capacity:** 4
- **Range:** 20 meters
