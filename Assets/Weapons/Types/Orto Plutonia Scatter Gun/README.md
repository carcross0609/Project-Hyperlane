# Orto Plutonia Scatter Gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Orto Plutonia Scatter Gun](https://starwars.fandom.com/wiki/Orto_Plutonia_Scatter_Gun)

The Orto Plutonia Scatter Gun was a scatter gun owned by the Trandoshan Hunter Charr that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard slugthrower. It was seemingly adorned with narglatch fur.
