# Light repeating blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Light repeating blaster](https://starwars.fandom.com/wiki/Light_repeating_blaster)

The light repeating blaster was a heavy rifle- and/or pistol-type blaster weapon carried by military personnel. The SE-14r light repeating blaster and the T-21 light repeating blaster were two light repeating blasters.
