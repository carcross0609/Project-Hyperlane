# Geonosian sonic blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Geonosian sonic blaster](https://starwars.fandom.com/wiki/Geonosian_sonic_blaster)

The Geonosian sonic blaster was a rifle-like sonic blaster manufactured by Gordarl Weaponsmiths. It was the standard sidearm of Geonosians, like the Geonosian warriors. The blasters fired sonic waves of energy that could stun, or if on full power, shatter every bone in the blast radius, effectively eliminating the target.
