# Unexpected Results

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Unexpected Results](https://starwars.fandom.com/wiki/Unexpected_Results)

"Unexpected Results" was a highly experimental blaster cannon developed by Czerka Arms during the Third Galactic War. Merely obtaining the weapon required signing a waiver.
