# C-44D "Piratesweeper" blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [C-44D "Piratesweeper" blaster rifle](https://starwars.fandom.com/wiki/C-44D_%22Piratesweeper%22_blaster_rifle)

The C-44D "Piratesweeper" blaster rifle was a model of black blaster rifle with a scope and silver barrel tip. The haulcraft pilot Trowee Astur wore a C-44D on a shoulder strap while in Point Ueda on the planet Ueda during the High Republic Era in 132 BBY.
