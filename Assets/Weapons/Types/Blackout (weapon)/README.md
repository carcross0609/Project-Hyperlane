# Blackout (weapon)

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blackout (weapon)](https://starwars.fandom.com/wiki/Blackout_%28weapon%29)

A Blackout was a type of weapon designed by Merr-Sonn. The Yarkoran smuggler Sheryc Seka sold difficult to find hardware, which included a Blackout with a triple-sling and custom fit by a Trandoshan.

## Specifications

- **Name:** Blackout
- **Manufacturer:** Merr-Sonn Munitions, Inc.
