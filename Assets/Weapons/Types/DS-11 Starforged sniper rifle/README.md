# DS-11 Starforged sniper rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DS-11 Starforged sniper rifle](https://starwars.fandom.com/wiki/DS-11_Starforged_sniper_rifle)

The DS-11 Starforged sniper rifle was a model of blaster sniper rifle available during the Galactic War between the Galactic Republic and the Sith Empire. Similar to the DS-8 Starforged sniper rifle and DS-9 Starforged sniper rifle, it featured a longer barrel and additional components on its stock.

- **Type:** Blaster sniper rifle
