# Bo-rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Bo-rifle](https://starwars.fandom.com/wiki/Bo-rifle)

The bo-rifle was a type of weapon that uniquely combined the functions of an electrostaff and a blaster rifle, intended for exclusive use by the Honor Guard of Lasan. It was considered a great insult if it was used by anyone else. The only known exception to this was if the individual in question had defeated a guardsmen and been presented with their weapon, in accordance with the Boosahn Keeraw, the warrior way of the Lasat species.
