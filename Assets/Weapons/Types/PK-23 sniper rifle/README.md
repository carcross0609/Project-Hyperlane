# PK-23 sniper rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [PK-23 sniper rifle](https://starwars.fandom.com/wiki/PK-23_sniper_rifle)

The PK-23 sniper rifle was a model of sniper rifle used during the Imperial Era. It was capable of firing ten shots in quick succession and came equipped with a scope.
