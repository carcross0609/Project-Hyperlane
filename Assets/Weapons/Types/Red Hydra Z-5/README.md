# Red Hydra Z-5

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Red Hydra Z-5](https://starwars.fandom.com/wiki/Red_Hydra_Z-5)

The Red Hydra Z-5 was a blaster pistol. Red Hydra pistols were once favored by officers and squad leaders in the military forces of the Quohag sector until they were decommissioned by Imperial order.

## Specifications

- **Name:** Red Hydra Z-5
- **Model:** Updated Red Hydra pistol
- **Type:** Blaster pistol
- **Range:** 25 meters
