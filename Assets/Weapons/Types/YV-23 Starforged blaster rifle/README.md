# YV-23 Starforged blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [YV-23 Starforged blaster rifle](https://starwars.fandom.com/wiki/YV-23_Starforged_blaster_rifle)

The YV-23 Starforged blaster rifle was a model of blaster rifle available during the Galactic War between the Galactic Republic and the reconstituted Sith Empire. It was a similar model to the YV-24 Starforged blaster rifle, and a simpler version of the YV-26 Starforged blaster rifle.
