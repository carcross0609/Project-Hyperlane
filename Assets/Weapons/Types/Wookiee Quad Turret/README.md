# Wookiee Quad Turret

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Wookiee Quad Turret](https://starwars.fandom.com/wiki/Wookiee_Quad_Turret)

A Wookiee Quad Turret or Wookiee Quadrail Launcher was a rocket system that contained a capacity for four tubes that could be fired in rapid succession. These were variable weapons in that they can either be taken by infantry or attached to vehicles to increase their firepower. This projectile launcher saw use in the Clone Wars and were created on Kashyyyk. They were occasionally outfitted with ion cannons for greater effectiveness against droids.
