# Outbreak Response blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Outbreak Response blaster rifle](https://starwars.fandom.com/wiki/Outbreak_Response_blaster_rifle)

The Outbreak Response blaster rifle was a model of blaster rifle used by the Hyland Organization for Rakghoul Neutralization during the Rakghoul pandemic, during the Galactic War between the reconstituted Sith Empire and the Galactic Republic.
