# F-4 Medium Ion Cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [F-4 Medium Ion Cannon](https://starwars.fandom.com/wiki/F-4_Medium_Ion_Cannon)

The f-4 Medium Ion Cannon was a starship ion cannon made by CoMar Combat Systems. It cost 1,500 credits, weighed one metric ton, and had an atmospheric range of three-point-six kilometers.
