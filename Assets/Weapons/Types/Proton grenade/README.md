# Proton grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Proton grenade](https://starwars.fandom.com/wiki/Proton_grenade)

Proton grenades, also called proton charges, were a type of grenade that were based on proton torpedo technology. The grenades cost 60 credits per unit. The Merr-Sonn Munitions, Inc. produced a popular model of proton grenade, as did Mesonics.

- **Name:** Proton grenade
- **Manufacturer:**

- **Type:** Grenade
