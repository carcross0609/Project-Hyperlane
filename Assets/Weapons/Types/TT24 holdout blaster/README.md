# TT24 holdout blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [TT24 holdout blaster](https://starwars.fandom.com/wiki/TT24_holdout_blaster)

TT24 holdout blaster was a make of hold-out blaster available during the Galactic Civil War between the Galactic Empire and the Alliance to Restore the Republic. During this time some agents of the Imperial Security Bureau, including supervisor Cal Alsen, used a TT24 as their primary weapon. The blasters could be set to a stun setting if needed.
