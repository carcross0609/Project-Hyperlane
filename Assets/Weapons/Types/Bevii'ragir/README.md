# Bevii'ragir

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bevii'ragir](https://starwars.fandom.com/wiki/Bevii%27ragir)

A bevii'ragir was a traditional Mandalorian hunting spear. Built strong enough to support the weight of an adult Human male, with a removable counterbalance weight located at the end opposite to the pointed tip, a bevii'ragir could function as both a dangerous weapon and a supportive walking stick.
