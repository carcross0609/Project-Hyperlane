# Micro-grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Micro-grenade](https://starwars.fandom.com/wiki/Micro-grenade)

Micro-grenades were the primary ammunition of the Relby-v10 micro grenade launcher, the weapon used by the Trandoshan bounty hunter Bossk'wassak'Cradossk. While boarding the Wookiee gunship Liswarr, Bossk fired a micro-grenade at the ship's small wroshyr tree. When the micro-grenade exploded, the tree's bark caught on fire.
