# Scout E-Web

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Scout E-Web](https://starwars.fandom.com/wiki/Scout_E-Web)

The Scout E-Web was an E-Web heavy repeating blaster cannon owned by the human Hunter Sentinel that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard E-Web. Elements of this E-Web resembled the 74-Z speeder bikes commonly utilized by Imperial scout troopers.
