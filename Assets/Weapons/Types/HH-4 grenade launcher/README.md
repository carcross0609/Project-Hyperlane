# HH-4 grenade launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [HH-4 grenade launcher](https://starwars.fandom.com/wiki/HH-4_grenade_launcher)

HH-4 grenade launchers were support units manufactured by Merr-Sonn Munitions, Inc. in use by certain smugglers and Wookiee warriors working with the Rebel Alliance during the Galactic Civil War. The launchers had a capacity of five grenades, which were set on a timer and were capable of taking out a small Imperial squad.

## Specifications

- **Name:** HH-4 grenade launcher
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** HH-4
- **Type:** Grenade launcher
- **Capacity:** 5 grenades
