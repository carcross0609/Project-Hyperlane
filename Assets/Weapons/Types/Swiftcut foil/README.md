# Swiftcut foil

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Swiftcut foil](https://starwars.fandom.com/wiki/Swiftcut_foil)

A Swiftcut foil was a foil—a type of sword—that was used by the Nagai, a warfaring species whose members favored the use of bladed weapons in combat. Along with Tehk'la blades and longswords, Swiftcut foils were employed in a number of fighting exercises that were daily customs in Nagai society. These exercises were both a form of meditation and a sign of social status; success in them could allow the victor to ascend societal ranks.
