# UR-G8 pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [UR-G8 pistol](https://starwars.fandom.com/wiki/UR-G8_pistol)

The UR-G8 pistol was a slim blaster pistol used by Wookiees. It was an unusually small weapon, mainly used by guards in areas where large weapons were considered inappropriate.
