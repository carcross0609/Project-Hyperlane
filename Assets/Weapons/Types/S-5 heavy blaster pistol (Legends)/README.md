# S-5 heavy blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [S-5 heavy blaster pistol/Legends](https://starwars.fandom.com/wiki/S-5_heavy_blaster_pistol/Legends)

The Security S-5 was a heavy blaster pistol produced by Theed Arms for the Royal Naboo Security Forces. This weapon was commonly used by members of the Security Officer Corps.

## Specifications

- **Name:** S-5 heavy blaster pistol
- **Manufacturer:** Theed Arms
- **Model:** Security S-5
- **Type:** Heavy blaster pistol and ascension gun
- **Locations:**
  - Naboo
  -   Theed Palace
- **Cost:** 1,000 to 1,250 credits
- **Size:** Medium
- **Weight:** 1.3 kg
- **Capacity:**
  - 20 shots
  - Twin scopes
  - Anesthetic (paralytic poison) microdart launcher (10 darts)
  - Stun setting
  - Liquid cable dispenser:
  -   20 meters of ascension cable (2 shots)
  -   Maximum lift of 500 kilograms
  -   Maximum range of 12 meters
- **Purpose:**
  - To scale walls
  - To put targets to sleep
- **Affiliation:**
  - Royal Naboo Security Forces
  -   Palace Guards
  -   Security Officers
