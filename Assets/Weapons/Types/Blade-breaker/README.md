# Blade-breaker

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Blade-breaker](https://starwars.fandom.com/wiki/Blade-breaker)

A blade-breaker was a small vibroblade that could catch an opponent's melee weapon. Blade-breakers were typically held in the off-hand and used in conjunction with a larger weapon, although it was possible to wield a blade-breaker in each hand. The weapons, which cost 250 credits, were usually fitted with an ultrasonic generator that was able to shatter durasteel.

## Specifications

- **Name:** Blade-breaker
- **Type:** Vibroweapon
- **Cost:** 250 credits
- **Purpose:** Melee weapon
