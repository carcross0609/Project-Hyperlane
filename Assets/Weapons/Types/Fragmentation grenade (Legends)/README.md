# Fragmentation grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Fragmentation grenade/Legends](https://starwars.fandom.com/wiki/Fragmentation_grenade/Legends)

Fragmentation grenades, also known as frag grenades, were cheap and low-damage grenades which were used mainly by military personnel, mercenaries, adventurers, and bounty hunters.

## Specifications

- **Name:** Fragmentation grenade
- **Type:** Grenade
- **Cost:** 50 credits to 200 credits (Available for military use only)
- **Size:** Hand-held
- **Weight:** 0.5 kg
- **Capacity:** Single use
- **Range:**
  - Thrown weapon
  - 3-meter to 4-meter blast radius
