# Scythe

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Scythe](https://starwars.fandom.com/wiki/Scythe)

A scythe was a melee weapon. In the Clone Wars, the LAAT/i gunship Grim Reaper had a painting of a clone trooper holding a large scythe drawn on the ship's nose. Decades later, during the reign of the First Order, Vicrul, a Knight of Ren, had a personal scythe.
