# Weequay blaster lance

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Weequay blaster lance/Legends](https://starwars.fandom.com/wiki/Weequay_blaster_lance/Legends)

The Weequay blaster lance also known as an ancient blaster rifle, long-barreled blaster rifle, or simply Weequay Rifle, was a type of exceptionally long-ranged blaster rifle native to Sriluur.
