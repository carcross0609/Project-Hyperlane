# WW-41 CryoBan grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [WW-41 CryoBan grenade/Legends](https://starwars.fandom.com/wiki/WW-41_CryoBan_grenade/Legends)

The Merr-Sonn WW-41 CryoBan grenade was a type of CryoBan grenade which used CryoBan, a chemical that absorbed heat energy, thus creating at the detonation point an area of intense cold. The CryoBan grenade was an outstanding fire suppressant, and could also be used to destroy electronic components, vehicles, and droids.

## Specifications

- **Name:** WW-41 CryoBan grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** CryoBan grenade
- **Cost:** 800 credits
- **Weight:** 0.5 kilogram
