# M-s3 concussion missile launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [M-s3 concussion missile launcher](https://starwars.fandom.com/wiki/M-s3_concussion_missile_launcher)

The M-s3 concussion missile launcher, also known as the M-s3 concussion missile and warhead launcher, was a model of concussion missile launcher manufactured by Sienar Fleet Systems. The TIE/sa tactical bomber manufactured by Sienar for the Galactic Empire was equipped with two forward-mounted M-s3s, with the bomber's missile port located at the base of the vehicle's central body beneath its sensor array and between the cockpit pod and ordnance pod.
