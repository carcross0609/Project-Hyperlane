# MS-1 ion cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MS-1 ion cannon](https://starwars.fandom.com/wiki/MS-1_ion_cannon)

The MS-1 ion cannon was a model of ion cannon manufactured by Borstel Galactic Defense. The Galactic Empire's DS-1 Death Star Mobile Battle Station was equipped with 2,500 MS-1.
