# BGA-900 Bio-Guard

**Kind:** Model  
**Continuity:** Legends  
**Source:** [BGA-900 Bio-Guard](https://starwars.fandom.com/wiki/BGA-900_Bio-Guard)

The BGA-900 Bio-Guard was a personal defense weapon manufactured by Xerithin Chemical Combinations. It fired a combination of multiple chemical agents to stop attackers.

## Specifications

- **Name:** BGA-900 Bio-Guard
- **Manufacturer:** Xerithin Chemical Combinations
- **Type:** Personnel defense device
- **Cost:** 100 credits (10 credits per ammunition load)
- **Range:** 5 meters
