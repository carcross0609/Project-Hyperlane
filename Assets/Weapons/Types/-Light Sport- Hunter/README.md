# "Light Sport" Hunter

**Kind:** Model  
**Continuity:** Legends  
**Source:** ["Light Sport" Hunter](https://starwars.fandom.com/wiki/%22Light_Sport%22_Hunter)

The "Light Sport" Hunter was a typical sporting blaster rifle. It was a well-balanced, well-built target rifle that could be used equally well right out of the case or after hanging on the wall for years. Like most sporting blaster rifles, it had a longer range but smaller punch than regular blaster rifles.
