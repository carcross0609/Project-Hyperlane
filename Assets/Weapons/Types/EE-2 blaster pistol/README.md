# EE-2 blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [EE-2 blaster pistol](https://starwars.fandom.com/wiki/EE-2_blaster_pistol)

The EE-2 blaster pistol was a model of blaster pistol used around the time of the Third Galactic War. The Mandalorian shock trooper Ri'kan Kateen used an EE-2 blaster pistol during the Showdown on Ruhnuk.
