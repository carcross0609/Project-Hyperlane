# CL-3 antistarfighter cluster bomb

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CL-3 antistarfighter cluster bomb](https://starwars.fandom.com/wiki/CL-3_antistarfighter_cluster_bomb)

The CL-3 antistarfighter cluster bomb was an anti-starfighter weapon manufactured by FreiTek Incorporated. A type of cluster bomb, the weapon was employed by the Rebel Alliance and later the New Republic. Disguised to blend in with a vessel's superstructure, the CL-3 released a burst of shrapnel in the initial detonation, followed by a cloud of magnetized grenades.
