# Arm cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Arm cannon](https://starwars.fandom.com/wiki/Arm_cannon)

An arm cannon was a cannon worn on an individual's arm. The Knight of Ren Cardo used a customized arm cannon that included a flamethrower, a repeating laser cannon, and a plasma bolt launcher.
