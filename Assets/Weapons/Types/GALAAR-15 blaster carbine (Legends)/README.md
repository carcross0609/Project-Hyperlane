# GALAAR-15 blaster carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [GALAAR-15 blaster carbine/Legends](https://starwars.fandom.com/wiki/GALAAR-15_blaster_carbine/Legends)

The GALAAR-15 was a heavy blaster carbine in production by the time of the Galactic Civil War. The origins of the carbine's name could be found in the Mandalorian language, specifically the Mando'a word galaar, which translated to "hawk" in Galactic Basic Standard.
