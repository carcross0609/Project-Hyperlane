# Smart sensor optics

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Smart sensor optics](https://starwars.fandom.com/wiki/Smart_sensor_optics)

Smart sensor optics were a type of specialized scope that utilized advanced sensors to automatically adjust for windage, distance, and movement of target. These scopes made the marksman exceptionally accurate.
