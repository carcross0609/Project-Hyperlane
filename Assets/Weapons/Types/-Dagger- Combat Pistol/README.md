# "Dagger" Combat Pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** ["Dagger" Combat Pistol](https://starwars.fandom.com/wiki/%22Dagger%22_Combat_Pistol)

The "Dagger" Combat Pistol was a slugthrower manufactured by Coruschal WeaponWorks. Like all Coruschal products, the weapon was considered to be a high quality weapon.

## Specifications

- **Name:** "Dagger" Combat Pistol
- **Manufacturer:** Coruschal WeaponWorks
- **Type:** Slugthrower
- **Cost:** 300 credits
- **Capacity:** 16 slugs
- **Range:** 60 meters
