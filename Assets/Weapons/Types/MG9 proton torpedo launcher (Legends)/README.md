# MG9 proton torpedo launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MG9 proton torpedo launcher/Legends](https://starwars.fandom.com/wiki/MG9_proton_torpedo_launcher/Legends)

The MG9 proton torpedo launcher was a model of proton torpedo launcher manufactured by Krupx Munitions. Two MG9s were installed in the Slayn & Korpil B-wing starfighter. Each launcher was capable of holding six torpedoes.

## Specifications

- **Name:** MG9 proton torpedo launcher
- **Manufacturer:** Krupx Munitions
- **Type:** Proton torpedo launcher
