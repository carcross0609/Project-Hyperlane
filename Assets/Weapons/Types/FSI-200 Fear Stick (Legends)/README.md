# FSI-200 Fear Stick

**Kind:** Model  
**Continuity:** Legends  
**Source:** [FSI-200 Fear Stick/Legends](https://starwars.fandom.com/wiki/FSI-200_Fear_Stick/Legends)

The FSI-200 Fear Stick was developed by Sabrashi Bio-Chemical Deterrents, Inc. as a self-defense weapon that appears at first to be a writing stylus. While seemingly innocuous in appearance, the fear stick contains a fast-acting nerve toxin.

## Specifications

- **Name:** FSI-200 Fear Stick
- **Manufacturer:** Sabrashi Bio-Chemical Deterrents, Inc.
- **Type:** Melee weapon
- **Culture:** Sabrashi
- **Cost:** 600 credits (50 credits per refill)
