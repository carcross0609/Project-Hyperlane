# Type 5 hunter-killer mine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Type 5 hunter-killer mine](https://starwars.fandom.com/wiki/Type_5_hunter-killer_mine)

The Type 5 hunter-killer mine was a space-based stationary drone manufactured by Imperial Munitions. Each space mine was equipped with active and passive sensors, a laser cannon, and a concussion missile launcher. The mine was controlled by a droid brain and was programmed to fire at targets not broadcasting a specific transponder code.

## Specifications

- **Name:** Type 5 hunter-killer mine
- **Manufacturer:** Imperial Munitions
- **Cost:** 1,200 credits
- **Length:** 5 meters
- **Affiliation:** Galactic Empire
