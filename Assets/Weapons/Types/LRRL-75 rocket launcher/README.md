# LRRL-75 rocket launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [LRRL-75 rocket launcher](https://starwars.fandom.com/wiki/LRRL-75_rocket_launcher)

The LRRL-75 rocket launcher was a type of rocket launcher produced by Czerka Arms by the time of the Cold War between the Galactic Republic and the reconstituted Sith Empire. The mercenary Corso Riggs owned a LRRL-75, which he named Bitsy.
