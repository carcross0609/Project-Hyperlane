# Merry Maker

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Merry Maker](https://starwars.fandom.com/wiki/Merry_Maker)

The Merry Maker was a circle shaped weapon that could cut through almost everything. If the user wore a certain glove, the Merry Maker came back when thrown.
