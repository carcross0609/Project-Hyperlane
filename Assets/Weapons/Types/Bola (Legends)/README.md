# Bola

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bola/Legends](https://starwars.fandom.com/wiki/Bola/Legends)

Bolas, also known as bolo-slings and bolos, were a type of melee weapon typically used by less-developed civilizations. The weapon consisted of weights attached to an interconnected cord.
