# XiX blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [XiX blaster pistol](https://starwars.fandom.com/wiki/XiX_blaster_pistol)

The XiX blaster pistol was a type of blaster pistol that was made by Galinolo during the Galactic Civil War. The starship racer Siro Simito owned one.
