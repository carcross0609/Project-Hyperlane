# Variable holdout blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Variable holdout blaster/Legends](https://starwars.fandom.com/wiki/Variable_holdout_blaster/Legends)

Variable holdout blasters were short-ranged holdout blasters that were popular with Rebel operatives on Ord Gimmel. The blasters could vary the strength of its shots, but this came at the cost of a smaller power pack. Each blaster cost 400 credits.

## Specifications

- **Name:** Variable holdout blaster
- **Type:** Holdout blaster
- **Locations:** Ord Gimmel
- **Cost:** 400 credits
- **Range:** Short
- **Affiliation:** Alliance to Restore the Republic
