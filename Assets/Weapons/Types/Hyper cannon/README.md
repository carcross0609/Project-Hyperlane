# Hyper cannon

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Hyper cannon](https://starwars.fandom.com/wiki/Hyper_cannon)

The hyper cannon was a superweapon capable of producing a laser that could destroy a planet or entire star systems from using the dark energy of a kyber crystal.
