# Karina (blaster rifle)

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Karina (blaster rifle)](https://starwars.fandom.com/wiki/Karina_%28blaster_rifle%29)

Karina was the name of the blaster rifle used by Johhar Kessen, ex-senator of Dandoran and big game hunter, during the Galactic Civil War. Thanks to a Magnetic Pulse Cannon attached to Karina, Kessen could fire a powerful shot that passed through multiple targets.

## Specifications

- **Name:** Karina
- **Type:** Blaster rifle
- **Owners:** Johhar Kessen
- **Size:** Two-handed weapon
- **Purpose:** Ranged combat
