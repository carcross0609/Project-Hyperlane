# SQD-1NK high intensity blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [SQD-1NK high intensity blaster](https://starwars.fandom.com/wiki/SQD-1NK_high_intensity_blaster)

The SQD-1NK high intensity blaster was a model of starship-mounted blaster cannon manufactured by Gyrhil. The Mon Calamari engineer Quarrie mounted two such blasters on his Blade Wing starfighter prototype.
