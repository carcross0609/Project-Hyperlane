# Knuckle duster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Knuckle duster](https://starwars.fandom.com/wiki/Knuckle_duster)

Knuckle dusters, also known as brass knuckles, were a type of weapon mounted on hands. The Wookiee Krrsantan owned a pair of electrified knuckle dusters. The Sixth Kin lieutenant Ariole Yu owned a pair of knuckle dusters, as did the Knight of Ren Massif.

## Specifications

- **Name:** Knuckle duster
- **Type:** Melee weapon
- **Locations:** Tatooine
- **Purpose:** Close-quarters combat
