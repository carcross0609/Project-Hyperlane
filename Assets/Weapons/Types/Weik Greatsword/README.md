# Weik Greatsword

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Weik Greatsword](https://starwars.fandom.com/wiki/Weik_Greatsword)

Weik Greatsword was a metal sword made from Weik. It permits a wielder to employ a tremendous amount of power and leverage to each swing. The greatsword required two hands to wield.
