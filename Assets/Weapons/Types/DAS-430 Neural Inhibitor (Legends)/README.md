# DAS-430 Neural Inhibitor

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DAS-430 Neural Inhibitor/Legends](https://starwars.fandom.com/wiki/DAS-430_Neural_Inhibitor/Legends)
