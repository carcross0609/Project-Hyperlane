# Smart missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Smart missile](https://starwars.fandom.com/wiki/Smart_missile)

Smart missiles were a classification of concussion missiles manufactured by Arakyd Industries. Fitted with a droid brain, smart missiles could track targets. They cost one thousand five hundred credits per missile, and could be used with the Morne-3 Concussion Missile Launcher.

## Specifications

- **Name:** Smart missile
- **Manufacturer:** Arakyd Industries
- **Type:** Concussion missile
- **Cost:** 1,500 credits
