# Flex Tube proton torpedo launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Flex Tube proton torpedo launcher](https://starwars.fandom.com/wiki/Flex_Tube_proton_torpedo_launcher)

The Flex Tube proton torpedo launcher was a proton torpedo launcher manufactured by Arakyd Industries. The BTL-A4 Y-wing assault starfighter/bomber and the BTA-NR2 Y-wing starfighter were armed with a pair of Flex Tube proton torpedo launchers.
