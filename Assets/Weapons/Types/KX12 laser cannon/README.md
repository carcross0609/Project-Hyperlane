# KX12 laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KX12 laser cannon](https://starwars.fandom.com/wiki/KX12_laser_cannon)

The KX12 laser cannon, also known as the KX12 wingtip cannon, was a type of laser cannon produced by Taim & Bak. The Incom-FreiTek Corporation T-70 X-wing starfighter was equipped with four wing-mounted KX12 cannons.
