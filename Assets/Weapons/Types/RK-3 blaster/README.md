# RK-3 blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [RK-3 blaster](https://starwars.fandom.com/wiki/RK-3_blaster)

The RK-3 blaster was a model of blaster pistol manufactured by Merr-Sonn Munitions, Inc. and later Sonn-Blas Corporation that was used by the Galactic Empire, the First Order, and crime lord Azmorigan.
