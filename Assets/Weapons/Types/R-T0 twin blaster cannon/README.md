# R-T0 twin blaster cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [R-T0 twin blaster cannon](https://starwars.fandom.com/wiki/R-T0_twin_blaster_cannon)

R-T0 twin blaster cannon were a type of blaster cannon. It was a retractable cannon that could be mounted on the aft of the ship and was designed by ArMek. They were used in Lambda-class T-4a shuttles.
