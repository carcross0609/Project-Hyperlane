# Ryyk kerarthorr

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ryyk kerarthorr](https://starwars.fandom.com/wiki/Ryyk_kerarthorr)

The Ryyk kerarthorr was a type of Ryyk blade, single-edged swords that were the traditional melee weaponary of the planet Kashyyyk's Wookiee species, who used them to cut down both thick jungle and enemies alike. The kerarthorr functioned more like a tonfa than the more standard curved machete or scythe-like Ryyk blade designs.
