# Assault cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Assault cannon](https://starwars.fandom.com/wiki/Assault_cannon)

The assault cannon was a type of blaster cannon used by the Phase II Dark Troopers of the Galactic Empire, which were being evaluated at some point between the Battle of Yavin and the Battle of Hoth. Some third-generation design Dark Troopers wielded the XS-IV Assault Cannon.

- **Name:** Assault cannon
- **Type:** Blaster cannon
