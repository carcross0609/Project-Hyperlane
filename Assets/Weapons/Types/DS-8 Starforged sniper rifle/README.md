# DS-8 Starforged sniper rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DS-8 Starforged sniper rifle](https://starwars.fandom.com/wiki/DS-8_Starforged_sniper_rifle)

The DS-8 Starforged sniper rifle was a model of blaster sniper rifle available during the Galactic War between the Galactic Republic and the reconstituted Sith Empire. It was a similar model to the DS-9 Starforged sniper rifle.
