# Grievance Striker

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Grievance Striker/Legends](https://starwars.fandom.com/wiki/Grievance_Striker/Legends)

The Grievance Striker was General Grievous's personal blaster pistol during the Clone Wars. It was later refurbished and used by N-K Necrosis during the Galactic Civil War.

## Specifications

- **Name:** Grievance Striker
- **Manufacturer:** BlasTech Industries
- **Model:** Modified DT-57 blaster
- **Type:**
  - Heavy blaster pistol
  - Blaster carbine (refurbished)
- **Owners:**
  - General Grievous
  - Treun Lorn
  - N-K Necrosis
- **Affiliation:**
  - Confederacy of Independent Systems
  - Galactic Empire
