# Electro-jabber

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Electro-jabber](https://starwars.fandom.com/wiki/Electro-jabber)

An electro-jabber was a hand-held shock device. It was similar to a stun baton, only older and more simplified. They gave the victim a violent and very painful shock.

- **Name:** Electro-jabber
