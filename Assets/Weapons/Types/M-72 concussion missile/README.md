# M-72 concussion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [M-72 concussion missile](https://starwars.fandom.com/wiki/M-72_concussion_missile)

A M-72 concussion missile was a model of concussion missile that could be launched from a starship. Upgrading an EML-850 light freighter previously equipped with M-52 concussion missiles to M-72s cost seven hundred and fifty credits and required ten units of Durasteel, and four 4XB Calculation Units.

## Specifications

- **Name:** M-72 concussion missile
- **Model:** M-72
- **Type:** Concussion missile
- **Cost:** 750 credits
