# RH8 laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [RH8 laser cannon](https://starwars.fandom.com/wiki/RH8_laser_cannon)

The RH8 laser cannon was a type of laser cannon manufactured by Borstel Galactic Defense. The EF76 Nebulon-B escort frigate manufactured by Kuat Drive Yards was equipped with twelve RH8 laser cannons.
