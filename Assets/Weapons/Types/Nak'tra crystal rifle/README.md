# Nak'tra crystal rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Nak'tra crystal rifle](https://starwars.fandom.com/wiki/Nak%27tra_crystal_rifle)

The Nak'tra crystal rifle was a type of blaster rifle. It used a specially modified Nak'tra crystal beamsplitter to increase the power of the shots that it fired, which made it a very deadly weapon.
