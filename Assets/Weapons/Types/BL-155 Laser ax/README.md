# BL-155 Laser ax

**Kind:** Model  
**Continuity:** Canon  
**Source:** [BL-155 Laser ax](https://starwars.fandom.com/wiki/BL-155_Laser_ax)

A BL-155 Laser ax was a type of ax that was utilized by Executioner troopers. It could be used to issue swift capital punishment via beheading. The axe consisted of four pairs of monomolecular energy ribbons, meant to cause severe pain upon executing victims.
