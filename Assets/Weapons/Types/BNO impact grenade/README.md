# BNO impact grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [BNO impact grenade](https://starwars.fandom.com/wiki/BNO_impact_grenade)

The BNO impact grenade was an grenade designed to explode only on impact. This function was designed as a means of preventing grenades from being thrown back at the thrower. However, a strong thrower was needed in order to toss the grenade with enough force to activate it, while at the same time known to go off accidentally if dropped on hard surfaces.

## Specifications

- **Name:** BNO impact grenade
- **Type:** Impact-activated grenade
- **Cost:** 150 credits (box of 3)
