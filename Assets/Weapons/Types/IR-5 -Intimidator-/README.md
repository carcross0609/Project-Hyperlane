# IR-5 "Intimidator"

**Kind:** Model  
**Continuity:** Legends  
**Source:** [IR-5 "Intimidator"](https://starwars.fandom.com/wiki/IR-5_%22Intimidator%22)

The IR-5 "Intimidator" was a rapid-fire blaster pistol manufactured by Merr-Sonn Munitions, Inc.. It was slightly less powerful than a standard blaster pistol, but compensated for this with a rate of fire akin to a repeating blaster and an integrated targeting computer to improve the weapon's accuracy.

## Specifications

- **Name:** IR-5 "Intimidator"
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Blaster pistol
- **Cost:** 750—1,225 credits (25 credits per power pack, 200 for retractable stock)
- **Weight:** 1 kilogram
- **Capacity:** 50
- **Range:** 50 meters
