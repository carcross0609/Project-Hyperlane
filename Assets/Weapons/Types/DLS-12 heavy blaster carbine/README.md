# DLS-12 heavy blaster carbine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DLS-12 heavy blaster carbine](https://starwars.fandom.com/wiki/DLS-12_heavy_blaster_carbine)

The DLS-12 heavy blaster carbine was the blaster carbine version of DLT-19 heavy blaster rifle that was designed for the Grand Army of the Galactic Republic during the final months of the Clone Wars by BlasTech Industries.

- **Manufacturer:** BlasTech Industries

- **Cost:** 1,350 credits
