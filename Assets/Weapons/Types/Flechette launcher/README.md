# Flechette launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Flechette launcher](https://starwars.fandom.com/wiki/Flechette_launcher)

Flechette launchers were weapons that fired flechettes. Golan Arms's FC-1 flechette launcher and the Salus Corporation's DF-D1 Duo-Flechette Rifle were both models of flechette launcher. Werth Plouth used a flechette launcher during the Night of Sorrow.

## Specifications

- **Name:** Flechette launcher
- **Type:** Launcher
- **Purpose:** Firing flechettes
