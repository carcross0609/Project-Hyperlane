# Impairment remote

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Impairment remote](https://starwars.fandom.com/wiki/Impairment_remote)

A remote was a type of explosive utilized by the Zabrak Hunter Nox within the Grand Arena on the planet Vespaara. Upon impact, these explosives would release an area of purple poison gas known as an "impairment field" which harmed, and eventually paralyzed, those who could not escape the effect radius.

- **Name:** Impairment remote
- **Type:** Bomb
- **Purpose:** Combat
- **Affiliation:** Hunters of the Outer Rim
