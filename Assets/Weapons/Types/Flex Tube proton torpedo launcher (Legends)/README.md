# Flex Tube proton torpedo launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Flex Tube proton torpedo launcher/Legends](https://starwars.fandom.com/wiki/Flex_Tube_proton_torpedo_launcher/Legends)

The Flex Tube proton torpedo launcher was a model of proton torpedo launcher manufactured by Arakyd Industries. A pair of the launchers were installed on Koensayr Manufacturing BTL Y-wing starfighter. Located beneath the cockpit, the launchers were concealed by armored doors that slid open once the pilot or weapons officer activated them. The launchers were fed from a central magazine, allowing either launcher to fire all eight loaded proton torpedoes.
