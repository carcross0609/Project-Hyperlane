# Cluster bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Cluster bomb](https://starwars.fandom.com/wiki/Cluster_bomb)

Cluster bombs were a type of bomb with which the MC30C Frigate was equipped. The weapons were fired from launchers and hung in space near frigate that had deployed them, where they became a threat to enemy starfighters.
