# Mark 3/S Medium Blaster Cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mark 3/S Medium Blaster Cannon](https://starwars.fandom.com/wiki/Mark_3/S_Medium_Blaster_Cannon)

The Mark 3/S Medium Blaster Cannon was manufactured by Merr-Sonn Munitions, Inc. It was the main weapon employed on the Imperial Repulsortank 1-L and Imperial Repulsortank 1-M.
