# D-16 blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [D-16 blaster pistol](https://starwars.fandom.com/wiki/D-16_blaster_pistol)

The D-16 blaster pistol was a model of blaster pistol. One was carried by Imperial warlord Moff Gideon on Nevarro, shooting Din Djarin in the head before shooting the power generator of the E-HOB heavy repeating laser cannon.
