# Annihilator-5 cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Annihilator-5 cannon](https://starwars.fandom.com/wiki/Annihilator-5_cannon)

The Annihilator-5 cannon was a type of portable blaster cannon produced during the Cold War between the Galactic Republic and the reconstituted Sith Empire. It had a green barrel.
