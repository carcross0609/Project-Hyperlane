# Dewback Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dewback Set](https://starwars.fandom.com/wiki/Dewback_Set)

The Dewback Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These sandy weathered weapons featured a kitbashed appearance with a black, gray, and orange color scheme, as well as tan cloth wrappings. The Arc Caster featured a two-pronged caster component and cylindrical container attached to the rear, while the Pulse Blaster possessed a drum barrel and large ribbed tube-like barrel.
