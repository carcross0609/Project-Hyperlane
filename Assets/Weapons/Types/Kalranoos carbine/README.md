# Kalranoos carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Kalranoos carbine](https://starwars.fandom.com/wiki/Kalranoos_carbine)

The Kalranoos carbine was a sonic carbine weapon developed by weapons engineer Bobor Kalranoos during the Imperial Era. It was a hybrid design that stemmed from the modifications of a Geonosian carbine. It was equipped with a bio-link module that permitted its user to be directly interfaced with the weapon.

## Specifications

- **Name:** Kalranoos carbine
- **Model:** Modified Geonosian carbine
- **Type:** Blaster carbine
- **Created:** Bobor Kalranoos
- **Owners:** Sordaan Xris
