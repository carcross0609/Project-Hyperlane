# Tof Soren Hunting Rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Tof Soren Hunting Rifle](https://starwars.fandom.com/wiki/Tof_Soren_Hunting_Rifle)

The Tof Soren Hunting Rifle, also known as the "Hunter," was a slugthrower produced in Tof Soren on Ord Vaxal.

- **Manufacturer:** Tof Soren
