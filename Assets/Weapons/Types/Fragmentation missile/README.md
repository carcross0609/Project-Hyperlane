# Fragmentation missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Fragmentation missile](https://starwars.fandom.com/wiki/Fragmentation_missile)

Fragmentation missiles, also known as frag missiles, were a type of missile designed for use against large formations of lightly armored troops. Upon detonating, fragmentation missiles would spread shrapnel around the area of impact, causing injuries to anyone in the area. Types of fragmentation missiles included the Merr-Sonn C-88 and the SoroSuub Mk XVIII Anti-Personnel Missile.
