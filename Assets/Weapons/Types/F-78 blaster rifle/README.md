# F-78 blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [F-78 blaster rifle](https://starwars.fandom.com/wiki/F-78_blaster_rifle)

The F-78 blaster rifle, also called Mimbanese blaster, was a blaster rifle produced by BlasTech Industries worth 1,200 credits. A F-78 blaster rifle, modified with a vibrobayonet, was utilized by Iasento of the Mimbanese Liberation Army. Cloud-Rider member Waydurk carried a Mimbanese blaster.
