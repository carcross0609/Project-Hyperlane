# Verpine prototype ion blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Verpine prototype ion blaster](https://starwars.fandom.com/wiki/Verpine_prototype_ion_blaster)

The Verpine prototype ion blaster was an ion blaster created by the Verpine to specifically annihilate droid enemies. The sheer amount of droids destroyed during the demonstration of this weapon increased the galaxy's uneasiness towards Verpine testing practices.
