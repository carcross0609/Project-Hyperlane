# Droid Assassin's rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Droid Assassin's rifle](https://starwars.fandom.com/wiki/Droid_Assassin%27s_rifle)

The Droid Assassin's rifle was a heavily modified disruptor rifle that was primarily used by the HK-series assassin droid during the Old Sith Wars. Some of the modifications of this weapon included improved optics, reduced recoil, extended range, and several open ports for even more modular upgrades.

## Specifications

- **Name:** Droid Assassin's rifle
- **Type:** Disruptor rifle
- **Discovered:** 3951 BBY
