# CC-V 'Legion' Cryo Projector

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CC-V 'Legion' Cryo Projector](https://starwars.fandom.com/wiki/CC-V_%27Legion%27_Cryo_Projector)

The CC-V 'Legion' Cryo Projector was a weapon that used a liquid cryo substance to cause severe freeze damage in targets. It was especially effective against heavily armored infantry units.

## Specifications

- **Name:** CC-V 'Legion' Cryo Projector
- **Manufacturer:** Ulban Corporation
- **Model:** CC-V 'Legion'
