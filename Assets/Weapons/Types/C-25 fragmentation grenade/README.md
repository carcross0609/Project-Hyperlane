# C-25 fragmentation grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [C-25 fragmentation grenade](https://starwars.fandom.com/wiki/C-25_fragmentation_grenade)

The C-25 fragmentation grenade was a fragmentation grenade manufactured by Merr-Sonn Munitions, Inc. It consisted of a sphere of baradium-impregnated detonite encased in a conductive shell, which was itself housed within a cylinder that was activated with a twist. To trigger an explosion, the C-25's user had to turn the cylindrical part of the grenade, which gave them a couple of seconds to move away before it exploded. The C-25 fragmentation grenade was visually very similar to the Sonic Imploder.
