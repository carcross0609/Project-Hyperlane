# Snare rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Snare rifle](https://starwars.fandom.com/wiki/Snare_rifle)

A snare rifle was a type of rifle that included the GRS-1 snare rifle. The bounty hunter Zuckuss owned one such weapon, which he handed over to Freerago's Satellite Diner and Motel shortly after entering around the time of the Battle of Hoth.
