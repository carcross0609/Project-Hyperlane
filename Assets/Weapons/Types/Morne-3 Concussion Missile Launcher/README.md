# Morne-3 Concussion Missile Launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Morne-3 Concussion Missile Launcher](https://starwars.fandom.com/wiki/Morne-3_Concussion_Missile_Launcher)

The Morne-3 Concussion Missile Launcher was a concussion missile launcher produced by Arakyd Industries. It cost 3,500 credits, weighed three metric tons, and had an atmospheric range of up to one and half kilometers. The Morne-3 was capable of launching dumb, smart, and savant missiles.

## Specifications

- **Name:** Morne-3 Concussion Missile Launcher
- **Manufacturer:** Arakyd Industries
- **Type:** Concussion missile launcher
- **Cost:** 3,500 credits
- **Weight:** 3 metric tons
- **Capacity:** 10
- **Range:** 1.5 kilometers (atmosphere)
