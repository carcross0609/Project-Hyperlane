# Orcon's trident

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Orcon's trident](https://starwars.fandom.com/wiki/Orcon%27s_trident)

Orcon's trident was a trident used by Orcon to control his pet devil serpent. It is unknown if the trident managed this through magical means, technology, or if the serpent was simply trained to obey the verbal commands of the wielder, whoever he might be.

- **Name:** Orcon's trident
- **Type:** Trident
- **Owners:** Orcon
