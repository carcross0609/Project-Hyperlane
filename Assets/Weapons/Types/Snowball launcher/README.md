# Snowball launcher

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Snowball launcher](https://starwars.fandom.com/wiki/Snowball_launcher)

A snowball launcher was a type of projectile launcher that fired snowballs. The Rebel troopers Kori Zaran and Oren Cole built a snowball launcher to fight cold weather assault stormtroopers during the galaxy mission.

- **Name:** Snowball launcher
- **Type:** Projectile launcher
