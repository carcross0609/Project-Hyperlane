# Machine gun

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Machine gun](https://starwars.fandom.com/wiki/Machine_gun)

A machine gun was a type of slugthrower. They fired heavy caliber slugs, and were capable of rapidly firing thousands of rounds a minute.
