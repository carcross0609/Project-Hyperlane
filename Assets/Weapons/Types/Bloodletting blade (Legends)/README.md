# Bloodletting blade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bloodletting blade/Legends](https://starwars.fandom.com/wiki/Bloodletting_blade/Legends)

Bloodletting blades were used by Tusken Raiders in clan rituals. These rituals could involve the sacrifice of animals, condemned sand people or prisoners such as Shmi Skywalker Lars.
