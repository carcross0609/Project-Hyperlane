# Magnetic pulse accelerator

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Magnetic pulse accelerator](https://starwars.fandom.com/wiki/Magnetic_pulse_accelerator)

A Magnetic pulse accelerator was a type of limited magnetic accelerator used in Tusken Cycler rifles. Magnetic pulse accelerators propelled projectiles through the barrels of these rifles, giving the rifle its range and stopping power.
