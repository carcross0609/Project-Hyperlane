# Musket

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Musket](https://starwars.fandom.com/wiki/Musket)

A musket was a pre-industrial military slugthrower weapon with slow reload time and only one round. Legendary bounty hunter Boba Fett carried a version of this weapon with him aboard his ship, Slave I.

- **Name:** Musket
- **Type:** Slugthrower
