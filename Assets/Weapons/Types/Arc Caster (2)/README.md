# Arc Caster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Arc Caster](https://starwars.fandom.com/wiki/Arc_Caster)

The Arc Caster was a type of electroshock weapon used by Utooni, a pair of Jawa brothers that participated in the Hunters of the Outer Rim tournament on Vespaara.

- **Type:** Electroshock weapon
