# Holdo's blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Holdo's blaster](https://starwars.fandom.com/wiki/Holdo%27s_blaster)

Holdo's blaster was a venerated classic Defender-5 sporting blaster used by Vice Admiral Amilyn Holdo from the Resistance. As her birth planet was Gatalenta, Holdo favored this type of blaster, as it was often carried by Gatalentan nobility.
