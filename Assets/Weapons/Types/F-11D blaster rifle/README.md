# F-11D blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [F-11D blaster rifle](https://starwars.fandom.com/wiki/F-11D_blaster_rifle)

The F-11D blaster rifle was a blaster rifle manufactured by Sonn-Blas Corporation. This ranged weapon was the successor of the older E-11 medium blaster rifle used by the Galactic Empire. It served as the standard issue weapon of First Order stormtroopers.
