# RLR-331 "Bulldog" rocket rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [RLR-331 "Bulldog" rocket rifle](https://starwars.fandom.com/wiki/RLR-331_%22Bulldog%22_rocket_rifle)

The RLR-331 "Bulldog" rocket rifle was a weapon manufactured by Kelvarek Consolidated Arms. The rifle launched small rockets from a detachable magazine. RLR-331s saw use from the Confederacy of Independent Systems, who armed their heavy-support B1-series battle droids with the weapons during the Clone Wars.

- **Manufacturer:** Kelvarek Consolidated Arms
- **Type:** Rifle

- **Range:** Long
