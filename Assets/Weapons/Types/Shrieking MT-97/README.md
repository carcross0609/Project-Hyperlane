# Shrieking MT-97

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Shrieking MT-97](https://starwars.fandom.com/wiki/Shrieking_MT-97)

The Shrieking MT-97 was a pair of MT-97 blaster pistols owned by the Mandalorian Hunter Aran Tal that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard blaster pistols. This colorful set of pistols feature a shriek-hawk sigil on the sides of each, though it is unclear if it was meant to represent Clan Vizsla or Death Watch.
