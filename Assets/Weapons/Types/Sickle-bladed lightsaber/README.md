# Sickle-bladed lightsaber

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Sickle-bladed lightsaber](https://starwars.fandom.com/wiki/Sickle-bladed_lightsaber)

The sickle-bladed lightsaber was a specialized variant of lightsaber which was wielded by the Sith Lord Darth Noctyss. Unlike more traditional lightsabers, this variant featured a curved blade, making it resemble a metal scimitar.
