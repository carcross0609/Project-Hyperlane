# Trandoshan double-blade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Trandoshan double-blade](https://starwars.fandom.com/wiki/Trandoshan_double-blade)

The Trandoshan double-blade was a bladed weapon favored by Trandoshans. Made of the metal chalon, the double blade was heavier and sharper than most melee weapons.
