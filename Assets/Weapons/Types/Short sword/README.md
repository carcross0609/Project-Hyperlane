# Short sword

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Short sword](https://starwars.fandom.com/wiki/Short_sword)

A short sword was a simple and ancient type of melee weapon, largely overlooked by contemporary warriors, but still effective in the hands of a skilled wielder. The sword could be used to parry incoming melee attacks, and was often used while wielding another weapon, as the former did not unbalance the user when held in the off-hand.
