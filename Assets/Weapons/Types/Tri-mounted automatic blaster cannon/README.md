# Tri-mounted automatic blaster cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Tri-mounted automatic blaster cannon](https://starwars.fandom.com/wiki/Tri-mounted_automatic_blaster_cannon)

A tri-mounted automatic blaster cannon was a crew mounted weapon used by the Galactic Empire. One operator would fire the weapon, while the other fed energy clips to the gun. One such cannon was employed by Captain Kolaff against a Rebel team aboard the Victory-class Star Destroyer Subjugator. The Imperial officer trapped the Rebels in a crossfire between the blaster and a squad of stormtroopers, but the insurgents were able to escape.
