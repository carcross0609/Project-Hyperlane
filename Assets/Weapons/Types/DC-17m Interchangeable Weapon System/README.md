# DC-17m Interchangeable Weapon System

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DC-17m Interchangeable Weapon System](https://starwars.fandom.com/wiki/DC-17m_Interchangeable_Weapon_System)

The DC-17m Interchangeable Weapon System, also known as the DC-17m Repeating Blaster Rifle, DC-17m ICWS Blaster Carbine, or DC-17M ICWS for short, was a type of reconfigurable repeating blaster rifle used by Republic clone commandos during the Clone Wars and the early days of the Empire. It could change between a repeating blaster rifle and grenade launcher by switching the weapon's barrel module. Other configurations included a sniper mode identified as the "Sniper Config" and an anti-armor mode known as the "Anti-Armor Config."
