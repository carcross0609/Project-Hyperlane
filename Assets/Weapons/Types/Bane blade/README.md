# Bane blade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Bane blade](https://starwars.fandom.com/wiki/Bane_blade)

Bane blades were ceremonial weapons given to every E'roni soldier during the Eiram and E'ronoh War. True to their ceremonial purpose, they were not used in combat.
