# HBt-4 hunting blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [HBt-4 hunting blaster](https://starwars.fandom.com/wiki/HBt-4_hunting_blaster)

The HBt-4 hunting blaster was a type of blaster rifle manufactured by Herloss. It was a high-powered rifle designed for big game hunting in safaris through dense tropical rainforests. The rifle was large and unwieldy, and its blaster bolts were known to lose beam cohesion quickly, but had more stopping power than almost any blaster on the unrestricted civilian market when used up close.

- **Name:** HBt-4 hunting blaster
