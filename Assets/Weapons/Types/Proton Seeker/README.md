# Proton Seeker

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Proton Seeker](https://starwars.fandom.com/wiki/Proton_Seeker)

A Proton Seeker was an explosive projectile weapon that was fired from a pistol. It had homing capabilities, allowing it to follow its designated target.
