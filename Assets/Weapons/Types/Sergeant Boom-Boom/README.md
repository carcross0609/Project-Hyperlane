# Sergeant Boom-Boom

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sergeant Boom-Boom](https://starwars.fandom.com/wiki/Sergeant_Boom-Boom)

Sergeant Boom-Boom was a weapon owned by a Human mercenary named Corso Riggs by the end of the Cold War and into the following Galactic War, fought between the Galactic Republic and the Sith Empire. While serving with a smuggler captain who worked as a privateer for the Republic, Riggs preferred using Sergeant Boom-Boom against the forces of the Empire.

## Specifications

- **Name:** Sergeant Boom-Boom
- **Created:** By 3642 BBY
- **Owners:** Corso Riggs
