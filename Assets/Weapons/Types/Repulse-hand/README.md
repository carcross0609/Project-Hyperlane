# Repulse-hand

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Repulse-hand](https://starwars.fandom.com/wiki/Repulse-hand)

The repulse-hand was a model of repulsor fist, a weaponized prosthetic, created by Control Zone Ltd. Unlike many prosthetics, the repulse-hand was not covered with the synthskin that normally gave prosthetics the appearance of a real appendage, nor was it designed with a sensory interface that would allow the user to feel through the hand as though it were real. Presentability was not a concern to the bearers of this brutish weapon.

## Specifications

- **Name:** Repulse-hand
- **Manufacturer:** Control Zone Ltd.
- **Model:** Repulsor fist
- **Owners:** Abav Ghart
