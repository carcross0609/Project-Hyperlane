# RPC-2 Rocket Launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [RPC-2 Rocket Launcher](https://starwars.fandom.com/wiki/RPC-2_Rocket_Launcher)

The RPC-2 Rocket Launcher was a class of rocket launcher that was deployed by the ARF troopers of the Galactic Republic during the Clone Wars. The rocket launchers were stored onboard their AT-RTs so they could be deployed whenever necessary.

## Specifications

- **Name:** RPC-2 Rocket Launcher
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Rocket launcher
