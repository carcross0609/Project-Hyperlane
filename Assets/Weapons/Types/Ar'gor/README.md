# Ar'gor

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ar'gor](https://starwars.fandom.com/wiki/Ar%27gor)

An ar'gor was a bladed melee weapon used during the time of the Galactic Civil War. The weapons were sold for 175 credits each by Galladinium Galactic Exports. Kassar Kosciusko, a former assassin and Rebel agent, owned an ar'gor blade.

## Specifications

- **Name:** Ar'gor
- **Manufacturer:** Ekkar Arms
- **Type:** Blade
- **Cost:** 175 credits
