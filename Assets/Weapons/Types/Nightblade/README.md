# Nightblade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Nightblade](https://starwars.fandom.com/wiki/Nightblade)

A Nightblade was a short melee weapon crafted by the natives of Utapau. It was sometimes referred to as an Utapaun Nightblade.

## Specifications

- **Name:** Nightblade
- **Type:** Knuckler
- **Creators:** Utapauns
- **Purpose:** Melee combat
