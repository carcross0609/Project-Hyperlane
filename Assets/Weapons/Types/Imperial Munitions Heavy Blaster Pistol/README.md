# Imperial Munitions Heavy Blaster Pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Imperial Munitions Heavy Blaster Pistol](https://starwars.fandom.com/wiki/Imperial_Munitions_Heavy_Blaster_Pistol)

Imperial Munitions manufactured a Heavy Blaster Pistol for use by the Imperial Military. Resembling the DL-44 heavy blaster pistol, it had an increased damage output without losing the range.

## Specifications

- **Name:** Imperial Munitions Heavy Blaster Pistol
- **Manufacturer:** Imperial Munitions
- **Type:** Heavy blaster pistol
- **Cost:** 1,250 credits; 25 credits per power pack
- **Capacity:** 25 shots
- **Range:** 50 meters
