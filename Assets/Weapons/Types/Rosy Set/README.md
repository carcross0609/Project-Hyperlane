# Rosy Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Rosy Set](https://starwars.fandom.com/wiki/Rosy_Set)

The Rosy Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These decorated weapons featured a pink, yellow, white, and gray color scheme, with various angular patterns painted across.
