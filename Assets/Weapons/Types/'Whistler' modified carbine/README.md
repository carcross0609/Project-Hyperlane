# 'Whistler' modified carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** ['Whistler' modified carbine](https://starwars.fandom.com/wiki/%27Whistler%27_modified_carbine)

The Whistler' modified carbine was a heavily modified carbine which saw use during the time of the Galactic Civil War. It fired acid filled ballistic rounds accelerated to extreme velocities. The projectiles created a distinct whistling sound as they cut through the air and their target.
