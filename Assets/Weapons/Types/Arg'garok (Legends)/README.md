# Arg'garok

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Arg'garok/Legends](https://starwars.fandom.com/wiki/Arg%27garok/Legends)

The Arg'garok was a large Gamorrean vibro-ax designed for use by beings with tremendous strength and a low center of gravity, and was used by many Gamorrean warriors. It required tremendous skill and physical strength to wield effectively. Non-Gamorreans often had great trouble using the Arg'garok and only the strongest and best-trained warriors could use it effectively.
