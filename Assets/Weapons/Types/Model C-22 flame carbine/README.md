# Model C-22 flame carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Model C-22 flame carbine](https://starwars.fandom.com/wiki/Model_C-22_flame_carbine)

The Model C-22 flame carbine was an incendiary weapon produced by Merr-Sonn Munitions, Inc.. The carbine featured an external fuel canister worn on a belt and connected to the weapon by a flexible tube.

## Specifications

- **Name:** Model C-22 flame carbine
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** Model C-22
- **Type:** Flame projector
- **Cost:** 500 credits
- **Size:** Medium
- **Weight:** 3 kg
- **Capacity:** 10 bursts
- **Range:**
  - 3 meters (optimum)
  - 7 meters (maximum)
- **Affiliation:** Corporate Sector
