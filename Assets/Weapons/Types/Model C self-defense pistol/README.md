# Model C self-defense pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Model C self-defense pistol](https://starwars.fandom.com/wiki/Model_C_self-defense_pistol)

The Model C self-defense pistol, nicknamed "Fiver" due to its five-round internal cylinder magazine, was a type of slugthrower pistol produced by Xet Industries during the Galactic Civil War and cost 200 credits.

## Specifications

- **Name:** Model C self-defense pistol
- **Manufacturer:** Xet Industries
- **Model:** Model C
- **Type:** Slugthrower pistol
- **Cost:** 200 credits
