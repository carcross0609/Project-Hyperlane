# Anti-personnel mine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Anti-personnel mine](https://starwars.fandom.com/wiki/Anti-personnel_mine)

Anti-personnel mines were small, concealed explosive devices that were capable of wiping out entire infantry squads. The mine's triggers ranged from low-tech pressure triggers that detonated the mine when stepped on, to sophisticated sensor triggers that could tell friend from foe and activate blaster bolts, gas emitters, or flame projectors. The most common land mines had laser triggers for explosive ordnance with anti-personnel shrapnel.
