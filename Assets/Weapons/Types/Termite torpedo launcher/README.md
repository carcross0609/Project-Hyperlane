# Termite torpedo launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Termite torpedo launcher](https://starwars.fandom.com/wiki/Termite_torpedo_launcher)

Termite torpedo launchers were a type of torpedo launcher that launched termite torpedos, a type of torpedo containing dozens of termite droids. They typically cost 10,000 credits on the market and notable models included the Arakyd Industries Dismantler Torpedo and the Baktoid BT-30 Termite Droid Launcher.

## Specifications

- **Name:** Termite torpedo launcher
- **Type:** Torpedo launcher
- **Cost:** 10,000 credits
- **Purpose:** Launch termite torpedos
