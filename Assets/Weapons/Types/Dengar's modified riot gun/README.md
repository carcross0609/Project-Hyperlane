# Dengar's modified riot gun

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dengar's modified riot gun](https://starwars.fandom.com/wiki/Dengar%27s_modified_riot_gun)

Dengar's modified riot gun was a riot gun modified by the bounty hunter Dengar. While riot guns were intended to disable and disperse multiple beings in an unruly crowd, Dengar changed it to target an individual.
