# DC-17 shotgun

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DC-17 shotgun](https://starwars.fandom.com/wiki/DC-17_shotgun)

The DC-17 shotgun was a type of blaster shotgun produced during the Cold War between the Galactic Republic and the reconstituted Sith Empire. It mainly consisted of a dark grey color with gold detailed outlines. It had a long boxed barrel and a small hand grip for stability while being used.
