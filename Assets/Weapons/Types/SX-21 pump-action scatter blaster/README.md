# SX-21 pump-action scatter blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [SX-21 pump-action scatter blaster](https://starwars.fandom.com/wiki/SX-21_pump-action_scatter_blaster)

The SX-21 pump-action scatter blaster, also known as the SX-21 scatterblaster, or the SX-21 blaster rifle, was a model of pump-action scatter blaster rifle made by Merr-Sonn Munitions, Inc., and proved invaluable to Imperial mudtroopers during the heavy fighting with the Mimbanese during the Mimban Campaign.
