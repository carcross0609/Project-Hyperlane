# Caltrop-5 chaff gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Caltrop-5 chaff gun](https://starwars.fandom.com/wiki/Caltrop-5_chaff_gun)

The Caltrop-5 chaff gun was a shrapnel weapon designed by Arakyd Industries. It was developed to spoof sensors, though could be used as an anti-ship weapon. Jadthu-class landing ships were equipped with the Caltrop-5, which saw use against the vulture droids of the Confederacy of Independent Systems during the Battle of Haruun Kal.
