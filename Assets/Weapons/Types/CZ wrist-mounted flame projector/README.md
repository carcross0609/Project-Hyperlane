# CZ wrist-mounted flame projector

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CZ wrist-mounted flame projector](https://starwars.fandom.com/wiki/CZ_wrist-mounted_flame_projector)

The CZ Wrist-Mounted Flame Projector was a flamethrower produced by Czerka Arms. It cost eight hundred credits when available and weighed about one kilogram. It was a thin wandlike-weapon meant to be attached to the back of a person's wrist with its fuel canister attached to the weapon by a tube. The weapon's fuel canister cost around thirty credits and was usually stored on the user's belt.
