# Lightning 22 ion grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Lightning 22 ion grenade/Legends](https://starwars.fandom.com/wiki/Lightning_22_ion_grenade/Legends)

The Lightning 22 was a model of ion grenade produced by Kirgo Blastworks during the Galactic Civil War and cost 65 credits. It could deactivate all droids caught in the blast radius.

## Specifications

- **Name:** Lightning 22 ion grenade
- **Manufacturer:** Kirgo Blastworks
- **Model:** Lightning 22
- **Type:** Ion grenade
- **Cost:** 65 credits
