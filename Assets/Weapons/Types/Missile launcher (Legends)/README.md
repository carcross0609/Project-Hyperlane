# Missile launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Missile launcher/Legends](https://starwars.fandom.com/wiki/Missile_launcher/Legends)

A missile launcher or rocket launcher was a weapon that fired an explosive projectile.

## Specifications

- **Name:** Missile launcher
- **Type:** Heavy weapon
- **Cost:** 1,500 credits (Available for military use only)
- **Size:** Large
- **Weight:** 10 kg
- **Capacity:**
  - 4 missiles
  - 3-meter blast radius
- **Range:**
  - Optimum: up to 75 meters
  - Maximum: up to 750 meters
- **Purpose:** Artillery bombardment
