# Dawnsorrow rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dawnsorrow rifle](https://starwars.fandom.com/wiki/Dawnsorrow_rifle)

The Dawnsorrow rifle was a rifle meant to provide an edge against the Tusken Raiders of Tatooine. By the time of Galactic Civil War, those weapons were no longer issued, but became highly prized.

## Specifications

- **Name:** Dawnsorrow rifle
- **Type:** Blaster rifle
- **Affiliation:** Galactic Empire
