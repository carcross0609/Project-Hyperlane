# M-IO4 ion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [M-IO4 ion missile](https://starwars.fandom.com/wiki/M-IO4_ion_missile)

A M-IO4 ion missile was a model of ion missile that could be equipped to starships. Equipping an EML-850 light freighter with a M-IO4 ion missile cost one thousand credits and required fiften units of quadranium, and seven heuristic processors.

## Specifications

- **Name:** M-IO4 ion missile
- **Model:** M-IO4
- **Type:** Ion missile
- **Cost:** 1000 credits
