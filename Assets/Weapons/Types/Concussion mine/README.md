# Concussion mine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Concussion mine](https://starwars.fandom.com/wiki/Concussion_mine)

A concussion mine was a type of space mine. It was typically deployed as an anti-starfighter measure, and used potent explosives to create shockwaves capable of breaking open starship hulls. Concussion mines were sold for 500 credits.

## Specifications

- **Name:** Concussion mine
- **Type:** Space mine
- **Cost:** 500 credits
- **Purpose:** Anti-starfighter measure
