# IQA-15 sniper rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [IQA-15 sniper rifle](https://starwars.fandom.com/wiki/IQA-15_sniper_rifle)

The IQA-15 sniper rifle was a model of sniper rifle. Company 77, a group of First Order stormtrooper defectors who resided on the ocean moon Kef Bir, owned a modified IQA-15 sniper rifle.
