# LBR-9 stun rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [LBR-9 stun rifle](https://starwars.fandom.com/wiki/LBR-9_stun_rifle)

The LBR-9 stun rifle was a type of stun blaster manufactured by BlasTech Industries, and was originally intended to be used as a sniper weapon for law enforcement and intelligence agencies. BlasTech used the DL-87 Firespray stun rifle as the LBR-9's starting point, and worked to increase the range, incorporating a longer barrel that featured an upgraded Galven-pattern, as well as a proprietary blend of blaster gases to achieve a coherent stun beam at range.

## Specifications

- **Name:** LBR-9 stun rifle
- **Manufacturer:** BlasTech Industries
- **Type:** Stun blaster
- **Cost:** 2,800 credits
- **Range:** Long-ranged
