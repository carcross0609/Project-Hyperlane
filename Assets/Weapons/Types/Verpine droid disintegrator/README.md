# Verpine droid disintegrator

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Verpine droid disintegrator](https://starwars.fandom.com/wiki/Verpine_droid_disintegrator)

The Verpine droid disintegrator was a powerful ion weapon designed by the Verpine for the destruction of droids. It was an improved version of the Verpine droid disruptor.
