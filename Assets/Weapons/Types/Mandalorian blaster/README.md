# Mandalorian blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mandalorian blaster](https://starwars.fandom.com/wiki/Mandalorian_blaster)

The Mandalorian blaster was a slightly more powerful version of the common blaster pistols used in the galaxy. Used extensively during the Mandalorian Wars, the blaster was fairly common throughout the galaxy due to the wars having taken place on so many worlds. Many of the blasters were found on the market following the end of the wars. It was believed that Bendak Starkiller's blaster was a modified version of the weapon.

## Specifications

- **Name:** Mandalorian blaster
- **Manufacturer:** Mandalorians
- **Type:** Blaster pistol
- **Range:** 23 meters
- **Affiliation:** Mandalorian Neo-Crusaders
