# Procured Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Procured Set](https://starwars.fandom.com/wiki/Procured_Set)

The Procured Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These kitbashed textured weapons featured a black, gray, and gold color scheme, with white cloth wrapped around various elements. The Arc Caster featured a silver and gold upper handle, as well as a ring secured around the barrel of the same color, while the Pulse Blaster possessed a red base and checkered pattern on the barrel. These weapons were rumored to have been created by an unidentified Anzellan.
