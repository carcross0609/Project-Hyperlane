# MG9 proton torpedo launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MG9 proton torpedo launcher](https://starwars.fandom.com/wiki/MG9_proton_torpedo_launcher)

The MG9 proton torpedo launcher, also known as MG9 emission-type proton torpedo launcher, was a proton torpedo launcher produced by Krupx. A/SF-01 B-wing starfighters were equipped with a pair of MG9 emission-type proton torpedo launchers.
