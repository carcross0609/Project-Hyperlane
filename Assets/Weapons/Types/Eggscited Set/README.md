# Eggscited Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Eggscited Set](https://starwars.fandom.com/wiki/Eggscited_Set)

The Eggscited Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These weathered weapons featured a black, gray, silver, and red color scheme, with what was apparently orange mudhorn egg yolk splattered across them.
