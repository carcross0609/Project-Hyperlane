# Kiavene

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Kiavene](https://starwars.fandom.com/wiki/Kiavene)

Kiavenes were a type of pike used by the royal guard of the Togruta regasa. A bladed melee weapon, kiavenes also had disintegrators built into them for longer-range combat.

- **Name:** Kiavene
- **Type:** Pike
- **Culture:** Togruta
