# Bacta bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Bacta bomb](https://starwars.fandom.com/wiki/Bacta_bomb)

A bacta bomb was a hand-thrown device consisting of a canister that contained a synthetic healing fluid called bacta. Upon impact, the bomb vaporized into a mist that healed those within range. Both the Galactic Empire and the Alliance to Restore the Republic used such devices during the Galactic Civil War.

- **Name:** Bacta bomb
