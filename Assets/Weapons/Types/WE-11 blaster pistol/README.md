# WE-11 blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [WE-11 blaster pistol](https://starwars.fandom.com/wiki/WE-11_blaster_pistol)

A WE-11 blaster pistol was a model of blaster pistol utilized by the Hidden Path member Tala Durith on the planet Jabiim. It had a muzzle brake that dispersed energy to counteract recoil when firing.
