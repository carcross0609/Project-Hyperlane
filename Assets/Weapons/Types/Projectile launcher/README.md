# Projectile launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Projectile launcher](https://starwars.fandom.com/wiki/Projectile_launcher)

A projectile launcher was a device equipped by starships to fire solid projectiles or other small devices like homing beacons. Slave I employed concealed projectile launchers, as did the TIE Advanced v1. Luthen Rael's Fondor Haulcraft mounted concealed twin 44-tube racks of ballistic chaff launchers which could fire explosive darts.
