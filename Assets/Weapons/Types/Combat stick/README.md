# Combat stick

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Combat stick](https://starwars.fandom.com/wiki/Combat_stick)

A combat stick was a type of handheld melee weapon. Soft-coat sticks were a type of combat stick and, while they maintained the same weight and balance as real combat sticks, were mainly used for training and sparring purposes. Between 39 BBY and 37 BBY, the Chiss cadets Mitth'raw'nuruodo, core name "Thrawn," and Irizi'ar'alani, core name "Ziara," sparred with soft-coat sticks at a dojo on the Chiss Ascendancy planet of Naporar.
