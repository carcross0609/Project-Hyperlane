# Hermit's Vigil

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Hermit's Vigil](https://starwars.fandom.com/wiki/Hermit%27s_Vigil)

The Hermit's Vigil was a type of blaster pistol available during the Cold War between the Galactic Republic and the reconstituted Sith Empire. It could be stored in a tailored holster.
