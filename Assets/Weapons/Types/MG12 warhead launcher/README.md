# MG12 warhead launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MG12 warhead launcher](https://starwars.fandom.com/wiki/MG12_warhead_launcher)

The MG12 warhead launcher, also known as the MG12 missile launcher, was a type of missile launcher that could deploy variable ordnance. Produced by Krupx, some BTA-NR2 Y-wing starfighters were equipped with a pair of these by Resistance personnel for its versatility compared to the standard Arakyd Flex Tube proton torpedo launchers.
