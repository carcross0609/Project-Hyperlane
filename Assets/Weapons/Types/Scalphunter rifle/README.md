# Scalphunter rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Scalphunter rifle](https://starwars.fandom.com/wiki/Scalphunter_rifle)

The Merr-Sonn Scalphunter rifle was an experimental blaster designed and created by the Trade Federation. It was fully automatic with collapsible stock, cortosis alloy barrel and long-range spectrum microscope.

- **Name:** Scalphunter rifle
- **Manufacturer:** Merr-Sonn Munitions, Inc.
