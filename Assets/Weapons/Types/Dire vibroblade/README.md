# Dire vibroblade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dire vibroblade](https://starwars.fandom.com/wiki/Dire_vibroblade)

The dire vibroblade was a larger version of the standard vibroblade which made it easier to wield with two hands for greater striking power. As in all vibroweapons, it used ultrasonic vibrations to increase cutting effectiveness.

## Specifications

- **Name:** Dire vibroblade
- **Type:** Vibroblade
- **Cost:** 60 credits
- **Shape:** Sword-like
- **Weight:** 2 kg
- **Affiliation:**
  - Mandalorians
  -   Mandalorian marauders
