# Dirtbomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dirtbomb](https://starwars.fandom.com/wiki/Dirtbomb)

Dirtbombs were a type of bomb filled with with metal shavings and soil native to Meddan—which contained minerals effective in scrambling sensor arrays—packed within shells. During the Imperial Era, the Zeltron criminal Samu Mavolak used a dirtbomb against the bounty hunter Boba Fett in an attempt to flee away.
