# Ascension gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ascension gun](https://starwars.fandom.com/wiki/Ascension_gun)

An ascension gun was a blaster weapon that was also able to fire a grappling hook attached to a tether, allowing the wielder to cross a horizontal gap or make a vertical climb. The S-5 Security-grade blaster/ascension gun was a model of heavy blaster pistol and ascension gun. Firing the ascension hook could also be used as a weapon, such as when the clone trooper Hardcase used it to shoot a noisy banshee during a stealthy mission on Umbara.

## Specifications

- **Name:** Ascension gun
- **Type:** Blaster pistol
- **Cost:** 500 credits
- **Purpose:**
  - To create a horizontal or vertical zipline
  - Ranged spearing weapon
