# Ax-25 blaster cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ax-25 blaster cannon](https://starwars.fandom.com/wiki/Ax-25_blaster_cannon)

The Ax-25 blaster cannon was a model of blaster cannon produced by BlasTech Industries. The C-PH patrol speeder bikes produced by the Aratech Repulsor Company for the Galactic Empire were equipped with a single forward fixed Ax-25.
