# Micro-rocket launcher pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Micro-rocket launcher pistol](https://starwars.fandom.com/wiki/Micro-rocket_launcher_pistol)

Micro-rocket launcher pistols were weapons that were built with the purpose of firing micro-rockets. The pistols cost 500 credits and were able to carry three micro-rockets at a time. The pistols' powerful pistons fired the micro-rocket with enough speed to double its ordinary range.

## Specifications

- **Name:** Micro-rocket launcher pistol
- **Cost:** 500 credits
