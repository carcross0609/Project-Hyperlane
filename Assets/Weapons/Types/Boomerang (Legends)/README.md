# Boomerang

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Boomerang/Legends](https://starwars.fandom.com/wiki/Boomerang/Legends)

A boomerang was an object that was popular on many backwaters of the galaxy. A handcrafted weapon favored by hunters and trappers on Auratera, it required some skill to throw correctly. When used properly, the boomerang would strike a target or spin around mid-air and return to the user. Once retrieved, a boomerang could be reused indefinitely until lost or damaged.

## Specifications

- **Name:** Boomerang
- **Model:** Handcrafted
- **Locations:** Auratera
- **Range:** Medium
