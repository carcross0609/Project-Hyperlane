# Proximity bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Proximity bomb](https://starwars.fandom.com/wiki/Proximity_bomb)

Proximity bombs were explosive charges used by soldiers during the Galactic Civil War. The bombs were set as traps and went off when an enemy was detected. They were visually similar to detonite charges, and operated similarly to anti-personnel mines.

- **Name:** Proximity bomb
- **Type:** Bomb
