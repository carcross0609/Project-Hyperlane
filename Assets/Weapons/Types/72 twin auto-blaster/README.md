# 72 twin auto-blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [72 twin auto-blaster](https://starwars.fandom.com/wiki/72_twin_auto-blaster)

The 72 twin auto-blaster was an auto-blaster manufactured by Gyrhil. B-wing starfighters had a single 72 twin auto-blaster under the cockpit, with some carrying a second pair in the optional mount next to it. The auto-blaster was capable of automatically firing on enemy targets, but many pilots chose to turn off this capability and directly control the weapon themselves.
