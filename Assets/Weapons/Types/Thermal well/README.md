# Thermal well

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Thermal well](https://starwars.fandom.com/wiki/Thermal_well)

The Thermal well was a sabotage and demolition device created for Alliance Special Forces. It used baradium mixed with ytterbium to produce a more stabilized device that would ignite when energized rather than explode. The resulting thermal reaction could melt through five meters of permacrete in a matter of seconds.

- **Type:** Baradium meltdown device
