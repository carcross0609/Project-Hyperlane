# ST-M40 heavy repeating blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [ST-M40 heavy repeating blaster pistol](https://starwars.fandom.com/wiki/ST-M40_heavy_repeating_blaster_pistol)
