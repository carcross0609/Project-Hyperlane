# Dye grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dye grenade](https://starwars.fandom.com/wiki/Dye_grenade)

Dye grenades were a type of grenade that released billowing clouds when detonated. Similar in use to smoke grenades, dye grenades were used to mark landing zones for incoming vessels, as well as obscuring the vision of enemy forces.

## Specifications

- **Name:** Dye grenade
- **Type:** Grenade
- **Purpose:**
  - Marking locations
  - Obscuring vision of enemy soldiers
