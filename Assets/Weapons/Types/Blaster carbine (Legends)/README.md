# Blaster carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blaster carbine/Legends](https://starwars.fandom.com/wiki/Blaster_carbine/Legends)

A blaster carbine was a shortened variant of an already existing weapon, traditionally blaster rifles. An individual who specialized at using carbines was known as a carbineer.

## Specifications

- **Name:** Blaster carbine
- **Type:** Blaster rifle
- **Cost:**
  - 850 credits without retractable stock
  - 900 credits with retractable stock
- **Size:**
  - One-handed weapon with stock folded
  - Two-handed weapon with stock extended
- **Weight:** 2.2 kg
- **Capacity:**
  - 50 shots
  - Close-range stun setting available
  - Autofire mode available
- **Range:**
  - Optimum: up to 45 m
  - Maximum: up to 225 m
