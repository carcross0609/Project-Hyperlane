# Deceiver Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Deceiver Set](https://starwars.fandom.com/wiki/Deceiver_Set)

The Deceiver Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These weapons featured a black, gray, and gold color scheme, wrapped in brown, white, and black straps and rope with dangling bits that had a bone-like appearance.
