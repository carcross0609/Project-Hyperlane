# Twin DF.9

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Twin DF.9](https://starwars.fandom.com/wiki/Twin_DF.9)

The Twin DF.9 was a variant of the DF.9 turret placement, manufactured by Golan Arms. It was equipped with two laser cannons and an advanced weapons system. It could fire twice as fast as the original DF.9.
