# GA-60s double laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [GA-60s double laser cannon](https://starwars.fandom.com/wiki/GA-60s_double_laser_cannon)

The GA-60s double laser cannon, also known as the GA-60s twin rotating blaster cannon was a type of blaster cannon manufacted by Taim & Bak. The Lambda-class T-4a shuttle had a GA-60s twin rotating blaster cannon on both of its foldable wings as had Scythe shuttles.
