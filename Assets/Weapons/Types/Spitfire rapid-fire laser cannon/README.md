# Spitfire rapid-fire laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Spitfire rapid-fire laser cannon](https://starwars.fandom.com/wiki/Spitfire_rapid-fire_laser_cannon)

The Spitfire rapid-fire laser cannon was a type of rapid-fire laser cannon developed by BlasTech Industries by the time of the Galactic War between the Galactic Republic and the reconstituted Sith Empire. The Spitfire had a particularly low power consumption, allowing for a massive number of bolts per second for a sustained period of time, though it was only effective in short-range engagements.
