# Single Dose

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Single Dose](https://starwars.fandom.com/wiki/Single_Dose)

"Single Dose" was a highly experimental sniper rifle developed by Czerka Arms during the Third Galactic War. Merely obtaining the weapon required signing a waiver.
