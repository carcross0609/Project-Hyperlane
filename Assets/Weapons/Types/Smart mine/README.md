# Smart mine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Smart mine](https://starwars.fandom.com/wiki/Smart_mine)

Smart mines were a type of space-based mine that could move to track targets. The Gobreton minefield, containing smart mines, was used by Yrica Quell's Alphabet Squadron for training and target practice. The Galactic Empire's 204th Imperial Fighter Wing deployed a minefield of smart mines in the Pandem Nai system to protect their forces on the planet Pandem Nai.
