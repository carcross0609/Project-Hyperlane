# Heavy Lightning Rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Heavy Lightning Rifle](https://starwars.fandom.com/wiki/Heavy_Lightning_Rifle)

The Heavy Lightning Rifle was a custom-crafted weapon that emitted an intense, cohesive blast of electrical energy. More powerful and more accurate than the basic Lightning Rifle, it was favored by bounty hunters.

- **Name:** Heavy Lightning Rifle
- **Type:** Electroshock rifle
