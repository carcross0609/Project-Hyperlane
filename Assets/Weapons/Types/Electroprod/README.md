# Electroprod

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electroprod](https://starwars.fandom.com/wiki/Electroprod)

The electroprod was an electrical melee weapon. The DX-90 electroprod was carried by the electroprod troopers, specialized stormtroopers of the First Order, who operated during the First Order's war against the Resistance.
