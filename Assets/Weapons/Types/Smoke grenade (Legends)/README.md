# Smoke grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Smoke grenade/Legends](https://starwars.fandom.com/wiki/Smoke_grenade/Legends)

Smoke grenades or smoke bombs were a type of grenade that released clouds of thick smoke to obscure the vision of enemies.

## Specifications

- **Name:** Smoke grenade
- **Type:** Grenade
- **Cost:** 100 credits
- **Size:** Hand-held
- **Weight:** 0.5 kg
- **Capacity:**
  - Single-use
  - Smoke lasted for one minute
- **Range:**
  - Thrown weapon range
  - 3-meter blast radius
- **Purpose:**
  - Marking landing zones
  - Obscuring the vision of enemies
  - Signaling
