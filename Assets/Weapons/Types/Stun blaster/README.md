# Stun blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Stun blaster](https://starwars.fandom.com/wiki/Stun_blaster)

Stun blasters were a type of blaster capable of stunning targets. Models of stun blaster included the LBR-9 stun rifle manufactured by BlasTech Industries and the Deck Sweeper Stun Blaster manufactured by Merr-Sonn Munitions, Inc. Cybot Galactica's WSW Mk III "Harrier" Combat Remote had built in stun blasters that could be used when training with the remotes. The weapon could be stripped down to make a stun blaster attachment for the hilt of a lightsaber, allowing the wielder to user the weapon as a blaster and conceal its true nature.
