# Yiv's gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Yiv's gun](https://starwars.fandom.com/wiki/Yiv%27s_gun)

Yiv's gun was owned by the Nikardun General Yiv, leader of the Unknown Regions Nikardun Destiny nation. In 19 BBY, Yiv attempted to shoot the Chiss Senior Captain Mitth'raw'nuruodo, core name "Thrawn," with the weapon aboard the Nikardun Battle Dreadnought Deathless. However, Thrawn removed the gun from the general's hand and released tava gas, which caused Yiv to pass out, allowing the Chiss to capture him.
