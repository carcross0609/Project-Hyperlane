# Slugthrower pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Slugthrower pistol](https://starwars.fandom.com/wiki/Slugthrower_pistol)

Slugthrower pistols were a type of slugthrower weapon that generally fired standard rounds. Czerka Arms' M9 "Boomer" heavy pistol was a model of slughthrower pistol available during the Galactic Civil War that fired fin-stabilized grenades rather than rounds. The Panic Pistol was another type of slugthrower pistol.
