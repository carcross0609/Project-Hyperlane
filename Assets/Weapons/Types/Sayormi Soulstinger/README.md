# Sayormi Soulstinger

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sayormi Soulstinger](https://starwars.fandom.com/wiki/Sayormi_Soulstinger)

The Sayormi Soulstinger was a Sayormi melee weapon developed for the personal use of the Sayormi Queen. Capable of destroying armors, it was more powerful than the Sayormi Heartstriker.

## Specifications

- **Name:** Sayormi Soulstinger
- **Type:** Knuckler
- **Culture:** Sayormi
- **Owners:** Sayormi Queen
- **Purpose:** Melee combat
