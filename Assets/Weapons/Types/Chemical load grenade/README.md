# Chemical load grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Chemical load grenade](https://starwars.fandom.com/wiki/Chemical_load_grenade)

Highly versatile, chemical load grenades could be used for many different purposes. Each carrying a specific type of chemical within, their contents ranged from lethal Fex-M3 nerve gas to plank gas, an airborne chemical which broke down mechanical objects. Some types were reusable and could carry multiple payloads.

## Specifications

- **Name:** Chemical load grenade
- **Manufacturer:** Czerka Arms
- **Type:** Grenade
- **Cost:**
  - Varies by load:
  - 650 credits (Agent T-238)
  - 1050 credits (Fex-M3)
  - 850 credits (Plank Gas)
  - 150 credits (Smoke)
- **Size:** Tiny
- **Weight:** 0.5 kg
