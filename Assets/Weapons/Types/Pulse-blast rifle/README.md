# Pulse-blast rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Pulse-blast rifle](https://starwars.fandom.com/wiki/Pulse-blast_rifle)

The pulse-blast rifle was the predecessor of pulse-wave weapons and the modern blaster. It emitted a constant low hum when loaded and was erratic at longer ranges.

## Specifications

- **Name:** Pulse-blast rifle
- **Manufacturer:** Core World Arms
- **Type:** Blaster rifle
- **Cost:** 2,000 credits
- **Size:** Medium
- **Weight:** 5 kg
