# Relby-v10 micro grenade launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Relby-v10 micro grenade launcher/Legends](https://starwars.fandom.com/wiki/Relby-v10_micro_grenade_launcher/Legends)

The Relby-v10 micro grenade launcher was a highly destructive blaster/mortar weapon modified from the BlasTech Industries CSPL-12 projectile launcher. It was commonly referred to simply as a Mortar Gun.
