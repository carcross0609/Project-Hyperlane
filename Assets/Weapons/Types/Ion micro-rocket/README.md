# Ion micro-rocket

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ion micro-rocket](https://starwars.fandom.com/wiki/Ion_micro-rocket)

Ion micro-rockets were a class of micro-rocket that released an ion pulse that could disable machinery. The rockets typically sold for 100 credits. Ion micro-rockets made use of small warheads, and as a result usually could affect just one target.

## Specifications

- **Name:** Ion micro-rocket
- **Type:** Micro-rocket
- **Cost:** 100 credits
