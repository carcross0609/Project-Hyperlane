# Forward Commander Carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Forward Commander Carbine](https://starwars.fandom.com/wiki/Forward_Commander_Carbine)

The Forward Commander Carbine was a carbine weapon used by the Forward Commander Mk II, one of HK-47's battle droids on the planet Mustafar. It closely resembled the Bothan Bola carbine.

## Specifications

- **Name:** Forward Commander Carbine
- **Type:** Blaster carbine
- **Owners:** Forward Commander Mk II
- **Locations:** Mustafar
- **Affiliation:** HK-47
