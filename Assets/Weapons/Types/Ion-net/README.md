# Ion-net

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ion-net](https://starwars.fandom.com/wiki/Ion-net)

An ion-net was an expensive type of electrified net that could be used to incapacitate droids. The hunters Nokk and Winloss purchased a singular ion-net, and intended to use it to capture the assassin droid 0-0-0, but were forced to use it against BT-1.

## Specifications

- **Name:** Ion-net
- **Locations:** Milvayne
- **Purpose:** Deactivating droids
