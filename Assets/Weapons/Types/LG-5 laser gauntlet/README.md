# LG-5 laser gauntlet

**Kind:** Model  
**Continuity:** Legends  
**Source:** [LG-5 laser gauntlet](https://starwars.fandom.com/wiki/LG-5_laser_gauntlet)

The LG-5 was a set of matching gauntlets, one of which had a small, powerful laser in it. Users could get a second laser in the other gauntlet for double the price. It was designed to fire along the back of the first finger. A popular modification was to remove the firing elements from an LG-5 and mount them in other hand wear.
