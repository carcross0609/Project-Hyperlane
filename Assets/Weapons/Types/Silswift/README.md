# Silswift

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Silswift](https://starwars.fandom.com/wiki/Silswift)

The silswift was an older form of the silspar sword that was intended for lighter-weight warriors and children used by the Silinese on the planet Siline.
