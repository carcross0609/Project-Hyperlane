# Vershyi Sharpshooter

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Vershyi Sharpshooter](https://starwars.fandom.com/wiki/Vershyi_Sharpshooter)

The Vershyi Sharpshooter was a long-range blaster rifle built by the Vershyi Corporation for military use. It was said that the Sharpshooter combined the best Vershyi had to offer in scope, power output and barrels. Few rifles could compare with this model.

## Specifications

- **Name:** Vershyi Sharpshooter
- **Manufacturer:** Vershyi Corporation
- **Type:** Blaster rifle
