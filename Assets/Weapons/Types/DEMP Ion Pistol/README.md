# DEMP Ion Pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DEMP Ion Pistol](https://starwars.fandom.com/wiki/DEMP_Ion_Pistol)

The Merr-Sonn Munitions, Inc. DEMP Ion Pistol was designed as a infantry support weapon for the Imperial Army. It is the predecessor to the more known DEMP 2 which built on the same principles.

## Specifications

- **Name:** DEMP Ion Pistol
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** DEMP gun
- **Cost:** 250–500 credits
- **Weight:** 1 kilogram
- **Capacity:** 10
- **Range:**
  - 3–10 meters
  - 11–30 meters
  - 31–120 meters
- **Purpose:** Anti-droid electromagnetic pulse weapon
