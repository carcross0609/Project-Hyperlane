# Ceremonial bowcaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ceremonial bowcaster](https://starwars.fandom.com/wiki/Ceremonial_bowcaster)

The Ceremonial bowcaster was a specialized bowcaster developed by the Wookiees to be used in ceremonial hunts. It was considered an impressive weapon for its time that did not require any further improvements.

- **Name:** Ceremonial bowcaster
- **Type:** Bowcaster
