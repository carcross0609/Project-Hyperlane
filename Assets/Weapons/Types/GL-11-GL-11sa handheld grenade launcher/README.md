# GL-11/GL-11sa handheld grenade launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [GL-11/GL-11sa handheld grenade launcher](https://starwars.fandom.com/wiki/GL-11/GL-11sa_handheld_grenade_launcher)

The GL-11 was a handheld grenade launcher that was designed to work with the Merr-Sonn family of grenades. It featured a blaster rifle stock with a chopped launcher barrel. The GL-11 fired C-16 fragmentation grenades, while the GL-11s fired C-10 stun grenades.

- **Name:** GL-11/GL-11sa handheld grenade launcher

- **Model:** GL-11
