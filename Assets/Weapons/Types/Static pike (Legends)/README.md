# Static pike

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Static pike/Legends](https://starwars.fandom.com/wiki/Static_pike/Legends)

The Geonosian static pike, also known as the picador's spear or simply static pike, was a melee weapon used by Geonosian Picadors and produced by Gordarl Weaponsmiths on Geonosis.

## Specifications

- **Name:** Static pike
- **Manufacturer:** Gordarl Weaponsmiths
- **Model:** Picador's spear
- **Type:** Electrical melee weapon
- **Culture:** Geonosian Picadors
- **Locations:** Petranaki arena
- **Cost:** 300 to 650 credits
- **Shape:** Long-handled spear
- **Weight:** 1.5kg to 1.8kg
- **Range:**
  - 4 meters melee range
  - Thrown weapon range
- **Purpose:**
  - Combat
  - Herding animals
