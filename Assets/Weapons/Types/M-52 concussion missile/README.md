# M-52 concussion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [M-52 concussion missile](https://starwars.fandom.com/wiki/M-52_concussion_missile)

The M-52 concussion missile was a model of concussion missile that could be launched from starships. In 3 ABY, the Trailblazer, an EML-850 light freighter, was equipped with M-52 concussion missiles when the thief Kay Vess stole it from the Imperial Security Bureau Director Sliro Barsha's Westhill Palace in the city of Canto Bight on the planet Cantonica.
