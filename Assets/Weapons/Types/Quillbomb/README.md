# Quillbomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Quillbomb](https://starwars.fandom.com/wiki/Quillbomb)

Quillbombs were grenades that were created by engineers, and inspired by the Ystervark, a creature found on the planet Thisspias. During the Imperial Era, the Galactic Empire despised the weapon, which made it popular amongst the Rebel Alliance. Per unit, each grenade cost 100 credits.

## Specifications

- **Name:** Quillbomb
- **Type:** Grenade
- **Cost:** 100 credits
- **Affiliation:** Alliance to Restore the Republic
