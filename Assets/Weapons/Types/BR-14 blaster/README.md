# BR-14 blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [BR-14 blaster](https://starwars.fandom.com/wiki/BR-14_blaster)

The BR-14 blaster was a type of blaster pistol used by Jedi Master Obi-Wan Kenobi during the Imperial Era. The blaster had a blaster cartridge that was front loaded with ionized particles.
