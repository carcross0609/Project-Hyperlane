# CM-2 Arana cluster missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [CM-2 Arana cluster missile](https://starwars.fandom.com/wiki/CM-2_Arana_cluster_missile)

A CM-2 Arana cluster missile was a model of cluster missile that could be launched from a starship and could lock onto multiple targets. Upgrading an EML-850 light freighter previously equipped with M-72 concussion missiles to CM-2 Arana missiles cost two thousand credits and required a X-FP-C28 ship computer, twenty units of quadanium steel, and eight enhanced durasteel hulls.

## Specifications

- **Model:** CM-2 Arana
- **Type:** Cluster missile
- **Cost:** 2000 credits
