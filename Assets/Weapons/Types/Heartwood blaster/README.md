# Heartwood blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Heartwood blaster](https://starwars.fandom.com/wiki/Heartwood_blaster)

The heartwood blaster was a type of blaster created by Tholothian Defense Forces. Made of heartwood, these weapons served as a reminder of Tholothian community.

## Specifications

- **Name:** Heartwood blaster
- **Manufacturer:** Tholothian Defense Forces
- **Type:** Blaster
- **Created:** Final days of the Clone Wars
- **Cost:** 1,000 credits
- **Material:** Heartwood
- **Range:** Medium-ranged
