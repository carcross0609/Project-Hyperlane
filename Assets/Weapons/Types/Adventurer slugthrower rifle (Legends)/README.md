# Adventurer slugthrower rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Adventurer slugthrower rifle/Legends](https://starwars.fandom.com/wiki/Adventurer_slugthrower_rifle/Legends)

The Czerka Adventurer was an accurate long-barreled slugthrower rifle. Manufactured by Czerka Arms, it was somewhat more advanced than the Czerka 6-2Aug2 hunting rifle as it included an oxidizer release module which increased the bullet's velocity.

## Specifications

- **Name:** Adventurer slugthrower rifle
- **Manufacturer:** Czerka Arms
- **Type:** Slugthrower rifle
- **Culture:** Bounty hunters
- **Cost:** 360 credits
- **Shape:** Rifle-shaped
- **Size:** Two-handed weapon
- **Weight:** 4 kg
- **Capacity:** 50 shots
- **Range:**
  - Optimum: up to 90 m
  - Maximum: up to 450 m
