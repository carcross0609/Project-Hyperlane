# Cluster bomb (ground)

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Cluster bomb (ground)](https://starwars.fandom.com/wiki/Cluster_bomb_%28ground%29)

Cluster bombs were a type of explosive projectile utilized by the Ewok Hunter Pilbush within the Grand Arena on the planet Vespaara. These bombs could be fired from the grenade launcher equipped to Pilbush's custom All Terrain Ewok Transport. Upon impact, the primary projectile would detonate, scattering smaller bombs across the surrounding area, which would then individually detonate, dealing a wide area of devastation.
