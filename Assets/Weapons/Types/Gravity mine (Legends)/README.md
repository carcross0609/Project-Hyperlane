# Gravity mine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Gravity mine/Legends](https://starwars.fandom.com/wiki/Gravity_mine/Legends)

A gravity mine, or interdiction mine, was a type of mine used to create a mass shadow for hyperspace interdiction purposes.

## Specifications

- **Name:** Gravity mine
- **Purpose:** Interdiction of starships
- **Affiliation:**
  - Galactic Empire
  -   Imperial Hyperspace Security Net
  -   Imperial Navy
  - Darth Krayt's Galactic Empire
