# L-13 cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [L-13 cannon](https://starwars.fandom.com/wiki/L-13_cannon)

The L-13 cannon was a model of rapid fire light plasma cannon that could be equipped to starships. In 3 ABY, the Rokana Raiders flew R93 refractor starfighters that were equipped with modified L-13 cannons. When the pirate fighters were flown in recon mode the two L-13 cannons were their primary weaponry. However the fighters could enter an assault mode with their NA-7 flight system during which the L-13 cannons would alternate fire with wing mounded M-19 cannons.
