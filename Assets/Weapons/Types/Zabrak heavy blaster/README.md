# Zabrak heavy blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Zabrak heavy blaster](https://starwars.fandom.com/wiki/Zabrak_heavy_blaster)

The Zabrak heavy blaster was a more cumbersome version of the Zabrak blaster pistol. This version was known to be even more damaging to its targets.

## Specifications

- **Name:** Zabrak heavy blaster
- **Manufacturer:** Zabraks
- **Type:** Heavy blaster pistol
