# Sunstar-imbued cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sunstar-imbued cannon](https://starwars.fandom.com/wiki/Sunstar-imbued_cannon)

The Sunstar-imbued cannon was, according to Doctor Raygar, the most powerful weapon in the universe. Raygar constructed it using the legendary Sunstar.
