# ST2 concussion missile tube

**Kind:** Model  
**Continuity:** Canon  
**Source:** [ST2 concussion missile tube](https://starwars.fandom.com/wiki/ST2_concussion_missile_tube)

The ST2 concussion missile tube was a concussion missile launcher developed by Arakyd Industries. The customized YT-1300f light freighter Millennium Falcon carried two of these tubes, which Han Solo modified to carry up to four missiles from a variety of manufacturers, including Arakyd and Dymek.

## Specifications

- **Name:** ST2 concussion missile tube
- **Manufacturer:** Arakyd Industries
- **Type:** Concussion missile launcher
- **Capacity:** 4 missiles
