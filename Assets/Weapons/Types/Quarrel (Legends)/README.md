# Quarrel

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Quarrel/Legends](https://starwars.fandom.com/wiki/Quarrel/Legends)

Quarrels were a secondary type of ammunition for a bowcaster and the DC-17m Interchangeable Weapon System's sniper mode. The beam emitted from the components near the stock energized the quarrel. The twin polarizers would then magnetically accelerate the energized quarrel out of the bow. The quarrel would ultimately explode upon impact with a target. It resembled an elongated laser bolt when fired because it was wrapped in an energy envelope that channeled the quarrel's explosive force into the target.
