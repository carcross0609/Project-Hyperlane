# G-20 Glop grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [G-20 Glop grenade/Legends](https://starwars.fandom.com/wiki/G-20_Glop_grenade/Legends)

The Merr-Sonn G-20 Glop grenade was a personal explosive that used high-pressure jets to spray an extremely strong adhesive foam over a ten-meter area, trapping anyone within the area at detonation.

## Specifications

- **Name:** G-20 Glop grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Adhesive grenade
- **Cost:** 100—600 credits
- **Weight:** 0.5 kilograms
- **Range:** Short
- **Affiliation:** Corporate Sector Authority
