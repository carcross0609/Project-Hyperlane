# Endor Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Endor Set](https://starwars.fandom.com/wiki/Endor_Set)

The Endor Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These bulky weathered weapons featured a green, black, blue, gold, and silver color scheme, with various glowing orangish-yellow elements, yellow and red decal designs, and small green leaves protruding from different areas. The Arc Caster also featured a brown handle and a pin on the stock, while the Pulse Blaster possessed rusted components on the barrel.
