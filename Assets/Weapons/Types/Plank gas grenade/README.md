# Plank gas grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Plank gas grenade](https://starwars.fandom.com/wiki/Plank_gas_grenade)

A plank gas grenade was a type of gas grenade that was filled with plank gas, a corrosive chemical. Plank gas grenades were effective at destroying defensive structures.

## Specifications

- **Name:** Plank gas grenade
- **Type:** Grenade
- **Purpose:** Deploy plank gas in combat
