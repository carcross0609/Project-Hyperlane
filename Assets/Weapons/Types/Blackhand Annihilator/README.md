# Blackhand Annihilator

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blackhand Annihilator](https://starwars.fandom.com/wiki/Blackhand_Annihilator)

The Blackhand Annihilator was a slugthrower pistol typically used among scoundrels and outcasts that was developed for use during the Clone Wars. As the developement came too late, it only saw limited use during that conflict. However, it later saw some military use during the time of the Galactic Civil War.

## Specifications

- **Name:** Blackhand Annihilator
- **Type:** Blaster pistol
- **Range:** 35 meters
