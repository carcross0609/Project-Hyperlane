# Turbolaser System I

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Turbolaser System I](https://starwars.fandom.com/wiki/Turbolaser_System_I)

The Turbolaser System I was a type of heavy turbolaser emplacement that was manufactured by Loronar Corporation.

## Specifications

- **Name:** Turbolaser System I
- **Manufacturer:** Loronar Defense Industries
- **Type:** Heavy fixed turbolaser emplacement
- **Cost:**
  - 250,000 credits (new)
  - 125,000 credits (used)
- **Protection:** Permacite casing
- **Crew:** 5
- **Capacity:** Unlimited (Boron fission reactor)
- **Range:**
  - 50–600 meters (short range)
  - 601–5,000 meters (medium range)
  - 5,001–25,000 meters (long range)
  - 10 meter blast radius
