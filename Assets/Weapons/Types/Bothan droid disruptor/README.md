# Bothan droid disruptor

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bothan droid disruptor](https://starwars.fandom.com/wiki/Bothan_droid_disruptor)

The Bothan droid disruptor was a weapon crafted by the Bothans for use by their espionage agents who might face droid guards. These weapons made quick work of any droid obstacles by having the ability to penetrate some defenses that blaster fire could not.
