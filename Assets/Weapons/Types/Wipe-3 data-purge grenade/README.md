# Wipe-3 data-purge grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Wipe-3 data-purge grenade](https://starwars.fandom.com/wiki/Wipe-3_data-purge_grenade)

The Wipe-3 data-purge grenade manufactured by SoroSuub Corporation was a type of grenade capable of erasing data stored on all devices within its blast radius with a brief, but intense, electromagnetic pulse. Individuals and organizations that wished to keep their data out of enemy hands made use of similar technology.

## Specifications

- **Name:** Wipe-3 data-purge grenade
- **Manufacturer:** SoroSuub Corporation
- **Type:** Grenade
- **Cost:** 100 credits
- **Purpose:** Erase stored data from devices
- **Affiliation:** Galactic Empire
