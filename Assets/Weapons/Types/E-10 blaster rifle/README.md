# E-10 blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [E-10 blaster rifle](https://starwars.fandom.com/wiki/E-10_blaster_rifle)

The E-10 blaster rifle was a model of blaster rifle manufactured by BlasTech Industries used by Imperial Army troopers and Imperial Stormtroopers of the Galactic Empire. It was equipped with a glow rod for low-light vision.
