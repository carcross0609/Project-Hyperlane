# Electro-prod staff

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro-prod staff](https://starwars.fandom.com/wiki/Electro-prod_staff)

An electro-prod staff was a type of electrostaff. One of these weapons was owned by Beezer Fortuna, who carried it on a strap during his time with Saw Gerrera's Partisans on Jedha.
