# X-86 rocket launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [X-86 rocket launcher](https://starwars.fandom.com/wiki/X-86_rocket_launcher)

The X-86 rocket launcher was a model of single-use disposable rocket launcher in use during the Cold War. House Ulgo of the planet Alderaan used a number of X-86 launchers.

## Specifications

- **Name:** X-86 rocket launcher
- **Type:** Rocket launcher
- **Capacity:** 1 rocket
