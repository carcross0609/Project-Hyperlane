# F-2 Light Ion Cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [F-2 Light Ion Cannon](https://starwars.fandom.com/wiki/F-2_Light_Ion_Cannon)

The f-2 Light Ion Cannon was a starship ion cannon made by CoMar Combat Systems. It cost 1,000 credits, weighed half a metric ton, and had an atmospheric range of three-point-six kilometers.

## Specifications

- **Name:** f-2 Light Ion Cannon
- **Manufacturer:** CoMar Combat Systems
- **Type:** Ion cannon
- **Cost:** 1,000 credits
- **Weight:** 0.5 metric tons
- **Range:** 3.6 kilometers (atmosphere)
- **Purpose:** Starship-mounted weapon
