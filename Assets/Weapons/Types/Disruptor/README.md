# Disruptor

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Disruptor](https://starwars.fandom.com/wiki/Disruptor)

Disruptors were a type of particularly dangerous energy weapon which was banned by Imperial law, as well as Rebel Alliance regulations, during the reign of the Galactic Empire.
