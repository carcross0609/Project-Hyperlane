# Dismantler Torpedo

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dismantler Torpedo](https://starwars.fandom.com/wiki/Dismantler_Torpedo)

The Dismantler Torpedo was a model of termite torpedo launcher manufactured by Arakyd Industries. It cost 10,000 credits on the market and launched termite torpedos, a type of torpedo containing dozens of termite droids.

## Specifications

- **Name:** Dismantler Torpedo
- **Manufacturer:** Arakyd Industries
- **Type:** Termite torpedo launcher
- **Cost:** 10,000 credits
- **Purpose:** Launch termite torpedos
