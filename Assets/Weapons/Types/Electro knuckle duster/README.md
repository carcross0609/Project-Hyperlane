# Electro knuckle duster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro knuckle duster](https://starwars.fandom.com/wiki/Electro_knuckle_duster)

Electro knuckle dusters were a type of electrified melee weapon called knuckle dusters that were mounted on hands. The Wookiee Krrsantan owned a pair of electro knuckle dusters.

## Specifications

- **Name:** Electro knuckle duster
- **Type:** Melee weapon
- **Locations:** Tatooine
