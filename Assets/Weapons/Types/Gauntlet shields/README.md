# Gauntlet shields

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Gauntlet shields](https://starwars.fandom.com/wiki/Gauntlet_shields)

A gauntlet shield or shield gauntlet was a type of armored gauntlet. A shield gauntlet consisted of a metallic gauntlet that contained a number of thin metal plates; when activated an articulated servo-joint would snap the metal plates outward, creating a metal fan that could be used as a physical shield.
