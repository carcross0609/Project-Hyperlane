# Mounted Repeating Blaster CVI

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mounted Repeating Blaster CVI](https://starwars.fandom.com/wiki/Mounted_Repeating_Blaster_CVI)

The Mounted Repeating Blaster CVI was a type of repeating blaster produced by BlasTech Industries. They were often installed on Rapid Deployment stations.

## Specifications

- **Name:** Mounted Repeating Blaster CVI
- **Manufacturer:** BlasTech Industries
- **Type:** Mounted repeating blaster
- **Cost:**
  - 8,000 credits (new)
  - 5,000 credits (used)
- **Crew:** 1
- **Capacity:** Unlimited (power generator)
- **Range:** 300 meters
