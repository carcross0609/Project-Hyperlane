# Ion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ion missile](https://starwars.fandom.com/wiki/Ion_missile)

An ion missile was a type of missile that could be launched from on a starfighter. The Rokana Raiders developed a technology that supercharged the ions used in ion weaponry. This was done by channeling ambient ionic energy into a ship's mounted ion turrets and ion missiles thus greatly increased the effectiveness of the weapons. By 3 ABY, this technology had been outlaws by the Galactic Empire.
