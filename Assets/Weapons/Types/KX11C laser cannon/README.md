# KX11C laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KX11C laser cannon](https://starwars.fandom.com/wiki/KX11C_laser_cannon)

The KX11C laser cannon was a type of laser cannon developed by Taim & Bak. The Fireball, a racing starfighter owned by Jarek Yeager, was equipped with two wingtip KX11C laser cannons.
