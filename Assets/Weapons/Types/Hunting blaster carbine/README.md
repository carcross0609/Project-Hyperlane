# Hunting blaster carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Hunting blaster carbine](https://starwars.fandom.com/wiki/Hunting_blaster_carbine)

The hunting blaster carbine was a light but powerful blaster carbine.

## Specifications

- **Name:** Hunting blaster carbine
- **Type:** Blaster carbine
- **Cost:** 1,000 credits
- **Size:** Medium
- **Weight:** 2.1 kg
- **Capacity:**
  - 50 shots
  - Close-range stun setting available
- **Range:**
  - Optimum: up to 45 m
  - Maximum: up to 225 m
