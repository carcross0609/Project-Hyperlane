# Model 7 Therm-ax

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Model 7 Therm-ax/Legends](https://starwars.fandom.com/wiki/Model_7_Therm-ax/Legends)

The Model 7 Therm-ax was a weapon manufactured by SoroSuub Corporation during the Galactic Civil War and cost 850 credits. It looked like a vibro-ax but its head reached temperatures in excess of 500 degrees.

## Specifications

- **Name:** Model 7 Therm-ax
- **Manufacturer:** SoroSuub Corporation
- **Cost:** 850 credits
