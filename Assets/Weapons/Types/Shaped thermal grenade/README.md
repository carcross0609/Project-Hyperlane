# Shaped thermal grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Shaped thermal grenade](https://starwars.fandom.com/wiki/Shaped_thermal_grenade)

Shaped thermal grenades were powerful grenades that were often used by special forces. The grenades were more expensive than other varieties, but were considered incredibly effective. The grenades were often attached to walls and doors with adhesive and set to explode after a certain amount of time.

## Specifications

- **Name:** Shaped thermal grenade
- **Type:** Grenade
- **Cost:** 3,500 credits
