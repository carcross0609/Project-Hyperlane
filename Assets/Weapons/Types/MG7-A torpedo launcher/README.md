# MG7-A torpedo launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MG7-A torpedo launcher](https://starwars.fandom.com/wiki/MG7-A_torpedo_launcher)

The MG7-A torpedo launcher was a torpedo launcher manufactured by Krupx and was installed on the T-70 X-wing starfighter. Its predecessor, the MG7 proton torpedo launcher, only held up to three proton torpedoes. The MG7-A held eight miniaturised MG7-A proton torpedoes. Quick-change magazines allowed for the torpedoes to be swapped for other payloads, such as concussion missiles or mag-pulse warheads. The launcher itself was also a detachable unit.
