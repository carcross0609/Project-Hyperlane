# RCH-01 shielded cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [RCH-01 shielded cannon](https://starwars.fandom.com/wiki/RCH-01_shielded_cannon)

The RCH-01 shielded turret was a type of shielded turret that was used as security emplacements along the road to the planet Sobrik. During the Cold War, the Balmorran resistance hijacked a number of turrets in the Gorinth Canyon and turned them against the reconstituted Sith Empire.
