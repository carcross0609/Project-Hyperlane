# Diamond-Boron Missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Diamond-Boron Missile](https://starwars.fandom.com/wiki/Diamond-Boron_Missile)

The Diamond-Boron Missile was a type of missile that first saw use during during the Clone Wars and continued to be utilized into the conflict between the First Order and the Resistance. It had the capability of deflecting laser blasts from a standard starfighter.
