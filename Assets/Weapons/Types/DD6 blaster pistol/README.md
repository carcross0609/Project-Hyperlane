# DD6 blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DD6 blaster pistol](https://starwars.fandom.com/wiki/DD6_blaster_pistol)

The DD6 blaster pistol was a type of blaster pistol produced by Merr-Sonn Munitions, Inc. The DD6 served as a precursor to the DR-45 "Dragoon" Cavalry Blaster, also manufactured by Merr-Sonn.
