# Enthusiast Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Enthusiast Set](https://starwars.fandom.com/wiki/Enthusiast_Set)

The Enthusiast Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These sandy weathered weapons featured an orange, black, white, blue, and silver color scheme, with dangling silver tubes and glowing orange cores.
