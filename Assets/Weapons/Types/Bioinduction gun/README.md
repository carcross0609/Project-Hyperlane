# Bioinduction gun

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bioinduction gun](https://starwars.fandom.com/wiki/Bioinduction_gun)

The bioinduction gun was designed by Hugo Cutter. It sent electrical charges to a target's brain to overcome the hypo-reflexive cortex to trigger sleep. It worked on Gigorans, but did not work on Humans, Rodians, or Devaronians.

- **Name:** Bioinduction gun
- **Creators:** Hugo Cutter
