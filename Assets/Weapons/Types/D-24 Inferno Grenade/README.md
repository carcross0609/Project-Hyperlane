# D-24 Inferno Grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [D-24 Inferno Grenade](https://starwars.fandom.com/wiki/D-24_Inferno_Grenade)

The D-24 Inferno Grenade was a type of incendiary grenade produced by Merr-Sonn Munitions, Inc. Upon detonation, the D-24 created intense heat that ignited any and all flammable materials within its blast radius. Initially created primarily for firefighters initiating controlled burns to reduce the risk of wildfires, the D-24 was marketed for military applications as well.

## Specifications

- **Name:** D-24 Inferno Grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Incendiary grenade
