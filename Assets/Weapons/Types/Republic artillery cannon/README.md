# Republic artillery cannon

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Republic artillery cannon](https://starwars.fandom.com/wiki/Republic_artillery_cannon)

The Republic artillery cannon was a four-legged, manned artillery piece armed with one elevating turret, similar to the AV-7 Antivehicle Cannon. The cannon was manned by one elite clone trooper.
