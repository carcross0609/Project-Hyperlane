# Cassian Andor's blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Cassian Andor's blaster](https://starwars.fandom.com/wiki/Cassian_Andor%27s_blaster)

Cassian Andor's blaster was a BlasTech A280-CFE convertible heavy blaster pistol used by Captain Cassian Andor. The blaster's primary function is that of a hand-held sidearm, which he carried in a thigh holster, but it could also accept barrel and stock attachments to convert it into a sniper rifle or an assault rifle.
