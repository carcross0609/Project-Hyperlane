# Octo-bladed lightsaber

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Octo-bladed lightsaber](https://starwars.fandom.com/wiki/Octo-bladed_lightsaber)

An Octo-bladed lightsaber was a lightsaber that had eight blades, with four protruding on each end. Darth Maul owned one of these weapons. It can be reduced to six, two or one blade, however, it's octo form isn't used for combat only used for intimidation.

## Specifications

- **Name:** Octo-bladed lightsaber
- **Type:** Lightsaber
- **Culture:** Sith
- **Owners:** Darth Maul (Darth Maul's lightsaber)
- **Purpose:** Combat
- **Affiliation:** Order of the Sith Lords
