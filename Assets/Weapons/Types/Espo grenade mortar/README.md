# Espo grenade mortar

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Espo grenade mortar](https://starwars.fandom.com/wiki/Espo_grenade_mortar)

The Espo grenade mortar was a mobile artillery grenade mortar, with an integrated repulsorlift unit. The repulsorlift did not propel the mortar, but did allow an operator to push or pull the mortar into position. The mortar was capable of firing any type of grenade up to a distance of a kilometer, and had an ammunition capacity of a hundred grenades.

## Specifications

- **Name:** Espo grenade mortar
- **Type:** Grenade mortar
- **Cost:** 3,500 credits
- **Crew:** 1
- **Capacity:** 100 grenades
- **Range:** 1 kilometer
- **Affiliation:**
  - Corporate Sector Authority
  - Alliance to Restore the Republic
