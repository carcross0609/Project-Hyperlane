# Rey's blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Rey's blaster](https://starwars.fandom.com/wiki/Rey%27s_blaster)

Rey's blaster was an NN-14 blaster pistol formerly owned by Han Solo, who gave it to the scavenger Rey. Manufactured by LPA, it had a safety switch that prevented the blaster from firing.
