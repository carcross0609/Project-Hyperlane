# NK-7 ion cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [NK-7 ion cannon](https://starwars.fandom.com/wiki/NK-7_ion_cannon)

NK-7 ion cannons were a model of ion cannon produced by the company Borstel. Sixty NK-7s were included in the armaments of the Galactic Empire's Imperial I-class Star Destroyer.
