# EXVR-1 Guardian Grid

**Kind:** Model  
**Continuity:** Legends  
**Source:** [EXVR-1 Guardian Grid](https://starwars.fandom.com/wiki/EXVR-1_Guardian_Grid)

The EXVR-1 Guardian Grid, commonly known as the Ion Defense Grid, was a an intricate network of ion field generators contained within a superstructure which could combine their ionic energy into a single ionic pulse capable of shutting down an enemy ship.

- **Type:** Ion generation field
- **Owners:** Luskin Exovar
