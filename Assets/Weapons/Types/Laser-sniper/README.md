# Laser-sniper

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Laser-sniper](https://starwars.fandom.com/wiki/Laser-sniper)

The laser-sniper was a type of black sniper rifle that fired lasers. It had a scope that provided a red tinted crosshair. Shortly after the Battle of Yavin that marked the start of 0 ABY, the bounty hunter Glunge made use of a laser-sniper while attempting to claim a bounty on the smuggler Han Solo on the Outer Rim planet Rion.
