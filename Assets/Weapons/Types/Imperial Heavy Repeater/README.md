# Imperial Heavy Repeater

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Imperial Heavy Repeater](https://starwars.fandom.com/wiki/Imperial_Heavy_Repeater)

The Imperial Heavy Repeater was a projectile weapon used by Imperial troops. It was an improvement over the earlier Imperial repeater rifle, which was developed by Moff Rebus.

## Specifications

- **Name:** Imperial Heavy Repeater
- **Model:** Slugthrower
- **Cost:** 1,500 credits
- **Capacity:** 400 metallic bolts, or 50 concussive blasts
- **Affiliation:**
  - Galactic Empire
  - Imperial Remnant
