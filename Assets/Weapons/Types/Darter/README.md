# Darter

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Darter](https://starwars.fandom.com/wiki/Darter)

A darter was a short-ranged large pistol that launched a dart via compressed air. It caused minimal damage, but could be used to deliver a surveillance tagger or poison. Hunters, medical personnel, assassins and security personnel were known to use them.

## Specifications

- **Name:** Darter
- **Type:** Dart-shooting pistol
- **Culture:**
  - Poachers
  - Game wardens
  - Security personnel
  - Assassins
  - Medical personnel
- **Cost:** 150 credits
- **Shape:** Pistol-shaped
- **Size:** One-handed weapon
- **Weight:** 3 kg
- **Capacity:** 1 dart
- **Range:**
  - Optimum: up to 30 m
  - Maximum: up to 60 m
- **Purpose:**
  - Poison a target
  - Tag a target with a surveillance tagger
