# Fire blade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Fire blade](https://starwars.fandom.com/wiki/Fire_blade)

A fire blade was a type of weapon owned by the bounty hunter Dengar. A typical humanoid hand-sized hilt carried a similarly lengthed orange-red flame.
