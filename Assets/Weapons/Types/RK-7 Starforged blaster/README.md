# RK-7 Starforged blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [RK-7 Starforged blaster](https://starwars.fandom.com/wiki/RK-7_Starforged_blaster)

The RK-7 Starforged blaster was a model of blaster pistol available during the Galactic War between the Galactic Republic and the reconstituted Sith Empire. It was a similar model to the RK-5 Starforged blaster, but featured a large magazine on its stock.
