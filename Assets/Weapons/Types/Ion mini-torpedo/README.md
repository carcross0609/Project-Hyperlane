# Ion mini-torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ion mini-torpedo](https://starwars.fandom.com/wiki/Ion_mini-torpedo)

An ion mini-torpedo was a type of mini-torpedo that functioned as an ion weapon. Like other mini-torpedoes, it only functioned underwater.
