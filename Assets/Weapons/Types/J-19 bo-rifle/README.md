# J-19 bo-rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [J-19 bo-rifle](https://starwars.fandom.com/wiki/J-19_bo-rifle)

The J-19 bo-rifle was a model of bo-rifle manufactured by the Lasan-Malamut Firearms Corporation. It was black in color with a bayonet that sat along the top edge and a folding stock was situated along the back. It was considered less artfully designed than the older AB-75 model.
