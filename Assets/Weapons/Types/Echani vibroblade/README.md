# Echani vibroblade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Echani vibroblade](https://starwars.fandom.com/wiki/Echani_vibroblade)

Used in the offhand, the Echani vibroblades possessed not only the cortosis weave that made them capable of blocking a lightsaber strike but, on occasions, were also super cooled, to keep them in alignment, which made strikes by these weapons icy to the touch.

## Specifications

- **Name:** Echani vibroblade
- **Type:** Vibroblade
- **Culture:** Echani
