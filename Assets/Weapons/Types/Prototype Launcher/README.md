# Prototype Launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Prototype Launcher](https://starwars.fandom.com/wiki/Prototype_Launcher)

The Prototype Launcher was a specialized Nanite Launcher utilized by the Twi'lek Hunter Tuya that she could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara. Tuya's droid partner T-U8 also had a matching set of exterior plating that was included under this title, being the droid's standard appearance.
