# Turbocannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Turbocannon](https://starwars.fandom.com/wiki/Turbocannon)

A turbocannon was a type of blaster rifle. The Death-Hunter Cyborg, created by the Galactic Empire's Operation Death-Hunter project, carried a prototype turbocannon. During Operation Shadow Hand, the darktrooper Grath carried a turbocannon.

- **Type:** Blaster rifle
