# Collector Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Collector Set](https://starwars.fandom.com/wiki/Collector_Set)

The Collector Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These weapons featured a metallic purple, orange, gold, white, and black color scheme, with additional dangling silver tubes, as well as glowing orange cores.
