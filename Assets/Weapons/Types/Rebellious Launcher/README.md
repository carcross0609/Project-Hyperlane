# Rebellious Launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Rebellious Launcher](https://starwars.fandom.com/wiki/Rebellious_Launcher)

The Rebellious Launcher was the name of a set of objects, including a custom Nanite Launcher, a specialized projectile launcher, owned by the Twi'lek Hunter Tuya that she could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to her standard launcher, as well as matching exterior plating for Tuya's droid partner, T-U8.
