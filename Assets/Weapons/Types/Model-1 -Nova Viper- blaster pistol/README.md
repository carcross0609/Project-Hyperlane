# Model-1 "Nova Viper" blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Model-1 "Nova Viper" blaster pistol](https://starwars.fandom.com/wiki/Model-1_%22Nova_Viper%22_blaster_pistol)

The Model-1 "Nova Viper" blaster pistol was a type of blaster pistol manufactured by Raider Arms. It used an elegant, long-bodied duelist pistol frame that provided unmatched accuracy, and as was common in Raider carbine designs, the barrel ran the entire length of the frame, and enabled an unprecedented beam cohesion at range for its size, which gave each blast far more "punch" than competitors.
