# S-4 Underwater Torpedo Launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [S-4 Underwater Torpedo Launcher](https://starwars.fandom.com/wiki/S-4_Underwater_Torpedo_Launcher)

The S-4 Underwater Torpedo Launcher was a weapon system produced by Czerka. It was designed to be used against submersibles and held one torpedo. Three of the launchers were installed near Quekka Trench Station by Pinae Wettan for defense.

## Specifications

- **Name:** S-4 Underwater Torpedo Launcher
- **Manufacturer:** Czerka
- **Type:** Torpedo launcher
- **Cost:** 10,000 credits
- **Range:** 500 meters
