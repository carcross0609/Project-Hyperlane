# Vilmarh's Revenge

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vilmarh's Revenge](https://starwars.fandom.com/wiki/Vilmarh%27s_Revenge)

Vilmarh's Revenge, also known as a precision laser dart, was a popular blaster pistol model manufactured by DevTech Sidearms. The weapon was easy to customize to one's liking, as the barrel adapter could fit various kinds of attachments. Vizago's pistol, for example, had a barrel shroud receiver with cooling vents. The Vilmarh's Revenge had a long distance sight adapter that can fold down and a pressure-sensitive trigger. Increased pressure on the trigger would result in an increased rate of fire.
