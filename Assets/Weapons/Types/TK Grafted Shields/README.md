# TK Grafted Shields

**Kind:** Model  
**Continuity:** Canon  
**Source:** [TK Grafted Shields](https://starwars.fandom.com/wiki/TK_Grafted_Shields)

The TK Grafted Shields were a pair of shields owned by the KX-series security droid Hunter K-A0S that she could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to her standard Grafted Twin Shields. These shields features visible wear and blast marks.
