# Blister blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blister blaster](https://starwars.fandom.com/wiki/Blister_blaster)

The blister blaster was a high-velocity slugthrower produced by Golan Arms. It fired hollow ammunition containing a volatile petro-chemical reactant that when exposed to oxygen upon impact ignited in a small area around the target.

## Specifications

- **Name:** Blister blaster
- **Manufacturer:** Golan Arms
- **Type:** Slugthrower
- **Cost:** 300 credits
- **Capacity:** 8
- **Range:** 60 meters
