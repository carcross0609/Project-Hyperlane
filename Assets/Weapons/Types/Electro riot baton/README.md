# Electro riot baton

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro riot baton](https://starwars.fandom.com/wiki/Electro_riot_baton)

The electro riot baton was a type of electrobaton used by Imperial scout troopers and KX-series Security Droid Enforcers. Krane, a high ranking Imperial officer used one to relieve a fellow officer of her duties on Zeffo.
