# M102 Fire Arc

**Kind:** Model  
**Continuity:** Legends  
**Source:** [M102 Fire Arc](https://starwars.fandom.com/wiki/M102_Fire_Arc)

The M102 Fire Arc Artillery Piece was a heavy projectile cannon produced by Golan Arms. Originally designed for the Galactic Empire, disinterest in the system led it to be sold on the open market, including to the Rebel Alliance.

## Specifications

- **Name:** M102 Fire Arc
- **Manufacturer:** Golan Arms
- **Model:** M102 Artillery Piece
- **Type:** Surface-to-Surface Shell Launcher
- **Cost:** 25,000 credits
- **Size:** Walker
- **Capacity:** 20 shells
- **Range:** 20 km
- **Affiliation:** Alliance to Restore the Republic
