# Thermal half-sphere

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Thermal half-sphere](https://starwars.fandom.com/wiki/Thermal_half-sphere)

Thermal half-spheres were remote-detonated thermal explosives. Professional thief Sienn Sconn owned several of these, and used one to kill Variise, a Mistryl Shadow Guard.
