# Force-imbued sword

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Force-imbued sword](https://starwars.fandom.com/wiki/Force-imbued_sword)

A Force-imbued sword was a type of sword, that according to the legend, was used prior to invention of the lightsaber by the earlier Force adepts and the Jedi Order.
