# Heavy blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Heavy blaster rifle/Legends](https://starwars.fandom.com/wiki/Heavy_blaster_rifle/Legends)

The heavy blaster rifle was a larger, more powerful version of the blaster rifle often used by clone troopers, stormtroopers, and other troopers.

## Specifications

- **Name:** Heavy blaster rifle
- **Type:** Blaster rifle
- **Cost:** 2,000 credits (Available for military use only)
- **Shape:** Rifle-shaped
- **Size:** Two-handed weapon
- **Weight:** 6 kg
- **Capacity:**
  - 30 shots
  - Close-range stun setting available
  - Autofire mode available
- **Range:**
  - Optimum: up to 45 m
  - Maximum: up to 225 m
- **Affiliation:**
  - Grand Army of the Republic
  - Galactic Empire
