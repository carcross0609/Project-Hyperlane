# Molecular purge bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Molecular purge bomb](https://starwars.fandom.com/wiki/Molecular_purge_bomb)

A molecular purge bomb was an explosive designed to remove all forensic trace of someone's presence. Doctor Aphra used one to conceal that she and Darth Vader had been to Obi-Wan Kenobi's hut on Tatooine while uncovering the identity of the Sith Lord's son.

## Specifications

- **Name:** Molecular purge bomb
- **Type:** Bomb
- **Owners:** Chelli Lona Aphra
- **Locations:** Ben Kenobi's home, Tatooine
