# Umbaran blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Umbaran blaster pistol](https://starwars.fandom.com/wiki/Umbaran_blaster_pistol)

The Umbaran blaster pistol was a model of blaster pistol used by the Umbaran Militia during the Clone Wars. It fired green blaster bolts. Although it was a type of blaster pistol, Umbaran soldiers typically used two hands to wield it.
