# VM-19 heavy blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [VM-19 heavy blaster pistol](https://starwars.fandom.com/wiki/VM-19_heavy_blaster_pistol)

The VM-19 heavy blaster was a heavy blaster pistol capable of switching modules during combat. Modules included blaster bolts, stun, and ion. Kay Vess used a worn VM-19 during the Imperial Era.
