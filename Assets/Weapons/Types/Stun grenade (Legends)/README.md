# Stun grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Stun grenade/Legends](https://starwars.fandom.com/wiki/Stun_grenade/Legends)

Stun grenades were grenades that stunned opponents, usually used when the object of a mission was to detain, capture, or subdue rather than kill.

## Specifications

- **Name:** Stun grenade
- **Type:** Grenade
- **Cost:** 75 credits to 250 credits
- **Size:** Hand-held
- **Weight:** 0.5 kilogram
- **Capacity:** Single use
- **Range:**
  - Thrown weapon
  - 3-meter to 4-meter blast radius
- **Purpose:** Nonlethal incapacitation of living targets
