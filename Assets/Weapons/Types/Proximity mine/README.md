# Proximity mine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Proximity mine](https://starwars.fandom.com/wiki/Proximity_mine)

Proximity mines were a type of mine that the Alliance to Restore the Republic placed proximity mines around Echo Base's Outpost Beta. Though several were detonated by Imperial All Terrain Armored Transports, they did little damage.

## Specifications

- **Name:** Proximity mine
- **Type:** Mine
- **Locations:** Outpost Beta, Hoth
- **Affiliation:** Alliance to Restore the Republic
