# T-28 repeating sniper rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [T-28 repeating sniper rifle](https://starwars.fandom.com/wiki/T-28_repeating_sniper_rifle)

The T-28 repeating sniper rifle was a long-barreled Blaster rifle produced by BlasTech. It was used by the Galactic Empire, and issued to stormtrooper snipers, such as Taxtro Grave.
