# Jurgan Kalta's carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Jurgan Kalta's carbine](https://starwars.fandom.com/wiki/Jurgan_Kalta%27s_carbine)

Jurgan Kalta's carbine was a very powerful and accurate blaster carbine commissioned by the Zabrak mercenary Jurgan Kalta by 3956 BBY. Sometime after Kalta's death, this carbine came into the hands of the Ithorian hunter Fazza Utral.

## Specifications

- **Name:** Jurgan Kalta's carbine
- **Type:** Blaster carbine
- **Created:** By 3956 BBY
- **Owners:**
  - Jurgan Kalta
  - Fazza Utral
- **Cost:** 4,500 credits
- **Size:** Two-handed weapon
- **Range:** 25 meters (Effective range)
