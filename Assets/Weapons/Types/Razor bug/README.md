# Razor bug

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Razor bug](https://starwars.fandom.com/wiki/Razor_bug)

Razor bugs or razorbugs were small, disc-shaped insects that were biologically engineered by the Yuuzhan Vong to serve as thrown ranged weapons that had the capability of being thrown up to 130 meters.

## Specifications

- **Name:** Razor bug
- **Manufacturer:** Yuuzhan Vong
- **Type:** Biologically engineered throwing weapon
- **Culture:** Yuuzhan Vong
- **Creators:** Yuuzhan Vong
- **Cost:** 800 credits (Illegal)
- **Shape:** Disc-shaped
- **Size:** Fist-sized
- **Weight:** 0.5 kg
- **Capacity:** Single-use but can be returned to wielder's hand
- **Range:**
  - Optimum: thrown up to 20 meters
  - Maximum: thrown up to 130 meters
- **Affiliation:** Yuuzhan Vong
