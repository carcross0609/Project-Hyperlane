# SSB-1 Static Pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [SSB-1 Static Pistol](https://starwars.fandom.com/wiki/SSB-1_Static_Pistol)

The SSB-1 Static Pistol was a type of static blaster that was originally developed by the long-defunct Systech Corporation. Thousands of years after Systech went out of business, the blaster's original design was revived by SoroSuub Corporation as the SSB-1.

## Specifications

- **Name:** SSB-1 Static Pistol
- **Manufacturer:**
  - Systech Corporation (originally)
  - SoroSuub Corporation (modern)
- **Type:** Static blaster
- **Cost:** 850 credits
- **Range:** Short-ranged
