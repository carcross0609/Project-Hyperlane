# DFA 998

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DFA 998](https://starwars.fandom.com/wiki/DFA_998)

The DFA 998 was a model of anti-infantry laser cannon manufactured by Golan Arms. Several were installed at Fortress Keremark.

## Specifications

- **Name:** DFA 998
- **Manufacturer:** Golan Arms
- **Type:** Anti-infantry laser cannon
- **Locations:** Fortress Keremark
- **Cost:**
  - 20,000 credits (new)
  - 10,000 credits (used)
- **Crew:** 3
- **Capacity:** Unlimited (power generator)
- **Range:** 16 kilometers
