# DR-45 "Dragoon" Cavalry Blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DR-45 "Dragoon" Cavalry Blaster](https://starwars.fandom.com/wiki/DR-45_%22Dragoon%22_Cavalry_Blaster)

The DR-45 "Dragoon" Cavalry Blaster was a type of blaster weapon produced by Merr-Sonn Munitions, Inc., who used the design of the DD6 blaster pistol to create the DR-45. A convertible carbine long-barreled variation of the DD6, the DR-45 possessed a quick-release clip-on rifle housing and buttstock, which allowed the weapon to be configured from pistol to rifle.
