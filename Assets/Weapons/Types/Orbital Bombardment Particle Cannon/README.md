# Orbital Bombardment Particle Cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Orbital Bombardment Particle Cannon](https://starwars.fandom.com/wiki/Orbital_Bombardment_Particle_Cannon)

The Orbital Bombardment Particle Cannon was a model of particle cannon and mass-driver cannon that was supposedly powered by kyber crystals and considered by the Rebel Alliance to be a superweapon. Onager-class Star Destroyers could be outfitted with either a pair of Superheavy Composite Beam Turbolasers or a pair of Orbital Bombardment Particle Cannons.

## Specifications

- **Name:** Orbital Bombardment Particle Cannon
- **Model:** Orbital Bombardment Particle Cannons/Mass-driver cannons
- **Type:** Superweapon
- **Locations:** Onager-class Star Destroyers
- **Range:** Long-range
- **Purpose:** Orbital bombardment
- **Affiliation:** Galactic Empire
