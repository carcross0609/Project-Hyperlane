# Plasma grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Plasma grenade/Legends](https://starwars.fandom.com/wiki/Plasma_grenade/Legends)

A plasma grenade was a type of grenade that exerted pressurized gas similar to the Cold grenade, except it ignited into flames when it reached the outside atmosphere. This type of grenade was not very common, as it also generated a magnetic field that occasionally caused it to attach to the thrower's hand .

## Specifications

- **Name:** Plasma grenade
- **Type:** Grenade
- **Cost:** 750-900 Credits
