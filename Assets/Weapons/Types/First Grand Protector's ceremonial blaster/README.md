# First Grand Protector's ceremonial blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [First Grand Protector's ceremonial blaster](https://starwars.fandom.com/wiki/First_Grand_Protector%27s_ceremonial_blaster)

The first individual to be Grand Protector, leader of the Rodian species' civilization on the planet Rodia possessed a ceremonial blaster that, by 3637 BBY, was rumored to be buried beneath the Wesessa Sea on Rodia.
