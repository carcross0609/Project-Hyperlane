# Shock-lance

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Shock-lance](https://starwars.fandom.com/wiki/Shock-lance)

Shock-lances were a type of lance wielded by members of the New Republic's Senate Guard on Chandrila following the Battle of Endor. Temmin Wexley and Mister Bones were accosted by Senate Guards armed with shock-lances while attempting to warn Norra Wexley prior to the Imperial attack on Chandrila.
