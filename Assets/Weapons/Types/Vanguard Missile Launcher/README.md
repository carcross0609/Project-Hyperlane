# Vanguard Missile Launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Vanguard Missile Launcher](https://starwars.fandom.com/wiki/Vanguard_Missile_Launcher)

Vanguard Missile Launchers were emplacement missile systems manufactured by Arakyd Industries. They were installed on space stations such as the FireStar-class Orbital Defense Station.
