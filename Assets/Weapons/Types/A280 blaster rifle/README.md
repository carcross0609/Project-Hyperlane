# A280 blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [A280 blaster rifle](https://starwars.fandom.com/wiki/A280_blaster_rifle)

The A280 blaster rifle was a type of blaster rifle mostly used by Rebel Alliance troopers and New Republic soldiers, as part of the A-series. There existed two variants of the A280 blaster, the A280C and the A280-CFE, both of which were favored by commandos and special forces of the Rebel Alliance.
