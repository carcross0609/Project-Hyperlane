# Fastcutter

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Fastcutter](https://starwars.fandom.com/wiki/Fastcutter)

The fastcutter was a common brand of vibro-cutter manufactured by Craftsbeing. It measured 0.3 meters and was a heavy cutting tool equipped with an ultrasonic generator which caused a vibration that enabled it to cut with the slightest touch. Like other vibro-cutters, the Fastcutter was designed with industrial uses in mind, but this did not prevent it from being used as a weapon.
