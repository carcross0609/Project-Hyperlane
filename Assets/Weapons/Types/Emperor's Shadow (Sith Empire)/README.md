# Emperor's Shadow (Sith Empire)

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Emperor's Shadow (Sith Empire)](https://starwars.fandom.com/wiki/Emperor%27s_Shadow_%28Sith_Empire%29)

The Emperor's Shadow was a space-faring device which included third-generation cloaking technology. It was commissioned by Darth Malgus and created using the power and materials extracted by the Sun Razer in the Vesla system.

## Specifications

- **Name:** Emperor's Shadow
- **Manufacturer:**
  - Sith Empire
  - Commissioned by Darth Malgus
- **Model:** Third generation cloaking device
- **Affiliation:** Sith Empire
