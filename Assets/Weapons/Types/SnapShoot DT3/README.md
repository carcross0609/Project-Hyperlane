# SnapShoot DT3

**Kind:** Model  
**Continuity:** Legends  
**Source:** [SnapShoot DT3](https://starwars.fandom.com/wiki/SnapShoot_DT3)

The SnapShoot DT3 was a quick-draw pulse-wave blaster manufactured by Greff-Timms Industrial. It cost 300 credits, had an ammunition capacity of only 3 shots, and a range of 10 meters.

## Specifications

- **Name:** SnapShoot DT3
- **Manufacturer:** Greff-Timms Industrial

- **Range:** 10 meters
