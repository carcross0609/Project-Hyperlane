# E-Web rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [E-Web rifle](https://starwars.fandom.com/wiki/E-Web_rifle)

The E-Web rifle was a portable version of the powerful E-Web heavy repeating blaster designed by Merr-Sonn Munitions, Inc. and manufactured by BlasTech Industries. It was used by Imperial snowtroopers during the Battle of Hoth.
