# YV-26 Starforged blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [YV-26 Starforged blaster rifle](https://starwars.fandom.com/wiki/YV-26_Starforged_blaster_rifle)

The YV-26 Starforged blaster rifle was a model of blaster rifle available during the Galactic War between the Galactic Republic and the Sith Empire. It was a similar model to the YV-24 Starforged blaster rifle, but featured an extension on its barrel.
