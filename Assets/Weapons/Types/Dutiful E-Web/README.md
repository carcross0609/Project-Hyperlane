# Dutiful E-Web

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dutiful E-Web](https://starwars.fandom.com/wiki/Dutiful_E-Web)

The Dutiful E-Web was an E-Web heavy repeating blaster cannon owned by the human Hunter Sentinel that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard E-Web.

- **Model:** E-Web heavy repeating blaster cannon (Sentinel's E-Web)
- **Type:** Heavy repeating blaster
- **Owners:** Sentinel
