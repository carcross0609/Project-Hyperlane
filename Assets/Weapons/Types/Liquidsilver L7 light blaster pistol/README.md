# Liquidsilver L7 light blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Liquidsilver L7 light blaster pistol](https://starwars.fandom.com/wiki/Liquidsilver_L7_light_blaster_pistol)

The Liquidsilver L7 light blaster pistol was a blaster pistol used among smugglers. It was named for its ability to blend into a starship's cargo hold, allowing its owner to get it unnoticed in dangerous situations.

## Specifications

- **Name:** Liquidsilver L7 light blaster pistol
- **Type:** Blaster pistol
