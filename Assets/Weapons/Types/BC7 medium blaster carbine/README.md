# BC7 medium blaster carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [BC7 medium blaster carbine](https://starwars.fandom.com/wiki/BC7_medium_blaster_carbine)

The BC7 medium carbine was produced by Merr-Sonn. An optional grenade launcher could be attached to it, instead of a foregrip. It was standard issue for the Balawai militia during the Summertime War on Haruun Kal.
