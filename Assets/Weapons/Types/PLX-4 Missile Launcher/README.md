# PLX-4 Missile Launcher

**Kind:** Model  
**Continuity:** Legends

- **Name:** PLX-4 Missile Launcher
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** PLX-4
- **Type:** Missile launcher
- **Cost:** 6,000 credits (launcher)
- **Capacity:** 4 (detachable missile rack)
- **Range:** 10 km
- **Affiliation:**
