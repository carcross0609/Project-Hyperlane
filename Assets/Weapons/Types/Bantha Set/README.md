# Bantha Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Bantha Set](https://starwars.fandom.com/wiki/Bantha_Set)

The Bantha Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These sandy weathered weapons featured a black and brown color scheme, with a yellow tube protruding from an Arc Caster, and both weapons were wrapped in ornate elements including vibrant cords and cloth, dark fur, and tan string.
