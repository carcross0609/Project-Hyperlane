# QuickShot

**Kind:** Model  
**Continuity:** Legends  
**Source:** [QuickShot](https://starwars.fandom.com/wiki/QuickShot)

The QuickShot was mounted on a forearm sleeve and designed to be worn under flowing sleeves. It held one round, with up to 4 extra quarrels stored in the sleeve for later use.

## Specifications

- **Name:** QuickShot
- **Manufacturer:** Drolan Plasteel
- **Type:** Wrist-caster
- **Cost:** 500 credits
- **Weight:** 1 kilogram
- **Capacity:** 2 quarrels
- **Range:** 20 meters
