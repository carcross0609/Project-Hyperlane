# Coyn'skar

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Coyn'skar](https://starwars.fandom.com/wiki/Coyn%27skar)

The coyn'skar was a bladed polearm manufactured by Ekkar Armaments for the Coynites. The weapon was a lengthy shaft designed to offer maximum grip. One end of the coyn'skar was a sharp blade, while the other had a hook that could be used to trip and disarm opponents. Dr. Itlar owned a complete set of Ekkar Armaments weapons, including a coyn'skar, that were obtained on a visit to a weapons factory. Itlar would practice with the weapons by dueling with friends.
