# Model Kylan-3

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Model Kylan-3](https://starwars.fandom.com/wiki/Model_Kylan-3)

The Model Kylan-3 was a heavy blaster pistol manufactured by the Sullustan SoroSuub Corporation. Jokingly referred to as a Sullustan Blast Rifle, it was produced under Imperial contract, though large numbers of them fell into rebel hands.

## Specifications

- **Name:** Model Kylan-3
- **Manufacturer:** SoroSuub Corporation
- **Type:** Heavy blaster pistol
- **Cost:** 750–825 credits
- **Size:** Medium
- **Weight:** 1.7 kilograms
- **Capacity:** 50
- **Range:** 80 meters
