# G-20 Glop grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [G-20 Glop grenade](https://starwars.fandom.com/wiki/G-20_Glop_grenade)

The G-20 Glop grenade was a reusable, non-lethal grenade that produced by Merr-Sonn Munitions, Inc. The grenades cost 100 credits per unit and were often used by law enforcement agencies. The grenades released a foam that hardened on contact with oxygen, thereby trapping anyone caught in the blast.

## Specifications

- **Name:** G-20 Glop grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Grenade
