# Zygerrian blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Zygerrian blaster rifle](https://starwars.fandom.com/wiki/Zygerrian_blaster_rifle)

The Zygerrian blaster rifle was a model of blaster rifle used by the Zygerrian Slave Empire during the Clone Wars. The Zygerrian Royal Guards used this weapon as a complement to their electro-whip. Some pirates of the Ohnaka Gang also made use of these weapons.
