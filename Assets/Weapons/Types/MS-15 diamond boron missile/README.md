# MS-15 diamond boron missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MS-15 diamond boron missile](https://starwars.fandom.com/wiki/MS-15_diamond_boron_missile)

The MS-15 diamond boron missile was an anti-starfighter missile system manufactured by Sienar Fleet Systems at the height of the Galactic Civil War. It was primarily used by the Galactic Empire.

## Specifications

- **Name:** MS-15 diamond boron missile
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Diamond boron missile
- **Cost:** Nearly 20,000 credits per missile
- **Length:** 1 meter
- **Range:** 50 meters (blast radius)
- **Affiliation:** Galactic Empire
