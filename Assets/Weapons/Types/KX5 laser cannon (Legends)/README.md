# KX5 laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [KX5 laser cannon/Legends](https://starwars.fandom.com/wiki/KX5_laser_cannon/Legends)

The KX5, manufactured by Taim & Bak, was a fighter-scale laser cannon manufactured during the Galactic Civil War. The KX5 was used in, among other craft, Incom Corporation/Subpro Corporation Z-95 Headhunters, Koensayr Manufacturing BTL-A4 Y-wing starfighters, Sienar Fleet Systems Lambda-class T-4a shuttles, and Cygnus Spaceworks Alpha-class Xg-1 Star Wings.
