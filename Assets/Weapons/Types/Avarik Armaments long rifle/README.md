# Avarik Armaments long rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Avarik Armaments long rifle](https://starwars.fandom.com/wiki/Avarik_Armaments_long_rifle)

The Avarik Armaments long rifle was a model of longblaster produced by Avarik Armaments. The rifle offered significant stopping power even at long distances, but required an expert sniper behind the trigger. The Onderonian Steela Gerrera owned an Avarik Armaments long rifle and used it as sniper rifle while leading the Onderon rebels against the King Sanjay Rash and the Confederacy of Independent Systems during the Clone Wars. The bounty hunter Onca carried a Avarik Armaments long rifle.
