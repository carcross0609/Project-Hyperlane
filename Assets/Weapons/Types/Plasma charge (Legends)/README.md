# Plasma charge

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Plasma charge/Legends](https://starwars.fandom.com/wiki/Plasma_charge/Legends)

A plasma charge was an explosive device generating high-temperature plasma shockwaves. It was produced by Tarascii Explosives during the Galactic Civil War and cost 200 credits.
