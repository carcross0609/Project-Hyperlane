# Sticky grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Sticky grenade](https://starwars.fandom.com/wiki/Sticky_grenade)

A sticky grenade was a type of grenade. During the High Republic Era, the human Krix Kamerat used latch-on thermal detonators, which were a type of sticky grenade.

- **Name:** Sticky grenade
