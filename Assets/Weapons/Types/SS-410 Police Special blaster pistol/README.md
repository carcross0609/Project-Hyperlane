# SS-410 Police Special blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [SS-410 Police Special blaster pistol](https://starwars.fandom.com/wiki/SS-410_Police_Special_blaster_pistol)

The SS-410 Police Special blaster pistol was a model of blaster pistol carried by the GU-series Guardian police droid of the Coruscant Security Force on certain assignments rather than the standard truncheon the droids carried while on patrol.
