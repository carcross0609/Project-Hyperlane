# Acid sword

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Acid sword](https://starwars.fandom.com/wiki/Acid_sword)

An acid sword was a type of sword which saw use during the time of the Galactic Civil War. In addition to physical damage, it released deadly acid that burnt its target.

- **Name:** Acid sword
- **Type:** Sword
- **Owners:** Sordaan Xris
