# LL-30 blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [LL-30 blaster pistol](https://starwars.fandom.com/wiki/LL-30_blaster_pistol)

The LL-30 blaster pistol was a type of blaster pistol used in the galaxy. The blaster had a slim barrel, and a scope attachment at the top. During the Clone Wars and into the Imperial Era, the bounty hunter Cad Bane wielded a pair of LL-30s.
