# Light concussion missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Light concussion missile](https://starwars.fandom.com/wiki/Light_concussion_missile)

A light concussion missile was an explosive projectile that was fired from a light concussion missile launcher, which was a portable antivehicle missile launcher. The missile was a smaller version of the standard concussion missile that was fired from starships.

## Specifications

- **Name:** Light concussion missile
- **Type:** Concussion missile
- **Cost:** 800 credits (Available for military use only)
- **Weight:** 10 kg
- **Capacity:** Collateral damage to nearby targets
- **Purpose:** Ammunition for light concussion missile launcher
