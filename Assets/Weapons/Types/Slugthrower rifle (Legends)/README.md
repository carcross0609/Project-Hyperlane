# Slugthrower rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Slugthrower rifle/Legends](https://starwars.fandom.com/wiki/Slugthrower_rifle/Legends)

A slugthrower rifle (or simply "rifle") was a type of slugthrower and a larger two-handed version of the slugthrower pistol. It was a vast improvement from a musket.

## Specifications

- **Name:** Slugthrower rifle
- **Type:** Slugthrower
- **Culture:**
  - Newly-industrialized cultures
  - Tusken Raiders
  - Primitive cultures
  - Petty criminals and street thugs
- **Cost:** 250 credits to 300 credits
- **Shape:** Rifle-shaped
- **Size:** Medium
- **Weight:** 4 kg
- **Capacity:**
  - 20 shots
  - Autofire mode available
- **Range:**
  - Optimum: up to 45 meters
  - Maximum: up to 450 meters
