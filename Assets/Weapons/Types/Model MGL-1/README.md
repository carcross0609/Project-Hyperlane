# Model MGL-1

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Model MGL-1](https://starwars.fandom.com/wiki/Model_MGL-1)

The Model MGL-1 was a type of micro-grenade launcher designed by Locris Syndicates. It was designed to fire Micro-grenades quickly and with minimal training for the user. It could be mounted on another rifle and be used as a separate weapon.

## Specifications

- **Name:** Model MGL-1
- **Manufacturer:** Locris Syndicates
- **Type:** Micro-grenade launcher
- **Cost:** 2,500 credits
- **Size:** Medium
- **Length:** 0.5 meters
- **Weight:** 3 kg
- **Capacity:** 30 (magazine)
- **Range:** 200 meters
- **Purpose:** Near-soundless fire ideal for stealth missions
