# PL-8 Piercer Missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [PL-8 Piercer Missile](https://starwars.fandom.com/wiki/PL-8_Piercer_Missile)

PL-8 Piercer Missiles were a type of concussion missile manufactured by Corellian Engineering Corporation. The Barloz-class medium freighter Solar Flare was armed with PL-8 Piercer Missiles.

## Specifications

- **Name:** PL-8 Piercer Missile
- **Manufacturer:** Corellian Engineering Corporation
- **Type:** Concussion missile
- **Cost:** 500 credits each
