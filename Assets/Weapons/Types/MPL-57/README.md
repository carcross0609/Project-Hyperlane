# MPL-57

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MPL-57](https://starwars.fandom.com/wiki/MPL-57)

The MPL-57 (Multi-Purpose Launcher) was a grenade launcher originally developed by Merr-Sonn Munitions, Inc. during the Galactic Civil War in an effort to widen its market share.

## Specifications

- **Name:** MPL-57
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Grenade launcher
- **Capacity:** 3 grenades / ion torpedo / homing missile / acid grenade
- **Purpose:** Anti-infantry, anti-vehicle
- **Affiliation:**
  - Galactic Empire
  -   Imperial Army
  - Alliance to Restore the Republic
  -   Alliance Army
