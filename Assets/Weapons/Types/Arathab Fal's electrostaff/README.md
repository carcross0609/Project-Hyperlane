# Arathab Fal's electrostaff

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Arathab Fal's electrostaff](https://starwars.fandom.com/wiki/Arathab_Fal%27s_electrostaff)

A double-bladed electrostaff was wielded by the Tarnab criminal Arathab Fal during the High Republic Era. The Tarnab used it to confront private investigator Sian Holt and her partner Keefar Branto on Coruscant.
