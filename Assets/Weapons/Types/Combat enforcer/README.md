# Combat enforcer

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Combat enforcer](https://starwars.fandom.com/wiki/Combat_enforcer)

The Combat enforcer was a powerful repeating blaster that inflicted considerable pain and damage upon its victim, but was somewhat unwieldy to use effectively. The origins of this weapon were unclear, though there had been suggestions that there were some similarities between its design and that of Mandalorian weapons.

## Specifications

- **Name:** Combat enforcer
- **Type:** Repeating blaster
- **Range:** 28 meters
