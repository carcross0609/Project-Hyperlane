# RG-9 laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [RG-9 laser cannon/Legends](https://starwars.fandom.com/wiki/RG-9_laser_cannon/Legends)

The RG-9 laser cannon was a model of laser cannon that was manufactured by Borstel Galactic Defense. The Rebel Alliance utilized these weapons aboard their RZ-1 A-wing interceptors.
