# Ink mini-torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ink mini-torpedo](https://starwars.fandom.com/wiki/Ink_mini-torpedo)

An ink mini-torpedo was a type of mini-torpedo that released a large amount of ink, which obscured opponents' vision. Like other mini-torpedoes, it only functioned underwater.

## Specifications

- **Name:** Ink mini-torpedo
- **Type:** Mini-torpedo
- **Culture:** Mon Calamari
- **Cost:** 50 credits
