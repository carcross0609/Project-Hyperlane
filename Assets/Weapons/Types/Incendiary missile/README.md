# Incendiary missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Incendiary missile](https://starwars.fandom.com/wiki/Incendiary_missile)

Incendiary missiles were powerful missiles similar to incendiary grenades. The volatile gel within incendiary missiles would stick to almost anything it touched, and burned at immense temperatures.

## Specifications

- **Name:** Incendiary missile
- **Type:** Missile
- **Cost:** 145 credits
