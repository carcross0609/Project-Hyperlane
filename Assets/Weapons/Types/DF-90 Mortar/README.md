# DF-90 Mortar

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DF-90 Mortar](https://starwars.fandom.com/wiki/DF-90_Mortar)

The DF-90 Mortar was a portable mortar artillery used by coastal defender stormtroopers of the Galactic Empire. The launcher had two projectile tubes, and was anchored down by two leg braces attached to either side of the launcher near the barrel openings.
