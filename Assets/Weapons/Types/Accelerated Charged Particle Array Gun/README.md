# Accelerated Charged Particle Array Gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Accelerated Charged Particle Array Gun](https://starwars.fandom.com/wiki/Accelerated_Charged_Particle_Array_Gun)

The ACP Array Gun, or Accelerated Charged Particle Array Gun, was a weapon best suited to close range combat. The gun was favored by some Trandoshans during the Clone Wars and Imperial Era. The pirate Kragan Gorr used a customized ACP Array Gun during the New Republic Era when he and his gang worked for the First Order. Although he lost this weapon after his mutiny on the Colossus.
