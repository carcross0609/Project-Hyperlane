# Vibro-stiletto

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vibro-stiletto](https://starwars.fandom.com/wiki/Vibro-stiletto)

The vibro-stiletto was a type of bladed vibro weapon. The human female cyborg Drash owned one such weapon, using it to defend Daimyo Boba Fett from the Wookiee bounty hunter Krrsantan during an assassination attempt.
