# Dueling pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dueling pistol/Legends](https://starwars.fandom.com/wiki/Dueling_pistol/Legends)

The Coronet Arms dueling pistol was a powerful, single-shot blaster pistol typically sold in pairs. They were high-quality pistols designed to be used in a honor duel. They were useless at any great distance, but at the short distances employed in a duel, they were incredibly accurate weapons. Their power pack fired a single shot—all that was allowed in a duel—which was almost always lethal.

## Specifications

- **Name:** Dueling pistol
- **Manufacturer:** Coronet Arms
- **Type:** Blaster pistol
- **Cost:** 750 credits
