# Systech electric blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Systech electric blaster](https://starwars.fandom.com/wiki/Systech_electric_blaster)

The Systech electric blaster was the more advanced model of the static blaster developed by the Systech Corporation for use against veermok, a ferocious primate found on the planet of Naboo. These primates were highly resistant to blaster fire, therefore this weapon's damage was mostly electrical, allowing it to bypass the resistance.

## Specifications

- **Name:** Systech electric blaster
- **Manufacturer:** Systech Corporation
- **Type:** Blaster pistol
- **Range:** 23 meters
