# Electrohammer

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electrohammer](https://starwars.fandom.com/wiki/Electrohammer)

An electrohammer was a heavy melee weapon wielded by Purge Troopers of the Galactic Empire's Inquisitorius after the events of Order 66. The weapon was able to block lightsaber attacks.
