# Sd-77 sonic pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sd-77 sonic pistol](https://starwars.fandom.com/wiki/Sd-77_sonic_pistol)

The Sd-77 sonic pistol was a ranged weapon produced by Pacnorval Defense Systems, Limited. The sonic pistol fired a wide blast of high-intensity sound waves which could shatter solid objects or stun a sentient.
