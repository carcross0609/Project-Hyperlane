# Stun laser

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Stun laser](https://starwars.fandom.com/wiki/Stun_laser)

Stun lasers were vehicle-mounted weapons. They were similar to lasers, but with reduced power that would stun, rather than harm, small animals.
