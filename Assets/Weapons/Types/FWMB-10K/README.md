# FWMB-10K

**Kind:** Model  
**Continuity:** Canon  
**Source:** [FWMB-10K](https://starwars.fandom.com/wiki/FWMB-10K)

The FWMB-10K was a heavy blaster used by the First Order. A smaller variant of the FWMB-10 repeating blaster, the FWMB-10K featured a medium rate of fire with a high damage output.

## Specifications

- **Name:** FWMB-10K
- **Manufacturer:** Sonn-Blas Corporation
- **Model:** FWMB-10K
- **Type:** Heavy blaster
