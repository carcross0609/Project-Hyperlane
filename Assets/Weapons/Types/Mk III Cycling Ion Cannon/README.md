# Mk III Cycling Ion Cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Mk III Cycling Ion Cannon](https://starwars.fandom.com/wiki/Mk_III_Cycling_Ion_Cannon)

The Mk III Cycling Ion Cannon was a model of repeating ion cannon manufactured by Sienar Fleet Systems. It could be equipped to starfighters and utilized ion pulses to disable enemy starships. It cost 6,000 credits on the market.

## Specifications

- **Name:** Mk III Cycling Ion Cannon
- **Manufacturer:** Sienar Fleet Systems
- **Type:** Repeating ion cannon
- **Cost:** 6,000 credits
- **Purpose:** Disable starships
