# F-Web Repeating Blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [F-Web Repeating Blaster](https://starwars.fandom.com/wiki/F-Web_Repeating_Blaster)

The BlasTech F-Web repeating blaster was the successor of the famous E-Web heavy repeating blaster. As such, it possessed increased power and was outfitted with a shield that could be operated by a third person. Like the E-Web, it served an anti-infantry role, as well as being collapsible, allowing for quick deployment. This made them a valuable asset in an army.

## Specifications

- **Name:** F-Web Repeating Blaster
- **Manufacturer:** BlasTech Industries
- **Model:** F-Web
- **Type:** Heavy repeating blaster
