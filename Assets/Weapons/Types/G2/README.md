# G2

**Kind:** Model  
**Continuity:** Canon  
**Source:** [G2](https://starwars.fandom.com/wiki/G2)

The G2 was a model of grenade manufactured by Merr-Sonn Munitions, Inc. that was available during the Galactic Civil War. It caused damage using over-pressure shockwaves rather than shrapnel, baradium or incendiary chemicals. Its closest competitor was Baktoid Personal Ordnance's BKX-4 "Shockwave" Grenade.
