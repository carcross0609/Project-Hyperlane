# Phasma's blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Phasma's blaster rifle](https://starwars.fandom.com/wiki/Phasma%27s_blaster_rifle)

Phasma's blaster rifle was the personal Sonn-Blas F-11D blaster rifle used by Captain Phasma. The blaster featured a buttstock, chromium finish, and a recurved trigger guard for a two-handed grip.
