# LX-4 proton mine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [LX-4 proton mine/Legends](https://starwars.fandom.com/wiki/LX-4_proton_mine/Legends)

The LX-4 proton mine was a self-detonating defensive mine produced by Merr-Sonn Munitions, Inc. for use by the Imperial Military.

## Specifications

- **Name:** LX-4 proton mine
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Self-detonating perimeter mine
- **Cost:** 750 credits
- **Range:** 20 meter blast radius
