# Mass-driver missile launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Mass-driver missile launcher](https://starwars.fandom.com/wiki/Mass-driver_missile_launcher)

A mass-driver missile launcher was a type of missile launcher used by the Galactic Republic throughout the Clone Wars. A twin set of mass-driver missile launchers were dorsally mounted to the Republic's Low Altitude Assault Transport/infantry gunships and RTT-04 armored troop transports. Low Altitude Assault Transport gunships could launch missiles at hypersonic speeds, whose warheads would focus their explosive detonation along a two-degree cone. However, a set of twin EP-750X EMP missile launchers could be armed to LAAT/i gunships in place of a mass-driver missile launcher.
