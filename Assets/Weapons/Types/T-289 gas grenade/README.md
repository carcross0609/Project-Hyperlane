# T-289 gas grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [T-289 gas grenade](https://starwars.fandom.com/wiki/T-289_gas_grenade)

The T-289 Gas Grenade was a gas grenade produced by Czerka Arms. When detonated, each grenade released T-289 stun gas, which caused disorientation, nausea, and vomiting. The gas was nonlethal, except in very large doses, and ineffective against targets wearing protective breath masks.

## Specifications

- **Name:** T-289 gas grenade
- **Manufacturer:** Czerka Arms
- **Type:** Gas grenade
- **Cost:** 325 credits
