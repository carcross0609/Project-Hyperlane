# Blade Launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Blade Launcher](https://starwars.fandom.com/wiki/Blade_Launcher)

A Blade Launcher was a type of wrist gauntlet capable of launching long-range blades. One was used by Glikkin for the Hunters of the Outer Rim sports competition.
