# MG7-A proton torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MG7-A proton torpedo/Legends](https://starwars.fandom.com/wiki/MG7-A_proton_torpedo/Legends)

The MG7-A proton torpedo was a model of proton torpedo produced by Krupx Munitions and commonly used aboard T-65 X-wing starfighters during the Galactic Civil War.

## Specifications

- **Name:** MG7-A proton torpedo
- **Manufacturer:** Krupx Munitions
- **Type:** Proton torpedo
- **Range:**

  - 600 meters (maximum)
- **Affiliation:** Alliance to Restore the Republic
