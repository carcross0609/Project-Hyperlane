# StarSlasher Blaster Carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [StarSlasher Blaster Carbine](https://starwars.fandom.com/wiki/StarSlasher_Blaster_Carbine)

The StarSlasher Blaster Carbine was a blaster carbine produced by BlasTech Industries. It was one of the oldest working models of blaster carbine in the galaxy, and was very reliable, able to remain functional after being left neglected in a storage crate for a decade.

## Specifications

- **Name:** StarSlasher Blaster Carbine
- **Manufacturer:** BlasTech Industries
- **Type:** Blaster carbine
- **Cost:**
  - 900 credits
  - 25 credits per blaster power pack
- **Capacity:** 100 shots
- **Range:** 250 meters
