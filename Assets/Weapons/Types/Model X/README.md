# Model X

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Model X](https://starwars.fandom.com/wiki/Model_X)

The Model X was a model of heavy blaster pistol manufactured by Caliban. The weapon's carbine-like barrel and frame were nearly identical to those of the "Renegade" heavy blaster pistol manufactured by SoroSuub Corporation and the C-10 heavy blaster pistol.

## Specifications

- **Name:** Model X
- **Manufacturer:** Caliban
- **Type:** Heavy blaster pistol
