# Watchman blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Watchman blaster](https://starwars.fandom.com/wiki/Watchman_blaster)

The Watchman blaster was a survival pistol that could match the performance of a heavy blaster when fully upgraded. Their stun capabilities rendered them useful as off-hand weapons for those beings who preferred combat with two ranged weapons.

## Specifications

- **Name:** Watchman blaster
- **Type:** Blaster pistol
- **Range:** 23 meters
