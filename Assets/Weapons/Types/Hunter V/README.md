# Hunter V

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Hunter V](https://starwars.fandom.com/wiki/Hunter_V)

The Hunter V was a sporting blaster carbine manufactured by BlasTech Industries. The weapon was a civilian version of the Sharpshooter V. Marketed as a sporting blaster, it was widely used by security forces in urban environments for use during inner-city combat.

## Specifications

- **Name:** Hunter V
- **Manufacturer:** BlasTech Industries
- **Type:** Sporting Blaster carbine
