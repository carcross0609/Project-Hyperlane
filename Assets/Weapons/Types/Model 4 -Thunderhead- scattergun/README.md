# Model 4 "Thunderhead" scattergun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Model 4 "Thunderhead" scattergun](https://starwars.fandom.com/wiki/Model_4_%22Thunderhead%22_scattergun)

The Model 4 "Thunderhead" scattergun was a scattergun manufactured by Czerka Arms as a competitor to Adostic Arms' 8-gauge "AA8" scattergun. The size of a rifle, the Model 4 fired clouds of small ferroalloy pellets, which were effective in enclosed spaces.

## Specifications

- **Name:** Model 4 "Thunderhead" scattergun
- **Manufacturer:** Czerka Arms
- **Type:** Scattergun
- **Cost:** 700 credits
- **Range:** Short
