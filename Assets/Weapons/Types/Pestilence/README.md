# Pestilence

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Pestilence](https://starwars.fandom.com/wiki/Pestilence)

The pikes known as Pestilence were named by the villagers who were overrun by the Deathswarm. The description was fitting as the weapons put an end to almost all who fought against them.
