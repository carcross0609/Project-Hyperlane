# Party Launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Party Launcher](https://starwars.fandom.com/wiki/Party_Launcher)

The Party Launcher was the name of a set of objects, including a custom Nanite Launcher, a specialized projectile launcher, owned by the Twi'lek Hunter Tuya that she could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to her standard launcher, as well as matching exterior plating and photoreceptor for Tuya's droid partner, T-U8.
