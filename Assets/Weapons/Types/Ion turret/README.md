# Ion turret

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ion turret](https://starwars.fandom.com/wiki/Ion_turret)

An ion turret was a turret-mounted ion weapon that could be equipped to starships. The Rokana Raiders developed a technology that supercharged the ions used in ion weaponry. This was done by channeling ambient ionic energy into a ship's mounted ion turrets and ion missiles thus greatly increased the effectiveness of the weapons. By 3 ABY, this technology had been outlaws by the Galactic Empire.
