# Sniper rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Sniper rifle](https://starwars.fandom.com/wiki/Sniper_rifle)

The sniper rifle, also called a sniper blaster rifle or assassin rifle, was a type of blaster rifle used to shoot targets at long range. Though some rifles were built as sniper rifles, many other models could be used as one with the addition of a scope and other accessories like a stock.

## Specifications

- **Name:** Sniper rifle
- **Type:** Blaster rifle
- **Range:** Long
- **Purpose:** Sniping
