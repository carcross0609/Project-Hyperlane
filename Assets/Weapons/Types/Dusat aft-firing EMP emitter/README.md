# Dusat aft-firing EMP emitter

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dusat aft-firing EMP emitter](https://starwars.fandom.com/wiki/Dusat_aft-firing_EMP_emitter)

The Dusat aft-firing EMP emitter was a model of electromagnetic pulse weapon which was mounted on the Joben T-85 speeder bikes made by Zebulon Dak Speeder Corporation. The Jedi Kanan Jarrus disabled the EMP emitter on his T-85 bike when he used it on the planet Lothal.
