# MG5 concussion missile launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MG5 concussion missile launcher/Legends](https://starwars.fandom.com/wiki/MG5_concussion_missile_launcher/Legends)

The MG5 concussion missile launcher was a model of concussion missile launcher manufactured by Krupx Munitions. The Z-95 Headhunter was commonly equipped with a pair of MG5 launchers.
