# Virus-Removing Oddly Operated Machine

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Virus-Removing Oddly Operated Machine](https://starwars.fandom.com/wiki/Virus-Removing_Oddly_Operated_Machine)

The Virus-Removing Oddly Operated Machine, or V.R.O.O.M. for short, was a melee weapon used to destroy the corruption, a virus that plagued the Observatory and Observatory HoloSimulator on The Island. When a pilot became stranded on the island where the Observatory and HoloSimulator were located, they utilized a V.R.O.O.M. to destroy the spreading corruption.

## Specifications

- **Name:** Virus-Removing Oddly Operated Machine
- **Type:** Melee weapon
- **Owners:**
  - TU-T0R
  - A pilot
- **Locations:** A planet
- **Purpose:** Wiping away corruption
