# Electro-scythe

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro-scythe](https://starwars.fandom.com/wiki/Electro-scythe)

The electro-scythe was a melee weapon used during the Galactic Civil War. In 5 ABY, the pirate Eleodie Maracavanya wielded an electro-scythe that could be folded into a staff. It released threads of blue energy.
