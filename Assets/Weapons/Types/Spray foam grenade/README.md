# Spray foam grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Spray foam grenade](https://starwars.fandom.com/wiki/Spray_foam_grenade)

Spray foam grenades were grenades that were developed by the Tenloss Syndicate and sold for 150 credits. The grenades released a foam that quickly hardened, trapping anyone within the blast radius. However, the hardened foam broke down relatively soon after forming.

## Specifications

- **Name:** Spray foam grenade
- **Manufacturer:** Tenloss Syndicate
- **Type:** Grenade
- **Cost:** 150 credits
