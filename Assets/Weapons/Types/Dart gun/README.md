# Dart gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dart gun](https://starwars.fandom.com/wiki/Dart_gun)

Dart guns were a ranged weapon-type used to fire physical dart projectiles. These darts were highly customizable, able to be converted into special-use ammunition such as Stim Darts and poison darts. The assassin droid IG-88's needle dart gun was a type of dart gun.

## Specifications

- **Name:** Dart gun
- **Type:** Long-range
- **Owners:**
  - IG-88
  - Skora
- **Affiliation:** Hunters of the Outer Rim
