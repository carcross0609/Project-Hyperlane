# "Wasp" blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** ["Wasp" blaster rifle](https://starwars.fandom.com/wiki/%22Wasp%22_blaster_rifle)

The "Wasp" blaster rifle was the name Razoo Qin-Fee gave to his customized blaster rifle. It was black with an external accelerator barrel cage crudely painted in yellow and used a pump action gas compressor to reload.

## Specifications

- **Name:** "Wasp" blaster rifle
- **Type:** Blaster rifle
- **Owners:** Razoo Qin-Fee
- **Size:** Two-handed weapon
- **Purpose:** Ranged combat
