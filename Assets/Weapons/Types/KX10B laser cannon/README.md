# KX10B laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KX10B laser cannon](https://starwars.fandom.com/wiki/KX10B_laser_cannon)

The KX10B laser cannon was a laser cannon manufactured by Taim & Bak. The Green Ace, a modified G30 racing starfighter flown by Hype Fazon, was equipped with two wingtip KX10B laser cannons.
