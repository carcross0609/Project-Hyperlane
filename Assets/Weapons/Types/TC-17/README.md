# TC-17

**Kind:** Model  
**Continuity:** Legends  
**Source:** [TC-17](https://starwars.fandom.com/wiki/TC-17)

The TC-17 was a long-range blaster rifle equipped with a scope and designed for use by snipers. The rifle had a range of over three-hundred meters. Each power cell held enough energy for a dozen shots before it needed to be replaced.

## Specifications

- **Name:** TC-17
- **Model:** TC-17
- **Type:** Blaster rifle
- **Capacity:** 12 shots
- **Range:** 300 meters
- **Purpose:** Sniper rifle
- **Affiliation:**

  - Gloom Walkers
