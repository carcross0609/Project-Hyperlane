# HSG-67 laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [HSG-67 laser cannon](https://starwars.fandom.com/wiki/HSG-67_laser_cannon)

The HSG-67 laser cannon was a type of starship-mounted laser cannon that was used by XS stock light freighters during the Great Galactic War, Cold War, and Galactic War. The HSG-67 was mounted atop the ship, which was produced by Soniver Arms.
