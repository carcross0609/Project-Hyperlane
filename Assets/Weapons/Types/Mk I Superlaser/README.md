# Mk I Superlaser

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Mk I Superlaser](https://starwars.fandom.com/wiki/Mk_I_Superlaser)

The Mk I Superlaser was the first model of kyber crystal-powered superlaser developed by the Galactic Empire. It was the primary weapon of the first Death Star battle station. Components for the superlaser dish were constructed at the Narkina 5 Imperial Prison Complex.

- **Name:** Mk I Superlaser
