# Oppressor flamethrower

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Oppressor flamethrower](https://starwars.fandom.com/wiki/Oppressor_flamethrower)

The Oppressor flamethrower was a flame projector sometimes used by the storm commandos of the Imperial Stormtrooper Corps. It was the standard equipment of the incinerator stormtroopers.

- **Name:** Oppressor flamethrower
- **Type:** Flamethrower
