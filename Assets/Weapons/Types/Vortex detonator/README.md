# Vortex detonator

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vortex detonator](https://starwars.fandom.com/wiki/Vortex_detonator)

Vortex detonators, also known as vortex bombs, were customized explosives that the Galactic Empire used to stoke the storms of Nacronis as part of Operation: Cinder.

- **Type:** Explosive
- **Locations:** Nacronis
- **Purpose:** Stoking storms
