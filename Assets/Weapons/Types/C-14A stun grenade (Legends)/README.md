# C-14A stun grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [C-14A stun grenade/Legends](https://starwars.fandom.com/wiki/C-14A_stun_grenade/Legends)

The C-14A stun grenade was a small grenade with the aim of incapacitating rather than killing targets. It was manufactured by Merr-Sonn Munitions, Inc. It had a metallic sphere covered in beam splitters and a clublike handle. The grenade held energy in optic capacitors that would discharge when it was used. The blast would hit the beam splitters and cover the area in stunning energy.
