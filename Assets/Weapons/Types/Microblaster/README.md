# Microblaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Microblaster](https://starwars.fandom.com/wiki/Microblaster)

Microblasters were a category of blaster characterised as small and easy to conceal. They conformed to the basic idea of a blaster, unlike the A95 Stingbeam, which also competed within the niche microblaster market.

## Specifications

- **Name:** Microblaster
- **Type:** Blaster
- **Size:** Small
