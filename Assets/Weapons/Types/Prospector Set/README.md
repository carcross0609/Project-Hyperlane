# Prospector Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Prospector Set](https://starwars.fandom.com/wiki/Prospector_Set)

The Prospector Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These weapons featured a black, blue, silver, and orange color scheme, with dangling orange and silver tubes, as well as glowing orange cores. The Arc Caster also possessed a white grip and tan upper handle.
