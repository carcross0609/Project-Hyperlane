# Double-bladed boot

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Double-bladed boot](https://starwars.fandom.com/wiki/Double-bladed_boot)

Double-bladed boots were weapons that looked like ordinary work boots, but when the boot was given a kick twin blades emerged from the toe. A miner named Jake attacked Luke Skywalker with double-bladed boots and double-bladed stilettos on Mimban.

## Specifications

- **Name:** Double-bladed boot
- **Owners:** Jake
- **Locations:** Mimban
- **Shape:** Twin knives
- **Material:** Metal
- **Length:** 10 centimeter blades
- **Width:** 3 centimeter blades
