# Acidic Paragon Vibro Axe

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Acidic Paragon Vibro Axe](https://starwars.fandom.com/wiki/Acidic_Paragon_Vibro_Axe)

The Acidic Paragon Vibro Axe was a type of vibro-ax in use sometime after the Battle of Yavin during the Galactic Civil War. As with most vibroblades, the weapon contained an ultrasonic vibration generator in the handle that granted the user far greater cutting power. However, the Acidic Paragon Vibro Axe was unique because the blade had tiny micro-pores in it that exuded a corrosive acid. Each strike would apply acid to the affected area, softening it up and making each subsequent blow from the weapon much more damaging.

- **Name:** Acidic Paragon Vibro Axe
