# M-19 cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [M-19 cannon](https://starwars.fandom.com/wiki/M-19_cannon)

The M-19 cannon was a model of heavy plasma cannon that could be mounted to starships. In 3 ABY, the Rokana Raiders flew R93 refractor starfighters that were equipped with modified M-19 cannons mounted to their wings. The pirates' R93 refractors NA-7 flight system could alternate between a recon mode and an assault mode. In recon mode the M-19 cannons were deactivated however in assault mode the M-19 cannons would alternate fire with nose mounted L-13 cannons.
