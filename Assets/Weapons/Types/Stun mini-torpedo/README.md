# Stun mini-torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Stun mini-torpedo](https://starwars.fandom.com/wiki/Stun_mini-torpedo)

An stun mini-torpedo was a type of mini-torpedo that could stun opponents. Like other mini-torpedoes, it only functioned underwater.
