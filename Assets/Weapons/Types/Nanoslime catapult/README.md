# Nanoslime catapult

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Nanoslime catapult](https://starwars.fandom.com/wiki/Nanoslime_catapult)

A nanoslime catapult was a type of catapult which fired a projectile called nanoslime. One such nanoslime catapult prototype was located in Hivebase-1, among other Tarkin Initiative prototypes.
