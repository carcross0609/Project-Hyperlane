# Point-defense ion cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Point-defense ion cannon](https://starwars.fandom.com/wiki/Point-defense_ion_cannon)

The point-defense ion cannon was a type of ion cannon that was outfitted on the Providence-class Dreadnoughts of the Confederacy of Independent Systems. The Confederate dreadnoughts were equipped with twelve point-defense ion cannons.

## Specifications

- **Name:** Point-defense ion cannon
- **Type:** Ion cannon
- **Locations:** Providence-class Dreadnoughts
- **Affiliation:** Confederacy of Independent Systems
