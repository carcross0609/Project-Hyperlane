# A295 blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [A295 blaster rifle/Legends](https://starwars.fandom.com/wiki/A295_blaster_rifle/Legends)

The BlasTech A295 blaster rifle was the standard-issue rifle used by the Rebel Alliance at Echo Base. It was favored by marksmen for its high accuracy and effectiveness at range. A sniper variant also existed.
