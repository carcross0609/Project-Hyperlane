# KD-30 pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KD-30 pistol](https://starwars.fandom.com/wiki/KD-30_pistol)

The KD-30 pistol was a type of slugthrower. Chass na Chadic owned a KD-30 pistol that fired custom rounds loaded with acid rather than particle bolts.

## Specifications

- **Name:** KD-30 pistol
- **Type:** Slugthrower
- **Capacity:** 10 rounds
