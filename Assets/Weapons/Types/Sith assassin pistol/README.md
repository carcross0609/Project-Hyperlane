# Sith assassin pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Sith assassin pistol](https://starwars.fandom.com/wiki/Sith_assassin_pistol)

The Sith assassin pistol was an ancient tool used by the Sith to dispatch people quickly without alerting the target of the person's presence. The power setting could be adjusted to allow for quick or a lingering death. These were the same weapons that were used during the Great Sith War which proved to be quite popular at the time.

## Specifications

- **Name:** Sith assassin pistol
- **Type:** Hold-out blaster
- **Affiliation:** Sith
