# Banger

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Banger](https://starwars.fandom.com/wiki/Banger)

A banger was a type of slugthrower that bore a resemblance to shotguns. The leader of the Open faction, Mother Pran, dual-wielded bangers.
