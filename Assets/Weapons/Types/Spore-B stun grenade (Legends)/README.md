# Spore/B stun grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Spore/B stun grenade/Legends](https://starwars.fandom.com/wiki/Spore/B_stun_grenade/Legends)

Spore/B stun grenades were black, ovoid grenades manufactured by Czerka Arms that released microscopic Bothan stun spores capable of incapacitating targets. These were extensively used by special forces, particularly Bothan spies. The Imperial Military used it with the CSPL-12 projectile launcher.
