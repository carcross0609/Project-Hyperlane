# GH-22 blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [GH-22 blaster](https://starwars.fandom.com/wiki/GH-22_blaster)

The GH-22 blaster was a weapon used in the days of the Old Republic. The Human mercenary Vrath Xizor had a GH-22 blaster aboard his starship, the Razor, around the year 3653 BBY.
