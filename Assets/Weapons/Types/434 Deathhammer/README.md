# 434 Deathhammer

**Kind:** Model  
**Continuity:** Canon  
**Source:** [434 Deathhammer](https://starwars.fandom.com/wiki/434_Deathhammer)

The 434 Deathhammer blaster was model of blaster pistol that was popular with bounty hunters. It has a slim grip designed for easy concealment. The blaster had a vented shroud around the barrel to prevent overheating in hot climates. It had a large dial on the side that adjusted its power settings.
