# DC-15x sniper rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DC-15x sniper rifle](https://starwars.fandom.com/wiki/DC-15x_sniper_rifle)

The DC-15x sniper rifle, also called the DC-15X Long Rifle, was a type of sniper rifle used by the Galactic Republic. It was a modified version of the DC-15A blaster rifle, dealing more damage, but containing fewer shots. Advanced Recon Commandos were known to use it.
