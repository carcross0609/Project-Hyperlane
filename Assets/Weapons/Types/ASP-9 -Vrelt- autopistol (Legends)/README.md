# ASP-9 "Vrelt" autopistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [ASP-9 "Vrelt" autopistol/Legends](https://starwars.fandom.com/wiki/ASP-9_%22Vrelt%22_autopistol/Legends)

The ASP-9 was a slugthrower pistol produced by Talus Ironworks during the Galactic Civil War. It was nicknamed "Vrelt," from a small rodent found in the Corellian sector.
