# Viper grenade launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Viper grenade launcher](https://starwars.fandom.com/wiki/Viper_grenade_launcher)

The Viper grenade launcher was a weapon attachment that could be mounted onto the underside of blaster rifles and carbines such as the A280 blaster rifle.

## Specifications

- **Name:** Viper grenade launcher
- **Manufacturer:** Zone Control
- **Type:** Grenade launcher rifle attachment
- **Cost:** 500 credits
- **Capacity:** 2 grenades
- **Range:** 500 meters
- **Affiliation:** Alliance to Restore the Republic
