# Piercing Round

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Piercing Round](https://starwars.fandom.com/wiki/Piercing_Round)

Piercing Rounds were a type of high-density slug capable of damaging multiple targets. Diago Velaar used Piercing Rounds for the Hunters of the Outer Rim sports competition.

- **Name:** Piercing Round
- **Type:** Slug
