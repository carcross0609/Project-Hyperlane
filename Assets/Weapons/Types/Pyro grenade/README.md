# Pyro grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Pyro grenade](https://starwars.fandom.com/wiki/Pyro_grenade)

A Pyro grenade was a type of grenade that caused a large fiery explosion. During the Vaklin insurgency, a Duro insurgent attempted to throw one at Darth Vader and his troops, only to have it backfire. Vader telekinetically made it impossible for the Duros to release it from his hand.
