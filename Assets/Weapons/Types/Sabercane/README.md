# Sabercane

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Sabercane](https://starwars.fandom.com/wiki/Sabercane)

A sabercane or cane lightsaber was any lightsaber with a hilt disguised as the handle of a cane. The elderly Jedi Tera Sinube used one such weapon during the Clone Wars, and so did Maul during the reign of the Galactic Empire.
