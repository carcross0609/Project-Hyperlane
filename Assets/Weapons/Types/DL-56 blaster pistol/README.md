# DL-56 blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DL-56 blaster pistol](https://starwars.fandom.com/wiki/DL-56_blaster_pistol)

The DL-56 blaster pistol was a model of blaster pistol manufactured by BlasTech Industries. In 8 ABY, Pathfinder Lilla Dade of the New Republic's elite Katarn Commandos used a DL-56 during the Battle of Kal'Shebbol.
