# Duelling sword

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Duelling sword](https://starwars.fandom.com/wiki/Duelling_sword)

A duelling sword was a sword specifically designed for dueling. Both Count Imal Valesovich and High Lord Jaris Affric employed the services of The Most Honourable Guild of Armourers to acquire ancient duelling swords.
