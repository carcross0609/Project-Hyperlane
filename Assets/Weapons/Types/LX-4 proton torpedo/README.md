# LX-4 proton torpedo

**Kind:** Model  
**Continuity:** Canon  
**Source:** [LX-4 proton torpedo](https://starwars.fandom.com/wiki/LX-4_proton_torpedo)

LX-4 proton torpedoes were Merr-Sonn Munitions, Inc. munitions. They were deployed by TIE/sa bombers. The warhead could be retrofitted to become proton mines.
