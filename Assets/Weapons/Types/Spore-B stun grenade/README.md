# Spore/B stun grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Spore/B stun grenade](https://starwars.fandom.com/wiki/Spore/B_stun_grenade)

The Spore/B stun grenade was a type of stun grenade manufactured by Czerka Arms. When detonated, the grenade dispersed a cloud of spores that could have strange interactions with different body chemistries.
