# F-Web repeating blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [F-Web repeating blaster](https://starwars.fandom.com/wiki/F-Web_repeating_blaster)

The F-Web repeating blaster was a type of repeating blaster produced by BlasTech Industries. It cost 8,500 credits and was equipped with a small deflector shield generator which could deflect small arms fire, but required a third person to operate. It was the successor to the E-Web heavy repeating blaster cannon. It was not as efficient as the E-Web (15).

## Specifications

- **Name:** F-Web repeating blaster
- **Manufacturer:** BlasTech Industries
- **Type:** Repeating blaster
- **Cost:** 8,500 credits
- **Crew:**
  - Two (without deflector shield generator)
  - Three (with deflector shield generator)
