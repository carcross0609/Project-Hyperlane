# P13-M Disruptor

**Kind:** Model  
**Continuity:** Canon  
**Source:** [P13-M Disruptor](https://starwars.fandom.com/wiki/P13-M_Disruptor)

The P13-M Disruptor was a type of disruptor weapon used by Fife and the foot soldiers of the Pyke Syndicate. It appeared rifle-like, featured a scope, and its name shared similarities to the P13 Long Blaster, the primary blaster used by Pykes.

## Specifications

- **Name:** P13-M Disruptor
- **Type:** Disruptor
- **Range:** Long
- **Affiliation:** Pyke Syndicate
