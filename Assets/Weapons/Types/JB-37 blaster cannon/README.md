# JB-37 blaster cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [JB-37 blaster cannon](https://starwars.fandom.com/wiki/JB-37_blaster_cannon)

The JB-37 blaster cannon was a model of blaster cannon manufactured by BlasTech Industries. Twin JB-37s were mounted on Aratech Repulsor Company 614-AvA speeder bikes, situated beneath the three front-mounted steering vanes, including the modified speeder bike owned by Ezra Bridger.
