# Enhanced TIE blaster cannon prototype

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Enhanced TIE blaster cannon prototype](https://starwars.fandom.com/wiki/Enhanced_TIE_blaster_cannon_prototype)

During the Galactic Civil War, an enhanced TIE blaster cannon prototype was tested by the Galactic Empire. Intended for use on TIE Advanced x1 starfighters, the prototype was field tested by elite TIE squadrons. The blaster cannon had improved targeting software, resulting in greater range and power for the weapon but at the cost of requiring more powerful energy cells.
