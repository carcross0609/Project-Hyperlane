# Jai'galaar blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Jai'galaar blaster](https://starwars.fandom.com/wiki/Jai%27galaar_blaster)

The Jai'galaar blaster was a type of Mandalorian blaster developed by MandalTech. It shared its name with the Mando'a word for shriek-hawk.
