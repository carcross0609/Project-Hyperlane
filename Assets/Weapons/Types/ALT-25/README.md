# ALT-25

**Kind:** Model  
**Continuity:** Legends  
**Source:** [ALT-25](https://starwars.fandom.com/wiki/ALT-25)

The ALT-25 was a blaster pistol model manufactured by BlasTech Industries before the Cold War. It features included a magnetic adhesion grip and side-mounted rangefinder. One such pistol was owned by Corso Riggs, who gave it the name "Torchy," like he did to all of his weapons.
