# Assault concussion missile launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Assault concussion missile launcher](https://starwars.fandom.com/wiki/Assault_concussion_missile_launcher)

The assault concussion missile launcher was a type of concussion missile launcher that was used on starships. The Maelstrom-class battle cruisers were each equipped with ten such launchers.

## Specifications

- **Name:** Assault concussion missile launcher
- **Type:** Concussion missile launcher
- **Cost:** 6,000 credits
- **Capacity:** 30 concussion missiles
