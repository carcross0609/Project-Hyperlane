# DW-3 concussion grenade launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DW-3 concussion grenade launcher](https://starwars.fandom.com/wiki/DW-3_concussion_grenade_launcher)

The DW-3 concussion grenade launcher was a model of concussion grenade launcher manufactured by Dymex. It stored three heavy-duty Dymex TriplePounder grenades capable of swiveling a wide swath of infantrymen. The All Terrain Scout Transport used by the Imperial Army was equipped with one such launcher on the starboard side of its command module.
