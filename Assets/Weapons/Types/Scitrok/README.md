# Scitrok

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Scitrok](https://starwars.fandom.com/wiki/Scitrok)

The Scitrok was a weapon used by warrior-monks known as Scitrok Warriors. It resembled a fierce scimitar with barbed spikes along the cutting edge and required about ten years to master in combat, since it was difficult to handle to the point that one may have easily injured himself doing so.

## Specifications

- **Name:** Scitrok
- **Type:** Melee weapon
- **Affiliation:** Scitrok Warriors
