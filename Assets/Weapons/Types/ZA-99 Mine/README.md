# ZA-99 Mine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [ZA-99 Mine](https://starwars.fandom.com/wiki/ZA-99_Mine)

ZA-99 Mine was a floating explosive miniprobe model used during the war against Zakuul. Alirra Semhess used several ZA-99 Mines while fighting off intruders on the X7-Cratus space station.
