# Junti Mace

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Junti Mace](https://starwars.fandom.com/wiki/Junti_Mace)

The Junti Mace was a legendary melee weapon that was considered a myth until it was discovered by the explorer known as The Planetwalker. The mace was later acquired by the Rodian hunter Ziven Tissak.

## Specifications

- **Name:** Junti Mace
- **Type:** Mace
- **Owners:**

  - Ziven Tissak
- **Purpose:** Melee combat
