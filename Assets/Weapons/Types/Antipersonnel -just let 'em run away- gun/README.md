# Antipersonnel "just let 'em run away" gun

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Antipersonnel "just let 'em run away" gun](https://starwars.fandom.com/wiki/Antipersonnel_%22just_let_%27em_run_away%22_gun)

The antipersonnel "just let 'em run away" gun was a model of blaster cannon which was less popular and considered less effective than the antipersonnel pursuit gun, a blaster used on the 74-Z speeder bike.
