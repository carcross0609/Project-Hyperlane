# Plasma pike

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Plasma pike](https://starwars.fandom.com/wiki/Plasma_pike)

The plasma pike was a type of pike utilised by a group of the Order of the Night Wind assassins during an ambush outside of the Sanctuary in Mos Espa.

- **Type:** Pike
