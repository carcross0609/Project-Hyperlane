# Caltrop

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Caltrop/Legends](https://starwars.fandom.com/wiki/Caltrop/Legends)

A caltrop was a type of defensive antipersonnel weapon made of sharp spikes. Caltrops were dropped to form a field which would slow enemies.
