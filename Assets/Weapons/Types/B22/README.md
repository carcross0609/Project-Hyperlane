# B22

**Kind:** Model  
**Continuity:** Canon  
**Source:** [B22](https://starwars.fandom.com/wiki/B22)

The B22 was a mechanically-activated blaster pistol produced by Merr-Sonn Munitions, Inc. and used during the Galactic Civil War. During the Siege of Inyusu Tor in 3 ABY, the Imperial Captain Tabor Seitaron owned one of these pistols as a sidearm and used it in an attempt to break up a fight between Prelate Verge and the Imperial-turned–rebel asset, Everi Chalis aboard the Imperial II-class Star Destroyer Herald. Although Seitaron intended to shoot Chalis, he accidentally shot and killed Verge instead.
