# Krayt's Scatter Gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Krayt's Scatter Gun](https://starwars.fandom.com/wiki/Krayt%27s_Scatter_Gun)

The Krayt's Scatter Gun was a scatter gun owned by the Trandoshan Hunter Charr that he could wield for the Hunters of the Outer Rim competition on Vespaara as an alternative to his standard slugthrower. This gun was adorned with the upper skull of a reptilian-like creature resembling a small krayt dragon.

- **Name:** Krayt's Scatter Gun
- **Type:** Scatter gun
- **Owners:** Charr
