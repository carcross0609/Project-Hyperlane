# Soft-coat stick

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Soft-coat stick](https://starwars.fandom.com/wiki/Soft-coat_stick)

Soft-coat sticks were a type of combat stick used for training and sparring by cadets at the Chiss Expansionary Defense Fleet's Taharim Academy on the Chiss Ascendancy planet Naporar. Between 39 BBY and 37 BBY, the cadets Mitth'raw'nuruodo, core name "Thrawn," and Irizi'ar'alani, core name "Ziara," sparred with soft-coat sticks at a dojo on the planet. Ziara noted that the soft-coat sticks had the same weight and balance as real combat sticks.
