# Vr'gedian tranquilizer harpoon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vr'gedian tranquilizer harpoon](https://starwars.fandom.com/wiki/Vr%27gedian_tranquilizer_harpoon)

A Vr'gedian tranquilizer harpoon, also known as a tranq spear, was a weapon that could subdue a creature. The hunters Nokk and Winloss carried a Vr'gedian tranquilizer harpoon, and used it when hunting the Shadowfang Beast for Doctor Chelli Aphra. Nokk tried to use the harpoon against the creature, but the weapon broke, damaging the beast's scales slightly.
