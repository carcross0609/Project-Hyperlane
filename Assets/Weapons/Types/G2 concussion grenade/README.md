# G2 concussion grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [G2 concussion grenade](https://starwars.fandom.com/wiki/G2_concussion_grenade)

The G2 was a type of concussion grenade manufactured by Merr-Sonn Munitions, Inc. during the Galactic Civil War and cost 100 credits. Its purpose was to disorient any opponents it did not kill.

## Specifications

- **Name:** G2 concussion grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** G2
- **Type:** Concussion grenade
- **Cost:** 100 credits
