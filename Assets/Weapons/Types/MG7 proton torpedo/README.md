# MG7 proton torpedo

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MG7 proton torpedo](https://starwars.fandom.com/wiki/MG7_proton_torpedo)

The MG7 proton torpedo was a model of proton torpedo manufactured by Krupx. Featuring guidance computers, it was generally used to soften targets for strafing runs, but could also destroy key targets such as engines or deflector shield generators.

## Specifications

- **Name:** MG7 proton torpedo
- **Manufacturer:** Krupx
- **Type:** Proton torpedo
