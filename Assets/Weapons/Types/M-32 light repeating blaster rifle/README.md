# M-32 light repeating blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [M-32 light repeating blaster rifle](https://starwars.fandom.com/wiki/M-32_light_repeating_blaster_rifle)

The M-32 light repeating blaster rifle, also known as drum blaster, was a model of light repeating blaster manufactured by Drearian Defense Conglomerate that was used by Carasynthia Dune after she received it from Din Djarin. She used it in many conflicts, including on Sorgan, and while rescuing Grogu, during which it jammed, and was fixed by Dune by slamming it against a wall.
