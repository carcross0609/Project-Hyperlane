# Mini-Torpedo Launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mini-Torpedo Launcher](https://starwars.fandom.com/wiki/Mini-Torpedo_Launcher)

The Mini-Torpedo Launcher was a torpedo launcher developed by Mon Cal Defenses, which fired self-propelled mini-torpedoes that would detonate on impact. This weapon was primarily designed for underwater combat and was attachable to heavy underwater battle armor.

## Specifications

- **Name:** Mini-Torpedo Launcher
- **Manufacturer:** Mon Cal Defenses
- **Type:** Torpedo launcher
- **Cost:** 1,250 credits
- **Capacity:** 3
- **Range:** 350 meters
