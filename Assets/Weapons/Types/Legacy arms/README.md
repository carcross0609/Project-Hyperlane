# Legacy arms

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Legacy arms](https://starwars.fandom.com/wiki/Legacy_arms)

The Legacy arms were a type of slugthrowers produced by Czerka Arms during the Galactic Civil War between the Galactic Empire and the Alliance to Restore the Republic. The weapons were appreciated in the Outer Rim Territories. One of these arms was the Model 38 sharpshooter's rifle.

- **Name:** Legacy arms
- **Manufacturer:** Czerka Arms
- **Type:** Slugthrower
