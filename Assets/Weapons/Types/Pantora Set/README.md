# Pantora Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Pantora Set](https://starwars.fandom.com/wiki/Pantora_Set)

The Pantora Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These ornate weapons featured a metallic orange, light blue, and dark blue, and tan color scheme, with yellow and light blue decorative designs on the bodies, as well as large, glowing, lamp-like barrels, with the Arc Caster's glowing orangish-yellow, while the Pulse Blaster's being yellowish-green.
