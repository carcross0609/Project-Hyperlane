# Mk I Saberdart

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mk I Saberdart/Legends](https://starwars.fandom.com/wiki/Mk_I_Saberdart/Legends)

The Mk I Saberdart, or referred to simply as a Kamino saberdart, was a type of toxic dart manufactured by Kaminoan Weaponsmiths, a Kaminoan company headquartered on Kamino.

## Specifications

- **Name:** Mk I Saberdart
- **Manufacturer:** Kaminoan Weaponsmiths
- **Model:** Mk I
- **Type:** Poison dart
- **Culture:** Kaminoan
- **Locations:**
  - Kamino
  - Subterrel
- **Material:** Durasteel
- **Purpose:** Carry neurotoxins
