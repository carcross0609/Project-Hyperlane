# 88i twin light blaster cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [88i twin light blaster cannon](https://starwars.fandom.com/wiki/88i_twin_light_blaster_cannon)

The 88i twin light blaster cannon was a model of light blaster cannon manufactured by Yaove Gunsmiths. It was part of the standard armaments on All Terrain Scout Transports of the Galactic Empire's military forces. Mounted on the port side of the walker's command module, it was capable of rotating in a 360 degree arc.
