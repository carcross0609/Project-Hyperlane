# Dathomirian poison dart

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Dathomirian poison dart](https://starwars.fandom.com/wiki/Dathomirian_poison_dart)

The Dathomirian poison dart was a type of poison dart used by the Nightsisters of Dathomir. During the Clone Wars, former Sith acolyte Asajj Ventress utilized the dart to dull the senses of Count Dooku in an attempt to exact revenge for his betrayal in the Battle of Sullust.
