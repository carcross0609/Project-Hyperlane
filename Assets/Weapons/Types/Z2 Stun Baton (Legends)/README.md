# Z2 Stun Baton

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Z2 Stun Baton/Legends](https://starwars.fandom.com/wiki/Z2_Stun_Baton/Legends)

The Z2 Stun Baton was a refined version of the original stun baton manufactured by Merr-Sonn Munitions, Inc.. It featured an adjuster knob to enhance the weapon's effect. At higher power levels, it could cause more damage but drained its energy cells much quicker. It was used by both the Galactic Empire and the New Republic Security Force.

## Specifications

- **Name:** Z2 Stun Baton
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Stun baton
- **Cost:** 200 to 400 credits
- **Size:** Medium
