# Actinium bomb

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Actinium bomb](https://starwars.fandom.com/wiki/Actinium_bomb)

Actinium Bombs were a type of explosives used by the Confederacy of Independent Systems. Imperial Investigation teams suspect that these were the type of bombs used in the destruction of the planet Caamas.
