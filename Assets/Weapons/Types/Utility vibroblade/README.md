# Utility vibroblade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Utility vibroblade](https://starwars.fandom.com/wiki/Utility_vibroblade)

A utility vibroblade was a style of vibroblade. The Rodian Tsoklo, an informant for the Galactic Empire on the planet Lothal, owned a utility vibroblade, which he kept as a weapon.
