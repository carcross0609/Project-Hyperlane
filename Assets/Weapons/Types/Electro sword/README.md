# Electro sword

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro sword](https://starwars.fandom.com/wiki/Electro_sword)

The electro sword was a type of electrified short sword used by the Kage Warriors of the planet Quarzite. Electro swords were used as melee weapons but were also often used as throwing blades, as Krismo Sodi used one in such a fashion to kill the Belugan Major Rigosso.
