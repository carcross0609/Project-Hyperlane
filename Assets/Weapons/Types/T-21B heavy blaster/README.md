# T-21B heavy blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [T-21B heavy blaster](https://starwars.fandom.com/wiki/T-21B_heavy_blaster)

The T-21B heavy blaster was a long-range version of the T-21 heavy blaster. It boasted two optics which the T-21 lacked, making it deadly at greater distances, but not useful for close quarters combat.
