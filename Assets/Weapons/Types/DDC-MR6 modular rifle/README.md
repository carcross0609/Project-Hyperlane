# DDC-MR6 modular rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DDC-MR6 modular rifle](https://starwars.fandom.com/wiki/DDC-MR6_modular_rifle)

The DDC-MR6 modular rifle was a model of modular blaster rifle that was built with an electromagnetic rail system that allowed users to quickly reconfigure the rifle for different situations. The rail system consisted of electromagnetic strips along the body of the weapon, which mean attachments could be swapped quickly even during battle. The rifle was also equipped with a stun setting.

## Specifications

- **Name:** DDC-MR6 modular rifle
- **Manufacturer:** Drearian Defense Conglomerate
- **Model:** DDC-MR6
- **Type:** Blaster rifle
- **Cost:** 1000 credits
