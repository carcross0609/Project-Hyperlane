# Baragwin assault gun

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Baragwin assault gun](https://starwars.fandom.com/wiki/Baragwin_assault_gun)

The Baragwin assault gun was a light repeating blaster that had been modified from existing repeater designs by the Baragwin, who were famous as skilled weaponsmiths. This model boasted a greatly increased damage output and added functionality with a variety of upgrade options.

## Specifications

- **Name:** Baragwin assault gun
- **Type:** Light repeating blaster
