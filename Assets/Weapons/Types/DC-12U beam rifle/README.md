# DC-12U beam rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DC-12U beam rifle](https://starwars.fandom.com/wiki/DC-12U_beam_rifle)

The DC-12U beam rifle, also known as the SCUBA trooper rifle, was a specialized blaster rifle that could operate underwater. It was a double-barreled blaster that came equipped with a glowlight attachment to provide visibility in dark ocean depths.
