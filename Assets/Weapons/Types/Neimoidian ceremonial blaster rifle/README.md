# Neimoidian ceremonial blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Neimoidian ceremonial blaster rifle](https://starwars.fandom.com/wiki/Neimoidian_ceremonial_blaster_rifle)

Members of the Neimoidian Royal Guard used ceremonial blaster rifles that were a type of long rifle. When writing about them for a report on organic soldiers of the Confederacy of Independent Systems to be included in the survival compendium "Neyo's Almanac of Clankers," the Advanced Recon Commando Muzzle claimed the weapons strongly resembled ancient projectile rifles and appeared just as impractical to wield, although the clone admitted that the Neimoidians used them skillfully.

## Specifications

- **Name:** Neimoidian ceremonial blaster rifle
- **Type:** Long rifle
- **Culture:** Neimoidian
