# I.M. mine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [I.M. mine](https://starwars.fandom.com/wiki/I.M._mine)

The I.M. mine was a simple type of land mine that could be set to explode in two functions: either by timeset or by proximity. It was manufactured by Imperial Machines.

## Specifications

- **Name:** I.M. mine
- **Manufacturer:** Imperial Machines
- **Type:** Land mine
