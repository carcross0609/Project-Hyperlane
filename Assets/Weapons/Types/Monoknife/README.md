# Monoknife

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Monoknife](https://starwars.fandom.com/wiki/Monoknife)

A monoknife was a model of knife that was often included within concealed escape kits, specialized kits that could be stored within the sole of a shoe and used to escape temporary imprisonment.
