# Karpaki Fifty

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Karpaki Fifty](https://starwars.fandom.com/wiki/Karpaki_Fifty)

The Karpaki Fifty was a slugthrower sniper rifle. Several modified Karpaki Fifties were used by the Galactic Alliance Guard in 40 ABY. One was used by Ben Skywalker to assassinate Dur Gejjen.

## Specifications

- **Name:** Karpaki Fifty
- **Model:** Sniper rifle
- **Type:** Slugthrower
- **Affiliation:** Galactic Alliance Guard
