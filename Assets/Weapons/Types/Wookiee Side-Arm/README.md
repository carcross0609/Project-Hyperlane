# Wookiee Side-Arm

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Wookiee Side-Arm](https://starwars.fandom.com/wiki/Wookiee_Side-Arm)

The Wookiee Side-Arm, also known as the Wookiee Blaster Pistol, was a model of blaster pistol was mass-produced by Wookiee workshops across the planet Kashyyyk around the time of the Clone Wars. The pistol featured a bronzium-alloy blast suppressor.

## Specifications

- **Name:** Wookiee Side-Arm
- **Type:** Blaster pistol
- **Material:** Bronzium alloy (blast suppressor)
- **Affiliation:** Wookiees
