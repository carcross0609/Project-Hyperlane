# Unidentified blaster pistol model

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Unidentified blaster pistol model](https://starwars.fandom.com/wiki/Unidentified_blaster_pistol_model)

A type of blaster pistol that was owned by Clone Commander Scorch, a clone commando in service to the Galactic Empire's Advanced Science Division. The blaster was largely black in color, while the top of the gun barrel and a line across each weapon's side was silver. Between that silver barrel portion and the rest of the pistol was also a blue coloration, with a red line present on each side above where a soldier's hand held the blaster pistol. The back of the pistol also featured a green line.
