# Mortar

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Mortar](https://starwars.fandom.com/wiki/Mortar)

A mortar was an indirect fire weapon that hurled explosive projectiles in a high arc. Certain models, such as those used by the Grand Army of the Republic during the Clone Wars, were portable enough to be carried by one clone trooper. Others were more suitable to be mounted on vehicles, such as those on some Imperial All Terrain Scout Transports.

## Specifications

- **Name:** Mortar
- **Purpose:** Launching projectiles at the enemy from a distance
- **Affiliation:**
  - Galactic Republic
  -   501st Legion
  - Galactic Empire
  - Gideon's Imperial remnant
