# Magnetising cluster bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Magnetising cluster bomb](https://starwars.fandom.com/wiki/Magnetising_cluster_bomb)

Magnetising cluster bombs, also known as magnetic cluster bombs, were explosive weapons carried by bomber craft such as the Rebel Alliance's Y-wings during the Galactic Civil War. The bombs were spherical in appearance and were able to be magnetized, which allowed them to attach to the metallic hulls of heavily armored vehicles such as All Terrain Armored Transports and produce great damage when released in vast numbers.

- **Type:** Cluster bomb
