# The Void (weapon)

**Kind:** Model  
**Continuity:** Legends  
**Source:** [The Void (weapon)](https://starwars.fandom.com/wiki/The_Void_%28weapon%29)

The Void was a heavy projectile weapon named after a heroic commando in the early wars. It was used by some commandos at the time of the Galactic Civil War.
