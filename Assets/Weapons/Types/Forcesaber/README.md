# Forcesaber

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Forcesaber](https://starwars.fandom.com/wiki/Forcesaber)

The Forcesaber was a Rakatan invention in which powerful dark-side energy was channeled through laboratory-grown ebon crystals in glowing energy blades, able to be ignited like the much later developed lightsaber.
