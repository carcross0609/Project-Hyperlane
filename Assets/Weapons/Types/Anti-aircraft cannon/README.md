# Anti-aircraft cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Anti-aircraft cannon](https://starwars.fandom.com/wiki/Anti-aircraft_cannon)

Anti-aircraft cannons were a type of weapon designed to destroy starships. These cannons were employed by the Galactic Republic's experimental stealth ship, which took part in the Battle of Christophsis during the Clone Wars. J-1 proton cannons were a type of anti-aircraft cannon. The Galactic Empire utilized the All Terrain Anti Aircraft as well as manned stationary turrets for anti-air defense.
