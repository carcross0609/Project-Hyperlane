# Ostrine edge

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ostrine edge](https://starwars.fandom.com/wiki/Ostrine_edge)

An ostrine edge was a type of melee weapon edge that had been augmented by a refined form of a rare, heat-absorbing mineral known as ostrine from the planet Hargeeva. Affixed to a weapon, the edge emitted an extreme chill that caused additional damage to objects that it struck, and it also partially protected the user from fires and extreme heat by decreasing the surrounding temperature. The edge was silver in color except for a red part of the edge near the weapon's hilt. Used during the time of the Dark Wars in 3951 BBY, the weapon upgrade sold for 28,850 credits.
