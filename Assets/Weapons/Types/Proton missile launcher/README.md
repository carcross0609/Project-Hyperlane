# Proton missile launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Proton missile launcher](https://starwars.fandom.com/wiki/Proton_missile_launcher)

The proton missile launcher had miniature proton warheads. Each clip contained five missiles. It was especially useful for neutralizing droids and other machinery. The ammunition for it was particularly hard to find, keeping wielders from overusing them. They were used during the Invasion of Naboo in 32 BBY.

## Specifications

- **Name:** Proton missile launcher
- **Model:** Missile launcher
- **Type:** Proton missile launcher
- **Capacity:** 5 proton missiles
