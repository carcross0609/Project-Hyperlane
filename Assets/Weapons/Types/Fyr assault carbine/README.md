# Fyr assault carbine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Fyr assault carbine](https://starwars.fandom.com/wiki/Fyr_assault_carbine)

The Fyr assault carbine was a type of slugthrower carbine that was manufactured by Glunok, an obscure Andoan arms manufacturer that offered a wide range of modern combat slugthrowers. It was manufactured as a response to the threat of possible Jedi invasions during the Clone Wars after many Aqualish aligned with the Confederacy of Independent Systems.

## Specifications

- **Name:** Fyr assault carbine
- **Manufacturer:** Glunok
- **Type:** Slugthrower carbine
- **Cost:** 250 credits
- **Range:** Short range
