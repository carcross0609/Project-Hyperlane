# OK-98 blaster carbine

**Kind:** Model  
**Continuity:** Canon  
**Source:** [OK-98 blaster carbine](https://starwars.fandom.com/wiki/OK-98_blaster_carbine)

The OK-98 blaster carbine was a type of blaster carbine manufactured by SoroSuub Corporation. It featured twin power packs that doubled the carbine's ammunition capacity. Although it was known to perform adequately, the OK-98 sold poorly, so despite its large production run, the blaster carbine was discontinued by SoroSuub and they were auctioned off.
