# Laser array

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Laser array](https://starwars.fandom.com/wiki/Laser_array)

A Laser array was a type of blaster weapon that projected bursts of particle beam energy. The Sith Lord Darth Scabrous' HK droid was equipped with a pair of augmented laser arrays.
