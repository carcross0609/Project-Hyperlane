# Type A pulse-wave rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Type A pulse-wave rifle](https://starwars.fandom.com/wiki/Type_A_pulse-wave_rifle)

The Type A pulse-wave rifle was basically a larger version of a pulse-wave blaster. It was long and heavy, and its effectiveness dropped at longer ranges.

## Specifications

- **Name:** Type A pulse-wave rifle
- **Manufacturer:** Greff-Timms Industrial
- **Type:** Pulse-wave rifle
- **Cost:** 1,200—2,000 credits
- **Weight:** 7.7 kilograms
- **Capacity:** 50
- **Range:** 150 meters
