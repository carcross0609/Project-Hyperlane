# CDEF carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CDEF carbine](https://starwars.fandom.com/wiki/CDEF_carbine)

The CDEF carbine was a very basic, low cost carbine weapon used during the time of the Galactic Civil War. The Corellian Security Force was known to incorporate the CDEF carbine and other CDEF weaponry into their arsenal.

## Specifications

- **Name:** CDEF carbine
- **Type:** Blaster carbine
- **Range:** 45 meters
- **Affiliation:** Corellian Security Force
