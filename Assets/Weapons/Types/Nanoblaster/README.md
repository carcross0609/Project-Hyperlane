# Nanoblaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Nanoblaster](https://starwars.fandom.com/wiki/Nanoblaster)

A nanoblaster was a type of blaster. When visiting the Weigh Station Karambola, Lando Calrissian asked Smooyt if they had managed to get ahold of some nanoblasters before being cut off by Smooyt.
