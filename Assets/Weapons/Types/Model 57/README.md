# Model 57

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Model 57](https://starwars.fandom.com/wiki/Model_57)

The Model 57 was a blaster manufactured by Merr-Sonn Munitions, Inc. to compete with BlasTech Industries's DL-44 heavy blaster pistol. It succeeded on the market and became known as a legal, low-power alternative to the DL-44.
