# L-s7.2 laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [L-s7.2 laser cannon](https://starwars.fandom.com/wiki/L-s7.2_laser_cannon)

The L-s7.2 laser cannon was a laser cannon that was equipped on TIE fighters. It was an improved design over the earlier L-s1 laser cannon that offered a lower recycle time and faster rate of fire.
