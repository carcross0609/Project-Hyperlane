# BTZ-47 heavy assault cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [BTZ-47 heavy assault cannon](https://starwars.fandom.com/wiki/BTZ-47_heavy_assault_cannon)

BTZ-47 heavy assault cannon was a blaster cannon model used during the Galactic War between the Galactic Republic and the reconstituted Sith Empire. One such cannon named Bitsy was used by the Whiphid recruiter K'krohl.
