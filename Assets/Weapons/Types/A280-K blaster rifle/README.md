# A280-K blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [A280-K blaster rifle](https://starwars.fandom.com/wiki/A280-K_blaster_rifle)

The A280-K blaster rifle was a model of blaster rifle, a variant of the A280 blaster rifles manufactured by BlasTech Industries. In 8 ABY, during the Battle of Kal'Shebbol, Katarn Commandos member Gottu carried an A280-K blaster rifle.
