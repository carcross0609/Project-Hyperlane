# Bubble wort projector

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Bubble wort projector](https://starwars.fandom.com/wiki/Bubble_wort_projector)

The bubble wort projector was a Gungan device used by the Amidalans to trap enemies. The device was composed of an energy field that made blaster bolts ricochet inside the bubble, in order to kill the shooter.

- **Name:** Bubble wort projector
- **Culture:** Gungan
