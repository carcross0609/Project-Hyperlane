# Lightning Rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Lightning Rifle](https://starwars.fandom.com/wiki/Lightning_Rifle)

A Lightning Rifle was a ranged weapon that emitted bursts of extremely concentrated electrical energy. A more powerful and more accurate version was the Heavy Lightning Rifle. The user manual specifically warned about using it underwater.

## Specifications

- **Name:** Lightning Rifle
- **Type:** Electroshock rifle
