# Plasma bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Plasma bomb](https://starwars.fandom.com/wiki/Plasma_bomb)

Plasma bombs were a type of explosive plasma weapon. They were used for orbital strikes against hardened ground targets. Free Virgillia-class bunkerbusters carried three high-yield (100 Megatons) heavy plasma bombs of Virgillian design.
