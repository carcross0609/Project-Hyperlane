# Charric rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Charric rifle](https://starwars.fandom.com/wiki/Charric_rifle)

Charric rifles were a type of charric. Chiss sharpshooters were armed with charric sniper rifles.
