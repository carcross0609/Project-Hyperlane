# C-10 stun grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [C-10 stun grenade/Legends](https://starwars.fandom.com/wiki/C-10_stun_grenade/Legends)

The C-10 stun grenade was a non-lethal explosive device developed by Merr-Sonn Munitions, Inc.. It had a smooth, round surface and was designed to stun its targets by concussive force.

- **Type:** Stun grenade
