# First Order proton torpedo

**Kind:** Model  
**Continuity:** Canon  
**Source:** [First Order proton torpedo](https://starwars.fandom.com/wiki/First_Order_proton_torpedo)

The First Order proton torpedo was a model of proton torpedo manufactured for the First Order. It was fired from a prototype launcher installed on the TIE/vn space superiority fighter.
