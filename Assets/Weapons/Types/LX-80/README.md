# LX-80

**Kind:** Model  
**Continuity:** Legends  
**Source:** [LX-80](https://starwars.fandom.com/wiki/LX-80)

The LX-80 was an anti-infantry missile launcher emplacement. Developed by Merr-Sonn Munitions, the launcher used missiles designed for the company's PLX series of portable missile launchers. The LX-80 launcher contained eighty missiles in as many missile tubes, and an automatic loader could reload those tubes with the launcher's reserve of missiles when the first payload was expended.

## Specifications

- **Name:** LX-80
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** LX-80
- **Type:** Anti-infantry missile launcher
- **Cost:** 75,000 credits

- **Range:** 10 kilometers
