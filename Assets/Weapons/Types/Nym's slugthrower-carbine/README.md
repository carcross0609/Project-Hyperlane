# Nym's slugthrower-carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Nym's slugthrower-carbine](https://starwars.fandom.com/wiki/Nym%27s_slugthrower-carbine)

Nym's slugthrower-carbine was a weapon produced by Nym. This slugthrower featured a liquid piston shock-absorbing stock assembly, and an advanced heat dissipation system for greater firepower, allowing for longer bursts exceeding most other carbines.
