# Rodian death blade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Rodian death blade](https://starwars.fandom.com/wiki/Rodian_death_blade)

The Rodian death blade was a short sword with a black and red hilt. This more powerful version of the standard Rodian blade was coated in a molecular-bonded poison that caused extreme pain and even death.

- **Name:** Rodian death blade
- **Type:** Sword
