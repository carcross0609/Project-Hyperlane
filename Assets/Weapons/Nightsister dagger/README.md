# Nightsister dagger

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Nightsister dagger](https://starwars.fandom.com/wiki/Nightsister_dagger)

A Nightsister dagger was a traditional, bladed weapon of the Nightsisters of Dathomir. It was commonly used by the clan led by Mother Talzin during the Clone Wars.
