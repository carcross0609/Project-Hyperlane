# ST2 concussion missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [ST2 concussion missile/Legends](https://starwars.fandom.com/wiki/ST2_concussion_missile/Legends)

The Arakyd ST2 concussion missile was a type of concussion missile armament installed in the Millennium Falcon by Han Solo.

## Specifications

- **Name:** ST2 concussion missile
- **Manufacturer:** Arakyd Industries
- **Type:** Concussion missile
- **Cost:** 750 credits
- **Length:** More than 1 meter
- **Range:**
  - 300 meters (optimum)
  - 700 meters (maximum)
