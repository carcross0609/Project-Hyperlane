# Snare rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Snare rifle/Legends](https://starwars.fandom.com/wiki/Snare_rifle/Legends)

The snare rifle was a cord-shooting weapon designed to ensnare a target so that they can be captured alive.

## Specifications

- **Name:** Snare rifle
- **Type:** Cord-launching rifle
- **Cost:** 1,200 credits
- **Size:** Medium
- **Weight:** 5 kg
- **Capacity:** 5 shots
- **Range:**
  - Optimum: up to 45 meters
  - Maximum: up to 450 meters
- **Purpose:** To capture targets alive
