# Armor-piercing grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Armor-piercing grenade](https://starwars.fandom.com/wiki/Armor-piercing_grenade)

Armor-piercing grenades were oversized grenades that were effective against armored vehicles. The grenades cost 100 credits per unit and could be set to detonate on impact, on a timer, or when it was affected by pressure.

## Specifications

- **Name:** Armor-piercing grenade
- **Type:** Grenade
- **Cost:** 100 credits
