# Echo Horn

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Echo Horn](https://starwars.fandom.com/wiki/Echo_Horn)

The Echo Horn was a weapon created by Glenna Kip as a way to control the Zixon, the native species of Minfar for the Galactic Empire. It had the ability to control any group that heard its call. After the fall of the Empire, the First Order traveled to Minfar to obtain the weapon, although it was successfully destroyed by the Resistance.
