# Kunai

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Kunai](https://starwars.fandom.com/wiki/Kunai)

A kunai was a small bladed weapon used by Jedi Hunters. Sparks activated when they were thrown. The Jedi Hunters Unda and Anda threw kunai to destroy the automated defenses of an abandoned ship while trying to capture the Jedi Lah Kara.
