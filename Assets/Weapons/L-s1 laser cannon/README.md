# L-s1 laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [L-s1 laser cannon](https://starwars.fandom.com/wiki/L-s1_laser_cannon)

The L-s1 laser cannon was a laser cannon manufactured by Sienar Fleet Systems. TIE/ln space superiority starfighters were each equipped with a pair of L-s1 laser cannons. These could be found on multiple Imperial fighters. Those such as TIE/ln space superiority, TIE/sa bomber, TIE/sk x1 experimental air superiority fighter, TIE/d "Defender" Multi-Role Starfighter, TIE/IN interceptor, and TIE Advanced x1.
