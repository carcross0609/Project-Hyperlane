# Fuel-air bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Fuel-air bomb](https://starwars.fandom.com/wiki/Fuel-air_bomb)

A fuel-air bomb was an anti-personnel weapon that used atmospheric oxygen as an oxidizer. This created a powerful explosion and created a temporary vacuum in the blast zone.

## Specifications

- **Name:** Fuel-air bomb
- **Type:** Explosive
- **Cost:** 150 credits
