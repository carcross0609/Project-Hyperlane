# Shield turret

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Shield turret](https://starwars.fandom.com/wiki/Shield_turret)

Shield turrets were a type of custom automated defensive emplacement designed by the Mon Calamari Hunter Sprocket for use in the Hunters of the Outer Rim competition hosted on the planet Vespaara. These turrets could generate shields, protecting Sprocket's allies within its vicinity while active.

- **Name:** Shield turret
- **Type:** Turret
- **Creators:** Sprocket
- **Owners:** Sprocket
- **Purpose:** Defensive emplacement
- **Affiliation:** Hunters of the Outer Rim
