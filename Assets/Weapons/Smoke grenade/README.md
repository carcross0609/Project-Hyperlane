# Smoke grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Smoke grenade](https://starwars.fandom.com/wiki/Smoke_grenade)

Smoke grenades, also known as smoke bombs or smoke balls, were an explosive device which, upon triggering, would release a cloud of dense smoke, blocking the target's vision.

## Specifications

- **Name:** Smoke grenade
- **Type:** Grenade
- **Affiliation:**
