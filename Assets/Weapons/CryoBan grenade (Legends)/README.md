# CryoBan grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CryoBan grenade/Legends](https://starwars.fandom.com/wiki/CryoBan_grenade/Legends)

The CryoBan grenade, also named cryo grenade, was a type of grenade that could temporarily freeze targets.

## Specifications

- **Name:** CryoBan grenade
- **Type:** Grenade
- **Cost:** 500–800 credits
- **Size:** Handheld
- **Weight:** 0.5 kg
- **Capacity:** Single-use
- **Range:**
  - Thrown weapon range
  - 3-meter blast radius
- **Purpose:**
  - Firefighting tool
  - To temporarily freeze targets
