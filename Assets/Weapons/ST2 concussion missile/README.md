# ST2 concussion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [ST2 concussion missile](https://starwars.fandom.com/wiki/ST2_concussion_missile)

The ST2 concussion missile was a model of concussion missile manufactured by Arakyd Industries. These were the standard missiles used in the Millennium Falcon, which Han Solo modified with a pair of Arakyd ST2 concussion missile tubes that could launch either these or Dymek concussion missiles.

## Specifications

- **Name:** ST2 concussion missile
- **Manufacturer:** Arakyd Industries
- **Model:** ST2
- **Type:** Concussion missile
- **Cost:** 750 credits
- **Length:** More than a meter
- **Range:**
  - 300 meters (optimum)
  - 700 meters (max)
