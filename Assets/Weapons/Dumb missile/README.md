# Dumb missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dumb missile](https://starwars.fandom.com/wiki/Dumb_missile)

Dumb missiles were basic unguided concussion missiles manufactured by Arakyd Industries. They cost five hundred credits per missile, and could be used with the Morne-3 Concussion Missile Launcher.

## Specifications

- **Name:** Dumb missile
- **Manufacturer:** Arakyd Industries
- **Type:** Concussion missile
- **Cost:** 500 credits
