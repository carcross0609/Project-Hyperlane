# Deck Sweeper

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Deck Sweeper](https://starwars.fandom.com/wiki/Deck_Sweeper)

"Deck Sweeper" was the nickname given to a heavy repeating blaster owned by the Gabdorin pirate Quiggold, who was part of Sidon Ithano's pirate crew.
