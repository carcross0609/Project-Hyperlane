# RG-4D

**Kind:** Model  
**Continuity:** Canon  
**Source:** [RG-4D](https://starwars.fandom.com/wiki/RG-4D)

The RG-4D was a model of blaster pistol. Some OOM command battle droids of the Separatist Droid Army made use of the RG-4D. During the later Republic Era, the droids of a police force used RG-4Ds and during the Clone Wars, spaceport police droids were also equipped with the pistol.
