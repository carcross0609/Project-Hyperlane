# Knockout drops

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Knockout drops](https://starwars.fandom.com/wiki/Knockout_drops)

Knockout drops were a type of artificial poison that could render a target unconscious if ingested. They could be put into food or drink.

## Specifications

- **Name:** Knockout drops
- **Type:** Artificial poison
- **Created:** By 22 BBY
- **Locations:** Outlander Club, Coruscant
- **Purpose:** Rendering a target unconscious if ingested
- **Affiliation:**
  - Malkite Poisoners
  - Galactic Empire
  - Dark Empire
