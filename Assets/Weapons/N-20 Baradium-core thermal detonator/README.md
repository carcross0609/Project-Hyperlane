# N-20 Baradium-core thermal detonator

**Kind:** Model  
**Continuity:** Canon  
**Source:** [N-20 Baradium-core thermal detonator](https://starwars.fandom.com/wiki/N-20_Baradium-core_thermal_detonator)

The N-20 Baradium-core thermal detonator was a model of thermal detonator manufactured by BlasTech Industries, worn on the backs of the belts of clone troopers and Imperial stormtroopers. Settings were available for arming, blast intensity, and timing. However, the detonator's controls were unlabeled to prevent enemy troopers from activating them.
