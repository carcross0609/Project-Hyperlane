# Flux cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Flux cannon](https://starwars.fandom.com/wiki/Flux_cannon)

The flux cannon was a type of emplacement weapon developed by the Anomid Schism Collective that was able to destroy capital ships in a single blast. The Emperor's Fortress was equipped with a number of flux cannons, which the Collective constructed when Darth Malgus seized the space station as his own.
