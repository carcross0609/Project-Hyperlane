# Octuple turbolaser barbette

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Octuple turbolaser barbette](https://starwars.fandom.com/wiki/Octuple_turbolaser_barbette)

The octuple turbolaser barbette was a type of turbolaser. Imperial II-class Star Destroyers were equipped with eight of them, four on the port side and four on the starboard side.
