# Concussion rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Concussion rifle](https://starwars.fandom.com/wiki/Concussion_rifle)

A concussion rifle was a type of rifle capable of discharging a concussion blast. The TL-50 Heavy Repeater used by Imperial Special Forces had the ability as secondary fire.

- **Name:** Concussion rifle
- **Type:** Rifle
- **Size:** Two-handed weapon
