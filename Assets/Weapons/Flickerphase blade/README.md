# Flickerphase blade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Flickerphase blade](https://starwars.fandom.com/wiki/Flickerphase_blade)

A flickerphase blade was a lightsaber that had been modified to allow its blade to ignite and extinguish at random intervals. Although combat with flickerphase blades could be more difficult than an ordinary lightsaber, it was challenging for an opponent to effectively block the weapon, a fact which caused the Jedi Order to generally view them as dishonorable and unsporting. Flickerphase blades cost 5,000 credits per unit and never saw widespread use.

- **Type:** Lightsaber
- **Cost:** 5,000 credits
