# Scavenger Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Scavenger Set](https://starwars.fandom.com/wiki/Scavenger_Set)

The Scavenger Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These sandy weathered weapons featured a brown, tan, orange, silver, and dark gray color scheme, both with vented barrels.
