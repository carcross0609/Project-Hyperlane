# Rakatan Battle Wand

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Rakatan Battle Wand](https://starwars.fandom.com/wiki/Rakatan_Battle_Wand)

A Rakatan Battle Wand was a stun weapon that was shaped only for the use by Rakatan hands and thus difficult for other species to use.
