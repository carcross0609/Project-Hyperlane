# HM-22 concussion missile launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [HM-22 concussion missile launcher](https://starwars.fandom.com/wiki/HM-22_concussion_missile_launcher)

The HM-22 concussion missile launcher was a type of concussion missile launcher manufactured by Dymek. Two launchers were installed on the RZ-2 A-wing interceptor, each loaded with a six-missile magazine.
