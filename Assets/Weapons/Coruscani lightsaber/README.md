# Coruscani lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Coruscani lightsaber](https://starwars.fandom.com/wiki/Coruscani_lightsaber)

A Coruscani lightsaber was constructed on the city-planet Coruscant by Duros Jedi artisan Felanil Baaks. The Coruscani weapon had a single blue blade and a hilt encased in black, glass-like material through which its internal components could be seen.
