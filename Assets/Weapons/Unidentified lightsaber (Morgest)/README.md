# Unidentified lightsaber (Morgest)

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Unidentified lightsaber (Morgest)](https://starwars.fandom.com/wiki/Unidentified_lightsaber_%28Morgest%29)
