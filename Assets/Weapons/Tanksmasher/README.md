# Tanksmasher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Tanksmasher](https://starwars.fandom.com/wiki/Tanksmasher)

Tanksmasher rockets were a class of rocket that were able to pierce the armor of the All Terrain Tactical Enforcer, a battle tank used by the Galactic Republic during the Clone Wars.
