# Signal grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Signal grenade](https://starwars.fandom.com/wiki/Signal_grenade)

A signal grenade was a colored-smoke producing grenade which was used for alerting the attention of individuals from afar. On the planet Panisia, the Imperial Commander Ellian Zahra used a signal grenade to alert the attention of a Rebel Alliance strike team led by General Leia Organa.

## Specifications

- **Name:** Signal grenade
- **Type:** Grenade
- **Purpose:** Producing a smoke signal
- **Affiliation:** Galactic Empire
