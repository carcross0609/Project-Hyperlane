# Arquebus

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Arquebus](https://starwars.fandom.com/wiki/Arquebus)

Arquebus were Slugthrower pistols that were favored amongst the Vurks. The pistol was used for long distance targets and cost 1,200 credits per unit.
