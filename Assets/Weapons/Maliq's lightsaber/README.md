# Maliq's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Maliq's lightsaber](https://starwars.fandom.com/wiki/Maliq%27s_lightsaber)

Maliq's lightsaber was a green-bladed lightsaber utilized by Jedi Padawan Maliq. After Maliq's death, the weapon was wielded by his Jedi Master Rok Buran.
