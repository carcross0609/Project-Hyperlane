# Percussion Cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Percussion Cannon](https://starwars.fandom.com/wiki/Percussion_Cannon)

A Percussive Cannon was a type of blaster used in the galaxy. The Hylobon Enforcers of the Crimson Dawn criminal syndicate used JND-41 percussive cannons manufactured by Tostovin Munitions.
