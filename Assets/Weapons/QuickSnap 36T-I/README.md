# QuickSnap 36T/I

**Kind:** Model  
**Continuity:** Legends  
**Source:** [QuickSnap 36T/I](https://starwars.fandom.com/wiki/QuickSnap_36T/I)

The QuickSnap 36T/I was a blaster carbine manufactured by SoroSuub Corporation. It was not as powerful as SoroSuub's QuickSnap 36T, but cost the same.

## Specifications

- **Name:** QuickSnap 36T/I
- **Manufacturer:** SoroSuub Corporation
- **Type:** Blaster carbine
- **Cost:** 900 credits
