# Glaive

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Glaive](https://starwars.fandom.com/wiki/Glaive)

A glaive was a type of pike. The Nihil Tempest Runner Lourna Dee used a glaive with a jagged, electrified blade when she fought Jedi archivist OrbaLin in the Starlight Pavilion during the attack on Valo, although the weapon was eventually destroyed by OrbaLin's lightsaber. Geonosian Brood Alphas used glaives.
