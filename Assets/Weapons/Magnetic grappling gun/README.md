# Magnetic grappling gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Magnetic grappling gun](https://starwars.fandom.com/wiki/Magnetic_grappling_gun)

A magnetic grappling gun was a gun loaded with a grappling line that could magnetically latch onto its target. In 3 ABY, while infiltrating the Governor's mansion on the Mid Rim planet Haidoral Prime, a Rebel Alliance squad led by First Sergeant Hazram Namir used a magnetic grappling gun to reach one of the mansion's balconies from a nearby rooftop garden. Pol Andrissus set up the gun in one of the flower beds.
