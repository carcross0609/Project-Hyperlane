# "Bunker Buster" shell

**Kind:** Model  
**Continuity:** Canon  
**Source:** ["Bunker Buster" shell](https://starwars.fandom.com/wiki/%22Bunker_Buster%22_shell)

"Bunker Buster" shells were missiles used by both Armored Assault Tanks of the Separatist Droid Army and TX-130 Saber-class fighter tanks of the Grand Army of the Republic. At one point, an AAT used these shells against phase II clone troopers.
