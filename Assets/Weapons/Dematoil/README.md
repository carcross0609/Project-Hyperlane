# Dematoil

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Dematoil](https://starwars.fandom.com/wiki/Dematoil)

A dematoil was a rare Bitthævrian melee weapon resembling a morningstar. Each was custom-designed using the quills of defeated enemies as spikes. Bitthævrian custom required for the winner of a fight to take the loser's biggest quill from his weapon arm, and attach it to the weapon.

## Specifications

- **Name:** Dematoil
- **Type:** Morningstar
- **Culture:** Bitthævrian
- **Locations:** Guiteica
- **Cost:** Not available for sale
