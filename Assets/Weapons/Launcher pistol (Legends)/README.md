# Launcher pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Launcher pistol/Legends](https://starwars.fandom.com/wiki/Launcher_pistol/Legends)

The launcher pistol was a type of heavy weapon available during the Galactic Civil War. It emitted a suite of small target-seeking rockets with explosive tips.
