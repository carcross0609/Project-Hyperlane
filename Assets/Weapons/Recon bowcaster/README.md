# Recon bowcaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Recon bowcaster](https://starwars.fandom.com/wiki/Recon_bowcaster)

Recon bowcasters were weapons developed by Wookiee weaponsmiths and was a medium ranged recon version of the traditional bowcaster. This variant was more powerful than its lighter counterpart but still light enough for practical usage on long treks through the wilderness.
