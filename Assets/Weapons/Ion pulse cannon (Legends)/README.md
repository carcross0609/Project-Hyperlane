# Ion pulse cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Ion pulse cannon/Legends](https://starwars.fandom.com/wiki/Ion_pulse_cannon/Legends)

The T2 ion pulse cannon, or simply ion pulse cannon was a massive experimental ion cannon model fitted onto the Subjugator-class heavy cruiser Malevolence.

## Specifications

- **Name:** Ion pulse cannon
- **Model:** T2
- **Type:** Experimental heavy anti-capital ship ion cannon
- **Cost:** Not available for public sale
- **Size:** Several hundred meters in diameter
- **Affiliation:** Confederacy of Independent Systems
