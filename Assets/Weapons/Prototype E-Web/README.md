# Prototype E-Web

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Prototype E-Web](https://starwars.fandom.com/wiki/Prototype_E-Web)

The Prototype E-Web was a modified E-Web heavy repeating blaster cannon utilized by the Hunter Sentinel as he competed in the Grand Arena. It was tinkered and modified by another Hunter, Dizzy. Its capabilities included a combat shield, and a Suppressing Shot which could stun opponents.

## Specifications

- **Name:** Prototype E-Web
- **Model:** Modified E-Web heavy repeating blaster cannon
- **Type:** Heavy repeating blaster
- **Destroyed:** 9 ABY, Vespaara (rebuilt)
- **Owners:** Sentinel
- **Affiliation:**

  - Hunters of the Outer Rim
