# Malorum's blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Malorum's blaster](https://starwars.fandom.com/wiki/Malorum%27s_blaster)

The Inquisitor Malorum owned a blaster. He used this blaster to threaten the manager of Naboo Essentials Provider on Naboo. Malorum threatened to kill everyone inside the building in front of the managers eyes if the manager did not give up the address of Ryoo Thule. The manager, realizing Malorum was completely capable of it, gave up the address. Malorum stormed out of the building, wanting to have blasted the manager.
