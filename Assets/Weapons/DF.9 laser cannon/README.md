# DF.9 laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DF.9 laser cannon](https://starwars.fandom.com/wiki/DF.9_laser_cannon)

The DF.9 laser cannon was a laser cannon produced by Golan Arms. Versions of the weapon were included in the company's DF.9 anti-infantry battery, the Twin DF.9, the SP.9 Anti-Infantry Artillery Vehicle, the Twin SP.9, and the DF.9/B. The DF.9 was also used on Arakyd Industries' XR-85 tank droid.
