# BT-30 Termite Droid Launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [BT-30 Termite Droid Launcher](https://starwars.fandom.com/wiki/BT-30_Termite_Droid_Launcher)

The BT-30 Termite Droid Launcher was a model of termite torpedo launcher manufactured by Baktoid Industries. It cost 10,000 credits on the market and launched termite torpedos, a type of torpedo containing dozens of termite droids.

## Specifications

- **Name:** BT-30 Termite Droid Launcher
- **Manufacturer:** Baktoid Industries
- **Type:** Termite torpedo launcher
- **Cost:** 10,000 credits
- **Purpose:** Launch termite torpedos
