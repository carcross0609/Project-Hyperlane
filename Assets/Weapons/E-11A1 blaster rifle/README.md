# E-11A1 blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [E-11A1 blaster rifle](https://starwars.fandom.com/wiki/E-11A1_blaster_rifle)

The E-11A1 blaster rifle was essentially the same as the E-11A blaster rifle, however it was a bit more compact than the E-11A, allowing it to be worn in a holster and fired with one hand.
