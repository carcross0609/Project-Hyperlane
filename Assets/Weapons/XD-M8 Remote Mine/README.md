# XD-M8 Remote Mine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [XD-M8 Remote Mine](https://starwars.fandom.com/wiki/XD-M8_Remote_Mine)

XD-M8 Remote Mine was a type of explosive used by the Eternal Empire of Zakuul. During the Invasion of Voss in 3630 BBY, several such mines were used by Zakuulan forces in their attack on Voss-Ka.

## Specifications

- **Name:** XD-M8 Remote Mine
- **Model:** Mine
- **Type:** Explosive
- **Shape:** Oval
- **Affiliation:** Eternal Empire
