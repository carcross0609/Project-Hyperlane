# Commando special rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Commando special rifle](https://starwars.fandom.com/wiki/Commando_special_rifle)

The Commando special rifle was a blaster rifle used by Republic commandos of the Old Republic. It was sawed-off to reduce weight, but it delivered as much punch as a heavy blaster rifle. It's only drawback was reduced ammunition.

## Specifications

- **Name:** Commando special rifle
- **Type:** Blaster rifle
- **Cost:** 1,250 credits (Available for military use only)
- **Shape:** Rifle-shaped
- **Size:** Two-handed weapon
- **Weight:** 3.3 kg
- **Capacity:**
  - 25 shots
  - Autofire mode available
- **Range:**
  - Optimum: up to 45 m
  - Maximum: up to 450 m
- **Affiliation:**
  - Galactic Republic
  -   Republic commandos
