# Treppus-2 vibroknife

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Treppus-2 vibroknife](https://starwars.fandom.com/wiki/Treppus-2_vibroknife)

The Treppus-2 vibroknife was a popular type of vibro-knife produced by Merr-Sonn Munitions, Inc.. A good example of a standard vibroblade, the Treppus-2 served as the basis for Merr-Sonn's M8 Combat Knife, which was used by the Galactic Republic's clone troopers during the Clone Wars.

## Specifications

- **Name:** Treppus-2 vibroknife
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Vibro-knife
- **Length:** Around 15 centimeters (blade)
