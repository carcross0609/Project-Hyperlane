# Stun tube

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Stun tube](https://starwars.fandom.com/wiki/Stun_tube)

Stun tube was a small, short-range melee weapon used to stun targets. The weapon carried one charge and was effective for several hours.

## Specifications

- **Name:** Stun tube
- **Type:** Stun weapon
- **Size:** Barely the size of a finger
