# Electrorod

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Electrorod](https://starwars.fandom.com/wiki/Electrorod)

The Electrorod was a type of melee weapon that used electricity over blunt edges. The tip of an electrorod packed enough charge that it could knock an opponent unconscious with just a grazing blow.

## Specifications

- **Name:** Electrorod
- **Type:** Melee weapon
- **Owners:** A female mercenary
- **Locations:** Dromund Kaas
- **Shape:** Cylindrical
