# Hunting blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Hunting blaster](https://starwars.fandom.com/wiki/Hunting_blaster)

Hunting blasters were a type of blaster. The Ithorian bartender Jho owned a hunting blaster and would sometimes draw it under the bar during combat in his cantina Old Jho's Pit Stop.
