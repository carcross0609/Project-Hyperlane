# Electro cudgel

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Electro cudgel](https://starwars.fandom.com/wiki/Electro_cudgel)

Electro cudgels were electrified melee weapons. The hunters Winloss and Nokk used electro cudgels while hunting the Shadowfang Beast as part of a job given to them by Doctor Chelli Aphra.
