# C-88 Fragmentation Missile

**Kind:** Model  
**Continuity:** Legends  
**Source:** [C-88 Fragmentation Missile/Legends](https://starwars.fandom.com/wiki/C-88_Fragmentation_Missile/Legends)

The C-88 Fragmentation Missile was a fragmentation missile manufactured by Merr-Sonn Munitions, Inc. during the Galactic Civil War and cost 75 credits. Like fragmentation grenades, it was used against infantry.

## Specifications

- **Name:** C-88 Fragmentation Missile
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Model:** C-88
- **Type:** Fragmentation missile
- **Cost:** 75 credits
