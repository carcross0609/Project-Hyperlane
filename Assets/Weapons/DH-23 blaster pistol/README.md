# DH-23 blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DH-23 blaster pistol](https://starwars.fandom.com/wiki/DH-23_blaster_pistol)

The DH-23 blaster pistol was a heavily modified DH-17 blaster pistol often used by hitmen. It was created to profit off of the success of the DH-17, but never managed to dominate the market as the DH-17 did.
