# D-29 repulsor rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [D-29 repulsor rifle/Legends](https://starwars.fandom.com/wiki/D-29_repulsor_rifle/Legends)

The D-29 repulsor rifle was a weapon produced by SakTek, Inc. It used similar technology to tractor beams to release energy, which pushed enemies backwards without causing serious damage.
