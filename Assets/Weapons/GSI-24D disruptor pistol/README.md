# GSI-24D disruptor pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [GSI-24D disruptor pistol](https://starwars.fandom.com/wiki/GSI-24D_disruptor_pistol)

The GSI-24D disruptor pistol was a disruptor pistol used by Dark Jedi Set Harth around 980 BBY. Such disruptors were banned on some planets, such as Doan.
