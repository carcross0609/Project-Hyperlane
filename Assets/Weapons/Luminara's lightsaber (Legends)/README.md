# Luminara's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Luminara's lightsaber/Legends](https://starwars.fandom.com/wiki/Luminara%27s_lightsaber/Legends)

Luminara's lightsaber was the weapon carried by Jedi Master Luminara Unduli. Trained as a Jedi Guardian, Unduli's weapon produced a green blade when ignited, which was somewhat unusual as Guardians typically carried blue-bladed lightsabers.

## Specifications

- **Name:** Luminara's lightsaber
- **Type:** Single-bladed lightsaber
- **Culture:** Jedi
- **Creator:** Luminara Unduli
- **Created:** Bet. 55 BBY - 44 BBY
- **Owners:** Luminara Unduli
- **Hilt Shape:** Cylindrical
- **Crystal:** Single Adegan crystal
- **Color:** Green
- **Design:** Based on Lacunas Subartuk's lightsaber
- **Purpose:** Lightsaber combat
- **Affiliation:**
  - Jedi Order
  - Galactic Republic
