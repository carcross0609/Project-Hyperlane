# Class II heavy laser cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Class II heavy laser cannon](https://starwars.fandom.com/wiki/Class_II_heavy_laser_cannon)

The class II heavy laser cannon was a variant of heavy laser cannon. Two such laser cannons, MS-1 fire-linked heavy laser cannons, were positioned on the bottom of the All Terrain Armored Transport walker's cockpit, below the windshield.

## Specifications

- **Name:** Class II heavy laser cannon
- **Type:** Heavy laser cannon
- **Purpose:** Armament for the All Terrain Armored Transport
- **Affiliation:** Galactic Empire
