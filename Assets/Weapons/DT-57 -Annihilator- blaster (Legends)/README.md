# DT-57 "Annihilator" blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DT-57 "Annihilator" blaster/Legends](https://starwars.fandom.com/wiki/DT-57_%22Annihilator%22_blaster/Legends)

The DT-57 "Annihilator" blaster was a high-powered heavy blaster pistol manufactured during the era of the Clone Wars. Highly customizable, the DT-57 featured a high output blaster magazine, a large trigger guard and a top-mounted scope.
