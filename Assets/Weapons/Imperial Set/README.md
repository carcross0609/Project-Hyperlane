# Imperial Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Imperial Set](https://starwars.fandom.com/wiki/Imperial_Set)

The Imperial Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara as an alternative to their standard set. These decorative weathered weapons featured a red, pink, gold, silver, and black color scheme, with decorative, swirling patterns and glowing pink cores.
