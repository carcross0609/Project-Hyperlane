# Gas grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Gas grenade/Legends](https://starwars.fandom.com/wiki/Gas_grenade/Legends)

Gas grenades were hand grenades that upon impact, deployed an airborne chemical agent that incapacitated targets. It also had the secondary effect of filling the blast area with a temporary smokescreen. Some gas grenades were more lethal, such as the FEX-M3 nerve gas grenade and poison gas grenade. Droids were immune to the grenades' effects as they did not breathe. Some beings, such as the Gand, were likewise immune due to the fact that they wore breath masks. Some Jedi were able to use the Force to rid themselves of the poison.

- **Name:** Gas grenade
