# NNJ-40 "Thunderbolt" long-range ion cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [NNJ-40 "Thunderbolt" long-range ion cannon](https://starwars.fandom.com/wiki/NNJ-40_%22Thunderbolt%22_long-range_ion_cannon)

The NNJ-40 "Thunderbolt" long-range ion cannon was a model of ion cannon manufactured by Borstel Galactic Defense. It was the main armament of the Galactic Republic's RX-200 Falchion-class assault tank. During the Imperial Era, an Imperial science vessel was armed with one such cannon.
