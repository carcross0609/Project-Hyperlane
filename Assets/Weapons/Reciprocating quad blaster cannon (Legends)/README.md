# Reciprocating quad blaster cannon

**Kind:** Model

The reciprocating quad blaster cannon, often shortened to "Cip-Quad," was an experimental quad laser cannon weapon developed during the Clone Wars by Merr-Sonn Munitions.

## Specifications

- **Name:** Reciprocating quad blaster cannon
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Portable quad laser
- **Locations:**

  - Coruscant
- **Length:** About 80 centimeters
