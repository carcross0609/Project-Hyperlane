# Ax-190-B blaster cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Ax-190-B blaster cannon](https://starwars.fandom.com/wiki/Ax-190-B_blaster_cannon)

The Ax-190-B blaster cannon was an underslung blaster cannon produced by BlasTech Industries. A rotatable Ax-190-B blaster cannon was installed on the undercarriage of the T-70 X-wing starfighter and combined with an automated computer targeting system for rearward defense against enemy fighters.
