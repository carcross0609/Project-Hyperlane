# DH-447 sniper rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DH-447 sniper rifle](https://starwars.fandom.com/wiki/DH-447_sniper_rifle)

The DH-447 sniper rifle was a blaster sniper rifle produced by BlasTech Industries. A DH-447 sniper rifle equipped with a supercollimator barrel. It was notably used by the Partisan Leevan Tenza during the Battle on Jedha.
