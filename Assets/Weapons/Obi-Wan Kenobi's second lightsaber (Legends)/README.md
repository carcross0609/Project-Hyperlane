# Obi-Wan Kenobi's second lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Obi-Wan Kenobi's second lightsaber/Legends](https://starwars.fandom.com/wiki/Obi-Wan_Kenobi%27s_second_lightsaber/Legends)
