# DL-22 blaster pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [DL-22 blaster pistol](https://starwars.fandom.com/wiki/DL-22_blaster_pistol)

The BlasTech Industries DL-22 Blaster Pistol was designed as a response to the MerrSonn DD6 weapon. Luke Skywalker had one of these weapons. Reen Irana also used one of these blasters.

## Specifications

- **Name:** DL-22 blaster pistol
- **Manufacturer:** BlasTech Industries
- **Model:** DL-22
- **Type:** Blaster pistol
- **Cost:** 500 to 550 credits
- **Size:** Small
- **Weight:** 1 kg
- **Capacity:** 100 shots
- **Range:** 120 meters
