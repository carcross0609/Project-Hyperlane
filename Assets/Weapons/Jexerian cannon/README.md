# Jexerian cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Jexerian cannon](https://starwars.fandom.com/wiki/Jexerian_cannon)

The Jexerian cannon was a primitive projectile cannon that emitted a notably loud noise when fired. It originated in the Jexeria system of the Outer Rim Territories' Tharin sector. At some point by 2 ABY, in a personal addendum to a Rebel Alliance Task Force on Alliance Security SecuriDex datafile on Barosa Warren, a former Morellian Enforcer and head of the Galactic Outdoor Survival School, the Human Derembus Sitnalta, an Alliance soldier and a graduate of the Galactic Outdoor Survival School, compared the report made by Warren's .48-caliber Enforcer pistol when fired to that of a Jexerian cannon.
