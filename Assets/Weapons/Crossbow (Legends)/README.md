# Crossbow

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Crossbow/Legends](https://starwars.fandom.com/wiki/Crossbow/Legends)

Crossbows were primitive weapons normally used by archaic peoples who did not have the technology to build blaster weapons or even black-powder weapons.

- **Size:** One-handed weapon
- **Weight:** 1.8 kg
- **Capacity:** 1 arrow
- **Range:**
