# Asajj Ventress's lightsabers

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Asajj Ventress's lightsabers/Legends](https://starwars.fandom.com/wiki/Asajj_Ventress%27s_lightsabers/Legends)

These lightsabers were a pair of curved-hilt lightsabers wielded by Asajj Ventress that once belonged to Komari Vosa. The lightsabers could be joined together to make a saberstaff.
