# CR-24 Flame Rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [CR-24 Flame Rifle](https://starwars.fandom.com/wiki/CR-24_Flame_Rifle)

The CR-24 Flame Rifle was a type of flamethrower utilized by dewback troopers of Stormtrooper Corps of the Galactic Empire. At some point, a dewback trooper used one of the flamethrowers to burn down a desert village.
