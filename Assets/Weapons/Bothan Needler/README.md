# Bothan Needler

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Bothan Needler](https://starwars.fandom.com/wiki/Bothan_Needler)

The possession of the Bothan Needler hold-out weapon in a non-Bothan system was usually grounds for arrest. They were state-of-the-art weapons 4,000 years before the Galactic Civil War.

- **Name:** Bothan Needler
- **Type:** Hold-out blaster
