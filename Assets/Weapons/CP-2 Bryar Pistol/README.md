# CP-2 Bryar Pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CP-2 Bryar Pistol](https://starwars.fandom.com/wiki/CP-2_Bryar_Pistol)

The CP-2 Bryar Pistol was a type of Bryar blaster pistol available during the Cold War between the Galactic Republic and the reconstituted Sith Empire. It could be stored in a tailored holster.
