# Composite-beam pinpoint laser turret

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Composite-beam pinpoint laser turret](https://starwars.fandom.com/wiki/Composite-beam_pinpoint_laser_turret)

The composite-beam pinpoint laser turret was a model of composite-beam laser turret used on LAAT/i gunships of the Galactic Republic and emitted a green laser beam. Two turrets were optional bow side-mounted manned turrets, while two others were remote controlled and located on each wing.
