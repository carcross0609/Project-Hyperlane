# Flechette pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Flechette pistol](https://starwars.fandom.com/wiki/Flechette_pistol)

Flechette pistols were a class of pistol that fired needle-like projectiles called flechettes. Malaxan Firepower Incorporated's FWG-5 flechette pistol was one such weapon.
