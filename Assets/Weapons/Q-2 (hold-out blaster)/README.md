# Q-2 (hold-out blaster)

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Q-2 (hold-out blaster)](https://starwars.fandom.com/wiki/Q-2_%28hold-out_blaster%29)

The Q-2 was a hold-out blaster manufactured by SoroSuub Corporation. The design was licensed from Merr-Sonn Munitions, Inc. and was nearly identical to Merr-Sonn's Q2 hold-out blaster pistol.

## Specifications

- **Name:** Q-2
- **Manufacturer:** SoroSuub Corporation
- **Type:** Hold-out blaster
- **Cost:** 350 credits
