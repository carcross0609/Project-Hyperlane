# Torpedo

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Torpedo](https://starwars.fandom.com/wiki/Torpedo)

A torpedo was a projectile that could be fired off of certain starships. The Corellian MPO-1400 Purgill-class star cruiser Halcyon had such armament. Ion torpedos were a type of torpedo.
