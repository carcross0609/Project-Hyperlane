# Akar-Deshu's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Akar-Deshu's lightsaber](https://starwars.fandom.com/wiki/Akar-Deshu%27s_lightsaber)

The Mahran Jedi Knight Akar-Deshu utiziled a blue bladed lightsaber during the Clone Wars. The lightsaber was later used by Quinlan Vos during the second battle of Christophsis to escape capture aboard the Vigilance.
