# Hunting rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Hunting rifle/Legends](https://starwars.fandom.com/wiki/Hunting_rifle/Legends)

A hunting rifle was a personal weapon which could be used to hunt small game. They were often part of the emergency supply cache aboard lifeboats. The Rodian hunter Jombo carried a hunting rifle while accompanying Gamgalon's Morodin-hunting safaris on the planet Varonat.
