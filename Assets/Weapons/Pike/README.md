# Pike

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Pike](https://starwars.fandom.com/wiki/Pike)

A pike was a type of polearm used in various cultures. Geonosian picadors used static pikes to control deadly creatures for Petranaki gladiatorial battles. Imperial sandtroopers who rode spamels on Jedha and dewbacks on Tatooine also carried pikes.
