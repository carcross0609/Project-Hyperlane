# Type IV Ship Restraining Net

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Type IV Ship Restraining Net](https://starwars.fandom.com/wiki/Type_IV_Ship_Restraining_Net)

The Type IV Ship Restraining Net was a conner web, an updated version of the conner net, manufactured by SoroSuub Corporation. The Type IV could be deployed against targets in space and a planetary atmosphere.

## Specifications

- **Name:** Type IV Ship Restraining Net
- **Manufacturer:** SoroSuub Corporation
- **Type:** Starship restraining unit
- **Cost:** 5,000 credits (per canister)
- **Range:** 1 kilometer (atmosphere)
