# Longsword

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Longsword/Legends](https://starwars.fandom.com/wiki/Longsword/Legends)

A longsword, also known as war sword, was a type of single-bladed sword. As the weapon was designed for battle, the blades were usually made of the finest metals. A two-bladed version of the war sword was the double-bladed sword.
