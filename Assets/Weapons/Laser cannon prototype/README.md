# Laser cannon prototype

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Laser cannon prototype](https://starwars.fandom.com/wiki/Laser_cannon_prototype)

During the Galactic Civil War, Sienar Fleet Systems produced a laser cannon prototype for the Galactic Empire's TIE series starfighters. The prototype enhanced the TIE's firepower, but the weapon was considered to be too expensive for widespread use by many of the Empire's Moffs.
