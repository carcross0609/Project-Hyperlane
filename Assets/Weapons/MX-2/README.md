# MX-2

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MX-2](https://starwars.fandom.com/wiki/MX-2)

The MX-2 was a model of surface-to-air rocket developed by Merr-Sonn Munitions, Inc. and used during the Cold War. The Galactic Republic used those launchers on Ord Mantell during the Separatist War, where some of the ordnance was stolen by the local separatists to be used against the Republic.

## Specifications

- **Name:** MX-2
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Rocket
- **Affiliation:** Galactic Republic
