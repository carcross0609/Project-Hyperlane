# DL-17 blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DL-17 blaster rifle](https://starwars.fandom.com/wiki/DL-17_blaster_rifle)

The DL-17 blaster rifle was a blaster rifle model built by BlasTech Industries. The bounty hunter Tam Posla carried one that was modified with an extended magazine when he was on the Mid Rim Territories moon of Jedha. The Mandalorian Pen Varad also carried a captured version of the rifle.
