# FWG-5 smart pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [FWG-5 smart pistol](https://starwars.fandom.com/wiki/FWG-5_smart_pistol)

The FWG-5 smart pistol, also known as the FWG-5 flechette pistol, was a type of flechette pistol manufactured by Malaxan Firepower Incorporated. The company later produced the FWG-7 Flechette Smart Carbine, a heavier version of the FWG-5.

## Specifications

- **Name:** FWG-5 smart pistol
- **Manufacturer:** Malaxan Firepower Incorporated
- **Type:** Pistol
- **Cost:** 825 credits
