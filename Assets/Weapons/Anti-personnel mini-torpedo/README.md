# Anti-personnel mini-torpedo

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Anti-personnel mini-torpedo](https://starwars.fandom.com/wiki/Anti-personnel_mini-torpedo)

An anti-personnel mini torpedo was a type of mini-torpedo. When detonated, it acted similarly to a fragmentation grenade. Like other mini-torpedoes, it only functioned underwater.
