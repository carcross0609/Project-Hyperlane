# B1-NA blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [B1-NA blaster pistol](https://starwars.fandom.com/wiki/B1-NA_blaster_pistol)

The B1-NA blaster pistol, also known as a Corpo blaster, was one of several types of blaster pistols used by Tac-Corpo troopers of the Pre-Mor Enforcement, Preox-Morlana's security branch. Although produced by BlasTech Industries, they had a Preox-Morlana corporate branding and serial number printed on them, and featured a detachable sight.

## Specifications

- **Name:** B1-NA blaster pistol
- **Manufacturer:** BlasTech Industries
- **Model:** B1-NA
- **Type:** Blaster pistol
- **Inscription:** Serial number
- **Markings:** Preox-Morlana signet
- **Affiliation:**

  -   Pre-Mor Authority Security Forces
