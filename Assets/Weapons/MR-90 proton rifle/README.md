# MR-90 proton rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [MR-90 proton rifle](https://starwars.fandom.com/wiki/MR-90_proton_rifle)

The MR-90 proton rifle was a proton rifle manufactured by Merr-Sonn Munitions, Inc. Marketed as a hunting rifle, it was also adopted by military and paramilitary groups as an anti-materiel weapon and high-powered sniper rifle.

## Specifications

- **Name:** MR-90 proton rifle
- **Manufacturer:** Merr-Sonn Munitions, Inc.
