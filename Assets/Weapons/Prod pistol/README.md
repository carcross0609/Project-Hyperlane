# Prod pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Prod pistol](https://starwars.fandom.com/wiki/Prod_pistol)

The prod pistol was a type of crossbow. While living as a hermit on the planet Pasaana, Lando Calrissian utilized a custom-crafted prod pistol, which he had made from one of his chromium-plated SE-14r light repeating blasters. This weapon has several flexorcords to fire armor-piercing arrow bolts.

- **Type:** Crossbow
