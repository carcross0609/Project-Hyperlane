# Massassi Guardian carbine

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Massassi Guardian carbine](https://starwars.fandom.com/wiki/Massassi_Guardian_carbine)

The Massassi Guardian carbine was a blaster carbine used during the time of the Galactic Civil War. It was named after the Massassi, the subspecies of an ancient Sith race.
