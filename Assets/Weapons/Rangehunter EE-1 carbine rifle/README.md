# Rangehunter EE-1 carbine rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Rangehunter EE-1 carbine rifle](https://starwars.fandom.com/wiki/Rangehunter_EE-1_carbine_rifle)

The Rangehunter EE-1 carbine rifle was a type of blaster carbine produced during the Cold War between the Galactic Republic and the Sith Empire. During the war against Zakuul, the Mandalorians would use these blaster rifles against the Skytroopers on Darvannis.
