# C-22 fragmentation grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [C-22 fragmentation grenade](https://starwars.fandom.com/wiki/C-22_fragmentation_grenade)

The Merr-Sonn C-22 fragmentation grenade was a grenade which consisted of a small detonite charge encased in a pre-stressed chrome shell. Upon detonation, the grenade filled an area of ten meters in diameter with shrapnel.

## Specifications

- **Name:** C-22 fragmentation grenade
- **Manufacturer:** Merr-Sonn Munitions, Inc.
- **Type:** Fragmentation grenade
- **Cost:** 700 credits
- **Size:** Tiny
- **Weight:** 0.5 kilograms
- **Affiliation:** Galactic Empire
