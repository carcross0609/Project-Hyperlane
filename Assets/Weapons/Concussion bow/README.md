# Concussion bow

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Concussion bow](https://starwars.fandom.com/wiki/Concussion_bow)

A concussion bow was a type of slugthrower used by the Ysanna for hunting. It used projectiles whose trajectories Ysanna could manipulate with the Force.
