# War club

**Kind:** Model  
**Continuity:** Canon  
**Source:** [War club](https://starwars.fandom.com/wiki/War_club)

A war club was a type of heavy club. The Knight of Ren Ushar carried a war club, which was powered by a kinetite generator that produced kinetite energy.
