# DEMP gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [DEMP gun](https://starwars.fandom.com/wiki/DEMP_gun)

A DEMP gun was a type of short-barreled ion blaster, manufactured by Merr-Sonn Munitions, Inc., which fired an electromagnetic pulse to disable droids. It was available in blaster carbine form and blaster pistol form. In 0 ABY, a DEMP gun was used by Sergeant TX-828 of the Galactic Empire's Stormtrooper Corps to incapacitate Captivator, a droid bounty hunter.
