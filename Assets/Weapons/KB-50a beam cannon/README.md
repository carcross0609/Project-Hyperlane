# KB-50a beam cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KB-50a beam cannon](https://starwars.fandom.com/wiki/KB-50a_beam_cannon)

The KB-50a beam cannon was a type of beam cannon turret that was manufactured by Taim & Bak and mounted on some of the TX-130 Saber-class fighter tanks used by the Grand Army of the Republic.
