# Bacta turret

**Kind:** Model  
**Continuity:** Uncategorized  
**Source:** [Bacta turret](https://starwars.fandom.com/wiki/Bacta_turret)

Bacta turrets were a type of custom automated defensive emplacement designed by the Mon Calamari Hunter Sprocket for use in the Hunters of the Outer Rim competition hosted on the planet Vespaara. These turrets could expel bacta, healing Sprocket's allies within its vicinity while active.

- **Name:** Bacta turret
- **Type:** Turret
- **Creators:** Sprocket
- **Owners:** Sprocket
