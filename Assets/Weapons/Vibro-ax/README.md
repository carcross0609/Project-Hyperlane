# Vibro-ax

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vibro-ax](https://starwars.fandom.com/wiki/Vibro-ax)

A vibro-ax, or vibro-axe, was a type of ax that used a compact generator to create vibrations along the cutting edge's surface, which significantly increased the weapon's lethality. There existed one-handed and two-handed models. Similar vibration-based technology could be found in vibro-blades, vibro-knives, vibro-pikes, and vibro-lances.

## Specifications

- **Name:** Vibro-ax
- **Type:** Melee weapon
- **Shape:** Ax-like
- **Size:** One- or two-handed weapon
