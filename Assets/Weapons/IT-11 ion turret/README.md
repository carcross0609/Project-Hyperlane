# IT-11 ion turret

**Kind:** Model  
**Continuity:** Canon  
**Source:** [IT-11 ion turret](https://starwars.fandom.com/wiki/IT-11_ion_turret)

A IT-11 ion turret was a model of ion turret that could be equipped on a starship. Equipping an EML-850 light freighter with a IT-11 turret cost two thousand and five hundred credits and required a X-FP-C28 ship computer, thirty units of quadanium steel, and fifteen 4XB Calculation Units.

## Specifications

- **Name:** IT-11 ion turret
- **Model:** IT-11
- **Type:** Ion turret
- **Cost:** 2500 credits
