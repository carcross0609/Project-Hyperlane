# HM-6 Concussion Missile Launcher

**Kind:** Model  
**Continuity:** Legends  
**Source:** [HM-6 Concussion Missile Launcher/Legends](https://starwars.fandom.com/wiki/HM-6_Concussion_Missile_Launcher/Legends)

The HM-6 Concussion Missile Launcher was a model of concussion missile launcher manufactured by Dymek. The launcher had a magazine of six concussion missiles. The New Republic's RZ-1 A-wing interceptors were fitted with a pair of HM-6 launchers.

## Specifications

- **Name:** HM-6 Concussion Missile Launcher
- **Manufacturer:** Dymek
- **Type:** Concussion missile launcher
