# Mirth gas grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Mirth gas grenade](https://starwars.fandom.com/wiki/Mirth_gas_grenade)

A mirth gas grenade was a weapon for sale at Kitak Hu's weapons shop on Vorzyd V. It was launched via voice activation, and could be attached to an R2-series astromech droid with a module harness. The grenade exploded into a cloud of mirth gas which caused attackers to have difficulty breathing.

- **Type:** Grenade
