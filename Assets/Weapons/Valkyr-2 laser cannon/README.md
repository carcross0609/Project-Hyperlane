# Valkyr-2 laser cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Valkyr-2 laser cannon](https://starwars.fandom.com/wiki/Valkyr-2_laser_cannon)

The Valkyr-2 laser cannon was a model of laser cannon manufactured by Zija. The customized racing starfighter Red Ace, flown by Freya Fenris, was equipped with two wing-mounted Valkyr-2 laser cannons.
