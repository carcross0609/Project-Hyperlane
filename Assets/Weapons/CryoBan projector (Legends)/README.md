# CryoBan projector

**Kind:** Model  
**Continuity:** Legends  
**Source:** [CryoBan projector/Legends](https://starwars.fandom.com/wiki/CryoBan_projector/Legends)

CryoBan projectors, manufactured by Tagge Company, were originally designed to extinguish fires aboard starships using a supercooling chemical agent. However, independent operators soon discovered that removing the safety nozzles from CryoBan projectors could convert them into lethal weapons. Many smugglers kept several of these stashed in strategic locations around their ships, both to extinguish fires and, if necessary, repel boarders.

## Specifications

- **Name:** CryoBan projector
- **Manufacturer:** Tagge Company
- **Cost:** 500 credits
- **Range:** Short
