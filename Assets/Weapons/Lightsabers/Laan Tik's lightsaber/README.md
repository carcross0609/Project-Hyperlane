# Laan Tik's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Laan Tik's lightsaber](https://starwars.fandom.com/wiki/Laan_Tik%27s_lightsaber)

Jedi General Laan Tik wielded a blue lightsaber during the Battle of Mimban in 22 BBY during the Clone Wars between Galactic Republic and the Confederacy of Independent Systems. When Tik fell in battle, Republic Junior Representative Jar Jar Binks took the lightsaber and nearly killed himself several times with the weapon, eventually managing to save Clone Captain Rex from several B1-series battle droids by using the lightsaber.
