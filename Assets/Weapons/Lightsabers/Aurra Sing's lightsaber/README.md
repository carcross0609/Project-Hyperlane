# Aurra Sing's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Aurra Sing's lightsaber](https://starwars.fandom.com/wiki/Aurra_Sing%27s_lightsaber)

The bounty hunter Aurra Sing had a scarlet-bladed lightsaber. Sing didn't construct the lightsaber herself, but took it from one of the Jedi she killed.
