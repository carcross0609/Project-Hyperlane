# Darth Maul's double-bladed lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Darth Maul's double-bladed lightsaber/Legends](https://starwars.fandom.com/wiki/Darth_Maul%27s_double-bladed_lightsaber/Legends)
