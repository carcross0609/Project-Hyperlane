# Werla's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Werla's lightsaber](https://starwars.fandom.com/wiki/Werla%27s_lightsaber)

Werla's lightsaber was a lightsaber used by Werla Cayn during the High Republic Era. After Cayn's death on Dalna, Char-Ryl-Roy took the lightsaber.

- **Name:** Werla's lightsaber
- **Culture:** Jedi
- **Owners:**

- **Crystal:** Kyber crystal
