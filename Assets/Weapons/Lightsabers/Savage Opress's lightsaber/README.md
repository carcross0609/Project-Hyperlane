# Savage Opress's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Savage Opress's lightsaber](https://starwars.fandom.com/wiki/Savage_Opress%27s_lightsaber)

Savage Opress's lightsaber was a double-bladed lightsaber used by Savage Opress during the Clone Wars. Savage used the lightsaber against foes like Adi Gallia, Katuunko, Obi-Wan Kenobi, Darth Sidious, and many others.
