# Maeve Cuilinn's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Maeve Cuilinn's lightsaber](https://starwars.fandom.com/wiki/Maeve_Cuilinn%27s_lightsaber)
