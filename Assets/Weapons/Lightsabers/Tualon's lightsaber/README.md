# Tualon's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Tualon's lightsaber](https://starwars.fandom.com/wiki/Tualon%27s_lightsaber)

Tualon's lightsaber was a green-bladed lightsaber used by the Twi'lek Jedi Knight Tualon Yaluna during his time in the Jedi Order.

- **Name:** Tualon's lightsaber
- **Owners:** Tualon Yaluna
- **Crystal:** Kyber crystal
- **Color:** Green
- **Succeed:** A double-bladed spinning lightsaber
