# Lightsaber-blaster hybrid

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Lightsaber-blaster hybrid](https://starwars.fandom.com/wiki/Lightsaber-blaster_hybrid)

A lightsaber-blaster hybrid was a type of lightsaber hilt equipped with a blaster. During the Imperial Era, one of these lightsabers was constructed by Ezra Bridger.

## Specifications

- **Name:** Lightsaber-blaster hybrid
- **Model:** Handcrafted
- **Type:** Lightsaber-blaster hybrid
- **Culture:** Jedi
- **Owners:** Ezra Bridger (Ezra Bridger's first lightsaber)
- **Hilt Shape:** Double-bar design
- **Crystal:** Kyber crystal
- **Mods:** Built-in Stun blaster
- **Purpose:** Lightsaber combat
- **Affiliation:** Spectres
