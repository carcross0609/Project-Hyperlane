# Barriss Offee's double-bladed spinning lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Barriss Offee's double-bladed spinning lightsaber](https://starwars.fandom.com/wiki/Barriss_Offee%27s_double-bladed_spinning_lightsaber)
