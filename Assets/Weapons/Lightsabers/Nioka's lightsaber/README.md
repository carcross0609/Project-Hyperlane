# Nioka's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Nioka's lightsaber](https://starwars.fandom.com/wiki/Nioka%27s_lightsaber)

Nioka's lightsaber was a lightsaber owned by a tinkerer named Nioka Nastar after she found it, it originally belonged to a Jedi Wayseeker from the High Republic Era named Rhea Anudis.
