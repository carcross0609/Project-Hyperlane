# Lox's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Lox's lightsaber](https://starwars.fandom.com/wiki/Lox%27s_lightsaber)

Lox's lightsaber was a blue-bladed lightsaber used by Jedi Master Mirro Lox during the High Republic Era. It was ornate and slender, with a black handgrip and a petal-like pattern near its emitter.
