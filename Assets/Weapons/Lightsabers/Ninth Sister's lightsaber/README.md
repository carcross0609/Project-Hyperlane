# Ninth Sister's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Ninth Sister's lightsaber](https://starwars.fandom.com/wiki/Ninth_Sister%27s_lightsaber)

The Ninth Sister utilized a double-bladed spinning lightsaber during her time as an Inquisitor of the Galactic Empire.

## Specifications

- **Name:** Ninth Sister's lightsaber
- **Model:** Double-bladed spinning lightsaber
- **Type:**
  - Double-bladed spinning lightsaber (disc mode)
  - Single-bladed lightsaber (crescent mode)
- **Owners:** Ninth Sister
- **Hilt Shape:** Cylindrical
- **Hilt Material:** Metallic
- **Crystal:** Kyber crystal
- **Color:** Red
- **Mods:** Extendable hand guard, can spin around central handle with detachable emitters locked to hand guard (disc mode)
- **Protection:** Large circular hand guard
- **Purpose:** Lightsaber combat
- **Affiliation:**
  - Galactic Empire
  -   Inquisitorius
