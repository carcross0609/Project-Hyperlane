# Yarael Poof's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Yarael Poof's lightsaber/Legends](https://starwars.fandom.com/wiki/Yarael_Poof%27s_lightsaber/Legends)

A long-handled lightsaber was constructed by the Quermian Jedi Master Yarael Poof. Poof built this lightsaber, which he powered using a yellow crystal. Later in his life, he would use a sapphire crystal to power it.
