# Adi Gallia's first lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Adi Gallia's first lightsaber](https://starwars.fandom.com/wiki/Adi_Gallia%27s_first_lightsaber)

At some point before 32 BBY, a lightsaber was constructed and was used by Jedi Master Adi Gallia, a member of the Jedi Order. Powered by a kyber crystal, it was destroyed during a mission by 32 BBY. Afterward, Gallia began using a new lightsaber.
