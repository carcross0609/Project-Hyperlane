# Ethan's lightsaber

**Kind:** Lightsaber  
**Continuity:** Uncategorized  
**Source:** [Ethan's lightsaber](https://starwars.fandom.com/wiki/Ethan%27s_lightsaber)

A lightsaber was created by the sabersmith Lah Zhima and was given to the Jedi Ethan. The lightsaber's kyber crystal was tempered so that its color would reflect the user's connection to the Force, and its blade was blue while Ethan wielded it.
