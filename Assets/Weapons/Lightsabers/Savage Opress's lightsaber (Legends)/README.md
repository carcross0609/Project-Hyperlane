# Savage Opress's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Savage Opress's lightsaber/Legends](https://starwars.fandom.com/wiki/Savage_Opress%27s_lightsaber/Legends)

Savage Opress's lightsaber was a double-bladed lightsaber used by Savage Opress as a Sith Lord during the Clone Wars. The weapon would see action on many fronts such as Toydaria, Lotho Minor, Florrum, Nal Hutta and Mandalore.
