# Lightsaber parasol

**Kind:** Lightsaber  
**Continuity:** Uncategorized  
**Source:** [Lightsaber parasol](https://starwars.fandom.com/wiki/Lightsaber_parasol)

The lightsaber parasol was a Sith lightsaber created by Kouru, a female Sith who led a bandit group. It functioned as a singled-bladed lightsaber when she used only the lightsaber hilt. With its attached parasol auxiliary, it produced multiple red plasma blades in a manner that resembled a parasol, particularly when she spun it to create a shield.
