# Luke Skywalker's yellow lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Luke Skywalker's yellow lightsaber](https://starwars.fandom.com/wiki/Luke_Skywalker%27s_yellow_lightsaber)

Luke Skywalker's yellow lightsaber was a yellow-bladed lightsaber used by Luke Skywalker after he discovered it within a Jedi outpost on Tempes. Unlike the other lightsaber pikes, this lightsaber only had a single blade due to Luke finding it damaged and later repaired it to serve as a single-blade variation.
