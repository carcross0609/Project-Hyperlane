# Gol's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Gol's lightsaber](https://starwars.fandom.com/wiki/Gol%27s_lightsaber)

A lightsaber was the personal weapon of the Sith named Gol. At one point, Gol bled a kyber crystal, embedding the memory of this lightsaber into the crystal. Around 3 ABY, Jedi-in-training Luke Skywalker convened with the red kyber crystal in hopes to purify it. While experiencing the realistic visions contained within the crystal, Luke became imprisoned by Gol, the latter accentuating a point that pain is a weapon by igniting his lightsaber. When Luke attempted to reconcile the pain Gol experienced throughout his life, Gol attacked Luke using his lightsaber, resulting a duel in which Luke disarmed the Sith.
