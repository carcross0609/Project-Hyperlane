# Qui-Gon Jinn's first lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Qui-Gon Jinn's first lightsaber](https://starwars.fandom.com/wiki/Qui-Gon_Jinn%27s_first_lightsaber)

A green-bladed lightsaber was used by the Jedi Master Qui-Gon Jinn before it got destroyed during a mission with his Padawan Xanatos. He later constructed another one to replace it.
