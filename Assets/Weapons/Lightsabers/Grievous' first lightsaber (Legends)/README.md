# Grievous' first lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Grievous' first lightsaber/Legends](https://starwars.fandom.com/wiki/Grievous%27_first_lightsaber/Legends)

This blue-bladed lightsaber was a weapon that had once belonged to Jedi Master Sifo-Dyas. It contained a blue Adegan crystal. After the Jedi Master's death in 32 BBY, it was given to the cyborg Grievous by the Sith Lord, Confederate Head of State Count Dooku for him to use. It served as the first Jedi lightsaber for his collection.
