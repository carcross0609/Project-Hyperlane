# Oppo Rancisis's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Oppo Rancisis's lightsaber/Legends](https://starwars.fandom.com/wiki/Oppo_Rancisis%27s_lightsaber/Legends)

Oppo Rancisis's lightsaber was a Jedi weapon created by the Thisspiasian Jedi Master. It had a single green blade and a cylindrical, straight, gray-colored hilt with a rectangular, jutting guard on its blade emitter.
