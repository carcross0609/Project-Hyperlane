# Corran Horn's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Corran Horn's lightsaber](https://starwars.fandom.com/wiki/Corran_Horn%27s_lightsaber)

Corran Horn constructed his silver-bladed lightsaber on Courkrus, using scrap parts from The Crash. Created using a Durindfire, along with an emerald and diamond (initially a Kubaz xirkonia, which rapidly failed and was soon replaced) for the focusing crystals, from jeweled furniture in Corran's room, it was based on designs hidden in Rostek Horn's columns for the Corellian Horticultural Digest, using a method for emergencies that took an average of two days to finish.
