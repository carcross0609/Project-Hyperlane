# Yoshi Raph-Elan's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Yoshi Raph-Elan's lightsaber](https://starwars.fandom.com/wiki/Yoshi_Raph-Elan%27s_lightsaber)

Constructed by Yoshi Raph-Elan, this lightsaber had a rare orange crystal. It was damaged when its wielder crash-landed on a barren planet. It was later repaired using wiring from a Goliath droid.
