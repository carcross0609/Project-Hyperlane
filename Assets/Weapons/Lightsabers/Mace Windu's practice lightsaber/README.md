# Mace Windu's practice lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Mace Windu's practice lightsaber](https://starwars.fandom.com/wiki/Mace_Windu%27s_practice_lightsaber)
