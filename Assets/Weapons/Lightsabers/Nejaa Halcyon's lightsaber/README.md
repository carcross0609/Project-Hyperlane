# Nejaa Halcyon's lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Nejaa Halcyon's lightsaber](https://starwars.fandom.com/wiki/Nejaa_Halcyon%27s_lightsaber)
