# Darth Nihilus' lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Darth Nihilus' lightsaber](https://starwars.fandom.com/wiki/Darth_Nihilus%27_lightsaber)

Darth Nihilus' lightsaber was the personal lightsaber of the Sith Lord Darth Nihilus during the First Jedi Purge. It was destroyed onboard the Ravager following Nihilus' confrontation with Meetra Surik, Mandalore the Preserver, and his former apprentice Visas Marr.
