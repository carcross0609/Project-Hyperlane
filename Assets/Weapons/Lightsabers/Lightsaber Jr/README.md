# Lightsaber Jr.

**Kind:** Lightsaber  
**Continuity:** Uncategorized  
**Source:** [Lightsaber Jr.](https://starwars.fandom.com/wiki/Lightsaber_Jr.)

Lightsaber Jr. was a type of lightsaber used by children. It required express parental consent to slice people in half.

## Specifications

- **Name:** Lightsaber Jr.
- **Culture:** Human
- **Color:** Bluish green
- **Markings:** "Lightsaber Jr."
- **Purpose:** For use by children
