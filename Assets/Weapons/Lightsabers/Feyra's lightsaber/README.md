# Feyra's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Feyra's lightsaber](https://starwars.fandom.com/wiki/Feyra%27s_lightsaber)

Feyra's lightsaber was a yellow-bladed lightsaber that belonged to the Pkorian Jedi Padawan Feyra Akaris. Her daughter Iskat later inherited the weapon.
