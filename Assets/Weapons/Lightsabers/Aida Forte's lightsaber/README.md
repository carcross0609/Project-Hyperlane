# Aida Forte's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Aida Forte's lightsaber](https://starwars.fandom.com/wiki/Aida_Forte%27s_lightsaber)

Aida Forte's lightsaber, or Aida's lightsaber was a green-bladed lightsaber used by Jedi Knight Aida Forte during the High Republic Era. After Forte's death, the kyber crystal was added to the Kyber Arch.

## Specifications

- **Name:** Aida Forte's lightsaber
- **Culture:** Jedi
- **Owners:** Aida Forte
- **Crystal:** Kyber crystal
- **Color:** Green
- **Affiliation:** Jedi Order
