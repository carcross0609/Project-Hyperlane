# Unidentified imitation lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Unidentified imitation lightsaber](https://starwars.fandom.com/wiki/Unidentified_imitation_lightsaber)

An imitation lightsaber was owned by Baron Orman Tagge in 0 ABY, during the Galactic Civil War. Tagge had the lightsaber constructed as an imitation of the weapons once carried by Jedi Knights, hoping to use it in lightsaber combat against Darth Vader.
