# FWG-5 Flechette Smart Pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [FWG-5 Flechette Smart Pistol](https://starwars.fandom.com/wiki/FWG-5_Flechette_Smart_Pistol)

The FWG-5 Flechette Smart Pistol was a handheld flechette pistol manufactured by Malaxan Firepower Incorporated. A featherweight version which was crafted using ultra-lightweight materials to provide the user with greater accuracy and mobility was also in use.

## Specifications

- **Name:** FWG-5 Flechette Smart Pistol
- **Manufacturer:** Malaxan Firepower Incorporated
- **Type:** Flechette pistol
- **Cost:** 500 credits (30 credits per ammunition clip)
- **Size:** Small
- **Weight:** 1.3 kilograms
- **Capacity:** 8 flechettes or 62 heat energy blasts
- **Range:** 100 meters
