# Obi-Wan Kenobi's first lightsaber

**Kind:** Lightsaber  
**Continuity:** Legends  
**Source:** [Obi-Wan Kenobi's first lightsaber/Legends](https://starwars.fandom.com/wiki/Obi-Wan_Kenobi%27s_first_lightsaber/Legends)

Obi-Wan Kenobi's first lightsaber was the weapon wielded by the Jedi Padawan Obi-Wan Kenobi until 32 BBY, when it was lost during a duel with Darth Maul.
