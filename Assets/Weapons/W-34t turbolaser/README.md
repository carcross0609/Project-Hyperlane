# W-34t turbolaser

**Kind:** Model  
**Continuity:** Legends  
**Source:** [W-34t turbolaser](https://starwars.fandom.com/wiki/W-34t_turbolaser)

The W-34t turbolaser was a starship weapon made by Incom Corporation. It cost 9,000 credits and was illegal for civilian use. The modified Corellian Engineering Corporation YT-1300 light freighter Storm Killer mounted a W-34t turbolaser in the dorsal gun turret position.

## Specifications

- **Name:** W-34t turbolaser
- **Manufacturer:** Incom Corporation
- **Type:** Turbolaser
- **Cost:** 9,000 credits
- **Weight:** 5 tons
