# Lumat (axe)

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Lumat (axe)](https://starwars.fandom.com/wiki/Lumat_%28axe%29)

Lumat was the name of a magical axe in Ewok mythology. The axe was wielded by the legendary hero Machook, traditionally considered to have built the first tree village. "Lumat" was a popular name for Ewok males, such as the archer and woodcutter who fought in the Battle of Endor.

## Specifications

- **Name:** Lumat
- **Type:** Axe
- **Culture:** Ewok
- **Owners:** Machook
