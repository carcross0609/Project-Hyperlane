# Lithitanium rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Lithitanium rifle](https://starwars.fandom.com/wiki/Lithitanium_rifle)

The Lithitanium rifle was a rifle variant appearing almost identical to the Tusken Cycler Rifle. However, this rifle was was built using an unknown metal component which created an improved, light weight and well balanced rifle.

## Specifications

- **Name:** Lithitanium rifle
- **Type:** Slugthrower rifle
- **Material:** Lithitanium
- **Range:** 0-64 meters
- **Affiliation:** Tusken Raiders
