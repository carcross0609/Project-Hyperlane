# Bossk's Relby-v10 Mortar Gun

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Bossk's Relby-v10 Mortar Gun](https://starwars.fandom.com/wiki/Bossk%27s_Relby-v10_Mortar_Gun)

Bossk's Relby-v10 Mortar Gun was a Relby-v10 micro grenade launcher used by the Trandoshan bounty hunter Bossk as his primary weapon. It held the ability to fire red heavy-duty blaster bolts, micro-grenades, and came with a mortar attachment.
