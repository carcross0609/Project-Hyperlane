# EMP missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [EMP missile](https://starwars.fandom.com/wiki/EMP_missile)

EMP missiles were a type of missile that utilized electromagnetic technology. The EP-750X EMP missile launcher fired guided EMP missiles that delivered a powerful ion blast, which were effective against large droid formations, as well as effective against starships and vehicles.
