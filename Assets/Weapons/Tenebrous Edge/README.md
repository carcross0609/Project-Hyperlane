# Tenebrous Edge

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Tenebrous Edge](https://starwars.fandom.com/wiki/Tenebrous_Edge)

The Tenebrous Edge was a small blade weapon designed to allow the wielder to keep the weapon hidden from view until it was time to strike. This made the weapon a favored choice for spies.

## Specifications

- **Name:** Tenebrous Edge
- **Type:** Melee weapon
- **Owners:** Unidentified spacers
