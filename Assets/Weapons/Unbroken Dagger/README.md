# Unbroken Dagger

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Unbroken Dagger](https://starwars.fandom.com/wiki/Unbroken_Dagger)

The Unbroken Dagger was a dagger that was a sacred relic of the Unbroken Clan. It was used by General Vukorah to kill the previous leader of the Clan.

- **Name:** Unbroken Dagger
