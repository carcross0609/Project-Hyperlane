# Qi'ra's electro swords

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Qi'ra's electro swords](https://starwars.fandom.com/wiki/Qi%27ra%27s_electro_swords)

A pair of electro swords were owned by Lady Qi'ra of Crimson Dawn during the Imperial Era. Wielding the blades in the style of Teräs Käsi, Qi'ra was highly-skilled with the swords and used them when dueling with the Dark Lord of the Sith Darth Vader.
