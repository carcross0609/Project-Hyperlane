# 'aKraB clip-point vibrodagger

**Kind:** Model  
**Continuity:** Canon  
**Source:** ['aKraB clip-point vibrodagger](https://starwars.fandom.com/wiki/%27aKraB_clip-point_vibrodagger)

The aKraB clip-point vibrodagger was a vibrodagger created by diehard survival enthusiasts from the planet Toprawa. It was engineered to slip in between the armor plates of large animals, allowing for close-range precision kills. It could also penetrate thick, armored hides and laminate armor with ease.
