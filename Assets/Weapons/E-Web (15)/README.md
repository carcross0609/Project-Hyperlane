# E-Web (15)

**Kind:** Model  
**Continuity:** Canon  
**Source:** [E-Web (15)](https://starwars.fandom.com/wiki/E-Web_%2815%29)

The E-Web (15) was a heavy repeating blaster manufactured by BlasTech Industries. It was equipped with an automatic deflector shield generator and a Gk7 Cryocooler, which made it more efficient than the F-Web repeating blaster. The repeating blaster could fire for up to an hour at a sufficient range to discourage most armies.
