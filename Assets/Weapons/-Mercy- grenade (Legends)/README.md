# "Mercy" grenade

**Kind:** Model  
**Continuity:** Legends  
**Source:** ["Mercy" grenade/Legends](https://starwars.fandom.com/wiki/%22Mercy%22_grenade/Legends)

The "Mercy" grenade was a model of gas grenade manufactured by Goseia Heavy Industries Concern. It was also called the nightmare grenade as it emitted an hallucinogenic gas that distorted perceptions, provoked intense visual illusions, impaired memory and created feelings of paranoia and dread. The effects of the gas on beings varied widely.

## Specifications

- **Name:** "Mercy" grenade
- **Manufacturer:** Goseia Heavy Industries Concern
- **Type:** Gas grenade
- **Cost:** 175 credits
