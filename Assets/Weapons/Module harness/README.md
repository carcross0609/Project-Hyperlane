# Module harness

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Module harness](https://starwars.fandom.com/wiki/Module_harness)

A module harness was a device for sale at Kitak Hu's weapons shop on Vorzyd V. It attached to an R2-series astromech droid and allowed the droid to be fitted with weapons.
