# RK-6 Starforged blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [RK-6 Starforged blaster](https://starwars.fandom.com/wiki/RK-6_Starforged_blaster)

The RK-6 Starforged blaster was a model of blaster pistol available during the Galactic War between the Galactic Republic and the Sith Empire. It was a similar model to the RK-4 Starforged blaster, but featured a large magazine on its stock.
