# Poe's blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Poe's blaster rifle](https://starwars.fandom.com/wiki/Poe%27s_blaster_rifle)

Poe's blaster rifle was a BlasTech EL-16HFE blaster rifle used by Resistance pilot and Commander Poe Dameron. Dameron used this weapon to defend the Jakku village Tuanul when the First Order attacked it during the Resistance's conflict with the First Order. He carried the blaster rifle in a charging slot inside the cockpit of his T-70 X-wing starfighter Black One.
