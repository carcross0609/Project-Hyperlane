# ST7 concussion missile

**Kind:** Model  
**Continuity:** Canon  
**Source:** [ST7 concussion missile](https://starwars.fandom.com/wiki/ST7_concussion_missile)

The ST7 concussion missile was a type of concussion missile produced by Arakyd Industries. They could be fired from the projectile launchers of the First Order's TIE interceptors and TIE silencers.
