# F-Z0 antipersonnel blaster cannon

**Kind:** Model  
**Continuity:** Canon  
**Source:** [F-Z0 antipersonnel blaster cannon](https://starwars.fandom.com/wiki/F-Z0_antipersonnel_blaster_cannon)

The F-Z0 antipersonnel blaster cannon was a model of double-barrel blaster cannon developed by Sienar-Jaemus Army Systems and used by the First Order. It was top-cover mounted on Atmospheric Assault Landers, where a single stormtrooper gave protective fire to troops being deployed in drop zones.
