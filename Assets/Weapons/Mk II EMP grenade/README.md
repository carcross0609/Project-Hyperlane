# Mk II EMP grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Mk II EMP grenade](https://starwars.fandom.com/wiki/Mk_II_EMP_grenade)

The Mk II EMP grenade was a type of Electro Magnetic Pulse grenade manufactured by SoroSuub Corporation for specific use by the Galactic Republic's clone army. 300 credits in cost, the Mk II EMP grenade was the same size as a standard fragmentation grenade and, upon detonation, released a powerful electromagnetic pulse capable of incapacitating droids and disabling electronic systems rather than an explosive force. During the Clone Wars between the Republic and Confederacy of Independent Systems, the grenade was the latest word in anti-droid weaponry.
