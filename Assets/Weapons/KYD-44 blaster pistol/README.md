# KYD-44 blaster pistol

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KYD-44 blaster pistol](https://starwars.fandom.com/wiki/KYD-44_blaster_pistol)

The KYD-44 blaster pistol was a model of blaster pistol. Two were carried by Bounty Hunters' Guild master Greef Karga. One of Gor Koresh's men carried one while confronting Din Djarin on RTK111.
