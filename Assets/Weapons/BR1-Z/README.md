# BR1-Z

**Kind:** Model  
**Continuity:** Legends  
**Source:** [BR1-Z](https://starwars.fandom.com/wiki/BR1-Z)

The BR1-Z was a model of blast-rifle manufactured by Core World Arms. Each rifle cost 1,500 credits, had an ammo capacity of fifty shots and a range of 150 meters.
