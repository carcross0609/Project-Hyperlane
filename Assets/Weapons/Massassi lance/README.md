# Massassi lance

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Massassi lance](https://starwars.fandom.com/wiki/Massassi_lance)

A Massassi lance was a two-bladed polearm used by the Massassi for close combat. The Massassi lance was a very ancient weapon by the time of the Galactic Civil War but it was still considered as effective.

## Specifications

- **Name:** Massassi lance
- **Type:** Polearm
- **Culture:** Massassi
- **Purpose:** Melee combat
