# T-350 torpedo

**Kind:** Model  
**Continuity:** Canon  
**Source:** [T-350 torpedo](https://starwars.fandom.com/wiki/T-350_torpedo)

A T-350 torpedo was a model of torpedo that could be equipped to starships. Equipping an EML-850 light freighter with a T-350 torpedo cost one thousand credits and required fifteen units of quadanium steel, and seven heuristic processors.

## Specifications

- **Name:** T-350 torpedo
- **Model:** T-350
- **Type:** Torpedo
- **Cost:** 1000 credits
