# Particle bomb

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Particle bomb](https://starwars.fandom.com/wiki/Particle_bomb)

Particle bombs were a type of ordnance used by the Galactic Empire in space combat. The Empire notably used one such bomb against the crew of the starship Ghost when they were on their way to rescue a captured Gand engineer from an Imperial base.

- **Type:** Bomb
