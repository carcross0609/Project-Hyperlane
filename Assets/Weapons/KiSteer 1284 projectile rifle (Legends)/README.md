# KiSteer 1284 projectile rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [KiSteer 1284 projectile rifle/Legends](https://starwars.fandom.com/wiki/KiSteer_1284_projectile_rifle/Legends)

The KiSteer 1284 projectile rifle was a slugthrower used during the last decades of the Galactic Republic. The Clawdite assassin Zam Wesell was known to carry a KiSteer 1284.

## Specifications

- **Name:** KiSteer 1284 projectile rifle
- **Model:** KiSteer 1284
- **Type:** Slugthrower
- **Range:** Over 20 meters
