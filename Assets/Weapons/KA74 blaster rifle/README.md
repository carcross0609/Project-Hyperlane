# KA74 blaster rifle

**Kind:** Model  
**Continuity:** Canon  
**Source:** [KA74 blaster rifle](https://starwars.fandom.com/wiki/KA74_blaster_rifle)

The KA74 blaster rifle was a blaster rifle used by Cobb Vanth and later by Jo. The rifle was light but fired with powerful blasts, which were a good match for quick-drawing.
