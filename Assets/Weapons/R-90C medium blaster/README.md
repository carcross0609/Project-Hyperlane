# R-90C medium blaster

**Kind:** Model  
**Continuity:** Canon  
**Source:** [R-90C medium blaster](https://starwars.fandom.com/wiki/R-90C_medium_blaster)

The R-90C medium blaster was a model of medium blaster cannon produced by Piperii-Cerlurn. The All Terrain Armored Transport walkers manufactured by Kuat Drive Yards were built with an R-90C mounted on a swivel axis and equipped with a rangefinder on each side of the vehicle's command module.

## Specifications

- **Name:** R-90C medium blaster
- **Manufacturer:** Piperii-Cerlurn
- **Model:** R-90C
- **Type:** Blaster cannon
