# C290

**Kind:** Model  
**Continuity:** Canon  
**Source:** [C290](https://starwars.fandom.com/wiki/C290)

The C290 was a model of blaster rifle produced by BlasTech Industries. It was designed for use in wet, humid, or swampy environments. BlasTech used the C290 as the basis for the DC-12U beam rifle, used in underwater operations.

## Specifications

- **Name:** C290
- **Manufacturer:** BlasTech Industries
- **Type:** Blaster rifle
