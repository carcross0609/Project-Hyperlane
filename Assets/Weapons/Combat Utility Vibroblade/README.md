# Combat Utility Vibroblade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Combat Utility Vibroblade](https://starwars.fandom.com/wiki/Combat_Utility_Vibroblade)

The Combat Utility Vibroblade (C.U.V) was a vibroblade created by Shistavanen survivalists from the planet Uvena Prime. It was created to contain every conceivable tool necessary to survive in battle or in the wilderness. Each C.U.V was a custom configuration, and could contain a fire starter, a hydrospanner, or a water contaminant detector.

## Specifications

- **Name:** Combat Utility Vibroblade
- **Type:** Vibroblade
- **Creators:** Shistavanen survivalists
- **Locations:** Uvena Prime
- **Cost:** 600 credits
- **Purpose:** Survival
