# Homing shot

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Homing shot](https://starwars.fandom.com/wiki/Homing_shot)

Homing shot was a type of rocket launcher used both by Imperial and Rebel infantry during the Galactic Civil War. It locked on to enemy soldiers from afar, following them once shot.

- **Name:** Homing shot
- **Type:** Rocket launcher
