# Katana lightsaber

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Katana lightsaber](https://starwars.fandom.com/wiki/Katana_lightsaber)

Katana lightsabers were lightsabers whose hilts were slightly curved and rectangular. Former Jedi Ahsoka Tano used as off-hand weapons.
