# Hunter-seeker Projectile Cannon

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Hunter-seeker Projectile Cannon](https://starwars.fandom.com/wiki/Hunter-seeker_Projectile_Cannon)

A Hunter-seeker Projectile Cannon was a type of missile launcher that fired explosive hunter-seeker missiles. E522 assassin droids were equipped with a Hunter-seeker Projectile Cannon on their left arm loaded with six hunter-seeker missiles.
