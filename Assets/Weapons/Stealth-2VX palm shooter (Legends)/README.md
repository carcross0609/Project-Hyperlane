# Stealth-2VX palm shooter

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Stealth-2VX palm shooter/Legends](https://starwars.fandom.com/wiki/Stealth-2VX_palm_shooter/Legends)

The Stealth-2VX palm shooter was a small, spring powered dart shooter. Manufactured by Prax Arms, this weapon was the smallest known spring-loaded dart shooter, so small that it could easily be hidden in the palm of a Human hand or inside a comlink or droid caller.

## Specifications

- **Name:** Stealth-2VX palm shooter
- **Manufacturer:** Prax Arms
- **Type:** Dart shooter
- **Cost:** 360 credits
- **Weight:**
  - 0.25 kilograms (weapon only)
  - 0.5 kilograms (weapon and spare ammunition wristband)
- **Capacity:** 3 darts
- **Range:** 3–4 meters
