# SE-14r light repeating blaster

**Kind:** Model  
**Continuity:** Legends  
**Source:** [SE-14r light repeating blaster/Legends](https://starwars.fandom.com/wiki/SE-14r_light_repeating_blaster/Legends)

The SE-14r light repeating blaster, sometimes referred to as the Imperial repeating pistol, was an alternate model of BlasTech Industries SR combat pistol with fully automatic capabilities. Manufactured specifically for the Galactic Empire, it was carried as a sidearm by some Imperial officers and stormtrooper commanders.
