# Suspicious Set

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Suspicious Set](https://starwars.fandom.com/wiki/Suspicious_Set)

The Suspicious Set was the name given to a set of two weapons, an Arc Caster and a Pulse Blaster, utilized by the team of Jawa brothers known collectively as the Hunter Utooni that they could wield for the Hunters of the Outer Rim competition in the Grand Arena on the planet Vespaara.

## Specifications

- **Name:** Suspicious Set
- **Type:**
  - Arc Caster
  - Pulse Blaster
- **Owners:** Utooni
- **Affiliation:** Hunters of the Outer Rim
