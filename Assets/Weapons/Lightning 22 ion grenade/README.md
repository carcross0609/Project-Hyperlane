# Lightning 22 ion grenade

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Lightning 22 ion grenade](https://starwars.fandom.com/wiki/Lightning_22_ion_grenade)

The Lightning 22 ion grenade was a model of ion grenade produced by Kirgo Blastworks. The grenades cost 65 credits per unit and were popular with skip tracers and bounty hunters.

- **Name:** Lightning 22 ion grenade
