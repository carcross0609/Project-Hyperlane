# MX9

**Kind:** Model  
**Continuity:** Legends  
**Source:** [MX9](https://starwars.fandom.com/wiki/MX9)

The MX9 was a type of blaster rifle that appeared in a short story by an unspecified party that was posted on the Cularin holonet node during the Clone Wars. The tale depicted the MX9 rifle as a standard issue weapon in the Thaereian military with components that included a mesobanis timer and a symon tube. The tale showed the protagonist, the Thaereian soldier Nightwing, attempting to repair his jammed MX9 rifle from his bunk in a Thaereian military barracks.

- **Affiliation:** Thaereian military
