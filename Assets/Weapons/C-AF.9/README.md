# C/AF.9

**Kind:** Model  
**Continuity:** Legends  
**Source:** [C/AF.9](https://starwars.fandom.com/wiki/C/AF.9)

Manufactured by Golan Arms, the C/AF.9 was a turreted anti-infantry weapon that was the predecessor to the DF.9 anti-infantry battery. During the Galactic Civil War, it was found amongst Imperial garrisons that relied on older equipment, as well as planetary militias.

## Specifications

- **Name:** C/AF.9
- **Manufacturer:** Golan Arms
- **Type:** Anti-infantry battery
