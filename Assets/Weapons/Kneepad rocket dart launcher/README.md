# Kneepad rocket dart launcher

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Kneepad rocket dart launcher](https://starwars.fandom.com/wiki/Kneepad_rocket_dart_launcher)

Kneepad rocket dart launchers were a type of rocket dart launcher worn and fired from a kneepad. Such weapons were incorporated into the armor worn by both Jango Fett and his son, Boba Fett.

## Specifications

- **Name:** Kneepad rocket dart launcher
- **Type:** Knee-mounted rocket dart launcher
- **Size:** Small
