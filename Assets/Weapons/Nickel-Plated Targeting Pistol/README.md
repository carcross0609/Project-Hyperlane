# Nickel-Plated Targeting Pistol

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Nickel-Plated Targeting Pistol](https://starwars.fandom.com/wiki/Nickel-Plated_Targeting_Pistol)

The Nickel-Plated Targeting Pistol was a nickel-plated pistol used mostly for target practice. When fired, it would create a series of explosions that resembled fireworks.

- **Name:** Nickel-Plated Targeting Pistol
