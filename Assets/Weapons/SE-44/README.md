# SE-44

**Kind:** Model  
**Continuity:** Canon  
**Source:** [SE-44](https://starwars.fandom.com/wiki/SE-44)

The SE-44 was a blaster pistol wielded by some officers of the First Order. It was a variant of the SE-44C blaster pistol and was utilized during the regime's war against the Resistance.
