# Persuader heavy stun gun

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Persuader heavy stun gun](https://starwars.fandom.com/wiki/Persuader_heavy_stun_gun)

The Persuader heavy stun gun was a model of stun gun manufactured by BlasTech Industries. The Seeker droid Lux was fitted with a retractable Persuader heavy stun gun.

- **Name:** Persuader heavy stun gun
