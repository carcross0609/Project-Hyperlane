# Vibro-lance

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vibro-lance](https://starwars.fandom.com/wiki/Vibro-lance)

A vibro-lance was a shafted electroshock weapon that was fitted with a vibro-edged head. It was longer and lighter than a force pike, and balanced in such a way that it could also be thrown like a spear.

## Specifications

- **Name:** Vibro-lance
- **Model:** Lance
- **Type:** Melee weapon
- **Locations:**

  - Eriadu
- **Affiliation:**
