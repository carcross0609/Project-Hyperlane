# Pablo-Jill's lightsaber

**Kind:** Lightsaber  
**Continuity:** Canon  
**Source:** [Pablo-Jill's lightsaber](https://starwars.fandom.com/wiki/Pablo-Jill%27s_lightsaber)

Pablo-Jill's lightsaber was the personal blue-bladed lightsaber of Jedi Knight Pablo-Jill. Separatist warlord General Grievous claimed the lightsaber from floating debris, after injuring Pablo-Jill in an intense duel in a collapsing satellite city over Duro.
