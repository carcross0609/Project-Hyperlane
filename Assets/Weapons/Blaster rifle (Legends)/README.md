# Blaster rifle

**Kind:** Model  
**Continuity:** Legends  
**Source:** [Blaster rifle/Legends](https://starwars.fandom.com/wiki/Blaster_rifle/Legends)

A blaster rifle was a type of rifle-shaped blaster weaponry, typically with a longer barrel than other types of blasters.

## Specifications

- **Name:** Blaster rifle
- **Type:** Blaster
- **Cost:**
  - 1,000 credits with retractable stock
  - 900 credits without retractable stock
- **Shape:** Rifle-like
- **Size:** Two-handed weapon
- **Weight:** 4.5 kg
- **Capacity:**
  - 50 shots
  - Close-range stun setting available
  - Autofire mode available
- **Range:**
  - Optimum: up to 100 m
  - Maximum: up to 300 m
