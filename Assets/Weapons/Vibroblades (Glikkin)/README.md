# Vibroblades (Glikkin)

**Kind:** Model  
**Continuity:** Canon  
**Source:** [Vibroblades (Glikkin)](https://starwars.fandom.com/wiki/Vibroblades_%28Glikkin%29)

The Vibroblades were a set of unique Dual Vibroblades owned by the Kubaz Hunter Glikkin. These vibroblades were petar-like, with a curved blade on each end, protruding handle, and glowing blade edges.

## Specifications

- **Name:** Vibroblades
- **Type:** Petar-like dual vibroblades
- **Owners:** Glikkin
- **Affiliation:** Hunters of the Outer Rim
